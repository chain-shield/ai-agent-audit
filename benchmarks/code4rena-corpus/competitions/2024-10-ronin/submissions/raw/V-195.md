# Vulnerability details

## Proof of Concept
No Validations on Addresses: There are no checks to ensure that addresses assigned to the struct fields are valid, particularly ensuring they are not zero addresses.

Proof of Concept: If an external function can set the permit2 address to zero:
contract Router {
    RouterParameters public parameters;

    function setPermit2(address _permit2) public {
        parameters.permit2 = _permit2; // No validation
    }
}
Setting permit2 to address(0) will render related functionalities inoperative.

Impact:
1. Critical functions may fail if called with a zero address.
2. Could lead to loss of funds or non-functional contract features.
## Recommended Mitigation Steps
Validate addresses before assigning them. For example, ensure they are not zero addresses:
require(_permit2 != address(0), "Invalid address");
