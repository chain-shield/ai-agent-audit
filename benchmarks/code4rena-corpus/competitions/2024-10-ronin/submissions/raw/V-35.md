# Vulnerability details

## Impact
In the AggregateRouter.sol contract, the execute function contains a for loop that iterates over a series of commands. Under specific circumstances, particularly when certain commands fail without requiring a revert, the loop may fail to progress its index (commandIndex). This can result in the function entering an infinite loop, leading to a Denial of Service (DoS) by exhausting the gas provided for the transaction. The vulnerability arises from how the commandIndex is incremented within the execute function. The function processes a list of commands by iterating through each command and executing it. The loop relies on manually incrementing the commandIndex within an unchecked block at the end of each iteration.

Here is the critical part of the function.
```Solidity
// https://github.com/ronin-chain/katana-operation-contracts/blob/27f9d28e00958bf3494fa405a8a5acdcd5ecdc5d/src/aggregate-router/AggregateRouter.sol#L44-L58

    for (uint256 commandIndex = 0; commandIndex < numCommands;) {
      bytes1 command = commands[commandIndex];


      bytes calldata input = inputs[commandIndex];


      (success, output) = dispatch(command, input);


      if (!success && successRequired(command)) {
        revert ExecutionFailed({ commandIndex: commandIndex, message: output });
      }


      unchecked {
        commandIndex++;
      }
    }
```

***Command Execution Failure Without Revert***
If a command execution fails (success == false) but does not require a revert (successRequired(command) == false), the function proceeds without reverting.

## Recommended Mitigation Steps
To mitigate the risk of an infinite loop within the execute function, it is essential to ensure that the commandIndex is incremented reliably, even in cases where command execution fails without requiring a revert.
```Solidity
/// @inheritdoc Dispatcher
function execute(bytes calldata commands, bytes[] calldata inputs) public payable override isNotLocked {
  bool success;
  bytes memory output;
  uint256 numCommands = commands.length;
  if (inputs.length != numCommands) revert LengthMismatch();

  // loop through all given commands, execute them and pass along outputs as defined
unchecked {
  for (uint256 commandIndex = 0; commandIndex < numCommands; commandIndex++) {
    bytes1 command = commands[commandIndex];
    bytes calldata input = inputs[commandIndex];
    (success, output) = dispatch(command, input);

    if (!success && successRequired(command)) {
      revert ExecutionFailed({ commandIndex: commandIndex, message: output });
    }
  }
}
}
```
