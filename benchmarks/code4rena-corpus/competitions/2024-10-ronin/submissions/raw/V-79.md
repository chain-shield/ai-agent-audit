# Vulnerability details

## Proof of Concept
`_updatePosition` function responsible for updating the tick information when a position is minted or modified does not have proper checks to handle extreme tick values. When a user mints a position with `tickLower` set to -887272 and `tickUpper` set to 887272, the `_updatePosition` function attempts to update the tick information using these extreme values. This leads to a revert, preventing the position from being minted.

In KatanaV3Pool.sol, the vulnerability is in the [_updatePosition function](https://github.com/ronin-chain/katana-v3-contracts/blob/03c80179e04f40d96f06c451ea494bb18f2a58fc/src/core/KatanaV3Pool.sol#L342-L408)

The reason for this vulnerability is that the `_updatePosition` function assumes that the provided `tickLower` and `tickUpper` values are within valid ranges. It does not enforce this assumption, leading to issues when extreme tick values are used.

## Impact
When a user mints a position with extreme tick values (e.g., -887272 and 887272), the `mint` function will revert. This prevents users from creating positions with these extreme tick values, which may lead to unexpected behavior or denial of service.

In a scenario where Alice attempts to mint a position with `tickLower` set to -887272 and t`ickUpper` set to 887272, the following sequence of events occurs:

1. Alice calls the `mint` function of the KatanaV3Pool contract, providing the extreme tick values.
2. The `mint` function calls the `_modifyPosition` function, which in turn calls the `_updatePosition` function.
3. The `_updatePosition` function attempts to update the tick information using the extreme tick values.
4. The `ticks.update` function reverts due to the extreme tick values, causing the entire `mint` function to revert.
5. Alice's transaction fails, and she is unable to mint the position with the desired tick range.

This prevents users from minting positions with extreme tick values, limiting the flexibility and usability of the KatanaV3Pool contract.

## Recommended Mitigation Steps
The `_updatePosition` function should be modified to handle the case when both `tickLower` and `tickUpper` are at extreme values.

{
