# Vulnerability details

`setTreasury` function in the KatanaV3Factory contract allows the owner to update the treasury address, which is where protocol fees are sent. The function does not check if the new `_treasury` address is different from the current one. 

[KatanaV3Factory.sol#L93-L97](https://github.com/ronin-chain/katana-v3-contracts/blob/03c80179e04f40d96f06c451ea494bb18f2a58fc/src/core/KatanaV3Factory.sol#L93-L97)
```solidity
function setTreasury(address _treasury) external override onlyOwner {
    require(_treasury != address(0), "KatanaV3Factory: INVALID_TREASURY");
    emit TreasuryChanged(treasury, _treasury);
    treasury = _treasury; // @audit - Allows setting treasury to the same address
}
```
Occurs because the function only validates that `_treasury` is not the zero address, but it does not ensure that `_treasury` differs from the current treasury value. This incomplete input validation allows the owner to set treasury to itself, leading to a misleading `TreasuryChanged` event emission.

## Impact
It does not directly risk user funds, since setting treasury to itself is not a critical issue, however, it does allow generating misleading events that may confuse off-chain monitoring if the owner accidentally sets treasury to the current address, the event will incorrectly signal a change

## Proof of Concept
Assume the scenario

1. The current owner is 0xOwner and the treasury is set to 0xTreasury.
2. The owner calls setTreasury with the existing treasury address:
```solidity
// Assume the current owner is 0xOwner and treasury is 0xTreasury
KatanaV3Factory factory = KatanaV3Factory(0xFactoryAddress); 

// Owner calls setTreasury with the existing treasury address
factory.setTreasury(0xTreasury);

// The call succeeds and emits TreasuryChanged(0xTreasury, 0xTreasury)
// However, factory.treasury() remains unchanged as 0xTreasury

```
3. The call succeeds and emits TreasuryChanged(0xTreasury, 0xTreasury).
4. However, factory.treasury() remains unchanged and still returns 0xTreasury.

## Recommended Mitigation Steps
```diff
function setTreasury(address _treasury) external override onlyOwner {
    require(_treasury != address(0), "KatanaV3Factory: INVALID_TREASURY");
+   require(_treasury != treasury, "KatanaV3Factory: TREASURY_NOT_CHANGED");
    emit TreasuryChanged(treasury, _treasury);
    treasury = _treasury;
}
```
