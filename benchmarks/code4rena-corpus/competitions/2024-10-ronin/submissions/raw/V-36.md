# Vulnerability details

Flash function in KatanaV3Pool is vulnerable to reentrancy attacks due to improper locking mechanism implementation.

**Here's why it happens**

In [KatanaV3Pool.sol:L104-L109](https://github.com/ronin-chain/katana-v3-contracts/blob/03c80179e04f40d96f06c451ea494bb18f2a58fc/src/core/KatanaV3Pool.sol#L104-L109)
```solidity
modifier lock() {
  require(slot0.unlocked, "LOK");
  slot0.unlocked = false;
  _;
  slot0.unlocked = true; // <= @audit
}
```
In [KatanaV3Pool.sol:L768](https://github.com/ronin-chain/katana-v3-contracts/blob/03c80179e04f40d96f06c451ea494bb18f2a58fc/src/core/KatanaV3Pool.sol#L768)

```solidity
function flash(address recipient, uint256 amount0, uint256 amount1, bytes calldata data) external override lock {
  // ...

  IKatanaV3FlashCallback(msg.sender).katanaV3FlashCallback(fee0, fee1, data); // <= @audit

  // ...
}
```

**Due to two main factors**

1. The `lock` modifier releases the lock (`slot0.unlocked = true;`) prematurely, before the flash function completes its execution.
2. The `flash` function makes an external call (`katanaV3FlashCallback`) while the pool is in an intermediate state.

This combination allows for reentrancy, as the `lock` is released before the function finishes, and the external call provides an opportunity for malicious actors to re-enter the `flash` function.

## Impact
* Destabilization of the entire pool
* Manipulation of market prices

## Proof of Concept
Let's imagine the following scenario

1. Attacker deploys a malicious contract with a `katanaV3FlashCallback` function that calls flash again.
2. Calls `flash` on KatanaV3Pool with a significant amount.
3. KatanaV3Pool transfers tokens to the attacker and calls `katanaV3FlashCallback`.
4. The malicious `katanaV3FlashCallback` calls `flash` again before repaying the first loan.
5. Steps 3-4 repeat until the pool is drained or the transaction runs out of gas.

Simplified illustration
```solidity
contract MaliciousContract {
    KatanaV3Pool pool;
    uint256 count = 0;

    constructor(address _pool) {
        pool = KatanaV3Pool(_pool);
    }

    function attack(uint256 amount) external {
        pool.flash(address(this), amount, 0, "");
    }

    function katanaV3FlashCallback(uint256 fee0, uint256 fee1, bytes calldata data) external {
        if (count < 5) {  // Limit to prevent out-of-gas errors
            count++;
            pool.flash(address(this), amount, 0, "");
        }
        // Repay the flash loan here (omitted for brevity)
    }
}
```

## Recommended Mitigation Steps
Move the `slot0.unlocked = true;` line from the `lock` modifier to the end of the `flash` function
```diff
function flash(address recipient, uint256 amount0, uint256 amount1, bytes calldata data) external override lock {
    // ...

    emit Flash(msg.sender, recipient, amount0, amount1, paid0, paid1);
+   slot0.unlocked = true;
-   // slot0.unlocked = true; (removed from lock modifier)
}
```
