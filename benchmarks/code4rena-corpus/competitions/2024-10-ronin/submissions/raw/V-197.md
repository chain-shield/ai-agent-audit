# Vulnerability details

## Proof of Concept
Lack of Event Emission: The struct itself does not emit any events when parameters change, making it hard to monitor changes.

Proof of Concept
If parameter changes do not emit events, tracking them becomes difficult:
contract Router {
    RouterParameters public parameters;

    function setParameters(RouterParameters memory newParams) public {
        parameters = newParams; // No event emitted
    }
}
Impact: Difficulty in auditing or monitoring the contract’s state changes can lead to undetected malicious activity.

## Recommended Mitigation Steps
Emit events when parameters change:
event ParametersUpdated(RouterParameters newParams);
