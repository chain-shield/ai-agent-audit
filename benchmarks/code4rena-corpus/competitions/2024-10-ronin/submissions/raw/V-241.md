# Vulnerability details

## Proof of Concept
The migrate function can be called by any user by passing the MigrateParams calldata params values of someone else's position in V2 to the function arguments and mint new tokenId position by investing another user's liquidity. Only params.percentageToMigrate is checked in the function.

## Recommended Mitigation Steps
add a check on the liquidity owner
