# Vulnerability details

## Proof of Concept
Direct ETH Sending: The interface defines an error for ETH not being accepted, but it does not enforce this restriction, which can lead to the contract inadvertently accepting ETH transfers.

Proof of Concept
An external contract could attempt to send ETH:
contract EthSender {
    IAggregateRouter public aggregateRouter;

    constructor(address _aggregateRouter) {
        aggregateRouter = IAggregateRouter(_aggregateRouter);
    }

    function sendEth() external payable {
        // Attempt to send ETH to the contract
        payable(address(aggregateRouter)).transfer(msg.value);
    }
}
Impact: If the contract accepts ETH transfers inadvertently, it could lead to loss of funds, as these funds may not be retrievable.
## Recommended Mitigation Steps
Implement a receive function to reject direct ETH transfers:
receive() external payable {
    revert ETHNotAccepted();
}
