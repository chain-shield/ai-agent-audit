# Vulnerability details

## Proof of Concept
Potential Misuse of Governance Address: The governance address may be critical for managing the contract's functionality. If misconfigured or compromised, it can be a vector for malicious actions.

Proof of Concept: If the governance address can be set by anyone:
contract Router {
    RouterParameters public parameters;

    function setGovernance(address _governance) public {
        parameters.governance = _governance; // No checks
    }
}
An attacker could change the governance address to their own.
Impact: An attacker could gain control over governance functions, modifying contract behavior or even locking out legitimate users.

## Recommended Mitigation Steps
1. Limit governance address changes to a trusted entity or multi-signature wallet.
2. Use a mechanism for verifying the new governance address before assignment
