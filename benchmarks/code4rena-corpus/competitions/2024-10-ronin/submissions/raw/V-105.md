# Vulnerability details


- **Severity:** Medium
- **Likelihood:** High
- **Description:** Logical error in  `_isAuthorized()` function of Contract KatanaGovernance allowing unauthorized user to create pair with expired tokens(expiry is set by the variable `whitelistUntil`) 

 **Root Cause**: [KatanaGovernance.sol Line 375-381](https://github.com/ronin-chain/katana-operation-contracts/blob/27f9d28e00958bf3494fa405a8a5acdcd5ecdc5d/src/governance/KatanaGovernance.sol#L375-L381)
