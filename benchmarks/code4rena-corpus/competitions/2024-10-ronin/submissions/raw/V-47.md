# Vulnerability details

## Proof of Concept
The `initialize` function takes a `sqrtPriceX96` parameter, which represents the initial price of the pool. Users may perform trades or provide liquidity based on the assumption that the pool has a valid price.

The vulnerable code is
```solidity
int24 tick = TickMath.getTickAtSqrtRatio(sqrtPriceX96); // <= FOUND
```
and

```solidity
slot0 = Slot0({
  sqrtPriceX96: sqrtPriceX96, // <= FOUND
  // ...
});
```
* The `sqrtPriceX96` value is used to calculate the `tick` using the `TickMath.getTickAtSqrtRatio` function.
* The `sqrtPriceX96` value is then assigned to `slot0.sqrtPriceX96` without any validation.

## Recommended Mitigation Steps
```solidity
function initialize(uint160 sqrtPriceX96) external override {
  require(slot0.sqrtPriceX96 == 0, "AI");
  require(sqrtPriceX96 > 0, "Invalid price"); // <= ADD THIS LINE

  int24 tick = TickMath.getTickAtSqrtRatio(sqrtPriceX96);
  // ...
}
```
