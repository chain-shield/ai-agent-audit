# Vulnerability details


## Proof of Concept
The swap() function contains an incorrect token transfer logic when zeroForOne == false. In this case, the swap direction should be from token1 (input token) to token0 (output token). However, the code incorrectly transfers tokenOut instead of tokenIn, which can result in the wrong asset being sent to the recipient, potentially leading to incorrect behavior and loss of funds for the user.

    require(balance0Before.add(uint256(amount0)) <= balance0(), "IIA");

In the else clause where zeroForOne == false, the code transfers tokenOut when it should be transferring tokenIn.
This could lead to unexpected behavior in the swap logic, as the wrong token is being sent.
