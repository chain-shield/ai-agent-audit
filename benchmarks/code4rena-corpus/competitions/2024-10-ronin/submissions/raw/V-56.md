# Vulnerability details

**Description:** 
The `katanaV3Factory::initialize` function sets the following parameters (beacon, owner and treasury address) 
which are crucial for the protocol to work absolutely right. 

However, the function has a missing access control which does not checks who is calling it. If the attacker calls the `katanaV3Factory::initialize` function before the actual owner/developers, attacker will be able up to set the parameters best-suited for him. Allowing anyone to call it before the protocol team.

```javascript
function initialize(address beacon_, address owner_, address treasury_) external (*NoAccesControlChecksHere) {
  // Code

}

```

https://github.com/ronin-chain/katana-v3-contracts/blob/03c80179e04f40d96f06c451ea494bb18f2a58fc/src/core/KatanaV3Factory.sol#L46

This issue still exist even if its deployed on L2 Ronin Chain : 
If the attacker calls the function with attacker specified parameters before the protocol team. It will cost the protocol in manipulation of contract’s configuration.

OR  It can also be called after the (MainTeam) calls it.


**Impact:** 
The absence of access control allows malicious actors to manipulate the contract’s main functionality parameter and can result in:

1. Attacker setted critical parameters (beacon, owner, treasury).
2. Potential loss of funds or functionality of the KatanaV3Factory.
3. Loss of ownership from the contract

IMPACT : HIGH
LIKELIHOOD : MEDIUM

**Proof of Concept:** 

1. Protocol Team deploys the contracts.
2. Just before their calling this `katanaV3Factory::initialize` function
3. Attacker call it and sets the parameters according to him.   

SCENRIO 2:

1. Protocol Team deploys the contracts.
2. Attacker calls katanaV3Factory::initialize` function and sets the parameters according to him.   


**Recommended Mitigation:** 
 To mitigate it, we have to make some changes to constructor. In constructor we have set the owner and then only allows the owner to call it.

```javascript

constructor() {
    // disable initialization
    beacon = address(1);
+   owner = msg.sender;
  }

```
Then, adding the onlyOwner modifier to the `katanaV3Factory::initialize` function. Also we can also  remove the owner_ parameter 'If wanted'.
```javascript

  function initialize(address beacon_, address owner_, address treasury_) external _checkOwner {
   //Code
}

```
