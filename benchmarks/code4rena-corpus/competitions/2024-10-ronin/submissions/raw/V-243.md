# Vulnerability details

# Description 
`KatanaV3Factory::initialize` function missing access control over `initialize` function, anyone can manipulate `critical storage` of this protocol, any malicious caller can change `beacon`, `owner`, `treasury` and other storage variables and also a malicious actor can initialize any pool created previously.

# **Impact** 
Malicious actor can initialize any pool created previously with unintended parameters, and can change critical storage variables. And anyone can change storage later after initialize. 

# **Proof of Concepts**
 we can initialize this function anytime with any address.
- see below: 
```function initialize(address beacon_, address owner_, address treasury_) external {```

# **Recommended mitigation**
 This function should have access control over `initialize` function.
