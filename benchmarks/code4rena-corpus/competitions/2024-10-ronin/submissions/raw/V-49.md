# Vulnerability details

## Proof of Concept
During a swap operation in the `swap` function, the `feeGrowthGlobal0X128` and `feeGrowthGlobal1X12`8 variables are updated based on the swap direction (`zeroForOne`) and the fees collected. However, the corresponding `totalFeeGrowth0` and `totalFeeGrowth1` variables, which are supposed to keep track of the total fee growth, are not being updated.

[#L715-L716](https://github.com/ronin-chain/katana-v3-contracts/blob/03c80179e04f40d96f06c451ea494bb18f2a58fc/src/core/KatanaV3Pool.sol#L714-L716)
```solidity
// update fee growth global
if (zeroForOne) feeGrowthGlobal0X128 = state.feeGrowthGlobalX128; // <= FOUND
else feeGrowthGlobal1X128 = state.feeGrowthGlobalX128; // <= FOUND
```
To demonstrate the vulnerability

1. Let's say the KatanaV3Pool contract is deployed with the necessary parameters.
2. Bob mints liquidity to the pool by calling the `mint` function with appropriate parameters.
3. Alice performs a swap operation that collects fees by calling the `swap` function with the following parameters:

   * `recipient`: Alice's address
   * `zeroForOne`: true (token0 to token1 swap)
   * `amountSpecified`: A non-zero amount of token0 to swap
   * `sqrtPriceLimitX96`: The price limit for the swap
   * `data`: Any additional data required by the callback function

4. After the swap, the values of `feeGrowthGlobal0X128` and `feeGrowthGlobal1X128` are updated based on the fees collected, but `totalFeeGrowth0` and `totalFeeGrowth1` remain unchanged.

5. Alice repeats step 3 multiple times, causing the discrepancy between the global fee growth variables and the total fee growth variables to grow.

```solidity
// update fee growth global
if (zeroForOne) feeGrowthGlobal0X128 = state.feeGrowthGlobalX128; // <= FOUND
else feeGrowthGlobal1X128 = state.feeGrowthGlobalX128; // <= FOUND
```
As evident from the code, the `feeGrowthGlobal0X128` and `feeGrowthGlobal1X128` variables are updated based on the swap direction, but there are no corresponding updates to the `totalFeeGrowth0` and `totalFeeGrowth1` variables.

## Recommended Mitigation Steps
Update the `totalFeeGrowth0` and `totalFeeGrowth1` variables whenever the `feeGrowthGlobal0X128` and `feeGrowthGlobal1X128` variables are updated.
```solidity
if (zeroForOne) {
    feeGrowthGlobal0X128 = state.feeGrowthGlobalX128;
    totalFeeGrowth0 = state.feeGrowthGlobalX128; // Update totalFeeGrowth0
} else {
    feeGrowthGlobal1X128 = state.feeGrowthGlobalX128;
    totalFeeGrowth1 = state.feeGrowthGlobalX128; // Update totalFeeGrowth1
}
```
