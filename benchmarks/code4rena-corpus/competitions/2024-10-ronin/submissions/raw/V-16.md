# Vulnerability details

## Proof of Concept
The `KatanaV3Pool` contract is vulnerable to price manipulation using flash loans. Flash loans allow attackers to borrow large amounts of tokens without collateral for a single transaction, potentially destabilizing the pool's price and exploiting downstream DeFi protocols that rely on the manipulated price. This vulnerability arises from the fact that the pool's pricing mechanism does not adequately account for large, temporary fluctuations in liquidity, allowing attackers to manipulate the price and gain arbitrage opportunities.

The `flash` function in the `KatanaV3Pool` contract allows users to borrow tokens without upfront collateral as long as they return the borrowed amount plus a fee in the same transaction. However, there is no mechanism to prevent temporary manipulation of the pool's price during the flash loan, which can be exploited in a single transaction. An attacker could borrow a large amount of tokens via flash loans, manipulate the price in the pool, perform arbitrage across DeFi protocols, and return the flash loan, profiting from the price difference.

This attack can have a cascading effect on other DeFi protocols that rely on the pool for price feeds, such as lending platforms and synthetic assets.

Vulnerable code:
The `flash` function implementation does not prevent price manipulation, allowing an attacker to exploit the price oracle during the flash loan:
```solidity
function flash(address recipient, uint256 amount0, uint256 amount1, bytes calldata data) external override lock {
    require(IKatanaV3Factory(factory).flashLoanEnabled(), "FD");

    uint128 _liquidity = liquidity;
    require(_liquidity > 0, "L");

    uint256 paid0;
    uint256 paid1;

    // scope to avoid stack too deep error
    {
        address _token0 = token0;
        address _token1 = token1;
        uint256 fee0 = FullMath.mulDivRoundingUp(amount0, fee, 1e6);
        uint256 fee1 = FullMath.mulDivRoundingUp(amount1, fee, 1e6);
        uint256 balance0Before = balance0();
        uint256 balance1Before = balance1();

        if (amount0 > 0) TransferHelper.safeTransfer(_token0, recipient, amount0);
        if (amount1 > 0) TransferHelper.safeTransfer(_token1, recipient, amount1);

        IKatanaV3FlashCallback(msg.sender).katanaV3FlashCallback(fee0, fee1, data);

        uint256 balance0After = balance0();
        uint256 balance1After = balance1();
        address treasury = IKatanaV3Factory(factory).treasury();

        require(balance0Before.add(fee0) <= balance0After, "F0");
        require(balance1Before.add(fee1) <= balance1After, "F1");

        // sub is safe because we know balanceAfter is gt balanceBefore by at least fee
        paid0 = balance0After - balance0Before;
        paid1 = balance1After - balance1Before;

        if (paid0 > 0) {
            uint256 fees0 = FullMath.mulDiv(paid0, slot0.feeProtocolNum, slot0.feeProtocolDen);
            if (fees0 > 0) TransferHelper.safeTransfer(_token0, treasury, fees0);
            feeGrowthGlobal0X128 += FullMath.mulDiv(paid0 - fees0, FixedPoint128.Q128, _liquidity);
        }
        if (paid1 > 0) {
            uint256 fees1 = FullMath.mulDiv(paid1, slot0.feeProtocolNum, slot0.feeProtocolDen);
            if (fees1 > 0) TransferHelper.safeTransfer(_token1, treasury, fees1);
            feeGrowthGlobal1X128 += FullMath.mulDiv(paid1 - fees1, FixedPoint128.Q128, _liquidity);
        }
    }

    emit Flash(msg.sender, recipient, amount0, amount1, paid0, paid1);
}
```
PoC:
An attacker creates a contract that calls the `flash` function to borrow tokens and manipulates the price in the pool. After manipulating the price, the attacker executes an arbitrage trade using another DeFi platform that relies on the pool's price. Finally, the attacker repays the flash loan and profits from the price difference.
```javascript
// Import necessary dependencies
const { expect } = require("chai");
const { ethers } = require("hardhat");

describe("Price Manipulation via Flash Loan", function () {
    let katanaPool;
    let flashLoanAttacker;
    let token0;
    let token1;
    let attacker;

    beforeEach(async function () {
        // Deploy the KatanaV3Pool contract and tokens
        const Token = await ethers.getContractFactory("MockERC20");
        token0 = await Token.deploy("Token0", "TK0", ethers.utils.parseEther("1000000"));
        token1 = await Token.deploy("Token1", "TK1", ethers.utils.parseEther("1000000"));

        const KatanaV3Pool = await ethers.getContractFactory("KatanaV3Pool");
        katanaPool = await KatanaV3Pool.deploy(token0.address, token1.address);

        // Deploy the attack contract
        const FlashLoanAttacker = await ethers.getContractFactory("FlashLoanAttacker");
        flashLoanAttacker = await FlashLoanAttacker.deploy(katanaPool.address);

        [attacker] = await ethers.getSigners();
    });

    it("Should allow price manipulation via flash loan", async function () {
        // Step 1: Attacker borrows tokens using flash loan
        await flashLoanAttacker.connect(attacker).executeFlashLoan(ethers.utils.parseEther("10000"), ethers.utils.parseEther("10000"));

        // Step 2: Verify that the price has been manipulated
        const manipulatedPrice = await katanaPool.getPrice();
        console.log("Manipulated Price:", manipulatedPrice.toString());

        // Step 3: Attacker profits from price difference
        expect(manipulatedPrice).to.not.equal("0");

        // Step 4: Verify flash loan repayment
        const poolBalance0 = await token0.balanceOf(katanaPool.address);
        const poolBalance1 = await token1.balanceOf(katanaPool.address);
        expect(poolBalance0).to.be.at.least(ethers.utils.parseEther("10000"));
        expect(poolBalance1).to.be.at.least(ethers.utils.parseEther("10000"));
    });
});
```


The impact of this vulnerability is severe, as it allows attackers to manipulate the price of the pool temporarily, potentially affecting all users and external DeFi protocols that rely on the pool's price for trading, lending, or borrowing. This could lead to significant financial losses, market destabilization, and loss of confidence in the protocol.
1. The attacker could manipulate the pool's price to create arbitrage opportunities between DeFi platforms, profiting from the price difference.
2. By manipulating the price, an attacker could force liquidations on lending platforms that use the manipulated price as collateral.
