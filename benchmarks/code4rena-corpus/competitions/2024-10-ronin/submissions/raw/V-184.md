# Vulnerability details

## Proof of Concept
Improper Access Control: The dispatch function could execute sensitive commands without proper access control, potentially allowing anyone to manipulate assets or execute unintended commands.

Proof of Concept: Without an access control mechanism, an attacker could directly interact with dispatch to invoke privileged commands.
Attacker calls dispatch with a high-impact command.
The contract performs the command without validating the caller, potentially causing loss or misuse of funds.
Impact: High-risk functions could be executed by unauthorized users, leading to potential fund loss or privilege escalation

## Recommended Mitigation Steps
1. Add access control (e.g., onlyOwner or onlyAuthorized modifiers).
2. Use AccessControl from OpenZeppelin for managing permissions.

Example:Many smart contract hacks, like the Parity Multisig Wallet hack, stem from improper access control, allowing attackers to access restricted functions.
