# Vulnerability details

# **Description** 
`PoolInitializer` contract or any related contract using `createAndInitializePoolIfNecessary` function is not transfering funds anywhere. But This function is marked payable it means, this contract recieves funds using function but there is no withdraw mechanism or any fund handling property in contracts.

# **Impact** Locking of funds

# **Recommended mitigation** 
- Remove payable if Unnecessary.
- Add Withdrawal Mechanism if Needed
