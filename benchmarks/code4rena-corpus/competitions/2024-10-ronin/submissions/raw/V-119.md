# Vulnerability details


## Vulnerability details
The `increaseLiquidity` function lacks access control, allowing a malicious user to prevent others from burning their liquidity positions.

## Proof of Concept
Since no access control on [increaseLiquidity](https://github.com/ronin-chain/katana-v3-contracts/blob/03c80179e04f40d96f06c451ea494bb18f2a58fc/src/periphery/NonfungiblePositionManager.sol#L246) function , malicious user able to add a tiny amount of liquidity(1wei).

## Impact
A malicious user can execute a griefing attack by adding a tiny amount of liquidity (1 wei), continuously preventing the burning of a user's position.
