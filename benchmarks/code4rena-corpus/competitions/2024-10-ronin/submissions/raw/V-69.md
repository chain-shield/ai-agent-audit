# Vulnerability details

## Issue Description: The KatanaV3Pool.sol contains functionality for flash loans but lacks adequate fee and collateral checks, exposing the contract to potential economic exploits where users withdraw more than they are supposed to.

## Proof of State: In the flash function, fees are calculated but there is no mechanism to ensure that enough collateral or margin is maintained before the function call:


function flash(...) external {
    ...
    // Insufficient margin checks before the operation
}
## Mitigation: Implement collateral validation mechanisms before flash loans are executed. Add strict fee logic to ensure the contract is not drained through repeated flash loans with insufficient collateral.
