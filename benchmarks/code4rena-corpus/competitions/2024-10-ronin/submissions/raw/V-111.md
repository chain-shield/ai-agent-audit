# Vulnerability details

## Proof of Concept
In the `constructor` of the `PeripheryImmutableState` contract, when it was initialized, no validation was performed, so the `_factory` parameter can be an `address(0)` and if it is, even the `governance` variable will be an `address(0)` ; The EVM will treat `address(0)` as if it implements the `IKatanaV3Factory` interface, even though `address(0)` does not have any code or contract associated with it. This will lead to unexpected behavior.
```solidity
    constructor(address _factory, address _WETH9) {
        // @audit missing address(0) check
@>      factory = _factory;
        WETH9 = _WETH9;
@>      governance = IKatanaV3Factory(_factory).owner();
    }
```

## Recommended Mitigation Steps
```diff
    constructor(address _factory, address _WETH9) {
+       require(_factory != address(0), "Invalid factory address");
        factory = _factory;
        WETH9 = _WETH9;
        governance = IKatanaV3Factory(_factory).owner();
    }
```
