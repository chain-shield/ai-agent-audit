# Vulnerability details

There is an issue with the tracking of the total number of pools created. The `createPool` function, which is used to deploy new pools, does not increment the `totalPools` variable. This leads to an inconsistency between the actual number of pools created and the value stored in `totalPools`.

The flaw arises from the missing logic to increment `totalPools` after a new pool is successfully created. 

**Scenario:**

1. Alice calls the `createPool` function with valid parameters to create a new pool.
2. The `createPool` function deploys a new pool contract and updates the `getPool` mappings.
3. However, the `totalPools` variable is not incremented.
4. Bob, another user or an external contract, relies on the value of `totalPools` to make certain decisions or calculations.
5. Due to the inconsistency, Bob's actions or computations may be based on incorrect information about the total number of pools.

## Impact
Any external tools or dashboards relying on the `totalPools` variable will display incorrect information about the total number of pools in the system.

## Proof of Concept
[KatanaV3Factory.sol#L86-L90](https://github.com/ronin-chain/katana-v3-contracts/blob/03c80179e04f40d96f06c451ea494bb18f2a58fc/src/core/KatanaV3Factory.sol#L86-L91)
```solidity
function createPool(address tokenA, address tokenB, uint24 fee) external override returns (address pool) {
    // ...
    pool = deploy(address(this), token0, token1, fee, tickSpacing);
    getPool[token0][token1][fee] = pool;
    getPool[token1][token0][fee] = pool;
    emit PoolCreated(token0, token1, fee, tickSpacing, pool); // @audit - totalPools is not incremented
}
```
As shown above, the `createPool` function deploys a new pool, updates the `getPool` mappings, and emits the `PoolCreated` event. However, it does not increment the `totalPools` variable.

## Recommended Mitigation Steps
Incrementing `totalPools` after creating a new pool, the contract will maintain an accurate count of the total number of pools created.
```diff
+ uint256 public totalPools;
+
  function createPool(address tokenA, address tokenB, uint24 fee) external override returns (address pool) {
      // ...
      pool = deploy(address(this), token0, token1, fee, tickSpacing);
      getPool[token0][token1][fee] = pool;
      getPool[token1][token0][fee] = pool;
+     totalPools++;
      emit PoolCreated(token0, token1, fee, tickSpacing, pool);
  }
```
