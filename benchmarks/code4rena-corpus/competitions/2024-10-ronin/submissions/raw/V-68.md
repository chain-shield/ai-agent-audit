# Vulnerability details

## Issue Description: The KatanaV3Factory.sol allows creation and deployment of new pools but lacks clear ownership transfer mechanics for pools it deploys, potentially allowing an unauthorized transfer of ownership.

## Proof of State: Ownership is initially assigned but lacks mechanisms to securely transfer control or manage permissions on newly created pools:


address public owner;
function createPool(...) external returns (...) {
    // No transfer validation
}

## Mitigation: Include secure ownership transfer logic in the factory to ensure proper control over deployed pools. This can be done by verifying authorized controllers before allowing ownership changes.
