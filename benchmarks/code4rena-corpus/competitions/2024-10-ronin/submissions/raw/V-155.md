# Vulnerability details

## Proof of Concept


** Summary **
In the Katana governance system, updating the router through the `setRouter` function without granting the necessary permissions results in reverted calls from the new Router. This issue arises because, unlike the `initializeV2` function, the `setRouter` function only updates the router but does not automatically set it as an allowed actor. Consequently, all calls from the newly assigned router fail, as the permissions to execute are not granted.

** Vulnerability Details **
When the router is updated using `setRouter`, calls originating from this new router revert due to lack of authorization. This breaks the flow of governance functions and creates operational issues.

```solidity
@audit>> 1 >>>    _setRouter(aggregateRouter);

_setAllowedActor(legacyPermissionedRouter, true);

@audit>> 2 >>>      _setAllowedActor(aggregateRouter, true);

```
In this `initializeV2` function, we see that once the router is set, it is also granted the necessary permissions as an allowed actor, ensuring that calls from the router are properly handled.


** Relevant Code from `setRouter` **

```solidity
/**
 * @inheritdoc IKatanaGovernance
 */
function setRouter(address router) external onlyOwner {

@audit>> Only sets>>>    _setRouter(router);

}
```
The `setRouter` function, however, only assigns the router without configuring the necessary permissions. Calls from this router will revert until it is explicitly set as an allowed actor.

** Impact **
The absence of permissions for the new router means that:
1. All operations and governance actions made from the new router will fail, disrupting the flow and functionality of governance.


## Recommended Mitigation Steps

To ensure that all calls from the newly assigned router do not revert due to permission issues, update the `setRouter` function to also include a call to `_setAllowedActor(router, true)` after assigning the router. This follows the pattern set in `initializeV2`, where the router is set and permissions are granted concurrently. 

**Updated `setRouter` Function Recommendation**:
```solidity
/**
 * @inheritdoc IKatanaGovernance
 */
function setRouter(address router) external onlyOwner {
    _setRouter(router);
++    _setAllowedActor(router, true);
}
```
