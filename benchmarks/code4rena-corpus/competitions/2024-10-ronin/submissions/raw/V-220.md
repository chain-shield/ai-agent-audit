# Vulnerability details

## Summary

An overflow vulnerability exists in the cachePoolKey function where _nextPoolId++ can silently overflow when reaching its maximum value (2^80 - 1). When this occurs, the next pool creation would attempt to reuse ID 0, potentially colliding with an existing pool mapping. This can lead to system inconsistency where new pools cannot be created and existing pool mappings could be compromised.

```solidity
function cachePoolKey(address pool, PoolAddress.PoolKey memory poolKey) private returns (uint80 poolId) {
    poolId = _poolIds[pool];
    if (poolId == 0) {
        _poolIds[pool] = (poolId = _nextPoolId++); // Key line
        _poolIdToPoolKey[poolId] = poolKey;
    }
}
```

The function assigns the current value of _nextPoolId to poolId BEFORE incrementing

When _nextPoolId is at max value (2^80 - 1):
- The assignment to poolId will work (gets max value)
- But the increment operation (_nextPoolId++) will overflow
- Next pool creation attempt will use _nextPoolId = 0

## Impact
- If a pool already exists with ID 0, the overflowed _nextPoolId could cause a collision
- Subsequent pool creations would fail since ID 0 would be already taken
- System could become partially or fully unusable for new pool creation

Real-world scenario:
```solidity
// Initial state
_nextPoolId = type(uint80).max;  // 2^80 - 1
existingPool has ID 0

// First pool creation after max
pool1 calls cachePoolKey:
- Gets assigned ID = 2^80 - 1 (last valid ID)
- _nextPoolId overflows to 0

// Second pool creation
pool2 calls cachePoolKey:
- Checks _poolIds[pool2] == 0 (true, new pool)
- Tries to assign _nextPoolId (0)
- But ID 0 is already taken by existingPool
- System state becomes inconsistent
```

## Fix
```solidity
function cachePoolKey(address pool, PoolAddress.PoolKey memory poolKey) private returns (uint80 poolId) {
    poolId = _poolIds[pool];
    if (poolId == 0) {
        require(_nextPoolId != 0, "Pool ID overflow"); // Check before assignment
        _poolIds[pool] = (poolId = _nextPoolId);
        _poolIdToPoolKey[poolId] = poolKey;
        _nextPoolId++; // Separate increment
    }
}
```
