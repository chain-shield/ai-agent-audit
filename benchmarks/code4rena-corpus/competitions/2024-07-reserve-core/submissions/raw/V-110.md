# Vulnerability details

## Description
The withdraw function in the smart contract lacks proper access control mechanisms. This function is marked as external, allowing any external account or contract to call it. However, there is no verification to ensure that only the account owner or authorized parties can initiate a withdrawal. This oversight could potentially allow unauthorized users to withdraw funds from any account.

## Impact
The absence of access control in the withdraw function poses a critical security risk. An attacker could exploit this vulnerability to:

- Withdraw funds from any account without authorization.
- Drain the contract of its assets.
- Disrupt the normal operation of the system.

## Recommended Mitigation
Implement proper access control by adding a check to ensure that only the account owner can initiate a withdrawal. This can be achieved by:

Adding a msg.sender check at the beginning of the function:
```solidity
withdraw(address account, uint256 endId) external {
    require(msg.sender == account, "Caller must be the account owner");
    // ... (rest of the function)
}
```
