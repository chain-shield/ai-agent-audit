# Vulnerability details

## Impact
The result of ``quantities[i]`` will be an underflow, when ``erc20s[i])).decimals()`` is 6 and the rounding is ``FLOOR``.

So, a function that triggers ``BasketHandler#quote`` then the decimal token is 6 and the rounding is ``FLOOR``, will underflow.

## Proof of Concept
see this code:
```
 function shiftl_toUint(
        uint192 x,
        int8 decimal,
        Rounding Mode
    ) internal pure return (uint256) {
        // Handle overflow cases
        if (x == 0) return 0; // always countable, no matter what the decimal is
        if (decimal <= -42) return (rounding == CEIL ? 1 : 0);
        if (96 <= decimal) return UIntOutOfBounds();

        decimal -= 18; // shift so that toUint occurs at the same time.

        uint256 coeff = uint256(10**abs(decimal));
        return decimal >= 0 ? uint256(x * coefficient) : uint256(_divrnd(x, coefficient, rounding));
    }
```
Assume that ``x`` is ``100000000000`` and ``decimals = 6``, and ``rounding`` is FLOOR.
So, ``_divrnd`` will be triggered.
```
function _divrnd(
    uint256 numerator,
    uint256 divisor,
    Rounding Mode Rounding Mode
) pure return(uint256) {
    uint256 result = numerator/divisor;

    if (rounding == FLOOR) return result;

    if (rounding == RATE) {
        if (numerator % divisor > (divisor - 1) / 2) {
            result ++;
        }
    } else {
        if (numerator % divisor != 0) {
            result ++;
        }
    }

    returns the result;
}
```
since ``rounding`` is FLOOR, then the result will be ``0``.
Because the decimal is 6, then ``decimal -= 18`` is -12
so, the ``coefficient`` will be ``10**12``.

### POC
- run with ``forge test``
```
pragma solidity 0.8.19;
import "forge-std/Test.sol";
import "../libraries/Fixed.sol";

contract PoC is Test {
    using FixLib for uint192;


     function test_qoute() public {
     uint256 result = shiftl_toUint(100000000000, 6, FLOOR);
     assertEq(result, 0);

    }

    function shiftl_toUint(uint192 x, int8 decimals) internal pure returns (uint256) {
        return shiftl_toUint(x, decimals, FLOOR);
    }

    /// Shift this uint192 left by `decimals` digits, and convert to a uint.
    /// @return x * 10**decimals
    // as-ints: x * 10**(decimals - 18)
    function shiftl_toUint(
        uint192 x,
        int8 decimals,
        RoundingMode rounding
    ) internal pure returns (uint256) {
        // Handle overflow cases
        if (x == 0) return 0; // always computable, no matter what decimals is
        if (decimals <= -42) return (rounding == CEIL ? 1 : 0);
        if (96 <= decimals) revert UIntOutOfBounds();

        decimals -= 18; // shift so that toUint happens at the same time.

        uint256 coeff = uint256(10**abs(decimals));
        return decimals >= 0 ? uint256(x * coeff) : uint256(_divrnd(x, coeff, rounding));
    }
}
```
