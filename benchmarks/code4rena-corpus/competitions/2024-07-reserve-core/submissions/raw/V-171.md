# Vulnerability details

## Summary
The div() function is susceptible to overflow when dividing large values, especially if the divisor is a large constant. This may cause the function to revert or yield incorrect results.


## Impact
Overflow during division could disrupt the contract’s operations, potentially causing a loss of funds or other significant errors in the contract's state.

##Reproduction Steps:
Input large values into the div() function.
Observe the overflow or reversion

## Tools Used
Manual Review
## Recommended Mitigation 
Implement overflow checks using Solidity's SafeMath library or upgrade to Solidity 0.8.0 or higher to prevent overflows.
