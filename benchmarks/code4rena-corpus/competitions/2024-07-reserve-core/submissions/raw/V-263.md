# Vulnerability details

## Vulnerability Description
The `BasketHandler.sol` contract lacks a mechanism to remove individual tokens from the basket if they become permanently disabled or significantly devalued. The current design only allows for disabling the entire basket or setting a new prime basket, but does not provide granular control over individual tokens within an existing basket. If a token in the basket becomes permanently disabled or loses its value (for example, due to a hack, rug pull, or other catastrophic event), there's no clear mechanism in this contract to remove just that specific token from the basket.
## Impact
- Reduced RToken Value: If a token in the basket becomes worthless, it would continue to be counted in the basket's value, potentially leading to an inflated perceived value of the RToken.
- Impaired Redemption: Users might not be able to redeem their RTokens for the full expected value, as part of the backing would be in the disabled or worthless token.
- Inaccurate Pricing: Functions like `price()` and `quote()` would include the compromised token in their calculations, leading to incorrect results.

## Proof of Concept
The vulnerability is evident in the structure of the BasketHandlerP1 contract. Specifically:

- The `basket` state variable holds the current basket configuration:
```
    Basket private basket;
```
- The `disableBasket()` function can only disable the entire basket: 
```
    function disableBasket() external {
        require(_msgSender() == address(assetRegistry), "asset registry only");

        uint256 len = basket.erc20s.length;
        uint192[] memory refAmts = new uint192[](len);
        for (uint256 i = 0; i < len; ++i) refAmts[i] = basket.refAmts[basket.erc20s[i]];
        emit BasketSet(nonce, basket.erc20s, refAmts, true);
        disabled = true;

        trackStatus(); // does NOT interact with collateral plugins or tokens
    }
```
- The `setPrimeBasket()` function replaces the entire prime basket:
```
    function setPrimeBasket(IERC20[] calldata erc20s, uint192[] calldata targetAmts) external {
        _setPrimeBasket(erc20s, targetAmts, false);
    }
```
- There is no function that allows for the removal of a single token from the basket while preserving the rest of the basket's composition.

## Tools Used
Manual code review
## Recommended Mitigation Steps
- Add a new function that allows governance to remove specific tokens from the basket. For example:
```
function removeTokenFromBasket(IERC20 token) external governance {
    require(_erc20s.contains(address(token)), "Token not in basket");
    
    // Remove token from basket
    basket.erc20s.remove(token);
    delete basket.refAmts[token];
    
    // Recalculate basket weights
    _recalculateBasketWeights();
    
    emit TokenRemovedFromBasket(token);
}
```
