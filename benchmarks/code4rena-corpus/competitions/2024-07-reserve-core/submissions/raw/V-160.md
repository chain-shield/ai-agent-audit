# Vulnerability details

## Impact
Unintended behavior and unchained trades as commented by the protocol

## Proof of Concept
The problem arises in [`Rebalance`](https://github.com/code-423n4/2024-07-reserve/blob/3f133997e186465f4904553b0f8e86ecb7bbacbf/contracts/p1/BackingManager.sol#L120-L122) we see in line 120 
`require(tradesOpen == 0, "trade open");

But this contradict the intended logic as commented by the protocol Dev in `settleTrade`
