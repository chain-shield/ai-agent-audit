# Vulnerability details

The `refresh()` function in `AssetRegistry` is responsible for updating the state and price information of these assets to ensure the system operates with accurate data. However, there is a critical issue in the implementation of the `refresh()` function that can lead to inconsistencies in the `AssetRegistry` state, causing dependent functions to behave incorrectly and compromising the stability of the entire system.

## Impact
* If an asset's `refresh()` function modifies the `_erc20s` array by registering or unregistering assets during the iteration, it will lead to an inconsistent state in the `AssetRegistry`. The length and contents of the `_erc20s` array will be different from what is expected, causing discrepancies in the system.

* The `refresh()` function may not refresh all the intended assets if the `_erc20s` array is modified during iteration. This means that some assets might not have their state and price information updated.

## Proof of Concept
The issue can be observed in the following scenario.

* The `AssetRegistry` is initialized with an initial set of assets.

* The `refresh()` function is called to update the state and price information of the registered assets.

* During the iteration in the `refresh()` function, an asset's refresh() function is called.

* The asset's `refresh()` function modifies the `_erc20s` array by registering or unregistering assets.

* The iteration continues, but the length and contents of the `_erc20s` array have changed, causing inconsistencies.

* After the `refresh()` function completes, the `AssetRegistry` state is inconsistent, and dependent functions may behave incorrectly.

## Recommended Mitigation Steps
Snapshot the `_erc20s` array before iterating over the `_erc20s` array in the `refresh()` function, create a snapshot of the array and use the snapshot for the iteration. The `AssetRegistry` to ensure that asset registration and unregistration cannot happen within an asset's `refresh()` function. Instead, provide separate functions for asset registration and unregistration that can only be called by authorized entities or governance.
