# Vulnerability details

##Summary
The register function allows for the registration of a new asset in the registry. It is critical to the integrity of the system as it determines which assets are recognized and managed by the contract. However, this function lacks access control, meaning any external user can call it to register an asset.


## Impact
Without access control, a malicious actor could register a harmful or fraudulent asset, potentially leading to systemic failures or security breaches within the ecosystem. This could compromise the trustworthiness of the asset registry and lead to financial losses for users and stakeholders.

Exploit Scenario:

An attacker deploys a malicious asset contract.
The attacker calls the register function with their contract, adding it to the registry.
The malicious asset is now treated as a legitimate asset by the system, potentially causing disruptions or allowing the attacker to exploit other parts of the system.

## Tools Used
Manual Review

## Recommended Mitigation 
Implement access control to ensure that only authorized addresses (such as a governance or owner address) can register assets. This can be achieved using OpenZeppelin's Ownable or AccessControl contracts.
