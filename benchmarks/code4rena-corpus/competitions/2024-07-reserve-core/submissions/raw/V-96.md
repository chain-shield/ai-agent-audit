# Vulnerability details

## Impact
Detailed description of the impact of this finding.

The deploy function does not check the return values of the init function calls. 

If any of these calls fail silently, the system could be deployed in a partially uninitialised or broken state. 

This could lead to undefined behaviour and potential security vulnerabilities.

Description:
The Akropolis platform, a DeFi protocol that provides yield farming and savings pools, suffered a significant exploit due to a vulnerability related to unchecked return values in its smart contracts. 

The vulnerability allowed the hacker to bypass the contract’s logic and re-enter certain functions multiple times, leading to the unauthorised minting of tokens and withdrawal of funds.

The attacker exploited the deposit function, which did not properly check the return values of certain internal calls, particularly those involved in the interaction with the Curve contracts. 

	•	Vulnerable Code (simplified example):
```solidity
function deposit(uint256 amount) external {

    balances[msg.sender] += yTokens;
```

## Recommended Mitigation Steps

Add checks for the successful execution of each init call by ensuring that they throw or revert on failure. 

Alternatively, wrap these calls in try-catch blocks (where applicable) and handle errors appropriately.
