# Vulnerability details

## Impact
Detailed description of the impact of this finding.

Dependence on Predictable Environment Variable in the delegateBySig function on the StRSRVotes contract

Contract: StRSRP1Votes
Function Name: delegateBySig(address,uint256,uint256,uint8,bytes32,bytes32)
PC Address: 12248
Estimated Gas Usage: 1427 - 1522

The delegateBySig function relies on the block.timestamp environment variable to determine whether a signature has expired:
```sol
require(block.timestamp <= expiry, "signature expired");
```

Using block.timestamp to enforce expiration can be problematic because it is a predictable and manipulatable value. 

A malicious miner could manipulate the timestamp of a block within a reasonable range to allow a transaction to pass or fail, depending on their incentive. 

This introduces a trust assumption on miners, which could lead to unexpected behaviours or security vulnerabilities.

Extend the validity of a signature beyond its intended expiration, which could allow unauthorised vote delegation.

Reject a valid signature by adjusting the timestamp to fall after the expiration, causing denial of service for the user.

## Recommended Mitigation Steps
To mitigate this risk, it is recommended to use a different mechanism for signature expiration that is less reliant on environment variables. 

Oracles can provide external data that is generally more resistant to manipulation by blockchain participants, such as miners.

```sol
interface ITimeOracle {
    function getCurrentTime() external returns (uint256);
}

contract StRSRP1Votes {
    ITimeOracle public timeOracle;

    constructor(address oracleAddress) {
        timeOracle = ITimeOracle(oracleAddress);
    }

    function delegateBySig(
        address delegatee,
        uint256 nonce,
        uint256 expiry,
        uint8 v,
        bytes32 r,
        bytes32 s
    ) public {
        uint256 currentTime = timeOracle.getCurrentTime();
        require(currentTime <= expiry, "signature expired");
        
        address signer = ECDSAUpgradeable.recover(
            _hashTypedDataV4(keccak256(abi.encode(_DELEGATE_TYPEHASH, delegatee, nonce, expiry))),
            v,
            r,
            s
        );
        require(nonce == _useDelegationNonce(signer), "invalid nonce");
        _delegate(signer, delegatee);
    }
}
```
