# Vulnerability details

## Summary
The `RewardControl.sol::withdrawFor` function is designed to withdraw tokens from an account. However, it withdraws the tokens to the same account it withdraws from, leading to unexpected behavior and rendering the function ineffective.

## Vulnerability Details
The `RewardControl.sol::withdrawFor` function attempts to withdraw tokens from an account (from) and transfer them back to the same account (from). This is counterproductive, as it does not achieve any meaningful transfer or withdrawal of funds.

## Impact
This function does not perform the intended action of withdrawing tokens, leading to user confusion and a lack of functionality

## Tools Used
Manual code review

## Recommendations
Modify the withdrawFor function to allow withdrawals to a different account.
