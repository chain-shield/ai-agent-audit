# Vulnerability details

**Root Cause**
In the [_validateArtCreationSignature](https://github.com/code-423n4/2024-08-phi/blob/8c0985f7a10b231f916a51af5d506dd6b0c54120/src/PhiFactory.sol#L589-L593) function in `PhiFactory.so`l, the signature expiration check is performed against the `expiresIn_` value decoded from `signedData_`
```solidity
function _validateArtCreationSignature(bytes calldata signedData_, bytes calldata signature_) private view {
    if (_recoverSigner(keccak256(signedData_), signature_) != phiSignerAddress) revert AddressNotSigned();
    (uint256 expiresIn_,,) = abi.decode(signedData_, (uint256, string, bytes));
    if (expiresIn_ <= block.timestamp) revert SignatureExpired();
}
```
> However, the actual expiration time for the art creation is specified in the `endTime` field of the `CreateConfig` struct, which is not checked in this function.

## Impact
The art creator suffers from the inability to enforce the intended signature expiration time for art creation.

An attacker can create art using an expired signature, bypassing the intended time restriction.

## Proof of Concept
1. `createArt` is called with.

   * `signedData` containing `expiresIn_ = 0`
   * `config.endTime = 0`

2. `createArt` does not revert
3. The assertion fails because `lastReverted` is false even though `e.block.timestamp > config.endTime`

This indicates a bug where `createArt` allows creating art with an expired signature.

Internal pre-conditions:

1. `phiSignerAddress` needs to be set to the attacker's address
2. `artCreateFee` needs to be set to a value the attacker can afford

**Attack Path:**

* Attacker calls `createArt` with `signedData_` containing `expiresIn_ = 0` and `config.endTime` set to a future timestamp
* `_validateArtCreationSignature` passes because `expiresIn_` is not checked against the current timestamp
* Art is created with the expired signature because `config.endTime` is not validated

## Tools Used
Manual review

## Recommended Mitigation Steps
Modify the `_validateArtCreationSignature` function to check the `endTime` field from the `CreateConfig `struct instead of `expiresIn_`
```diff
function _validateArtCreationSignature(bytes calldata signedData_, bytes calldata signature_) private view {
    if (_recoverSigner(keccak256(signedData_), signature_) != phiSignerAddress) revert AddressNotSigned();
-   (uint256 expiresIn_,,) = abi.decode(signedData_, (uint256, string, bytes));
-   if (expiresIn_ <= block.timestamp) revert SignatureExpired();
+   (,, CreateConfig memory config) = abi.decode(signedData_, (uint256, string, CreateConfig));
+   if (block.timestamp > config.endTime) revert SignatureExpired();
}
```
