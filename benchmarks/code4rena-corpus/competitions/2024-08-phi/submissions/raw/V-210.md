# Vulnerability details

## Impact
function _curve(uint256 targetAmount_) private pure returns (uint256) {
        return (TOTAL_SUPPLY_FACTOR * CURVE_FACTOR * 1 ether) / (TOTAL_SUPPLY_FACTOR - targetAmount_)
            - CURVE_FACTOR * 1 ether - INITIAL_PRICE_FACTOR * targetAmount_ / 1000;
    }

If targetAmount_ equals TOTAL_SUPPLY_FACTOR, this will result in a division by zero, causing the transaction to revert.


## Recommended Mitigation Steps
Add a check to ensure that targetAmount_ does not equal TOTAL_SUPPLY_FACTOR:

require(targetAmount_ < TOTAL_SUPPLY_FACTOR, "Division by zero");
