# Vulnerability details

## Impact
This leads to the full crash of the system, since functions with `external` visibility can't be called by internally in the contract

## Proof of Concept
functions with `external` visibility can't be called internally in the contract, meaning that the `PhiFactory` contract won't work at all after deployment. 
Here are the function, which visibility should be changed to `internal`:
``` 
function signatureClaim(
        bytes calldata signature_,
        bytes calldata encodeData_,
        MintArgs calldata mintArgs_
    )
        external
        payable
        whenNotPaused
    {
```
```
 function merkleClaim(
        bytes32[] calldata proof_,
        bytes calldata encodeData_,
        MintArgs calldata mintArgs_,
        bytes32 leafPart_
    )
        external
        payable
        whenNotPaused
    {
```
Here is the function which visibility should be changet to public, since it should be able to be called both externally and internally:
```
function claim(bytes calldata encodeData_) external payable {
```
## Tools Used
manual review
## Recommended Mitigation Steps
change the `signatureClaim()` and `merkleClaim()` functions visibility to `internal` and change the `claim()` function visibility to public, since it is called internally from the `batchClaim()` functiin.
