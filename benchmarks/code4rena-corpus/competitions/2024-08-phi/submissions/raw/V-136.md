# Vulnerability details

## Vulnerability Detail

In the `_handleTrade` function, the state variable `lastTradeTimestamp[credId_][curator_]` is updated after the `safeTransferETH` function which sends ETH to `msg.sender` when `exceePayment > 0`. This is referred to as a `re-entrancy` vulnerability as a malicious contract could reenter the contract to bypass the SHARE_LOCK_PERIOD check in `sellShareCred`.

```solidity
    function _handleTrade(
        uint256 credId_,
        uint256 amount_,
        bool isBuy,
        address curator_,
        uint256 priceLimit
    )
        internal
        whenNotPaused
    {
        ...

        _updateCuratorShareBalance(credId_, curator_, amount_, isBuy);

        if (isBuy) {
            cred.currentSupply += amount_;
            uint256 excessPayment = msg.value - price - protocolFee - creatorFee;
            if (excessPayment > 0) {
                _msgSender().safeTransferETH(excessPayment);
            }
            lastTradeTimestamp[credId_][curator_] = block.timestamp;
        } else {
            cred.currentSupply -= amount_;
            curator_.safeTransferETH(price - protocolFee - creatorFee);
        }

        ...
    }
```

## Impact

A distributor can significantly increase his shareNumber with a flash loan and take most of the distributed reward for himself.

## Proof of Concept

1.deploy a malicious contract implementing the fallback function.
2.get a flashloan of ETH
3.call the function `buyShareCred` with `msg.value` bigger than `price + protocolFee + creatorFee` to trigger the logic when `exceePayment > 0`.
4.call the function `distribute` to take most of the distributed reward.
5.call the function `sellShareCred` in `fallback()` to bypass the SHARE_LOCK_PERIOD check and withdraw the ETH.
6.repay the flashloan with ETH.

## Recommended Mitigation Steps

Update the state variable `lastTradeTimestamp[credId_][curator_]` before invoking the `safeTransferETH` function which sends ETH to `msg.sender`.

```solidity

        if (isBuy) {
            cred.currentSupply += amount_;
            lastTradeTimestamp[credId_][curator_] = block.timestamp;
            uint256 excessPayment = msg.value - price - protocolFee - creatorFee;
```
