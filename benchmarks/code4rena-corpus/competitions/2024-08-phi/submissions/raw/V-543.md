# Vulnerability details

## Impact

`PhiFactory.createArt` may fail if the user sends more ether than `artCreateFee`, because when creating a new art, it calling `PhiNFT1155.createArtFromFactory` that will try to return the excess ether back to the factory, but the factory does not have a `receive`/`fallback` to handle this situation.

## Proof of Concept

`test_DoSinRefund` is a PoC, the rest is setup and helpers for calling complex functions
