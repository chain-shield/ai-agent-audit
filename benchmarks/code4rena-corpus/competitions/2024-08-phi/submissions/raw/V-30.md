# Vulnerability details

## Impact
DOS. 
The recipient address will never claim a art token when the token ID will have the value `0`.

## Description
In the `PhiNFT1155::claimFromFactory` function, the transaction is reverted every time the `tokenId=0`, and this value comes from the `PhiNFT1155::_artIdToTokenId` mapping which has `artId` as its key.So for a given value of `artId`, we will have `_artIdToTokenId[artId]=0` which is our `tokenId`. And in this particular case, the `PhiNFT1155::claimFromFactory` function will revert and the recipient address will never receive his art token.
```solidity
    function claimFromFactory(
        uint256 artId_,
        address minter_,
        address ref_,
        address verifier_,
        uint256 quantity_,
        bytes32 data_,
        string calldata imageURI_
    )
        external
        payable
        whenNotPaused
        onlyPhiFactory
    {
@>      uint256 tokenId_ = _artIdToTokenId[artId_];
@>      if (tokenId_ == 0) {
            revert InValdidTokenId();
        }
        
        // ...
    }
```
And no restrictions or special status has been mentioned anywhere in the documentation for `tokend with ID 0`. So a `token with ID 0` can be minted and assigned to an address. So it's this token that will block the claiming of art token.

## Proof of Concept
Create a temporary public function in `PhiNFT1155.sol` file for directly change the key and value of `_artIdToTokenId` mapping. it is just for the test.
```solidity
    function setArtToken(uint256 artId, uint256 tokenId) public {
        _artIdToTokenId[artId] = tokenId;
    }
```
After that in the test `PhiFactory.t.sol` file add these line of code and execute the test:
```solidity
    // Import this contract a top of the file
    import {PhiNFT1155} from "../src/art/PhiNFT1155.sol";

    // Add these two declaration in the top of setUp function
    PhiNFT1155 phiNFT1155;
    IPhiFactory phiFactory2;

    // And finally add this function after the setUp function 
    function test_claim_from_factory_revert_when_token_id_is_zero() public {
        address minter_ = makeAddr(("minter_"));
        address ref_ = makeAddr(("ref_"));
        address verifier_ = makeAddr(("verifier_"));
        uint256 quantity_ = 10;
        bytes32 data_ = "Just for test";
        uint256 artId = 1;
        uint256 tokenId = 0;

        phiNFT1155.setArtToken(artId, tokenId);
        vm.startPrank(address(phiFactory2));
        phiNFT1155.claimFromFactory(artId, minter_, ref_, verifier_, quantity_, data_, IMAGE_URL);
        vm.stopPrank();
    }
```
Execute this test will fail with the error `FAIL. Reason: InValdidTokenId()`.


## Tools Used
Manual analysis and fuzz test.

## Recommended Mitigation Steps
Remove the revert condition when the `tokenId is equal to 0`.
```diff
    function claimFromFactory(
        uint256 artId_,
        address minter_,
        address ref_,
        address verifier_,
        uint256 quantity_,
        bytes32 data_,
        string calldata imageURI_
    )
        external
        payable
        whenNotPaused
        onlyPhiFactory
    {
       uint256 tokenId_ = _artIdToTokenId[artId_];
-       if (tokenId_ == 0) {
-           revert InValdidTokenId();
-       }
        
        // ...
    }
```
