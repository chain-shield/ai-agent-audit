# Vulnerability details

## Impact

Potential loss of funds due to double reporting of curators' positions.

## Summary

[Cred::_addCredIdPerAddress](https://github.com/code-423n4/2024-08-phi/blob/8c0985f7a10b231f916a51af5d506dd6b0c54120/src/Cred.sol#L685) has incorrect access modifier, `public` instead of `private`:

```solidity
    // Function to add a new credId to the address's list
    function _addCredIdPerAddress(uint256 credId_, address sender_) public {
```

This allows anyone to call this function and add an arbitrary `credId` to any curator. While by itself this doesn't lead to direct loss of funds, it can be exploited via interactions with the `Cred` contract, as the integrity of curators' position reporting becomes compromised. One possibility of exploiting the vulnerability arises via the public function [getPositionsForCurator](https://github.com/code-423n4/2024-08-phi/blob/8c0985f7a10b231f916a51af5d506dd6b0c54120/src/Cred.sol#L476-L484), which, when the exploit is executed, reports the same curator position multiple times. Together with external systems which rely on this function this can be used e.g. to claim multiple rewards, or to artificially over-collateralize user's lending position by claiming to have more shares than they actually possess.

## Proof of Concept

Drop this test to [Cred.t.sol](https://github.com/code-423n4/2024-08-phi/blob/8c0985f7a10b231f916a51af5d506dd6b0c54120/test/Cred.t.sol#L105) and execute via `forge test --match-test Kuprum`

```solidity
    function testKuprum_DoublePosition() public {
        _createCred("BASIC", "SIGNATURE", 0x0);
        vm.startPrank(anyone);
        uint256 buyPrice = bondingCurve.getBuyPriceAfterFee(1, 1, 1);
        uint256 maxPrice = bondingCurve.getBuyPriceAfterFee(1, 1, 2);

        cred.buyShareCred{ value: buyPrice }(1, 1, maxPrice);
        assertEq(cred.isShareHolder(1, anyone), true, "cred 1 is voted by anyone");
   
        // Anyone can add anyone to `credIdsPerAddress` mappings
        cred._addCredIdPerAddress(1, anyone);
        
        uint256[] memory credIds;
        uint256[] memory amounts;

        // Curator's position is now reported twice 
        (credIds, amounts) = cred.getPositionsForCurator(anyone, 0,0);      
        assertEq(credIds.length, 2);
        assertEq(credIds[0], 1);
        assertEq(credIds[1], 1);
        assertEq(amounts.length, 2);
        assertEq(amounts[0], 1);
        assertEq(amounts[1], 1);
    }
```

## Tools Used

Manual review; Foundry

## Recommended Mitigation Steps

Change `Cred::_addCredIdPerAddress` access modifier from `public` to `private`.
