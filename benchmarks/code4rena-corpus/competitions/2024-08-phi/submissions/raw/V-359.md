# Vulnerability details

## Impact
Users can create art through the `PhiFactory` contract by calling the `createArt` function. A fee, set by the admin, is charged during the creation process. This fee is paid in native ETH. However, any amount sent above the required fee is mistakenly returned to the factory contract instead of the art creator. Since the factory contract does not implement fallback or receive functions, this causes the transaction to revert.
## Proof of Concept
To test this you can modify the amount sent in the helper function `PhiFactory.t.sol::_createArt`, increasing it by 1 ether. Then run the following test:

```javascript
function testExcessPayment() public {
    vm.expectRevert();
    _createArt(ART_ID_URL_STRING);
}
```
## Tools Used
Manual review.
## Recommended Mitigation Steps
Include the art creator's address in the function parameters and return any excess funds directly to that address.
