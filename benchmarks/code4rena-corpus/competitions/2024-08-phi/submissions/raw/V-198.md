# Vulnerability details

## Impact
The lack of proper `upgradeability` setup introduces operational risks, as the contract may not behave as expected during upgrade attempts, leading to potential downtime or service disruptions.

## Proof of Concept
The [`PhiNFT1155` contract inherits from `UUPSUpgradeable`](https://github.com/code-423n4/2024-08-phi/blob/8c0985f7a10b231f916a51af5d506dd6b0c54120/src/art/PhiNFT1155.sol#L23), a contract from `OpenZeppelin` that provides `upgradeability` features.
```solidity
    contract PhiNFT1155 is
        Initializable,
>>      UUPSUpgradeable,
        ---SNIP---
```
This standard requires certain `initialization` steps to be performed to ensure the contract is properly set up for upgrades. 

However during initialization,  the `__UUPSUpgradeable_init()` function is not called within the [`initialize()`](https://github.com/code-423n4/2024-08-phi/blob/8c0985f7a10b231f916a51af5d506dd6b0c54120/src/art/PhiNFT1155.sol#L96-L125) function.
```solidity
    function initialize(
        uint256 credChainId_,
        uint256 credId_,
        string memory verificationType_,
        address protocolFeeDestination_
    )
        external
        initializer
    {
        __Ownable_init(msg.sender);

        // @audit-info Missing `UUPSUpgradeable` initialization
        __Pausable_init();
        __ReentrancyGuard_init();
        initializeRoyalties(protocolFeeDestination_);


        ---SNIP---
    }
``` 

This omission leaves the `upgrade mechanism` improperly configured.

The `UUPSUpgradeable` contract relies on an internal function [`_authorizeUpgrade()`](https://github.com/code-423n4/2024-08-phi/blob/8c0985f7a10b231f916a51af5d506dd6b0c54120/src/art/PhiNFT1155.sol#L352-L354) to control who can upgrade the contract. Without proper initialization, the upgrade authorization mechanism may not function as intended, potentially preventing upgrades.

## Tools Used
Manual Review

## Recommended Mitigation Steps
Ensure that the `__UUPSUpgradeable_init()` function is called within the `initialize()` function of the `PhiNFT1155` contract
```diff
        ---SNIP---  
        __Ownable_init(msg.sender);

        __Pausable_init();
        __ReentrancyGuard_init();
+       __UUPSUpgradeable_init();
        ---SNIP---       
```
