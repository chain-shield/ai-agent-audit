# Vulnerability details

## Impact
Leads to loss of profit for people who are selling shares in a batch due to wrongful calculation

## Proof of Concept

There is an issue in _validateAndCalculateBatch where the price when buying or selling in batch is calcualted wrongly by using only the  buy pirce even when selling which leads to incorrect prices.

    function _validateAndCalculateBatch(
        uint256[] calldata credIds_,
        uint256[] calldata amounts_,
        uint256[] calldata priceLimits_,
        bool isBuy
    )


            (prices[i], protocolFees[i], creatorFees[i]) =
                IBondingCurve(cred.bondingCurve).getPriceData(credId, cred.currentSupply, amount, isBuy);




## Tools Used
Code review

## Recommended Mitigation Steps

Use 

            (prices[i], protocolFees[i], creatorFees[i]) =
                IBondingCurve(cred.bondingCurve).getPriceData(credId, cred.currentSupply, amount, isSell); 

when selling instead and isBuy when buying.
