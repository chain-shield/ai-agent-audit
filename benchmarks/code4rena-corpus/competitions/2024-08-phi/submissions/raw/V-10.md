# Vulnerability details

## Impact
This vulnerability could lead to:

Unintended accumulation of ETH in the contract
Potential loss of funds for users who overpay

## Proof of Concept
https://github.com/code-423n4/2024-08-phi/blob/8c0985f7a10b231f916a51af5d506dd6b0c54120/src/PhiFactory.sol#L299

The `claim` function is payable and accepts ETH.
It calculates `mintFee` using `getArtMintFee(artId, quantity_)`.
It then calls `this.merkleClaim` or `this.signatureClaim` with `value: mintFee`.

If actual `msg.value` is greater than `mintFee`, the excess ETH will remain in the contract.
There seems to be no mechanism in this function to refund or handle excess ETH. 

## Tools Used
Manual Review

## Recommended Mitigation Steps
Add a check to ensure msg.value exactly matches mintFee
Alternatively implement a refund mechanism for excess ETH
