# Vulnerability details

## Impact
The _getPriceData function in the Cred contract sets the creator fee to zero when the supply is zero, regardless of whether the cred has been previously created. This can lead to creators losing out on fees for purchases made when the supply reaches zero because creator sold their first share.
```solidity
function _getPriceData(
    uint256 credId_,
    uint256 supply_,
    uint256 amount_,
    bool isSign_
) internal view returns (uint256 price, uint256 protocolFee, uint256 creatorFee) {
    // ...
    if (supply_ == 0) {
        creatorFee = 0;
        return (price, protocolFee, creatorFee);
    }
    // ...
}
```

1. Creator mints a cred and receives 1 share.
2. Creator sells their 1 share, bringing supply to 0.
3. A buyer purchases shares when supply is 0.
4. Due to the current implementation, the creator receives no fee for this purchase.
