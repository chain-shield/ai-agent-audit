# Vulnerability details

The `setArtCreatFee()` function in the `PhiFactory` contract incorrectly interprets basis points (bps) as a direct percentage when setting the art creation fee. Basis points are a financial unit equal to one hundredth of a percentage point, meaning `1%` is equivalent to `100 bps`. The code currently allows a maximum of `10,000 bps`, which is equivalent to `100%`, but incorrectly applies this value as a direct fee in wei, leading to inaccurate fee calculations and transfers. Additionally, the `artCreateFee` is initialized without any upper limit check, leading to potential misconfigurations.

## Impact
This bug can cause incorrect fee calculations and transfers, where the fee is either set too high or misinterpreted during transactions. For example, if `artCreateFee` is set to `10,000 bps`, it will be treated as `100%` in the code, leading to a full transfer of the specified amount in wei, which is incorrect. This can cause significant financial discrepancies, particularly when transferring funds, leading to overcharging or misallocation of fees.

## Proof of Concept
```
/// @notice Sets the art creation fee percentage.
/// @param artCreateFee_ The new art creation fee percentage (in basis points).
function setArtCreatFee(uint256 artCreateFee_) external onlyOwner {
    if (artCreateFee_ > 10_000) revert ArtCreatFeeTooHigh();
    artCreateFee = artCreateFee_;
    emit ArtCreatFeeSet(artCreateFee_);
}
```

Test Case:

In the tests, `NFT_ART_CREATE_FEE` (artCreateFee) is set to `0.0002` ether, which equals `200,000,000,000,000` wei. However, this value is incorrectly handled in future updates, as the `artCreateFee` in the `initialize` function is set without any maximum limit checks. This means that in the future, the owner can update `artCreateFee` to a maximum of `10,000` wei, which is an incorrect calculation. It should instead calculate a percentage from a certain value, but currently, basis points (BPS) are mistakenly used as the direct transfer amount, leading to invalid behavior.

## Recommended Mitigation Steps

To address this issue, the calculation of the `artCreateFee` should be corrected to properly interpret basis points as a percentage, rather than as a direct transfer amount. Additionally, ensure that any fee-related calculations or transfers accurately reflect the intended percentage of the transaction amount. It's also important to implement consistent checks and validations during initialization and updates to prevent misconfigurations and ensure that the fee is applied correctly in all scenarios.
