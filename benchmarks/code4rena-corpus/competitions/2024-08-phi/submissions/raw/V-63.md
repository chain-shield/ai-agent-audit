# Vulnerability details

## Impact
Updating of phiSignerAddress in Cred by owner will cause revert in creating and updating Creds.

The offline signatures are done by the owners to authorise a transaction. If the signer address is changed before the transaction is processed, then such offline signature is not valid any more. The impact is limited to grievance that signed transaction did not go through.

## Proof of Concept
Owner of `Cred` contract can update the `phiSignerAddress` address by calling the below `setPhiSignerAddress(...)` function.

```
      function setPhiSignerAddress(address phiSignerAddress_) external nonZeroAddress(phiSignerAddress_) onlyOwner {
        phiSignerAddress = phiSignerAddress_;
        emit PhiSignerAddressSet(phiSignerAddress_);
    }
```
All the transactions that were signed offline and pending execution will revert as the `phiSignerAddress` is now changed and will not match during signature verification.

The transactions that can be signed offline line are

- createCred()
- updateCred()


## Tools Used
Manual Review

## Recommended Mitigation Steps
The risk is limited, but it is advised to rethink the need to update `phiSignerAddress` address.
