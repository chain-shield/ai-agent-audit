# Vulnerability details

## Impact
**`createArt()`** is designed to create artwork, requiring users to send ETH to cover the associated fees. If a user sends more ETH than needed, the function is supposed to refund the surplus. However, the **`PhiFactory.sol`** contract lacks a **`receive()`** or **`fallback()`** function to handle the excess ETH, causing the transaction to revert whenever a surplus is sent.

## Proof of Concept
**`createArt()`** is implemented as follows.

If a user sends more ETH than the required **`artFee`**, the excess is intended to be refunded to **`PhiFactory.sol`**.
 
However, the contract lacks a function to receive ETH, causing the transaction to revert whenever a refund is attempted.

This results in users paying fees for a transaction that will always fail due to the incorrect implementation, leading to a loss of funds.

To demonstrate the issue, copy and paste the following POC into **`PhiFactory.t.sol`**.

## Recommended Mitigation Steps
To resolve the issue, implement a **`receive()`** or **`fallback()`** function in **`PhiFactory.sol`**.

Additionally, I'm unsure of the developers' intended implementation of this functionality. However, it appears that the excess ETH should be returned to the user. Currently, it's being sent to the **`PhiFactory`** contract, which may not be the correct behavior. If the developers' goal is to return the excess ETH to the user, this presents other problem since it's being sent to the wrong address. In this case, the excess ETH should not be sent to the contract but rather returned to the user. One solution is to use **`tx.origin`** instead of **`_msgSender()`** to ensure the ETH is sent to the correct address.
```diff
function createArtFromFactory(uint256 artId_) external payable onlyPhiFactory whenNotPaused returns (uint256) {

        _tokenIdToArtId[tokenIdCounter] = artId_;

        emit ArtCreated(artId_, tokenIdCounter);

        unchecked {
            tokenIdCounter += 1;
        }
        if ((msg.value - artFee) > 0) {
-          _msgSender().safeTransferETH(msg.value - artFee);
+          payable(tx.origin).safeTransferETH(msg.value - artFee);
        }
```
