# Vulnerability details

## Impact
`PhiNFT1155::receive(...)` enables PhiNFT1155 contract to accept Ether directly. But, the Ether received into the contract does not have a mechanism to withdraw those funds deposited in the contract.

If a user sends funds to `PhiNFT1155`, such funds will remain locked in the contract permanently.

## Proof of Concept

`PhiNFT1155` contract allows anyone to send funds to the contract. But, there is no mechanism to withdrawn those funds from the contract.

```
   receive() external payable {
        // This function is intentionally left empty to allow the contract to 
        receive ETH
    }
}
```

As such, any funds sent to `PhiNFT1155` contract will be locked in the contract.

## Tools Used
Manual review

## Recommended Mitigation Steps
Funds received into `PhiNFT1155` contract should be restricted to scenarios under which the `PhiNFT1155` contract can accept ether. The contract should expose a mechanism where such Ether can be withdrawn out from the contract,
