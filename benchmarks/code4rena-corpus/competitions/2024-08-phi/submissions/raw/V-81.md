# Vulnerability details

## Impact
The `_addCredIdPerAddress()` function have public visibility which allows a malicious actor to update the values of `_credIdsPerAddress`, `_credIdsPerAddressCredIdIndex` and `_credIdsPerAddressArrLength` maps on behalf of any user. 

In worst case scenario, the `credIds` array of an user may grow excessively large, leading to the `getPositionsForCurator()` function reverting due to exceeding the block gas limit.
