# Vulnerability details

## Description
In `PhiFactory::createArt()` any malicious user or the current artist could reuse the `signedData_` & `signature_`, to create another transaction with the same attributes.
Which was intended to be used once by `phiSignerAddress` per chain.
Exploiter could use it to store the malicious data in the protocol & thus omitting the backend storage procedure that generates the required params for `createArt` function.

## Impact
- User could add himself as artist & start earning rewards, without actually having any backend proof for it.
- This would put the contract in undesirable state.
