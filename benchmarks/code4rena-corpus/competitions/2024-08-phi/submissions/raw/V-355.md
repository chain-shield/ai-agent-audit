# Vulnerability details

## Impact
A malicious user can manipulate other curators' positions by calling `_addCredIdPerAddress`, which breaks the reporting logic.

## Proof of Concept
https://github.com/code-423n4/2024-08-phi/blob/8c0985f7a10b231f916a51af5d506dd6b0c54120/src/Cred.sol#L685
Similar to `_removeCredIdPerAddress` a user can call the `_addCredIdPerAddress` to alter the position of a curator `getPositionsForCurator`

## Tools Used
manual search

## Recommended Mitigation Steps
Change the accessor from `public` to `internal`
