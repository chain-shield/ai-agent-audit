# Vulnerability details

This loop iterates over the distributeAddresses array and calls credContract.getShareNumber for each address. If the credContract.getShareNumber function is expensive or can be manipulated to consume a lot of gas, a malicious actor could provide a large number of addresses in the distributeAddresses array to intentionally increase the gas cost of the transaction. This could make it prohibitively expensive for honest users to execute the distribute function, effectively preventing them from using the contract.

Vulnerability Details
Unbounded Loop in distributeAddresses: The code iterates over the distributeAddresses array twice:

First Loop: Aggregates the total number of shares each address holds.
Second Loop: Calculates individual rewards and prepares the data for distribution.
Since the distributeAddresses array is populated from an external call to credContract.getCuratorAddresses(), the size of this array can be arbitrarily large. If an attacker (or a natural scenario with many curators) causes this array to be extremely large, the gas required to execute this function can exceed the block gas limit.

Exploit Scenario
An attacker adds a large number of curator addresses to a specific credId by exploiting the credContract.
The attacker or any user tries to call the distribute function.
Due to the large number of addresses in the distributeAddresses array, the loop exceeds the block gas limit, causing the transaction to revert.
This results in a denial of service, where rewards cannot be distributed, effectively locking the funds in the contract.

To mitigate this vulnerability, you can introduce a maximum loop iteration limit:


uint256 maxIterations = 100; // Adjust this value as needed

for (uint256 i = 0; i < distributeAddresses.length && i < maxIterations; i++) {
    // ...
}

This will ensure that the loop terminates after a certain number of iterations, preventing unbounded gas consumption. However, it's important to set the maxIterations value carefully to avoid limiting legitimate use cases.
