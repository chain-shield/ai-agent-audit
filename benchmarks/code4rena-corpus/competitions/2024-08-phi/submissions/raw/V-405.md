# Vulnerability details

## Impact
A malicious admin can can put a number thats above 100% ultimately blocking the functionality of the protocol.

## Proof of Concept
Since this value is denominated in percents, the malicious admin can put a value that represents `>= 100%`, ultimately leading to blocked functionality in the protocol.
```javascript
    function setProtocolFeePercent(uint256 protocolFeePercent_) external onlyOwner {
        protocolFeePercent = protocolFeePercent_;
        emit ProtocolFeePercentChanged(_msgSender(), protocolFeePercent_);
    }

```

## Tools Used

Manual Review

## Recommended Mitigation Steps
Implement an upper bound check in the `Cred::setProtocolFeePercent()` function.
