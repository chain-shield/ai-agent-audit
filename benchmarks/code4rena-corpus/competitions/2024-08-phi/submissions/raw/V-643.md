# Vulnerability details

## Vulnerability Detail
The `PhiFactory.sol`'s `createArt` function uses a signature validation mechanism that lacks a nonce or other single-use identifier. This allows for potential replay attacks where a single valid signature could be used multiple times to create art pieces.

## Impact
The impact of this vulnerability is significant:

- Unauthorized Art Creation: An attacker could reuse a valid signature to create multiple art pieces without the artist's consent.
- Economic Exploitation: If there are fees or rewards associated with art creation, this could be exploited for financial gain.

## Proof of Concept
The vulnerability exists in the `createArt` and `_validateArtCreationSignature` functions:

https://github.com/code-423n4/2024-01-phi/blob/main/src/PhiFactory.sol#L196-L213
```
function createArt(
    bytes calldata signedData_,
    bytes calldata signature_,
    CreateConfig memory createConfig_
)
    external
    payable
    nonReentrant
    whenNotPaused
    returns (address)
{
    _validateArtCreationSignature(signedData_, signature_);
    // ... rest of the function
}
```
https://github.com/code-423n4/2024-01-phi/blob/main/src/PhiFactory.sol#L589-L593
```
function _validateArtCreationSignature(bytes calldata signedData_, bytes calldata signature_) private view {
    if (_recoverSigner(keccak256(signedData_), signature_) != phiSignerAddress) revert AddressNotSigned();
    (uint256 expiresIn_,,) = abi.decode(signedData_, (uint256, string, bytes));
    if (expiresIn_ <= block.timestamp) revert SignatureExpired();
}
```
The `_validateArtCreationSignature` function only checks the signer and expiration time, without any mechanism to prevent reuse of the signature.

## Recommended Mitigation Steps
- Introduce a nonce in the signed data structure:
```
   struct SignedArtData {
       uint256 nonce;
       uint256 expiresIn;
       string uri;
       bytes credData;
   }
   ```
- Implement a mapping to track used nonces:
```
   mapping(address => mapping(uint256 => bool)) private usedNonces;
   ```
- Update the signature validation to check and mark nonces as used:
```
   function _validateArtCreationSignature(bytes calldata signedData_, bytes calldata signature_) private {
       SignedArtData memory data = abi.decode(signedData_, (SignedArtData));
       address signer = _recoverSigner(keccak256(signedData_), signature_);
       
       if (signer != phiSignerAddress) revert AddressNotSigned();
       if (data.expiresIn <= block.timestamp) revert SignatureExpired();
       if (usedNonces[signer][data.nonce]) revert NonceAlreadyUsed();
       
       usedNonces[signer][data.nonce] = true;
   }
   ```
These changes will ensure that each signature can only be used once for art creation, effectively preventing replay attacks.
