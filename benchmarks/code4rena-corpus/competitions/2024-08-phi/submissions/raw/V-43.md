# Vulnerability details

## Impact
`PhiFactory` contract supports offline signing of transactions for Art creation and claiming functions. At the same time, the owner of `PhiFactory` contract can update the `phiSignerAddress`.

Updating of the  `phiSignerAddress` by the owner will invalidate and revert some of the transactions that were signed offline. This is potentially leading to grievance for the caller.

There is no other loss.

## Proof of Concept
Owner of PhiFactory` contract can update the `phiSignerAddress` address by calling the below `setPhiSignerAddress(...)` function.

```
   function setPhiSignerAddress(address phiSignerAddress_) external nonZeroAddress(phiSignerAddress_) onlyOwner {
        phiSignerAddress = phiSignerAddress_;
        emit PhiSignerAddressSet(phiSignerAddress_);
    }
```

All the transactions that were signed offline and pending execution will revert as the `phiSignerAddress` is now changed and will not match during signature verification.

The transactions that can be signed offline line are
