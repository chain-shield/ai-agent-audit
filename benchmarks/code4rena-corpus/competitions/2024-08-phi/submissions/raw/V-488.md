# Vulnerability details

## Impact
Artist can change url of art without signature.
It can damage the buyer of that art because the `url` can be changed after they buy the art.

## Proof of Concept
Url of art is set with signature in `PhiFactory.createArt()` function.
But artist can change url of art without signature in `PhiFactory.updateArtSettings()` function.

`PhiFactory.createArt()` function is following.
```solidity
    function createArt(
        bytes calldata signedData_,
        bytes calldata signature_,
        CreateConfig memory createConfig_
    )
        external
        payable
        nonReentrant
        whenNotPaused
        returns (address)
    {
        _validateArtCreationSignature(signedData_, signature_);
208:    (, string memory uri_, bytes memory credData) = abi.decode(signedData_, (uint256, string, bytes));
        ERC1155Data memory erc1155Data = _createERC1155Data(artIdCounter, createConfig_, uri_, credData);
        address artAddress = createERC1155Internal(artIdCounter, erc1155Data);
        artIdCounter++;
        return artAddress;
    }
```
As can be seen, the url of art is extracted from `signedData_` in `L208`.
However, `PhiFactory.updateArtSettings()` function is following.
```solidity
    function updateArtSettings(
        uint256 artId_,
        string memory url_,
        address receiver_,
        uint256 maxSupply_,
        uint256 mintFee_,
        uint256 startTime_,
        uint256 endTime_,
        bool soulBounded_,
        IPhiNFT1155Ownable.RoyaltyConfiguration memory configuration
    )
        external
        onlyArtCreator(artId_)
    {
        --- SKIP ---
        art.uri = url_;

        uint256 tokenId = IPhiNFT1155Ownable(art.artAddress).getTokenIdFromFactoryArtId(artId_);
        IPhiNFT1155Ownable(art.artAddress).updateRoyalties(tokenId, configuration);
        emit ArtUpdated(artId_, url_, receiver_, maxSupply_, mintFee_, startTime_, endTime_, soulBounded_);
    }
```
As can be seen, artist can change url of art without signature.

## Recommended Mitigation Steps
Remove `url_` parameter from `PhiFactory.updateArtSettings()` function.
