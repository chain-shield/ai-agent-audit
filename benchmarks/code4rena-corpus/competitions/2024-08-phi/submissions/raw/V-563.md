# Vulnerability details


## Vulnerability details
The `PhiFactory` contract does not have a function to **receive** ether. Thus the contract cannot **receive** ether if there is a success check after a low-level `call` function or if `safeTransferETH` is used. 

Since the contract has the withdraw function
```solidity 
function withdraw() external onlyOwner {

protocolFeeDestination.safeTransferETH(address(this).balance);

}
```
it should have the function of accepting ether, because the contract, for example, will not be able to transfer ether using the withdraw function of `WETH` and similar tokens.  


## Recommended Mitigation Steps
Add the `receive` function to the contract `PhiFactory.sol`
```solidity 
receive() external payable {}
```
