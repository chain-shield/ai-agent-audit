# Vulnerability details

## Impact

`protocolFeePercent` in `Cred` contract can be set to any uint256 value. Which will lead to unfair conditions for buyers/sellers of shares or even cause protocol DoS if the value is much higher than `RATIO_BASE` (10_000).

## Proof of Concept

`test_HighFee` — main function

1. In `setUp` we initialize `Cred` with 10_000 as `protocolFeePercent`
    1. We can initialize it with `type(uint256).max` which will cause DoS
2. Users have to pay 100% fee for every share buy and sell

    function sign(bytes memory data) internal view returns (bytes memory) {
        bytes32 createMsgHash = keccak256(data);
        bytes32 createDigest = ECDSA.toEthSignedMessageHash(createMsgHash);
        (uint8 cv, bytes32 cr, bytes32 cs) = vm.sign(SIGNER_KEY, createDigest);
        if (cv != 27) cs = cs | bytes32(uint256(1) << 255);

        return abi.encodePacked(cr, cs);
    }

    function padDecimal(uint256 num) internal pure returns (string memory) {
        string memory numStr = vm.toString(num);
        if (bytes(numStr).length == 18) {
            return numStr;
        } else if (bytes(numStr).length < 18) {
            uint256 padLength = 18 - bytes(numStr).length;
            string memory padding = new string(padLength);
            bytes memory paddingBytes = bytes(padding);
            for (uint256 i = 0; i < paddingBytes.length; i++) {
                paddingBytes[i] = bytes1(uint8(48)); // ASCII code for '0'
            }
            return string(abi.encodePacked(paddingBytes, numStr));
        } else {
            // If the number is too large, truncate it (this usually shouldn't happen)
            return string(abi.encodePacked("...", numStr));
        }
    }

    function logBalance(uint256 value, string memory prefix) internal view {
        uint256 wholePart = value / 1 ether;
        uint256 decimalPart = value % 1 ether;

        string memory decimalStr = padDecimal(decimalPart);

        console2.log("%s %d.%s in ethers", prefix, wholePart, decimalStr);
    }
