# Vulnerability details

## Impact
The protocol suffers from unauthorized cred creation, compromising the integrity and trust of the system. The attacker gains the ability to create creds without proper authorization from the designated `phiSignerAddress`.

## Proof of Concept
The incorrect usage of the `ECDSA.recover` function from the `solady` library will cause a signature verification bypass for the protocol as an attacker will be able to create creds with invalid signatures.

The signature verification logic is flawed: [Cred.sol#L292](https://github.com/code-423n4/2024-08-phi/blob/8c0985f7a10b231f916a51af5d506dd6b0c54120/src/Cred.sol#L292)
```solidity
if (_recoverSigner(keccak256(signedData_), signature_) != phiSignerAddress) revert AddressNotSigned();
```
The `_recoverSigner` function, which internally uses `ECDSA.recover` from the `solady` library, does not perform all the necessary checks for signature malleability and invalid signatures. This allows an attacker to bypass the signature verification and create creds without a valid signature from the `phiSignerAddress`.

The choice to use the `ECDSA.recover` function from the `solady` library is a mistake as it lacks the required checks for signature validity and malleability.

When the `phiSignerAddress` set to a valid address by the contract owner.

**Attack Scenario**

* The attacker crafts a `signedData_` and signature_ pair that exploits the vulnerability in the `ECDSA.recover` function.

* The attacker calls the `createCred` function with the crafted `signedData_` and `signature_`.

* The `_recoverSigner` function fails to properly validate the signature, allowing the attacker's signature to pass the verification.

* The `createCred` function proceeds with the cred creation using the attacker's provided data.

* The attacker successfully creates an unauthorized cred without a valid signature from the `phiSignerAddress`.

## Tools Used
Manual review

## Recommended Mitigation Steps
```diff
- if (_recoverSigner(keccak256(signedData_), signature_) != phiSignerAddress) revert AddressNotSigned();
+ if (ECDSA.recover(ECDSA.toEthSignedMessageHash(keccak256(signedData_)), signature_) != phiSignerAddress) revert AddressNotSigned();
```
