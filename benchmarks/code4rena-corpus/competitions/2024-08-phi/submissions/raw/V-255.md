# Vulnerability details

## Impact
Added calls to all base class initialization methods in the initialize function, including __ERC1155_init, to ensure that the initialization logic of all parent contracts is executed correctly.
## Proof of Concept
https://github.com/code-423n4/2024-08-phi/blob/main/src/art/PhiNFT1155.sol#L96-L109
```sol
    function initialize(
        uint256 credChainId_,
        uint256 credId_,
        string memory verificationType_,
        address protocolFeeDestination_
    )
        external
        initializer
    {
        __Ownable_init(msg.sender);

        __Pausable_init();
        __ReentrancyGuard_init();
        initializeRoyalties(protocolFeeDestination_);
```
In the PhiNFT1155.sol contract, many parent contracts are inherited. According to the writing rules of the upgradeable contract, the __ERC1155_init function of ERC1155Upgradeable is missing.
https://docs.openzeppelin.com/upgrades-plugins/1.x/writing-upgradeable

    function initialize(
