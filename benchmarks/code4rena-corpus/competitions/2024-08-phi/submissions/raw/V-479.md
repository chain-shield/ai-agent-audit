# Vulnerability details

## Impact

The CreatorRoyaltiesControl contract lacks an upper bound check for the royaltyBPS value when updating royalties. This can lead to several critical issues:

- _Excessive Royalties_: royalties can be set to 100% or even higher, which could effectively freeze token transfers or create economically unviable situations.
- _Compliance Issues_: many platforms and marketplaces have maximum royalty limits. Exceeding these could lead to compatibility issues or rejection of the token on these platforms.
- _Potential for abuse_: Malicious actors could exploit this to set extreme royalty rates, potentially as part of more complex attack scenarios.
