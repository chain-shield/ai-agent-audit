# Vulnerability details

## Impact
Anyone can call functions `Cred#_addCredIdPerAddress` and `Cred#_removeCredIdPerAddress` to add and remove `credId` from any address's list

## Proof of Concept
Modify the test file `test/Cred.t.sol` as below:

