# Vulnerability details

## Impact
It's not appropriate since the user may want to send his ether to another address, or has other plans for this funds.

## Proof of Concept
Its allowed for everybody to withdraw fund for other users, which may not be relevant to the plans that these users have for their funds, ultimately meaning that this action becomes malicious.
```javascript
 function withdrawFor(address from, uint256 amount) external {
        _withdraw(from, from, amount);
    }
```
## Tools Used
Manual Review 
## Recommended Mitigation Steps
Add a permission logic so that a user can specify an operator that can withdraw his funds for him.
