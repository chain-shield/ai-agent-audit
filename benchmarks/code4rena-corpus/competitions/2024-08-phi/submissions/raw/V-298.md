# Vulnerability details

## Impact
When merkleClaim() is invoked, verifyCalldata() is used to check if validity between root and leaf using some proofs, which allows to claim from corresponding art contract. There is no mechcnaism that prevents a user from calling this function once and again with the same parameters, claiming multiple times and therefore having more tokens minted than they should.

## Proof of Concept
Proof calling claim() function with "MERKLE" as verification type 3 times in a row.
