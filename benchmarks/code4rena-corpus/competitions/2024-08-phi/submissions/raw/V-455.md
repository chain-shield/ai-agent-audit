# Vulnerability details

## Proof of Concept
In the RewardControl.withdrawFor() function, the _withdraw() function is called with two parameters from:
https://github.com/code-423n4/2024-08-phi/blob/main/src/abstract/RewardControl.sol#L96-L98
_withdraw(from, from, amount);

Probably a typo. The second from should be to. However, if this is the case, it is possible to steal funds from any account.

## Tools Used
Manual review

## Recommended Mitigation Steps
Remove the withdrawFor() function.
