# Vulnerability details

## Impact

The protocol's inability to adjust its mint fees due to a misconfigured upper limit introduces a significant operational risk. The current fee cap is mistakenly set to a maximum of 10,000 wei, which is negligible in ETH terms. This flaw not only prevents the protocol from responding to market conditions or adjusting its revenue model but also severely limits its financial flexibility. Over time, this could lead to lost revenue opportunities, as the protocol would be unable to adapt its fee structure in line with economic changes.

## Proof of Concept

- The `PhiFactory` contract is deployed with an initial `protocolFee_` set to 0.0005 ether, as specified in the [deployment scripts](https://github.com/code-423n4/2024-08-phi/blob/main/script/Deploy.s.sol#L48-L50).

- At a later stage, the deployer attempts to increase the mint fee to 0.0006 ether to boost revenue. However, this action fails due to the [hardcoded upper limit of 10,000 wei](https://github.com/code-423n4/2024-08-phi/blob/main/src/PhiFactory.sol#L423).

```solidity
// SPDX-License-Identifier: MIT
pragma solidity 0.8.25;

import { Settings, console2 as console } from "../helpers/Settings.sol";

import { IPhiFactory } from "../../src/interfaces/IPhiFactory.sol";

contract MintFeesIncorrectCheck is Settings {
    function setUp() public override {
        super.setUp();
    }

    function test_setProtocolFee_revert_ProtocolFeeTooHigh() public {
        // Get the current protocol fee.
        uint256 initialMintProtocolFee = phiFactory.mintProtocolFee();

        // Log the current protocol fee.
        console.log("Initial mint protocol fee: %18e ether", initialMintProtocolFee);

        // Set the desired protocol fee.
        uint256 desiredMintProtocolFee = 0.0006 ether;

        // Log the desired protocol fee.
        console.log("Desired mint protocol fee: %18e ether", desiredMintProtocolFee);

        // Owner tries to update the mint protocol fee to increase protocol revenue.
        vm.startPrank(owner);

        // Transaction reverts because the desired mint protocol fee is over the cap
        vm.expectRevert(IPhiFactory.ProtocolFeeTooHigh.selector);
        phiFactory.setProtocolFee(desiredMintProtocolFee);

        vm.stopPrank();
    }
}
```
