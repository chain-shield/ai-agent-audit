# Vulnerability details

## Impact

The excess fee should be returned to `msg.sender`, but a flaw in the `PhiNFT1155::createArtFromFactory` refund process, combined with the inability of `PhiFactory` to receive ether, causes the `createArt` function to fail when adding new art on existing NFT contract.

## Proof of Concept

Calling `PhiFactory::createArt` with excess fee would make the excess fee be refunded back to `msg.sender` but the logic of refunding is located in `PhiNFT1155` contract:

```javascript
    function createArtFromFactory(uint256 artId_) external payable onlyPhiFactory whenNotPaused returns (uint256) {
        _artIdToTokenId[artId_] = tokenIdCounter;
        _tokenIdToArtId[tokenIdCounter] = artId_;

        uint256 artFee = phiFactoryContract.artCreateFee();

        protocolFeeDestination.safeTransferETH(artFee);
        emit ArtCreated(artId_, tokenIdCounter);
        uint256 createdTokenId = tokenIdCounter;

        unchecked {
            tokenIdCounter += 1;
        }
        if ((msg.value - artFee) > 0) {
@>          _msgSender().safeTransferETH(msg.value - artFee);
        }

        return createdTokenId;
    }
```

The refund logic on `createArtFromFactory` uses `_msgSender()`, which is always `PhiFactory` due to the `onlyPhiFactory` modifier. The fact that `PhiFactory` lacks a `receive()` or `fallback()` function would make this call fail. The correct `_msgSender()` should be the caller of `PhiFactory::createArt`, not `PhiFactory` itself.

## Recommended Mitigation Steps

To correct the refund behavior when adding new art NFT to existing NFT contract, I suggest implementing the refund logic inside `PhiFactory` instead of `PhiNFT1155`:

`PhiFactory.sol`:

```diff
    function _useExistingNFTContract(
        PhiArt storage art,
        uint256 newArtId,
        ERC1155Data memory createData_,
        uint256 credId,
        uint256 credChainId
    )
        private
        returns (address)
    {
        address existingArt = credNFTContracts[credChainId][credId];
        art.artAddress = existingArt;
        (bool success_, bytes memory response) =
-           existingArt.call{ value: msg.value }(abi.encodeWithSignature("createArtFromFactory(uint256)", newArtId));
+       // sending only the required amount of ether to PhiNFT1155 contract
+           existingArt.call{ value: artCreateFee }(abi.encodeWithSignature("createArtFromFactory(uint256)", newArtId));

        if (!success_) revert CreateFailed();
        uint256 tokenId = abi.decode(response, (uint256));
        emit NewArtCreated(createData_.artist, credId, credChainId, newArtId, createData_.uri, existingArt, tokenId);
+       // send the excess back to msg.sender
+       if (msg.value > artCreateFee) {
+           _msgSender().safeTransferETH(msg.value - artCreateFee);
+       }
        return existingArt;
    }
```
