# Vulnerability details

## Impact
When the amount parameter is set to zero in the withdraw function, no transfer should be executed from the user's perspective because withdrawing zero should equate to making no withdrawal at all. However, when tested, the code currently transfers the user's entire balance to the specified address if amount is set to zero.

User Error: If the user makes a mistake by entering zero, they would not expect their entire balance to be withdrawn, which would significantly decrease user satisfaction.
Gas Inefficiency: Even if no funds are meant to be withdrawn, the user would still incur gas fees, which is an undesirable and inefficient outcome.
