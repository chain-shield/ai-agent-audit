# Vulnerability details

## Impact
BondingCurve.getPrice() is used to get the price of a credId given the current supply and the amount to buy/sell, but it reverts under certain circumstances:

- If input 'supply' or 'amount' param is >= 1000 wei, which prevents any user from buying more amount than that little quantity. This is because getPrice() calls _curve() function multiplying the input by 1 ether to scale it and make calculations easier, but _curve() has the expression ```(TOTAL_SUPPLY_FACTOR - targetAmount_)``` in the denominator, that will revert if it becomes 0 or negative (for being a uint).

- If second term of ```getPrice()``` is higher than first, then the subtraction will be negative and function will revert, this can happen in very specific cases in which both terms wound the same number.

## Proof of Concept
This proofs that function reverts whenever supply >= 1000:
```solidity
function testRevertsIfHigherThan1000(uint supply, uint amount) external{
        vm.assume(supply >= 1000);
        vm.expectRevert();
        bondingCurve.getPrice(supply,amount);
    }```

## Recommended Mitigation Steps
Easiest solution is not to scale the function by multiplying by 1 ether.

```solidity
function getPrice(uint256 supply_, uint256 amount_) public pure returns (uint256) {
- return _curve((supply_ + amount_) * 1 ether) - _curve(supply_ * 1 ether);
+ return _curve(supply_ + amount_) - _curve(supply_);
}
```

However, this has the incovenient that in some cases ```_curve(supply_)``` could be higher than ```_curve(supply_ + amount_)```, making the result negative. Here is a PoC for a case in which supply_ = 200 wei and amount_ = 150 wei (```getPriceNoScaled()``` is the proposed mitigation for the issue):

function testNegativeResult() external{
        vm.expectRevert();
        bondingCurve.getPriceNoScaled(200,150);
}

To fix this, make sure that minimum returned value is 1. We do not want to receive 0 as price because this would allow users to get shares for free, this would be the final solution:

```solidity
function getPrice(uint256 supply_, uint256 amount_) public pure returns (uint256) {
- return _curve((supply_ + amount_) * 1 ether) - _curve(supply_ * 1 ether);
+ if(_curve(supply_) >= _curve(supply_ + amount_)) return 1;
+ return _curve(supply_ + amount_) - _curve(supply_);
}
```
