# Vulnerability details

## Impact
The absence of storage gaps will lead to lack of possibility for both contracts to be upgraded

## Proof of Concept
Since the system is upgradable, if at some point new variables are needed the protocol team won't be able to add them, because if they do, the storage of both `PhiFactory` and `Cred` contracts will be messed up, leading to the full crash of the system

## Tools Used

Manual review

## Recommended Mitigation Steps
Add storage gaps to both contracts like this:
```javascrip
uint256[50] private gaps;
```





## Assessed type

Upgradable
