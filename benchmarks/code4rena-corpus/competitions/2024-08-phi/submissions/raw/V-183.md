# Vulnerability details

## Impact
The lack of a `verificationType` check in the `signatureClaim()` function allows for unauthorized claims to be processed. This means that users could potentially claim art pieces that were not intended to be verified through `signatures`.

## Proof of Concept
The [`signatureClaim()`](https://github.com/code-423n4/2024-08-phi/blob/8c0985f7a10b231f916a51af5d506dd6b0c54120/src/PhiFactory.sol#L327-L346) function in the `PhiFactory` contract is designed to process claims based on signed data that is provided by users.
```solidity
    function signatureClaim(
        bytes calldata signature_,
        bytes calldata encodeData_,
        MintArgs calldata mintArgs_
    )
        external
        payable
        whenNotPaused
    {
        (uint256 expiresIn_, address minter_, address ref_, address verifier_, uint256 artId_,, bytes32 data_) =
            abi.decode(encodeData_, (uint256, address, address, address, uint256, uint256, bytes32));

        if (expiresIn_ <= block.timestamp) revert SignatureExpired();
        if (_recoverSigner(keccak256(encodeData_), signature_) != phiSignerAddress) revert AddressNotSigned();
        // @audit-info Does not verify art.verificationType
        _validateAndUpdateClaimState(artId_, minter_, mintArgs_.quantity);
        _processClaim(artId_, minter_, ref_, verifier_, mintArgs_.quantity, data_, mintArgs_.imageURI, msg.value);

        emit ArtClaimedData(artId_, "SIGNATURE", minter_, ref_, verifier_, arts[artId_].artAddress, mintArgs_.quantity);
    }
```
However, there is a critical oversight in the implementation of this function. 

Specifically, the function does not verify whether the `artId_` being claimed corresponds to an art piece that is meant to be verified using a `signature`. This means that the function processes claims without checking if the `verificationType` for the given `artId_` is indeed `"SIGNATURE"`.

## Recommended Mitigation Steps
Modify the `signatureClaim()` function to include a check for the `verificationType` as follows:
```diff
        ---SNIP---
+       // Retrieve artId_
        (uint256 expiresIn_, address minter_, address ref_, address verifier_, uint256 artId_,, bytes32 data_) =
            abi.decode(encodeData_, (uint256, address, address, address, uint256, uint256, bytes32));

        if (expiresIn_ <= block.timestamp) revert SignatureExpired();
        if (_recoverSigner(keccak256(encodeData_), signature_) != phiSignerAddress) revert AddressNotSigned();

+       // Verify art.verificationType
+       PhiArt storage art = arts[artId_];
+       if (!art.verificationType.eq("SIGNATURE")) {
+           revert InvalidVerificationType();
+       }
        ---SNIP---
```
