# Vulnerability details

## Impact
if the **mintFee** parameter is less than the result of **mintProtocolFee** * **quantity_** we risk the possibility of an underflow resulting on undesired reverts.


## Tools Used
Manual review.

## Recommended Mitigation Steps
Protocol should add a check that ensures that the value of **mintFee** is always greater than the result of **mintProtocolFee** * **quantity_**


## Assessed type

Under/Overflow
