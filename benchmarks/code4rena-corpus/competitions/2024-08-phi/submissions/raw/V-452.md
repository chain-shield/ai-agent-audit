# Vulnerability details

## Proof of Concept
The _addCredIdPerAddress() and _removeCredIdPerAddress() functions are of the public type. Anyone can call them with their own parameters. At the same time, an attacker can use these functions to influence the array: _credIdsPerAddress, _credIdsPerAddressCredIdIndex, _credIdsPerAddressArrLength. Data can be changed, added, and deleted in these arrays.

At the moment, the array _credIdsPerAddress, _credIdsPerAddressCredIdIndex, _credIdsPerAddressArrLength are not used anywhere except for the getPositionsForCurator() function, which is a view. However, it can be assumed that these parameters will be used when expanding the functionality of the system. This will lead to incorrect operation.

## Tools Used
Manual review

## Recommended Mitigation Steps
Change the type of the functions _addCredIdPerAddress() and _removeCredIdPerAddress() from public to internal.
