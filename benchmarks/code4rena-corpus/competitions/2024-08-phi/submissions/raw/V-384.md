# Vulnerability details


#### Description
   The `priceLimit` checks (`priceLimit` in buy and sell scenarios) can be exploited by front-running attacks. An attacker could monitor pending transactions and front-run them by submitting a transaction with a slightly better price limit, causing the original transaction to fail.

   **Recommendation:**  
   - Implement a time-based order mechanism or allow users to specify tighter slippage limits to reduce the window for front-running attacks.
   - Consider implementing a commitment scheme where the user first submits a hash of their order and then reveals it later, making it harder for attackers to front-run.
