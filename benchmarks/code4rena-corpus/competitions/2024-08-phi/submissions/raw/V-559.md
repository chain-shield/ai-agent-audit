# Vulnerability details

## Impact
This report highlights a potential Denial of Service (DoS) vulnerability that affects both the claim and batchClaim functions in the smart contract. The core issue arises from the use of the merkleClaim and  signatureClaim functions, which is protected by a whenNotPaused modifier. When the contract is paused, both claim and batchClaim functions will fail, leading to a denial of service for users attempting to claim their tokens.
## Proof of Concept

claim Function:

The claim function allows users to claim their tokens by providing proof, claim data, minting arguments, and other parameters. This function internally calls merkleClaim and  signatureClaim, which is the actual function responsible for verifying Merkle proofs and signers respectively for minting token.

batchClaim Function:

The batchClaim function enables users to execute multiple claim operations within a single transaction to save gas costs. It accepts an array of encoded claim data and corresponding ETH values and iteratively calls the claim function for each item in the array.

Vulnerability Description
Both the claim and batchClaim functions are indirectly dependent on the merkleClaim and  signatureClaim functions, which is guarded by the whenNotPaused modifier. When the contract is paused:

merkleClaim  and signatureClaim functions fails: Because it is protected by whenNotPaused, any call to merkleClaim and  signatureClaim will revert.
claim function fails: The claim function directly call merkleClaim and  signatureClaim. If the latter fails, the claim function will also revert.
batchClaim function fails: The batchClaim function iteratively calls claim. If any call to claim fails due to a paused state, the entire batch operation will revert, causing a DoS for the claim and  batch claim attempt.

## Tools Used
Manual Analysis

## Recommended Mitigation Steps
Add a check at the beginning of both functions to determine if the contract is paused. If it is paused, revert immediately with a clear error message, avoiding unnecessary computation and gas fees.
