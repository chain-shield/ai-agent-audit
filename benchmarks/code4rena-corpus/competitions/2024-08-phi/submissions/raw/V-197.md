# Vulnerability details

## Impact
The `CuratorRewardsDistributor.sol:distribute` is in charge of distributing the curators' rewards and it should be called by someone. 
The problem is that it is using the push pattern, which makes it so expensive to distribute rewards to all curators because the gas cost increases with the increase of curators. 
This will delay the distribution of rewards when there are many curators because they may experience losses instead of profit if they
distribute the rewards

Curators will receive their rewards with a delay or even lose their profit

## Proof of Concept
Paste the following test in `Cred.t.sol` to see the gas consumption, which is about `32825780` gas
when there are 999 curators:

```javascript
function testLargeGasConsuptionOnDistribution() public {
    uint256 credId = 1;
    bytes32 merkleRoot = 0xdc4c272ceaa7b5ba9e0f3f9972f735f14e1b4ed191e15d0d17afc62792226428;

    // Create the initial cred
    _createCred("ADVANCED", "MERKLE", merkleRoot);

    address[] memory buyers = new address[](998);

    vm.warp(START_TIME + 1);
    // Buy one by one up to 998
    for (uint256 i = 0; i < 998; i++) {
        address buyer = makeAddr(string(abi.encodePacked("buyer", i)));
        buyers[i] = buyer;
        vm.deal(buyer, 11_000 ether);

        vm.startPrank(buyer);
        uint256 currentSupply = cred.credInfo(credId).currentSupply;
        uint256 buyAmount = 1;
        uint256 price = bondingCurve.getBuyPriceAfterFee(credId, currentSupply, buyAmount);

        cred.buyShareCred{ value: price }(credId, buyAmount, 0);

        assertEq(cred.getShareNumber(credId, buyer), buyAmount);
        assertEq(cred.credInfo(credId).currentSupply, currentSupply + buyAmount);
        vm.stopPrank();
    }

    assertEq(cred.credInfo(credId).currentSupply, 999); // 1 initial + 998 purchases
    assertEq(cred.getCuratorAddresses(credId, 0, 0).length, 999);

    // Distribute rewards
    vm.startPrank(owner);
    vm.deal(owner, 1_000_000 ether);
    uint256 depositAmount = 1 ether;

    // Deposit some ETH to the curatorRewardsDistributor
    curatorRewardsDistributor.deposit{ value: depositAmount }(credId, depositAmount);
    uint256 gasBefore = gasleft();
    console2.log("Gas before distribute: ", gasBefore);
    curatorRewardsDistributor.distribute(credId);
    console2.log("Gas after distribute: ", gasleft());
    console2.log("Gas used: ", gasBefore - gasleft());
}
```
