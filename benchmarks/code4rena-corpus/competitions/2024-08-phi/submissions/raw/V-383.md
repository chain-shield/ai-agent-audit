# Vulnerability details

#### Description:
   The `sellShareCred` function does not effectively control slippage. The `priceLimit` (used as `minPrice_`) in the `_handleTrade` function is applied after fees (protocol and creator) are deducted. This can result in a sale being executed at a much lower price than expected, especially if fees are high.


   **Recommendation:**  
   - Apply the slippage check before subtracting the fees:
     ```solidity
     if (priceLimit != 0 && price < priceLimit + protocolFee + creatorFee) revert PriceBelowLimit();
     ```
