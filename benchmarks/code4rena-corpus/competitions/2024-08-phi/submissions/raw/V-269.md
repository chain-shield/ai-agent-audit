# Vulnerability details

## Impact
The `handleRewardsAndGetValueSent` function in the `PhiRewards` contract lacks access control This oversight allows malicious actors to inflate their reward balance, while the malicious actor still needs to provide `msg.value`, this is still a vulnerability as rewards balance can be used for potential airdrops.
I should also note that `handleRewardsAndGetValueSent` doesn't check the relation between `artId` and `credId`
The platform's reward system might not accurately reflect the intended relationship between art pieces and their associated credentials.
