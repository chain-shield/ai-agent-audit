# Vulnerability details

## Description:
The claim function in PhiFactory.sol does not validate whether the provided artId exists before proceeding with the claim process. If the artId does not exist, the function will still proceed, causing the transaction to fail and other unintended behaviors.


## Proof of Concept
Add the following function in
/test/PhiFactory.t.sol
and run with
forge test --mt test_claim_invalid_artId -vvv
```
function test_claim_invalid_artId() public {
    // Use a non-existent artId
    uint256 invalidArtId = 9999; // Set an invalid artId to simulate the edge case
    // Ensure the artId does not exist
    require(arts[invalidArtId].artAddress == address(0), "artId should not exist");
    // Prepare advanced data for the claim
    bytes32 advanced_data = bytes32("1");
    // Construct the signData for the claim
    bytes memory signData = abi.encode(expiresIn, participant, referrer, verifier, invalidArtId, block.chainid, advanced_data);
    // Generate the message hash and digest for signing
    bytes32 msgHash = keccak256(signData);
    bytes32 digest = ECDSA.toEthSignedMessageHash(msgHash);
    // Sign the digest using the claim signer's private key
    (uint8 v, bytes32 r, bytes32 s) = vm.sign(claimSignerPrivateKey, digest);
    if (v != 27) s = s | bytes32(uint256(1) << 255); // Adjust the signature if necessary
    // Encode the signature and other claim data
    bytes memory signature = abi.encodePacked(r, s);
    bytes memory data = abi.encode(invalidArtId, participant, referrer, verifier, expiresIn, uint256(1), advanced_data, IMAGE_URL, signature);
    // Compress the claim data
    bytes memory dataCompressed = LibZip.cdCompress(data);
    // Calculate the total mint fee for the claim
    uint256 totalMintFee = phiFactory.getArtMintFee(invalidArtId, 1);
    // Start simulating the participant's actions
    vm.startPrank(participant, participant);
    // Expect this call to fail because artId does not exist
    vm.expectRevert();
    phiFactory.claim{ value: totalMintFee }(dataCompressed);
}
```
