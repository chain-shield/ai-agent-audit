# Vulnerability details

## Impact
The `getPositionsForCurator` function incorrectly populates the `credIds` and `amounts` arrays, which can lead to gaps in the returned data. As a result, the function will return arrays with empty slots, leading to incorrect or incomplete data being provided to the caller. 

## Proof of Concept
Here in the `getPositionsForCurator` function: https://github.com/code-423n4/2024-08-phi/blob/8c0985f7a10b231f916a51af5d506dd6b0c54120/src/Cred.sol#L508-L517

```solidity
for (uint256 i = start_; i < stopIndex; i++) {
    uint256 credId = userCredIds[i];
    if (_credIdExistsPerAddress[curator_][credId]) {
        uint256 amount = shareBalance[credId].get(curator_);
        credIds[i] = credId;  // Incorrect indexing
        amounts[i] = amount;  // Incorrect indexing
        index++;
    }
}
```

The `getPositionsForCurator` function is meant to return two arrays: `credIds` and `amounts`, representing the cred IDs where the curator has a position and the corresponding amounts.


The function creates `credIds` and `amounts` arrays with a size of `stopIndex - start_`. It then loops through the `userCredIds` array from `start_` to `stopIndex`. For each credId, it checks if the curator has a position (`_credIdExistsPerAddress[curator_][credId]`). If the curator has a position, it adds the credId and amount to the arrays:

   ```solidity
   credIds[i] = credId;
   amounts[i] = amount;
   ```
The meat of the matter here is that it's using `i` as the index for `credIds` and `amounts`, which is the same as the loop counter. The problem with this approach is that if there are any credIds where the curator doesn't have a position, it will leave gaps in the `credIds` and `amounts` arrays.

For example, if the curator has positions in credIds 1, 3, and 5, but not 2 and 4, the resulting arrays might look like this:

```
credIds:  [1, _, 3, _, 5]
amounts:  [10, _, 20, _, 30]
```

Where `_` represents empty or default values.

## Recommended Mitigation Steps

The function should use a separate index (like `index` in the code) for populating the `credIds` and `amounts` arrays, only incrementing it when a valid position is found:

```diff
for (uint256 i = start_; i < stopIndex; i++) {
    uint256 credId = userCredIds[i];
    if (_credIdExistsPerAddress[curator_][credId]) {
        uint256 amount = shareBalance[credId].get(curator_);
-       credIds[i] = credId; 
-       amounts[i] = amount; 
+       credIds[index] = credId;  
+       amounts[index] = amount;  
        index++;
    }
}
```


This way, still using our example above, the resulting arrays would be:

```
credIds:  [1, 3, 5]
amounts:  [10, 20, 30]
```
