# Vulnerability details

## Impact

Excess amount of fee should be returned to `msg.sender` but a flaw in `PhiNFT1155::createArtFromFactory` refund process combined with the inability of `PhiFactory` to receive ether would make the `createArt` when creating new NFT contract fails.

## Proof of Concept

Calling `PhiFactory::createArt` with excess fee would make the excess fee be refunded back to `msg.sender` but the logic of refunding is located in `PhiNFT1155` contract:

```javascript
    function createArtFromFactory(uint256 artId_) external payable onlyPhiFactory whenNotPaused returns (uint256) {
        _artIdToTokenId[artId_] = tokenIdCounter;
        _tokenIdToArtId[tokenIdCounter] = artId_;

        uint256 artFee = phiFactoryContract.artCreateFee();

        protocolFeeDestination.safeTransferETH(artFee);
        emit ArtCreated(artId_, tokenIdCounter);
        uint256 createdTokenId = tokenIdCounter;

        unchecked {
            tokenIdCounter += 1;
        }
        if ((msg.value - artFee) > 0) {
@>          _msgSender().safeTransferETH(msg.value - artFee);
        }

        return createdTokenId;
    }
```

the refunding process takes `_msgSender()` as recipient whose in this context is `PhiFactory` and emphasize by the modifier `onlyPhiFactory`. this is problematic because `PhiFactory` does not have `receive()` or `fallback()` function. also the correct way is the value of `_msgSender()` when refunding should be the one calling the `PhiFactory::createArt` not the `PhiFactory` itself.

## Recommended Mitigation Steps

to correct the refund behavior when creating new NFT contract, I suggest to implement the refund logic inside `PhiFactory` instead of `PhiNFT1155`:

`PhiFactory.sol`:

```diff
    function _createNewNFTContract(
        PhiArt storage art,
        uint256 newArtId,
        ERC1155Data memory createData_,
        uint256 credId,
        uint256 credChainId,
        string memory verificationType
    )
        private
        returns (address)
    {
        address payable newArt =
            payable(erc1155ArtAddress.cloneDeterministic(keccak256(abi.encodePacked(block.chainid, newArtId, credId))));

        art.artAddress = newArt;

        IPhiNFT1155Ownable(newArt).initialize(credChainId, credId, verificationType, protocolFeeDestination);

        credNFTContracts[credChainId][credId] = address(newArt);
        (bool success_, bytes memory response) =
-           newArt.call{ value: msg.value }(abi.encodeWithSignature("createArtFromFactory(uint256)", newArtId));
+       // sending only the required amount of ether to PhiNFT1155 contract
+           newArt.call{ value: artCreateFee }(abi.encodeWithSignature("createArtFromFactory(uint256)", newArtId));

        if (!success_) revert CreateFailed();
        uint256 tokenId = abi.decode(response, (uint256));
        emit ArtContractCreated(createData_.artist, address(newArt), credId);
        emit NewArtCreated(createData_.artist, credId, credChainId, newArtId, createData_.uri, address(newArt), tokenId);

+       // send the excess back to msg.sender
+       if (msg.value > artCreateFee) {
+           _msgSender().safeTransferETH(msg.value - artCreateFee);
+       }
        return address(newArt);
    }

```
