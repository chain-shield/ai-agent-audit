# Vulnerability details

In the contract, there are two functions for claiming art rewards: `signatureClaim` and `merkleClaim`. The `merkleClaim` function includes a verification check to ensure that the art's verification type matches the claim method (i.e., the art must have a verification type of "MERKLE" to be claimed using the `merkleClaim` function). However, the `signatureClaim` function lacks a similar check for the art's verification type.

## Impact
The lack of a verification type check in the `signatureClaim` function compromises the integrity of the art claiming process. It allows users to claim art rewards using a signature even if the art is meant to be verified only through a Merkle proof. This could result in unauthorized claims, where the art's verification type is not properly enforced, leading to potential misuse and incorrect distribution of rewards.

## Proof of Concept
```
function signatureClaim(
    bytes calldata signature_,
    bytes calldata encodeData_,
    MintArgs calldata mintArgs_
)
    external
    payable
    whenNotPaused
{
    // No verification type check
    _validateAndUpdateClaimState(artId_, minter_, mintArgs_.quantity);
    _processClaim(artId_, minter_, ref_, verifier_, mintArgs_.quantity, data_, mintArgs_.imageURI, msg.value);

    emit ArtClaimedData(artId_, "SIGNATURE", minter_, ref_, verifier_, arts[artId_].artAddress, mintArgs_.quantity);
}
```

The `merkleClaim` function ensures that only art with a verification type of `"MERKLE"` can be claimed using a Merkle proof.
The `signatureClaim` function does not check if the art's verification type matches `"SIGNATURE"`, allowing invalid claims.

## Recommended Mitigation Steps
To ensure that claims are made only with the appropriate verification type, add a similar verification type check in the `signatureClaim` function as is done in the `merkleClaim` function. This will enforce that art can only be claimed using the correct method and prevent unauthorized claims.

Suggested code change:
```
if (!art.verificationType.eq("SIGNATURE")) {
    revert InvalidSignatureClaim();
}
```
