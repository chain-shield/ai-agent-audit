# Vulnerability details

## Impact
contract will revert when call `contractURI`

## Proof of Concept
https://github.com/code-423n4/2024-08-phi/blob/8c0985f7a10b231f916a51af5d506dd6b0c54120/src/PhiFactory.sol#L64

if we call `contractURI` like this, it will revert. 
```
    function test_contractURI() public {
        string memory uri = phiFactory.contractURI(address(0));
    }
```
