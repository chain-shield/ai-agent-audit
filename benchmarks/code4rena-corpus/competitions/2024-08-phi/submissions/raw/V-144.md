## Impact

The current `initialize` function incorrectly calls `__Ownable_init(msg.sender);`, which is a non-existent function in the provided code since the contract is using `Ownable2StepUpgradeable`. This will result in the contract's ownership not being properly initialized.

## Proof of Concept
In the `initialize` function of the `PhiNFT1155` contract, the following line is used to initialize ownership:

```javascript 
__Ownable_init(msg.sender);
```

However, the correct OpenZeppelin initialization function for `Ownable2StepUpgradeable` is `__Ownable2Step_init()`, which does not accept any parameters. The incorrect initialization call could leave the owner variable unassigned.

## Recommended Mitigation Steps
Replace the incorrect `__Ownable_init(msg.sender);` call with the correct OpenZeppelin function `__Ownable2Step_init();`.

```diff
function initialize(
    uint256 credChainId_,
    uint256 credId_,
    string memory verificationType_,
    address protocolFeeDestination_
)
    external
    initializer
{
-   __Ownable_init(msg.sender);
+   __Ownable2Step_init();

    __Pausable_init();
    __ReentrancyGuard_init();
    initializeRoyalties(protocolFeeDestination_);

}
```
