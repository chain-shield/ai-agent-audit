# Vulnerability details

## Impact
The `artCreateFee` in PhiFactory is supposed to use BPS. But, the protocol uses it as a flat fee causing the protocol to take less fees than it should.

## Proof of Concept
In `PhiFactory.setArtCreateFee()` the value is limited to `<= 10_000`:

```sol
    /// @notice Sets the art creation fee percentage.
    /// @param artCreateFee_ The new art creation fee percentage (in basis points).
    function setArtCreatFee(uint256 artCreateFee_) external onlyOwner {
        if (artCreateFee_ > 10_000) revert ArtCreatFeeTooHigh();
        artCreateFee = artCreateFee_;
        emit ArtCreatFeeSet(artCreateFee_);
    }
```

In `PhiNft1155`, it uses `artCreateFee` as a flat fee:

```sol

    /// @notice Creates a new art from the Phi Factory contract.
    function createArtFromFactory(uint256 artId_) external payable onlyPhiFactory whenNotPaused returns (uint256) {
        _artIdToTokenId[artId_] = tokenIdCounter;
        _tokenIdToArtId[tokenIdCounter] = artId_;

        uint256 artFee = phiFactoryContract.artCreateFee();

        protocolFeeDestination.safeTransferETH(artFee);
        emit ArtCreated(artId_, tokenIdCounter);
        uint256 createdTokenId = tokenIdCounter;

        unchecked {
            tokenIdCounter += 1;
        }
        if ((msg.value - artFee) > 0) {
            _msgSender().safeTransferETH(msg.value - artFee);
        }

        return createdTokenId;
    }
```

On initialization, you can use any value you want for `artCreateFee`. But, the current deployment script sets it to $0$:

```sol
        PhiFactory(payable(address(phiFactoryProxy))).initialize(
            signer, oji3, address(phiNFT1155), address(phiRewards), oji3, 0.00005 ether, 0
        );
```

After deployment, you're limited to at most $10,000$ which is 0.00000000000001 ETH or 2.5e-11 USD.
