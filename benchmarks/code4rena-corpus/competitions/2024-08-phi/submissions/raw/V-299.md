# Vulnerability details

## Impact
The sellers of shares in the bonding curve are directly affected when the supply of shares reaches zero after a sell operation, the `getPrice` function in BondingCurve.sol returns a sell price of zero. Consequently, the sellers will receive zero funds for their shares, suffering a complete loss of their investment.

The impact of this issue is severe, as it can result in substantial financial losses for sellers and erode trust in the bonding curve mechanism.

## Proof of Concept
The root cause of the issue lies in the [getPrice function](https://github.com/code-423n4/2024-08-phi/blob/8c0985f7a10b231f916a51af5d506dd6b0c54120/src/curve/BondingCurve.sol#L47-L49) of the BondingCurve.sol contract. Specifically.
```solidity
// BondingCurve.sol: Line 47-48
function getPrice(uint256 supply_, uint256 amount_) public pure returns (uint256) {
    return _curve((supply_ + amount_) * 1 ether) - _curve(supply_ * 1 ether);
}
```
When the `supply_` parameter is zero and the `amount_` parameter is non-zero (e.g., when selling shares and the resulting supply becomes zero), the `getPrice` function calculates the price by subtracting `_curve(0)` from `_curve(amount_ * 1 ether)`. However, due to the design of the bonding curve formula in the `_curve` function, both `_curve(0)` and `_curve(amount_ * 1 ether)` evaluate to the same value, resulting in a sell price of zero.

The choice to calculate the price using the current approach in the `getPrice` function is a mistake, as it fails to handle the case when the supply becomes zero after a sell operation.

**Scenario**

1. Alice owns 1 share of a bonding curve with a total supply of 1 share.
2. Alice decides to sell her 1 share by calling the `sellShareCred` function in the Cred.sol contract.
3. The `sellShareCred` function calls the `getPrice` function in the `BondingCurve.sol `contract to determine the sell price.
4. Since the current supply is 1 and Alice is selling 1 share, the `getPrice` function is called with supply_ set to 0 and amount_ set to 1.
5. The `getPrice` function calculates the sell price by subtracting `_curve(0)` from` _curve(1 ether)`, which both evaluate to the same value, resulting in a sell price of zero.
6. Alice's sell transaction is processed, and she receives zero funds for her 1 share, losing her entire investment.

## Recommended Mitigation Steps
Handle the case when the supply becomes zero after a sell operation. One possible solution is to add a check to return a non-zero price when the supply is zero and the amount is non-zero.

```diff
// BondingCurve.sol: Line 47-48
function getPrice(uint256 supply_, uint256 amount_) public pure returns (uint256) {
+   if (supply_ == 0 && amount_ > 0) {
+       return _curve(amount_ * 1 ether);
+   }
    return _curve((supply_ + amount_) * 1 ether) - _curve(supply_ * 1 ether);
}
```
By adding this check, the `getPrice` function will return a non-zero sell price when the supply is zero and the amount is non-zero, ensuring that sellers receive the correct amount of funds for their shares.
