# Vulnerability details

## Impact
Denial of Service (DoS)


## Proof of Concept
The _processClaim function in the PhiFactory smart contract has a vulnerability related to unsigned integer subtraction. Specifically, the function performs the subtraction etherValue_ - mintFee without checking if etherValue_ is greater than or equal to mintFee. As both etherValue_ and mintFee are of type uint256, if etherValue_ is less than mintFee, this will cause an integer underflow, resulting in a revert due to Solidity's built-in overflow and underflow checks (enabled by default in Solidity 0.8.0 and later). If a user provides an etherValue_ that is less than mintFee, the subtraction will cause the function to revert, leading to a denial of service. This can disrupt the normal functioning of the contract and prevent users from claiming their art if their input is not perfectly calibrated to match the required mintFee.
