# Vulnerability details

## Proof of Concept
The createArt() function - Creates an art. This is done by calling cloneDeterministic from the solady library (https://github.com/code-423n4/2024-08-phi/blob/main/src/PhiFactory.sol#L632).

The PhiNFT1155 contract is an upgradable contract because it inherits from UUPSUpgradeable:
https://github.com/code-423n4/2024-08-phi/blob/main/src/art/PhiNFT1155.sol#L23

Using clone is incompatible with upgradable contracts, which require the use of a proxy.

This issue will result in the PhiNFT1155 created PhiFactory instance not being upgraded. The PhiNFT1155 contract will contain all the logic needed to upgrade, but the action will fail because there is no proxy to change to the new potential implementation.

## Tools Used
Manual review

## Recommended Mitigation Steps
An instance of PhiNFT1155 should be created using a proxy on top of the base implementation ( createERC1967Proxy ) instead of cloning the implementation.
