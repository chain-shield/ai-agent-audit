# Vulnerability details

## Impact

The functions `Cred::_addCredIdPerAddress()` and `Cred::_removeCredIdPerAddress()` are only called via the function
`Cred::_updateCuratorShareBalance()`, which is internal. However, both `_addCredIdPerAddress` and
`_removeCredIdPerAddress` are marked as public, which allows anyone to update the state and add/remove a new credId to the address's list. These functions take arbitrary
`uint256 credId_` and `address sender_`, enabling anyone to change values for any user.

Here is the implementation of `Cred::_updateCuratorShareBalance()`:

```javascript
function _updateCuratorShareBalance(uint256 credId_, address sender_, uint256 amount_, bool isBuy) internal {
    (, uint256 currentNum) = shareBalance[credId_].tryGet(sender_);

    if (isBuy) {
        if (currentNum == 0 && !_credIdExistsPerAddress[sender_][credId_]) {
            // @audit _addCredIdPerAddress() can only be called through here, therefore shouldn't be public
            @> _addCredIdPerAddress(credId_, sender_);
            _credIdExistsPerAddress[sender_][credId_] = true;
        }
        shareBalance[credId_].set(sender_, currentNum + amount_);
    } else {
        if ((currentNum - amount_) == 0) {
            // @audit _removeCredIdPerAddress() can only be called through here, therefore shouldn't be public
            @> _removeCredIdPerAddress(credId_, sender_);
            _credIdExistsPerAddress[sender_][credId_] = false;
        }
        shareBalance[credId_].set(sender_, currentNum - amount_);
    }
}
```

## Recommended Mitigation Steps

- Change the functions' visibility to either `private` or `internal` based on the use case, so that nobody can
  externally call these functions with arbitrary data.

```diff
- function _addCredIdPerAddress(uint256 credId_, address sender_) public
+ function _addCredIdPerAddress(uint256 credId_, address sender_) private

- function _removeCredIdPerAddress(uint256 credId_, address sender_) public
+ function _removeCredIdPerAddress(uint256 credId_, address sender_) private
```
