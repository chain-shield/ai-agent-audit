# Vulnerability details

## Impact
1. Overflow Risk:
 - There's a potential for overflow in the calculation (supply_ + amount_) * 1 ether. If supply_ and amount_ are large enough, this multiplication could overflow.
2. Precision Loss:
 - The function multiplies by 1 ether (10^18) before calling _curve(), which could lead to precision loss for very small values of supply_ or amount_.
3. Negative Price:
 - It's possible for this function to return a negative value if _curve(supply_ * 1 ether) is greater than _curve((supply_ + amount_) * 1 ether), which could lead to unexpected behavior.
4. Dependency on _curve():
 - The function relies heavily on the _curve() function, which we've already identified as having potential issues (division by zero, overflow, underflow).
5. No Input Validation:
 - There are no checks on the input parameters supply_ and amount_. This could lead to unexpected results or reverts if invalid values are provided.
6. Gas Inefficiency:
 - The function calls _curve() twice, which could be gas inefficient for complex curve calculations.
