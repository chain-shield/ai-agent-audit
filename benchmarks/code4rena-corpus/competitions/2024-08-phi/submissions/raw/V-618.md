# Vulnerability details

### Summary

There is a critical flaw in the sell price calculation within the BondingCurve contract, specifically in the `getSellPrice` function. This issue arises due to the incorrect treatment of the supply parameter when calculating the sell price, leading to unintended financial implications for users.

The `getSellPrice` function currently calls `getPrice(supply_ - amount_, amount_)`. This approach mistakenly treats the sell operation as a buy operation at a lower supply level, which results in a higher sell price than intended. The expected behavior of a bonding curve is that the sell price should decrease as more shares are sold, reflecting reduced demand. However, the current implementation contradicts this principle, leading to inflated prices during sell transactions.

### Impact

1. **Overpayment to Sellers**: Sellers receive more funds than they should when selling shares, disrupting the expected economic model.
2. **Incentive Misalignment**: The bonding curve fails to incentivize users to hold shares during periods of low demand, which could lead to rapid depletion of contract funds.
3. **Trust Erosion**: If users discover this flaw, it could significantly damage trust in the platform, potentially leading to a loss of user engagement and financial backing.

### Scenario

In a scenario where a cred has a current supply of 100 shares, and a user attempts to sell 10 shares, the incorrect calculation would treat it as if the supply were increasing from 90 to 100. This results in a higher price than what would be appropriate, effectively overpaying the seller.

## Proposed Fix

The `getSellPrice` function should be modified to correctly reflect the intended pricing mechanism of the bonding curve. The corrected function should look like this:

```solidity
function getSellPrice(uint256 supply_, uint256 amount_) public pure returns (uint256) {
    return _curve(supply_ * 1 ether) - _curve((supply_ - amount_) * 1 ether);
}
```

This adjustment ensures that the sell price is calculated as the difference between the current supply point on the curve and the point after reducing the supply by the sold amount.

Additionally, the `getPriceData` function should utilize this corrected `getSellPrice` function for sell operations to ensure consistency across the contract:

```solidity
function getPriceData(
    uint256 credId_,
    uint256 supply_,
    uint256 amount_,
    bool isSign_
)
    public
    view
    returns (uint256 price, uint256 protocolFee, uint256 creatorFee)
{
    price = isSign_ ? getPrice(supply_, amount_) : getSellPrice(supply_, amount_);
    // ... rest of the function remains the same
}
```

```solidity
function testIncorrectSellPriceMechanism() public {
    uint256 credId = 1;
    uint256 initialSupply = 1;
    uint256 buyAmount = 10;
    uint256 sellAmount = 5;

    // Create initial cred
    _createCred("BASIC", "SIGNATURE", 0x0);

    // Buy some shares
    vm.startPrank(anyone);
    uint256 buyPrice = bondingCurve.getBuyPriceAfterFee(credId, initialSupply, buyAmount);
    cred.buyShareCred{ value: buyPrice }(credId, buyAmount, 0);
    vm.stopPrank();

    // Wait for lock period to pass
    vm.warp(block.timestamp + 10 minutes + 1 seconds);

    // Calculate expected correct sell price
    uint256 currentSupply = initialSupply + buyAmount;
    uint256 expectedSellPrice = bondingCurve.getPrice(currentSupply - sellAmount, sellAmount);
    
    // Calculate actual sell price from the contract
    uint256 actualSellPrice = bondingCurve.getSellPrice(currentSupply, sellAmount);

    // Assert that the actual sell price is higher than the expected correct price
    assertGt(actualSellPrice, expectedSellPrice, "Actual sell price should be higher than expected");

    // Calculate the difference to show the overpricing
    uint256 priceDifference = actualSellPrice - expectedSellPrice;
    console2.log("Sell price overestimation:", priceDifference);

    // Try to sell shares
    vm.startPrank(anyone);
    uint256 balanceBefore = anyone.balance;
    cred.sellShareCred(credId, sellAmount, 0);
    uint256 balanceAfter = anyone.balance;

    // Check that the seller received more than they should have
    uint256 receivedAmount = balanceAfter - balanceBefore;
    assertGt(receivedAmount, expectedSellPrice, "Seller received more than expected");

    console2.log("Expected sell price:", expectedSellPrice);
    console2.log("Actually received:", receivedAmount);
    console2.log("Excess amount received:", receivedAmount - expectedSellPrice);

    vm.stopPrank();
}
```
