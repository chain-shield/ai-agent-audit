# Vulnerability details

## Impact

Check [these](https://github.com/code-423n4/2024-07-traitforge/blob/279b2887e3d38bc219a05d332cbcb0655b2dc644/contracts/EntityForging/EntityForging.sol#L111-L118) `require()` statements which check that merger and forger NFTs don't have the same owner.

User can transfer NFT to his own smart contract (which bypasses those checks) and basically forge between his own accounts. This way user doesn't pay a mint fee (at least `0.005 ether`) but pays only a 10% dev cut from a minimal forge fee of `0.01` ether. 

So user can basically "mint" (via forging) new NFTs paying only `0.001` ether instead of a normal mint fee.

## Tools Used

Manual review

## Recommended Mitigation Steps

One of the solutions could be to increase a minimal forge fee to equal current mint fee.
