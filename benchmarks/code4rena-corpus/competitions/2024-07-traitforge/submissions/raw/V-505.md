# Vulnerability details

## Impact

Forging for the first few generations will not work.

## Proof of Concept

Whenever `_mintInternal` (user pays to mint) or `_mintNewEntity` (user forges and mint) is called, the `generationMintCounts[currentGeneration]` increases by 1.

In `forge()`, if two gen1 heroes is forged together, a gen2 hero will be forged (only 1 above).

```
uint256 newGeneration = getTokenGeneration(parent1Id) + 1;
```

In `_mintNewEntity()`, there is a check that to make sure that `generationMintCounts[gen]` not greater than maxTokensPerGen (10,000).

```
  function _mintNewEntity(
    address newOwner,
    uint256 entropy,
    uint256 gen
  ) private returns (uint256) {
    require(
      generationMintCounts[gen] < maxTokensPerGen,
      'Exceeds maxTokensPerGen'
    );

```

If there is an influx of mints, let's say 30,000 mint happens at once because of good marketing and publicity, then if Alice and Bob wants to forge their gen1 hero and make a good gen2 hero, they can't do so because the current generation is 4 now and not 2. Their good gen1 heroes will be wasted since it cannot be used to forge anymore.

## Recommended Mitigation Steps

Early generations should still have the capability to mint, maybe until maximum total mint or maximum forging mint. Recommend not combining the total paid entities with the total forged entities.
