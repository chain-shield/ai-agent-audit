# Vulnerability details

## Impact
The `startAirdrop` function uses `tx.origin` to transfer tokens, which can lead to functional issues if the contract owner is not an Externally Owned Account (EOA) but another contract. In such cases, `tx.origin` will not correctly reflect the contract owner, potentially leading to failed transactions or incorrect token transfers.

## Proof of Concept

    function startAirdrop(
      uint256 amount
    ) external whenNotPaused nonReentrant onlyOwner {
      require(!started, 'Already started');
      require(amount > 0, 'Invalid amount');
      traitToken.transferFrom(tx.origin, address(this), amount);
      started = true;
      totalTokenAmount = amount;
    }

tx.origin is used to transfer tokens from the original sender of the transaction. If the contract owner is another contract, tx.origin will not match the contract owner, leading to incorrect or failed transfers.

## Tools Used
Manual code review.

## Recommended Mitigation Steps
Use the stored contract owner address instead of tx.origin to ensure that the token transfer is initiated from the correct account.

    address public owner;

    constructor() {
      owner = msg.sender;
    }

    function startAirdrop(
      uint256 amount
    ) external whenNotPaused nonReentrant onlyOwner {
      require(!started, 'Already started');
      require(amount > 0, 'Invalid amount');
      traitToken.transferFrom(owner, address(this), amount);
      started = true;
      totalTokenAmount = amount;
    }
