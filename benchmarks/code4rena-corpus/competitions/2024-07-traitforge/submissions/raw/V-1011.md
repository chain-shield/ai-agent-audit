# Vulnerability details

## Vulnerability details :-
The `nukeFundAddress` variable stores the address of the NukeFund contract, which is set by the contract owner.
If the owner fails to set the `nukeFundAddress` after contract deployment, the _distributeFunds function will send Ether to an arbitrary address when invoked, resulting in potential loss of funds.

```
function _distributeFunds(uint256 totalAmount) private {
        require(address(this).balance >= totalAmount, "Insufficient balance");

@>        (bool success,) = nukeFundAddress.call{value: totalAmount}("");
        require(success, "ETH send failed");

        emit FundsDistributedToNukeFund(nukeFundAddress, totalAmount);
    }
```


## Impact:-
The contract will lose Ether if the address is not set correctly.

## Proof of Concept:-
The `nukeFundAddress` is set by the owner of contract after the creation of contract using the function given below:-
```
    function setNukeFundAddress(address payable _nukeFundAddress) external onlyOwner {
        nukeFundAddress = _nukeFundAddress;
    }
```
If the nukeFundAddress is not set either during contract deployment or by the owner subsequently, any use of the contract's _distributeFunds function will result in Ether being sent to an arbitrary address.
## Tools Used:-
Manual review

## Recommended Mitigation Steps:-
The following steps can be taken to prevent the loss of Ether:
1. The function should include a require statement to verify that the nukeFundAddress is set before proceeding, preventing Ether loss due to unintended transfers.
```
function _distributeFunds(uint256 totalAmount) private {
        require(address(this).balance >= totalAmount, "Insufficient balance");
+       require(nukeFundAddress != address(0), "NukeFund address not set");

        (bool success,) = nukeFundAddress.call{value: totalAmount}("");
        require(success, "ETH send failed");

        emit FundsDistributedToNukeFund(nukeFundAddress, totalAmount);
    }
```
2. The nukeFundAddress variable can be initialized with the NukeFund contract address during contract deployment via the constructor.
```
    constructor(address _traitForgeNft, address _nukeFundAddress) {
        nftContract = ITraitForgeNft(_traitForgeNft);
+        nukeFundAddress = _nukeFundAddress;
    }
