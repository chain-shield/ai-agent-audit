# Vulnerability details

## Impact
nukeFundAddress is not initialized during contract deployment. so it remains set to zero address and will break buyNFT function until it is set to a valid address by the owner.

## Proof of Concept
    constructor(address _traitForgeNft, address payable _nukeFundAddress) {
        require(_nukeFundAddress != address(0));
        require(_traitForgeNft != address(0));
        
        nftContract = ITraitForgeNft(_traitForgeNft);
        nukeFundAddress = _nukeFundAddress;
    }

## Tools Used

## Recommended Mitigation Steps
initialize nukeFundAddress to a valid address inside the constructor.
