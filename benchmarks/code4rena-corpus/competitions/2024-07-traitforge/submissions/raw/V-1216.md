# Vulnerability details

## Impact
Using transferFrom() might cause the NFT to be sent to contracts that do not support ERC721, potentially locking the NFTs permanently.

## Proof of Concept
In function `buyNFT` and `cancelListing`, the NFT will be transferred from EntityTrading to seller/buyer address.

However, if the reveiving address is a contract address that does not support ERC721, the NFT can be locked in that contract.

```
nftContract.transferFrom(address(this), msg.sender, tokenId);
```

Ref: 
https://eips.ethereum.org/EIPS/eip-721
https://github.com/sherlock-audit/2022-11-frankendao-judging/issues/55

## Tools Used

Manual

## Recommended Mitigation Steps

Using safeTransferFrom() instead of transferFrom().


## Assessed type

ERC721
