# Vulnerability details

There are two issues:
1. Incorrect Percentage Calculation
2. Potential result for devShare could be 0

uint256 devShare = msg.value / taxCut;

if msg.value is 5 and taxCut is 10, this calculation will lead to devShare = 0, caused by integer division in Solidity. 

if we are speaking about representing 10% it should looks like:
uint256 devShare = (5 * 10) / 100; 

possible solution with MAX_DENOMINATOR;
uint256 devShare = (msg.value * taxCut) / MAX_DENOMINATOR;

msg.value = 5000 (representing some value in wei)
taxCut = 10000 (representing a 10% tax cut, as 10 * (MAX_DENOMINATOR / 100))
MAX_DENOMINATOR = 100000
