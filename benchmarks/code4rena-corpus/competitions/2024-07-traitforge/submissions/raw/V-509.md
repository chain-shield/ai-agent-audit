# Vulnerability details

### Summary

The `receive` function does not restrict who can send ETH to the contract. This can result in ETH being permanently locked in the contract if sent by an unauthorized address.

### Vulnerability Details

- **Issue:** The `receive` function allows any address to send ETH, which can lead to unintended ETH transfers being distruputed to the devs with no way to  redistribute them appropriately.

- **Affected Function:** `receive`

- **Snippet:**
  ```solidity
  receive() external payable {
    // @audit Ensure only specific addresses can send ETH
    require(msg.sender == entityForgingAddress, "Unauthorized sender");

    uint256 devShare = msg.value / taxCut; // Calculate developer's share
    uint256 remainingFund = msg.value - devShare; // Calculate remaining funds to add to the fund

    fund += remainingFund; // Update the fund balance

    if (!airdropContract.airdropStarted()) {
      (bool success, ) = devAddress.call{ value: devShare }('');
      require(success, 'ETH send failed');
      emit DevShareDistributed(devShare);
    } else if (!airdropContract.daoFundAllowed()) {
      (bool success, ) = payable(owner()).call{ value: devShare }('');
      require(success, 'ETH send failed');
    } else {
      (bool success, ) = daoAddress.call{ value: devShare }('');
      require(success, 'ETH send failed');
      emit DevShareDistributed(devShare);
    }

    emit FundReceived(msg.sender, msg.value); // Log the received funds
    emit FundBalanceUpdated(fund); // Update the fund balance
  }
  ```

### Impact

If a normal user sends ETH to this contract, he will be lossing it  forever as the protocol does not refund the amount. This can result in funds being effectively lost, leading to a poor user experience and potential loss of trust in the protocol.

### Tools Used

- Manual Code Review

### Recommendations

1. **Restrict Accepted Senders:** Add a requirement to accept funds only from specific addresses, such as `entityForgingAddress`.
   ```solidity
   require(msg.sender == entityForgingAddress, "Unauthorized sender");
   ```

2. **Add Fallback Mechanism:** Implement a mechanism to refund ETH sent from unauthorized addresses.
   ```solidity
   receive() external payable {
      if (msg.sender != entityForgingAddress) {
          // Refund the sender if unauthorized
          (bool refundSuccess, ) = msg.sender.call{ value: msg.value }('');
          require(refundSuccess, 'Refund failed');
          return;
      }
   ```
