# Vulnerability details

## Impact
The current implementation of the `deriveTokenParameters` function contains errors in the calculation of the `forgePotential` and `nukeFactor`. These errors can lead to incorrect game-related parameters

## Proof of Concept
check out entropy section 
https://docs.google.com/document/d/1pihtkKyyxobFWdaNU4YfAy56Q7WIMbFJjSHUAfRm6BA/edit#heading=h.45lywoxkn9oi

Incorrect Calculation of Forge Potential:

The function uses getFirstDigit(entropy) to determine the forgePotential. This method extracts the first digit of the entropy, which is incorrect.
The correct way to calculate the `forgePotential` should be (entropy / 10) % 10 to extract the second digit from the right.

example -> entropy = 123456, after 123456/10=> 12345%10 = 5 which is the forgePotential.,which indicates how many time forger role can forge.

Incorrect Calculation of Nuke Factor:

The function calculates nukeFactor as entropy / 4000000.
Given that the entropy has a maximum of 6 digits, dividing by 4,000,000 will almost always result in zero.
example -> entropy = 123456/4000000 => 0.030864 == 0

Manual review

## Recommended Mitigation Steps
calculation of forgePotential to correctly extract the second digit from the right.
Adjust the divisor to ensure a meaningful nukeFactor value to 40
```diff

  uint256 slotIndex,
  uint256 numberIndex
)
  public
  view

    uint256 nukeFactor,
    uint256 forgePotential,
    uint256 performanceFactor,
    bool isForger
  )
{
  uint256 entropy = getEntropy(slotIndex, numberIndex);

  // example calculations using entropy to derive game-related parameters
-  nukeFactor = entropy / 4000000;
+  nukeFactor = entropy / 40; // Adjusted divisor for meaningful nukeFactor
-  forgePotential = getFirstDigit(entropy);
+  forgePotential = (entropy / 10) % 10; // Corrected calculation for forgePotential
  performanceFactor = entropy % 10;

  // example logic to determine a boolean property based on entropy
  uint256 role = entropy % 3;
  isForger = role == 0;

  return (nukeFactor, forgePotential, performanceFactor, isForger); // return derived parameters
}
```
