# Vulnerability details

## Impact
Developers will collect less fees.

## Proof of Concept
The provided [docs](https://docs.google.com/document/d/1pihtkKyyxobFWdaNU4YfAy56Q7WIMbFJjSHUAfRm6BA/edit#heading=h.g7dgt2kibh7m) state that 10% of the Nuke fund is streamed directly to the devs.
 
> 10% of all income to the Nuke Fund is streamed to the DEV Fund. Devs can withdraw income at any time. 

However currently these 10% will go to the devs, **but only after the airdrop has started**. Up to it's start of this airdrop the funds will go either to owner or to the DAO.

```solidity
   receive() external payable {
      uint256 devShare = msg.value / taxCut; 
      uint256 remainingFund = msg.value - devShare;
      
      // Devs get the cut, but only after airdrop has started
      if (!airdropContract.airdropStarted()) {
          (bool success,) = devAddress.call{value: devShare}("");
          require(success, "ETH send failed");
          emit DevShareDistributed(devShare);

      // Owner gets the cut
      } else if (!airdropContract.daoFundAllowed()) {
          (bool success,) = payable(owner()).call{value: devShare}("");
          require(success, "ETH send failed");

      // DAO gets the cut
      } else {
          (bool success,) = daoAddress.call{value: devShare}("");
          require(success, "ETH send failed");
          emit DevShareDistributed(devShare);
      }
```
This will significantly lower the amount of fees the decs collect. Even more so as the airdrop can be called months after the project starts.

> It is likely that the Airdrop will be called sometime in the first year of gameplay.
