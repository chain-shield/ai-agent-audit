# Vulnerability details

## Impact
NukeFund::nuke function implemented a check ` require(canTokenBeNuked(tokenId), 'Token is not mature yet');`
https://github.com/code-423n4/2024-07-traitforge/blob/279b2887e3d38bc219a05d332cbcb0655b2dc644/contracts/NukeFund/NukeFund.sol#L163
which calls canTokenBeNuked function which checks wheather tokenAgeInSeconds >= minimumDaysHeld and return true if it is true.
https://github.com/code-423n4/2024-07-traitforge/blob/279b2887e3d38bc219a05d332cbcb0655b2dc644/contracts/NukeFund/NukeFund.sol#L184-L194
the owner of the contract can set minimumDaysHeld to any value of his choice, even to type(uint256).max because they don't set any maximum value to it.
https://github.com/code-423n4/2024-07-traitforge/blob/279b2887e3d38bc219a05d332cbcb0655b2dc644/contracts/NukeFund/NukeFund.sol#L67-L69
If it happens then the check implemented by NukeFund::nuke function will always revert. so users can't nuke and get their share in funds. so eventually funds will be get locked in NukeFund contract.
And then users eventually sell their NFTs with very less price and then owner can buy all those and again change minimumDaysHeld value to a small value and then nuke 
all the NFTs and get ETH back, so this comes under some kind of rug pull.



## Proof of Concept
owner set minimumDaysHeld = type(uint256).max, then NukeFund::nuke function always reverts. so user funds get locked in NukeFund contract.so users eventually sell their TraitForgeNfts will very less prices.Then owner will buy all those NFTs and again set back minimumDaysHeld variable to a very small value and eventually nuke all those NFTs and get all ETH held in NukeFund contract.
Even though owner is a Benevolent (guy or multisig wallet) their private keys may get stolen and eventually attacker gain all funds.
If there is a possibility of rug pull or permanent loss of funds then users may not be interested in protocol. so it is suggested to set a max value(ex- may be 10 days  like that) check so that minimumDaysHeld variable can't be greater than that.

manual review, VS code
## Recommended Mitigation Steps
add this codesnippet in NukeFund::setMinimumDaysHeld function,
`require(0<value<= 10 days,"value can't be greater than 10 days");`
