# Vulnerability details

## Impact
The following contracts: EntityTrading, TraitForgeNft, NukeFund, EntityForging, EntropyGenerator and DevFund (in scope), and Airdrop (not in scope) are supposed to be pausable (as they all inherit from Pausable contract, and use the `whenNotPaused` modifier in some functions), but they don't implement the external `pause/unpause` function which means it will never be possible to pause them. And the modifier `whenNotPaused` will also not work.

## Proof of Concept
All the following contracts: EntityTrading, TraitForgeNft, NukeFund, EntityForging, EntropyGenerator and DevFund inherit from the openzeppelin's Pausable contract which means that they contain internal functions `_pause` and `_unpause` and some functions and modifiers regarding the pause funcionality.

```solidity
    function _pause() internal virtual whenNotPaused {
        _paused = true;
        emit Paused(_msgSender());
    }
    function _unpause() internal virtual whenPaused {
        _paused = false;
        emit Unpaused(_msgSender());
    }
```

Because those two key functions are internal, all contracts inherit from the Pausable contract must implement two other public/external `pause` and `unpause` functions to allow the manager to pause and unpause these contracts when necessary. 

But we can found that none of the aforementioned contracts implement corresponding exteranl functions, which means even if those contracts are supposed to be pausable and some functions are supposed to be unusable when emergency, none of them can be paused in fact.

## Tools Used
Manual Review 

## Recommended Mitigation Steps
Add these two exteranl functions with access control in every contract which should be pausable.

```solidity
  function pause() external onlyOwner {
    _pause();
  }
  function unpause() external onlyOwner {
    _unpause();
  }
```
