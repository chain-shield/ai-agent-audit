# Vulnerability details

### [H-3] TITLE `TraitForgeNft::_incrementGeneration()` fails while calling an onlyOwner function `initializeAlphaIndices()` in `EntropyGenerator.sol` 

**Description:** 
* protocol have the initial plan of deploying `EntropyGenerator.sol`  with their multisig wallet, however forgots that a function from `TraitForgeNft.sol` by name `_incrementGeneration()` is calling another function in `EntropyGenerator.sol` by name `initializeAlphaIndices()` which is restricted to onlyOwner.

**Impact:** 
 `TraitForgeNft::_incrementGeneration()` will never successfully increment generations because it will revert while trying to call an onlyOwner function in `EntropyGenerator.sol`

**Proof of Concept:**
* `EntropyGenerator.sol` deploys with a multisig wallet
* `TraitForgeNft::mintToken` will run successfully till line 281 in `TraitForgeNft::mintInternal` [see here](https://github.com/code-423n4/2024-07-traitforge/blob/279b2887e3d38bc219a05d332cbcb0655b2dc644/contracts/TraitForgeNft/TraitForgeNft.sol#L281) becomes true
* then it will trigger the `_incrementGeneration()` which will also revert on line 353 [see here](https://github.com/code-423n4/2024-07-traitforge/blob/279b2887e3d38bc219a05d332cbcb0655b2dc644/contracts/TraitForgeNft/TraitForgeNft.sol#L353)

* this revert is due to the fact that `TraitForgeNft` is not the owner of `EntropyGenerator.sol`
  
**Recommended Mitigation:**
* either you make TraitForgeNft the owner or you use the modifier `onlyAllowedCaller` which is already designed to be callable by only TraitForgeNft contract
