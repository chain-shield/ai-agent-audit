# Vulnerability details

## Impact
Certain operations which should not work when paused, are still operatable.

## Proof of Concept
All contracts in scope inherit `Pausable` and implements the `whenNotPaused` modifier, but none of them implement any method to actually `pause` or `unpause` the contract. 

`Pausable.sol` only implements `internal` functions, which requires external or public functions to be implemented to wrap them. Since nothing like this has been implemented, the entire pausing system is rendered useless and the required functions cannot be paused as is intended.

## Tools Used
Manual Review

## Recommended Mitigation Steps
Create simple external `pause` and `unpause` functions that can be called by owner.
