# Vulnerability details

## Impact
The variable `maxGeneration` in the `TraitForgeNft.sol` represents the maximum number of generations users are able to mint. 
The generation increases if the maximal number of tokens per one generation is minted/forged.

As we can see from the code snippets above, there is a missing check in all mint functions (`mintWithBudget`, `mintToken`, `_mintInternal`, `_mintNewEntity`), i.e. in the `_incrementGeneration` that checks if the maxGeneration limit is reached before incrementing the generation. This oversight allows users to mint an unlimited number of new tokens regardless of the specified limit

It is also important to mention that this check has been properly applied in the `forge` function. 

## Proof of Concept
In order to simplify the testing for this case, the `maxGeneration` variable is set to 2, and the `maxTokensPerGen` is set to 1. 

After setting the storage variables, add the following test to the `TraitForgeNft.sol`:

```
it('should not be possible to mint tokens after maxGeneration limit is reached', async() => {
        await nft.setMaxGeneration(2);
        const maxGeneration = await nft.maxGeneration();
        const currentGeneration = await nft.currentGeneration();
        console.log("Current generation: ", currentGeneration);
        console.log("Max generation: ", maxGeneration);
        fastForward(24 * 60 * 60 + 1);
        await nft.connect(user2).mintToken(merkleInfo.whitelist[1].proof, {
          value: ethers.parseEther('1'),
        });
        await nft.connect(user2).mintToken(merkleInfo.whitelist[1].proof, {
          value: ethers.parseEther('1'),
        });
        console.log("Current gen after 2 mints: ", await nft.currentGeneration());
        await nft.connect(user2).mintToken(merkleInfo.whitelist[1].proof, {
          value: ethers.parseEther('1'),
        });
        console.log("Current gen after 3 mints: ", await nft.currentGeneration());
    });
```

## Tools Used
VS Code, Hardhat

## Recommended Mitigation Steps
Add this check after the first `require` statement in the `_incrementGeneration` function: 
`require (currentGeneration < maxGeneration, "Maximal number of generations reached");`
