# Vulnerability details

## Impact
In EntropyGenerator.sol::deriveTokenParameters the nukeFactor is calculating by dividing the entropy (6 digits) by 4000000 (7 digits). This will result in the nukeFactor always being 0
## Proof of Concept
A simple Foundry test showcasing how the NukeFactor will be 0 no matter what the entropy is

```solidity
// SPDX-License-Identifier: UNLICENSED
pragma solidity ^0.8.13;

import {Test, console} from "forge-std/Test.sol";

contract CounterTest is Test {
    uint256 divideBy = 4_000_000;
    uint256 example1 = 123_456;
    uint256 example2 = 999_999;
    uint256 example3 = 432_156;

    function test_divide() public view {
        uint256 result1 = divide(example1, divideBy);
        uint256 result2 = divide(example2, divideBy);
        uint256 result3 = divide(example3, divideBy);

        assertEq(result1, 0);
        assertEq(result2, 0);
        assertEq(result3, 0);
    }

    function divide(uint256 num1, uint256 num2) public pure returns (uint256) {
        return num1 / num2;
    }
}
```
