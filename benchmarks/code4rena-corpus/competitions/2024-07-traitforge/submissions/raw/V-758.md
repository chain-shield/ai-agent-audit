# Vulnerability details

## Summary

Every contract in the protocol inherits the `Pausable` contract except DAOFund.sol, but none of them implement the `pause` and `unpause` functions. This can lead to unexpected behavior if the protocol needs to be paused in the future.

## Vulnerability Details

`Airdrop.sol`, `NukeFund.sol`, `EntropyGenerator.sol`, `EntropyTrading.sol`, `TraitForgeNft.sol`, `EntityForging.sol` and `DevFund.sol` all inherit the `Pausable` from openzeppelin and `ERC20Pausable` in Trait.sol, but none of them implement the `pause` and `unpause` functions. As they are internal functions in the `Pausable` contract, they can be called by the contracts that inherit it. However if the `pause` and `unpause` functions are not implemented, the protocol cannot be paused or unpaused as the inherited `pause` and `unpause` functions are with internal scope.

## Impact

Unable to pause the protocol in case of emergency or any other reason.

## Tools used

Manual Review

## Recommended Mitigation Steps

Implement the `pause` and `unpause` functions with `external` view scope in the contracts that inherit the `Pausable` contract to allow the protocol to be paused and unpaused.

Example:
```solidity

contract Airdrop is Pausable {
    ...
    function pause() external onlyOwner {
        _pause();
    }

    function unpause() external onlyOwner {
        _unpause();
    }
    ...
}
```
