# Vulnerability details

## Impact
The EntropyGenerator contract's initializeAlphaIndices function is restricted by the onlyOwner modifier, which means only the contract owner can call this function. When the TraitForgeNFT contract attempts to call initializeAlphaIndices via _mintInternal, it fails with the error 'Ownable: caller is not the owner'. This issue prevents the mintToken function from completing successfully when the maximum number of tokens per generation has been reached.

Since the TraitForgeNFT contract is not set as the owner of the EntropyGenerator contract, it cannot trigger the initializeAlphaIndices function, causing a critical failure in the minting process. This affects the functionality of the NFT contract and may lead to an inability to mint tokens as expected.

    describe('test', () => {

## Recommended Mitigation Steps
Consider updating the EntropyGenerator contract’s ownership to include the TraitForgeNFT contract.

    constructor(address _traitForgetNft) {
      allowedCaller = _traitForgetNft;
      initializeAlphaIndices();

      transferOwnership(_traitForgetNft);
    }
