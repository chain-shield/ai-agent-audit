# Vulnerability details

## Impact
The mintWithBudget function cannot be called after the first 10,000 NFTs have been minted. But this is not written anywhere in the documentation

## Proof of Concept
For the test, in the TraitForgeNft contract, I modified maxTokensPerGen to equal 10 for simplicity. 
I've also removed onlyOwner from the EntropyGenerator contract's initializeAlphaIndices function.

In the test file TraitForgeNft.test.ts, insert these lines:
