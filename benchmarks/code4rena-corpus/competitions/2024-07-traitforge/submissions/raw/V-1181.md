# Vulnerability details

## Impact
From the TraitForge's docs
> There is a certain entropy, “999999” which is referred to as “the Golden God”, since it has perfect parameters and will exceed all other entities if played correctly. The Golden God is scanned for and is kept out of the first 2 passes, but is deliberately set in the final pass (at some random point). 

The `999999` is supposed to be kept out of first 2 passes. But the validations in `writeEntropyBatch1` and `writeEntropyBatch2` are not sufficient to ensure that

```solidity
require(pseudoRandomValue != 999999, 'Invalid value, retry.');
```

The `999999` still can appear in a slot index that is greater than zero, and the validations still pass in this case. E.g: `pseudoRandomValue = 999999123456`.

## Tools Used
Manual Review.

## Recommended Mitigation Steps
Looping through every slot of `pseudoRandomValue` to ensure that the entropy is not equal to `999999`.
