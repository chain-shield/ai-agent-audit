# Vulnerability details

## Summary

Using safeTransferFrom guarantees that the receiver address is either a smart contract implementing IERC721Receiver.onERC721Received or an EOA.


## Impact

Loss of token if transferred to a smart contract that can't properly handle ERC721 tokens.

Especially when buying NFTs.


## Tool used
Manual Review

## Recommendation
Use `safeTransferFrom` instead of `transferFrom` to ensure that the token receiver can safely handle ERC721 tokens.

Token-Transfer
