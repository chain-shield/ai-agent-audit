# Vulnerability details

## Impact
- Even when `minimumDaysHeld` period has been passed from the time it got minted user would not be able `nuke` NFT .
- This happens due to 2 reasons:
  - Let's suppose `minimumDaysHeld` has been completed and after that the user 
    puts NFT for sale using `listNFTForSale()`.
  - Inside `listNFTForSale()` the NFT get's transferred from user address to 
    contract address and during 
    `nftContract.transferFrom(msg.sender, address(this), tokenId);`
    transferFrom() , `_beforeTokenTransfer()` gets triggered which updates 
    `lastTokenTransferredTimestamp[firstTokenId] = block.timestamp;` to current 
    timestamp.
  - Now after sometime user cancels listing of NFT through `cancelListing()`.
  - Now when user tries to `nuke()` NFT at that time error would be thrown due to 
    this check
    `uint256 tokenAgeInSeconds = block.timestamp -
      nftContract.getTokenLastTransferredTimestamp(tokenId);
    return tokenAgeInSeconds >= minimumDaysHeld;
    `
  - As `lastTokenTransferredTimestamp` gets updated during `beforeTransfer()` so it would be less than `minimumDaysHeld` period which leads to users not able to `nuke()` NFT.
