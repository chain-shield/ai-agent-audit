# Vulnerability details

## Impact
When a player places his token for sale he gives it to the contract, this is done for a secure transaction. But if the player changes his mind about selling his token, the contract will return the token to the owner and the player will have to wait 3 days again for his token to become eligible for nuking. 

## Proof of Concept
```solidity
function test_held() public afterWhitelist {
    vm.startPrank(player1);
    bytes32[] memory input;
    traitForgeNft.mintToken{ value: 5000000000000000 }(input);
    vm.warp(block.timestamp + 4 days);
    assertTrue(nukeFund.canTokenBeNuked(1));
    traitForgeNft.approve(address(entityTrading), 1);
    entityTrading.listNFTForSale(1, 1 ether);
    entityTrading.cancelListing(1);
    assertFalse(nukeFund.canTokenBeNuked(1));
  }
  ```
