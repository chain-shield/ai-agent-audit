# Vulnerability details

## Impact
The `EntropyGenerator::initializeAlphaIndices` function is currently restricted to `onlyOwner`, but it needs to be called by `TraitForgeNft` contract when incrementing the generation. 
This mismatch in access control causes both the minting process and the forging process to revert when a generation needs to be incremented.
No nft will be minted after the first generation.


## Proof of Concept
A. Minting
1. User mint nft by calling `TraitForgeNft::mintToken` or `TraitForgeNft::mintWithBudget`
2. Both cases will trigger `TraitForgeNft::_mintInternal` function
3. The function will check if the max token per generation is reached
```
if (generationMintCounts[currentGeneration] >= maxTokensPerGen) {
      _incrementGeneration();
    }
```
4. If the max token per generation is reached, `_incrementGeneration` function calls `EntropyGenerator::initializeAlphaIndices` to initialize alpha indices: 
```
function _incrementGeneration() private {
    require(
      generationMintCounts[currentGeneration] >= maxTokensPerGen,
      'Generation limit not yet reached'
    );
    currentGeneration++;
    generationMintCounts[currentGeneration] = 0;
    priceIncrement = priceIncrement + priceIncrementByGen;
@>    entropyGenerator.initializeAlphaIndices();
    emit GenerationIncremented(currentGeneration);
  }
```
5. `EntropyGenerator::initializeAlphaIndices` has onlyOwner modifier, and since `TraitForgeNft` contract is not the owner, the function will revert
```
function initializeAlphaIndices() public 
    whenNotPaused 
@>  onlyOwner {
//...
```
6. The entire minting process will revert, making it impossible to mint in a new generation.

B. Forging
Same flow as the Minting process:
1. User call `TraitForgeNft::forge` to forge nft.
2. It triggers `_mintNewEntity`
3. It checks if max token per generation is reached
```
if (
      generationMintCounts[gen] >= maxTokensPerGen && gen == currentGeneration
    ) {
      _incrementGeneration();
    }
```
4. If all checks are valid, `_incrementGeneration` function call `EntropyGenerator::initializeAlphaIndices` to initialize alpha indices, but does not have access which will revert the whole process.

```
// SPDX-License-Identifier: MIT
pragma solidity ^0.8.20;

import { Test, console } from 'forge-std/Test.sol';
import { EntropyGenerator } from '../contracts/EntropyGenerator/EntropyGenerator.sol';
import { DevFund } from '../contracts/DevFund/DevFund.sol';
import { Airdrop } from '../contracts/Airdrop/Airdrop.sol';
import { TraitForgeNft } from '../contracts/TraitForgeNft/TraitForgeNft.sol';
import { Trait } from '../contracts/Trait/Trait.sol';
import { EntityForging } from '../contracts/EntityForging/EntityForging.sol';
import { EntityTrading } from '../contracts/EntityTrading/EntityTrading.sol';
import { NukeFund } from '../contracts/NukeFund/NukeFund.sol';

contract BaseTest is Test {
  address public owner = makeAddr('owner');

  EntropyGenerator public entropyGenerator;
  DevFund public devFund;
  Airdrop public airdrop;
  TraitForgeNft public traitForgeNft;
  EntityForging public entityForging;
  EntityTrading public entityTrading;
  NukeFund public nukeFund;
  address public user = address(0x2);
  bytes32[] public proof;

  function setUp() public {
    vm.startPrank(owner);
    devFund = new DevFund();

    traitForgeNft = new TraitForgeNft();
    entropyGenerator = new EntropyGenerator(address(traitForgeNft));
    entityForging = new EntityForging(address(traitForgeNft));
    entityTrading = new EntityTrading(address(traitForgeNft));
    address devAddress = makeAddr('devAddress');
    address daoAddress = makeAddr('daoAddress');
    nukeFund = new NukeFund(
      address(traitForgeNft),
      address(airdrop),
      payable(devAddress),
      payable(daoAddress)
    );
    vm.stopPrank();
    vm.startPrank(address(traitForgeNft));
    airdrop = new Airdrop();
    vm.stopPrank();
  }

function test_incrementNewGeneration() public {
    //set up
    vm.startPrank(traitForgeNft.owner());
    traitForgeNft.setEntityForgingContract(address(entityForging));
    traitForgeNft.setEntropyGenerator(address(entropyGenerator));
    traitForgeNft.setAirdropContract(address(airdrop));
    vm.stopPrank();
    // initialization
    entropyGenerator.writeEntropyBatch1();
    entropyGenerator.writeEntropyBatch2();
    entropyGenerator.writeEntropyBatch3();

    proof = new bytes32[](1);
    proof[0] = keccak256(abi.encodePacked(user));
    // skip whitelist
    vm.warp(3 days);
    vm.deal(user, 10000 ether);
    vm.startPrank(user);
    //user mint 10 000 token id, as mintWithBudget allow to mint until 10 000 tokens
    traitForgeNft.mintWithBudget{ value: 1500 ether }(proof);
    // after 10 000 token id reached in the first generation
    assertEq(traitForgeNft.generationMintCounts(1), 10000);
    //make sure second generation is empty
    assertEq(traitForgeNft.generationMintCounts(2), 0);
    // user should now mint in new generation
    traitForgeNft.mintToken{ value: 15 ether }(proof);
    vm.stopPrank();
}
```

To run the test : `forge test --mt test_incrementNewGeneration -vvvvv`
