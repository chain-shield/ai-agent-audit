# Vulnerability details

## Impact
`mintWithBudget` will be unavailable to use after `tokenId` has reached a certain number.

## Proof of Concept
Here is the code for `mintWithBudget`, which allows user to mint batch with an amount of budgets, and the excessive funds will be returned to user:

```solidity
  function mintWithBudget(
    bytes32[] calldata proof
  )
    public
    payable
    whenNotPaused
    nonReentrant
    onlyWhitelisted(proof, keccak256(abi.encodePacked(msg.sender)))
  {
    uint256 mintPrice = calculateMintPrice();
    uint256 amountMinted = 0;
    uint256 budgetLeft = msg.value;

    while (budgetLeft >= mintPrice && _tokenIds < maxTokensPerGen) {
      _mintInternal(msg.sender, mintPrice);
      amountMinted++;
      budgetLeft -= mintPrice;
      mintPrice = calculateMintPrice();
    }
    if (budgetLeft > 0) {
      (bool refundSuccess, ) = msg.sender.call{ value: budgetLeft }('');
      require(refundSuccess, 'Refund failed.');
    }
  }
```

In the loop logic, we see that only when this statement returns true, NFTs can be minted: `(budgetLeft >= mintPrice && _tokenIds < maxTokensPerGen)`, where `_tokenIds ` is a global variable, denotes the current token ID, and essentially the total tokens have been minted. `maxTokensPerGen` is also a global variable, which represents the max tokens can be minted per generation. For the sake of proving PoC, let's assume the max count is 10, and is currently at generation 2. This means there are more than 10 tokens minted, so, let's also suppose the current `_tokenId` is at 12.

Notice that, with out assumption above, will make the statement in while loop to evaluate as false, as 12 > 10. But in reality, this is faulty, because `_tokenId` represents the total token amount minted, not the tokens minted in the current generation. The correct variable to use is `generationMintCounts[currentGeneration]`. This faulty logic will make batch minting unavailable when `_tokenId` is greater than `maxTokensPerGen`.

## Tools Used
Manual review

## Recommended Mitigation Steps
Replace `_tokenId` with `generationMintCounts[currentGeneration]`
