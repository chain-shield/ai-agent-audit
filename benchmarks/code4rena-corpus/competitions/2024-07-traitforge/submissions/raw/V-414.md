# Vulnerability details

## Impact

Users can forge one extra time.

## Proof of Concept

The amount of forges of an NFT depends on its fifth digit of the number. If the entropy is 511798, then the NFT can be forged 9 times.

When checking for forging count, the `forgingCounts[tokenId]` should be less than or equal to the `forgePotential`.

```
    uint8 forgePotential = uint8((entropy / 10) % 10); // Extract the 5th digit from the entropy
    require(
      mergerForgePotential > 0 &&
>       forgingCounts[mergerTokenId] <= mergerForgePotential,
      'forgePotential insufficient'
    );
```

If the `forgePotential` is 1 (5th digit is 1), then the NFT only be able to be forged once.

Let's say NFT A has a `forgePotential` of 1, and it is already forged once. Now, `forgingCounts[tokenId]` is 1.

Since 1 <= 1, NFT A can be forged again, bypassing the threshold of 1.

## Tools Used

Manual Review

## Recommended Mitigation Steps

Change `<=` to `<` 

```
forgePotential > 0 && forgingCounts[tokenId] < forgePotential,
```
