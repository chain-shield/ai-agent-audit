# Vulnerability details

## Impact
**- DESCRIPTION -**

"Due to the incorrect comparison operator, the last token (per generation) will never be minted."

**- DETAILS -**

In the [TraitForgeNft::_mintNewEntity()](https://github.com/code-423n4/2024-07-traitforge/blob/279b2887e3d38bc219a05d332cbcb0655b2dc644/contracts/TraitForgeNft/TraitForgeNft.sol#L311-L343) function, the intention is to ensure that no more than `maxTokensPerGen` are minted, which is achieved. 

The problem is that the final tokenId can never be minted because the `require` statement uses the `less than` operator instead of `less than or equal to`.

```solidity
function _mintNewEntity(
    address newOwner,
    uint256 entropy,
    uint256 gen
  ) private returns (uint256) {
    require(
@>     generationMintCounts[gen] < maxTokensPerGen, // @audit-issue wrong comparison operator
      'Exceeds maxTokensPerGen'
    );

    _tokenIds++;
    uint256 newTokenId = _tokenIds;
    _mint(newOwner, newTokenId);

    tokenCreationTimestamps[newTokenId] = block.timestamp;
    tokenEntropy[newTokenId] = entropy;
    tokenGenerations[newTokenId] = gen;
    generationMintCounts[gen]++;
    initialOwners[newTokenId] = newOwner;

    if (
      generationMintCounts[gen] >= maxTokensPerGen && gen == currentGeneration
    ) {
      _incrementGeneration();
    }

    if (!airdropContract.airdropStarted()) {
      airdropContract.addUserAmount(newOwner, entropy);
    }

    emit NewEntityMinted(newOwner, newTokenId, gen, entropy);
    return newTokenId;
  }
```
**- IMPACT -**

A small amount of funds is lost for that last token (per generation).

## Recommended Mitigation Steps
Change the code from `<` to `<=`.
```diff
function _mintNewEntity(
    address newOwner,
    uint256 entropy,
    uint256 gen
  ) private returns (uint256) {
    require(
-      generationMintCounts[gen] < maxTokensPerGen,
+      generationMintCounts[gen] <= maxTokensPerGen,
      'Exceeds maxTokensPerGen'
    );
    ...
  }
```
