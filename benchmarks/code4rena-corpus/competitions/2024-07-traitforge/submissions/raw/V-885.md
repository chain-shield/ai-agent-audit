# Vulnerability details

## Bug description
When a user attempts to forge with a listed NFT, he has to pay a forging fee.

[EntityForging.sol#L125-L126](https://github.com/code-423n4/2024-07-traitforge/blob/279b2887e3d38bc219a05d332cbcb0655b2dc644/contracts/EntityForging/EntityForging.sol#L125-L126)
```solidity
uint256 forgingFee = _forgerListingInfo.fee;
require(msg.value >= forgingFee, 'Insufficient fee for forging');
```
If a user provided more ETH than the `forgingFee` that excess is not refunded and stays locked in the contract without a way to rescue it.

## Impact
Loss of funds for a user and locked ETH in the contract.

## Recommended Mitigation
Refund excess ETH sent during the call to `forgeWithListed()`.
