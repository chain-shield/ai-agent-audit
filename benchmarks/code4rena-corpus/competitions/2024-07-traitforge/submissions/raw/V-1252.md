# Vulnerability details

## Impact
The current implementation of the `forgeWithListed` function allows a forger to exceed their forging potential by not properly incrementing and checking the forging count before forging

## Proof of Concept
The issue arises from the order in which the `forgingCounts[forgerTokenId]` is incremented and checked. In the `listForForging` function, the forging potential is checked and if valid, the token is listed for forging. However, during the `forgeWithListed` function, the forging count is incremented before checking, which means it allows one additional forging operation beyond the limit.
```javascript
require(
  forgePotential > 0 && forgingCounts[tokenId] <= forgePotential,
  'Entity has reached its forging limit'
);

forgingCounts[forgerTokenId]++; // Incrementing before checking

``` 

Example:-
1->A forger token with a forge potential of 5 is used.
2->The token has already been used 5 times (forgingCounts[forgerTokenId] = 5).
3->he listForForging check will pass because the check happens before the count increment.
4->In forgeWithListed, the count is incremented, allowing one more forging, resulting in a total of 6 forges.

or
suppose forgePotentail = 5
forgerCount[tokenid] => 0, which passes the check in `listForForging`, forger count ++, called `forgeWithListed`
forgerCount[tokenid] => 1, which passes the check in `listForForging`, forger count ++, called `forgeWithListed`
forgerCount[tokenid] => 2, which passes the check in `listForForging`, forger count ++, called `forgeWithListed`
forgerCount[tokenid] => 3, which passes the check in `listForForging`, forger count ++, called `forgeWithListed`
forgerCount[tokenid] => 4, which passes the check in `listForForging`, forger count ++, called `forgeWithListed`
forgerCount[tokenid] => 5, which passes the check in `listForForging`, forger count ++,called `forgeWithListed`
forgerCount[tokenid] => 6, here check fails in `listForForging`,

total times forged => 6, potential = 5

## Recommended Mitigation Steps
the `forgeWithListed` function should increment and check the `forgingCounts[forgerTokenId]` similar to how it is done for the merger token.

``` diff 
  forgingCounts[forgerTokenId]++;
    require(
      forgerForgePotential > 0 &&
        forgingCounts[forgerTokenId] <= forgerForgePotential,
      'forgePotential insufficient for forger'
    );
```
