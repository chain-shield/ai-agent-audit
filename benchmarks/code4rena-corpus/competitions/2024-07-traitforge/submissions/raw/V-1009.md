# Vulnerability details

## Impact
All contracts that have the potential to be paused cannot be paused

## Proof of Concept
All contracts in the protocol that inherit the `pausable` contract from openzeppelin do not have any `pause` and `unpause` functions as a result these contracts cannot be paused and unpaused like they have to.

## Tools Used
Manual Review(Vs Code)

## Recommended Mitigation Steps
Include `pause` and `unpause` functions in all the contracts to only be callable by admin or any other privilieged role.

```solidity
// pauses the contract
function pause() public {
// Add access control
    _pause();
}

// unpauses the contract
function unpause() public {
add access control
    _unpause();
}
```
