# Vulnerability details

# Wrong access control of `initializeAlphaIndices()` blocks the mint from early stage
## Vulnerablity details
When `_incrementGeneration()` in contract `TraitForgeNft` is triggered, it will call `initializeAlphaIndices()` in contract `EntropyGenerator`. However, `initializeAlphaIndices()` is modified by `onlyOwner`, and the `owner` is the deployer instead of `TraitForgeNft`, so the call will revert.
```solidity
function _incrementGeneration() private {
    ...
    entropyGenerator.initializeAlphaIndices();
    ...
  }
```
```solidity
function initializeAlphaIndices() public whenNotPaused onlyOwner {
    ...
}
```

## Impact
The issue is when the generation increases, `_incrementGeneration()` must be triggered by the mint procedure (forge mechanism not considered). After the last Entity of Generation 1 minted, `mintToken()` and `mintWithBudget()` are blocked.
```solidity
function mintToken(
    bytes32[] calldata proof
)
    public
    payable
    whenNotPaused
    nonReentrant
    onlyWhitelisted(proof, keccak256(abi.encodePacked(msg.sender)))
{
    ...
    _mintInternal(msg.sender, mintPrice);
    ...
}

function mintWithBudget(
    bytes32[] calldata proof
)
    public
    payable
    whenNotPaused
    nonReentrant
    onlyWhitelisted(proof, keccak256(abi.encodePacked(msg.sender)))
{
    ...
    _mintInternal(msg.sender, mintPrice);
    ...
}

function _mintInternal(address to, uint256 mintPrice) internal {
    ...
    if (generationMintCounts[currentGeneration] >= maxTokensPerGen) {
      _incrementGeneration();
    }
    ...
  }
```
Anyone can DOS mint functions, stopping it early in Gen1 instead of Gen10. This undermines the liquidity of NFT and in NukeFund.

## Recommended Mitigation Steps
Modify `initializeAlphaIndices()` with `onlyAllowedCaller` instead of `onlyOwner`. Temporarily set the deployer as `allowedCaller` for constructor and then set back to contract `TraitForgeNft`.
```diff
    constructor(address _traitForgetNft) {
-       allowedCaller = _traitForgetNft;
+       allowedCaller = msg.sender;
        initializeAlphaIndices();
+       allowedCaller = _traitForgetNft;
    }
    ...
-   function initializeAlphaIndices() public whenNotPaused onlyOwner {
+   function initializeAlphaIndices() public whenNotPaused onlyAllowedCaller {
```
