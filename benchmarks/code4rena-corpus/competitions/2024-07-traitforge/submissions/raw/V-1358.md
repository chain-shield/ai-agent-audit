# Vulnerability details

## Impact
The entropy of a NFT can be 0, which will make the nft useless as the `nukeFactor` and `forgePotential` will be 0. This Nft will not be able `forge` or `nuke`. As 0 entropy is not the part of the protocol and it is an unexpected value.

@>  uint256 paddedEntropy = entropy * (10 ** (6 - numberOfDigits(entropy)));

later we are getting `entropy` based on the `slotValue` which is pseudoRandomValue and `numberIndex`.
Now let's assume we got `slotValue` as any 78 digit number but end with 6 consecutive 0's. Eg:- 123...000000 and `position` is 72. So `entropy` will be `slotValue % 1000000` which is the last 6 digit numbers, ie six 0's (000000). Now `paddedEntropy` will be `000000 * 1000000` which is 0.

## Recommended Mitigation Steps
when getting the `entropy` using `getEntropy()` function, check at the end if the `entropy` is zero or not, if it's zero then run the function again to get a non-zero entropy.
