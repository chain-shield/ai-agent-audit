# Vulnerability details

## Impact

The contract `EntropyGenerator` uses `onlyOwner` modifier on multiple occasions but the problem is that the OZ `Ownable` contract is not initialized correctly - in particular, the owner is not initialized and the ownership over the contract is not transferred to him.

## Proof of Concept

The contract should provide the owner to the constructor of the Ownable contract to be able to use the `onlyOwner` modifier:


https://github.com/OpenZeppelin/openzeppelin-contracts/blob/master/contracts/access/Ownable.sol#L38-43
```
constructor(address initialOwner) {
        if (initialOwner == address(0)) {
            revert OwnableInvalidOwner(address(0));
        }
        _transferOwnership(initialOwner);
    }

```

But currently the contract is not initialized at all:

https://github.com/code-423n4/2024-07-traitforge/blob/main/contracts/EntropyGenerator/EntropyGenerator.sol#L30-33
```
constructor(address _traitForgetNft) {
    allowedCaller = _traitForgetNft;
    initializeAlphaIndices();
  }
```

This does not allow to use the `onlyOwner` modifier as the usage of the OZ contract is not implemented correctly.

## Tools Used

Manual review.

## Recommended Mitigation Steps

Initialize `Ownable` contract properly.
