# Vulnerability details

## Impact
The `fetchListings()` function in the `EntityForging` contract may be vulnerable to a Denial of Service (`DoS`) attack due to its `unbounded loop`, which iterates over all `listings`. This can cause the function to run out of gas and fail, especially as the number of `listings` grows.

## Proof of Concept
The [`fetchListings()`](https://github.com/code-423n4/2024-07-traitforge/blob/279b2887e3d38bc219a05d332cbcb0655b2dc644/contracts/EntityForging/EntityForging.sol#L48-L53) function creates an array of all `listings` and iterates through each one to populate the array. This loop is unbounded, meaning it will continue to run as long as there are `listings`, potentially causing the function to consume all available gas.
```solidity
function fetchListings() external view returns (Listing[] memory _listings) {
    _listings = new Listing[](listingCount + 1);
    for (uint256 i = 1; i <= listingCount; ++i) {
        _listings[i] = listings[i];
    }
}
```
In the above code, the for loop iterates from `1` to `listingCount`, which can be very large, leading to high gas consumption and potential failure of the function.

## Recommended Mitigation Steps
Consider implementing `pagination` or limiting the number of `listings` returned in a single call.

Add parameters to the `fetchListings()` function to specify the `starting index` and the `number of listings` to fetch.
```diff
-   function fetchListings() external view returns (Listing[] memory _listings) {
+   function fetchListings(uint256 startIndex, uint256 count) external view returns (Listing[] memory _listings) {
+     require(startIndex > 0 && startIndex <= listingCount, "Invalid start index");
+       uint256 endIndex = startIndex + count - 1;
+       if (endIndex > listingCount) {
+           endIndex = listingCount;
+       }
+       uint256 resultCount = endIndex - startIndex + 1;
-       _listings = new Listing[](listingCount + 1);
+       _listings = new Listing[](resultCount);
-       for (uint256 i = 1; i <= listingCount; ++i) {
+       for (uint256 i = 0; i < resultCount; ++i) {
-           _listings[i] = listings[i];
+           _listings[i] = listings[startIndex + i];
+       }
+   }
```
