# Vulnerability details

## Vulnerability details:-
The entropy value returned by the `EntropyGenerator.sol::getEntropy` function will be zero in many cases.
The various combinations of `slotValue` and `position` variables will result in zero entropy values due to incorrect calculation implementation.

```

    uint256 slotIndex,
    uint256 numberIndex
  ) private view returns (uint256) {
    require(slotIndex <= maxSlotIndex, 'Slot index out of bounds.');

    if (
      slotIndex == slotIndexSelectionPoint &&
      numberIndex == numberIndexSelectionPoint
    ) {
      return 999999;
    }

    uint256 position = numberIndex * 6; // calculate the position for slicing the entropy value
    require(position <= 72, 'Position calculation error');

@>    uint256 slotValue = entropySlots[slotIndex]; // slice the required [art of the entropy value
@>    uint256 entropy = (slotValue / (10 ** (72 - position))) % 1000000; // adjust the entropy value based on the number of digits
@>    uint256 paddedEntropy = entropy * (10 ** (6 - numberOfDigits(entropy)));
```

Due to a large denominator in the calculation, the entropy value will frequently be reduced to zero.
```
uint256 entropy = (slotValue / (10 ** (72 - position))) % 1000000;
```
## Impact:-
The function will return a zero value multiple times throughout the contract's lifespan due to incorrect calculation implementation, causing the protocol to malfunction and resulting in significant financial losses for NFT token holders.

## Proof of Concept:-

Since the `slotValue` variable stores a random value retrieved from the `entropySlots` array, which is populated by the `EntropyGenerator.sol::writeEntropyBatch1` function, the number can have between 0 and 78 digits as determined by the same function.

Let's take an example to demonstrate the vulnerability in the calculation.

If the slotValue contains a 20-digit number and the numberIndex is 3, the following calculation will occur according to `EntropyGenerator.sol::getEntropy` function:

```

slotValue = 542368421579456328754 // 20 digit random number

entropy = (542368421579456328754/ (10 **(72-18))) % 1000000
entropy = (542368421579456328754/ 10 ** 54) % 1000000
// the number of digits in denominator is very large
entropy = 0 % 1000000
entropy = 0

paddedEntropy = entropy * (10 ** (6 - numberOfDigits(entropy)))
paddedEntropy  = 0 * (10 ** (6 - numberOfDigits(0)))
paddedEntropy=0
```
Hence, the function will return a zero value for paddedEntropy in many combinations.
