# Vulnerability details

## Impact
The EntityTrading contract contains a vulnerability that can lead to a denial of service condition in the buyNFT function. This vulnerability arises from the implementation of the transferToNukeFund function and its dependency on the nukeFundAddress being set.

Technical Details:

The nukeFundAddress is not initialized in the constructor.
The setNukeFundAddress function allows setting nukeFundAddress to any address, including address(0).
The transferToNukeFund function, called within buyNFT, requires nukeFundAddress to be non-zero

Impact: If nukeFundAddress is not set or is set to address(0), all NFT purchase transactions will revert.
This can lead to a complete denial of service for the core functionality of buying NFTs.

## Recommended Mitigation Steps

* Initialize nukeFundAddress in the constructor with a valid address.
* Add a check in setNukeFundAddress to prevent setting it to address(0):

```solidity
function setNukeFundAddress(address payable _nukeFundAddress) external onlyOwner {
    require(_nukeFundAddress != address(0), "Invalid NukeFund address");
    nukeFundAddress = _nukeFundAddress;
}
```
