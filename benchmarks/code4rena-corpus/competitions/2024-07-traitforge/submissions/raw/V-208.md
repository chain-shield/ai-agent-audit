# Vulnerability details

## Impact
The modulus operation used to generate `pseudoRandomValue` involves a modulus of 10^78, which is greater than the maximum value of a `uint256`. This miscalculation can result in incorrect entropy values being generated, potentially affecting the randomness and security aspects of the contract.

## Proof of Concept

    uint256 pseudoRandomValue = uint256(
      keccak256(abi.encodePacked(block.number, i))
    ) % uint256(10) ** 78;

The expression `10 ** 78` exceeds the range of `uint256`. In practice, the value of `10 ** 78` is approximated to 7.36633 * 10^76, which is incorrect.

## Tools Used
Manual code review

## Recommended Mitigation Steps
Instead of using a modulus operation to constrain the value, consider using the full range of the uint256 data type. This approach ensures that the entire value is utilized, avoiding issues related to overflow and incorrect calculations.

    uint256 pseudoRandomValue = uint256(
      keccak256(abi.encodePacked(block.number, i))
    );
