# Vulnerability details

## Description
There is a bug when `minting NFT` which allow to mint beyond the `maxGeneration` limit which is unexpected and seems to warrant `High` severity.

The root cause is due to the fact that `_incrementGeneration` is lacking check against `maxGeneration` which allow to mint to the moon.

## Impact
Player is able to mint beyond `maxGeneration` which break a major invariant into the game.

## Recommended Mitigation Steps
Apply the following patch to resolve this issue.


```diff
  function _incrementGeneration() private {
    require(
      generationMintCounts[currentGeneration] >= maxTokensPerGen,
      'Generation limit not yet reached'
    );
+   require(currentGeneration < maxGeneration, "can't be over max generation");
+
    currentGeneration++;
    generationMintCounts[currentGeneration] = 0; //@audit : how is this playing out with forging which can be done prior to a gen increment
    priceIncrement = priceIncrement + priceIncrementByGen;
    entropyGenerator.initializeAlphaIndices(); //@audit: entropyGenerator ownership must be transfered to this contract, but in test it is not.
    emit GenerationIncremented(currentGeneration);
  }
```
