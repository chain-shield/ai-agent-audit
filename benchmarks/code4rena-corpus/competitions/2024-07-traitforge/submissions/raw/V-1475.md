# Vulnerability details

## Impact
Considering the deployment of the real protocol will be deployed the same way as the testnet game was deployed (as said in the discord), if the project will succeed, and the minting pace will be very fast (for example, as we have seen in the NFT bull craze) some tokens will be with 0 entropy.

## Proof of Concept
in the test net deployment, and as seen in the tests, the contracts are being deployed with everything set and only `EntropyGenerator::writeEntropyBatch1` is being called.
which means, that at first, only the tokens related to the Batch1 will have entropy set.

TraitForgeNft functions (please go to the last page, and view the orders):
https://sepolia.etherscan.io/txs?a=0x9ee29226bc3a3c2da4f95b8722f55ac467eb1ded&p

after [setRootHash](https://sepolia.etherscan.io/tx/0x5fcc5dc0f758ddfd9bc42dbe7051a8e4cceced1f3a6d9c9cd0acc92cb402b1b9) function is being called, together with: [writeEntropyBatch1](https://sepolia.etherscan.io/tx/0xee80e2f94b377507fc38072b80f5e5f123c0085c8209b69cb4175228f4f5a4f5)

people can start and mint.
there was a 12 seconds delay between writeEntropyBatch1 function and [writeEntropyBatch2](https://sepolia.etherscan.io/tx/0x753183939fbeecc013065d010aa6e8384dec2b8c2ba3aeb56ce8794ac3178bea) function calls.

which means, that if at this delay period, a massive amount of mints would have been occur, tokens that their entropy is being defined by the batch2 or batch3 functions, will be with entropy = 0.

        eg = new EntropyGenerator(address(nft));
        ef = new EntityForging(address(nft));

        address test = makeAddr("test");

        nft.setEntityForgingContract(address(ef));
        nft.setEntropyGenerator(address(eg));
        nft.setAirdropContract(address(airdrop));
        nft.setNukeFundContract(payable(address(nf)));
        eg.setAllowedCaller(address(nft));
        df = new DevFund();
    }

    //@audit - medium:
    function testWithoutEntropy() public {
        eg.writeEntropyBatch1();

        // eg.writeEntropyBatch2(); // these were in 12seconds delay.
        // eg.writeEntropyBatch3();

        console.log("token Entropy", entropy);

        eg.writeEntropyBatch2();
        eg.writeEntropyBatch3();

        nft.mintWithBudget{value: 775 ether}(a);

        entropy = nft.getTokenEntropy(4000);
        console.log("token Entropy after batch written should still be 0: ", entropy);

        //this token entropy is fine, as it got minted *AFTER* writeEntropyBatch functions got called.
        entropy = nft.getTokenEntropy(8000);
        console.log("token Entropy of this token should be regular as we called the function already:", entropy);
    }
}
