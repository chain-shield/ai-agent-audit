# Vulnerability details

## Impact
The contract is intended to use the Pausable functionality to allow pausing and unpausing of certain operations. However, the required `pause` and `unpause` functions are not exposed, making it impossible to utilize this functionality.

The contract should include and expose the following functions:

pause(): This function should allow the contract owner or an authorized role to pause the contract, halting specified operations.
unpause(): This function should allow the contract owner or an authorized role to unpause the contract, resuming normal operations.



## Tools Used
Manual review

## Recommended Mitigation Steps
Add following functions in all contract:
```solidity
function pause() public onlyOwner {
        _pause();
    }

    function unpause() public onlyOwner {
        _unpause();
    }
```
