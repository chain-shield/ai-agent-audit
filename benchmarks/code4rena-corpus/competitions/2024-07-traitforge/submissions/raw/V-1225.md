# Vulnerability details

## Impact
In the TraitForgeNft contract, tokens can be minted using the mintToken() and mintWithBudget() functions, both of which call the _mintInternal() function. Within _mintInternal(), the following check is performed:
```js
if (generationMintCounts[currentGeneration] >= maxTokensPerGen) {
    _incrementGeneration();
}
```
When the generationMintCounts of the currentGeneration exceeds maxTokensPerGen, the _incrementGeneration() function is called. This function, in turn, calls entropyGenerator.initializeAlphaIndices():
```js
function initializeAlphaIndices() public whenNotPaused onlyOwner {
    uint256 hashValue = uint256(
        keccak256(abi.encodePacked(blockhash(block.number - 1), block.timestamp))
    );

    uint256 slotIndexSelection = (hashValue % 258) + 512;
    uint256 numberIndexSelection = hashValue % 13;

    slotIndexSelectionPoint = slotIndexSelection;
    numberIndexSelectionPoint = numberIndexSelection;
}
```
The initializeAlphaIndices() function is protected by the onlyOwner modifier, meaning that only the owner of the EntropyGenerator contract can call this function. Since the TraitForgeNft contract is added as an allowedCaller but not as the owner, the function cannot be called through TraitForgeNft. This restriction implies that after the first generation, initializeAlphaIndices() cannot be called, and further minting will be halted.


## Proof of Concept
1. Users mint tokens until the generationMintCounts for the current generation exceeds maxTokensPerGen.
2. The _incrementGeneration() function is triggered, which attempts to call entropyGenerator.initializeAlphaIndices().
3. Due to the onlyOwner restriction, the call to initializeAlphaIndices() fails.
4. Further minting operations are halted as the initializeAlphaIndices() function is not executed.

## Recommended Mitigation Steps
Modify the access control for the initializeAlphaIndices() function to allow the TraitForgeNft contract to call it, ensuring that generation increments do not halt minting.
```js
// Add this modifier to the EntropyGenerator contract
modifier onlyAllowedCaller() {
    require(msg.sender == owner() || msg.sender == allowedCaller, "Caller is not allowed");
    _;
}

// Update the initializeAlphaIndices() function
function initializeAlphaIndices() public whenNotPaused onlyAllowedCaller {
    uint256 hashValue = uint256(
        keccak256(abi.encodePacked(blockhash(block.number - 1), block.timestamp))
    );

    uint256 slotIndexSelection = (hashValue % 258) + 512;
    uint256 numberIndexSelection = hashValue % 13;

    slotIndexSelectionPoint = slotIndexSelection;
    numberIndexSelectionPoint = numberIndexSelection;
}
```
