# Vulnerability details

## Impact
Attackers can select and mint entities based on their traits(nukefactor, forgepotential, role etc). Attackers end up with all the best entities and normal users end up getting the lower valued entities as a result.

## Proof of Concept
Any user with access to the minting function can either simulate the transaction before hand and have the transaction revert if the traits are not wanted, or read the "EntropyGenerator.sol::uint256[770] private entropySlots" array and simulate all entities, then wait for opportune time to mint desired entity.
