# Vulnerability details

 Users Unable to Mint NFTs Using TraitForgeNFT::mintWithBudget Function due to a logical error

### Vulnerability Details:
Users will be unable to mint NFTs using the `TraitForgeNFT::mintWithBudget` function once the `_tokenId` reaches 10,000. This limitation will prevent users from minting multiple NFTs efficiently, leading to decreased user engagement and potential attrition from the protocol.

 ### Impact
`TraitForgeNFT::mintWithBudget` function is designed to allow users to mint NFTs within a specified budget. The function contains the following loop:
```javascript
while (budgetLeft >= mintPrice && _tokenIds < maxTokensPerGen) {
    _mintInternal(msg.sender, mintPrice);
    amountMinted++;
    budgetLeft -= mintPrice;
    mintPrice = calculateMintPrice();
}
```
This function includes a condition that checks if _tokenId is less than `maxTokensPerGen` (10,000). However, _tokenId is incremented globally across all generations, not just the current one. Once _tokenId reaches 10,000, the function wont be able to run the `_mintInternal` again preventing further minting through `mintWithBudget`.

### Proof of Concept
Deploy the TraitForgeNFT contract.
Mint NFTs until `_tokenId` reaches 10,000 using any minting function.
Attempt to mint additional NFTs using the `mintWithBudget` function.
Observe that the transaction reverts due to the `_tokenIds < maxTokensPerGen` check.

### Recommended Mitigation Steps
To ensure that users can continue to mint NFTs using the mintWithBudget function, remove the unnecessary check for _tokenIds < maxTokensPerGen. This will allow minting beyond the 10,000 token limit across generations.
- while (budgetLeft >= mintPrice && _tokenIds < maxTokensPerGen) {
+ while (budgetLeft >= mintPrice) {
    _mintInternal(msg.sender, mintPrice);
    amountMinted++;
    budgetLeft -= mintPrice;
    mintPrice = calculateMintPrice();
}
By implementing this change, the protocol will allow users to mint NFTs without being restricted by the global _tokenId limit, thereby maintaining user engagement and ensuring the protocol's functionality remains intact.
