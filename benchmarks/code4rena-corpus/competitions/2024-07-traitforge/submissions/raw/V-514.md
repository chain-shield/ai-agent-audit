# Vulnerability details

## Impact
Weak prng in initializeAlphaIndices, writeEntropyBatch(1,2,3). The function initializeAlphaIndices is designed to generate specific indices in the entropy contract in regard to the 999_999 entropy which is designed to be assigned to the best nft. WriteEntropyBatch as the function name says, writes entropy batches. Using block.number, blockhash(block.number - 1), block.timestamp is not suggested when trying to create random values as they could be manipulated.
Malicous miner may game the system.

Impact - high
Likelihood - low
Overall - medium
