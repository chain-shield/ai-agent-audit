# Vulnerability details

## Impact

>NOTE: This issue is currently masked by an access control bug reported separately and affecting `_incrementGeneration` that prevents minting beyond the first generation.

The price of the first token in a new generation is calculated using the price parameters that would apply to the next token in the previous generation if it hadn't reached its limit, resulting in the first token of the new generation being more expensive than both the last actual token of the previous generation and the second token of its own generation.

Assuming:
```solidity
uint256 public maxTokensPerGen = 1000;
uint256 public startPrice = 0.005 ether;
uint256 public priceIncrement = 0.0000245 ether;
uint256 public priceIncrementByGen = 0.000005 ether;
```

The first token of Gen 1 will be minted for 0.005 ether, the last for 0.24997550 ether.
The first token of Gen 2 will be minted for 0.250 ether (4900% more!), the second for 0.0050295 ether.

This is incorrect because
- the tokens price in a generation grow linearly as new tokens are minted (price increment 0.0000245 ether)
- the first token of each generation all have the same price (starting price 0.005 ether)
- between generation only the price increment grow linearly (gen increment of price increment 0.000005 ether)
## Proof of Concept

In [`mintToken`](https://github.com/code-423n4/2024-07-traitforge/blob/279b2887e3d38bc219a05d332cbcb0655b2dc644/contracts/TraitForgeNft/TraitForgeNft.sol#L181C12-L181C20) the price is calculated before the [`_mintInternal`](https://github.com/code-423n4/2024-07-traitforge/blob/279b2887e3d38bc219a05d332cbcb0655b2dc644/contracts/TraitForgeNft/TraitForgeNft.sol#L193C5-L193C18)  function. The [`_mintInternal`](https://github.com/code-423n4/2024-07-traitforge/blob/279b2887e3d38bc219a05d332cbcb0655b2dc644/contracts/TraitForgeNft/TraitForgeNft.sol#L280) checks whether the end of the current generation has been reached, and if so it [steps to the next generation](https://github.com/code-423n4/2024-07-traitforge/blob/279b2887e3d38bc219a05d332cbcb0655b2dc644/contracts/TraitForgeNft/TraitForgeNft.sol#L281-L283) and resets the [generation's mint counter](https://github.com/code-423n4/2024-07-traitforge/blob/279b2887e3d38bc219a05d332cbcb0655b2dc644/contracts/TraitForgeNft/TraitForgeNft.sol#L351) which is used when calculating the minted token's price. But at this point the token price was already calculated and is the price that would apply to the next token in the previous generation if it hadn't reached its limit.

```typescript
  describe('testsForAudit', () => {
    it('Incorrect Token Pricing Across Generations', async () => {
      fastForward(24 * 60 * 60 + 1);
      const proof: BytesLike[] | Typed = [];
      const sut = nft.connect(owner);
      // *NOTE*: change TraitForgeNft.maxTokensPerGen to something smaller, i.e. 10
      let maxTokensPerGen = await sut.maxTokensPerGen();

      for (let index = 1; index < maxTokensPerGen; index++) {        
        await sut.mintToken(proof, { value: ethers.parseEther('1') });
      }
      
      let balanceBefore = await ethers.provider.getBalance(owner.address);
      await sut.mintToken(proof, { value: ethers.parseEther('1') });
      let lastTokenGen1Price = balanceBefore - await ethers.provider.getBalance(owner.address);

      
      balanceBefore = await ethers.provider.getBalance(owner.address);
      await sut.mintToken(proof, { value: ethers.parseEther('1') });
      let firstTokenGen2Price = balanceBefore - await ethers.provider.getBalance(owner.address);

      balanceBefore = await ethers.provider.getBalance(owner.address);
      await sut.mintToken(proof, { value: ethers.parseEther('1') });
      let secondTokenGen2Price = balanceBefore - await ethers.provider.getBalance(owner.address);

      expect(firstTokenGen2Price).to.be.gt(lastTokenGen1Price); // PASS! should fail and should have the same price of the first token of Gen 1
      expect(firstTokenGen2Price).to.be.gt(secondTokenGen2Price); // PASS! should fail and be cheaper than second token of Gen 2
    });
  });
```
