# Vulnerability details

## Impact
The codebase uses `taxCut` variable as a percentage. But the implementation used is incorrect and only works well in some cases. variable `taxCut` can be updated by calling `setTaxCut`.  If the percentage needs to be set as 11%, then value of taxCut needs to be 9.09 which is not possible in solidity due to lack of decimal support. 

## Tools Used
Manual review

## Recommended Mitigation Steps
the percentage can be calculated as following:
```solidity
uint value = (x * taxCut) / 100;
```


## Assessed type

Decimal
