# Vulnerability details

## Impact

The function `mintWithBudget` does not increase the generation when the previous one is completed, which results in the user pointlessly wasting gas on calculations and transferring ETH back and forth, new tokens will not be minted.

## Proof of Concept

### NOTES: for this PoC to work we need to fix another vulnerability, to allow `mintWithBudget` work as intended.
For fix replace condition in `mintWithBudget` :

from:
```solidity
while (budgetLeft >= mintPrice && _tokenIds < maxTokensPerGen)
```
to:
```solidity
while (budgetLeft >= mintPrice && generationMintCounts[currentGeneration] < maxTokensPerGen) 
```


- For debugging purposes, you may want to make `TraitForgeNft._tokenIds` visible internally or even publicly.
- `testMedium_genNotUpdated` is PoC, the rest is setup
-  Increase gas limit in configs or `--gas-limit` in cmd.
