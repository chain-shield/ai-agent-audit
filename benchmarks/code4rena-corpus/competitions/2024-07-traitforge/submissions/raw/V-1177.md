# Vulnerability details

The listForForging function in EntityForging.sol allows users to list their tokens for forging. 

However, these listings can become stale or outdated if not actively managed.

Without a mechanism to clean up or validate these listings periodically, the contract can accumulate outdated data, leading to inefficiencies and a cluttered marketplace.

## Impact
If the listings become outdated, users will have to manually cancel them by calling cancelListingForForging function.

## Tools Used
Manual Review

## Recommended Mitigation Steps
Add an expiration time to each listing. Listings should automatically expire after a certain period.
