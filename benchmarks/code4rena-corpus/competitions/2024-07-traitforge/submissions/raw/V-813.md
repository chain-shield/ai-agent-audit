# Vulnerability details

## Impact

In `EntropyGenerator` smart contract, there is a `nukeFactor` value that determines how much of nuke fund a user can claim after some delay. The problem is that it's not calculated the same way as it's done in the docs and it creates inconsistency as it deviates from the spec.

## Proof of Concept

Take a look at `deriveTokenParameters()` functionality:

https://github.com/code-423n4/2024-07-traitforge/blob/main/contracts/EntropyGenerator/EntropyGenerator.sol#L152
```
  nukeFactor = entropy / 4000000;
```

From the docs:

```
Entropy /40 = initalNukeFactor
```

So it creates a deviation from the spec and will calculate an incorrect value.

## Tools Used

Manual review.

## Recommended Mitigation Steps

Change the formula of `nukeFactor` in `deriveTokenParameters` function.
