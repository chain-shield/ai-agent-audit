# Vulnerability details

## Vulnerability Details

Minting is not the only way an entity can be created. When two entities from a generation fuse together to create a stronger entity, they create an entity in the next generation. The total number of entities that can be minted per Generation is 10000 whether as a result of forging or minting. Also the current generation doesnt have to end before forging can take place which means that new entities for the next generation can be minted from the current generation. 

Assume that at generation 1, two entities decide to forge to create the first entity in generation 2, it is expected and required for proper accounting that the first ID in generation 2 is given to the entity that resulted from the forging and the next entity to be minted for that generation when the generation has finally been reached will have an ID of 2 but as seen in [`TraitForgeNft::_incrementGeneration()`](https://github.com/code-423n4/2024-07-traitforge/blob/279b2887e3d38bc219a05d332cbcb0655b2dc644/contracts/TraitForgeNft/TraitForgeNft.sol#L345-L356C1), the ID is completely reset and the next mint is given the ID of 1. This allows well over 10000 entities per generation to be minted from Generation 2 to Generation 10.

## Impact

Depending on the number of forging that took place, this vulnerability allows more than 10000 entities to be minted. Since 1/3 of the total minted entities in gen 1 will be forgers, with an assumed forge potential of 1 each, total minted in generation 2 could rise to 13,400 ((1/3 * 10000) + 10000)

Also, the invariant below is broken:

```
    entity total supply == 10 Generations * 10000
```

## Proof of Concept

Assume 50 forging event took place in generation 1. Instead of continuing from 51, the count is reset to start from 0 and will result in 10050 entities being minted instead of 10000.

```solidity
  function _incrementGeneration() private {
    require(
      generationMintCounts[currentGeneration] >= maxTokensPerGen,
      'Generation limit not yet reached'
    );
    currentGeneration++;
    generationMintCounts[currentGeneration] = 0;
    priceIncrement = priceIncrement + priceIncrementByGen;
    entropyGenerator.initializeAlphaIndices();
    emit GenerationIncremented(currentGeneration);
  }
```
