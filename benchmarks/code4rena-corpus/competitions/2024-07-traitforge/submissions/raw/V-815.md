**Description:- `EntityTrading::setNukeFundAddress`** set the `nukeFundAddress` but this function doesn't check it's parameter value against zero if admin is set zero the main two function functionality will broke. when someone want to buy nft and call `EntityTrading::buyNft` function after loading the list, checks and calculation at the middle of the **`EntityTrading::buyNft` **function the **`EntityTrading::transferToNukeFund` **function get called to transfer the fund. Inside the **`EntityTrading::transferToNukeFund` **the parameter is check against zero address and revert if it is zero.

this will lead that always when `BuyNft` function get call it will revert after loading list from memory, multiple check and calculation which will lead to Denial Of Services and prevent user from buying NFT and user will pay lots of gas for just reverting.

## Impact
`EntityTrading::setNukeFundAddress`  will lead to DOS and lot of gas consuming. 

## Recommended Mitigation Steps

Check the parameter value in  `EntityTrading::setNukeFundAddress` function when it call. and revert prevent from setting address zero

```solidity
function setNukeFundAddress(
    address payable _nukeFundAddress
  ) external onlyOwner {
 ++ require(_nukeFundAddress != address(0), 'NukeFund address not set'); 
    nukeFundAddress = _nukeFundAddress;
  }
```
