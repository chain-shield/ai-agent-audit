# Vulnerability details

In EntityTrading.sol cancelListing function has the `whenNotPaused` modifier, which prevents seller of getting back his NFT when protocol is paused.

## Impact
This is a common issue where a withdraw function has `whenNotPaused` modifier.
Its not recommended and its considered a bad practice, due to security implications when owner is compromised, as users won't be able to withdraw.

Examples of this issue, are: [Code4rena Example](https://github.com/code-423n4/2023-12-ethereumcreditguild-findings/issues/1249#issuecomment-1898741180) and M-03 from [pashov](https://github.com/pashov/audits/blob/master/solo/pdf/FlorenceFinance-security-review.pdf)
