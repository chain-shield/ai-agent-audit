# Vulnerability details

## Description
There is a bug in `EntityForging::forgeWithListed` when the player is forging. If he send excess funds, this excess will get stuck in the contract forever which seems to warrant `High` severity as fund loss. Since the price to forge is constantly changing (fee set by the forgers), this scenario has definatelly a Medium/High Likelihood and High Impact. 

The root cause is due to the fact that `forgeWithListed` is simply not reimbursing the excess, so it remains in the contract. The owner doesn't have either a way to extract it for this type of error, so it will be `stuck there forever`.

## Impact
Player incur a `fund loss` if he forge with `excess funds` (sending msg.value > forge fee).

## PoC

We can see that the Merger will be `loosing 2 ETH`, the Forger get his proper share (90% of 1 ETH), and the contract 1 ETH which is the excess.

      const forgerTokenId = FORGER_TOKEN_ID;
      const mergerTokenId = MERGER_TOKEN_ID;
      const EXCESS_FUNDS = ethers.parseEther('1.0'); // 1 ETH

      // 1) List a forger (fee 1 ETH)
      await entityForging.connect(owner).listForForging(forgerTokenId, FORGING_FEE);

      // 2) Forge it and check balances. We are sending 1 ETH of excess (1 ETH for fee, 1 ETH in excess)
      const efInitialBalance = await ethers.provider.getBalance(entityForging.getAddress());
      const mergerInitialBalance = await ethers.provider.getBalance(user1.address);
      const forgerInitialBalance = await ethers.provider.getBalance(owner.address);
      await entityForging.connect(user1).forgeWithListed(forgerTokenId, mergerTokenId, {value: FORGING_FEE + EXCESS_FUNDS,});
      const efFinalBalance = await ethers.provider.getBalance(entityForging.getAddress());
      const forgerFinalBalance = await ethers.provider.getBalance(owner.address);
      const mergerFinalBalance = await ethers.provider.getBalance(user1.address);
      expect(forgerFinalBalance - forgerInitialBalance).to.be.eq((FORGING_FEE * 9n) / 10n);

      console.log("Balance diff Merger:               ", mergerFinalBalance - mergerInitialBalance);
      console.log("Balance diff Forger:               ", forgerFinalBalance - forgerInitialBalance);
      console.log("Balance diff EntityForginContract: ", efFinalBalance - efInitialBalance);
    });
