# Vulnerability details

## Impact
The value of `currentGeneration` storage variable can be more than `maxGeneration`.



## Proof of Concept


## Tools Used
Manual review

## Recommended Mitigation Steps
Replace `_incrementGeneration` function with below code
```
function _incrementGeneration() private {
    require(
      generationMintCounts[currentGeneration] >= maxTokensPerGen,
      'Generation limit not yet reached'
    );
    require(currentGeneration < maxGeneration, 'Maximum generation limit reached');
    currentGeneration++;
    generationMintCounts[currentGeneration] = 0;
    priceIncrement = priceIncrement + priceIncrementByGen;
    entropyGenerator.initializeAlphaIndices();
    emit GenerationIncremented(currentGeneration);
}
```
