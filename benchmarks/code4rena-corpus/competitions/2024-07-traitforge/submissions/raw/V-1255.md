# Vulnerability details

## Impact
**- DESCRIPTION -**

In `calculateAge()`, there is a possibility of returning zero, which could result in the token being burned without any claim amount in exchange. This scenario represents a loss of value for the user.

**- DETAILS -**

The `performanceFactor` has a chance of being zero if modulo 10 is applied to the entropy value, as modulo 10 yields values from 0 to 9.

- [`NukeFund::calculateAge()`](https://github.com/code-423n4/2024-07-traitforge/blob/279b2887e3d38bc219a05d332cbcb0655b2dc644/contracts/NukeFund/NukeFund.sol#L118-L133)

If the `calculateAge()` is zero, then the `finalNukeFactor` will also be zero.

- [`calculateNukeFactor()`](https://github.com/code-423n4/2024-07-traitforge/blob/279b2887e3d38bc219a05d332cbcb0655b2dc644/contracts/NukeFund/NukeFund.sol#L136-L151)
