# Vulnerability details

## Vulnerability Details

According to the documentation, aging factor is related with the entropy values of the entities. The best entity's entropy is 999999, it's performance factor is 9 which is fastest and it has biggest initial nuke factor. According to the documentation, if an entity reach 50% nuke factor level it's fully mature. 

https://docs.google.com/document/d/1pihtkKyyxobFWdaNU4YfAy56Q7WIMbFJjSHUAfRm6BA/edit

And the best entity should be mature in 30 days based on the documentation but the current implementation doesn't fit with this statement with current parameters.

## Impact
Much slower aging for every entity

## Proof of Concept
In order to prove this claim. I will show the calculations in reverse order using 999999 entity. According to the documents 999999 should be mature in 30 days.

Note: calculation codes are mentioned in affected code part

Calculation:

Initial parameters: 
MAX_DENOMINATOR = 100000
performanceFactor = 9 ( in 999999 entity )
ageMultiplier = 1
initialNukeFactor = 25000 ( 999999 / 40 )
defaultNukeFactorIncrease = 250

In order to reach 50% level final nuke factor should be 25000 + initialNukeFactor ( 25000 )

25000 * MAX_DENOMINATOR = 2500000000
2500000000 / defaultNukeFactorIncrease = 10000000 ( It's adjusted age right now)
10000000 * 365 = 3650000000
3650000000 / MAX_DENOMINATOR = 36500
skip ageMultiplier because it's 1
36500 / performanceFactor = 4055 days

Which means 999999 entity should wait 4055 days in order to be fully mature.
