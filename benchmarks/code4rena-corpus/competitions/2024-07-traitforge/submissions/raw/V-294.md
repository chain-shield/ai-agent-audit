# Vulnerability details

## Impact
Forging NFTs can cause the god NFT to be skipped in a generation.

## Proof of Concept
Both [_mintInternal](https://github.com/code-423n4/2024-07-traitforge/blob/main/contracts/TraitForgeNft/TraitForgeNft.sol#L280) and [_mintNewEntity](https://github.com/code-423n4/2024-07-traitforge/blob/main/contracts/TraitForgeNft/TraitForgeNft.sol#L311) mint new NFTs and increase the count for the current generation (`generationMintCounts`). After 10,000 NFTs are minted, we move 1 generation up.

The difference between the two is that [_mintInternal](https://github.com/code-423n4/2024-07-traitforge/blob/main/contracts/TraitForgeNft/TraitForgeNft.sol#L280) calls [getNextEntropy](https://github.com/code-423n4/2024-07-traitforge/blob/main/contracts/EntropyGenerator/EntropyGenerator.sol#L101-L120) to generate the entropy for its NFT.

```solidity
    uint256 entropyValue = entropyGenerator.getNextEntropy();

    tokenCreationTimestamps[newItemId] = block.timestamp;
    tokenEntropy[newItemId] = entropyValue;
```

[getNextEntropy](https://github.com/code-423n4/2024-07-traitforge/blob/main/contracts/EntropyGenerator/EntropyGenerator.sol#L101-L120) can return 10,000 entropy values, with one guaranteed to be 999_999 (a god NFT). This occurs when `slotIndex` and `numberIndex` match predefined values.

```solidity
    if (slotIndex == slotIndexSelectionPoint && numberIndex == numberIndexSelectionPoint) {
        return 999999;
    }
```

In short, both [_mintInternal](https://github.com/code-423n4/2024-07-traitforge/blob/main/contracts/TraitForgeNft/TraitForgeNft.sol#L280) and [_mintNewEntity](https://github.com/code-423n4/2024-07-traitforge/blob/main/contracts/TraitForgeNft/TraitForgeNft.sol#L311) increase `generationMintCounts`. When `generationMintCounts` reaches 10,000, the generation increments, potentially causing the god NFT to be skipped if it lands between `x` and 10,000:

```markdown
x = 10,000 - forgedNFTs
```

Example:
1. Gen 2 god NFT is set to be at entropy 9500 (`slotIndex = 730` `numberIndex = 10`)
2. During normal minting, users forge another 1000 Gen 2 NFTs (from gen 1)
3. The last NFT from Gen 2 is minted with an ID of 10,000, but entropy slots are still at 9000 (`slotIndex = 692` and `numberIndex = 4`)
4. The first NFT of Gen 3 is minted, resetting `slotIndexSelectionPoint` and `numberIndexSelectionPoint` to new values

In this example, due to users forging NFTs, gen 2 skipped its god NFT.

## Tools Used
Manual review

## Recommended Mitigation Steps
Reconsider how god NFTs are distributed.
