# Vulnerability details

## Impact
The `mintWithBudget()` function is designed for users to buy NFTs in batch. However, if `_tokenIds` reaches or exceeds `maxTokensPerGen`, this function becomes useless.

## Proof of Concept
The `mintWithBudget()` function incorrectly uses the `_tokenIds` variable to enforce the minting limit.

This leads to an issue where, if `_tokenIds >= maxTokensPerGen`, the function becomes ineffective, and users cannot mint additional NFTs in a batch. The `amountMinted` variable tracks the number of NFTs minted in the current batch, is not used to limit the number of NFTs minted per batch. Instead, the `_tokenIds` is used mistakenly in the condition `_tokenIds < maxTokensPerGen`:
