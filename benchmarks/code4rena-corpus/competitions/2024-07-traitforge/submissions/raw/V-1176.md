# Vulnerability details

## Impact

The `TraitForgeNft.mintWithBudget` function allows a user to `batch mint` the `TraitForgeNft` tokens by passing in the adequate amount of funds (`msg.value`). The batch minting happens inside the `while loop` as shown below:

```solidity
    while (budgetLeft >= mintPrice && _tokenIds < maxTokensPerGen) { //@audit-issue - `generationMintCounts[currentGeneration]` should be checked against the maxTokensPerGen
      _mintInternal(msg.sender, mintPrice); //@audit-info - _tokenIds gets increemnted here
      amountMinted++; //@audit-issue - The `amountMinted` variable is local and not used anywhere
      budgetLeft -= mintPrice; //@audit-info - update the budgetLeft amount
      mintPrice = calculateMintPrice(); //@audit - mintPrice is increasing and the budgetLeft is decreasing
    }
```

The `while loop` will continue to `mint the NFTs` as long as the `budgetLeft >= mintPrice && _tokenIds < maxTokensPerGen` condition is `true`. The `_tokenIds < maxTokensPerGen` condition checks whether the `_tokenId` is less than the `maxTokensPerGen` which is `10000`. 

But the `_tokenIds < maxTokensPerGen` is wrong. Since the `_tokenIds` state variable is a univeral variable which is used as the token id for every nft minted for any generation. Hence the `tokenId < maxTokensPerGen` check will allow only the `first generation` tokens to be minted via the `TraitForgeNft.mintWithBudget` function. This is because after the first generation is minted the `_tokenId` will start from 10001 and this is (10001 > 10000). As a result the subsequent calls to the `TraitForgeNft.mintWithBudget` function will only refunds the `msg.value` to the `msg.sender` and will not mint any tokens to the `msg.sender`. This is not the expected behavior of the `TraitForgeNft.mintWithBudget` function and this is broken functionality of a critical function of the TraitForge protocol.

## Recommended Mitigation Steps

Hence it is recommended to update the `condition` in the `while loop` to allow the `TraitForgeNft.mintWithBudget` function to mint tokens till the `_tokenId` reaches `100000` tokens (This is because there are 10 generations and each generation has 10000 tokens in it). This will allow the `TraitForgeNft.mintWithBudget` function to `batch mint` the `TraitForgeNft` tokens belonging to any generation. It is recommended to modify the `while loop` condition as shown below:

```solidity
    while (budgetLeft >= mintPrice && _tokenIds < maxTokensPerGen*10) {
```
