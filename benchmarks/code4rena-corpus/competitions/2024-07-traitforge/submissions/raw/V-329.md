# Vulnerability details

## Description 

The `EntropyGenerator` contract is designed to generate and manage pseudo-random values for use in other contracts. One of its functions, `getNextEntropy()`, retrieves the next entropy value for the allowed caller. The function includes a check to ensure that the `currentSlotIndex` is within the valid range. However, the condition `currentSlotIndex <= maxSlotIndex` allows `currentSlotIndex` to be equal to `maxSlotIndex`, which can lead to out-of-bounds access when retrieving entropy values.

The issue arises because the condition `currentSlotIndex <= maxSlotIndex` allows `currentSlotIndex` to be equal to `maxSlotIndex`. This can cause out-of-bounds access when trying to retrieve entropy values from `entropySlots[maxSlotIndex]`, which is beyond the valid range of indices (0 to `maxSlotIndex - 1`).

## Impact
This bug can lead to out-of-bounds access in the `entropySlots` array, potentially causing unintended behavior or overwriting important data. This could compromise the integrity of the entropy values and affect the functionality of other contracts relying on these values.

## Proof of Concept
1. Assume `maxSlotIndex` is 770.
2. If `currentSlotIndex` is 770, the condition `currentSlotIndex <= maxSlotIndex` will pass.
3. The function will attempt to retrieve entropy values from `entropySlots[770]`, which is beyond the valid range of indices (0 to 769).
4. This results in out-of-bounds access in the `entropySlots` array.

## Recommended Mitigation Steps
Update the condition to `currentSlotIndex < maxSlotIndex` to ensure `currentSlotIndex` is always within the valid range. The corrected code is as follows:

```diff
function getNextEntropy() public onlyAllowedCaller returns (uint256) {
- require(currentSlotIndex <= maxSlotIndex, 'Max slot index reached.');
+ require(currentSlotIndex < maxSlotIndex, 'Max slot index reached.'); // updated condition
  uint256 entropy = getEntropy(currentSlotIndex, currentNumberIndex);

  if (currentNumberIndex >= maxNumberIndex - 1) {
    currentNumberIndex = 0;
    if (currentSlotIndex >= maxSlotIndex - 1) {
      currentSlotIndex = 0;
    } else {
      currentSlotIndex++;
    }
  } else {
    currentNumberIndex++;
  }

  emit EntropyRetrieved(entropy);
  return entropy;
}
```
