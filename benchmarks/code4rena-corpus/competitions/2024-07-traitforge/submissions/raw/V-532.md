# Vulnerability details

## Summary

The`EntropyGenerator::writeEntropyBatch1`,`EntropyGenerator::writeEntropyBatch2`,`EntropyGenerator::writeEntropyBatch3` functions does not verify if the generated pseudo-random values are unique before storing them in the entropySlots array. This oversight can lead to duplicate values.

## Vulnerability Details
Function Affected: writeEntropyBatch1
Issue: The function generates pseudo-random values without checking for uniqueness.

Code Snippet:
```solidity

function writeEntropyBatch1() public {
  require(lastInitializedIndex < batchSize1, 'Batch 1 already initialized.');

  uint256 endIndex = lastInitializedIndex + batchSize1;
  unchecked {
    for (uint256 i = lastInitializedIndex; i < endIndex; i++) {
      uint256 pseudoRandomValue = uint256(keccak256(abi.encodePacked(block.number, i))) % uint256(10) ** 78;
      require(pseudoRandomValue != 999999, 'Invalid value, retry.');
      entropySlots[i] = pseudoRandomValue;
    }
  }
  lastInitializedIndex = endIndex;
}
```
Explanation: The function generates a pseudo-random value for each index in the entropySlots array but does not ensure that these values are unique. As a result, it is possible for the same value to be stored in multiple slots, which reduces the overall randomness and predictability of the entropy.

## Impact
If pseudo-random values are not unique, the entropy stored in entropySlots may be less effective and potentially predictable. This can weaken the security of any system relying on this entropy for randomness.

## Recommendations
- Implement a Uniqueness Check:
Add a check to ensure that each pseudo-random value is unique before storing it in the entropySlots array. but this would run out of gas .

```solidity
function writeEntropyBatch1() public {
  require(lastInitializedIndex < batchSize1, 'Batch 1 already initialized.');

  uint256 endIndex = lastInitializedIndex + batchSize1;
  uint256[] memory generatedValues = new uint256[](batchSize1);
  unchecked {
    for (uint256 i = lastInitializedIndex; i < endIndex; i++) {
      uint256 pseudoRandomValue = uint256(keccak256(abi.encodePacked(block.number, i))) % uint256(10) ** 78;
      require(pseudoRandomValue != 999999, 'Invalid value, retry.');

      // Check for uniqueness
      bool isUnique = true;
      for (uint256 j = 0; j < generatedValues.length; j++) {
        if (generatedValues[j] == pseudoRandomValue) {
          isUnique = false;
          break;
        }
      }
      require(isUnique, 'Duplicate value detected.');

      entropySlots[i] = pseudoRandomValue;
      generatedValues[i - lastInitializedIndex] = pseudoRandomValue;
    }
  }
  lastInitializedIndex = endIndex;
}
```
