# Vulnerability details

## Impact
The OZs [Pausable.sol](https://github.com/OpenZeppelin/openzeppelin-contracts/blob/master/contracts/utils/Pausable.sol#L103) contract is inherited by all the contracts in scope to utilize the `pause()` and `unpause()` functionality for some important functions. 

To utilize it, just inheriting the contract won't lead to leverage this functionality. But it is required that these functions are exposed via an external function which makes a call to the internal `pause()` and `unpause()` functions.

## Proof of Concept
In the **Links to affected code** section, I have already provided links to all the contracts in scope that has this error. 

Giving a single (instance) contract's link here
[TraitForgeNFT.sol](https://github.com/code-423n4/2024-07-traitforge/blob/main/contracts/TraitForgeNft/TraitForgeNft.sol#L7)

## Tools Used
Manual Analysis

## Recommended Mitigation Steps
Add the following piece of code to all the contracts listed above: 

```solidity
/* compiler will search for current contract's _pause() 
since it is not there, it will search this function in 
the inherited contract's from right to left */

function pause() external onlyOwner {
    _pause();  
}
function unpause() external onlyOwner {
    _unpause();
}
```
