# Vulnerability details

## Impact
All contracts lack a function or logic to set the `_paused` variable to `true` or `false`. As a result, the `whenNotPaused` modifier and `Pausable` library are effectively useless. This means that the protocol cannot pause or resume functionality across all contracts when needed.

The ability to pause and resume contract functionality is crucial for managing protocol operations, especially in response to emergencies or maintenance needs. The absence of functionality to control the `_paused` variable compromises the protocol's ability to effectively manage its contracts, potentially leading to operational risks and vulnerabilities. Implementing proper pausing mechanisms ensures that the protocol can be controlled and maintained as intended.

## Tools Used
Manual Review

## Recommended Mitigation Steps
Implement functions in each contract to set the `_paused` variable to `true` or `false`, allowing for proper pausing and resuming of contract functionality. Such as:
```javascript
  function pause() public onlyOwner {
    _pause();
  }
  function unpause() public onlyOwner {
    _unpause();
  }
```
