# Vulnerability details

In the `listForForging` function, the comparison for forger tokens uses `<=` instead of `<`:

```
    require(
      forgePotential > 0 && forgingCounts[tokenId] <= forgePotential,
      'Entity has reached its forging limit'
    );
```

## Impact
This allows one more forge than intended by the `forgePotential` value increasing the value of the forger tokens.

## Proof of Concept
Assume a forger token with `forgePotential` of 5.

Use the token for forging 5 times, incrementing `forgingCounts[tokenId]` to 5.

Attempt to list the token for forging again.

The transaction will succeed, allowing a 6th forge, despite the intended limit of 5.

## Tools Used
Manual review

## Recommended Mitigation Steps
Change the comparison operator from `<=` to `<`:

```
    require(
      forgePotential > 0 && forgingCounts[tokenId] < forgePotential,
      'Entity has reached its forging limit'
    );
```
