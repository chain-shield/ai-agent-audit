# Vulnerability details

## Impact
- In `_mintNewEntity` function, there is if statement which checks that if generation count is more than max token per gen and gen is equal to current gen then function `_incrementGeneration` will be called.
- But the catch is that gen variable is from the parameter of `_mintNewEntity` and this function is only called in `forge` function.
- In `forge` function new NFT is minted of new genration and `_mintNewEntity` is called with the param of `newGeneration` variable which is always +1 from current generation.
- So condition of If statement will never be true that means `_incrementGeneration` function will never be called.
