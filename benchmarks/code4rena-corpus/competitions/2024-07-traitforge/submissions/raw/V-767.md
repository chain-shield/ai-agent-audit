# Vulnerability details

Initialization Order:

Issue: If writeEntropyBatch1(), writeEntropyBatch2(), and writeEntropyBatch3() are not called in the correct sequence, the entropySlots array may not be initialized properly. For example, calling writeEntropyBatch2() before writeEntropyBatch1() could result in writing to slots that haven't been set up correctly.
State Management:

Current Implementation: The contract uses the lastInitializedIndex variable to track progress. If the functions are called out of order or multiple times, this index may become inconsistent, leading to overlapping or skipped slots and resulting in incorrect data.
Gas Consumption and Integrity:

Potential Problems: Initializing large batches can consume a lot of gas. If the state isn't managed correctly between function calls, it might cause incomplete or incorrect entropy values, which could affect the contract's overall functionality and reliability
