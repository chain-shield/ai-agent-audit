# Vulnerability details

The order of operations affects how rewards are calculated. If done incorrectly, developers might receive the wrong amounts of rewards.

The calculation of info.pendingRewards depends on the info.weight before its updated. Calculating and updating info.pendingRewards, we ensure that we are working with the old state. This line calculates the pending rewards using the old info.weight. If we update totalDevWeight first, the old info.weight might not correctly show the developer's contribution before the change.

totalDevWeight = totalDevWeight - info.weight + weight;
info.pendingRewards += (totalRewardDebt - info.rewardDebt) * info.weight;

correct one:

info.pendingRewards += (totalRewardDebt - info.rewardDebt) * info.weight;
totalDevWeight = totalDevWeight - info.weight + weight;
