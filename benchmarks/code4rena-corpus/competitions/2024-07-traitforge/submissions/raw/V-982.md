# Vulnerability details

## Impact
In `TraitForgeNft` contract, `currentGeneration` is a critical state variable it should not exceed `maxGeneration` which is a settable variable. In this contract `_mintInternal` and `_mintWithEntity` functions checks for current generation mint counts but not checking `currentGeneration` which should not exceed `maxGeneration`. if `currentGeneration` in this protocol is `maxGeneration` then also anyone can mint NFTs in unknown generations, although the owner can increase the `maxGeneration` parameter there is no check in the protocol's mint functionality or `_incrementGeneration` functionality to not exceed after `maxGeneration`. The lack of checks for `currentGeneration` should not exceed `maxGeneration` in the `_incrementGeneration` function, whatever the `maxGeneration` is, anyone can surpass the `maxGeneration`, which breaks the protocol's functionality. Anyone can mint NFTs after maxGeneration, which is not informed. if the protocol pauses, it can lead to the locking of funds and NFTs in the protocol and it breaks the protocol's functionality.

## Proof of Concept
1. Address A called `mintToken` and `_mintInternal` called by contract with `msg.sender` and `mintPrice` parameters.
2. `_mintInternal` uses `_incrementGeneration` function to update currentGeneration and generationMintCounts.

- see in code of `_mintInternal` function below :
<details>
<summary>code</summary>

```javascript
function _mintInternal(address to, uint256 mintPrice) internal {
    if (generationMintCounts[currentGeneration] >= maxTokensPerGen) {
      _incrementGeneration();
    }
```

</details>

3. `_incrementGeneration` updates currentGeneration and generationMintCounts.
4. Now this above function doesn't check for currentGeneration should not exceed maxGeneration.

- see the `_incrementGeneration` code below:

<details>
<summary>code</summary>

```javascript
function _incrementGeneration() private {
    require(
      generationMintCounts[currentGeneration] >= maxTokensPerGen,
      'Generation limit not yet reached'
    );
    currentGeneration++;
    generationMintCounts[currentGeneration] = 0;
    priceIncrement = priceIncrement + priceIncrementByGen;
    entropyGenerator.initializeAlphaIndices();
    emit GenerationIncremented(currentGeneration);
  }
```

</details>

## Recommended Mitigation Steps
Add the following changes in `TraitForgeNft::_incrementGeneration` :

```diff
  function _incrementGeneration() private {
    require(
      generationMintCounts[currentGeneration] >= maxTokensPerGen,
      'Generation limit not yet reached'
    );
+    require(currentGeneration <= maxGeneration, 'MaxGeneration exceeds');
    currentGeneration++;
    generationMintCounts[currentGeneration] = 0;
    priceIncrement = priceIncrement + priceIncrementByGen;
    entropyGenerator.initializeAlphaIndices();
    emit GenerationIncremented(currentGeneration);
  }
```
