# Vulnerability details

## Impact

According to [Documentation](https://traitforge.info/howitworks):
> forgePotential is determined by the 5th digit from the entropy. An entropy of 123456 means forgePotential is 5x.

However, different methods are used for calculating `forgePotential` in `EntityForfing.sol` and `EntropyGenerator.sol` which yields diffrent values. If the contracts are meant to be consistent, this discrepancy can lead to unexpected behavior.

**NOTE:** Let it be noted that the Documentation mentioned above is not the one marked (`needs to be updated`). See [here](https://code4rena.com/audits/2024-07-traitforge#top). Therefore, I am working with the assumption that this is up-to-date.

## Proof of Concept
**Different Extraction Methods**:
1. EntityForfing.sol: [Extracts the `5th digit`](https://github.com/code-423n4/2024-07-traitforge/blob/279b2887e3d38bc219a05d332cbcb0655b2dc644/contracts/EntityForging/EntityForging.sol#L86):
```solidity
uint8 forgePotential = uint8((entropy / 10) % 10);
```
2. EntropyGenerator.sol: [Extracts the first digit](https://github.com/code-423n4/2024-07-traitforge/blob/279b2887e3d38bc219a05d332cbcb0655b2dc644/contracts/EntropyGenerator/EntropyGenerator.sol#L153):
```solidity
forgePotential = getFirstDigit(entropy);
```
Here is [`getFirstDigit()`](https://github.com/code-423n4/2024-07-traitforge/blob/279b2887e3d38bc219a05d332cbcb0655b2dc644/contracts/EntropyGenerator/EntropyGenerator.sol#L198-L203):
```solidity
// utility to get he first digit of a number
  function getFirstDigit(uint256 number) private pure returns (uint256) {
    while (number >= 10) {
      number /= 10;
    }
    return number;
  }
```
### Example Number: 123456
**Method 1: Extracting the 5th Digit**

*Calculation*: uint8 `forgePotential = uint8((entropy / 10) % 10);`

*Steps*:
- `entropy / 10 = 123456 / 10 = 12345`
- `12345 % 10 = 5`

*Result*: `5`

**Method 2: Extracting the First Digit**

*Calculation*: `forgePotential = getFirstDigit(entropy);`

*Steps*:
- Loop: `123456 -> 12345 -> 1234 -> 123 -> 12 -> 1`

*Result*: `1`

**Comparison**:
- 5th Digit Extraction: `5`
- First Digit Extraction: `1`

**Conclusion**:
The methods yield different results (5 vs 1), indicating a significant discrepancy in the logic.

Manual Review

## Recommended Mitigation Steps
Ensure both contracts use the same logic for calculating `forgePotential` to maintain consistency. Verify which digit extraction is intended and update the code accordingly.
