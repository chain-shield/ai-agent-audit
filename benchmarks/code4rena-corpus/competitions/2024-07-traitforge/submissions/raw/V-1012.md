# Vulnerability details

## Impact

Many contracts inherit the `Pausable` contract, but do not expose the interface for external calls, resulting in the contract being unable to pause when encountering security issues.

## Proof of Concept

```solidity
    function _pause() internal virtual whenNotPaused {
        _paused = true;
        emit Paused(_msgSender());
    }

    function _unpause() internal virtual whenPaused {
        _paused = false;
        emit Unpaused(_msgSender());
    }
```

Internal functions need to be explicitly declared as external functions

## Tools Used

Manual review

## Recommended Mitigation Steps

Internal functions need to be explicitly declared as external functions
