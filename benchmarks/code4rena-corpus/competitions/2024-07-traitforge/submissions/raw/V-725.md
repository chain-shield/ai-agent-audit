# Vulnerability details

## Impact
In EntropyGenerator.sol ,deriveTokenParameters() calculates wrong parameter values for nukeFactor and forgePotential

## Proof of Concept

https://github.com/code-423n4/2024-07-traitforge/blob/279b2887e3d38bc219a05d332cbcb0655b2dc644/contracts/EntropyGenerator/EntropyGenerator.sol#L136

```Solidity
  function deriveTokenParameters(
    uint256 slotIndex,
    uint256 numberIndex
  )
    public
    view
    returns (
      uint256 nukeFactor,
      uint256 forgePotential,
      uint256 performanceFactor,
      bool isForger
    )
  {
    uint256 entropy = getEntropy(slotIndex, numberIndex);

    // example calcualtions using entropyto derive game-related parameters
    nukeFactor = entropy / 4000000;
    forgePotential = getFirstDigit(entropy);
    performanceFactor = entropy % 10;

    // exmaple logic to determine a boolean property based on entropy
    uint256 role = entropy % 3;
    isForger = role == 0;

    return (nukeFactor, forgePotential, performanceFactor, isForger); // return derived parammeters
  }
```

`nukeFactor = entropy / 4000000;`
The nukeFactor in this calculation will always be 0 as entropy is a 6 digit value.
Also forgePotential should be the 5th digit of the entropy , not the first digit.

Manual Review

## Recommended Mitigation Steps

nukeFactor = entropy / 40;
Calculate the 5th digit and assign to forgePotential
