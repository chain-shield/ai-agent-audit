# Vulnerability details

## Impact
The function `forgeWithListed` is used to list the entity for forging. The trait named `forgePotential` is used to ensure that entity can't forge more than `forgePotential` in certain time interval(denoted by `oneYearInDays`). The condition is as follows:
```solidity
require(
      forgePotential > 0 && forgingCounts[tokenId] <= forgePotential,
      'Entity has reached its forging limit'
    );
```
Due to above condition, it will be possible to create a listing even if `forgingCounts[tokenId]` is equal to `forgePotential`. And since there isn't any checking on `forgingCounts` during `forge`, it will be possible to forge an entity more than `forgePotential`. 


## Tools Used
Manual review

## Recommended Mitigation Steps
Update the condition as follows:
```solidity
require(
      forgePotential > 0 && forgingCounts[tokenId] < forgePotential,
      'Entity has reached its forging limit'
    );
```
