# Vulnerability details

## Details
- The vulnerability is present in the `NukeFund::calculateNukeFactor` function where it incorrectly calculates the final nuke factor due to the incorrect percentage in calculation of increased nuke factor on the basis of the age of entity.
- The additional nuke factor is calculated as some percentage on the age of the entity and docs define it as 2.5% on the entity age, but in actual practice it only accounts for 0.25% leading to reduced overall nuke factor.

## Impact
- The overall nuke factor calculated will be incorrect as additional nuke factor is calculated at 0.25% instead of 2.5%, leading to users getting less amount of ETH return for nuking their NFT.

## Proof of Concept
The docs mention that the nuke factor increase at 2.5% on the calculated age and is actually calculated as below in code:
```
    uint256 finalNukeFactor = ((adjustedAge * defaultNukeFactorIncrease) /
      MAX_DENOMINATOR) + initialNukeFactor;
```

Here the value of defaultNukeFactorIncrease = 250, and MAX_DENOMINATOR = 100000,
as a result of which it will be (250 / 100000) = 0.0025 = 0.25%

Thus, it can be clearly seen that the actual code implementation calculates at 0.25%, but it should be calculated at 2.5% in accordance with the docs.

## Tools Used
Manual Review

## Recommended Mitigation Steps
Correct the overall percentage evaluation for calculation of additional nuke factor to 2.5% as mentioned.
```diff
- uint256 public defaultNukeFactorIncrease = 250;
+ uint256 public defaultNukeFactorIncrease = 2500;
```

Now percentage calculation will be (2500 / 100000) = 0.025 = 2.5%
