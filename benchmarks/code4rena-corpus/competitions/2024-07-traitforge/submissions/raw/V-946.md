# Vulnerability details

The `fetchListings` function iterates through all listings without any limit:

```
  function fetchListings() external view returns (Listing[] memory _listings) {
    _listings = new Listing[](listingCount + 1);
    for (uint256 i = 1; i <= listingCount; ++i) {
      _listings[i] = listings[i];
    }
  }
```
## Impact
This unbounded loop could lead to several issues:

Gas Limit Exceeded: If the number of listings grows large enough, the function could exceed the block gas limit, making it impossible to call.

Denial of Service: The function could become too expensive to call, effectively denying service to users trying to fetch listings.

## Proof of Concept
Create a large number of listings (e.g., 1000+) using the `listForForging` function.

Call the `fetchListings()` function.

Observe that the gas cost increases linearly with the number of listings.

With a sufficiently large number of listings, the function call will fail due to exceeding the block gas limit.

## Recommended Mitigation Steps
Implement pagination in the `fetchListings()` function:

```
function fetchListings(uint256 start, uint256 limit) external view returns (Listing[] memory _listings) {
    require(start > 0 && start <= listingCount, "Invalid start index");
    uint256 end = Math.min(start + limit - 1, listingCount);
    
    _listings = new Listing[](end - start + 1);
    for (uint256 i = start; i <= end; ++i) {
        _listings[i - start] = listings[i];
    }
}
```

Consider adding a flag to filter only active listings:

```
function fetchActiveListings() external view returns (Listing[] memory _listings) {
    uint256 activeCount = 0;
    for (uint256 i = 1; i <= listingCount; ++i) {
        if (listings[i].isActive) {
            ++activeCount;
        }
    }
    
    _listings = new Listing[](activeCount);
    uint256 index = 0;
    for (uint256 i = 1; i <= listingCount; ++i) {
        if (listings[i].isActive) {
            _listings[index++] = listings[i];
        }
    }
}
```

These mitigations would significantly reduce the gas cost of fetching listings, improve scalability, and prevent potential denial of service as the number of listings grows over time.
