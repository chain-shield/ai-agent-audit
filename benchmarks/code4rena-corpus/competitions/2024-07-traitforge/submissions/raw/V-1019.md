# Vulnerability details

When users mint nft either directly or through forging & if the airdrop has not started, the entropy of the minted nft is added to the user's info in the Airdrop contract which is used to claim rewards later.

However incase the original user has transferred or sold the nft to someone else, they are still eligible to claim the airdrop.

## Proof of Concept
Both `_mintInternal()` & `_mintNewEntity()` contain the below line of code which would increase the `userInfo` parameter in the Airdrop contract which is used to determine the users share while claiming.

```solidity
File: TraitForgeNft.sol

   if (!airdropContract.airdropStarted()) {
         airdropContract.addUserAmount(newOwner, entropy);
   }
```
But if the nft is burned either by calling `burn()` directly or `nuke()`, the below function is accessed which decreases/removes the original user's for claiming the airdrop.

```solidity
File: TraitForgeNft.sol

>   if (!airdropContract.airdropStarted()) {
>     uint256 entropy = getTokenEntropy(tokenId);
>     airdropContract.subUserAmount(initialOwners[tokenId], entropy);
```
Two scenarios can occur now:
### 1st
*Note: Airdrop hasn't started.*
- Alice mints a nft. Alice can now claim airdrop.
- Alice sells the nft to Bob. Now Bob is the new owner of that nft.
- When airdrop starts, Alice can still claim rewards from airdrop but Bob can't.

### 2nd
*Note: Airdrop hasn't started.*
- Alice mints a nft. Alice can now claim airdrop.
- Alice sells the nft to Bob. Now Bob is the new owner of that nft.
- Bob calls the `nuke()` to claim rewards from the honeypot.
- The nft is burned & Alice is removed from the list of users who can claim airdrop because she was the `initialOwners` of that tokenId.
```solidity
    airdropContract.subUserAmount(initialOwners[tokenId], entropy);
```
## Impact
Users who initally minted the nfts can claim airdrop even if they don't hold the nft anymore. The new owners of the nft cannot claim the airdrop. The new owner can burn the nft & thus no one will receive any airdrop.

## Tools Used
Manual Review

## Recommended Mitigation Steps
When transferring the nft, update the `initialOwners` parameter with the current owner & call the airdrop contract to update the changes.
