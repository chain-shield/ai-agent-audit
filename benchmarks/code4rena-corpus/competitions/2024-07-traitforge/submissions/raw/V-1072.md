# Vulnerability details

## Impact
The approved role may have equal authorities as the owner to conduct activities such as listForForgin, forgeWithListed, cancelListingForForgin or listNFTForSale.
Currently the code only allow the approved role to burn the NFT.



## Tools Used
manual
## Recommended Mitigation Steps

make the following changes in function listForForging(), forgeWithListed(), cancelListingForForging() and listNFTForSale()
```Solidity
- nftContract.ownerOf(tokenId) == msg.sender,
+ nftContract.isApprovedOrOwner(msg.sender, tokenId),
```
