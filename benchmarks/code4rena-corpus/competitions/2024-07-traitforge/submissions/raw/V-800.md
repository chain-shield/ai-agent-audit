# Vulnerability details

## Impact
Users can be griefed with arbitrarily high gas fees when buying or forging with tokens owned by malicious contracts since token owners are paid through a high level ".call".

## Proof of Concept
Under normal conditions, buying an NFT from EntityTrading.sol costs about 160000 gas.
https://github.com/Myc3L1um-c4/griefing-example/blob/main/Normal%20Transaction.png

A malicious actor could deploy a contract to return a large array of random bytes to the ".call" made during payment and increase gas fees at will, like in the following example.
https://github.com/Myc3L1um-c4/griefing-example/blob/main/grief.sol

The following is a transaction to buy an NFT owned by the provided malicious contract where 6000 random bytes were loaded into memory, consuming unnecessary gas.
https://github.com/Myc3L1um-c4/griefing-example/blob/main/Malicious%20Transaction.png

This same method of griefing would likely affect more users if applied to EntityForging.sol since there can be much more interaction with the malicious token owner.

## Tools Used
Remix IDE

## Recommended Mitigation Steps
Token owners could be paid with a low level call built in assembly similar to the following example. By specifying an outsize of 0 return data is not loaded into memory.
https://github.com/Myc3L1um-c4/griefing-example/blob/main/mitigation%20example.sol
