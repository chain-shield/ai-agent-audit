# Vulnerability details

When minting, users can instantly see the NFT they've received, so nothing stops them from reverting the transaction (if they use a smart contract wallet) if the entity minted doesn't have desirable parameters like high entropy etc.
## Impact
Smart contract wallet users can have an unfair advantage over EOA users because they can intentionally revert the minting transaction if the entity minted doesn't have desirable parameters.

## Tools Used
Manual review

## Recommended Mitigation Steps
Users should only request minting, and entities' parameters should not be determined in the transaction called by the user.
