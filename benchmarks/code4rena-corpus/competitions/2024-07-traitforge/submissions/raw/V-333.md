Consider The following scenario:
```javascript
Msg.value = 1000000000 wei
totalDevWeight = 3
```

Current Calculation:
```javascript
uint256 amountPerWeight = msg.value / totalDevWeight; // Integer division
// amountPerWeight = 1000000000 / 3 => 333333333 wei

uint256 remaining = msg.value - (amountPerWeight * totalDev Weight);
// remaining=10ooooooo-(33s33s33*3) =>1wei;
```
In this case, the precision loss results in a remainder of only 1 wei, which could accumulate over multiple transactions.


## Tools Used: Manual Review, Slither

## Recommended Mitigation Steps: 
1. Ensure proper handling of rounding errors.
2. Validate weight and totalDevWeight to avoid division by zero
