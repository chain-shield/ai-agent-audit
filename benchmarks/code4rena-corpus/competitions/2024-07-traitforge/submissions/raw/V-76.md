# Vulnerability details

## Impact
Entropy value of NFT is not randomly assigned to NFTs, users can mint NFTs with specific desired entropy values. Since NFT entropy value determines forger or merger NFT type, the forgeable number and nuke-able assets, this vulnerable could significantly impact the protocol.

## Proof of Concept
In the `EntropyGenerator` contract, state variables `entropySlots`, `currentSlotIndex`, and `currentNumberIndex` are accessible by users. This exposure allows users to predict the next entropy value returned by the [getNextEntropy()](https://github.com/code-423n4/2024-07-traitforge/blob/main/contracts/EntropyGenerator/EntropyGenerator.sol#L101) function. Users can input `currentSlotIndex` and `currentNumberIndex` to call [getPublicEntropy()](https://github.com/code-423n4/2024-07-traitforge/blob/main/contracts/EntropyGenerator/EntropyGenerator.sol#L123) and obtain the next entropy value.

As a result, malicious users can wait for a desired next entropy value and then front-run honest users to mint NFT with specific entropy value.
