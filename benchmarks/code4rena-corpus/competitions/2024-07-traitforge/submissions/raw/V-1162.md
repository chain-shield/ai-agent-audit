# Vulnerability details

## Impact
The function `writeEntropyBatch1` and `writeEntropyBatch2` includes a requirement that pseudoRandomValue should not be equal to 999999. However, since the entropy values are limited to 77 digits due to the overflow issue, there is a possibility that the number could include 999999 within one of its slots. This allows the number 999999 to appear in the first two batches, which is not what the protocol intends.

## Proof of Concept
imagine an entropy value of ______999999_______ (replace _ with random numbers) and it will be of length 77 digits then the check is
`number != 999999` which in this case it will be valid and it fails to detect the appearance of the 999999 number.
