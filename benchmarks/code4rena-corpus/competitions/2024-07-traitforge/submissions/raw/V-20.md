# Vulnerability details

## Impact
The `IDevFund` interface includes an `UpdateDev` event, which implies the existence of a function that updates developer information. However, there is no declaration of an `updateDev` function within the interface. This inconsistency can lead to confusion and potential security issues, as the intended functionality for updating a developer's information is not explicitly defined.

## Proof of Concept
The following interface declaration lacks the `updateDev` function, despite having an `UpdateDev` event.

    interface IDevFund {
      struct DevInfo {
        uint256 weight;
        uint256 rewardDebt;
        uint256 pendingRewards;
      }

      event AddDev(address indexed dev, uint256 weight);
      event UpdateDev(address indexed dev, uint256 weight);
      event RemoveDev(address indexed dev);
      event Claim(address indexed dev, uint256 amount);
      event FundReceived(address indexed from, uint256 amount); // Log the received funds

      receive() external payable;

      function addDev(address user, uint256 weight) external;

      function removeDev(address user) external;

      function claim() external;

      function pendingRewards(address user) external view returns (uint256);
    }

## Tools Used
Manual code review.

## Recommended Mitigation Steps
Add the `updateDev` function declaration to the `IDevFund` interface to ensure consistent and secure handling of developer updates.

    function updateDev(address user, uint256 weight) external;
