# Vulnerability details

## Impact
According to the original documentation(https://traitforge.info/howitworks), `initialNukeFactor` should be calculated as `entropy / 4`, where an entropy value of `999999` divided by `4` gives a `percentage of 24.9%`.
However, in the current code implementation, `initialNukeFactor` is calculated by dividing `entropy` by `4000000`. Given that the maximum entropy value is `999999`, this results in `initialNukeFactor` always being zero due to integer division in Solidity.  

This incorrect computation means that the `initialNukeFactor` will never represent the intended destructive power percentage. Entities within the system will have an `initialNukeFactor` of zero, leading to significant misrepresentations in their capabilities. Consequentially, this can disrupt game balance, user experience, and the strategic elements designed around entity strengths.  

## Proof of Concept
Consider the following segment of code from the `deriveTokenParameters` function (lines 37-38):  

```solidity  
function deriveTokenParameters(  
    uint256 slotIndex,  
    uint256 numberIndex  
)  
  public  
  view  
  returns (  
    uint256 initialNukeFactor,  
    uint256 forgePotential,  
    uint256 performanceFactor,  
    bool isForger  
  )  
{  
  uint256 entropy = getEntropy(slotIndex, numberIndex);  

  // Incorrect calculation of initialNukeFactor  
@>  initialNukeFactor = entropy / 4000000; // This always results in 0 for entropy <= 999999  
  forgePotential = getFirstDigit(entropy);  
  performanceFactor = entropy % 10;  

  uint256 role = entropy % 3;  
  isForger = role == 0;  

  return (initialNukeFactor, forgePotential, performanceFactor, isForger); // return derived parameters  
} 
```
Example Calculation Steps:
Maximum possible entropy value: 999999
Current calculation: `initialNukeFactor` = entropy / 4000000
For maximum entropy: `initialNukeFactor` = 999999 / 4000000 = 0 (integer division in Solidity results in zero)
Expected calculation: `initialNukeFactor` = entropy / 4
For maximum entropy: `initialNukeFactor` = 999999 / 4 = 249999 (percentage: 24.9%)

## Recommended Mitigation Steps
Example Mitigation Code:
The following revised code snippet corrects the calculation of initialNukeFactor:
```solidity
function deriveTokenParameters(  
    uint256 slotIndex,  
    uint256 numberIndex  
)  
  public  
  view  
  returns (  
    uint256 initialNukeFactor,  
    uint256 forgePotential,  
    uint256 performanceFactor,  
    bool isForger  
  )  
{  
  uint256 entropy = getEntropy(slotIndex, numberIndex);  

  // Corrected calculation of initialNukeFactor  
@>  initialNukeFactor = entropy / 4; // Matches the documented calculation method  

  forgePotential = getFirstDigit(entropy);  
  performanceFactor = entropy % 10;  

  uint256 role = entropy % 3;  
  isForger = role == 0;  

  return (initialNukeFactor, forgePotential, performanceFactor, isForger);  
}
```
