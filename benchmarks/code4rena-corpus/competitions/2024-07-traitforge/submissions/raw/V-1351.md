# Vulnerability details

## Impact
- In `deriveTokenParameters` function, there is a variable called `nukeFactor` which is derived by dividing 4000000 to entropy of NFT.
- But the entropy is 6 digit number and in denominator it is 7 digit number.
- So that means it will always be 0 because in solidity's rounding down nature which is not intended.
