# Vulnerability details

## Impact
Users that call `TraitForgeNft::mintWithBudget` to mint multiple nfts can only use this function on the first generation. Once `tokenId` reaches the `maxTokensPerGen`, they can no longer mint with budget:
```
while (budgetLeft >= mintPrice && 
@>     _tokenIds < maxTokensPerGen
      ) {
```
`_tokenIds` should increment even when a new generation is set. But this restriction makes it impossible to mint up to `maxTokensPerGen` which means mint in the other generations.
The handle of max token per generation is managed on `TraitForgeNft::_mintInternal` function
```
if (generationMintCounts[currentGeneration] >= maxTokensPerGen) {
      _incrementGeneration();
    }
```

```
function test_multipleMint() public {
    //set up
    vm.startPrank(traitForgeNft.owner());
    traitForgeNft.setEntityForgingContract(address(entityForging));
    traitForgeNft.setEntropyGenerator(address(entropyGenerator));
    traitForgeNft.setAirdropContract(address(airdrop));
    vm.stopPrank();
    // initialization
    entropyGenerator.writeEntropyBatch1();
    entropyGenerator.writeEntropyBatch2();
    entropyGenerator.writeEntropyBatch3();

    proof = new bytes32[](1);
    proof[0] = keccak256(abi.encodePacked(user));
    // skip whitelist
    vm.warp(3 days);
    vm.deal(user, 10000 ether);
    vm.startPrank(user);
    //user mint with all his balance
    traitForgeNft.mintWithBudget{ value: user.balance }(proof);
    vm.stopPrank();
    //user can only mint up to 10 000 nfts
    assertEq(traitForgeNft.balanceOf(user), 10000);
    uint256 nftPrice = traitForgeNft.calculateMintPrice();
    // user still has funds to buy more NFTs but can't do it with mintWithBudget function
    assertGt(user.balance, nftPrice);
  }
```

## Recommended Mitigation Steps
Remove the `_tokenIds < maxTokensPerGen` check as it's handled in `_mintInternal` function
```
function mintWithBudget(
    bytes32[] calldata proof
  )
    public
    payable
    whenNotPaused
    nonReentrant
    onlyWhitelisted(proof, keccak256(abi.encodePacked(msg.sender)))
  {
    uint256 mintPrice = calculateMintPrice();
    uint256 amountMinted = 0;
    uint256 budgetLeft = msg.value;

    while (budgetLeft >= mintPrice 
-           && _tokenIds < maxTokensPerGen
    ) {
```
