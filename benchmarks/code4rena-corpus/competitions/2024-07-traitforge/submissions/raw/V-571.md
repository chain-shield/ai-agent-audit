# Vulnerability details

## Impact
Users to mint NFT at a higher price than expected because the price calculation of the first NFT is inaccurate in over 2nd generation.

## Proof of Concept
Users mint TraitForge NFTs using the `mintToken()/mintWithBudget()` functions of the `TraitForgeNft` contract.
-TraitForgeNft.sol#mintToken:
```solidity
  function mintToken(
    bytes32[] calldata proof
  )
    ...
  {
--> uint256 mintPrice = calculateMintPrice();
    require(msg.value >= mintPrice, 'Insufficient ETH send for minting.');

--> _mintInternal(msg.sender, mintPrice);
    SNIP...
  }
```
-TraitForgeNft.sol#mintWithBudget:
```solidity
  function mintWithBudget(
    bytes32[] calldata proof
  )
    ...
  {
--> uint256 mintPrice = calculateMintPrice();
    uint256 amountMinted = 0;
    uint256 budgetLeft = msg.value;

    while (budgetLeft >= mintPrice && _tokenIds < maxTokensPerGen) {
-->   _mintInternal(msg.sender, mintPrice);
      amountMinted++;
      budgetLeft -= mintPrice;
-->   mintPrice = calculateMintPrice();
    }
    SNIP...
  }
```
As you can see above this code snippet, the price of the NFT to be minted is determined using the `TraitForgeNft.sol#calculateMintPrice()` function, and then the NFT is minted using the `TraitForgeNft.sol#_mintInternal()` function.

In the `TraitForgeNft.sol#calculateMintPrice()` function, the price of NFT is set according to `generationMintCounts[currentGeneration]`.
```solidity
  function calculateMintPrice() public view returns (uint256) {
--> uint256 currentGenMintCount = generationMintCounts[currentGeneration];
--> uint256 priceIncrease = priceIncrement * currentGenMintCount;
--> uint256 price = startPrice + priceIncrease;
    return price;
  }
```

The whitepaper mentions the following:
> Gen 1’s produce Gen 2’s, Gen 2’s can produce Gen 3’s etc. The game is capped at 10 Generations for now. Generations can only forge with each other and up to a max of 10000 for each generation. The Mint fee for generation 1 starts at 0.005 ETH and ends at 0.25ETH after 10,000. Generation 2 starts at 0.005 ETH and ends at 0.3ETH. Generation 3 starts at 0.005 ETH and ends at 0.35 ETH, and so on.

As a result, the price of the first NFT of each generation is `startPrice` (i.e. 0.005 ETH).
However, due to incorrect processing in the `TraitForgeNft.sol#_mintInternal()` function when the generation increases, the price of the first NFT becomes much larger than expected.
```solidity
  function _mintInternal(address to, uint256 mintPrice) internal {
--> if (generationMintCounts[currentGeneration] >= maxTokensPerGen) {
      _incrementGeneration();
    }

    _tokenIds++;
    uint256 newItemId = _tokenIds;
    _mint(to, newItemId);
    uint256 entropyValue = entropyGenerator.getNextEntropy();

    tokenCreationTimestamps[newItemId] = block.timestamp;
    tokenEntropy[newItemId] = entropyValue;
    tokenGenerations[newItemId] = currentGeneration;
--> generationMintCounts[currentGeneration]++;
    initialOwners[newItemId] = to;

    SNIP...
  }
```
As you can see, the `_incrementGeneration()` function is called first before incrementing `generationMintCounts[currentGeneration]`.
In the `_incrementGeneration()` function, `generationMintCounts[currentGeneration]` is initialized to 0.
```solidity
  function _incrementGeneration() private {
    require(
      generationMintCounts[currentGeneration] >= maxTokensPerGen,
      'Generation limit not yet reached'
    );
    currentGeneration++;
--> generationMintCounts[currentGeneration] = 0;
    priceIncrement = priceIncrement + priceIncrementByGen;
    entropyGenerator.initializeAlphaIndices();
    emit GenerationIncremented(currentGeneration);
  }
```

To illustrate the problem:
- Assume `currentGeneration` = 1`, `generationMintCounts[currentGeneration]` = 9999.
- Alice calls the `mintToken()` function.
  In other words, the last NFT of the first generation is created (there are only 10,000 NFTs in one generation).
  However, since `generationMintCounts[currentGeneration] < 10000` at this time, the `_incrementGeneration()` function is not called.
  Therefore, `currentGeneration` is still 1 and `generationMintCounts[currentGeneration] ` = 10000.
- Alice calls the `mintToken()` function again. In other words, the first NFT of the second generation must be created.
  At this time, because the generation has not increased in the `calculateMintPrice()` function, the NFT price is calculated as follows.
  > price = startPrice + priceIncrement * generationMintCounts[currentGeneration] =
    = 0.005 ETH + 0.0000245 ETH * 10000 = 0.25 ETH
As you can see, the price of the first NFT of the second generation was calculated as 0.25 ETH, not 0.005 ETH. In other words, users have to pay more funds than expected.

