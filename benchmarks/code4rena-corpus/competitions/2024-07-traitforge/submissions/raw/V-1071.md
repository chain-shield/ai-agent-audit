# Vulnerability details

## Impact
In the `TraitForgeNft` contract, when a player mints the first token of a new generation, the mint price is calculated as `0.005 + priceIncrement * 10000` rather than the intended `0.005`. This deviation from the intended pricing mechanism results in a significant overcharge for the player minting the first token of a new generation.

As a result, any player minting the last few tokens of the current generation or the first token of a new generation using the `mintToken` and `mintWithBudget` functions will incur a higher cost than expected.

This issue affects all generations, causing potential loss of funds for players multiple times over the lifespan of the protocol.

The current calculation of NFT prices in the `TraitForgeNft` contract leads to an unintended mint price calculation for the first token of a new generation. This results in overcharging players and causing a loss of funds, deviating from the protocol's intended behavior.

## Tools Used
Manual Review

## Recommended Mitigation Steps
To resolve this issue, the `mintToken`, `mintWithBudget` and `calculateMintPrice` functions should be updated to correctly calculate the mint price for the first token of a new generation.
