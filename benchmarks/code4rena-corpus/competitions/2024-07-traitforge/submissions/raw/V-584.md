# Vulnerability details

## Impact
The token price of the first token of a generation (generations >= 2) is calculated incorrectly (50-140 times more than the intended price).

## Proof of Concept
Assume that currently it is generation 1 and the number of tokens minted/forged is 10,000. This would make :
tokenIds = 10,000
generationMintCounts[1] = 10,000.
currentGeneration = 1
(this is because after updating the `enerationMintCounts[currentGeneration]` in the `_mintInternal` function, it doesn't increment the `currentGeneration`)

When a user comes to mint the next token (10,000 + 1)th token (which should be generation 2's first token), the following happens in the mintToken() (mintWithBudget() function is also erroneous) function:
(https://github.com/code-423n4/2024-07-traitforge/blob/279b2887e3d38bc219a05d332cbcb0655b2dc644/contracts/TraitForgeNft/TraitForgeNft.sol#L181-L200)
1. calculateMintPrice() function calculates the price of the token as 0.25ETH
(https://github.com/code-423n4/2024-07-traitforge/blob/279b2887e3d38bc219a05d332cbcb0655b2dc644/contracts/TraitForgeNft/TraitForgeNft.sol#L227-L232)

2. After which the _mintInternal() function is called which increments the generation and mints the first token of the second generation to the user.
(https://github.com/code-423n4/2024-07-traitforge/blob/279b2887e3d38bc219a05d332cbcb0655b2dc644/contracts/TraitForgeNft/TraitForgeNft.sol#L280-L309)

This essentially means that the user has to spend 0.25ETH instead of 0.005ETH (as mentioned in the documentation) for the first token of the second generation(which corresponds to a price increase of 50 times). 

Note: this disparity in the price is larger for higher generations:
For example for the 10th generation the user would be charged 0.7ETH for a 0.005ETH token(140 times increase in price).

## Tools Used
Manual Review

## Recommended Mitigation Steps
One way to resolve this issue is to check for incrementing the generation after the token has been minted and count has been increased by adding the following check at line 295 (_mintInternal function):

`if (generationMintCounts[currentGeneration] >= maxTokensPerGen) {`
     ` _incrementGeneration();`
  `  }`
