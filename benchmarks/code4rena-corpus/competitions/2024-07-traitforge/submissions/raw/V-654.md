# Vulnerability details

## Impact
In the [forgeWithListed](https://github.com/code-423n4/2024-07-traitforge/blob/279b2887e3d38bc219a05d332cbcb0655b2dc644/contracts/EntityForging/EntityForging.sol#L102) function, after a successful forge operation, the contract automatically cancels the listing for the forger token by calling [_cancelListingForForging(forgerTokenId)]().
 However due to an oversight [cancelListingForForging(forgerTokenId)]() is not used allowing cancellation  to occur without any checks to ensure that caller is authorized to cancel list . This allows an attacker can cancel  list for  forging tokens for intended benefits .

## Proof of Concept
The contract contains two function [_cancelListingForForging(forgerTokenId)]( )
which cancels the list and  [cancelListingForForging(forgerTokenId)]() which serves as a check to ensure that the caller is the owner of the `tokenId`

The function [cancelListingForForging( )]()

```solidity
  function cancelListingForForging(
    uint256 tokenId
  ) external whenNotPaused nonReentrant {
    require(
      nftContract.ownerOf(tokenId) == msg.sender ||
        msg.sender == address(nftContract),
      'Caller must own the token'
    );
    require(
      listings[listedTokenIds[tokenId]].isListed,
      'Token not listed for forging'
    ); 
    _cancelListingForForging(tokenId);
  }

```

As you can see it performs a series of checks to ensure that the caller is the owner of the `tokenId` before calling `_cancelListingForForging(tokenId);`

The oversight in [EntityForging.sol:forgeWithListed()](https://github.com/code-423n4/2024-07-traitforge/blob/279b2887e3d38bc219a05d332cbcb0655b2dc644/contracts/EntityForging/EntityForging.sol#L102)

```solidity
 function forgeWithListed(
    uint256 forgerTokenId,
    uint256 mergerTokenId
  ) external payable whenNotPaused nonReentrant returns (uint256) {                                  
                         //

//@audit-issue 
   _cancelListingForForging(forgerTokenId);  


                     //

}
```
A  attacker can abuse this oversight to by pass the checks and cancel listings which will lead to loss of funds for users

```solidity

    uint256 forgerTokenId,
    uint256 mergerTokenId
  ) external payable whenNotPaused nonReentrant returns (uint256) {                                  
                         //

 
 --  _cancelListingForForging(forgerTokenId);  

++   cancelListingForForging(forgerTokenId); 
                     //

}
