# Vulnerability details

## Impact
The function does not work after minting 10,000 NFTs due to incorrect validation in `TraitForgeNft.sol#mintWithBudget`.

## Proof of Concept
`TraitForgeNft.sol#mintWithBudget` is a function that mints NFTs in a batch manner.
```solidity

    bytes32[] calldata proof
  )
    public
    payable
    whenNotPaused
    nonReentrant
    onlyWhitelisted(proof, keccak256(abi.encodePacked(msg.sender)))
  {
    uint256 mintPrice = calculateMintPrice();
    uint256 amountMinted = 0;
    uint256 budgetLeft = msg.value;

--> while (budgetLeft >= mintPrice && _tokenIds < maxTokensPerGen) {
      _mintInternal(msg.sender, mintPrice);
      amountMinted++;
      budgetLeft -= mintPrice;
      mintPrice = calculateMintPrice();
    }
    if (budgetLeft > 0) {
      (bool refundSuccess, ) = msg.sender.call{ value: budgetLeft }('');
      require(refundSuccess, 'Refund failed.');
    }
  }
```
As you can see, `tokenIds` must be less than `maxTokensPerGen`(10000).
However, a total of 100000 (`maxGeneration` * `maxTokensPerGen`) NFTs can be minted, and therefore `_tokenIds` can take a value between 1 and 100000.
Therefore, the `mintWithBudget` function does not work after 10000 NFTs are minted.
