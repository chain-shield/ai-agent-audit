# Vulnerability details

## Impact
After a new NFT is minted and the threshold of one generation is reached, it calls `_incrementGeneration`: [_mintInternal](https://github.com/code-423n4/2024-07-traitforge/blob/279b2887e3d38bc219a05d332cbcb0655b2dc644/contracts/TraitForgeNft/TraitForgeNft.sol#L282) and [_mintNewEntity](https://github.com/code-423n4/2024-07-traitforge/blob/279b2887e3d38bc219a05d332cbcb0655b2dc644/contracts/TraitForgeNft/TraitForgeNft.sol#L334). This function updates the current generation and calls the entropy generator, to update the alpha indices [initializeAlphaIndices](https://github.com/code-423n4/2024-07-traitforge/blob/279b2887e3d38bc219a05d332cbcb0655b2dc644/contracts/TraitForgeNft/TraitForgeNft.sol#L353C22-L353C44). This function is a restricted one, with only owner access [initializeAlphaIndices](https://github.com/code-423n4/2024-07-traitforge/blob/279b2887e3d38bc219a05d332cbcb0655b2dc644/contracts/EntropyGenerator/EntropyGenerator.sol#L206-L216). Therefor the mint tx reverts and stops the protocol from functioning. 

Notice: The EntropyGenerator expects the NFT to be the [allowedCaller](https://github.com/code-423n4/2024-07-traitforge/blob/279b2887e3d38bc219a05d332cbcb0655b2dc644/contracts/EntropyGenerator/EntropyGenerator.sol#L22C19-L22C32) as the NFT contracts calls [getNextEntropy](https://github.com/code-423n4/2024-07-traitforge/blob/279b2887e3d38bc219a05d332cbcb0655b2dc644/contracts/TraitForgeNft/TraitForgeNft.sol#L288) while minting an NFT. This function is restricted to be only called by the allowed contract [see](https://github.com/code-423n4/2024-07-traitforge/blob/279b2887e3d38bc219a05d332cbcb0655b2dc644/contracts/EntropyGenerator/EntropyGenerator.sol#L101). So just transferring ownership can not solve the issue.

## Proof of Concept

First mint 10,000 NFTs to complete the first generation.
```
for (uint256 i; i < 10_000; i++) {
  uint256 price = nft.calculateMintPrice();
  nft.mintToken{ value: price }(proof);
}
```

When minting the next NFT, the call will revert with: "revert: Ownable: caller is not the owner". It is no longer possible to mint any new NFT and the game is no longer playable after generation 1.

            address(nft),

            payable(address(devFund)),
            payable(daoFund)
        );

        nft.setNukeFundContract(payable(address(nukeFund)));
        trading.setNukeFundAddress(payable(address(nukeFund)));

        vm.stopPrank();

        vm.label(address(nft), "nft");
        vm.label(address(trading), "trading");
        vm.label(address(entropy), "entropy");
        vm.label(address(devFund), "devFund");

    receive() external payable {

        vm.warp(block.timestamp + 25 hours);

        vm.pauseGasMetering();
        for (uint256 i; i < 10_000; i++) {
            uint256 price = nft.calculateMintPrice();
            nft.mintToken{ value: price }(proof);

        vm.resumeGasMetering();

        nft.mintToken{ value: price }(proof);

## Recommended Mitigation Steps

I recommend adding a new function named updateAlphaIndices(), which should be defined as external, and should be protected by the modifiers whenNotPaused and onlyAllowedCaller. This addition will address the access control issues and clarify the intent of the NFT code. The current function, initializeAlphaIndices, seems ambiguous in its purpose, and renaming or replacing it with updateAlphaIndices would better convey the function's role.

Furthermore, implementing updateAlphaIndices ensures a clear separation of access rights. This approach prevents the owner, even if trusted, from being able to modify the alpha indices after the initial setup, enhancing the security and transparency of the contract.

Here is an example implementation showing the changes in EntropyGenerator. Additionally IEntropyGenerator.sol need to be updated and inside [TraitForgeNFT.sol::_incrementGeneration](https://github.com/code-423n4/2024-07-traitforge/blob/279b2887e3d38bc219a05d332cbcb0655b2dc644/contracts/TraitForgeNft/TraitForgeNft.sol#L353) the ".initializeAlphaIndices() changed to ".updateAlphaIndices()"
```
function initializeAlphaIndices() public whenNotPaused onlyOwner {
    require(
        slotIndexSelectionPoint == 0 &&
        numberIndexSelectionPoint == 0,
        "Already initialized"
    );

    _setAlphaIndices();
}

function updateAlphaIndices() external whenNotPaused onlyAllowedCaller {
    _setAlphaIndices();
}

function _setAlphaIndices() internal {
    uint256 hashValue = uint256(
        keccak256(abi.encodePacked(blockhash(block.number - 1), block.timestamp))
    );

    uint256 slotIndexSelection = (hashValue % 258) + 512;
    uint256 numberIndexSelection = hashValue % 13;

    slotIndexSelectionPoint = slotIndexSelection;
    numberIndexSelectionPoint = numberIndexSelection;
}

```

Alternatively consider adding a new modifier that allows the owner and the allowedCaller to call the function.
