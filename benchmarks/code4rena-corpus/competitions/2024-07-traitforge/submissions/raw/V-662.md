# Vulnerability details

## Impact
Malicious actor can launch a gas griefing attack and users can lose their gas 

## Proof of Concept
The EntityForging::forgeWithListed function sends eth to forgerOwner of forger using 
`(bool success_forge, ) = forgerOwner.call{ value: forgerShare }('');`
    `require(success_forge, 'Failed to send to Forge Owner');`
https://github.com/code-423n4/2024-07-traitforge/blob/279b2887e3d38bc219a05d332cbcb0655b2dc644/contracts/EntityForging/EntityForging.sol#L158-L159
(.call) will send (63/64) of remaining gas left in that transaction  to forgerOwner address ,IF it is not a EOA and a smart contract with recieve function which has implemented a infinite loop in it then users will lose gas and function will revert.Even a sophisticated malicious actor can made a smart contract that buys few TraitForge NFTs and list them for forge with minimumListFee  so that many users will try to forge with them and then he implements infinite loop in that contract's recieve function, even their is no economic incentive for the attacker, he can do these to defame the protocol. 


## Tools Used
manual review 

## Recommended Mitigation Steps
even though we set maximum gas limit in (.call) he will send heavy return data so, 
this (bool success_forge, ) = forgerOwner.call{ value: forgerShare }(''); 
is same as this
(bool success_forge,bytes memory data ) = forgerOwner.call{ value: forgerShare }(''); 
      which basically means that even though the data is omitted it doesn’t mean that the contract does not handle it. Actually, the way it works is the bytes data that was returned from the forgerowner will be copied to memory. Memory allocation becomes very costly if the payload is big, so this means that if a forgerowner implements a recieve function that returns a huge payload, then the msg.sender of the transaction, in our case the one who called forgeWithListed, will have to pay a huge amount of gas for copying this payload to memory.And eventually transaction reverts so
Use a low-level assembly call since it does not automatically copy return data to memory

bool success;
assembly {
    success := call(300, forgerOwner,forgerShare , 0, 0, 0, 0)
}
