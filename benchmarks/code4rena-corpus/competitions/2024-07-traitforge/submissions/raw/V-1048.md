# Vulnerability details

The `TraitForgeNft` contract is using functions from the `Airdrop` contract in several instances:

- [`TraitForgeNft.startAirdrop`](https://github.com/code-423n4/2024-07-traitforge/blob/279b2887e3d38bc219a05d332cbcb0655b2dc644/contracts/TraitForgeNft/TraitForgeNft.sol#L97) calls `Airdrop.startAirdrop`
- [`TraitForgeNft.burn`](https://github.com/code-423n4/2024-07-traitforge/blob/279b2887e3d38bc219a05d332cbcb0655b2dc644/contracts/TraitForgeNft/TraitForgeNft.sol#L148) calls `Airdrop.subUserAmount`
- [`TraitForgeNft.forge`](https://github.com/code-423n4/2024-07-traitforge/blob/279b2887e3d38bc219a05d332cbcb0655b2dc644/contracts/TraitForgeNft/TraitForgeNft.sol#L176) → [`TraitForgeNft._mintNewEntity`](https://github.com/code-423n4/2024-07-traitforge/blob/279b2887e3d38bc219a05d332cbcb0655b2dc644/contracts/TraitForgeNft/TraitForgeNft.sol#L338) calls `Airdrop.addUserAmount`
- [`TraitForgeNft.mintToken`](https://github.com/code-423n4/2024-07-traitforge/blob/279b2887e3d38bc219a05d332cbcb0655b2dc644/contracts/TraitForgeNft/TraitForgeNft.sol#L193) → [`TraitForgeNft._mintInternal`](https://github.com/code-423n4/2024-07-traitforge/blob/279b2887e3d38bc219a05d332cbcb0655b2dc644/contracts/TraitForgeNft/TraitForgeNft.sol#L297) calls `Airdrop.addUserAmount`
- [`TraitForgeNft.mintWithBudget`](https://github.com/code-423n4/2024-07-traitforge/blob/279b2887e3d38bc219a05d332cbcb0655b2dc644/contracts/TraitForgeNft/TraitForgeNft.sol#L216) → [`TraitForgeNft._mintInternal`](https://github.com/code-423n4/2024-07-traitforge/blob/279b2887e3d38bc219a05d332cbcb0655b2dc644/contracts/TraitForgeNft/TraitForgeNft.sol#L297)calls `Airdrop.addUserAmount`

However, all of these functions are protected by the `onlyOwner` modifier, which restricts access to the contract deployer only. Attempting to call these functions from `TraitForgeNft` will result in a revert, blocking all of the above functionalities.

## Impact

The functions which calls access restricted functions in the `Airdrop` contract will be completely unusable.

## Recommended Mitigation Steps

Replace the `onlyOwner` restriction with `onlyNftContract` to allow the necessary access:

```solidity
  modifier onlyNftContract() {
    require(msg.sender == traitForgeNft || msg.sender == owner(), 'Caller is not allowed');
    _;
  }
```
