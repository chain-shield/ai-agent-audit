# Vulnerability details

## Impact
The `EntropyGenerator` contract documentation states that the initial Nuke Factor should be calculated as `Entropy / 40`. However, the actual implementation in the `deriveTokenParameters` function uses a different formula, resulting in a significant discrepancy. This discrepancy can result in entities having unintended strengths or weaknesses, potentially skewing the game balance and affecting the overall player experience

## Proof of Concept
Given an example entropy value of 123456, the correct calculation should yield:
```
nukeFactor = entropy / 40;
nukeFactor = 123456 / 40;
nukeFactor = 3086;
```
but it is incorrectly giving 
```
nukeFactor = entropy / 4000000;
nukeFactor = 123456 / 4000000;
nukeFactor = 0; // Integer division truncates to 0
```
## Tools Used
Manual
## Recommended Mitigation Steps
Correct the formula for calculating the `Nuke Factor` in the `deriveTokenParameters` function to align with the documentation.
