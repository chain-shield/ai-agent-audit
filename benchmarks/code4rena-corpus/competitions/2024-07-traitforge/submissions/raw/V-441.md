# Vulnerability details

## Impact
Wrongly calculated return variables forgePotential and nukeFactor when user call EntropyGenerator::deriveTokenParameters() function

## Proof of Concept
In the docs, here's are how each variable are calculated:
```solidity
Entropy: 123456
Entropy[0] = physicalTrait1
Entropy[1] = physicalTrait2
Entropy[2] = physicalTrait3
Entropy[3] = physicalTrait4
Entropy[4] = colour1 && forgePotential
Entropy[5] = colour2
Entropy /40 = initalNukeFactor
Entropy % 10 = performanceFactor
Entropy % 3 ? 0 == Role
```

But [forgePotential here is calculated](https://github.com/code-423n4/2024-07-traitforge/blob/279b2887e3d38bc219a05d332cbcb0655b2dc644/contracts/EntropyGenerator/EntropyGenerator.sol#L153) to get the first digit not the fifth digit in the docs
```solidity
forgePotential = getFirstDigit(entropy);
```

And [nukeFactor](https://github.com/code-423n4/2024-07-traitforge/blob/279b2887e3d38bc219a05d332cbcb0655b2dc644/contracts/EntropyGenerator/EntropyGenerator.sol#L152) should be divided by 40 instead
```solidity
nukeFactor = entropy / 4000000;
```
