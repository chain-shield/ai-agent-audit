# Vulnerability details


**Description**
* The `TraitForgeNFT::mintWithBudget` function contains a condition that unintentionally limits the total number of NFTs that can be minted across a generation 

**Impact**
* so `while (budgetLeft >= mintPrice && _tokenIds < maxTokensPerGen)` while this is true mintWithBudget calls _mintInternal to mint entities, now later on the line `_tokenIds = maxTokensPerGen` now when this happens `TraitForgeNFT::mintWithBudget` will not be able to call the _mintInternal functions again leading to protocol core functionality break 

* below is the function and the vulnerable line in question

**Recommended Mitigation**
Remove the `_tokenIds < maxTokensPerGen` check from the while loop in the `mintWithBudget` function.
