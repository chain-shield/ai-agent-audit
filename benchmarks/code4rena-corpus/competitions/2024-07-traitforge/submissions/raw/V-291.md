# Vulnerability details

## Description
There is potential time-bomb in `EntityForging::fetchListings` as the `loop un unbounded` which could DoS dApps/front-end that rely on it which seems to warrant `Medium` severity. 

The root cause is due to the fact that `fetchListings` loop un unbounded, and since the number of forger NFT allowed to be listed is also unbounded, this could potentially stop working at some point.

## Impact
`fetchListings` might stop working at some point, always timing out or running out of gas, if a certain amount of forger NFT are listed.

## PoC
No PoC really needed, pretty self-explanatory.

## Tools Used
Manual review

## Recommended Mitigation Steps
You need to implement either a maximum on how many forger NFT can be listed at the same time AND/OR `refactor fetchListings` such that you can `paginated call` in certain batch.
