# Vulnerability details

## Impact
The forge NFT's ability to be used for forging is determined by `forgePotential`. This value is extracted from the last second digit of entropy and dictates how many times the NFT can be used in the forging process. However, due to the `EntropyGenerator::getEntropy()` function right-pads the entropy value with zeros, many NFTs are prone to having a `forgePotential` of zero, rendering them unusable for forging.

## Proof of Concept
The `EntropyGenerator::getEntropy()` function right-pads the entropy value with zeros, which increases the likelihood that the last second digit of the entropy will be zero:

```solidity
182:     uint256 paddedEntropy = entropy * (10 ** (6 - numberOfDigits(entropy)));
```

In `EntityForging::listForForging()` function, the `forgePotential` is extracted by taking the last second digit from the entropy:

```solidity
86:     uint8 forgePotential = uint8((entropy / 10) % 10); // Extract the 5th digit from the entropy
```

Due to the padding of entropy values, the last second digit is often zero, leading to a significant number of NFTs with a `forgePotential` of zero.

## Recommended Mitigation Steps
```diff
-    uint8 forgePotential = uint8((entropy / 10) % 10); // Extract the 5th digit from the entropy

```
