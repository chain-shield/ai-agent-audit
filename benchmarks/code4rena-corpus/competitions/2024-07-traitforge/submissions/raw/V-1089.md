# Vulnerability details

## Description
The NukeFactor calculation in the contract doesn't align with the whitepaper's specification of NukeFactor being between 0 and 50%.

```
nukeFactor = entropy / 4000000;
```

## Impact
1. NukeFactor will always be 0 for entropy values less than 4,000,000.
2. This severely limits the range and distribution of NukeFactor values.
3. It could significantly impact the game balance and economy of TraitForge.

## Proof of Concept

Given entropy values:

* For entropy = 3,999,999, nukeFactor = 0
* For entropy = 4,000,000, nukeFactor = 1
* For entropy = 999,999 (max possible), nukeFactor = 0

This doesn't provide the 0-50% range specified in the whitepaper.

## Tools Used
Manual Review

## Recommended Mitigation Steps

1. Adjust the calculation to properly scale the entropy to the 0-50% range:
```
nukeFactor = (entropy * 50) / 1000000;
```
