# Vulnerability details

The following contracts: [`DevFund`](https://github.com/code-423n4/2024-07-traitforge/blob/279b2887e3d38bc219a05d332cbcb0655b2dc644/contracts/DevFund/DevFund.sol#L9), [`EntityForging`](https://github.com/code-423n4/2024-07-traitforge/blob/279b2887e3d38bc219a05d332cbcb0655b2dc644/contracts/EntityForging/EntityForging.sol#L10), [`EntityTrading`](https://github.com/code-423n4/2024-07-traitforge/blob/279b2887e3d38bc219a05d332cbcb0655b2dc644/contracts/EntityTrading/EntityTrading.sol#L11), [`EntropyGenerator`](https://github.com/code-423n4/2024-07-traitforge/blob/279b2887e3d38bc219a05d332cbcb0655b2dc644/contracts/EntropyGenerator/EntropyGenerator.sol#L9), [`NukeFund`](https://github.com/code-423n4/2024-07-traitforge/blob/279b2887e3d38bc219a05d332cbcb0655b2dc644/contracts/NukeFund/NukeFund.sol#L11), and [`TraitForgeNft`](https://github.com/code-423n4/2024-07-traitforge/blob/279b2887e3d38bc219a05d332cbcb0655b2dc644/contracts/TraitForgeNft/TraitForgeNft.sol#L14) are supposed to be pausable (as they all inherit OZ’s `Pausable` contract). However, they don't expose the `pause()` and `unpause()` functionalities, meaning they cannot be paused or unpaused by administrators.

## Impact

In emergency situations, the contracts cannot be paused or unpaused, which can lead to severe issues.

## Proof of Concept

The `_pause` and `_unpause` are internal virtual functions in OZ’s `Pausable` contract, which means they should be exposed as public or external functions to the protocol administrators to be available when necessary. None of the mentioned contracts implement these functions.

https://github.com/OpenZeppelin/openzeppelin-contracts/blob/fd81a96f01cc42ef1c9a5399364968d0e07e9e90/contracts/security/Pausable.sol#L89-L104

```solidity
function _pause() internal virtual whenNotPaused {
    _paused = true;
    emit Paused(_msgSender());
}

function _unpause() internal virtual whenPaused {
    _paused = false;
    emit Unpaused(_msgSender());
}
```

## Recommended Mitigation Steps

Add public/external `pause` and `unpause` functions in the [`DevFund`](https://github.com/code-423n4/2024-07-traitforge/blob/279b2887e3d38bc219a05d332cbcb0655b2dc644/contracts/DevFund/DevFund.sol#L9), [`EntityForging`](https://github.com/code-423n4/2024-07-traitforge/blob/279b2887e3d38bc219a05d332cbcb0655b2dc644/contracts/EntityForging/EntityForging.sol#L10), [`EntityTrading`](https://github.com/code-423n4/2024-07-traitforge/blob/279b2887e3d38bc219a05d332cbcb0655b2dc644/contracts/EntityTrading/EntityTrading.sol#L11), [`EntropyGenerator`](https://github.com/code-423n4/2024-07-traitforge/blob/279b2887e3d38bc219a05d332cbcb0655b2dc644/contracts/EntropyGenerator/EntropyGenerator.sol#L9), [`NukeFund`](https://github.com/code-423n4/2024-07-traitforge/blob/279b2887e3d38bc219a05d332cbcb0655b2dc644/contracts/NukeFund/NukeFund.sol#L11), and [`TraitForgeNft`](https://github.com/code-423n4/2024-07-traitforge/blob/279b2887e3d38bc219a05d332cbcb0655b2dc644/contracts/TraitForgeNft/TraitForgeNft.sol#L14) to allow them to be pausable.

```solidity
/**
 * @dev Pauses all functions affected by `whenNotPaused`.
 */
function pause() public onlyOwner {
    _pause();
}

/**
 * @dev Unpauses all functions affected by `whenNotPaused`.
 */
function unpause() public onlyOwner {
    _unpause();
}
```
