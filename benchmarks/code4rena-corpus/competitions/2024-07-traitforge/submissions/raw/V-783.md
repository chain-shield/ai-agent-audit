# Vulnerability details

# Details
- The documentation states the following for the elements of the entropy slots: "each slot able to contain a 78 digit number".
However, the logic for generating the digits number (specified in the github links) generates 77 digit numbers and not 78.

- Also the methods responsible for generating the first and second generation of entropies must not allow golden entropy in the generated slots.
However, checking 77 digit number (which should have been 78 digits) with statements such as `require(pseudoRandomValue != 999999, 'Invalid value, retry.');` will never catch if the 77 digit number contains such sequence.

## Impact
- Entropy slots elements hold 77 digit number instead of 78 digits.
- The generated numbers for first and second generation of entropy may contains the golder entropy - 999999 inside them, since the validation `require(pseudoRandomValue != 999999, 'Invalid value, retry.');` does not work properly.

## Proof of Concept
Follow these steps:
- Deploy the following smart contract in Remix IDE or using other tools:
```javascript
// SPDX-License-Identifier: MIT
pragma solidity ^0.8.20;

contract EntropyManager {
    uint256[770] private entropySlots; // Array to store entropy values
    uint256 private lastInitializedIndex = 0; // Index to keep track of the initialization of entropy values
    uint256 private currentSlotIndex = 0;
    uint256 private currentNumberIndex = 0;
    uint256 private batchSize1 = 256;
    uint256 private batchSize2 = 512;
    uint256 private maxSlotIndex = 770;
    uint256 private maxNumberIndex = 13;
    uint256 public slotIndexSelectionPoint;
    uint256 public numberIndexSelectionPoint;

    // Function to write entropy values in batches of batchSize1
    function writeEntropyBatch1() public {
        require(lastInitializedIndex < batchSize1, 'Batch 1 already initialized.');

        uint256 endIndex = lastInitializedIndex + batchSize1; // Calculate the end index for the batch
        unchecked {
            for (uint256 i = lastInitializedIndex; i < endIndex; i++) {
                uint256 pseudoRandomValue = uint256(
                    keccak256(abi.encodePacked(block.number, i))
                ) % uint256(10) ** 78; // Generate a pseudo-random value using block number and index
                require(pseudoRandomValue != 999999, 'Invalid value, retry.');
                entropySlots[i] = pseudoRandomValue; // Store the value in the slots array
            }
        }
        lastInitializedIndex = endIndex;
    }

    // Getter functions to access private variables for testing and validation purposes
    function getEntropySlot(uint256 index) public view returns (uint256) {
        require(index < maxSlotIndex, 'Index out of bounds');
        return entropySlots[index];
    }
}
```
- Call the method `writeEntropyBatch1`
- Call the method for getting entropy slot with proper argument such as `getEntropySlot(1)`.
- Copy the output of the method and count it's digits. The output is a 77 digit number which looks like this: `19085876106743701664961649015242405312216082383703184670357774050142071594619`.

Not that the generated number may contain the sequence 999999 since the validation: `require(pseudoRandomValue != 999999, 'Invalid value, retry.');` won't catch it.

## Recommended Mitigation Steps
- For generating 78 digit number instead of the current 77 digit numbers I would suggest a method which is similar to this one:
```javascript
function getRandom78DigitNumber(uint256 i) public view returns (uint256) {
    // Generate a random number using keccak256
    uint256 randomHash = uint256(keccak256(abi.encodePacked(block.number, i)));

    // Ensure the random number is within the range of 78 digits
    uint256 upperBound = type(uint256).max; // Maximum value for a 78-digit number
    uint256 lowerBound = 10**77;     // Minimum value for a 78-digit number

    // Adjust the random number to ensure it's within the 78-digit range
    uint256 random78DigitNumber = lowerBound + (randomHash % (upperBound - lowerBound + 1));

    return random78DigitNumber;
}
```

// Function to check if the sequence "999999" is in the number
function containsSequence(uint256 number) public pure returns (bool) {
    string memory numStr = uintToString(number);
    bytes memory sequence = bytes("999999");
    bytes memory numBytes = bytes(numStr);

    // Scan through the number string to find the sequence
    for (uint256 i = 0; i <= numBytes.length - sequence.length; i++) {
        bool isMatch = true;
        for (uint256 j = 0; j < sequence.length; j++) {
            if (numBytes[i + j] != sequence[j]) {
                isMatch = false;
                break;
            }
        }
        if (isMatch) {
            return true;
        }
    }
    return false;
}

function uintToString(uint256 v) internal pure returns (string memory) {
    if (v == 0) {
        return "0";
    }
    uint256 maxLength = 78; // maximum length for 78 digits
    bytes memory reversed = new bytes(maxLength);
    uint256 i = 0;
    while (v != 0) {
        uint256 remainder = v % 10;
        v = v / 10;
        reversed[i++] = bytes1(uint8(48 + remainder));
    }
    bytes memory s = new bytes(i); // total digits length
    for (uint256 j = 0; j < i; j++) {
        s[j] = reversed[i - j - 1];
    }
    return string(s);
}
