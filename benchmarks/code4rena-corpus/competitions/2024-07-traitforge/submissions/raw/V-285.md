# Vulnerability details

## Impact
Forging can only be done between `tokenIds` of the `same genaration`. When this is done, the `newTokenId` minted will be `1 generation` higher than the `parents`. However, if that next generation has been fully minted, the whole minting of the `newTokenId` will revert.

## Proof of Concept
During forging in [`TraitForgeNft::forge()`](https://github.com/code-423n4/2024-07-traitforge/blob/279b2887e3d38bc219a05d332cbcb0655b2dc644/contracts/TraitForgeNft/TraitForgeNft.sol#L163-L176), the properties for the `newTokenId` are calculated as follows:
```solidity
    uint256 newGeneration = getTokenGeneration(parent1Id) + 1;

    /// Check new generation is not over maxGeneration
    require(newGeneration <= maxGeneration, "can't be over max generation");

    // Calculate the new entity's entropy
    (uint256 forgerEntropy, uint256 mergerEntropy) = getEntropiesForTokens(
      parent1Id,
      parent2Id
    );
    uint256 newEntropy = (forgerEntropy + mergerEntropy) / 2;

    // Mint the new entity
>>  uint256 newTokenId = _mintNewEntity(newOwner, newEntropy, newGeneration);
```
### Scenario
- Let the generation for the `parent1Id` and `parent2Id` be `2`
- `currentGeneration` = 4

Now `newGeneration` = 2 + 1 = `3`.
However, a total of `10000` tokens have been minted in `gen 3` which is why the `currentGeneration` = `4`

When [`_mintNewEntity()`](https://github.com/code-423n4/2024-07-traitforge/blob/279b2887e3d38bc219a05d332cbcb0655b2dc644/contracts/TraitForgeNft/TraitForgeNft.sol#L316-L319) is called, the following will be required:
```solidity
    require(
      generationMintCounts[gen] < maxTokensPerGen,
      'Exceeds maxTokensPerGen'
    );
```
As seen, `generationMintCounts[3]` will not be less than  `maxTokensPerGen` since a total of `10000` tokens have been minted already.
This function will therefore revert since the required condition will not be met.

## Tools Used
Manual Review

## Recommended Mitigation Steps
Allow the `forging` process to dynamically adjust to the next available generation if the intended generation is fully minted.
