# Vulnerability details

## Impact
Because `ForgeWithListed()` doesn't refund excess ETH sent as fee and there's no way to extract. Those ETH will be frozen in the `EntityForging` contract.

## Proof of Concept
In the following POC Alice is forging an NFT but sends 3.0 ETH with call but the fee was only 1 ETH. The rest of 2 ETH gets stuck in the contract.

```javascript
it('should allow forging with a listed token but users excess ETH gets frozen', async () => {
  const forgerTokenId = FORGER_TOKEN_ID;
  const mergerTokenId = MERGER_TOKEN_ID;

  const initialBalance = await ethers.provider.getBalance(owner.address);

  const forgerEntropy = await nft.getTokenEntropy(forgerTokenId);
  const mergerEntrypy = await nft.getTokenEntropy(mergerTokenId);
  /// The new token id will be forger token id + 1, cause it's the last item
  const expectedTokenId = FORGER_TOKEN_ID + 1;
  await expect(
    entityForging
      .connect(user1)
      .forgeWithListed(forgerTokenId, mergerTokenId, {
        value: FORGING_FEE + ethers.parseEther('2.0'),
      })
  )
    .to.emit(entityForging, 'EntityForged')
    .withArgs(
      expectedTokenId,
      forgerTokenId,
      mergerTokenId,
      (forgerEntropy + mergerEntrypy) / 2n,
      FORGING_FEE
    )
    .to.emit(nft, 'NewEntityMinted')
    .withArgs(
      await user1.getAddress(),
      expectedTokenId,
      2,
      (forgerEntropy + mergerEntrypy) / 2n
    );

  const finalBalance = await ethers.provider.getBalance(owner.address);

  const testbalance = await ethers.provider.getBalance(entityForging.getAddress())
  console.log("balance of EntityForging contract after forging", testbalance)

  expect(finalBalance - initialBalance).to.be.eq((FORGING_FEE * 9n) / 10n);
  // Check forger nft delisted

  const listingInfo = await entityForging.listings(forgerTokenId);

  expect(listingInfo.isListed).to.be.eq(false);
});
```

## Recommended Mitigation Steps
Refund the excess ETH to the caller at the end of the function call. See below:
```solidity
(bool success, ) = (msg.sender).call{ value: (msg.value - forgingFee) }('');
require(success, 'Failed to refund sender's excess fee');
```
