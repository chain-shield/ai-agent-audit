# Vulnerability details

## Impact
The `EntityTrading` contract in charge of performing trading operations does not work properly

Faulty functionality originates in the process of purchasing NFTs or canceling the sales process.

```
// function to buy an NFT listed for sale
function buyNFT(uint256 tokenId) external payable whenNotPaused nonReentrant {
  Listing memory listing = listings[listedTokenIds[tokenId]];
  require(
    msg.value == listing.price,
    'ETH sent does not match the listing price'
  );
  require(listing.seller != address(0), 'NFT is not listed for sale.'); // @audit is possible buy inexistent NFT??

  //transfer eth to seller (distribute to nukefund)
  uint256 nukeFundContribution = msg.value / taxCut; // @audit round to zero (HIGH)
  uint256 sellerProceeds = msg.value - nukeFundContribution;
  transferToNukeFund(nukeFundContribution); // transfer contribution to nukeFund

  // transfer NFT from contract to buyer
  (bool success, ) = payable(listing.seller).call{ value: sellerProceeds }(
    ''
  );
  require(success, 'Failed to send to seller');
  nftContract.transferFrom(address(this), msg.sender, tokenId); // transfer NFT to the buyer

  delete listings[listedTokenIds[tokenId]]; // remove listing

  emit NFTSold(
    tokenId,
    listing.seller,
    msg.sender,
    msg.value,
    nukeFundContribution
  ); // emit an event for the sale
}
```

The buyNFT function in charge of the task of buying a NFT involves transferring the NFT to the buyer, like any purchase process.

However, this is not possible because the `listing.seller's` address is not resolved

```
struct Listing {
  address seller; // address of NFT seller
  uint256 tokenId; // token id of NFT
  uint256 price; // Price of the NFT in wei
  bool isActive; // flag to check if the listing is active
}
```

This field represents the seller's address but is not assigned in the trading process causing it to always revert when performing a purchase operation.

## Proof of Concept

    const listingId = await entityTrading.listedTokenIds(TOKEN_ID);

    expect(listing.isActive).to.be.false;

    // Check if the NFT is transferred back to the owner
