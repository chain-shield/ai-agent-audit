# Vulnerability details

## Impact
Miners can gain unfair advantage over normal users to get desired result.

## Proof of Concept
The `writeEntropyBatch1` , `writeEntropyBatch2` , `writeEntropyBatch3` functions in `EntropyGenerator` uses `block.number` as a source of randomness which is bad. 

The above mentioned three function uses similar code i.e. -
```js
      for (uint256 i = lastInitializedIndex; i < endIndex; i++) {
        uint256 pseudoRandomValue = uint256(
          keccak256(abi.encodePacked(block.number, i)) 
        ) % uint256(10) ** 78;
```
To generate random value `pseudoRandomValue`, which is not a good source of randomness.As miners can keep trying to generate randomness until they acquire the desired result.Although the premise for miners to continue doing this is based upon the level of incentive.

## Tools Used
Manual Review

## Recommended Mitigation Steps
Use better sources to generate randomness like, [Chainlink Keepers](https://docs.chain.link/vrf).
