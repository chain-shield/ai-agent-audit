# Vulnerability details

## Impact
`TraitForgeNft::generationMintCounts` is reset to 0 after increment to the next generation which break the invariant that there's no more than 10000 each generation because there will be 10000 NFTs minted or forged in that generation + some NFTs that were merged (forged) before  that generation but is reset to 0 after currentGeneration incremented to that generation.


## Proof of Concept
Let's do an example:
1. When merging two tokenId generation 1 you will have a new tokenId generation 2.

- New generation of child token is incremented [here](https://github.com/code-423n4/2024-07-traitforge/blob/279b2887e3d38bc219a05d332cbcb0655b2dc644/contracts/TraitForgeNft/TraitForgeNft.sol#L163) in TraitForgeNft::forge() function: 
```solidity
uint256 newGeneration = getTokenGeneration(parent1Id) + 1;
```
- Then the [new gen is passed to _mintNewEntity()](https://github.com/code-423n4/2024-07-traitforge/blob/279b2887e3d38bc219a05d332cbcb0655b2dc644/contracts/TraitForgeNft/TraitForgeNft.sol#L176) to be minted here:
```solidity
 uint256 newTokenId = _mintNewEntity(newOwner, newEntropy, newGeneration);
```
2. Then [TraitForgeNft::generationMintCounts variable is incremented](https://github.com/code-423n4/2024-07-traitforge/blob/279b2887e3d38bc219a05d332cbcb0655b2dc644/contracts/TraitForgeNft/TraitForgeNft.sol#L328) for generation 2
```solidity
    generationMintCounts[gen]++;
```
3. When all token in generation 1 has been minted, and someone call TraitForgeNft::mintToken() function which will call TraitForgeNft::_mintInternal() function, it will call TraitForgeNft::_incrementGeneration() and then increment the current generation to 2 [after the check](https://github.com/code-423n4/2024-07-traitforge/blob/279b2887e3d38bc219a05d332cbcb0655b2dc644/contracts/TraitForgeNft/TraitForgeNft.sol#L280-L283):
```solidity
 function _mintInternal(address to, uint256 mintPrice) internal {
    if (generationMintCounts[currentGeneration] >= maxTokensPerGen) {
      _incrementGeneration();
    }
```
4. Then in TraitForgeNft::_incrementGeneration() function generationMintCounts for current generation which is 2 is set to 0 which erase the count of merged child token from 2 parent tokens of generation 1.
```solidity
 generationMintCounts[currentGeneration] = 0;
```
