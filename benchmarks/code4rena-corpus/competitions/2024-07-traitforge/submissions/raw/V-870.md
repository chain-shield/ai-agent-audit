# Vulnerability details



### Description
* All contracts in the protocol have inherited the Pausable contract from OpenZeppelin, which includes internal virtual functions `_pause() and _unpause()`. These functions are intended to be overridden in the main contract to implement the pausing functionality. However, the protocol has not overridden these functions, resulting in the inability to pause or unpause any of the contracts.

*  this below are the internal virtual functions inside the pausable contract that are supposed to be overridden 
```javascript
function _pause() internal virtual whenNotPaused {
        _paused = true;
        emit Paused(_msgSender());
    }

    function _unpause() internal virtual whenPaused {
        _paused = false;
        emit Unpaused(_msgSender());
    }
```
* with the protocol forgetting to override such important functions, this breaks the whole protocol concept of not being able to pause in certain scenerio. 
  
### Impact
* When these contracts are deployed, the protocol will be unable to pause or unpause any of the contracts. This renders the whenNotPaused modifier in all the contracts ineffective, potentially allowing critical functions to be executed even when the protocol should be paused.
   
### Proof of Concept
* contract is Deployed on the first day.
* On the following day, the protocol attempt to pause one of the contracts due to a specific reason.
* the protocol searches for a way to pause the contract but couldn't see because overridden the `_pause() and _unpause()` functions was how the protocol was suppose to pause the contract,
* Observe that there is no way to pause the contract 

### Tool used
* manual

### Recommended Mitigation
* kindly Override the pause and unpause functions in every contract that has inherited the Pausable contract.

```javascript
function pause() external override onlyOwner {
        _pause();
    }

    
function unpause() external override onlyOwner {
       _unpause();
    }
```
