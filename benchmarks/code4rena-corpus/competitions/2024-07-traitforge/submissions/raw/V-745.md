# Vulnerability details

## Vulnerability details
The protocol uses a uint256 value to store the values of 13 genes, which have a value from 0 to 999999. The protocol uses uint256 and all its digits as if its maximum value was 78 nines, however the maximum value is 115792089237316195423570985008687907853269984665640564039457584007913129639935. Which means that the distribution of genes will be different.


## Impact: 
The economy of the game will be broken, genes distribution will be uneven and due to the max value of uint256 not being 78 nines the minters can be put on advantegous or disadvantegous situation because users will be unaware of the uneven distribution of genes.

## Recommended Mitigation Steps

Do not use the whole uint256 and only part of it.
