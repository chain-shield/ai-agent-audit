# Vulnerability details

## Summary
The protocol utilizing `OpenZeppelin` `Pausable.sol` version `4.9.3` lacks the necessary external `pause` and `unpause` functions in its derived contracts. This omission means the protocol cannot be paused or unpaused as intended, potentially impacting the entire functionality of the protocol.

## Vulnerability Details
The protocol's contracts do not implement external pause and unpause functions, which are necessary to change the protocol state via the inherited internal `_pause` and `_unpause` functions from `OpenZeppelin's` `Pausable.sol`. The `OpenZeppelin` `Pausable.sol` version `4.9.3` is different from other versions here `paused` function in `Pausable.sol` only returns the `boolean` value of `_paused` and does not alter the state of the protocol.

## Impact
Uncontrollable State Management: The inability to `pause` or `unpause` the protocol leaves it in a potentially vulnerable state, as the mechanism to control the protocol's activity during emergency situations or maintenance is non-functional.

## Recommended Mitigation Steps
Modify Function Scope:
Change the scope of the pause and unpause functions from internal to public or external in the `Pausable` contract.
Add External Functions:
Introduce external or public functions in the derived contract to call the pause and unpause functions, enabling the owner or authorized entities to control the protocol's state.
```diff
 function pause() external onlyOwner whenNotPaused{
    _pause();
   }
   
 function unpause() external onlyOwner{
    _unpause();
   }
 
```
