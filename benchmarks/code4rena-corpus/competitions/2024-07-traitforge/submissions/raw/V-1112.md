# Vulnerability details

**Description:** 
The following contracts: `DevFund`, `EntityForging`, `EntityTrading`, `EntropyGenerator`, `NukeFund` and `TraitForgeNft` contracts are supposed to be pausable (as they all inherit from Pausable contract), but they don't implement the external pause/unpause functionalities which means it will never be possible to pause them.

**Proof of Concept:**
All the following contracts  `DevFund`, `EntityForging`, `EntityTrading`, `EntropyGenerator`, `NukeFund` and `TraitForgeNft` from the openzeppelin `Pausable` extension which means that they contain internal functions _pause and _unpause.

Because those functions are internal, the contract must implement two other public/external pause and unpause functions to allow the owner to pause and unpause the contracts when necessary. None of the contracts implement those functions, which means even if those contracts are supposed to be pausable (and have the pause/unpause functionalities), none of them can be paused.

**Impact:** 
The impact will be when owner wants to pause the contract for some reason, the owner will be not able to do it.

**Recommended Mitigation:** 
Add public/external pause and unpause functions in the contracts to allow them to be pausable, this can be done as in the `DedFund` contract. For example:
```solidity
/**
 * @dev Triggers stopped state.
 * Contract must not be paused
 */
function pause() external onlyOwner {
    _pause();
}

/**
 * @dev Returns to normal state.
 * Contract must be paused
 */
function unpause() external onlyOwner {
    _unpause();
}
