# Vulnerability details

## Description & Impact

The `EntropyGenerator::writeEntropyBatch1` and `EntropyGenerator::writeEntropyBatch2` functions contain the following `require` statement intended to prevent the entropy value from being 999999 in the first 512 slots:

```
require(pseudoRandomValue != 999999, 'Invalid value, retry.');
```

However, this implementation is incorrect. The `pseudoRandomValue` represents the entire value of the slot and is divided into 13 6-digit numbers as entropy values. Consequently, the check does not effectively prevent 999999 from being one of the entropy values within the slot. This bug allows the 'Golden God' entropy value of 999999 to exist within the first 512 slots.

## Impact 

This bug significantly affects the integrity of the contract by allowing the 'Golden God' to appear in the first 512 slots. This could lead to unintended game advantages or disruptions, undermining the game's fairness and strategic elements. Specifically, if the 'Golden God' appears early, it could skew the Nuke Fund distribution and the overall gameplay balance, leading to loss of trust and potential financial losses for other participants.

                }
              }
            }
          }
        })

## Recommended Mitigation Steps

To address this issue, modify the `EntropyGenerator::writeEntropyBatch1` and `EntropyGenerator::writeEntropyBatch2` functions. After generating each slot, use the `EntropyGenerator::getEntropy` method to extract the 13 entropy values and check each of them to ensure none are 999999.
