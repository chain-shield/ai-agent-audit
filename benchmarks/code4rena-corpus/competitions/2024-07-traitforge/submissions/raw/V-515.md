# Vulnerability details

## Vulnerability details

`EntropyGenerator` contract inherits the openzeppelins' `ownable` contract,
where the project teams' multisig contract will be the owner.
This allows them to use the `initializeAlphaIndices` function at will.
 
However the `initializeAlphaIndices` function with the `onlyOwner` modifier 
is also designed to be called by the `_incrementGeneration` function of `TraitForgeNft` contract 
while incrementing the current Generation.

But this call will be reverted due to the `onlyOwner` modifier.

## Impact

Subsequent Generation TokenIds cannot be minted 
due to potential DOS created by access control restriction.


## Tools Used

Manual Review

## Recommended Mitigation Steps

Consider removing the 'onlyOwner' modifier 
and allow either of the multisig or the `TraitForgeNft` contract 
to call the `initializeAlphaIndices` function. 
For example,

```
require (msg.sender == nftContractAddress || 
         msg.sender == multiSigAddress, 
         "Not allowed")
```
