# Vulnerability details

## Impact
Clash of calculated entropy value with the magic value of 999999 used.

## Proof of Concept
In `getEntropy()`, the entropy value is hardcoded to return 999999 if `slotIndex == slotIndexSelectionPoint && numberIndex == numberIndexSelectionPoint`. This is presumbly used to represent when this particular condition has occured.

However, there are also values for which the final calculated `entropy` value will be 999999 as well for certain values of `entropySlots`.

By solving the equation of,

`entropy = (slotValue / 10 ** (72 - position)) % 1000000`

we are able to figure out slotValue to be,

`slotValue = 999999 * 10 ** (72 - position)`, where position is a multiple of 6

As a result, there are 12 combinations of `slotValue` and `position` such that `entropy` will be calculated to be 999999.

When this happens, the magic number that is used will no longer be effective to represent the paritcular condition it is anchored on.

## Tools Used
Manual review

## Recommended Mitigation Steps
Consider using a magic number that falls beyond the possible values of `entropy`.
