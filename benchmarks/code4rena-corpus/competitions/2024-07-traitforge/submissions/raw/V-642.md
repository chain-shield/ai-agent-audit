# Vulnerability details

## Impact
From second generation onwards, the mintWithBudget function wont work

## Proof of Concept
At line 215, in the mintWithBudget function, there is the following check:
` while (budgetLeft >= mintPrice && _tokenIds < maxTokensPerGen) {`
this would mean that once _tokenIds crosses 9,999 the function will never mint any NFT. 
(https://github.com/code-423n4/2024-07-traitforge/blob/279b2887e3d38bc219a05d332cbcb0655b2dc644/contracts/TraitForgeNft/TraitForgeNft.sol#L215)

## Tools Used
Manual Review

## Recommended Mitigation Steps
Remove the check as follows:
` while (budgetLeft >= mintPrice) {`
