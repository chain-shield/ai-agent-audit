# Vulnerability details

## Impact
Price for the first token of new generation is incorrect as mint price calculation in [TraitForgeNft::mintToken()](https://github.com/code-423n4/2024-07-traitforge/blob/279b2887e3d38bc219a05d332cbcb0655b2dc644/contracts/TraitForgeNft/TraitForgeNft.sol#L190) and [TraitForgeNft::mintWithBudget()](https://github.com/code-423n4/2024-07-traitforge/blob/279b2887e3d38bc219a05d332cbcb0655b2dc644/contracts/TraitForgeNft/TraitForgeNft.sol#L211) is performed before generation increment, which happens in [TraitForgeNft::_mintInternal()](https://github.com/code-423n4/2024-07-traitforge/blob/279b2887e3d38bc219a05d332cbcb0655b2dc644/contracts/TraitForgeNft/TraitForgeNft.sol#L280), on which mint price calculation depends.

```javascript
function calculateMintPrice() public view returns (uint256) {
  uint256 currentGenMintCount = generationMintCounts[currentGeneration];
  uint256 priceIncrease = priceIncrement * currentGenMintCount;
  uint256 price = startPrice + priceIncrease;
  return price;
}
```

As a result, users minting the first token of a new generation will be charged a significantly higher price than intended. This could lead to unexpected loss of funds for users and potential dissatisfaction with the minting process. Furthermore, impact increases as the `currentGeneration` increases (due to higher price increment in every next generation).

## Proof of Concept

Place the following code into TraitForgeNft.test.ts:

```javascript
   it("should mint 10,000 tokens and check the price of the first Gen 2 token", async function() {
      this.timeout(0); // Disable timeout for this test
  
      const startPrice = await nft.startPrice();
      const firstMintPrice = await nft.calculateMintPrice();
      console.log("First Gen 1 mint price:", ethers.formatEther(firstMintPrice));
 
      let maxTokens = await nft.maxTokensPerGen()
      console.log("Starting price:", ethers.formatEther(startPrice));
      for (let i = 0; i < maxTokens; i++) {
  
        await nft.connect(owner).mintToken(merkleInfo.whitelist[0].proof, { value: ethers.parseEther('1') });
  
      }
      let gen1Counter = await nft.generationMintCounts(1);
      expect(gen1Counter).to.be.equal(maxTokens);

  
      // Check the price for the first Gen 2 token. This function is called before the
      // miniting and not taking into account case where cap is reached.
      // so this price will be the price user is charged...
      const gen2FirstTokenPrice = await nft.calculateMintPrice();
      expect(gen2FirstTokenPrice).be.not.equal(startPrice);
      console.log("First Gen 2 mint price:", ethers.formatEther(gen2FirstTokenPrice));
    });
```

## Recommended Mitigation Steps

Remove logic for incrementing generation from the `_mintInternal()` function and place it in the mintToken() and mintWithBudget() functions before the call to the `calculateMintPrice()` function.

```diff
  function mintToken(
    bytes32[] calldata proof
  )
    public
    payable
    whenNotPaused
    nonReentrant
    onlyWhitelisted(proof, keccak256(abi.encodePacked(msg.sender)))
  {
+    if (generationMintCounts[currentGeneration] >= maxTokensPerGen) {
+      _incrementGeneration();
    }
    uint256 mintPrice = calculateMintPrice();
 ...
}
```

and

```diff

  )
```
