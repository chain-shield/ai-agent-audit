# Vulnerability details

## Impact
The `EntityForging`, `EntityTrading` and `DevFund` contracts all inherits `Pausable` contract from Openzeppelin to allow the contracts to be paused in the event of emergencies. To this effect, these aforementioned contracts all implement a `whenNotPaused` modifier on their various functions. 

For example, in `EntityTrading` the functions `listNFTForSale`, `buyNFT` and `cancelListing` all have the `whenNotPaused` modifier. The same is true for `listForForging`, forgeWithlisted` and `cancelListingForForging` functions in `EntityForging` contract as well as `claim` function in `DevFund` contract. 

It is noted that neither of the three contracts have implemented the `pause()` and `unpause ()` functions which means that the contracts can never enter a pause state . There is absolutely no mechanism for the contract to be paused. 

Openzeppelin requires contracts inheriting from `Pausable` contract to implement an external/public `pause` and `unpause` function which would in turn call their internal `_pause` and `_unpause` functions. 

Effectively, if there is any form of emergency, the contracts can never be paused and critical actions such as canceling Listing, buyingNFT, listing NFT for sale are never paused.
