# Vulnerability details

## Impact
During claim, users would not be transferred the correct token, when DevFund has under-supply of it.

There is an assumption that the DevFund contract will own enough tokens to distribute to users as a reward during claims. However, if there is excess user activity, the DevFund may run out of token. All claims that happen after that will result in zero transfer of token to the user. This will continue until the DevFund contract is replenished again.

## Proof of Concept
If the DevFund contract is undersupplied with tokens, the `claim()` function will send fewer token than needed. This is particularly unsafe because the missing tokens are not accounted for. Consequently, a user who calls a [claim()](https://github.com/code-423n4/2024-07-traitforge/blob/279b2887e3d38bc219a05d332cbcb0655b2dc644/contracts/DevFund/DevFund.sol#L69) function might invoke the [safeRewardTransfer()](https://github.com/code-423n4/2024-07-traitforge/blob/279b2887e3d38bc219a05d332cbcb0655b2dc644/contracts/DevFund/DevFund.sol#L83-L92) function and not receive the tokens they were supposed to.
```solidity
  function safeRewardTransfer(
    address to,
    uint256 amount
  ) internal returns (uint256) {
    uint256 _rewardBalance = payable(address(this)).balance;
    if (amount > _rewardBalance) amount = _rewardBalance;
    (bool success, ) = payable(to).call{ value: amount }('');
    require(success, 'Failed to send Reward');
    return amount;
  } 
```
## POC
Note: Temporarily modify the internal function `DevFund.safeRewardTransfer()` to public function, for unit test validation
```solidity
// SPDX-License-Identifier: UNLICENSED
pragma solidity ^0.8.20;

import {Test, console} from "forge-std/Test.sol";

import {DevFund} from "../contracts/DevFund/DevFund.sol";

contract DevFundTest is Test {
    DevFund devFund;

    address user = makeAddr("USER");

    function setUp() public {
        devFund = new DevFund();
    }

    // Function to receive Ether. msg.data must be empty
    receive() external payable {}

    function testSafeRewardTransfer() external {
        devFund.addDev(user, 100);

        // funding DevFund
        (bool success,) = payable(devFund).call{value: 100}("");
        require(success, "Funding failed");

        assertEq(devFund.safeRewardTransfer(user, 60), 60); // user is rewarded correctly.

        assertEq(devFund.safeRewardTransfer(user, 60), 40); // user is rewarded lesser by 20.

        assertEq(devFund.safeRewardTransfer(user, 60), 0); // user is totally not rewarded when DevFund is Under-supplied.
    }
}

```

## Recommended Mitigation Steps
To ensure that the `safeRewardTransfer()` function only executes when there is a positive reward balance, add the following require statement:
```solidity
   require(_rewardBalance > 0, "safeRewardTransfer: balance is zero");
```
