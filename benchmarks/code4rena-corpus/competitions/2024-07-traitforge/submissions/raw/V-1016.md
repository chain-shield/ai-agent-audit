# Vulnerability details

## Impact
An invariant of the game is for `forgeCounts` (the number of times a forge token can `breed` before becoming infertile) of forge NFTs to be reset in `_resetForgeCountsIfNeeded` after `oneYear`, this is hardcoded in storage to `365` days. This is also an low trust setter that can rug users, among other things.

## Proof of Concept
`setOneYear` in days is set to `1000` for example, there is not input validation to prevent this even though a year will never be more than 366 days(rounded, leap year)
owner sets `oneYearInDays` to `1000`


```solidity
function setOneYearInDays(uint256 value) external onlyOwner {
    oneYearInDays = value; @audit <= no input validation
  }
```

## Tools Used
Manual Review

## Recommended Mitigation Steps
add the following condition to the code 
`if(oneYearInDays > 366) revert MoreThanAYearError()`;

Invalid Validation
