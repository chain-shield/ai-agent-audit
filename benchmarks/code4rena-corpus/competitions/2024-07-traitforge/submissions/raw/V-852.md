# Vulnerability details

## Impact
The project has defined "Golden God" which is the most valuable entity. From the documentation,
``
There is a certain entropy, “999999” which is referred to as “the Golden God”, since it has perfect parameters and will exceed all other entities if played correctly. The Golden God is scanned for and is kept out of the first 2 passes, but is deliberately set in the final pass (at some random point). The Golden God should be the most valuable entity. 
``

As confirmed with the sponsor, the game requires to have one "Golden God" in each generation. However, due to inclusion of forged entity in generation count, it is very possible case that there may not be any "Golden God" in some generation. 


## Proof of Concept
* Let's assume 10000 entities are minted in first generation. 
* 3000 entities of second generation are minted via forging from two first generation entities.
* Due to this, only `7000` can be minted now in second generation. If `slotIndexSelectionPoint` for second generation is more than `(7000/13 = 539)`, then minting in second generation won't reach at that `slotIndexSelectionPoint` and no golden god entity will be minted in second generation.
