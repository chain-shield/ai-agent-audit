# Vulnerability details

## Impact
In the `TraitForgeNft` contract, there is no function available to call the `allowDaoFund` function of the `Airdrop` contract. Since only the `Owner` can call `allowDaoFund` and the `TraitForgeNft` contract is the owner of the `Airdrop` contract, this function remains inaccessible.

Without calling `allowDaoFund`, due to the logic in the `NukeFund` contract, no funds can be transferred to the `DAOFund` contract.
```javascript
    } else if (!airdropContract.daoFundAllowed()) {
      (bool success, ) = payable(owner()).call{ value: devShare }('');
      require(success, 'ETH send failed');
```

Also, as mentioned in the docs of the protocol, protocol will be transition to DAO-controlled game at a later date, `allowDaoFund` function cannot be called early on at the time of the deployment.

This prevents a critical feature of the protocol, which is transitioning from a developer-controlled to a DAO-controlled game. Consequently, the `DAOFund` contract cannot receive any funds, hindering the protocol's decentralization goal.

## Proof of Concept

Consider this scenario:

1. The `TraitForgeNft` contract is deployed and set as the owner of the `Airdrop` contract.
2. Protocol decides to transition to DAO-controlled game by starting the airdrop.
3. Owner attempts to call `allowDaoFund` but the transaction reverts.
4. No function in `TraitForgeNft` can call the `allowDaoFund` function in the `Airdrop` contract.
5. Attempts to transfer funds to the `DAOFund` contract fail due to the absence of the `allowDaoFund` call.
6. As a result, the game cannot transition from developer-controlled to DAO-controlled, and the `DAOFund` contract remains unfunded.

Foundry is used in the Proof of Concept (PoC). You can set up the Foundry environment by following the instructions provided here: https://hardhat.org/hardhat-runner/docs/advanced/hardhat-and-foundry

Copy the test file to run the test using: `forge test --match-test testnotdao -vv`

## Recommended Mitigation Steps
Add a function in the `TraitForgeNft` contract that allows it to call the `allowDaoFund` function in the `Airdrop` contract.
