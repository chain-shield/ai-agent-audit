# Vulnerability details

**Description**

As per the [GitBook](https://github.com/TraitForge/GitBook/blob/main/GamePlay/Generations.md#generations) and the [Whitepaper](https://docs.google.com/document/d/1pihtkKyyxobFWdaNU4YfAy56Q7WIMbFJjSHUAfRm6BA/edit#heading=h.56jevmqnri5f), the final entity price of the first generation should be `0.25 ETH`.

As per the communication with the sponsor the starting price of each NFT of each generation should be `0.005 ETH`
>ManPeach.0x: 0.005 across all gens

However the maximum value that [TraitForgeNft::calculateMintPrice](https://github.com/code-423n4/2024-07-traitforge/blob/279b2887e3d38bc219a05d332cbcb0655b2dc644/contracts/TraitForgeNft/TraitForgeNft.sol#L227) for 10_000th NFT of the first generation will be `0.2499755`, hence the final entity price for the first generation will be reached at the 10_001st NFT.

**Impact**

For the first 4 generations, with the current rates, the NukeFund will collect `0.000128` less than expected.

This number could increase, because as explained in the docs:
>Generation max mint price will increase as genreations progress, generations 1-4 are initaly set as seen below. Later generations are not currently set, as gens 1-4 will give feedback for game-play.

**Proof of Concepts**

```javascript
it('should give incorrect price for the 10_000th mint', async () => {
    const ADJUSTMENT = 1000;
    const PRECISION = 10000;
    const priceIncrement = 0.0000245
    const priceIncrementAdjusted = priceIncrement * ADJUSTMENT;

    const expectedPrice = 0.25;
    const startPrice = ethers.formatEther(await nft.startPrice());


    await nft.setPriceIncrement(ethers.parseEther(priceIncrementAdjusted.toString()));

    // The price of the first NFT should be the start price
    let price = ethers.formatEther(await nft.calculateMintPrice());
    expect(price).to.be.eq(startPrice);
    // Mint the 9000 NFTs (because of the ADJUSTMENT)
    for (let i = 0; i < 9; i++) {
      await nft.connect(owner).mintToken(merkleInfo.whitelist[0].proof, {
        value: ethers.parseEther('1'),
      });
    }

    // The price of the 10_000th NFT
    price = ethers.formatEther(await nft.calculateMintPrice());

    expect(price).not.to.be.eq(expectedPrice);

    // The differance should be the price increment
    expect((expectedPrice * PRECISION - price * PRECISION) / (PRECISION * ADJUSTMENT)).to.be.eq(priceIncrement);
  });
```

**Tools used**

VS code

**Recommended mitigation**

Adjust the documentation, or the starting price to be `startPrice + priceIncrement`.
