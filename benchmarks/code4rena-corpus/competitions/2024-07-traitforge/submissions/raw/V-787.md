# Vulnerability details


 

### Description
The root cause of this bug is an unbounded loop in the fetchListings function. The function iterates through all listings from 1 to listingCount without any upper limit.

### Impact
As the number of listings grows, the gas required to execute this function will increase. Eventually, it could exceed the block gas limit, making the function impossible to call.
 Loss of Functionality: Users rely on this function to fetch listings before forging multiple tokens. If they can't fetch listings, they can't use core features of the contract.
