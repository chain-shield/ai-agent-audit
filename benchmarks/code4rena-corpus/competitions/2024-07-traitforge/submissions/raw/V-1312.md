# Vulnerability details

## Impact
`EntropyGenerator::deriveTokenParameters` function counts different parameters. One of them is nukeFactor. It should be calculated as the entropy value divided by 40 accordingly to the docs. The entropy value has 6 digits. In the code, they divide entropy by 4000000 which will always truncate to zero
