# Vulnerability details

## Impact
Loss of opportunity for the users.

## Proof of Concept
As the initializeAlphaIndices is called every generation incremental, the values of slotIndexSelectionPoint and numberIndexSelectionPoint are modified each generation incremental. 
As the values of numberIndexSelectionPoint and slotIndexSelectionPoint can be defined as inferior to the currentSlotIndex and currentNumberIndex, the golden god could never be generated.

## Tools Used
Manual review

## Recommended Mitigation Steps
Add requirement about the values of numberIndexSelectionPoint and slotIndexSelectionPoint in the initializeAlphaIndices function.

require( currentSlotIndex  < numberIndexSelectionPoint )
require( currentNumberIndex < slotIndexSelectionPoint )

( Owner can call the mint function multiple times to finally bypass these requirements in case of initial failure)
