# Vulnerability details

## Details
- It is mentioned that there should be no Golden God in first two batches, but if in case a Golden God occurs the function should revert.
- But the check inside both `writeEntropyBatch1` and `writeEntropyBatch2` is not sufficient as it only checks for the value for a slot to not be `999999`. A uint256 number for a slot can contain `999999` anywhere multiple times as it has 78 digits, as a result of which Golden God will be possible multiple times in first 2 batches.
- For the number like `xxxx999999xxxxx` (x can be any 1-digit number). Here `999999` is present but this number is not equal to `999999`, therefore the check will fail and allow it to be set in the slot, thus allowing golden god.

## Impact
- Golden God can be present in the first 2 batches (but according to docs there should be no Golden God in first 2 batches), due to insufficient check for Golden God, and a larger number of people can have Golden God.

## Proof of Concept
The check present in both batch1 and batch2 generation function is:
```
require(pseudoRandomValue != 999999, 'Invalid value, retry.');
```
- Here, it allows values to be set to slot if they are not `999999`, but as a uint256 number have 78 digits therefore `999999` can be present in the number and the number not necessarily be `999999`
Example: 
Let pseudoRandomValue = `123456999999`, here the check will return true as `123456999999 != 999999` and this entropy will be added to the slot, as this number is not `999999`, but still Golden God (999999) is present in here which would be applied for the last entity of this slot.

- Thus, the check is not sufficient and allows multiple Golden God to exist in first 2 batches.

## Recommended Mitigation Steps
For every slot, check for all 13 entities represented by 6 digits in the whole uint256 number generated as below:
So, instead of the `require(pseudoRandomValue != 999999, 'Invalid value, retry.');`, add the below check:

```
for (uint256 j = 0; j <= 12; ++j) {
  uint256 position = j * 6;
  uint256 entropy = (pseudoRandomValue / (10 ** (72 - position))) % 1000000; 
  require(entropy != 999999, 'Invalid value, retry.');
}
```
