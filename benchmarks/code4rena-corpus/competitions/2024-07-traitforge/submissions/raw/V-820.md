# Vulnerability details

## Impact
`TraitForgeNft.mintWithBudget()` which was creatd for users to mint multiple tokens can get DOS'd very easily and be rendered useless forcing users to mint tokens singly.

## Proof of Concept
The vulnerability is found in this line of code that checks if `tokenId` is < `maxTokensPerGen`, 
` while (budgetLeft >= mintPrice && _tokenIds < maxTokensPerGen) {` and `maxTokensPerGen` is just 10,000 and there are 10 generations currently which can be increased so there is a high likelihood that after the first generation or even before the first generation is done minting considering `forging` also increases `tokenId`,  `TraitForgeNft.mintWithBudget()` a crucial function, is rendred useless and unaccessible for the entirerity of the contract life.
