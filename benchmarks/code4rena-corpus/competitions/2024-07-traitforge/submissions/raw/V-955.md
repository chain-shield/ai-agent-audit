# Vulnerability details

## Bug description
When NFT is minted while the airdrop has not yet started, the entropy of the NFT is recorded for the user in the airdrop contract.

[TraitForgeNft.sol#L296-L298](https://github.com/code-423n4/2024-07-traitforge/blob/279b2887e3d38bc219a05d332cbcb0655b2dc644/contracts/TraitForgeNft/TraitForgeNft.sol#L296-L298)
```solidity
if (!airdropContract.airdropStarted()) {
    airdropContract.addUserAmount(to, entropyValue);
}
```
[Airdrop.sol#L53-L54](https://github.com/code-423n4/2024-07-traitforge/blob/279b2887e3d38bc219a05d332cbcb0655b2dc644/contracts/Airdrop/Airdrop.sol#L53-L54)
```solidity
userInfo[user] += amount;
totalValue += amount;
```
Later when airdrop commences, this value will be used to determine the share of the airdrop a user is entitled to.

[Airdrop.sol#L71](https://github.com/code-423n4/2024-07-traitforge/blob/279b2887e3d38bc219a05d332cbcb0655b2dc644/contracts/Airdrop/Airdrop.sol#L71)
```solidity
uint256 amount = (totalTokenAmount * userInfo[msg.sender]) / totalValue;
```

When NFT is transferred from the user, this value in the airdrop contract is not updated and still belongs to the initial owner, which is evident from the `burn()` function of the `TraitForgeNft` contract.

[TraitForgeNft.sol#L146-L149](https://github.com/code-423n4/2024-07-traitforge/blob/279b2887e3d38bc219a05d332cbcb0655b2dc644/contracts/TraitForgeNft/TraitForgeNft.sol#L146-L149)
```solidity
if (!airdropContract.airdropStarted()) {
    uint256 entropy = getTokenEntropy(tokenId);
    airdropContract.subUserAmount(initialOwners[tokenId], entropy);
}
```
As can be seen, when the NFT is burnt, the value of its entropy is deducted from the initial owner of the NFT set during minting and not the actual owner of the NFT.

This is problematic because entropy is an inherent part of the NFT and it's something that makes it valuable. When NFT is transferred, the entropy itself is transferred with it, which comes in the form of NFT having a role, performance factor, etc (because all of those things come from entropy), therefore it's only logical that entropy recorded in the airdrop contract should also be transferred with the NFT.

## Impact
A valuable part of the NFT is not transferred with it.

## Recommended Mitigation
When NFT is transferred to a new user, also transfer its entropy recorded in the airdrop contract.
