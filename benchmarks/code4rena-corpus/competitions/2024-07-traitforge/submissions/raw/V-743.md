# Vulnerability details


## Vulnerability details
The documentation states that the best entity in the game should mature fully after 30 days(their nuke factor is 50%). However after checking the variables and calculations performed by the contract the estimated amount of days to mature is a lot longer. The variable is indeed mutable, but developers probably set the default variable to 250 thinking that it is the correct value, so it should be a valid finding

## Proof of Concept
Create a new test file paste the code below and run it. The calculateNukeFactor simulates the calculations that contract does when calculating entity nuke factor. Tests prove that even after 300 days the golden entity does not reach maturity

```
const { expect } = require('chai');
const { ethers } = require('hardhat');

function calculateNukeFactor(entropy: number, daysOld: number) {
  let initialNukeFactor = Math.floor(entropy / 40);
  const MAX_DENOMINATOR = 100000;
  let perfomanceFactor = entropy % 10;
  /// we omit the ageMultiplier because the sponsors stated that it will be removed and should be omitted when auditing
  let age = Math.floor((daysOld * perfomanceFactor * MAX_DENOMINATOR) / 365);
  let defaultNukeFactorIncrease = 250;

  let finalNukeFactor = Math.floor(
    (age * defaultNukeFactorIncrease) / MAX_DENOMINATOR
  );

  return finalNukeFactor;
}

describe('Test', () => {
  it('', async () => {
    //calculate nuke factor of golden god entity after 30 days
    const NukeFactor1 = calculateNukeFactor(999999, 30);

    expect(NukeFactor1).to.be.lt(BigInt(50000));

    //calculate nuke factor of golden god entity after 300 days
    const NukeFactor2 = calculateNukeFactor(999999, 300);

    expect(NukeFactor2).to.be.lt(BigInt(50000));

    // even after 300 days the Nuke factor is not greater than 50k proving that defaultNukeFactorIncrease is setup incorrectly
  });
});

```

## Impact
Users encounter unexpected calculations regarding their entities nuke factor, breaking the economy of the game and the core functionalites.

## Recommended Mitigation Steps
Change the default value of defaultNukeFactorIncrease to match desired maturity rate
