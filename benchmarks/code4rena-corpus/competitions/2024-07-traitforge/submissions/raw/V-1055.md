# Vulnerability details

## Impact
Impact: High, as this issue breaks a main invariant of the protocol, which is the maximum mint count of 10,000 entities per generation.

Likelihood: High, due to the frequent use of the forging functionality that can increase the entity count per generation beyond the set limit.

## Description
Entities can be minted through three functions: `mintToken()`, `mintWithBudget()`, and `forge()`.

There are two types of entities: Forger and Merger. Forger entities can be listed for forging, and Merger entities can be combined with listed Forger entities using the forge() function. The result of this process is a new entity from the next generation (Forger + Merger = New Entity from the next generation), incrementing the generation mint count by one.

A critical invariant of the protocol dictates that each generation should have a maximum of 10,000 entities. This limit is enforced by a private function `_incrementGeneration()`, which is invoked by `mintToken()` and `forge()` when the generation mint count reaches 10,000.

The problem arises when entities are forged from Gen1 to the next generation (e.g., 5 entities). When the limit of 10,000 entities per generation is reached, the `_incrementGeneration()` function is called. This function increments the generation (currentGeneration++) and incorrectly sets `generationMintCounts[currentGeneration]` to 0 instead of the actual count, which should be 5 in this example

```solidity
function _incrementGeneration() private {
    require( 
      generationMintCounts[currentGeneration] >= maxTokensPerGen, 
      'Generation limit not yet reached'
    );

 -->   generationMintCounts[currentGeneration] = 0;

```
Given that up to 1/3 of the total entities in a generation can be forged, this bug can lead to an increase in the entity count per generation by approximately 1/3. Consequently, instead of being limited to 10,000 entities per generation, the count could reach up to 13,333 entities, violating the primary invariant of the protocol.

        function generateMerkleTree(address[] memory addresses) public returns (bytes32[] memory) {

                    );
                }
                offset += n;
                n = n / 2;
            }
