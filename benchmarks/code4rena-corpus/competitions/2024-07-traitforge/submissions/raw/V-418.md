# Vulnerability details

## Impact

The contract cannot receive NFTs.

## Proof of Concept

EntityTrading.sol intends to accept NFTs. When a player calls `listNFTForSale()`, they will have to transfer their NFT in the contract.

```
  function listNFTForSale(
    uint256 tokenId,
    uint256 price
  ) public whenNotPaused nonReentrant {
    require(price > 0, 'Price must be greater than zero');
    require(
      nftContract.ownerOf(tokenId) == msg.sender,
      'Sender must be the NFT owner.'
    );
    require(
      nftContract.getApproved(tokenId) == address(this) ||
        nftContract.isApprovedForAll(msg.sender, address(this)),
      'Contract must be approved to transfer the NFT.'
    );

>   nftContract.transferFrom(msg.sender, address(this), tokenId); 
```

The contract does not have onERC721Received, which means it is unable to receive any NFTs.

## Tools Used

Manual Review

## Recommended Mitigation Steps

Import and inherit the IERC721Receiver.

```
import "@openzeppelin/contracts/token/ERC721/IERC721Receiver.sol";

    
    contract EntityTrading is IERC721Receiver, x, y, z {
```
