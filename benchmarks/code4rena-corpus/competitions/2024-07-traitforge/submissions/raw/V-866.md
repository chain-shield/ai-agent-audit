# Vulnerability details


### Impact
Users won't be able to fetch the forge listings as there is an unbounded for loop. This will lead to a loss of functionality for the users like forge multiple tokens. User will fetch the listings and then forge multiple tokens based on their needs. But the EntityForging::fetchListings function will not be able to fetch the listings because of the unbounded for loop consuming more gas than the block gas limit.
