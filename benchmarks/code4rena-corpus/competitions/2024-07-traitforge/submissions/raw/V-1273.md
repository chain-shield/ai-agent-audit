# Vulnerability details

## Impact
Users cannot return extra money that can be sent to the `EntityForging` contract via `forgeWithListed` function. The only amount of money that is distributed equals `forgingFee` amount. But the user can send more, and the function does not return what was sent above forgingFee amount

## Proof of Concept
https://github.com/code-423n4/2024-07-traitforge/blob/279b2887e3d38bc219a05d332cbcb0655b2dc644/contracts/EntityForging/EntityForging.sol#L146-L159

## Tools Used
Manual review

## Recommended Mitigation Steps
Add check - if `msg.value` is bigger than `forgingFee`, send `msg.value - forgingFee` back to the msg.sender
