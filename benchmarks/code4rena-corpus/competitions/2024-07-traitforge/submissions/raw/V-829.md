# Vulnerability details

## Impact
The `EntityTrading` and `NukeFund` contracts both lack mechanisms to revoke or reset token approvals after they are granted. This could potentially allow the contracts to transfer NFTs without the current intent of the token owner if they forget to revoke approvals directly through the NFT contract. The impact is low, as it doesn't result in direct fund loss **but could lead to unexpected transfers of valuable NFTs.**


## Proof of Concept

**EntityTrading**

In the `listNFTForSale` function of the `EntityTrading` contract, there's a check for token approval:

```solidity
require(
   nftContract.getApproved(tokenId) == address(this) ||
     nftContract.isApprovedForAll(msg.sender, address(this)),
   'Contract must be approved to transfer the NFT.'
 );
```

This check allows the listing operation to proceed if either a blanket approval for all tokens or a specific token approval is in place. 

However, there are two key issues:

1. Lingering Approvals: The contract does not provide a way to revoke these approvals within its own functions. There's no mechanism to reset or check for revoked approvals before subsequent transfer operations. For example, if a user grants approval and later wants to revoke it, they must do so through the NFT contract directly. If they forget to do this, the EntityTrading contract will still consider itself approved for future transfers.

2. Potential for Unauthorized Transfers: If the user does not revoke the approval after a transaction, the contract retains the ability to transfer the NFT, leading to possible unauthorized transfers if the contract is compromised or if there are bugs in the contract logic.

**NukeFund**
Inside the `nuke` function of the `NukeFund` contract, we have exactly the same issue.

```solidity
require(
   nftContract.getApproved(tokenId) == address(this) ||
     nftContract.isApprovedForAll(msg.sender, address(this)),
   'Contract must be approved to transfer the NFT.'
 );
```

## Tools Used

Manual review

## Recommended Mitigation Steps

Implement a function in both contracts that allows users to revoke approvals for their tokens. This function should interact with the NFT contract to remove the approvals, ensuring that the user can easily reset the permissions granted to the contracts.
