# Vulnerability details

## Impact
The `mintToken` and `mintWithBudget` functions in the TraitForgeNft smart contract calculate the mint price using the `startPrice` variable. However, this variable can be altered through the `setStartPrice` function during the execution of these minting functions. This inconsistency can lead to incorrect price calculation, unintended behavior, and potential financial loss.
## Proof of Concept
Consider the `mintToken` function starting its execution:
```solidity
uint256 mintPrice = calculateMintPrice();
```
During the execution of the function, if another transaction changes the value of `startPrice` using:
```solidity
function setStartPrice(uint256 _startPrice) external onlyOwner nonReentrant {  
    startPrice = _startPrice;  
}
```
The calculated mint price may be inconsistent with the expected logic, leading to unexpected behavior.
## Tools Used
Manual code review
## Recommended Mitigation Steps
Add `nonReentrant` Modifier:
Ensure that critical setter functions such as `setStartPrice`, `setPriceIncrement`, and other price-related functions have the `nonReentrant` modifier to prevent reentrancy issues.
```solidity
function setStartPrice(uint256 _startPrice) external onlyOwner nonReentrant {  
    startPrice = _startPrice;  
}
```
