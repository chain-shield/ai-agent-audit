# Vulnerability details

## Description
In the `TraitForgeNft` contract, the forge function is responsible for creating a new NFT entity by combining the entropies of two parent tokens. The new entity’s entropy is calculated as the average of the `forgerEntropy` and `mergerEntropy`. This approach can lead to potential collisions, where multiple entities may end up with the same entropy value.
## Impact
Since the new entropy is calculated as the average of two parent entropies, different pairs of parent tokens could result in the same entropy value. This reduces the uniqueness of the newly forged entities.

## Recommended Mitigation Steps
Implement a mapping to ensure each entropy value is unique, such as `mapping(uint256 => uint256) public entropyToTokenId;`. Before assigning a new entropy value, check that the new entropy is not assigned to other token to avoid collisions.
