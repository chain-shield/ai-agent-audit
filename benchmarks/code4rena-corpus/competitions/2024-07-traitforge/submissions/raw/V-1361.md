# Vulnerability details

## Impact
When users send more money than required for operations the established operation was to refund the excess funds back to the user, or don't allow excess funds to be sent to the contract, but in `forgeWithListed` it does not follow this, infact the implementation does not use the msg.value to calculate nukeFundFee and forger fee and it allows excess funds to be sent to the contract, which will cause loss of funds for users
