# Vulnerability details

## Impact
TraitForge contracts inherit OpenZeppelin's Pausable contract and implements the `whenNotPaused` modifier on critical functions, but doesn't implement any method to actually pause or unpause the contract. The `Pausable.sol` contract (even in this version of OZ which is used in this contract) only implements internal functions, which requires external or public functions to be triggered to wrap them. Since nothing like this has been implemented, the entire pausing system is rendered useless and staking cannot be paused as is intended.

## Proof of Concept
Once the contracts are deployed, then the critical functions can not be paused in emergency, leaving them unprotected during this situation. The `whenNotPaused` modifier couldn't be changed in the future.

This issue is also explained inside the OZ's Pausable contract:
```Solidity
 /**
 * @dev Contract module which allows children to implement an emergency stop
 * mechanism that can be triggered by an authorized account.
 *
 * This module is used through inheritance. It will make available the
 * modifiers `whenNotPaused` and `whenPaused`, which can be applied to
 * the functions of your contract. Note that they will not be pausable by
 * simply including this module, only once the modifiers are put in place.
 */
```
