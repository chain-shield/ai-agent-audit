# Vulnerability details

## Description
There is a bug in `TraitForgeNft::_distributeFunds` when the contract is minting. 100% of the minting fees goes to the Nuke Fund but there are scenarios where this might not be set which will essentially burn this value (as sending it to address(0)), which is unexpected and seems to warrant `Medium` severity. This would usually be High severity, but since this is fully controlled by the owner, severity is reduced. 

The root cause is due to the fact that `_distributeFunds` is simply not checking if Nuke Fund contract has been set or not. So the contract could be deployed with empty contract or without calling `setNukeFundContract` or the owner could actually call it with address(0) and those would results in the problematics scenarios.

```solidity
  // distributes funds to nukeFund contract, where its then distrubted 10% dev 90% nukeFund
  function _distributeFunds(uint256 totalAmount) private {
    require(address(this).balance >= totalAmount, 'Insufficient balance');

    (bool success, ) = nukeFundAddress.call{ value: totalAmount }(''); // <-----------------------------
    require(success, 'ETH send failed');

    emit FundsDistributedToNukeFund(nukeFundAddress, totalAmount);
  }
```  

## Impact
Protocol would incur a `fund loss` when there is minting activities and nuke fund contract is not set as the minting fee will be `burned` instead of being sent to Nuke fund contract.

## PoC
This is `very similar` to my other PoC issue `Forging when nuke contract is not set will cause the dev cut to be burned`, so the proof has been proven in that other issue, there is no difference here, the funds would be sent to address(0), so burned.

## Tools Used
Manual review, Hardhat test

## Recommended Mitigation Steps
Apply the following protection to be safe.

```diff
  // distributes funds to nukeFund contract, where its then distrubted 10% dev 90% nukeFund
  function _distributeFunds(uint256 totalAmount) private {
    require(address(this).balance >= totalAmount, 'Insufficient balance');
+   require(nukeFundAddress != address(0), 'Nuke Fund not set');

    (bool success, ) = nukeFundAddress.call{ value: totalAmount }('');
    require(success, 'ETH send failed');

    emit FundsDistributedToNukeFund(nukeFundAddress, totalAmount);
  }

```
