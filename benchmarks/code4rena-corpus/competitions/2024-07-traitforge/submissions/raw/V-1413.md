# Vulnerability details

## Impact
Call to re-initialise Alpha indices on `EntrioyGenerator` by `TraitForgeNFT` will fail as calling contract is not authorised to access the given function, `initializeAlphaIndices()`

## Proof of Concept
`initializeAlphaIndices()` is an public function in `EntropyGenerator.sol` that is restricted to `onlyOwner` modifier.

```solidity
  function initializeAlphaIndices() public whenNotPaused onlyOwner {
    uint256 hashValue = uint256(
      keccak256(abi.encodePacked(blockhash(block.number - 1), block.timestamp))
    );

    uint256 slotIndexSelection = (hashValue % 258) + 512;
    uint256 numberIndexSelection = hashValue % 13;

    slotIndexSelectionPoint = slotIndexSelection;
    numberIndexSelectionPoint = numberIndexSelection;
  }
```
The contract has a special modifier that is set in place for functions that can be called only by the `TraitForgeNFT` contract:

```solidity
  modifier onlyAllowedCaller() {
    require(msg.sender == allowedCaller, 'Caller is not allowed');
    _;
  }
```

Now, instead of using that modifier, `onlyOwner` modifier is used for `initializeAlphaIndices()` function, causing the execution to be reverted in case `TraitForgeNft.sol` contract calls it when increasing generation and wanting to re-initialise Alpha indices on `EntropyGenerator`

## Recommended Mitigation Steps
Change the modifier from `onlyOwner` to `onlyAllowedCaller` for the `initializeAlphaIndices()` function in `EntropyGenerator.sol` at line `206`.
