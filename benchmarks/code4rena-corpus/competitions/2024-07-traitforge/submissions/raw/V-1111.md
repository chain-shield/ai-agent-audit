# Vulnerability details

## Impact

The protocol cannot be paused and the core functionalities of the protocol cannot be stopped. This means that if there is a bug in the protocol, it cannot be stopped and the bug can be exploited by the attacker.

## Proof of Concept

The following contracts inherit OpenZeppelin's `Pausable`, but do not implement pause/unpause functions:

- TraitForgeNft
- EntityForging
- EntityTrading
- DevFund
- EntropyGenerator
- NukeFund 


Multiple critical functions use the `whenNotPaused` modifier or check `!paused()`, including:

```solidity
  function burn(uint256 tokenId) external whenNotPaused nonReentrant {
        ...
  }
```

## Tools Used

## Recommended Mitigation Steps

Implement `pause()` and `unpause()` functions in all relevant contracts:

```solidity
  function pause() public onlyOwner {
    _pause();
  }

  function unpause() public onlyOwner {
    _unpause();
  }

```
