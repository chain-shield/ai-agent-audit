# Vulnerability details

## Description
The `EntityTrading` contract allows users to buy and sell ERC721 tokens (NFTs) through a listing mechanism. When a user buys an NFT using the `buyNFT()` function, the contract transfers the NFT from itself to the buyer using the `transferFrom()` function of the ERC721 token contract: [#Line 81](https://github.com/code-423n4/2024-07-traitforge/blob/279b2887e3d38bc219a05d332cbcb0655b2dc644/contracts/EntityTrading/EntityTrading.sol#L81)

```solidity
nftContract.transferFrom(address(this), msg.sender, tokenId); // transfer NFT to the buyer
```

However, using `transferFrom()` instead of `safeTransferFrom()` can be problematic. The `transferFrom()` function does not ensure that the recipient is capable of receiving ERC721 tokens. If the recipient is a contract that doesn't implement the necessary ERC721 receiver function (`onERC721Received()`), the token transfer will fail silently, and the token may get stuck in the contract.

This issue is not limited to the `buyNFT()` function. The `EntityTrading` contract uses `transferFrom()` in multiple places: [#Line 53](https://github.com/code-423n4/2024-07-traitforge/blob/279b2887e3d38bc219a05d332cbcb0655b2dc644/contracts/EntityTrading/EntityTrading.sol#L53)

```solidity
nftContract.transferFrom(msg.sender, address(this), tokenId); // transfer NFT to contract
nftContract.transferFrom(address(this), msg.sender, tokenId); // transfer the NFT back to seller
```

If a user accidentally (or maliciously) interacts with the contract using an incompatible contract as the recipient, the NFTs involved in these transactions could be permanently lost.

## Impact

NFTs bought or sold through the `EntityTrading` contract may become permanently stuck if the recipient is a contract that doesn't support ERC721 tokens.

## Proof of Concept

1. Alice lists an NFT for sale on the `EntityTrading` contract.
2. Bob, using a contract that doesn't implement `onERC721Received()`, calls `buyNFT()` to purchase Alice's NFT.
3. The `transferFrom()` call in `buyNFT()` fails silently because Bob's contract can't receive ERC721 tokens.
4. Alice's NFT is now stuck in the `EntityTrading` contract and cannot be recovered.

## Tools Used

Manual review

## Recommended Mitigation Steps

Replace all instances of `transferFrom()` with `safeTransferFrom()` when transferring ERC721 tokens:

```solidity
- nftContract.transferFrom(msg.sender, address(this), tokenId);
+ nftContract.safeTransferFrom(msg.sender, address(this), tokenId);

- nftContract.transferFrom(address(this), msg.sender, tokenId);
+ nftContract.safeTransferFrom(address(this), msg.sender, tokenId);
```
