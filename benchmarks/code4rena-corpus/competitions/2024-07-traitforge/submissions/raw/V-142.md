# Vulnerability details

## Impact
The Golden God entropy is assigned to a certain slot in function `EntropyGenerator::initializeAlphaIndices`. Regardless of the actual value assigned to that slot during the batch write process, it will be considered the perfect value. To ensure the perfect entropy is not granted to another user during each batch write, the following check is added:

```javascript
require(pseudoRandomValue != 999999, "Invalid value, retry.");
```

This is added in the first and second batch while in the third is removed, which should not be if the check were to be correctly implemented as no other slot than the one calculated via `initializeAlphaIndices` should be assigned the Golden God. 

The validation is incorrect because the entropy slots are 78 digits numbers while the check is performed against a 6 digits number, therefore unless the Golden God is in the last 6 digits of the entropy slot and the rest are 0, the pseudorandom value will not be rejected. 
## Proof of Concept

This can be simply checked running the following on Chisel:

```javascript
➜ uint256 entropySlotValue = 999999999999999999999999999999999999;
➜ if (entropySlotValue != 999999) revert("Incorrect Validation");
```


The value stored in `entropySlotValue` will result in 6 Golden Gods granted to different users and it will not be rejected as it is different from 999999.

## Recommended Mitigation Steps
Checking each slot's index in a for loop to find the perfect number would be gas-intensive, since minting the Golden God is a rare scenario, the checks can be removed for simplicity. 

To ensure only one Golden God per generation without uncertainty, the entropy for users with the Golden God at a different index than the one calculated via `initializeAlphaIndices` can be recalculated based on the slot and number index, ensuring it is always less than 999999.

For example you could add the following in function `EntropyGenerator::getEntropy`:

```javascript
if (paddedEntropy == 999999)
    return
        uint256(keccak256(abi.encode(slotIndex, numberIndex))) % 999999;
```
