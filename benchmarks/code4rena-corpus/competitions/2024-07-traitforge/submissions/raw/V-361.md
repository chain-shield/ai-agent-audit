# Vulnerability details

## Impact
The current protocol unfairly disadvantages users with NFTs that have a `zero forgePotential`. These NFTs cannot participate as either `forgers` or `mergers`, limiting their utility and value.

## Proof of Concept
**Forge Potential Calculation**: 
The [`5th` digit of the `entropy`](https://github.com/code-423n4/2024-07-traitforge/blob/279b2887e3d38bc219a05d332cbcb0655b2dc644/contracts/EntityForging/EntityForging.sol#L86) determines the `forgePotential`. 
```solidity
uint8 forgePotential = uint8((entropy / 10) % 10); // Extract the 5th digit from the entropy
```
If this digit is `zero`, the NFT has `zero forgePotential`.

**Role Determination**:
1. [`Forgers`](https://github.com/code-423n4/2024-07-traitforge/blob/279b2887e3d38bc219a05d332cbcb0655b2dc644/contracts/EntityForging/EntityForging.sol#L92): NFTs with `entropy` divisible by `3`.
```solidity
bool isForger = (entropy % 3) == 0; // Determine if the token is a forger based on entropy
```
2. [`Mergers`](https://github.com/code-423n4/2024-07-traitforge/blob/279b2887e3d38bc219a05d332cbcb0655b2dc644/contracts/EntityForging/EntityForging.sol#L137): NFTs with `entropy` not divisible by `3`.
```solidity
require(mergerEntropy % 3 != 0, 'Not merger');
```

**Issue**: 
NFTs with `zero forgePotential` cannot be `forgers` or `mergers`, rendering them useless in the `forging` process.

1. *[User Disadvantage](https://github.com/code-423n4/2024-07-traitforge/blob/279b2887e3d38bc219a05d332cbcb0655b2dc644/contracts/EntityForging/EntityForging.sol#L87-L90)*: Owners of zero forge potential NFTs cannot participate in `forging`.
```solidity
require(
      forgePotential > 0 && forgingCounts[tokenId] <= forgePotential,
    );
```
They therefore miss out on `potential earnings` e.g `forgerShare` for `forgers` and new NFTs of higher generation for `mergers`.

2. *Market Value*: Zero forge potential NFTs may have significantly lower `market value` due to their limited utility. Chances of other users buying these NFTs if listed for sale will be really low.

## Tools Used
Manual Review

## Recommended Mitigation Steps
- Ensure all NFTs have a minimum forge potential greater than zero.
- Modify the entropy-based calculation to guarantee a non-zero 5th digit.
