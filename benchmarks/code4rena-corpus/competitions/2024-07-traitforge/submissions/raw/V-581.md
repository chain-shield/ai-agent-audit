# Vulnerability details

## Impact
After listing a nft for forging, if the nft is listed for sale, then nft will not be forged and nft owner will not get forging fees i.e users can’t both sell or forge a nft together which is unfair.

## Proof of Concept
1. Let’s assume, Alice has a forger role tokenid nft.

2. Alice lists the nft for forging by calling the function listForForging.

3. Then Alice lists the nft for sale by calling the  function listNFTForSale.

4. When  function listNFTForSale is called,the nft is transferred from alice to EntityTrading contract by transferFrom function which calls function _beforeTokenTransfer before transferring the nft. In function _beforeTokenTransfer, the nft’s listingforforging is cancelled as the tokenid is transferred from one to another address.

5. Now Alice can’t list for forging for this tokenid. If no one buys the nft of alice, then alice will not get benefit from both sides i.e alice will not get forging fees and also no one buys the nft.

## Tools Used
manual review
## Recommended Mitigation Steps
Implement a mechanism so that users can sell and forge a nft at the same time.
