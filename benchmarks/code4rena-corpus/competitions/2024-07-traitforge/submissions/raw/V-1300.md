# Vulnerability details

## Description
The contract initializes entropy in batches but lacks a mechanism to ensure that all batches are fully initialized before `getNextEntropy()` is called. This oversight could lead to issues with entropy retrieval.

## Impact
If `getNextEntropy()` is invoked before complete initialization:

1.Uninitialized Values: The function may return values that are still zero or uninitialized.
2.Predictable Traits: This could lead to predictable or biased NFT traits.
3.Unexpected Behavior: It may cause erratic behavior in TraitForge's game mechanics.

## Proof of Concept
```
function getNextEntropy() public onlyAllowedCaller returns (uint256) {
    // No check if initialization is complete
    uint256 entropy = getEntropy(currentSlotIndex, currentNumberIndex);
    // ... rest of the function
}
```

## Tools Used
Manual review

## Recommended Mitigation Steps
1.Introduce Initialization Flag:
Add a boolean flag `isInitialized` that is set to `true` only after all batches are initialized.
2.Update `getNextEntropy()` to Check Initialization:
```
require(isInitialized, "Entropy not fully initialized");
```
3.Add Initialization Completion Function:
Implement a function to verify and finalize initialization if needed before allowing entropy retrieval.
