# Vulnerability details

## Impact
One of the core features of TraitForge is the pseudo-random generation of NFTs ad their traits. As it turns out, these traits are predictable before minting, allowing an attacker to simulate the NFT minting locally and maximizing the value of their minted NFTs by carefully timing their minting.

## Proof of Concept
The entropy value of each token in generated by [EntropyGenerator.getNextEntropy](https://github.com/code-423n4/2024-07-traitforge/blob/279b2887e3d38bc219a05d332cbcb0655b2dc644/contracts/EntropyGenerator/EntropyGenerator.sol#L100-L120) calling [EntropyGenerator.getEntropy](https://github.com/code-423n4/2024-07-traitforge/blob/279b2887e3d38bc219a05d332cbcb0655b2dc644/contracts/EntropyGenerator/EntropyGenerator.sol#L163-L185). While fairly complex, it is predictable. The returned entropy value is calculated based on the following values, which if known by an attacker would allow them to predict the next values:
- currentNumberIndex
- currentSlotIndex
- entropySlots

All of these values are known. These state variables are declared private, but as with any smart contract deployed to a public blockchain this merely means that the compiler will not create a getter function.

These values can be obtained by anyone in two different ways. Firstly, by inspecting the `EntropyGenerator`'s storage. Since the contract's code is public, deploying it and debugging it locally to obtain the storage layout is trivial.
Secondly, by monitoring all transactions calling the `EntropyGenerator` contract and keeping track of the counters and the `writeEntropyBatch*` calldata.

Unreleased AI tool

## Recommended Mitigation Steps
Use a secure and unpredictable method for entropy generation, such as Chainlink VRF or a similar oracle-based solution. Alternatively, one could implement a commit-reveal scheme, forcing the user to commit to some seed value, but delaying the minting by at least one block time, incorporating data from the latest block that the user could not have predicted at the time they were committing.
