# Vulnerability details

## Impact
No function can be paused when needed.

## Proof of Concept
Even though most functions implement the whenNotPaused modifier, there is no way to actually pause the functions. Openzeppelin's pausable has only internal functions to pause, and without any external functions implemented to call these internal functions, it is impossible to pause any function. Thus, the entire pausing system is useless as of now and can't be paused as intended.

## Tools Used
Manual Review

## Recommended Mitigation Steps
Add simple external functions to call the _pause and _unpause functions of Openzeppelin.

`// Pause external`
`function pause() external onlyOwner {`
    `_pause();`
`}`

`// Unpause external`
`function unpause() external onlyOwner {`
    `_unpause();`
`}`
