# Vulnerability details

The following contracts, `DevFund`, `EntityForging`, `EntityTrading`, `EntropyGenerator`, `NukeFund`, and `TraitForgeNft`, are pausable contracts. Some important functions in these contracts use the `whenNotPaused` modifier. However, these contracts have not implemented external `pause/unpause` functionalities, which call the internal `_pause()`/`_unpause()` functions from `Pausable.sol`. This omission means these contracts cannot actually be paused.

## Impact

The inability to pause these contracts means that, in the event of an emergency or a discovered vulnerability, there is no way to halt critical functions. This could lead to the potential exploitation of the contract, resulting in financial loss or other adverse outcomes.

## Proof of Concept
These contracts are designed to be pausable, as indicated by the use of the `whenNotPaused` modifier on critical functions. This modifier ensures that these functions can only be executed when the contract is not paused. The pausable functionality is typically provided by inheriting from `Pausable.sol` and using the internal `_pause()` and `_unpause()` functions to change the paused state of the contract.

However, these contracts lack the external functions to invoke `_pause()` and `_unpause()`. As a result, there is no way to pause or unpause the contracts externally, rendering the pausable functionality ineffective.

## Recommended Mitigation Steps
Implement external functions in each contract to allow authorized accounts to pause and unpause the contract. These functions should call the internal `_pause()` and `_unpause()` functions from `Pausable.sol`. 

Example implementation:

```diff
+    function pause() external onlyOwner{
+        _pause();
+    }

+    function unpause() external onlyOwner{
+        _unpause();
+    }
```
