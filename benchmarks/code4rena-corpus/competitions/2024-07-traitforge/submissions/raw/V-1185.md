# Vulnerability details

## Impact
The current implementation allows initial owners of NFTs to continue receiving airdrops even after they have transferred ownership of the NFT through a `transferFrom` call or via trading in the `EntityTrading` contract. This behavior is unintended, as the airdrop should be received only by the current owner of the NFT, not the original minter.

The `userInfo` variable in the `Airdrop` contract tracks claimable users. It adds new users when the NFT is minted via the `forge`, `mintToken`, or `mintWithBudget` functions of the `TraitForgeNft` contract. It also removes users who burn their NFT via the `burn` function of the `TraitForgeNft` contract or the `nuke` function of the `NukeFund` contract. However, when an NFT changes ownership through trading using the `EntityTrading` contract or other markets, the `userInfo` variable remains unchanged. As a result, the initial owner can still claim the airdrop even after losing ownership of the NFT.

Airdrops are generally intended to reward current token holders. If initial owners continue to receive airdrops after transferring or trading their NFTs, it compromises the fairness of the reward system and could lead to unintended distribution problems.

## Recommended Mitigation Steps
Update `userInfo` variable whenver a transfer of NFT takes place by adding these lines in `_beforeTokenTransfer` function of `TraitForgeNft` contract:
```javascript
  function _beforeTokenTransfer(
    address from,
    address to,
    uint256 firstTokenId,
    uint256 batchSize
  ) internal virtual override {
    super._beforeTokenTransfer(from, to, firstTokenId, batchSize);
    if (!airdropContract.airdropStarted()) {
      if (from == address(entityTrading)) airdropContract.addUserAmount(to, getTokenEntropy(firstTokenId));
      else if (to == address(entityTrading)) airdropContract.subUserAmount(from, getTokenEntropy(firstTokenId));
      else {
        airdropContract.subUserAmount(from, getTokenEntropy(firstTokenId));
        airdropContract.addUserAmount(to, getTokenEntropy(firstTokenId));
      }
    }
```
