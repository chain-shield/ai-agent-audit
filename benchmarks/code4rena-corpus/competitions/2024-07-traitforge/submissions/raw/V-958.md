# Vulnerability details

 ### Title: EntityForging::fetchListings Block gas outrage leading to denial of service due to unbounded loop

### Impact
Before users start to forge a new entity with merger and forger, they will first fetch the listing from the fetchListing function,  but now this fetchListings() function have unbounded loop which in future will cause too much gas blockage, players   will be unable to fetch forge listings due to an unbounded for loop in the EntityForging::fetchListings function. This can result in the function consuming more gas than the block gas limit, leading to a denial of service.

### Proof of Concept
```solidity
    function fetchListings() external view returns (Listing[] memory _listings) {
        _listings = new Listing[](listingCount + 1);
@>      for (uint256 i = 1; i <= listingCount; ++i) {
            _listings[i] = listings[i];
        }
    }
```
