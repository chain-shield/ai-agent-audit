# Vulnerability details

## Impact

An issue exists where the "The Golden God" entropy value (999,999) might be inadvertently excluded from a specific generation. This could alter the intended rarity and value distribution within the game mechanics, potentially affecting user motivation to mint NFTs from that generation.

## Proof of Concept

1. **Entropy Generation Misalignment:** The `maxSlotIndex` and `currentNumberIndex` configuration generates 10,010 entropies (770 x 13) as opposed to the intended 10,000 for a generation.
2. **Excess Entropy Generation:** This results in the `getNextEntropy` function providing 10,010 entropies before resetting to a new generation instead of the expected 10,000.
3. **"The Golden God" Exclusion:** The `initializeAlphaIndices` function assigns the slot for the "The Golden God" value (999,999) potentially beyond the 10,000th index of the `entropySlots` array.
4. **Misplaced Storage:** If the chosen slot falls within the last 10 indices (10,001 to 10,010), the "The Golden God" value gets stored for the following generation, effectively excluding it from the current one.


The discrepancy between the number of generated entropies (10,010) and the intended generation size (10,000) combined with the storage location selection for the "The Golden God" value leads to its potential omission from a generation.

## Tools Used
Manual review

## Recommended Mitigation Steps
**Adjust Slot Selection:** Refine the `initializeAlphaIndices` function to ensure the slot chosen for "The Golden God" value falls within the valid range for the current generation (maximum of 10,000 index).

By implementing this recommendations, the "The Golden God" entropy value gets correctly included in each generation, maintaining the intended rarity and value distribution within the game's mechanics.
