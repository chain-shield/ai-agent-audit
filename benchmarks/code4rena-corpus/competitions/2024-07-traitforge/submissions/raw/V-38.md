# Vulnerability details

## Impact
The `initializeAlphaIndices` function in the `EntropyGenerator` contract is designed to set specific indices within the entropy array for generating special entropy values. However, the current way of calculating the uint256 variables - `slotIndexSelection` and `numberIndexSelection` is not truly random. They use the `uint256 hashValue` variable which is generated using the global variables `block.number` and `block.timestamp` which are not truly random at all. The way `hashValue` is calculated is public and anyone can easily compute the indices. Also miners could manipulate the values ​​of `block.number` and `block.timestamp` because they can order the transactions of the blockchain.
