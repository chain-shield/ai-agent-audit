# Vulnerability details

## Description
There is a major bug in `all the six contracts in scope` which prevent the contracts to be paused which seems to warrant `High` as breaking a key emergency measure. 

The root cause is due to the fact that the contracts (DevFund, EntityForging, EntityTrading, EntropyGenerator, NukeFund, TraitForgeNft) while they inherits `OZ Pausable` they don't call `_pause/_unpause`, so they can't be paused.

## Impact
Owner will not be able to pause any contracts in scope.

## PoC
I can't really add any PoC due to the simplicity of this report.

## Tools Used
Manual review

## Recommended Mitigation Steps
`Every contract will need something like the following` to be able to pause the contracts.

```solidity
  function pause() external onlyOwner {
    _pause();
  }

  function unpause() external onlyOwner {
    _unpause();
  }
```
