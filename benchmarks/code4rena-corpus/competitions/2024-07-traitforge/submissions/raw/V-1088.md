# Vulnerability details

## Description of Issue
The contract initializes entropy in batches, but there's no check to ensure all batches are initialized before getNextEntropy() can be called.

## Impact
If `getNextEntropy()` is called before full initialization:

1. It could return uninitialized (zero) values.
2. This could lead to predictable or biased NFT traits.
3. It might cause unexpected behavior in the TraitForge game mechanics.

## Proof of Concept
```
function getNextEntropy() public onlyAllowedCaller returns (uint256) {
    // No check if initialization is complete
    uint256 entropy = getEntropy(currentSlotIndex, currentNumberIndex);
    // ... rest of the function
}
```

## Tools Used

## Recommended Mitigation Steps
1. Add a boolean flag isInitialized that is set to true only after all batches are initialized.
2. Modify getNextEntropy() to check this flag:
```
require(isInitialized, "Entropy not fully initialized");
```

3. Implement a function to check and complete initialization if needed before allowing entropy retrieval.
