# Vulnerability details

Using block.number and block.timestamp together creates a predictable final number. A predictable number is not a good random number. Malicious users can manipulate these values to choose the correct moment for minting with 'The Golden God' entropy.

## Impact
Any user can predict the exact moment to mint with 'The Golden God' entropy since the weak randomization logic.

## Proof of Concept

The issue starts from this function:
https://github.com/code-423n4/2024-07-traitforge/blob/279b2887e3d38bc219a05d332cbcb0655b2dc644/contracts/EntropyGenerator/EntropyGenerator.sol#L206-L216

Since the randomness of those two variables is weak attacker is able to wait for the right time to mint.
