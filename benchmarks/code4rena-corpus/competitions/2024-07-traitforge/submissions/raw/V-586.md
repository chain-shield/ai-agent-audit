# Vulnerability details

## Impact
The _incrementGeneration() always reverting would cause the entire game to stop after the first generation.

## Proof of Concept
The _incrementGeneration() function calls the initializeAlphaIndices() function at line 353 which is access controlled to be called only by the deployer of the EntropyGenerator contract 
(https://github.com/code-423n4/2024-07-traitforge/blob/279b2887e3d38bc219a05d332cbcb0655b2dc644/contracts/EntropyGenerator/EntropyGenerator.sol#L206-L217)

This would cause the _incrementGeneration() function to always revert (since TraitForgeNft.sol cannot be the owner of the EntropyGenerator contract).

## Tools Used
Manual Review

## Recommended Mitigation Steps
Change the initializeAlphaIndices function as follows:
`function initializeAlphaIndices() public whenNotPaused { // remove the onlyOwner modifier`
    `require(msg.sender == allowedCaller || msg.sender == _owner, "Call not Authorized"); // add access control check here`
` // rest of the function`
`}`
