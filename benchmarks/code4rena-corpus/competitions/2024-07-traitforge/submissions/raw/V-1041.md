# Vulnerability details

## Impact
`fetchListing` is an array that returns the Forge NFTs listed in the EntityForgingContract, the function will DOS and eventually hit the base blockchain gas Limit due to the fact that, `cancelListing` doesn't reduce `listingCount` even when a listing is cancelled. and there is no restriction on how long NFTs can be listed, taking into account the fact that there are 10,000 TraitForgeNFTs in the contract.

## Proof of Concept
user can list their forge NFT using the `listForForging` with no obligation to cancel/delist, and even when they cancel, the listing count remains the same, making sure that the `fetchListing`  loop length only increases.

```solidity 
  function fetchListings() external view returns (Listing[] memory _listings) {
    _listings = new Listing[](listingCount + 1);
    for (uint256 i = 1; i <= listingCount; ++i) {
      _listings[i] = listings[i];
    }
  }
```

## Tools Used
Manual Review

## Recommended Mitigation Steps
add a constraint or a mechanism to cancel after a while, to reduce gas required to fetchListings.
