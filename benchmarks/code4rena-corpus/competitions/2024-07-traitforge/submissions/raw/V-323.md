# Vulnerability details

According to Natspec:
"*There is a certain entropy, “999999” which is referred to as “the Golden God”, since it has perfect parameters and will exceed all other entities if played correctly.*"

Although the index values are calculated randomly, the values can be determined beforehand by the attacker & mint the golden rod nft. 

## Proof of Concept

The main issue occurs because its easy for an attacker to keep track when the `slotIndexSelectionPoint` & `numberIndexSelectionPoint` are changed.

As per the docs:
"*The Golden God entropies' position changes every generation.*"

```solidity
File: TraitForgeNft.sol

    function _incrementGeneration() private {
    ...
>    entropyGenerator.initializeAlphaIndices();
```
For the 1st generation, the attacker only needs to know when the contract was initialized because `initializeAlphaIndices()` is called in the constructor.
```solidity
File: EntropyGenerator.sol

  constructor(address _traitForgetNft) {
    allowedCaller = _traitForgetNft;
    initializeAlphaIndices();
  }
```
For the rest of the generations, the attacker just needs to keep track when the generation was incremented.

## Impact
Attacker can front runs & obtains the golden rod nft for every generation.

## Tools Used
Manual Review

## Recommended Mitigation Steps
`initializeAlphaIndices()` should be called at random intervals rather than only being changed after every generation increment.
