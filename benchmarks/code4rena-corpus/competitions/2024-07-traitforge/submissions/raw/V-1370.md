# Vulnerability details

## Impact
The constructor parameter _traitForgetNft is not validated, potentially allowing an invalid address to be set.

## Proof of Concept

constructor(address _traitForgetNft) {
    allowedCaller = _traitForgetNft;
    initializeAlphaIndices();
}


## Tools Used
Slither

## Recommended Mitigation Steps

Add a validation check for the address parameter in the constructor.

constructor(address _traitForgetNft) {
    require(_traitForgetNft != address(0), "Invalid address");
    allowedCaller = _traitForgetNft;
    initializeAlphaIndices();
}

Invalid Validation
