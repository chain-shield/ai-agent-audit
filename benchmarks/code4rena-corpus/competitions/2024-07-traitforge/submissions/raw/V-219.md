# Vulnerability details

## Impact

`TraitForgeNft::mintToken` and `TraitForgeNft::mintWithBudget` can be front-ran and all NFTs with more favourable traits can be minted by malicious actors while leaving NFTs with less favourable traits to other users, allowing them a bigger share at the Nuke Fund.

## Proof of Concept
Each NFT is assigned an entropy. Entropy determines the traits of the NFT. Based on the entropy value, a user is allocated a share in the Nuke Fund.
Since this entropy value is fetched from the storage slots which are public, any malicious user can read the favourable entropy values and front-run any mint transactions to these specific NFTs.

## Tools Used
Manual Review

## Recommended Mitigation Steps

Supplement bit stuffing with Chainlink VRF to randomise entropy and make it unpredictable.
