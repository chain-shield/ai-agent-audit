# Vulnerability details

## Impact

As _tokenIds will become greater than maxTokensPerGen after the 1st generation so the  function mintWithBudget will revert after the 1st generation.


## Proof of Concept
1. Let’s assume, currently currentGeneration = 1;

2. Private variable _tokenIds is incremented by 1 when   function _mintInternal/function _mintNewEntity is called i.e when a new  tokenId is created.

3. Now, after 1st generation, _tokenIds value become 10010(  extra 10 is minted through _mintNewEntity)

4. Now  function mintWithBudget is called, see the code,  while (budgetLeft >= mintPrice && _tokenIds < maxTokensPerGen), as _tokenIds i.e 10010 is greater than 10000(maxTokensPerGen) , so the function mintWithBudget will not mint new tokenid which is unexpected.

## Tools Used
manual review 
## Recommended Mitigation Steps
Multiply maxTokensPerGen with maxGeneration i.e 10000*10.

 _tokenIds< 10000*10 = 100000
