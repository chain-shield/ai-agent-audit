# Vulnerability details

## Impact
According to the docs, the amount expected of eth to get from gen 1 is 1,275 ETH. The real amount is close to 1274.8775 ETH

## Proof of Concept
Run the following test in NukeFund.test.ts. It tries to mint all gen 1 and then checks the final eth balance of the nuke fund.

```typescript
  it('AUDIT: to mint gen 1 is needed way more ether than expected', async () => {
    await send('hardhat_setBalance', [
      await owner.getAddress(),
      `0x${ethers.parseEther('2000').toString(16)}`,
    ]);

    for (let i = 0; i < 51; i++) {
      await nft.connect(owner).mintWithBudget(merkleInfo.whitelist[0].proof, {
        value: ethers.parseEther('25'),
      });
    }

    for (let i = 0; i < 19; i++) {
      await nft.connect(owner).mintToken(merkleInfo.whitelist[0].proof, {
        value: ethers.parseEther('1'),
      });
    }

    expect(await nft.generationMintCounts(1)).to.eq(10000);
    expect(ethers.formatEther(await owner.provider.getBalance(nukeFund))).to.eq(
      '1147.38975'
    );
  });
```

You can run this python script to get the real amount. The formula is simply the initial amount by the number of tokens (init * 10000) plus the increase on each one, which is inc*0 + inc*1 + inc*2 + inc*3 + ... + inc*10000, this translates to inc * sum(1,10000). sum(1,10000) = (10000 - 1)*10000 / 2

```python
init =  0.005
inc = 0.0000245
qty = 10000
total = (qty - 1)*qty/2 * inc + init * 10000
print(total)
```
