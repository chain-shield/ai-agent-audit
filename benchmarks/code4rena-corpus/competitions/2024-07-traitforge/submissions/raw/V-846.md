# Vulnerability details

## Impact
The function `mintWithBudget` is used to mint entities(NFTs) in bulk. However, the condition it checks in loop which will always return false once `_tokenIds >= maxTokensPerGen`. Due to this, the function won't mint any entities once `_tokenIds >= maxTokensPerGen`.

`_tokenIds` is incremental variable which will increment on every mint of entity done via minting or forging. 

## Proof of Concept
The PoC won't be needed for this simple bug but let me explain the series of steps to reproduce it.
Steps:
* call `mintToken` `maxTokensPerGen`(i.e.`10000`) times. The ether needs to be passed for this to cover mint costs.
* Due to above mint, `_tokenIds` will be `10000` now.
* call `mintWithBudget` by passing 2 ether. No entities will be minted and all eth will be refunded to the caller.

The problametic condition can be removed since it doesn't serve any purpose in current implementation and blocks the functionality.
