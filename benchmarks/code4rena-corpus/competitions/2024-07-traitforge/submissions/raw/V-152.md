# Vulnerability details

## Impact
The `Golden God` token is predictable for every generation. Users who can predict the issuance of the `Golden God` token can gain unearned advantages, potentially acquiring high-value tokens without the corresponding effort or cost. This leads to unfair distribution of rewards or resources within your ecosystem and encourages users to manipulate the market. Fairness and unpredictability are crucial in blockchain-based games and applications. If users believe that certain aspects are predictable or manipulated, they will lose trust in the system.
## Proof of Concept
the function `initializeAlphaIndices` is called in the constructor of the `EntropyGenerator` and then once every generation increase in `TraitForgeNft::_incrementGeneration`, the problem is the function `initializeAlphaIndices` updates two public variables `slotIndexSelectionPoint` and `numberIndexSelectionPoint` that decides the slot for the `Golden God Token` in the function 
```javascript
function getEntropy(
    uint256 slotIndex,
    uint256 numberIndex
  ) private view returns (uint256) {
    require(slotIndex <= maxSlotIndex, 'Slot index out of bounds.');

    if (
      slotIndex == slotIndexSelectionPoint &&
      numberIndex == numberIndexSelectionPoint
    ) {
      return 999999;
    }

    uint256 position = numberIndex * 6; // calculate the position for slicing the entropy value
    require(position <= 72, 'Position calculation error');

    uint256 slotValue = entropySlots[slotIndex]; // slice the required [art of the entropy value
    uint256 entropy = (slotValue / (10 ** (72 - position))) % 1000000; // adjust the entropy value based on the number of digits
    uint256 paddedEntropy = entropy * (10 ** (6 - numberOfDigits(entropy)));

    return paddedEntropy; // return the caculated entropy value
  }
  ```
the arguments `slotIndexSelectionPoint` and `numberIndexSelectionPoint` are public, Another problem is that nfts are distributed  sequentially this means token1 will get slot,index= [0,0], token2=[0,1], token 3 = [0,2] and so on, this means that we can calculate the tokenId that will match `slotIndexSelectionPoint` and `numberIndexSelectionPoint` and snipe the golden god token, for example if `slotIndexSelectionPoint`= 562 and `numberIndexSelectionPoint`=10 this means Total NFTs = (561 * 13) + 10 = 7303.
this means all the attacker has to do is wait for this tokenId and frontrun any other transaction to get the `Golden God`
