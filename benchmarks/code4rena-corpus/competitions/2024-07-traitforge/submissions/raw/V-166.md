# Vulnerability details

## Impact
The [maxCap](https://github.com/code-423n4/2024-07-traitforge/blob/279b2887e3d38bc219a05d332cbcb0655b2dc644/contracts/TraitForgeNft/TraitForgeNft.sol#L22) for each nft generation is set to 10K. However that can be violated. 

## Proof of Concept
I'll go through an example to make it more clear by providing the necessary code part. Let's say 100 merger and 100 forger of generation 1 are forged through [forge](https://github.com/code-423n4/2024-07-traitforge/blob/279b2887e3d38bc219a05d332cbcb0655b2dc644/contracts/TraitForgeNft/TraitForgeNft.sol#L153) function. In this function the following line of code :
```solidity
 uint256 newGeneration = getTokenGeneration(parent1Id) + 1;
```
shows that the new nft that will be minted has an upper generation.In this case there will be 100 tokens of gen2.After maxCap for generation1 is reached, if [mintToken](https://github.com/code-423n4/2024-07-traitforge/blob/279b2887e3d38bc219a05d332cbcb0655b2dc644/contracts/TraitForgeNft/TraitForgeNft.sol#L181) is called, there will be a call to `_mintInternal` function:
```solidity
 function _mintInternal(address to, uint256 mintPrice) internal {
    if (generationMintCounts[currentGeneration] >= maxTokensPerGen) {
      _incrementGeneration();
    }
   //SKIP

  }
```
as it can be seen from the code above,the if check will be  passed (due to fact that gen1 maxcap is reached) and there will be a call to `_incrementGeneration()`:
```solidity
 function _incrementGeneration() private {
    require(
      generationMintCounts[currentGeneration] >= maxTokensPerGen,
      'Generation limit not yet reached'
    );
    currentGeneration++;
    generationMintCounts[currentGeneration] = 0;//@audit-issue  ignores already minted ones
    priceIncrement = priceIncrement + priceIncrementByGen;
    entropyGenerator.initializeAlphaIndices();
    emit GenerationIncremented(currentGeneration);
  }
```
the function initial check will be passed and currentGeneration will be increased to 2. Later generationMintCounts[2] is set to  0, ignoring already minted 100 tokens of gen2 based on the example ı provided above. That will result in over minting and dilute the value of NFTs.

## Recommended Mitigation Steps
Implement a check that ensures the mint count for the new generation is not reset if it already has minted tokens
```solidity
 function _incrementGeneration() private {
    require(
      generationMintCounts[currentGeneration] >= maxTokensPerGen,
      'Generation limit not yet reached'
    );
```
