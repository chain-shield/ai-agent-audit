# Vulnerability details

## Description
The calculateAge function in the NukeFund contract uses integer division, which can lead to significant precision loss, especially for young tokens or those with low performance factors. This could result in incorrect age calculations, potentially affecting the nuke factor and claim amounts.

## Impact
1. Young tokens or tokens with low performance factors may be severely undervalued.
2. The nuke factor calculation, which depends on the age, will be inaccurate for these tokens.
3. This could lead to unfair distribution of funds when tokens are nuked, potentially allowing some users to claim less than they should.

## Proof of Concept
```
  function calculateAge(uint256 tokenId) public view returns (uint256) {
    require(nftContract.ownerOf(tokenId) != address(0), 'Token does not exist');

    uint256 daysOld = (block.timestamp -
      nftContract.getTokenCreationTimestamp(tokenId)) /
      60 /
      60 /
      24;
    uint256 perfomanceFactor = nftContract.getTokenEntropy(tokenId) % 10;

    uint256 age = (daysOld *
      perfomanceFactor *
      MAX_DENOMINATOR *
      ageMultiplier) / 365; // add 5 digits for decimals
    return age;
  }
```

Consider a scenario where:
1. A token is 1 day old: daysOld = 1
2. The token has a performanceFactor of 1
3. MAX_DENOMINATOR = 100000
4. ageMultiplier = 1

The calculation would be:
age = (1 * 1 * 100000 * 1) / 365 = 273

This results in a very small age value, which could significantly undervalue young tokens.

## Tools Used : Manual Review

## Recommended Mitigation Steps

1. Use a higher precision for intermediate calculations:
   - Multiply by a large factor (e.g., 1e18) before division to maintain precision.
   - Store age as a fixed-point number with more decimal places.

2. Consider using a library like ABDKMath64x64 for high-precision calculations.

3. Adjust the age calculation to better handle young tokens:

```
function calculateAge(uint256 tokenId) public view returns (uint256) {
    require(nftContract.ownerOf(tokenId) != address(0), 'Token does not exist');

    uint256 secondsOld = block.timestamp - nftContract.getTokenCreationTimestamp(tokenId);
    uint256 perfomanceFactor = nftContract.getTokenEntropy(tokenId) % 10;

    // Use higher precision and avoid integer division until the end
    uint256 age = (secondsOld * perfomanceFactor * MAX_DENOMINATOR * ageMultiplier * 1e18) / (365 days);
    return age;
}
```
