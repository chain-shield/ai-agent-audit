# Vulnerability details

## Impact
Some functions cannot be paused as intended on some of the Trait Forge Contracts.

## Proof of Concept

The following contracts inherit from the `Pausable OpenZeppelin` contract:

- `TraitForge.sol`
- `NukeFund.sol`
- `EntropyGenerator.sol`
- `EntityTrading.sol`
- `EntityForging.sol`
- `DevFund.sol`

These contracts inherit the Pausable contract and implement the whenNotPaused modifier to various functions on the contracts, but they don't implement any method to actually pause or unpause the contract. Pausable.sol only implements internal functions, which requires external or public functions to be implemented to wrap them. Since nothing like this has been implemented, the entire pausing system is rendered useless and many function cannot be paused as intended.

## Tools Used
- Static Analysis

## Recommended Mitigation Steps
Implement simple external `pause` and `unpause` functions that can be called by the owner.
