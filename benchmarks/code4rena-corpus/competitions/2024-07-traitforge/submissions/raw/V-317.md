# Vulnerability details

## Impact

Check the following `require()` statements which restrict the "Golden God" (i.e. NFT with entropy 999999) to be set in the 1st or 2nd entropy batches:
1. https://github.com/code-423n4/2024-07-traitforge/blob/279b2887e3d38bc219a05d332cbcb0655b2dc644/contracts/EntropyGenerator/EntropyGenerator.sol#L56
2. https://github.com/code-423n4/2024-07-traitforge/blob/279b2887e3d38bc219a05d332cbcb0655b2dc644/contracts/EntropyGenerator/EntropyGenerator.sol#L76
 
The `pseudoRandomValue` variable is always greater than "Golden God"'s 999999 entropy so those checks never happen thus allowing "Golden God" NFT to be set in the 1st or 2nd entropy batches.

## Tools Used

Manual review

## Recommended Mitigation Steps

Check for actual entropy value by slot index and slot number via `getPublicEntropy()` instead of comparing 999999 with `pseudoRandomValue`.
