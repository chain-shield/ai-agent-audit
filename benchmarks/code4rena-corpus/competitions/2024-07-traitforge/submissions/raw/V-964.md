# Vulnerability details

## Impact
Thanks to all entropies being stored in a private variable, the malicious user may know which tokens will have which characteristics associated with particular entropy value. Malicious users may frontrun minting of most favorable tokens and obtain unfair advantage, which would compromise the essence of game.

Namely, the entropies are stored in a private array `entropySlots` in the EntropyGenerator smart contract. Although this is a private variable, the moment it is set, it can be decoded and its value would be known. This means that malicious users can know in advance which tokens will have which entropy and use this information to frontrun and mint most favorable tokens for themselves.

## Recommended Mitigation Steps
An approach to overcome this system design issue is to integrate Chainlink VRF for properly generating random values for entropies.
