# Vulnerability details


### Impact: 

    The pausable contracts inherited by all the contracts have an internal virtual  function that is supposed to be overriden in the main contracts , which the protocol missed overridden these functions,  this leads to the protocol not been able to pause or unpause due to the lack of overriden these crucial functions.



### Proof of Concept:

    take a look at all the functions in each contract and noticed none of them overrides the pause and unpause functions


### Recommended Mitigation:

    overide these functions in all the contracts with onlyOwner modifier


function pause() external override onlyOwner {
        _pause();
    }

    
    function unpause() external override onlyOwner {
        _unpause();
    }
