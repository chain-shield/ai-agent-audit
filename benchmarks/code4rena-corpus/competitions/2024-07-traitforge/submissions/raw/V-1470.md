# Vulnerability details

## Impact
No function available to make use `whenNotPaused` modifier

## Proof of Concept
All the above lines use `whenNotPaused()` modifier to pause execution if the contract is paused. They are using `@openzeppelin/contracts/security/Pausable.sol` for this functionality.

Now this contract provides the modifier mentioned above:
```solidity
    bool private _paused;
    modifier whenPaused() {
        _requirePaused();
        _;
    }

    function _requireNotPaused() internal view virtual {
        if (paused()) {
            revert EnforcedPause();
        }
    }

    function paused() public view virtual returns (bool) {
        return _paused;
    }

    function _unpause() internal virtual whenPaused {
        _paused = false;
        emit Unpaused(_msgSender());
    }

    function _pause() internal virtual whenNotPaused {
        _paused = true;
        emit Paused(_msgSender());
    }
```

As you can see, the main variable used for checking pause phase `_paused` is private in `Pauseable.sol` contract, and the functions to change it's value, `_unpause()` and `_pause()` are internal to the contract. As there are no public/external functions in any of the above contracts that provide access to changing the value of `_paused` from `true` or `false`, this variable is always going to stay false, making the usage of the modifier useless as it cannot work unless someone changes the value of `_paused` to `true`.

## Recommended Mitigation Steps
Create public facing functions that allow `owner()` to `pause()` or `unpause()` any given contract to get the intended functionality of being able to pause or unpause a contract.
