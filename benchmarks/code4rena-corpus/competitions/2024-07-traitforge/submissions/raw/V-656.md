# Vulnerability details

## Impact
In the case of emergency, protocol can't be paused.

## Proof of Concept
The intentions that the protocol should be able to be paused are very clear. Almost every function has the `whenNotPaused` modifier attached to it. All contracts in scope inherit from `Pausable` but there isn't an externally exposed `paused` method in none of them. By default the the bool `paused` will be set to false upon deployment and will stay like this forever.
## Tools Used

Manual Review
## Recommended Mitigation Steps
Declare externally exposed `pause` method which calls `Pausable's` internal `_pause` and attach `onlyOwner` modifier to it.
