# Vulnerability details

## Impact
The `listedTokenIds` mapping is not updated and the `listingCount` iss not decremented when and NFT is sold and listing is removed, which can cause issues with future operations that rely on the accuracy of this mapping. This can result in incorrect behavior, such as attempting to access or modify non-existent listings, potentially leading to unexpected errors.

## Proof of Concept
In the [`buyNFT` function](https://github.com/code-423n4/2024-07-traitforge/blob/279b2887e3d38bc219a05d332cbcb0655b2dc644/contracts/EntityTrading/EntityTrading.sol#L63-L92), the listing is removed from the `listings` mapping but not from the `listedTokenIds` mapping like this:

```solidity
delete listings[listedTokenIds[tokenId]]; // remove listing
```

This leaves the `listedTokenIds` mapping pointing to an index that no longer exists in the `listings` mapping. 

## Tools Used
- Manual code review


## Recommended Mitigation Steps
Update the `listedTokenIds` mapping when removing a listing in the `buyNFT` function like this:

```diff
function buyNFT(uint256 tokenId) external payable whenNotPaused nonReentrant {
    Listing memory listing = listings[listedTokenIds[tokenId]];
    require(
        msg.value == listing.price,
        'ETH sent does not match the listing price'
    );
    require(listing.seller != address(0), 'NFT is not listed for sale.');

    // transfer NFT from contract to buyer
    nftContract.transferFrom(address(this), msg.sender, tokenId); // transfer NFT to the buyer

    // transfer eth to seller (distribute to nukefund)
    uint256 nukeFundContribution = msg.value / taxCut;
    uint256 sellerProceeds = msg.value - nukeFundContribution;
    transferToNukeFund(nukeFundContribution); // transfer contribution to nukeFund

    (bool success, ) = payable(listing.seller).call{ value: sellerProceeds }('');
    require(success, 'Failed to send to seller');

    // remove listing
    delete listings[listedTokenIds[tokenId]];
    delete listedTokenIds[tokenId];
    listingCount--; 

    emit NFTSold(
        tokenId,
        listing.seller,
        msg.sender,
        msg.value,
        nukeFundContribution
    ); // emit an event for the sale
}
```

By adding `delete listedTokenIds[tokenId]` and `listingCount--`, it will ensure that the mappings are updated correctly and `listingCount` is decremented, preventing any future errors.
