# Vulnerability details

## Impact
[entropySlots](https://github.com/code-423n4/2024-07-traitforge/blob/279b2887e3d38bc219a05d332cbcb0655b2dc644/contracts/EntropyGenerator/EntropyGenerator.sol#L10C3-L10C37) is not populated as intended, which will cause a violation with the dynamics of the protocol;
## Proof of Concept
according to [whitepaper](https://docs.google.com/document/d/1pihtkKyyxobFWdaNU4YfAy56Q7WIMbFJjSHUAfRm6BA/edit):
'There is a certain entropy, “999999” which is referred to as “the Golden God”, since it has perfect parameters and will exceed all other entities if played correctly. The Golden God is scanned for and is kept out of the first 2 passes, but is deliberately set in the final pass (at some random point). The Golden God should be the most valuable entity'
entropy 999999 is intentionally set to final pass. Golden pass is based on the alpha indices which is set by the owner in [initializeAlphaIndices](https://github.com/code-423n4/2024-07-traitforge/blob/279b2887e3d38bc219a05d332cbcb0655b2dc644/contracts/EntropyGenerator/EntropyGenerator.sol#L206C12-L206C34):
```solidity
  function initializeAlphaIndices() public whenNotPaused onlyOwner {
    uint256 hashValue = uint256(
      keccak256(abi.encodePacked(blockhash(block.number - 1), block.timestamp))
    );

    uint256 slotIndexSelection = (hashValue % 258) + 512;
    uint256 numberIndexSelection = hashValue % 13;

    slotIndexSelectionPoint = slotIndexSelection;
    numberIndexSelectionPoint = numberIndexSelection;
  }
```
as it can be seen from the function,slotIndexSelection value will be between 512  and 769,which a line later set to slotIndexSelectionPoint. That means golden god entropy(999999) is intented to set in [writeEntropyBatch3()](https://github.com/code-423n4/2024-07-traitforge/blob/279b2887e3d38bc219a05d332cbcb0655b2dc644/contracts/EntropyGenerator/EntropyGenerator.sol#L84C12-L84C30)
```solidity
function writeEntropyBatch3() public {
    require(
      lastInitializedIndex >= batchSize2 && lastInitializedIndex < maxSlotIndex,
      'Batch 3 not ready or already completed.'
    );//@audit-info 512=<index <770
    unchecked {
      for (uint256 i = lastInitializedIndex; i < maxSlotIndex; i++) {
        uint256 pseudoRandomValue = uint256(
          keccak256(abi.encodePacked(block.number, i))
        ) % uint256(10) ** 78;
        entropySlots[i] = pseudoRandomValue;
      }
    }
    lastInitializedIndex = maxSlotIndex;
  }
```
so far there is no issue between code and wp. To explain the issue better I'll use some numbers from this point.Let's say the owner sets slotIndexSelectionPoint  to 696 and numberIndexSelection  to 11  by calling `initializeAlphaIndices`.now when getEntrop() is called the following check:
```solidity
if (
      slotIndex == slotIndexSelectionPoint &&
      numberIndex == numberIndexSelectionPoint
    ) {
      return 999999;
    }
```
if slotIndex and numberIndex correspond to 696 and 11 respectively, it will return 999999. That means entropSlots[696] is 999999. However if we check writeEntropyBatch3 function given above, it is not certain that index 696 will be populated with 999999.  Because the value is generated randomly based on the previous block number and index. There is even no guarantee that it will be set Batch3 due to the fact that current logic generates pseudo-random values that may or may not include `999999`.In the case of `999999` is not even set to any index from 512 to 770, even the owner will not able to rewrite due the initial check in writeEntropyBatch3 . That will broke the whole dynamics of the game

## Recommended Mitigation Steps
Ensure that `999999` is added to EntropySlots array and it is set to alpha indices.
adjusted code:
```solidity
function writeEntropyBatch3() public {
    require(
        lastInitializedIndex >= batchSize2 && lastInitializedIndex < maxSlotIndex,
        'Batch 3 not ready or already completed.'
    );
    unchecked {
++        bool goldenGodSet = false;
        for (uint256 i = lastInitializedIndex; i < maxSlotIndex; i++) {
            uint256 pseudoRandomValue = uint256(
                keccak256(abi.encodePacked(block.number, i))
            ) % uint256(10) ** 78;

            // Ensure the Golden God value is set in the specific slot
++            if (i == slotIndexSelectionPoint) {
                pseudoRandomValue = 999999;
                goldenGodSet = true;
            }

            // Store the generated value in the entropy slots
            entropySlots[i] = pseudoRandomValue;
        }

 ++       // Verify that the Golden God has been set
        require(goldenGodSet, 'Failed to set the Golden God value');
    }
    lastInitializedIndex = maxSlotIndex;
}
```
