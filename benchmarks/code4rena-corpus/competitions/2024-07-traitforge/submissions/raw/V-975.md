# Vulnerability details

## Impact
The same NFTs with identical images and entropy can exist within the same generation. As a result, duplicate NFTs will exist, undermining the game objectives and goals. This can affect the rarity and uniqueness of NFTs, which are essential for maintaining user interest and the value of the game assets.

## Proof of Concept
Each time two NFTs are forged, the resulting NFTs get an entropy value which is the average entropy from its parentIds:

`
uint256 newEntropy = (forgerEntropy + mergerEntropy) / 2;
`

As a result, if the `forgeWithListed` function is executed multiple times using the same parentIds, the same NFTs will be produced.

## Tools Used
Manual review

## Recommended Mitigation Steps
The `newEntropy` that is produced when using the same parentIds should be checked and modified to ensure it results in an entropy value that does not already exist. This will prevent the creation of duplicate NFTs within the same generation and maintain the uniqueness and value of each NFT.
