# Vulnerability details

## Impact
When a Forger token that is listed for forging is nuked the Listing struct of that token is not deleted from the mapping, which leads to stale data in the mapping.

## Proof of Concept
The `NukeFund::nuke` function doesn’t check if the NFT that is nuked is listed for forging. After the NFT is burned the EntityForging listings mapping will still contain the Listing data of the burned NFT.

## Tools Used
Manual Review

## Recommended Mitigation Steps
Check if the NFT is listed for forging and if it is delete the Listing from the mapping
