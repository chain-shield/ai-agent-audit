# Vulnerability details

## Impact
Multiple contracts inherit OpenZeppelin's Pausable contract and uses the modifier `whenNotPaused` to allow the protocol to unpause/pause contracts. There is a varying level of importance for the pause functionality for the different functions. For instance, in the DevFund.sol contract, owner should be able to pause users from `claim()`.

However, due to not implementing a way to actually pause the contract, the protocol will be unable to do so across multiple contracts.

## Proof of Concept
Protocol does not expose the pause and unpause functionality of Pausable, hence will be unable to pause contracts.

## Tools Used
Manual Review

## Recommended Mitigation Steps
Consider exposing the neccessary `_pause()` and `_unpause()` functions.
