# Vulnerability details

## Impact
The `EntropyGenerator` contract exposes sensitive entropy values and derived token parameters through the public functions `deriveTokenParameters()` and `getPublicEntropy()`. Since these functions are public, anyone can call them to retrieve detailed entropy data and derive various token parameters. This can potentially allow malicious actors to predict the generated pseudo-random values and token properties, undermining the security and fairness of the system using this contract.

## Proof of Concept
These functions are defined to public and they return sensitive data.

## Recommended Mitigation Steps
Implement access control mechanisms to restrict access to the `deriveTokenParameters()` and `getPublicEntropy()` functions. Consider using an `onlyAllowedCaller` modifier or similar access control strategies to ensure only authorized entities can call these functions.
