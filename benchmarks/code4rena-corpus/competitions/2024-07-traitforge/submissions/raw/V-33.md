# Vulnerability details

## Impact
NFT's value can be derived before it has been minted, leading to strategic high-value mints and stealing of value from other minters.

## Proof of Concept
* Once the contract is deployed and set up, fork it and deploy several nfts - you can see their nuke factor by calling `calculateNukeFactor` - this gives an approximation of the value of the nft.
* Wait until before each of the 10 (or any number of) highest valued nfts are minted and mint them after (or front-run the minter)
* Sell them for profit

## Tools Used
Manual review

## Recommended Mitigation Steps
Use an off-chain source for the nuke factor entropy generation
