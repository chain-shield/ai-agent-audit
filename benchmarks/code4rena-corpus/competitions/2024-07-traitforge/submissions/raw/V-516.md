# Vulnerability details

## Vulnerability details 

In the `TraitForgeNft` contract, 
the `mintWithBudget` function allows users to mint multiple tokens within a budget.

```
maxGeneration =  10.
maxTokensPerGen = 10,000.
Thus the maximum possible value for `tokenIds` currently is 10000 ×10 = 100,000
```

However, there is an issue with the implementation that restricts the `mintWithBudget` function
to only mint `_tokenIds` upto 10000.

```
 while (budgetLeft >= mintPrice && _tokenIds < maxTokensPerGen) {
```

This condition `_tokenIds < maxTokensPerGen` ensures that 
the minting loop stops once `_tokenIds` reaches 10,000. 

However, `_tokenIds` is a cumulative counter across all generations, 
not just within the current generation.

## Impact

`mintWithBudget` function becomes unusable and 
basically enters a state of DOS beyond `_tokenIds` 10000.

## Proof of Concept


Insert the following test case in a foundry setup 

```
    function testMintWithBudgetRevertsAfter9999() public {
        vm.startPrank(user);
        
        // Initial minting to reach the limit of 9999 tokens
        for (uint i = 0; i < 10000; i++) {
            nftContract.mintWithBudget{value: nftContract.calculateMintPrice()}('');
        }
        
        uint256 initialBalance = user.balance;

        // Attempt to mint the 10001st tokenID   
        nftContract.mintWithBudget{value: 1 ether}('');
				
				uint256 finalBalance = user.balance;

				assertEq(finalBalance, initialBalance, 'user refunded');															
				assertEq(nftContract._tokenIds(), 10000, "10001st tokenID not minted") 
    }

```
At this point, 
due to the condition `_tokenIds < maxTokensPerGen`, 
the minting process will stop, 
even though subsequent generations (2 to 10) can still have 10,000 tokens each.

## Recommended Mitigation Steps

Since the following logic is already present in the `_mintInternal` function.
```
    if (generationMintCounts[currentGeneration] >= maxTokensPerGen) {
      _incrementGeneration();
    }
```
We could ignore the 'mint count per generation' check 
from the while loop condition and modify it as below

```
while (budgetLeft >= mintPrice) {
```
