# Vulnerability details

## Impact

The `EntityForging::forgeWithListed()` requires that user sends msg.value >= forgingFee

The `EntityForging::forgeWithListed()` function requires that the user sends `msg.value greater than or equal to the forgingFee`. However, the function only uses forgingFee for calculations and does not refund any excess amount sent. This can result in users unintentionally losing funds if they send more than the required fee.

Refer to impacted line(s) of code here:

- Requires that msg.sender sends `msg.value >= forgingFee`

  - [EntityForging.sol#L125-L126](https://github.com/code-423n4/2024-07-traitforge/blob/main/contracts/EntityForging/EntityForging.sol#L125-L126)

- The calculations are made using the `forgingFee` and not `msg.value`, which does not take into account any excess amount sent to the function, in which case the user won't be getting any refund.
  - [EntityForging.sol#L146-L147](https://github.com/code-423n4/2024-07-traitforge/blob/main/contracts/EntityForging/EntityForging.sol#L146-L147)

## Recommended Mitigation Steps

### One of the two of the following mitigations can be made

- Mitigation 1: Modify the check to accept exact value from `msg.sender`.

[EntityForging.sol#L126](https://github.com/code-423n4/2024-07-traitforge/blob/279b2887e3d38bc219a05d332cbcb0655b2dc644/contracts/EntityForging/EntityForging.sol#L126)

```diff
L126:
-   require(msg.value >= forgingFee, 'Insufficient fee for forging');
+   require(msg.value == forgingFee, 'Insufficient fee for forging');
```

- Mitigation 2 : Calculate `devFee` and `forgerShare` with `msg.value` instead of `forgingFee` and refund the remaining funds

[EntityForging.sol#L146-L147](https://github.com/code-423n4/2024-07-traitforge/blob/main/contracts/EntityForging/EntityForging.sol#L146-L147)

```diff
L146-L147 :
-    uint256 devFee = forgingFee / taxCut;
-    uint256 forgerShare = forgingFee - devFee;
+    uint256 devFee = msg.value / taxCut;
+    uint256 forgerShare = msg.value - devFee;
+    uint256 excess = msg.value - devFee - forgerShare
+    if(excess > 0){
+       (bool success_refund, ) = msg.sender.call{ value: excess }('');
+       require(success_refund, 'Failed to refund excess amount');
+    }
```
