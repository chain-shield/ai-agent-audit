# Vulnerability details

## Impact
The tax fees collected during minting may be burnt instead of being sent to nukeFund.

## Proof of Concept
Since the nukeFund address is not being set at deployment, when a user mints token could be burnt in the _distributeFunds() function:
`(bool success, ) = nukeFundAddress.call{ value: totalAmount }('');`
    `require(success, 'ETH send failed');`
As this would return true and transfer the eth to the 0 address (essentially burning it) leading to a loss of funds to the dev, and the user.
This happens since there is no check to see if the nukeFund contract address has been initialized using the setNukeFundContract() function.

## Tools Used
Manual Review

## Recommended Mitigation Steps
Add the following check at line 359 in _distributeFunds() function:
`require(nukeFundAddress != address(0), "NukeFund contract not initialized");`
