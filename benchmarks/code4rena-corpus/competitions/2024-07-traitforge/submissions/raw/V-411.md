# Vulnerability details

## Impact

The calculateAge function always returns 0 due to the performance factor being 0 for the given token entropy. This causes the calculateNukeFactor function to return a constant value regardless of the token's age. As a result:

The time-based increase in nuke factor is non-functional.
Tokens do not accrue value over time as intended.
The tokenomics of the system are fundamentally altered, removing incentives for long-term holding.
Users holding tokens for extended periods receive no benefits for their long-term investment.
The system's core mechanic of time-based value accrual is broken.

The provided test demonstrates that:

The calculated age is always 0, regardless of the time passed.
The nuke factor remains constant over time, equal to the initial nuke factor.

This proves that the time-based mechanics intended in the system are non-functional.

function testNukeFactorCalculation3() public {
        // Impersonate the owner
        vm.startPrank(ownerAddr);

        // Set a non-zero ageMultiplier
        uint256 testAgeMultiplier = 100;
        nukeFund.setAgeMultplier(testAgeMultiplier);

        // Stop impersonating the owner
        vm.stopPrank();

        // Mint a token
        bytes32[] memory proof;
        vm.prank(player1);
        traitForgeNft.mintToken{value: 1 ether}(proof);
        uint256 tokenId = 1;

        // Log initial state
        uint256 mintTimestamp = block.timestamp;
        console.log("Mint timestamp:", mintTimestamp);

        // Test multiple time periods
        uint256[] memory timePeriods = new uint256[](3);
        timePeriods[0] = 1 days;
        timePeriods[1] = 30 days;
        timePeriods[2] = 365 days;

        for (uint256 i = 0; i < timePeriods.length; i++) {
            // Advance time
            vm.warp(mintTimestamp + timePeriods[i]);
            console.log("\nTesting period:", timePeriods[i] / 1 days, "days");

            // Calculate age and nuke factor
            uint256 calculatedAge = nukeFund.calculateAge(tokenId);
            uint256 nukeFactor = nukeFund.calculateNukeFactor(tokenId);

            console.log("Calculated age:", calculatedAge);
            console.log("Calculated nuke factor:", nukeFactor);

            // Get components for manual calculation
            uint256 tokenEntropy = traitForgeNft.getTokenEntropy(tokenId);
            uint256 initialNukeFactor = tokenEntropy / 40;

            console.log("Token entropy:", tokenEntropy);
            console.log("Initial nuke factor:", initialNukeFactor);

            // Assert that nuke factor doesn't change over time
            assertEq(nukeFactor, initialNukeFactor, "Nuke factor should not change over time");
        }
    }

## Recommended Mitigation Steps

Modify the performance factor calculation to ensure it's never zero:
```
uint256 perfomanceFactor = (nftContract.getTokenEntropy(tokenId) % 10) + 1;
```
Implement a minimum age value to ensure that even new tokens have some non-zero age:
```
uint256 age = ((daysOld * perfomanceFactor * MAX_DENOMINATOR * ageMultiplier) / 365) + 1;
```
Review and adjust the nuke factor calculation to ensure it scales appropriately with token age.
