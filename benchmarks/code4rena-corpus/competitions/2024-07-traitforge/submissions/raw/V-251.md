# Vulnerability details

## Impact
**`fetchListings()`** is used to view all the NFTs listed for forging. However, the number of listings will increase over time, eventually surpassing the block gas limit and causing the transaction to revert. This renders the function useless and results in a DOS.
## Proof of Concept
**`fetchListings()`** iterates through all the listed NFTs, including those that have already been forged and those still waiting to be forged. This distinction is important to note.
```Solidity
function fetchListings() external view returns (Listing[] memory _listings) {
    _listings = new Listing[](listingCount + 1);
    for (uint256 i = 1; i <= listingCount; ++i) {
      _listings[i] = listings[i];
    }
  }
```
When **`forgeWithListed()`** is called to forge an NFT, the final step is to call **`_cancelListingForForging()`** to remove the NFT from the listings mapping.
```Solidity
function _cancelListingForForging(uint256 tokenId) internal {
    delete listings[listedTokenIds[tokenId]];

    emit CancelledListingForForging(tokenId); // Emitting with 0 fee to denote cancellation
  }
```
The problem is that when you delete a mapping entry, it remains with default values instead of being completely removed, as an array element would be with **`pop`**. 

As a result, **`fetchListings()`** iterates over all entries in the listings mapping, including those that have already been forged (with the default values). Over time, this accumulation will cause the block gas limit to be reached, resulting in transaction reversion and rendering the function useless.
## Tools Used
 Manual review.
## Recommended Mitigation Steps
To resolve this problem, you can modify **`fetchListings()`** to iterate over a specific range.
```diff
-function fetchListings() external view returns (Listing[] memory _listings) {
+function fetchListings(uint256 start) external view returns (Listing[] memory _listings) {
    _listings = new Listing[](listingCount - start + 1);
    for (uint256 i = start; i <= listingCount; ++i) {
      _listings[i] = listings[i];
    }
  }
```
