# Vulnerability details

## Impact
The functions which are wanted to pause  or un-pause can not be paused or un-paused.

## Proof of Concept

The contracts **DevFund**, **EntityForging**, **EntityTrading**, **NukeFund** inherits the abstract contract `Pausable` which will be used to pause or un-pause some of the functions such as [claim](https://github.com/code-423n4/2024-07-traitforge/blob/279b2887e3d38bc219a05d332cbcb0655b2dc644/contracts/DevFund/DevFund.sol#L61), [nuke](https://github.com/code-423n4/2024-07-traitforge/blob/279b2887e3d38bc219a05d332cbcb0655b2dc644/contracts/NukeFund/NukeFund.sol#L153-L154) and other function where the pause or un-pause is used.

We think that pause or un-pause is needed whenever the owner want to update certain set of parameters. when doing so, these function would be paused temporarily and un-paused once the operation is done.

The problem here is, just inheriting the Pausible module will not ensure the calling of the below function as they are internally protected. 

#L89-L104 : https://github.com/code-423n4/2024-07-traitforge/blob/279b2887e3d38bc219a05d332cbcb0655b2dc644/node_modules/@openzeppelin/contracts/security/Pausable.sol#L89-L104

```solidity
    function _pause() internal virtual whenNotPaused {
        _paused = true;
        emit Paused(_msgSender());
    }

    /**
     * @dev Returns to normal state.
     *
     * Requirements:
     *
     * - The contract must be paused.
     */
    function _unpause() internal virtual whenPaused {
        _paused = false;
        emit Unpaused(_msgSender());
    }
```

Manual review.

## Recommended Mitigation Steps

We would suggest to implement public function to call the above function only by the owner.
