# Vulnerability details

## Impact
As we are using `EntityTrading.sol` for buying and selling NFT at a marketplace. It uses ERC721 standard.However there is a function for buying NFt `EntityTrading::buyNFT()` in the contract and that function uses `transferFrom()` function for transfering NFT to the buyer account. So while transferring if the buyer is an address which is not capable of holding the ERC721 gets the NFT and the transaction is successfully completed.
But the problem is that NFT is now completely locked for lifetime as there will be no owner assigned for that NFT because the address which buys NFT does hold compatibility of holding it and it results into a loss of funds and loss of NFT.

The attached POC will show how the noErc named contract will be able to buy the NFT but after that the NFT will be transferred to zero address because of using `transferFrom` function as it does not check the receiver is ERC721receiver compatible  of not while buying the NFT using `EntityTrading::buyNFT` .

