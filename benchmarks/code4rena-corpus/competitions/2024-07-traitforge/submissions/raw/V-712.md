# Vulnerability details

## Impact

In the writeEntropyBatch1, writeEntropyBatch2, writeEntropyBatch3 functions, the check for the Golden God entropy(999999) is wrong. With the current check , the 999999 entropy can still be present in any of the index in the entropy slots.


## Proof of Concept

https://github.com/code-423n4/2024-07-traitforge/blob/279b2887e3d38bc219a05d332cbcb0655b2dc644/contracts/EntropyGenerator/EntropyGenerator.sol#L56
```Solidity
  function writeEntropyBatch1() public {
    require(lastInitializedIndex < batchSize1, 'Batch 1 already initialized.');

    uint256 endIndex = lastInitializedIndex + batchSize1; // calculate the end index for the batch
    unchecked {
      for (uint256 i = lastInitializedIndex; i < endIndex; i++) {
        uint256 pseudoRandomValue = uint256(
          keccak256(abi.encodePacked(block.number, i))
        ) % uint256(10) ** 78; // generate a  pseudo-random value using block number and index
        require(pseudoRandomValue != 999999, 'Invalid value, retry.');
        entropySlots[i] = pseudoRandomValue; // store the value in the slots array
      }
    }
    lastInitializedIndex = endIndex;
  }
```

The current check used to ensure that the entropy (999999) is not set in the intial 2 batches is:
```require(pseudoRandomValue != 999999, 'Invalid value, retry.');```

But this check is wrong and this entropy can still be present in any of the index in the entropy slots.
Take for instance the `pseudoRandomValue` generated is `33669829935327267799999999999999999963489585009520908909005966739999999118267`

In this pseudoRandomValue itself there are 4 instances of 999999 entropy.
So like this there can be many entropy slots which can contain this Golden God entropy and many users will get this entropy.

## Recommended Mitigation Steps

Create a function to check if there is any index which has the 999999 entropy in a given generated pseudoRandomValue.
```Solidity
for (uint256 i = lastInitializedIndex; i < endIndex; i++) {
        uint256 pseudoRandomValue = uint256(
          keccak256(abi.encodePacked(block.number, i))
        ) % uint256(10) ** 78; // generate a  pseudo-random value using block number and index
        require(!checkForGoldenGod(pseudoRandomValue), 'Invalid value, retry.');
        entropySlots[i] = pseudoRandomValue;
```
