# Vulnerability details

## Impact

In the `buyNFT()` function, the `sellerProceeds` could be sent to an invalid address (`listing.seller`). If the actual seller updates their address or exits the application for a long period of time, this function will inadvertently send the reward to an outdated address (old address) instead of the updated one.

## Proof of Concept
```solidity
 function buyNFT(uint256 tokenId) external payable whenNotPaused nonReentrant {
    Listing memory listing = listings[listedTokenIds[tokenId]];
    ...

    // transfer NFT from contract to buyer
@>  (bool success, ) = payable(listing.seller).call{ value: sellerProceeds }(
      ''
    );
    ...
  }
```

## Recommended Mitigation Steps
Update listing information whenever users update their information to ensure accurate address details.
