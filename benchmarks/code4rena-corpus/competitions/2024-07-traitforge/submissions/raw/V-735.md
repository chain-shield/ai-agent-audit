# Vulnerability details

## Vulnerability details
Every transaction that increments the current generation will revert because trait forge nft contract do not have permission to call initializeAlphaIndices function on the EntropyGenerator contract. 

## Proof of Concept
Create a new test file, paste the code below and run it. The test shows that when user mints entity from new generation, the transaction reverts because contracts tries to call initializeAlphaIndices function which is restricted to onlyOwner (owner is creators multisig).
