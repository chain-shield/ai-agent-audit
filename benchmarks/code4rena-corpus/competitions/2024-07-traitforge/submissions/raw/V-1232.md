# Vulnerability details

## Impact

In the `EntropyGenerator` contract `writeEntropyBatch1()`, `writeEntropyBatch2()` functions include a check intended to prevent more than one instance of the "Golden God" entropy value (999_999) per generation. This check currently only validates the entire 78-digit pseudo-random number to ensure it is not exactly 999_999, missing cases where 999_999 could appear in any of the 13 groups of 6 digits.
Furthermore, `writeEntropyBatch3` does not have any check regarding this.

The current check:

```javascript
require(pseudoRandomValue != 999999, 'Invalid value, retry.');
```

only ensures that the entire 78-digit value is not 999_999. However, since the `getEntropy` function slices this large number into smaller groups of 6 digits, it is possible for 999_999 to appear within any of these groups, thus bypassing the check.

The current validation mechanism fails to fully prevent multiple occurrences of the "Golden God" value within a generation. As a result, it is possible to have multiple instances of 999_999 in different slots or positions, which contradicts the intended uniqueness of this value. This leads to unintended advantages in the system that relies on this entropy value, undermining the contract's integrity and fairness.

## Recommended Mitigation Steps

To ensure that the "Golden God" value does not appear more than once in any generation, a more comprehensive validation mechanism should be implemented. This mechanism should check all possible 6-digit slices of the 78-digit pseudo-random number to ensure none of them are 999_999.

Here is an example of how the check can be improved:

```javascript
function validateGoldenGod(uint256 pseudoRandomValue) private pure returns (bool) {
    for (uint256 i = 0; i <= 72; i += 6) {
        uint256 slice = (pseudoRandomValue / (10 ** i)) % 1_000_000;
        if (slice == 999999) {
            return false;
        }
    }
    return true;
}
```

This function should be called within each batch writing function to validate the pseudo-random value before it is stored:

```javascript
require(validateGoldenGod(pseudoRandomValue), 'Invalid value, retry.');
```
