# Vulnerability details

## Summary
TraitForgeNft was defined as Pausable to avoid emergency cases, but it doesn't provide a pause interface for the owner and made it pointless to make the contract Pausable. 
The _pause() function provided by Pausable can only be called internally. If the contract doesn't provide another interface for pausing, the pause won't work.
The same issues also happens in other contracts like EntropyGenerator, EntityForging and EntityTrading.

## Impact
In emergence cases owner won't be able to pause the contract, causing fund loss.


## Tools Used
Manual code review

## Recommended Mitigation Steps
Add a external onlyOwner pause function.
