# Vulnerability details

## Impact
`EntropyGenerator::deriveTokenParameters` calculates forgePotential as first digit of the entropy. Accordingly to docs, it should be the 5th digit of the entropy. Actually, the calculate it correctly in another place: `EntityForging::listForForging`:
```solidity
uint8 forgePotential = uint8((entropy / 10) % 10); // Extract the 5th digit from the entropy
```
