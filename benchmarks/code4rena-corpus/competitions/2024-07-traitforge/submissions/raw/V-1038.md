# Vulnerability details

## Impact
In the `TraitForgeNft#mintWithBudget` function, there is a condition `_tokenIds < maxTokensPerGen` for the while loop 

```solidity
    while (budgetLeft >= mintPrice && _tokenIds < maxTokensPerGen) {
      _mintInternal(msg.sender, mintPrice);
      amountMinted++;
      budgetLeft -= mintPrice;
      mintPrice = calculateMintPrice();
    }
```

Since `_tokenIds >= maxTokensPerGen` after the first generation, his condition will always be false, which resulting in minters can not use the `mintWithBudget` after the first generation.

## Tools Used
Manual Review.

## Recommended Mitigation Steps
Remove the `_tokenIds < maxTokensPerGen` condition at `TraitForgeNft.sol#215`

```diff
-   while (budgetLeft >= mintPrice && _tokenIds < maxTokensPerGen) {
+   while (budgetLeft >= mintPrice) {
      _mintInternal(msg.sender, mintPrice);
      amountMinted++;
      budgetLeft -= mintPrice;
      mintPrice = calculateMintPrice();
    }
```
