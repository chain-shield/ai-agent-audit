# Vulnerability details

## Impact
The `taxCut` variable can be altered by the contract owner using the `setTaxCut()` function without notifying users. 
Users should be informed about changes to the tax rate prior to its implementation to avoid unexpected financial impacts. 
Additionally, the contract should emit an event to transparently communicate any modifications to the tax rate, ensuring that users are aware of such changes in a timely manner.

## Proof of Concept
The `setTaxCut()` function allows the owner to update the `taxCut` value, but it does not notify users or emit any event:
```solidity
function setTaxCut(uint256 _taxCut) external onlyOwner {
    taxCut = _taxCut;
}
```

## Tools Used
Manual

## Recommended Mitigation Steps
Implement an event to notify users of changes to the `taxCut` value and ensure users are informed prior to its implementation. This can be achieved by emitting an event when the tax cut is updated.

```solidity
event TaxCutChanged(uint256 newTaxCut);

function setTaxCut(uint256 _taxCut) external onlyOwner {
    taxCut = _taxCut;
    emit TaxCutChanged(_taxCut);
}
```
