# Vulnerability details

## Bug description
Each NFT is designated as either a forger or a merger. Forger NFTs can be made available for forging, allowing other users to merge their NFTs with them.
The `forgePotential` of an NFT is determined by the 5th digit of its entropy. 

[EntityForging.sol#L86](https://github.com/code-423n4/2024-07-traitforge/blob/279b2887e3d38bc219a05d332cbcb0655b2dc644/contracts/EntityForging/EntityForging.sol#L86)
```solidity
uint8 forgePotential = uint8((entropy / 10) % 10); // Extract the 5th digit from the entropy
```

NFT's `forgingCount` is checked against `forgePotential` to ensure that each NFT is forged at most `forgePotenial` times.

[EntityForging.sol#L87-L90](https://github.com/code-423n4/2024-07-traitforge/blob/279b2887e3d38bc219a05d332cbcb0655b2dc644/contracts/EntityForging/EntityForging.sol#L87-L90)
```solidity
require(
    forgePotential > 0 && forgingCounts[tokenId] <= forgePotential,
    'Entity has reached its forging limit'
);
```

Assume a scenario where `forgePotential` and `forgingCount` is 9, which means that NFT has been forged 9 times and depleted its `forgePotential` entirely.
Because the check `forgingCounts[tokenId] <= forgePotential` is using lesser or equal, when such NFT is attempted to get listed one more time, the check will pass, resulting in `forgingCount` being incremented later when forging takes place in `forgeWithListed()`.

[EntityForging.sol#L131-L133](https://github.com/code-423n4/2024-07-traitforge/blob/279b2887e3d38bc219a05d332cbcb0655b2dc644/contracts/EntityForging/EntityForging.sol#L131-L133)
```solidity
// Check forger's breed count increment but do not check forge potential here
// as it is already checked in listForForging for the forger
forgingCounts[forgerTokenId]++;
```

The resulting state for such NFT is:
* forgingCount = 10
* forgePotential = 9

Additionally, NFTs with a `forgePotential` of 0 will be available for forging, even though they shouldn't be.

## Impact
NFTs can be forged more times than allowed by `forgePotential`.

## Recommended Mitigation
Change the require statement in `listForForging()` to use strictly less than.

[EntityForging.sol#L87-L90](https://github.com/code-423n4/2024-07-traitforge/blob/279b2887e3d38bc219a05d332cbcb0655b2dc644/contracts/EntityForging/EntityForging.sol#L87-L90)
```diff
require(
-    forgePotential > 0 && forgingCounts[tokenId] <= forgePotential,
+    forgePotential > 0 && forgingCount[tokenId] < forgePotential,
    'Entity has reached its forging limit'
);
```
