# Vulnerability details

## Vulnerability details
The `EntropyGenerator` contract has a specific requirement to exclude the value 999999 (referred to as "the Golden God") from the first two entropy initialization batches and deliberately include it in the final batch. However, the current implementation does not handle this requirement correctly, rendering the exclusion and deliberate inclusion of `999999` ineffective.

## Impact
The incorrect implementation affects the integrity of the entropy generation process, potentially leading to predictable or skewed randomness, which can be exploited or result in unintended behavior in dependent contracts.

## Proof of Concept
The pseudo-random value generation logic produces a 78-digit number not a 6 digit number, so there is no way that would exclude getting 999999 as the entropy value.

## Recommended Mitigation Steps
Modify the pseudo-random value generation to produce values within a more reasonable range.
Implement explicit logic to exclude 999999 from the first two batches and include it in the final batch.
