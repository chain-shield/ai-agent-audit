# Vulnerability details

## Impact
The function nuke(contract NukeFund) will revert as nuke function calls TraitForgeNft contract’s isApprovedOrOwner function, but the nuke function will revert as  _isApprovedOrOwner(spender, tokenId) function is not implemented in the TraitForgeNft contract.

## Proof of Concept
1. Let’s assume,  nuke function is called.

2. the nuke function calls TraitForgeNft contract’s isApprovedOrOwner function, but the nuke function will revert as  _isApprovedOrOwner(spender, tokenId) function is not implemented in the TraitForgeNft contract.

## Tools Used
manual review
## Recommended Mitigation Steps
Implement _isApprovedOrOwner(spender, tokenId) function in the TraitForgeNft contract.
