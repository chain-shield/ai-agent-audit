# Vulnerability details

## Impact
Listed NFT can be impossible to cancel and remain listed forever. This can occur when NFT owner first list an NFT for sale, then nukes the NFT.

## Proof of Concept
An NFT owner can list NFT for sale by calling the listNFTForSale function:

https://github.com/code-423n4/2024-07-traitforge/blob/279b2887e3d38bc219a05d332cbcb0655b2dc644/contracts/EntityTrading/EntityTrading.sol#L38

This lists the NFT.

And before a buyer buys the NFT, the NFT owner calls the nuke function, this burns the NFT.

https://github.com/code-423n4/2024-07-traitforge/blob/279b2887e3d38bc219a05d332cbcb0655b2dc644/contracts/NukeFund/NukeFund.sol#L176

Whereas, the NFT is still listed for sale.

It would be impossible to call cancelListing() or buy the NFT because the NFT is no longer in existence and has no owner.

https://github.com/code-423n4/2024-07-traitforge/blob/279b2887e3d38bc219a05d332cbcb0655b2dc644/contracts/EntityTrading/EntityTrading.sol#L99

## Tools Used
Manual review

## Recommended Mitigation Steps
tokenId should be checked if listed and cancelled first before calling the nuke().
