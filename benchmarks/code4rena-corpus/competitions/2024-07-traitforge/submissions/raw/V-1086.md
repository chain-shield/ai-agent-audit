# Vulnerability details

## Impact
Forger entities can be used for forging more than the allowed

## Proof of Concept
In EntityForging#listForForging() we check if the forgePotential is >= than the forgingCount (forgingCount starts at 0).

The issue is the following: it first make a check and then it increment the forgingCount itself in EntityForging#forgeWithListed().

A forger with forgePotential of 5 can be used for breeding 6 times before
resetting, contradicting the information we have in the whitepaper & docs + it was confirmed by the sponsor.

Let me give you an example of a forger with forgePotential of 4

1st check: forgingCount 0 <= 4 forgePotential -> true
2nd check: forgingCount 1 <= 4 forgePotential -> true
3rd check: forgingCount 2 <= 4 forgePotential -> true
4th check: forgingCount 3 <= 4 forgePotential -> true
5th check: forgingCount 4 <= 4 forgePotential -> true
6th check: forgingCount 5 <= 4 forgePotential -> false 

This allows us to breed our forger entity one more than intended, which is going to result in faster breed of entities, thus creating a bigger supply in less time and possibly diluting the entities.
