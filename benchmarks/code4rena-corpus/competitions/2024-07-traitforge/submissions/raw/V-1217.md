# Vulnerability details

## Impact
When `EntityForging::forgeWithListed()` is called, the user must send a certain amount of fee that is required for forging - `forgingFee`. If the user sends more than `forgingFee`, the excess amount will not be returned to the user and will remain locked in the smart contract.

Likelihood of user sending incorrect amount increases by the fact that forging fee is dynamic and can change.

## Proof of Concept

Place the following test into EntityForging.test.ts:

```javascript
it('contract locking assets', async () => {
      const forgerTokenId = FORGER_TOKEN_ID;
      const mergerTokenId = MERGER_TOKEN_ID;
  
      const forgerEntropy = await nft.getTokenEntropy(forgerTokenId);
      const mergerEntrypy = await nft.getTokenEntropy(mergerTokenId);
      /// The new token id will be forger token id + 1, cause it's the last item
      const expectedTokenId = FORGER_TOKEN_ID + 1;
      // Log user1's balance before forgeWithListed
      const user1BalanceBefore = await ethers.provider.getBalance(user1.address);
      console.log("User1 balance before forgeWithListed:", ethers.formatEther(user1BalanceBefore), "ETH");
      await expect(
        entityForging
          .connect(user1)
          .forgeWithListed(forgerTokenId, mergerTokenId, {
            value: FORGING_FEE+FORGING_FEE, //the user sends more fee than necessary
          })
      )
        .to.emit(entityForging, 'EntityForged')
        .withArgs(
          expectedTokenId,
          forgerTokenId,
          mergerTokenId,
          (forgerEntropy + mergerEntrypy) / 2n,
          FORGING_FEE
        )
        .to.emit(nft, 'NewEntityMinted')
        .withArgs(
          await user1.getAddress(),
          expectedTokenId,
          2,
          (forgerEntropy + mergerEntrypy) / 2n
        );
        // Log user1's balance after forgeWithListed
        const user1BalanceAfter = await ethers.provider.getBalance(user1.address);
        console.log("User1 balance after forgeWithListed:", ethers.formatEther(user1BalanceAfter), "ETH");
        
        expect(user1BalanceBefore-FORGING_FEE).to.not.equal(user1BalanceAfter); //we expect this to pass because the user was charged more than the required fee
    });
```
