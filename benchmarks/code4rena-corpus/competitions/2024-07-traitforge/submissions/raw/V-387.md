# Vulnerability details

## Summary

The WhitePaper documentation states that there is only one "Golden God" NFT, which is falsely represented in the code.
The "Golden God" NFT is minted when the NFT with the highest `entropy == 999999` is forged.

However, when we call the [TraitForgeNft::forge](https://github.com/code-423n4/2024-07-traitforge/blob/279b2887e3d38bc219a05d332cbcb0655b2dc644/contracts/TraitForgeNft/TraitForgeNft.sol#L153-L179) function, the so called “the Golden God” (999999) is set for to be currently minted `entropy` for the given generation, with the highest entropy generated so far, even if not being the "Golden God" NFT that by the documentation statement should be a "certain NFT with 999999 entropy".

[There is a certain entropy, “999999” which is referred to as “the Golden God”, since it has perfect parameters and will exceed all other entities if played correctly. The Golden God is scanned for and is kept out of the first 2 passes, but is deliberately set in the final pass (at some random point). The Golden God should be the most valuable entity.](https://docs.google.com/document/d/1pihtkKyyxobFWdaNU4YfAy56Q7WIMbFJjSHUAfRm6BA/edit)

## Vulnerability Details

It can be clearly seen in the code that when we mint an NFT by calling the `TraitForgeNft::mintToken` function, later in the logic calling `TraitForgeNft::_mintInternal` -> `EntropyGenerator::getNextEntropy` -> `EntropyGenerator::getEntropy` which if the attributes passed are equal to `slotIndexSelectionPoint` and `numberIndexSelectionPoint` which are set upon in `EntropyGenerator::initializeAlphaIndices()` which in itself is called in the `EntropyGenerator::constructor` and every gen-increment or `TraitForgeNft::forge` when a next-gen NFT will be minted. This all results that in every generation we would have a "Golden God NFT".

```solidity
  function getEntropy(
    uint256 slotIndex,
    uint256 numberIndex
  ) private view returns (uint256) {
    require(slotIndex <= maxSlotIndex, 'Slot index out of bounds.');
    // here
    if (
      slotIndex == slotIndexSelectionPoint &&
      numberIndex == numberIndexSelectionPoint
    ) {
      return 999999;
    }

    ...
  }
```

## Impact

The documentation is misleading, as the "Golden God" NFT is not a unique NFT with 999999 entropy, but rather the NFT with the highest entropy minted in the current generation.
