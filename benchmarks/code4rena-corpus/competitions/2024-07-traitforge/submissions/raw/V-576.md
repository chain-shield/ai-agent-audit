# Vulnerability details

## Impact
In the `TraitForgeNft.sol#_incrementGeneration` function, `generationMintCounts` is initialized to 0, so more NFTs can be created equal to the number of NFTs forged, which damages the core function of the protocol. This is a critical problem.

## Proof of Concept
The forging function in facilitates the forging between two entities, identified by parent1Id and parent2Id, to create a new entity.
```solidity
  function forge(
    ...
  ) external whenNotPaused nonReentrant returns (uint256) {
    require(
      msg.sender == address(entityForgingContract),
      'unauthorized caller'
    );
--> uint256 newGeneration = getTokenGeneration(parent1Id) + 1;

    SNIP...

--> uint256 newTokenId = _mintNewEntity(newOwner, newEntropy, newGeneration);
    
    return newTokenId;
  }
```
As you can see, a new Entity is minted for `newGeneration`.
That is, `generationMintCounts[newGeneration]` will be increased by the number of new Entities minted by the `forge()` function and will take a non-zero value.

The problem is that when the generation increases as a new NFT is minted by `mintToken/mintWithBudget`, the `generationMintCounts` of the next generation is initialized to 0.
```solidity
  function _incrementGeneration() private {
    require(
      generationMintCounts[currentGeneration] >= maxTokensPerGen,
      'Generation limit not yet reached'
    );
    currentGeneration++;
--> generationMintCounts[currentGeneration] = 0;
    priceIncrement = priceIncrement + priceIncrementByGen;
    entropyGenerator.initializeAlphaIndices();
    emit GenerationIncremented(currentGeneration);
  }
```
In this way, Even though multiple NFTs of the next generation have been created, NFTs of the next generation can be created again, and as a result, the number of NFTs in one generation can exceed 10,000.

## Recommended Mitigation Steps
It is recommended that the `_incrementGeneration` as follows:
```solidity
  function _incrementGeneration() private {
    require(
      generationMintCounts[currentGeneration] >= maxTokensPerGen,
      'Generation limit not yet reached'
    );
    currentGeneration++;
--- generationMintCounts[currentGeneration] = 0;
    priceIncrement = priceIncrement + priceIncrementByGen;
    entropyGenerator.initializeAlphaIndices();
    emit GenerationIncremented(currentGeneration);
  }
```
