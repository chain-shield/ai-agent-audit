# Vulnerability details

## Impact
calculateAge() function experience precision loss that will affect user's nuking reward calculations.
In solidity the division operator "/" has a function to round down. What this means for the calculateAge function is that a user 
may experience precision loss first with days old. Let say you had the nft for 7 days - 1 second.
Then this calculation:
```solidity
uint256 daysOld = (block.timestamp - nftContract.getTokenCreationTimestamp(tokenId)) / 60 / 60 / 24;
```
will result in 6 days. This is essentialy a whole day lost for the user.

If we continue with the execution of the code, we can see that we calculate the age. We can see that there still 
is a division operator and this time by 365. Here we still have precision loss although not as bad as daysOld.

Essentially difference in age will be perceptible as daysOld is multiplied by perfomanceFactor and MAX_DENOMINATOR.
```solidity
uint256 age = (daysOld * perfomanceFactor * MAX_DENOMINATOR * ageMultiplier) / 365; // adds to the precision loss
```

age is later used in calculateNukeFactor() which calculates the reward.
That means we lose in rewards due to precision loss.

Impact - medium (the loss is not as significant for a signle user, but if every user experience it these will be massive numbers)
Likelihood - high 
Overall - high
