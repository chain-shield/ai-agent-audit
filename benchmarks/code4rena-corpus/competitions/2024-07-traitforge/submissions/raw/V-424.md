# Vulnerability details

## Impact
EntityForging allows the merger to send more ETH than necessary in `forgeWithListed()`. It doesn't return the excess funds causing a loss of funds for the user.

## Proof of Concept
Excess funds aren't handled. They are just locked in the contract. It only splits the forge fee with the forger and the nuke fund

```sol
    (bool success, ) = nukeFundAddress.call{ value: devFee }('');
    require(success, 'Failed to send to NukeFund');
    (bool success_forge, ) = forgerOwner.call{ value: forgerShare }('');
    require(success_forge, 'Failed to send to Forge Owner');
```

## Tools Used
None

## Recommended Mitigation Steps
Return excess funds to msg.sender
