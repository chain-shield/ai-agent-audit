# Vulnerability details

## Impact
`mintToken()` and `mintWithBudget()` will always revert because `msg.sender` is not cast to `payable` when attempting to `refund excess ETH`.

## Proof of Concept
In [solidity](https://solidity-by-example.org/payable/), only Functions and `addresses` declared `payable` can receive `ether`.
For this reason, the `msg.sender` is  cast to `payable` in [`NukeFund::nuke()`]() so as to receive `claimAmount`:
```solidity
>>  (bool success, ) = payable(msg.sender).call{ value: claimAmount }('');
    require(success, 'Failed to send Ether');
```
However, in [`TraitForgeNft::mintToken()`](https://github.com/code-423n4/2024-07-traitforge/blob/279b2887e3d38bc219a05d332cbcb0655b2dc644/contracts/TraitForgeNft/TraitForgeNft.sol#L196-L198) and [`TraitForgeNft::mintWithBudget()`](https://github.com/code-423n4/2024-07-traitforge/blob/279b2887e3d38bc219a05d332cbcb0655b2dc644/contracts/TraitForgeNft/TraitForgeNft.sol#L221-L224), this is not done.
```solidity
    if (excessPayment > 0) {
>>    (bool refundSuccess, ) = msg.sender.call{ value: excessPayment }('');
      require(refundSuccess, 'Refund of excess payment failed.');
    }
```
```solidity
    if (budgetLeft > 0) {
>>    (bool refundSuccess, ) = msg.sender.call{ value: budgetLeft }('');
      require(refundSuccess, 'Refund failed.');
    }
```
Users will not receive refunds for excess ETH, causing transactions to fail.

## Tools Used
Manual Review

## Recommended Mitigation Steps
Cast `msg.sender` to `payable` in `mintToken()` and `mintWithBudget()`:
```diff
    if (excessPayment > 0) {
-     (bool refundSuccess, ) = msg.sender.call{ value: excessPayment }('');
+     (bool refundSuccess, ) = payable(msg.sender).call{ value: excessPayment }('');
      require(refundSuccess, 'Refund of excess payment failed.');
    }
```
```diff
    if (budgetLeft > 0) {
-     (bool refundSuccess, ) = msg.sender.call{ value: budgetLeft }('');
+     (bool refundSuccess, ) = payable(msg.sender).call{ value: budgetLeft }('');
      require(refundSuccess, 'Refund failed.');
    }
```
