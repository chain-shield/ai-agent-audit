# Vulnerability details

### [H-3] Incomplete Implementation of Pausable Contract Prevents Protocol from Being Paused

### Description
The Pausable contract from OpenZeppelin includes internal virtual functions _pause and _unpause, which are intended to be overridden in the main contract to implement the pausing functionality. Despite inheriting the Pausable contract, none of the protocol's contracts override these functions. As a result, the protocol cannot be paused or unpaused as intended.

### Proof of Concept
* Review the inherited Pausable contract in all protocol contracts.
* Observe that none of the contracts override the _pause and _unpause` functions.
Deploy the contracts and attempt to pause them.
Note that the owner cannot pause the contracts due to the lack of overridden functions.

### Impact
Critical functions protected by the whenNotPaused modifier will remain callable even when the contracts should be paused during critical conditions. This could lead to unintended and potentially harmful interactions with the protocol.

### Recommended Mitigation
Override the pause and unpause functions in all relevant contracts. Ensure these functions are protected by the onlyOwner modifier to restrict pausing and unpausing capabilities to the contract owner.
```solidity
function pause() external override onlyOwner {
    _pause();
}

function unpause() external override onlyOwner {
    _unpause();
}
```
Implementing these changes will allow the protocol to be paused and unpaused as needed, ensuring better control during critical conditions.
