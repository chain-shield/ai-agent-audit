# Vulnerability details

## Impact
Every time a new entity is forged there is a msg.value that is sent by the merger along the transaction that must be >= forging fees. For cases where the msg.value is in excess there is no refund to the merger and the excess will get stuck in the contract forever.

## Proof of Concept
Inside TraitForgeNft.sol, excess msg.value are handled correctly and reimbursed to the caller whenever they are > 0. However that is not the case when calling EntityForging.forgeWithListed().
At this line there is a check to make sure msg.value >= forging fees: https://github.com/code-423n4/2024-07-traitforge/blob/279b2887e3d38bc219a05d332cbcb0655b2dc644/contracts/EntityForging/EntityForging.sol#L126

And devFee and forger fees are correctly forwarded to them here: https://github.com/code-423n4/2024-07-traitforge/blob/279b2887e3d38bc219a05d332cbcb0655b2dc644/contracts/EntityForging/EntityForging.sol#L156-L159

But there is no refund for any excess msg.value that might be sent along with the transaction and this eventually will get stuck inside the contract forever incuring a permanent loss for the merger.

Copy and paste this test inside EntityForging.test.ts, do not forget to paste this at the top of the file: 
```
const EXCESS_FEE = ethers.parseEther('3.0'); // 3 ETH
```
``` solidity
it.only('Does not refund user excess value sent with the transaction', async () => {
      const forgerTokenId = FORGER_TOKEN_ID;
      const mergerTokenId = MERGER_TOKEN_ID;
      const fee = FORGING_FEE;

      // list for forging
      await entityForging.connect(owner).listForForging(forgerTokenId, fee);

      const listedTokenId = await entityForging.listedTokenIds(forgerTokenId);
      const listing = await entityForging.listings(listedTokenId);
      expect(listing.isListed).to.be.true;
      expect(listing.fee).to.equal(fee);
      // user1 bal before forging
      const balBefore = await ethers.provider.getBalance(user1.address);
      console.log("user bal before", balBefore);
      // forge with excess 2 ETH fees
      // const EXCESS_FEE = ethers.parseEther('3.0'); // 3 ETH
      let newId = await
        entityForging
          .connect(user1)
          .forgeWithListed(forgerTokenId, mergerTokenId, {
            value: EXCESS_FEE,
          });

      const balAfter = await ethers.provider.getBalance(user1.address);
      console.log("user bal after", balAfter);

      // Log the diff of bal
      // it's 3 ETH + gas fees spent on the transaction (3000519192647277026 wei)
      console.log("Total fee + gas spent",balBefore - balAfter);


    });
```
