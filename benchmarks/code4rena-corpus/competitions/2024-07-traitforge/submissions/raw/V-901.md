# Vulnerability details

## Impact
fetchListings can be DOS (out of gas) when iterating the loop if the are a lot of listings. If this happens players won’t be able to select a forger nft to forge with

## Proof of Concept

```solidity
  function fetchListings() external view returns (Listing[] memory _listings) {
    _listings = new Listing[](listingCount + 1);
    for (uint256 i = 1; i <= listingCount; ++i) {
      _listings[i] = listings[i];
    }
  }
```
## Tools Used
Manual Review

## Recommended Mitigation Steps
Store the listings in different mappings (based on generation), and when fetching fetch by generation.


## Assessed type

DoS
