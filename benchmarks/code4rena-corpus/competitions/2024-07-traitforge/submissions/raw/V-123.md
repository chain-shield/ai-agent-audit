# Vulnerability details

## Impact
As per the contest docs, each generation should have a maximum of 10000 NFTs. NFTs can be created by forging or minting. Since `generationMintCounts[currentGeneration]` is set to 0 when incrementing the `currentGeneration` value, the further generations can have more than 10000 NFTs.

## Proof of Concept
Consider this scenario:

> Let's say 8000 of Gen-1 NFTs are minted.
> These NFTs are then forged and 2000 new Gen-2 NFTs are created by forging.
> When Gen-1 mint count reaches 10000, `_incrementGeneration` will be called for further mints.
> This would first increase `currentGeneration` value from 1 to 2 and then reset `generationMintCounts[currentGeneration]` to 0. After this another 10000 NFTs of Gen-2 can be minted.
> This would be the case for all generations from Gen-2 to Gen-10.

```javascript
  function _incrementGeneration() private {
    require(
      generationMintCounts[currentGeneration] >= maxTokensPerGen,
      'Generation limit not yet reached'
    );
    currentGeneration++;
    generationMintCounts[currentGeneration] = 0;
    priceIncrement = priceIncrement + priceIncrementByGen;
    entropyGenerator.initializeAlphaIndices();
    emit GenerationIncremented(currentGeneration);
  }
```

## Recommended Mitigation Steps

Simply removing the line `generationMintCounts[currentGeneration] = 0` won't solve the issue.

If this line is removed, consider the following scenario:

> Let's say 8000 of Gen-1 NFTs are minted.
> These NFTs are then forged and all of 10000 new Gen-2 NFTs are created by forging.
> When Gen-1 reaches 10000 NFTs and `mintToken` is called again, inside `_mintInternal` it'll increment the generation to Gen-2, but 10000 of Gen-2 are already created by forging, so it need to increment further however this is not the case.
> This allows 10001 NFTs of Gen-2 to be minted before it moves on to Gen-3.


Probable Fix:
```diff
  function _incrementGeneration() private {
    require(
      generationMintCounts[currentGeneration] >= maxTokensPerGen,
      'Generation limit not yet reached'
    );
    currentGeneration++;
-   generationMintCounts[currentGeneration] = 0;
    priceIncrement = priceIncrement + priceIncrementByGen;
    entropyGenerator.initializeAlphaIndices();
    emit GenerationIncremented(currentGeneration);
  }
```

```diff
  function _mintInternal(address to, uint256 mintPrice) internal {
-   if (generationMintCounts[currentGeneration] >= maxTokensPerGen) {
+   while (generationMintCounts[currentGeneration] >= maxTokensPerGen) {
      _incrementGeneration();
    }
```
