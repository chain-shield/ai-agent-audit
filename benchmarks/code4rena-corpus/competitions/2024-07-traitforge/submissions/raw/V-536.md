# Vulnerability details

## Impact
The following contracts do not implement pausability functionality correctly from Openzeppelin `Pausable` contract:
 `DevFund`, `EntityForging`, `EntityTrading`, `EntropyGenerator`, `NukeFund`, `TraitForgeNft`.
Without pausability functionality enabled correctly, none of these contracts are protected from cases where the owner needs to pause critical functions from happening during a crucial moment in time such as an exploit being found.

## Proof of Concept

Inside `Pausable` you can see the functions `Pausable::_pause` and `Pausable::_unpause` have internal visibility, which means the contract inheriting can't directly call these.
```
    function _pause() internal virtual whenNotPaused {
        _paused = true;
        emit Paused(_msgSender());
    }
    function _unpause() internal virtual whenPaused {
        _paused = false;
        emit Unpaused(_msgSender());
    }
```

## Tools Used
Foundry

## Recommended Mitigation Steps
Implement new functions `pause` and `unpause` in all affected contracts:

```diff
+  function pause() external onlyOwner {
+    _pause();
+  }

+  function unpause() external onlyOwner {
+    _unpause();
+  }
```
