# Vulnerability details

 ## Impact
it is mentioned in the docs `There are a total of 10 Generations (extended as the game goes on), which can be minted in parallel via a breeding mechanism.` however when the function `_incrementGeneration` is called in mint function after the current generation has reached it's limit, the `generationMintCounts` for the next generation is set to 0 without accounting for nfts that were minted by forging.
```javascript
function _incrementGeneration() private {
    require(generationMintCounts[currentGeneration] >= maxTokensPerGen, "Generation limit not yet reached");
    currentGeneration++;
    generationMintCounts[currentGeneration] = 0;
    priceIncrement = priceIncrement + priceIncrementByGen;
    entropyGenerator.initializeAlphaIndices();
    emit GenerationIncremented(currentGeneration);
}
```
this means the next generation might have more nfts than what `generationMintCounts[currentGeneration]` shows and hence could lead to more tokens in a generation than the intended maximum`.
Users aware of this issue could strategically forge tokens of the next generation before the current generation ends, essentially getting "uncounted" tokens.
## Proof of Concept
In the following test We assume `MaxTokensPerGen` is 100 for the sipmlicity of the test, we show that Current generation is 1, with 98 tokens minted (out of 100 max for this example)
2 tokens of generation 2 have been created through forging
The last 100 tokens of `generation 1` are minted, and a new token from `generation 2` is also minted triggering `_incrementGeneration`, the `generationMintCounts` is 1 and didn't account for the 2 tokens created through forging.
```javascript
function testMintAndGenerationIncrementWithForging() public {
        bytes32[] memory proof = new bytes32[](0); // Adjust based on your Merkle proof setup
        vm.startPrank(owner);
        traitForgeNft.setWhitelistEndTime(block.timestamp);
        traitForgeNft.setMaxGeneration(100);

        vm.stopPrank();
        vm.warp(block.timestamp + 2 hours);
        vm.startPrank(user);
        vm.deal(user, 100 ether);

        uint256 initialGeneration = traitForgeNft.getGeneration();
        console.log("initialGeneration",initialGeneration);

        // Mint 9,900 tokens for generation 1
        for (uint256 i = 0; i < 98; i++) {
            traitForgeNft.mintToken{value: 1 ether}(proof);
        }
        vm.stopPrank();
        // Forge some tokens for generation 2
        vm.startPrank(address(entityForging));
        traitForgeNft.forge(address(this), 1, 2, "tokenURI");
        traitForgeNft.forge(address(this), 3, 4, "tokenURI");
        vm.stopPrank();
        // // Ensure some tokens are forged for generation 2
        uint256 forgedTokenGen1 = traitForgeNft.getTokenGeneration(99);
        uint256 forgedTokenGen2 = traitForgeNft.getTokenGeneration(100);
        assertEq(forgedTokenGen1, initialGeneration + 1, "Forged token 1 generation is incorrect");
        assertEq(forgedTokenGen2, initialGeneration + 1, "Forged token 2 generation is incorrect");
        vm.startPrank(user);
        // // Mint the remaining 100 tokens for generation 1
        for (uint256 i = 0; i < 3; i++) {
            traitForgeNft.mintToken{value: 1 ether}(proof);
        }

        // // Check that the generation incremented
        uint256 newGeneration = traitForgeNft.getGeneration();
        assertEq(newGeneration, initialGeneration + 1, "Generation did not increment correctly");

        // // Check that generationMintCounts is not reset to 0
        uint256 gen2MintCount = traitForgeNft.generationMintCounts(newGeneration);
        console.log("gen2MintCount",gen2MintCount);
        assertEq(gen2MintCount, 3, "Generation 2 mint count is incorrect");
    }
```
