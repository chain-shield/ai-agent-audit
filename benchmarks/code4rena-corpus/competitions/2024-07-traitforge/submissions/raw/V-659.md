# Vulnerability details

## Impact
Multiple contracts use `whenNotPaused` modifier. But there is no function to update   `_paused` state. There is no way to pause these contrats. 

## Proof of Concept

`DevFund` , `EntityForging`, `EntityTrading`, `EntropyGenerator`, `NukeFund`, `TraitForgeNft` contracts use openzeppelin `Pausable` contract. But `Pausable` doesnt have a public function to update pause state. Because of this multiple contracts can not be paused.

``` solidity
import '@openzeppelin/contracts/security/Pausable.sol';

contract DevFund is IDevFund, Ownable, ReentrancyGuard, Pausable {
```
