# Vulnerability details

## Impact
The seller can steal buyer funds when a buyer calls the `buyNFT` function to buy NFT
and calls to transfer ETH to their address The seller is watching this transaction and before NFTs transfer to the buyer's address seller calls `cancelListing` function with high gas fees to cancel the listing of NFTs and the buyer is unable to get their NFT because the NFTs are not listed their this happens due to not following check-effect-interaction in code.

```
  function cancelListing(uint256 tokenId) public whenNotPaused nonReentrant {
    Listing storage listing = listings[listedTokenIds[tokenId]];

    // check if caller is the seller and listing is acivte
    require(
      listing.seller == msg.sender,
      'Only the seller can canel the listing.'
    );
    require(listing.isActive, 'Listing is not active.');

    nftContract.transferFrom(address(this), msg.sender, tokenId); // transfer the nft back to seller

    delete listings[listedTokenIds[tokenId]]; // mark the listing as inactive or delete it

    emit ListingCanceled(tokenId, msg.sender);
  }
```

### Steps to Reproduce:
Buyer calls buyNFT: The buyer sends ETH to purchase an NFT.
ETH Transfer to Seller: The contract transfers ETH to the seller before transferring the NFT to the buyer.
Seller Monitors Network: The seller monitors the network for the incoming transaction.
Seller Calls cancelListing: The seller immediately calls cancelListing to transfer the NFT back to themselves and cancel the listing.
The seller's transaction is mined before the buyNFT function completes because the seller pays high gas fees, the seller can receive the ETH and cancel the listing, preventing the buyer from receiving the NFT.
