# Vulnerability details

## Summary

The entropy of the NFT that is minted should be random. The randomness which is used in the code in order to check if the special NFT with 999999 entropy has to be minted is not actually random and allows a user to predict when that NFT will be minted.

## Proof of Concept

In the `EntropyGenerator::initializeAlphaIndices` function the value of the `hashValue` variable is predictable by the users.  `slotIndexSelectionPoint` and `numberIndexSelectionPoint` are calculated using the hashValue variable which also makes them predictable which makes the check for the 999999 entropy in the `EntropyGenerator::getEntropy` predictable. A user can calculate when the token with 999999 entropy will be minted and then mint it for himself

## Recommended Mitigation steps

Get the randomness offchain (e.g. ChainLink VRF)
