# Vulnerability details

## Impact
The `cancelListing` function does not update the `listedTokenIds` mapping when a listing is canceled. This will cause an issue specifically, the `listedTokenIds[tokenId]` will still point to the old index, which can cause errors or unexpected behavior in the contract.


## Proof of Concept
The current implementation of the `cancelListing` function only deletes the entry from the `listings` mapping but fails to update the `listedTokenIds` mapping: https://github.com/code-423n4/2024-07-traitforge/blob/279b2887e3d38bc219a05d332cbcb0655b2dc644/contracts/EntityTrading/EntityTrading.sol#L94-L109

```solidity
function cancelListing(uint256 tokenId) public whenNotPaused nonReentrant {
    Listing storage listing = listings[listedTokenIds[tokenId]];

    // check if caller is the seller and listing is active
    require(
        listing.seller == msg.sender,
        'Only the seller can cancel the listing.'
    );
    require(listing.isActive, 'Listing is not active.');

    nftContract.transferFrom(address(this), msg.sender, tokenId); // transfer the nft back to seller

    delete listings[listedTokenIds[tokenId]]; // mark the listing as inactive or delete it

    emit ListingCanceled(tokenId, msg.sender);
}
```

This implementation leaves the `listedTokenIds[tokenId]` intact, pointing to a now-deleted listing. If the same token is listed again, it may cause conflicts with the old, invalid listing index.

## Recommended Mitigation Steps
Update the `cancelListing` function to also delete the entry in the `listedTokenIds` mapping:

```diff
function cancelListing(uint256 tokenId) public whenNotPaused nonReentrant {
    Listing storage listing = listings[listedTokenIds[tokenId]];

    // check if caller is the seller and listing is active
    require(
        listing.seller == msg.sender,
        'Only the seller can cancel the listing.'
    );
    require(listing.isActive, 'Listing is not active.');

    nftContract.transferFrom(address(this), msg.sender, tokenId); // transfer the nft back to seller

    delete listings[listedTokenIds[tokenId]]; // mark the listing as inactive or delete it
+   delete listedTokenIds[tokenId]; // also delete the entry in listedTokenIds mapping

    emit ListingCanceled(tokenId, msg.sender);
}
```
