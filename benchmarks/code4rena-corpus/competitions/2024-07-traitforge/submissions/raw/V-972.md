# Vulnerability details

## Impact
Repetitive executions of the same nuke factor tokenId can result in multiple withdrawals from the `NukeFund.sol` contract, potentially depleting its funds. This exploit allows a malicious user to almost drain the contract, leading to financial loss and disruption of the intended game mechanics.

## Proof of Concept
To illustrate this issue, consider the following scenario:

1. A malicious user utilizes multiple accounts that possess different NFTs.
2. The malicious user forges the same NFTs multiple times using different accounts until their ForgePotential reaches its maximum.
3. The resulting forgedId NFTs have the same NukeFactor since they are produced using the same parentIds.
4. The cooldown period for the minimum days held of the NFTs passes, allowing the malicious user to nuke multiple NFTs with the same NukeFactor simultaneously.

This results in multiple withdrawals of funds from the `NukeFund.sol` contract. Depending on the number of NFTs produced, this exploit can nearly empty the contract.

## Tools Used
Manual review

## Recommended Mitigation Steps
Prevent the forging of the same parentIds or implement a cooldown period during which the same parentId cannot be forged again. This will limit the ability of malicious users to exploit the system and drain huge amounts of the contract's funds.
