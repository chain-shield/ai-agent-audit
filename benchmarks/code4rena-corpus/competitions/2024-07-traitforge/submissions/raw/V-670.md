# Vulnerability details

## Impact
Owner of `Airdrop` contract is the `TraitForgeNft`. Owner of `TraitForgeNft` contract should be able to pause the `Airdrop` contract.

## Proof of Concept
`Airdrop` contract cannot be paused because no relevant functions are implemented in both `Airdrop` and `TraitForgeNft` contract.

## Tools Used
Manual Review

## Recommended Mitigation Steps
Implement a function in `Airdrop` contract with `onlyOwner` modifier so that only `TraitForgeNft` contract can pause it. Implement another function in `TraitForgeNft` contract with `onlyOwner` that calls the previous function is `Airdrop` to pause it.

Access Control
