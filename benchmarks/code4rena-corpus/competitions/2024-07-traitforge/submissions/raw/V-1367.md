# Vulnerability details

## Summary
The entropy of entities is determined before mining, allowing malicious users to frontrun and buy valuable entities before normal users can. When the next entity to mint has an undesirable entropy like 000000 or 111111, no one would spend money to buy those, potentially halting the minting process.

## Impact
MEV (Miner Extractable Value) attacks on minting entities can prevent normal users from making proper profits. This could disappoint users and lead them to quit the game.

## Tools Used
Manual review

## Recommended Mitigation Steps
Use tools like Chainlink VRF (Verifiable Random Function) to add randomness to the minting of new entities.


## Assessed type

MEV
