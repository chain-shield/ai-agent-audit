# Vulnerability details

## Impact
The current implementation of the listNFTForSale function allows the token owner to list the same tokenId multiple times with different prices. This issue arises because there is no check to see if the token is already listed for sale. Consequently, the owner could create multiple listings for the same NFT, each with a different price, potentially leading to confusion and inconsistencies in the contract's state.

## Recommended Mitigation Steps

The additional check (listingId == 0 || !listings[listingId].isActive) ensures that an NFT cannot be listed again if it is already active. This prevents the creation of multiple listings for the same token ID with different prices.
```
function listNFTForSale(
    uint256 tokenId,
    uint256 price
) public whenNotPaused nonReentrant {
    require(price > 0, 'Price must be greater than zero');
    require(
        nftContract.ownerOf(tokenId) == msg.sender,
        'Sender must be the NFT owner.'
    );
    require(
        nftContract.getApproved(tokenId) == address(this) ||
        nftContract.isApprovedForAll(msg.sender, address(this)),
        'Contract must be approved to transfer the NFT.'
    );
    
 
  +  uint256 listingId = listedTokenIds[tokenId];
  +  require(listingId == 0 || !listings[listingId].isActive, 'NFT is already listed.');

    nftContract.transferFrom(msg.sender, address(this), tokenId); // transfer NFT to contract

    ++listingCount;
    listings[listingCount] = Listing(msg.sender, tokenId, price, true);
    listedTokenIds[tokenId] = listingCount;

    emit NFTListed(tokenId, msg.sender, price);
}

```
