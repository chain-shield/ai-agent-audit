# Vulnerability details

## Vulnerability details

It is a common practice to ensure that users are not overcharged due to miscalculations or overpayments.

This logic is correctly included in `mintToken` and `mintWithBudget` functions, 
but missing in `forgeWithListed` function.

When a user sends extra ETH while forging, 
the surplus should be refunded to the sender. 

## Impact

Loss of funds:
Users will lose any surplus ETH sent while forging.

## Tools Used

Manual Review

## Recommended Mitigation Steps

Add the following lines to `forgeWithListed` function.

```
// Refund extra ETH if sent
if (msg.value > forgingFee) {	
        uint256 excessPayment = msg.value - forgingFee ;			
        (bool refundSuccess, ) = msg.sender.call{ value: excessPayment  }('');
        require(refundSuccess, 'Refund failed');
}
```
