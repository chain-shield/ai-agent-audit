# Vulnerability details

## Impact
All contracts in scope (`NukeFund.sol`, `TraitForgeNft.sol`, `EntityForging.sol`, `EntityTrading.sol`, `EntropyGenerator.sol`, `DevFund.sol`) implement the Pausable interface from OpenZeppelin, and they all use the `whenNotPaused` modifier in different functions. 
However, none of the contracts actually implement any function to pause or unpause the contracts. `Pausable.sol` only implements internal functions that require external functions to be implemented to wrap them.
Due to the lack of implementation for these functions, the owner cannot pause or unpause the contracts, rendering the pause system ineffective.

## Tools Used
VS Code, Manual Review

## Recommended Mitigation Steps
Create external functions to pause / unpause the contracts that can only be called by the owner. These functions should then call `_pause() / _unpause()` from the Pausable interface.
