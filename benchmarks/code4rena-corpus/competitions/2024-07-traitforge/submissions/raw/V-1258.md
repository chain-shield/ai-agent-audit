# Vulnerability details

## Description
The ratio of Mergers to Forgers is 2:1, but the current contract implementation assigns roles based on entropy % 3 == 0, which results in a 1:2 ratio instead.

## Impact
1.Inverted Role Ratio: The actual ratio of Forgers to Mergers will be reversed from the intended 2:1.
2.Game Balance Disruption: This discrepancy could significantly alter game balance and economic dynamics.

## Proof of Concept
Under the current implementation:

* When `entropy % 3 == 0`: `isForger` is true.
* When `entropy % 3 != 0`: `isForger` is false.
This results in approximately 33% Forgers and 67% Mergers, contrary to the intended 2:1 ratio.

## Tools Used
Manual Review

## Recommended Mitigation Steps
1.Adjust Role Assignment Logic:
```
uint256 role = entropy % 3;
isForger = role == 2;
```
2.Alternative Method for Desired Ratio:
```
isForger = entropy % 3 < 2;
```
