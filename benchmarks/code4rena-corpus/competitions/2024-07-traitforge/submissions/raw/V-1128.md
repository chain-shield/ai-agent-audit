# Vulnerability details

## Impact
According to the docs and dev, users have to wait 3 days before being able to nuke their NFT:
> After a 3-day maturity period, anyone can nuke their entity (forever burn) to claim a share of the ETH in the Fund

> -Can people nuke their nfts in the first generations?
-Yes but they must wait 3 days after acquiring

However they can nuke whenever they want without waiting 3 days.

## Proof of Concept
The function `NukeFund.sol:canTokenBeNuked()` returns whether a token can be nuked or not. It does so by checking if the 3 day period has passed:
```solidity
  function canTokenBeNuked(uint256 tokenId) public view returns (bool) {
...
    uint256 tokenAgeInSeconds = block.timestamp -
      nftContract.getTokenLastTransferredTimestamp(tokenId);
    // Assuming tokenAgeInSeconds is the age of the token since it's holding the nft, check if it's over minimum days held
    return tokenAgeInSeconds >= minimumDaysHeld;
  }
```
According to the comment it assumes that `tokenAgeInSeconds` is the time that has passed since the current owner of the token acquired it.
The issue here is that it checks how much time has passed since the token was transferred between users. If the owner has only minted the token without transferring it then he will be able to nuke at any time.

`getTokenLastTransferredTimestamp()` returns a mapping `lastTokenTransferredTimestamp[tokenId]`. This mapping is only changed in `_beforeTokenTransfer()` which is called only during transfers and not on mints. 
This means that if the owner hasn't transferred his token then the mapping will return 0. Now if we try to calculate `tokenAgeInSeconds` we will get `block.timestamp - 0` which will always be more than 3 days. This means any user can nuke his token after minting without waiting.

When I messaged the dev about this issue he said that "Minting sets value for getTokenCreationTimeStamp". Perhaps it was intended for `canTokenBeNuked()` to also check for `getTokenCreationTimeStamp` but it does not.

## Recommended Mitigation Steps
```diff
  function canTokenBeNuked(uint256 tokenId) public view returns (bool) {
...
-    uint256 tokenAgeInSeconds = block.timestamp -
-      nftContract.getTokenLastTransferredTimestamp(tokenId);
...
-    return tokenAgeInSeconds >= minimumDaysHeld;

+    uint256 ageSinceTransfer = block.timestamp -
+      nftContract.getTokenLastTransferredTimestamp(tokenId);

+    uint256 ageSinceBirth = block.timestamp -
+      nftContract.getTokenCreationTimestamp(tokenId);

+    return ageSinceTransfer >= minimumDaysHeld &&
+    ageSinceBirth >= minimumDaysHeld
  }
```
