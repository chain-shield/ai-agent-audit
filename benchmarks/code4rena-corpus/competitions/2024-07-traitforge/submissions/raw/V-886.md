# Vulnerability details

## Impact

All of the contracts in scope inherit from the Pausable contract, but as that’s not enough, none of the contracts can be paused, consequently all functions with the modifier whenNotPaused won’t be paused as well.  

## Proof of Concept

The following contracts are in scope for this audit: `TraitForgeNft, NukeFund, EntropyGenerator, EntityTrading, EntityForging and DevFund` - all of which inherit from the [Pausable](https://github.com/OpenZeppelin/openzeppelin-contracts/blob/master/contracts/utils/Pausable.sol) contract. Its primary purpose is to allow the inheriting contract to pause/unpause functions that have the modifiers [whenNotPaused/whenPaused](https://github.com/OpenZeppelin/openzeppelin-contracts/blob/master/contracts/utils/Pausable.sol#L54-L69).

However, one important step was missed, and that is making an external function for both the internal [pause/unpause](https://github.com/OpenZeppelin/openzeppelin-contracts/blob/master/contracts/utils/Pausable.sol#L103-L118) functions. Without them, the contracts can’t take advantage of the functionality of `Pausable`, therefore none of the functions with the modifier `whenNotPaused` can be paused.

## Tools Used

Manual Review

## Recommended Mitigation Steps

To address the issue, two external functions must be implemented in all inheriting contracts:

```solidity
function pause() external onlyOwner {
 _pause();
}

function unpause() external onlyOwner {
 _unpause();
}
```
