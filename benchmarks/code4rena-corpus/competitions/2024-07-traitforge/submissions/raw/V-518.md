# Vulnerability details

## Vulnerability details 

As per the current implementation, 
The `TraitForgeNft` can have a maximum of 10 generations defined by the  
`maxGeneration` variable which can be changed later if needed.

`
maxGeneration =  10
`

The `_incrementGeneration` is the function 
responsible for handling the `currentGeneration` count.

It is important that the `currentGeneration` 
cannot exceed the `maxGeneration`

However currently there is no check to ensure that the
`currentGeneration` does not increase beyond the `maxGeneration`



## Impact

`currentGeneration` will exceed the defined  `maxGeneration` of 10,
which also means there is no limit on the NFTs minted.

For example
If `_incrementGeneration` is called when `currentGeneration` is 10, 
`currentGeneration` will be incremented to 11,
and total NFTs minted could exceed 100,000
both of which are beyond the allowed limits.

## Recommended Mitigation Steps

Consider including the following check after incrementing the `currentGeneration` 


```
currentGeneration++;

if(currentGeneration > maxGeneration) {
  revert MaxGenerationError();
}

 ```
