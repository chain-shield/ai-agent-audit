# Vulnerability details

## Impact
The line uint256(10) ** 78 is intended to be used as the modulo to generate the pseudo-random number. However, this value exceeds the maximum limit for a uint256, causing an overflow. The maximum value a uint256 can hold is 2**256−1, which is a 78-digit number. Therefore, uint256(10) ** 78 will overflow, resulting in a value that is only 77 digits long, leading to a lack of 13 entropy slots.

## Proof of Concept
considering the max of uint256 is 
- 2**256 -1 which is a 78 digits number allowing for 13 (6 digits) entropy slots
- 10**78 results in a 79 digits number which is bigger than max uint leading to an overflow to this number : 73663286101470436611432119930496737173840122674875487684339327936694962880520
- the number is 77 digits which not allow to have 13 slots as it requires 78 digits
