# Vulnerability details

## Description 
The `TraitForgeNft` contract includes a function `calculateMintPrice()` that determines the price for minting new tokens. This function is crucial as it directly impacts the cost users incur when minting tokens. The current implementation of `calculateMintPrice()` calculates the mint price based on the `startPrice` and the `priceIncrement` multiplied by the number of tokens minted in the current generation. However, it omits the `priceIncrementByGen`, which should increase the base price with each new generation. This omission results in an incorrect mint price, potentially leading to financial discrepancies and unfair pricing for users across different generations.

## Impact
The incorrect calculation of the mint price can lead to users being charged less than intended for minting tokens in later generations. This could result in a loss of revenue for the contract owner and an unfair advantage for users minting tokens in later generations. The financial model of the contract is undermined, leading to potential economic imbalances and user dissatisfaction.

## Proof of Concept
1. A user attempts to mint a token in the second generation.
2. The `calculateMintPrice()` function is called to determine the mint price.
3. The function calculates the price as `startPrice + (priceIncrement * currentGenMintCount)`, omitting the `priceIncrementByGen`.
4. The user is charged less than the intended price, resulting in a financial discrepancy.

## Recommended Mitigation Steps
Include the `priceIncrementByGen` in the `calculateMintPrice()` function to ensure the mint price accurately reflects the intended pricing model. The updated function should be:

```diff
function calculateMintPrice() public view returns (uint256) {
    uint256 currentGenMintCount = generationMintCounts[currentGeneration];
    uint256 priceIncrease = priceIncrement * currentGenMintCount;
+   uint256 genPriceIncrease = priceIncrementByGen * (currentGeneration - 1);
    uint256 price = startPrice + priceIncrease;
+   price += genPriceIncrease;
    return price;
}
```

This update ensures that the mint price calculation includes the incremental price increase for each generation, aligning with the intended pricing model.
