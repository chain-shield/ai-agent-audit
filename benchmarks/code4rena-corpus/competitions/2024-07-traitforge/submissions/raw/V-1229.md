# Vulnerability details

## Impact
In `writeEntropyBatch1`, `writeEntropyBatch2`, and `writeEntropyBatch3`, the calculation for `pseudoRandomValue` is

```solidity
  uint256 pseudoRandomValue = uint256(
    keccak256(abi.encodePacked(block.number, i))
  ) % uint256(10) ** 78;
```

Since `uint256` can not hold `10**78`, `10**78` will be overflow to `10**78 % 2**256`. As a result, the largest value of the entropy slot can only be `(10**78 % 2**256) / 10**72 = 73663`.

## Tools Used
Manual Review.

## Recommended Mitigation Steps
Let an entropy slot hold only a 12 six-digit number.



## Assessed type

Under/Overflow
