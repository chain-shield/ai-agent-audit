# Vulnerability details

## Impact
Contracts can't be paused as the pause function is not overridden

## Proof of Concept
All of the contracts in scope inherit the `Pausable` contract. To pause the contracts, this function should be called:
```solidity
    function _pause() internal virtual whenNotPaused {
        _paused = true;
        emit Paused(_msgSender());
    }
```
The issue is that the function is internal. In order to use the functionality, the function should be overridden in the according contract. Since it is not, the function will not be callable.

## Tools Used
Manual Review

## Recommended Mitigation Steps
Override the `_pause()` and `_unpause()` functions
