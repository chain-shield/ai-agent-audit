# Vulnerability details

## Impact
Minting can be done by anyone for free, that inherits the TraitForgeNft contract.
Malicious user that is not whitelisted could create a contract that inherits the TraitForgeNft contract calling _mintInternal as much times as he likes.

```solidity
function _mintInternal(address to, uint256 mintPrice) internal { //@audit internal mint function could be used by other contracts that inherits it 
    if (generationMintCounts[currentGeneration] >= maxTokensPerGen) {
      _incrementGeneration();
    }

```

Impact - high (evades whitelisted modifier)
Likelihood - high
Overall - high

## Proof of Concept
Alice creates AttackMint and calls attack as much as she wants for as much mintPrice as she wants (probably 0 wei) making it free to mint to the "to" address.

```solidity
contract AttackMint is TraitForgeNft{
    function attack() public{
        super._mintInternal(to, mintPrice);
    }
}
```
