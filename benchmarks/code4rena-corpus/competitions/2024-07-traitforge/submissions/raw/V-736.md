# Vulnerability details

## Impact
`mergerEntropy` being greater than 255 will silently overflow.

## Proof of Concept
[forgeWithListed](https://github.com/code-423n4/2024-07-traitforge/blob/main/contracts/EntityForging/EntityForging.sol#L138) function is downcasting uint256 type to uint8 type which can cause potential issues when value of `mergerEntropy` is greater than 255, this will cause silent overflow withing the function and will lead to unexpected results.

## Tools Used
Manual Review
## Recommended Mitigation Steps
Use uint256 instead of uint8


## Assessed type

Under/Overflow
