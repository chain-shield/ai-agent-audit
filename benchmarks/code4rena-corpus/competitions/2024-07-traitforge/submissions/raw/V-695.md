# Vulnerability details

## Impact
Contract functions are unable to be paused as intended

## Proof of Concept
Several contracts in the codebase utilize the Pausable feature but lack the necessary functions to actually pause or unpause them. The Pausable library only provides internal functions, which means external controls for pausing are missing. As a result, the intended pausing functionality is currently inoperable
```
function testNoPausing() public {
        vm.warp(block.timestamp + 25 hours);
        vm.roll(1);
        vm.deal(alice, 10e18);
        vm.deal(bob, 1e18);

        vm.prank(owner);
        entropyGenerator.writeEntropyBatch1();

        vm.prank(owner);
        //doesnt compile as function is not implemented
        entityForging.pause();
}
```
## Tools Used
Manual Review

## Recommended Mitigation Steps
Implement external pause and unpause functions that can be called by owner only.
