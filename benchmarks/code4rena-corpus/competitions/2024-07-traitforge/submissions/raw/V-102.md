# Vulnerability details

## Impact
**`mintWithBudget()`** is used to mint multiple NFTs in a single transaction. However, the function checks **`_tokenIds`** instead of **`generationMintCounts[currentGeneration]`**, which restricts minting to the first generation only, rendering the function useless for subsequent generations.

## Proof of Concept
**`mintWithBudget()`** is implemented as follows.
```Solidity
function mintWithBudget(
    bytes32[] calldata proof
  )
    public
    payable
    whenNotPaused
    nonReentrant
    onlyWhitelisted(proof, keccak256(abi.encodePacked(msg.sender)))
  {
    uint256 mintPrice = calculateMintPrice();
    uint256 amountMinted = 0;
    uint256 budgetLeft = msg.value;

@>  while (budgetLeft >= mintPrice && _tokenIds < maxTokensPerGen) {
      _mintInternal(msg.sender, mintPrice);
      amountMinted++;
      budgetLeft -= mintPrice;
      mintPrice = calculateMintPrice();
    }
    if (budgetLeft > 0) {
      (bool refundSuccess, ) = msg.sender.call{ value: budgetLeft }('');
      require(refundSuccess, 'Refund failed.');
    }
  }
```
The issue arises from the while loop in the function, which has two conditions:
 
The remaining ether is sufficient to pay for the NFT, and **`_tokenIds < maxTokensPerGen`**.
 
The second condition is the problem because **`_tokenIds`** is a common variable across all generations. 
Once **`_tokenIds`** reaches 10,000 (first generation), it prevents the loop from executing further since **`maxTokensPerGen`** is hardcoded to 10,000, the maximum number of tokens per generation. This flaw renders the function unusable beyond the first generation.

To demonstrate the problem, copy the following POC into **`TraitForgeNft.test.ts`**. To avoid an "out of gas" exception, modify **`maxTokensPerGen`** to 10 in **`TraitForgeNft.sol`**.
```Solidity
it('mintWithBudget can only mint the first generation', async () => {
      fastForward(24 * 60 * 60 + 1);

      //mint the first generation
      for (let i = 0; i < 10; i++) {
        
        const tx = await nft.connect(user2).mintWithBudget(merkleInfo.whitelist[1].proof, {
          value: ethers.parseEther('1'),
        });
        await tx.wait(); 
      }
      
      //user has 10 NFT 
      expect(await nft.balanceOf(user2.address)).to.be.eq(10);

      //user wants to mint the first NFT of the second generation, but it cannot be done.
      await nft.connect(user2).mintWithBudget(merkleInfo.whitelist[1].proof, {
        value: ethers.parseEther('1'),
      });

      //user cant mint the first NFT of the second generation
      expect(await nft.balanceOf(user2.address)).to.be.eq(10);
    });
```
