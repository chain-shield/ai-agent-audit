# Vulnerability details

## Impact
According to [Info Website](https://traitforge.info/howitworks):
> InitialNukeFactor is calculated as entropy divided by 4, entropy [999999/4 = 249999] gives a percentage of 24.9%

However in `NukeFund::calculateNukeFactor()`, the division is done by `40` and not `4`. This yields incorrect value and hence `finalNukeFactor`.

**NOTE:** Let it be noted that the Documentation mentioned above is not the one marked (`needs to be updated`). See [here](https://code4rena.com/audits/2024-07-traitforge#top). Therefore, I am working with the assumption that this is up-to-date.

## Proof of Concept
In [`calculateNukeFactor()`](https://github.com/code-423n4/2024-07-traitforge/blob/279b2887e3d38bc219a05d332cbcb0655b2dc644/contracts/NukeFund/NukeFund.sol#L145), `initialNukeFactor` is calculated as follows:
```solidity
    function calculateNukeFactor(uint256 tokenId) public view returns (uint256) {
      require(
        nftContract.ownerOf(tokenId) != address(0),
        'ERC721: operator query for nonexistent token'
      );

      uint256 entropy = nftContract.getTokenEntropy(tokenId);
      uint256 adjustedAge = calculateAge(tokenId);

>>    uint256 initialNukeFactor = entropy / 40; // calcualte initalNukeFactor based on entropy, 5 digits

      uint256 finalNukeFactor = ((adjustedAge * defaultNukeFactorIncrease) /
        MAX_DENOMINATOR) + initialNukeFactor;

      return finalNukeFactor;
    }
```
As seen, the division is done by `40` and not `4` yielding a `5 digit` value.
- `entropy` = 999999
- `initialNukeFactor` = 999999/40 = 24999

With this, the `finalNukeFactor` calculated will be incorrect.

## Recommended Mitigation Steps
Correct the division in `calculateNukeFactor()` to divide by `4` instead of `40`
```diff
    function calculateNukeFactor(uint256 tokenId) public view returns (uint256) {
      require(
        nftContract.ownerOf(tokenId) != address(0),
        'ERC721: operator query for nonexistent token'
      );

      uint256 entropy = nftContract.getTokenEntropy(tokenId);
      uint256 adjustedAge = calculateAge(tokenId);

-     uint256 initialNukeFactor = entropy / 40; // calcualte initalNukeFactor based on entropy, 5 digits
+     uint256 initialNukeFactor = entropy / 4;

      uint256 finalNukeFactor = ((adjustedAge * defaultNukeFactorIncrease) /
        MAX_DENOMINATOR) + initialNukeFactor;

      return finalNukeFactor;
    }
```
