# Vulnerability details

## Impact
The function `mintWithBudget` includes a check that ensures the number of tokens minted (_tokenIds) does not exceed maxTokensPerGen. However, the current implementation does not account for multiple generations of tokens. Specifically, the maxTokensPerGen is set to a static value (e.g., 10,000 tokens), and there are 10 generations in total. Starting from the second generation, this function will become unusable because it does not adjust the token ID count by generation.
