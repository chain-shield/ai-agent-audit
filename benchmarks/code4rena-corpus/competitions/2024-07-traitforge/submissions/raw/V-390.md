# Vulnerability details


**Description**
* pausable contract have an internal virtual function _pause and _unpause which is meant to be overridden in the main contract that is using the paused and unpaused functionality, all the contracts inherited this pausable contract but the protocol forgets to override the functions that are supposed to be in charge of pausing or unpausing the contracts
* 

**Proof of Concept**
* if you check all the contract you will clearly find out that none of the contracts override the paused and unpaused function 
* which when deployed the owner of the contract won't be able to pause his contract ever again.

**Impact**
* players will still be able to call some critical functions with whenNotPaused modifier even when the contracts are in a critical condition and needs to be paused

**Recommended Mitigation**
* kindly override the pause and unpause function in all of the contracts also dont forget to use onlyOwner modifier if not then everyone will be able to pause the contract
```javascript
function pause() external override onlyOwner {
        _pause();
    }

    
    function unpause() external override onlyOwner {
        _unpause();
    }
```
