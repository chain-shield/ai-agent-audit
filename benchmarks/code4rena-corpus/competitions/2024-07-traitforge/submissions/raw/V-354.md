# Vulnerability details

## Impact
It's stated that there are max 10 generations of NFTs. However that restriction is not imposed inside the code.

## Proof of Concept
[_mintNewEntity](https://github.com/code-423n4/2024-07-traitforge/blob/main/contracts/TraitForgeNft/TraitForgeNft.sol#L311-L343) and [_mintInternal](https://github.com/code-423n4/2024-07-traitforge/blob/main/contracts/TraitForgeNft/TraitForgeNft.sol#L280-L298) both call [_incrementGeneration](https://github.com/code-423n4/2024-07-traitforge/blob/main/contracts/TraitForgeNft/TraitForgeNft.sol#L345-L355) if the current generation is at it's limits.

```solidity
    if (generationMintCounts[currentGeneration] >= maxTokensPerGen) {
        _incrementGeneration();
    }
```

However there are no checks to verify that `maxGeneration` is not exceeded. Enabling users to mint gen 10 fully and continue to gen 11 and onwards.

```solidity
    function _incrementGeneration() private {
        require(generationMintCounts[currentGeneration] >= maxTokensPerGen, "Generation limit not yet reached");
        currentGeneration++;
        generationMintCounts[currentGeneration] = 0;
        priceIncrement = priceIncrement + priceIncrementByGen;
        entropyGenerator.initializeAlphaIndices();
        emit GenerationIncremented(currentGeneration);
    }
```

`maxGeneration` is only used when [forging](https://github.com/code-423n4/2024-07-traitforge/blob/main/contracts/TraitForgeNft/TraitForgeNft.sol#L166), and nowhere else:

```solidity
    function forge(...) external whenNotPaused nonReentrant returns (uint256) {
        require(newGeneration <= maxGeneration, "can't be over max generation");

```

Manual review

## Recommended Mitigation Steps
Implement a check when calling [_incrementGeneration](https://github.com/code-423n4/2024-07-traitforge/blob/main/contracts/TraitForgeNft/TraitForgeNft.sol#L345-L355):
 
```diff
-   if (generationMintCounts[currentGeneration] >= maxTokensPerGen) {
+   if (generationMintCounts[currentGeneration] >= maxTokensPerGen && currentGeneration <= maxGeneration) {
        _incrementGeneration();
    }
```
