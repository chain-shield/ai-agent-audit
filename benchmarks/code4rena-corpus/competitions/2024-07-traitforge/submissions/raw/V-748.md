# Vulnerability details

## Impact
When forging occurs between two entities, the chance of having an entropy that exists will increase. Tokens with identical entropy would have the same physical traits, colors, and gameplay parameters since traits are derived from entropy. This could make tokens less unique and diverse.

## Proof of Concept
In `TraitForgeNft::forge` function, the generation of a new entropy is the the average of two entropies.
```
uint256 newEntropy = (forgerEntropy + mergerEntropy) / 2;
```

Multiple scenarios are possible for having the same entropy

1. Truncation:
Example :
- forger entropy = 123456. (123456 % 3 = 0 so it's a valid forger entropy)
- merger entropy = 654323. (654323 % 3 = 2 so it's a valid merger entropy)
newEntropy = (123456 + 654323) /2 = 388889 (due to truncation)

Another case:
- forger entropy = 123456. (123456 % 3 = 0 so it's a valid forger entropy)
- merger entropy = 654322. (654322 % 3 = 1 so it's a valid merger entropy)
newEntropy = (123456 + 654322) /2 = 388889 

So forging with different merger entropy will have the same entropy.

2. Mass forging in the TraitForge system leads to a convergence of entropy values towards the middle range of the possible spectrum. As forging repeatedly averages parent entropies, extreme values become rarer, and more entities cluster around the median.
