# Vulnerability details

## Impact
The entities have generation and there are maximum entities per generation. Every generation has one entropy "999999", called "The Golden God", this entropy has specific alpha indices created with `EntropyGenerator.sol:initializeAlphaIndices`. This function is called on the deployment of `EntropyGenerator.sol` and on each generation incrementation by `TraitForgeNft.sol`. The problem is with the `onlyOwner` modifier of the `EntropyGenerator.sol:initializeAlphaIndices`. The modifier gives access only to `EntropyGenerator.sol` to initialize alpha indices, although the function is called by `TraitForgeNft.sol` when a generation increases.

The impact is a denial of service of the game because the generation cannot be increased and entities from the upper generation can only be minted by forging

## Proof of Concept
Open `TraitForgeNft.test.ts` and add this test along with the describe block to make sure it is executed after the previous describe:

! To speed up the test change the `maxTokensPerGen` in `TraitForgeNft.sol` to `10`

```javascript
describe('POC', () => {
  it('should not be able to increase generation', async () => {
    const maxTokensPerGen = await nft.maxTokensPerGen();
    let generationOneCount = await nft.generationMintCounts(1);
    console.log(`Generation one minted count: ${generationOneCount}`);

    for (let i = 1; i <= maxTokensPerGen - generationOneCount; i++) {
      await nft.connect(user2).mintToken([], {
        value: ethers.parseEther('1'),
      });
      console.log(`Minted #${generationOneCount + BigInt(i)}`);
    }

    generationOneCount = await nft.generationMintCounts(1);
    console.log(`Generation one minted count: ${generationOneCount}`);

    await expect(
      nft.connect(user2).mintToken([], {
        value: ethers.parseEther('1'),
      })
    ).to.be.revertedWith('Ownable: caller is not the owner');
  });
});
```
