# Vulnerability details

## Impact

An issue exists where forging NFTs using the same parent IDs within the same generation could lead to the creation of duplicate NFTs. These duplicates would possess identical images and entropy values, undermining the intended uniqueness and rarity of NFTs within the game. This can negatively impact user experience and potentially decrease the perceived value of NFTs, hindering game objectives.

## Proof of Concept
The vulnerability arises from the calculation of the new entropy value (`newEntropy`) during the forging process. This value is simply the average of the parent NFTs' entropy:

`
uint256 newEntropy = (forgerEntropy + mergerEntropy) / 2;
`

Consequentially, repeated executions of the `forgeWithListed` function with the same parent IDs will consistently generate NFTs with the same average entropy. This results in identical NFTs within the same generation, jeopardizing the game's reliance on unique and rare NFTs.


The current approach to generating entropy for forged NFTs does not consider the possibility of duplicate parent IDs. This allows for the creation of identical NFTs within a generation, diminishing their perceived value and uniqueness.

Manual review

## Recommended Mitigation Steps

To address this vulnerability, it's recommended to implement a mechanism that verifies and potentially modifies the calculated `newEntropy` when using the same parent IDs:

1. **Uniqueness Check:** Before finalizing the forged NFT, perform a check to ensure the generated `newEntropy` doesn't already exist within the current generation.
2. **Entropy Modification (Optional):** If a duplicate is detected, consider implementing an additional logic to modify the `newEntropy` in a way that guarantees its uniqueness while maintaining the core functionality of the forging process. This modification could involve introducing a small random factor or utilizing a different calculation approach for duplicate parent IDs.

By implementing these recommendations, duplicate NFT generation is prevented, ensuring that each NFT within a generation remains unique and contributes to the intended rarity distribution, fostering a more engaging and valuable experience for users.
