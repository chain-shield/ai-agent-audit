# Vulnerability details

## Description
The special "999999" entropy (Golden God) is hardcoded, and its placement method doesn't guarantee it will be in the final pass as specified in the whitepaper.

```
if (
  slotIndex == slotIndexSelectionPoint &&
  numberIndex == numberIndexSelectionPoint
) {
  return 999999;
}
```

## Impact
* The Golden God entity may not be placed as intended, potentially appearing in earlier batches.
2. This could lead to an unfair advantage if the Golden God is minted earlier than designed.
3. It may disrupt the intended game balance and progression.

## Proof of Concept

[Link to code](https://github.com/code-423n4/2024-07-traitforge/blob/279b2887e3d38bc219a05d332cbcb0655b2dc644/contracts/EntropyGenerator/EntropyGenerator.sol#L206-L216)


```
  function initializeAlphaIndices() public whenNotPaused onlyOwner {
    uint256 hashValue = uint256(
      keccak256(abi.encodePacked(blockhash(block.number - 1), block.timestamp))
    );

    uint256 slotIndexSelection = (hashValue % 258) + 512;
    uint256 numberIndexSelection = hashValue % 13;

    slotIndexSelectionPoint = slotIndexSelection;
    numberIndexSelectionPoint = numberIndexSelection;
  }
```

The `initializeAlphaIndices` function sets the placement:

```
uint256 slotIndexSelection = (hashValue % 258) + 512;
uint256 numberIndexSelection = hashValue % 13;
```

This allows the Golden God to potentially appear as early as slot 512, which may not be in the final pass.

Manual Review

## Recommended Mitigation Steps
1. Modify the placement logic to ensure the Golden God appears in the final batch:
```
uint256 slotIndexSelection = (hashValue % 258) + 512;
if (slotIndexSelection < maxSlotIndex - 258) {
  slotIndexSelection = maxSlotIndex - 258 + (hashValue % 258);
}
```

2. Consider making the Golden God placement truly random across all slots to increase fairness.
