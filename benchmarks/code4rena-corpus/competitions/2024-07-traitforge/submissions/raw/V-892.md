# Vulnerability details

## Impact

Each time a new generation begins, the `EntropyGenerator::initializeAlphaIndices` function is invoked to select indices associated with the maximum entropy value (999999). The NFT linked to this maximum entropy is considered the most valuable of the generation. 

When a new token is minted, the `EntropyGenerator::getNextEntropy` function determines its entropy by comparing the current set of indices with those generated during `initializeAlphaIndices`. If the indices match, the token receives the maximum entropy value. 

A user aware of the next entropy value could time their minting to obtain a desired NFT. The current issue lies in the precomputation and storage of all entropy values within the `EntropyGenerator` contract. This allows one to infer the entropy for the next minted NFT by inspecting the `currentSlotIndex`, `slotIndexSelectionPoint`, `currentNumberIndex`, and `numberIndexSelectionPoint` storage variables.

```solidity
  // private function to calculate the entropy value based on slot and number index
  function getEntropy(
    uint256 slotIndex,
    uint256 numberIndex
  ) private view returns (uint256) {
    require(slotIndex <= maxSlotIndex, 'Slot index out of bounds.');

    // @> These variables are accessible from storage, allowing
    // front-running of the 999999 entropy.
    if (
      slotIndex == slotIndexSelectionPoint &&
      numberIndex == numberIndexSelectionPoint
    ) {
      return 999999;
    }

    uint256 position = numberIndex * 6; // calculate the position for slicing the entropy value
    require(position <= 72, 'Position calculation error');

    uint256 slotValue = entropySlots[slotIndex]; // slice the required [art of the entropy value
    uint256 entropy = (slotValue / (10 ** (72 - position))) % 1000000; // adjust the entropy value based on the number of digits
    uint256 paddedEntropy = entropy * (10 ** (6 - numberOfDigits(entropy)));

    return paddedEntropy; // return the caculated entropy value
  }
```

```solidity
  // function to retrieve the next entropy value, accessible only by the allowed caller
 // @> All variables can be access from storage to front-run the minting and select the maximum entropy.
  function getNextEntropy() public onlyAllowedCaller returns (uint256) {
    require(currentSlotIndex <= maxSlotIndex, 'Max slot index reached.');
    uint256 entropy = getEntropy(currentSlotIndex, currentNumberIndex);

    if (currentNumberIndex >= maxNumberIndex - 1) {
      currentNumberIndex = 0;
      if (currentSlotIndex >= maxSlotIndex - 1) {
        currentSlotIndex = 0;
      } else {
        currentSlotIndex++;
      }
    } else {
      currentNumberIndex++;
    }

    // Emit the event with the retrieved entropy value
    emit EntropyRetrieved(entropy);

    return entropy;
  }
```

## Recommended Mitigation Steps

The current implementation relies heavily on pre-calculated entropy values, making it susceptible to front-running exploits. 

An alternative approach would involve using Chainlink VRF to generate entropy values randomly at the moment of minting.
