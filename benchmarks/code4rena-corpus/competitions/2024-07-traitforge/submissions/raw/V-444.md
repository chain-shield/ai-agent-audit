# Vulnerability details

## Impact
Token can be listed for forging forever withouth being able to call cancel listing for forging.

## Proof of Concept
Based on cancelListingForForging(), there are two entities that can cancel listing for forging:

- tokenId owner
- TraitForgeNFT contract

```
 function cancelListingForForging(
    uint256 tokenId
  ) external whenNotPaused nonReentrant {
    require(
      nftContract.ownerOf(tokenId) == msg.sender ||
        msg.sender == address(nftContract),
      'Caller must own the token'
    );
    require(
      listings[listedTokenIds[tokenId]].isListed,
      'Token not listed for forging'
    );

    _cancelListingForForging(tokenId);
  }
```
https://github.com/code-423n4/2024-07-traitforge/blob/279b2887e3d38bc219a05d332cbcb0655b2dc644/contracts/EntityForging/EntityForging.sol#L177-L198

A tokenId owner can call nuke() while the tokenId is listed for forging. There is no check in nuke() that checks whether the about to be nuked tokenId is listed for forging. As a result, tokenId owner can nuke tokenId, and the tokenId is deleted. 

https://github.com/code-423n4/2024-07-traitforge/blob/279b2887e3d38bc219a05d332cbcb0655b2dc644/contracts/NukeFund/NukeFund.sol#L153-L182

When this occurs, it means the owner who initially listed the tokenId for forging is no longer the owner, and thus, cannot call cancelListingForForging() anylonger. TraitForgeNFT is then the only contract that can call cancelListingForForging(). However, there is also an issue with this.

Looking at TraitForgeNFT contract from a to z, cancelListingForForging() is mentioned once in the contract and that is in _beforeTokenTransfer(). 

```
   entityForgingContract.cancelListingForForging(firstTokenId);
```
https://github.com/code-423n4/2024-07-traitforge/blob/279b2887e3d38bc219a05d332cbcb0655b2dc644/contracts/TraitForgeNft/TraitForgeNft.sol#L390

However, _beforeTokenTransfer() is an internal funtion that can't be called directly by TraitForgeNFt contract. The result is, TraitForgeNFT contract also cannot call cancelListingForForging() to cancel token listed for forging.

## Tools Used
Manual review

## Recommended Mitigation Steps
The below two solutions are suggested:

- Call cancelListingForForging() when nuke() is called
- Include a way to to call cancelListingForForging() in TraitForgeNFT.sol
