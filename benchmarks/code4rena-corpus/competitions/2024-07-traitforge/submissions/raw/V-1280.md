# Vulnerability details

## Impact
`forgePotential` is checked inside `listForForging` function with `<=` operator. It means that if my current forging current equals `forgePotential`, the check will pass successfully, and forge will be listed. After that, we increase forgingCounts by one inside `forgeWithListed` without the check. So it allows us to create one more forge than is allowed by `forgePotential`
