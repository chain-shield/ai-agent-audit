# Vulnerability details

**Description**

The `TraitForgeNft`, `NukeFund`, `EntropyGenerator`, `EntityForgin`, `EntityTrading`, `DevFund` smart contracts inherit from OpenZeppelin's Pausable contract, but the _pause and _unpause methods are not exposed externally to be callable. Also there are a lot of functions which use `whenNotPaused`, but this modifier will always allow the calls. 

**Impact**

Pausable was used incorrectly and is possible to give out a false sense of security when actually contract is not pausable at all.

**Recommended mitigation**
Either remove Pausable from the contract or expose the `_pause` and `_unpause` methods externally with access control.
