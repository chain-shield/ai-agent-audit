# Vulnerability details

## Impact
The `receive()` function of the `NukeFund` contract contains a validation where it calls the `airdropContract` to check some conditions. Failing to set the `airdropContract` correctly, it will produce the following scenarios:
- Any ether transfers will fail
- All mint transactions coming from the `TraitForgeNft` contract will fail.
- Since 10% of Forge Fees and Sales goes into the Nuke Fund. 100% of all mint fees go into the Nuke Fund. All these functions will fail as well.

## Proof of Concept
Foundry Test Code:

```
  function testAirdropContractBug() public {
    address deployer = makeAddr('deployer');
    deal(deployer, 1000 ether);

    vm.startPrank(deployer);

    // 1 - Setting up needed contracts
    TraitForgeNft nftContract = new TraitForgeNft();
    Airdrop airdropContract = new Airdrop();
    nftContract.setAirdropContract(address(airdropContract));
    airdropContract.transferOwnership(address(nftContract));
    EntropyGenerator entropyGenerator = new EntropyGenerator(
      address(nftContract)
    );
    nftContract.setEntropyGenerator(address(entropyGenerator));
    EntityForging entityForging = new EntityForging(address(nftContract));
    nftContract.setEntityForgingContract(address(entityForging));
    DevFund devFund = new DevFund();

    // 2 - deploying a NukeFund contract with a non-Airdrop address
    NukeFund nukeContract = new NukeFund(
      address(nftContract),
      makeAddr('not-airdrop-contract'),
      payable(address(devFund)), // just eoa for now
      payable(daoAddress)
    );

    nftContract.setNukeFundContract(payable(address(nukeContract)));
    EntityTrading entityTrading = new EntityTrading(address(nftContract));
    entityTrading.setNukeFundAddress(payable(address(nukeContract)));

    // 3 - setting up nft contract's whitelist
    nftContract.setRootHash(rootHash);
    vm.stopPrank();

    // 4 - this merkle root proofs is the second account on the json file in
    // 2024-07-traitforge/consts/merkle.json
    bytes32[] memory proofs = new bytes32[](2);
    proofs[
      0
    ] = 0xccde2ddaf58b1f916d5359378d87667005516a28fb95b92cffadebf464f8240b;
    proofs[
      1
    ] = 0xc8fbcb936bf99fdc0fe0524b9a208cf8c60d1fbc93de9d08ab1d204b91dd7a47;

    // 5 - funds for the user

    deal(w_user2, 1000 ether);
    vm.startPrank(w_user2);

    // 6
    // 10% of Forge Fees and Sales goes into the Nuke Fund.
    // 100% of all mint fees go into the Nuke Fund.
    // this mint function from the NFT contract will attempt to send eth to the
    // NukeFund contract
    nftContract.mintToken{ value: 1 ether }(proofs);
  }
```

## Tools Used
Foundry, Manual Review

## Recommended Mitigation Steps
We can do either of the following:
- Add validations on the constructor and `setAirdropContract` to make sure that it points to the right contract
- Add a validation or a handler on `receive()`  to make sure `airdropContract` calls are successful.
