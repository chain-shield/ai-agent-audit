# Vulnerability details

## Impact
Minting first NFT of the current generation will result in wrongly calculated price.

## Proof of Concept
Lets say that the first generation just finished and the user tries to mint the first NFT from the second generation. 
The problem comes from the way in which the checks are ordered. The mintToken function first calculates the price for the 10000th NFT. Afterwards in the _mintInternal function the generation is updated after the if check `generationMintCounts[currentGeneration] >= maxTokensPerGen`. This would lead to the user paying a lot higher price than expected for the NFT, because he will be paying the price for the 10000th NFT of the 1st generation but recieving the 1st NFT of the 2nd generation.

    if (excessPayment > 0) {
