# Vulnerability details

## Impact

All NFT transfer transactions using the `safeTransferFrom` function to `EntityTrading.sol` will always revert

## Proof of Concept

When an NFT is sent using the `safeTransferFrom` function, it will continue to check whether the recipient is a contract that can handle NFTs or not. This is done in the `_checkOnERC721Received` function.

```solidity
function _checkOnERC721Received(
        address from,
        address to,
        uint256 tokenId,
        bytes memory data
    ) private returns (bool) {
        if (to.isContract()) {
            try IERC721Receiver(to).onERC721Received(_msgSender(), from, tokenId, data) returns (bytes4 retval) {
                return retval == IERC721Receiver.onERC721Received.selector;
            } catch (bytes memory reason) {
                if (reason.length == 0) {
                    revert("ERC721: transfer to non ERC721Receiver implementer");
                } else {
                    /// @solidity memory-safe-assembly
                    assembly {
                        revert(add(32, reason), mload(reason))
                    }
                }
            }
        } else {
            return true;
        }
    }
```

If the recipient is not a contract, the result will always be true and the transfer can be done. While if the recipient is a contract, the return value in the form of `bytes4` will be checked whether it matches or not. This can be done if the recipient contract implements `IERC721Receiver` and the functions in it. If not, the result will immediately be false and the transfer will always revert.

The main problem here is that the `EntityTrading` contract does not implement `IERC721Receiver`, so all NFT transfer transactions with the `safeTransferFrom` method to this contract will always revert.

## Tools Used

Manual review

## Recommended Mitigation Steps

Make sure to implement `IERC721Receiver`

```solidity
function onERC721Received(
        address operator,
        address from,
        uint256 tokenId,
        bytes calldata data
    ) external returns (bytes4);
}
```
