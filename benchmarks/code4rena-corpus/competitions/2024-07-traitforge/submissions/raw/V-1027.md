# Vulnerability details

## Description
The `safeRewardTransfer` function in the `DevFund.sol` contract is marked as internal, which means it can be called by any function within the same contract or any contract that inherits from it. This function handles the transfer of rewards to a specified address and does not include explicit access controls or checks to validate the caller's permissions beyond its internal visibility. If a derived contract maliciously or inadvertently calls this function, it could lead to unauthorized or unintended reward distributions, potentially draining the contract's funds.

## Impact
The lack of access controls on the `safeRewardTransfer` function exposes the contract to risks where inherited contracts might misuse this function, leading to loss of funds. This vulnerability could be exploited by attackers if they can influence or deploy a derived contract that interacts with `DevFund.sol`. The financial implications could be significant, depending on the balance and usage of the contract at the time of exploitation.

## Recommended Mitigation Steps

1- Change the function visibility to Private that only the `DevFund.sol` contract call it. but this way the inherit contracts will never access to `safeRewardTransfer`
2- Refactor the `claim` and `safeRewardTransfer` functions.
```solidity
function claim() external whenNotPaused nonReentrant {
    uint256 claimedAmount = safeRewardTransfer(msg.sender);
    info.pendingRewards = pending - claimedAmount;
    emit Claim(msg.sender, claimedAmount);
    info.rewardDebt = totalRewardDebt;
  }
  function safeRewardTransfer(
    address to
  ) internal returns (uint256) {
    DevInfo storage info = devInfo[msg.sender];
    uint256 pendingAmount = info.pendingRewards +
      (totalRewardDebt - info.rewardDebt) *
      info.weight;
    require(pendingAmount > 0, "Pending should be greater than zero");
    uint256 _rewardBalance = payable(address(this)).balance;
    if (pendingAmount > _rewardBalance) pendingAmount = _rewardBalance;
    (bool success, ) = payable(to).call{ value: pendingAmount }('');
    require(success, 'Failed to send Reward');
    return amount;
  }
```
