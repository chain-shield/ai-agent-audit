# Vulnerability details

## Impact

In the `EntropyGenerator.deriveTokenParameters` function the `nukeFactor` is calculated as follows:

```solidity
    nukeFactor = entropy / 4000000;
```

But the above calculation is errorneous since the `TraitForge` documentation implements the `nukeFactor = entropy / 40`. It is considered that the `entropy` value has 6 digits and the `nukeFactor` has `5 digits`. But the above `nukeFactor` calculation will either result in `0` or one digit value for the `nukeFactor`.`

As a result the use of the `EntropyGenerator.deriveTokenParameters` function to retrieve the token parameters will result in errorneous values for `nukeFactor` which would break the subsequent logic which is dependent on the `nukeFactor` value.

## Recommended Mitigation Steps

Hence it is recommended to correct the `nukeFactor` calculation in the `EntropyGenerator.deriveTokenParameters` function as shown below:

```solidity
    nukeFactor = entropy / 40;
```
