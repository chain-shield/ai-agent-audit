# Vulnerability details

## Bug description
The following contracts: `DevFund`, `EntityForging`, `EntityTrading`, `EntropyGenerator`, `NukeFund`, `TraitForgeNft` are supposed to be pausable, as they all inherit `Pausable`, but the don't implement external `pause/unpause` functionalities, which means it will never be possible to pause them.

## Impact
Contracts cannot be paused.


## Recommended Mitigation
Implement external `pause/unpause` functions.

```solidity
function pause() external onlyOwner {
    _pause();
}
function unpause() external onlyOwner {
    _unpause();
}
```
