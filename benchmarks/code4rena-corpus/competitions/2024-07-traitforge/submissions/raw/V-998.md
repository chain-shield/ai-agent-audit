# Vulnerability details

## Impact

A critical vulnerability exists that allows the creation of more NFTs per generation than intended. The current system fails to enforce the 10,000 NFT cap per generation, potentially leading to an oversupply of NFTs. This can significantly disrupt the game's economic balance and devalue individual NFTs due to exceeding the planned scarcity.

## Proof of Concept

1. **Initial Minting:** Minting begins for generation 1, and the `generationMintCounts[1]` variable keeps track of minted NFTs for this generation.
2. **Forging NFTs:** The `forgeWithListed` function is used with two generation 1 NFTs, resulting in a generation 2 NFT. The `generationMintCounts[2]` variable is incremented accordingly.
3. **Generation Cap Reached:** After 10,000 generation 1 NFTs are minted, the `_incrementGeneration` function is triggered.
4. **Unintended Reset:** This function performs the following actions:

   `
   currentGeneration++;`
   `generationMintCounts[currentGeneration] = 0;
   `

   Crucially, it resets `generationMintCounts` for generation 2 to zero, effectively disregarding all previously minted generation 2 NFTs.

The issue arises from the way the `_incrementGeneration` function resets the `generationMintCounts` array. It doesn't account for the existing mints in the current generation, leading to an inaccurate representation of the total minted NFTs. This allows for the creation of more NFTs than intended in subsequent generations.

## Recommended Mitigation Steps

To address this vulnerability and enforce the 10,000 NFT cap per generation, the `_incrementGeneration` function needs modification:

1. **Track Total Mints:** Instead of resetting the current generation's `generationMintCounts` to zero, accumulate the total mints from the previous generation. This can be achieved by adding the value of `generationMintCounts[currentGeneration]` to the corresponding entry for the new generation.
2. **Enforce Cap:** Implement a check within the minting logic to ensure the total number of minted NFTs (including forged ones) doesn't exceed the 10,000 cap before allowing further minting for the current generation.

By implementing these recommendations, the intended 10,000 NFT cap per generation is enforced. This ensures a balanced NFT economy within the game and maintains the perceived value of individual NFTs by adhering to the planned scarcity.
