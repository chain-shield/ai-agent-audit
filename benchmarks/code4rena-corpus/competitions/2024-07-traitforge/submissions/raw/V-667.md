# Vulnerability details

## Impact
The NFT operator cannot nuke the token, which conflicts with the context. 
## Proof of Concept
The nuke function requires the msg.sender must be the token owner or operator at Line 155.
https://github.com/code-423n4/2024-07-traitforge/blob/279b2887e3d38bc219a05d332cbcb0655b2dc644/contracts/NukeFund/NukeFund.sol#L155

However, the token operator is not able to do this. Once the operator nukes the token on behalf of the owner, the function will revert because the token is not approved to the NukeFund contract, so the contract cannot burn the token at Line 176. 
https://github.com/code-423n4/2024-07-traitforge/blob/279b2887e3d38bc219a05d332cbcb0655b2dc644/contracts/NukeFund/NukeFund.sol#L176C17-L176C21

## Tools Used
Manual review.
## Recommended Mitigation Steps
Transfer the token from the owner and then burn the token.
