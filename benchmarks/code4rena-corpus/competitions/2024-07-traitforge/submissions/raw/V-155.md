# Vulnerability details

## Impact
When entropies have fewer than 6 digits, they are right padded. For example, the entropy 000123 will be treated as 123000. Consequently, numbers with fewer than 5 digits will all be infertile:

```javascript
function getEntropy(
    uint256 slotIndex,
    uint256 numberIndex
) private view returns (uint256) {
    require(slotIndex <= maxSlotIndex, "Slot index out of bounds.");

    if (
        slotIndex == slotIndexSelectionPoint &&
        numberIndex == numberIndexSelectionPoint
    ) {
        return 999999;
    }

    uint256 position = numberIndex * 6; // calculate the position for slicing the entropy value
    require(position <= 72, "Position calculation error");

    uint256 slotValue = entropySlots[slotIndex]; // slice the required [art of the entropy value will be granted
    uint256 entropy = (slotValue / (10 ** (72 - position))) % 1000000; // adjust the entropy value based on the number of digits

@>  uint256 paddedEntropy = entropy * (10 ** (6 - numberOfDigits(entropy))); 
    return paddedEntropy; // return the caculated entropy value
}
```

A small entropy is generated by using 10 as the dividend, then the value is padded to the right. The original entropy was 10 and therefore the forge potential should be 1 (5th digit), however after the padding, the entity becomes infertile in excahnge of a higher initial nuke factor.
