# Vulnerability details

## Vulnerability details

According to the docs

```
TraitForge has a unique visual Entity system. 
It consists of generational progression, 
colour variation through maturity 
and an array of parameters providing unique visual distinction between entity's.

### entropy: 123456
Entropy[1] = varOptions1 && Role
Entropy[2] = varOptions2
Entropy[3] = varOptions3 && colorOptions3
Entropy[4] = varOptions4 && colorOptions4
Entropy[5] = colorOptions5 && color2
Entropy[6] = colorOptions6 && color1
Entropy = initalNukeFactor
Entropy % 10 = performanceFactor
Entropy % 3 ? 0 == Role
```
This means,
Entropies decide the traits and visual attributes of an Entity.
Same entropy values results in same NFTs.

Entropy value is obtained in 2 ways 
1. During direct minting thru a randomized process from `EntropyGenerator` 
2. During forging by taking the average of the parentIDs' Entropies

```
    uint256 newEntropy = (forgerEntropy + mergerEntropy) / 2;

```


So its important that every new entropy is unique.

However, due to the design of the forging mechanism 
and the way newEntropy is calculated as an average of 2 ParentIDs.

It is easier for users to deterministically mint the offspring entropies.
Some desirable entropies will be forged multiple times 
resulting in batches of several entities having 
the same parents, same traits & visual attribiutes. 


## Impact

Multiple Entities could be minted with same entropies while forging. 
This results in several entities having same traits and visuals.

## Proof of Concept

1. Lets assume Alice holds a Forger Entity and a merger Entity in 2 different addresess.
```
Forger Entropy = 100035 (forgePotential = 3)
Merger Entropy = 500141 (forgePotential = 4)
```
2. When forged 
```
the resulting Child's Entropy = ( 100005 + 898163 ) / 2 = 300088
(forgePotential = 8)
(Performance factor = 8)
```
3. Now Alice could forge 3 times using the same parents every year
   producing 3 similar entities.

4. Consider the fact that the same entropy could also be obtained 
   by different combination of parentIDs. 
```
for example 
ForgerEntropy = 100002
MergerEntropy = 500174

also results in ChildEntropy = 300088
```
5. When the same process is repeated by every user at scale using different combinaions. The uniqueness of the entire collection will be seriously affected as therell be several similar entities.
