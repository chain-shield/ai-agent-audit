# Vulnerability details

## Impact
Malicious users can read EntropyGenerator::entropySlots, EntropyGenerator::currentSlotIndex, and EntropyGenerator::currentNumberIndex private variables by analyzing the deployed contract's storage slots and effectively cherry-pick NFTs during the minting process to guarantee desirable entropies. 

## Proof of Concept
1 - Deploy the contract
```
forge script test/EntropyGenerator/DeployEntropyGenerator.s.sol --rpc-url http://localhost:8545 --broadcast --private-key 0x92db14e403b83dfe3df233f83dfa3a0d7096f21ca9b0d6d6b8d88b2b4ec1564e
```

2 - Analyze the contract's storage to read `entropySlots` (the same commands can be run for `currentSlotIndex` and `currentNumberIndex`  
```
cast storage 0x77c7E3905c21177Be97956c6620567596492C497 0
# output -> 0x000000000000000000000000976ea74026e726554db657fa54763abd0c3a0aa9

cast storage 0x77c7E3905c21177Be97956c6620567596492C497 1
# output -> 0x2b232c97452f0950c94e2539fdc7e69d21166113cf7a9bcb99b220a3fe5d720a

cast --to-dec 0x2b232c97452f0950c94e2539fdc7e69d21166113cf7a9bcb99b220a3fe5d720a 

#output -> 19511599891424801449367108142964227787403202039135897967463264740723690140170
```
3 - We can split this into 13 groups of 6 digits each:
195115 998914 248014 493671 081429 642277 874032 020391 358979 674632 647407 236901 401700 (add padding)

4. So, the 13 entropies stored in this slot are:
    - 195115
    - 998914
    - 248014
    - ...

5. Perform the same steps to read `currentSlotIndex` and `currentNumberIndex`
6. With the entropies, currentSlotIndex, and currentNumberIndex, malicious users can call/front-run `TraitForgeNft::mintToken` on entropies next up in `EntropyGenerator::entropySlots` guaranteeing they get the best: nuke factor, forge potential, performance factor, a forger NFT over a merger, or “the Golden God.” 
7. This effectively makes the game a gas competition for who can call `TraitForgeNft::mintToken` with the most gas and at the right time to get a desirable entropy score, effectively making the game unplayable.   

## Tools Used
Manual Review, Foundry (cast)

## Recommended Mitigation Steps
Refactor the sequential nature of `EntropyGenerator::getNextEntropy` and randomly select from `EntropyGenerator::entropySlots` using Chainlinks VRF.
