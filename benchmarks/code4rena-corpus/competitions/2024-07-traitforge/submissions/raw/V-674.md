# Vulnerability details

## Impact
TraitForgeNFT._incrementGeneration fails to execute as intended. As a result, after all tokens in Generation 1 have been minted, the mintToken and mintWithBudget functions will revert.

## Proof of Concept
The _mintInternal function is designed to increment the current generation once the minting count for the current generation exceeds a specified limit.

```solidity
function _mintInternal(address to, uint256 mintPrice) internal {
  if (generationMintCounts[currentGeneration] >= maxTokensPerGen) {
>>  _incrementGeneration();
  }

  _tokenIds++;
  uint256 newItemId = _tokenIds;
  _mint(to, newItemId);
  uint256 entropyValue = entropyGenerator.getNextEntropy();
  ...
}

function _incrementGeneration() private {
  require(
    generationMintCounts[currentGeneration] >= maxTokensPerGen,
    'Generation limit not yet reached'
  );
  currentGeneration++;
  generationMintCounts[currentGeneration] = 0;
  priceIncrement = priceIncrement + priceIncrementByGen;
>>entropyGenerator.initializeAlphaIndices();
  emit GenerationIncremented(currentGeneration);
}

// EntrophyGenerator.sol
  //select index points for 999999, triggered each gen-increment
  function initializeAlphaIndices() public whenNotPaused onlyOwner { // << onlyOwner
    uint256 hashValue = uint256(
      keccak256(abi.encodePacked(blockhash(block.number - 1), block.timestamp))
    );

    uint256 slotIndexSelection = (hashValue % 258) + 512;
    uint256 numberIndexSelection = hashValue % 13;

    slotIndexSelectionPoint = slotIndexSelection;
    numberIndexSelectionPoint = numberIndexSelection;
  }
```

The mintToken and mintWithBudget functions are expected to call _incrementGeneration to increase the currentGeneration value when all tokens for a generation are minted. However, the issue arises because the entropyGenerator.initializeAlphaIndices() function has a onlyOwner modifier.

```soliditiy
// EntropyGenerator.sol
// Function to update the allowed caller, restricted to the owner of the contract
function setAllowedCaller(address _allowedCaller) external onlyOwner {
  allowedCaller = _allowedCaller;
  emit AllowedCallerUpdated(_allowedCaller);
}
```

Another function in EntropyGenerator, setAllowedCaller, also has the onlyOwner modifier, and there is no logic within TraitForgeNFT to call this function. Consequently, TraitForgeNFT cannot become the owner of EntropyGenerator, which leads to the failure of _incrementGeneration.

## Recommended Mitigation Steps
This can be achieved by utilizing the onlyAllowedCaller modifier already implemented in EntropyGenerator.
```soliditiy
// Modifier to restrict certain functions to the allowed caller
modifier onlyAllowedCaller() {
  require(msg.sender == allowedCaller, 'Caller is not allowed');
  _;
}

```
