# Vulnerability details

## Impact
Misunderstanding of the nuke Factor entity parameter.

## Proof of Concept
We can calculate the nukeFactor in two ways. 

In the EntropyGenerator contract, the `EntropyGenerator::deriveTokenParameters()` function allows us to calculate the nukeFactor as follows: `nukeFactor = entropy / 4000000`. With Solidity, integer division of numbers less than the divisor always equals 0. As all entropy values are less than 4000000 (max 999999), the result of nuke Factor will be always 0. 

In the NukeFund contract, the `NukeFund::calculateNukeFactor()` function allows us to calculate the nukeFactor as follows: uint256 initialNukeFactor = entropy / 40;

## Recommended Mitigation Steps

Following the whitepaper: "[...]Entropy /40 = initalNukeFactor[...]",  the `EntropyGenerator::deriveTokenParameters()` function should calculate the nukeFactor as follows : nukeFactor = entropy / 40

 function deriveTokenParameters(
    uint256 slotIndex,
    uint256 numberIndex
  )
    public
    view
    returns (
      uint256 nukeFactor,
      uint256 forgePotential,
      uint256 performanceFactor,
      bool isForger
    )
  {
    uint256 entropy = getEntropy(slotIndex, numberIndex);

    // example calcualtions using entropyto derive game-related parameters
--   nukeFactor = entropy / 4000000;
++   nukeFactor = entropy / 40;
    forgePotential = getFirstDigit(entropy);
    performanceFactor = entropy % 10;

    // exmaple logic to determine a boolean property based on entropy
    uint256 role = entropy % 3;
    isForger = role == 0;

    return (nukeFactor, forgePotential, performanceFactor, isForger); // return derived parammeters
  }
