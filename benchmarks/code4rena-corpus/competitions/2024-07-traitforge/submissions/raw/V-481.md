# Vulnerability details

## Impact
The **entropy** of an NFT significantly influences its value. However, the current entropy generation mechanism allows for pre-calculation, enabling malicious users to predict and mint NFTs with desired characteristics, leading to potential unfairness and manipulation in the market.

## Proof of Concept
The `entropy` of an NFT is generated through the `EntropyGenerator::getNextEntropy` function, which ultimately calls the `getEntropy` function:

```solidity
  function getNextEntropy() public onlyAllowedCaller returns (uint256) {
    require(currentSlotIndex <= maxSlotIndex, 'Max slot index reached.');
@=> uint256 entropy = getEntropy(currentSlotIndex, currentNumberIndex);

    if (currentNumberIndex >= maxNumberIndex - 1) {
      currentNumberIndex = 0;
      if (currentSlotIndex >= maxSlotIndex - 1) {
        currentSlotIndex = 0;
      } else {
        currentSlotIndex++;
      }
    } else {
      currentNumberIndex++;
    }

    // Emit the event with the retrieved entropy value
    emit EntropyRetrieved(entropy);

    return entropy;
  }
```

```solidity
  // private function to calculate the entropy value based on slot and number index
  function getEntropy(
    uint256 slotIndex,
    uint256 numberIndex
  ) private view returns (uint256) {
    require(slotIndex <= maxSlotIndex, 'Slot index out of bounds.');

    if (
      slotIndex == slotIndexSelectionPoint &&
      numberIndex == numberIndexSelectionPoint
    ) {
      return 999999;
    }

    uint256 position = numberIndex * 6; // calculate the position for slicing the entropy value
    require(position <= 72, 'Position calculation error');

    uint256 slotValue = entropySlots[slotIndex]; // slice the required [art of the entropy value
    uint256 entropy = (slotValue / (10 ** (72 - position))) % 1000000; // adjust the entropy value based on the number of digits
    uint256 paddedEntropy = entropy * (10 ** (6 - numberOfDigits(entropy)));

    return paddedEntropy; // return the caculated entropy value
  }
```

Even though `getEntropy` is a private function and `currentSlotIndex` is private state variable, **the data stored on-chain can be accessed and computed by anyone off-chain**. As a result, users can still pre-calculate the `entropy` values and mint NFTs with desirable traits, leading to potential unfairness and manipulation in the market.

## Tools Used

Manual

## Recommended Mitigation Steps

1. **Integrate Other Variables**: Incorporate variables that are more challenging to manipulate(still possible to manipulate), such as block.timestamp and block.difficulty, into the entropy generation process.
2. **Add a blacklist mechanism**: Implement a blacklist to prevent addresses that engage in suspicious activity from participating in the minting process.
