# Vulnerability details

## Impact
listForForging doesn't update forging count allowing users to forge past there forgePotential

## Proof of Concept
Owners whose token can be forge can do so using the listForForging() function which has a limit, as the chack:
```solidity
require(
      forgePotential > 0 && forgingCounts[tokenId] <= forgePotential,
      'Entity has reached its forging limit'
    );
```
However, after and before this check, the forging counts doesn't get updated in the function. but gets updated in the forgeWithListed() function. allowing users to list token for forge past there forgePotential

## Tools Used
Manual Review

## Recommended Mitigation Steps
Update forgingCounts in the listForForging() function
