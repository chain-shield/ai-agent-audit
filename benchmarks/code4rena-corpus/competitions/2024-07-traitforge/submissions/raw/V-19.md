# Vulnerability details

## Impact
The protocol contracts inherits from `Pausable` contract of `openzeppelin`, but the  feature to pause and unpause the contract will be available only if the inheriting contract expose the `_pause()` and `_unpause()` functions as external. Since these functions in the library are internal functions, it is the responsibility of the inheriting contract to extend and expose these functions with proper access restrictions.

As all the below contract did not expose the `_pause()` and `_unpause()` functions, none of these contracts are pausable when required.


- DevFund.sol
- EntityForging.sol
- EntityTrading.sol
- EntropyGenerator.sol
- NukeFund.sol
- TraitForgeNft.sol

As such, none of the above contracts are pausable.

## Proof of Concept

The _pause() and _unpause() are internal functions and hence are available to the inheriting contracts. But, since this functionality is not exposed by the inheriting contracts, the contracts cannot be paused or unpaused when required.

```
    function _pause() internal virtual whenNotPaused {
        _paused = true;
        emit Paused(_msgSender());
    }
   
    function _unpause() internal virtual whenPaused {
        _paused = false;
        emit Unpaused(_msgSender());
    }
```

Manual review

## Recommended Mitigation Steps
All the contracts listed above that extends the `Pausable` contract should exposed the below functions. It is important to apply proper access control to the two functions so that only account with correct entitlement can pause and unpause the respective contracts.

`onlyOwner()` is used an example to demonstrate the need for access control.

```solidity
function pause() public onlyOwner() {
        _pause();
    }

function unpause() public onlyOwner() {
        _unpause();
}
```
