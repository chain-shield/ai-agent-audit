# Vulnerability details

## Impact
The wrong price is calculated when a user mints the first token of the new generation. When a user calls `mintToken` to mint a token, the mint price is calculated based on the `startPrice` and `priceIncrease * currentGenMintCount`. So, if I want to mint the first token from generation 2, the mint price will be equal to `startPrice + priceIncrement * 10000 = 0.005 ether + 0.0000245 ether * 10000 = 0.25 ether`.


```solidity
function mintToken(
    bytes32[] calldata proof
  )
    public
    payable
    whenNotPaused
    nonReentrant
    onlyWhitelisted(proof, keccak256(abi.encodePacked(msg.sender)))
  {
    uint256 mintPrice = calculateMintPrice();
    require(msg.value >= mintPrice, 'Insufficient ETH send for minting.');

    _mintInternal(msg.sender, mintPrice);
    // .......
  }
```

```solidity
  function calculateMintPrice() public view returns (uint256) {
    uint256 currentGenMintCount = generationMintCounts[currentGeneration];
    // priceIncrement * gen number
    uint256 priceIncrease = priceIncrement * currentGenMintCount;

    uint256 price = startPrice + priceIncrease;
    return price;
  }
```

In the internal function `_mintInternal`, the condition `generationMintCounts[currentGeneration] >= maxTokensPerGen` will be true, and the generation will be incremented as `currentGeneration` is increased by 1. The `priceIncrement` is increased by `priceIncrementByGen`, and `generationMintCounts[currentGeneration]` is set to zero.

```solidity
  function _incrementGeneration() private {
    require(generationMintCounts[currentGeneration] >= maxTokensPerGen, 'Generation limit not yet reached');

    currentGeneration++;
    generationMintCounts[currentGeneration] = 0;

    //@note poslednite token ot edna generation shte sa po skupi
    // ot purvkite tokani na sledvashtata generaciq
    priceIncrement = priceIncrement + priceIncrementByGen;

    entropyGenerator.initializeAlphaIndices();

    emit GenerationIncremented(currentGeneration);
  }
```

So now, if we make the same calculation for how much the token price should be, the price is equal to `startPrice + priceIncrement * 0 = 0.005 ether + 0 = 0.005 ether`. The new price when the generation is incremented is less than the initial calculation of the mint price.

Every time a user mints the first token of the next generation, he will receive a higher price for his token because the variables used for the price calculation are updated after the mint price is calculated.
