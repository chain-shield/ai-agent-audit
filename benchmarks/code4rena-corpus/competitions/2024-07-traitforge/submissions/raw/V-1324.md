# Vulnerability details

## Impact
The contracts DevFund, EntityForging, EntityTrading, EntropyGenerator, and NukeFund all inherit from the Pausable contract and use its modifiers. However, these contracts do not implement the pause or unpause functions. As a result, the contracts cannot actually be paused or unpaused, rendering the use of Pausable modifiers

## Proof of Concept
False Sense of Security:
Developers and users might believe that the contracts can be paused in case of an emergency or for maintenance, but this functionality is not actually available.

A developer tries to pause one of the contracts during an emergency but finds that there is no way to do so, leading to security issues.

## Tools Used
Manual review

## Recommended Mitigation Steps
Remove Pausable Inheritance and Modifiers:
If the pause functionality is not required, remove the inheritance from Pausable and the use of its modifiers to reduce complexity and gas costs.

Implement Pause/Unpause Functions if Needed:
If pausing functionality is desired, ensure that the pause and unpause functions are implemented in the contracts.
