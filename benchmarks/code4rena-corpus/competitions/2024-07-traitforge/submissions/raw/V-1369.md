# Vulnerability details

## Description

Based on protocol's documentation for Generations: "The Mint fee for generation 1 starts at 0.005 ETH and ends at 0.25ETH after 10,000. Generation 2 starts at 0.005 ETH and ends at 0.3ETH...". But due to incorrect logic, when Generation 1 finishes and new Generation (2-10) starts, Entity #1 will cost `0.0050295` ETH, instead of `0.005` ETH. The problem lies in the `_mintInternal()` function, more specifically where the incrementing `generationMintCounts` mapping is placed, which is as a counter for NFT mints per generation and is used for the price calculation of each Entity. 

```javascript
function mintToken(
    bytes32[] calldata proof
  )
    ...
  {
@>> uint256 mintPrice = calculateMintPrice();
    
    require(msg.value >= mintPrice, 'Insufficient ETH send for minting.');

@>> _mintInternal(msg.sender, mintPrice);

    ...
  }

function calculateMintPrice() public view returns (uint256) {
    uint256 currentGenMintCount = generationMintCounts[currentGeneration];
    uint256 priceIncrease = priceIncrement * currentGenMintCount;
    uint256 price = startPrice + priceIncrease;
    return price;
}

function _mintInternal(address to, uint256 mintPrice) internal {
    if (generationMintCounts[currentGeneration] >= maxTokensPerGen) {
      _incrementGeneration();
    }

    _tokenIds++;
    uint256 newItemId = _tokenIds;
    _mint(to, newItemId);
    uint256 entropyValue = entropyGenerator.getNextEntropy();

    tokenCreationTimestamps[newItemId] = block.timestamp;
    tokenEntropy[newItemId] = entropyValue;
    tokenGenerations[newItemId] = currentGeneration;
@>> generationMintCounts[currentGeneration]++;
    initialOwners[newItemId] = to;

function _incrementGeneration() private {
    require(
      generationMintCounts[currentGeneration] >= maxTokensPerGen,
      'Generation limit not yet reached'
    );
    currentGeneration++;
    generationMintCounts[currentGeneration] = 0;
    priceIncrement = priceIncrement + priceIncrementByGen;
    ...
  }    
```

Consider the following scenario involving Alice and Bob: 

1. As can be seen `generationMintCounts` increments in last place, it will increment to 10,000 when Entity #9999 is minted, so it can calculate the price of the NFT for the next caller.
2. Alice mints Entity #10,000, `generationMintCounts` is 10,000 so it triggers the `_incrementGeneration()` function, which increments the `currentGeneration` to 2 and resets `generationMintCounts` for the newly starting generation
3. But `generationMintCounts` is increased in `_mintInternal`, so the values for the next user will be -> `generationMintCounts[2] = 1`, instead of `generationMintCounts[2] = 0`
4. Following this logic Bob will have his NFT price incorrectly increased.
5. Bob calls the mint function, which calls `calculateMintPrice`
6. In `calculateMintPrice`:
   - `currentGenMintCount = generationMintCounts[currentGeneration]` -> 1
   - `priceIncrease = priceIncrement * currentGenMintCount` -> (0.0000245 ether + 0.000005 ether) * 1
   - `price = startPrice + priceIncrease` -> 0.005 ether + 0.0000295 ether = 0.0050295 ether
7. Price for Entity #1 for Generation 2 will be with 0.0000295 ether more

## Impact
- Likelihood: Medium, this miscalculation will happen everytime in the beginning of every new generation
- Impact: Medium, breaks functionality, as protocol will require more ETH from users on start of new generation
- Overall Severity: Medium, no loss of funds for protocol, but breaks the pricing functionality 

## Proof of Concept
The test is in Foundry, i'm using a mock contract which is a simplified version of `TraitForgeNft` for easier testing. Basically the external interactions and `bytes32[] proof` are removed, also all unnecessary variable updates which are not involved in the exploit. Additionally a custom `uint256 priceChecker` variable is added to track properly the calculated price. No changes are made to the original code: 

1. Install Foundry
2. Paste the following code in a file
3. Run `forge test --mt testWrongPrice -vv`

```javascript
import {Test, console} from "forge-std/Test.sol";

contract MockTraitForgeNft {
  uint256 public maxTokensPerGen = 10000;
  uint256 public startPrice = 0.005 ether;
  uint256 public priceIncrement = 0.0000245 ether;
  uint256 public priceIncrementByGen = 0.000005 ether;

  uint256 public currentGeneration = 1;
  uint256 public maxGeneration = 10;

  uint256 public priceChecker;

  mapping(uint256 => uint256) public generationMintCounts;
  mapping(uint256 => uint256) public tokenGenerations;

  function set() public {
    generationMintCounts[1] = 10000;
  }


  function mintToken() public payable {
    uint256 mintPrice = calculateMintPrice();
    priceChecker = mintPrice;
    require(msg.value >= mintPrice, 'Insufficient ETH send for minting.');

    _mintInternal(msg.sender, mintPrice);
  }

  function calculateMintPrice() public view returns (uint256) {
    uint256 currentGenMintCount = generationMintCounts[currentGeneration];
    uint256 priceIncrease = priceIncrement * currentGenMintCount;
    uint256 price = startPrice + priceIncrease;
    return price;
  }

  function _mintInternal(address to, uint256 mintPrice) internal {
    if (generationMintCounts[currentGeneration] >= maxTokensPerGen) {
      _incrementGeneration();
    }

    generationMintCounts[currentGeneration]++;
  }

  function _incrementGeneration() private {
    require(
      generationMintCounts[currentGeneration] >= maxTokensPerGen,
      'Generation limit not yet reached'
    );
    currentGeneration++;
    generationMintCounts[currentGeneration] = 0;
    priceIncrement = priceIncrement + priceIncrementByGen;
  }
}

contract Tests is Test {
    MockTraitForgeNft mock;

    function setUp() external {
        mock = new MockTraitForgeNft();
    }

    function testWrongPrice() public {
        // sets mint counts for Gen 1 to 10,000
        mock.set();

        mock.mintToken{value: 0.25 ether}();
        // price for NFT #10,000 Gen1 should be 0.25 ETH according to docs
        console.log("Price for NFT #10,000 Gen1: %s", mock.priceChecker());

        mock.mintToken{value: 0.25 ether}();
        // price for NFT #1 Gen2 should equal to the "startPrice" according to docs
        console.log("Price for NFT #1 Gen2: %s", mock.priceChecker());
    }
}

Output result: 

Logs:
  Price for NFT #10,000 Gen1: 250000000000000000
  Price for NFT #1 Gen2: 5029500000000000
```

## Recommended Mitigation Steps

Increment the `generationMintCounts` mapping before the `_mintInternal()` function is called, same applies for the mint with budget function: 

```diff

    _mint(to, newItemId);
    uint256 entropyValue = entropyGenerator.getNextEntropy();

    tokenCreationTimestamps[newItemId] = block.timestamp;
    tokenEntropy[newItemId] = entropyValue;
    tokenGenerations[newItemId] = currentGeneration;
-   generationMintCounts[currentGeneration]++;
    initialOwners[newItemId] = to;

    ...

    bytes32[] calldata proof
```
