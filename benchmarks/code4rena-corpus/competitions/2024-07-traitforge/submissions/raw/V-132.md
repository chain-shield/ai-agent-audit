# Vulnerability details

## Impact
A user can find the block number and timestamp on etherscan very easily if they get the transaction hash when the function `initialiseAlphaIndices` is called. This renders the randomness invalid.

## Proof of Concept
Once the function is called, a user just needs to find the transaction on etherscan, this will give them access to the block number and the timestamp. they just need to then run the maths of the function in a dummy contract and they will be given the exact slot and number index for the rare entropy value.
The user then simply needs to wait for these numbers to be hit and claim the rare entropy value for themselves.

## Tools Used
Chat GBT
slither
foundry

## Recommended Mitigation Steps
Consider implementing chainlinkVRF, which is a proven off chain random number generator. This will give users a fair chance at claiming the rare entropy value.
