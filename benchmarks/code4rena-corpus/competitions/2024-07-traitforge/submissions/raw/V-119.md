# Vulnerability details

## Impact
The system has a max NFT per generation count - `maxTokensPerGen` set to 10k initially. However due to an error more NFTs than this max can be minted, breaking a core invariant.

## Proof of Concept
When [_mintNewEntity](https://github.com/code-423n4/2024-07-traitforge/blob/main/contracts/TraitForgeNft/TraitForgeNft.sol#L311) or [_mintInternal](https://github.com/code-423n4/2024-07-traitforge/blob/main/contracts/TraitForgeNft/TraitForgeNft.sol#L280) are called they track how many NFTs are minted, and if they are equal to `maxTokensPerGen` they trigger [_incrementGeneration](https://github.com/code-423n4/2024-07-traitforge/blob/main/contracts/TraitForgeNft/TraitForgeNft.sol#L331-L335) to increase the gen and start the process all over, but in the next gen.

```solidity
   if (generationMintCounts[gen] >= maxTokensPerGen && gen == currentGeneration) {
      _incrementGeneration();
   }
```

However [_incrementGeneration](https://github.com/code-423n4/2024-07-traitforge/blob/main/contracts/TraitForgeNft/TraitForgeNft.sol#L345-L355) sets `generationMintCounts` of the next generation to 0.

```solidity
   function _incrementGeneration() private {
      require(generationMintCounts[currentGeneration] >= maxTokensPerGen, "Generation limit not yet reached");
      currentGeneration++;
      generationMintCounts[currentGeneration] = 0;
```

This would not have been a problem if the only NFTs that can be minted are from `currentGeneration`. However [_mintNewEntity](https://github.com/code-423n4/2024-07-traitforge/blob/main/contracts/TraitForgeNft/TraitForgeNft.sol#L311), triggered by [forge](https://github.com/code-423n4/2024-07-traitforge/blob/main/contracts/TraitForgeNft/TraitForgeNft.sol#L153), has the ability to forge 2 NFTs together and mint the generation after them. In a way you put 2 NFTs of gen 3 and you get 1 of gen 4.

The above shows how users can mint NFTs using [forge](https://github.com/code-423n4/2024-07-traitforge/blob/main/contracts/TraitForgeNft/TraitForgeNft.sol#L153) for `currentGeneration + 1` (or even above), but when the `currentGeneration` reaches it's limit and gets upgraded to the next gen, all of these NFTs from that new gen will be removed from `generationMintCounts`, allowing another 10k NFTs to be minted.

## Recommended Mitigation Steps
Don't update `generationMintCounts` inside [_incrementGeneration](https://github.com/code-423n4/2024-07-traitforge/blob/main/contracts/TraitForgeNft/TraitForgeNft.sol#L351).

```diff
    function _incrementGeneration() private {
        require(generationMintCounts[currentGeneration] >= maxTokensPerGen, "Generation limit not yet reached");
        currentGeneration++;
-       generationMintCounts[currentGeneration] = 0;
        priceIncrement = priceIncrement + priceIncrementByGen;
        entropyGenerator.initializeAlphaIndices();
        emit GenerationIncremented(currentGeneration);
    }
```
