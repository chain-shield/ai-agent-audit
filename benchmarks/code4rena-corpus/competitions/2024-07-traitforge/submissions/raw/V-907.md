# Vulnerability details

## Impact

Check this `require()` statement which checks the number of times a forger NFT can be forged in a year:
- https://github.com/code-423n4/2024-07-traitforge/blob/279b2887e3d38bc219a05d332cbcb0655b2dc644/contracts/EntityForging/EntityForging.sol#L87-L90

Forger NFTs can be listed for forging and forged N+1 times instead of N. So, for example, if a forger NFT's forge potential is 5 then it can be forged 6 times in year, not 5 as expected.

## Tools Used

Manual review

## Recommended Mitigation Steps

Change [this](https://github.com/code-423n4/2024-07-traitforge/blob/279b2887e3d38bc219a05d332cbcb0655b2dc644/contracts/EntityForging/EntityForging.sol#L87-L90) `require()` statement to:
```
require(
  forgePotential > 0 && forgingCounts[tokenId] < forgePotential,
  'Entity has reached its forging limit'
);
```
