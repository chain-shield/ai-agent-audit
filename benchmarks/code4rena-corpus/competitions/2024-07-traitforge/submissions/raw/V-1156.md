# Vulnerability details

## Impact
The minting token count per generation will exceed the maximum token limit of 10,000 from generation 2 to 10 due to forging. This happens because:

1. Forged tokens are counted towards the next generation.
2. When a new generation starts, the count resets to zero.
3. This reset ignores the forged tokens already counted.
4. As a result, each generation after the first can have 10,000 minted tokens plus any number of forged tokens.

This means every generation from 2 to 10 can have more than 10,000 tokens, breaking the intended limit and affecting the token's scarcity.

## Proof of Concept
The issue happens because of how two functions work together:
1. In `TraitForgeNft::_mintNewEntity`, when a token is forged, it counts for the next generation:
```
generationMintCounts[gen]++;
```
2. But in `TraitForgeNft::_incrementGeneration`, when we move to the next generation, it will reset the count, even if a token has been generated through the forging process:
```
currentGeneration++;
generationMintCounts[currentGeneration] = 0;
```
Here's how this plays out:
1. We're in generation 1. People mint tokens until we're close to 10,000.
2. Some tokens are forged, which counts towards generation 2.
3. The last few tokens for generation 1 are minted, hitting 10,000.
4. We move to generation 2, but the count resets to 0, forgetting the forged tokens.
5. Now generation 2 can have 10,000 minted tokens, plus all the forged ones.

This can happen for every generation after the first, always allowing more than 10,000 tokens per generation.

## Recommended Mitigation Steps
Modify the `_incrementGeneration` function to preserve the count of forged tokens:
```diff
function _incrementGeneration() private {
    require(
        generationMintCounts[currentGeneration] >= maxTokensPerGen,
        'Generation limit not yet reached'
    );
    currentGeneration++;
    // Remove this line: 
-   generationMintCounts[currentGeneration] = 0;
    priceIncrement = priceIncrement + priceIncrementByGen;
    entropyGenerator.initializeAlphaIndices();
    emit GenerationIncremented(currentGeneration);
}
```
