# Vulnerability details

Users can sell their nft for any price they desire. In case if the nft has forger potential, the owner may charge a high price.
The buyer can check this by calling the `isForger()` in TraitForgeNft contract.

However there is no way to check how many times the nft has already been used for forging with another nft. Same goes for a normal (merger) nft.

## Proof of Concept

### Scenario
- Bob has a forger nft but has hit the limit the number of times he can use it to forge with others (`forgingCounts` reached forger potential).
- Bob lists the nft for selling.
- Alice verifies this by calling the `isForger()` function to validate Bob's claim.
- Alice buys the nft. But when she calls `listForForging()`, the function reverts because the `forgingCounts` has reached the forge potential threshold.
- Also its impossible for Alice to use it for forging till `lastForgeResetTimestamp` becomes greater than one year from the time it was first listed.

Same situation can happen with a non forger nft whose `forgingCounts` has hit the potential. The `forgingCounts` will only be reset when one year has passed.

## Impact
Buyers can be deceived when buying an nft who has already hit its forger or merger potential depriving them from using the nft for forging.

## Tools Used
Manual Review

## Recommended Mitigation Steps
Add a function which fetches the `forgingCounts` for a nft so that buyers can  validate if they want to buy one which cannot be forged for a year.
