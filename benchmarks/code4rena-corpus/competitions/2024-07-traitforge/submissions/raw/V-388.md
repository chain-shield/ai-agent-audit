# Vulnerability details

## Summary

`ageMultiplier` variable in the `NukeFund` contract is initialized with a default value of 0, which can lead to unexpected behavior if the value is not updated before being used in calculations.

## Proof of Concept

The `ageMultiplier` variable is used in the `NukeFund::calculateAge` function to calculate the age factor of the NFTs. If the `ageMultiplier` is not updated before being used in the calculation, the age factor will be 0, leading to wrong calculations and potentially undesired behavior.

[NukeFund.sol#L24](https://github.com/code-423n4/2024-07-traitforge/blob/279b2887e3d38bc219a05d332cbcb0655b2dc644/contracts/NukeFund/NukeFund.sol#L24)

[NukeFund.sol#L117-L133](https://github.com/code-423n4/2024-07-traitforge/blob/279b2887e3d38bc219a05d332cbcb0655b2dc644/contracts/NukeFund/NukeFund.sol#L117-L133)

Although the folder `/scripts` files are out of the scope of the audit, the `ageMultiplier` is not set in any of the files. Leading to the conclusion that the `ageMultiplier` is not being set in the contract. So it's default value is 0 upon deployment.

## Impact

The default value of 0 for `ageMultiplier` can lead to incorrect calculations in the `NukeFund::getNukeAge` function.

## Tools Used

Manual Review

## Recommended Mitigation Steps

Set a default value for `ageMultiplier` in the `NukeFund` contract to avoid unexpected behavior.

```diff
-   uint256 public ageMultiplier;
+   uint256 public ageMultiplier = 1;
```
