# Vulnerability details

## Vulnerability Detail
According to the documentation, the 5th digit in the entropy value should represent the Forge Potential, which is intended to be an integer between 0 and 9. However, the current implementation retrieves the first digit of the entropy value instead of the 5th digit.
## impact
The use of the first digit for calculating Forge Potential instead of the 5th digit means that the Forge Potential will be derived incorrectly.
