# Vulnerability details

## Impact

Check the [deriveTokenParameters()](https://github.com/code-423n4/2024-07-traitforge/blob/279b2887e3d38bc219a05d332cbcb0655b2dc644/contracts/EntropyGenerator/EntropyGenerator.sol#L136-L161) method responsible for fetching NFT characteristics. 

[This](https://github.com/code-423n4/2024-07-traitforge/blob/279b2887e3d38bc219a05d332cbcb0655b2dc644/contracts/EntropyGenerator/EntropyGenerator.sol#L152) line calculates an initial nuke factor. Keeping in mind that max entropy is 999999 then `999999 / 4000000` always returns 0 thus making initial nuke factor to be 0 for all NFT entities on start. The expected behavior (from whitepaper) is that nuke factor should be random.
