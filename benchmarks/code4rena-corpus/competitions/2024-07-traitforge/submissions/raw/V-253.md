# Vulnerability details

## Impact

Impact: High
Likelihood: High

When a function is internal this means that everyone can call the function if they inherit the contract the function is in and have a function which calls the parent function. In this vulnerability the case is the same as the function `TraitForgeNft::_mintInternal`


## Proof of Concept
1. Deploy all contracts in the project. 
2. Attacker waits for the project to be unpaused and everything starts working normally.
3. Attacker creates a new contract X which inherits `TraitForgeNft.sol`
4. Attacker creates a function inside the contract X which calls `_mintInternal` of its parent contract with `to` address as their own and an arbitrary `mintPrice`, thus minting for free and as much as they want.

## Tools Used
Solidity, VSCode

## Recommended Mitigation Steps
Just change the function from internal to private:
```solidity
+ function _mintInternal(address to, uint256 mintPrice) private {
- function _mintInternal(address to, uint256 mintPrice) internal {
    if (generationMintCounts[currentGeneration] >= maxTokensPerGen) {
      _incrementGeneration();
    }
    ...
  }
```
