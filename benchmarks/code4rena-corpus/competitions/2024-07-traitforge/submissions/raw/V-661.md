# Vulnerability details

## Impact

Loss of funds for user. Some bots will have an unfair advantage.

## Proof of Concept

When a token is minted, the token ID is incremented. Using the function getTokenEntropy allows a user to determine the characteristics of the next token. Knowing the characteristics of future entities allows a bot to call mintWithBudget or mintToken to obtain the most profitable tokens.

## Tools Used

Manual review.

## Recommended Mitigation Steps

Add a randomness factor to the _mintInternal function using a library like chainlink VRF 








## Assessed type

ERC721
