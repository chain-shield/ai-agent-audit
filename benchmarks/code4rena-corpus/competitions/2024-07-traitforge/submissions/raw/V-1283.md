# Vulnerability details

Impact

`_mintNewEntity` and `_mintInternal`rely on `_incrementGeneration` which will always revert when called (alas, when transitioning to a new generation is required).
All mint/forge functions of the TraitForgeNFT contract are affected: `mintToken`, `mintWithBudget`, `forge`.

This issue has severe implications:
1. Generation transitions will always revert, effectively halting the entire minting process once the first generation is complete.
2. The contract will be unable to progress beyond the first generation, limiting the total supply and breaking core functionality.
3. Users will be unable to mint tokens once the generation limit is reached, leading to a degraded user experience and potential loss of trust.

## Proof of Concept

EntropyGenerator's [`initializeAlphaIndices`](https://github.com/code-423n4/2024-07-traitforge/blob/279b2887e3d38bc219a05d332cbcb0655b2dc644/contracts/EntropyGenerator/EntropyGenerator.sol#L206) is guarded by an onlyOwner modifier which prevents the [`entropyGenerator.initializeAlphaIndices()`](https://github.com/code-423n4/2024-07-traitforge/blob/279b2887e3d38bc219a05d332cbcb0655b2dc644/contracts/TraitForgeNft/TraitForgeNft.sol#L353) in TraitForgeNFT's [`_incrementGeneration`](https://github.com/code-423n4/2024-07-traitforge/blob/279b2887e3d38bc219a05d332cbcb0655b2dc644/contracts/TraitForgeNft/TraitForgeNft.sol#L345) function to execute successfully.

Both [`mintToken`](https://github.com/code-423n4/2024-07-traitforge/blob/279b2887e3d38bc219a05d332cbcb0655b2dc644/contracts/TraitForgeNft/TraitForgeNft.sol#L181) and [`mintWithBudget`](https://github.com/code-423n4/2024-07-traitforge/blob/279b2887e3d38bc219a05d332cbcb0655b2dc644/contracts/TraitForgeNft/TraitForgeNft.sol#L202) rely on [`_mintInternal`](https://github.com/code-423n4/2024-07-traitforge/blob/279b2887e3d38bc219a05d332cbcb0655b2dc644/contracts/TraitForgeNft/TraitForgeNft.sol#L193C5-L193C18) which depends on successful execution of [`_incrementGeneration`](https://github.com/code-423n4/2024-07-traitforge/blob/279b2887e3d38bc219a05d332cbcb0655b2dc644/contracts/TraitForgeNft/TraitForgeNft.sol#L345) when crossing generation boundary is [`required`](https://github.com/code-423n4/2024-07-traitforge/blob/279b2887e3d38bc219a05d332cbcb0655b2dc644/contracts/TraitForgeNft/TraitForgeNft.sol#L281-L283). [`forge`](https://github.com/code-423n4/2024-07-traitforge/blob/279b2887e3d38bc219a05d332cbcb0655b2dc644/contracts/TraitForgeNft/TraitForgeNft.sol#L345) rely on [`_mintNewEntity`](https://github.com/code-423n4/2024-07-traitforge/blob/279b2887e3d38bc219a05d332cbcb0655b2dc644/contracts/TraitForgeNft/TraitForgeNft.sol#L311) which also depends on [`_incrementGeneration`](https://github.com/code-423n4/2024-07-traitforge/blob/279b2887e3d38bc219a05d332cbcb0655b2dc644/contracts/TraitForgeNft/TraitForgeNft.sol#L345) when crossing generation boundary is [`required`](https://github.com/code-423n4/2024-07-traitforge/blob/279b2887e3d38bc219a05d332cbcb0655b2dc644/contracts/TraitForgeNft/TraitForgeNft.sol#L331-L335).
