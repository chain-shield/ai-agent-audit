# Vulnerability details

## Impact
Minting the first NFT of each gen will only cost `startPrice`, avoiding any `priceIncrement`.

## Proof of Concept
[mintToken](https://github.com/code-423n4/2024-07-traitforge/blob/main/contracts/TraitForgeNft/TraitForgeNft.sol#L181) and [mintWithBudget](https://github.com/code-423n4/2024-07-traitforge/blob/main/contracts/TraitForgeNft/TraitForgeNft.sol#L202) each calculate the starting price of NFTs and call [_mintInternal](https://github.com/code-423n4/2024-07-traitforge/blob/main/contracts/TraitForgeNft/TraitForgeNft.sol#L280), and if the already minted NFTs are equal to `maxTokensPerGen` `_mintInterna` will move 1 gen up.


```solidity
   if (generationMintCounts[currentGeneration] >= maxTokensPerGen) {
      _incrementGeneration();
   }
```

When moving generations, the new `generationMintCounts` can start at 0 because of 2 things:
1. There may be no forged NFTs from the next gen, making `generationMintCounts[newGen] == 0`
2. [_incrementGeneration]() which moves generations purposefully  sets `generationMintCounts[newGen]` to 0.

```solidity
    function _incrementGeneration() private {
        currentGeneration++;
        generationMintCounts[currentGeneration] = 0;
```

Meaning that after minting the last NFT from a generation, the next NFT will mint at `generationMintCounts[newGen] == 0`. However that will calculate it's minting price to be equal to `startPrice`, without charging any `priceIncrease`.

```solidity
   function calculateMintPrice() public view returns (uint256) {
      //@audit if generationMintCounts = 0, then we only charge startPrice
      // startPrice + generationMintCounts[currentGeneration] * priceIncrement
      uint256 currentGenMintCount = generationMintCounts[currentGeneration];
      uint256 priceIncrease = priceIncrement * currentGenMintCount;
      uint256 price = startPrice + priceIncrease;
      return price;
   }
```

## Tools Used
Manual review

## Recommended Mitigation Steps
An `if` can be placed inside [calculateMintPrice](https://github.com/code-423n4/2024-07-traitforge/blob/main/contracts/TraitForgeNft/TraitForgeNft.sol#L227-L233) to charge `startPrice + priceIncrement` if that is the first NFT.
