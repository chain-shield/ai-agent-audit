# Vulnerability details



## Vulnerability Details

Whenever a new entity is minted, the entropy is calculated using the `EntropyGenerator:getEntropy` function. If the following condition is satisfied, the entity will receive a special "Golden God" status (with an entropy value of 999999):

```solidity
if (
      slotIndex == slotIndexSelectionPoint &&
      numberIndex == numberIndexSelectionPoint
    ) {
      return 999999;
}
```

An attacker can monitor the blockchain and wait until this specific condition is about to be met. They can then execute their transaction precisely at the right moment to claim the "Golden God" entity, thereby preventing genuine users from obtaining it.

## Impact

This vulnerability allows an attacker to exploit the system and gain an unfair advantage by claiming the special entity. This undermines the fairness and integrity of the minting process, potentially leading to loss of trust among users.

## Recommendation

To mitigate this issue, consider introducing a more robust and unpredictable method for assigning the special "Golden God" status. This could involve using a more secure source of randomness or implementing additional checks to prevent manipulation.
