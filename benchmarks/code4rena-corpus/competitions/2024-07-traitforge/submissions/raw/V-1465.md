# Vulnerability details

## Impact
Loss of rewardDebt since msg.value is used for calculating `amountPerWeight` instead of `balanceOf(address.this)`

## Proof of Concept

https://github.com/code-423n4/2024-07-traitforge/blob/279b2887e3d38bc219a05d332cbcb0655b2dc644/contracts/DevFund/DevFund.sol#L14-L28
```solidty
  receive() external payable {
    if (totalDevWeight > 0) {
      uint256 amountPerWeight = msg.value / totalDevWeight;
      uint256 remaining = msg.value - (amountPerWeight * totalDevWeight);
      totalRewardDebt += amountPerWeight;
      if (remaining > 0) {
        (bool success, ) = payable(owner()).call{ value: remaining }('');
        require(success, 'Failed to send Ether to owner');
      }
    } else {
      (bool success, ) = payable(owner()).call{ value: msg.value }('');
      require(success, 'Failed to send Ether to owner');
    }
    emit FundReceived(msg.sender, msg.value);
  }
```

Here amountPer Weight sohuld be calculated using `balanceOf(address.this)`.
and the remaing =`balanceOf(address.this)` - (amountPerWeight * totalDevWeight);

Else DevFund contract will get undeserved funds.
