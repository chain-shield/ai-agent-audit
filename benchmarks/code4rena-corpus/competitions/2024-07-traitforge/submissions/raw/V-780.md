# Vulnerability details


### Impact
In the mintWithBudget function, the condition _tokenIds < maxTokensPerGen is misapplied. The _tokenIds variable serves as a global counter across all generations, now while _tokenIds is equal to maxTokensPerGen (10,000) then the mintWithBudget function will revert,ceasing operation of mintWithBudget permanently

### Proof of Concept
```jsx
@> while (budgetLeft >= mintPrice && _tokenIds < maxTokensPerGen) {
    _mintInternal(msg.sender, mintPrice);
    amountMinted++;
    budgetLeft -= mintPrice;
    mintPrice = calculateMintPrice();
}
```
### Tool used
manual

### Recommended Mitigation
kindly remove this vulnerable part of check in TraitForgeNFT::mintWithBudget
```jsx
 _tokenIds < maxTokensPerGen)
```
