# Vulnerability Details

The `EntropyGenerator:getNextEntropy` function calculates the entropy for new minting entities. This function calls `getEntropy()` with parameters `currentSlotIndex` and `currentNumberIndex`.

- **currentNumberIndex**: Increases every time a new NFT is minted for a particular generation, ranging from 0 to 12.
- **currentSlotIndex**: Increases every time `currentNumberIndex` completes its cycle (0 to 12), ranging from 0 to 769.

The `getEntropy` function includes the following check:

```solidity
if (slotIndex == slotIndexSelectionPoint && numberIndex == numberIndexSelectionPoint) {
    return 999999;
}
```

Here, both `slotIndexSelectionPoint` and `numberIndexSelectionPoint` are random numbers calculated each time the generation changes. `slotIndexSelectionPoint` ranges from 512 to 769, while `numberIndexSelectionPoint` ranges from 0 to 12.

If a user's minting process satisfies this condition, they will receive a "Golden Gold" entity (with entropy value 999999). However, due to the current logic, users in some generations may not be able to claim this "Golden Gold" entity.

### Vulnerability Explained

1. When 10,000 entities have been minted, `currentSlotIndex` will be 769 and `currentNumberIndex` will be 3 \[(769 * 13) + (2 + 1) = 10,000\].
2. As minting of the next generation starts, these values continue to increase until `currentNumberIndex` reaches 12.
3. When `(currentSlotIndex, currentNumberIndex)` is (769, 12), these values reset to (0, 0)[For next minting]. At this point, 10 entities of the new generation will have been minted. For the second generation, when 10,000 entities are minted, `(currentSlotIndex, currentNumberIndex)` will be (768, 5).
4. Given that `slotIndexSelectionPoint` ranges from 512 to 769 and `numberIndexSelectionPoint` ranges from 0 to 12, if the second generation gets the values (768, 10) for `slotIndexSelectionPoint` and `numberIndexSelectionPoint`, users in the second generation will not receive the "Golden Gold" entity. Conversely, users in other generations might receive multiple "Golden Gold" entities, while some generations might receive none.



## Impact

This inconsistency can lead to unfair distribution of the "Golden Gold" entities, with some users receiving none and others receiving more than one.


## Tools Used
Manually
## Recommended Mitigation Steps
Use some other values of `slotIndexSelectionPoint` and `numberIndexSelectionPoint`
