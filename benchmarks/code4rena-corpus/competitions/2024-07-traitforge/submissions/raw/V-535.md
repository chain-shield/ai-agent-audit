# Vulnerability details

## Impact
forge function allow user to send more ETH than is required, but not refund excess payment.

## Proof of Concept
Line 126 allows user to send more eth than forgingFee: `require(msg.value >= forgingFee, 'Insufficient fee for forging');`. 

But inside `forgeWithListed()` no refund excess payment back to user.

## Tools Used
Manual review

## Recommended Mitigation Steps
Change require statement inside `forgeWithListed()`.
```diff
- require(msg.value >= forgingFee, 'Insufficient fee for forging');
+ require(msg.value == forgingFee, 'Insufficient fee for forging');
```

or add excess payment refunding like this: https://github.com/code-423n4/2024-07-traitforge/blob/279b2887e3d38bc219a05d332cbcb0655b2dc644/contracts/TraitForgeNft/TraitForgeNft.sol#L195-L198
