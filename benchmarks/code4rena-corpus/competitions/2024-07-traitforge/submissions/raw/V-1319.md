# Vulnerability details

## Impact

The protocol will be DoS because no one will want to mint tokens because of the huge mint price. The price will be of huge value when `generationMintCounts` per generation increases a lot. The max value is set to 10,000.

## Proof of Concept

In `TraitForgeNft.sol` we have `mintToken()` and `mintWithBudget()`. I will give an example with `mintToken()` but this also applies to the other function:

```solidity
  function mintToken(
    bytes32[] calldata proof
  )
    public
    payable
    whenNotPaused
    nonReentrant
    onlyWhitelisted(proof, keccak256(abi.encodePacked(msg.sender)))
  {
    uint256 mintPrice = calculateMintPrice();
    require(msg.value >= mintPrice, 'Insufficient ETH send for minting.');

    _mintInternal(msg.sender, mintPrice);

    uint256 excessPayment = msg.value - mintPrice;
    if (excessPayment > 0) {
      (bool refundSuccess, ) = msg.sender.call{ value: excessPayment }('');
      require(refundSuccess, 'Refund of excess payment failed.');
    }
  }
```

This function allows a user to mint a NFT. What we need to see is how the price is calculated:

```solidity
190: uint256 mintPrice = calculateMintPrice();
```

```solidity
  function calculateMintPrice() public view returns (uint256) {
    uint256 currentGenMintCount = generationMintCounts[currentGeneration];
    uint256 priceIncrease = priceIncrement * currentGenMintCount;
    uint256 price = startPrice + priceIncrease;
    return price;  
  }
```

- **`currentGenMintCount`**: Retrieves the number of tokens minted in the current generation.
- **`priceIncrease`**: Computes the price increase based on the number of tokens minted and a predetermined increment value (`priceIncrement`).
- **`price`**: Adds the price increase to the base price (`startPrice`) to determine the current mint price.

The root of the problem is `generationMintCounts[currentGeneration]`.  This value can reach up to 10 000. And then multiply by `priceIncrement`.  Currently, the `priceIncrement` is `0.0000245 ether`, but this value will also increase. That is, towards the end of the generation, the cost of minting a token may reach over $1000(depending on the price of ETH can reach much larger values than that). Nobody will pay, and this will lead to DoS of the protocol because nobody will use it.
