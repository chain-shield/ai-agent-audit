# Vulnerability details

## Impact
- Loss of users fund if they provided excess ETH during `forgeWithListed()`.
- If user provided ETH greater than forgingFee then contract would not refund it and there is no way to retrieve the ETH from contract.
- There are other functions in contract which returns the extra ETH send my user while interacting with functions.
- Total lock of excessive ETH in contract and loss to users for extra ETH provided.
