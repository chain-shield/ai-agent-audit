# Vulnerability details

## Impact
`TraitForgeNft::_tokenIds` is a storage variable that keeps increasing exceeding `TraitForgeNft::maxTokensPerGen` variable. So the comparision `_tokenIds < maxTokensPerGen` in 
```solidity
 while (budgetLeft >= mintPrice && _tokenIds < maxTokensPerGen)
```
in TraitForgeNft::mintWithBudget() function is wrong so after _tokenIds exceed maxTokensPerGen which is 10000 for now, you can not call mintWithBudget() function anymore.
# PoC
No PoC code here because there's a vulnerability (which I have reported with title: `After minting all generation 1, no one can mint again because EntropyGenerator::initializeAlphaIndices() function will revert`) that make you can't mint after generation one has fully minted.

## Recommended Mitigation Steps
Remove the comparison `_tokenIds < maxTokensPerGen`
