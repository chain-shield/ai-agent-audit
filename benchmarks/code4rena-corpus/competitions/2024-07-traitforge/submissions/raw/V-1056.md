# Vulnerability details

## Impact - Medium
Impact: High, because it can lead to loss of funds 

Likelihood: Medium , as the owner of the `TraitForgeNft.sol` contract might forget to set `nukeFundAddress`.


## Description
When a new entity is minted by `_mintInternal()` function in the `TraitForgeNft.sol` contract, 10% of the mint price should be distributed to `NukeFund.sol` contract by the internal `_distributeFunds()` function.However,`_distributeFunds()` lacks checks for `nukeFundAddress`.

```solidity
 function _distributeFunds(uint256 totalAmount) private {
    require(address(this).balance >= totalAmount, 'Insufficient balance');
    (bool success, ) = nukeFundAddress.call{ value: totalAmount }(''); 
    require(success, 'ETH send failed');

    emit FundsDistributedToNukeFund(nukeFundAddress, totalAmount);
  }
```


The `nukeFundAddress` in `TraitForgeNft.sol` is set by the `setNukeFundContract()` function, which can only be called by the contracto owner.

```solidity
function setNukeFundContract(
    address payable _nukeFundAddress
  ) external onlyOwner {
    nukeFundAddress = _nukeFundAddress;
    emit NukeFundContractUpdated(_nukeFundAddress); .
  }
```

If owner of the `TraitForgeNft.sol` forget to set `nukeFundAddress`, the low-level call in `_distributeFunds()` -> `nukeFundAddress.call{ value: totalAmount }('')` will return `true`, the transaction will pass successfully and this will lead to loss of funds.

    ```solidity
    import '@openzeppelin/contracts/utils/cryptography/MerkleProof.sol';

    contract MerkleTree {
        bytes32[] public hashes;

        constructor() {
        }

        function generateMerkleTree(address[] memory addresses) public returns (bytes32[] memory) {
            
            for (uint256 i = 0; i < addresses.length; i++) {
                hashes.push(keccak256(abi.encodePacked(addresses[i])));
            }

            uint256 n = addresses.length;
            uint256 offset = 0;

            while (n > 0) {
                for (uint256 i = 0; i < n - 1; i += 2) {
                    hashes.push(
                        keccak256(
                            abi.encodePacked(
                                hashes[offset + i], hashes[offset + i + 1]
                            )
                        )
                    );
                }
                offset += n;
                n = n / 2;
            }
            return hashes;
        }
        function getRoot() public view returns (bytes32) {
            return hashes[hashes.length - 1];
        }
    }
    ```

## Recommended Mitigation Steps
Add check for  `nukeFundAddress != address(0)` in `_didtributeFunds()` function :
```solidity

  function _distributeFunds(uint256 totalAmount) private {
  +  require(nukeFundAddress != address(0), 'NukeFund address not set');
    require(address(this).balance >= totalAmount, 'Insufficient balance');
```
