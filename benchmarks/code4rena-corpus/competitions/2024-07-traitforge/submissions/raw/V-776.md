# Vulnerability details

## Impact
The current smart contract design allows NFT owners to bypass the official listing mechanism, potentially facilitating tax evasion

## Proof of Concept
The current implementation allows NFTs to be transferred freely between users without any restrictions or tracking mechanisms in the marketplace contract. This enables users to conduct peer-to-peer trades without using the official listing function, potentially to avoid taxes or fees. check [here](https://github.com/code-423n4/2024-07-traitforge/blob/279b2887e3d38bc219a05d332cbcb0655b2dc644/contracts/TraitForgeNft/TraitForgeNft.sol#L367-L395).

Users can directly call this function to transfer NFTs without interacting with the marketplace contract. For example:

* Alice owns a valuable NFT with tokenId 123.
* Alice agrees to sell the NFT to Bob for 100 ETH in a private deal.
* Bob sends 100 ETH to Alice through a separate transaction or off-chain payment.
* Alice calls transferFrom(aliceAddress, bobAddress, 123) on the NFT contract.
* The NFT is transferred to Bob without any record in the marketplace contract.
