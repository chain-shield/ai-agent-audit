# Vulnerability details

The current implementation has a high probability that no user will receive the entropy value of 999999. This occurs because the initializeAlphaIndices function, 
which can be called at any time a token is minted, dynamically changes the variables slotIndexSelection and numberIndexSelectionPoint. 
As a result, the specific conditions needed for a user to receive the value 999999 are likely to change before they can be met.

## Impact
The intended special entropy value 999999 might never be assigned, leading to a loss of intended functionality. 
Users expecting a chance to receive 999999 may never actually have that opportunity, affecting user trust and satisfaction.
