# Vulnerability details

## Impact
The `updateDev` function in the `DevFund` contract calculates the pending rewards using the developer's old weight before updating it. This can lead to incorrect reward calculation. For example, in cases where a developer's weight is increased, they will receive fewer rewards than they should for the period between their last update and this one and also in a case where a developer's weight is decreased, they will receive more rewards than they should for the same period.This miscalculation results in an unfair distribution of rewards.

## Proof of Concept
The [`updateDev` function](https://github.com/code-423n4/2024-07-traitforge/blob/279b2887e3d38bc219a05d332cbcb0655b2dc644/contracts/DevFund/DevFund.sol#L40-L49) in the `DevFund.sol` contract looks like this:

```solidity
function updateDev(address user, uint256 weight) external onlyOwner {
    DevInfo storage info = devInfo[user];
    require(weight > 0, 'Invalid weight');
    require(info.weight > 0, 'Not dev address');
    totalDevWeight = totalDevWeight - info.weight + weight;
    info.pendingRewards += (totalRewardDebt - info.rewardDebt) * info.weight;
    info.rewardDebt = totalRewardDebt;
    info.weight = weight;
    emit UpdateDev(user, weight);
}
```

Here, the `info.pendingRewards` is calculated using the old weight before updating the developer's weight and `totalDevWeight` which is incorrect.

## Recommended Mitigation Steps 

```solidity
function updateDev(address user, uint256 weight) external onlyOwner {
    DevInfo storage info = devInfo[user];
    require(weight > 0, 'Invalid weight');
    require(info.weight > 0, 'Not dev address');
    
    // Calculate pending rewards with current weight
    info.pendingRewards += (totalRewardDebt - info.rewardDebt) * info.weight;
    
    // Update totalDevWeight
    totalDevWeight = totalDevWeight - info.weight + weight;
    
    // Update dev's weight
    info.weight = weight;
    
    // Update rewardDebt
    info.rewardDebt = totalRewardDebt;
    
    emit UpdateDev(user, weight);
}
```

This will ensure that the pending rewards are calculated correctly based on the developer's current weight before any changes are made thereby allowing for a fair distribution of the rewards.
