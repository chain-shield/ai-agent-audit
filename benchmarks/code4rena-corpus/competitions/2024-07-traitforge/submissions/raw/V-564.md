# Vulnerability details

## Impact

The current implementation of `TraitForgeNft` contract allows users to mint new entities directly via calling `mintToken()` or `mintWithBudget()` functions and paying a gradually changing mint price. These functions would call internal `_mintInternal()`. The problem is that `_mintInternal()` checks whether the tokens for the particular generation has reached its maximum (10000) and if so, it increases the generation. However, `_incrementGeneration()` function does not check whether the new incremented generation is bigger than the maximum allowed generation.

## Proof of Concept

The sequence of calls:

https://github.com/code-423n4/2024-07-traitforge/blob/main/contracts/TraitForgeNft/TraitForgeNft.sol#L193
```
 _mintInternal(msg.sender, mintPrice);
```

https://github.com/code-423n4/2024-07-traitforge/blob/main/contracts/TraitForgeNft/TraitForgeNft.sol#L280-283
```
 function _mintInternal(address to, uint256 mintPrice) internal {
    if (generationMintCounts[currentGeneration] >= maxTokensPerGen) {
      _incrementGeneration();
    }
```

`_mintInternal()` checks whether the mint count is bigger than maximum tokens per generation and is so, generation is incremented:

https://github.com/code-423n4/2024-07-traitforge/blob/main/contracts/TraitForgeNft/TraitForgeNft.sol#L345-355
```
 function _incrementGeneration() private {
    require(
      generationMintCounts[currentGeneration] >= maxTokensPerGen,
      'Generation limit not yet reached'
    );
    currentGeneration++;
    generationMintCounts[currentGeneration] = 0;
    priceIncrement = priceIncrement + priceIncrementByGen;
    entropyGenerator.initializeAlphaIndices();
    emit GenerationIncremented(currentGeneration);
  }
```

This function only checks again if the mint count is bigger than the maximum tokens per generation but it does not check if the new generation is bigger than the maximum allowed generation. This would effectively allow minting in a generation that is not allowed:


https://github.com/code-423n4/2024-07-traitforge/blob/main/contracts/TraitForgeNft/TraitForgeNft.sol#L35
```
 uint256 public maxGeneration = 10;
```

## Tools Used

Manual review.

## Recommended Mitigation Steps

Add the check inside of `_incrementGeneration` to make sure that the max generation has not been exceeded.
