# Vulnerability details

## Impact
The following contracts: `TraitForgeNft.sol`, `EntityForging.sol`, `EntropyGenerator.sol`, `EntityTrading.sol`, `DevFund.sol` and `NukeFund.sol` are supposed to be pausable (as they all inherit from Pausable), but they don't implement the external pause/unpause functionalities which means it will never be possible to pause them.
## Proof of Concept
All the following contracts `TraitForgeNft`, `EntityForging`, `EntropyGenerator`, `EntityTrading`, `DevFund` and `NukeFund` inherit from the `openzeppelin Pausable` extension which means that they contain internal functions `_pause` and `_unpause`.

Since these functions are internal, two other public/external functions must be implemented, so that the owner can pause and cancel the pause, if necessary.None of the aforementioned contracts implement those functions, which means even if those contracts are supposed to be pausable (and have the pause/unpause functionalities), none of them can be paused
## Tools Used
forge
## Recommended Mitigation Steps
In each contract you should create public/external functions, with modifier `onlyOwner`, that will enable pause and disable pause.For example: 

```solidity
/**
 * @dev Triggers stopped state.
 * Contract must not be paused
 */
function pause() public onlyOwner {
    _pause();
}

/**
 * @dev Returns to normal state.
 * Contract must be paused
 */
function unpause() public onlyOwner {
    _unpause();
}
```
