# Vulnerability details

## Impact
Malicious user can game the system to accumulate airdrops and user who purchases nfts from secondary markets gets no airdrop.

## Proof of Concept
In the traitForgeNft contracts, whenever a user mints a NFT the user is allocated an airdrop amount in the airdrop contract 
```
if (!airdropContract.airdropStarted()) {
      airdropContract.addUserAmount(to, entropyValue);
    }
```

However, the minted NFTs are transferrable and can be listed for sale or bought. The NFT contract however fails to update the token minter's airdrop amount whenever the minted nft is sold, neither does it assign any airdrop value to the buyer of the NFTs. Causing the seller to gain more airdrops than he ought to and the buyer to recieve none. A malicious user can also game the system by repeatedly using the same amount to mint and sell NFTs while accumulating airdrop points.

```
function testAirdropAmountNotUpdated() public {
        vm.warp(block.timestamp + 25 hours);
        vm.roll(1);
        vm.deal(alice, 10e18);
        vm.deal(bob, 1e18);

        vm.prank(owner);
        entropyGenerator.writeEntropyBatch1();
        
        bytes32[] memory proof;
        uint256 mintPrice = traitForgeNft.calculateMintPrice();

        vm.startPrank(alice);
        traitForgeNft.mintToken{value : mintPrice}(proof);

        mintPrice = traitForgeNft.calculateMintPrice();

        traitForgeNft.mintToken{value : mintPrice}(proof);
        
        //returns 862495
        console.log(airdrop.userInfo(alice));

        traitForgeNft.approve(address(entityTrading), 1);

        //alice lists an NFT for sale
        entityTrading.listNFTForSale(1, 1e18);
        vm.stopPrank();
       
        //bob buys the an NFT from alice
        vm.prank(bob);
        entityTrading.buyNFT{value: 1e18}(1);



        console.log(airdrop.userInfo(alice)); //862495
        console.log(airdrop.userInfo(bob));  //0
    }
```
