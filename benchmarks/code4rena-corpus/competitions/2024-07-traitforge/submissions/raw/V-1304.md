# Vulnerability details

## Impact
The idea of 999999 checks inside `EntropyGenerator::writeEntropyBatch1` and `EntropyGenerator::writeEntropyBatch2` is to not allow to write a 999999 entropy to any of the first 2 batches slots. Each slot has 13 entropy values. 

Inside `EntropyGenerator::writeEntropyBatch1` and `EntropyGenerator::writeEntropyBatch2` functions we generate a slot as a whole 78-digit number. It means we should take each slot, and check each possible entropy (13 overall) of the slot not to equal 999999. Instead, they check not each entropy value, but the whole 78-digit slot value, which is not correct.
