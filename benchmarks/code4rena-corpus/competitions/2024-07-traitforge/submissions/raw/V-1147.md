# Vulnerability details

## Impact

The `Airdrop`, `DevFund`, `EntityForging`, `EntropyGenerator`, `NukeFund`, and `TraitForgeNFT` contracts inherit from the `Pausable` contract, which allows the owner to pause the functions that implement the `whenNotPaused` modifier. However, none of these contracts provide functions to pause or unpause, as the `Pausable` contract only includes these methods as internal. Since these functions are internal, the contract must implement additional public or external pause and unpause functions to allow the owner to control the pausing state when necessary.

## Tools Used

Manual Review

## Recommended Mitigation Steps

Add public or external pause and unpause functions to the aforementioned contracts to enable their pausability:

```solidity
function pause() external onlyOwner {
    _pause();
}

function unpause() external onlyOwner {
    _unpause();
}
```
