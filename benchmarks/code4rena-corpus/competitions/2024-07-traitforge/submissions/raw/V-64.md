# Vulnerability details

## Impact

The uninitialized state variable `ageMultiplier` can lead to significant problems in the contract’s functionality.

Specifically, the following impacts may occur:

1. **Incorrect Calculations:** Since `ageMultiplier` is not initialized, it defaults to `0`, leading to all age-related calculations resulting in `0`. This can cause incorrect rewards or penalties for token holders.
2. **Inconsistent Behavior:** The contract’s behavior becomes unpredictable as the calculations relying on `ageMultiplier` will not function as intended.
3. **Contract Integrity:** The overall integrity of the contract is compromised if calculations produce unexpected results, which could impact its reliability and security.


## Proof of Concept

1. **Deploy the Contract:**
   - Deploy the `NukeFund` contract.

2. **Mint and Transfer NFT:**
   - Mint an NFT to a user.
   - Send funds to the `NukeFund` contract.

3. **Initiate Age Calculation:**
   - Call the `calculateAge` function, which will:
     - Use the uninitialized `ageMultiplier`.
     - Result in `0` age-related value due to `ageMultiplier` being `0`.

**Expected Outputs:**
- The `calculateAge` function returns `0` for any token due to `ageMultiplier` being `0`.

## Recommended Mitigation Steps

Ensure that the `ageMultiplier` is initialized to a non-zero default value and validated properly before use. Update the contract as below:

**Constructor Initialization:**

```solidity
constructor(
  address _traitForgeNft,
  address _airdrop,
  address payable _devAddress,
  address payable _daoAddress
) {
  nftContract = ITraitForgeNft(_traitForgeNft);
  airdropContract = IAirdrop(_airdrop);
  devAddress = _devAddress;
  daoAddress = _daoAddress; 
  ageMultiplier = 1; // Set a default value
}
```

**Setter Validation:**

```solidity
function setAgeMultiplier(uint256 _ageMultiplier) external onlyOwner {
(+)require(_ageMultiplier > 0, "Multiplier must be greater than zero");
   ageMultiplier = _ageMultiplier;
}
```

**Explanation:**
- The updated implementation initializes `ageMultiplier` with a default value of `1` to ensure calculations are correct from the start.
- The setter function includes a validation to prevent setting `ageMultiplier` to `0`, ensuring the integrity of the age-related calculations.
