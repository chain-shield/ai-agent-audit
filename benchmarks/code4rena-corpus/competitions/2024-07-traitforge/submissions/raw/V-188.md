# Vulnerability details

## Impact

Impact: High, likelihood: Low

In multiple functions in the contracts below is missing input validation:
1. contracts/EntityForging/EntityForging.sol
2. contracts/EntityTrading/EntityTrading.sol
3. contracts/EntropyGenerator/EntropyGenerator.sol
4. contracts/NukeFund/NukeFund.sol
5. contracts/TraitForgeNft/TraitForgeNft.sol

The functions in question are mentioned all in the recommended mitigation.

Without those missing input validations, there may occur dire consequences because if, by incorrectly setting an contract address as address(0) or a variable value to 0 could send could result in inaccurate behavior.

Some of them are setters and can only be set by the owner of the contract by still it could happen due to a human error. Those checks are required to ensure the safety of the protocol.

In the recommended mitigation are addressed 30 missing input validations. There are several others but in my opinion they are NOT high severity but rather in low severity, hence they are not included.

## Proof of Concept

As this is input validation. 
1. Deploy contracts
2. Call contracts' functions with invalid input. The functions to call can be seen in the recommended mitigation section and also their github links are attached to this submition. For most of the functions only the owner can call them. For other function, since some of them are internal an another contract has to be created which inherits the contract which contains the function with missing input validation and use that newly deployed contract to call the internal function from its parent.
