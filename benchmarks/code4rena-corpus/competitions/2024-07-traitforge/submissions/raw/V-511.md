# Vulnerability details

## Impact
Inside EntropyGenerator.sol there is a initializeAlphaIndices() function that is only callable by the owner as seen by it onlyOwner modifier. This function is called inside multiple function, the first is the EntropyGenerator.sol constructor (this one succeed upon called because the owner is the deployer of the contract).Then it's also called inside _incrementGeneration() function in TraitforgeNft.sol. The _incrementGeneration() function is an internal function that is called by _mintInternal() and _mintNewEntity(), these 2 internal function are called by mintToken(), mintWithBudget(), and forge().
The problem is after deployment when the first generation of NFT are sold out and it's time for either forge(), mintToken() or mintWithBudget() to be called, those will call either _mintInternal() or _mintNewEntity() that at their turn will call _incrementGeneration() that will call EntropyGenerator.initializeAlphaIndices(). Notice how EntropyGenerator.initializeAlphaIndices() is called by the TraitForgeNft.sol contract and not the owner ? This will effectively DoS the whole protocol preventing any new minting of token because TraitForgeNft.sol is not the owner. The consequence is no activity (minting, forging, nuking etc ...) in the protocol.

## Recommended Mitigation Steps
Instead of using the OnlyOwner modifier use the onlyAllowedCaller modifier for the initializeAlphaIndices() function . Then create another internal function that does the same things and attach the OnlyOwner modifier to it so the owner can call it inside the constructor.
For example:
```solidity
function initializeAlphaIndices() public whenNotPaused onlyAllowedCaller { 
    uint256 hashValue = uint256(
      keccak256(abi.encodePacked(blockhash(block.number - 1), block.timestamp))
    );

    uint256 slotIndexSelection = (hashValue % 258) + 512;
    uint256 numberIndexSelection = hashValue % 13;

    slotIndexSelectionPoint = slotIndexSelection;
    numberIndexSelectionPoint = numberIndexSelection;
  }

function _initializeAlphaIndicesInternal() public whenNotPaused onlyOwner { 
    uint256 hashValue = uint256(
      keccak256(abi.encodePacked(blockhash(block.number - 1), block.timestamp))
    );

    uint256 slotIndexSelection = (hashValue % 258) + 512;
    uint256 numberIndexSelection = hashValue % 13;

    slotIndexSelectionPoint = slotIndexSelection;
    numberIndexSelectionPoint = numberIndexSelection;
  }

```
