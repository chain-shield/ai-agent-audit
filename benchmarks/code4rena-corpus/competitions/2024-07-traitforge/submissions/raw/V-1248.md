# Vulnerability details

## Bug description
Entropies are stored in 770 slots, where each slot contains 13 concatenated entropies.
There exists a special entropy of 999999, which is called the `Golden God` because it's the best entropy in the game. Each generation has 1 such entropy, which is set in the call to `initializeAlphaIndices()`.

[EntropyGenerator.sol#L207-L215](https://github.com/code-423n4/2024-07-traitforge/blob/279b2887e3d38bc219a05d332cbcb0655b2dc644/contracts/EntropyGenerator/EntropyGenerator.sol#L207-L215)
```solidity
uint256 hashValue = uint256(
    keccak256(
        abi.encodePacked(blockhash(block.number - 1), block.timestamp)
    )
);
uint256 slotIndexSelection = (hashValue % 258) + 512;
uint256 numberIndexSelection = hashValue % 13;
slotIndexSelectionPoint = slotIndexSelection;
numberIndexSelectionPoint = numberIndexSelection;
```

 Entropy for an NFT is queued by `currentSlotIndex` which can be in the range of [0, 769], and `currentNumberIndex` which can be in the range of [0,12].

[EntropyGenerator.sol#L103](https://github.com/code-423n4/2024-07-traitforge/blob/279b2887e3d38bc219a05d332cbcb0655b2dc644/contracts/EntropyGenerator/EntropyGenerator.sol#L103)
```solidity
uint256 entropy = getEntropy(currentSlotIndex, currentNumberIndex);
```

If the `currentSlotIndex` and `currentNumberIndex` appear to be values set during the call to initializeAlphaIndices(), that NFT will get the best entropy in the game.

[EntropyGenerator.sol#L170-L175](https://github.com/code-423n4/2024-07-traitforge/blob/279b2887e3d38bc219a05d332cbcb0655b2dc644/contracts/EntropyGenerator/EntropyGenerator.sol#L170-L175)
```solidity
if (
    slotIndex == slotIndexSelectionPoint &&
    numberIndex == numberIndexSelectionPoint
) {
    return 999999;
}
```

The problem is that each generation can have at most 10000 NFTs, but 770 slots represent 10010 entropies. If the `slotIndexSelectionPoint` is the last slot and the `currentNumberIndex` is in the range [3,12] then the `GoldenNFT, will never be minted in that generation.

## Impact
The `Golden God` NFT might never be minted in a generation.

## Recommended Mitigation
When generating `slotIndexSelectionPoint` ensure that it's at most can be 768.
[EntropyGenerator.sol#L211-L215](https://github.com/code-423n4/2024-07-traitforge/blob/279b2887e3d38bc219a05d332cbcb0655b2dc644/contracts/EntropyGenerator/EntropyGenerator.sol#L211-L215)
```diff
- uint256 slotIndexSelection = (hashValue % 258) + 512;
+ uint256 slotIndexSelection = (hashValue % 258) + 511;
  uint256 numberIndexSelection = hashValue % 13;

  slotIndexSelectionPoint = slotIndexSelection;
  numberIndexSelectionPoint = numberIndexSelection;
```
