# Vulnerability details

## Impact
`DevFund::updateDev()` allows the owner of the contract to change the weight-age between the members. The update logic is incorrectly computing the pending rewards amount for the target account using the old weight-age  and not the new weight-age which should be the case.

Due to this incorrect computation, the target account could gain or loss his entitled reward based on the direction of change in weight-age. 

## Proof of Concept
In the below code snippet, refer to the computation of `pendingRewards` for the account. The logic is using `info.weight` instead of `weight` which is the new applicable weight.

```
   function updateDev(address user, uint256 weight) external onlyOwner {
    DevInfo storage info = devInfo[user];
    require(weight > 0, 'Invalid weight');
    require(info.weight > 0, 'Not dev address');
    totalDevWeight = totalDevWeight - info.weight + weight;
==>    info.pendingRewards += (totalRewardDebt - info.rewardDebt) * info.weight;// @audit
    info.rewardDebt = totalRewardDebt;
    info.weight = weight;
    emit UpdateDev(user, weight);
  }
```
Lets demonstrate with an example.

contract level:
- totalDevWeight = 70
- totalRewardDebt = 100

user level:
- info.userWeight = 10
- info.newWeight = 5
- info.rewardDebt = 90

lets say, `owner` wants to adjust `info.userWeight` from 10 to 5.

```
totalDevWeight = totalDevWeight - info.weight + weight;
               = 70 - 10 + 5
               = 65
```

Lets say, there was addition deposit of ether since the pending rewards for the user were updated.

Due to bug in logic, the user will get more rewards as older weight-age is being used.
 
```              
pendingRewards += (totalRewardDebt - info.rewardDebt) * info.weight
               += (100 - 90) * 10
               += 10 * 10
               += 100
```
                                 
But, since the new weight-age was revised to 5, the account is entitled to only `50` instead of `100`.

```
PendingRewards += (totalRewardDebt - info.rewardDebt) * weight
               += (100 - 90) * 5
               += 10 * 5
               += 50 
```

Likewise, the account can loose in case the weight-age was adjusted to higher side, example from 10 to 15.

Due to this incorrect logic, accounts exiting earlier will take away a share that was entitled for other account.

## Recommended Mitigation Steps
Revise the logic to use the new `weightage` in the function.

```
 function updateDev(address user, uint256 weight) external onlyOwner {
    DevInfo storage info = devInfo[user];
    require(weight > 0, 'Invalid weight');
    require(info.weight > 0, 'Not dev address');
    totalDevWeight = totalDevWeight - info.weight + weight;
    info.pendingRewards += (totalRewardDebt - info.rewardDebt) * weight;// @audit
    info.rewardDebt = totalRewardDebt;
    info.weight = weight;
    emit UpdateDev(user, weight);
  }
```
