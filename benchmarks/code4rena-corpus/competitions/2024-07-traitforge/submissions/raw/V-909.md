## Impact
Currently, the writeEntropyBatch1, writeEntropyBatch2, and writeEntropyBatch3 can be called by anyone, as they are missing the `onlyOwner` function modifier.

However, the desired behavior would be that only the owner will be able to call those, as they decide when entropies are registered.

## POC
Random User A is able to call 
```solidity
function writeEntropyBatch1() public {
```
And others, as they don't have the correct function modifier

## Tools Used
Manual Review

## Recommended Mitigation Steps
Add the onlyOwner modifier to the functions writeEntropyBatch1, writeEntropyBatch2 and writeEntropyBatch3.
```diff
-  function writeEntropyBatch1() public {
+  function writeEntropyBatch1() public onlyOwner {  
```
```diff
-  function writeEntropyBatch2() public {
+  function writeEntropyBatch2() public onlyOwner {  
```
```diff
-  function writeEntropyBatch3() public {
+  function writeEntropyBatch3() public onlyOwner {  
```
