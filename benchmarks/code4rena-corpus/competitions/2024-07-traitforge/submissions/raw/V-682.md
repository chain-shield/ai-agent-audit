# Vulnerability details

## Impact
mintWithBudget does not work after the end of Generation 1 minting.

## Proof of Concept
```solidity
  function mintWithBudget(
    bytes32[] calldata proof
  )
    public
    payable
    whenNotPaused
    nonReentrant
    onlyWhitelisted(proof, keccak256(abi.encodePacked(msg.sender)))
  {
    uint256 mintPrice = calculateMintPrice();
    uint256 amountMinted = 0;
    uint256 budgetLeft = msg.value;

>>  while (budgetLeft >= mintPrice && _tokenIds < maxTokensPerGen) { // @audit maxTokensPerGen
      _mintInternal(msg.sender, mintPrice);
      amountMinted++;
      budgetLeft -= mintPrice;
      mintPrice = calculateMintPrice();
    }
    if (budgetLeft > 0) {
      (bool refundSuccess, ) = msg.sender.call{ value: budgetLeft }('');
      require(refundSuccess, 'Refund failed.');
    }
  }
```

mintWithBudget is a function that mint as many NFTs as possible for the ETH provided by the user.

It checks `_tokenIds < maxTokensPerGen` as a condition of the while statement, and maxTokensPerGen is fixed at 10000.

Therefore, after minting the total amount of Gen 1, which is 10000, _tokenIds will be 10000, which does not satisfy the while statement.

This means that after minting Gen 1, no NFTs will be minted even if mintWithBudget is executed.


POC:

```javascript
    it.only('mintWithBudget no mint after Gen 1 POC', async () => {
      while(await nft.balanceOf(owner.address) != 10000)
      {
        await nft.connect(owner).mintToken(merkleInfo.whitelist[0].proof, {
          value: ethers.parseEther('1'),
        });
      }
      let balBefore = await nft.balanceOf(owner.address);
      await nft.connect(owner).mintWithBudget(merkleInfo.whitelist[0].proof, {
        value: ethers.parseEther('1'),
      });
      expect(await nft.balanceOf(owner.address)).to.be.not.eq(balBefore); // Fail
    });
```
