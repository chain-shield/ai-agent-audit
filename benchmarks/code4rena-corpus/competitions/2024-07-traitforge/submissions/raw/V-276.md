# Vulnerability details

## Impact
- Attackers can predict or manipulate the pseudo-random values generated by the contract.
- This can lead to exploitation in applications relying on these values, such as gaming, lotteries, or any system requiring randomness.

## Proof of Concept
1. Deploy the Contract:
```
// Deploy the EntropyGenerator contract
EntropyGenerator entropyGen = new EntropyGenerator(allowedCallerAddress);
```
2. Manipulate Block Variables:
- As a miner, control the block number and timestamp.
- Call `writeEntropyBatch1`, `writeEntropyBatch2`, or `writeEntropyBatch3` to generate entropy.
3. Predict Entropy:
- Use the same block number and index i to predict the pseudo-random values:
```
uint256 predictedValue = uint256(keccak256(abi.encodePacked(block.number, i))) % uint256(10) ** 78;
```
4. Exploit:
- Use the predicted values to gain an unfair advantage in any application relying on these entropy values.
