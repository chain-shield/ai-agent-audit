# Vulnerability details

## Impact

According to the docs, its stated that "The Golden God is scanned for and is kept out of the first 2 passes, but is deliberately set in the final pass ,at some 'random point'. The Golden God should be the most valuable entity."
But the current calculation of the indices of the Golden God entropy (999999) is predictable

## Proof of Concept

https://github.com/code-423n4/2024-07-traitforge/blob/279b2887e3d38bc219a05d332cbcb0655b2dc644/contracts/EntropyGenerator/EntropyGenerator.sol#L206-L216

```Solidity
  function initializeAlphaIndices() public whenNotPaused onlyOwner {
    uint256 hashValue = uint256(
      keccak256(abi.encodePacked(blockhash(block.number - 1), block.timestamp))
    );

    uint256 slotIndexSelection = (hashValue % 258) + 512;
    uint256 numberIndexSelection = hashValue % 13;

    slotIndexSelectionPoint = slotIndexSelection;
    numberIndexSelectionPoint = numberIndexSelection;
  }
```
The blockhash and block.timestamp values are not truly random. They are deterministic based on the blockchain state and can be predicted.
And so the indices for the Golden God entropy, the most valuable entity in the protocol can be predictable by the users.
