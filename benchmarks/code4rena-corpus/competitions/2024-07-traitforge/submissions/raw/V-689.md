# Vulnerability details

## Impact
The function `mintWithBudget` mint tokens while the `_tokenIds` is less than `maxTokensPerGen`. Which is incorrect, since the `_tokenIds` is a global tracker, not a tracker for generation. Incorrect check leads to the fact that in 2+ generations this function will never mint new tokens, but only waste user gas on unnecessary calculations.

## Proof of Concept

- For debugging purposes, you may want to make `TraitForgeNft._tokenIds` visible internally or even publicly.
- `testHigh_deadFunc` is PoC, the rest is setup
