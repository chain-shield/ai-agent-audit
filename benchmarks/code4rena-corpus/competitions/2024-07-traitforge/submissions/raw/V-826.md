# Vulnerability details

## Details
- Forging is a mechanism in which 2 NFTs of `x` generation forges to produce NFTs of `x + 1` generation and so on and so forth.
- Forging doesn't depend on whether current generation is fully minted or not.
- Thus, there will be entities in `y` generation even though current generation is `z`, where (y > z).
- But the `_incrementGeneration` function upon incrementing the currentGeneration, resets the `generationMintCounts` of the incremented generation to 0, but as discussed above there will be entities in the next generations, as a result of this reset more than 10,000 NFTs can be minted per generation.
- Suppose newly incremented generation has `x` entities from forging, therefore when `_incrementGeneration` is called, the entities can be minted = `10000 - x`, but as `generationMintCounts` is reset to 0, therefore `10000` more NFT can be minted allowing `10000 + x` NFTs for that generation.

## Impact
`_incrementGeneration` resetting the `generationMintCounts` to 0, allows the incremented generation to have more than 10,000 entities to be minted.

## Proof of Concept
```
  function _incrementGeneration() private {
    require(
      generationMintCounts[currentGeneration] >= maxTokensPerGen,
      'Generation limit not yet reached'
    );
    currentGeneration++;
@>  generationMintCounts[currentGeneration] = 0;
    priceIncrement = priceIncrement + priceIncrementByGen;
    entropyGenerator.initializeAlphaIndices();
    emit GenerationIncremented(currentGeneration);
  }
```
- Here, the generationMintCounts for the incremented generation is reset to 0.
- But as there will be some forged entities existing for that incremented generation, resetting it to 0 will allow `10000 + x` entities to be minted, where `x` is the forged NFTs minted before reset.

## Recommended Mitigation Steps
Do not reset the generationMintCounts in `_incrementGeneration`.
```diff
  function _incrementGeneration() private {
    require(
      generationMintCounts[currentGeneration] >= maxTokensPerGen,
      'Generation limit not yet reached'
    );
    currentGeneration++;
-   generationMintCounts[currentGeneration] = 0;
    priceIncrement = priceIncrement + priceIncrementByGen;
    entropyGenerator.initializeAlphaIndices();
    emit GenerationIncremented(currentGeneration);
  }
```
