# Vulnerability details

##  Description
The calculateAge function within the NukeFund contract employs integer division, which can lead to notable precision loss, particularly for newer tokens or those with lower performance factors. This imprecision can result in erroneous age calculations, potentially affecting the nuke factor and claim amounts.


## Impact
1.Newer tokens or tokens with lower performance factors may be significantly undervalued.
2.The nuke factor calculation, which relies on the age, will be inaccurate for these tokens.
3. This could lead to an unfair distribution of funds during token nuking, possibly causing some users to claim less than they are entitled to.

## Proof of Concept
```
function calculateAge(uint256 tokenId) public view returns (uint256) {
    require(nftContract.ownerOf(tokenId) != address(0), 'Token does not exist');

    uint256 daysOld = (block.timestamp -
      nftContract.getTokenCreationTimestamp(tokenId)) /
      60 /
      60 /
      24;
    uint256 performanceFactor = nftContract.getTokenEntropy(tokenId) % 10;

    uint256 age = (daysOld *
      performanceFactor *
      MAX_DENOMINATOR *
      ageMultiplier) / 365; // add 5 digits for decimals
    return age;
}
```

Example scenario:

1. Token is 1 day old: daysOld = 1
2. Token has a performanceFactor of 1
3. MAX_DENOMINATOR = 100000
4. ageMultiplier = 1

The calculation results in:
```
age = (1 * 1 * 100000 * 1) / 365 = 273
```
This small age value could significantly undervalue newer tokens.

## Recommended Mitigation Steps
1. Enhance precision for intermediate calculations:

  * Multiply by a large factor (e.g., 1e18) before division to maintain precision.
  * Store age as a fixed-point number with more decimal places.

2. Modify the age calculation to better accommodate newer tokens:
```
function calculateAge(uint256 tokenId) public view returns (uint256) {
    require(nftContract.ownerOf(tokenId) != address(0), 'Token does not exist');

    uint256 secondsOld = block.timestamp - nftContract.getTokenCreationTimestamp(tokenId);
    uint256 performanceFactor = nftContract.getTokenEntropy(tokenId) % 10;

    // Use higher precision and avoid integer division until the end
    uint256 age = (secondsOld * performanceFactor * MAX_DENOMINATOR * ageMultiplier * 1e18) / (365 days);
    return age;
}
```

3. Consider utilizing a library such as ABDKMath64x64 for high-precision calculations.
