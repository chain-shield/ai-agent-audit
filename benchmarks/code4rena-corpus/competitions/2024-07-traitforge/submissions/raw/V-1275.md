# Vulnerability details

## Vulnerability Details
The method `EntropyGenerator::deriveTokenParameters` returns calculated parameters including `nukeFactor`. The docs specified that the nuke factor is calculated by dividing the entropy (a six digit number) by 40: `Entropy /40 = initalNukeFactor`. However, the method `deriveTokenParameters` makes the following calculation: `nukeFactor = entropy / 4000000;`. As a result the nuke factor will always be zero.

## Impact
The method `EntropyGenerator::deriveTokenParameters` returns always zero for the nuke factor. This can confuse the user.

## Proof of Concept

```javascript
it('Nuke factor is always zero', async function () {
  const slotIndex = 2;
  const numberIndex = 3;
```
