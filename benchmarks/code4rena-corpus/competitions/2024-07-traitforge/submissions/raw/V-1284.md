# Vulnerability details

## Impact

`EntityForging.forgeWithListed` checks that the merger has provided more or the same quantity as the price.

the Mergers excess funds will be stuck in the contract forever with no way to get them back.

unlike `EntityTrading`, this contract does not provide any means of control to ensure that the amount transferred by the user is equivalent to price and does not provide any ways to return excess funds like mint functions in `TraitForgeNft`

## Proof of Concept

- Onnly `testMedium_userRefund` is PoC the rest is default setup

        airdrop.setTraitToken(address(token));
        airdrop.transferOwnership(address(nft));
        nft.setNukeFundContract(payable(address(nukeFund)));

        entityTrading.setNukeFundAddress(payable(address(nukeFund)));
        entityForging.setNukeFundAddress(payable(address(nukeFund)));

        entropyGenerator.writeEntropyBatch1();

        entropyGenerator.writeEntropyBatch3();
        vm.stopPrank();

    function testMedium_userRefund() public {
        _initVars();
        _noWhitelist();

        uint256 _forgerId = _mintForger(USER2); // @note from prev. tests i know that this have zero forging potential, so mint again
        _forgerId = _mintForger(USER2);
        uint256 _mergerId = _mintMerger(USER1);

        vm.startPrank(USER2);
        entityForging.listForForging(_forgerId, 1 ether);

        vm.startPrank(USER1);
        deal(USER1, 10 ether);
        console2.log("USER1 Balance before: ", USER1.balance, ", contract balance: ", address(entityForging).balance);

    }

    function _mintForger(address _user) internal returns (uint256) {
        uint256 _forgerId;
        do {
            _forgerId = _mintToken(_user);
        } while (!nft.isForger(_forgerId));
        return _forgerId;
    }

    function _mintMerger(address _user) internal returns (uint256) {
        uint256 _mergerId;
        do {
            _mergerId = _mintToken(_user);
        } while (nft.isForger(_mergerId));
        return _mergerId;
    }

    function _mintToken(address _user) internal returns (uint256) {
        trackId++;

        uint256 _mintPrice = nft.calculateMintPrice();
        deal(_user, _mintPrice);
        vm.startPrank(_user);
        nft.mintToken{value: _mintPrice}(new bytes32[](0));
        vm.stopPrank();

        return trackId;
    }

    function _noWhitelist() internal {
        vm.warp(nft.whitelistEndTime() + 1);
    }
}
