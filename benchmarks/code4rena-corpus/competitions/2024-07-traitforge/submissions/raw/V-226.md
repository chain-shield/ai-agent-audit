# Vulnerability details

## Impact
Protocol intends to pause some function by inheriting openzepplin pausable, the issue is that the protocol does not have an external handle to call `_pause` and `_unpause` therefore function marked `whenNotPaused` cannot be paused.
This issue is also found in all contract in-scope

## Proof of Concept
Can be seen that there's no way to call `_pause` and `unpause` from the current implementation.

## Tools Used
Manual Review

## Recommended Mitigation Steps
Implement an external function to call `_pause()` and `_unpause()` from openzepplin pausable library
