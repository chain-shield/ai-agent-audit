# Vulnerability details

### Impact

Contracts cannot be paused/unpaused in case of an emergency.

### Proof of Concept

1. Context

For safety reasons, the protocol inherits OpenZeppelin Pausable.sol, while also implementing the `whenNotPaused` modifier on major functions in multiple contracts. However there are no `pause` functions in these contracts to modify the no `_paused` state If a security event occurs, and as such, the contracts cannot be paused at all.

2. Bug Location

The contracts in scope all inherit OpenZeppelin's Pausable.sol and all have this issue, but for brevity we'll consider TraitForgeNft.sol.
As can be seen from it's implementation, it's meant to be pausable.

```solidity
// SPDX-License-Identifier: MIT
pragma solidity ^0.8.20;

//...
import '@openzeppelin/contracts/security/Pausable.sol';
//...

contract TraitForgeNft is
  ITraitForgeNft,
  ERC721Enumerable,
  ReentrancyGuard,
  Ownable,
  Pausable
{
```

This is further cemented by various functons, which are all marked with the `whenNotPaused` modifier.

```solidity
  function startAirdrop(uint256 amount) external whenNotPaused onlyOwner {
    airdropContract.startAirdrop(amount);
  }
```

```solidity
  function burn(uint256 tokenId) external whenNotPaused nonReentrant {
//...
    _burn(tokenId);
  }
```

```solidity
  function forge(
    address newOwner,
    uint256 parent1Id,
    uint256 parent2Id,
    string memory
  ) external whenNotPaused nonReentrant returns (uint256) {
//...
    return newTokenId;
  }
```

```solidity

  function mintToken(
    bytes32[] calldata proof
  )
    public
    payable
    whenNotPaused
    nonReentrant
    onlyWhitelisted(proof, keccak256(abi.encodePacked(msg.sender)))
  {
//...
  }
```

```solidity
  function mintWithBudget(
    bytes32[] calldata proof
  )
    public
    payable
    whenNotPaused
    nonReentrant
    onlyWhitelisted(proof, keccak256(abi.encodePacked(msg.sender)))
  {
//...
  }

```

The modifier checks and ensures that the contract is not paused before continuing the execution.

```solidity
    modifier whenNotPaused() {
        _requireNotPaused();
        _;
    }
```

3. Final effect

Now during an emergency situation, the owner might decide to pause the contract temporarily. For instance to prevent minting of the Trait NFT and protect from potential loss of funds. But the function to put this into effect is non-existent, not just in TraitForgeNFT.sol, but in all the in-scope contract. The search [functionality](<https://github.com/search?q=repo%3Acode-423n4%2F2024-07-traitforge%20%22function%20pause(%22&type=code>) proves just that.


<img width="1484" alt="SearchResult" src="https://gist.github.com/user-attachments/assets/589ed6e4-7e45-4b3d-a27f-dd8497f23d3c">


And in OpenZeppelin's Pausable.sol, we find that the [functions to pause and unpause ](https://github.com/OpenZeppelin/openzeppelin-contracts/blob/54b3f14346da01ba0d159114b399197fea8b7cda/contracts/security/Pausable.sol#L89C1-L104C6)are both internal, not external/public and as such cannot be directly called.

```solidity
    function _pause() internal virtual whenNotPaused {
        _paused = true;
        emit Paused(_msgSender());
    }
```
```solidity
    function _unpause() internal virtual whenPaused {
        _paused = false;
        emit Unpaused(_msgSender());
    }
```
### Tools Used
Manual code review

### Recommended Mitigation Steps

Expose the `pause` and `unpause` functions and protect them with an `onlyOwner` modifier.
