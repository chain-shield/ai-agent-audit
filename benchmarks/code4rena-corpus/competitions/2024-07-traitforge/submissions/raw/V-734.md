# Vulnerability details

## Impact
The [EntityForging contract](https://github.com/code-423n4/2024-07-traitforge/blob/main/contracts/EntityForging/EntityForging.sol#L40) allows the owner to modify critical parameters, such as oneYearInDays, taxCut, and minimumListFee, after deployment. Although the setter functions in the contract is regulated by the onlyOwner modifier, which implies a level of trust in the owner, the ability to change these parameters can lead to significant disruptions if not properly managed.

The primary concern is the setOneYearInDays function, which allows the owner to reset the annual reset period for forging counts. If set to an unreasonably low value, this can lead to frequent resets, causing tokens to reset their forging counts too often and disrupting the intended functionality of the contract.

## Proof of Concept

While the onlyOwner modifier in the associated function provides a layer of trust, the potential for human error or malicious actions cannot be ignored. Implementing reasonable bounds will enhance the security and reliability of the contract, ensuring it operates as intended without unexpected disruptions. This approach aligns with best practices in smart contract development, promoting trustless systems and minimizing risks.

```solidity
  uint256 public oneYearInDays = 365 days;

  function setOneYearInDays(uint256 value) external onlyOwner {
    oneYearInDays = value;
  }
```

- The setOneYearInDays function allows the owner to set the duration for one year in days.
- This parameter is critical for managing the forging counts reset logic.
- The owner sets oneYearInDays to an unreasonably low value (e.g., 10 days).
- Tokens' forging counts reset too frequently, allowing potentially unlimited forging or disrupting the expected forging cycle.

## Tools Used

Manual Review

## Recommended Mitigation Steps

Implement upper/lower or a fixed range of [365,366] days bounds for oneYearInDays to ensure it stays within a reasonable range. This minimizes the risk of setting the parameter to an unintended value.
