# Vulnerability details

## Impact
Missing functions for pausing and unpausing contract operations.

## Proof of Concept
The contracts include the OZ pausable feature to pause or resume certain functions with `whenNotPaused` modifier. However, they are missing public privileged functions that allow authorized users to call `_pause()` and `_unpause()` to enable this OZ pausable feature.

## Tools Usedf
vscode

## Recommended Mitigation Steps
Add public privileged functions that allow authorized users to call `_pause()` and `_unpause()`.

DoS
