# Vulnerability details

**Description**

The `onlyOwner` modifier of the [EntropyGenerator::initializeAlphaIndices](https://github.com/code-423n4/2024-07-traitforge/blob/279b2887e3d38bc219a05d332cbcb0655b2dc644/contracts/EntropyGenerator/EntropyGenerator.sol#L206) function ensures that only the deployer of the contract can call it. However, this function is only called from [TraitForgeNft::_incrementGeneration()](https://github.com/code-423n4/2024-07-traitforge/blob/279b2887e3d38bc219a05d332cbcb0655b2dc644/contracts/TraitForgeNft/TraitForgeNft.sol#L345), meaning that `TraitForgeNft` must be the owner. Additionally, there is another modifier, [onlyAllowedCaller](https://github.com/code-423n4/2024-07-traitforge/blob/279b2887e3d38bc219a05d332cbcb0655b2dc644/contracts/EntropyGenerator/EntropyGenerator.sol#L25), which uses the [EntropyGenerator::allowedAddress](https://github.com/code-423n4/2024-07-traitforge/blob/279b2887e3d38bc219a05d332cbcb0655b2dc644/contracts/EntropyGenerator/EntropyGenerator.sol#L22C19-L22C32) state variable, which is set to the address of the `TraitForgeNft` contract on creation of the contract.

**Impact**

If `TraitForgeNft` does not own the `EntropyGenerator`, calling [TraitForgeNft::_incrementGeneration()](https://github.com/code-423n4/2024-07-traitforge/blob/279b2887e3d38bc219a05d332cbcb0655b2dc644/contracts/TraitForgeNft/TraitForgeNft.sol#L345) will revert, causing a denial of service (DoS) for minting new NFTs.

**Proof of Concepts**

```javascript
it('should revert on generation increase', async () => {
  // Setup new EntropyGenerator
  const EntropyGenerator = await ethers.getContractFactory(
    'EntropyGenerator'
  );
  const entropyGenerator = (await EntropyGenerator.deploy(
    await nft.getAddress()
  )) as EntropyGenerator;

  await entropyGenerator.writeEntropyBatch1();

  await entropyGenerator.transferOwnership(owner);

  await nft.setEntropyGenerator(await entropyGenerator.getAddress());

  const maxTokensPerGen = 10;

  let currentGen = await nft.currentGeneration();

  // Set max tokens per generation for simplicity
  await nft.setMaxTokensPerGen(maxTokensPerGen);

  // Mint all possible NFTs
  for (let i = 0; i < 9; i++) {
    await nft.connect(owner).mintToken(merkleInfo.whitelist[0].proof, {
      value: ethers.parseEther('1'),
    });
  }

  currentGen = await nft.currentGeneration();

  // Mint one more NFT
  await expect(nft.connect(owner).mintToken(merkleInfo.whitelist[0].proof, {
    value: ethers.parseEther('1'),
  })).to.be.revertedWith("Ownable: caller is not the owner");
});
```
**Recommended mitigation**

Create an internal/private function `_initializeAlphaIndices`, which will be called from the `constructor` and the public `initializeAlphaIndices()`.

```diff
constructor(address _traitForgetNft) {
    allowedCaller = _traitForgetNft;
-    initializeAlphaIndices();
+    _initializeAlphaIndices();
}

-     uint256 numberIndexSelection = hashValue % 13;
```
