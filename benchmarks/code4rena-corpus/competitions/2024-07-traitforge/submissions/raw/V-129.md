# Vulnerability details

## Impact
Contract EntityTrading.sol is not using `safeTransfer` and is not implementing ERC721Receiver. Whenever user will try to list his NFT with `EntityTrading::listNFTForSale` it will end up stuck and impossible to retrieve it back.
Additionaly `EntityTrading::buyNFT` also does not use `safeTransfer`. The buyer can end up with stuck NFT

## Recommended Mitigation Steps
Implement `IERC721Receiver` in `EntityTrading.sol`
1. Import library
```diff
+import {IERC721Receiver} from "@openzeppelin/contracts/token/ERC721/IERC721Receiver.sol";
```
2. Add interface
```diff
-contract EntityTrading is IEntityTrading, ReentrancyGuard, Ownable, Pausable {
+contract EntityTrading is IEntityTrading, ReentrancyGuard, Ownable, Pausable, IERC721Receiver {
```
3. Add interface function `onERC721Received`
```diff
+  function onERC721Received(
+      address operator,
+      address from,
+      uint256 tokenId,
+      bytes calldata data
+  ) external override returns (bytes4) {
+      return IERC721Receiver.onERC721Received.selector;
+  }
```
4. Use `safeTransferFrom` instead of `transferFrom` whenever possible
