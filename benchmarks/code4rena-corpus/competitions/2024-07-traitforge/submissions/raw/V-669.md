# Vulnerability details

## Summary
The `DevFund.sol`, `EntityForging.sol`, `EntityTrading.sol`, `EntropyGenerator.sol `, `NukeFund.sol`, `TraitForgeNft.sol` contracts inherits the Pausable contract and implements the whenNotPaused modifier on the its functions, but it lacks the necessary functions to pause and unpause the contract, rendering the pause mechanism ineffective.

## Vulnerability Details
Missing Pause/Unpause Functions: The `DevFund.sol`, `EntityForging.sol`, `EntityTrading.sol`, `EntropyGenerator.sol `, `NukeFund.sol`, `TraitForgeNft.sol`  contracts includes the Pausable functionality but does not implement any methods to actually pause or unpause the contract. The Pausable.sol contract only provides internal functions for pausing and unpausing, requiring the implementation of external or public functions to utilize them.


## Impact

Without the ability to pause or unpause the contract, functions can be called even if the functions should be paused, potentially leading to exploitation of vulnerabilities. and the protocol cannot effectively manage or mitigate potential vulnerabilities or issues. it remains exploitable even if the contract is intended to be paused.

functions like burn and mint would dos the protocol.

## Tools Used
Manual code review

Recommendations
Implement Pause/Unpause Functions: Create simple external functions for pausing and unpausing the contract that can be called by the owner.

```
function pause() external onlyOwner {
    _pause();
}

function unpause() external onlyOwner {
    _unpause();
}
```
