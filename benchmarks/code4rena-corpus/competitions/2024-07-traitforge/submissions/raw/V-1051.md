# Vulnerability details

## Impact
Impact: High, as the inability to increase the current generation count prevents the protocol from functioning correctly.

Likelihood: High, since in all probability the current genration count must be increased

## Description
The protocol allows the minting of entities, with a total of 10 generations, each having a capacity of 10,000 entities. Generations start from 1 and can only be increased when the current generation reaches its maximum capacity of 10,000 entities. Once this limit is reached, the next minted entity should trigger an increase in the generation and should be minted in the new generation.

The `mintToken` function calls `_mintInternal`, which in turn calls `_incrementGeneration()`. This function is responsible for handling the generation increment and initializing certain parameters for the "Golden God" entity through the `initializeAlphaIndices()` function in `EntropyGenerator.sol`.


And here is the problem.

The issue arises because the `initializeAlphaIndices()` function in EntropyGenerator.sol can only be called by the contract owner due to the onlyOwner modifier. This makes it impossible to increase the generation and mint a new entity, disrupting the normal workflow of the protocol, since `EntrophyGenerator.sol` contract is not created by `TraitForgeNft.sol` contract, therefore the owner of `EntrophyGenerator.sol` is not `TraitForgeNft.sol`.

    ```solidity
    contract MerkleTree {
        bytes32[] public hashes;

        constructor() {
        }

        function generateMerkleTree(address[] memory addresses) public returns (bytes32[] memory) {
            
            for (uint256 i = 0; i < addresses.length; i++) {
                hashes.push(keccak256(abi.encodePacked(addresses[i])));
            }

            uint256 n = addresses.length;
            uint256 offset = 0;

            while (n > 0) {
                for (uint256 i = 0; i < n - 1; i += 2) {
                    hashes.push(
                        keccak256(
                            abi.encodePacked(
                                hashes[offset + i], hashes[offset + i + 1]
                            )
                        )
                    );
                }
                offset += n;
                n = n / 2;
            }
            return hashes;
        }
        function getRoot() public view returns (bytes32) {
            return hashes[hashes.length - 1];
        }
    ```

Test Scenario

1 - Set maxTokensPerGen to 10 (for testing purposes).

2 - User1 mints 10 entities.

3 - When User1 tries to mint 1 more entity, the initializeAlphaIndices() function will revert with " Ownable: caller is not the owner" because it has the 'onlyOwner' modifier.

## Recommended Mitigation Steps
You need to transfer ownership of `EntrophyGenerator.sol` to `TraitForgeNft.sol` contract in constructor.

```solidity
 constructor(address _traitForgetNft) {
    allowedCaller = _traitForgetNft;
    initializeAlphaIndices();
+   transferOwnership(_traitForgetNft);
  }
  ```
