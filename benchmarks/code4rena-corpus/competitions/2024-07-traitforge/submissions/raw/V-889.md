# Vulnerability details

## Impact
In 'TraitForgeNft::mintWithBudget' user can mint one or multiples NFT's in the same transactions paying any amount of money. 
The problem is that after 10.000 have been minted, this function will not be more usable in order to mint new NFT's. This happens because the variable '_tokenIds' becomes higher than 'maxTokenPerGen'. 
Users will always be able to call this function (and they will not lose money since the budgetLeft is always got back) but they will not be able to mint NFT's using this function. 

## Proof of Concept
(Foundry)
```javascript
function test_vulnerability_mintWithBudget_DoesNotWorkAboveGen2() public {
vm.startPrank(owner); 
//Here the owner sets all the contracts, transfes ownership, and write batch1.
traitForgeNft.setAirdropContract(address(airdropContract));
traitForgeNft.setEntityForgingContract(address(entityForging));
traitForgeNft.setEntropyGenerator(address(entropyGenerator));
address nukeFundAddress = address(142735484); 
traitForgeNft.setNukeFundContract(payable(nukeFundAddress));
airdropContract.transferOwnership(address(traitForgeNft));
entropyGenerator.writeEntropyBatch1();
vm.stopPrank(); 

address user1 = address(123); 
//Assigning 10000 ether to the user1
deal(user1, 10000 ether); 
vm.startPrank(user1); 
skip(2 days);
bytes32[] memory proof = new bytes32[](1); 
proof[0] = keccak256(abi.encode("Hi")); 

//Here the user mint 10.000 nfts (in the first gen) and he has effectively 10.000 nfts
uint256 initialMintPrice = traitForgeNft.startPrice(); 
for(uint256 i = 0; i < 10000; i++){
traitForgeNft.mintWithBudget{value: initialMintPrice}(proof);
initialMintPrice += traitForgeNft.priceIncrement(); 
}
assertEq(traitForgeNft.balanceOf(address(user1)), 10000); 

//Here the user mints others 100 nfts (in the second gen) but he has again only 10.000 nfts and not 10.100 nfts
uint256 initialMintPrice2 = traitForgeNft.startPrice(); 
for(uint256 i = 0; i < 100; i++){
traitForgeNft.mintWithBudget{value: initialMintPrice2}(proof);
initialMintPrice += traitForgeNft.priceIncrement(); 
}

assertEq(traitForgeNft.balanceOf(address(user1)), 10000); 
}
```

## Recommended Mitigation Steps
Add a different logic in order to know if the maximum number of tokenId per gen is reached. 
Instead of doing this: 
```javascript
 while (budgetLeft >= mintPrice && _tokenIds < maxTokensPerGen) {
      _mintInternal(msg.sender, mintPrice);
      amountMinted++;
      budgetLeft -= mintPrice;
      mintPrice = calculateMintPrice();
    }
```

Consider doing this: 
```javascript
 while (budgetLeft >= mintPrice && generationMintCounts[currentGeneration] < maxTokensPerGen) {
      _mintInternal(msg.sender, mintPrice);
      amountMinted++;
      budgetLeft -= mintPrice;
      mintPrice = calculateMintPrice();
    }
``
