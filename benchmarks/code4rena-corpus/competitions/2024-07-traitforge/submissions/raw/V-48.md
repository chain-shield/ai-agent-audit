# Vulnerability details

## Impact
In TraitForgeNft, NukeFund, EntityTrading contract, we have one pause function. This function aims to pause the key functions to protect the funds if one vulnerability is found or some emergency scenarios. Currently, the pause function is not implemented and all functions cannot be pause. The emergency protection does not work.

## Proof of Concept
Take TraitForgeNft as one example, we inherit `Pausable` from openzepplin library, but openzepplin library only provide the internal version `_pause()`. If we want to support pause function, we should to add one external/public function to support pause function.
```javascript
contract TraitForgeNft is
  ITraitForgeNft,
  ERC721Enumerable,
  ReentrancyGuard,
  Ownable,
  Pausable
{
}
```
```javascript
    function _pause() internal virtual whenNotPaused {
        _paused = true;
        emit Paused(_msgSender());
    }
```

## Tools Used
Manual

## Recommended Mitigation Steps
Add external/public pause()/unpause() function.
