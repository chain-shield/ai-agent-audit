# Vulnerability details

## Description
The receive() function in the NukeFund contract performs integer division to determine the developer's share of incoming funds. This method can introduce rounding inaccuracies, leading to minor discrepancies in fund allocation. Over time, these discrepancies can accumulate, resulting in a noticeable difference between the expected and actual fund distribution.

## Impact
1.The developer might receive slightly less than the intended share for most transactions.
2.Accumulated rounding errors could lead to a significant discrepancy between expected and actual fund distribution over time.
3.In instances where msg.value < taxCut, the developer may not receive any funds, which contradicts the intended design.

## Proof of Concept

```
receive() external payable {
    uint256 devShare = msg.value / taxCut; // Calculate developer's share (10%)
    uint256 remainingFund = msg.value - devShare; // Calculate remaining funds to add to the fund

    fund += remainingFund; // Update the fund balance

    // ... (rest of the function)
}
```
Example:

* Given `taxCut = 10` (representing 10%)
* With `msg.value = 101 wei`

The calculations would be:

* `devShare = 101 / 10 = 10 wei`
* `remainingFund = 101 - 10 = 91 wei`
Here, the developer receives 9.9% instead of 10%, and the fund receives 90.1% instead of the intended 90%.

## Recommended Mitigation Steps
1. Adopt Percentage-Based Calculations:
```
receive() external payable {
    uint256 devShare = (msg.value * taxCut) / 100; // Calculate developer's share (taxCut%)
    uint256 remainingFund = msg.value - devShare; // Calculate remaining funds to add to the fund

    fund += remainingFund; // Update the fund balance

    // ... (rest of the function)
}
```
2. Utilize Fixed-Point Arithmetic Libraries:
```
import "@openzeppelin/contracts/utils/math/SafeMath.sol";

contract NukeFund is INukeFund, ReentrancyGuard, Ownable, Pausable {
    using SafeMath for uint256;

    // ... (rest of the contract)

    receive() external payable {
        uint256 devShare = msg.value.mul(taxCut).div(100); // Calculate developer's share (taxCut%)
        uint256 remainingFund = msg.value.sub(devShare); // Calculate remaining funds to add to the fund

        fund = fund.add(remainingFund); // Update the fund balance

        // ... (rest of the function)
    }
}
```
3. Set a Minimum Transaction Value:
```receive() external payable {
    require(msg.value >= taxCut, "Transaction value too low");
    // ... (rest of the function)
}
```
4. Accumulate and Distribute Small Remainders:
```
uint256 public devShareRemainder;

receive() external payable {
    uint256 devShare = (msg.value * taxCut) / 100;
    devShareRemainder += (msg.value * taxCut) % 100;
    
    if (devShareRemainder >= 100) {
        devShare += devShareRemainder / 100;
        devShareRemainder = devShareRemainder % 100;
    }

    uint256 remainingFund = msg.value - devShare;
    fund += remainingFund;

    // ... (rest of the function)
}
```
