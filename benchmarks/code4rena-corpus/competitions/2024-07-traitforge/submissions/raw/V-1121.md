# Vulnerability details

## Impact
The value of `isForger` should not have a default value of `true` because that would incorrectly indicate that a token is a `forger` regardless of the actual entropy value. 
## Proof of Concept

```solidity
import {
  TraitForgeNft,
} from '../typechain-types';
import { HardhatEthersSigner } from '@nomicfoundation/hardhat-ethers/signers';

const { expect } = require('chai');
const { ethers } = require('hardhat');

describe('TraitForgeNFT : Check If token Id is a  Forger', () => {
  let nft: TraitForgeNft;
  let owner: HardhatEthersSigner;

  before(async () => {
    [owner] = await ethers.getSigners();

    // Deploy TraitForgeNft contract
    const TraitForgeNft = await ethers.getContractFactory('TraitForgeNft');
    nft = (await TraitForgeNft.deploy()) as TraitForgeNft;


  });

  describe('', () => {

    it('is forger ?', async () => {
    // returns true instead of false for any given token Id
        nft.connect(owner).isForger(2000)
        console.log(":",await nft.connect(owner).isForger(2))
      });
  });
});

```
As you can see the default value is set to true for any given tokenId.

run command :
```console
npx hardhat test --grep 'is forger ?'
```

Manual Review

Ensure the default value for   `isForger` is set to false
