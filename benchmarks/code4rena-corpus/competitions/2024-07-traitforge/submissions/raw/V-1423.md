# Vulnerability details

## Impact
MintPrice is wrongly calculated for the token when that minting leads to an `incrementGeneration`. As a result the mint price of  the first token of any generation except the first genration is calculated incorrect and lead to an excess price contradicting the document.

## Proof of Concept


In the function `mintToken()` we are calculating the mintPrice prior the `_mintInternal(msg.sender, mintPrice);` to pass the mintPrice as the parameter.

   https://github.com/code-423n4/2024-07-traitforge/blob/279b2887e3d38bc219a05d332cbcb0655b2dc644/contracts/TraitForgeNft/TraitForgeNft.sol#L181-L200

```solidity
    function mintToken(
    bytes32[] calldata proof
  )
    ....
  {
    uint256 mintPrice = calculateMintPrice();
    require(msg.value >= mintPrice, 'Insufficient ETH send for minting.');


    _mintInternal(msg.sender, mintPrice);


    uint256 excessPayment = msg.value - mintPrice;
    if (excessPayment > 0) {
      (bool refundSuccess, ) = msg.sender.call{ value: excessPayment }('');
      require(refundSuccess, 'Refund of excess payment failed.');
    }
  }

```

So , Noting from the document
https://docs.google.com/document/d/1pihtkKyyxobFWdaNU4YfAy56Q7WIMbFJjSHUAfRm6BA/edit?pli=1
>"Generation 2 starts at 0.005 ETH and ends at 0.3 ETH. Generation 3 starts at 0.005 ETH and ends at 0.35 ETH, and so on."

It says that genration 2 should start from 0.005 which is the `startPrice` for all generations and increment by  (0.0000245+ 0.000005)=0.0000295 and by the end of the generation it reaches (0.005 + 10000*0.0000295 )= 0.3. And the first token in the generation 3 should start from 0.005 (`startPrice`) again.

But the mintprice of the  first token  in the Gen 3 is calculated prior to the `incrementGeneration()` call. Which results in the wrong value of priceIncrement.(priceIncrements value is still of the gen 2)

and the secondtken of gen 3's mintprice is (0.005 + 1*0.000054)=0.005054 which is  less than the first token(0.3).

It also contradicts the document where it says Gen 3 starts from 0.005.
