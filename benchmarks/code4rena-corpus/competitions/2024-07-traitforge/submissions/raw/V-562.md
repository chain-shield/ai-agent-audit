# Vulnerability details

## Impact

In the current implementation of `EntityForging`, the contract inherits OZ  `Pausable` functionality but does not initialize `pause()` and `unpause()` externally as they are internal functions.

## Proof of Concept

OZ implementation:

https://github.com/OpenZeppelin/openzeppelin-contracts/blob/master/contracts/utils/Pausable.sol#L103-106
```
  function _pause() internal virtual whenNotPaused {
        _paused = true;
        emit Paused(_msgSender());
    }
```

https://github.com/OpenZeppelin/openzeppelin-contracts/blob/master/contracts/utils/Pausable.sol#L115-118
```
function _unpause() internal virtual whenPaused {
        _paused = false;
        emit Unpaused(_msgSender());
    }
```

The contract `EntityForging` only implements `whenNotPaused` modifier:

https://github.com/code-423n4/2024-07-traitforge/blob/main/contracts/EntityForging/EntityForging.sol#L70

But it cannot be practically used as there are no functions that would pause and unpause the contract.

## Tools Used

Manual review.

## Recommended Mitigation Steps

Implement external `pause()` and `unpause()`.
