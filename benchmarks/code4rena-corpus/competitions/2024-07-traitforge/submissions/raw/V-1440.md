# Vulnerability details

## Impact
In the TraitForgeNft contract, there is a variable maxGeneration set to 10, which is intended to limit the number of generations. However, there are no checks in place during the minting process to enforce this limit. This can result in users being able to mint tokens beyond the intended maximum generation.

## Proof of Concept
1. Users continuously mint new tokens.
2. The _incrementGeneration() function is called without a check for the maximum generation limit.
3. New generations are created indefinitely, bypassing the intended limit of 10 generations.

## Tools Used
Manual Code Review

## Recommended Mitigation Steps
To address this issue, implement a check within the _incrementGeneration() function and the minting functions to enforce the maximum generation limit. If the current generation exceeds this limit, further minting should be halted.
```js
function _incrementGeneration() private {
    require(
        currentGeneration < maxGeneration,
        "Maximum generation limit reached"
    );
    require(
        generationMintCounts[currentGeneration] >= maxTokensPerGen,
        'Generation limit not yet reached'
    );
    currentGeneration++;
    generationMintCounts[currentGeneration] = 0;
    priceIncrement = priceIncrement + priceIncrementByGen;
    entropyGenerator.initializeAlphaIndices();
    emit GenerationIncremented(currentGeneration);
}
```
