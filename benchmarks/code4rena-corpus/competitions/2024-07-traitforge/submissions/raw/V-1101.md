# Vulnerability details

## Impact
When the maxTokensPerGen limit is reached and a user calls, for example, mintToken, the function reverts back, as mintToken calls _incrementGeneration which calls initializeAlphaIndices, but initializeAlphaIndices can only be called by the owner of the EntropyGenerator contract. Currently, for currentGeneration to increment, the EntropyGenerator owner must call mintToken.
mint functions become unusable for users as soon as generationMintCounts[currentGeneration] >= maxTokensPerGen
