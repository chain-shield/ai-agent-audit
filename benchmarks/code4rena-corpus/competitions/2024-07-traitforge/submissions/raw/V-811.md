# Vulnerability details

## Impact
All the contracts that has function with WhenNotPaused modifier will not have the posibility to pause, making the protocol unable to pause the system if needed.

## Proof of Concept
All the contracts that inherit from the openzeppelin `Pausable` contract which contain internal functions `_pause` and `_unpause`

Because those functions are internal, the contract must implement two other public/external pause and unpause functions to allow the manager to pause and unpause the contracts when necessary. None of the contracts in the protocol implement those functions, which means even if those contracts are supposed to be pausable (and have the pause/unpause functionalities), none of them can be paused.

## Tools Used

## Recommended Mitigation Steps
Add pause/unpause function with onlyOwner modifier like this:
``` solidity
/**
 * @dev Triggers stopped state.
 * Contract must not be paused
 */
function pause() external onlyOwner {
    _pause();
}

function unpause() external onlyOwner {
    _unpause();
}
```
