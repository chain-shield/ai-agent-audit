# Vulnerability details

## Impact
Resetting count of mints per generation, leading to minting of more NFTs in future generation than the set limit.

## Proof of Concept
Every mint in `TraitForgeNft.sol` increases the counter variable of `  mapping(uint256 => uint256) public generationMintCounts;` which keeps track of mints per generation. This allows the contract to increase the generation when it reaches `maxTokensPerGen`. Now, as NFTs are forged, future generation NFTs are minted and added to the count before they are available for direct sale.

```solidity
  function forge(
    address newOwner,
    uint256 parent1Id,
    uint256 parent2Id,
    string memory
  ) external whenNotPaused nonReentrant returns (uint256) {
    require(
      msg.sender == address(entityForgingContract),
      'unauthorized caller'
    );
    uint256 newGeneration = getTokenGeneration(parent1Id) + 1;

    /// Check new generation is not over maxGeneration
    require(newGeneration <= maxGeneration, "can't be over max generation");

    // Calculate the new entity's entropy
    (uint256 forgerEntropy, uint256 mergerEntropy) = getEntropiesForTokens(
      parent1Id,
      parent2Id
    );
    uint256 newEntropy = (forgerEntropy + mergerEntropy) / 2;

    // Mint the new entity
    uint256 newTokenId = _mintNewEntity(newOwner, newEntropy, newGeneration);

    return newTokenId;
  }
```

The function mints an Entity that is 1 generation ahead of the generation Entity that are being forged. Now, in the function `_increaseGeneration()` :
```solidity
  function _incrementGeneration() private {
    require(
      generationMintCounts[currentGeneration] >= maxTokensPerGen,
      'Generation limit not yet reached'
    );
    currentGeneration++;
    generationMintCounts[currentGeneration] = 0;
    priceIncrement = priceIncrement + priceIncrementByGen;
    entropyGenerator.initializeAlphaIndices();
    emit GenerationIncremented(currentGeneration);
  }
```
The variable counter of mints of each generation, `generationMintCounts` is reset to 0 for the upcoming generation. Now, this will replace any number of recorded mints that was there due to forging mints of previous generation. This is will turn cause the final total number of mints in next generation to more than `maxTokensPerGen` by number of forge mints that were done before the generation was increamented.

## Recommended Mitigation Steps
Remove the `generationMintCounts[currentGeneration] = 0;` from the code at line 351 of `TraitForgeNft.sol` to not cause this error of minting more than `maxTokensPerGen`.
