# Vulnerability details

## Impact
The initializeAlphaIndices function is intended to be called during the _incrementGeneration process, which is triggered when a new token is minted via the forge(). The forge function should be callable by anyone. However, the onlyOwner modifier on initializeAlphaIndices prevents this, making the forge() restricted.

## Tools Used
Manuel Review

## Recommended Mitigation Steps
Remove the onlyOwner modifier from initializeAlphaIndices and replace it with another mechanism to ensure it can be called securely and as needed.
