# Vulnerability details

**Description**

As per the communication with the sponsor the starting price of each NFT of each generation should be `0.005 ETH`
>ManPeach.0x: 0.005 across all gens

The starting price of each generation after the first is `startingPrice + priceIncrement` because [TraitForgeNft::_incrementGeneration()](https://github.com/code-423n4/2024-07-traitforge/blob/279b2887e3d38bc219a05d332cbcb0655b2dc644/contracts/TraitForgeNft/TraitForgeNft.sol#L345) is called on the last mint of the current generation in the beggining of[TraitForgeNft::_mintInternal()](https://github.com/code-423n4/2024-07-traitforge/blob/279b2887e3d38bc219a05d332cbcb0655b2dc644/contracts/TraitForgeNft/TraitForgeNft.sol#L280), instead of after the mint. This results in an increased count of minted tokens for the next generation. Which affectes the [TraitForgeNft::calculateMintPrice()](https://github.com/code-423n4/2024-07-traitforge/blob/279b2887e3d38bc219a05d332cbcb0655b2dc644/contracts/TraitForgeNft/TraitForgeNft.sol#L227).

**Impact**

The users will have to pay higher fee to mint the first token.
