# Vulnerability details

## Vulnerability Details
Function mint with budget will stop working and not mint any nfts after the protocol has minted 10k nfts. The function will not revert and wont provide any error despite not minting any nft.

## Proof of Concept
Create new test file, paste the code below and run it. The test shows that the function wont mint any nfts after tokenIds is greater or equal to 10k and it wont show any errors.

## Impact
One of the functions that is the core functionality and entry point into the protocol will not work properly and because it doesn't show any error it can mislead the user that it indeed minted nft.

## Recommended Mitigation Steps
If protocol owners want to restrict the amount of tokens users can mint in one transaction they should implement a check using the amountMinted variable, and require msg.value equal or greater than the next mint price.
