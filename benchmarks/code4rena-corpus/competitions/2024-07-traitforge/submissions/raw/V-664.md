# Vulnerability details

## Impact
In case of an emergency, the owner/protocol should be able to pause the functionality of the smart contracts. However no functions are implemented for the owner to be able to pause the contracts.

## Proof of Concept
All contracts `TraitForgeNft`, `NukeFund`, `EntropyGenerator`, `EntityTrading`, `EntityForging` and `DevFund` do not implement an external function for the owner to pause the operations of the smart contracts.

## Tools Used
Manual Review

## Recommended Mitigation Steps
Implement a suitable external function with `onlyOwner` access control.





## Assessed type

Access Control
