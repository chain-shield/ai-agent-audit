# Vulnerability details

## Impact

Mint functions, and the generation increase function does not take into account the maximum generation. Which allow users to mint into generations that are bigger than `maxGeneration`, while do not allow to forge into this gen.

In the worst case, an attacker could completely occupy the overflowed generation (or, if the developer ignores the overflow long enough, even regular users could occupy the overflowed generation), making the last "legitimate" generation of tokens infertile, and the users who owned them lost their investments in vain.

## About Severity:
 - I estimate the vulnerability as high if we consider the worst case scenario (which can be prevented if devs act quickly and there is no attacker willing to spend a large cost of the attack immidiatly). 
 - If we ignore the worst case scenario, the vulnerability can be considered as medium, since it breaks the normal logic of the contract.



## Proof of Concept

### NOTE: for this PoC to work we need to fix another vulnerability, to allow `mintWithBudget` work as intended, as an alternative you can call `mintToken` 10000 times.
For fix replace condition in `mintWithBudget` :

from:
```solidity
while (budgetLeft >= mintPrice && _tokenIds < maxTokensPerGen)
```
to:
```solidity
while (budgetLeft >= mintPrice && generationMintCounts[currentGeneration] < maxTokensPerGen) 
```


- For debugging purposes, you may want to make `TraitForgeNft._tokenIds` visible internally or even publicly.
- `testHign_OverGen` is PoC, the rest is setup
-  for the test `maxGeneration` is set to 2, to avoid minting 10*10000 tokens
-  Increase gas limit in configs or `--gas-limit` in cmd.

    function _mintForger(address _user) internal returns (uint256) {
        uint256 _forgerId;
        do {
            _forgerId = _mintToken(_user);
        } while (!nft.isForger(_forgerId));
        return _forgerId;
    }

    function _mintMerger(address _user) internal returns (uint256) {
        uint256 _mergerId;
        do {
            _mergerId = _mintToken(_user);
        } while (nft.isForger(_mergerId));
        return _mergerId;

        trackId++;

        deal(_user, _mintPrice);
        vm.startPrank(_user);
        nft.mintToken{value: _mintPrice}(new bytes32[](0));
        vm.stopPrank();

        return trackId;
    }

        vm.warp(nft.whitelistEndTime() + 1);
