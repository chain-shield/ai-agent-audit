# Vulnerability details

## Impact
The `nuke(uint256)` function cannot be paused as intended.

## Proof of Concept
`NukeFund.sol` inherits `Pausable` and applies the `whenNotPaused` modifier to the `nuke(uint256)` function. However, it lacks any method to actually pause or unpause the contract. The `Pausable.sol` file only provides internal functions, which require external or public functions to wrap them for execution. Since such functions are not implemented, the entire pausing mechanism is rendered useless, and staking cannot be paused as intended.

## Tools Used
- Static Analysis

## Recommended Mitigation Steps
Implement simple external `pause` and `unpause` functions that can be called by the owner.
