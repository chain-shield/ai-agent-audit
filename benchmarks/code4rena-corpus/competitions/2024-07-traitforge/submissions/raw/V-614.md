# Vulnerability details

## Impact

Will be different from documentation, mentioning only 1 per gen. If there is more than one 999,999 entropy entity, then the two entity can merge together to create *infinitely* (wait 1 year every 9 forges) more 999,999 entropy entities, breaking the game balance.

## Proof of Concept

`initializeAlphaIndices` is callable by the owner, and if the owner calls it to reset the slot and number index, there is a potential for another person to get a 999,999 entity.

The function is set as public with the `onlyOwner` modifier.

```
> function initializeAlphaIndices() public whenNotPaused onlyOwner {
    uint256 hashValue = uint256(
      keccak256(abi.encodePacked(blockhash(block.number - 1), block.timestamp))
    );

    uint256 slotIndexSelection = (hashValue % 258) + 512;
    uint256 numberIndexSelection = hashValue % 13;
```

If `slotIndexSelection` and `numberIndexSelection` is reset, another person can get 999,999.

```
  function getEntropy(
    uint256 slotIndex,
    uint256 numberIndex
  ) private view returns (uint256) {
    require(slotIndex <= maxSlotIndex, 'Slot index out of bounds.');

    if (
      slotIndex == slotIndexSelectionPoint &&
      numberIndex == numberIndexSelectionPoint
    ) {
      return 999999;

```


- Someone gets the golden entropy entity early in the mint
- Owner calls `initializeAlphaIndices`
- Another person has a chance to get the golden entropy entity
