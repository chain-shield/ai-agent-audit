# Vulnerability details

## Description

The project imports OpenZeppelin's `Pausable.sol` contract for additional security layer in it's contracts in scope with the idea to be paused by the owner in case of an emergency. However currently the contracts pause functionality is not available as it can be observed from the provided code links. This is because `Pausable.sol`'s pause function is `internal`, thus owner can't freeze the contracts.

```javascript
function _pause() internal virtual whenNotPaused {
        _paused = true;
        emit Paused(_msgSender());
    }
```

## Impact

- Impact: High, in case of an exploit owner can't pause the contracts
- Likelihood: Low, as it requires a criticial exploit to happen
- Overall: Medium

## Recommended Mitigation Steps

Explicitly implement the internal pause/unpause functions in custom public/external functions:  

```diff
+ function pause() public onlyOwner {
+   _pause();
+ } 

+ function unpause() public onlyOwner {
+   _unpause(); 
+ }
```
