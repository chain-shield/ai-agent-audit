# Vulnerability details

## Impact
In mintWithBudget(), there is one limitation `_tokenIds` must be less than `maxTokensPerGen`. Whitelist users cannot mint NFT via mintWithBudget() if current generation is not 1.

## Proof of Concept
Function `mintWithBudget()` aims to help users mint multiple NFTs in one transaction compared with mintToken(). However, in function mintWithBudget(), when current tokenId is not less than `maxTokensPerGen`, all operations will be reverted. This is not one expected behaviour.
