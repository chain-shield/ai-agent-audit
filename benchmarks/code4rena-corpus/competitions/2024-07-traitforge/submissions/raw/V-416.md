# Vulnerability details

## Impact

`forgePotential` is calculated wrongly.

## Proof of Concept

EntropyGenerator.deriveTokenParameters() calculates the `forgePotential` wrongly. It takes the first digit of the entropy instead of the fifth digit.

```
    forgePotential = getFirstDigit(entropy);
```

`forgePotential` will return a wrong value.

Impact is high because calculation is wrong, but since it is a view function, setting as medium severity because other players/contracts/protocols may build on top of this protocol and call `deriveTokenParameters` without knowing the mistake and causing confusion.

## Tools Used

Manual Review

## Recommended Mitigation Steps

Calculate it like it is done in EntityForging.sol, to extract the fifth digit.

```
    uint8 mergerForgePotential = uint8((mergerEntropy / 10) % 10); // Extract the 5th digit from the entropy
```
