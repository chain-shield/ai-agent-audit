# Vulnerability details

## Impact
Medium - if ageMultiplier is never initialized player experience will be ruined

## Proof of Concept
This variable is not initialized on contract creation. This means players can start playing before it gets set, in which case everybody's nukeFactor won't increase thus ruining their UX and incentive to play.

Now consider the `calculateAge()` function. The 'age' is calculated like so:

     uint256 age = (daysOld *
     perfomanceFactor *
     MAX_DENOMINATOR *
     ageMultiplier) / 365;

If ageMultiplier remains unset this equation will always equal 0. This will be used in the `calculateNukeFactor()` function like this:

     uint256 finalNukeFactor = ((adjustedAge * defaultNukeFactorIncrease) /
     MAX_DENOMINATOR) + initialNukeFactor;

If adjustedAge is 0 then this equation will reduce like this:

     uint256 finalNukeFactor = 0 + initialNukeFactor;


## Tools Used
Manual review

## Recommended Mitigation Steps
Initialize the ageMultiplier storage variable in constructor
