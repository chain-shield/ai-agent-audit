# Vulnerability details

## Impact
Users can mint NFTs and sell them to others just to farm the airdrop. Selling or transferring these NFTs does not change the airdrop amount they receive.

## Proof of Concept
Airdrop amounts are added when a new `tokenID` is minted:

```solidity
    tokenEntropy[newTokenId] = entropy;
    initialOwners[newTokenId] = newOwner;

    ...
    if (!airdropContract.airdropStarted()) {
        airdropContract.addUserAmount(newOwner, entropy);
    }
```

However, that entropy is removed only when the token is [burned](https://github.com/code-423n4/2024-07-traitforge/blob/main/contracts/TraitForgeNft/TraitForgeNft.sol#L141-L151). It is not removed on transfers or sales, enabling airdrop farmers to farm airdrop points by minting NFTs and selling them to active users who actually play the game.

This will lower the value of the game as some users exploit it for quick points and move on when the airdrop ends.

## Tools Used
Manual review

## Recommended Mitigation Steps
In the [_beforeTokenTransfer](https://github.com/code-423n4/2024-07-traitforge/blob/main/contracts/TraitForgeNft/TraitForgeNft.sol#L367) function, decrease the airdrop value for `from` and increase it for `to`:

```diff
    }

+   if (!airdropContract.airdropStarted()) {
+       uint256 entropy = getTokenEntropy(tokenId);
+       airdropContract.subUserAmount(initialOwners[tokenId], entropy);
+       initialOwners[tokenId] = to;
+       airdropContract.addUserAmount(initialOwners[tokenId], entropy);
+   }

    require(!paused(), "ERC721Pausable: token transfer while paused");
}
```
