# Vulnerability details

## Description

The `EntropyGenerator` contract is designed to generate and manage pseudo-random values for use in other contracts. It includes functions to initialize these values in batches to spread out gas costs. One such function is `writeEntropyBatch1()`, which initializes the first batch of entropy values. The function calculates an `endIndex` based on the `lastInitializedIndex` and `batchSize1`. However, if `lastInitializedIndex` is close to `batchSize1`, the calculated `endIndex` can exceed `batchSize1`, leading to potential out-of-bounds writes in the `entropySlots` array.

The relevant part of the code is as follows:
[EntropyGenerator.sol#L46-L61](https://github.com/code-423n4/2024-07-traitforge/blob/279b2887e3d38bc219a05d332cbcb0655b2dc644/contracts/EntropyGenerator/EntropyGenerator.sol#L46-L61)

The issue arises because the `endIndex` is not checked to ensure it does not exceed `batchSize1`. This can cause the loop to write beyond the intended range, potentially overwriting unintended slots in the `entropySlots` array.

## Impact
This bug can lead to out-of-bounds writes in the `entropySlots` array, potentially causing unintended behavior or overwriting important data. This could compromise the integrity of the entropy values and affect the functionality of other contracts relying on these values.

## Proof of Concept
1. Assume `lastInitializedIndex` is 250 and `batchSize1` is 256.
2. The `endIndex` will be calculated as `250 + 256 = 506`.
3. The loop will run from 250 to 505, which exceeds the intended range of 0 to 255 for `batchSize1`.
4. This results in out-of-bounds writes in the `entropySlots` array.

## Recommended Mitigation Steps
Ensure that `endIndex` does not exceed `batchSize1` by adding a check to limit `endIndex` to `batchSize1` if it exceeds it. The corrected code is as follows:

```diff
function writeEntropyBatch1() public {
  require(lastInitializedIndex < batchSize1, 'Batch 1 already initialized.');

  uint256 endIndex = lastInitializedIndex + batchSize1;
+ if (endIndex > batchSize1) {
+   endIndex = batchSize1;
+ }

  unchecked {
    for (uint256 i = lastInitializedIndex; i < endIndex; i++) {
      uint256 pseudoRandomValue = uint256(
        keccak256(abi.encodePacked(block.number, i))
      ) % uint256(10) ** 78;
      require(pseudoRandomValue != 999999, 'Invalid value, retry.');
      entropySlots[i] = pseudoRandomValue;
    }
  }
  lastInitializedIndex = endIndex;
}
```
