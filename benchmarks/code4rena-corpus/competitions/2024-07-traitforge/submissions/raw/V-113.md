# Vulnerability details

## Description
There is a bug when `minting the first NFT of generation 2+` that deviate from the expected price of 0.005 ETH and seems to warrant `Medium` severity.

The root cause is due to the fact that when minting the first NFT of those generations (2 and +), `_incrementGeneration` is called which do his job, but since `_mintInternal` is receiving the `mintPrice`, it does not recalculate the price, but since _incrementGeneration is applying some changes which affect the mint price, it requires to be recalculated to be accurate.

## Impact
Player will `pay more than expected` for the first NFT mint for generation 2 and beyond.
