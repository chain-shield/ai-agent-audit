# Vulnerability details

## Impact
The owner is unable to pause the contracts.

## Proof of Concept
All of the in-scope contracts inherits from OZ Pausable but none of them provides any public methods for pausing/unpausing the contract.

## Tools Used
Manual review

## Recommended Mitigation Steps
Add public/external pause and unpause functions to all the contracts:

```js
function pause() external onlyOwner{
    _pause();
}

function unpause() external onlyOwner {
    _unpause();
}
```
