# Vulnerability details

## Impact
The following contracts:
DevFund.sol
EntityForging.sol
EntityTrading.sol
EntropyGenerator.sol
NukeFund.sol
TraitForgeNft.sol
are meant to be pausable but they do not implement any external/public `pause/unpause` functionalities, which means the admin can not pause or unpause them .

All the contracts mentioned above inherit Pausable from OpenZeppelin, which means they include internal functions `_pause` and `_unpause`. Because they are internal functions, the mentioned contracts should implement external pause/unpause functions that allow the admin to pause/unpause them. Otherwise none of the contracts can be paused/unpaused in an emergency case.
## Tools Used
None. Manual Review
## Recommended Mitigation Steps
Implement necessary external pause/unpause functions that can be called by the admin.
