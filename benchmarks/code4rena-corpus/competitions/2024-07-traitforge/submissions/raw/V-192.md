# Vulnerability details

## Impact
writeEntropyBatch1(), writeEntropyBatch2() and writeEntropyBatch3() are used to initialize the 770 slots of entropy values in EntropyGenerator.sol. The way they set these values always overflow because of lack of parenthesis, which tries to calculate 10 ** 78, which overflows type(uint256).max.

## Tools Used
Manual review

## Recommended Mitigation Steps
Use parenthesys to avoid overflow. This way the highest result possible is 9 ** 78 which is lower than type(uint256).max
