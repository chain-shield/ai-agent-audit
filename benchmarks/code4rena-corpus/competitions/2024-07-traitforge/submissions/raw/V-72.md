# Vulnerability details

## Impact
Incorrect distribution of rewards among developers, with some potentially receiving less than their fair share.Also undistributed funds are accumulated over time, which will then be redirected to the contract owner instead of the developers. In extreme cases,there is a complete failure to distribute rewards when the calculated `amountPerWeight` rounds down to zero.



## Proof of Concept
Looking at the [`receive()` function](https://github.com/code-423n4/2024-07-traitforge/blob/279b2887e3d38bc219a05d332cbcb0655b2dc644/contracts/DevFund/DevFund.sol#L14-L28):

```solidity
function receive() external payable {
  if (totalDevWeight > 0) {
    uint256 amountPerWeight = msg.value / totalDevWeight;
    uint256 remaining = msg.value - (amountPerWeight * totalDevWeight);
    totalRewardDebt += amountPerWeight;
    if (remaining > 0) {
      (bool success, ) = payable(owner()).call{ value: remaining }('');
      require(success, 'Failed to send Ether to owner');
    }
  } else {
    // ... (omitted for brevity)
  }
}
```

To further illustrate this issue, let's assume that `totalDevWeight` is 3 and `msg.value` is 100 wei. `amountPerWeight` = 100 / 3 = 33 (rounded down). `remaining` = 100 - (33 * 3) = 1

We can see that 1 wei is lost in the process of rounding and sent to the owner instead of being distributed to developers.

Also, illustrating it in more extreme cases i talked about above, let's assume that `totalDevWeight` is 100 and `msg.value` is 10 wei. `amountPerWeight` = 10 / 100 = 0 (rounded down).
`remaining` = 10 - (0 * 100) = 10

We can also see that all 10 wei are sent to the owner, with no distribution at all to developers.

## Recommended Mitigation Steps

Implement a scaling factor to increase precision:

```solidity
uint256 constant SCALE_FACTOR = 1e18;

function receive() external payable {
  if (totalDevWeight > 0) {
    uint256 amountPerWeight = (msg.value * SCALE_FACTOR) / totalDevWeight;
    totalRewardDebt += amountPerWeight;
    // No need to calculate remaining, as all funds are now accounted for
  } else {
    // ... (existing code for when totalDevWeight is 0)
  }
}
```

You can also modify the [`claim()`](https://github.com/code-423n4/2024-07-traitforge/blob/279b2887e3d38bc219a05d332cbcb0655b2dc644/contracts/DevFund/DevFund.sol#L61-L75) function to use the scale factor:

```solidity
function claim() external whenNotPaused nonReentrant {
  DevInfo storage info = devInfo[msg.sender];
  uint256 pending = info.pendingRewards +
    ((totalRewardDebt - info.rewardDebt) * info.weight) / SCALE_FACTOR;
  // ... (rest of the function remains the same)
}
```
