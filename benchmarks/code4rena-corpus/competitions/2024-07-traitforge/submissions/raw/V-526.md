# Vulnerability details

## Impact
Multiple scenarios of rounding down issues

## Proof of Concept
There are multiple scenarios where rounding down can occur as the divisions happen directly. For example, in `DevFund`, we have the following code:
```solidity
uint256 amountPerWeight = msg.value / totalDevWeight;
```
Or the following code in `NukeFund`:
```solidity
uint256 initialNukeFactor = entropy / 40;
```
There are other scenarios where that also occurs and will cause rounding down issue.

## Tools Used
Manual Review

## Recommended Mitigation Steps
Use higher precision
