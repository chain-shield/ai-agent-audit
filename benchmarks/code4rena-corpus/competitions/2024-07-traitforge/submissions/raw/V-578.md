# Vulnerability details

## Impact
Due to a lack of validation for `maxGeneration` in the `TraitForgeNft.sol#_incrementGeneration()` function, more NFTs may be created than expected. This is a damage to the primary characteristics of the protocol.

## Proof of Concept
The `TraitForgeNft.sol#_incrementGeneration()` function is called when the generation increases in the `mintToken()` and `mintWithBudget()` functions of the `TraitForgeNft` contract.
Validation for `maxGeneration` of the `TraitForgeNft.sol#_incrementGeneration()` function is not performed.
```solidity
  function _incrementGeneration() private {
    require(
      generationMintCounts[currentGeneration] >= maxTokensPerGen,
      'Generation limit not yet reached'
    );
    currentGeneration++;
    generationMintCounts[currentGeneration] = 0;
    priceIncrement = priceIncrement + priceIncrementByGen;
    entropyGenerator.initializeAlphaIndices();
    emit GenerationIncremented(currentGeneration);
  }
```
The contract clearly regulates the generation limit.
```solidity
  /// @dev generation limit
  uint256 public maxGeneration = 10;
```

However, due to lack of validation in the `_incrementGeneration()` function, `currentGeneration` may exceed `maxGeneration`, which is a violation of the primary characteristics of the protocol.

This is also a valid problem considering the restriction that `newGeneration` specified in the `TraitForgeNft.sol#forge()` function cannot be greater than `maxGeneration`.
```solidity
    /// Check new generation is not over maxGeneration
    require(newGeneration <= maxGeneration, "can't be over max generation");
```

## Recommended Mitigation Steps
It is recommended that modify the `_incrementGeneration` as follows
```solidity
  function _incrementGeneration() private {
    require(
      generationMintCounts[currentGeneration] >= maxTokensPerGen,
      'Generation limit not yet reached'
    );

+++ require(currentGeneration <= maxGeneration, 'Generation is too high');

    currentGeneration++;
    generationMintCounts[currentGeneration] = 0;
    priceIncrement = priceIncrement + priceIncrementByGen;
    entropyGenerator.initializeAlphaIndices();
    emit GenerationIncremented(currentGeneration);
  }
```
