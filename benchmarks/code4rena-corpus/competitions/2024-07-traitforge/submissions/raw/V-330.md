# Vulnerability details

## Description

The `TraitForgeNft` contract includes a `onlyWhitelisted` modifier intended to restrict access to certain functions to only whitelisted users during a specific period. The modifier is defined as follows:

[TraitForgeNft.sol#L51-L59](https://github.com/code-423n4/2024-07-traitforge/blob/279b2887e3d38bc219a05d332cbcb0655b2dc644/contracts/TraitForgeNft/TraitForgeNft.sol#L51-L59)
```solidity
File: TraitForgeNft.sol
51:   modifier onlyWhitelisted(bytes32[] calldata proof, bytes32 leaf) {
52:     if (block.timestamp <= whitelistEndTime) {
53:       require(
54:         MerkleProof.verify(proof, rootHash, leaf),
55:         'Not whitelisted user'
56:       );
57:     }
58:     _;
59:   }

```

The `onlyWhitelisted` modifier checks if the current time is within the whitelist period (`block.timestamp <= whitelistEndTime`). If it is, it verifies the user's proof against the Merkle root. However, if the whitelist period has ended, the modifier does nothing, allowing anyone to call the function it protects. This behavior is observed in the `mintToken` and `mintWithBudget` functions, which are critical for minting new tokens.

## Impact
Unauthorized users can mint tokens after the whitelist period has ended, bypassing the intended access control. This could lead to an uncontrolled minting of tokens, potentially disrupting the tokenomics and fairness of the system. The impact is significant as it undermines the whitelist mechanism, allowing non-whitelisted users to mint tokens, which could lead to an oversupply and devaluation of the tokens.

## Proof of Concept
1. The whitelist period is set to end at a specific `whitelistEndTime`.
2. A user attempts to call the `mintToken` function after the `whitelistEndTime`.
3. The `onlyWhitelisted` modifier does not revert the transaction because the current time is beyond the `whitelistEndTime`.
4. The user successfully mints a token without being whitelisted.

## Recommended Mitigation Steps
To ensure that only whitelisted users can mint tokens during the whitelist period and prevent any access after the period, the `onlyWhitelisted` modifier should be updated to revert if the whitelist period has ended. Here is the recommended fix:

```diff
modifier onlyWhitelisted(bytes32[] calldata proof, bytes32 leaf) {
-    if (block.timestamp <= whitelistEndTime) {
+    require(block.timestamp <= whitelistEndTime, 'Whitelist period ended');

            'Not whitelisted user'

-    }

}
```
