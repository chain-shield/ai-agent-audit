# Vulnerability details

## Impact
The first user to mint an NFT in a new generation after the fist generation gets it an inflated amount.

## Proof of Concept
Whenever the first NFT in a new generation is to be minted, the start price is calculated before incrementing the generation, thus the nft is minted with the penultimate token price of the last generation, rather than the price of the first token in the next generation

```
    // mint price is calculated before incrementing gen
    uint256 mintPrice = calculateMintPrice();
    require(msg.value >= mintPrice, 'Insufficient ETH send for minting.');
   
    _mintInternal(msg.sender, mintPrice);
```

is calculated before the generation is incremented in _mintInternal()
```
   if (generationMintCounts[currentGeneration] >= maxTokensPerGen) {
      _incrementGeneration();
    }
```

Therefore the NFT is minted with the priceIncrement of the last generation.

```
function test2ndGenMintedWithInflatedPrice() public {
        vm.warp(block.timestamp + 25 hours);
        vm.roll(1);
        vm.deal(alice, 10e18);
        vm.deal(bob, 1e18);
        vm.deal(owner, 1e18);

        vm.prank(owner);
        entropyGenerator.writeEntropyBatch1();

        bytes32[] memory proof;

        //maxTokens per gen has been modified for  testing purposes
        //mint all tokens from the first generation
        vm.prank(alice);
        traitForgeNft.mintWithBudget{value: 0.6e18}(proof); //mint price of last token from 1st gen: 5098000000000000

        uint256 mintPrice = traitForgeNft.calculateMintPrice();
        vm.prank(bob);
        traitForgeNft.mintToken{value : mintPrice}(proof); //mint price: 5122500000000000(inflated price)

        mintPrice = traitForgeNft.calculateMintPrice();

        console.log(traitForgeNft.generationMintCounts(2));
        console.log(traitForgeNft.priceIncrement());
        console.log(traitForgeNft.startPrice());

        vm.prank(bob);
        traitForgeNft.mintToken{value : mintPrice}(proof); // mint price: 5029500000000000(correct increment for 2nd gen)

        mintPrice = traitForgeNft.calculateMintPrice();

        vm.prank(bob);
        traitForgeNft.mintToken{value : mintPrice}(proof); // mint price: 5059000000000000 (correct increment for 2nd gen)

    }
```

## Recommended Mitigation Steps
In the mint internal function, whenever the generation is to be incremented, recalculate the mintPrice and refund excess amounts to the msg sender
