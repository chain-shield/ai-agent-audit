# Vulnerability details

## Impact
`EntropyGenerator.deriveTokenParameters()` reports wrong forge potential value. Spec defines forge potential as 5th digit from the entropy. However, `EntropyGenerator.deriveTokenParameters()`  uses first digit.

```
forgePotential = getFirstDigit(entropy);
```
[Link](https://github.com/code-423n4/2024-07-traitforge/blob/main/contracts/EntropyGenerator/EntropyGenerator.sol#L153)

## Proof of Concept
Following test added to fails:
```
  it('forge potential from derive parameters should be correct', async function () {
    for (let i = 0; i < 770; i++) {
      for (let j = 0; j < 13; j++) {
        const entropy = await entropyGenerator.connect(allowedCaller).getPublicEntropy(i, j);
        const [nukeFactor, forgePotential, performanceFactor, isSire] =
          await entropyGenerator.deriveTokenParameters(i, j);

        expect((entropy / 10n) % 10n).to.equal(forgePotential);
      }
    }
  });
```

## Recommended Mitigation Steps
Use formula from the spec to report forge potential.
