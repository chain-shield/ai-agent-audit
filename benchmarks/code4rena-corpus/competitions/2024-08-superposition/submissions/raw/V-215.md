# Vulnerability details

## Summary
The `swapIn32502CA71` function sets no upper bound on the price of the swap, potentially allowing for price manipulation or extreme slippage.

## Code Snippet

https://github.com/code-423n4/2024-08-superposition/blob/main/pkg/sol/SeawaterAMM.sol#L262

```solidity
function swapIn32502CA71(address token, uint256 amountIn, uint256 minOut) external returns (int256, int256) {
    (bool success, bytes memory data) = _getExecutorSwap().delegatecall(abi.encodeCall(
        ISeawaterExecutorSwap.swap904369BE,
        (
            token,
            true,
            int256(amountIn),
            type(uint256).max  // This is the problematic line
        )
    ));
    // ... (rest of the function)
}
```

## Impact
1. Price Manipulation: An attacker could potentially manipulate the price by front-running transactions and setting unfavorable rates.
2. Extreme Slippage: Users might receive significantly fewer tokens than expected, especially in low liquidity situations.
3. Financial Loss: Users could experience substantial financial losses due to unexpected trade outcomes.

## Scenario
1. Alice wants to swap 1000 USDC for ETH when 1 ETH is worth 2000 USDC.
2. Bob, a malicious actor, sees Alice's transaction in the mempool.
3. Bob front-runs Alice's transaction, temporarily manipulating the price to 1 ETH = 3000 USDC.
4. Alice's transaction executes, but she receives significantly less ETH than expected.
5. Bob back-runs to restore the price, profiting from the manipulation.

## Fix
Implement a maximum acceptable price (maxPrice) parameter in the function:

```solidity
function swapIn32502CA71(address token, uint256 amountIn, uint256 minOut, uint256 maxPrice) external returns (int256, int256) {
    (bool success, bytes memory data) = _getExecutorSwap().delegatecall(abi.encodeCall(
        ISeawaterExecutorSwap.swap904369BE,
        (
            token,
            true,
            int256(amountIn),
            maxPrice  // Use the provided maxPrice instead of type(uint256).max
        )
    ));
    // ... (rest of the function remains the same)
}
```
