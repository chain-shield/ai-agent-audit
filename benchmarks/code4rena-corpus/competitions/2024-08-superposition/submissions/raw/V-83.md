# Vulnerability details

## Impact
If an already initialized Id is passed to the new function of StoragePositions the position will be updated.

## Proof of Concept
Since there aren't any checks if the position with the passed Id already exists in the pool, the properties of that position will be updated. Because there are also no checks for the ownership of the position, an attacker could update another user's position thus making their liquidity not being used in the pool and preventing them from getting any fees from their assets.

## Tools Used
Manual Review

## Recommended Mitigation Steps
Consider adding a check if the position with 'id' has been initialized:
```
let position = self.positions.getter(id);
if position.lower == 0 && position.upper == 0 {
   return Err(Error::PositionAlreadyInitialized);
}
```
