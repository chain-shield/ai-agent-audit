# Vulnerability details

## Impact
High. The quote function performs an actual token transfer, potentially depleting contract funds or user allowances, and significantly increasing gas costs for what should be a gas-free, read-only operation.
## Proof of Concept
The quote_72_E2_A_D_E7 function, intended to provide a quote for a swap operation, unnecessarily executes a real token transfer. This violates the principle that quote operations should be read-only and cost-free.

Vulnerable Code
```
pub fn quote_72_E2_A_D_E7(
    &mut self,
    pool: Address,
    zero_for_one: bool,
    amount: I256,
    price_limit_x96: U256,
) -> Result<(), Revert> {
    let swapped = self
        .pools
        .setter(pool)
        .swap(zero_for_one, amount, price_limit_x96);
    match swapped {
        Ok((amount_0, amount_1, _)) => {
            let (give_token, give_amount) = match zero_for_one {
                true => (FUSDC_ADDR, amount_1),
                false => (pool, amount_0),
            };
            // @audit-info ---->> it doesn't need to transfer
            erc20::transfer_to_sender(give_token, give_amount.abs_neg()?)?;
            // ... (rest of the function)
        }
        Err(e) => Err(e),
    }
}
```
Quote functions should be read-only operations that simulate a swap to provide price information without executing an actual transfer. The current implementation erroneously performs a real token transfer.

Proof of Concept
1. A user calls quote_72_E2_A_D_E7 expecting only to receive price information.
2. The function performs an actual token transfer: erc20::transfer_to_sender(give_token, give_amount.abs_neg()?)?;
3. This results in unexpected token movement and high gas costs for the user.
