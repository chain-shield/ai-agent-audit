# Vulnerability details

## Impact

The current implementation of the `SeawaterAMM` smart contract uses Diamond-like proxy pattern directing calls to the implementation contracts via delegatecall. It enables the users to call different functions from different features. The problem is that the contract initializes `EXECUTOR_FALLBACK_SLOT` and assigns the corresponding smart contract address of the Rust implementation but there is no currently such feature in the Rust code.

## Proof of Concept

`EXECUTOR_FALLBACK_SLOT` is assigned to the corresponding address in the internal `_setProxies()` function:

https://github.com/code-423n4/2024-08-superposition/blob/main/pkg/sol/SeawaterAMM.sol#L568
```
StorageSlot.getAddressSlot(EXECUTOR_FALLBACK_SLOT).value = address(executorFallback);
```

https://github.com/code-423n4/2024-08-superposition/blob/main/pkg/sol/SeawaterAMM.sol#L30
```
bytes32 constant EXECUTOR_FALLBACK_SLOT = bytes32(uint256(keccak256("seawater.impl.fallback")) - 1);
```

As you can see from the next lines, the "fallback" feature is called in the `fallback()` function if no any other feature does not correspond to the `msg.data` sent to the contract:


https://github.com/code-423n4/2024-08-superposition/blob/main/pkg/sol/SeawaterAMM.sol#L520
```
        else directDelegate(_getExecutorFallback());
    }
```

`directDelegate` in its turn calls implementation address (in the terms of the protocol, it's "features" in the Rust code):


https://github.com/code-423n4/2024-08-superposition/blob/main/pkg/sol/SeawaterAMM.sol#L129-132
```

 // call a function with the same name and calldata on another contract
    // this ends execution!
    // proxy implementation adapted from openzeppelin
    function directDelegate(address to) internal 

```

As the comment above points out, the proxy implementation is adapted from the OZ meaning `directDelegate` is similar to the `_delegate()` function from the `Proxy` contract that calls implementation.

Therefore, the contract calls "fallback" feature but there is nothing initialized in the Rust code:

https://github.com/code-423n4/2024-08-superposition/blob/main/pkg/seawater/src/lib.rs#L81-89
```
#[cfg(not(any(
    feature = "swaps",
    feature = "swap_permit2",
    feature = "quotes",
    feature = "positions",
    feature = "update_positions",
    feature = "admin",
    feature = "migrations"
)))]

```

## Tools Used

Manual review.

## Recommended Mitigation Steps

Implement "fallback" feature in the Rust implementation code.
