# Vulnerability details

## Impact
The function _setProxies() is used to set various executor addresses, but there is no validation to ensure that the addresses being set are valid contracts. This allows setting a zero address or an invalid contract as an executor.

## Proof of Concept
The following code snippet does not validate that executorSwap, executorQuote, etc., are non-zero addresses and point to valid contracts.

```
function _setProxies(
    ISeawaterExecutorSwap executorSwap,
    ISeawaterExecutorSwapPermit2 executorSwapPermit2,
    ISeawaterExecutorQuote executorQuote,
    ISeawaterExecutorPosition executorPosition,
    ISeawaterExecutorUpdatePosition executorUpdatePosition,
    ISeawaterExecutorAdmin executorAdmin,
    ISeawaterExecutorFallback executorFallback
) internal {
    StorageSlot.getAddressSlot(EXECUTOR_SWAP_SLOT).value = address(executorSwap);
    // ...
}
```
If an invalid or malicious contract is set as one of the executors, the entire proxy system can be compromised.

## Tools Used
Manual

## Recommended Mitigation Steps
Add checks to validate that the executor addresses are non-zero and point to valid contracts.
```
function _setProxies(
    ISeawaterExecutorSwap executorSwap,
    ISeawaterExecutorSwapPermit2 executorSwapPermit2,
    ISeawaterExecutorQuote executorQuote,
    ISeawaterExecutorPosition executorPosition,
    ISeawaterExecutorUpdatePosition executorUpdatePosition,
    ISeawaterExecutorAdmin executorAdmin,
    ISeawaterExecutorFallback executorFallback
) internal {
    require(Address.isContract(executorSwap), "Invalid executorSwap contract");
    require(Address.isContract(executorQuote), "Invalid executorQuote contract");
    // ...

    StorageSlot.getAddressSlot(EXECUTOR_SWAP_SLOT).value = address(executorSwap);
    // ...
}
```
This ensures that only valid contract addresses are used for executors.
