# Vulnerability details

## Impact
Emergency council cannot be set because of the incorrect update.

## Proof of Concept
The seawater admin can update the emergency council address. 
The problem is that when we try to update the `emergency_council`, we set the incorrect variable `nft_manager`. This will cause that we cannot set the `emergency_council`.
