# Vulnerability details

## Impact
EIP721 is violated as the standard is not enforced correctly

## Proof of Concept
According to [EIP721](https://eips.ethereum.org/EIPS/eip-721#specification):
```solidity
    /// @dev Throws if `_tokenId` is not a valid NFT. URIs are defined in RFC
    
    function tokenURI(uint256 _tokenId) external view returns (string);
```

In order to be EIP721 compliant, the [`tokenURI()`](https://github.com/code-423n4/2024-08-superposition/blob/4528c9d2dbe1550d2660dac903a8246076044905/pkg/sol/OwnershipNFTs.sol#L182-L184) should check the existence of the `tokenId`, which is not being performed here:
```solidity
    function tokenURI(uint256 /* _tokenId */) external view returns (string memory) {
        return TOKEN_URI;
    }
```

## Tools Used
Manual Review

## Recommended Mitigation Steps
The `tokenURI()` function should be modified to check the existence of the `tokenId` before returning
```diff
-   function tokenURI(uint256 /* _tokenId */) external view returns (string memory) {
+   function tokenURI(uint256 _tokenId) external view returns (string memory) {
+       owner = ownerOf(_tokenId);
+       require(owner != address(0));
        return TOKEN_URI;
    }
```
