# Vulnerability details

## Impact
There is not one function to set `fee_protocol`. This will cause protocol fee is always zero. The protocol team cannot collect any protocol fee.

## Proof of Concept
In pool.rs, variable `fee_protocol` is used to record the protocol fee rate. When traders swap via pool, the swap fees will be splitted into two part. One part is for LP holders and another part is for protocol team.

The problem is that we don't initialize the variable `fee_protocol`. And what's more, we missed one setting function to set the variable `fee_protocol`.
```javascript
            if fee_protocol > 0 {
                // Split one part of swap fee to the protocol fee.
                let delta = step_fee_amount.wrapping_div(U256::from(fee_protocol));
                step_fee_amount -= delta;
                // Update protocol fee in the temporary state.
                state.protocol_fee += u128::try_from(delta).or(Err(Error::FeeTooHigh))?;
            }

```

## Tools Used
Manual

## Recommended Mitigation Steps
Add one onlyOwner function to set `fee_protocol`, just like Uniswap V3.
