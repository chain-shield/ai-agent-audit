# Vulnerability details

## Impact
Detailed description of the impact of this finding.

Some functions, such as collect_7_F21947_C, iterate over user-supplied arrays (e.g., pools and position IDs). If a user submits excessively large arrays, this could lead to a denial of service (DoS) by exceeding the block gas limit. As a result, the contract could fail to process legitimate user requests.

## Recommended Mitigation Steps

Limit the maximum size of input arrays in functions that loop over user-supplied data. Enforce a reasonable limit (e.g., 256 pools/IDs) to ensure the function does not consume excessive gas.

