# Vulnerability details

## Proof of Concept

Users can modify their liquidity from:
- incr_position
- update_position
- decr_position

However update_position is the only one of them that has no slippage protection.

```rust
    pub fn update_position_C_7_F_1_F_740(
        &mut self,
        pool: Address,
        id: U256,
        delta: i128,
    ) -> Result<(I256, I256), Revert> {
        self.update_position_internal(pool, id, delta, None)
    }
```


## Tools Used

Eyes

## Recommended Mitigation Steps

Add slippage protection in `update_position_C_7_F_1_F_740`.
