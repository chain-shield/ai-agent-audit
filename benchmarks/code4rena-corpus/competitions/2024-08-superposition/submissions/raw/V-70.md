# Vulnerability details

In the `update_emergency_council_7_D_0_C_1_C_58` function, there is an incorrect update where the **NFT manager (self.nft_manager)** is being set instead of the **emergency council**. The function is intended to update the **emergency council**, which has the authority to disable pools in critical situations. However, due to this error, the function modifies the wrong storage variable.

This mistake leads to unintended behavior where the emergency council remains unchanged, and the NFT manager, which is responsible for managing NFTs, is incorrectly overwritten

## Impact
- **Operational Issues:** Failure to update the proper entities may result in allowing unauthorized or misconfigured entities to hold control, causing operational risks.

- **Inability to update the emergency council:** The emergency council, which should have the authority to disable pools, remains unchanged.

- **Overwriting the NFT manager:** The incorrect assignment changes the NFT manager, which may lead to improper management of NFT-related functions, such as token transfers or user permissions.
