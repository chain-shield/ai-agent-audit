# Vulnerability details

### Impact

Emergency council cannot be updated if need be and NFTManager contract is replaced, potentially dossing all processes that occur from it.

### Proof of Concept

1. Context

The emergency council is reponsible for disabling the pools, potentially in cases of emergency. There's also the `nft_manager` contract through which positions can be transferred from one user to another. These addresses can be updated through the `update_emergency_council_7_D_0_C_1_C_58` and `update_nft_manager_9_B_D_F_41_F_6` functions.

2. Bug Location

When updating the emergency council through the `update_emergency_council_7_D_0_C_1_C_58` function, we can see at the @audit tag, that instead of setting the address as emergency council, it is set instead as nft manager. 

```rust
    pub fn update_emergency_council_7_D_0_C_1_C_58(
        &mut self,
        manager: Address,
    ) -> Result<(), Revert> {
        assert_eq_or!(
            msg::sender(),
            self.seawater_admin.get(),
            Error::SeawaterAdminOnly
        );

        self.nft_manager.set(manager); //@audit

        Ok(())
    }
```

3. Final Effect

- Emergency council cannot be updated to a different address especially if the initial address goes rouge, potentially compromising protcol integrity.
- NFT manager role mismatch as the `transfer_position_E_E_C7_A3_C_D` function is expected to be callable through the nft manager contract, but cannot be called. Users attempting to transfer their positions, including transferring their OwnershipNFTs will not be able to, halting a core part of protocol operation. 

### Tools Used
Manual code review
 
### Recommended Mitigation Steps

Set the address to the emergency council instead. 

```diff
    pub fn update_emergency_council_7_D_0_C_1_C_58(
        &mut self,
        manager: Address,
    ) -> Result<(), Revert> {
        assert_eq_or!(
            msg::sender(),
            self.seawater_admin.get(),
            Error::SeawaterAdminOnly
        );

-        self.nft_manager.set(manager);
+        self.emergency_council.set(manager);        

        Ok(())
    }
```
