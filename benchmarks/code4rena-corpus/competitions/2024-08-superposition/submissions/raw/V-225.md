# Vulnerability details

### Summary
The `_transfer` function in the OwnershipNFTs contract is responsible for transferring ownership of NFT positions in the Seawater AMM system. It relies on the SeawaterAMM contract to perform the actual transfer.

The `_transfer` function checks authorization but then calls the SeawaterAMM contract without passing the authorization check result. The SeawaterAMM contract then delegates the call to an executor contract without performing any additional checks. This creates a potential vulnerability where the executor contract could be manipulated to bypass authorization checks.

### Impact
An attacker could potentially exploit this vulnerability to transfer NFT positions they don't own, leading to unauthorized transfers and potential loss of assets for legitimate owners.

### Scenario
1. An attacker deploys a malicious executor contract.
2. The attacker somehow manages to set this malicious contract as the position executor (e.g., through a separate vulnerability in the admin functions).
3. The malicious executor ignores the `_from` parameter and allows transfers from any address.
4. The attacker can now transfer any NFT position, bypassing the authorization check in the OwnershipNFTs contract.

### Fix
Implement a two-step verification process:

1. In OwnershipNFTs, generate and return a unique, single-use authorization token after checking permissions.
2. Modify SeawaterAMM to accept and verify this token before delegating the call.
3. Ensure the executor contract also verifies this token.

**Example Fix:**

OwnershipNFTs contract:
```solidity
function _transfer(address _from, address _to, uint256 _tokenId) internal returns (bytes32) {
    _requireAuthorised(_from, _tokenId);
    bytes32 authToken = keccak256(abi.encodePacked(_from, _to, _tokenId, block.number));
    SEAWATER.transferPositionEEC7A3CD(_tokenId, _from, _to, authToken);
    return authToken;
}
```

SeawaterAMM contract:
```solidity
function transferPositionEEC7A3CD(uint256 id, address from, address to, bytes32 authToken) external {
    require(keccak256(abi.encodePacked(from, to, id, block.number)) == authToken, "Invalid auth token");
    directDelegate(_getExecutorPosition());
}
```
