# Vulnerability details

## Impact

Attacker can DoS any functions that uses permit2 by extracting the signature parameters from the function call and frontrunning with a direct `permit()`.

## Proof of Concept

Users can choose to use permit2 capability in some functions in lib.rs.

```
 pub fn update_position_internal(
        &mut self,
        pool: Address,
        id: U256,
        delta: i128,
>       permit2: Option<(Permit2Args, Permit2Args)>,
``` 

An attacker can extract the `Permit2Args` and call `permit()` directly, DoSing the call.

```
pub struct Permit2Args<'a> {
    pub max_amount: U256,
    pub nonce: U256,
    pub deadline: U256,
    pub sig: &'a [u8],
}
```

Manual Review

## Recommended Mitigation Steps

From [this](https://www.trust-security.xyz/post/permission-denied) recommendation, 

> Attempt to call permit() first, then catches an exception and would allow logic to continue in case the allowance is enough (this would be the case after a frontrun).
