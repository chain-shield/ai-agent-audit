# Vulnerability details

## Impact
High. The current implementation prevents all valid NFT transfers to contracts implementing the ERC721TokenReceiver interface.

## Proof of Concept
The ERC721 standard requires that contracts receiving NFTs must implement the ERC721TokenReceiver interface and return a specific selector from the onERC721Received function to indicate they can handle the NFT.
The current implementation reverts when the correct selector is returned, which is the opposite of what it should do. This prevents all valid transfers to contracts, effectively breaking the NFT transfer functionality to any contract recipient.

The _onTransferReceived function in the contract incorrectly checks the return value of the onERC721Received callback. The function reverts when the callback returns the correct selector, which is the opposite of the intended behavior.

Vulnerable Code
```
function _onTransferReceived(
    address _sender,
    address _from,
    address _to,
    uint256 _tokenId
) internal {
    if (_to.code.length == 0) return;
    bytes4 data = IERC721TokenReceiver(_to).onERC721Received(
        _sender,
        _from,
        _tokenId,
        ""
    );
    require(
        data != IERC721TokenReceiver.onERC721Received.selector, <@==
        "bad nft transfer received data"
    );
}
```
