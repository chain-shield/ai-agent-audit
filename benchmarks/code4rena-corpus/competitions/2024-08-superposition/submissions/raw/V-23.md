# Vulnerability details

## Impact
Access control is crucial for functions that affect the contract's state or financial operations to ensure only trusted entities can perform sensitive actions, the absence of it on those functions exposes the protocol to several severe consequences, for example:
- **Unauthorized Pool Creation:** Any user or contract could create liquidity pools without restriction, potentially leading to the introduction of pools that could be used for malicious purposes or to drain funds.
- **Reputation Damage:** If exploited, the lack of access control could damage the protocol's reputation, leading to loss of user trust and confidence.
