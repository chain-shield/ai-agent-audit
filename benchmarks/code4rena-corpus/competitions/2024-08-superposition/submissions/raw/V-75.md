# Vulnerability details

## Impact
When a user calls update_emergency_council it actually updates the nft manager.

## Proof of Concept
The parameter that the function accepts is manager: Address and inside the function self.nft_manager.set(manager); is called, which changes the nft manager and not the emergency council.

## Tools Used
Manual Review

## Recommended Mitigation Steps
Change the input parameter to emergency_council: Address and the setter to self.emergency_council.set(emergency_council); so the function looks like this:
```
/// Update the emergency council that can disable the pools.
    #[allow(non_snake_case)]
    pub fn update_emergency_council_7_D_0_C_1_C_58(
        &mut self,
        emergency_council: Address,
    ) -> Result<(), Revert> {
        assert_eq_or!(
            msg::sender(),
            self.seawater_admin.get(),
            Error::SeawaterAdminOnly
        );

        self.emergency_council.set(emergency_council);

        Ok(())
    }
```
