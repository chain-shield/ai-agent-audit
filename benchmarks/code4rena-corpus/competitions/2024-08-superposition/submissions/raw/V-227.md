# Vulnerability details

### Summary
The `swapOutPermit23273373B` function is intended to swap USDC for another token using Permit2 for approvals. However, the implementation incorrectly sets up the swap direction.

In the contract implementation, the function calls `swapPermit2EE84AD91` with `zeroForOne` set to `false`. This setting indicates a swap from the target token to USDC, which is the opposite of the intended behavior as described in the interface.

### Code Snippet

https://github.com/code-423n4/2024-08-superposition/blob/main/pkg/sol/SeawaterAMM.sol#L322

```solidity
function swapOutPermit23273373B(address token, uint256 amountIn, uint256 minOut, uint256 nonce, uint256 deadline, uint256 maxAmount, bytes memory sig) external returns (int256, int256) {
    (bool success, bytes memory data) = _getExecutorSwapPermit2().delegatecall(abi.encodeCall(
        ISeawaterExecutorSwapPermit2.swapPermit2EE84AD91,
        (
            token,
            false,  // This should be true for swapping USDC to token
            int256(amountIn),
            type(uint256).max,
            nonce,
            deadline,
            maxAmount,
            sig
        )
    ));
    // ... rest of the function
}
```

### Impact
This bug causes the swap to occur in the wrong direction. Users attempting to swap USDC for another token will instead have the opposite occur, potentially leading to unexpected token movements and financial losses.

### Scenario
A user calls `swapOutPermit23273373B` expecting to swap 1000 USDC for at least 100 TOKEN_X. Due to the bug, the contract attempts to swap TOKEN_X for USDC instead, which will fail if the user hasn't approved TOKEN_X, or worse, swap an unexpected amount of TOKEN_X if they have.

### Fix
Change the `zeroForOne` parameter to `true` in the `swapPermit2EE84AD91` call:

```solidity
function swapOutPermit23273373B(address token, uint256 amountIn, uint256 minOut, uint256 nonce, uint256 deadline, uint256 maxAmount, bytes memory sig) external returns (int256, int256) {
    (bool success, bytes memory data) = _getExecutorSwapPermit2().delegatecall(abi.encodeCall(
        ISeawaterExecutorSwapPermit2.swapPermit2EE84AD91,
        (
            token,
            true,  // Changed to true for correct swap direction
            int256(amountIn),
            type(uint256).max,
            nonce,
            deadline,
            maxAmount,
            sig
        )
    ));
    // ... rest of the function
}
```
