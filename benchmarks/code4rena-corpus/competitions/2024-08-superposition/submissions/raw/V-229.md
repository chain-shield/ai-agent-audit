# Vulnerability details

## Impact
- The emergency council address remains unchanged, potentially leaving an outdated or compromised address in control.
- The NFT manager address is unexpectedly changed, which could disrupt NFT-related operations.

## Proof of Concept

The `update_emergency_council_7_D_0_C_1_C_58` function is intended to update the emergency council address. However, it incorrectly updates the NFT manager address instead

```
pub fn update_emergency_council_7_D_0_C_1_C_58(
        &mut self,
        manager: Address,
    ) -> Result<(), Revert> {
        assert_eq_or!(
            msg::sender(),
            self.seawater_admin.get(),
            Error::SeawaterAdminOnly
        );

        self.nft_manager.set(manager); //this line is incorrect

        Ok(())
    }
```


## Tools Used
Manual Review

## Recommended Mitigation Steps

Modify the function to correctly update the emergency council address:
```solidity
pub fn update_emergency_council_7_D_0_C_1_C_58(
    &mut self,
    new_council: Address,
) -> Result<(), Revert> {
    assert_eq_or!(
        msg::sender(),
        self.seawater_admin.get(),
        Error::SeawaterAdminOnly
    );

    self.emergency_council.set(new_council);  // Correct update

    Ok(())
}

```
