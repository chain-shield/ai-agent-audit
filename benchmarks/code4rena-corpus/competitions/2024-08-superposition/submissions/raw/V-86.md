# Vulnerability details

## Impact
When the pool is disabled users won't be able to remove their liquidity.

## Proof of Concept
update_position function in pool.rs requires the pool to be enabled however the comment on update_position_internal in lib.rs, which is the caller of update_position states that this check should be performed only when adding liquidity - https://github.com/code-423n4/2024-08-superposition/blob/4528c9d2dbe1550d2660dac903a8246076044905/pkg/seawater/src/lib.rs#L687.This will prevent the users from removing their liquidity when the pool is disabled.

## Tools Used
Manual Review

## Recommended Mitigation Steps
Consider checking if the pool is enabled only when the delta is >= 0
