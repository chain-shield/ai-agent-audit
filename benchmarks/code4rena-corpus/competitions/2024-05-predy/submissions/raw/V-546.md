# Vulnerability details

## Impact
`take` function in `PredyPool` can only becalled by `onlyLocker`. and there is not setter function for `onlyLocker` making it set by default to the zero address. This means `predySettlementCallback` and `predyTradeAfterCallback` are going to be redundant

## Recommended Mitigation Steps

add a setter function for `locker` just the same as the one for `operator`.
