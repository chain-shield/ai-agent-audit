# Vulnerability details

## Summary
As predypool accounting depends on ERC20(currency).balanceOf(address(this)), so an attacker can directly transfer the minimumi token(1 wei)  to the predypool to make the trade function revert.



## Proof of Concept
1. Let’s assume, trade function is called with TradeParams.tradeAmount = -100e18, TradeParams.tradeAmountSqrt = 0 by a trader. Currently, globalData.lockData.quoteReserve = 1000e18, globalData.lockData.baseReserve = 1000e18. Currently the quotetoken balance = 1000e18, the basetoken balance = 1000e18 in the predypool.

2. Before executing the trade function by trader, an attacker directly transfers 1 base token to the predypool. So currently total basetoken balance = 1000+1 = 1001e18 in the predypool.

3. See trade function(library trade), this function calls swap function with SwapStableResult.amountPerp = -(-100e18) = 100e18. SwapStableResult.amountSqrtPerp = 0, SwapStableResult.fee = 0.

4. See  function swap, here totalBaseAmount = 100e18+0+0 = 100e18. This function calls globalData.callSettlementCallback with totalBaseAmount = 100e18, settlementData

5. See  globalData.callSettlementCallback which calls predySettlementCallback(BaseMarket) with deltaBaseAmount = 100e18 and settlementData. This predySettlementCallback function calls SettlementCallbackLib.execSettlement with baseAmountDelta = 100e18 param which calls  execSettlementInternal with baseAmountDelta = 100e18. As baseAmountDelta > 0, so this calls sell function.

6.  See sell function, as  settlementParams.contractAddress == address(0), so quoteAmount = 100e18(assume), this sell function calls predyPool.take(false, sender, 100e18). 

7. See function take(library GlobalDataLibrary), as isQuoteAsset = false, so the currency is base token. So 100e18 base tokens are transferred from predypool to sender and 100e18 quote  tokens are transferred from sender to predypool.now the base token balance = 1001e18-100e18 = 901e18 and qutetoken balance = 1000+100 = 1100e18   in the predypool.

8. After That, the trade function calls the  globalData.finalizeLock() which calls  settle(globalData, true).

9. See settle function, as isQuoteAsset = false, so base token’s reservesBefore = globalData.lockData.baseReserve = 1000e18 and  reserveAfter = ERC20(currency).balanceOf(address(this)) = 901e18.  paid = reserveAfter.toInt256() - reservesBefore.toInt256() = 901e18-1000e18 = -99e18. Similarly quote token paid = 100e18.

10. So globalData.finalizeLock() returns settledBaseAmount = -99e18.  if (settledBaseAmount != -totalBaseAmount) {
            revert IPredyPool.BaseTokenNotSettled();
        }
As settledBaseAmount = -99e18 and -totalBaseAmount = -100e18 i.e both are different, so the function trade revert.


## Impact
Attackers can revert the trade function by transferring the token directly to the predypool.

## Tools Used
manual review

## Recommended Mitigation Steps
Make different accounting mechanisms, don’t depend on ERC20(currency).balanceOf(address(this)).
