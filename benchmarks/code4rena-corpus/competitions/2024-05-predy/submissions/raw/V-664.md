# Vulnerability details

## Impact
Using stale prices leads to inaccurate calculations of total asset values and share prices.

## Proof of Concept

according to the Pyth documentations, using the `getSqrtPrice` can return stale price if the price is not updated.

    /// @notice Returns the price of a price feed without any sanity checks.
    /// @dev This function returns the most recent price update in this contract without any recency checks.
    /// This function is unsafe as the returned price update may be arbitrarily far in the past.
    ///
    /// Users of this function should check the `publishTime` in the price to ensure that the returned price is
    /// sufficiently recent for their application. If you are considering using this function, it may be
    /// safer / easier to use either `getPrice` or `getPriceNoOlderThan`.
    /// @return price - please read the documentation of PythStructs.Price to understand how to use this safely.
    function getPriceUnsafe(
        bytes32 id
    ) external view returns (PythStructs.Price memory price);

The `getSqrtPrice` function doesn't verify `updatePriceFeeds`, potentially leading to outdated exchange rates, incorrect investment calculations, and distorted total asset values.

## Tools Used

Manual Review

## Recommended Mitigation Steps

Using pyth.updatePriceFeeds for updating prices, followed by pyth.getPrice for retrieval. Following the example in: https://github.com/pyth-network/pyth-sdk-solidity/blob/main/README.md#example-usage
