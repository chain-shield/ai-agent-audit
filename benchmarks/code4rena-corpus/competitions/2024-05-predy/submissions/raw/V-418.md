# Vulnerability details

## Impact
The function contains a potential DoS vulnerability. If the user has a very large number of positions, the gas required to iterate over the array and call `_getUserPosition` for each position may exceed the block gas limit, causing the transaction to fail. This issue can lead to the following problems:

- The function could become unusable for users with a large number of positions.
- Malicious users could exploit this to cause transactions to fail.
