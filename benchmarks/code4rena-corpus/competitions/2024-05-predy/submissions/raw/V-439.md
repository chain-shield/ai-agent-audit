# Vulnerability details

## Impact
When int24(tickCumulatives[1] - tickCumulatives[0]) is negative and ((tickCumulatives[1] - tickCumulatives[0]) % secondsAgo != 0 holds true, the tick will be larger than it is supposed to be leading to wrong prices that could eventually lead to trades, supply and liquidation executed at incorrect prices. 

## Proof of Concept
The `callUniswapObserve(...)` function of the UniHelper.sol is called by the `getSqrtTWAP` function which is in turn called in the `PositionCalculator.getSqrtIndexPrice(...)` function  that is used in the `autoHedge(...)`, `autoClose(...)`  and `checkAutoHedgeAndClose(...)` function of `GammaTradeMarket.sol`.


The `callUniswapObserve(...)` function below calls Uniswap oracle's `observe(...)` function to get the `tickCumulatives` array that is used to calculate the `tick`.

The main issue is that when the difference between the `tickCumulatives` element values is negative that is: 

`int24(tickCumulatives[1] - tickCumulatives[0])` is negative 

and 

`(tickCumulatives[1] - tickCumulatives[0]) % secondsAgo != 0` holds true, 

Then the tick should be rounded down this way `tick--` as done in the [Uniswap oracle library here](https://github.com/Uniswap/v3-periphery/blob/697c2474757ea89fec12a4e6db16a574fe259610/contracts/libraries/OracleLibrary.sol#L36)

Decrementing the `tick` will round it down towards negative infinity but it is not done here in the `callUniswapObserve` function for negative values of `int24((tickCumulatives[1] - tickCumulatives[0])`.
 
```solidity
File: UniHelper.sol
function callUniswapObserve(IUniswapV3Pool uniswapPool, uint256 ago) internal view returns (uint160, uint256) {
        uint32[] memory secondsAgos = new uint32[](2);

        secondsAgos[0] = uint32(ago);
        secondsAgos[1] = 0;

        (bool success, bytes memory data) =
            address(uniswapPool).staticcall(abi.encodeWithSelector(IUniswapV3PoolOracle.observe.selector, secondsAgos));

        if (!success) {
            if (keccak256(data) != keccak256(abi.encodeWithSignature("Error(string)", "OLD"))) {
                revertBytes(data);
            }

            (,, uint16 index, uint16 cardinality,,,) = uniswapPool.slot0();

            (uint32 oldestAvailableAge,,, bool initialized) = uniswapPool.observations((index + 1) % cardinality);

            if (!initialized) {
                (oldestAvailableAge,,,) = uniswapPool.observations(0);
            }

            ago = block.timestamp - oldestAvailableAge;
            secondsAgos[0] = uint32(ago);

            (success, data) = address(uniswapPool).staticcall(
                abi.encodeWithSelector(IUniswapV3PoolOracle.observe.selector, secondsAgos)
            );
            if (!success) {
                revertBytes(data);
            }
        }

        int56[] memory tickCumulatives = abi.decode(data, (int56[]));

        int24 tick = int24((tickCumulatives[1] - tickCumulatives[0]) / int56(int256(ago)));//FINDING: NO ROUNDING DOWN WHEN tickCumulatives[1] - tickCumulatives[0] IS NEGATIVE

        uint160 sqrtPriceX96 = TickMath.getSqrtRatioAtTick(tick);

        return (sqrtPriceX96, ago);
    }

```
