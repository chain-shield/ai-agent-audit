# Vulnerability details

## Impact
When a protocol `rounds down` in favor of the user, this only results in `value leak` from the protocol itself.

## Proof of Concept
During withdrawal, user's `bond` tokens get [burned](https://github.com/code-423n4/2024-05-predy/blob/a9246db5f874a91fb71c296aac6a66902289306a/src/libraries/logic/SupplyLogic.sol#L79-L91) in in exchange for the tokens being withdrawn. (`quoteToken` or `baseToken`).
```solidity
    function burnBondAndTransferToken(Perp.AssetPoolStatus storage _pool, uint256 _amount)
        internal
        returns (uint256 finalburntAmount, uint256 finalWithdrawalAmount)
    {
        address supplyTokenAddress = _pool.supplyTokenAddress;


        (finalburntAmount, finalWithdrawalAmount) =
            _pool.tokenStatus.removeAsset(ERC20(supplyTokenAddress).balanceOf(msg.sender), _amount);


        ISupplyToken(supplyTokenAddress).burn(msg.sender, finalburntAmount);


        ERC20(_pool.token).safeTransfer(msg.sender, finalWithdrawalAmount);
    }
```
This function makes a call to [_pool.tokenStatus.removeAsset()](https://github.com/code-423n4/2024-05-predy/blob/a9246db5f874a91fb71c296aac6a66902289306a/src/libraries/ScaledAsset.sol#L55-L63) which acually calculates the amount of `bond` tokens to be burned.

```solidity
        require(_supplyTokenAmount > 0, "S3");


        uint256 burnAmount = FixedPointMathLib.mulDivDown(_amount, Constants.ONE, tokenState.assetScaler); // @audit-issue Rounded down


        if (_supplyTokenAmount < burnAmount) {
            finalBurnAmount = _supplyTokenAmount;
        } else {
            finalBurnAmount = burnAmount;
        }
```
As seen above, the `burnAmount` is rounded down here instead of up. This works in favor of the user and against protocol.

##### Example:
If say, the value calculated is `1000.9`, the `.9` will be truncated and only `1000` bond tokens of the user will be burned. This `leaked value` grows exponentially with the number of users and withdrawals made.

## Tools Used
Manual Review

## Recommended Mitigation Steps
Always round against the user.

```diff
-       uint256 burnAmount = FixedPointMathLib.mulDivDown(_amount, Constants.ONE, tokenState.assetScaler);
+       uint256 burnAmount = FixedPointMathLib.mulDivUp(_amount, Constants.ONE, tokenState.assetScaler);
```
