# Vulnerability details

## Impact
The `AddPairLogic::initializeGlobalData` is used to set global.uniswapFactory when a new PredyPool is initialized. The problem is that everyone can call the `AddPairLogic::initializeGlobalData` after the Pool is initialized and change the address of the UniswapFactory.

## Proof of Concept
`AddPairLogic::initializeGlobalData` is missing the `onlyInitializing` modifier allowing anyone to call it after initialization.

```solidity
 function initializeGlobalData(GlobalDataLibrary.GlobalData storage global, address uniswapFactory) external {
        global.pairsCount = 1;
        global.vaultCount = 1;
        global.uniswapFactory = uniswapFactory;
    }

```
