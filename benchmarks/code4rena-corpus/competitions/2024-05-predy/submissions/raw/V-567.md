# Vulnerability details

## Impact

The absence of `validateIRMParams` in the `_storePairStatus` function allows malicious actors to add pairs with arbitrary interest rate model parameters.

## Proof of Concept

A malicious user calls `addPair` with manipulated `quoteIrmParams` and `baseIrmParams`.
These parameters are not validated in `_storePairStatus`.

The malicious user sets extremely high or low interest rates, exploiting the system

## Recommended Mitigation Steps

Add Validation in `_storePairStatus`: Ensure `validateIRMParams` is called for both `quoteIrmParams` and `baseIrmParams` within `_storePairStatus`.

```diff
  function _storePairStatus(
        address quoteToken,
        mapping(uint256 => DataType.PairStatus) storage _pairs,
        uint256 _pairId, //counted global pair
        address _tokenAddress,
        bool _isQuoteZero,
        AddPairParams memory _addPairParam
    ) internal {
        validateRiskParams(_addPairParam.assetRiskParams);
        validateFeeRatio(_addPairParam.fee);
++      validateIRMParams(_addPairParam.quoteIrmParams)
++      validateIRMParams(_addPairParam.baseIrmParams)

        require(_pairs[_pairId].id == 0, "AAA");

        _pairs[_pairId] = DataType.PairStatus(
            _pairId,// which is the pair count for initally is 1
            quoteToken,
            _addPairParam.poolOwner,
            Perp.AssetPoolStatus(
                quoteToken,
                deploySupplyToken(quoteToken),
                ScaledAsset.createAssetStatus(),
                _addPairParam.quoteIrmParams,
                0,
                0
            ),
            Perp.AssetPoolStatus(
                _tokenAddress,
                deploySupplyToken(_tokenAddress),
                ScaledAsset.createAssetStatus(),
                _addPairParam.baseIrmParams,
                0,
                0
            ),
            _addPairParam.assetRiskParams,
            Perp.createAssetStatus(
                _addPairParam.uniswapPool,
                -_addPairParam.assetRiskParams.rangeSize,
                _addPairParam.assetRiskParams.rangeSize
            ),
            _addPairParam.priceFeed,
            _isQuoteZero,
            _addPairParam.allowlistEnabled,
            _addPairParam.fee, // 20
            block.timestamp
        );

        emit AssetRiskParamsUpdated(_pairId, _addPairParam.assetRiskParams);
        emit IRMParamsUpdated(_pairId, _addPairParam.quoteIrmParams, _addPairParam.baseIrmParams);
    }
```
