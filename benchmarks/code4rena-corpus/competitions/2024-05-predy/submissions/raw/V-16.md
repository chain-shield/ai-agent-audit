# Vulnerability details

## Impact
The uninitialized-local vulnerability occurs when a local variable within a function is not initialized before being used. This can lead to unpredictable behavior and potential security risks in the code. Attackers may exploit this vulnerability by manipulating the uninitialized variable to gain unauthorized access, modify data, or disrupt the application's normal operation. It is important to always initialize local variables before using them to ensure the stability and security of the code.
