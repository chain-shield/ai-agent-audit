# Vulnerability details

Solidity rounds down the result of an integer division, and because of that, it is always recommended to multiply before dividing to avoid that precision loss. In the case of a prior division over multiplication, the final result may face serious precision loss as the first answer would face truncated precision and then multiplied to another integer.

In PriceFeed.sol we have a function getSqrtPrice(). This function is responsible for sqrtPrice return. However in the calculation we can see that precision loss is presented.

## Impact
Every time when getSqrtPrice() is called, the return value will be subject of precision loss.

## Proof of Concept
https://github.com/code-423n4/2024-05-predy/blob/a9246db5f874a91fb71c296aac6a66902289306a/src/PriceFeed.sol#L54-L55

```
uint256 price = uint256(int256(basePrice.price)) * Constants.Q96 / uint256(quoteAnswer);
```
When performing the division steps in the code, any remainder from the division operation is discarded, leading to precision loss.
For example: (3*3)/2=4 instead of 4.5
```
price = price * Constants.Q96 / _decimalsDiff;
```
Multiplying by a large constant like Constants.Q96 can result in multiplying the precision loss.

In the code, multiplication is followed by division and then we can see the multiplication and division again. In the first division we will have precision loss and the following multiplication will make the precision loss even bigger.

## Recommended Mitigation Steps
Multiplication should be performed first and then division at the end.
For example:
```
function getSqrtPrice() external view returns (uint256 sqrtPrice) {
        (, int256 quoteAnswer,,,) = AggregatorV3Interface(_quotePriceFeed).latestRoundData();

        IPyth.Price memory basePrice = IPyth(_pyth).getPriceNoOlderThan(_priceId, VALID_TIME_PERIOD);

        require(basePrice.expo == -8, "INVALID_EXP");

        require(quoteAnswer > 0 && basePrice.price > 0);

-       uint256 price = uint256(int256(basePrice.price)) * Constants.Q96 / 
-       uint256(quoteAnswer);
-       price = price * Constants.Q96 / _decimalsDiff;

+       uint256 price = (uint256(int256(basePrice.price)) * Constants.Q96 * 
+       Constants.Q96) / (uint256(quoteAnswer) * _decimalsDiff);

        sqrtPrice = FixedPointMathLib.sqrt(price);
    }
```
