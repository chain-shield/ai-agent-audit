# Vulnerability details

## Summary
The `updateWhitelistFiller` and `updateWhitelistSettlement` functions in the `BaseMarketUpgradeable` contract are intended to be callable only by the contract owner. However, they can currently be called by the whitelist filler, which poses significant security risks.

## Vulnerability Detail
The `updateWhitelistFiller` and `updateWhitelistSettlement` functions are documented to be accessible only by the contract owner. In reality, these functions can be executed by the whitelist filler. This discrepancy allows the whitelist filler to update the whitelist filler address and the whitelist settlement addresses. Consequently, a malicious filler could exploit this to gain unauthorized control over these critical addresses, potentially compromising the contract's security and functionality.

## Impact
Allowing the whitelist filler to call `updateWhitelistFiller` and `updateWhitelistSettlement` functions can lead to serious security issues, such as:
1. The filler could change the whitelist filler address to a malicious address, gaining further control over the contract.
2. The filler could manipulate the whitelist settlement addresses, leading to unauthorized transactions and potential loss of assets.

## Code Snippet
```solidity
/**
 * @notice Updates the whitelist filler address
 * @dev only owner can call this function
 */
function updateWhitelistFiller(
    address newWhitelistFiller
) external onlyFiller {
    whitelistFiller = newWhitelistFiller;
}
```

And:

```solidity
/**
 * @notice Updates the whitelist settlement address
 * @dev only owner can call this function
 */
function updateWhitelistSettlement(
    address settlementContractAddress,
    bool isEnabled
) external onlyFiller {
    _whiteListedSettlements[settlementContractAddress] = isEnabled;
}
```

## Tool used
Manual Review

## Recommendation
Modify the access control of the `updateWhitelistFiller` and `updateWhitelistSettlement` functions to ensure that only the contract owner can call them. This can be done by replacing the `onlyFiller` modifier with the `onlyOwner`modifier (the contract should then inherit `Ownable` implementation.
