# Vulnerability details

## Impact
Since everyone can register a pair in `PredyPool`, the pair owner is not considered as a trusted admin. Anyone trading with the pair have to have trust in the pair owner.

A malicious pair owner could set unfavorable configs to users such as:
- Wrong price feed to liquidate users' position.
- Unrealistic interest rate that users have not knew before opening a position. Then the owner will benefit from the interest fee.

## Tools Used
Manual Review.

## Recommended Mitigation Steps
When the pair owner changes the pair's configs, it should happen in two steps:
1. The pair owner registers a new config to `PredyPool`. But the new config has not take effect yet.
2. The pair owner has to wait for a duration, then he can finalize the new config for it to be effective.

During that duration, if users saw the new config is unreasonable then they can close their position to exist from the pair.
