# Vulnerability details

## Impact
Chainlink aggregators have a built-in circuit breaker to prevent the price of an asset from deviating outside a predefined price range. This circuit breaker may cause the oracle to persistently return the minPrice instead of the actual asset price in the event of a significant price drop, as witnessed during the LUNA crash.

## Proof of Concept
PriceFeed::latestRoundData extracts the linked aggregator and requests round data from it. If an asset's price falls below the minPrice, the protocol continues to value the token at the minPrice rather than its real value. This discrepancy could result in user getting liquidated early or executing the order at a uneven price.

For instance, if TokenA's minPrice is $1 and its price falls to $0.10, the aggregator continues to report $1, rendering the related function calls to entail a value that is ten times the actual value.

It's important to note that while Chainlink oracles form part of the Price Feed system  since we use different oracles for different base/quote token price fetching. but the prices can be disrupted if one of the prices is wrong from a particular oracle.

## Tools Used
Chainlink

## Recommended Mitigation Steps
```diff
 (, int256 quoteAnswer,,,) = AggregatorV3Interface(_quotePriceFeed).latestRoundData();
+ if (quoteAnswer >= maxPrice or quoteAnswer <= minPrice) revert();
```
This ensures that a false price will not be returned if the underlying asset's value hits the minPrice.
