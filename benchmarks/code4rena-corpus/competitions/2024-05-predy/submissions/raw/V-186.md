# Vulnerability details

## Impact
An uninitialized contract can be taken over by an attacker.


## Proof of Concept
https://github.com/code-423n4/2024-05-predy/blob/a9246db5f874a91fb71c296aac6a66902289306a/src/PredyPool.sol#L68

```solidity
     constructor() {}
```

## Tools Used
Manual review

## Recommended Mitigation Steps
https://docs.openzeppelin.com/contracts/4.x/api/proxy#Initializable-_disableInitializers--
Call the _disableInitializers method in the constructor of the PredyPool.sol

```diff
constructor() {
 +   _disableInitializers()
}
```
Note - This issue is present in the following Smart Contracts:
- PredyPool.sol
- BaseHookCallbackUpgradeable.sol
- BaseMarketUpgradeable.sol
- GammaTradeMarket.sol
- PerpMarketV1.sol
