# Vulnerability details

## Impact

The difference in `BaseMarket.sol` and `BaseMarketUpgradable.sol` storage layout will cause data misalignment and state variable corruption.

## Proof of Concept

1. To inspect the storage slots in `BaseMarket.sol`

3. The inspections above show

Slot2:
BaseMarket has \_quoteTokenMap (a mapping) at slot 2.
BaseMarketUpgradable has \_quoter (a contract reference) at slot 2.

Slot3:
BaseMarket has \_whiteListedSettlements (a mapping) at slot 3.
BaseMarketUpgradable has \_quoteTokenMap (a mapping) at slot 3.

4. The cause is immutables are not stored in the storage. In `BaseMarket.sol:_quoter` is immutable, whereas `BaseMarketUpgradable.sol:_quoter` is not.

## Tools Used

Manual & Foundry

## Recommended Mitigation Steps

Update BaseMarketUpgradable.sol

```diff
    address public whitelistFiller;

-    PredyPoolQuoter internal _quoter;
+    PredyPoolQuoter internal immutable _quoter;

    mapping(uint256 pairId => address quoteTokenAddress) internal _quoteTokenMap;

    mapping(address settlementContractAddress => bool) internal _whiteListedSettlements;
```
