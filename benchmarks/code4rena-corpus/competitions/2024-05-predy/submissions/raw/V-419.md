# Vulnerability details

## Impact
There are instances where a function takes a uint256 as an input parameter and within the function is downcasted to a much smaller uint .
This is a problem because if the result of `(liquidityAmount * sqrtRatioB) / (liquidityAmount - denominator1)`  is bigger than uint160 , then only the least significant 160 bits will be used. And `sqrtPrice` will be wrong.
