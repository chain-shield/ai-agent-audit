# Vulnerability details

## summary
If any long positions are not opened for a pairid, then quote token’s totalNormalDeposited will be always 0 and if any short positions are not opened for a pairid, then base token’s totalNormalDeposited will be always 0 . if totalNormalDeposited = 0 for a token, then tokenState.assetScaler will not be updated for this token.

## Proof of Concept
1. Let’s assume, a pairid’s quote tokens = 1000e18, base tokens = 500e18 deposited by lenders in predypool. So the quote token’s  totalCompoundDeposited = 1000e18 and base token’s totalCompoundDeposited = 500e18.here 1 quotetoken = 1 base token.

2. Now Alice opens a long position in prepmarket with 500e18 quantity, as position is long, so 500e18 base tokens are transferred to filler from predypool and 500e18 quote tokens are transferred to predypool. So now base token’s totalNormalBorrowed = 500e18 and quote token’s totalNormalDeposited = 500e18.

3. See   function updateScaler, tokenState.assetScaler for a token is only updated when totalCompoundDeposited and totalNormalDeposited both are non zero.

4. Now if short positions are not opened  for this pairid, then  base token’s totalNormalDeposited will be always 0. As totalNormalDeposited will be always 0 for base token, so base token’s assetScaler will not be updated. So lenders will not get the interest.

## impact
Lenders may not get rewards for supplying tokens in predypool.
