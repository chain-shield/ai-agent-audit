## Proof of Concept
The function [trade()](https://github.com/code-423n4/2024-05-predy/blob/main/src/libraries/Trade.sol#L49) in `Trade.sol` is fetching the `sqrtPrice` from the [getSqrtPrice](https://github.com/code-423n4/2024-05-predy/blob/main/src/libraries/Trade.sol#L112C5-L114C6) internal function which is calling convertSqrtPrice from Unihelper.sol which further fetches the price from the slot0.

```solidity
  function getSqrtPrice(address uniswapPoolAddress, bool isQuoteZero) internal view returns (uint256 sqrtPriceX96) {
        return UniHelper.convertSqrtPrice(UniHelper.getSqrtPrice(uniswapPoolAddress), isQuoteZero);
    }
```

```solidity
 function getSqrtPrice(address uniswapPoolAddress) internal view returns (uint160 sqrtPrice) {
        (sqrtPrice,,,,,,) = IUniswapV3Pool(uniswapPoolAddress).slot0();
    }
```

The spot price fetched from the slot0 can be easily manipulated by flash loans and so the trade [ calculateStableAmount](https://github.com/code-423n4/2024-05-predy/blob/main/src/libraries/Trade.sol#L116-L120) amount calculated will be an inflated price fetched from the slot0, leading to price manipulation for the trades done.
