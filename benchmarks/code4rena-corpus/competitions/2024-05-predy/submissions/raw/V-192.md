# Vulnerability details

## Impact
`BaseMarketUpgradable.execLiquidationCall`, the `closeRatio` parameter, which is expected to be a value between 0 and 1e18 (100%). The function does not validate or enforce this range, allowing any value to be passed as `closeRatio`.

If a value greater than 1e18 is passed as `closeRatio`, it could lead to unexpected behavior or potential vulnerabilities in the `_predyPool.execLiquidationCall` function, as it may not be designed to handle such values.

**Impact on Liquidation Process**
The `closeRatio` parameter is used to determine the portion of the vault's position that should be liquidated. It is expected to be a value between 0 and 1e18 (100%), representing the percentage of the position to be closed. If a value greater than 1e18 is passed, it could result in unexpected behavior or errors within the `_predyPool.execLiquidationCall` function, as it may not be designed to handle such invalid values.

**Potential Vulnerabilities**
Allowing an arbitrary value for `closeRatio` could potentially lead to vulnerabilities or exploits in the system. For example, if the `_predyPool.execLiquidationCall` function performs calculations or operations based on the `closeRatio` value, an attacker could potentially manipulate the value to cause integer overflows, underflows, or other arithmetic errors, leading to unintended consequences or potential fund losses.

## Recommended Mitigation Steps
It would be recommended to add a validation check for the `closeRatio` parameter before calling `_predyPool.execLiquidationCall`. For example:
```solidity
function execLiquidationCall(
    uint256 vaultId,
    uint256 closeRatio,
    IFillerMarket.SettlementParamsV3 memory settlementParams
) external virtual returns (IPredyPool.TradeResult memory) {
    require(closeRatio <= 1e18, "Invalid closeRatio value");

    return _predyPool.execLiquidationCall(
        vaultId,
        closeRatio,
        _getSettlementDataFromV3(settlementParams, msg.sender)
    );
}
```
By adding the check, the function will revert if an invalid `closeRatio` value is provided, preventing potential issues and ensuring the correctness of the liquidation process.
