# Vulnerability details

## Impact
InterestRateModel.calculateInterestRate is wrongly calculated as per the docs.

## Proof of Concept
According to the docs interest rate is calculated as ``Base + U.Slope1`` if utilization ratio is lesser than kinkRate and interest rate is calculated as ``
Base + kinkRate.Slope1 + (U - kinkRate).slope2`` if utilization ratio is greater equal to kinkRate.
```solidity
The interest rate R follows the model:
R = Base + U.Slope1 (U < kinkRate)
R = Base + kinkRate.Slope1 + (U - kinkRate).slope2 (U >= kinkRate)
```

But in the implementation of code ``Base + U.Slope1`` is calculated if ``(utilizationRatio <= irmParams.kinkRate)`` and the docs stated it should be calculated only if utilizationRatio is strictly lesser than kinkRate. whereas the interest rate calculated as ``Base + kinkRate.Slope1 + (U - kinkRate).slope2``if 
utilizationRatio  is strictly lesser than the kinkRate but as per the docs it should be calculated if utilizationRatio is lesser or equal to kinkRate.

```solidity
 if (utilizationRatio <= irmParams.kinkRate) {
            ir += (utilizationRatio * irmParams.slope1) / _ONE;
        } else {
            ir += (irmParams.kinkRate * irmParams.slope1) / _ONE;
            ir += (irmParams.slope2 * (utilizationRatio - irmParams.kinkRate)) / _ONE;
        }
```
Therefore, when ``utilizationRatio == kinkRate`` is wrongly calculated by the formula ``Base + U.Slope1`` instead of using ``Base + kinkRate.Slope1 + (U - kinkRate).slope2`` as per the docs stated.

## Recommended Mitigation Steps
Change the operator as below.
```diff 
-   if (utilizationRatio <= irmParams.kinkRate) {
            ir += (utilizationRatio * irmParams.slope1) / _ONE;
        } else {
            ir += (irmParams.kinkRate * irmParams.slope1) / _ONE;
            ir += (irmParams.slope2 * (utilizationRatio - irmParams.kinkRate)) / _ONE;

+  if (utilizationRatio < irmParams.kinkRate) {
            ir += (utilizationRatio * irmParams.slope1) / _ONE;
        } else {
            ir += (irmParams.kinkRate * irmParams.slope1) / _ONE;
            ir += (irmParams.slope2 * (utilizationRatio - irmParams.kinkRate)) / _ONE;
```
