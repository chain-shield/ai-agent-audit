# Vulnerability details

According to the docs:
*"Liquidator
When a trader's position meets the conditions for liquidation, the Liquidator forcibly closes the position. Liquidators can earn profits from the differences in the liquidation process."*

Also
*"As slippageTolerance increases, the difference between the market price and the liquidation price also grows, thereby providing a greater incentive for the liquidator."*

But there is nothing that is being sent to the liquidator in the whole process of liquidation.

## Proof of Concept
The function executes a liquidation call to close an unsafe vault.
```solidity
File: PredyPool.sol

  function execLiquidationCall(uint256 vaultId, uint256 closeRatio, bytes memory settlementData)
        external
        nonReentrant
        returns (TradeResult memory tradeResult)
    {
        return LiquidationLogic.liquidate(vaultId, closeRatio, globalData, settlementData);
    }
```
As we can see inside the `liquidate()` that if the given vault is in danger, the remaining margin is sent to the `vault.recipient` which is the owner of the vault (unless changed by the vault owner themselves).
```solidity
File: LiquidationLogic

     function liquidate(
      ...
      if (!hasPosition) {
            int256 remainingMargin = vault.margin;

            if (remainingMargin > 0) {
                if (vault.recipient != address(0)) {
                    // Send the remaining margin to the recipient.
                    vault.margin = 0;

                    sentMarginAmount = uint256(remainingMargin);

                    ERC20(pairStatus.quotePool.token).safeTransfer(vault.recipient, sentMarginAmount);
                }
            } else if (remainingMargin < 0) {
                vault.margin = 0;

                // To prevent the liquidator from unfairly profiting through arbitrage trades in the AMM and passing losses onto the protocol,
                // any losses that cannot be covered by the vault must be compensated by the liquidator
                ERC20(pairStatus.quotePool.token).safeTransferFrom(msg.sender, address(this), uint256(-remainingMargin));
            }
        }
```
We can also see that if the liquidator tries to profit through arbitrages, the liquidator end up paying the remaining margin.

## Impact
In the whole liquidation process, the liquidator is at a loss unless the liquidator is the owner of the of the vault themselves in which case the margin gets sent to them.
Even in case of successful liquidation, the liquidators would end paying losing in terms of gas fees as they are provided nothing in return.
