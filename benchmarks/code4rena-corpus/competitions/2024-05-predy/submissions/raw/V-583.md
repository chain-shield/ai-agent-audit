# Vulnerability details

## Impact

The used `totalProtocolFee` would be more than its actual value.
It would decrease the total pool value based on the error value accumulated over a period of time since the fee is withdrawn by the operator and pool owner in the form of the pool.token.

## Proof of Concept
[applyInterestForPoolStatus](https://github.com/code-423n4/2024-05-predy/blob/a9246db5f874a91fb71c296aac6a66902289306a/src/libraries/ApplyInterestLib.sol#L50-L73) is library function and does the following actions.

1. Checking that the current timestamp is later than the last update.

2. Retrieving and checking the utilization ratio.

3. Calculating the interest rate based on the utilization ratio and elapsed time.

4. Updating the total protocol fee based on the interest rate and fee.

5. Distributing the protocol fee equally between protocol revenue and creator revenue.

This function would be used during the trade and other operations.

for example - gamma trade : [_executeTrade](https://github.com/code-423n4/2024-05-predy/blob/a9246db5f874a91fb71c296aac6a66902289306a/src/markets/gamma/GammaTradeMarket.sol#L163-L176)-> [trade](https://github.com/code-423n4/2024-05-predy/blob/a9246db5f874a91fb71c296aac6a66902289306a/src/PredyPool.sol#L278)->[refer](https://github.com/code-423n4/2024-05-predy/blob/a9246db5f874a91fb71c296aac6a66902289306a/src/libraries/logic/TradeLogic.sol#L35-L38) -> [refer](https://github.com/code-423n4/2024-05-predy/blob/a9246db5f874a91fb71c296aac6a66902289306a/src/libraries/ApplyInterestLib.sol#L31-L47) -> [applyInterestForPoolStatus](https://github.com/code-423n4/2024-05-predy/blob/a9246db5f874a91fb71c296aac6a66902289306a/src/libraries/ApplyInterestLib.sol#L71-L73)

```solidity
        totalProtocolFee = poolStatus.tokenStatus.updateScaler(interestRate, fee);

        poolStatus.accumulatedProtocolRevenue += totalProtocolFee / 2;
        poolStatus.accumulatedCreatorRevenue += totalProtocolFee / 2;
```

As shown above the `totalProtocolFee` is divided and shared between the protocol and the creator.

Lets see this division with some numbers.

assume the  totalProtocolFee is 1500 (ignore the decimals)

When it is divided by 2 two times, we would get 1000 and 1000.

So the total `totalProtocolFee` would be 2000 which is higher than the actual value.
