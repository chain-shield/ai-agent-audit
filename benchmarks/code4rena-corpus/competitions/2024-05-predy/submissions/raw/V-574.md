# Vulnerability details


## Impact
In the PriceFeed.sol, The function `getSqrtPrice` uses the chainlink `AggregatorV3Interface` to get the `quoteprice` which is then calculated with the `basePrice`, however some issues have been unhandled. 

- There is no staleness check for prices returned from the chainlink oracle: The updateAt param from `latestRoundData()` refers to the timestamp of the round. This value isn’t checked to make sure it is recent.
- There is no check if the `quoteprice` is equal the minPrice which is the lowest possible price for an asset. 


This two issues can lead to wrong prices being computed by the pricefeed contract, and leading to overcharging or undercharging users

## Recommended Mitigation Steps

Set a max threshold for ``updateAt``. If `block.timestamp - updateAt` exceeds that threshold, revert the transaction
Also, fetch the minAnswer and revert if price has hit that value.
