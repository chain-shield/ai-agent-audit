# Vulnerability details

## Impact
The absence of a nonce in the `hash` calculation for `GammaModifyInfo` can make the protocol vulnerable to replay attacks. An attacker could reuse a previously used GammaModifyInfo object to execute the same operation multiple times, leading to potential loss of funds or unintended behavior.

```javascript
struct GammaModifyInfo {
    bool isEnabled;
    uint256 expiration;
    uint256 maximaDeviation;
    uint256 lowerLimit;
    uint256 upperLimit;
    uint256 hedgeInterval;
    uint256 sqrtPriceTrigger;
    uint256 minSlippageTolerance;
    uint256 maxSlippageTolerance;
    uint256 auctionPeriod;
    uint256 auctionRange;
}

bytes32 internal constant GAMMA_MODIFY_INFO_TYPE_HASH = keccak256("GammaModifyInfo(bool,uint256,uint256,uint256,uint256,uint256,uint256,uint256,uint256,uint256,uint256)");

/// @notice hash a GammaModifyInfo object
/// @param info The GammaModifyInfo object to hash
function hash(GammaModifyInfo memory info) internal pure returns (bytes32) {
    return keccak256(
        abi.encode(
            GAMMA_MODIFY_INFO_TYPE_HASH,
            info.isEnabled,
            info.expiration,
            info.maximaDeviation,
            info.lowerLimit,
            info.upperLimit,
            info.hedgeInterval,
            info.sqrtPriceTrigger,
            info.minSlippageTolerance,
            info.maxSlippageTolerance,
            info.auctionPeriod,
            info.auctionRange
        )
    );
}
```

## Proof of Concept

The `GammaModifyInfo` struct lacks a `nonce`, which means that the hash function will produce the same result for identical GammaModifyInfo objects.
An attacker can replay the same GammaModifyInfo object multiple times, leading to potential exploits.
Example Attack Scenario:

An attacker submits a `GammaModifyInfo` object with specific parameters.
The protocol processes this object, performing the corresponding operations.
The attacker then reuses the same `GammaModifyInfo` object to execute the same operations again, as the hash remains unchanged due to the missing `nonce`.
This can result in repeated and unintended execution of operations.

## Recommended Mitigation Steps
Add a nonce to the GammaModifyInfo struct and incorporate it into the hash calculation.

```javascript
function hash(GammaModifyInfo memory info) internal pure returns (bytes32) {
    return keccak256(
        abi.encode(
            GAMMA_MODIFY_INFO_TYPE_HASH,
            info.isEnabled,
            info.expiration,
            info.maximaDeviation,
            info.lowerLimit,
            info.upperLimit,
            info.hedgeInterval,
            info.sqrtPriceTrigger,
            info.minSlippageTolerance,
            info.maxSlippageTolerance,
            info.auctionPeriod,
            info.auctionRange,
            info.nonce  // Include nonce here
        )
    );
}
```
