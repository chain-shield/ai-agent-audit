# Vulnerability details

## Impact
According to [protocol](https://docs.predy.finance/predy-v6/dev/architecture#filler):
> The Filler is responsible for actually submitting and executing the Trade's orders on the blockchain. The Filler can determine the token exchange route.

In `BaseMarketUpgradable` contract however, the `Filler` is tasked with:
1. Updating the whitelist filler address
2. Updating the whitelist settlement address

This is not correctly done because these are tasks reserved for `onlyOwner` as done in `BaseMarket` contract.

## Vulnerability Details
In `BaseMarket` contract, [updateWhitelistFiller()](https://github.com/code-423n4/2024-05-predy/blob/a9246db5f874a91fb71c296aac6a66902289306a/src/base/BaseMarket.sol#L84-L86) and [updateWhitelistSettlement()](https://github.com/code-423n4/2024-05-predy/blob/a9246db5f874a91fb71c296aac6a66902289306a/src/base/BaseMarket.sol#L92-L94) are callable by `onlyOwner`:
```solidity
    // @dev only owner can call this function
    function updateWhitelistFiller(address newWhitelistFiller) external onlyOwner {
        whitelistFiller = newWhitelistFiller;
    }

    // @dev only owner can call this function
    function updateWhitelistSettlement(address settlementContractAddress, bool isEnabled) external onlyOwner {
        _whiteListedSettlements[settlementContractAddress] = isEnabled;
    }
```
As seen, both comments and actual implementation are in sync.

However, in `BaseMarketUpgradable` contract, the `Filler` is tasked with them when the developer comment also states clealy that `only owner can call this function`.

[updateWhitelistFiller()](https://github.com/code-423n4/2024-05-predy/blob/a9246db5f874a91fb71c296aac6a66902289306a/src/base/BaseMarketUpgradable.sol#L128-L130) and [updateWhitelistSettlement()](https://github.com/code-423n4/2024-05-predy/blob/a9246db5f874a91fb71c296aac6a66902289306a/src/base/BaseMarketUpgradable.sol#L140-L142)
```solidity
    // @dev only owner can call this function
    function updateWhitelistFiller(address newWhitelistFiller) external onlyFiller {
        whitelistFiller = newWhitelistFiller;
    }

    // @dev only owner can call this function
    function updateWhitelistSettlement(address settlementContractAddress, bool isEnabled) external onlyFiller {
        _whiteListedSettlements[settlementContractAddress] = isEnabled;
    }
```

This is against the roles outlined for the `Filler` and does not reflect proper gorvenance within the protocol.
