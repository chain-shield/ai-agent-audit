# Vulnerability details

# Title
latestRoundData might return stale results 



## Impact
https://github.com/code-423n4/2024-05-predy/blob/main/src/PriceFeed.sol#L45C5-L58C6

`PriceFeed.sol:PriceFeed::getSqrtPrice()` uses the oracle method `latestRoundData()`. However, the function receives and checks only the **price** and neither `roundID` nor `timeStamp` is checked, which leads to irrelevant prices.


```solidity 
function getSqrtPrice() external view returns (uint256 sqrtPrice) {
        (, int256 quoteAnswer,,,) = AggregatorV3Interface(_quotePriceFeed).latestRoundData();

        IPyth.Price memory basePrice = IPyth(_pyth).getPriceNoOlderThan(_priceId, VALID_TIME_PERIOD);

        require(basePrice.expo == -8, "INVALID_EXP");

        require(quoteAnswer > 0 && basePrice.price > 0);

        uint256 price = uint256(int256(basePrice.price)) * Constants.Q96 / uint256(quoteAnswer);
        price = price * Constants.Q96 / _decimalsDiff;

        sqrtPrice = FixedPointMathLib.sqrt(price);
    }
```

If there is a problem with chainlink starting a new round and finding consensus on the new value for the oracle (e.g. chainlink nodes abandon the oracle, chain congestion, vulnerability/attacks on the chainlink system) consumers of this contract may continue using outdated stale data (if oracles are unable to submit no new round is started)

This price is used in the dividers, if the price is not correct, users may receive an incorrectly calculated price 

This function is used in many pricing functions, for example, margin calculation will be incorrect, as well as it can be used by an attacker

## Recommended Mitigation Steps
To check the valid price, the `IPyth.getPriceNoOlderThan()` method is used which returns the price not older than the specified age (`VALID_TIME_PERIOD == 5 minutes`)in seconds from the current time . It ensures that the data is fresh. 

And this check should be applied to `quotePrice`

The return value updatedAt contains the timestamp at which the received price was last updated, and can be used to ensure that the price is not outdated. See more information about latestRoundID in the Chainlink [docs](https://docs.chain.link/data-feeds/api-reference#latestrounddata). 

It is recommended to establish confidence intervals for the `roundId` and
`updatedAt` parameters and reject any Chainlink data feed response which
falls outside those ranges

```solidity 
 function getSqrtPrice() external view returns (uint256 sqrtPrice) {
->      (uint80 roundId, int256 quoteAnswer,,uint256 updateTime,) = AggregatorV3Interface(_quotePriceFeed).latestRoundData();

        IPyth.Price memory basePrice = IPyth(_pyth).getPriceNoOlderThan(_priceId, VALID_TIME_PERIOD);

        require(basePrice.expo == -8, "INVALID_EXP");

        require(quoteAnswer > 0 && basePrice.price > 0);
->      require(block.timestamp <= updatedTime + VALID_TIME_PERIOD)  
        uint256 price = uint256(int256(basePrice.price)) * Constants.Q96 / uint256(quoteAnswer);
        price = price * Constants.Q96 / _decimalsDiff;

        sqrtPrice = FixedPointMathLib.sqrt(price);
    }
```
