# Vulnerability details

## Impact
According to the [protocol](https://docs.predy.finance/predy-v6/dev/architecture#lender): 
```solidity
A Lender is a user who provides tokens to Predy. 
These provided tokens are borrowed by traders when they open positions. 
Traders pay interest to the Lender, and in return, the Lender provides leverage to the traders.
```
This is done via the [supply()](https://github.com/code-423n4/2024-05-predy/blob/a9246db5f874a91fb71c296aac6a66902289306a/src/PredyPool.sol#L222-L228) function which allows `lenders` to deposit either `quoteToken` or `baseToken` to the lending pool and receive `bond` tokens in return.
These `bond` tokens are minted to the `lender` and tracked via the `ERC20(supplyTokenAddress).balanceOf(msg.sender)`.

However, during withdrawal, there is no accounting for any `interests` earned for the lent tokens by the `lender`. The `lender` can only withdraw upto a maximum of `ERC20(supplyTokenAddress).balanceOf(msg.sender)` which get burned in exchange for `quoteToken` or `baseToken`.

As such, a lender may supply tokens to the pool but at the end of the day, during withdrawal, they will get just about what they supplied with no `interest`.

## Vulnerability Details
When a lender supply/withdraw tokens to/from the pool, the [applyInterestForToken()](https://github.com/code-423n4/2024-05-predy/blob/a9246db5f874a91fb71c296aac6a66902289306a/src/libraries/logic/SupplyLogic.sol#L32-L33) function is called. Here is the [comment on this function by the Dev](https://github.com/code-423n4/2024-05-predy/blob/a9246db5f874a91fb71c296aac6a66902289306a/src/libraries/ApplyInterestLib.sol#L23-L24):
```solidity
* @notice Each time a user interacts with the contract, interest and premium from the previous interaction to the current one are applied.
* This increases the amount available for withdrawal by the lender and the premium income for Squart.
```
The intention behind `applyInterestForToken()` is to `increases the amount available for withdrawal by the lender and the premium income for Squart.`

##### Break down
During [withdrawal](https://github.com/code-423n4/2024-05-predy/blob/a9246db5f874a91fb71c296aac6a66902289306a/src/libraries/logic/SupplyLogic.sol#L79-L91), `finalburntAmount` reffers to the amount of `bond` tokens burned in exchange for `finalWithdrawalAmount` which is either the `quoteToken` or `baseToken` sent to the user.

```solidity
(finalburntAmount, finalWithdrawalAmount) =
            _pool.tokenStatus.removeAsset(ERC20(supplyTokenAddress).balanceOf(msg.sender), _amount);
```
Here is the [removeAsset()](https://github.com/code-423n4/2024-05-predy/blob/a9246db5f874a91fb71c296aac6a66902289306a/src/libraries/ScaledAsset.sol#L55-L69) function which actually determines the amount of `bond` tokens to be burned:
```solidity
        require(_supplyTokenAmount > 0, "S3");

        uint256 burnAmount = FixedPointMathLib.mulDivDown(_amount, Constants.ONE, tokenState.assetScaler);

        if (_supplyTokenAmount < burnAmount) {
            finalBurnAmount = _supplyTokenAmount;
        } else {
            finalBurnAmount = burnAmount; 
        }

        finalWithdrawAmount = FixedPointMathLib.mulDivDown(finalBurnAmount, tokenState.assetScaler, Constants.ONE);

        require(getAvailableCollateralValue(tokenState) >= finalWithdrawAmount, "S0");

        tokenState.totalCompoundDeposited -= finalBurnAmount;
```
The function calculates the `burnAmount` then checks if `_supplyTokenAmount` i.e (user's `bond` token balance) is less than this value.
Since `_supplyTokenAmount` balance is only increased through minting more `bond` tokens which means supplying more tokens to the pool, it represents only a value equivalent to the user's total deposit.

However, as seen, there is no accounting for any `interest` earned for lending these tokens. The amount withdrawable by the lender is not inflated by any `interest` thereby receiving just the exact amount he supplied.

## Recommended Mitigation Steps
Implement a way that allows lenders to track and claim interest for their token supply to the lending pool.
