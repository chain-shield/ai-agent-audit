# Vulnerability details

## Impact

Unexpected DOS due to improper price update.

This would revert trade for some time which cause unnecessary confusion to the user.

## Proof of Concept

[PriceFeed.sol#L45-L58](https://github.com/code-423n4/2024-05-predy/blob/a9246db5f874a91fb71c296aac6a66902289306a/src/PriceFeed.sol#L45-L58)

```solidity
    function getSqrtPrice() external view returns (uint256 sqrtPrice) {
        (, int256 quoteAnswer,,,) = AggregatorV3Interface(_quotePriceFeed).latestRoundData();

        IPyth.Price memory basePrice = IPyth(_pyth).getPriceNoOlderThan(_priceId, VALID_TIME_PERIOD);

        require(basePrice.expo == -8, "INVALID_EXP");

        require(quoteAnswer > 0 && basePrice.price > 0);

        uint256 price = uint256(int256(basePrice.price)) * Constants.Q96 / uint256(quoteAnswer);
        price = price * Constants.Q96 / _decimalsDiff;

        sqrtPrice = FixedPointMathLib.sqrt(price);
    }
``` 

getPriceNoOlderThan is used to get the price and then the staleness check is done.

The caller provides an age argument that specifies how old the price can be. The call reverts with a StalePriceError if the on-chain price is from more than age seconds in the past (with respect to the current on-chain timestamp). 

when we look at the pyth implementation, the price should be updated (push based).
[Link](https://docs.pyth.network/price-feeds/api-reference/evm/get-price-no-older-than#:~:text=This%20function%20reverts,solve%20this%20problem.)
``This function reverts with a PriceFeedNotFound error if the requested feed id has never received a price update. This error could either mean that the provided price feed id is incorrect, or (more typically) that this is the first attempted use of that feed on-chain. In the second case, calling updatePriceFeeds will solve this problem.``

But in preddy we could not seen any place where the `updatePriceFeeds` is done by the admin/owner.

So, the price update is done some time before, the stale time check will revert the transaction. 

## Tools Used

Manual review.

## Recommended Mitigation Steps

We suggest to follow the recommendation mentioned [here](https://docs.pyth.network/price-feeds/api-reference/evm/get-price-no-older-than#:~:text=This%20function%20reverts,solve%20this%20problem.).

It is something, have function to call the `updatePriceFeeds` by the admin.
