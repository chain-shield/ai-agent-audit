# Vulnerability details

## Impact
Usage of `slot0` is extremely easy to manipulate

## Proof of Concept
Pool `sqrtPrice` value can be manipulated by mev bots.
```
function getSqrtPrice(address uniswapPoolAddress) internal view returns (uint160 sqrtPrice) {
        (sqrtPrice,,,,,,) = IUniswapV3Pool(uniswapPoolAddress).slot0(); //@audit
    }
```

## Tools Used
Code review

## Recommended Mitigation Steps
Use the `TWAP` function to get the value of `sqrtPrice`.


## Assessed type

MEV
