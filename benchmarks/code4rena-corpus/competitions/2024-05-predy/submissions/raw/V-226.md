# Vulnerability details

## Impact
`PerpMarketLib#validateMarketOrder` responsible for validating the trade price against the decayed price range based on the auction parameters decayed price range is calculated using the `DecayLib.decay` function, which takes the `startPrice`, `endPrice`, `startTime`, and `endTime` as inputs.

The function checks two conditions.

For buy orders (`tradeAmount > 0`), it checks if the `decayedPrice` is less than the `tradePrice`. If this condition is true, it means the trade price is higher than the upper bound of the decayed price range, and the function returns `false` to indicate an invalid trade. [validateMarketOrder#L200-L206](https://github.com/code-423n4/2024-05-predy/blob/a9246db5f874a91fb71c296aac6a66902289306a/src/markets/perp/PerpMarketLib.sol#L200-L206)
```solidity
if (tradeAmount > 0 && decayedPrice < tradePrice) {
    return false;
}

if (tradeAmount < 0 && decayedPrice > tradePrice) {
    return false;
}
```
The conditions should be reversed for the case when `tradeAmount` is negative (i.e., a sell order).

For sell orders (`tradeAmount < 0`), it checks if the `decayedPrice` is greater than the `tradePrice`. However, this condition is incorrect.

For a sell order, the function should return `false` if the `decayedPrice` is less than the `tradePrice`, not greater than the `tradePrice`. This is because, in a sell order, the seller wants to sell at a price higher than or equal to the lower bound of the decayed price range.

## Proof of Concept
Suppose the decayed price range is [100, 120], and the `tradeAmount` is -100 (a sell order).

If the `tradePrice` is 90, the function should return `false` because the trade price is lower than the lower bound of the decayed price range (100). However, with the current condition (`decayedPrice > tradePrice`), the function will return `true`, incorrectly validating the trade.

If the `tradePrice` is 110, the function should return true because the trade price is within the decayed price range. However, with the current condition (`decayedPrice > tradePrice`), the function will return `false`, incorrectly invalidating the trade.

The impact of this bug is that sell orders may be executed at prices lower than the intended lower bound of the decayed price range, potentially causing financial losses for the seller.

if (tradeAmount > 0 && decayedPrice < tradePrice) {
