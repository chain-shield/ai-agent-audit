# Vulnerability details

## Impact
In EVM the ERC20 standard operates with integers, so it would be useful to scale to a scale of 1e18. Without this, there would be a loss of precision.

## Proof of Concept
Error converting a decimal int256 value to a uint256. It is necessary to scale it.

## Tools Used
Manual, Remix.

## Recommended Mitigation Steps
Scale `int256 remainingMargin = vault.margin;` to * 1e18, if `vault.margin` is a positive decimal it does not generate an error when carrying out the conversion and transfer.
  `int256 remainingMargin = vault.margin * 1e18;`


```javascript
int256 remainingMargin = vault.margin * 1e18;

if (remainingMargin > 0) {
        if (vault.recipient != address(0)) {
           // Envie a margem restante para o destinatário.
           vault.margin = 0;

           uint256 scaledRemainingMargin = uint256(remainingMargin * 1e18);

           sentMarginAmount = scaledRemainingMargin;

           ERC20(pairStatus.quotePool.token).safeTransfer(vault.recipient, sentMarginAmount);
        }
}
```
