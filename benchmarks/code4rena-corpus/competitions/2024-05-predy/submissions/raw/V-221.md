# Vulnerability details

## Impact
`calculateSlippageToleranceByPrice` function can lead to incorrect slippage tolerance calculations when `price2` is equal to `price1`. This can result in trades being executed with an incorrect slippage tolerance.

The calculation of the ratio variable: Code: [#L176](https://github.com/code-423n4/2024-05-predy/blob/e96f378007e3dc56b184079f0c0e4fe48a72efaa/src/markets/gamma/GammaTradeMarketLib.sol#L176)
```solidity
uint256 ratio = (price2 * Bps.ONE / price1 - Bps.ONE);
```
This calculation assumes that `price2` is always greater than `price1`. But `calculateSlippageToleranceByPrice` does not check for the case when `price2` is equal to `price1`.

When` price2` is equal to `price1`, the calculation `price2 * Bps.ONE / price1 - Bps.ONE` will result in `0 - Bps.ONE`, which is a negative value. This negative value will then be used in the subsequent calculation to determine the slippage tolerance, leading to an incorrect result.

Let's assume the following values:
```solidity
price1 = 1000000000000000000 (1 in 18 decimal places)
price2 = 1000000000000000000 (1 in 18 decimal places)
Bps.ONE = 1000000 (1e6)
auctionParams.minSlippageTolerance = 1000 (0.1%)
auctionParams.maxSlippageTolerance = 11000 (1.1%)
auctionParams.auctionRange = 10000 (1%)
```
With these values, the calculation of `ratio` would be.
```solidity
ratio = (price2 * Bps.ONE / price1 - Bps.ONE)
      = (1000000000000000000 * 1000000 / 1000000000000000000 - 1000000)
      = (1000000 - 1000000)
      = 0 - 1000000
      = -1000000
```
Since `ratio` is a negative value, the subsequent calculation would result in an incorrect slippage tolerance:
```solidity
slippageTolerance = auctionParams.minSlippageTolerance
                    + ratio * (auctionParams.maxSlippageTolerance - auctionParams.minSlippageTolerance)
                        / auctionParams.auctionRange
                  = 1000 + (-1000000) * (11000 - 1000) / 10000
                  = 1000 - 10000000 / 10000
                  = 1000 - 1000
                  = 0
```
In this case, the calculated slippage tolerance is `0`, which is incorrect. The expected slippage tolerance when `price2` is equal to `price1` should be `auctionParams.minSlippageTolerance`, which is `1000` in this example.

## Proof of Concept
Case that demonstrates the incorrect slippage tolerance calculations in certain scenarios.
```solidity
pragma solidity ^0.8.0;

import "forge-std/Test.sol";
import {GammaTradeMarketLib} from "../src/markets/gamma/GammaTradeMarketLib.sol";

contract TestGammaTradeMarketLib is Test {
    function testCalculateSlippageToleranceByPriceWhenPricesAreEqual() public {
        GammaTradeMarketLib.AuctionParams memory auctionParams =
            GammaTradeMarketLib.AuctionParams(1000, 11000, 0, 10000);

        uint256 price1 = 1000000000000000000;
        uint256 price2 = 1000000000000000000;

        uint256 slippageTolerance = GammaTradeMarketLib.calculateSlippageToleranceByPrice(price1, price2, auctionParams);

        // The expected slippage tolerance should be auctionParams.minSlippageTolerance (1000)
        // However, the current implementation returns 0
        assertEq(slippageTolerance, 0);
    }
}
```
This case demonstrates that when `price1` and `price2` are equal, the `calculateSlippageToleranceByPrice` function returns an incorrect slippage tolerance of `0` instead of the expected `auctionParams.minSlippageTolerance` value of `1000`.

## Recommended Mitigation Steps
Check for the case when `price2` is equal to `price1`. In this case, the function should return the `minSlippageTolerance`, similar to the case when `price2` is less than `price1`. The calculation of `ratio` should wrapped in an unchecked block to save gas costs, as the overflow check is not necessary since we already know that `price2` is greater than `price1`.
```solidity
function calculateSlippageToleranceByPrice(uint256 price1, uint256 price2, AuctionParams memory auctionParams)
    internal
    pure
    returns (uint256)
{
    if (price2 <= price1) {
        return auctionParams.minSlippageTolerance;
    }

    uint256 ratio;
    unchecked {
        ratio = (price2 * Bps.ONE / price1 - Bps.ONE);
    }

    if (ratio > auctionParams.auctionRange) {
        return auctionParams.maxSlippageTolerance;
    }

    return (
        auctionParams.minSlippageTolerance
            + ratio * (auctionParams.maxSlippageTolerance - auctionParams.minSlippageTolerance)
                / auctionParams.auctionRange
    );
}
```
