# Vulnerability details

## Impact
Detailed description of the impact of this finding.
### Unauthorized Access Vulnerability

#### Description:
The `PriceFeedFactory` contract allows any external user to create a new `PriceFeed` contract using the `createPriceFeed` function. Additionally, the `PriceFeed` contract's `getSqrtPrice` function can be called by anyone. This lack of access control can lead to several potential issues:

1. **Unrestricted Contract Creation**: Any user can create multiple `PriceFeed` contracts, potentially leading to unnecessary consumption of blockchain resources and increased gas costs. This could also result in the deployment of malicious or redundant contracts.

2. **Unrestricted Price Querying**: The `getSqrtPrice` function in the `PriceFeed` contract can be called by any user. This could lead to potential abuse where users repeatedly call the function, causing unnecessary load on the network and potentially leading to denial of service (DoS) attacks.

#### Recommendations:
1. **Access Control for Contract Creation**: Implement access control mechanisms (e.g., using OpenZeppelin's `Ownable` or `AccessControl` libraries) to restrict who can call the `createPriceFeed` function. This ensures that only authorized users can create new `PriceFeed` contracts.

2. **Access Control for Price Querying**: Consider implementing access control for the `getSqrtPrice` function to restrict its usage to authorized users or specific contracts. This can help prevent abuse and ensure that the function is used as intended.

By implementing these access control measures, the contract can prevent unauthorized access and potential abuse, ensuring a more secure and efficient deployment.

## Recommended Mitigation Steps
### Recommendation to Resolve Unauthorized Access Vulnerability

#### Description:
To address the unauthorized access vulnerability in the `PriceFeedFactory` and `PriceFeed` contracts, we recommend implementing access control mechanisms to restrict who can create new `PriceFeed` contracts and who can call the `getSqrtPrice` function.

#### Steps to Implement Access Control:

1. **Access Control for Contract Creation**:
   - Use OpenZeppelin's `Ownable` contract to restrict the `createPriceFeed` function to only the contract owner.

2. **Access Control for Price Querying**:
   - Use OpenZeppelin's `Ownable` contract to restrict the `getSqrtPrice` function to only the contract owner or authorized addresses.

#### Implementation:

1. **Add OpenZeppelin's Ownable Contract**:
   - Install OpenZeppelin Contracts: `npm install @openzeppelin/contracts`
   - Import the `Ownable` contract in `PriceFeedFactory` and `PriceFeed`.

2. **Modify `PriceFeedFactory` Contract**:
   ```solidity
   // SPDX-License-Identifier: UNLICENSED
   pragma solidity ^0.8.17;

   import {FixedPointMathLib} from "@solmate/src/utils/FixedPointMathLib.sol";
   import {AggregatorV3Interface} from "./vendors/AggregatorV3Interface.sol";
   import {IPyth} from "./vendors/IPyth.sol";
   import {Constants} from "./libraries/Constants.sol";
   import "@openzeppelin/contracts/access/Ownable.sol";

   contract PriceFeedFactory is Ownable {
       address private immutable _pyth;

       event PriceFeedCreated(address quotePrice, bytes32 priceId, uint256 decimalsDiff, address priceFeed);

       constructor(address pyth) {
           _pyth = pyth;
       }

       function createPriceFeed(address quotePrice, bytes32 priceId, uint256 decimalsDiff) external onlyOwner returns (address) {
           PriceFeed priceFeed = new PriceFeed(quotePrice, _pyth, priceId, decimalsDiff);

           emit PriceFeedCreated(quotePrice, priceId, decimalsDiff, address(priceFeed));

           return address(priceFeed);
       }
   }
   ```

3. **Modify `PriceFeed` Contract**:
   ```solidity
   // SPDX-License-Identifier: UNLICENSED
   pragma solidity ^0.8.17;

   import {FixedPointMathLib} from "@solmate/src/utils/FixedPointMathLib.sol";
   import {AggregatorV3Interface} from "./vendors/AggregatorV3Interface.sol";
   import {IPyth} from "./vendors/IPyth.sol";
   import {Constants} from "./libraries/Constants.sol";
   import "@openzeppelin/contracts/access/Ownable.sol";

   contract PriceFeed is Ownable {
       address private immutable _quotePriceFeed;
       address private immutable _pyth;
       uint256 private immutable _decimalsDiff;
       bytes32 private immutable _priceId;

       uint256 private constant VALID_TIME_PERIOD = 5 * 60;

       constructor(address quotePrice, address pyth, bytes32 priceId, uint256 decimalsDiff) {
           _quotePriceFeed = quotePrice;
           _pyth = pyth;
           _priceId = priceId;
           _decimalsDiff = decimalsDiff;
       }

       /// @notice This function returns the square root of the baseToken price quoted in quoteToken.
       function getSqrtPrice() external view onlyOwner returns (uint256 sqrtPrice) {
           (, int256 quoteAnswer,,,) = AggregatorV3Interface(_quotePriceFeed).latestRoundData();

           IPyth.Price memory basePrice = IPyth(_pyth).getPriceNoOlderThan(_priceId, VALID_TIME_PERIOD);

           require(basePrice.expo == -8, "INVALID_EXP");

           require(quoteAnswer > 0 && basePrice.price > 0);

           uint256 price = uint256(int256(basePrice.price)) * Constants.Q96 / uint256(quoteAnswer);
           price = price * Constants.Q96 / _decimalsDiff;

           sqrtPrice = FixedPointMathLib.sqrt(price);
       }
   }
   ```

By implementing these changes, the `PriceFeedFactory` and `PriceFeed` contracts will have proper access control, preventing unauthorized users from creating new `PriceFeed` contracts and calling the `getSqrtPrice` function.
