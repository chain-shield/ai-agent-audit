# Vulnerability details

## Impact
`_getOrInitPosition()` is used to fetch a user's posistion details or create a new position if `isCreatedNew` is set to `true`. 

However, when invoked in `_executeTrade()`, it passes `tradeResult.vaultId` in place of `positionId`. This may result in the function saving incorrect information  under `userPosition` via `_saveUserPosition()`.

## Vulnerability Details
[_getOrInitPosition()](https://github.com/code-423n4/2024-05-predy/blob/a9246db5f874a91fb71c296aac6a66902289306a/src/markets/gamma/GammaTradeMarket.sol#L408-L411) takes the following parameters:
```solidity
function _getOrInitPosition(uint256 positionId, bool isCreatedNew, address trader, uint64 pairId)
     internal
     returns (GammaTradeMarketLib.UserPosition storage userPosition)
{}
```
As seen above, the first parameter is `positionId`.

However, in place of `positionId`, `tradeResult.vaultId` is passed instead of `gammaOrder.positionId` here within [_executeTrade()](https://github.com/code-423n4/2024-05-predy/blob/a9246db5f874a91fb71c296aac6a66902289306a/src/markets/gamma/GammaTradeMarket.sol#L185-L187).
```solidity
        GammaTradeMarketLib.UserPosition storage userPosition = _getOrInitPosition(
            tradeResult.vaultId, gammaOrder.positionId == 0, gammaOrder.info.trader, gammaOrder.pairId
        ); // @audit-issue Incorrect value used
```
As such, the `_getOrInitPosition()` will end up retrieving incorrect information as `userPosition` which finally will get saved for this particular user via [_saveUserPosition()](https://github.com/code-423n4/2024-05-predy/blob/a9246db5f874a91fb71c296aac6a66902289306a/src/markets/gamma/GammaTradeMarket.sol#L189):
```solidity
 _saveUserPosition(userPosition, gammaOrder.modifyInfo);
```

### Note:
Reffer [_modifyAutoHedgeAndClose()](https://github.com/code-423n4/2024-05-predy/blob/a9246db5f874a91fb71c296aac6a66902289306a/src/markets/gamma/GammaTradeMarket.sol#L220-L222) where the correct value is passed:
```solidity
    // save user position
    GammaTradeMarketLib.UserPosition storage userPosition =
        _getOrInitPosition(gammaOrder.positionId, false, gammaOrder.info.trader, gammaOrder.pairId); // @audt Correct value used here

```
As seen here, the correct value to pass is `gammaOrder.positionId` not a `vaultId`.

Manual Review

## Recommended Mitigation Steps
Pass `gammaOrder.positionId` instead of `tradeResult.vaultId` in the `_getOrInitPosition()` call.

```diff
        GammaTradeMarketLib.UserPosition storage userPosition = _getOrInitPosition(
-           tradeResult.vaultId, gammaOrder.positionId == 0, gammaOrder.info.trader, gammaOrder.pairId
+           gammaOrder.positionId, gammaOrder.positionId == 0, gammaOrder.info.trader, gammaOrder.pairId
        );
```
