# Vulnerability details

## Impact
The reallocation function in Perp.sol is used to Reallocates LP position to be in range, but this will suffer a precision loss due to division before multiplication.

## Proof of Concept
Let's just take a flow of the internal calls made in the function `realloacate`

```
realloacate  -->  Reallocation.getNewRange();
Reallocation.getNewRange() --> _getNewRange()
_getNewRange() --> calculateUsableTick()
```

While realloacating when ` if (totalLiquidityAmount == 0)` we are further calculating `_sqrtAssetStatus.tickLower, _sqrtAssetStatus.tickUpper` by calling `Reallocation.getNewRange` now this will suffer the precision loss and will return wrong value due to decimal truncation.

`_getNewRange` function the [lower & upper](https://github.com/code-423n4/2024-05-predy/blob/main/src/libraries/Reallocation.sol#L85-L86) are calculated by calling [calculateUsableTick](https://github.com/code-423n4/2024-05-predy/blob/main/src/libraries/Reallocation.sol#L109-L121) function which has the exact vulnerability of precision loss.

```solidity
function calculateUsableTick(int24 _tick, int24 tickSpacing) internal pure returns (int24 result) {
        require(tickSpacing > 0);

        result = _tick;

        if (result < TickMath.MIN_TICK) {
            result = TickMath.MIN_TICK;
        } else if (result > TickMath.MAX_TICK) {
            result = TickMath.MAX_TICK;
        }

        result = (result / tickSpacing) * tickSpacing; //<@audit division before multiplication
    }
```

## Recommended Mitigation Steps

Change the implementation from division before multiplication to multiplication before division :

```diff
function calculateUsableTick(int24 _tick, int24 tickSpacing) internal pure returns (int24 result) {
        require(tickSpacing > 0);

        result = _tick;

        if (result < TickMath.MIN_TICK) {
            result = TickMath.MIN_TICK;
        } else if (result > TickMath.MAX_TICK) {
            result = TickMath.MAX_TICK;
        }

-        result = (result / tickSpacing) * tickSpacing; 
+        result = (result * tickSpacing) / tickSpacing; 
    }
```
