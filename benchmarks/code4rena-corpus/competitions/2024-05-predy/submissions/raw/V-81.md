# Vulnerability details

## Impact
The `autoHedge()` and `autoClose()` functions allow anyone to call them without checking if the `caller` is the owner of the `positionId`.

Non-owners can therefore trigger `hedging` or `closing` of positions and exploit these functions to manipulate positions.

## Proof of Concept
The [autoClose()](https://github.com/code-423n4/2024-05-predy/blob/a9246db5f874a91fb71c296aac6a66902289306a/src/markets/gamma/GammaTradeMarket.sol#L274-L313) function closes positions when specific criteria are met. 
```solidity
    function autoClose(uint256 positionId, SettlementParamsV3 memory settlementParams)
        external
        returns (IPredyPool.TradeResult memory tradeResult)
    {
        // save user position
        GammaTradeMarketLib.UserPosition memory userPosition = userPositions[positionId];


        // @audit-issue Only checks for position validity
        if (userPosition.vaultId == 0 || positionId != userPosition.vaultId) {
            revert PositionNotFound();
        }

        //...
    }
```

The [autoHedge()](https://github.com/code-423n4/2024-05-predy/blob/a9246db5f874a91fb71c296aac6a66902289306a/src/markets/gamma/GammaTradeMarket.sol#L227-L272) function ensures positions maintain a desired hedge ratio,
```solidity
    function autoHedge(uint256 positionId, SettlementParamsV3 memory settlementParams)
        external
        returns (IPredyPool.TradeResult memory tradeResult)
    {
        GammaTradeMarketLib.UserPosition storage userPosition = userPositions[positionId];


        // @audit-issue Only checks for position validity
        if (userPosition.vaultId == 0 || positionId != userPosition.vaultId) {
            revert PositionNotFound();
        }

        //...
    }
```
The current implementation lacks `access control`, allowing anyone to call these functions. This can lead to unauthorized actions, such as `non-owners` triggering `hedging` or `closing` of positions. 
Consequently, users may experience unexpected `financial losses` and `disruptions` to their trading positions.

## Tools Used
Manual Review

## Recommended Mitigation Steps
Restrict these functions to position owners or authorized addresses.

```solidity
require(msg.sender == userPositions[positionId].owner);
```
