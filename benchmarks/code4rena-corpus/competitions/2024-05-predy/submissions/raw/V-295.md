# Vulnerability details

## Impact
The protocol uses `safeTransfer` to push the remaining margin to the recipient. However, tokens like `USDT` have blocklists. If the recipient is on the blocklist, the `safeTransfer` will revert, which can lead to a `liquidation` DoS.

## Proof of Concept
During liquidator invoking `execLiquidationCall` to liquidate a position.
If `!hasPosition` && `remainingMargin` && `vault.recipient > 0`, protocol will send the remainingMargin to vault recipient.

    DataType.Vault storage vault = globalData.vaults[vaultId];

    vault.recipient = recipient;
