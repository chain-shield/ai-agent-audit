# Vulnerability details

## Impact
The protocol does not pause `interest` payments while an unsafe vault is liquidated. As such, `interest` continues to accrue and is updated even during liquidation.

## Vulnerability Details
The liquidation process involves checking if the `vault` is in danger, executing the liquidation trade, and adjusting the vault's margin based on the trade result.

The `interest` is updated right before the liquidation process begins. This means that the vault's position continues to accrue `interest` up to the point of liquidation.
This can be seen in the following lines in [liquidate()](https://github.com/code-423n4/2024-05-predy/blob/a9246db5f874a91fb71c296aac6a66902289306a/src/libraries/logic/LiquidationLogic.sol#L49-L53) function:
```solidity
    // update interest growth
    ApplyInterestLib.applyInterestForToken(globalData.pairs, vault.openPosition.pairId);

    // update rebalance interest growth
    Perp.updateRebalanceInterestGrowth(pairStatus, pairStatus.sqrtAssetStatus);
```
The liquidation process checks if the `vault` is in danger using the [checkVaultIsDanger()](https://github.com/code-423n4/2024-05-predy/blob/a9246db5f874a91fb71c296aac6a66902289306a/src/libraries/logic/LiquidationLogic.sol#L55-L57) function.
If the vault is deemed `liquidatable`, the [Trade.trade()](https://github.com/code-423n4/2024-05-predy/blob/a9246db5f874a91fb71c296aac6a66902289306a/src/libraries/logic/LiquidationLogic.sol#L67) function is called to execute the liquidation trade.
The `vault`'s `margin` is then adjusted based on the trade result, which includes the updated `interest` values.

---> The `vault` continues to accrue `interest` up to the point of liquidation, which may lead to additional penalties for the liquidated position.
This can be unfair to the vault owner, as the liquidation process itself should ideally halt any further interest accrual.

## Tools Used
Manual Review

## Recommended Mitigation Steps
Implement logic to `pause interest accrual` for positions flagged for liquidation. This ensures that no `additional interest` is accrued once the liquidation process begins.
