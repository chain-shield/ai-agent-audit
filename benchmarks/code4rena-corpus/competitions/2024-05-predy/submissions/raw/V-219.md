# Vulnerability details

## Impact
If the `order.positionId` does not correspond to a valid position ID in the `userPositions` mapping, the line `uint64 pairId = userPositions[order.positionId].pairId;` will revert with an error. The entire transaction will fail, and the intended trade execution will not occur.

Code: [GammaTradeMarketL2#executeTradeL2](https://github.com/code-423n4/2024-05-predy/blob/e96f378007e3dc56b184079f0c0e4fe48a72efaa/src/markets/gamma/GammaTradeMarketL2.sol#L42-L70)
```solidity
function executeTradeL2(GammaOrderL2 memory order, bytes memory sig, SettlementParamsV3 memory settlementParams)
    external
    nonReentrant
    returns (IPredyPool.TradeResult memory tradeResult)
{
    GammaModifyInfo memory modifyInfo = L2GammaDecoder.decodeGammaModifyInfo(
        order.modifyParam, order.lowerLimit, order.upperLimit, order.maximaDeviation
    );
    (uint64 deadline, uint64 pairId, uint32 slippageTolerance, uint8 leverage) =
        L2GammaDecoder.decodeGammaParam(order.param);

    // No validation check for order.positionId

    return _executeTrade(
        GammaOrder(
            OrderInfo(address(this), order.trader, order.nonce, deadline),
            pairId, // <-- pairId retrieved from userPositions[order.positionId]
            order.positionId,
            _quoteTokenMap[pairId],
            order.quantity,
            order.quantitySqrt,
            order.marginAmount,
            order.baseSqrtPrice,
            slippageTolerance,
            leverage,
            modifyInfo
        ),
        sig,
        settlementParams
    );
}
```
In the above code, the `pairId` is retrieved from the `userPositions` mapping using the `order.positionId` as the key. However, there is no validation check to ensure that `order.positionId` corresponds to a valid position ID in the `userPositions` mapping.

If `order.positionId` does not exist in the `userPositions` mapping, the line `uint64 pairId = userPositions[order.positionId].pairId;` will revert with an error, causing the entire transaction to fail.

## Proof of Concept
Consider a scenario where a user attempts to execute a trade with an invalid `positionId`. Assume that the `userPositions` mapping does not contain an entry for the `positionId` provided in the order.
```solidity
GammaOrderL2 memory invalidOrder = GammaOrderL2({
    trader: msg.sender,
    nonce: 0,
    deadline: block.timestamp + 1 hours,
    positionId: 13957, // Invalid positionId (not present in userPositions)
    quantity: -1000,
    quantitySqrt: 0,
    marginAmount: 1e6,
    closePosition: false,
    limitValue: 0,
    leverage: 2,
    param: 0x0,
    lowerLimit: 0,
    upperLimit: 0
});

bytes memory signature = /* ... */;
SettlementParamsV3 memory settlementParams = /* ... */;

// Executing the trade with an invalid positionId
IPredyPool.TradeResult memory tradeResult = executeTradeL2(invalidOrder, signature, settlementParams);
```
In the above, the `positionId` provided in the `invalidOrder` (13957) does not exist in the `userPositions` mapping. When the `executeTradeL2` function attempts to retrieve the `pairId` using `userPositions[order.positionId].pairId`, it will revert with an error, causing the entire transaction to fail and preventing the intended trade execution.

## Recommended Mitigation Steps
Check to ensure that the `order.positionId` is a valid position ID and that it exists in the `userPositions` mapping before attempting to retrieve the `pairId`.
```solidity
function executeTradeL2(GammaOrderL2 memory order, bytes memory sig, SettlementParamsV3 memory settlementParams)
    external
    nonReentrant
    returns (IPredyPool.TradeResult memory tradeResult)
{
    GammaModifyInfo memory modifyInfo = L2GammaDecoder.decodeGammaModifyInfo(
        order.modifyParam, order.lowerLimit, order.upperLimit, order.maximaDeviation
    );
    (uint64 deadline, uint64 pairId, uint32 slippageTolerance, uint8 leverage) =
        L2GammaDecoder.decodeGammaParam(order.param);

    // Check if the positionId is valid
    if (userPositions[order.positionId].pairId == 0) {
        revert("Invalid position ID");
    }

    uint64 actualPairId = userPositions[order.positionId].pairId;

    // Ensure that the pairId from the order matches the actual pairId
    if (pairId != actualPairId) {
        revert("Pair ID mismatch");
    }

    return _executeTrade(
        GammaOrder(
            OrderInfo(address(this), order.trader, order.nonce, deadline),
            actualPairId,
            order.positionId,
            _quoteTokenMap[actualPairId],
            order.quantity,
            order.quantitySqrt,
            order.marginAmount,
            order.baseSqrtPrice,
            slippageTolerance,
            leverage,
            modifyInfo
        ),
        sig,
        settlementParams
    );
}
```
We first check if the `order.positionId` is a valid position ID by checking if the corresponding `pairId` in the `userPositions` mapping is non-zero. If the `pairId` is zero, it means the position ID is invalid, and we revert with an appropriate error message.

Next, we retrieve the actual `pairId` from the `userPositions` mapping and compare it with the `pairId` decoded from the order parameters. If they don't match, we revert with another error message.

Finally, we use the actual `pairId` and the corresponding quote token from the `_quoteTokenMap` when creating the `GammaOrder` struct and calling the `_executeTrade` function.
