# Vulnerability details

## Impact

    function getSqrtPrice() external view returns (uint256 sqrtPrice) {
        (, int256 quoteAnswer,,,) = AggregatorV3Interface(_quotePriceFeed).latestRoundData();

There is no check in the `getSqrtPrice()` function to validate Chainlink's `latestRoundData`  completeness, or the returned timestamp, and this could lead to stale, outdated, or incorrect price return value, which could affect `getSqrtIndexPrice` function that depends on the getSqrtPrice() function.

## Proof of Concept

https://vscode.dev/github/code-423n4/2024-05-predy/blob/main/src/PriceFeed.sol#L45-L47

The getSqrtPrice() function from the PriceFeed.sol contract calls the
`latestRoundData` from ChainLink price feeds. However, there is
no check on the return values to validate stale data prices.

This could lead to stale prices according to the ChainLink documentation:
[here](https://docs.chain.link/data-feeds/historical-data)

Manual Review

## Recommended Mitigation Steps

Add checks for the returned data after calling `latestRoundData()`
