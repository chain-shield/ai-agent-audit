# Vulnerability details

## Impact
The `settlementWhitelist()` function is used to whitelist the settlement address and also to enable the whitelist, the function is found in both BaseMarket contract and in BaseMarketUpgradeable contrat and the function is supposed to be called by only the `owner`. but in BaseMarketUpgradeabe.sol the `filler` can actually call this function to set the settlement whitelist, which does not conform to the `natspec` in the codebase and also the filler is not a trusted role.

## Proof of Concept
```solidity
src/base/BaseMarketUpgradable.sol
 /**
     * @notice Updates the whitelist settlement address
     * @dev only owner can call this function
     */
    function updateWhitelistSettlement(address settlementContractAddress, bool isEnabled) external onlyFiller {
        _whiteListedSettlements[settlementContractAddress] = isEnabled;
    }
```
```solidity
src/base/BaseMarket.sol
/**
     * @notice Updates the whitelist settlement address
     * @dev only owner can call this function
     */
    function updateWhitelistSettlement(address settlementContractAddress, bool isEnabled) external onlyOwner {
        _whiteListedSettlements[settlementContractAddress] = isEnabled;
    }
```

Manual Review
## Recommended Mitigation Steps
ensure that only the owner can call the method using the `onlyOwner` modifier.
