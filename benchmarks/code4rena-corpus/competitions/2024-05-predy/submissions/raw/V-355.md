# Vulnerability details

## Impact
Relying on the current state of Uniswap V3's slot0 to determine prices exposes the system to potential manipulations through front-running, back-running, and sandwich attacks. These attacks can lead to unfavorable trading conditions, incorrect liquidations, and financial losses for users.

Consider the following function, which retrieves the current square root price from Uniswap V3's slot0:

```javascript
  function getSqrtPrice(address uniswapPoolAddress) internal view returns (uint160 sqrtPrice) {
        (sqrtPrice,,,,,,) = IUniswapV3Pool(uniswapPoolAddress).slot0();
    }
```
