# Vulnerability details

## Impact
If an incorrect `amount` value is passed to the `_verifyOrderV3` function, it could result in an unintended transfer of tokens from the trader's account. This could happen in the following scenarios:

If the `amount` is greater than the order's `quantity` or `marginAmount`, more tokens could be transferred from the trader's account than intended.
If the `amount` is less than the order's `quantity` or `marginAmount`, fewer tokens could be transferred, potentially leading to a failed or partial execution of the order.

**Code:**
```solidity
function _verifyOrderV3(ResolvedOrder memory order, uint256 amount) internal {
    order.validate();

    _permit2.permitWitnessTransferFrom(   // is called with the amount parameter as the requestedAmount in the SignatureTransferDetails struct
        order.toPermit(),
        ISignatureTransfer.SignatureTransferDetails({to: address(this), requestedAmount: amount}),
        order.info.trader,
        order.hash,
        PerpOrderV3Lib.PERMIT2_ORDER_TYPE,
        order.sig
    );
}
```
In the code, the `_permit2.permitWitnessTransferFrom` is called with the amount parameter as the `requestedAmount` in the `SignatureTransferDetails` struct. However, there is no validation or check to ensure that the amount matches the order's `quantity` or `marginAmount`.

## Proof of Concept
Let's assume that a trader submits an order with a `quantity` of 1000 tokens and a `marginAmount` of 500 tokens. If an attacker or a bug in the system passes an `amount` value of 10000 to the `_verifyOrderV3` function, the `permitWitnessTransferFrom` would transfer 10000 tokens from the trader's account instead of the intended 1000 or 500 tokens.

This is an unintended transfer of tokens.

## Tools Used
Manual Audit

## Recommended Mitigation Steps
Check to ensure that the `amount` parameter matches the order's quantity or margin `amount`, depending on the intended behavior.
```solidity
function _verifyOrderV3(ResolvedOrder memory order, uint256 amount) internal {
    order.validate();

    // Check if the amount matches the order's quantity or margin amount
    require(amount == order.quantity || amount == order.marginAmount, "Invalid amount");

    _permit2.permitWitnessTransferFrom(
        order.toPermit(),
        ISignatureTransfer.SignatureTransferDetails({to: address(this), requestedAmount: amount}),
        order.info.trader,
        order.hash,
        PerpOrderV3Lib.PERMIT2_ORDER_TYPE,
        order.sig
    );
}
```
