# Vulnerability details

## Proof of Concept
The `convertSqrtPrice` function in the `UniHelper` library aims to calculate the square root price on base and quote tokens. However, the current implementation of this function can lead to incorrect calculations, due to not considering the differences of token decimals in base token and quote token. This can significantly impact the functionality that relies on accurate price conversions.
[UniHelper.sol#L27-L33](https://github.com/code-423n4/2024-05-predy/blob/a9246db5f874a91fb71c296aac6a66902289306a/src/libraries/UniHelper.sol#L27-L33)
```solidity
  function convertSqrtPrice(uint160 sqrtPriceX96, bool isQuoteZero) internal pure returns (uint160) {
        if (isQuoteZero) {
            return uint160((Constants.Q96 << Constants.RESOLUTION) / sqrtPriceX96);
        } else {
            return sqrtPriceX96;
        }
    }
```
You can check more details on [here](https://blog.uniswap.org/uniswap-v3-math-primer).
## Impact
The incorrect calculation can cause downstream functions that rely on this conversion to behave incorrectly, potentially leading to erroneous financial computations, incorrect liquidity provision decisions, or flawed trading strategies within the DeFi application.

Manual
## Recommended Mitigation Steps
Use the base token and quote token decimal difference in to equation when converting the [sqrtPrice](https://github.com/code-423n4/2024-05-predy/blob/a9246db5f874a91fb71c296aac6a66902289306a/src/libraries/UniHelper.sol#L29).
