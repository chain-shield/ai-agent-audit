# Vulnerability details

## Impact
The `createPriceFeed` function deploys a new priceFeed contract using the create.

At the same time, some of the chains (Optimism, Arbitrum) to which the `PriceFeed` will be deployed are suspicious of the reorg attack.
These optimistic rollups can experience chain reorganizations, which might allow an attacker to exploit predictable contract addresses.

The  create method is used and, the address derivation depends only on the arguments passed.


```javascript
function createPriceFeed(address quotePrice, bytes32 priceId, uint256 decimalsDiff) external returns (address) {
 @>     PriceFeed priceFeed = new PriceFeed(quotePrice, _pyth, priceId, decimalsDiff);

        emit PriceFeedCreated(quotePrice, priceId, decimalsDiff, address(priceFeed));

        return address(priceFeed);
    }
```

## Proof of Concept
This function deploys the contract at a deterministic address based on the deployer's address and nonce, making it vulnerable to reorg attacks.

## Recommended Mitigation Steps
Deploy such contracts via create2 with salt that includes `msg.sender`.
