# Vulnerability details

## Impact
The condition **`vault.openPosition.perp.amount == 0 && vault.openPosition.sqrtPerp.amount == 0`** is used to determine if a hedge or close is required for a given position. But this condition alone is not sufficient because it relies solely on the `vault.openPosition` values, which may not accurately reflect the current state of the position.

If a position has already been closed or hedged, but the `vault.openPosition` values have not been updated accordingly, the function will incorrectly return (`false, false, positionId`), indicating that neither a hedge nor a close is required. This could lead to the following issues:

**`Missed Hedge Opportunities`** If a position needs to be hedged based on other conditions (e.g., time elapsed, price movement), but the `vault.openPosition` values are stale, the function will miss the opportunity to hedge the position.

**`Missed Close Opportunities`** Similarly, if a position needs to be closed based on other conditions (e.g., expiration time, price movement), but the `vault.openPosition` values are stale, the function will miss the opportunity to close the position.

**`Incorrect Position Management`** By relying solely on the `vault.openPosition` values, the function may fail to properly manage the position's lifecycle, leading to potential losses or missed opportunities.

Code snippet from the **`GammaTradeMarket:checkAutoHedgeAndClose`**: [#L342-L344](https://github.com/code-423n4/2024-05-predy/blob/e96f378007e3dc56b184079f0c0e4fe48a72efaa/src/markets/gamma/GammaTradeMarket.sol#L342-L344)
```solidity
if (vault.openPosition.perp.amount == 0 && vault.openPosition.sqrtPerp.amount == 0) {
    return (false, false, positionId);
}
```
This condition checks if both the perpetual (`perp.amount`) and square root perpetual (`sqrtPerp.amount`) amounts are zero. If this condition is true, the function returns `(false, false, positionId)`, indicating that neither a hedge nor a close is required, and the position ID remains unchanged.

But as I mentioned earlier, this condition alone is not sufficient to determine if a hedge or close is required because the `vault.openPosition` values may not accurately reflect the current state of the position.

## Proof of Concept
A user opens a position with a non-zero `perp.amount and sqrtPerp.amount`.
The position is later closed or hedged, but the `vault.openPosition` values are not updated accordingly (e.g., due to a bug or external factors).
When the `checkAutoHedgeAndClose` function is called for this position, the condition `vault.openPosition.perp.amount == 0 && vault.openPosition.sqrtPerp.amount == 0` will be false because the `vault.openPosition` values are stale and still reflect the initial non-zero values.
As a result, the function will proceed to call `GammaTradeMarketLib.validateHedgeCondition` and `GammaTradeMarketLib.validateCloseCondition`, which may or may not trigger a hedge or close based on other conditions.
However, since the position has already been closed or hedged (but the `vault.openPosition` values are not updated), any hedge or close action triggered by the function would be redundant or potentially lead to incorrect behavior.

You can see how relying solely on the `vault.openPosition` values can lead to incorrect position management if the values are not accurately updated.

## Recommended Mitigation Steps
It would be better to check the position's status or other relevant conditions to determine if a hedge or close is required, rather than relying solely on the `vault.openPosition` values.
```solidity
function checkAutoHedgeAndClose(uint256 positionId)
    external
    view
    returns (bool hedgeRequired, bool closeRequired, uint256 resultPositionId)
{
    GammaTradeMarketLib.UserPosition memory userPosition = userPositions[positionId];

    // Check if the position exists and is active
    if (userPosition.vaultId == 0 || positionId != userPosition.vaultId) {
        return (false, false, positionId);
    }

    uint256 sqrtPrice = _predyPool.getSqrtIndexPrice(userPosition.pairId);

    (hedgeRequired, , ) = GammaTradeMarketLib.validateHedgeCondition(userPosition, sqrtPrice);
    (closeRequired, , ) = GammaTradeMarketLib.validateCloseCondition(userPosition, sqrtPrice);

    resultPositionId = positionId;
}
```
