# Vulnerability details

## Impact
The vulnerability identified in the PerpMarketV1 contract is related to reentrancy. In this case, there is a potential for reentrancy in the _executeOrderV3 function, specifically in the external call to _predyPool.trade. After this call, the state variable userPosition.vaultId is updated based on the trade result. The userPositions mapping in PerpMarketV1 can be accessed in other functions, such as getUserPosition and quoteExecuteOrderV3, which could lead to cross-function reentrancies.

An attacker could potentially exploit this vulnerability by calling _executeOrderV3 with malicious input that triggers reentrant calls to functions utilizing the userPositions mapping. This could result in unexpected behavior or manipulation of user positions and vault IDs within the PerpMarketV1 contract.
