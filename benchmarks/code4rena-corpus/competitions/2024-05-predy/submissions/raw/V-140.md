# Vulnerability details

## Impact
Due to incorrect validation of `globalData.lockData.locker` in the `GlobalData.sol#initializeLock()` function, once `globalData.lockData.locker` is set, this function cannot be accessed again.
However, since the `initializeLock()` function is called from several core functions of `Predy`, the protocol cannot perform its function. In other words, the protocol is in a situation where it can go bankrupt.

## Proof of Concept
The `GlobalData.sol#initializeLock()` is the function that Initializes lock for token settlement.
