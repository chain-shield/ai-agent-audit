# Vulnerability details

## Impact
The condition for checking the stop price when the trade amount is negative (sell order) in `validateStopPrice` function is incorrect. The condition `if (stopPrice < oraclePrice)` should be `if (stopPrice > oraclePrice)`. This is because, for a sell order, the stop price should be higher than the oracle price, not lower.

The incorrect condition `if (stopPrice < oraclePrice)` for sell orders (when `tradeAmount < 0`) means that the function will allow stop prices that are lower than the current market price (oracle price). This is counterintuitive and contradicts the purpose of a stop order, which is to sell a position when the market price reaches or exceeds a predetermined level (the stop price).

Code: [validateStopPrice#L164-L173](https://github.com/code-423n4/2024-05-predy/blob/a9246db5f874a91fb71c296aac6a66902289306a/src/markets/perp/PerpMarketLib.sol#L164-L173)
```solidity
if (tradeAmount < 0) {
    // sell
    if (stopPrice < oraclePrice) { // Incorrect condition
        return false;
    }

    if (tradePrice < Bps.lower(oraclePrice, decayedSlippageTorelance)) {
        return false;
    }
}
```

## Proof of Concept
Suppose a trader wants to set a stop order to sell their position when the market price reaches or exceeds $100. With the current implementation, if the trader sets the stop price to $90 (which is lower than the desired $100), the `validateStopPrice` function will incorrectly validate this stop price for a sell order.

This means that the trader's position could be sold at a price lower than their intended stop price, potentially resulting in significant financial losses.

## Recommended Mitigation Steps
Here's the corrected code.
```solidity
if (tradeAmount < 0) {
    // sell
    if (stopPrice > oraclePrice) { // Change this line
        return false;
    }

    if (tradePrice < Bps.lower(oraclePrice, decayedSlippageTorelance)) {
        return false;
    }
}
```
The reason for this bug is that the stop price for a sell order should be a price higher than the current market price (oracle price) at which the trader wants to sell their position. If the stop price is lower than the oracle price, it would mean that the trader wants to sell their position at a price lower than the current market price, which is counterintuitive for a stop order.
