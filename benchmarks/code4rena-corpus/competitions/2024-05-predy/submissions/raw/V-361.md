# Vulnerability details

## Impact
The `getSqrtPrice` function retrieves price data from `latestRoundData` However, it does not currently check the timestamps ie `updatedAt` of the retrieved data to ensure it is not stale. Using outdated price data can lead to inaccurate calculations, potentially causing functions to behave unexpectedly or result in financial losses.

## Proof of Concept
```javascript
 (, int256 quoteAnswer,,,) = AggregatorV3Interface(_quotePriceFeed).latestRoundData();
```

No check is performed on the `updatedAt` timestamp from Chainlink to ensure the price data is recent.

## Tools Used
Manual Review

## Recommended Mitigation Steps
Add other fields that are usually returned by `latestRoundData` especially the `updatedAt`

```javascript
 (
        uint80 roundID, 
        int256 quoteAnswer, 
        uint256 startedAt, 
        uint256 updatedAt, 
        uint80 answeredInRound
    ) = AggregatorV3Interface(_quotePriceFeed).latestRoundData();
```
