# Vulnerability details

## Impact
Solidity's integer division truncates. Thus, performing division before multiplication can lead to precision loss.


## Proof of Concept
https://github.com/crytic/slither/wiki/Detector-Documentation#divide-before-multiply

In the following code, the protocol performs division before multiplication.

1.

    uint256 price = uint256(int256(basePrice.price)) * Constants.Q96 / uint256(quoteAnswer);
        price = price * Constants.Q96 / _decimalsDiff;

2.

    result = (result / tickSpacing) * tickSpacing;

3.
  
    uint256 elapsed = (currentTime - startTime) * Bps.ONE / auctionParams.auctionPeriod;

        if (elapsed > Bps.ONE) {
            return auctionParams.maxSlippageTolerance;
        }

        return (
            auctionParams.minSlippageTolerance
                + elapsed * (auctionParams.maxSlippageTolerance - auctionParams.minSlippageTolerance) / Bps.ONE
        );


## Tools Used
slither


## Recommended Mitigation Steps
Consider ordering multiplication before division.
