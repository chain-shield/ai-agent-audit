# Vulnerability details

## Proof of Concept
The `validate` function in the `SettlementCallbackLib` library is designed to ensure that the settlement contract address provided in the settlement parameters is whitelisted. However, there is a potential issue where the zero address (`address(0)`) is not properly validated. Below is the original code for the validate function:
[SettlementCallbackLib.sol#L34](https://github.com/code-423n4/2024-05-predy/blob/a9246db5f874a91fb71c296aac6a66902289306a/src/base/SettlementCallbackLib.sol#L34)
```solidity
function validate(
        mapping(address settlementContractAddress => bool) storage _whiteListedSettlements,
        SettlementParams memory settlementParams
    ) internal view {
        if (
            settlementParams.contractAddress != address(0) && !_whiteListedSettlements[settlementParams.contractAddress]
        ) {
            revert IFillerMarket.SettlementContractIsNotWhitelisted();
        }
    }
```
In this implementation, if `settlementParams.contractAddress` is the zero address, the function does not revert and allows the transaction to proceed. This behavior can lead to unintended scenarios where transactions with a zero address are processed without proper validation. The intended purpose of the `validate` function is to ensure that only whitelisted settlement contract addresses are allowed to proceed, thereby maintaining the integrity and security of the settlement process.


## Impact
Allowing the zero address to bypass validation can lead to unauthorized or unintended transactions being processed, potentially compromising the security of the system. This could result in unauthorized settlements, leading to financial loss or other adverse effects on the platform.

## Recommended Mitigation Steps
 The `validate` function should be updated to explicitly check for the zero address and revert if it is encountered.
```solidity
function validate(
    mapping(address settlementContractAddress => bool) storage _whiteListedSettlements,
    SettlementParams memory settlementParams
) internal view {
    if (settlementParams.contractAddress == address(0) || !_whiteListedSettlements[settlementParams.contractAddress]) {
        revert IFillerMarket.SettlementContractIsNotWhitelisted();
    }
}
```
