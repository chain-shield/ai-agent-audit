# Vulnerability details

## summary
When a long position is opened, then base tokens are transferred to filler from predypool and quote tokens are transferred to predypool. When a short position is opened, quote tokens are transferred to filler from predypool and base tokens are transferred to predypool.when opening long and short positions , liquidity must exist for a token(because the token is transferred to filler). So when liquidating a position, if one token(the token which is transferred to filler during liquidation) available liquidity is 0(or this token utilization ratio is high), then liquidation will not work. 

Before liquidation, an attacker can frontrun and open a big position(long or short depending on liquidation situation) so that the token’s(the token which is transferred to filler during liquidation)  totalNormalBorrowed increases and  the token’s AvailableCollateral becomes 0 in predypool.as the token’s available collateral 0 in the predypool, so liquidation/closing position will be DOS.

## Proof of Concept
1. Let’s assume, a pairid’s quote tokens = 1000e18, base tokens = 500e18 deposited by lenders in predypool. So the quote token’s  totalCompoundDeposited = 1000e18 and base token’s totalCompoundDeposited = 500e18.here 1 quotetoken = 1 base token.

2. Now Alice opens a long position in prepmarket with 500e18 quantity in this pairid, as position is long, so 500e18 base tokens are transferred to filler from predypool and 500e18 quote tokens are transferred to predypool. So now base token’s totalNormalBorrowed = 500e18 and quote token’s totalNormalDeposited = 500e18.

3. Now bob opens a short position with 500e18 quantity in this pairid, as position is short, so 500e18 quote tokens are transferred to filler from predypool and 500e18 base tokens are transferred to predypool. So now base token’s totalNormalDeposited = 500e18 and quote token’s totalNormalBorrowed = 500e18.

4. Then  john opens a long position in prepmarket with 500e18 quantity in this pairid, as position is long, so 500e18 base tokens are transferred to filler from predypool and 500e18 quote tokens are transferred to predypool. So now base token’s totalNormalBorrowed = 500e18(previous totalNormalBorrowed) +500e18 = 1000e18, totalCompoundDeposited = 500e18,totalNormalDeposited = 500e18 and quote token’s totalNormalDeposited = 500e18(previous totalNormalDeposited)+500e18 = 1000e18, totalNormalBorrowed = 500e18, totalCompoundDeposited = 1000e18.

5. AvailableCollateral = ( totalCompoundDeposited+totalNormalDeposited) - totalNormalBorrowed. So quote token’s  AvailableCollateral = 1000e18+1000e18 - 500e18 = 1500e18. Base token’s AvailableCollateral = 500e18+500e18 - 1000e18 = 0.

6. Now bob’s short position become liquidable (or may be bob want to close the short position), when liquidating/closing the short position, then base token willbe transferred to the filler from predypool but now Base token’s AvailableCollateral = 0, so position is not liquidated and the protocol will reach to bad debt.

## impact
DOS on liquidation when totalNormalBorrowed is equal to ( totalCompoundDeposited+totalNormalDeposited) for a  token in predypool.


## Tools Used
manual review 
## Recommended Mitigation Steps
make sure, there should always remain available tokens in predypool


## Assessed type

DoS
