# Vulnerability details

## Impact
In Trade.sol, the function trade() in order to get tradeResult.sqrtPrice it calls getSqrtPrice() that calls UniHelper.convertSqrtPrice() that use ```IUniswapV3Pool(uniswapPoolAddress).slot0()``` to get the value of sqrtPriceX96, which is used to perform the swap if ```if (totalBaseAmount == 0)```. However, the sqrtPriceX96 is pulled from Uniswap.slot0, which is the most recent data point and can be manipulated easily via MEV bots and Flashloans with sandwich attacks. This can cause loss of funds when interacting with the swap function.
