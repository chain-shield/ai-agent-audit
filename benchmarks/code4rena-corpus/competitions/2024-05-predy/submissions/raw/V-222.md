# Vulnerability details

## Impact
`getFinalTradeAmount` will return incorrect values when reducing a short position, which could lead to incorrect position calculations, incorrect trade amounts.

Code with the problematic: [getFinalTradeAmount#L49-L60](https://github.com/code-423n4/2024-05-predy/blob/a9246db5f874a91fb71c296aac6a66902289306a/src/markets/perp/PerpMarketLib.sol#L49-L60)
```solidity
if (reduceOnly) {
    if (currentPositionAmount > 0) {
        if (currentPositionAmount > -currentPositionAmount) {
            return -currentPositionAmount;
        } else {
            return currentPositionAmount;
        }
    } else {
        if (-currentPositionAmount > tradeAmount) {
            return tradeAmount;
        } else {
            return -currentPositionAmount;
        }
    }
}
```
The issue is with the condition [if (-currentPositionAmount > tradeAmount)](https://github.com/code-423n4/2024-05-predy/blob/a9246db5f874a91fb71c296aac6a66902289306a/src/markets/perp/PerpMarketLib.sol#L66). Let's consider an example:
```solidity
int256 currentPositionAmount = -100;
string memory side = "Sell";
uint256 quantity = 50;
bool reduceOnly = true;
bool closePosition = false;

// ...

if (-currentPositionAmount > tradeAmount) {
    // This condition is always false because -currentPositionAmount (-100) can never be greater than tradeAmount (50)
    // The code should check if the absolute value of currentPositionAmount is greater than tradeAmount
}
```
In this case, when `currentPositionAmount` is negative (i.e., a short position) and `tradeAmount` is positive (i.e., reducing the short position), the condition `-currentPositionAmount > tradeAmount` will always be false because `-currentPositionAmount` (a negative number) can never be greater than `tradeAmount` (a positive number).

This means that the function will always return `-currentPositionAmount` instead of `tradeAmount`, which is incorrect behavior. It should return `tradeAmount` if `tradeAmount` is less than or equal to the absolute value of `currentPositionAmount`.

## Recommended Mitigation Steps
The correct logic should be:
```solidity
if (currentPositionAmount < 0) {
    if (-currentPositionAmount > tradeAmount) {
        return -currentPositionAmount;
    } else {
        return tradeAmount;
    }
} else {
    if (currentPositionAmount > tradeAmount) {
        return currentPositionAmount;
    } else {
        return tradeAmount;
    }
}
```
Check the absolute value of `currentPositionAmount` against `tradeAmount` and returns the appropriate value based on whether the position is long or short, and whether `reduceOnly` is `true` or `false`.
