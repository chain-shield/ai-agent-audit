# Vulnerability details

## Impact
totalCompoundDeposited is scaled twice, resulting in incorrect TotalCollateralValue.

## Proof of Concept
Because Constants.ONE is 1e18, when tokenState.assetScaler is 1e18, the calculation result is not affected.
If Constants.ONE and tokenState.assetScaler are inconsistent, Constants.ONE is 1e18, but tokenState.assetScaler changes according to different tokens, assuming it is 1e6, in this case, the calculation result will be very different from the correct result.
### The following example is a proof:
_amount = 4e6
Constants.ONE = 1e18
tokenState.assetScaler = 1e6
```sol
    function addAsset(AssetStatus storage tokenState, uint256 _amount) internal returns (uint256 claimAmount) {
        if (_amount == 0) {
            return 0;
        }

        claimAmount = FixedPointMathLib.mulDivDown(_amount, Constants.ONE, tokenState.assetScaler);

        tokenState.totalCompoundDeposited += claimAmount;
    }
```
claimAmount=4e6*1e18/1e6=4e18
tokenState.totalCompoundDeposited=0+4e18=4e18
```sol
    function getTotalCollateralValue(AssetStatus memory tokenState) internal pure returns (uint256) {
        return FixedPointMathLib.mulDivDown(tokenState.totalCompoundDeposited, tokenState.assetScaler, Constants.ONE)
            + tokenState.totalNormalDeposited;
    }
```
The vulnerability occurs here. When calculating CollateralValue, the value of totalCompoundDeposited will be scaled again, and the previously recorded totalCompoundDeposited has already been scaled. The second scaling will cause the result to be wrong.
`FixedPointMathLib.mulDivDown(tokenState.totalCompoundDeposited, tokenState.assetScaler, Constants.ONE)`
4e18*1e18/1e6=4e30

At this time, the CollateralValue will be 10^12 times larger than the correct result.
## Tools Used
Manual review
## Recommended Mitigation Steps
No further scaling calculation is required, just use tokenState.totalCompoundDeposited directly.
```sol
   function getTotalCollateralValue(AssetStatus memory tokenState) internal pure returns (uint256) {
        return tokenState.totalCompoundDeposited + tokenState.totalNormalDeposited;
    }
```
