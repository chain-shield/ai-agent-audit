# Vulnerability details

## Impact

Integrating Chainlink on L2 networks like Arbitrum necessitates validating the sequencer's status to ensure accurate price feeds. Not implementing this check can lead to stale or inaccurate price data being utilized, potentially exploited by malicious actors during sequencer downtime. The impact varies based on usage scenarios, such as:

- **Collateral Usage**: Users might obtain advantageous borrowing rates when prices appear inflated.
- **Liquidation Avoidance**: Users could evade liquidations if prices inaccurately reflect undervaluation.

## Description

The current implementation lacks a validation mechanism for sequencer downtime:

