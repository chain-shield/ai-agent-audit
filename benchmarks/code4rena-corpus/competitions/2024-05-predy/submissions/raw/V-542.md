# Vulnerability details

## Impact
When the contract is Deployed. The owner must call initialize .This is redudant for 
deploying and initilializing can be done in one Transaction. an Attacker can see the transaction of Initializing and frontRun it make him the operator.

## Proof of Concept

## Recommended Mitigation Steps
add the initialization on the constructor.
```javascript
constructor(address _uniswapFactory) {
    initialize(_uniswapFactory);
}
```
