# Vulnerability details

## Impact
The function `getSqrtPrice` doesn't check Arbitrum l2 chainlink feed is active

When integrating Chainlink on Layer 2 (L2) chains like Arbitrum, it's crucial to prevent the misconception that price data is fresh, especially during sequencer downtime. This vulnerability presents an opportunity for malicious actors to exploit, potentially gaining an unfair advantage.
