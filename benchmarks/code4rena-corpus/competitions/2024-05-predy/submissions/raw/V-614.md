# Vulnerability details

## Impact
The problem arises due to the changing value of tokenState.assetScaler, which impacts the calculation of claimAmount when a user supplies tokens to the pool. When the pool is unstable and the tokenState.assetScaler changes, it can lead to users receiving fewer shares than expected.

## Proof of Concept

```solidity

function receiveTokenAndMintBond(Perp.AssetPoolStatus storage _pool, uint256 _amount)
        internal
        returns (uint256 mintAmount)
    {
        mintAmount = _pool.tokenStatus.addAsset(_amount);

        ERC20(_pool.token).safeTransferFrom(msg.sender, address(this), _amount);

        ISupplyToken(_pool.supplyTokenAddress).mint(msg.sender, mintAmount);
    }

```

When tokenState.assetScaler increases, the denominator in the claimAmount calculation becomes larger.This results in a smaller claimAmount for the same _amount. With a higher tokenState.assetScaler, stakers receive fewer shares (mintAmount) for the tokens they supply.This is especially problematic when the pool is unstable and the interest rate changes frequently.
