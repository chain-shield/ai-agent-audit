# Vulnerability details

## Impact
In `getFeeGrowthInside()`, subtractions are performed within an `unchecked` block. These unchecked subtractions without validation can lead to `underflows`, resulting in incorrect `fee` calculations.

`Underflows` can lead to `negative values being interpreted as large positive values` in the context of unsigned integers, leading to incorrect fee growth calculations.

## Proof of Concept
The function [getFeeGrowthInside()](https://github.com/code-423n4/2024-05-predy/blob/a9246db5f874a91fb71c296aac6a66902289306a/src/libraries/UniHelper.sol#L113-L147) calculates the fee growth inside a specific range of ticks (`tickLower` to `tickUpper`) for a Uniswap V3 pool. It does this by considering the `global fee growth` and subtracting the fee growth outside the specified `tick` range.

**Unchecked Block**
The subtractions are performed within an unchecked block to save gas by skipping overflow and underflow checks:
```solidity
unchecked {
            {
                (,, uint256 lowerFeeGrowthOutside0X128, uint256 lowerFeeGrowthOutside1X128,,,,) =
                    IUniswapV3Pool(uniswapPoolAddress).ticks(tickLower);

                if (tickCurrent >= tickLower) {
                    feeGrowthBelow0X128 = lowerFeeGrowthOutside0X128;
                    feeGrowthBelow1X128 = lowerFeeGrowthOutside1X128;
                } else {
                    feeGrowthBelow0X128 = feeGrowthGlobal0X128 - lowerFeeGrowthOutside0X128;
                    feeGrowthBelow1X128 = feeGrowthGlobal1X128 - lowerFeeGrowthOutside1X128;
                }
            }

            // calculate fee growth above
            uint256 feeGrowthAbove0X128;
            uint256 feeGrowthAbove1X128;

            {
                (,, uint256 upperFeeGrowthOutside0X128, uint256 upperFeeGrowthOutside1X128,,,,) =
                    IUniswapV3Pool(uniswapPoolAddress).ticks(tickUpper);

                if (tickCurrent < tickUpper) {
                    feeGrowthAbove0X128 = upperFeeGrowthOutside0X128;
                    feeGrowthAbove1X128 = upperFeeGrowthOutside1X128;
                } else {
                    feeGrowthAbove0X128 = feeGrowthGlobal0X128 - upperFeeGrowthOutside0X128;
                    feeGrowthAbove1X128 = feeGrowthGlobal1X128 - upperFeeGrowthOutside1X128;
                }
            }

            feeGrowthInside0X128 = feeGrowthGlobal0X128 - feeGrowthBelow0X128 - feeGrowthAbove0X128;
            feeGrowthInside1X128 = feeGrowthGlobal1X128 - feeGrowthBelow1X128 - feeGrowthAbove1X128;
        }
}
```
If `lowerFeeGrowthOutside0X128 > feeGrowthGlobal0X128`, the subtraction will `underflow`, causing an incorrect value for `feeGrowthBelow0X128`.

Similar underflow risks exist for the other subtractions in the unchecked block.
