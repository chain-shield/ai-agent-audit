# Vulnerability details

## Impact
This report identifies a potential vulnerability in the `updatePoolOwner` function of the Predy Pool contract. While the function itself has the `onlyPoolOwner` modifier to restrict access, it delegates the update logic to an external function in the `AddPairLogic` contract. This external function, `updatePoolOwner`, lacks its own access control modifier, creating a bypass scenario:

1. **Intended Behavior:** Only the authorized pool owner (identified by `pairId`) can call the `updatePoolOwner` function within the Predy Pool contract.
2. **Vulnerability:** A malicious user can directly call the external `updatePoolOwner` function in the `AddPairLogic` contract, bypassing the `onlyPoolOwner` modifier. This allows them to change the pool owner address to their own.
3. **Impact:** By changing the pool owner, the attacker could potentially:
    * Withdraw accumulated creator revenue intended for the legitimate pool creator.
    * Manipulate other pool settings since other `AddPairLogic` functions lack proper access control.

## Recommended Mitigation Steps

To mitigate this vulnerability, it's recommended to nest an access control modifier within the `updatePoolOwner` function of the `AddPairLogic` contract. This ensures that only authorized callers can modify the pool owner information. Here's how:

1. **Identify Authorized Callers:** Determine who is allowed to call `updatePoolOwner` in the `AddPairLogic` contract. Typically, this should be limited to the Predy Pool contract itself.
2. **Implement Access Control Modifier:** Modify the `updatePoolOwner` function signature in the `AddPairLogic` contract to include an access control modifier. For example:

   ```solidity
   function updatePoolOwner(DataType.PairStatus storage _pairStatus, address _poolOwner) external onlyPredyPool {
       // ... existing logic ...
   }
   ```

3. **Define Authorized Caller:** Define the `onlyPredyPool` modifier to restrict access only to the Predy Pool contract address. This can be achieved using a combination of `msg.sender` and a constant variable storing the Predy Pool contract address.
