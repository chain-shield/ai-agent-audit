# Vulnerability details

## Impact
`PredyPool::reallocate` reallocates the range of concentrated liquidity provider position to be in-range.

If the LP position is not in-range, then the range is updated and a swap is executed to ensure the LP has the correct amount of liquidity for the new range.

The problem is that when calculating the amount to swap, the amount is rounded up. In certain cases, this will lead to DoS due to insufficient liquidity.

## Proof of Concept
During reallocation, if the LP is out of range, a swap is executed to rebalance the liquidity

Since it is rounded up, it may round up to a value that does not reflect the actual amount that is within the pool.

The `deltaPosition` value returned is sent to the `settlement callback`

[ReallocationLogic.sol#L54](https://github.com/code-423n4/2024-05-predy/blob/main/src/libraries/logic/ReallocationLogic.sol#L54)


Depending on the sign of `baseAmountDelta` (which is our `deltaPosition` value, the variable name changed), we buy or sell `base tokens`

[SettlementCallbackLib.sol#L67-L87](https://github.com/code-423n4/2024-05-predy/blob/main/src/base/SettlementCallbackLib.sol#L67-L87)

When buying or selling, base tokens are taken from the pool that corresponds to `sellAmount` which is the `baseAmountDelta` (the same value of `deltaPosition` from the beginning, the variable names changed)

[SettlementCallbackLib.sol#L103](https://github.com/code-423n4/2024-05-predy/blob/main/src/base/SettlementCallbackLib.sol#L103)

Due to round up, this may revert due to insufficient liquidity, causing DoS of reallocations.

## Recommended Mitigation Steps
Round down instead when calculating the amount to swap

```diff
    function swapForOutOfRange(
        DataType.PairStatus storage pairStatus,
        uint160 _currentSqrtPrice,
        int24 _tick,
        uint128 _totalLiquidityAmount
    ) internal returns (int256 deltaPositionBase, int256 deltaPositionQuote) {
        uint160 tickSqrtPrice = TickMath.getSqrtRatioAtTick(_tick);

        // 1/_currentSqrtPrice - 1/tickSqrtPrice
        int256 deltaPosition0 =
-           LPMath.calculateAmount0ForLiquidity(_currentSqrtPrice, tickSqrtPrice, _totalLiquidityAmount, true);
+           LPMath.calculateAmount0ForLiquidity(_currentSqrtPrice, tickSqrtPrice, _totalLiquidityAmount, false);

        // _currentSqrtPrice - tickSqrtPrice
        int256 deltaPosition1 =
-           LPMath.calculateAmount1ForLiquidity(_currentSqrtPrice, tickSqrtPrice, _totalLiquidityAmount, true);
+           LPMath.calculateAmount1ForLiquidity(_currentSqrtPrice, tickSqrtPrice, _totalLiquidityAmount, false);

        if (pairStatus.isQuoteZero) {
            deltaPositionQuote = -deltaPosition0;
            deltaPositionBase = -deltaPosition1;
        } else {
            deltaPositionBase = -deltaPosition0;
            deltaPositionQuote = -deltaPosition1;
        }

        updateRebalancePosition(pairStatus, deltaPosition0, deltaPosition1);
    }
```
