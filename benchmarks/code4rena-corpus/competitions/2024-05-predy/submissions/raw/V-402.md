# Vulnerability details

## Impact
The `sell()` and `buy()` functions in the `SettlementCallbackLib` library have incorrect token transfer logic when `settlementParams.contractAddress == address(0)`. This results in the user supplying and receiving the wrong tokens during direct fills.

## Proof of Concept
When selling, the user should:
- Supply `baseToken`.
- Receive `quoteToken`.
However, the opposite is done in [sell()](https://github.com/code-423n4/2024-05-predy/blob/a9246db5f874a91fb71c296aac6a66902289306a/src/base/SettlementCallbackLib.sol#L99-L108):
```solidity
    if (settlementParams.contractAddress == address(0)) {
            // direct fill
            uint256 quoteAmount = sellAmount * price / Constants.Q96;

            predyPool.take(false, sender, sellAmount); // @audit-issue User receives baseToken

            ERC20(quoteToken).safeTransferFrom(sender, address(predyPool), quoteAmount); @audit-issue User supplies quoteToken

            return;
        }
```


When buying, the user should:
- Supply `quoteToken`.
- Receive `baseToken`.
However, the opposite is done in [buy()](https://github.com/code-423n4/2024-05-predy/blob/a9246db5f874a91fb71c296aac6a66902289306a/src/base/SettlementCallbackLib.sol#L146-L155):
```solidity
    if (settlementParams.contractAddress == address(0)) {
            // direct fill
            uint256 quoteAmount = buyAmount * price / Constants.Q96;

            predyPool.take(true, sender, quoteAmount); // @audit-issue User receives quoteToken

            ERC20(baseToken).safeTransferFrom(sender, address(predyPool), buyAmount); // @audit-issue User supplies baseToken

            return;
        }
```
As seen, the whole logic is incorrect resulting incorrect trade executions.

## Recommended Mitigation Steps
Correct this as follows:

`sell()`
```solidity
uint256 quoteAmount = sellAmount * price / Constants.Q96;
predyPool.take(true, sender, quoteAmount); // @audit User takes quote tokens
ERC20(baseToken).safeTransferFrom(sender, address(predyPool), sellAmount); // @audit User supplies base tokens
````

`buy()`
```solidity
uint256 baseAmount = buyAmount * price / Constants.Q96;
predyPool.take(true, sender, baseAmount ); // @audit User takes baseToken
ERC20(quoteToken).safeTransferFrom(sender, address(predyPool), buyAmount); // @audit User supplies quoteToken
````
