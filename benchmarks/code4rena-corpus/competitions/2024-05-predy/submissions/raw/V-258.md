# Vulnerability details

## Impact
During `pool` creation, the `operator` sets the `poolOwner` address. The `poolOwner` therefore takes control of all modifications pertaining to the  pool given by `pairId`.

If `quote token` address is not registered yet i.e `_quoteTokenMap[pairId] == address(0)`, it means that trading in this `pool` is not yet allowed. However, `updateQuoteTokenMap()` in `BaseMarket` contract allows anyone to register `quote token` address for the pair which may be against the `poolOwner`.

Therefore, any user will be in a position to initiate trading in any `pool` by registering `quote token` address for these pairs without permission.

## Vulnerability Details
[updateQuoteTokenMap()](https://github.com/code-423n4/2024-05-predy/blob/a9246db5f874a91fb71c296aac6a66902289306a/src/base/BaseMarket.sol#L96-L101) :
```solidity
    /// @notice Registers quote token address for the pair
    function updateQuoteTokenMap(uint256 pairId) external { // @audit-issue No access control
        if (_quoteTokenMap[pairId] == address(0)) {
            _quoteTokenMap[pairId] = _getQuoteTokenAddress(pairId);
        }
    }
```
As seen here, there is no access control whatsoever implemented for this function allowing anyone to register `quote token` address for the pair.

##### Note:
`poolOwner` is tasked with all duties pertaining to `pairId`. These include:
1. [updateAssetRiskParams()](https://github.com/code-423n4/2024-05-predy/blob/a9246db5f874a91fb71c296aac6a66902289306a/src/PredyPool.sol#L121)
2. [updateIRMParams()](https://github.com/code-423n4/2024-05-predy/blob/a9246db5f874a91fb71c296aac6a66902289306a/src/PredyPool.sol#L137)
3. [updateFeeRatio()](https://github.com/code-423n4/2024-05-predy/blob/a9246db5f874a91fb71c296aac6a66902289306a/src/PredyPool.sol#L147)
4. [updatePoolOwner()](https://github.com/code-423n4/2024-05-predy/blob/a9246db5f874a91fb71c296aac6a66902289306a/src/PredyPool.sol#L157)
5. [updatePriceOracle()](https://github.com/code-423n4/2024-05-predy/blob/a9246db5f874a91fb71c296aac6a66902289306a/src/PredyPool.sol#L167)
6. [withdrawCreatorRevenue()](https://github.com/code-423n4/2024-05-predy/blob/a9246db5f874a91fb71c296aac6a66902289306a/src/PredyPool.sol#L199)

As such, `updateQuoteTokenMap()` should as well be one of his roles.

## Tools Used
Manual Review

## Recommended Mitigation Steps
Add `onlyPoolOwner` modifier to this function to restrict this action to only the `poolOwner`.
```diff
-   function updateQuoteTokenMap(uint256 pairId) external {
+   function updateQuoteTokenMap(uint256 pairId) external onlyPoolOwner(pairId) {
        if (_quoteTokenMap[pairId] == address(0)) {
            _quoteTokenMap[pairId] = _getQuoteTokenAddress(pairId);
        }
    }
```
