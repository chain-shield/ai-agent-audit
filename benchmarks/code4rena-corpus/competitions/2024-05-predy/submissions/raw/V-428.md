# Vulnerability details

## Impact
Stale price feed data when reading from Pyth price feed oracle. This can become an issue with bots and arbitrage traders

## Proof of Concept
Pyth price feeds are different than Chainlink in that they are `pull` oracles while chainlink is a `push` oracle by design. Please check the [Pyth documentation](https://docs.pyth.network/price-feeds/pull-updates) for more details and explanation.

## Tools Used
Manual Review

## Recommended Mitigation Steps
When using Pyth feeds it is recommended to call the `PythPriceFeed:: updatePriceFeeds` function before reading the price feed to guarantee the price data is up to date. 


## Assessed type

Oracle
