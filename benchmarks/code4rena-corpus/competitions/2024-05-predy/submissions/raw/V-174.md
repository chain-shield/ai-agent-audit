# Vulnerability details

## Impact
The __createPriceFeed__ function in the __PriceFeedFactory__ contract does not validate the input parameters. Specifically, there are no checks to ensure that the __quotePrice__ address is valid, the __priceId__ is not zero, and __decimalsDiff__ is a valid non-zero value. This lack of validation can lead to several issues:

-Deployment of Malicious Contracts: Attackers can pass in malicious addresses, leading to the deployment of __PriceFeed__ contracts with malicious intent.
-Unexpected Behavior: Invalid inputs can cause the contract to behave unpredictably, which can affect its reliability and security.
-Financial Losses: Incorrect input values can lead to incorrect calculations in the __PriceFeed__ contract, potentially resulting in significant financial losses for users relying on accurate price feeds.

## Proof of Concept
1.Setup: Assume an attacker wants to exploit the createPriceFeed function by providing invalid inputs.
2.Invalid Address: The attacker calls __createPriceFeed__ with an invalid __quotePrice__ address, such as 0x0000000000000000000000000000000000000000.
priceFeedFactory.createPriceFeed(0x0000000000000000000000000000000000000000, somePriceId, someDecimalsDiff);

3.Effect on __PriceFeed__ Contract: The __PriceFeed__ contract is deployed with the invalid __quotePrice__ address, leading to potential failures when it tries to fetch the latest round data.

4.Incorrect Calculations: Due to the invalid __quotePrice__, the __getSqrtPrice__ function in __PriceFeed__ will fail to get valid data, resulting in incorrect calculations.
(, int256 quoteAnswer,,,) = AggregatorV3Interface(_quotePriceFeed).latestRoundData();
// This will fail if _quotePriceFeed is an invalid address


5.Financial Loss: Users relying on the __getSqrtPrice__ function for financial transactions will receive incorrect price data, leading to potential financial losses.

Example:
If the __getSqrtPrice__ function returns an incorrect value due to invalid input, a trading bot or a decentralized finance (DeFi) protocol might execute trades based on this faulty data, causing significant financial losses.

## Recommended Mitigation Steps

Add Proper Input Validation:
Ensure that all input parameters in the __createPriceFeed__ function are validated to prevent invalid data from being processed.

1.Validate __quotePrice__ Address:
Ensure that the __quotePrice__ address is not a zero address.
require(quotePrice != address(0), "Invalid quote price address");

2.Validate __priceId__:
Ensure that the priceId is not a zero value.
require(priceId != bytes32(0), "Invalid price ID");

3.Validate __decimalsDiff__:
Ensure that __decimalsDiff__ is a valid non-zero value.
require(decimalsDiff > 0, "Invalid decimals difference");

Implement Access Control:
Restrict access to the __createPriceFeed__ function to prevent unauthorized entities from calling it.
