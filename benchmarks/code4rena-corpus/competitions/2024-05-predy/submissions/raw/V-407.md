# Vulnerability details

## Proof of Concept
The `getSqrtPrice` function in the `PriceFeed` contract fetches price data from two different oracles: Chainlink and Pyth. It then calculates the square root of the price of a base token in terms of a quote token. However, the precision of the prices returned from these oracles is not explicitly specified or verified, leading to potential inconsistencies and inaccuracies in price calculations.

The code assumes that the Pyth contract provides prices with an exponent of -8 (i.e., prices are quoted with 8 decimal places), but there is no mechanism to enforce or verify this precision within the function. This lack of explicit precision handling can lead to incorrect calculations if the price precision from the oracles differs from the assumed values.

Here is the relevant code snippet from the PriceFeed contract:
```solidity
    function getSqrtPrice() external view returns (uint256 sqrtPrice) {
        (, int256 quoteAnswer,,,) = AggregatorV3Interface(_quotePriceFeed).latestRoundData();

        IPyth.Price memory basePrice = IPyth(_pyth).getPriceNoOlderThan(_priceId, VALID_TIME_PERIOD);

        require(basePrice.expo == -8, "INVALID_EXP");

        require(quoteAnswer > 0 && basePrice.price > 0);

        uint256 price = uint256(int256(basePrice.price)) * Constants.Q96 / uint256(quoteAnswer);
        price = price * Constants.Q96 / _decimalsDiff;

        sqrtPrice = FixedPointMathLib.sqrt(price);
    }
```
The precision of prices returned from oracles is not explicitly specified. The code relies on the assumption that the Pyth contract provides prices with an exponent of $-8$. However, there is no direct verification or specification of the precision of prices returned from the oracles involved in the price calculation process.
## Impact
If the precision of prices from the oracles does not match the assumed precision, the calculated square root price may be significantly incorrect. This can lead to inaccurate pricing information being used in downstream applications, potentially resulting in financial losses or erroneous decision-making.
