# Vulnerability details

## Impact
The `liquidate` function in the `LiquidationLogic` library does not validate the `tradeResult` to ensure it was successful. If the trade fails, this could lead to incorrect state updates, resulting in discrepancies in the vault margin and other critical state variables. This oversight could potentially lead to financial losses or unintended behaviors in the protocol, as failed trades may go unnoticed and cause the system to operate on incorrect data.

## Proof of Concept
In the provided code snippet, the `tradeResult` is used to update the vault margin without any validation to ensure the trade was successful.

##### Affected Code Snippet:
```solidity
tradeResult = Trade.trade(globalData, tradeParams, settlementData);

vault.margin += tradeResult.fee + tradeResult.payoff.perpPayoff + tradeResult.payoff.sqrtPayoff;

// Missing validation check for tradeResult success
```
## Tools Used
Manual

## Recommended Mitigation Steps
Add a validation check for `tradeResult.success` before updating the vault margin to ensure that only successful trades affect the state.


```solidity
tradeResult = Trade.trade(globalData, tradeParams, settlementData);

// Validate the success of the trade result
require(tradeResult.success, "Trade Failed");

vault.margin += tradeResult.fee + tradeResult.payoff.perpPayoff + tradeResult.payoff.sqrtPayoff;
```
