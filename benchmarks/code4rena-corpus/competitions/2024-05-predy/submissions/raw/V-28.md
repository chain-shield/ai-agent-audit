# Vulnerability details

## Impact
Detailed description of the impact of this finding.
### Vulnerability: Unrestricted Access & Incorrect or Malicious Data in `updateQuoteTokenMap` Function

**Description:**

The `updateQuoteTokenMap` function in the `BaseMarketUpgradable` contract is vulnerable to unrestricted access, which can lead to incorrect or malicious data being registered in the `_quoteTokenMap` mapping. This function allows any caller to register a quote token address for a given `pairId` without any access control or validation checks. 

**Details:**

- **Unrestricted Access:** The function lacks access control modifiers, allowing any external account to call it. This can lead to unauthorized users registering quote token addresses.
- **Incorrect or Malicious Data:** Since there is no validation on the input `pairId`, an attacker can register incorrect or malicious quote token addresses, potentially disrupting the contract's functionality.
- **Data Integrity:** The function does not verify if the `_quoteTokenMap[pairId]` is already correctly set, which can lead to overwriting valid data with incorrect data.

**Code Snippet:**
```solidity
function updateQuoteTokenMap(uint256 pairId) external {
    if (_quoteTokenMap[pairId] == address(0)) {
        _quoteTokenMap[pairId] = _getQuoteTokenAddress(pairId);
    }
}
```

**Impact:**

- **Security Risk:** Unauthorized users can manipulate the `_quoteTokenMap`, leading to potential financial losses or disruption of the contract's operations.
- **Data Integrity:** Incorrect or malicious data can be registered, causing the contract to behave unexpectedly or fail.

**Recommendation:**

- Implement access control mechanisms to restrict who can call the `updateQuoteTokenMap` function.
- Add validation checks to ensure the `pairId` and the corresponding quote token address are correct and valid before updating the `_quoteTokenMap`.

## Recommended Mitigation Steps
### Recommendation: Secure and Validate `updateQuoteTokenMap` Function

To address the identified vulnerabilities in the `updateQuoteTokenMap` function, we recommend implementing the following changes:

1. **Access Control:** Restrict the function to be callable only by authorized accounts, such as the contract owner or a designated admin.
