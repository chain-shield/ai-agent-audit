# Vulnerability details

## Impact
`PerpMarketLib::validateStopPrice()` method uses the return value of `PerpMarketLib::ratio(oraclePrice, stopPrice)` as the last parameter to call `DecayLib.decay2()` to calculate `decayedSlippageTorelance`. However, the return value of `PerpMarketLib::ratio()` is a ratio value based on the base point (Bps.ONE), not the timestamp expected by the method.

### PerpMarketLib::ratio()
The return value of this method is a base point based on the base number.
```js
    function ratio(uint256 price1, uint256 price2) internal pure returns (uint256) {
        if (price1 == price2) {
            return 0;
        } else if (price1 > price2) {
            return (price1 - price2) * Bps.ONE / price2;
        } else {
            return (price2 - price1) * Bps.ONE / price2;
        }
    }
```
