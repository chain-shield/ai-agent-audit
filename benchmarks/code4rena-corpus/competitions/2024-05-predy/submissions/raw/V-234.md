# Vulnerability details

## Impact
```solidity
    function getSqrtPrice() external view returns (uint256 sqrtPrice) {
        (, int256 quoteAnswer,,,) = AggregatorV3Interface(_quotePriceFeed).latestRoundData();
```

`PriceFeed.getSqrtPrice()` uses the `quoteAnswer` returned from the price feed but never checks the data's freshness. This can lead to using stale quote token prices.

As a result, the protocol might make decisions based on outdated prices, potentially causing losses.

## Tools Used
Manual Review

## Recommended Mitigation Steps
Make sure the prices returned from the price feed are recent enough:

```diff
-   (, int256 quoteAnswer,,,) = AggregatorV3Interface(_quotePriceFeed).latestRoundData();
+   (, int256 quoteAnswer,, uint256 updatedAt,) = AggregatorV3Interface(_quotePriceFeed).latestRoundData();

+   require(block.timestamp < updatedAt + MAX_DELAY, "stale price"); 
```
