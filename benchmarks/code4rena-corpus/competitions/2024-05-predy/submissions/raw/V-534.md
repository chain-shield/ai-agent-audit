# Vulnerability details

## Impact
When the vault is liquidated and the remaining margin is negative, the liquidator compensates any losses that can not be covered by the vault to prevent the liquidator from unfairly profiting. 

```solidity
} else if (remainingMargin < 0) {
                vault.margin = 0;

                // To prevent the liquidator from unfairly profiting through arbitrage trades in the AMM and passing losses onto the protocol,
                // any losses that cannot be covered by the vault must be compensated by the liquidator
                ERC20(pairStatus.quotePool.token).safeTransferFrom(msg.sender, address(this), uint256(-remainingMargin)); 
            }
```

The problem is that when the execLiquidation function is called in the gammaTradeMarket, quote tokens are taken from the gammaTradeMarket, not the liquidator, because the msg.sender will be the gammaTradeMarket.

```solidity
function execLiquidationCall(
        uint256 vaultId,
        uint256 closeRatio,
        IFillerMarket.SettlementParamsV3 memory settlementParams
    ) external override returns (IPredyPool.TradeResult memory tradeResult) {
        tradeResult =
            _predyPool.execLiquidationCall(vaultId, closeRatio, _getSettlementDataFromV3(settlementParams, msg.sender));

        if (closeRatio == 1e18) {
            _removePosition(vaultId);
        }
    }
```

Because the liquidator does not compensate for losses, the liquidator takes advantage and profits through arbitrage trades and can pass losses onto the protocol.
