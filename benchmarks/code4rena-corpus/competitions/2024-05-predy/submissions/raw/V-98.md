# Vulnerability details

## Impact
`updatePosition` function is responsible for updating the position of a user or a rebalance position in the respective pool (quote or base). If the wrong update amount is passed to the function, it can lead to incorrect position updates, which can have severe consequences.

If the rebalance positions are not updated correctly, it can result in a discrepancy between the actual positions and the recorded positions. This discrepancy can lead to potential loss of funds, as the recorded positions may not accurately reflect the true state of the positions.

## Proof of Concept
Suppose `_pairStatus.isQuoteZero` is `true`, and the intended behavior is to update the quote pool's rebalance position with `_updateAmount0` and the base pool's rebalance position with `_updateAmount1`.

In the `if` block, the code correctly updates the positions: [updateRebalancePosition#L798-L803](https://github.com/code-423n4/2024-05-predy/blob/2fb1e0ec7a52fc06c2e9c8e561bccba84302e4bb/src/libraries/Perp.sol#L798-L803)
```solidity
_pairStatus.quotePool.tokenStatus.updatePosition(
    sqrtAsset.rebalancePositionQuote, _updateAmount0, _pairStatus.id, true
);
_pairStatus.basePool.tokenStatus.updatePosition(
    sqrtAsset.rebalancePositionBase, _updateAmount1, _pairStatus.id, false
);
```
In the `else` block, the order of arguments is swapped: [updateRebalancePosition#L805-L810](https://github.com/code-423n4/2024-05-predy/blob/2fb1e0ec7a52fc06c2e9c8e561bccba84302e4bb/src/libraries/Perp.sol#L805-L810)
```solidity
_pairStatus.basePool.tokenStatus.updatePosition(
    sqrtAsset.rebalancePositionBase, _updateAmount0, _pairStatus.id, false
);
_pairStatus.quotePool.tokenStatus.updatePosition(
    sqrtAsset.rebalancePositionQuote, _updateAmount1, _pairStatus.id, true
);
```
In this case, the base pool's rebalance position will be updated with `_updateAmount0` instead of `_updateAmount1`, and the quote pool's rebalance position will be updated with `_updateAmount1` instead of `_updateAmount0`. This can lead to incorrect position updates and the potential issues mentioned above.

## Tools Used
Manual Review

## Recommended Mitigation Steps
The order of the arguments should be consistent in both the `if` and `else` blocks, or the logic should be refactored to ensure that the correct update amounts are passed to the respective pool's `updatePosition` function.
