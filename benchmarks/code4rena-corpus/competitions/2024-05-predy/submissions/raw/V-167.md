# Vulnerability details

## Impact
User can use trade with an disabled pair, this is not intended by the protocol.


## Proof of Concept
PredyPool.sol contract, in trade function, line 272. The protocol revert if the list is enabled and the trader isn't allowed. But it doesn't revert if the list is disabled.

    if (globalData.pairs[tradeParams.pairId].allowlistEnabled && !allowedTraders[msg.sender][tradeParams.pairId]) {
            revert TraderNotAllowed();
        }
