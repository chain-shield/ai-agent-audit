# Vulnerability details

## Impact
Loss of funds for the market since users can gain tokens at no cost

## Proof of Concept
https://github.com/code-423n4/2024-05-predy/blob/2fb1e0ec7a52fc06c2e9c8e561bccba84302e4bb/src/markets/spot/SpotMarket.sol#L246-L247
When executing an order in the spot market, users provide the parameters through `SettlementParams`
```
 function executeOrder(SignedOrder memory order, SettlementParams memory settlementParams)
        external
        returns (int256 quoteTokenAmount)
    {
        SpotOrder memory spotOrder = abi.decode(order.order, (SpotOrder));

        return _executeOrder(spotOrder, order.sig, settlementParams);
    }
```
```
struct SettlementParams {
        address contractAddress;
        bytes encodedData;
        uint256 maxQuoteAmount;
        uint256 price;
        int256 fee;
    }
```

Among these parameters is the fee for the order to be completed. However, during the process of completing the order within `_executeSettlement`, the fees are transferred to the user if its value is >0.
```
 function _execSettlement(
        address quoteToken,
        address baseToken,
        SettlementParams memory settlementParams,
        int256 baseAmountDelta
    ) internal {
        if (settlementParams.fee < 0) {
            ERC20(quoteToken).safeTransferFrom(msg.sender, address(this), uint256(-settlementParams.fee));
        }

       
        if (baseAmountDelta > 0) {
            _execSell(quoteToken, baseToken, settlementParams, settlementParams.price, uint256(baseAmountDelta));
        } else if (baseAmountDelta < 0) {
            _execBuy(quoteToken, baseToken, settlementParams, settlementParams.price, uint256(-baseAmountDelta));
        }

@>       if (settlementParams.fee > 0) {
            ERC20(quoteToken).safeTransfer(msg.sender, uint256(settlementParams.fee));

```
Since this parameter is provided by the user and there is no alteration to the value of fees throughout the execution of the order, then the provided amount is what gets transferred to the user. A user can input any arbitrary amount as fee and receive that value during the process of execution.
