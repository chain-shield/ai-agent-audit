# Vulnerability details

## Impact
Malicious user can easily profit off price difference between two tokens by using a false decimalsDiff between the 2.

## Proof of Concept
https://github.com/code-423n4/2024-05-predy/blob/2fb1e0ec7a52fc06c2e9c8e561bccba84302e4bb/src/PriceFeed.sol#L20-L26

https://github.com/code-423n4/2024-05-predy/blob/2fb1e0ec7a52fc06c2e9c8e561bccba84302e4bb/src/libraries/logic/AddPairLogic.sol#L115-L119

`PriceFeedFactory.createPriceFeed` allows the creation of price feeds for token pairs. This functions lacks any access control therefore pricefeeds can be created by any user.
```
@> function createPriceFeed(address quotePrice, bytes32 priceId, uint256 decimalsDiff) external returns (address) {
        PriceFeed priceFeed = new PriceFeed(quotePrice, _pyth, priceId, decimalsDiff);

        emit PriceFeedCreated(quotePrice, priceId, decimalsDiff, address(priceFeed));

        return address(priceFeed);
    }
```
The user can also update the pricefeed for any token pair at any time in `AddPairLogic.updatePriceOracle` since this also lacks an access control
```
    function updatePriceOracle(DataType.PairStatus storage _pairStatus, address _priceOracle) external {
        _pairStatus.priceFeed = _priceOracle;

        emit PriceOracleUpdated(_pairStatus.id, _priceOracle);
    }

```
One of the parameters which `PriceFeedFactory.createPriceFeed` takes is the decimal difference between both tokens which is important to scale the price of between both tokens when retrieving the price from the oracle.

```
function getSqrtPrice() external view returns (uint256 sqrtPrice) {
                (, int256 quoteAnswer,,,) = AggregatorV3Interface(_quotePriceFeed).latestRoundData();

        
        IPyth.Price memory basePrice = IPyth(_pyth).getPriceNoOlderThan(_priceId, VALID_TIME_PERIOD);

    
        require(basePrice.expo == -8, "INVALID_EXP");

        require(quoteAnswer > 0 && basePrice.price > 0);

        uint256 price = uint256(int256(basePrice.price)) * Constants.Q96 / uint256(quoteAnswer);

        
@>       price = price * Constants.Q96 / _decimalsDiff;
```
Expectedly this parameter would normalize the price between both tokens. For example if `basePrice` has a decimal of 18 and quoteAnswer returns its price as 1e8. `_decimalsDiff` of 10 would allow normalizing the price. However, what if a user sets this value as 1. This would cause the price of basetoken to be exponentially higher than it should be. This can then be used to profit through trades, swaps and other activities.
