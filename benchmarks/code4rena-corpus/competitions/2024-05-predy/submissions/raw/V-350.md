# Vulnerability details

## Impact
In the `withdrawProtocolRevenue` function, transferring accumulated protocol revenue directly to `msg.sender` can cause transactions to revert if msg.sender is blacklisted by certain ERC20 tokens like `USDC`. This can disrupt the withdrawal process and affect the operator's ability to access the protocol's revenue.

If `msg.sender` is blacklisted, the safeTransfer call will revert, preventing the successful withdrawal of protocol revenue. This can lead to operational disruptions, especially if the protocol relies on consistent revenue withdrawals for liquidity or operational expenses.

## Proof of Concept
Consider a scenario where the operator is attempting to withdraw USDC and their address is blacklisted:

The operator calls withdrawProtocolRevenue.
The function attempts to transfer USDC directly to msg.sender.
Since msg.sender is blacklisted by the USDC token contract, the safeTransfer call reverts.
The withdrawal fails, and the protocol revenue remains locked.

 ```javascript
/**
 * @notice Withdraws accumulated protocol revenue.
 * @dev Only operator can call this function.
 * @param pairId The id of pair
 * @param isQuoteToken Is quote or base
 */
function withdrawProtocolRevenue(uint256 pairId, bool isQuoteToken) external onlyOperator {
    Perp.AssetPoolStatus storage pool = _getAssetStatusPool(pairId, isQuoteToken);

    uint256 amount = pool.accumulatedProtocolRevenue;
    require(amount > 0, "AZ");

    pool.accumulatedProtocolRevenue = 0;

    // This transfer can fail if msg.sender is blacklisted
    ERC20(pool.token).safeTransfer(msg.sender, amount);

    emit ProtocolRevenueWithdrawn(pairId, isQuoteToken, amount);
}
```

## Recommended Mitigation Steps
To mitigate this issue, introduce an `address _to` parameter to specify the recipient of the withdrawn funds to avoid using `msg.sender` this way if msg.sender is blacklisted they just provide an `address _to`. 

```javascript
 function withdrawCreatorRevenue(uint256 pairId, bool isQuoteToken, address _to) external onlyPoolOwner(pairId)
```
