# Vulnerability details

## Impact
The UniswapSettlement contract is vulnerable to an approval race condition. This issue arises because the contract approves the exact amount required for a swap on every call. If the approval transaction is mined before the transfer, it can lead to a race condition where funds might get stuck. Additionally, this vulnerability can be exploited by re-entrancy attacks, potentially allowing an attacker to manipulate the approval process and drain funds.

## Proof of Concept
1- Approval Call:
The contract calls approve to set the allowance for the swap router. This is done each time the function is executed.

2- Race Condition:
If the approval transaction is mined before the transfer transaction, an attacker could potentially trigger a re-entrancy attack, manipulating the approval process and causing the funds to get stuck or drained.

Steps to Reproduce
Deploy the UniswapSettlement contract.
Execute the swapExactIn function.
Observe that the approval is done on each call, which can be intercepted to create a race condition.
## Tools Used
Manual Review

## Recommended Mitigation Steps
1- Approve Maximum Limit Once:
Approve a maximum limit once and reuse it for subsequent transactions.

// In the constructor or initialization function
ERC20(baseToken).approve(address(_swapRouter), type(uint256).max);

2- Set Allowance to Zero Before Setting Desired Amount:
Explicitly set the allowance to zero before setting it to the desired amount.

function swapExactIn(
    address,
    address baseToken,
    bytes memory data,
    uint256 amountIn,
    uint256 amountOutMinimum,
    address recipient
) external override returns (uint256 amountOut) {
    ERC20(baseToken).safeTransferFrom(msg.sender, address(this), amountIn);
    ERC20(baseToken).approve(address(_swapRouter), 0); // Reset approval
    ERC20(baseToken).approve(address(_swapRouter), amountIn); // Set desired amount

    amountOut = _swapRouter.exactInput(
        ISwapRouter.ExactInputParams(data, recipient, block.timestamp, amountIn, amountOutMinimum)
    );
}
