# Vulnerability details

## Impact
The `getSqrtPrice` function in the `PriceFeed` contract retrieves the latest round data from the `AggregatorV3Interface` and uses the `quoteAnswer` value to calculate the square root price of the base token quoted in the quote token.

However, the function does not check the freshness of the data, which can lead to stale data being used.

## Proof of Concept
```solidity
        (, int256 quoteAnswer,,,) = AggregatorV3Interface(_quotePriceFeed).latestRoundData();
```

The `getSqrtPrice` function fetches `quoteAnswer` using `latestRoundData` from `AggregatorV3Interface`.

```solidity
    function latestRoundData()
        external
        view
        returns (uint80 roundId, int256 answer, uint256 startedAt, uint256 updatedAt, uint80 answeredInRound);
```

There is no check to ensure that the data retrieved is recent.

The absence of a staleness check can lead to the use of outdated `quoteAnswer` values, compromising the accuracy of the square root price calculation.

## Tools Used
Manual review

## Recommended Mitigation Steps
A freshness check should be added to ensure that the data is recent and reliable.
This can be achieved by comparing the `updatedAt` timestamp returned by `latestRoundData` with the current block timestamp and rejecting data that exceeds a predefined staleness threshold.
