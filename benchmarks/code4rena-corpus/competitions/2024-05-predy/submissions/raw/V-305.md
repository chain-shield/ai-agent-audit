# Vulnerability details

## Impact

As the [filler](https://docs.predy.finance/predy-v6/dev/architecture#filler) is the one who makes sure that the traders' orders are executed, it is of utter importance for them to be available at all times. However, they are able to resign from the position in order to revert any execution of trades, or even worse - they can create a new contract, which can make them a profit by utilizing the incoming orders for the filler.

## Proof of Concept

When deploying a new market, within the constructor of both [BaseMarket](https://github.com/code-423n4/2024-05-predy/blob/main/src/base/BaseMarket.sol) and [BaseMarketUpgradeable](https://github.com/code-423n4/2024-05-predy/blob/main/src/base/BaseMarketUpgradable.sol), the `whitelistFiller` address gets set and can only be updated using the function `updateWhitelistSettlement` ([BaseMarket](https://github.com/code-423n4/2024-05-predy/blob/main/src/base/BaseMarket.sol#L92-L94), [BaseMarketUpgradeable](https://github.com/code-423n4/2024-05-predy/blob/main/src/base/BaseMarketUpgradable.sol#L128-L130)), which is access controlled by the [onlyFiller](https://github.com/code-423n4/2024-05-predy/blob/main/src/base/BaseMarketUpgradable.sol#L31-L34) modifier. Nevertheless, calling [updateWhitelistSettlement](https://github.com/code-423n4/2024-05-predy/blob/main/src/base/BaseMarketUpgradable.sol#L128-L130) in `BaseMarketUpgradeable` would allow a malicious filler to resign from their role by calling that same function and setting the `whitelistFiller` to `address(0)` -  making any trades in `PerpMarketV1` and `GammaTradeMarket` revert, as a filler simply wouldn't exist.

- [_executeOrderV3](https://github.com/code-423n4/2024-05-predy/blob/main/src/markets/perp/PerpMarketV1.sol#L200-L205) in `PerpMarketV1`:
```solidity
...
if (tradeResult.minMargin > 0) {
    // only whitelisted filler can open position
    if (msg.sender != whitelistFiller) {
     revert CallerIsNotFiller();
   }
}
...
```
- [_executeTrade](https://github.com/code-423n4/2024-05-predy/blob/main/src/markets/gamma/GammaTradeMarket.sol#L178-L183) in `GammaTradeMarket`
```solidity
if (tradeResult.minMargin > 0) {
    // only whitelisted filler can open position
    if (msg.sender != whitelistFiller) {
     revert CallerIsNotFiller();
   }
}
```

The `filler`'s other option is to create a contract that will profit from every order they would have to carry out. Besides having to create the contract, they would only have to call `updateWhitelistSettlement` and assign their malicious contract. The end result is profit for them and loss for the protocol and the users.

Even though the [BaseMarket](https://github.com/code-423n4/2024-05-predy/blob/main/src/base/BaseMarket.sol) contract is mentioned in the report, it has proper access control, where the function `whitelistFiller` can only be called by the [owner](https://github.com/code-423n4/2024-05-predy/blob/main/src/base/BaseMarket.sol#L84C73). As the only trusted roles in the protocol are the `operator` and the `pool owner`, the function has to be updated with valid access control.

## Recommended Mitigation Steps

Consider implementing the following changes to [updateWhitelistSettlement](https://github.com/code-423n4/2024-05-predy/blob/main/src/base/BaseMarketUpgradable.sol#L128-L130) and the [BaseMarketUpgradable](https://github.com/code-423n4/2024-05-predy/blob/main/src/base/BaseMarketUpgradable.sol): Firstly, import the [Owned](https://github.com/transmissions11/solmate/blob/main/src/auth/Owned.sol) library (used by `BaseMarket`), make the contract inherit it from it, and initialize the `Owned` contract in [__BaseMarket_init](https://github.com/code-423n4/2024-05-predy/blob/main/src/base/BaseMarketUpgradable.sol#L38-L47) as this would set the `Owner`. Secondly, change `updateWhitelistSettlement`'s code as follows:

```diff
-    function updateWhitelistSettlement(address settlementContractAddress, bool isEnabled) external onlyFiller {
+    function updateWhitelistSettlement(address settlementContractAddress, bool isEnabled) external onlyOwner {
        _whiteListedSettlements[settlementContractAddress] = isEnabled;
    }
```
