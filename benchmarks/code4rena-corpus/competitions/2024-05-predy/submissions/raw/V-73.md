# Vulnerability details

## Impact
If the `PerpOrderV3Lib.resolve` does not properly validate the signature or allows an empty `bytes("") `as a valid signature, it could enable an attacker to execute orders without proper authorization. 

_An attacker could potentially execute unauthorized trades, leading to the loss of funds held in user positions or the contract itself._

```solidity
function resolve(PerpOrderV3 memory perpOrder, bytes memory sig) internal pure returns (ResolvedOrder memory) {
    return ResolvedOrder(perpOrder.info, perpOrder.entryTokenAddress, perpOrder.marginAmount, hash(perpOrder), sig);
}
```
In the `quoteExecuteOrderV3`, `PerpOrderV3Lib.resolve` is called with an empty `bytes("")` as the signature. The resolve function does not properly validate the signature or allow an empty `bytes("")` as a valid signature.

## Proof of Concept
Assume that the `resolve` does not validate the signature and returns a `ResolvedOrder` struct with the provided signature, even if it's an empty `bytes("")`. In this case, an attacker could call the `quoteExecuteOrderV3` with a crafted `PerpOrderV3` struct and an empty `bytes("")` as the signature, which would bypass any signature verification and allow the attacker to execute unauthorized trades.

```solidity
// Attacker's code
PerpOrderV3 maliciousOrder = PerpOrderV3(
    // Crafted order details
    ...
);

// Call quoteExecuteOrderV3 with an empty signature
perpMarket.quoteExecuteOrderV3(maliciousOrder, SettlementParamsV3(...), attacker);
```
If the `resolve` function does not properly validate the signature, the `quoteExecuteOrderV3` would execute the trade based on the attacker's crafted `PerpOrderV3` struct.

## Tools Used
Vs

## Recommended Mitigation Steps
The `PerpOrderV3Lib.resolve` function should be reviewed and updated to ensure that it properly validates the provided signature. It should not allow an empty `bytes("")` as a valid signature unless explicitly intended. Additionally, the `quoteExecuteOrderV3` function should be updated to obtain the signature from a trusted source (e.g., a signed order struct) before calling `PerpOrderV3Lib.resolve`.
