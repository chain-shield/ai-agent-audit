# Vulnerability details

## Impact
When a position is closed or liquidated, its `positionId` is removed from `positionIDs[user]` array. 

https://github.com/code-423n4/2024-05-predy/blob/a9246db5f874a91fb71c296aac6a66902289306a/src/markets/gamma/GammaTradeMarket.sol#L99

https://github.com/code-423n4/2024-05-predy/blob/a9246db5f874a91fb71c296aac6a66902289306a/src/markets/gamma/GammaTradeMarket.sol#L147

But when the user reuses that `positionId` in `executeTrade`, the `positionId` is not added back to `positionIDs[user]` array because of the check at 

https://github.com/code-423n4/2024-05-predy/blob/a9246db5f874a91fb71c296aac6a66902289306a/src/markets/gamma/GammaTradeMarket.sol#L197-L201

As a result, the user can not close the new position because the `positionId` can not be found when looping through `positionIDs[user]`. The user can only claim his money back when the position is liquidated through `PredyPool::execLiquidationCall`.

On the frontend, the protocol can prevent users from open a new position on an old `positionId`, users can only execute a trade on a `positionId` that has not been closed or liquidated yet. If the users try to open a new position on the old `positionId`, then it would consider a user error.

But consider this scenario, Alice saw her vault is currently in danger, she sign an order to add more margin to the position. Bob has liquidated the position through `GammaTradeMarket::execLiquidationCall` before the filler could fill the order. Then the filler execute the trade with the old `positionId`, leading to Alice's fund got locked.

## Proof of Concept
```solidity
// SPDX-License-Identifier: UNLICENSED
pragma solidity ^0.8.0;

import "./market/gamma/Setup.t.sol";
import {MockPriceFeed} from "./mocks/MockPriceFeed.sol";
import {Constants} from "../src/libraries/Constants.sol";

contract TestGammaExecuteOrder is TestGammaMarket {
    uint256 alicePrivateKey;
    address alice;

    MockPriceFeed private _priceFeed;

    function setUp() public override {
        TestGammaMarket.setUp();

        _priceFeed = new MockPriceFeed();

        _priceFeed.setSqrtPrice(Constants.Q96);

        registerPair(address(currency1), address(_priceFeed));
        gammaTradeMarket.updateQuoteTokenMap(1);

        predyPool.supply(1, true, 1e10);
        predyPool.supply(1, false, 1e10);

        alicePrivateKey = 0x12341234;
        alice = vm.addr(alicePrivateKey);

        currency1.mint(alice, type(uint128).max);

        vm.prank(alice);
        currency1.approve(address(permit2), type(uint256).max);
    }

    function testExecuteOrderSucceedsForOpen() public {
        // Alice opens a new position
        {
            GammaOrder memory order =
                _createOrder(alice, 0, block.timestamp + 100, 1, 0, 2e6, 0, 2e6, Constants.Q96);
            gammaTradeMarket.executeTrade(order, _sign(order, alicePrivateKey), _getSettlementDataV3(Constants.Q96));
        }

        // Price change making Alice's vault in danger
        _priceFeed.setSqrtPrice(5 * Constants.Q96 / 10);

        // Alice signs an order to add more margin
        GammaOrder memory order =
                _createOrder(alice, 1, block.timestamp + 100, 1, 1, 2e6, 0, 5e6, Constants.Q96);

        // Bob liquidate the position before the filler can fill the order
        gammaTradeMarket.execLiquidationCall(1, 1e18, _getSettlementDataV3(5 * Constants.Q96 / 10));

        // The filler executes the trade with the old `positionId`
        gammaTradeMarket.executeTrade(order, _sign(order, alicePrivateKey), _getSettlementDataV3(5 * Constants.Q96 / 10));

        {
            GammaOrder memory order =
                _createOrder(alice, 2, block.timestamp + 100, 1, 1, -2e6, 0, 0, Constants.Q96);

            // Alice can not close the position
            vm.expectRevert();
            gammaTradeMarket.executeTrade(order, _sign(order, alicePrivateKey), _getSettlementDataV3(5 * Constants.Q96 / 10));
        }
    }
}
```

Manual Review.

## Recommended Mitigation Steps
Do not rely on `gammaOrder.positionId` to check if the `positionId` should be added to `positionIDs[user]` or not. Add a separate check that if the `positionId` does not exist in `positionIDs[user]` then add it to the array.
