# Vulnerability details

## Impact
The below functions will not revert as expected.

## Proof of Concept
Assembly revert only be caught for those functions with returns declaration. But note the below function signatures which does not have return values and hence
will not behave as expected.


```
 function revertPairStatus(uint256 pairId) external {
        ReaderLogic.getPairStatus(globalData, pairId);
    }

    /// @notice Gets the status of the vault
    /// @dev This function always reverts
    function revertVaultStatus(uint256 vaultId) external {
        ReaderLogic.getVaultStatus(globalData, vaultId);
    }
```

This problem arises due to how revert behaves in assembly. Note how the function signature does not have return type for both functions and hence revert will not  bubble up.

```
    function revertPairStatus(DataType.PairStatus memory pairStatus) internal pure {
        bytes memory data = abi.encode(pairStatus);

        assembly {
            revert(add(32, data), mload(data))
        }
    }

    function revertVaultStatus(IPredyPool.VaultStatus memory vaultStatus) internal pure {
        bytes memory data = abi.encode(vaultStatus);

        assembly {
            revert(add(32, data), mload(data))
        }
    }
```
