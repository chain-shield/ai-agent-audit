# Vulnerability details

## Impact
The smart contracts (`PriceFeed` and `PriceFeedFactory`) do not include checks to determine if the Arbitrum L2 sequencer is operational before executing price feed updates. This omission could lead to reliance on outdated or incorrect price data if the sequencer is down, affecting functions that rely on the most current prices.

If the sequencer is down, any transaction relying on the price fetched by the `getSqrtPrice()` function might execute based on stale or incorrect data. This could lead to financial discrepancies, incorrect trading outcomes, or exploitation of the stale price data for economic gain by malicious actors.

## Proof of Concept
In the `PriceFeed` contract, the function `getSqrtPrice()` fetches price data using both the AggregatorV3Interface and IPyth interfaces without checking the sequencer's status. This function could potentially receive and process outdated price data if the sequencer is not operational.
   
```solidity
   function getSqrtPrice() external view returns (uint256 sqrtPrice) {
       (, int256 quoteAnswer,,,) = AggregatorV3Interface(_quotePriceFeed).latestRoundData();
       IPyth.Price memory basePrice = IPyth(_pyth).getPriceNoOlderThan(_priceId, VALID_TIME_PERIOD);

       require(basePrice.expo == -8, "INVALID_EXP");
       require(quoteAnswer > 0 && basePrice.price > 0);

       uint256 price = uint256(int256(basePrice.price)) * Constants.Q96 / uint256(quoteAnswer);
       price = price * Constants.Q96 / _decimalsDiff;
       sqrtPrice = FixedPointMathLib.sqrt(price);
   }
```

No additional logic is present to verify the real-time operational status of the Arbitrum L2 sequencer, which is crucial for maintaining accurate and reliable pricing information.

## Tools Used
Manual

## Recommended Mitigation Steps
Implement a mechanism to check the health of the Arbitrum L2 sequencer within your contracts. This can be done by utilizing existing APIs or through a custom health-check function that can verify the sequencer's status before fetching or updating price feeds.
