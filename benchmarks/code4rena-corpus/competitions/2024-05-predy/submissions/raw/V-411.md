# Vulnerability details

## Impact
Detailed description of the impact of this finding.

## Vulnerability Detail
In `PredyPool.sol`,`GammaTradeMarket.sol` and `PerpMarketV1.sol` contracts, they
implement Openzeppelin’s UUPS model, uninitialized implementation contract can be taken over by an attacker with the initialize function, it’s recommended to invoke the _disableInitializers function in the constructor to prevent the implementation contract from being used by the attacker. However all the contracts which implements ReentrancyGuardUpgradeable and BaseMarketUpgradable do not call _disableInitializers in their constructors

## Tool used 
Manual Review

## Recommended Mitigation Steps
 Disabling initializers in the constructor by invoking the `_disableInitializers` function in the constructor of contract which implement Openzeppelin’s UUPS model to prevent the implementation contract from being used by the attacker helps mitigate these risk.
 ```diff
     constructor() {
+     _disableInitializers()
   }
```
