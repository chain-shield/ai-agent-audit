# Vulnerability details

## Impact
Some Uniswap pools like [WBTC/SHIBA](https://etherscan.io/address/0x1153C8F2B05Fdde2dB507c8D16E49d4C7405c907#readContract) that can have `sqrtPriceX96` greater than 128 bit value cannot be used due to DOS that result from the overflow in the `Math.calSqrtPriceToPrice(sqrtPrice)` computation.



## Proof of Concept
The `Math.calSqrtPriceToPrice(sqrtPrice)` is used to convert the `sqrtPriceX96` price retrieved from Uniswap pools to the actual `price`. In this process, the `sqrtPriceX96` is first multiplied by itself.
```solidity
File: Math.sol
function calSqrtPriceToPrice(uint256 sqrtPrice) internal pure returns (uint256 price) {
        price = FullMath.mulDiv(sqrtPrice, sqrtPrice, Constants.Q96);
    }
```

The `Math.calSqrtPriceToPrice(sqrtPrice)` function is used in the highlighted affected code to get the price. This will revert for Uniswap pools with `sqrtPriceX96` larger than 128-bit value because `sqrtPriceX96` is multiplied by itself first in `Math.calSqrtPriceToPrice(sqrtPrice)` function.

The main issue is that there some Uniswap pools that can have `sqrtPriceX96` greater than 128-bit value for example [Uniswap WBTC/SHIBA pool](https://etherscan.io/address/0x1153C8F2B05Fdde2dB507c8D16E49d4C7405c907#readContract) at timestamp `1714392894` have a `sqrtPriceX96` value of `380146371870332863053439965317548561928` which is a 129-bit value. So multiplying a 129-bit value by itself will overflow the maximum available Solidity 256 bit value(uint256). This will cause the transaction to revert rendering such pools unusable.

Uniswap handles this by using the [Uniswap Fullmath library](https://github.com/Uniswap/v3-core/blob/d8b1c635c275d2a9450bd6a78f3fa2484fef73eb/contracts/libraries/FullMath.sol#L4C1-L68C10) which can handle math computations of up to 512-bits.

As used in the [Uniswap Official oracle library](https://github.com/Uniswap/v3-periphery/blob/697c2474757ea89fec12a4e6db16a574fe259610/contracts/libraries/OracleLibrary.sol#L58), there is an if statement to check if `sqrtPriceX96` is not greater than 128-bit then `1 << 192` is passed as the `denomenator` parameter of `FullMath.mulDiv(...)` function `else`, `1 << 128` `denomenator` is passed instead.

## Recommended Mitigation Steps

Consider using the [Uniswap Fullmath library](https://github.com/Uniswap/v3-core/blob/d8b1c635c275d2a9450bd6a78f3fa2484fef73eb/contracts/libraries/FullMath.sol#L4C1-L68C10) as it can handle up to 512-bit math computations as it is implemented in the [Uniswap official oracle library](https://github.com/Uniswap/v3-periphery/blob/697c2474757ea89fec12a4e6db16a574fe259610/contracts/libraries/OracleLibrary.sol#L58)

From the function below we can see how there is check for if `sqrtRatioX96 <= type(uint128).max` is `true` then `1 << 192` is passed as the `denomenator` parameter of `FullMath.mulDiv(...)` function and if not `1 << 128` `denomenator` is passed instead.

Below is how the overflow is checked by [Uniswap official oracle library](https://github.com/Uniswap/v3-periphery/blob/697c2474757ea89fec12a4e6db16a574fe259610/contracts/libraries/OracleLibrary.sol#L58)

```

    /// @param tick Tick value used to calculate the quote
    /// @param baseAmount Amount of token to be converted
    /// @param baseToken Address of an ERC20 token contract used as the baseAmount denomination
    /// @param quoteToken Address of an ERC20 token contract used as the quoteAmount denomination
    /// @return quoteAmount Amount of quoteToken received for baseAmount of baseToken
    function getQuoteAtTick(
        int24 tick,
        uint128 baseAmount,
        address baseToken,
        address quoteToken
    ) internal pure returns (uint256 quoteAmount) {
        uint160 sqrtRatioX96 = TickMath.getSqrtRatioAtTick(tick);

        // Calculate quoteAmount with better precision if it doesn't overflow when multiplied by itself
@>        if (sqrtRatioX96 <= type(uint128).max) { 
            uint256 ratioX192 = uint256(sqrtRatioX96) * sqrtRatioX96;
            quoteAmount = baseToken < quoteToken
                ? FullMath.mulDiv(ratioX192, baseAmount, 1 << 192)
                : FullMath.mulDiv(1 << 192, baseAmount, ratioX192);
        } else {
            uint256 ratioX128 = FullMath.mulDiv(sqrtRatioX96, sqrtRatioX96, 1 << 64);
            quoteAmount = baseToken < quoteToken
                ? FullMath.mulDiv(ratioX128, baseAmount, 1 << 128)
                : FullMath.mulDiv(1 << 128, baseAmount, ratioX128);
        }
    }
```
