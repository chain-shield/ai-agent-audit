# Vulnerability details

## Impact
Leaving an implementation contract uninitialized can pose a significant security risk. An attacker could potentially take over the uninitialized implementation contract, which may adversely impact the associated proxy contract. To mitigate this risk, the `_disableInitializers` function should be invoked in the constructor to lock the contract automatically upon deployment.

## Recommended Mitigation Steps
Invoke the _disableInitializers function in the constructor. This will prevent the contract from being initialized by an attacker,

```javascript
constructor() {
        _disableInitializers();
    }
```
