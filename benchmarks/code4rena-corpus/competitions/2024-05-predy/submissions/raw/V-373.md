# Vulnerability details

## Impact

The Price Feed can be created by using the function createPriceFeed in PriceFeed.sol. The function requires three parameters, quotePrice, priceId and decimalsDiff. Then the decimalsDiff input is used for calculating the price. If the manual input of decimalsDiff value is incorrect, the resulting price calculation will be off. Since sqrtPrice is derived from price using a square root function, any error in the price calculation will be propagated and magnified in the sqrtPrice.

## Proof of Concept

1. createPriceFeed by inputting the decimalsDiff
https://github.com/code-423n4/2024-05-predy/blob/main/src/PriceFeed.sol#L18-L24

```
    function createPriceFeed(address quotePrice, bytes32 priceId, uint256 decimalsDiff) external returns (address) {
        PriceFeed priceFeed = new PriceFeed(quotePrice, _pyth, priceId, decimalsDiff);

        emit PriceFeedCreated(quotePrice, priceId, decimalsDiff, address(priceFeed));

        return address(priceFeed);
    }
```

2. Directly use input decimalsDiff for calculating the price without any validation of the accurancy.
https://github.com/code-423n4/2024-05-predy/blob/main/src/PriceFeed.sol#L29-L58

