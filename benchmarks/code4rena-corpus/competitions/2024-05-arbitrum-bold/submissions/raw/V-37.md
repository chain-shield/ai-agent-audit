# Vulnerability details

### Vulnerability Details

#### Code for: DelayBuffer.sol, SequencerInbox.sol

**Vulnerability Type:** Race Condition

**Description:**
The `isUpdatable` function in the `DelayBuffer` library checks whether the buffer is updatable based on its current state. However, if multiple or specific contracts are accessing and modifying the same `BufferData` struct concurrently, there could be a race condition leading to inconsistent states. Specifically, if one contract updates the buffer while another contract is checking its updatable status, the result might not reflect the current state accurately. This could lead to unexpected behavior or erroneous decisions based on outdated information. The `isSynced` state reference from the `DelayBuffer` contract to determine `isUpdatable` is one use case of the `isSynced`. However, if the `isSynced` function is called from multiple places concurrently, there could be a race condition leading to unwanted consistencies in the returned state or a double spend concern

**Impact:**
The race condition in the `isUpdatable` function could lead to incorrect decisions regarding the updatable status of the buffer. This could potentially disrupt the intended functionality of contracts relying on this status for decision making.
