# Vulnerability details

## Impact

Most critical functions in RollupAdminLogic.sol don't have access control implemented on them.

This allows anyone to tamper with the system, making it vulnerable.

functions like `pause()` can be used by malicious actors to halt interactions with the rollup contract in a way that will disorganize the system. 
Here's a vivid example:
- Alice a malicious actor calls `RollupAdminLogic.pause()`  
- Bob the admin calls `RollupAdminLogic.resume()` 
- Alice calls `RollupAdminLogic.pause()` immediately.

Now the above scenario just goes on in a cycle.

## Proof of Concept
Most critical functions in RollupAdminLogic.sol lack access control 

## Tools Used
Manual Review

## Recommended Mitigation Steps
implement access control on all critical functions(i mean functions that update state vars) in RollupAdminLogic.sol.
