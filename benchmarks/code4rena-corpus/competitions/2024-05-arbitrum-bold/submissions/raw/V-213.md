# Vulnerability details

## Impact
Detailed description of the impact of this finding.
### Location:
Function `SequencerInbox.setBufferConfig(BufferConfig)` (src/bridge/SequencerInbox.sol#947-950)

### Description:
The `setBufferConfig` function does not correctly set storage variables or pass arguments to external calls. It appears to be a setter, but it neither writes to storage nor utilizes function parameters appropriately.

### Recommendation:
Ensure that the setter function properly updates storage variables. The current implementation incorrectly sets the parameter in memory within the function. Instead, the setter should update the relevant storage variables directly. Additionally, avoid setting the parameter to an object within the function; it should either update storage or pass arguments to an external call.

## Tools Used
Slither.
## Recommended Mitigation Steps
The setter is incorrectly assigned to a parameter within the function's memory. It should be assigned in storage outside the function. Ensure that your setter performs an actual assignment and is not set to a memory parameter or an object. Additionally, it should be set through an external call or storage variable not memory parameter.
