# Vulnerability details

## Impact
The `initializeProxy` function in the RollupProxy contract (src/rollup/RollupProxy.sol) is an external function that initializes the proxy contract with the provided configuration and connected contracts. However, this function lacks proper access control mechanisms, such as modifiers, to restrict who can call it.

The absence of access control on the initializeProxy function can have the following impacts:

Unauthorized Initialization: Anyone can call the `initializeProxy` function and initialize the proxy contract with arbitrary configuration and connected contracts. This could allow an attacker to take control of the proxy contract and manipulate its behavior.

Contract Manipulation: An attacker can call the `initializeProxy` function multiple times with different configuration and connected contracts, potentially overwriting the intended initialization and causing unexpected behavior or loss of funds.

Bypass of Intended Access Control: If the `initializeProxy` function is meant to be called only by a specific entity (which I believe it is), such as the contract owner or a trusted initializer, the lack of access control allows anyone to bypass this intended restriction and perform unauthorized initialization.

## Proof of Concept
The `RollupProxy` contract is deployed without proper initialization.

An attacker calls the `initializeProxy` function with malicious configuration and connected contracts.

The attacker's provided configuration and connected contracts are used to initialize the proxy contract, potentially giving the attacker control over the contract's behavior.

The attacker can then manipulate the proxy contract, such as changing the implementation contracts or modifying the contract's state, leading to unintended consequences or loss of funds.

The attacker can repeat the initialization process multiple times, overwriting the intended initialization and causing further damage.

## Recommended Mitigation Steps
Implementing a modifier, such as `onlyOwner` or `Initializer`, to restrict access to the function only to authorized entities.
