# Vulnerability details

Force include can only read messages older than the delay period.

The `forceInclusion()` has `l1BlockAndTime[1]` which contains the l1 timestamp.The l1 timestamp with `delaySeconds` is not checked with the current timestamp.

## Impact
The `forceInclusion()` can be called before the sequencer-only window expires or earlier than the delay period.

## Proof of Concept

Technically, if `l1BlockAndTime[1] + delaySeconds = 1500` and `block.timestamp = 1200`, the SequencerInbox should revert for error `ForceIncludeTimeTooSoon()`.But SequencerInbox missing check on this.

Hence, the sequencer batch can be delivered too early before the sequencer window expires.

## Tools Used
Manual Review

## Recommended Mitigation Steps
Include this check:
```solidity
if (l1BlockAndTime[1] + delaySeconds >= block.timestamp) revert ForceIncludeTimeTooSoon();
```
