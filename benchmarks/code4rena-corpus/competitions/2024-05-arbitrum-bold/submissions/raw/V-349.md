# Vulnerability details

## Proof of Concept

RollupAdminLogic does not have any owner modifier in any function. Anyone can control any function in the contract.

```
    function pause() external override {
        _pause();
        emit OwnerFunctionCalled(3);
    }
    /**
     * @notice Resume interaction with the rollup contract
     */
    function resume() external override {
        _unpause();
        emit OwnerFunctionCalled(4);
    }
```

Any user can set owner, or set the base stake.

```
    function setBaseStake(uint256 newBaseStake) external override {
        baseStake = newBaseStake;
        emit OwnerFunctionCalled(12);
    }
    function setOwner(address newOwner) external override {
        _changeAdmin(newOwner);
        emit OwnerFunctionCalled(7);
    }
```

## Impact

Anyone can control any function, affects assertion.

## Tools Used

Manual Review

## Recommended Mitigation Steps

Recommend having modifiers for all the function.
