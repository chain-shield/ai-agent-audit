# Vulnerability details

### Description: 
The `setBaseStake` function in the `RollupAdminLogic` contract is marked as `external` and lacks proper access control. This allows any external user to call this function and modify the `baseStake` value, leading to potential security vulnerabilities and unauthorized state changes.

### Vulnerability Details:

Location in Code: The `setBaseStake` function is defined in the `RollupAdminLogic` contract.
Link to Code: https://github.com/code-423n4/2024-05-arbitrum-foundation/blob/6f861c85b281a29f04daacfe17a2099d7dad5f8f/src/rollup/RollupAdminLogic.sol#L223-L226
Code Snippet:
function setBaseStake(uint256 newBaseStake) external override {
    baseStake = newBaseStake;
    emit OwnerFunctionCalled(12);
}

### Impact:

Unauthorized users can call the `setBaseStake` function, allowing them to change the `baseStake` value arbitrarily.
This can lead to potential financial losses or other adverse effects, depending on how the `baseStake` is used in the overall system.
Recommended Fix:
Implement access control to restrict who can call the `setBaseStake` function. This can be achieved by inheriting from OpenZeppelin’s `Ownable` contract and using the `onlyOwner` modifier.

### Suggested Code Change:

Install OpenZeppelin Contracts (if not already installed):
npm install @openzeppelin/contracts

// SPDX-License-Identifier: MIT
pragma solidity ^0.8.0;

import "@openzeppelin/contracts/access/Ownable.sol";

contract RollupAdminLogic is RollupCore, IRollupAdmin, DoubleLogicUUPSUpgradeable, Ownable {

    function setBaseStake(uint256 newBaseStake) external onlyOwner {
        baseStake = newBaseStake;
        emit OwnerFunctionCalled(12);
    }
}

### Rationale for the Fix:

Access Control: By using the `onlyOwner` modifier, we ensure that only the owner of the contract can call the `setBaseStake` function, preventing unauthorized access and modifications.
Security: This change may enhance the security of the contract by safeguarding critical state-changing functions from external attacks.
