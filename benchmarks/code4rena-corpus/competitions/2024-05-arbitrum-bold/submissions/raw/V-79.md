# Vulnerability details

## Impact
The `withdrawFromPool` function allows anyone to withdraw funds without verifying if they staked token, besides the checking the `depositBalance[msg.sender]` which can be compromised as it is a public variable.

## Tools Used
Manual Review.

## Recommended Mitigation Steps
To mitigate this would be to implement a more robust access control mechanism, such as  a `bool => address` mapping checking if the sender is actually a staker, incase `depositBalance` is compromised, while `depositBalance` checks if `msg.sender` is the owner of the deposited amount, before proceeding with the withdrawal.
