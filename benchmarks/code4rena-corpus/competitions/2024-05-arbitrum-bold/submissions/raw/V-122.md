# Vulnerability details


## Impact
The postUpgradeInit function can only be called if the contract's buffer configuration is not yet initialized.
However, upgradeSequencerInbox calls this function without verifying the buffer configuration status.
As a result, the function may revert, potentially disrupting all upgrade actions.

        external
        onlyDelegated

    {
        if (!isDelayBufferable) revert NotDelayBufferable();
