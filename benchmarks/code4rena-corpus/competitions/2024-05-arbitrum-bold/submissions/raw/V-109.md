# Vulnerability details

## Impact
The vulnerability identified in the codebase (for instance in src/bridge/AbsOutbox.sol#L196-L225) is related to reentrancy. Specifically, the issue lies in the AbsOutbox.executeTransactionImpl function in the AbsOutbox contract. This vulnerability allows for potential reentrancy attacks due to the way external calls are made within the code. The state variable AbsOutbox.context is written after the external call to executeBridgeCall, which can lead to reentrancy problems.

An attacker could potentially exploit this vulnerability by calling the executeTransactionImpl function multiple times in quick succession, allowing them to reenter the function before the state variable is updated. This could result in unexpected behavior and manipulation of the contract's state.

It is important to address this vulnerability to prevent potential reentrancy attacks and ensure the security of the contract.
