# Vulnerability details

## Impact
The link to the Governance Action contracts is provided in the readme of this contest. However here is a directt link to the documentation:
https://github.com/ArbitrumFoundation/governance/blob/main/src/gov-action-contracts/README.md#governance-action-contract-standards-and-guidelines

```
2. A GAC should have only one external function; it should be named perform and it should take no parameters.
```

This condition is violated by the `BOLDUpgradeAction.perform()`.
## Proof of Concept
In the `BOLDUpgradeAction.perform()`, this takes in some parameters:
```solidity
//@audit does not follow the GAC standard
    function perform(address[] memory validators) external {
```

## Tools Used
Manual Review, Josephdara

## Recommended Mitigation Steps

Use the `ROLLUP_READER` to store the validator addresses, or use the `ConstantArrayStorage` as used for the minimum stake Values
