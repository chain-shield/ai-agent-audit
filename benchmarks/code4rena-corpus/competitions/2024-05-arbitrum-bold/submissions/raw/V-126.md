# Vulnerability details

## Impact
The logical vulnerability resides in the `deleteStaker` function. When a staker is deleted from the `_stakerMap` map and `_stakerList` array, the indexing realignment is not handled properly for the case when the staker itself is at the last index of `_stakerList`. The code modifies the index of the staker that is moved from the last position to the position of the deleted staker but does not handle cleaning up or resetting the index of the last element of `_stakerList` when it points to itself.
