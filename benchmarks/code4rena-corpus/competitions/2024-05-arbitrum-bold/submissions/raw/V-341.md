# Vulnerability details

## Impact

Functions cannot be paused/unpaused.

## Proof of Concept

In RollupUserLogic, it inherits RollupCore,

```
contract RollupUserLogic is RollupCore, UUPSNotUpgradeable, IRollupUser {
```

which inherits `PausableUpgradeable`.

```
abstract contract RollupCore is IRollupCore, PausableUpgradeable {
```

and initializeCore initializes Pausable through `Pausable_init`.

```
 function initializeCore(AssertionNode memory initialAssertion, bytes32 assertionHash) internal {
        __Pausable_init();
        initialAssertion.status = AssertionStatus.Confirmed;
        _assertions[assertionHash] = initialAssertion;
        _latestConfirmed = assertionHash;
    }
```

However, RollupUserLogic does not expose the pausing/unpausing functionality, which means all the function in the RollupUserLogic cannot be paused, eg stakeOnNewAssertion.

```
 function stakeOnNewAssertion(AssertionInputs calldata assertion, bytes32 expectedAssertionHash)
        public
        onlyValidator
        whenNotPaused
    {
```

Another contract, RollupAdminLogic, also inherits RollupCore, but it exposes the pausing and unpausing function.

```
RollupAdminLogic.sol Line 150:
 function pause() external override {
        _pause();
        emit OwnerFunctionCalled(3);
    }

    /**
     * @notice Resume interaction with the rollup contract
     */
    function resume() external override {
        _unpause();
        emit OwnerFunctionCalled(4);
    }
```

## Tools Used

Manual Review

## Recommended Mitigation Steps

Expose the pause and unpause function in RollupUserLogic as well.
