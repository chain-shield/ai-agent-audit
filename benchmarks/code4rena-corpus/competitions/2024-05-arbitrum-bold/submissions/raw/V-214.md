# Vulnerability details

## Vulnerability details 
The contract contains two functions, removeWhitelistAfterFork and removeWhitelistAfterValidatorAfk, which allow for the disabling of the validator whitelist. These functions lack proper access control, allowing any user to call them under certain conditions, thereby disabling the whitelist 
```solidity
function removeWhitelistAfterFork() external {
    require(!validatorWhitelistDisabled, "WHITELIST_DISABLED");
    require(_chainIdChanged(), "CHAIN_ID_NOT_CHANGED");
    validatorWhitelistDisabled = true;
}

function removeWhitelistAfterValidatorAfk() external {
    require(!validatorWhitelistDisabled, "WHITELIST_DISABLED");
    require(_validatorIsAfk(), "VALIDATOR_NOT_AFK");
    validatorWhitelistDisabled = true;
}
```
this function  should only be callable by onlyowner
- in scenario that An attacker can exploit this by:
- Disabling Whitelist after Chain ID Change:
- The attacker waits until the chain ID changes as an example after a fork.
- The attacker calls removeWhitelistAfterFork to disable the validator whitelist without being an authorized entity.
- Disabling Whitelist when Validators are AFK:
- The attacker waits until the validators are AFK (inactive for more than VALIDATOR_AFK_BLOCKS).
- The attacker calls removeWhitelistAfterValidatorAfk to disable the validator whitelist without being an authorized entity.
- And This  allow unauthorized validators to participate in the system, compromising its integrity.

as result --> The call fails with "WHITELIST_DISABLED".
## Impact
Unauthorized users can disable the validator whitelist, then compromising the security of the system. and this allow untrusted validators to participate, undermining the integrity of the validation process.

```solidity
class RollupUserLogic:
    def __init__(self):
        self.validatorWhitelistDisabled = False
        self.deployTimeChainId = 1  # Simulating initial chain ID
        self.currentChainId = self.deployTimeChainId
        self.latestConfirmedBlock = 100
        self.blockNumber = 150
        self.VALIDATOR_AFK_BLOCKS = 201600

    def _chainIdChanged(self):
        return self.deployTimeChainId != self.currentChainId

    def _validatorIsAfk(self):
        return (self.blockNumber - self.latestConfirmedBlock) > self.VALIDATOR_AFK_BLOCKS

    def removeWhitelistAfterFork(self, user):
        if self.validatorWhitelistDisabled:
            return "WHITELIST_DISABLED"
        if not self._chainIdChanged():
            return "CHAIN_ID_NOT_CHANGED"
        self.validatorWhitelistDisabled = True
        return "Whitelist disabled by fork"

    def removeWhitelistAfterValidatorAfk(self, user):
        if self.validatorWhitelistDisabled:
            return "WHITELIST_DISABLED"
        if not self._validatorIsAfk():
            return "VALIDATOR_NOT_AFK"
        self.validatorWhitelistDisabled = True
        return "Whitelist disabled by validator AFK"

def fuzz_test():
    contract = RollupUserLogic()
    
    # Scenario 1: Attempt to disable whitelist without a chain ID change
    print("Scenario 1:", contract.removeWhitelistAfterFork("attacker"))  # Expect: CHAIN_ID_NOT_CHANGED
    
    # Scenario 2: Change chain ID and attempt to disable whitelist
    contract.currentChainId = 2  # Simulating a chain ID change
    print("Scenario 2:", contract.removeWhitelistAfterFork("attacker"))  # Expect: Whitelist disabled by fork

    # Resetting state
    contract = RollupUserLogic()
    
    # Scenario 3: Attempt to disable whitelist when validators are not AFK
    contract.latestConfirmedBlock = contract.blockNumber - 100  # Validators are not AFK
    print("Scenario 3:", contract.removeWhitelistAfterValidatorAfk("attacker"))  # Expect: VALIDATOR_NOT_AFK
    
    # Scenario 4: Simulate validators being AFK and attempt to disable whitelist
    contract.latestConfirmedBlock = contract.blockNumber - contract.VALIDATOR_AFK_BLOCKS - 1  # Validators are AFK
    print("Scenario 4:", contract.removeWhitelistAfterValidatorAfk("attacker"))  # Expect: Whitelist disabled by validator AFK

    # Scenario 5: Attempt to disable whitelist when it is already disabled
    contract.validatorWhitelistDisabled = True
    print("Scenario 5:", contract.removeWhitelistAfterFork("attacker"))  # Expect: WHITELIST_DISABLED
    print("Scenario 5:", contract.removeWhitelistAfterValidatorAfk("attacker"))  # Expect: WHITELIST_DISABLED

fuzz_test()
```
