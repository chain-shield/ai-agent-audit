# Vulnerability details

## Impact
The `createRollup` function in the `RollupCreator` contract does not have any explicit policy or checks against delegate calls to untrusted contracts. This absence of input validation and policy enforcement can lead to potential vulnerabilities where the `createRollup` function may make a delegate call to an untrusted or malicious contract, granting it full control over the `RollupCreator` contract's state and allowing it to execute arbitrary code in the context of the `RollupCreator` contract.

If exploited, an attacker could gain unauthorized access to the `RollupCreator` contract's state, manipulate contract variables, or steal funds held by the contract. The attacker could potentially take control of the entire rollup creation process, create malicious rollups, or disrupt the normal functioning of the protocol. This vulnerability can result in severe financial losses, compromise of user funds, and damage to the protocol's reputation.



## Proof of Concept
An attacker identifies the absence of policy against delegate calls to untrusted contracts in the `createRollup` function.

The attacker creates a malicious contract with a fallback function that performs malicious actions, such as modifying contract state or stealing funds.

The attacker tricks the `createRollup` function into making a delegate call to the malicious contract by manipulating the input parameters or exploiting any other vulnerabilities in the contract.

When the delegate call is made to the malicious contract, it executes the malicious code in the context of the `RollupCreator` contract, granting the attacker unauthorized access and control.

The attacker can then perform various malicious actions, such as stealing funds, creating fraudulent rollups, or disrupting the protocol's functionality.

## Tools Used
Manual Review

## Recommended Mitigation Steps
Implement a strict policy against delegate calls to untrusted contracts in the `createRollup` function. Thoroughly validate and whitelist the target contracts before making any delegate calls. Ensure that the `createRollup` function has proper access controls and error handling mechanisms in place to prevent unauthorized access and state manipulation. Restrict delegate calls to only trusted, reviewed, and audited contracts.
