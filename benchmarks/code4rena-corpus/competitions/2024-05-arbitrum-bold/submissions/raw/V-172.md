# Vulnerability details

## Impact
 contract `RollupAdminLogic` may not works well because most functions don't have access control, any one can change the state of the contract.

## Proof of Concept

most functions don't have access control, take `pause` and `setValidator` function for example:

```solidity
  function pause() external override {
        _pause();
        emit OwnerFunctionCalled(3);
    }
  ...


    function setValidator(address[] calldata _validator, bool[] calldata _val) external override {
        require(_validator.length > 0, "EMPTY_ARRAY");
        require(_validator.length == _val.length, "WRONG_LENGTH");
        
        for (uint256 i = 0; i < _validator.length; i++) {
        isValidator[_validator[i]] = _val[i];
        }
        emit OwnerFunctionCalled(6);
    }


```

 I don't think it's intended to don't have access contorl , becasue anyone is able to pause or set validator.
