# Vulnerability details

## Impact

All new assertions will be rejected until the admin uses forceConfirmAssertion. Some transactions may be lost in the process.

## Proof of Concept
When the wasmModuleRoot is modified without pausing the contract, all new assertions will be rejected because their assertion hash will not be compatible with the previous assertion hash.

## Tools Used

Manual review

## Recommended Mitigation Steps

Add the modifier "whenPaused" to the function.

Access Control
