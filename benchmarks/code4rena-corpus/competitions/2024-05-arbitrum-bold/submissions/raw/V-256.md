# Vulnerability details

## Impact
Detailed description of the impact of this finding.
### Vulnerability: Unchecked Transfer in `createLayerZeroEdge` Function

**Description:**

The `createLayerZeroEdge` function in the `EdgeChallengeManager` contract contains a vulnerability related to the unchecked transfer of ERC20 tokens using the `IERC20.safeTransferFrom` method. This function does not have a modifier to ensure that the transfer is executed under specific conditions, which can lead to potential issues.

**Details:**

1. **Function Overview:**
   - The `createLayerZeroEdge` function is responsible for creating a new layer zero edge and involves transferring a stake amount of ERC20 tokens from the caller to the contract or an excess stake receiver.

2. **Lines of Concern:**
   - The vulnerability is present between lines 371 to 448, where the `IERC20.safeTransferFrom` method is called without proper modifiers.

3. **Potential Issues:**
- **Absence of Access Control:** The function lacks access control modifiers, which means any user can call this function and trigger the token transfer, potentially leading to unauthorized or unintended transfers.

4. **Code Snippet:**
   ```solidity
   IERC20 st = stakeToken;
   uint256 sa = stakeAmounts[args.level];
   if (address(st) != address(0) && sa != 0) {
       address receiver = edgeAdded.hasRival ? excessStakeReceiver : address(this);
       st.safeTransferFrom(msg.sender, receiver, sa);
   }
   ```

5. **Impact:**
- **Unauthorized Transfers:** Without proper access control, unauthorized users could potentially exploit this function to transfer tokens.

6. **Recommendation:**
- **Implement Access Control:** Use appropriate access control modifiers to restrict who can call this function.

By addressing these issues, the contract can ensure that token transfers are executed securely and only under the intended conditions.

```solidity
// Add a modifier to restrict access to the function
modifier onlyValidator() {
    require(assertionChain.isValidator(msg.sender), "Not a validator");
    _;
}

function createLayerZeroEdge(CreateEdgeArgs calldata args) external onlyValidator returns (bytes32) {
    // Check if whitelist is enabled in the Rollup
    bool whitelistEnabled = !assertionChain.validatorWhitelistDisabled();

    if (whitelistEnabled && !assertionChain.isValidator(msg.sender)) {
        revert NotValidator(msg.sender);
    }

    EdgeAddedData memory edgeAdded;
    EdgeType eType = ChallengeEdgeLib.levelToType(args.level, NUM_BIGSTEP_LEVEL);
    uint256 expectedEndHeight = getLayerZeroEndHeight(eType);
    AssertionReferenceData memory ard;

    if (eType == EdgeType.Block) {
        if (args.proof.length == 0) {
            revert EmptyEdgeSpecificProof();
        }
        (, AssertionStateData memory predecessorStateData, AssertionStateData memory claimStateData) =
            abi.decode(args.proof, (bytes32[], AssertionStateData, AssertionStateData));

        assertionChain.validateAssertionHash(
            args.claimId, claimStateData.assertionState, claimStateData.prevAssertionHash, claimStateData.inboxAcc
        );

        assertionChain.validateAssertionHash(
            claimStateData.prevAssertionHash,
            predecessorStateData.assertionState,
            predecessorStateData.prevAssertionHash,
            predecessorStateData.inboxAcc
        );

        if (args.endHistoryRoot != claimStateData.assertionState.endHistoryRoot) {
            revert EndHistoryRootMismatch(args.endHistoryRoot, claimStateData.assertionState.endHistoryRoot);
        }

        ard = AssertionReferenceData(
            args.claimId,
            claimStateData.prevAssertionHash,
            assertionChain.isPending(args.claimId),
            assertionChain.getSecondChildCreationBlock(claimStateData.prevAssertionHash) > 0,
            predecessorStateData.assertionState,
            claimStateData.assertionState
        );
    }
    edgeAdded = store.createLayerZeroEdge(
        args, ard, oneStepProofEntry, expectedEndHeight, NUM_BIGSTEP_LEVEL, whitelistEnabled
    );

    IERC20 st = stakeToken;
    uint256 sa = stakeAmounts[args.level];
    if (address(st) != address(0) && sa != 0) {
        // Pre-transfer check: Ensure the allowance is sufficient
        require(st.allowance(msg.sender, address(this)) >= sa, "Insufficient allowance");

        address receiver = edgeAdded.hasRival ? excessStakeReceiver : address(this);
        st.safeTransferFrom(msg.sender, receiver, sa);

        // Post-transfer verification (optional, as safeTransferFrom reverts on failure)
        require(st.balanceOf(receiver) >= sa, "Transfer failed");
    }

    emit EdgeAdded(
        edgeAdded.edgeId,
        edgeAdded.mutualId,
        edgeAdded.originId,
        edgeAdded.claimId,
        edgeAdded.length,
        edgeAdded.level,
        edgeAdded.hasRival,
        edgeAdded.isLayerZero
    );
    return edgeAdded.edgeId;
}
```
