# Vulnerability details

In the [stakeOnNewAssertion()](https://github.com/code-423n4/2024-05-arbitrum-foundation/blob/6f861c85b281a29f04daacfe17a2099d7dad5f8f/src/rollup/RollupUserLogic.sol#L163-L217) function, there is a potential bug in the `else` block where the stakes are refunded to the loser's escrow account.

**Problem:**

* The [assertion.beforeStateData.configData.requiredStake](https://github.com/code-423n4/2024-05-arbitrum-foundation/blob/6f861c85b281a29f04daacfe17a2099d7dad5f8f/src/rollup/RollupUserLogic.sol#L215) value is used to calculate the amount to be transferred to the loser's escrow account.
* However, this value may be incorrect if it has been modified after the `stakeOnNewAssertion()` function was called.

## Impact
This can lead to incorrect stake refunds for losing stakers. If the configuration of `requiredStake` is modified after the assertion is created, the refunded amount to the loser's escrow account may not be sufficient.

  * Losing stakers may not receive the full stake they are entitled to if the requiredStake is changed after the assertion creation.

## Proof of Concept
https://github.com/code-423n4/2024-05-arbitrum-foundation/blob/6f861c85b281a29f04daacfe17a2099d7dad5f8f/src/rollup/RollupUserLogic.sol#L291-L296

```solidity
function stakeOnNewAssertion(AssertionInputs calldata assertion, bytes32 expectedAssertionHash) public onlyValidator whenNotPaused {
    // ...
    if (!getAssertionStorage(newAssertionHash).isFirstChild) {
        // Incorrectly calculates required stake
        IERC20(stakeToken).safeTransfer(loserStakeEscrow, assertion.beforeStateData.configData.requiredStake);
    }
    // ...
}
```
The `AssertionStorage` struct should store the `requiredStake` value associated with each assertion.

The `stakeOnNewAssertion()` function should retrieve the `requiredStake` value from the AssertionStorage struct instead of using the value from `assertion.beforeStateData.configData`.

## Recommended Mitigation Steps
Retrieve the `requiredStake` value from the `AssertionStorage` struct associated with the `prevAssertion` before transferring funds to the loser's escrow account.

```solidity
if (!getAssertionStorage(newAssertionHash).isFirstChild) {
    // Retrieve requiredStake from AssertionStorage
    uint256 requiredStake = getAssertionStorage(prevAssertion).statusData.requiredStake;

    // Send the required stake to the loser's escrow
    IERC20(stakeToken).safeTransfer(loserStakeEscrow, requiredStake);
}
```
* The `statusData.requiredStake` field should be updated whenever the `requiredStake` configuration is modified.
