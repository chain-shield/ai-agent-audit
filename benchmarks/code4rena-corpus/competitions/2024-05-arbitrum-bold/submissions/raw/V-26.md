# Vulnerability details

**Vulnerability Report: Missing Implementation of IAssertionChain**

**Description:**
The `EdgeChallengeManager` contract in the Arbitrum Foundation project references the `IAssertionChain` interface but does not include any contract in the codebase that implements this interface.

**Impact:**
This vulnerability potentially leads to a discrepancy between the expected behavior defined in the `IAssertionChain` interface and the actual behavior provided by the Assertion Chain contract. Without a concrete implementation of the `IAssertionChain` interface, the functionality associated with the Assertion Chain cannot be utilized as intended.

**Recommendation:**
1. **Implementation of IAssertionChain**: Develop and deploy a contract that implements the `IAssertionChain` interface, providing the necessary functionality for the Assertion Chain.
2. **Integration Testing**: Once the Assertion Chain contract is implemented, thoroughly test its integration with the `EdgeChallengeManager` contract to ensure proper functionality and compatibility.
3. **Documentation Update**: Update project documentation to reflect the presence of the Assertion Chain contract and provide guidelines for its usage within the Arbitrum Foundation project.
