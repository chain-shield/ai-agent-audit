# Vulnerability details

## Description:

The contract's critical state-changing functions, such as `removeWhitelistAfterFork`, `removeWhitelistAfterValidatorAfk`, and `fastConfirmAssertion`, do not emit any events to log these changes. This omission can hinder monitoring and auditing efforts, making it more challenging to track significant actions within the contract.

## Impact:

The absence of event emissions for critical state changes can lead to reduced transparency and difficulty in detecting and responding to crucial actions. Users and monitoring systems rely on events to track changes in contract state. Without these events, important state changes may go unnoticed, potentially allowing malicious activities to persist undetected for longer periods.

## Proof of Concept:
Functions that change significant state variables without emitting events:

1. `removeWhitelistAfterFork` and `removeWhitelistAfterValidatorAfk`:

```solidity

function removeWhitelistAfterFork() external {
    require(!validatorWhitelistDisabled, "WHITELIST_DISABLED");
    require(_chainIdChanged(), "CHAIN_ID_NOT_CHANGED");
    validatorWhitelistDisabled = true;
}

function removeWhitelistAfterValidatorAfk() external {
    require(!validatorWhitelistDisabled, "WHITELIST_DISABLED");
    require(_validatorIsAfk(), "VALIDATOR_NOT_AFK");
    validatorWhitelistDisabled = true;
}
```
2. `fastConfirmAssertion`:

```solidity

function fastConfirmAssertion(
    bytes32 assertionHash,
    bytes32 parentAssertionHash,
    AssertionState calldata confirmState,
    bytes32 inboxAcc
) public whenNotPaused {
    require(msg.sender == anyTrustFastConfirmer, "NOT_FAST_CONFIRMER");

```

## Recommended Mitigation Steps:

Add event emissions to these functions to log the critical state changes. This improves transparency and aids in monitoring and auditing the contract.

#### Example mitigations:

1. `removeWhitelistAfterFork` and `removeWhitelistAfterValidatorAfk`:

```solidity
event WhitelistRemoved(string reason);

function removeWhitelistAfterFork() external {
    require(!validatorWhitelistDisabled, "WHITELIST_DISABLED");
    require(_chainIdChanged(), "CHAIN_ID_NOT_CHANGED");
    validatorWhitelistDisabled = true;
    emit WhitelistRemoved("Fork detected");
}

function removeWhitelistAfterValidatorAfk() external {
    require(!validatorWhitelistDisabled, "WHITELIST_DISABLED");
    require(_validatorIsAfk(), "VALIDATOR_NOT_AFK");
    validatorWhitelistDisabled = true;
    emit WhitelistRemoved("Validator AFK");
}
```
2. `fastConfirmAssertion`:

```solidity

event AssertionFastConfirmed(bytes32 indexed assertionHash, bytes32 indexed parentAssertionHash);

function fastConfirmAssertion(
    bytes32 assertionHash,
    bytes32 parentAssertionHash,
    AssertionState calldata confirmState,
    bytes32 inboxAcc
) public whenNotPaused {
    require(msg.sender == anyTrustFastConfirmer, "NOT_FAST_CONFIRMER");
    confirmAssertionInternal(assertionHash, parentAssertionHash, confirmState, inboxAcc);
    emit AssertionFastConfirmed(assertionHash, parentAssertionHash);
}
```
By emitting these events, the contract will be more transparent and easier to monitor, thus enhancing security and user trust.
