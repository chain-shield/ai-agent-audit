# Vulnerability details

## Impact
The lack of the `onlyRollupOwner` modifier in the `setOwne`r function represents a critical security vulnerability. This oversight allows any external caller to invoke the `setOwner` function and change the owner of the rollup contract.

## Proof of Concept
```solidity
/**
 * @notice Set a new owner address for the rollup
 * @dev it is expected that only the rollup admin can use this facet to set a new owner
 * @param newOwner address of new rollup owner
 */
function setOwner(address newOwner) external override {
    _changeAdmin(newOwner);
    emit OwnerFunctionCalled(7);
}
```
## Tools Used

## Recommended Mitigation Steps
Ensure the `setOwner` function includes the `onlyRollupOwner` modifier to restrict access to the current owner.


```solidity
 function setOwner(address newOwner) external override onlyRollupOwner {
        _changeAdmin(newOwner);
        emit OwnerFunctionCalled(7);
    }
```
