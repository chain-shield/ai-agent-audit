# Vulnerability details

## Impact
The flashLoan and creditFlashLoan functions rely on calls to IERC3156FlashBorrower and ICreditFlashBorrower, which means they can be exploited. This is risky because a bad actor could use these functions to borrow money without paying it back. Even though the attack needs to be done quickly, attackers are known for moving fast and exploiting weaknesses. To pull off this attack, the attacker would need to set up a malicious contract and make a call before the first 'flashloan' transaction is completed. 

## Proof of Concept
## Current code Scenario
1. Attacker initiates flashLoan
- the attacker calls the 'flashLoan' function
- the contract updates the internal state to lend tokens and emits an event

2. The exploitation
- before the balance is updated in the contract, the attacker re-enters the 'flashLoan' function by using their contract.
- the malicious contract calls 'flashLoan' again while the original transaction is still processing.
3. the attacker exploits the fact that the internal state was not updated before the external call was made
4. the attacker successfully withdraws additional funds

## Secure contract Scenario
1. attacker calls 'flashloan'
2. contract updates internal state (balance) first. 
3. attacker tries to re-enter but the 'nonReentrant' modifier prevents it.
4. attack fails. funds are protected.

## Reentrancy Risk:
Lines 68-72 (flashLoan function):
External call: receiver.onFlashLoan is made before updating the contract’s internal state (the call to underlyingToken.transferFrom and pool.repayCreditAccount).

Lines 86-90 (creditFlashLoan function):
External call: receiver.onCreditFlashLoan is made before updating the contract’s internal state (the call to underlyingToken.transferFrom and pool.repayCreditAccount).

## Recommended Mitigation Steps

Updated flashLoan function with an update to internal state ``` pool.lendCreditAccount(amount, address(receiver));``` to close the timing gap that attackers can exploit
```
/// @notice Flashlender lends `token` to `receiver`
/// @dev Reverts if `Flashlender` gets reentered in the same transaction or if token is not Stablecoin
/// @param receiver Address of the receiver of the flash loan
/// @param token Address of the token to borrow (has to be the address of Stablecoin)
/// @param amount Amount of `token` to borrow [wad]
/// @param data Arbitrary data structure, intended to contain user-defined parameters
/// @return true if flash loan
function flashLoan(
    IERC3156FlashBorrower receiver,
    address token,
    uint256 amount,
    bytes calldata data
) external override nonReentrant returns (bool) {
    if (token != address(underlyingToken)) revert Flash__flashLoan_unsupportedToken();
    uint256 fee = wmul(amount, protocolFee);
    uint256 total = amount + fee;

    // Update internal state first
    pool.lendCreditAccount(amount, address(receiver)); // added

    emit FlashLoan(address(receiver), token, amount, fee);

    // External call
    if (receiver.onFlashLoan(msg.sender, token, amount, fee, data) != CALLBACK_SUCCESS)
        revert Flash__flashLoan_callbackFailed();

    // Update internal state again
    underlyingToken.transferFrom(address(receiver), address(pool), total); // removed
    pool.repayCreditAccount(total - fee, fee, 0); // removed

    return true;
}


```
Updated creditFlashLoan
```
/// @notice Flashlender lends ICreditFlashBorrower Credit to `receiver`
/// @dev Reverts if `Flashlender` gets reentered in the same transaction
/// @param receiver Address of the receiver of the flash loan [ICreditFlashBorrower]
/// @param amount Amount of `token` to borrow [wad]
/// @param data Arbitrary data structure, intended to contain user-defined parameters
/// @return true if flash loan
function creditFlashLoan(
    ICreditFlashBorrower receiver,
    uint256 amount,
    bytes calldata data
) external override nonReentrant returns (bool) {
    uint256 fee = wmul(amount, protocolFee);
    uint256 total = amount + fee;

    // Update internal state first
    pool.lendCreditAccount(amount, address(receiver)); // added

    emit CreditFlashLoan(address(receiver), amount, fee);

    // External call
    if (receiver.onCreditFlashLoan(msg.sender, amount, fee, data) != CALLBACK_SUCCESS_CREDIT)
        revert Flash__creditFlashLoan_callbackFailed();

    // Update internal state again
    underlyingToken.transferFrom(address(receiver), address(pool), total); // removed
    pool.repayCreditAccount(total - fee, fee, 0); // removed

    return true;
}

```
