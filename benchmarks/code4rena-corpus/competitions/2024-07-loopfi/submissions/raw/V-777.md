# Vulnerability details

## Impact

The `_removeVaultFromList(ICDPVault vault)` method is used to remove a vault from the `vaultList` array. The implementation currently swaps the vale at index i with the value at the last index in the array and then proceeds to remove the last value from the array. 

However, the logic doesn't account for a possible scenario where the given `vault` is placed at the last index in the array. 

In this case, the same vault would be present both at index i (after swapping) and the last index.

## Proof of Concept
https://github.com/code-423n4/2024-07-loopfi/blob/main/src/VaultRegistry.sol#L49-L55

```solidity
function _removeVaultFromList(ICDPVault vault) private {
    uint256 vaultLen = vaultList.length;
    for (uint256 i = 0; i < vaultLen; ) {
        if (vaultList[i] == vault) {
            vaultList[i] = vaultList[vaultLen - 1];
            vaultList.pop();
            break;
        }
        unchecked { ++i; }
    }
}
```
If the vault to be deleted is at the last index, this code does not properly delete it. Instead, it swaps the vault at index `i` with the last index, effectively creating a duplicate at index `i`.

## Recommended Mitigation Steps

It would be better to check if a vault object is at the last index of the array before swapping. If it is, you can simply pop the last value without swapping, as there won't be any duplication in this case.

for example,

```solidity
function _removeVaultFromList(ICDPVault vault) private {
    uint256 vaultLen = vaultList.length;
    for (uint256 i = 0; i < vaultLen; ) {
        if (vaultList[i] == vault) {
            if(i != vaultLen -1){
              vaultList[i] = vaultList[vaultLen - 1];
            }
            vaultList.pop();
            break;
        }
        unchecked { ++i; }
    }
}
```
