# Vulnerability details

## Vulnerability Details 
By default, pendle markets' oracles are un-initialized. If the oracle is un-initialized then the following `_validatePtOracle` check will always return false.

```solidity
function _validatePtOracle() internal view returns (bool isValid) {
    try ptOracle.getOracleState(address(market), twapWindow) returns (
        bool increaseCardinalityRequired,
        uint16,
        bool oldestObservationSatisfied
    ) {
        if(!increaseCardinalityRequired && oldestObservationSatisfied) return true; 
    } 
    catch {
       // return default value on failure
    }
       
}
```

Even if it was initialized by someone else, it may have been for a smaller TWAP window than what LoopFi intends to use. In this case `_validatePtOracle` check will also always return false.

Pendle recommends protocols to check if the oracle is initialized (like LoopFi has done in the above function) and then if `increaseCardinalityRequired == true`, call `increaseObservationsCardinalityNext(uint16 cardinalityNext)` directly on the market contract with the required cardinality for the twapWindow

## Impact
If the oracle is un-initialized, which it will be by default, then the oracle will not be usable

If the oracle was initialized for a lower twapWindow then it will also be unusable

## Recommended Mitigation Steps
Very simple solution

1. Create a constant uint16 cardinalityRequired that corresponds to the required twapWindow

2. Modify the `_validatePtOracle()` function as follows

```diff
function _validatePtOracle() internal view returns (bool isValid) {
    try ptOracle.getOracleState(address(market), twapWindow) returns (
        bool increaseCardinalityRequired,
        uint16,
        bool oldestObservationSatisfied
    ) {
        
-       if(!increaseCardinalityRequired && oldestObservationSatisfied) return true;
+       if (increaseCardinalityRequired) {
+           IPMarket(market).increaseObservationsCardinalityNext(cardinalityRequired)
+       }

+       if (!oldestObservationSatisfied) {
+           // It's necessary to wait for at least the twapDuration, to allow data population.
+           return false;
+       }
                
    }
    catch {
        // return default value on failure
    }
       
}
```
