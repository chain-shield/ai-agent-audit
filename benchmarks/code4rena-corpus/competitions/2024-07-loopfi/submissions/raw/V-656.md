# Vulnerability details

## Vulnerability details
In `CDPVault` contract, function `borrow()` is used to borrow credit:

    function borrow(address borrower, address position, uint256 amount) external {
        int256 deltaDebt = toInt256(amount);
        modifyCollateralAndDebt({
            owner: position,
            collateralizer: position,
            creditor: borrower,
            deltaCollateral: 0,
            deltaDebt: deltaDebt
        });
    }
In `modifyCollateralAndDebt()`, there is no mechanism to check minimum amount of token to borrow. When user borrow with very small amount, and that position is underwater, there is no incentive for other user to liquidate that position, because there is no profit for user to do it. That position will become bad debt for protocol

## Impact
No incentive for user to liquidate position, lead to bad debt for protocol

## Tools Used
Manual review

## Recommended Mitigation Steps
Create minimum amount that user can borrow. When repaying, make sure all debt is repaid, or the debt is kept in minimum number.
