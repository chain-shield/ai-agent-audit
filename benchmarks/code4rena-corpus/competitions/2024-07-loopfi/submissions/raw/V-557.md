# Vulnerability details

## Vulnerability details

Protocol only allow registered vaults be called by users with `PositionAction#deposit/withdraw/borrow/repay` actions, but the registered vaults can be removed by the owner even the vaults have assets and debt, it may cause the users can't operate the vaults anymore and cause bad debt to the protocol or users.

`VaultRegistry#removeVault`:

```solidity
function removeVault(ICDPVault vault) external override(IVaultRegistry) onlyRole(VAULT_MANAGER_ROLE) {
    if (!registeredVaults[vault]) revert VaultRegistry__removeVault_vaultNotFound();

    _removeVaultFromList(vault);
    registeredVaults[vault] = false;
    emit VaultRemoved(vault);
}
```

## Impact

Registered vaults can be removed even the vaults have assets and debt to harm users or protocol.

## Tools Used

vscode

## Recommended Mitigation Steps

protocol should check the vault is still have assets/debt or not before admin remove the vaults.
