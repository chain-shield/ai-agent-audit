# Vulnerability details

## Impact
when the CDPVault.sol is paused, users can still take loans. So for example in the event of an exploit like oracle manipulation and the system is paused, attackers will still be able to take loans at manipulated prices, leaving the contract with bad debt

## Proof of Concept
Pause mechanism is there to pause the system in the event of security exploit. This means that functions like `borrow` are also supposed to be pausable since the `borrow` operation is what most attackers use to steal assets from vaults like this.
Other functions in the CDPVault.sol are pausable but the `borrow(...)` function is not.

```solidity
File: CDPVault.sol
/// @notice Borrows credit against collateral
    /// @param borrower Address of the borrower
    /// @param position Address of the position
    /// @param amount Amount of debt to generate [wad]
    /// @dev The borrower will receive the amount of credit in the underlying token
    function borrow(address borrower, address position, uint256 amount) external {
        int256 deltaDebt = toInt256(amount);
        modifyCollateralAndDebt({
            owner: position,
            collateralizer: position,
            creditor: borrower,
            deltaCollateral: 0,
            deltaDebt: deltaDebt
        });
    }

```


## Tools Used
Manual review

## Recommended Mitigation Steps
Add the `whenNotPaused` modifier to the `borrow(...)` function
```diff
-- function borrow(address borrower, address position, uint256 amount) external {
++ function borrow(address borrower, address position, uint256 amount) external whenNotPaused {
        int256 deltaDebt = toInt256(amount);
        modifyCollateralAndDebt({
            owner: position,
            collateralizer: position,
            creditor: borrower,
            deltaCollateral: 0,
            deltaDebt: deltaDebt
        });
    }

```
