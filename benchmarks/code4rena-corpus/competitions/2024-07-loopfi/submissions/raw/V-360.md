# Vulnerability details

## Impact

A liquidated position will be worse off than before if liquidation discount is in play.

## Proof of Concept

- Alice takes out a loan of 80 ETH for a 100 ETH collateral (100 aETH worth 1 ETH each), with a collateralization ratio of 100%.
- A while later, the value of the 100 ETH collateral becomes 90 ETH instead (100 aETH worth 0.9 each). Alice is now liquitable. The 80 ETH loan now becomes 81 ETH due to interests.
- Bob wants to liquidate Alice position. He calls `liquidatePosition()`, with 70 ETH, expecting some bonus (eg getting 75 ETH worth of collateral).

In liquidatePosition, `spotPrice()` is called and `discountedPrice` is calculated. Assume `liquidationDiscount` is 20%.:

```
        // load price and calculate discounted price
        uint256 spotPrice_ = spotPrice();
        uint256 discountedPrice = wmul(spotPrice_, liqConfig_.liquidationDiscount);
```

- The `spotPrice` is now 0.9ETH per 1 aETH.
- discountedPrice is now 0.72ETH per 1 aETH.

`TotalDebt` is checked, 81ETH and collateral is 90ETH, function continues:

```
        // Enusure that there's no bad debt
        if (calcTotalDebt(debtData) > wmul(position.collateral, spotPrice_)) revert CDPVault__BadDebt();
```

`takeCollateral`, `deltaDebt`, `penalty` is calculated. `liquidationPenalty` is negligible in this report.  

```
        // compute collateral to take, debt to repay and penalty to pay
        uint256 takeCollateral = wdiv(repayAmount, discountedPrice);
        uint256 deltaDebt = wmul(repayAmount, liqConfig_.liquidationPenalty);
        uint256 penalty = wmul(repayAmount, WAD - liqConfig_.liquidationPenalty);
```

takeCollateral = 70 ETH / 0.72 = 97.2 ETH 

```
        // transfer the collateral amount from the vault to the liquidator
        token.safeTransfer(msg.sender, takeCollateral);
```

With the liquidation discount, the liquidator can take 97.2 of the 100 aETH while repaying only 70 ETH.

Before: Alice has 81 ETH debt and 90 ETH collateral (no bad debt, CR = 90 / 81 = 111%)
After: Alice has 11 ETH debt and 2.8 * 0.9 = 2.52 ETH collateral (collaterization ratio is worse off, CR = 2.52 / 11 = 22%, bad debt incurred)


## Tools Used

Manual Review

## Recommended Mitigation Steps

Consider simplifying the liquidation process by removing the liquidation discount. Ensure that the borrower's position must not be worse off after any sort of liquidation.
