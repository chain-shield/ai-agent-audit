# Vulnerability details



## Proof of Concept

Take a look at https://github.com/code-423n4/2024-07-loopfi/blob/57871f64bdea450c1f04c9a53dc1a78223719164/src/oracle/BalancerOracle.sol#L158-L164

```solidity
function spot(
  address /*token*/
) external view virtual override returns (uint256 price) {
  if (!_getStatus()) {
    revert BalancerOracle__spot_invalidPrice();
  }
  return safePrice;
}

```

This function is expected to return the latest price for the asset, however this is never done, cause the function just returns the stored `safePrice` instead of the `currentPrice`.

From [here](https://github.com/code-423n4/2024-07-loopfi/blob/57871f64bdea450c1f04c9a53dc1a78223719164/src/oracle/BalancerOracle.sol#L45-L48) we can see how the pattern of the prices the contract implements is:

```solidity
    uint256 public safePrice;
    uint256 public currentPrice;
    uint256 public lastUpdate;

```

Note that asides the fact that common concept of `spot` prices is the most recent price/current price, it's also been clearly documented that this should indeed return the latest price so the right way would be to check if currentPrice != safePrice and then return the safePrice so `- return safePrice` & `+ return currentPrice`, would be key to note that we can't expect the keeper to ensure the _safePrice_ is always equal to the _currentPrice_ cause in order to update we need to wait for a specific duration, otherwise the attempt reverts [here](https://github.com/code-423n4/2024-07-loopfi/blob/57871f64bdea450c1f04c9a53dc1a78223719164/src/oracle/BalancerOracle.sol#L115).

## Impact

The `spot` function returns `safePrice` instead of `currentPrice`, providing outdated non-spot prices, flawing all logics that need the correct current pricing to function in the protocol.

## Recommended Mitigation Steps

Update the `spot` function to return the `currentPrice`:

```diff
function spot(address /*token*/) external view virtual override returns (uint256 price) {
    if (!_getStatus()) {
        revert BalancerOracle__spot_invalidPrice();
    }
-    return safePrice;
+    return currentPrice;
}
```
