# Vulnerability details

## Vulnerability Details
The `updateLeverJoin` function in the `PoolAction` contract is crucial for updating parameters when joining a Balancer pool with leveraged positions. It adjusts token amounts for joining based on flash loan amounts and upfront tokens.

The function attempts to skip the Balancer Pool Token (BPT) when updating the `assetsIn` array. However, the implemented logic incorrectly adjusts the index, causing a mismatch between the `assets` and `assetsIn` arrays.

## Code Snippet
```solidity
bool skipIndex = false;
for (uint256 i = 0; i < len; ) {
    uint256 assetIndex = i - (skipIndex ? 1 : 0);
    if (assets[i] == joinToken) {
        maxAmountsIn[i] = joinAmount;
        assetsIn[assetIndex] = joinAmount;
    } else if (assets[i] == upFrontToken && assets[i] != poolToken) {
        maxAmountsIn[i] = upfrontAmount;
        assetsIn[assetIndex] = upfrontAmount;
    } else {
        skipIndex = skipIndex || assets[i] == poolToken;
    }
    unchecked {
        ++i;
    }
}
```

## Impact
1. Incorrect token amounts may be assigned in the `assetsIn` array.
2. This can lead to failed transactions when attempting to join the Balancer pool.
3. In worst cases, it could result in unintended token transfers or incorrect pool share allocation.

## Scenario
Consider a Balancer pool with tokens [TokenA, BPT, TokenB, TokenC]. If BPT is the second token:
- For TokenA: Correct assignment (index 0 in both arrays)
- For BPT: Skipped in `assetsIn` (correct)
- For TokenB: Incorrect assignment (index 2 in `assets`, but 1 in `assetsIn`)
- For TokenC: Incorrect assignment (index 3 in `assets`, but 2 in `assetsIn`)

## Fix
Refactor the loop to maintain separate indices for `assets` and `assetsIn` arrays:

```solidity
uint256 assetsInIndex = 0;
for (uint256 i = 0; i < assets.length; i++) {
    if (assets[i] != poolToken) {
        if (assets[i] == joinToken) {
            maxAmountsIn[i] = joinAmount;
            assetsIn[assetsInIndex] = joinAmount;
        } else if (assets[i] == upFrontToken) {
            maxAmountsIn[i] = upfrontAmount;
            assetsIn[assetsInIndex] = upfrontAmount;
        }
        assetsInIndex++;
    } else {
        maxAmountsIn[i] = 0;  
    }
}
```

function test_updateLeverJoin_indexMisalignment() public {
    address mockJoinToken = address(0x1);
    address mockUpFrontToken = address(0x2);
    address mockPoolToken = address(0x3);
    address mockExtraToken = address(0x4);
    uint256 flashLoanAmount = 1000 ether;
    uint256 upfrontAmount = 500 ether;

    address[] memory assets = new address[](4);
    assets[0] = mockUpFrontToken;
    assets[1] = mockPoolToken;
    assets[2] = mockJoinToken;
    assets[3] = mockExtraToken;

    uint256[] memory assetsIn = new uint256[](3);
    uint256[] memory maxAmountsIn = new uint256[](4);

    PoolActionParams memory params = PoolActionParams({
        protocol: Protocol.BALANCER,
        minOut: 0,
        recipient: user,
        args: abi.encode(bytes32(0), assets, assetsIn, maxAmountsIn)
    });

    // Call updateLeverJoin
    PoolActionParams memory updatedParams = poolAction.updateLeverJoin(
        params,
        mockJoinToken,
        mockUpFrontToken,
        flashLoanAmount,
        upfrontAmount,
        mockPoolToken
    );

    // Decode the updated args
    (,, uint256[] memory updatedAssetsIn, uint256[] memory updatedMaxAmountsIn) = abi.decode(
        updatedParams.args,
        (bytes32, address[], uint256[], uint256[])
    );

    // Check for misalignment
    assertEq(updatedMaxAmountsIn[0], upfrontAmount, "Incorrect upfront amount");
    assertEq(updatedMaxAmountsIn[1], 0, "Pool token amount should be 0");
    assertEq(updatedMaxAmountsIn[2], flashLoanAmount, "Incorrect flash loan amount");
    assertEq(updatedMaxAmountsIn[3], 0, "Extra token amount should be 0");

    // The bug causes misalignment in assetsIn
    assertEq(updatedAssetsIn[0], upfrontAmount, "Incorrect upfront amount in assetsIn");
    assertEq(updatedAssetsIn[1], 0, "Second token in assetsIn should be 0");
    assertEq(updatedAssetsIn[2], 0, "Third token in assetsIn should be 0");

    // This assertion should fail due to the bug
    assertTrue(updatedAssetsIn[1] == flashLoanAmount, "Flash loan amount is misaligned in assetsIn");
}
