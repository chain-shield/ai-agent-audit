# Vulnerability details

## Impact

In CDPVault.sol, the `liquidatePosition` function may potentially throw unexpected exceptions if the position to be liquidated has a collateral that can't fully cover the debt. 

The exact scenario is when the value of the collateral multiplied by the spot price of the token is less than the total debt of the position, which in financial terms, is termed as 'bad debt'. 

Currently, the contract does not handle such scenarios, and an attempt to liquidate such a position would fail with a generic Solidity exception.

https://github.com/code-423n4/2024-07-loopfi/blob/main/src/CDPVault.sol#L526

```solidity
if (calcTotalDebt(debtData) > wmul(position.collateral, spotPrice_)) revert CDPVault__BadDebt();
```

## Recommended Mitigation Steps

Instead of directly reverting in such situations, the contract could implement a strategy to handle bad debt (like ways to recover it or mitigate its impact). 

Apart from that, proper error messages could be returned to indicate the problem faced during the liquidation process. If the decision to disallow liquidations in 'bad debt' scenarios is intentional, it would be helpful for users if a detailed explanation was included in the comments.
