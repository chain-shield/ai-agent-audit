# Vulnerability details

## Impact
All protocol oracles extend `UUPSUpgradeable`, allowing protocol managers to upgrade these oracles to another implementation if the oracle is down. The only condition for this to be possible is if the price is invalid or if the whole referenced protocol (Chainlink/Balancer/Pendle) is in an "invalid" state, this is done in `BalancerOracle` and  `PendleLPOracle`, where `_authorizeUpgrade` checks if the price is valid before allowing upgradability.

However, this is missed in `ChainlinkOracle`, allowing managers to upgrade the oracle's implementation even if it's valid, violating the integrity of the protocol.

## Tools Used

Manual review

## Recommended Mitigation Steps

Add status check in `_authorizeUpgrade` just like in `BalancerOracle` and  `PendleLPOracle`.
