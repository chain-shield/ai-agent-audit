# Vulnerability details

## Impact
Any user can reduce their accrued interest rate by a larger than usual amount, simply by repaying quotaInterestRate < repayAmount < accruedInterest; 
This is because the profit variable (https://github.com/code-423n4/2024-07-loopfi/blob/57871f64bdea450c1f04c9a53dc1a78223719164/src/CDPVault.sol#L670, https://github.com/code-423n4/2024-07-loopfi/blob/57871f64bdea450c1f04c9a53dc1a78223719164/src/CDPVault.sol#L676) is reused both in the cumulativeQuotaInterest repayment logic (https://github.com/code-423n4/2024-07-loopfi/blob/57871f64bdea450c1f04c9a53dc1a78223719164/src/CDPVault.sol#L665-L681), and in the accrued interest rate repayment logic (https://github.com/code-423n4/2024-07-loopfi/blob/57871f64bdea450c1f04c9a53dc1a78223719164/src/CDPVault.sol#L685-L710).
Because the same variable is used, the user can choose to fully repay the cumulativeQuotaInterest, and add, for example 1, to the the repayment amount, to invoke the accrued interest repayment logic. Because we aren't repaying the full accrued interest amount, the cumulative index is recalculated: https://github.com/code-423n4/2024-07-loopfi/blob/57871f64bdea450c1f04c9a53dc1a78223719164/src/CDPVault.sol#L703-L708. Inside the calculation, we can see the profit variable, and because it is set to cumulativeQuotaInterest+1, the cumulativeIndex is recalculated as less than what it should be, meaning that next time the user repays the debt, they will have less interest rate to pay.

Logs:

We can see we started with the same accruedInterest, same cumulativeQuotaInterest, however our accruedInterest after the repayment is entirely different.
Following the same calculation as above, 13671659951651893633 + 1128082191780821917+1 != 15927824335213537468 (accrued interest after the repayment + cumulativeQuotaInterest != accrued interest before repayment)

In this case, the user just saved 1128082191780821918 worth of interest, just by repaying cumulativeQuotaInterest+1 instead of, for example, cumulativeQuotaInterest, or just repaying the whole interest, etc.
