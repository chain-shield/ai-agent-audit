# Vulnerability details




## Impact
The `_onIncreaseLever` function does not actually deposit the calculated collateral amount into the `CDPVault`. This results in the leverage not being increased as intended, which can lead to potential financial losses for users relying on this function to manage their leveraged positions.

## Proof of Concept
In we take a look at the [`_onIncreaseLever`](https://github.com/code-423n4/2024-07-loopfi/blob/57871f64bdea450c1f04c9a53dc1a78223719164/src/proxy/PositionAction20.sol#L59-L71) function: 
```solidity
function _onIncreaseLever(
    LeverParams memory leverParams,
    address /*upFrontToken*/,
    uint256 upFrontAmount,
    uint256 swapAmountOut
) internal override returns (uint256) {
    // for standard erc20 cdps treat the upFrontAmount and swapAmountOut as the collateral token
    uint256 addCollateralAmount = swapAmountOut + upFrontAmount;

    // allow deposit into the CDP Vault
    IERC20(leverParams.collateralToken).forceApprove(leverParams.vault, addCollateralAmount);
    return addCollateralAmount;
}
```
We can see that the calculated `addCollateralAmount` is only approved for spending by the `CDPVault`, but the actual deposit is never made.

## Recommended Mitigation Steps
Update the `_onIncreaseLever` function to include a call to the `deposit` method on the `CDPVault` after approving the tokens. This will ensure that the calculated `addCollateralAmount` is actually deposited into the `CDPVault`, thereby correctly increasing the leverage as intended.

```solidity
function _onIncreaseLever(
    LeverParams memory leverParams,
    address /*upFrontToken*/,
    uint256 upFrontAmount,
    uint256 swapAmountOut
) internal override returns (uint256) {
    // for standard erc20 cdps treat the upFrontAmount and swapAmountOut as the collateral token
    uint256 addCollateralAmount = swapAmountOut + upFrontAmount;

    // allow deposit into the CDP Vault
    IERC20(leverParams.collateralToken).forceApprove(leverParams.vault, addCollateralAmount);

    // deposit the collateral into the CDP Vault
    return ICDPVault(leverParams.vault).deposit(leverParams.position, addCollateralAmount);
}
```
