# Vulnerability details

## Impact
If a user withdraws an amount that reduces the collateral to zero, the resulting position will become undercollateralized. This violates the safety condition that the collateral value should be at least 125% of the debt (based on the `liquidationRatio` of 12500).

## Proof of Concept
In a scenario where an attacker could exploit this vulnerability to drain the collateral from the vault, leaving the position with no collateral and a non-zero debt. This could lead to financial losses for the protocol and its users.

Even in less severe cases, allowing undercollateralized positions undermines the integrity of the collateral system and poses risks to the stability of the protocol.

The below PoC shows how.

* User has a position with an initial collateral of 1 and an initial debt of 0.
* User calls the `withdraw()` function with an amount of 1.
* The `withdraw()` function calculates `tokenAmount` as 1 and updates the position's collateral to 0.
* The `spotPrice()` returns 0, resulting in a `collateralValue` of 0.
* The `withdraw()` function completes without any validation, allowing the user to withdraw the entire collateral.

After the withdrawal, the position has a `newCollateral` of 0, a `newDebt` of 0, and a `collateralValue` of 0. The `liquidationRatio` is set to 12500, requiring the collateral value to be at least 125% of the debt. With no collateral remaining, the position becomes undercollateralized, violating the safety condition.

## Tools Used
Manual review

## Recommended Mitigation Steps
The `withdraw()` function should checks to ensure that the resulting position remains safe after the withdrawal. It should validate that the remaining collateral value is sufficient to maintain the required liquidation ratio.
```solidity
function withdraw(address to, uint256 amount) external whenNotPaused returns (uint256 tokenAmount) {
    tokenAmount = wdiv(amount, tokenScale);
    int256 deltaCollateral = -toInt256(tokenAmount);

+   Position memory position = positions[to];
+   uint256 newCollateral = sub(position.collateral, tokenAmount);
+   uint256 collateralValue = wmul(newCollateral, spotPrice());
+   uint256 totalDebt = calcTotalDebt(_calcDebt(position));
+   
+   require(_isCollateralized(totalDebt, collateralValue, vaultConfig.liquidationRatio), "Withdrawal would make position unsafe");

    modifyCollateralAndDebt({
        owner: to,
        collateralizer: msg.sender,
        creditor: msg.sender,
        deltaCollateral: deltaCollateral,
        deltaDebt: 0
    });
}
```
