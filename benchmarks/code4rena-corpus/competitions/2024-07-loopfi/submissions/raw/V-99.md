# Vulnerability details

## Impact
The `maxFlashLoan` function  returns an inflated maximum borrowable amount by not accounting for the protocol fee. This can lead to users attempting to borrow more than the system can handle resulting in failed transactions or unexpected behavior.

## Proof of Concept
Take a look at the `maxFlashLoan` function: https://github.com/code-423n4/2024-07-loopfi/blob/57871f64bdea450c1f04c9a53dc1a78223719164/src/Flashlender.sol#L64-L68

```solidity
function maxFlashLoan(address token) external view override returns (uint256 max) {
    if (token == address(underlyingToken)) {
        max = pool.creditManagerBorrowable(address(this));
    }
}
```

It returns the raw borrowable amount from the pool without considering the protocol fee. However, in the `flashLoan` function, a fee is added to the borrowed amount:

```solidity
function flashLoan(
    IERC3156FlashBorrower receiver,
    address token,
    uint256 amount,
    bytes calldata data
) external override nonReentrant returns (bool) {
    // ... (other code)
    uint256 fee = wmul(amount, protocolFee);
    uint256 total = amount + fee;
    // ... (rest of the function)
}
```

If a user attempts to borrow the full amount reported by `maxFlashLoan`, the actual amount plus the fee would exceed the pool's lending capacity causing the transaction to fail.

## Recommended Mitigation Steps
Modify the `maxFlashLoan` function to account for the protocol fee when calculating the maximum borrowable amount. The function should return a value that, when borrowed, will not exceed the pool's capacity after the fee is added. 
```diff
function maxFlashLoan(address token) external view override returns (uint256 max) {
    if (token == address(underlyingToken)) {
-       max = pool.creditManagerBorrowable(address(this));
+       uint256 borrowable = pool.creditManagerBorrowable(address(this));
+       max = borrowable * WAD / (WAD + protocolFee);
    }
}
```

This makess sure that the reported maximum flash loan amount is one that can be fully repaid (including the fee) without exceeding the pool's borrowable limit. Make sure that the `WAD` constant (typically 10^18) is properly defined or imported.
