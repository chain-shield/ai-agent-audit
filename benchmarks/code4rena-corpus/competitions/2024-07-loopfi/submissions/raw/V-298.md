# Vulnerability details

`setCreditManagerDebtLimit()` allows setting a credit manager's debt limit to any value without validation. This can lead to a scenario where the total borrowed amount exceeds the total assets in the pool, violating a critical invariant.

## Impact
If a credit manager's debt limit is set too high, it can cause the pool's `totalBorrowed` to surpass `totalAssets`. This breaks the fundamental invariant `totalAssets >= totalBorrowed`, which is essential for maintaining the pool's solvency and correct operation.

Even without malicious intent, incorrectly setting debt limits can lead to accounting errors and loss of user confidence in the system.

## Proof of Concept
a. The pool is initialized with `totalAssets = 0` and `totalBorrowed = 0`.
b. A credit manager with address 0x179b6b1cb6755e31 is added to the pool.
c. The pool controller calls `setCreditManagerDebtLimit()` with parameters:

   * `creditManager = 0x179b6b1cb6755e31`

   * `newLimit = 1`

d. The function executes without any checks, setting [src/PoolV3.sol#L813](https://github.com/code-423n4/2024-07-loopfi/blob/57871f64bdea450c1f04c9a53dc1a78223719164/src/PoolV3.sol#L813)
```solidity
        _creditManagerDebt[creditManager].limit = _convertToU128(newLimit); // U:[LP-25D]
```
e. The invariant `totalAssets >= totalBorrowed` is now violated because:

   * `totalAssets = 0`
   * `totalBorrowed = 1`

## Recommended Mitigation Steps
To prevent this issue, add a check in `setCreditManagerDebtLimit()` to ensure that setting a new debt limit does not cause `totalBorrowed` to exceed `totalAssets`.
```solidity
function setCreditManagerDebtLimit(
    address creditManager,
    uint256 newLimit
)
    external
    override
    controllerOnly
    nonZeroAddress(creditManager)
{
+   require(totalAssets() >= totalBorrowed() + newLimit, "Debt limit too high");
    // ...
}
```
This check guarantees that the `totalAssets >= totalBorrowed` invariant holds after updating a credit manager's debt limit, preventing the pool from entering an invalid state.
