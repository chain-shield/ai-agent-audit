# Vulnerability details

## Impact
Admin might recover the staked token, instead of the rewards token

## Proof of Concept
The `recoverERC20` in ChiefIncentiveCOntroller.sol & MultiFeeDistributor.sol is  used to recover rewards token such as BAL obtained in the contract
```
function recoverERC20(address tokenAddress, uint256 tokenAmount) external onlyOwner {
        _recoverERC20(tokenAddress, tokenAmount);
    }
```
The only problem is it doesn't really check the sent token that is being withdrawn is the rewards token or not.
As the comment indicates it is used to recover only rewards tokens
Allowing to retrieve all tokens also enables the retrieval of legitimate ones. This way rewards cannot be collected anymore. It could be seen as allowing a rug pull by the project and should be avoided

## Tools Used
Manual review

 function recoverERC20(
    address tokenAddress,
