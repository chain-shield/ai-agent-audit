# Vulnerability details

## Impact
The `_chainlinkSpot` function in `AuraVault.sol` lacks stale data validation, which can cause the vault to operate with outdated price feeds.

## Proof of Concept
The `_chainlinkSpot` function in `AuraVault.sol` [retrieves the latest price](https://github.com/code-423n4/2024-07-loopfi/blob/57871f64bdea450c1f04c9a53dc1a78223719164/src/vendor/AuraVault.sol#L367) from the Chainlink feed without checking if the price is **fresh or stale**. It uses the `latestRoundData` function of the AggregatorV3Interface to obtain the price and [only verifies that the price is greater than 0](https://github.com/code-423n4/2024-07-loopfi/blob/57871f64bdea450c1f04c9a53dc1a78223719164/src/vendor/AuraVault.sol#L375):
```solidity
    function _chainlinkSpot() private view returns (uint256 price) {
        bool isValid;
        try AggregatorV3Interface(BAL_CHAINLINK_FEED).latestRoundData() returns (
            uint80 /*roundId*/,
            int256 answer,
            uint256 /*startedAt*/,
            uint256 /*updatedAt*/,
            uint80 /*answeredInRound*/
        ) {
            price = wdiv(uint256(answer), BAL_CHAINLINK_DECIMALS);
@>          isValid = (price > 0);
        } catch {}

        if (!isValid) revert AuraVault__chainlinkSpot_invalidPrice();
    }
```
As shown above, the function doesn't check the `updatedAt` value to verify for stale data, which means it might retrieve outdated or stale prices that will then be used in the calculation of rewards:
```solidity
    function _previewReward(
        uint256 balReward,
        uint256 auraReward,
        VaultConfig memory config
    ) private view returns (uint256 amount) {
@>      amount = (balReward * _chainlinkSpot()) / IOracle(feed).spot(asset());

        amount = (amount * (INCENTIVE_BASIS - config.claimerIncentive)) / INCENTIVE_BASIS;
    }
```

## Recommended Mitigation Steps
Make sure the price is up-to-date:
```diff
    function _chainlinkSpot() private view returns (uint256 price) {
        bool isValid;
        try AggregatorV3Interface(BAL_CHAINLINK_FEED).latestRoundData() returns (
            uint80 /*roundId*/,
            int256 answer,
            uint256 /*startedAt*/,
-           uint256 /*updatedAt*/,
+           uint256 updatedAt,
            uint80 /*answeredInRound*/
        ) {
+           uint256 stalePeriod = 10 minutes; // Example threshold for stale data
            price = wdiv(uint256(answer), BAL_CHAINLINK_DECIMALS);
-           isValid = (price > 0);
+           isValid = (price > 0 && block.timestamp - updatedAt <= stalePeriod);
        } catch {}

        if (!isValid) revert AuraVault__chainlinkSpot_invalidPrice();
    }
```
