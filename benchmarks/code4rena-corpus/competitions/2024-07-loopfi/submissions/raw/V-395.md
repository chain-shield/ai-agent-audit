# Vulnerability details

## Impact

Functions with the `controllerOnly` modifier cannot be used, like `setCreditManagerDebtLimit()`, `setTotalDebtLimit()`, `setAllowed()`, `setLocked()`.

## Proof of Concept

PoolV3 inherits ACLNonReentrantTrait from Gearbox.

```
import {ACLNonReentrantTrait} from "@gearbox-protocol/core-v3/contracts/traits/ACLNonReentrantTrait.sol";
...

contract PoolV3 is ERC4626, ERC20Permit, ACLNonReentrantTrait, ContractsRegisterTrait, IPoolV3 {
```

PoolV3 also uses the modifier `controllerOnly`:

```
  /// @param status `true` to allow, `false` to disallow
    function setAllowed(address account, bool status) external controllerOnly {
        _allowed[account] = status;
    }
```

The issue with this is that `controllerOnly` is a modifier in ACLNonReentrantTrait.sol, which is from [Gearbox](https://github.com/Gearbox-protocol/core-v3/blob/main/contracts/traits/ACLNonReentrantTrait.sol).

```
abstract contract ACLNonReentrantTrait is ACLTrait, Pausable, ReentrancyGuardTrait {
    /// @notice Emitted when new external controller is set
    event NewController(address indexed newController);

    /// @notice External controller address
    address public controller;

    /// @dev Ensures that function caller is external controller or configurator
    modifier controllerOnly() {
        _ensureCallerIsControllerOrConfigurator();
        _;
    }
```

This means that Gearbox sets the controller, and not Loop. Functions with `controllerOnly` will not work.

PoolV3.sol has some new functions that is not part of the original fork, such as `setAllowed()` and `setLocked()`. 

```
    function setAllowed(address account, bool status) external controllerOnly {
        _allowed[account] = status;
    }

    /// @notice Locks or unlocks the pool, can only be called by controller
    /// @param status `true` to lock, `false` to unlock, default pool status is locked
    function setLock(bool status) external controllerOnly {
        locked = status;
    }
```

The problem is that these functions cannot be invoked since the access control is from gearbox.

Manual Review

## Recommended Mitigation Steps

Set access control for the loop contracts only.
