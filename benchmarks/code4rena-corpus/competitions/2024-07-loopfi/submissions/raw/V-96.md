# Vulnerability details

## Impact
The implementation of `liquidatePositionBadDebt` function does not allow for partial liquidations of positions with bad debt. This limitation can discourage liquidators from acting on large positions leading to the accumulation of bad debt in the system. 

## Proof of Concept
Take a look at the `liquidatePositionBadDebt` function, where the logic forces the liquidation of the entire position regardless of the `repayAmount` provided by the liquidator.

https://github.com/code-423n4/2024-07-loopfi/blob/57871f64bdea450c1f04c9a53dc1a78223719164/src/CDPVault.sol#L598-L608
```solidity
598:         // Enusure that the debt is greater than the collateral at discounted price
599:         if (calcTotalDebt(debtData) <= wmul(position.collateral, discountedPrice)) revert CDPVault__noBadDebt();
600:         // compute collateral to take, debt to repay
601:         uint256 takeCollateral = wdiv(repayAmount, discountedPrice);
602:         if (takeCollateral < position.collateral) revert CDPVault__repayAmountNotEnough();
603: 
604:         // account for bad debt
605:         takeCollateral = position.collateral;
606:         repayAmount = wmul(takeCollateral, discountedPrice);
607:         uint256 loss = calcTotalDebt(debtData) - repayAmount;
```

On line 599, the function first checks if the total debt exceeds the discounted value of the collateral. If not, it reverts with `CDPVault__noBadDebt`.

On 601, it then calculates the amount of collateral (`takeCollateral`) that the provided `repayAmount` would cover.

If this amount is less than the total collateral, it reverts with `CDPVault__repayAmountNotEnough` as seen on 602.

However, immediately after this check, it sets `takeCollateral` to the full amount of collateral in the position thereby totally ignoring the initial calculation.

This means that even if a liquidator only wants to repay a portion of the bad debt, they will always end up liquidating the entire position.

## Tools used
Manual review

## Recommended Mitigation Steps
Modify the function to consistently use the original `repayAmount` provided by the liquidator, allowing for partial liquidations of bad debt positions.
