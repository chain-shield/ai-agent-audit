# Vulnerability details

## Vulnerability Details
Bad debt will accrue in the protocol if liquidations are paused. Liquidations can be paused, which shouldn't be as accruing excessive bad debt could put the protocol at risk of protocol insolvency. As seen below, liquidation and liquidations of bad debt can be paused. This will lead to bad debt being accrued in the protocol.

### Coded PoC
Modify `test_liquidate_partial_1` in `test/unit/CDPVault.t.sol` with the test below to demonstrate the described scenario.
```solidity
    function test_liquidate_partial_1() public {
        CDPVault vault = createCDPVault(token, 150 ether, 0, 1.25 ether, 1 ether, 1 ether);
        createGaugeAndSetGauge(address(vault));

        // create position
        _modifyCollateralAndDebt(vault, 100 ether, 80 ether);

        // liquidate position
        address position = address(this);
        uint256 repayAmount = 40 ether;
        _updateSpot(0.80 ether);
        mockWETH.approve(address(vault), repayAmount);

        uint256 creditBefore = credit(address(this));
        uint256 virtualDebtBefore = virtualDebt(vault, position);
        vault.pause();
        // Liquiations will fail when the vault is paused, leaving debt in the protocol.
        vm.expectRevert();
        vault.liquidatePosition(position, repayAmount);
    }
```

## Impact
Bad debt will accrue in the protocol if liquidations and liquidations of bad debt are paused, which puts the protocol at risk of protocol insolvency.
