# Vulnerability details

## Vulnerability details

User's positions collateral only can be increased when he deposit collateral to the vault:

```solidity
 function _modifyPosition(
    address owner,
    Position memory position,
    uint256 newDebt,
    uint256 newCumulativeIndex,
    int256 deltaCollateral,
    uint256 totalDebt_
) internal returns (Position memory) {
    uint256 currentDebt = position.debt;
    // update collateral and debt amounts by the deltas
    // @audit - the position collateral only can be increased when users deposit collateral to the vault
    position.collateral = add(position.collateral, deltaCollateral);
    ...
}
```

But when liquidating the position, the protocol don't consider the position accumulated interest, such that the position may be liquidated earlier than expected:

```solidity
function liquidatePosition(address owner, uint256 repayAmount) external whenNotPaused {
    ...
    if (takeCollateral > position.collateral) revert CDPVault__tooHighRepayAmount();

    // verify that the position is indeed unsafe
    if (_isCollateralized(calcTotalDebt(debtData), wmul(position.collateral, spotPrice_), config.liquidationRatio))
        revert CDPVault__liquidatePosition_notUnsafe();
    ...
```

## Impact

Wrong position collateral calculation may cause users be liquidated earlier than expected.

## Tools Used

vscode

## Recommended Mitigation Steps

Add the accumulated interest to the position collateral before liquidating the position.
