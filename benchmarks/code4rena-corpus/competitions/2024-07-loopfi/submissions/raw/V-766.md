# Vulnerability details

## Impact
In the unlikely case that the price returned by the oracle is 0, unhealthy positions with or without bad debt won't be liquidatable because all the oracles revert with that value.
If this ever happens, it is critical for `CDPVault` to be able to liquidate all of the unhealthy positions, so that losses don't grow and insolvency can be avoided.

## Tools Used
Manual Review
## Recommended Mitigation Steps
Implement a mechanism that allows positions to be liquidated even if the price drops to zero.


## Assessed type

Oracle
