# Vulnerability details

## Impact
`lastDebtUpdate` will have an incorrect value.

## Proof of Concept
in the `CDPVault` on [line 318](https://github.com/code-423n4/2024-07-loopfi/blob/57871f64bdea450c1f04c9a53dc1a78223719164/src/CDPVault.sol#L318) `position.lastDebtUpdate=uint64(block.number)` however in the natspec for the struct declaration in which position is of type, it is indicated that `lastDebtUpdate` should be timestamp as we can see below
```
    // Position Accounting
    struct Position {
        uint256 collateral; // [wad]
        uint256 debt; // [wad]
        uint256 lastDebtUpdate; // [timestamp]
        uint256 cumulativeIndexLastUpdate;
        uint192 cumulativeQuotaIndexLU;
        uint128 cumulativeQuotaInterest;
    }
```

## Tools Used
Manual Review
## Recommended Mitigation Steps
`lastDebtUpdate` should be equal to block.timestamp
