# Vulnerability details

## Impact
Detailed description of the impact of this finding.

This report addresses a likely bug in the vote() and _vote() functions of the GaugeV3 contract, part of the Gearbox Protocol. 

The issue arises from inadequate validation of user voting power, potentially allowing users to cast more votes than they should, leading to governance manipulation. 

## Proof of Concept
Provide direct links to all referenced code in GitHub. Add screenshots, logs, or any other relevant proof that illustrates the concept.

The vote() function relies on an external voting contract to verify that the caller is authorised to vote, but it does not explicitly check whether the user has sufficient voting power before adding their votes.

Without proper validation within _vote(), users can potentially cast more votes than they have voting power for, assuming that there are no checks elsewhere in the protocol.

The vulnerable lines of code are depicted below.
```sol
    function vote(
        address user,
        uint96 votes,
        bytes calldata extraData
    )
        external
        override
        onlyVoter // U:[GA-02]
    {
        (address token, bool lpSide) = abi.decode(extraData, (address, bool)); // U:[GA-10,11,12]
        _vote({user: user, token: token, votes: votes, lpSide: lpSide}); // U:[GA-10,11,12]
    }

    function _vote(address user, uint96 votes, address token, bool lpSide) internal {
        if (!isTokenAdded(token)) revert TokenNotAllowedException(); // U:[GA-10]


        _checkAndUpdateEpoch(); // U:[GA-11]


        QuotaRateParams storage qp = quotaRateParams[token]; // U:[GA-12]
        UserVotes storage uv = userTokenVotes[user][token];


        if (lpSide) {
            qp.totalVotesLpSide += votes; // U:[GA-12]
            uv.votesLpSide += votes; // U:[GA-12]
        } else {
            qp.totalVotesCaSide += votes; // U:[GA-12]
            uv.votesCaSide += votes; // U:[GA-12]
        }


        emit Vote({user: user, token: token, votes: votes, lpSide: lpSide}); // U:[GA-12]
    }
```

## Recommended Mitigation Steps

Integrate a validation step within _vote() that verifies the user’s available voting power. 

Mitigation Code:
```sol
function _vote(address user, uint96 votes, address token, bool lpSide) internal {
    if (!isTokenAdded(token)) revert TokenNotAllowedException();

    // Check user's available voting power before proceeding
    uint96 availableVotes = IGearStakingV3(voter).getAvailableVotes(user);
    if (votes > availableVotes) revert InsufficientVotesException();

    _checkAndUpdateEpoch();

    QuotaRateParams storage qp = quotaRateParams[token];
    UserVotes storage uv = userTokenVotes[user][token];

    if (lpSide) {
        qp.totalVotesLpSide += votes;
        uv.votesLpSide += votes;
    } else {
        qp.totalVotesCaSide += votes;
        uv.votesCaSide += votes;
    }

    emit Vote({user: user, token: token, votes: votes, lpSide: lpSide});
}
```
