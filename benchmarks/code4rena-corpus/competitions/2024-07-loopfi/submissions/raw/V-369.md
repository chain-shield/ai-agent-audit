# Vulnerability details

## Impact
The  user’s funds may not be able to be withdrawn properly. Causing user funds to be locked in the protocol.

## Proof of Concept
```javascript
    function _withdraw(
        address caller,
        address receiver,
        address _owner,
        uint256 assets,
        uint256 shares
    ) internal override nonReentrant {
        super._withdraw(caller, receiver, _owner, assets, shares);
@>        _checkMinShares();
    }
```
When withdrawing funds, it is necessary to check the minimum share. However, in the _checkMinShares() function,
```
  /// @notice ensures a small non-zero amount of shares does not remain, exposing to donation attack
    function _checkMinShares() internal view {
        uint256 _totalSupply = totalSupply();
@>        if (_totalSupply > 0 && _totalSupply < MIN_SHARES) revert MinSharesViolation();
    }
```
_totalSupply needs to be equal to 0, or _totalSupply >= MIN_SHARES. 
Let’s look at the following scenario where funds cannot be withdrawn:
1 alice deposit 0.1 lpEth
2 bob deposit  0.1 lpEth
3 alice redeem() or cooldownAssets() her asserts, left  1 wei share
4 bob can't not cooldownAssets all his asserts, because _totalSupply= 1 wei will revert.
He must left (MIN_SHARES - 1wei) share which can't be withdraw

#### proof of code
```javascript
function testRevertReedemBecauseMinShare() public{

        vm.startPrank(user1);
        liquidityPool.approve(address(stakingLpEth), 0.1 ether);
        stakingLpEth.deposit(0.1 ether, user1);
        vm.stopPrank();

        vm.startPrank(user2);
        liquidityPool.approve(address(stakingLpEth), 0.1 ether);
        stakingLpEth.deposit(0.1 ether, user2);
        vm.stopPrank();

        //user1 left 1 wei
        vm.startPrank(user1);
        stakingLpEth.approve(address(stakingLpEth), 0.1 ether -1);
        stakingLpEth.redeem(0.1 ether - 1, user1, user1);
        vm.stopPrank();

        vm.startPrank(user2);
        stakingLpEth.approve(address(stakingLpEth), 0.1 ether);
        //will revert
        stakingLpEth.redeem(0.1 ether, user2, user2);
        vm.stopPrank();

    }
```
