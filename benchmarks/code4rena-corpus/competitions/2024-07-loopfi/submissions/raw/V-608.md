# Vulnerability details

## Vulnerability details
In multiple functions in `CDPVault` contract: `modifyCollateralAndDebt()`, `liquidatePosition()`, `liquidatePositionBadDebt()`, all variable in `positions` is updated in temporatory variable:

        Position memory position = positions[owner];    <--
        DebtData memory debtData = _calcDebt(position);
                .   .   .   .   .   .   .
        position = _modifyPosition(owner, position, newDebt, newCumulativeIndex, deltaCollateral, totalDebt);

These temporatory variable is not writen back to its origin, which mean the value of them is not kept over time.

## Impact
Variable value is not updated.

## Tools Used
Manual review.

## Recommended Mitigation Steps
Replace from memory to storage:

        -   Position memory position = positions[owner];
        +   Position storage position = positions[owner];
