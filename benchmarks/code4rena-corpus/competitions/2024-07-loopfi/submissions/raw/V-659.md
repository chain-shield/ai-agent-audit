# Vulnerability details

## Impact
User functions `deposit/mint` and `withdraw/redeem` do not account for unclaimed rewards. Meanwhile, there is no function to claim reward using his vault shares. There is just only 1 function `AuraVault#claim` to claim accumulated rewards by immediately depositing assets without using vault shares or assets deposited before.
So far, users can not receive rewards for the liquidity they provided
