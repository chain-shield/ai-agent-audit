# Vulnerability details

### Description

The flashLoan function in the contract assumes that all ERC20 tokens follow the standard behavior of returning true upon successful transfers. However, this is not guaranteed across all ERC20 implementations. Some ERC20 tokens might not return true on success, leading to potential issues when handling transfers.

## Impact
Non-compliant ERC20 tokens, such as USDT, may not return true on successful transfers. This can lead to failed transactions without proper error handling, causing financial losses and operational disruptions in the contract. If the contract assumes successful transfers based on the standard ERC20 behavior, it may result in undetected transaction failures, potentially allowing attackers to exploit these weaknesses for financial gain.

## Recommended Mitigation
To safeguard against issues with non-compliant ERC20 tokens, utilize the SafeTransfer library to handle token transfers. This library ensures proper handling of token transfers and checks for successful completion, thus avoiding issues with tokens that do not conform to the ERC20 standard.
