# Vulnerability details

## Impact
[`PoolV3`](https://github.com/code-423n4/2024-07-loopfi/blob/main/src/PoolV3.sol#L46-L49) is a tokenized vault contract, which should be compatible with ERC4626 standard.

But because of changes in the contract compared to original `PoolV3`, `PoolV3.maxWithdraw` and `PoolV3.maxMint` functions do not comply with ERC4626 standard.


## Proof of Concept
[According to ERC4626](https://eips.ethereum.org/EIPS/eip-4626) for maxWithdraw/maxRedeem functions
```
MUST factor in both global and user-specific limits, like if withdrawals are entirely disabled (even temporarily) it MUST return 0.
```

In the current `PoolV3`, `locked` storage variable is added, which controls if redeeming/withdrawing is locked or not. 
```solidity
    /// @notice Redeeming or withdrawing locked status
    bool public locked;
```

But the `locked` value is not taken into account in `maxWithdraw` and `maxRedeem`. Both functions MUST return 0 according to ERC4626 standard.
 
```solidity
    /// @notice Maximum amount of underlying that can be withdrawn from the pool by `owner`, 0 if pool is on pause
    function maxWithdraw(address owner) public view override(ERC4626, IERC4626) returns (uint256) {
        // @audit-notes `locked` not considered here
        return
            paused()
                ? 0
                : _amountMinusFee(
                    _amountMinusWithdrawalFee(Math.min(availableLiquidity(), _convertToAssets(balanceOf(owner))))
                ); // U:[LP-11]
    }

    /// @notice Maximum number of shares that can be redeemed for underlying by `owner`, 0 if pool is on pause
    function maxRedeem(address owner) public view override(ERC4626, IERC4626) returns (uint256) {
        // @audit-notes `locked` not considered here
        return paused() ? 0 : Math.min(balanceOf(owner), _convertToShares(availableLiquidity())); // U:[LP-11]
    }
```

Manual Review

## Recommended Mitigation Steps
Update `maxWithdraw` and `maxRedeem` to take `locked` value into account

```solidity
    /// @notice Maximum amount of underlying that can be withdrawn from the pool by `owner`, 0 if pool is on pause
    function maxWithdraw(address owner) public view override(ERC4626, IERC4626) returns (uint256) {
        return
-           paused()
+           (paused() || locked)
                ? 0
                : _amountMinusFee(
                    _amountMinusWithdrawalFee(Math.min(availableLiquidity(), _convertToAssets(balanceOf(owner))))
                ); // U:[LP-11]
    }

    /// @notice Maximum number of shares that can be redeemed for underlying by `owner`, 0 if pool is on pause
    function maxRedeem(address owner) public view override(ERC4626, IERC4626) returns (uint256) {
-       return paused() ? 0 : Math.min(balanceOf(owner), _convertToShares(availableLiquidity())); // U:[LP-11]
+       return (paused() || locked) ? 0 : Math.min(balanceOf(owner), _convertToShares(availableLiquidity())); // U:[LP-11]
    }
```
