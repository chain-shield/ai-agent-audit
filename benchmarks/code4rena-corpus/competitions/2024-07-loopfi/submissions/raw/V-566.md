# Vulnerability details

## Vulnerability details

`CDPVault#_isCollateralized` is called by `CDPVault#liquidatePosition` and `CDPVault#modifyCollateralAndDebt` to check if the position is insolvent or not:

```solidity
function modifyCollateralAndDebt(
    address owner,
    address collateralizer,
    address creditor,
    int256 deltaCollateral,
    int256 deltaDebt
) public {
    ...
    uint256 spotPrice_ = spotPrice();
    uint256 collateralValue = wmul(position.collateral, spotPrice_);
    if (
        (deltaDebt > 0 || deltaCollateral < 0) &&
        !_isCollateralized(calcTotalDebt(_calcDebt(position)), collateralValue, config.liquidationRatio)
    ) revert CDPVault__modifyCollateralAndDebt_notSafe();
    ...
}

function liquidatePosition(address owner, uint256 repayAmount) external whenNotPaused {
    ...
    uint256 spotPrice_ = spotPrice();
    if (_isCollateralized(calcTotalDebt(debtData), wmul(position.collateral, spotPrice_), config.liquidationRatio))
                revert CDPVault__liquidatePosition_notUnsafe();
    ...
}
```

However, the insolvent calculation is incorrect because the collateral value calculation is based on `position.collateral * spotPrice_` but the debt value is based on `debtData.debt + debtData.accruedInterest`, the token units is not the same, as collateral value is about `X $usd`, but the debt is the debt token units like `WETH` or something else.

For example, if collateral token is 1 WETH or ETH derivatives and the price is about 3000 $usd, but the debt token is SOL and the price is 150 $usd. If he want to borrow 1000 SOL, then collateral value is 3000 $usd but the debt value is calculated as 1000 SOL, because `3000 > 1000` so he can borrow successfully, but the debt value in `usd` is `1000 * 150 = 150000 $usd`, which is larger than the collateral value.

## Impact

Incorrect insolvent calculation can cause users borrow more or avoid be liquidated may cause protocol debt.

## Tools Used

vscode

## Recommended Mitigation Steps

Fix the `CDPVault#_isCollateralized` function to both calculate the collateral and debt value in the same units.
