# Vulnerability details

## Vulnerability Details 
Lending protocols should always allow repayments, even if the protocol is paused. This is because interest still accumulates when the protocol is paused which can lead to the user getting insta-liquidated by a bot once the protocol is unpaused.

LoopFi intends to allow repayments when the protocol is paused, proof is in the CDPVault contract. The deposit/withdraw functions have the `whenNotPaused` modifier to revert when the protocol is paused BUT the `repay` function does not have this modifier.

The issue is that if the `PoolV3` contract is paused then the `repayCreditAccount` that has the `whenNotPaused` modifier will revert. 

Therefore users that call `CDPVault.repay()` to repay their loan when the protocol will have their Tx revert because it makes an external call to `pool.repayCreditAccount(debtData.debt - newDebt, profit, 0);` inside the `modifyCollateralAndDebt` function.

## Impact
Users unfairly accumulate interest

Users are unfairly liquidated

## Recommended Mitigation Steps
Remove the `whenNotPaused` modifier from the `PoolV3.repayCreditAccount()` function
