# Vulnerability details

## Impact

A user can claim more rewards than the corresponding deposited WETH.

When claiming accumulated rewards, users must deposit an amount of WETH that match the overall amounts of BAL and AURA tokens they are claiming.  
To get this amount of WETH, the `AuraVault::claim` function makes a call to the `AuraVault::_previewReward` function. This function uses the `AuraVault::_chainlinkSpot` function and the `AuraVault::_getAuraSpot` function to get the BAL and AURA price respectively. These function might return stale prices as they do not check whether prices are stale.

## Tools Used

Manual review.

## Recommended Mitigation Steps

Check the time elapsed since the last update against the heartbeat:

- of the BAL/USD feed in the `AuraVault::_chainlinkSpot()`, which is currently 86400s (1 day) on Ethereum.
- of the ETH/USD feed in the `AuraVault::_getAuraSpot()`, which is currently 3600s (1 hour) on Ethereum.
