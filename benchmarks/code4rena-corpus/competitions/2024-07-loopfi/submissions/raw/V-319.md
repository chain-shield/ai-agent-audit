# Vulnerability details

## Impact
In PositionAction4626, when users deposit/withdraw for one position(0xAA), PositionAction4626 will deposit with position(address(this)). When users want to borrow WETH based on the position(0xAA), this operation will be reverted. Because there is not any collateral in this position(0xAA).

## Proof of Concept
In PositionAction4626, when users want to deposit for one position(0xAA), the actual deposited position is address(this). When we try to borrow some WETH based on the position(0xAA), the operation will be reverted because there is not any collateral in this position(0xAA) in CDPVault.
And the function depositAndBorrow() will always be reverted.
