# Vulnerability details

## Impact

Users with positions that have already incurred bad debt can steal gain from the position by liquidating their own position. The earnings they gain is at the expense of the staker's profits.

## Proof of Concept

1. When a position incurs bad debt, it means that the collateral value is lesser than the borrowed value.
2. Anyone can liquidate a position, including the position owner himself.

A position owner can liquidate his own bad debt position, to also gain profits at the expense of stakers.

- Alice borrows 60 ETH , and has a collateral value of 100 ETH (100 aETH worth 1 ETH each). Her collateral ratio is 166%, which is higher than the intended collateral ratio of 125%.
- The value of aETH drops by 50%. Alice now has a collateral value of 50 ETH (100 aETH worth 0.5 ETH each). She has incurred a bad debt of 10 ETH.

Someone calls `liquidatePositionBadDebt()`.

- The `spotPrice` of the collateral is 0.5 ETH.
- The `discountedPrice` of the collateral, assuming 10% discount, is 0.45 ETH.
- The current collateralization ratio is ~83%, which means the position is unsafe

```
>       uint256 spotPrice_ = spotPrice();
        if (spotPrice_ == 0) revert CDPVault__liquidatePosition_invalidSpotPrice();
        // verify that the position is indeed unsafe
        if (_isCollateralized(calcTotalDebt(debtData), wmul(position.collateral, spotPrice_), config.liquidationRatio))
            revert CDPVault__liquidatePosition_notUnsafe();

        // load price and calculate discounted price
>       uint256 discountedPrice = wmul(spotPrice_, liqConfig_.liquidationDiscount);
```

The debt, 60 ETH, is greater than the collateral at `discountedPrice`, which is 45 ETH.

```
        // Enusure that the debt is greater than the collateral at discounted price
        if (calcTotalDebt(debtData) <= wmul(position.collateral, discountedPrice)) revert CDPVault__noBadDebt();
```

- `takeCollateral` is 100 aETH.
- repayAmount is 100 aETH * 0.45 ETH = 45 ETH.
- loss = 60 ETH - 45 ETH = 15 ETH.

```
        // account for bad debt
        takeCollateral = position.collateral;
        repayAmount = wmul(takeCollateral, discountedPrice);
        uint256 loss = calcTotalDebt(debtData) - repayAmount;
```

Because of the discounted price, the loss now is 15 ETH instead of 10 ETH.

The liquidator transfers 45 ETH to the pool.

```
        // transfer the repay amount from the liquidator to the vault
        poolUnderlying.safeTransferFrom(msg.sender, address(pool), repayAmount);
```

The pool calls `repayCreditAccount` with a loss of 15 ETH.

The liquidator gets 100 aETH worth 50 ETH.

```
        pool.repayCreditAccount(debtData.debt, 0, loss); // U:[CM-11]
        // transfer the collateral amount from the vault to the liquidator
        token.safeTransfer(msg.sender, takeCollateral);
```

In this sense, the liquidator earns 5 ETH.

In repayCreditAccount, if the treasury has more than 15 ETH (or rather lpETH), then 15 ETH will be deducted from the treasury. Otherwise, if the treasury has 5 ETH, then 5 ETH will be deducted and the 10 ETH will simply be written off. These amount from the treasury is used to distribute to stakers, loopers etc.

```
else if (loss > 0) {
            address treasury_ = treasury;
            uint256 sharesInTreasury = balanceOf(treasury_);
            uint256 sharesToBurn = convertToShares(loss);
            if (sharesToBurn > sharesInTreasury) {
                unchecked {
                    emit IncurUncoveredLoss({
                        creditManager: msg.sender,
                        loss: convertToAssets(sharesToBurn - sharesInTreasury)
                    }); // U:[LP-14D]
                }
                sharesToBurn = sharesInTreasury;
            }
>           _burn(treasury_, sharesToBurn); // U:[LP-14C,14D]
```

The problem is that with liquidation discount, the liquidator gets to earn 5 ETH at the expense of the treasury's money.

Let's say Alice herself is the liquidator. Not only does she already get 10 ETH (since her borrowed > collateral), she gets an extra 5 ETH from her own position, extracting value from the treasury.

There is no downside to Alice for having bad debt.

## Tools Used

Manual Review

## Recommended Mitigation Steps

Liquidators should not be earning when clearing bad debt. There should not be any liquidation discount. Liquidators should at most get back the equivalent amount of collateral.
