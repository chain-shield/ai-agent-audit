# Vulnerability details

## Vulnerability Details
The `updateLeverJoin` function in the `PoolAction` contract is responsible for updating parameters when joining a Balancer pool with leveraged positions. It should properly handle all tokens, including the Balancer Pool Token (BPT).

The function fails to explicitly set or handle the `maxAmountsIn` value for the pool token (BPT). This omission can lead to unpredictable behavior, especially if the `maxAmountsIn` array contained pre-existing values.

## Code Snippet
```solidity
bool skipIndex = false;
for (uint256 i = 0; i < len; ) {
    uint256 assetIndex = i - (skipIndex ? 1 : 0);
    if (assets[i] == joinToken) {
        maxAmountsIn[i] = joinAmount;
        assetsIn[assetIndex] = joinAmount;
    } else if (assets[i] == upFrontToken && assets[i] != poolToken) {
        maxAmountsIn[i] = upfrontAmount;
        assetsIn[assetIndex] = upfrontAmount;
    } else {
        skipIndex = skipIndex || assets[i] == poolToken;
    }
    unchecked {
        ++i;
    }
}
```

## Impact
1. The `maxAmountsIn` value for the BPT remains undefined or keeps a pre-existing value.
2. This can lead to unexpected behavior when the join operation is executed, potentially causing transaction failures or incorrect pool calculations.
3. In severe cases, it might allow unintended BPT transfers or minting, disrupting the pool's balance.

## Scenario
Consider a Balancer pool with tokens [TokenA, BPT, TokenB]. If the `maxAmountsIn` array initially contains non-zero values:
- TokenA: Correctly updated
- BPT: Remains unchanged (potential issue)
- TokenB: Correctly updated

The unchanged BPT value in `maxAmountsIn` could be interpreted as a non-zero input amount for BPT, which is typically not allowed or intended in most pool join operations.

## Fix
Modify the loop to explicitly set the `maxAmountsIn` value for the pool token to zero:

```solidity
for (uint256 i = 0; i < len; i++) {
    if (assets[i] == poolToken) {
        maxAmountsIn[i] = 0;  // Explicitly set to 0 for pool token
    } else if (assets[i] == joinToken) {
        maxAmountsIn[i] = joinAmount;
        assetsIn[assetsInIndex] = joinAmount;
        assetsInIndex++;
    } else if (assets[i] == upFrontToken) {
        maxAmountsIn[i] = upfrontAmount;
        assetsIn[assetsInIndex] = upfrontAmount;
        assetsInIndex++;
    }
}
```
