# Vulnerability details

## Vulnerability Details 
Chainlink aggregators have a built-in circuit breaker if the price of an asset goes outside of a predetermined price band. The result is that if an asset experiences a huge drop in value (i.e. LUNA crash) the price of the oracle will continue to return the minPrice instead of the actual price of the asset.

This would allow user to continue borrowing with the asset but at the wrong price, which will lead to draining of the protocol. This is exactly what happened to [Venus](https://rekt.news/venus-blizz-rekt/) on BSC when LUNA imploded. However, the protocol missed to implement such a check.

## Impact
This has critical impact in lending protocols since users can effectively borrow an amount worth more than the collateral

It is medium severity because the likelihood of such an event to drop the price of the asset below the minimum is low

## Recommended Mitigation Steps
get the minPrice and maxPrice from the aggregator, then compare it to the price. revert if it is outside the bounds

```solidity
    require(answer >= minPrice && answer <= maxPrice, "invalid price");
```
