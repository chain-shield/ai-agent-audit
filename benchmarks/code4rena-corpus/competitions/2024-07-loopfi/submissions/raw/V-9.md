# Vulnerability details

## Impact
_modifyPosition is using `block.number` intead of `block.timestamp` when modifying a position which will result in an incorrect lastDebtUpdate time.

## Vulnerability Details
`_modifyPosition ` is using block.number intead of block.timestamp when modifying a position. This will result in an incorrect `lastDebtUpdate` time. as block.number is smaller and different from block.timestamp. block.timestamp, (the correct value), is significantly larger than block.number, hence lastDebtUpdate time will always be incorrect. 

## Proof of Concept
If we look at the [postion struct](https://github.com/code-423n4/2024-07-loopfi/blob/4f508781a49ffa53511e7e5ed6cda0ff0eb5bdc5/src/CDPVault.sol#L99), we see that `lastDebtUpdate` is meant to be in block.timestamp, not block.number. block.number is the block's height, indicating its position in the chain. block.timestamp indicates the time when the block was mined in unix timestamp.

lastDebtUpdate is meant to be in block.timestamp.
```solidity
    // Position Accounting
    struct Position {
        uint256 collateral; // [wad]
        uint256 debt; // [wad]
@>      uint256 lastDebtUpdate; // [timestamp] <
        uint256 cumulativeIndexLastUpdate;
        uint192 cumulativeQuotaIndexLU;
        uint128 cumulativeQuotaInterest;
    }
```
But it is set to block.number which is incorrect.

## Recommended Mitigation Steps
The protocol should replace block.number with block.timestamp.

```solidity
    function _modifyPosition(
        address owner,
        Position memory position,
        uint256 newDebt,
        uint256 newCumulativeIndex,
        int256 deltaCollateral,
        uint256 totalDebt_
    ) internal returns (Position memory) {
        uint256 currentDebt = position.debt;
        // update collateral and debt amounts by the deltas
        position.collateral = add(position.collateral, deltaCollateral);
        position.debt = newDebt; // U:[CM-10,11]
        position.cumulativeIndexLastUpdate = newCumulativeIndex; // U:[CM-10,11]
+       position.lastDebtUpdate = uint64(block.timestamp); // U:[CM-10,11]
            ...
    }
```
