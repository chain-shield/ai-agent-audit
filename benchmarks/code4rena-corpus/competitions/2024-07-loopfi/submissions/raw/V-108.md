# Vulnerability details

## Proof of Concept
The `expectedLiquidity` function in the contract currently does not correctly account for all components that contribute to the total expected liquidity. The function is intended to calculate the total liquidity expected in the pool by summing various components, but its current implementation omits the inclusion of `availableLiquidity()` in the final calculation.

Here is the existing implementation:
```solidity
function expectedLiquidity() public view override returns (uint256) {
    return _expectedLiquidityLU + _calcBaseInterestAccrued() + _calcQuotaRevenueAccrued();
}
```
In this version, the function only sums `_expectedLiquidityLU`, `_calcBaseInterestAccrued()`, and `_calcQuotaRevenueAccrued()`, leaving out `availableLiquidity()`.

Given the intended purpose of the `expectedLiquidity` function is to provide a comprehensive view of the total expected liquidity in the pool, it is essential to include `availableLiquidity()` as well.
By excluding `availableLiquidity()` from the calculation, the function fails to account for the liquidity currently available in the pool. This oversight means that the total liquidity reported by the function will be inaccurate, as it does not reflect the real-time liquidity that is accessible.
## Impact
The primary impact of this issue is the incorrect calculation of the total expected liquidity. This miscalculation can lead to errors in liquidity management, forecasting, and any financial calculations or decisions based on the reported liquidity. Specifically, if `availableLiquidity()` is not included, the total assets and liquidity in the pool might be reported incorrectly, affecting liquidity planning and potentially leading to adverse financial outcomes.

## Recommended Mitigation Steps
Update the `expectedLiquidity` function to include `availableLiquidity()` in the calculation.
```solidity
function expectedLiquidity() public view override returns (uint256) {
    return _expectedLiquidityLU + _calcBaseInterestAccrued() + _calcQuotaRevenueAccrued() + availableLiquidity();
}

```
