# Vulnerability details

## Impact
[`CDPVault`](https://github.com/code-423n4/2024-07-loopfi/blob/57871f64bdea450c1f04c9a53dc1a78223719164/src/CDPVault.sol#L367-L460) implements a pausing functionality through [`Pause`](https://github.com/code-423n4/2024-07-loopfi/blob/57871f64bdea450c1f04c9a53dc1a78223719164/src/utils/Pause.sol) contract which is meant to allow the halting of some functions in the contract. In `CDPVault`'s case the functions that have the `whenNotPaused` modifier are:
* [`setParameter`](https://github.com/code-423n4/2024-07-loopfi/blob/57871f64bdea450c1f04c9a53dc1a78223719164/src/CDPVault.sol#L195-L202)
* [`deposit`](https://github.com/code-423n4/2024-07-loopfi/blob/57871f64bdea450c1f04c9a53dc1a78223719164/src/CDPVault.sol#L223-L233)
* [`withdraw`](https://github.com/code-423n4/2024-07-loopfi/blob/57871f64bdea450c1f04c9a53dc1a78223719164/src/CDPVault.sol#L239-L249)
* [`liquidatePosition`](https://github.com/code-423n4/2024-07-loopfi/blob/57871f64bdea450c1f04c9a53dc1a78223719164/src/CDPVault.sol#L509-L574)
* [`liquidatePositionBadDebt`](https://github.com/code-423n4/2024-07-loopfi/blob/57871f64bdea450c1f04c9a53dc1a78223719164/src/CDPVault.sol#L579-L632)

However, if someone pauses the contract, users can still make deposits and withdrawals via the public [`modifyCollateralAndDebt`](https://github.com/code-423n4/2024-07-loopfi/blob/57871f64bdea450c1f04c9a53dc1a78223719164/src/CDPVault.sol#L367-L460) function. This happens because the function `hasPermission` returns `true` if `msg.sender` equals the `owner`, i.e. the two inputs of the function are the same. This should not happen since it can have grave consequences in the event that a hack is occurring or an exploit is discovered.

## Proof of Concept

    function test_canDepositWithContractPaused_cid() public {
        address bob = makeAddr("bob");
        CDPVault vault = createCDPVault(token, 150 ether, 0, 1.25 ether, 1 ether, 1 ether);
        createGaugeAndSetGauge(address(vault));
        
        // bob creates a position
        uint256 depositAmount = 100 ether;
        deal(address(token), bob, depositAmount);
        // vm.startPrank(bob);
        // token.approve(address(vault), 100 ether);
        // vault.deposit(bob, 100 ether);
        // vm.stopPrank();

        // contract is paused
        vault.pause();

        //bob can still make deposits
        vm.startPrank(bob);
        token.approve(address(vault), depositAmount);
        int256 deltaCollateral = int256(depositAmount);
        vault.modifyCollateralAndDebt(bob, bob, bob, deltaCollateral, 0);
        vm.stopPrank();    
        (uint256 collateral, , , , , ) = vault.positions(bob);
        assertEq(collateral, depositAmount);
    }
