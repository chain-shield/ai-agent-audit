# Vulnerability details

## Impact
The treasury always suffer a loss even when it should have gain a profit

## Proof of Concept
Anyone can liquidate a under-collateralized position by calling `CDPVault#liquidatePositionBadDebt()` as far as it is `bad-debt` position.
The `bad-debt` position must be fully liquidated. Any loss should be accounted on `treasury`:
```solidity
607:        uint256 loss = calcTotalDebt(debtData) - repayAmount;
```
However, the `loss` calculation above is incorrect because `calcTotalDebt(debtData)` is the sum of `debt` and `accruedInterest`:
```solidity
    function calcTotalDebt(DebtData memory debtData) internal pure returns (uint256) {
        return debtData.debt + debtData.accruedInterest; //+ debtData.accruedFees;
    }
```
If `repayAmount` exceeds `debtData.debt`, the treasury should gain a profit instead of suffering a loss. However the incorrect calculation will result in the `debtData.accruedInterest` amount of asset being locked.
