# Vulnerability details

## Description
`PendleLPOracle::spot` function uses chainlink and pendle's market `getLpToAssetRate` function to calculate the price of the token, but there are no checks on the `lprate` value returned from the function `getLpToAssetRate`, during high volatility the `getLpToAssetRate` might not return the accurate `lprate` or when the liquidity or trading activity on the market is low.
## Impact
`PendleLPOracle::spot` will not return the accurate price of the token, where malicious users can take advantage of.

## Recommended Mitigation Steps
Implement proper checks and balances, monitor slippage, verify data accuracy and have fallback mechanism.
Make an separate function to get the `lpRate` which should perform sanity checks on the returned `lpRate`. e.g
```javascript
// Example function to get rate and check slippage
function getLpRateWithSlippageCheck(uint256 twapWindow, uint256 acceptableSlippage) public view returns (uint256) {
    uint256 lpRate = market.getLpToAssetRate(twapWindow);

    // Fetch the current market rate for comparison (if available)
    uint256 currentMarketRate = getCurrentMarketRate(); 

    // Calculate slippage
    uint256 slippage = (lpRate > currentMarketRate) ? (lpRate - currentMarketRate) : (currentMarketRate - lpRate);
    uint256 slippagePercentage = (slippage * 100) / currentMarketRate;

    // Check if slippage is within acceptable limits
    require(slippagePercentage <= acceptableSlippage, "Slippage exceeds acceptable limits");

    return lpRate;
}
```
