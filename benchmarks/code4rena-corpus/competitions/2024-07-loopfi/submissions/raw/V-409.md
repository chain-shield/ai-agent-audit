# Vulnerability details

## Impact
Not converting to shares when minting profit upon liquidations

## Proof of Concept
Upon deposits/withdrawals and all kinds of different operations, assets are handled by first converting them to shares and then, minting or burning. However, when liquidating, we calculate a penalty:
```solidity
uint256 penalty = wmul(repayAmount, WAD - liqConfig_.liquidationPenalty);
```
Which is then directly minted:
```solidity
IPoolV3Loop(address(pool)).mintProfit(penalty);
```
```solidity
function mintProfit(uint256 amount) external creditManagerOnly {
     _mint(treasury, amount);

     _updateBaseInterest({ expectedLiquidityDelta: amount.toInt256(), availableLiquidityDelta: 0, checkOptimalBorrowing: false });
    }
```
This causes an inaccurately minted amount of shares.
 
## Tools Used
Manual Review

## Recommended Mitigation Steps
Convert to shares before minting
