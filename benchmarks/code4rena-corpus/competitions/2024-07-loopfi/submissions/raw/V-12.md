# Vulnerability details

## Impact
The Solidity version ^0.8.0 contains known severe issues. Upgrading to a later version such as ^0.8.9 or later is recommended to avoid these issues. Using this version exposes the contract to known vulnerabilities like:

FullInlinerNonExpressionSplitArgumentEvaluationOrder
MissingSideEffectsOnSelectorAccess
AbiReencodingHeadOverflowWithStaticArrayCleanup
DirtyBytesArrayToStorage
DataLocationChangeInInternalOverride
NestedCalldataArrayAbiReencodingSizeValidation
SignedImmutables
ABIDecodeTwoDimensionalArrayMemory
KeccakCaching.

## Proof of Concept
Review the known issues for the Solidity version ^0.8.0. The details can be found on the Solidity documentation 
https://solidity.readthedocs.io/en/latest/bugs.html


## Tools Used
Manual code review and Solidity documentation.


## Recommended Mitigation Steps

Update the Solidity pragma to use ^0.8.9 or later:
pragma solidity ^0.8.9;
