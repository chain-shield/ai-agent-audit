# Vulnerability details


## Impact
This could lead to a situation where, by default, any user can stop the emissions for other users, causing them to incur losses.

## Proof of Concept
```javascript
modifier isWhitelisted() {
        if (whitelistActive) {
            if (!whitelist[msg.sender] && msg.sender != address(this)) revert NotWhitelisted();
        }
        _;
    }
```
The isWhitelisted modifier is used in the manualStopEmissionsFor() and manualStopAllEmissionsFor() functions, and its purpose is to allow users within the Whitelisted group to stop user emissions. 

When whitelistActive is true, users within the Whitelisted group can stop user emissions, but when whitelistActive is false, no one should be able to stop user emissions. 

However, in the current isWhitelisted logic, when whitelistActive is false, everyone can have the ability to stop user emissions, which is clearly incorrect. Especially since whitelistActive is false by default.
