# Vulnerability details

## Impact

The current implementation allows both `liquidatePosition` and `liquidatePositionBadDebt` functions to successfully liquidate positions under the same conditions. This overlap in functionality could lead to inconsistent liquidation behaviors where in extreme market conditions, it might result in suboptimal liquidations, where a position that should be treated as bad debt is liquidated through the standard process, or vice versa.


The root cause of this issue lies in the inconsistent implementation of bad debt checks between the `liquidatePosition` and `liquidatePositionBadDebt` functions. 

[// Enusure that the debt is greater than the collateral at discounted price](https://github.com/code-423n4/2024-07-loopfi/blob/57871f64bdea450c1f04c9a53dc1a78223719164/src/CDPVault.sol#L598-L600)
```solidity
        // Enusure that the debt is greater than the collateral at discounted price
        if (calcTotalDebt(debtData) <= wmul(position.collateral, discountedPrice)) revert CDPVault__noBadDebt();
```

[// Enusure that there's no bad debt](https://github.com/code-423n4/2024-07-loopfi/blob/57871f64bdea450c1f04c9a53dc1a78223719164/src/CDPVault.sol#L525-L527)

```solidity
        // Enusure that there's no bad debt
        if (calcTotalDebt(debtData) > wmul(position.collateral, spotPrice_)) revert CDPVault__BadDebt();
```

## Proof of Concept

This test shows that both liquidation functions can be used interchangeably at the liquidation price (bad debt price), please add this code to CDPVault.t.sol.

```solidity
function test_liquidate_bad_debt_works_in_both_liquidate_functions() public {
    // Set up the vault with specific parameters
    uint64 lDiscount = 0.95 ether;
    CDPVault vault = createCDPVault(token, 300 ether, 0, 1.25 ether, 1 ether, lDiscount);
    createGaugeAndSetGauge(address(vault));

    uint256 initialPrice = 1 ether;
    _updateSpot(initialPrice);
    console.log("Initial Price:", initialPrice);

    // Create two identical positions
    uint256 collateralAmount = 100 ether;
    uint256 debtAmount = 80 ether;
    address position1 = address(this);
    address position2 = address(0x123); // A different address for the second position

    // Create position 1
    token.mint(position1, collateralAmount);
    token.approve(address(vault), collateralAmount);
    vault.modifyCollateralAndDebt(position1, position1, position1, int256(collateralAmount), int256(debtAmount));

    // Create position 2
    token.mint(position2, collateralAmount);
    vm.prank(position2);
    token.approve(address(vault), collateralAmount);
    vm.prank(position2);
    vault.modifyCollateralAndDebt(position2, position2, position2, int256(collateralAmount), int256(debtAmount));

    console.log("Two identical positions created:");
    console.log("Collateral:", collateralAmount);
    console.log("Debt:", debtAmount);

   
    // Calculate the price at which the position becomes bad debt
    // Bad debt occurs when: collateral * price < debt
    uint256 badDebtPrice =  ((debtAmount * initialPrice) / collateralAmount);
    _updateSpot(badDebtPrice);

    console.log("Updated price for liquidation:");
    console.log("Current price:", badDebtPrice);

    // Attempt to liquidate the positions
    uint256 attemptedRepayAmount = debtAmount;
    mockWETH.mint(address(this), attemptedRepayAmount * 2); // Mint enough for both liquidations
    mockWETH.approve(address(vault), attemptedRepayAmount * 2);



    console.log("Attempting to liquidate position 2 with liquidatePositionBadDebt:");
    vault.liquidatePositionBadDebt(position2, attemptedRepayAmount);

    (uint256 collateral2, uint256 normalDebt2, , , , ) = vault.positions(position2);
    console.log("Position 2 after liquidatePositionBadDebt:");
    console.log("Collateral:", collateral2);
    console.log("Debt:", normalDebt2);


    console.log("Attempting to liquidate position 1 partially with liquidatePosition:");
    vault.liquidatePosition(position1, attemptedRepayAmount/2);

    (uint256 collateral1, uint256 normalDebt1, , , , ) = vault.positions(position1);
    console.log("Position 1 after liquidatePosition:");
    console.log("Collateral:", collateral1);
    console.log("Debt:", normalDebt1);


    // // Verify both positions are now liquidated
    // assert(collateral1 == 0 && normalDebt1 == 0);
    // assert(collateral2 == 0 && normalDebt2 == 0);
    console.log("Both positions successfully liquidated");
}
```
