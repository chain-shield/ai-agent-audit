# Vulnerability details

## Impact
Detailed description of the impact of this finding.

The toggleAutocompound function in the MultiFeeDistribution contract can be called by any address without any access control. 

This function allows users to toggle the auto-compounding feature on or off.

Without proper access restrictions, unauthorised users can manipulate this setting for any account, potentially leading to unexpected behaviour in the reward compounding process and affecting users’ earnings strategies.

Location: MultiFeeDistribution.sol

***Code Snippet:***
```sol
    function toggleAutocompound() external {
        autocompoundEnabled[msg.sender] = !autocompoundEnabled[msg.sender];
    }
```

The function is publicly accessible and allows any external address to toggle the autocompoundEnabled status for the calling address. 

This could be exploited by unauthorised users, leading to unexpected changes in the auto-compounding status.

## Recommended Mitigation Steps
To prevent unauthorised access to the toggleAutocompound function, implement the following mitigations:

***1.	Access Control:***
	•	Restrict the function to be callable only by the authorised user associated with the account.
	•	Use access control mechanisms, such as OpenZeppelin’s Ownable or AccessControl, to enforce permissions.
	
***2.	Modifier Implementation:***
	•	Add a modifier to check if the caller is authorised to toggle their auto-compounding status.

***Example Mitigation Code***
```sol
    function toggleAutocompound() external onlyAuthorised {
        autocompoundEnabled[msg.sender] = !autocompoundEnabled[msg.sender];
    }
```

The toggleAutocompound function in the MultiFeeDistribution contract lacks proper access control, allowing unauthorised users to toggle the auto-compounding status. 

Implementing robust access control mechanisms will mitigate this vulnerability, ensuring that only authorised users can modify their auto-compounding preferences.
