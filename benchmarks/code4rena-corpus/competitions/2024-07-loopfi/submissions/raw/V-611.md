# Vulnerability details

## Description
According to Balancer's documentation at https://docs.balancer.fi/concepts/advanced/valuing-bpt/valuing-bpt.html#getting-bpt-supply ,the totalSupply function only makes sense to call for older "legacy" pools.
For the most recent versions of Weighted and Stable pools, contracts should call the getActualSupply function, as it accounted for the pre-minted BPT and the protocol fees.

BalancerOracle's update function utilizes the totalSupply function to query the totalSupply:
```solidity
function update() external virtual onlyRole(KEEPER_ROLE) returns (uint256 safePrice_) {
...
 uint256 totalSupply = IWeightedPool(pool).totalSupply();
 ...
 }
```

## Impact
The BalancerOracle is not compatible with the most recent Weighted and Stable pools and will return wrong totalSupply values for those contracts.
## Tools Used
Manual review
## Recommended Mitigation Steps
Make sure to utilize the most up to date method to query a Balancer pool's total supply. In our case, getActualSupply should be the one utilized.
