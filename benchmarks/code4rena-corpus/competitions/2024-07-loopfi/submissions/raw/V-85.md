# Vulnerability details

## Impact
Detailed description of the impact of this finding.

The setUserSlippage function in the MultiFeeDistribution contract is exposed to external calls without any access control. 

This function allows users to set the slippage they are willing to tolerate during the auto-compounding process. 

Without proper access restrictions, malicious actors can alter this setting for any user, potentially leading to unfavourable trading conditions and financial losses.

Location: MultiFeeDistribution.sol

***Code Snippet:***
```sol
    function setUserSlippage(uint256 slippage) external {
        if (slippage < MAX_SLIPPAGE || slippage >= PERCENT_DIVISOR) {
            revert InvalidAmount();
        }
        userSlippage[msg.sender] = slippage;
    }
```

The function is publicly accessible and allows any external address to set the userSlippage for the calling address. 

This can be exploited by unauthorised users to change the slippage tolerance settings, which may result in users experiencing unexpected trading outcomes.

## Recommended Mitigation Steps
To prevent unauthorised access to the setUserSlippage function, implement the following mitigations:

***1.	Access Control:***
	•	Ensure the function is only callable by the intended users or contracts.
	•	Consider using OpenZeppelin’s Ownable or AccessControl libraries to enforce proper permissions.

***2.	Modifier Implementation:***
	•	Add a modifier to check if the caller is authorized to make changes to their slippage settings.

***Example Mitigation Code***
```sol
    function setUserSlippage(uint256 slippage) external onlyAuthorised {
        if (slippage < MAX_SLIPPAGE || slippage >= PERCENT_DIVISOR) {
            revert InvalidAmount();
        }
        userSlippage[msg.sender] = slippage;
    }
```

The setUserSlippage function in the MultiFeeDistribution contract lacks proper access control, allowing unauthorised users to modify the slippage settings. 

Implementing robust access control mechanisms will mitigate this vulnerability, ensuring that only authorised users can modify their slippage preferences.
