# Vulnerability details

## Impact
When a liquidator liquidates a position, a liquidation penalty is calculated from the repay amount.

```solidity
uint256 deltaDebt = wmul(repayAmount, liqConfig_.liquidationPenalty);
        uint256 penalty = wmul(repayAmount, WAD - liqConfig_.liquidationPenalty);
```

The problem is that the liquidator can only liquidate an amount equal to the repay amount minus the liquidation penalty, even if they want to liquidate the position fully. 

The new debt will be equal old debt - (repay amount - liquidation penalty).

When the _modifyPosition function is called, the newDebt will be small, and the function will revert because the positions' remaining debt will be less than the debtFloor. 

```solidity
function _modifyPosition(
        address owner,
        Position memory position,
        uint256 newDebt,
        uint256 newCumulativeIndex,
        int256 deltaCollateral,
        uint256 totalDebt_
    ) internal returns (Position memory) {
        uint256 currentDebt = position.debt;
        // update collateral and debt amounts by the deltas
        position.collateral = add(position.collateral, deltaCollateral);
        position.debt = newDebt; // U:[CM-10,11]
        position.cumulativeIndexLastUpdate = newCumulativeIndex; // U:[CM-10,11]
        position.lastDebtUpdate = uint64(block.number); // U:[CM-10,11]

        // position either has no debt or more debt than the debt floor
        if (position.debt != 0 && position.debt < uint256(vaultConfig.debtFloor))
            revert CDPVault__modifyPosition_debtFloor();

        //......
    }
```

Liquidators cannot fully liquidate positions. Even after some partial liquidations, when the amount falls below the debt floor, the function will revert, and the position cannot be liquidated.
