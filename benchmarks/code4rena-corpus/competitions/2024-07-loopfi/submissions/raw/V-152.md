# Vulnerability details

## Impact
When a position has only a small amount of collateral left due to a previous call to partially liquidate a position via the liquidatePosition, there is little incentive to liquidate the remainder of the position. The maximum a user can recover is the remaining collateral, which can be too small to cover the gas fees required for the transaction. As a consequence bad debt can accumulate.

````
        uint256 takeCollateral = wdiv(repayAmount, discountedPrice);
````

As can be seen above, the takeCollateral is based off the repayAmount divided by the discounted price. It is then slashed from current positions collateral as so :

````
        position = _modifyPosition(owner, position, newDebt, newCumulativeIndex, -toInt256(takeCollateral), totalDebt);
````

## Proof of Concept
````

    function test_liquidate_Too_Little_Remaining() public {
        CDPVault vault = createCDPVault(token, 150 ether, 0, 1.25 ether, 1 ether, 1 ether);
        createGaugeAndSetGauge(address(vault));
        // create position, taking max debt
        _updateSpot(1 ether);
        _modifyCollateralAndDebt(vault, 100 ether, 80 ether);

        // liquidate position
        address position = address(this);
        uint256 repayAmount = 79.9 ether;
        _updateSpot(0.8 ether);

        mockWETH.approve(address(vault), repayAmount);
        console.log(vault.totalDebt(), "totalDebt");
        uint256 creditBefore = credit(address(this));
        uint256 virtualDebtBefore = virtualDebt(vault, position);
        (uint256 collateral, , , , , ) = vault.positions(position);
        console.log(collateral, "collateral before");
        vault.liquidatePosition(position, repayAmount);
        
        (uint256 collateralAfter, , , , , ) = vault.positions(position);

        console.log(collateralAfter/1e18, "collateral after");
        // @audit collateral left in position is less than one ether
        assertLt(collateralAfter, 1 ether);
        assertGt(collateralAfter, 0);
    }
````

## Recommended Mitigation Steps
It should be not possible liquidate a position and leave dust collateral, this can be mitigated in a number of ways, including introducing liquidation limit, if the liquidator will reduce collateral by 95% then this call should revert.
