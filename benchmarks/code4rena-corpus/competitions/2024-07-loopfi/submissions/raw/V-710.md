# Vulnerability details

## Impact

`PoolV3` calls `convertToShares()` instead of `_convertToShares()` which will use the base `ERC4626` `convertToShares()` function which will incorrectly calculate the shares to a lower amount. The ETH corresponding to the lost shares are inaccessible since ETH:plETH is 1:1.

## Proof of Concept

Profit from interest is minted to the treasure here
https://github.com/code-423n4/2024-07-loopfi/blob/57871f64bdea450c1f04c9a53dc1a78223719164/src/PoolV3.sol#L549

```solidity
_mint(treasury, convertToShares(profit)); // U:[LP-14B]
```

this convertToShares function will call the base `ERC4626` function 
https://github.com/OpenZeppelin/openzeppelin-contracts/blob/e1a77ab15f9e311edffe855cf5f5a2f078cdd1ea/contracts/token/ERC20/extensions/ERC4626.sol#L103-L105

```solidity
    function convertToShares(uint256 assets) public view virtual override returns (uint256) {
        return _convertToShares(assets, Math.Rounding.Down);
    }

```

This will call the following function
https://github.com/OpenZeppelin/openzeppelin-contracts/blob/e1a77ab15f9e311edffe855cf5f5a2f078cdd1ea/contracts/token/ERC20/extensions/ERC4626.sol#L199-L201

```solidity
    function _convertToShares(uint256 assets, Math.Rounding rounding) internal view virtual returns (uint256) {
        return assets.mulDiv(totalSupply() + 10 ** _decimalsOffset(), totalAssets() + 1, rounding);
    }
```

But this is incorrect since `totalAssets()` 
https://github.com/code-423n4/2024-07-loopfi/blob/57871f64bdea450c1f04c9a53dc1a78223719164/src/PoolV3.sol#L223-L225

```solidity
    function totalAssets() public view override(ERC4626, IERC4626) returns (uint256 assets) {
        return expectedLiquidity();
    }

```

We will as a result mint less shares than we should. 

The correct `convertShares()` function to call is the `_convertShares` function in `PoolV3` would that would convert 1:1 
https://github.com/code-423n4/2024-07-loopfi/blob/57871f64bdea450c1f04c9a53dc1a78223719164/src/PoolV3.sol#L429-L432

```solidity
    function _convertToShares(uint256 assets) internal pure returns (uint256 shares) {
        // uint256 supply = totalSupply();
        return assets; //(assets == 0 || supply == 0) ? assets : assets.mulDiv(supply, totalAssets(), rounding);
    }
```

The shares lost and the corresponding ETH is lost and stuck in the contract.
