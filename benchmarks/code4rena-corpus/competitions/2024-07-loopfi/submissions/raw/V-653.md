# Vulnerability details

## Impact
When there is no auxiliary action data for the leverage parameters, the function `PositionActionPendle#_onDecreaseLever` returns value `0`, which means `0 = withdrawnCollateral = _onDecreaseLever(leverParams, subCollateral)`(https://github.com/code-423n4/2024-07-loopfi/blob/57871f64bdea450c1f04c9a53dc1a78223719164/src/proxy/PositionAction.sol#L457C17-L457C36). 
After a valid swap action for `leverParams.primarySwap`, the value `swapAmountIn` is likely to gt than `0` (https://github.com/code-423n4/2024-07-loopfi/blob/57871f64bdea450c1f04c9a53dc1a78223719164/src/proxy/PositionAction.sol#L459-L466), which will cause the line `residualAmount = withdrawnCollateral - swapAmountIn` to underflow
