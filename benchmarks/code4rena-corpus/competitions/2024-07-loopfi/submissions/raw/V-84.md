# Vulnerability details

## Impact
Detailed description of the impact of this finding.

The setAutocompound function in the MultiFeeDistribution contract can be called by any address without restrictions. 

This function allows users to enable or disable auto compounding of their rewards and set the slippage they are willing to tolerate. 

Without access control, malicious actors can manipulate these settings, which could lead to suboptimal or even harmful financial outcomes for users by changing their reward compounding settings without consent.

Location: MultiFeeDistribution.sol

***Code Snippet:***
```sol
    function setAutocompound(bool status, uint256 slippage) external {
        autocompoundEnabled[msg.sender] = status;
        if (slippage < MAX_SLIPPAGE || slippage >= PERCENT_DIVISOR) {
            revert InvalidAmount();
        }
        userSlippage[msg.sender] = slippage;
    }
```

The function allows any address to call it and change the autocompoundEnabled and userSlippage settings for the calling address. 

This lack of access control could be exploited by unauthorised users, leading to unexpected behaviour in auto compounding, potentially causing financial losses or service disruptions.
