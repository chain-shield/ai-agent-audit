# Vulnerability details

## Impact
The `flashLoan` and `creditFlashLoan` functions in the Flashlender contract is missing a crucial check to ensure that the requested loan amount does not exceed the maximum allowable limit. This may attempt to lend more funds than are available and then lead to transaction failures.

## Proof of Concept
This error is present in both the [`flashLoan`](https://github.com/code-423n4/2024-07-loopfi/blob/57871f64bdea450c1f04c9a53dc1a78223719164/src/Flashlender.sol#L87-L109) and [`creditFlashLoan`](https://github.com/code-423n4/2024-07-loopfi/blob/57871f64bdea450c1f04c9a53dc1a78223719164/src/Flashlender.sol#L117-L137) functions. Looking at the `flashLoan` function:

```solidity
function flashLoan(
    IERC3156FlashBorrower receiver,
    address token,
    uint256 amount,
    bytes calldata data
) external override nonReentrant returns (bool) {
    if (token != address(underlyingToken)) revert Flash__flashLoan_unsupportedToken();
    uint256 fee = wmul(amount, protocolFee);
    uint256 total = amount + fee;

    pool.lendCreditAccount(amount, address(receiver));

    // ... rest of the function
}
```

As shown, the function directly calls `pool.lendCreditAccount(amount, address(receiver))` without first checking if `amount` is within the allowable limit.

## Tools Used
Manual code review

## Recommended Mitigation Steps
Implement a check in both `flashLoan` and `creditFlashLoan` functions to ensure the requested amount does not exceed the maximum allowable loan or you can use the `maxFlashLoan` function to determine the maximum allowable amount.Also display an error when the requested amount exceeds the maximum allowed.



```solidity
function flashLoan(
    IERC3156FlashBorrower receiver,
    address token,
    uint256 amount,
    bytes calldata data
) external override nonReentrant returns (bool) {
    if (token != address(underlyingToken)) revert Flash__flashLoan_unsupportedToken();
    
    // Add this check
    uint256 maxLoan = pool.creditManagerBorrowable(address(this));
    if (amount > maxLoan) revert Flash__flashLoan_exceedsMaximum();

    uint256 fee = wmul(amount, protocolFee);
    uint256 total = amount + fee;

    pool.lendCreditAccount(amount, address(receiver));

    // ... rest of the function
}
```

Also, add the new error:

```solidity
error Flash__flashLoan_exceedsMaximum();
```
