# Vulnerability details

## Impact
Precision loss in interest calculations can lead to users losing their accrued interest, especially for users with small deposits when the total assets in the pool are very large. This could result in unfair distribution of interest and potentially cause smaller depositors to receive zero interest, discouraging participation in the protocol.
## Proof of Concept
https://github.com/code-423n4/2024-07-loopfi/blob/57871f64bdea450c1f04c9a53dc1a78223719164/src/PoolV3.sol#L603-L611
The vulnerability is present in the supplyRate() function which is susceptible to precision loss when ``totalAssets`` is very large compared to ``baseInterestRate`` ``* totalBorrowed``.:
```solidity
function supplyRate() public view returns (uint256) {
    if (totalAssets == 0) return 0;
    return
        ((baseInterestRate * totalBorrowed) * (PERCENTAGE_FACTOR - withdrawFee)) /
        PERCENTAGE_FACTOR /
        assets;
}
```
- Alice deposits a large amount: 1e36 tokens
- Bob deposits a small amount: 1e18 tokens
- Total borrowed is set to 50% of total assets: 5e35 tokens
``baseInterestRate`` is set to 0.1% per year: ``1e24 (in RAY units)``

Calculate supply rate:
```
supplyRate = (1e24 * 5e35 * 1e4) / 1e4 / 1e36
           = 5e23 / 1e36
           = 0
```
The supply rate rounds down to 0 due to integer division.
Now, when calculating Bob's interest:
```
Interest = (0 * 1e18) / RAY = 0
```
Expected Result: Bob should receive a small but non-zero amount of interest.
Actual Result: Bob receives 0 interest due to precision loss.

## Recommended Mitigation Steps
Implement a higher precision factor:

```solidity
uint256 constant HIGHER_PRECISION = 1e36;

function supplyRate() public view returns (uint256) {
    if (totalAssets == 0) return 0;
    return
        (((baseInterestRate * totalBorrowed) * HIGHER_PRECISION / totalAssets) * (PERCENTAGE_FACTOR - withdrawFee)) /
        PERCENTAGE_FACTOR;
}
```

Implement a minimum interest rate to prevent rounding to zero:

```solidity
uint256 constant MINIMUM_INTEREST_RATE = 1; // 1 wei per RAY

function calculateUserInterest(address user) public returns (uint256) {
    uint256 rate = supplyRate();
    uint256 userDeposit = userDeposits[user];
    return Math.max((rate * userDeposit) / RAY, MINIMUM_INTEREST_RATE);
}
```

Consider implementing a dynamic precision adjustment mechanism that scales precision based on the pool's total assets.
