# Vulnerability details

## Proof of Concept
The provided smart contract does not fully comply with the EIP-4626 standard in the `_withdraw` and `redeem` functions.

`_withdraw` Function:

The `_withdraw` function should revert if all specified assets cannot be withdrawn due to withdrawal limits being reached, slippage, or the owner not having enough shares. However, the current implementation lacks these checks, potentially allowing partial withdrawals or withdrawals without sufficient shares.
```solidity
    function _withdraw(
        address receiver,
        address owner,
        uint256 assetsSent,
        uint256 assetsReceived,
        uint256 amountToUser,
        uint256 shares
    ) internal {
        if (msg.sender != owner) _spendAllowance({owner: owner, spender: msg.sender, amount: shares}); // U:[LP-8,9]
        _burn(owner, shares); // U:[LP-8,9]

        _updateBaseInterest({
            expectedLiquidityDelta: -assetsSent.toInt256(),
            availableLiquidityDelta: -assetsSent.toInt256(),
            checkOptimalBorrowing: false
        }); // U:[LP-8,9]

        IERC20(underlyingToken).safeTransfer({to: receiver, value: amountToUser}); // U:[LP-8,9]
        if (assetsSent > amountToUser) {
            unchecked {
                IERC20(underlyingToken).safeTransfer({to: treasury, value: assetsSent - amountToUser}); // U:[LP-8,9]
            }
        }
        emit Withdraw(msg.sender, receiver, owner, assetsReceived, shares); // U:[LP-8,9]
    }
```
`redeem` Function:

The `redeem` function should check if `msg.sender` has the necessary allowance to spend the owner's funds. This ensures that unauthorized users cannot redeem shares on behalf of others without proper approval. The current implementation does not perform this check, potentially allowing unauthorized redemptions.
`maxWithdraw` function must not revert.
```solidity
unction redeem(
        uint256 shares,
        address receiver,
        address owner
    )
        public
        override(ERC4626, IERC4626)
        whenNotPaused // U:[LP-2A]
        whenNotLocked
        nonReentrant // U:[LP-2B]
        nonZeroAddress(receiver) // U:[LP-5]
        returns (uint256 assets)
    {
        uint256 assetsSent = _convertToAssets(shares); // U:[LP-9]
        uint256 assetsToUser = _amountMinusWithdrawalFee(assetsSent);
        assets = _amountMinusFee(assetsToUser); // U:[LP-9]
        _withdraw(receiver, owner, assetsSent, assets, assetsToUser, shares); // U:[LP-9] // @audit SHOULD check msg.sender can spend owner funds using allowance.
    }
```
