# Vulnerability details

## Impact
 A user cannot claim their previously pending reward once they become ineligible

## Proof of Concept
Anyone can claim reward for others by calling [`ChefIncentivesController#claim()`](https://github.com/code-423n4/2024-07-loopfi/blob/main/src/reward/ChefIncentivesController.sol#L518-L550). The function will check if `_user` is a eligible user when `eligibilityMode` is not `EligibilityModes.DISABLED`:
```solidity
    function claim(address _user, address[] memory _tokens) public whenNotPaused {
        if (eligibilityMode != EligibilityModes.DISABLED) {
@>          if (!eligibleDataProvider.isEligibleForRewards(_user)) revert EligibleRequired();
            checkAndProcessEligibility(_user, true, true);
        }
    ...
    }
```
As we can see, if the `_user` is not eligible for reward, the function `claim()` will revert. If someone has pending reward unclaimed, they have no way to claim it unless they become eligible again.
## Tools Used
Manual review
## Recommended Mitigation Steps
The ineligible user should be allowed to claim their pending reward.
