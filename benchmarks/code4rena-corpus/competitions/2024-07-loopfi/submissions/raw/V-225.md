# Vulnerability details

## Details
`PendleLPOracle::_fetchAndValidate` uses the deprecated answeredInRound and Chainlink price feeds have in-built minimum & maximum prices they will return. if during a flash crash, bridge compromise, or depegging event, an asset’s value falls below the price feed’s minimum price, it fails to check that returned `answer` is between the range minAnswer and MaxAnswer.

## Impact
Code will execute with prices that don’t reflect the current pricing resulting in a potential loss of funds for users.

## Recommended Mitigation Steps
1. Remove the deprecated `answeredInRound` check
2. function should cross-check the returned answer against the minPrice/maxPrice and revert if the answer is outside of these bounds
