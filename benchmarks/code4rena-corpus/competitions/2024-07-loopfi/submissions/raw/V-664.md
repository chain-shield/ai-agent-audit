# Vulnerability details

## Impact
The function `AuraVault#claim` is commented as 
> @notice Allows anyone to claim accumulated rewards by depositing WETH instead

which expects that user can deposit assets and claim the accumulated rewards at the same time. However, his deposited assets are not accounted as vault share, which means that he cant not withdraw the assets

If the function's purpose is to allow user stake funds to get reward, then that funds will get locked in the `rewardPool` contract


## Proof of Concept
There is no minting shares in the function `AuraVault#claim` (https://github.com/code-423n4/2024-07-loopfi/blob/57871f64bdea450c1f04c9a53dc1a78223719164/src/vendor/AuraVault.sol#L280-L294)


## Tools Used
Manual

## Recommended Mitigation Steps
Consider adding logics to mint shares for the assets users deposited when claiming rewards by function `AuraVault#claim`
