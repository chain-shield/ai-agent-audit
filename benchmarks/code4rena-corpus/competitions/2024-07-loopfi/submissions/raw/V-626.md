# Vulnerability details


**Impact:**
Administrator is not able to pause users’ withdrawals in `MultidistributionFee.sol` contract as expected.
**Proof of Concept:**
The `MultidistributionFee.sol` contract inherits PausableUpgradable to provide pausing capabilities to the administrator on users’ withdrawals. The contract correctly exposes the _pause() and _unpause() internal functions through access restricted external functions.

However, none of the functions implement the whenNotPaused modifier on the function `MultidistributionFee::withdraw` or `MultidistributionFee::_withdrawTokens`. This is especially problematic for user-accessible functions like this one.

// @POC:MultidistributionFee inherits PausableUpgradeable
