# Vulnerability details

## Description

The `CDPVault` contract is designed to manage collateralized debt positions, allowing users to deposit collateral and borrow against it. The [`liquidatePosition()` function](https://github.com/code-423n4/2024-07-loopfi/blob/57871f64bdea450c1f04c9a53dc1a78223719164/src/CDPVault.sol#L509-L575) is intended to liquidate positions that are deemed unsafe, i.e., positions where the collateral value is insufficient to cover the debt according to a specified collateralization ratio.

> The function is doing like ,

The `liquidatePosition()` function in the `CDPVault` contract is responsible for liquidating positions that are deemed unsafe. The function follows these steps:

1. **Load Position and Debt Data**: The function retrieves the position and debt data for the specified owner.
    ```solidity
    Position memory position = positions[owner];
    DebtData memory debtData = _calcDebt(position);
    ```

2. **Calculate Spot Price and Discounted Price**: The function calculates the current spot price of the collateral and applies a liquidation discount to determine the discounted price.
    ```solidity
    uint256 spotPrice_ = spotPrice();
    uint256 discountedPrice = wmul(spotPrice_, liqConfig_.liquidationDiscount);
    if (spotPrice_ == 0) revert CDPVault__liquidatePosition_invalidSpotPrice();
    ```

3. **Check for Bad Debt**: The function checks if the total debt exceeds the collateral value at the spot price.
    ```solidity
    if (calcTotalDebt(debtData) > wmul(position.collateral, spotPrice_)) revert CDPVault__BadDebt();
    ```

4. **Compute Collateral to Take, Debt to Repay, and Penalty**: The function calculates the amount of collateral to take, the debt to repay, and the penalty to apply.
    ```solidity
    uint256 takeCollateral = wdiv(repayAmount, discountedPrice);
    uint256 deltaDebt = wmul(repayAmount, liqConfig_.liquidationPenalty);
    uint256 penalty = wmul(repayAmount, WAD - liqConfig_.liquidationPenalty);
    if (takeCollateral > position.collateral) revert CDPVault__tooHighRepayAmount();
    ```

5. **Check if Position is Unsafe**: Only after performing the above calculations does the function check if the position is unsafe using the `_isCollateralized()` function.
    ```solidity
    if (_isCollateralized(calcTotalDebt(debtData), wmul(position.collateral, spotPrice_), config.liquidationRatio))
        revert CDPVault__liquidatePosition_notUnsafe();
    ```

The current implementation of `liquidatePosition()` does not correctly handle the conditions under which a position can be liquidated. Specifically, the function performs calculations and state changes before verifying if the position is indeed unsafe. This can lead to the liquidation of positions that are actually safe, causing unnecessary financial losses for users.

The function first calculates the `spotPrice` and `discountedPrice`, and then checks if there is any bad debt. It proceeds to compute the collateral to take, debt to repay, and penalty to pay. Only after these calculations does it check if the position is unsafe using the `_isCollateralized()` function. This order of operations is incorrect because it allows for the possibility of liquidating safe positions.

The issue lies in the order of operations. The function performs calculations and state changes before verifying if the position is unsafe. This can lead to the liquidation of positions that are actually safe, causing unnecessary financial losses for users. The check to verify if the position is unsafe should be performed before any calculations or state changes are made.

3. **Calculations and State Changes**: The function calculates the `spotPrice` and `discountedPrice`, checks for bad debt, and computes the collateral to take, debt to repay, and penalty to pay.

This undermines the trust in the contract and can lead to significant financial repercussions for users who have their positions liquidated despite meeting the collateralization requirements.
