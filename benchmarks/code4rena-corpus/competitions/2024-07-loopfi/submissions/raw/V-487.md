# Vulnerability details

`liquidatePosition()` function may fail and revert when attempting to liquidate positions that have fallen into bad debt, where the total debt exceeds the value of the collateral.

The issue occurs [here](https://github.com/code-423n4/2024-07-loopfi/blob/57871f64bdea450c1f04c9a53dc1a78223719164/src/CDPVault.sol#L571-L573), where the function attempts to update the quota revenue after liquidating the position.
```solidity
if (debtData.debt - newDebt != 0) {
    IPoolV3(pool).updateQuotaRevenue(_calcQuotaRevenueChange(-int(debtData.debt - newDebt))); // U:[PQK-15]
}
```
Prior to this, at [CDPVault.sol:526](https://github.com/code-423n4/2024-07-loopfi/blob/57871f64bdea450c1f04c9a53dc1a78223719164/src/CDPVault.sol#L526), the function checks for bad debt and reverts if the condition is met.
```solidity
// Enusure that there's no bad debt
if (calcTotalDebt(debtData) > wmul(position.collateral, spotPrice_)) revert CDPVault__BadDebt();
```
## Impact
If a position falls into bad debt, the `liquidatePosition()` function will always revert, preventing the liquidation of the undercollateralized position. This can lead to:

* The protocol accumulates bad debt that cannot be recovered through liquidation.
* Liquidators cannot liquidate positions and losing gas fees due to the reverted transactions.

## Proof of Concept
This can happen.

* Alice opens a position with 100 ETH as collateral and borrows 50,000 USDC.
* The value of ETH drops significantly, causing Alice's position to become undercollateralized.
* Bob attempts to liquidate Alice's position by calling [liquidatePosition()](https://github.com/code-423n4/2024-07-loopfi/blob/57871f64bdea450c1f04c9a53dc1a78223719164/src/CDPVault.sol#L509-L574).
* The function checks for bad debt at [CDPVault.sol:526](https://github.com/code-423n4/2024-07-loopfi/blob/57871f64bdea450c1f04c9a53dc1a78223719164/src/CDPVault.sol#L526) and reverts because the total debt exceeds the collateral value.
* Bob's transaction fails, and Alice's undercollateralized position remains in the protocol.

## Recommended Mitigation Steps
* Skip the bad debt check at [CDPVault.sol:526](https://github.com/code-423n4/2024-07-loopfi/blob/57871f64bdea450c1f04c9a53dc1a78223719164/src/CDPVault.sol#L526).
* Liquidate the position by seizing all the collateral and repaying as much debt as possible.
* Write off any remaining debt that the collateral cannot cover.
