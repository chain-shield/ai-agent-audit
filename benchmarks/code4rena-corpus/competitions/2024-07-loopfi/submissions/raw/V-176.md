# Vulnerability details

## Proof of Concept
If `user.rewardDebt` is greater than `user.amount`, it suggests that the user's reward debt has exceeded their actual stake or amount in the pool. This scenario can lead to unexpected or potentially incorrect results in the calculation of the claimable amount.

Breakdown of Calculation
Let's revisit the formula for `claimable`:
```solidity
claimable[i] = (user.amount * accRewardPerShare) / ACC_REWARD_PRECISION - user.rewardDebt;
```
When `user.rewardDebt > user.amount`:
The term `(user.amount * accRewardPerShare) / ACC_REWARD_PRECISION` represents the amount of rewards that have been accumulated for the user's staked amount.
If `user.rewardDebt` is greater than this accumulated reward amount, then:
```solidity
claimable[i] = (user.amount * accRewardPerShare) / ACC_REWARD_PRECISION - user.rewardDebt;
```
This will result in:
```solidity
claimable[i] = AccumulatedReward - user.rewardDebt;
```
Since` AccumulatedReward` (i.e., `(user.amount * accRewardPerShare) / ACC_REWARD_PRECISION)` is less than `user.rewardDebt`, the value of `claimable[i]` will be negative:

```solidity
claimable[i] = NegativeValue;
```
For example, if `user.amount` is $1000$, `accRewardPerShare` is $500$, and `ACC_REWARD_PRECISION` is $1000$, the calculated rewards would be:
```solidity
calculatedRewards = (1000 * 500) / 1000 = 500
```
If `user.rewardDebt` is $600$, then:
```solidity
claimable[i] = 500 - 600 = -100
```
## Impact
A negative `claimable` value means that the contract allows the user to have a claimable amount that is less than zero, which could lead to incorrect reward distributions, potential overflows, or erroneous behavior in reward claiming mechanisms. This could undermine the integrity of the reward system and lead to unexpected losses or errors.

## Recommended Mitigation Steps
Include a check to ensure that `claimable[i]` cannot be negative. For instance, you can use the `max` function to ensure the value is non-negative:
```solidity
claimable[i] = max(0, (user.amount * accRewardPerShare) / ACC_REWARD_PRECISION - user.rewardDebt);
```
Here's a simple implementation of the `max` function in Solidity:
```solidity
function max(uint256 a, uint256 b) internal pure returns (uint256) {
    return a > b ? a : b;
}

```
