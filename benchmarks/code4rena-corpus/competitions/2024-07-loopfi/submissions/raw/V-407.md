# Vulnerability details

## Impact
Bad price staleness check does not insure that the price is valid or not

## Proof of Concept
Both the `_chainlinkSpot` and `_getAuraSpot` functions have bad price checks, since they don't check the pricefeed heartbeat to ensure that the price is relevant to the current market conditions. If the checks remain like this, the users may take advantage, since the old market conditions may be better from users' point of view

## Tools Used
Manual review
## Recommended Mitigation Steps
Check the pricefeed heartbeat like this for the `_chainlinkSpot` function:
```javascript
AggregatorV3Interface(BAL_CHAINLINK_FEED).latestRoundData() returns (
            uint80 /*roundId*/,
            int256 answer,
            uint256 /*startedAt*/,
            uint256 updatedAt,
            uint80 /*answeredInRound*/
        ) {
            isValid = (answer > 0 && block.timestamp - updatedAt <= priceFeedHeartbeat);
```
and like this for the `_getAuraSpot` function:
```javascript
AggregatorV3Interface(ETH_CHAINLINK_FEED).latestRoundData() returns (
            uint80 /*roundId*/,
            int256 answer,
            uint256 /*startedAt*/,
            uint256 updatedAt,
            uint80 /*answeredInRound*/
        ) {
            isValid = (answer > 0 && block.timestamp - updatedAt <= priceFeedHeartbeat);
```
