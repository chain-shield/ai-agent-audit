# Vulnerability details

## Impact
The setOracles function does not validate the lengths of the input arrays _tokens and _oracles, which could lead to mismatched entries if the arrays have different lengths.

## Proof of Concept
function setOracles(address[] calldata _tokens, Oracle[] calldata _oracles) external onlyRole(DEFAULT_ADMIN_ROLE) {
        for (uint256 i = 0; i < _tokens.length; i++) {
            oracles[_tokens[i]] = _oracles[i];
        }
    }

## Recommended Mitigation Steps
function setOracles(address[] calldata _tokens, Oracle[] calldata _oracles) external onlyRole(DEFAULT_ADMIN_ROLE) {
    require(_tokens.length == _oracles.length, "Input arrays must have the same length");  // add require
    for (uint256 i = 0; i < _tokens.length; i++) {
        oracles[_tokens[i]] = _oracles[i];
    }
}
