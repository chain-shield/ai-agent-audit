# Vulnerability details

## Title
When liquidation is paused, user can still borrow fund out to create bad debt.

## Impact

The CDPVault contract implements pause and unpause functionality. When the contract is paused, no liquidation can happen and liquidate act as a way to clear bad debt for protocol, otherwise user can over borrow can cause loss of fund. But when the contract is paused, the user can still borrow the fund out because the function borrow has no `whenNotPaused` Modifier:

```solidity
@>  function borrow(address borrower, address position, uint256 amount) external {
        int256 deltaDebt = toInt256(amount);
        modifyCollateralAndDebt({
            owner: position,
            collateralizer: position,
            creditor: borrower,
            deltaCollateral: 0,
            deltaDebt: deltaDebt
        });
    }
```
If the borrowing operation is allowed when the liquidation is paused protocol, the bad debt might accumulate if no liquidation happens.

## Proof of Concept
We can see the function [CDPVault::liquidatePosition()](https://github.com/code-423n4/2024-07-loopfi/blob/57871f64bdea450c1f04c9a53dc1a78223719164/src/CDPVault.sol#L509) has `whenNotPaused` modifier.

```solidity
 function liquidatePosition(address owner, uint256 repayAmount) external whenNotPaused {
        // validate params
       ...
       ...
        if (debtData.debt - newDebt != 0) {
            IPoolV3(pool).updateQuotaRevenue(_calcQuotaRevenueChange(-int(debtData.debt - newDebt))); // U:[PQK-15]
        }
    }

```
But the borrow [function](https://github.com/code-423n4/2024-07-loopfi/blob/57871f64bdea450c1f04c9a53dc1a78223719164/src/CDPVault.sol#L256C1-L265C6) has no modifier to stop borrowing when contract is paused.

```solidity
@>  function borrow(address borrower, address position, uint256 amount) external {
        int256 deltaDebt = toInt256(amount);
        modifyCollateralAndDebt({
            owner: position,
            collateralizer: position,
            creditor: borrower,
            deltaCollateral: 0,
            deltaDebt: deltaDebt
        });
    }
```
