# Vulnerability details

## Impact
The increaseLever function can not be usable with the ERC4626 vault.

## Proof of Concept
When increasing a position's leverage with the increaseLever function, after taking the flash loan, the onFlashLoan function will be called. The function swaps the underlying token that comes from the flash loan for the collateral token. And after that _onIncreaseLever function is called.

```solidity
// handle the flash loan swap
        bytes memory swapData = _delegateCall(
            address(swapAction),
            abi.encodeWithSelector(swapAction.swap.selector, leverParams.primarySwap)
        ); //@audit check the msg.sender 
        uint256 swapAmountOut = abi.decode(swapData, (uint256));

        // deposit collateral and handle any CDP specific actions
        uint256 collateral = _onIncreaseLever(leverParams, upFrontToken, upFrontAmount, swapAmountOut);
```

If an ERC4626 vault is used, the _onIncreaseLever function first deposits into the ERC4626 vault. After that, it approves and deposits into the CDP vault, which is wrong because, in the onFlashLoan function, the modifyCollateralAndDebt function will do that.

https://github.com/code-423n4/2024-07-loopfi/blob/57871f64bdea450c1f04c9a53dc1a78223719164/src/proxy/PositionAction4626.sol#L121-L129

```solidity
// deposit into the ERC4626 vault
        IERC20(underlyingToken).forceApprove(leverParams.collateralToken, addCollateralAmount);
        addCollateralAmount =
            IERC4626(leverParams.collateralToken).deposit(addCollateralAmount, address(this)) +
            upFrontCollateral;

        // deposit into the CDP vault
        IERC20(leverParams.collateralToken).forceApprove(leverParams.vault, addCollateralAmount);
        
        return ICDPVault(leverParams.vault).deposit(address(this), addCollateralAmount);
```
When the modifyCollateralAndDebt function is called, it will try to deposit again because the collateral amount is greater than 0. But it will revert because collateral tokens are already deposited in the _onIncreaseLever function.

## Tools Used
Manual Review
## Recommended Mitigation Steps
Just approve the CDP vault and dont deposit into the CDP vault in the _onIncreaseLever function.
