# Vulnerability details

## Impact
In PositionActionPendle, function _onDecreaseLever()'s return value will keep 0 if users don't use `leverParams.auxAction`. This will cause core function decreaseLever() will always be reverted.

## Proof of Concept
In _onDecreaseLever(), we will return the amount of underlying token withdraw from CDPVault. 
The problem is that if the parameter `leverParams.auxAction` is not necessary for users. When users don't config `leverParams.auxAction`, the return value `tokenOut` will be always 0.
When we try to calculate the left collateral via `withdrawnCollateral - swapAmountIn`, the calculation will be reverted.
Because `withdrawnCollateral` is zero, and `swapAmountIn` is one positive value.
```javascript
    function _onDecreaseLever(
        LeverParams memory leverParams,
        uint256 subCollateral
    ) internal override returns (uint256 tokenOut) {
        _onWithdraw(leverParams.vault, leverParams.position, address(0), subCollateral);

        if (leverParams.auxAction.args.length != 0) {
            bytes memory exitData = _delegateCall(
                address(poolAction), abi.encodeWithSelector(poolAction.exit.selector, leverParams.auxAction)
            );

            tokenOut = abi.decode(exitData, (uint256));
        }
    }
```
