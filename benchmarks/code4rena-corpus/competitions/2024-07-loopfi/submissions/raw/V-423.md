# Vulnerability details

## Vulnerability details
https://github.com/code-423n4/2024-07-loopfi/blob/main/src/vendor/AuraVault.sol#L375-L375

`AuraVault` uses Chainlink to get AURA and ETH prices, but do not check if the data is stale.
This is correctly implemented in the `ChainlinkOracle` contract, but `AuraVault` has its own implementation for price fetching.

These prices [are then used](https://github.com/code-423n4/2024-07-loopfi/blob/main/src/vendor/AuraVault.sol#L330-L331) to compute the value of claimed reward by users.

## Impact
Consumed price could be stale, which would lead to incorrect valuation of reward token prices when user are claiming.
This can lead to protocol losing against users, or the opposite, depending on the current real token market price.
