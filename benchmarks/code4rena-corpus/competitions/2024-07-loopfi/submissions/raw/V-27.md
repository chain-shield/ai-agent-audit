# Vulnerability details

### Impact
Administrator is not able to pause users' withdrawals and deposits as expected.

### Proof of Concept
The CDPVault contract inherits Pausable to provide pausing capabilities to the administrator on users' deposits and withdrawals. The contract correctly exposes the `whenNotPaused()` modifier to the deposit and withdrawal functions. However, these functions are simply used to format input for the `modifyCollateralAndDebt()` public function, which does not implement the `whenNotPaused()` modifier, rendering the pausability feature ineffective.

Add the test below to `2024-07-loopfi/src/test/unit/CDPVault.t.sol`:

```solidity
  function test_PauseAndDeposit_Withdrawal() public {
    CDPVault vault = createCDPVault(token, 150 ether, 10 ether, 1.25 ether, 1.0 ether, 0);
    createGaugeAndSetGauge(address(vault));
    token.mint(address(this), 100 ether);
    token.approve(address(vault), 100 ether);
    address position = address(new PositionOwner(vault));

    vault.pause();  //@auditor Admin pauses contract
    
    vm.expectRevert("Pausable: paused"); // @auditor Foundry Cheatcode to expect a revert only on next line
    vault.deposit(position, 50 ether); // @auditor User makes initial deposit with the deposit function and is reverted as protocol is paused.
    vault.modifyCollateralAndDebt({ // @auditor User bypasses the pause by calling modifyCollateralAndDebt, achieving the same result as deposit without reverting.
        owner: position,
        collateralizer: address(this),
        creditor: address(this),
        deltaCollateral: 50 ether,
        deltaDebt: 0
    });

    vm.expectRevert("Pausable: paused"); // @auditor Foundry Cheatcode to expect a revert only on next line
    vault.withdraw(position, 50 ether); // @auditor User makes initial deposit with the withdraw function and is reverted as protocol is paused.
    vault.modifyCollateralAndDebt({  // @auditor User bypasses the pause by calling modifyCollateralAndDebt, achieving the same result as withdraw without reverting.
        owner: position,
        collateralizer: address(this),
        creditor: address(this),
        deltaCollateral: -50 ether,
        deltaDebt: 0
    });
 }
```
`Run the following command`
```shell
forge test --match-contract CDPVault --match-test test_PauseAndDeposit_Withdrawal -vvv
```
### Tools Used
Foundry

### Recommended Mitigation Steps
Add the `whenNotPaused()` modifier to the `modifyCollateralAndDebt()` function.
