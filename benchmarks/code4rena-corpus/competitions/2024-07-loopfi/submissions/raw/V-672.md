# Vulnerability details

`StakingLPEth` is implementing the ERC4626 standard and also there are some checks that are trying to prevent from inflation attack. But there is a case where the contract could be vulnerable to inflation attack.

## Impact
Potential complete loss of funds for new depositors, given they receive no ownership in exchange for their deposited tokens.

## Proof of concept
Let's imagine the below scenario, which can lead to inflation attack:

1.  During cooldown is on, users can withdraw all the shares
2.  Admin changes the cooldown duration to zero
3.  The contract is vulnerable to inflation attack, because there are no funds in the contract. 

## Tools Used
Manual Review

## Recommended Mitigation Steps
Add the _checkMinShares into the cooldownShares and cooldownAssets to prevent this

```diff
/// @notice redeem assets and starts a cooldown to claim the converted underlying asset
    /// @param assets assets to redeem
    function cooldownAssets(uint256 assets) external ensureCooldownOn returns (uint256 shares) {
        if (assets > maxWithdraw(msg.sender)) revert ExcessiveWithdrawAmount();

        shares = previewWithdraw(assets);

        cooldowns[msg.sender].cooldownEnd = uint104(block.timestamp) + cooldownDuration;
        cooldowns[msg.sender].underlyingAmount += uint152(assets);

        _withdraw(msg.sender, address(silo), msg.sender, assets, shares);
+       _checkMinShares();
    }

    /// @notice redeem shares into assets and starts a cooldown to claim the converted underlying asset
    /// @param shares shares to redeem
    function cooldownShares(uint256 shares) external ensureCooldownOn returns (uint256 assets) {
        if (shares > maxRedeem(msg.sender)) revert ExcessiveRedeemAmount();

        assets = previewRedeem(shares);

        cooldowns[msg.sender].cooldownEnd = uint104(block.timestamp) + cooldownDuration;
        cooldowns[msg.sender].underlyingAmount += uint152(assets);

        _withdraw(msg.sender, address(silo), msg.sender, assets, shares);
+       _checkMinShares();
    }
```
