# Vulnerability details

## Vulnerability details
In `AuraVault` contract, function `_chainlinkSpot()` check and return price as below:

    function _chainlinkSpot() private view returns (uint256 price) {
        bool isValid;
        try AggregatorV3Interface(BAL_CHAINLINK_FEED).latestRoundData() returns (
            uint80 /*roundId*/,
            int256 answer,
            uint256 /*startedAt*/,
            uint256 /*updatedAt*/,
            uint80 /*answeredInRound*/
        ) {
            price = wdiv(uint256(answer), BAL_CHAINLINK_DECIMALS);
            isValid = (price > 0);
        } catch {}

        if (!isValid) revert AuraVault__chainlinkSpot_invalidPrice();
    }

It can be seen that there is no checking about stale price, which mean old price can be returned, lead to wrong price return to user.

## Impact
Wrong price can be returned due to stale price

## Tools Used
Manual review

## Recommended Mitigation Steps
Add checking conditions about output of chainlink like roundId, startedAt, .. to make sure price returned is correct.
