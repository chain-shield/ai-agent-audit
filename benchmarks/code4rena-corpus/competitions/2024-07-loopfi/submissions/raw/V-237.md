# Vulnerability details

## Impact
A malicious user can use the `transferAndJoin(...)` function of PoolAction.sol to steal all the tokens that users have approved the PoolAction.sol contract as spender.

## Proof of Concept
The major issue is that users are allowed to pass arbitrary `from` address parameter, which is finally used to transfer tokens with an `ERC20.transferFrom(...)` function.

`transferAndJoin(...)` function of PoolAction.sol contract takes a `from` address parameter which can be used to transfer tokens `from` any address that has granted approval to the PoolAction.sol contract before executing the balancer join operation. This `transferAndJoin(...)` function also allows the `poolActionParams` parameter that allows the attacker to pass his address to receive the LP tokens which can be used to exit the pool thereby stealing the tokens.

function _transferFrom(
        address token,
        address from,
        address to,
        uint256 amount,
        PermitParams memory params
    ) internal {
        if (params.approvalType == ApprovalType.PERMIT2) {
            // Consume a permit2 message and transfer tokens.
            ISignatureTransfer(permit2).permitTransferFrom(
                ISignatureTransfer.PermitTransferFrom({
                    permitted: ISignatureTransfer.TokenPermissions({token: token, amount: params.approvalAmount}),
                    nonce: params.nonce,
                    deadline: params.deadline
                }),
                ISignatureTransfer.SignatureTransferDetails({to: to, requestedAmount: amount}),
                from,
                bytes.concat(params.r, params.s, bytes1(params.v)) // Construct signature
            );
        } else if (params.approvalType == ApprovalType.PERMIT) {
            // Consume a standard ERC20 permit message
            IERC20Permit(token).safePermit(
                from,
                to,
                params.approvalAmount,
                params.deadline,
                params.v,
                params.r,
                params.s
            );
            IERC20(token).safeTransferFrom(from, to, amount);
        } else {
            // No signature provided, just transfer tokens.
            IERC20(token).safeTransferFrom(from, to, amount);
        }
    }
