# Vulnerability details

## Impact
When CDPVault is paused for some reason, users can still deposit/withdraw via modifyCollateralAndDebt()

## Proof of Concept
In CDPVault, function deposit()/withdraw() can be paused for some reason. If paused, users cannot deposit or withdraw collateral from the vault.
The problem is that there is not any limitation for function `modifyCollateralAndDebt()`. It means that users can deposit/withdraw via `modifyCollateralAndDebt()` even if admin paused the deposit/withdraw.

```javascript
    function deposit(address to, uint256 amount) external whenNotPaused returns (uint256 tokenAmount) {
        ...
    }

    function withdraw(address to, uint256 amount) external whenNotPaused returns (uint256 tokenAmount) {
        ...
    }
```

## Tools Used
Manual

## Recommended Mitigation Steps
Add some limitation for function modifyCollateralAndDebt(). When admin pause the deposit/withdraw, function modifyCollateralAndDebt cannot change the position's collateral.
