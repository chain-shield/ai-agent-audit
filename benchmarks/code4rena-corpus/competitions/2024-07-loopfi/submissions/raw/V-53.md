# Vulnerability details

## Impact
The liquidator's collateral reward amount will be smaller than expected because it is not properly scaled with tokenScale.

## Vulnerability Details

The liquidator's collateral reward amount will be smaller than expected if the collateral token's decimals are not not properly scaled with tokenScale. Liquidation is crucial and all unsafe positions must be liquidated to maintain the protocol's solvency. However, because the liquidator's collateral rewards are correctly scaled to the collateral's token decimals using tokenScale, users are not incentivized to liquidate unhealthy positions.

Collateral tokens are scaled to prevent their value from being too small or inconsistent. `takeCollateral`, the liquidator's reward is gotten from `repayAmount` which is not scaled. This might make it to be smaller than expected.
## Proof of Concept
Underlying tokens are set to 18 decimals at deployment. [PoolV3.sol#L182-#L184](https://github.com/code-423n4/2024-07-loopfi/blob/4f508781a49ffa53511e7e5ed6cda0ff0eb5bdc5/src/PoolV3.sol#L182-#L184)
```solidity
        if (ERC20(underlyingToken_).decimals() != 18) {
            revert IncompatibleDecimalsException();
        }
```

But as seen below, `repayAmount` and `takeCollateral` are not scaled. This will lead to the liquidator receiving a smaller reward amount.
[CDPVault.sol#L529](https://github.com/code-423n4/2024-07-loopfi/blob/4f508781a49ffa53511e7e5ed6cda0ff0eb5bdc5/src/CDPVault.sol#L529)
```solidity

@>      uint256 takeCollateral = wdiv(repayAmount, discountedPrice);

        // @audit takeCollateral is not scaled, hence it might be smaller.
```

`takeCollateral` is also not scaled when liquidating positions with bad debt, which makes the liquidator's collateral reward to be smaller than expected.

## Recommended Mitigation Steps
`repayAmount` should be properly scaled to the collateral token's decimals in `liquidatePosition` and `liquidatePositionBadDebt`. This will make `takeCollateral` which is gotten from `repayAmount` to be properly scaled.
```solidity
    function liquidatePosition(address owner, uint256 repayAmount) external whenNotPaused {
        // validate params
        if (owner == address(0) || repayAmount == 0) revert CDPVault__liquidatePosition_invalidParameters();
+       repayAmount = wdiv(repayAmount, tokenScale);
        ...
    }
```

```solidity
    function liquidatePositionBadDebt(address owner, uint256 repayAmount) external whenNotPaused {
        // validate params
        if (owner == address(0) || repayAmount == 0) revert CDPVault__liquidatePosition_invalidParameters();
+       repayAmount = wdiv(repayAmount, tokenScale);
        ...
    }
```
