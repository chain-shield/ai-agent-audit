# Vulnerability details

## Impact
increaseLever() will not work for PositionAction4626. In PositionAction4626, we try to deposit collateral into CDPVault twice. This will cause revert.

## Proof of Concept
In PositionAction4626, we swap and get the `addCollateralAmount` collateral. And the `addCollateralAmount` will be deposited into CDPVault directly in function _onIncreaseLever().
In the whole increaseLever process, after we call `_onIncreaseLever()` in function onFlashLoan(), we will call `modifyCollateralAndDebt()` function to add collateral again. The `modifyCollateralAndDebt()` function call will be reverted because of not enough funds in PoolAction.
```javascript
    function _onIncreaseLever(
        LeverParams memory leverParams,
        address upFrontToken,
        uint256 upFrontAmount,
        uint256 swapAmountOut
    ) internal override returns (uint256) {
        ...
        // deposit into the CDP vault
        IERC20(leverParams.collateralToken).forceApprove(leverParams.vault, addCollateralAmount);
        // @audit we should not deposit into CDP Vault here.
        return ICDPVault(leverParams.vault).deposit(address(this), addCollateralAmount);
    }
```

Do not deposit collateral in CDPVault in `_onIncreaseLever()`. Because flashloan() function will deposite the collateral into CDPVault.
