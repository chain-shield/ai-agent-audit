# Vulnerability details

## Impact
The current implementation of the `setInterestRateModel` function sets bool checkOptimalBorrowing to false in its function call
```
function setInterestRateModel(
        address newInterestRateModel
    )
        external
        override
        configuratorOnly // U:[LP-2C]
        nonZeroAddress(newInterestRateModel) // U:[LP-22A]
    {
        interestRateModel = newInterestRateModel; // U:[LP-22B]
        _updateBaseInterest(0, 0, false); // U:[LP-22B]
        emit SetInterestRateModel(newInterestRateModel); // U:[LP-22B]
    }

```
thus does not ensure that the total amount being borrowed is optimal according to the logic parameters of newly implemented the interest rate model which may have a different parameter for checking for optimal borrowing from the old interest rate model contract . This could lead to potential suboptimal borrowing state after the interest rate model update.

## Proof of Concept
In the setInterestRateModel function, the updateBaseInterest method is called with the third parameter set to false:
```
function setInterestRateModel(
    address newInterestRateModel
)
    external
    override
    configuratorOnly
    nonZeroAddress(newInterestRateModel)
{
    interestRateModel = newInterestRateModel;
    _updateBaseInterest(0, 0, false);
    emit SetInterestRateModel(newInterestRateModel);
}
```
This does not check if the total amount being borrowed is optimal according to the new logic parameters of the interest rate model. which is checked here
```
   _baseInterestRate = ILinearInterestRateModelV3(interestRateModel)
            .calcBorrowRate({
                expectedLiquidity: expectedLiquidity_,
                availableLiquidity: availableLiquidity_,
                checkOptimalBorrowing: checkOptimalBorrowing
            })
```
in the updateBaseInterest function.
The checkOptimalBorrowing parameter is set to false, which means the function does not verify if the current borrowed amount aligns with the optimal borrowing conditions defined by the new interest rate model.

## Recommended Mitigation Steps
Change the third parameter of the updateBaseInterest call to true to ensure that the current borrowed amount is optimal according to the new logic parameters for optimal borrowing in the interest rate model:
```
function setInterestRateModel(
    address newInterestRateModel
)
    external
    override
    configuratorOnly
    nonZeroAddress(newInterestRateModel)
{
    interestRateModel = newInterestRateModel;
 +   _updateBaseInterest(0, 0, true);
    emit SetInterestRateModel(newInterestRateModel);
}
```
