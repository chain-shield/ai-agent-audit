# Vulnerability details

## Description
Look at this:
```
 function modifyCollateralAndDebt(){
        if (deltaDebt > 0) {
            //////////////////////////////
        } else if (deltaDebt < 0) {
            //////////////////////////////
        } else {
            newDebt = position.debt;
            newCumulativeIndex = debtData.cumulativeIndexLastUpdate;
        }
        ////////////////////////////////////

        position = _modifyPosition(owner, position, newDebt, newCumulativeIndex, deltaCollateral, totalDebt);

```
Look at that. What happen if ``deltaDebt`` is `0`?

So, when ``deltaDebt`` is `0`, ``newDebt`` will be initialized with ``position.debt``, at first glance it looks normal.

But look deeper:
```
    function _modifyPosition(
 uint256 currentDebt = position.debt;
////////////////////////////////////
if (newDebt > currentDebt) {
            totalDebt_ = totalDebt_ + (newDebt - currentDebt);
        } else {
            totalDebt_ = totalDebt_ - (currentDebt - newDebt);
        }
        totalDebt = totalDebt_;

        if (address(rewardController) != address(0)) {
            rewardController.handleActionAfter(owner, position.debt, totalDebt_);
        }

        emit ModifyPosition(owner, position.debt, position.collateral, totalDebt_);
```
since ``newDebt`` is equal to ``position.debt``, this code will be executed:
``` 
else {
            totalDebt_ = totalDebt_ - (currentDebt - newDebt);
```
now ``totalDebt_ `` is zero, just like when someone pays off their debt normally.

As a result, a malicious user can call ``payment`` with amount = 0, to make this emit ``ModifyPosition`` and ``UpdateBalance`` incorrectly.


## Impact
- malicious user can set someone's ``totalDebt_`` to zero.
- Thas's impact emit ``ModifyPosition`` and ``UpdateBalance`` incorrectly

## Proof of Concept
- When someone have position debt.
- malicious user will call ``repay`` with amount = 0
- as a result, emit ``ModifyPosition`` and ``UpdateBalance`` incorrectly.
- which is ``totalDebt_`` will zero, just like when someone pays off their debt normally
