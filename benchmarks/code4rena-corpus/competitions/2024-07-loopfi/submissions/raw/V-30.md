# Vulnerability details

## Vulnerabily Details

The `modifyCollateralAndDebt` function in the `CDPVault` contract is responsible for modifying the collateral and debt balances of a position.

This function is called internally by four functions:

* Deposit
* Withdraw
* Borrow
* Repay

```Javascript
function deposit(address to, uint256 amount) external whenNotPaused returns (uint256 tokenAmount) {
    tokenAmount = wdiv(amount, tokenScale);
    int256 deltaCollateral = toInt256(tokenAmount);
    modifyCollateralAndDebt({
        owner: to,
        collateralizer: msg.sender,
        creditor: msg.sender,
        deltaCollateral: deltaCollateral,
        deltaDebt: 0
    });
}

function withdraw(address to, uint256 amount) external whenNotPaused returns (uint256 tokenAmount) {
    tokenAmount = wdiv(amount, tokenScale);
    int256 deltaCollateral = -toInt256(tokenAmount);
    modifyCollateralAndDebt({
        owner: to,
        collateralizer: msg.sender,
        creditor: msg.sender,
        deltaCollateral: deltaCollateral,
        deltaDebt: 0
    });
}

function borrow(address borrower, address position, uint256 amount) external {
    int256 deltaDebt = toInt256(amount);
    modifyCollateralAndDebt({
        owner: position,
        collateralizer: position,
        creditor: borrower,
        deltaCollateral: 0,
        deltaDebt: deltaDebt
    });
}

function repay(address borrower, address position, uint256 amount) external {
    int256 deltaDebt = -toInt256(amount);
    modifyCollateralAndDebt({
        owner: position,
        collateralizer: position,
        creditor: borrower,
        deltaCollateral: 0,
        deltaDebt: deltaDebt
    });
}
```

As you can see, each function (`deposit, withdraw, repay, borrow`) sets the arguments necessary to call the `modifyCollateralAndDebt` function and perform one of the four operations.

The problem is that as the function is public, it is possible to call it directly by modifying the parameters that should be set.

## Impact
This could allow undesired behavior in the execution of the contract.
