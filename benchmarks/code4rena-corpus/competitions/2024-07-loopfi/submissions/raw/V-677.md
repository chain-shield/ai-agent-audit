# Vulnerability details

## Impact
The `lendCreditAccount` function does not check if the `borrowedAmount` exceeds the amount available to borrow as determined by the `availableToBorrow` function in the `interestratemodel` contract.This can lead to the pool lending out more than what is deemed safe or permissible by the interest rate model.

## Proof of Concept
The lendCreditAccount function lacks a check against the availableToBorrow amount from the interest rate model, while creditManagerBorrowable includes this check:
```
function lendCreditAccount(uint256 borrowedAmount, address creditAccount) external override {
    // Existing checks
    if (borrowedAmount == 0 || cmBorrowed_ > cmDebt.limit || totalBorrowed_ > _totalDebt.limit) {
        revert CreditManagerCantBorrowException();
    }
    // Missing check against availableToBorrow
    // ...
}

function creditManagerBorrowable(address creditManager) external view override returns (uint256 borrowable) {
    // ...
    uint256 available = ILinearInterestRateModelV3(interestRateModel).availableToBorrow({
        expectedLiquidity: expectedLiquidity(),
        availableLiquidity: availableLiquidity()
    });
    borrowable = Math.min(borrowable, available);
}

```
In the function `creditManagerBorrowable`, when calculating the borrowable amount for a credit manager, there's a check to compare the credit manager's limit against the `availableToBorrow` amount from the `interestRateModel` contract. This check indicates that `availableToBorrow` is a separate constraint, distinct from the available liquidity, that needs to be verified to ensure the contract doesn't lend out more than what the interest rate model determines is safe to borrow.

## Recommended Mitigation Steps
Add the missing check in lendCreditAccount:
```
function lendCreditAccount(uint256 borrowedAmount, address creditAccount) external override {
    // Existing checks
    // ...
    uint256 availableToBorrow = ILinearInterestRateModelV3(interestRateModel).availableToBorrow({
        expectedLiquidity: expectedLiquidity(),
        availableLiquidity: availableLiquidity()
    });
    if (borrowedAmount > availableToBorrow) {
        revert ExceedsAvailableToBorrowException();
    }
    // Proceed with lending
}

```
This ensures consistency with creditManagerBorrowable and prevents lending beyond the interest rate model's recommendations.
