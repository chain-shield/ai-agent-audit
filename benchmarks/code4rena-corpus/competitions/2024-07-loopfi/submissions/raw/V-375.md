## Impact

If a token gets deregistered from the Balancer pool, the oracle will continue to use the old token address, leading to incorrect price calculations/updates.

## Recommended Mitigation Steps

Consider retrieving the Balancer pool tokens via the _getPoolTokens()_ function whenever needed instead of caching them to prevent issues when the pool tokens change.
