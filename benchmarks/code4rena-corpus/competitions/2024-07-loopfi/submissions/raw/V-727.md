# Vulnerability details

## Issue 
The ChainlinkOracle contract relies on Chainlink's price feeds, which implement min-max circuit breakers. While these circuit breakers are designed to protect against erroneous data, they can lead to significant mispricing during extreme market events, potentially returning incorrect prices that do not reflect the true market conditions.

Chainlink oracles have configurable minimum and maximum price bounds. When the actual market price falls outside these bounds:

1. If the price falls below the minimum, the oracle returns the minimum price.
2. If the price exceeds the maximum, the oracle returns the maximum price.

This behavior, while protecting against erroneous data in normal conditions, can lead to severe mispricing during extreme market events.

## Example Scenario: LUNA Crash
During the LUNA/UST crash in May 2022, the price of LUNA fell from around $60 to fractions of a cent in a matter of days. Many Chainlink price feeds for LUNA had a minimum price set significantly above zero (e.g., $0.10).

As the actual LUNA price fell below this minimum:
1. The Chainlink oracle continued to report the minimum price (e.g., $0.10).
2. This reported price was orders of magnitude higher than the actual market price.
3. Systems relying on this oracle data were operating with severely inflated LUNA prices.

## Impact
The current implementation of the ChainlinkOracle contract does not account for this limitation:

```solidity
function _fetchAndValidate(address token) internal view returns (bool isValid, uint256 price) {
    Oracle memory oracle = oracles[token];
    try AggregatorV3Interface(oracle.aggregator).latestRoundData() returns (
        uint80 /*roundId*/,
        int256 answer,
        uint256 /*startedAt*/,
        uint256 updatedAt,
        uint80 /*answeredInRound*/
    ) {
        isValid = (answer > 0 && block.timestamp - updatedAt <= oracle.stalePeriod);
        return (isValid, wdiv(uint256(answer), oracle.aggregatorScale));
    } catch {
        // return the default values (false, 0) on failure
    }
}
```

The contract will consider the price valid as long as it's positive and not stale, even if it's stuck at the minimum or maximum bound of the Chainlink feed. This can lead to assets being severely overvalued or undervalued.


## Recommendations
- Track historical prices and implement alerts for prices that remain constant over extended periods, especially during high market volatility.

- Implement a mechanism to suspend operations or switch to alternative price sources if suspicious price behavior is detected.
