# Vulnerability details

## Impact
The use of deprecated `answeredInRound` in `PendleLPOracle.sol` risks contract failures or unexpected behavior if Chainlink removes or alters this feature.

## Proof of Concept
When the `PendleLPOracle.sol` fetches the price from Chainlink's aggregator, [it checks](https://github.com/code-423n4/2024-07-loopfi/blob/57871f64bdea450c1f04c9a53dc1a78223719164/src/oracle/PendleLPOracle.sol#L120) that `answeredInRound` is greater than or equal to the `roundId`:
```solidity
            isValid = (answer > 0 && answeredInRound >= roundId && block.timestamp - updatedAt <= stalePeriod);
            return (isValid, wdiv(uint256(answer), aggregatorScale));
```
Since `answeredInRound` **[is deprecated](https://docs.chain.link/data-feeds/api-reference#latestrounddata)**, continuing to use it means the protocol might be relying on a feature that could be removed or altered in the future. If Chainlink removes support for this feature, the contract could fail or behave unexpectedly.
