# Vulnerability details

## Impact
In repay(), we support to transfer arbitrary token and swap to underlying tokens. If users try to swap via EXACT_IN swap type, the output amount is not one fixed value, maybe less or larger than `creditParams.amount`. If the output amount is less than `creditParams.amount`, reapy() will be reverted. Otherwise, some collateral will be left into the PositionAction() contract.

## Proof of Concept
In PositionAction::repay(), if users try to swap some arbitrary tokens to underlying token via EXACT_IN swap type, the return value `amount` may be larger than `creditParams.amount`. This will cause users' collateral left in the PositionAction().
