# Vulnerability details

## Impact
The CDPVault.sol contract provides the whenNotPaused modifier. This modifier is present in the functions:
withdraw();
deposit();
liquidatePosition();
liquidatePositionBadDebt().
However, the following functions with the external or public type do not have it:
modifyCollateralAndDebt();
repay();
borrow().

Moreover, the whenNotPaused modifier is useless for the withdraw() and deposit() functions. It can be bypassed by calling the modifyCollateralAndDebt() function directly.

The absence of the whenNotPaused modifier in functions may lead to a deterioration in the security of the CDPVault.sol contract.

## Tools Used
Manual review

## Recommended Mitigation Steps
Add the whenNotPaused modifier to the functions:
modifyCollateralAndDebt();
repay();
borrow().
