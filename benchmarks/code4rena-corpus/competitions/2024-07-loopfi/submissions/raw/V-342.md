# Vulnerability details

## Impact
The `borrow` function is designed not to revert based on its implementation. However, it makes an external call to the `poolV3` contract, which includes a `whenNotPaused` modifier. If the `poolV3` contract is paused, this external call will revert, causing the `borrow` function to fail unexpectedly. This issue also affects both flash loan functionality and the `cdpVault` action, potentially disrupting the protocol's operations and leading to failed transactions.

## Proof of Concept

1. **Borrow Function Reversion:**
   - The `borrow` function calls `modifyCollateralAndDebt` to generate debt against collateral. Within this flow, the `poolV3` contract's `lendCreditAccount` function is invoked.
   - The `lendCreditAccount` function in `poolV3` has a `whenNotPaused` modifier:
    

 ```solidity
     function lendCreditAccount(
         uint256 borrowedAmount,
         address creditAccount
     )
         external
         override
         creditManagerOnly // U:[LP-2C]
@audit>>>         whenNotPaused // U:[LP-2A]
         nonReentrant // U:[LP-2B]
     {
         // Function implementation...
     }
 ```

   - If `poolV3` is paused, the `whenNotPaused` modifier causes `lendCreditAccount` to revert, which in turn causes the `borrow` function to fail.

2. **Effect on Flash Loans and `cdpVault`:**
   - Both flash loan operations and the `cdpVault` rely on successful execution of the `borrow` function. If the function reverts, these operations will also fail.

## Recommended Mitigation Steps

1. **Remove `whenNotPaused` Modifier in `lendCreditAccount`:**
   - Remove the `whenNotPaused` modifier from the `lendCreditAccount` function in the `poolV3` contract. This will ensure that the `borrow` function does not inadvertently revert due to the pause state of `poolV3`.
   - Example Mitigation:
     
```solidity
     function lendCreditAccount(
         uint256 borrowedAmount,
         address creditAccount
     )
         external
         override
         creditManagerOnly // U:[LP-2C]
         nonReentrant // U:[LP-2B]
     {
         // Function implementation...
     }
  ```
