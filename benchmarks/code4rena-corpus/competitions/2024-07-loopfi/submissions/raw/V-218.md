# Vulnerability details

## Impact
Admin can remove a `CDPVault` from the `VaultRegistry`. The user's total Debt is computed in the `VaultRegistry` by looping through the vaults and computing the debt for the user's positions across all vaults.

When admin removes the `CDPVault` vault, then the borrowed positions under that vault will not show up as Debt for all the users. This under accounts the total due from the users and will not show as due. This will be the case until the `CDPVault` is added back to the `VaultRegistry`.

The vulnerability arises from the fact that, the `removeVault(...)` function does not check for `totalDebt` in the `CDPVault` before removing from the registry.

## Proof of Concept
The `removeVault(...)` function does not check for `totalDebt` to be 0 in the vault before removing. Hence it removes the vault from the list.  

```
function removeVault(ICDPVault vault) external override(IVaultRegistry) onlyRole(VAULT_MANAGER_ROLE) {
        if (!registeredVaults[vault]) revert VaultRegistry__removeVault_vaultNotFound();

        _removeVaultFromList(vault);
        registeredVaults[vault] = false;
        emit VaultRemoved(vault);
    }
```
Since the vault is removed from `vaultList`, any position in the removed vault is not accounted as debt due from the user. Hence it impacts the User's Total Debt position.

This is risky for the protocol as the collateral valuation might fall due to market circumstances, but since certain debts are not accounted, the protocol may end up having less collateral them borrowings.
   
```
    /// @notice Returns the aggregated position stats for a user across all vaults
    /// @param user The position owner
    function getUserTotalDebt(address user) external view override(IVaultRegistry) returns (uint256 totalNormalDebt) {
        uint256 vaultLen = vaultList.length;
        for (uint256 i = 0; i < vaultLen; ) {
            (, uint256 debt, , , , ) = ICDPVault(vaultList[i]).positions(user);

            totalNormalDebt += debt;

            unchecked {
                ++i;
            }
        }
    }
```

As in the above code snippet, `totalNormalDebt` is computed for vaults where in the `vaultList` array.
