# Vulnerability details

## Details
`AuraVault::_chainlinkSpot` function uses `latestRoundData` but there is no check on return value as it might not return the correct price.
## Impact
Code will execute with prices that don’t reflect the current pricing resulting in a potential loss of funds for users.

## Tools Used
Manual/Foundry
## Recommended Mitigation Steps
1. Always check the updatedAt parameter returned from latestRoundData() and compare it to a staleness threshold. The staleness threshold should correspond to the heartbeat of the oracle’s price feed.

2. function should cross-check the returned answer against the minPrice/maxPrice and revert if the answer is outside of these bounds
