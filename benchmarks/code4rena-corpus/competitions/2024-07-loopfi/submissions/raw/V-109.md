# Vulnerability details

## Proof of Concept
In the `_deposit` function, the `availableLiquidityDelta` should be updated to reflect the change in liquidity based on the amount deposited and the fees applied. However, if the calculation of `assetsReceived` (which is derived from `_amountMinusFee(assets))` is non-zero, this should result in a non-zero `availableLiquidityDelta` as well. If the `availableLiquidityDelta` remains unchanged when `assetsReceived` is non-zero, it indicates a discrepancy.

Here’s a detailed code snippet to illustrate:
```solidity
    function _deposit(address receiver, uint256 assetsSent, uint256 assetsReceived, uint256 shares) internal {
        IERC20(underlyingToken).safeTransferFrom({from: msg.sender, to: address(this), value: assetsSent}); // U:[LP-6,7]

        _updateBaseInterest({
            expectedLiquidityDelta: assetsReceived.toInt256(),
            availableLiquidityDelta: 0, // @audit
            checkOptimalBorrowing: false
        }); // U:[LP-6,7]

        _mint(receiver, shares); // U:[LP-6,7]
        emit Deposit(msg.sender, receiver, assetsSent, shares); // U:[LP-6,7]
    }
```
 If `availableLiquidityDelta` is not updated in line with `assetsReceived`, the liquidity state of the contract could become inconsistent. For example, if `assetsReceived` is calculated as non-zero but `availableLiquidityDelta` remains unchanged, this discrepancy can lead to incorrect liquidity calculations.
## Impact
If `availableLiquidityDelta` does not correctly account for the `assetsReceived` amount, the liquidity state of the contract may be incorrect. This could lead to inconsistencies in liquidity calculations, potentially affecting the contract's ability to handle future deposits or withdrawals properly.
## Tools Used
Manual
## Recommended Mitigation Steps
Ensure that `availableLiquidityDelta` is updated correctly within the `_deposit` function.
I'd suggest:
```solidity
_updateBaseInterest({
    expectedLiquidityDelta: assetsReceived.toInt256(),
    availableLiquidityDelta: availableLiquidityDelta,
    checkOptimalBorrowing: false
});
```
