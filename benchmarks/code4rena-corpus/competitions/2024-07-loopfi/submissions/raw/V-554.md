# Vulnerability details

## Impact

The CDP vault liquidation mechanism allow anyone liquidate any users' positions including himself position, but when liquidate himself, the liquidator can gain the liquidation profit, which is not the expected behavior from security POV.


## Tools Used

vscode

## Recommended Mitigation Steps

Forbid the users to liquidate himeself position.
