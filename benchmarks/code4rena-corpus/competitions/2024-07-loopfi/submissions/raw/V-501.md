# Vulnerability details

## Impact
In `CDPVault`, when calling `liquidatePosition`, a penalty is applied to the liquidated user "to mitigate against profitable self liquidations". The penalty is charged by subtracting it to the amount of debt removed from the position owner.
```solidity
uint256 deltaDebt = wmul(repayAmount, liqConfig_.liquidationPenalty);
```
Because of this, after a liquidation happens, the position's collateral ratio decreases (becomes more unhealthy). Liquidations should never make the position more unhealthy since that can be followed by successive liquidations and can potentially lead to a liquidation crisis. They should instead be a mechanism to protect the protocol from incurring in bad debt, by repaying some debt and claiming some collateral so that the position gets healthier.

## Proof of Concept
```solidity
    function test_liquidationWorsesThePosition_cid() public {
        address bob = makeAddr("bob");
        address alice = makeAddr("alice");
        CDPVault vault = createCDPVault(token, 150 ether, 2 ether, 1.25 ether, 0.98 ether, 0.97 ether);
        createGaugeAndSetGauge(address(vault));
        LiquidationConfig memory liqConfig;
        (liqConfig.liquidationPenalty, liqConfig.liquidationDiscount) = vault.liquidationConfig();

        // alice deposits 100 ether
        uint256 collateral = 100 ether;
        deal(address(token), alice, collateral);
        vm.startPrank(alice);
        token.approve(address(vault), collateral);
        vault.deposit(alice, collateral);

        // alice borrows 80 ether
        uint256 borrowAmount = 80 ether;
        vault.borrow(alice, alice, borrowAmount);
        vm.stopPrank();

        // position becomes unhealthy due to price movement
        vm.warp(block.timestamp + 365 days);
        _updateSpot(0.9 ether);
        uint256 totalDebt = virtualDebt(vault, alice);
        uint256 spotPrice_ = vault.spotPrice();
        uint256 discountedPrice = wmul(spotPrice_, liqConfig.liquidationDiscount);        

        //bob liquidates alice
        uint256 repayAmount = 70 ether;
        vm.startPrank(bob);
        deal(address(mockWETH), bob, repayAmount);
        mockWETH.approve(address(vault), repayAmount);
        vault.liquidatePosition(alice, repayAmount);

        (uint256 collateralAfter, , , , , ) = vault.positions(alice);
        uint256 totalDebtAfter = virtualDebt(vault, alice);

        // position is more unhealthy
        assertGt(wdiv(collateral, totalDebt), wdiv(collateralAfter, totalDebtAfter));

    }     
```

## Recommended Mitigation Steps
