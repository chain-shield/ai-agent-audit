# Vulnerability details

The `liquidatePositionBadDebt()` function transfers the entire collateral of a position to the liquidator, regardless of the actual `repayAmount` provided.

## Impact
In the current implementation, a liquidator can receive the full collateral of a position even if they provide a `repayAmount` that is less than the discounted value of the collateral. This could lead to a loss of funds for the vault and unfair gains for the liquidator.

## Proof of Concept
Here's how:
* Alice has a position with 100 ETH collateral and 50,000 DAI debt.
* The current `spotPrice` is 1000 DAI/ETH, and the `liquidationDiscount` is 0.95.
* Alice's position becomes undercollateralized, and the vault allows liquidation.
* Bob, a liquidator, calls `liquidatePositionBadDebt()` with a `repayAmount` of only 25,000 DAI.

In this case, the following lines in `liquidatePositionBadDebt()` will be executed: [#L605-L606](https://github.com/code-423n4/2024-07-loopfi/blob/57871f64bdea450c1f04c9a53dc1a78223719164/src/CDPVault.sol#L605-L606)
```solidity
takeCollateral = position.collateral;
repayAmount = wmul(takeCollateral, discountedPrice);
```
And later: [#L626](https://github.com/code-423n4/2024-07-loopfi/blob/57871f64bdea450c1f04c9a53dc1a78223719164/src/CDPVault.sol#L626)
```solidity
token.safeTransfer(msg.sender, takeCollateral);
```
As a result, Bob will receive the entire 100 ETH collateral, even though he only repaid 25,000 DAI, which is less than the discounted value of the collateral (95,000 DAI).

## Recommended Mitigation Steps
To ensure fair liquidation, transfer only the portion of the collateral that corresponds to the actual `repayAmount` provided by the liquidator. 
```solidity
- takeCollateral = position.collateral;
- repayAmount = wmul(takeCollateral, discountedPrice);
+ uint256 discountedCollateralValue = wmul(position.collateral, discountedPrice);
+ takeCollateral = wdiv(repayAmount, discountedPrice);
+ repayAmount = wmul(takeCollateral, discountedPrice);
+ uint256 remainingCollateral = position.collateral - takeCollateral;
```
And later
```solidity
- token.safeTransfer(msg.sender, takeCollateral);
+ token.safeTransfer(msg.sender, takeCollateral);
+ if (remainingCollateral > 0) {
+     token.safeTransfer(owner, remainingCollateral);
+ }
```
These ensure that the liquidator receives only the portion of the collateral that corresponds to their actual `repayAmount`, and any remaining collateral is returned to the position owner.
