# Vulnerability details

## Vulnerability details

The `AuraVault#_chainlinkSpot` don't check the `latestRoundData` return price is stale or not, it may cause the protocol use the stale price to calculate incorrect aura reward.

```solidity
function _chainlinkSpot() private view returns (uint256 price) {
    bool isValid;
    try AggregatorV3Interface(BAL_CHAINLINK_FEED).latestRoundData() returns (
        uint80 /*roundId*/,
        int256 answer,
        uint256 /*startedAt*/,
        uint256 /*updatedAt*/,
        uint80 /*answeredInRound*/
    ) {
        price = wdiv(uint256(answer), BAL_CHAINLINK_DECIMALS);
        isValid = (price > 0);
    } catch {}

    if (!isValid) revert AuraVault__chainlinkSpot_invalidPrice();
}
```

## Impact

`AuraVault` may use the stale price to calculate incorrect aura reward cause reward distribution incorrectly.

## Tools Used

vscode

## Recommended Mitigation Steps

Check the `latestRoundData` return price is stale or not before use it.
