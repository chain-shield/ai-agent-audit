# Vulnerability details

## Impact

The access control restriction - `whenNotPaused` can be bypassed easily and collateral can be deposited.

## Proof of Concept

`CDPVault` contract has the function `deposit` . User can call this function and deposit the collateral.This function has the access control restriction `whenNotPaused`  - when it is ON, the deposit would be halted for brief period of time.There would be some critical operation undergoing or some other fixes would be happening. During this time, the protocol would not accepting any deposit.

if we see the deposit function, it makes call to the public function         `modifyCollateralAndDebt({` and the deposit is completed. Since this function is public, user can directly call and make deposit.

## Tools Used

Manual review.

## Recommended Mitigation Steps

Add `whenNotPaused` restriction to `modifyCollateralAndDebt` as well.


## Assessed type

Access Control
