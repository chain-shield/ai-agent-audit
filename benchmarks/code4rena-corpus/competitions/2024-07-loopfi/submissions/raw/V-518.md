# Vulnerability details

## Title
Remove a vault without checking underlying debt, can DoS users who claim rewards via ```ChefIncentivesController:::claim```

## Impact
```VaultRegistry:::removeVault``` only checks if the vault is registered in registeredVaults, but it does not check its underlying debt. Remove a vault with debt can DoS users not eligible for claiming rewards, since the ```VaultRegistry:::getUserTotalDebt``` gets user's total debt across all vaults.
