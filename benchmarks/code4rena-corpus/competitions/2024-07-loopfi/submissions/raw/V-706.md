# Vulnerability details

The `_fetchAndValidate()` function in the `PendleLPOracle` contract uses the `answeredInRound` variable from Chainlink's `latestRoundData()`, which has been deprecated. This could lead to inaccurate price validation.

## Impact
The reliance on deprecated features could lead to the oracle failing to validate prices correctly, causing issues with price feeds or the contract's functionality in general. This could cause the failure of `spot()` and `getStatus()` which is used by other contracts for getting the assets price.


## Proof of Concept
In the `_fetchAndValidate()` function, the `answeredInRound` variable is used to check the validity of the Chainlink price feed data. However, `answeredInRound` is a deprecated feature in Chainlink's `AggregatorV3Interface`. Relying on deprecated features can cause problems in the future if the Chainlink interface updates or removes this feature, potentially leading to the oracle failing to validate prices correctly.
