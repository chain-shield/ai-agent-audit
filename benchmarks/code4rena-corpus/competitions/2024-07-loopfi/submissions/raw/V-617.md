# Vulnerability details

## Impact
Under collateralized position might not be fully liquidated, leaving bad debt to the protocol

## Proof of Concept
Anyone can liquidate a under-collateralized position. The liquidator can buy the collateral in discount price.
- If the under-collateralized position is not `bad debt` position, it can be liquidated by calling `CDPVault#liquidatePosition()`. All debt and interest should be able to be fully repaid. A portion of repaid asset will be sent to `treasury` as penalty.
- If the under-collateralized position is` bad debt` position, it can only be liquidated by calling `CDPVault#liquidatePositionBadDebt()`. There is no penalty for `liquidatePositionBadDebt()`.

However, The bad debt calculation in `liquidatePosition()` didn't account for the  discount price and penalty:
```solidity
526:        if (calcTotalDebt(debtData) > wmul(position.collateral, spotPrice_)) revert CDPVault__BadDebt();
```
A liquidator could liquidate a bad debt position, get all its collateral and leave partial of its debt un-repaid.

The [audit report 5](https://notes.watchpug.com/p/190dd9d39acrEJAv) from watchpug did not address the issue of `liquidationPenalty `.
## Tools Used
Manual review
## Recommended Mitigation Steps
The bad debt calculation in `liquidatePosition()` should account for the discount price and penalty:
```math
\begin{align*}
collateral * price_{discount} * ratio_{penalty} &>= debt + interest
\end{align*}
```
$ratio_{penalty}$ is `liquidationConfig.liquidationPenalty` of `CDPVault`.
