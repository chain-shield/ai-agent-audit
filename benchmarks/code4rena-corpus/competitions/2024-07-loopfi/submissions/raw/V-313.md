# Vulnerability details

`unstake()` function in the `StakingLPEth` contract (StakingLPEth.sol:88-100) allows users to unstake their assets after the cooldown period has ended. meanwhile, there is an inconsistency in how the cooldown conditions are checked, allowing users to unstake their assets before the intended cooldown period has passed.

The issue arises because the `unstake()` function checks the condition `block.timestamp >= userCooldown.cooldownEnd || cooldownDuration == 0`, which allows unstaking if either the current timestamp is greater than or equal to the user's cooldown end time or if the global `cooldownDuration` is set to zero. This does not properly enforce the cooldown period as intended.

## Impact
Users may be able to unstake their assets before the intended cooldown period has elapsed, bypassing the purpose of the cooldown mechanism.

The premature unstaking of assets violates the intended staking rules and could have implications for the overall stability and fairness of the staking system.

## Proof of Concept
1. The `cooldownDuration` is initially set to `100`.

2. Alice calls `cooldownShares(shares)` or `cooldownAssets(assets)` to start the cooldown process when `block.timestamp` is `1000`. Her `userCooldown.cooldownEnd` is set to 1100.

3. The contract owner calls `setCooldownDuration(50)`, reducing the `cooldownDuration` to 50. However, Alice's `userCooldown.cooldownEnd` remains at 1100.

4. At `block.timestamp` `1075`, Alice calls `unstake()`. The condition `block.timestamp >= userCooldown.cooldownEnd || cooldownDuration == 0` evaluates to `true` because `1075 >= 1100` is false, but `cooldownDuration == 0` is also false. The overall condition is `true` due to the `||` operator.

5. The `unstake()` function does not revert and allows Alice to unstake her assets, even though `block.timestamp` (`1075`) is less than her `initialCooldownEnd` (1100) and the `cooldownDuration` is not zero.

Add this test to `StakingLP.t.sol`
```solidity
    function test_cooldown_unstake_violation() public {
        // Set initial cooldown duration to 100
        stakingLpEth.setCooldownDuration(100);
    
        // User1 deposits assets
        vm.startPrank(user1);
        liquidityPool.approve(address(stakingLpEth), 0.1 ether);
        stakingLpEth.deposit(0.1 ether, user1);
        vm.stopPrank();
    
        // User1 starts cooldown
        vm.startPrank(user1);
        stakingLpEth.cooldownShares(stakingLpEth.balanceOf(user1));
        vm.stopPrank();
    
        // Get initial cooldown end timestamp
        (uint104 initialCooldownEnd, ) = stakingLpEth.cooldowns(user1);
    
        // Reduce cooldown duration to 50
        stakingLpEth.setCooldownDuration(50);
    
        // Advance timestamp to a point before initialCooldownEnd but after reduced cooldown duration
        vm.warp(initialCooldownEnd - 25);
    
        // User1 unstakes assets
        vm.startPrank(user1);
        stakingLpEth.unstake(user1);
        vm.stopPrank();
    
        // Assert that user1 was able to unstake assets before the initial cooldown end
        assertEq(stakingLpEth.balanceOf(user1), 0);
        assertEq(liquidityPool.balanceOf(user1), 0.1 ether);
    }  
```
