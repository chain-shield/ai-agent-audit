# Vulnerability details

## Impact
On ChainlinkOracle.sol and AuraVault.sol, the Chainlink oracle data feed from the latestRoundData is insufficiently validated as there is no check for stale price data. This could lead to stale and wrong prices return value according to chainlink documentation:

    https://docs.chain.link/docs/historical-price-data/#historical-rounds
    https://docs.chain.link/docs/faq/#how-can-i-check-if-the-answer-to-a-round-is-being-carried-over-from-a-previous-round
