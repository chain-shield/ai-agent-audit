# Vulnerability details

## Impact

Redundant quoted tokens will therefore still contribute to Pool's quota revenue calculations in `PoolQuotaKeeperV3::poolQuotaRevenue`, thereby inflating new `quotaRevenue` value.

The function `PoolQuotaKeeperV3::poolQuotaRevenue` iterates over the `quotaTokensSet`, calculating the quota revenue based on the tokens present in this set. 

Since there is no method to remove tokens from `quotaTokensSet`, any token that was once added but is no longer actively borrowed by `creditManagers` will still be included in the `quotaRevenue` calculations. This could lead to inflated quota revenue values.


As a result, the persistence of redundant tokens which `Credit Managers` might have stopped borrowing might inflate the `newQuotaRevenue` calculation, used to set new quota revenue value in `PoolV3::setPoolQuotaKeeper`.

## Recommended Mitigation Steps


To mitigate this issue, consider the following recommendations:

* Implement a removal function: Add a function to remove quota tokens. This function should:

  * Remove the token from `quotaTokensSet`
  * Clear or reset the corresponding `totalQuotaParams[token]`
  * Emit an event for the removal.

Like so

```diff
+ function removeQuotaToken(address token) external gaugeOnly {
+   if (!quotaTokensSet.contains(token)) {
+       revert TokenNotQuotedException();
+   }
    
+   quotaTokensSet.remove(token);
+   delete totalQuotaParams[token];
    
+   emit RemovedQuotaToken(token);
+ }

```

And the corresponding event declaration:

```diff
+ /// @notice Emitted when a quota token is removed
+ event RemovedQuotaToken(address indexed token);
```

* Update related functions: Ensure that other functions that interact with quota tokens (like updateRates) handle the case where a token has been removed gracefully.

* Consider a token status flag: Instead of removing tokens entirely, you could add a status flag to each token (e.g., active/inactive). This would allow for easier reactivation if needed and could be used to skip inactive tokens in revenue calculations.
