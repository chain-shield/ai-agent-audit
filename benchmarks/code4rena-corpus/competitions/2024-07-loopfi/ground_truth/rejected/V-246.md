## Brief Summary

The `PositionActionPendle` contract contains functions that delegate calls to external contracts (`poolAction.join` and `poolAction.exit`). These delegated calls could introduce reentrancy risks if the external functions are not properly secured. Reentrancy attacks can allow an attacker to repeatedly call a function before the previous execution is complete, potentially manipulating state variables or draining funds from the contract.
