There is currently no incentive to rebalance
Bauchibred
27
Sufficient
383d ago
Proof of Concept

Take a look at https://github.com/code-423n4/2024-12-lambowin/blob/874fafc7b27042c59bdd765073f5e412a3b79192/src/rebalance/LamboRebalanceOnUniwap.sol#L62-L70

    function rebalance(uint256 directionMask, uint256 amountIn, uint256 amountOut) external nonReentrant {
        uint256 balanceBefore = IERC20(weth).balanceOf(address(this));
        bytes memory data = abi.encode(directionMask, amountIn, amountOut);
        IMorpho(morphoVault).flashLoan(weth, amountIn, data);
        uint256 balanceAfter = IERC20(weth).balanceOf(address(this));
        uint256 profit = balanceAfter - balanceBefore;
        require(profit > 0, "No profit made");
    }


This is the most critical section in scope, i.e when if the 1:1 peg is not expected then we are to rebalance, issue however is that there are no incentives whatsoever to call this function, cause the profit from the rebalancing is only restricted to the admin to withdraw via https://github.com/code-423n4/2024-12-lambowin/blob/874fafc7b27042c59bdd765073f5e412a3b79192/src/rebalance/LamboRebalanceOnUniwap.sol#L55-L60

    function extractProfit(address to, address token) external onlyOwner {
        uint256 balance = IERC20(token).balanceOf(address(this));
        if (balance > 0) {
            IERC20(token).safeTransfer(to, balance);
        }
    }

This then means that if there is a depeg no one would repeg since there are no rewards for this.

Impact

Depegs would stay longer than if it is avaialble to the public, considering the admin is the only one who is incentivised to repeg to 1:1 if ever diverged.

Recommended Mitigation Steps

Introduce a reward for repegging, this can be shared by the owner and the one who called the rebalance function, this way the 1:1 peg would always be enforced.
