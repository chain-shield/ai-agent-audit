# Vulnerability details

## Impact
A non-zero reserve value when used inside calcLpTokenSupply function can lead to division by Zero Error.

## Proof of Concept
`if (reserves[0] == 0 && reserves[1] == 0) return 0;` condition is false when reserves[0] != 0 but reserves[1] = 0 or vice versa. This value is passed to getScaledReserves() function 
`uint256[] memory scaledReserves = getScaledReserves(reserves, decimals);`
which can result in scaledReserves[0] = 0 or scaledReserves[1] = 0. 

```
dP = dP * lpTokenSupply / (scaledReserves[0] * N);
dP = dP * lpTokenSupply / (scaledReserves[1] * N);
```

These zero valued scaledReserves can break the code.
## Tools Used
Manual
## Recommended Mitigation Steps
Use an OR (||) operator instead of an AND (&&) operator.
`if (reserves[0] == 0 || reserves[1] == 0) return 0;`
