# Vulnerability details

## Impact
The 'initNoWellToken' function is unprotected, posing a high-severity risk by allowing unauthorized reinitialization of the contract, which could result in significant adverse consequences.

## Proof of Concept
'''solidity
function initNoWellToken() external initializer {}
'''

This function is marked with the initializer modifier but lacks any access control, such as 'onlyOwner'. This means anyone can call this function, potentially reinitializing the contract.

## Tools Used
Manual Review

## Recommended Mitigation Steps
The `initNoWellToken` function must be secured with access control to ensure that only the contract owner or a trusted entity can invoke it. The recommended implementation is as follows:

```solidity
function initNoWellToken() external initializer onlyOwner {}
```
