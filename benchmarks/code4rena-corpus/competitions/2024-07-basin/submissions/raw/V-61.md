# Vulnerability details

The `_authorizeUpgrade` function is intended to manage `UUPS` proxy upgrades. It includes checks to ensure that upgrades are only authorized through delegate calls, through proxies managed by an `Aquifer`, and with valid implementations. However, the assumption that `address(this) != ___self` guarantees a delegate call is problematic for minimal proxies. These proxies might not meet this assumption, potentially allowing unauthorized upgrades. Furthermore, relying on assumptions about `ERC-1967` implementations could introduce vulnerabilities if minimal proxies are not properly accounted for.


## Impact
An attacker exploiting minimal proxy patterns could bypass the upgrade authorization checks, leading to unauthorized contract upgrades. This could allow the execution of arbitrary code or compromise the contract’s security.
