# Vulnerability details


## Proof of Concept

`getRatiosFromPriceLiquidity` uses a series of nested if-else statements to determine the appropriate `PriceData` to return based on the input price. This implementation relies heavily on hardcoded price points and corresponding ratios, and it doesn't handle cases where the input price exactly matches a boundary value.

## Impact

This approach fails to handle cases where the input price exactly equals a boundary value. Which would then lead to slightly inaccurate results in these edge cases, potentially affecting the precision of calculations based on this function's output.
