# Vulnerability details

## Impact
The `notDelegatedOrIsMinimalProxy` modifier is used in the `proxiableUUID` function. The issue is that it has been implemented incorrectly, causing it to revert in many cases. As a result, it will not be possible to upgrade a Well.

## Proof of Concept
Here is how the modifier is implemented:
```solidity
    modifier notDelegatedOrIsMinimalProxy() {
        if (address(this) != ___self) {
            address aquifer = aquifer();
            address wellImplmentation = IAquifer(aquifer).wellImplementation(address(this));
            require(wellImplmentation == ___self, "Function must be called by a Well bored by an aquifer");
        } else {
            revert("UUPSUpgradeable: must not be called through delegatecall");
        }
        _;
    }
```

As we can see if it has not been called through a delegatecall it will revert (reverts if `address(this) == ___self`). This is likely a mistake, due to the revert statement stating: `"UUPSUpgradeable: must not be called through delegatecall"`, which is also incorrect as in reality it can only be called through a delegatecall.

Furthermore, when a Well gets upgraded and `_authorizeUpgrade` is called, a normal call(not a delegatecall) is made to `proxiableUUID`, thus invoking the `notDelegatedOrIsMinimalProxy`. As the call is not a delegatecall the modifier will instantly revert, causing the upgrade of the Well to fail.

## Recommended Mitigation Steps
Perhaps, removing the revert in the `else` statement will be a sufficient fix.
