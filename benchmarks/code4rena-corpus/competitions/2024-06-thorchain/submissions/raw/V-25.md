# Vulnerability details

## Impact
Some tokens don't return any value after transfer (like USDT), the source contract implements a `safeTransferFrom` method that aims to solve this problem, but it still checks that the `success` variable is true, but USDT won't return true, so you won't be able to transfer USDT at all, even though it's in the ERC20 whitelist.

## Proof of Concept
```solidity
(bool success, bytes memory data) = _asset.call(
      abi.encodeWithSignature(
        "transferFrom(address,address,uint256)",
        msg.sender,
        address(this),
        _amount
      )
    );
  @>  require(success && (data.length == 0 || abi.decode(data, (bool))));
```

## Tools Used
Manual review.

## Recommended Mitigation Steps
Use OpenZeppelin's SafeERC20 lib and its `safeTransferFrom` method.
