# Vulnerability details

## Description
Using `type(uint).max` as the default expiry time effectively means that the deposit will never expire. In theory, if the transaction is in the mempool for a while, it could be confirmed after the vault rotated.

## Impact
Such a scenario implies that the targetted vault is no longer valid as rotation happened. That would result in a loss of funds.

## Recommended mitigation
Don't set the expiry to `type(uint).max`, but, prefer the following, as  the vaults rotate every 3 days:

```diff

    iROUTER(_router).depositWithExpiry(
      _vault,
      _asset,
      _amount,
      _memo,
-      type(uint).max
+      block.timestamp + 3 days
    );
```
