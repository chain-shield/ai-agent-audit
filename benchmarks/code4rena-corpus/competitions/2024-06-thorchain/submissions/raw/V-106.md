# Vulnerability details

## Impact
`transferAllowance` currently does not check if `msg.sender` has the appropriate allowance for the asset before updating the `_vaultAllowance` map.

## Proof of Concept
Che original `transferAllowance` function without the necessary check: [@>/THORChain_Router.sol#(transferAllowance)](https://github.com/code-423n4/2024-06-thorchain/blob/e5ae503d0dc2394a82242be6860eb538345152a1/chain/ethereum/contracts/THORChain_Router.sol#L165-L177)
```solidity
function transferAllowance(
    address router,
    address newVault,
    address asset,
    uint amount,
    string memory memo
) external nonReentrant {
    if (router == address(this)) {
        _adjustAllowances(newVault, asset, amount);
        emit TransferAllowance(msg.sender, newVault, asset, amount, memo);
    } else {
        _routerDeposit(router, newVault, asset, amount, memo);
    }
}
```
PoC:
1. **Initial State:**
    - Vault A has an allowance of 100 tokens for Asset X.
    - Vault B has no allowance for Asset X.

2. **Malicious Actor:**
    - A malicious actor calls the `transferAllowance` function to transfer 50 tokens of Asset X from Vault A to Vault B without having any allowance for Asset X.

3. **Execution:**
    - The `transferAllowance` function does not check if the `msg.sender` has the appropriate allowance for Asset X.
    - The function proceeds to adjust the allowances, transferring 50 tokens from Vault A to Vault B.

4. **Result:**
    - Vault B now has an unauthorized allowance of 50 tokens for Asset X.
    - Vault A's allowance is reduced by 50 tokens without proper authorization.

## Recommended Mitigation Steps
Check to ensure that `msg.sender` has the appropriate allowance for the asset before making any changes.
```solidity
function transferAllowance(
    address router,
    address newVault,
    address asset,
    uint amount,
    string memory memo
) external nonReentrant {
    require(_vaultAllowance[msg.sender][asset] >= amount, "Insufficient allowance"); <@

    if (router == address(this)) {
        _adjustAllowances(newVault, asset, amount); <@
        emit TransferAllowance(msg.sender, newVault, asset, amount, memo); <@
    } else {
        _routerDeposit(router, newVault, asset, amount, memo);
    }
}
```
