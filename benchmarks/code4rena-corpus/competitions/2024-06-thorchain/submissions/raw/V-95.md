# Vulnerability details

## Impact
In the `_deposit` function when handling ETH deposits. The current implementation uses `vault.send(safeAmount)` to forward the ETH to the vault address. However, using `send` has a fixed gas stipend of 2300 gas, which may not be sufficient for the vault contract to handle the received ETH.

## Proof of Concept
Impact of using `vault.send(safeAmount)` with a fixed gas stipend of 2300 gas in the _deposit function can be significant, as it may lead to failed ETH transfers to the vault contract. This issue arises when the vault contract requires more than 2300 gas to handle the received ETH, which is a common scenario when the vault contract has additional logic or interactions with other contracts.

   1. The _deposit function is responsible for handling both ETH and ERC20 token deposits. When depositing ETH, the function uses `vault.send(safeAmount)` to forward the ETH to the provided vault address.: [chain/ethereum/contracts/THORChain_Router.sol#_deposit](https://github.com/code-423n4/2024-06-thorchain/blob/e5ae503d0dc2394a82242be6860eb538345152a1/chain/ethereum/contracts/THORChain_Router.sol#L143-L160)
```solidity
function _deposit(
    address payable vault,
    address asset,
    uint amount,
    string memory memo
) private nonReentrant {
    uint safeAmount;
    if (asset == address(0)) {
        safeAmount = msg.value;
        bool success = vault.send(safeAmount);
        require(success);
    } else {
        // Handle ERC20 token deposit
        // ...
    }
    emit Deposit(vault, asset, safeAmount, memo);
}
```
   2. The `send` function in Solidity has a fixed gas stipend of 2300 gas. This means that when using `vault.send(safeAmount)`, only 2300 gas is forwarded to the vault contract along with the ETH transfer.
   3. In the current implementation, the `_deposit` function checks the return value of `send` using `require(success)`. However, this only ensures that the `send` function itself executed successfully, but it does not guarantee that the vault contract received and processed the ETH correctly.

## Recommended Mitigation Steps
Use `vault.call{value: safeAmount}("")` instead of `vault.send(safeAmount)`. This will forward the entire remaining gas to the vault contract, allowing it to execute any necessary logic upon receiving the ETH. By using `vault.call{value: safeAmount}("")`, you ensure that the vault contract receives the ETH along with sufficient gas to handle the transfer. The `require(success, "ETH transfer to vault failed")` statement checks if the ETH transfer was successful and reverts the transaction if it fails.
```diff
function _deposit(

    string memory memo

    uint safeAmount;
    if (asset == address(0)) {
        safeAmount = msg.value;

+       (bool success, ) = vault.call{value: safeAmount}("");

    emit Deposit(vault, asset, safeAmount, memo);
}
```
