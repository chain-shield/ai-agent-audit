# Vulnerability details

## Impact
The Router contract uses the low level `.send()` function to send ETH in multiple places.
The issue is that `.send()` only forwards 2300 gas, if the recipient implements a fallback function containing some sort of logic, this may revert due to the 2300 gas stipend. This is highly likely to happen when the recipient is a multi-sig smart contract.
In summary, the use of the `.send()` to transfer ETH may make the transaction fail due to the 2300 gas stipend.

## Tools Used
Manual Review

## Recommended Mitigation Steps
Use `call()` instead. For example
```
    (bool success, ) = payable(to).call{amount}("");
    require(success, "Transfer failed.");
```
