# Vulnerability details

## [M-1] Usage of transfer() for ETH Transfer

### Description:

The `THORChain_Router::_transferOutV5` && `THORChain_Router::transferOutAndCall` && `THORChain_Router::_transferOutAndCallV5` functions uses `send()` for `ETH` transfers, which has fixed gas behavior and is discouraged due to potential changes in gas costs.

### THORChain_Router::\_transferOutV5

```javascript
@> if (!success) {
                payable(address(msg.sender)).transfer(transferOutPayload.amount); // For failure, bounce back to vault & continue.
            }
```

### THORChain_Router::transferOutAndCall

```javascript
@> if (!ethSuccess) {
                payable(address(msg.sender)).transfer(_safeAmount); // For failure, bounce back to vault & continue.
            }
```

### THORChain_Router::\_transferOutV5

```javascript
@> if (!sendSuccess) {
                    payable(address(msg.sender)).transfer(msg.value); // For failure, bounce back to vault & continue.
                }
```

### Impact:

Using `transfer()` can lead to failed transactions due to its `fixed gas` stipend of `2300` gas, which might be insufficient in future network updates or for certain operations.

### Proof of Concept:

Refer to the following documents for more details:

- [Consensys Blog](https://consensys.io/diligence/blog/2019/09/stop-using-soliditys-transfer-now/)
- [EIP-1884](https://eips.ethereum.org/EIPS/eip-1884#motivation)

### Recommended Mitigation: Use `call()` instead of `transfer` for `ETH` transfers:

```diff
- payable(address(msg.sender)).transfer(transferOutPayload.amount); // For failure, bounce back to vault & continue.
+ (bool success, ) = payable(address(msg.sender)).call{value: transferOutPayload.amount}("");
+ require(success, "ETH transfer failed");

```

```diff
- payable(address(msg.sender)).transfer(_safeAmount); // For failure, bounce back to vault & continue.
+ (bool success, ) = payable(address(msg.sender)).call{value: _safeAmount}(""); // For failure, bounce back to vault & continue.
+ require(success, "ETH transfer failed");

```

```diff
- payable(address(msg.sender)).transfer(msg.value); // For failure, bounce back to vault & continue.
+ (bool success, ) = payable(address(msg.sender)).call{value: msg.value}(""); // For failure, bounce back to vault & continue.
+ require(success, "ETH transfer failed");


```
