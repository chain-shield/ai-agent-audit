# Vulnerability details

## Impact
When using the approval mechanism in USDT, the approval must be set to 0 before it is updated.the paired asset's approval is not set to 0 before it is updated.

## Proof of Concept
```solidity
    safeApprove(_asset, _router, _amount);
```

```solidity
  function safeApprove(
    address _asset,
    address _address,
    uint _amount
  ) internal {
    (bool success, ) = _asset.call(
      abi.encodeWithSignature("approve(address,uint256)", _address, _amount)
    ); // Approve to transfer
    require(success);
  }
```
## Tools Used
Manual Review
## Recommended Mitigation Steps
Set the allowance to 0 before setting it to the new value.
