# Vulnerability details

## Impact
Some tokens don't return any value after approve (like USDT), the source contract implements a `safeApprove` function, but it still checks that the `success` variable is true, but USDT won't return true, so you won't be able to approve USDT at all and that means that Router won't be able to transfer USDT back to asgard or to the new router.

## Proof of Concept
```javascript
   (bool success, ) = _asset.call(
      abi.encodeWithSignature("approve(address,uint256)", _address, _amount)
    ); // Approve to transfer
 USDT won't return true @>   require(success);
```

## Tools Used
Manual review.

## Recommended Mitigation Steps
Use OpenZeppelin's SafeERC20 lib and its `safeApprove` function.
