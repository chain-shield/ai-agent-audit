# Vulnerability details

## Impact
USDT (Tether) has non-standard return values for its `transfer` and `approve` functions, which do not return a boolean value. Instead, they may return nothing (i.e., an empty response). This deviation from the ERC-20 standard can cause issues in smart contracts that expect a boolean return value. Consequently, this can lead to the contract incorrectly handling token transfers and approvals, causing unexpected reverts or assuming failed transactions.

## Proof of Concept
In the `THORChain_Router` contract, the `safeTransferFrom` function and any function that relies on ERC-20 token transfers or approvals may not handle USDT’s non-standard return values properly.

### Lines of Code
```solidity
function safeTransferFrom(address _asset, uint _amount) internal returns(uint amount) {
    uint _startBal = iERC20(_asset).balanceOf(address(this));
    (bool success, bytes memory data) = _asset.call(abi.encodeWithSignature("transferFrom(address,address,uint256)", msg.sender, address(this), _amount));
    require(success, "Transfer failed");
    // Check if the transfer returned a boolean value and if it's true
    if (data.length > 0) {
        require(abi.decode(data, (bool)), "ERC20 transfer failed");
    }
    uint _endBal = iERC20(_asset).balanceOf(address(this));
    require(_endBal >= _startBal, "Transfer amount exceeds balance");
    uint transferredAmount = _endBal - _startBal;
    require(transferredAmount <= _amount, "Transferred amount exceeds requested amount");
    return transferredAmount;
}
```

## Recommended Mitigation Steps
To properly handle USDT’s non-standard return values, modify the function to account for empty return data, treating such cases as successful operations:

```solidity
function safeTransferFrom(address _asset, uint _amount) internal returns(uint amount) {
    uint _startBal = iERC20(_asset).balanceOf(address(this));
    (bool success, bytes memory data) = _asset.call(abi.encodeWithSignature("transferFrom(address,address,uint256)", msg.sender, address(this), _amount));
    require(success, "Transfer failed");
    // Handle USDT non-standard return values
    if (data.length == 0) {
        // Assume success if no data is returned (USDT case)
    } else {
        require(abi.decode(data, (bool)), "ERC20 transfer failed");
    }
    uint _endBal = iERC20(_asset).balanceOf(address(this));
    require(_endBal >= _startBal, "Transfer amount exceeds balance");
    uint transferredAmount = _endBal - _startBal;
    require(transferredAmount <= _amount, "Transferred amount exceeds requested amount");
    return transferredAmount;
}
```
