# Vulnerability details

## [M-1] Usage of send() for ETH Transfer

### Description:

The `THORChain_Router::_deposit` && `THORChain_Router::transferOut` && `THORChain_Router::_transferOutV5` && `THORChain_Router::transferOutAndCall` && `THORChain_Router::_transferOutAndCallV5` functions uses `send()` for `ETH` transfers, which has fixed gas behavior and is discouraged due to potential changes in gas costs.

### THORChain_Router::\_deposit

```javascript
@> bool success = vault.send(safeAmount);
require(success);
```

### THORChain_Router::transferOut

```javascript
@> bool success = to.send(safeAmount); // Send ETH.
            if (!success) {
```

### THORChain_Router::\_transferOutV5

```javascript
@> bool success = transferOutPayload.to.send(transferOutPayload.amount); // Send ETH.
            if (!success) {
```

### THORChain_Router::transferOutAndCall

```javascript
@> bool ethSuccess = payable(to).send(_safeAmount); // If can't swap, just send the recipient the ETH
            if (!ethSuccess) {
```

### THORChain_Router::\_transferOutAndCallV5

```javascript
@> bool sendSuccess = payable(aggregationPayload.target).send(msg.value); // If can't swap, just send the recipient the gas asset
                if (!sendSuccess) {
```

### Impact:

Using `send()` can lead to failed transactions due to its `fixed gas` stipend of `2300` gas, which might be insufficient in future network updates or for certain operations.

### Proof of Concept:

Refer to the following documents for more details:

- [Consensys Blog](https://consensys.io/diligence/blog/2019/09/stop-using-soliditys-transfer-now/)
- [EIP-1884](https://eips.ethereum.org/EIPS/eip-1884#motivation)

### Recommended Mitigation: Use `call()` instead of `send()` for `ETH` transfers:

```diff
+ (bool success, ) = vault.call{value: safeAmount}("");
+ require(success, "ETH transfer failed");

```

```diff
+ (bool success, ) = to.call{value: safeAmount}(""); // Send ETH.
+  if (!success) {
```

```diff
+ (bool success, ) = transferOutPayload.to.call{value: transferOutPayload.amount}(""); // Send ETH.
+ if (!success) {

```

```diff
+ (bool ethSuccess, ) = payable(to).call{value: _safeAmount}(); // If can't swap, just send the  +recipient the ETH
+ if (!ethSuccess) {

```

```diff
+ (bool sendSuccess, ) = payable(aggregationPayload.target).call{value: msg.value}(); // If can't swap, + just send the recipient the gas asset
+ if (!sendSuccess) {


```
