# Vulnerability details

## Impact
The impact of this vulnerability is significant as it can cause the program to terminate abruptly with a panic error. This can lead to service disruption or unexpected behavior, potentially affecting the reliability and availability of the system.

## Proof of Concept
The vulnerability arises from a lack of validation in the unpackVaultLog function. Specifically, the code attempts to access properties of an event in the ABI without verifying whether the event exists. If the event does not exist (i.e., is nil), attempting to access its properties will result in a runtime panic.

## Recommended Mitigation Steps
To address this vulnerability, it is recommended to implement proper error handling and validation in the unpackVaultLog function. Specifically:

Before accessing properties of an event in the ABI, verify that the event exists by checking if it is nil.
If the event does not exist, return an appropriate error instead of attempting to access its properties.
Ensure that error handling is robust and informative, providing clear feedback to the caller about the nature of the issue.
