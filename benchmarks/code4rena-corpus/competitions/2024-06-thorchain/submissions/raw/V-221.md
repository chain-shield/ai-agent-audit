# Vulnerability details


## [M-2] Missing onlyVault Check in THORChain_Router::transferAllowance Function

### Description:

The `THORChain_Router::transferAllowance` function in the given code is intended to be called only by a THORChain `vault`, as indicated in the comments. However, there is no check to enforce that only a vault can call this function. This could allow unauthorized addresses to call `THORChain_Router::transferAllowance`, potentially leading to unauthorized allowance transfers.

### Impact:

This oversight could lead to unauthorized allowance transfers between `vaults`, potentially compromising the security and integrity of the `vaults`. Unauthorized entities could misuse this function to alter allowances in ways that were not intended by the contract design.

### Proof of Concept:

The following code shows the missing check:

```javascript
function transferAllowance(address router, address newVault, address asset, uint256 amount, string memory memo)
    external
    nonReentrant
{
    if (router == address(this)) {
        _adjustAllowances(newVault, asset, amount);
        emit TransferAllowance(msg.sender, newVault, asset, amount, memo);
    } else {
        _routerDeposit(router, newVault, asset, amount, memo);
    }
}
```

**There is no onlyVault modifier or equivalent check to ensure that the caller is an authorized vault.**

### Recommended Mitigation:

Add a modifier to restrict access to the function, ensuring that only authorized vaults can call `THORChain_Router::transferAllowance`. For example:

```javascript
modifier onlyVault() {
require(isVault(msg.sender), "Caller is not a vault");
_;
}

function transferAllowance(address router, address newVault, address asset, uint256 amount, string memory memo)
external
nonReentrant
onlyVault
{
if (router == address(this)) {
_adjustAllowances(newVault, asset, amount);
emit TransferAllowance(msg.sender, newVault, asset, amount, memo);
} else {
_routerDeposit(router, newVault, asset, amount, memo);
}
}

function isVault(address account) internal view returns (bool) {
// Logic to check if the address is a vault
}
```
