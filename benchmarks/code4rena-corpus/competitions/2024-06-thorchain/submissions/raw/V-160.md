# Vulnerability details

## Impact
the function batchTransferOutV5 not check if the transferOutPayload[i] is a contract that can accept ether or not , this will lead this function to revert 
## Proof of Concept
```solidity
function batchTransferOutV5(
    TransferOutData[] calldata transferOutPayload
  ) external payable nonReentrant {
    //@audit if transferOutPayload[i] is contract batchTransferOutV5 will revert
    for (uint i = 0; i < transferOutPayload.length; ++i) {
      _transferOutV5(transferOutPayload[i]);
    }
  }
```
