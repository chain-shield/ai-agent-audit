# Vulnerability details

The `safeApprove` internal function only check the return value of `call` external call but failed to check the return value of the approve function as some tokens such as COMP (Whitelisted) are not approving very large amount, there are chances that the return value might be false or the hole approve function call revert.

## Impact
Denial of service to the functions that call the safeApprove like transferAllowance

## Tools Used
Manual review

## Recommended Mitigation Steps
Add and remove the lines indicated in below code
```diff
function safeApprove(address _asset, address _address, uint _amount) internal {
-  (bool success, ) = _asset.call(abi.encodeWithSignature("approve(address,uint256)", _address, _amount));
-  require(success);

+  (bool success, bytes memory data) = _asset.call(abi.encodeWithSignature("approve(address,uint256)", _address, _amount));
+  require(success && (data.length == 0 || abi.decode(data, (bool))));
}
```
