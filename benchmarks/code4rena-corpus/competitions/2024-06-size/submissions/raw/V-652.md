# Vulnerability details


## Summary

Currently, borrowers are unable to `compensate` their debt with credits that have the same due date due to the use of a strict inequality check. This limitation can prevent potentially beneficial transactions for both lenders and borrowers.

## Description

In certain conditions, a borrower can purchase credit from their own lender at a lower rate, thereby reducing their overall debt (with `compensate`). However, this process is impeded if the due dates of the debt and the purchased credit are identical. The strict inequality check (<) in the `validateCompensate` function prevents compensation with credits that have the same due date, blocking what could otherwise be a mutually advantageous transaction.

The relevant code can be found in the `Compensate` library file from the specified repository:

[https://github.com/code-423n4/2024-06-size/blob/8850e25fb088898e9cf86f9be1c401ad155bea86/src/libraries/actions/Compensate.sol#L75-L82](https://github.com/code-423n4/2024-06-size/blob/8850e25fb088898e9cf86f9be1c401ad155bea86/src/libraries/actions/Compensate.sol#L75-L82)

```sol
if (
                debtPositionToRepay.dueDate
                    < state.getDebtPositionByCreditPositionId(params.creditPositionToCompensateId).dueDate
            ) {
                revert Errors.DUE_DATE_NOT_COMPATIBLE(
                    params.creditPositionWithDebtToRepayId, params.creditPositionToCompensateId
                );
            }
```

## Impact

This restriction could lead to missed opportunities where the lender is willing to sell the debt at a lower rate, which the borrower would prefer to purchase to reduce their liability. The inability to compensate due to identical due dates can thus result in financial inefficiency and lost profitability for both parties.

## Recommendation

Modify the comparison operator from `<` to `<=` in the `validateCompensate` function to permit the compensation of debt with credits that have the same due date.

```diff
if (
                debtPositionToRepay.dueDate
-                    < state.getDebtPositionByCreditPositionId(params.creditPositionToCompensateId).dueDate
+                    <= state.getDebtPositionByCreditPositionId(params.creditPositionToCompensateId).dueDate
            ) {
                revert Errors.DUE_DATE_NOT_COMPATIBLE(
                    params.creditPositionWithDebtToRepayId, params.creditPositionToCompensateId
                );
            }
```
By implementing this change, borrowers will have the flexibility to offset their debts even when the due dates of the involved positions match, potentially improving financial outcomes for both lenders and borrowers.
