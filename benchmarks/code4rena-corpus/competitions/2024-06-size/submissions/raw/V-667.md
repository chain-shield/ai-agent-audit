# Vulnerability details

## Description:
The `PriceFeed` contract's `_getPrice()` function lacks a crucial round completeness check when fetching price data from Chainlink aggregators. This omission could lead to the use of stale, incomplete, or potentially manipulated price data, compromising the integrity and reliability of the price feed mechanism.

## Code:

https://github.com/code-423n4/2024-06-size/blob/8850e25fb088898e9cf86f9be1c401ad155bea86/src/oracle/PriceFeed.sol#L84

```solidity
function _getPrice(AggregatorV3Interface aggregator, uint256 stalePriceInterval) internal view returns (uint256) {
    (, int256 price,, uint256 updatedAt,) = aggregator.latestRoundData();
    if (price <= 0) revert Errors.INVALID_PRICE(address(aggregator), price);
    if (block.timestamp - updatedAt > stalePriceInterval) {
        revert Errors.STALE_PRICE(address(aggregator), updatedAt);
    }
    return SafeCast.toUint256(price);
}
```

The current implementation only checks for non-positive prices and staleness based on the `updatedAt` timestamp. It does not verify if the returned round is complete, potentially allowing the use of incomplete round data.

## Impact:
1. Data Integrity: The contract may use price data from incomplete rounds, which could be subject to change or manipulation.
2. Incorrect Pricing: This could lead to incorrect price calculations in the `getPrice()` function, affecting all contract operations relying on accurate price data.
3. Potential for Economic Exploits: In a fast-moving market, this vulnerability could be exploited by malicious actors to gain unfair advantages or manipulate contract behaviors dependent on price feeds.

## Recommended Fix:
Implement a round completeness check in the `_getPrice()` function:

```solidity
function _getPrice(AggregatorV3Interface aggregator, uint256 stalePriceInterval) internal view returns (uint256) {
    (uint80 roundId, int256 price, , uint256 updatedAt, uint80 answeredInRound) = aggregator.latestRoundData();
    
    if (answeredInRound < roundId) {
        revert Errors.INCOMPLETE_ROUND(address(aggregator));
    }

    if (price <= 0) revert Errors.INVALID_PRICE(address(aggregator), price);
    if (block.timestamp - updatedAt > stalePriceInterval) {
        revert Errors.STALE_PRICE(address(aggregator), updatedAt);
    }
    return SafeCast.toUint256(price);
}
```

This modification:
1. Captures all relevant data from `latestRoundData()`.
2. Adds a check to ensure the round is complete (`answeredInRound >= roundId`).
3. Reverts with a custom error if an incomplete round is detected.
4. Adds a new custom error to the `Errors` library:
   
```solidity
   error INCOMPLETE_ROUND(address aggregator);
```
