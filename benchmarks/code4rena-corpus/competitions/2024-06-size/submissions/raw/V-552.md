# Vulnerability details

## Impact
All lending and borrowing limit orders with none-zero `marketRateMultiplier` configurations will be blocked if `variablePoolBorrowRateStaleRateInterval` was set to `0`

## Proof of Concept
The protocol allows use to submit a lending limit order or a borrowing limit order.
APR could be vary based on the tenor. The lender or borrower can hook the APRs of their limit orders to AAVE pool APR.
The APR of AAVE is updated only by `BORROW_RATE_UPDATER_ROLE` through calling `setVariablePoolBorrowRate()`, which will be used to calcualte the APR of the order laterly.

If somehow `variablePoolBorrowRateStaleRateInterval` is set to `0`, all limit orders hooked to AAVE will be not available.

Copy below codes to [SellCreditMarketTest.t.sol](https://github.com/code-423n4/2024-06-size/blob/main/test/local/actions/SellCreditMarket.t.sol) and run `forge test --match-test test_SellCreditMarket_sellCreditMarketHookAAVE`
```solidity
    function test_SellCreditMarket_sellCreditMarketHookAAVE() public {
        _deposit(bob, weth, 100e18);
        _deposit(alice, usdc, 100e6);
        //@audit-info Initially variablePoolBorrowRateStaleRateInterval was 3600
        _updateConfig("variablePoolBorrowRateStaleRateInterval", 3600);
        _setVariablePoolBorrowRate(0.1e18);
        _buyCreditLimit(alice, block.timestamp + 365 days, YieldCurveHelper.marketCurve());
        uint256 tenor = 90 days;
        uint256 apr = size.getLoanOfferAPR(alice, tenor);
        //@audit-info alice has 100e6 szaUSDC 
        assertEq(size.getUserView(alice).borrowATokenBalance, 100e6);
        //@audit-info bob sell 50e6 credit to alice for szaUSDC
        vm.prank(bob);
        size.sellCreditMarket(
            SellCreditMarketParams({
                lender: alice,
                creditPositionId: RESERVED_ID,
                amount: 50e6,
                tenor: tenor,
                deadline: block.timestamp,
                maxAPR: apr,
                exactAmountIn: true
            })
        );
        //@audit-info variablePoolBorrowRateStaleRateInterval was set to 0
        _updateConfig("variablePoolBorrowRateStaleRateInterval", 0);
        //@audit-info bob can not sell credit to alice
        vm.expectRevert(abi.encodeWithSelector(Errors.STALE_RATE.selector, block.timestamp));
        vm.prank(bob);
        size.sellCreditMarket(
            SellCreditMarketParams({
                lender: alice,
                creditPositionId: RESERVED_ID,
                amount: 50e6,
                tenor: tenor,
                deadline: block.timestamp,
                maxAPR: apr,
                exactAmountIn: true
            })
        );
    }
```
As we can see that alice's lending limit order will be blocked once `variablePoolBorrowRateStaleRateInterval` is set to `0`.
