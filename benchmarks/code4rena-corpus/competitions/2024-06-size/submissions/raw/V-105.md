# Vulnerability details

## Impact
The tokenomics calculation could lead to incorrect results, the issue is the way the `pointsWeight` and `timeWeight` mappings are updated within the loop.
[VoteWeighting.sol:226-245](https://github.com/code-423n4/2024-05-olas/blob/3ce502ec8b475885b90668e617f3983cea3ae29f/governance/contracts/VoteWeighting.sol#L226-L245)
```solidity
for (uint256 i = 0; i < MAX_NUM_WEEKS; i++) {
    if (t > block.timestamp) {
        break;
    }
    t += WEEK;
    uint256 dBias = pt.slope * WEEK;
    if (pt.bias > dBias) {
        pt.bias -= dBias;
        uint256 dSlope = changesWeight[nomineeHash][t];
        pt.slope -= dSlope;
    } else {
        pt.bias = 0;
        pt.slope = 0;
    }

    pointsWeight[nomineeHash][t] = pt;
    if (t > block.timestamp) {
        timeWeight[nomineeHash] = t;
    }
}
```
The loop continues to update the `pointsWeight` and `timeWeight` mappings even after the condition `t > block.timestamp` is met, meaning that the loop may update the mappings with future timestamps, leading to incorrect calculations.

## Proof of Concept
Consider the following scenario:

  1. A nominee's vote weight is being calculated using the `_getWeight` function.
  2. The current block timestamp is 1000, and the loop starts iterating with `t = 1000`.
  3. The loop continues to update the mappings even after `t > block.timestamp` condition is met.
  4. The mappings are updated with future timestamps, such as 1100, 1200, etc., leading to incorrect calculations.
  5. The vote weight returned by the function may not accurately reflect the intended weight based on the current block timestamp.

## Recommended Mitigation Steps
The loop should break immediately after updating the mappings when `t > block.timestamp`. By breaking the loop immediately after updating the mappings when `t > block.timestamp`, the calculations are based on the correct timestamps and avoid updating the mappings with future timestamps.
```solidity
for (uint256 i = 0; i < MAX_NUM_WEEKS; i++) {
    if (t > block.timestamp) {
        break;
    }
    t += WEEK;
    uint256 dBias = pt.slope * WEEK;
    if (pt.bias > dBias) {
        pt.bias -= dBias;
        uint256 dSlope = changesWeight[nomineeHash][t];
        pt.slope -= dSlope;
    } else {
        pt.bias = 0;
        pt.slope = 0;
    }

    pointsWeight[nomineeHash][t] = pt;
    timeWeight[nomineeHash] = t;
    if (t > block.timestamp) {
        break;
    }
}
```
