# Vulnerability details

## Description

The `multicall` function executes multiple calls in a single transaction but does not check the return values of these calls. This can lead to a situation where one of the calls fails silently, which might result in unintended behavior or state corruption.

## Impact

If a function call within the `multicall` fails and this failure is not handled properly, it could cause the contract to enter an unexpected state or lead to partial execution of critical operations. This could be exploited to bypass security checks or manipulate contract logic.


## Tools Used

vscode

## Recommended Mitigation Steps 

Check the return values of each call to ensure they are successful. If any call fails, the entire transaction should revert.


Implement a check for each call within the multicall function:


```
function multicall(bytes[] calldata _data)
    public
    payable
    override(IMulticall)
    whenNotPaused
    returns (bytes[] memory results)
{
    results = new bytes[](_data.length);
    for (uint256 i = 0; i < _data.length; i++) {
        (bool success, bytes memory result) = address(this).call(_data[i]);
        require(success, "Multicall: call failed");
        results[i] = result;
    }
}
```
