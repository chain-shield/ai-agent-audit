# Vulnerability details

## Impact

Chainlink aggregators incorporate a circuit breaker mechanism that activates if an asset's price moves beyond a specified range. This means that if an asset's value plummets dramatically (such as during the LUNA crash), the oracle will report the minPrice instead of the asset's actual price. Consequently, users could continue using the protocol using an incorrect reported price. This scenario occurred with Venus on BSC when LUNA collapsed. 

Reference: https://rekt.news/venus-blizz-rekt/

## Proof of Concept
The following code snippet is taken from the `PriceFeed` file:

```solidity
// slither-disable-next-line unused-return
(, int256 price,, uint256 updatedAt,) = aggregator.latestRoundData();

if (price <= 0) revert Errors.INVALID_PRICE(address(aggregator), price);
        
if (block.timestamp - updatedAt > stalePriceInterval) {
   revert Errors.STALE_PRICE(address(aggregator), updatedAt);
}
```
The code only checks for staleness but not for `minAnswer` and `maxAnswer`.
