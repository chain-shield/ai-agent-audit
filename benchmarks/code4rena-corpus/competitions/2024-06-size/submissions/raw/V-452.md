# Vulnerability details



## Impact
Lender/SelfLiquidator receives less collateral from borrower than expected due to extra flooring done to calculate the `ProRataAssignedCollateral`.

## Proof of Concept

In the `executeSelfLiquidate` we are passing `creditPosition` to calculate the `ProRataAssignedCollateral` which is then transferred to selfLiquidator.

https://github.com/code-423n4/2024-06-size/blob/8850e25fb088898e9cf86f9be1c401ad155bea86/src/libraries/actions/SelfLiquidate.sol#L59-L70

```solidity
function executeSelfLiquidate(State storage state, SelfLiquidateParams calldata params) external {
....
=>        uint256 assignedCollateral = state.getCreditPositionProRataAssignedCollateral(creditPosition);
....
}   
```

Inorder to calculate the the `proRataAssignedCollateral` protocol is first calculating the assignedCollateral to that debt Position from the total debt that the borrower has and then again calculating the assigned credit to that particular lender of that debtPosition.

https://github.com/code-423n4/2024-06-size/blob/8850e25fb088898e9cf86f9be1c401ad155bea86/src/libraries/LoanLibrary.sol#L170-L186
https://github.com/code-423n4/2024-06-size/blob/8850e25fb088898e9cf86f9be1c401ad155bea86/src/libraries/LoanLibrary.sol#L148-L161

   `assignedCollateral` = floor(collateralToken * debtPosition.futureValue/debt)
   `proRataAssignedCollateral` = floor(`assignedCollateral`*credit/debtPosition.futureValue)

So the final `proRataAssignedCollateral` can result to a less amount since flooring is done more than once.

Instead , we can just do `proRataAssignedCollateral` = floor(collateralToken*credit/debt).

because, (collateralToken * debtPosition.futureValue/debt) * (credit/debtPosition.futureValue) = collateralToken*credit/debt

This can be proved theoretically.

suppose there 2 lenders `A` and `B` for a debtPosition `X` and the borrower of the debtPosition has one more debtPosition `Y` which has a lender with credit `C`.

so some of all the credits should be equal to total debt.
=> creditAx + creditBx + creditCy = debtPostionX.futurevalue  +  debtPostionY.futurevalue = debt.
=> Equivalent share of lender can be calculated directly using (credit of that lender / debt );

floor(collateralToken*creditAx / debt ) + floor(collateralToken*creditBx / debt ) + floor(collateralToken*creditCy / debt ) <= collateralTOken.

since, creditAx + creditBx + creditCy = debt

## Recommended Mitigation Steps
We can replace the above caluclation by this equation
```solidity
uint256 debt = state.data.debtToken.balanceOf(debtPosition.borrower);
uint256 collateral = state.data.collateralToken.balanceOf;
uint256 creditPositionCredit = creditPosition.credit;(debtPosition.borrower);
proRataAssignedCollateral = Math.mulDivDown(collateral, creditPositionCredit, debt);  
```
