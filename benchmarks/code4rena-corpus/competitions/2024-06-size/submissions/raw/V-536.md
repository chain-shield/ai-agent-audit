# Vulnerability details

## Impact
`binarySearch` function can occur overflow error.
It seems to be the right if it is common to calculate the `mid` value of `low` and `high`.
However, if both `low` and `high` are large enough (close to Max values), overflow will occur in `low + high` calculations.

## Proof of Concept
It is simple math equation.
    
    low + (high - low) / 2 = 
        ( 2 * low + high - low ) / 2 = 
             (low + high) / 2
    
The two expressions are the same, but when calculated on a computer, they may produce different values ​​because of data-type's overflow issues.

## Tools Used

Manual review

## Recommended Mitigation Steps
Replace this:
    `uint256 mid = (low + high) / 2;`
into this:
    `uint256 mid = low + (high - low) / 2;`

If you change it as above, you can safely find the `mid` value even if `low` and `high` are sufficiently large numbers.
