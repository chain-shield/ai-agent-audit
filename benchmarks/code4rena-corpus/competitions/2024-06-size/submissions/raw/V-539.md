# Vulnerability details

## Impact

The Chainlink aggregator in the `PriceFeed` contract lacks a mechanism to detect and handle scenarios where the price of an asset falls outside of a predetermined price band. This is a crucial part because Chainlink aggregators have a built-in circuit breaker if the price of an asset goes outside of a predetermined price band. The result is that if an asset experiences a huge drop in value (i.e. LUNA crash) the price of the oracle will continue to return the `minPrice` instead of the actual price of the asset. This would allow user to continue interacting with the asset but at the wrong price. This is exactly what happened to Venus on BSC when [LUNA](https://rekt.news/venus-blizz-rekt/) imploded.

## Proof of Concept

The `PriceFeed::_getPrice` function doesn't check if the returned price from the oracle is between the `minPrice` and `maxPrice`:

```javascript

    function _getPrice(AggregatorV3Interface aggregator, uint256 stalePriceInterval) internal view returns (uint256) {
        // slither-disable-next-line unused-return
@>      (, int256 price,, uint256 updatedAt,) = aggregator.latestRoundData();

        if (price <= 0) revert Errors.INVALID_PRICE(address(aggregator), price);
        if (block.timestamp - updatedAt > stalePriceInterval) {
            revert Errors.STALE_PRICE(address(aggregator), updatedAt);
        }

        return SafeCast.toUint256(price);
    }

```

## Recommended Mitigation Steps

Implement a mechanism to check the returned answer against predefined `minPrice` and `maxPrice` bounds. If the answer falls outside of these bounds, the oracle should revert the transaction, indicating that the price data is unreliable due to market conditions.


```diff

    function _getPrice(AggregatorV3Interface aggregator, uint256 stalePriceInterval) internal view returns (uint256) {
        // slither-disable-next-line unused-return
        (, int256 price,, uint256 updatedAt,) = aggregator.latestRoundData();

+       require(price >= minPrice && price <= maxPrice, "invalid price");

        if (price <= 0) revert Errors.INVALID_PRICE(address(aggregator), price);
        if (block.timestamp - updatedAt > stalePriceInterval) {
            revert Errors.STALE_PRICE(address(aggregator), updatedAt);
        }

        return SafeCast.toUint256(price);
    }

```
