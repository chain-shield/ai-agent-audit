# Vulnerability details

## Impact
Solidity version >= 0.8.20 will not work on Base due to PUSH0.

## Proof of Concept
The README clearly states that the protocol is going to be deployed on Base layer2:
> Target networks:
> - Ethereum mainnet
> - Base

However solidity version 0.8.20 or above uses the new [Shanghai EVM](https://blog.soliditylang.org/2023/05/10/solidity-0.8.20-release-announcement/#important-note) which introduces the PUSH0 opcode. This op code may not yet be implemented on Base, so deployment on Base will fail. 

## Tools Used
Manual Review

## Recommended Mitigation Steps
Consider using an earlier solidity version.
