# Vulnerability details

## Impact
Borrowers who borrow on the Size protocol have no control over the maximum loan amount. This means that anybody can lend any amount they so wish putting the borrower at risk of liquidation. Consider the User & BorrowOffer structs, there's no provision for limiting the maximum loan amount:

```solidity
struct User {
    // The user's loan offer
    LoanOffer loanOffer;
    // The user's borrow offer
    BorrowOffer borrowOffer;
    // The user-defined opening limit CR. If not set, the protocol's crOpening is used.
    uint256 openingLimitBorrowCR;
    // Whether the user has disabled all credit positions for sale
    bool allCreditPositionsForSaleDisabled;
}

struct BorrowOffer {
    // The yield curve in relative terms
    // Borrowers can protect themselves by setting an opening limit CR for a loan to be matched
    YieldCurve curveRelativeTime;
}
```
Consider a case where a borrower puts up a lucrative BorrowOffer looking for USDC 20_000 and ends up with USDC 1_000_000. Since there's no way to confirm this offer, the borrower has no option but to be liquidated.
**Impact**
Borrowers are at risk of liquidation from lenders who can provide huge loan amounts.

## Proof of Concept
Consider this scenario:
1. Alice wishes to borrow 500 from the market and puts up a lucrative offer of APR = 0.03e18 and tenor= 365 days.
2. Bob, a crypto whale, lends to Alice by calling buyCreditMarket with an amount of 10_000.
Alice is now indebted to Bob for 10_000 and is destined for liquidation.

This test proves that lenders can lend any amount they wish since the lender has all control over the amount:

```solidity

    function test_BuyCreditMarket_buyCreditMarket_Max_amount() public {
        uint256 amountIn = 10_000e6;
        _deposit(alice, weth, 100e18);
        _deposit(alice, usdc, 100e6);
        _deposit(bob, weth, 100e18);
        _deposit(bob, usdc, 20_000e6);
        _sellCreditLimit(alice, 0.03e18, 365 days);

        uint256 tenor = 365 days;
        uint256 futureValue = Math.mulDivDown(amountIn, PERCENT + 0.03e18, PERCENT);

        Vars memory _before = _state();
        (uint256 loansBefore,) = size.getPositionsCount();

        uint256 debtPositionId = _buyCreditMarket(bob, alice, amountIn, tenor, true);

        Vars memory _after = _state();
        (uint256 loansAfter,) = size.getPositionsCount();

        assertEq(
            _after.alice.borrowATokenBalance,
            _before.alice.borrowATokenBalance + amountIn - size.getSwapFee(amountIn, tenor)
        );
        assertEq(_after.bob.borrowATokenBalance, _before.bob.borrowATokenBalance - amountIn);
        assertEq(_after.alice.debtBalance, _before.alice.debtBalance + futureValue);
        assertEq(loansAfter, loansBefore + 1);
        assertEq(size.getDebtPosition(debtPositionId).futureValue, futureValue);
        assertEq(size.getDebtPosition(debtPositionId).dueDate, block.timestamp + tenor);
    }
```
