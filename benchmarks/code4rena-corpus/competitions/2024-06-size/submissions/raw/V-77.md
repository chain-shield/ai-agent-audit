# Vulnerability details

## Impact
The `executeDeposit` function in the deposit process of the protocol contains multiple vulnerabilities that can be exploited, potentially leading to severe consequences.

Reentrancy Attack: External calls to state.data.weth.deposit and IERC20Metadata.safeTransferFrom before committing state changes.
Improper Input Validation: No thorough checks on params.token and amount.
Authorization Issues: Use of forceApprove without proper authorization checks.

## Tools Used
Manual Code Review

## Recommended Mitigation Steps

Add rigorous validation checks for params.token and amount to ensure they meet expected criteria.
Ensure proper authorization checks before performing forceApprove and other critical operations.
Verify the logic for handling WETH deposits and amounts to ensure correctness.
```
   function executeDeposit(State storage state, DepositParams calldata params) public {
        require(params.token == address(state.data.underlyingCollateralToken) || params.token == address(state.data.underlyingBorrowToken), "Invalid token");

        address from = msg.sender;
        uint256 amount = params.amount;
        if (msg.value > 0) {
            // do not trust msg.value (see `Multicall.sol`)
            amount = address(this).balance;
            // slither-disable-next-line arbitrary-send-eth
            state.data.weth.deposit{value: amount}();
            state.data.weth.forceApprove(address(state.data.variablePool), amount);
            from = address(this);
        }else{
            IERC20Metadata(params.token).safeTransferFrom(from, address(this), amount);
            IERC20Metadata(params.token).forceApprove(address(state.data.variablePool), amount);
        }

        if (params.token == address(state.data.underlyingBorrowToken)) {
            state.depositUnderlyingBorrowTokenToVariablePool(from, params.to, amount);
            // borrow aToken cap is not validated in multicall,
            //   since users must be able to deposit more tokens to repay debt
            if (!state.data.isMulticall) {
                state.validateBorrowATokenCap();
            }
        } else {
            state.depositUnderlyingCollateralToken(from, params.to, amount);
        }

        emit Events.Deposit(params.token, params.to, amount);
    }
```
