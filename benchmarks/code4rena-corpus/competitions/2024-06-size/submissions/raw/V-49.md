# Vulnerability details

The setUserConfiguration function in the Size contract lacks proper access control, which allows any external account to call this function when the contract is not paused. This can lead to unauthorized configuration changes, posing significant security and operational risks

The Size contract defines a role USER_CONFIGURATOR_ROLE but does not enforce this role in the setUserConfiguration function. As a result, any external account can call this function and alter user configurations.

Proof of Concept
The provided PoC exploit demonstrates that an unauthorized user can successfully call the setUserConfiguration function, confirming the lack of access control.

Impact
The lack of access control on the setUserConfiguration function can lead to:

Unauthorized access and modifications to user configurations.
Financial losses due to improper settings.
Operational disruptions affecting the platform's stability and reliability.
Recommendation
Add the onlyRole(USER_CONFIGURATOR_ROLE) modifier to the setUserConfiguration function to restrict access to authorized accounts only.

By addressing this issue, you can ensure that only authorized users can modify user configurations, thereby mitigating the risks associated with this vulnerability.

This report, combined with the provided PoC, should effectively communicate the nature and impact of the vulnerability to the Code4rena team.
