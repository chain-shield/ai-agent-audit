# Vulnerability details

## Impact
Detailed description of the impact of this finding.

The testing was performed using the Foundry framework, particularly focusing on the amountToWad function.

Audit Scope Files
src/libraries/Math.sol (Library implementation)
test/libraries/Maths.t.sol (Test cases for the library)

amountToWad was thoroughly tested to ensure its reliability in converting amounts with different decimal places to a fixed decimal format.

The amountToWad function in the Math library is intended to convert token amounts with arbitrary decimal places into an equivalent representation in Wad format (18 decimal places). However, the function failed the unit test when trying to convert an amount of 1000 with 5 decimals to Wad, returning 10^16 instead of the expected 10^11.

This incorrect conversion could lead to significant financial discrepancies in applications relying on this function for financial calculations involving token amounts.

The amountToWad function is implemented as follows:
```sol
function amountToWad(uint256 amount, uint8 decimals) internal pure returns (uint256) {
    return amount * 10 ** (18 - decimals);
}
```

This implementation assumes that multiplying by 10 ** (18 - decimals) will always convert the amount correctly to Wad format. The failure in the test case indicates a misapplication of the decimal conversion logic.
