# Vulnerability details

## Impact
```solidity
    function executeSelfLiquidate(State storage state, SelfLiquidateParams calldata params) external {
        emit Events.SelfLiquidate(params.creditPositionId);


        CreditPosition storage creditPosition = state.getCreditPosition(params.creditPositionId);
        DebtPosition storage debtPosition = state.getDebtPositionByCreditPositionId(params.creditPositionId);


        uint256 assignedCollateral = state.getCreditPositionProRataAssignedCollateral(creditPosition);


        // debt and credit reduction
        state.reduceDebtAndCredit(creditPosition.debtPositionId, params.creditPositionId, creditPosition.credit);


        state.data.collateralToken.transferFrom(debtPosition.borrower, msg.sender, assignedCollateral);
    }
}
```
The code correctly reduces the `credit` in the `creditPosition` to zero, indicating the position is closed. However, it doesn't explicitly reduce the overall `debt` in the `debtPosition`. This means the debt associated with the self-liquidated portion remains, leading to inconsistencies.

**Consequences:**
 * The `debtPosition` will show a higher debt amount than what's outstanding after the self-liquidation.
 * This discrepancy could be exploited in various ways, mainly if other parts of the system rely on the accuracy of the `debtPosition`'s debt value.

**Let's say:**
   - Debt Position: $1000 principal, $100 in unpaid fees (total value = $1100)
   - Creditor 1: Lent $500 (50% share)
   - Creditor 2: Lent $500 (50% share)

**Scenario: Creditor 1 self-liquidates**
* Expected: Creditor 1 should receive $550 worth of collateral (50% of $1100) and the debt position's debt should be reduced by $500.
* Actual (Due to Bugs):
     - **Bug 1**: Creditor 1 might receive more than $550 because the collateral calculation doesn't account for Creditor 2's unpaid fees.
     - **Bug 2**: The debt position still shows $1000 debt, even though $500 should have been repaid.

## Recommended Mitigation Steps
1. **Adjust `getCreditPositionProRataAssignedCollateral`**: Deduct unpaid fees from totalCollateral before calculating the pro-rata share.
2. Reduce `debtPosition.debt`: In `reduceDebtAndCredit`, subtract the `debtProRata` from the `debtPosition.debt`.
