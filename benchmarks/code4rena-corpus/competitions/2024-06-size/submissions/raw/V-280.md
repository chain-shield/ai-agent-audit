# Vulnerability details

## Impact
The `multicall()` function bypasses the `borrowATokenCap` when making a deposit:
```
if (!state.data.isMulticall) {
                state.validateBorrowATokenCap();
            }
```
When `multicall()` is called, `validateBorrowATokenIncreaseLteDebtTokenDecrease()` is internally invoked with four arguments: `borrowATokenSupplyBefore`, `debtTokenSupplyBefore`, `borrowATokenSupplyAfter`, and `debtTokenSupplyAfter`.

The `validateBorrowATokenIncreaseLteDebtTokenDecrease()` function performs the following check if the supply is above the cap: 
- `borrowATokenSupplyIncrease` is calculated if `borrowATokenSupplyAfter` is greater than `borrowATokenSupplyBefore` 
- `debtATokenSupplyDecrease` is  calculated if `debtTokenSupplyBefore` is greater than `borrowATokenSupplyAfter`.

If the supply increase exceeds the debt reduction, the transaction reverts.

However, `borrowATokenSupplyBefore` and `borrowATokenSupplyAfter` represent the borrowAToken balance of the contract (`address(this)`). These variables does not represent the total supply, because `borrowAToken` is minted to the `to` address specified in the parameters (`params.to`) when `depositUnderlyingBorrowTokenToVariablePool()` is internally called by `executeDeposit()`.

The balance of the size contract only increases when a debt position is repaid. When `executeRepay()` is called, the future value of the debt position is transferred from the borrower to the size contract.
```
state.data.borrowAToken.transferFrom(msg.sender, address(this), debtPosition.futureValue);
```
The balance of the size contract decreases when `claim()` is called. The `executeClaim()` function transfers the claim amount from the size contract to the lender
```
state.data.borrowAToken.transferFrom(address(this), creditPosition.lender, claimAmount);
```
Therefore, anyone could deposit using `multicall()` even if the `borrowTokenCap` is reached, rendering the function `validateBorrowATokenIncreaseLteDebtTokenDecrease()` useless. 
The protocol won’t be able to prevent growing at a faster pace than its security/safety/trust. 

## Proof of Concept
Add the following import and POC to `Multicall.t.sol`
```
import {UserView} from "@src/SizeView.sol";
```
```
    function test_Multicall_multicall_can_bypass_borrowATokenCap() public {
        uint256 amountBorrowTokenCap = 1000000e6;

        _deposit(bob, usdc, amountBorrowTokenCap);
        UserView memory bobUser = size.getUserView(bob);
        assertEq(bobUser.borrowATokenBalance, amountBorrowTokenCap);

        _mint(address(usdc), alice, amountBorrowTokenCap);

        vm.startPrank(alice);
        IERC20Metadata(address(usdc)).approve(address(size), amountBorrowTokenCap);

        vm.expectRevert(abi.encodeWithSelector(Errors.BORROW_ATOKEN_CAP_EXCEEDED.selector, 1e12, 2e12));
        size.deposit(DepositParams({token: address(usdc), amount: amountBorrowTokenCap, to: alice}));
        vm.stopPrank();
        
        bytes[] memory data = new bytes[](1);
        data[0] = abi.encodeCall(size.deposit, (DepositParams({token: address(usdc), amount: amountBorrowTokenCap, to: alice})));

        vm.prank(alice);
        size.multicall(data);

        assertEq(size.getUserView(alice).borrowATokenBalance, amountBorrowTokenCap);
        assertEq(size.getUserView(bob).borrowATokenBalance, amountBorrowTokenCap);
    }
```
In this case the block with the check within `validateBorrowATokenIncreaseLteDebtTokenDecrease()` is not reached:
```// and the supply increase is greater than the debt reduction
            if (borrowATokenSupplyIncrease > debtATokenSupplyDecrease) {
                // revert
                revert Errors.BORROW_ATOKEN_INCREASE_EXCEEDS_DEBT_TOKEN_DECREASE(
                    borrowATokenSupplyIncrease, debtATokenSupplyDecrease
                );
            }
```

## Recommended Mitigation Steps
Change `multicall()` line 29 to:
```uint256 borrowATokenSupplyBefore = state.data.borrowAToken.totalSupply();```
Change `multicall()` line 37 to:
```uint256 borrowATokenSupplyAfter = state.data.borrowAToken.totalSupply();```
