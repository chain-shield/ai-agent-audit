# Impact
In the Size.sol contract, there is a mechanism stated for PAUSE/UNPAUSE. The contract may be paused if a vulnerability is found, which is the most probable scenario. It is a known limitation that all functions will be paused, as there is no individual pause.

As we can see, the other functions such as multicall, deposit, withdraw, buyCreditLimit, sellCreditLimit, buyCreditMarket, sellCreditMarket, repay, claim, setUserConfiguration, compensate, liquidateWithReplacement, selfLiquidate, and liquidate have the `whenNotPaused` condition, meaning they can only be called when the contract is `UNPAUSED`. Therefore, in a paused state, the remaining functions (setVariablePoolBorrowRate and updateConfig) should also implement this condition to ensure that they can only be called when the contract is in an `UNPAUSED` state.

https://github.com/code-423n4/2024-06-size/blob/main/src/Size.sol

### Recommendation
Utilize the whenNotPaused modifier on functions like UpdateConfig and setVariableConfiguration when the contract is paused.
