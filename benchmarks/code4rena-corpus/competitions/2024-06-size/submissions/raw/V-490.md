# Vulnerability details

vulnerability details

a borrower can compensate a debtposition with a different token the compensate.sol does not check if the token used to compensate is the valid token

impact

a malicious user can provide any token to compensate his debposition this results in insolvency of the protocol


recommendation

implement a check to ensure that the token in this transfer is valid
