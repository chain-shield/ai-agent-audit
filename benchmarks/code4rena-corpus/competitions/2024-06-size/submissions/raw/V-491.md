# Vulnerability details

vulnerability details

a borrower can repay his debt by calling the repay function but the contract does not check whether the token used to repay is valid

impact

anyone can repay their debt with a invalid token this results in insolvency of the protocol

recommendation

check if the token used to repay is valid
