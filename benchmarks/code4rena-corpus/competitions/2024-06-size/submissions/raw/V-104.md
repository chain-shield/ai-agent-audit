# Vulnerability details

## Impact
In the current implementation, the relative weight is calculated as follows: [VoteWeighting.sol:_nomineeRelativeWeight:432](https://github.com/code-423n4/2024-05-olas/blob/3ce502ec8b475885b90668e617f3983cea3ae29f/governance/contracts/VoteWeighting.sol#L432)
```solidity
weight = 1e18 * nomineeWeight / totalSum;
```
this calculation assumes that the `totalSum` is always greater than or equal to the `nomineeWeight`. If the `nomineeWeight` is greater than the `totalSum`, the resulting weight will be incorrect and may exceed the expected range of values.

For example, let's say `nomineeWeight` is 1000 and `totalSum` is 500. Using the current calculation.
```solidity
weight = 1e18 * 1000 / 500 = 2e18
```
The resulting `weight` would be 2e18, which is not the intended behavior. The weight should represent the relative proportion of the nominee's weight compared to the total sum, and it should typically be within the range of 0 to 1e18 (100%).

## Proof of Concept
The current implementation calculates `weight1` as 125% and `weight2` as 62.5%, which exceeds the expected range. The expected behavior should be `weight1` as 100% (since it dominates the total sum) and `weight2` as 33.3% (proportional to the total sum).
```solidity
// Example pointsWeight and totalSum values
pointsWeight[nominee1][t].bias = 1000;
pointsWeight[nominee2][t].bias = 500;
totalSum = 800;

// Current implementation
weight1 = 1e18 * 1000 / 800 = 1.25e18 (125%)
weight2 = 1e18 * 500 / 800 = 0.625e18 (62.5%)

// Expected behavior
weight1 = 1e18 (100%)
weight2 = 1e18 * 500 / 1500 = 0.333e18 (33.3%)
```

## Recommended Mitigation Steps
The weight calculation should always return a value between 0 and 1e18. One way to do this is by adding a condition to check if the `nomineeWeight` is greater than the `totalSum`, if the `nomineeWeight` is greater than the `totalSum`, the `weight` is set to 1e18 (100%) to indicate that the nominee's weight dominates the total sum. Otherwise, the weight is calculated as before.
```solidity
if (totalSum > 0) {
    uint256 nomineeWeight = pointsWeight[nomineeHash][t].bias;
    if (nomineeWeight <= totalSum) {
        weight = 1e18 * nomineeWeight / totalSum;
    } else {
        weight = 1e18;
    }
}
```
