# Vulnerability details

## Impact
Size protocol allows user to open limit orders either using `LoanOffer` or `BorrowOffer`   and in the same way the protocol allows users to dynamically calculate apy using the interest rates from AAVE and a variable `marketMultiplier`that the user can set in the limit order. Knowing that the interest rates on AAVE are highly volatile for USDC most of the time the rate is around 6% but sometimes the interest rates peaks shortly to 70 or 80% for a couple of hours or days. Shortly said the rates on aave on the short term are highly unpredictable and this could open up the oppurtinity for MEV BOTS to to backrun the import of high rates (or really low 1%) to lock borrowers or lenders in unfavourable deals.


## Proof of concept

1. Borrower creates a `LoanOffer` with a `marketMultiplier` of 0.9, expecting an APY around the typical 6% based on current AAVE rates.
2. MEV bot detects a sudden spike in AAVE rates to 80%.
3. MEV bot awaits the updates of the rates in size with `setVariablePoolBorrowRate()`   
4. MEV bot quickly backruns the import of the high rates and matches the borrower's offer via a market order
5. The borrower is now locked into a loan with an APY of around 72%, significantly higher than expected.

Similarly, a lender creating a `LoanOffer` could be locked into a loan with an extremely low APY if rates suddenly drop and an MEV bot backruns the import of the low rates.


## Recomendation
This arbitrage vector could be completely mitigated by adding a minimum apy for borrowers and a maximum apy for lenders that they can submit in their limit orders, and checking those values when matching orders via market orders.

```diff
struct BorrowOffer {
    // The yield curve in relative terms
    // Borrowers can protect themselves by setting an opening limit CR for a loan to be matched
    YieldCurve curveRelativeTime;
+   uint256 maxApy;
}
```


```diff
struct LoanOffer {
    // The maximum due date of the loan offer
    // Since the yield curve is defined in relative terms, lenders can protect themselves by
    //   setting a maximum timestamp for a loan to be matched
    uint256 maxDueDate;
    // The yield curve in relative terms
    YieldCurve curveRelativeTime;
+   uint256 maxApy;
}
```
