# Vulnerability details

## Impact
In both `getBorrowOfferAPR` and `getLoanOfferAPR`, the `tenor` parameter is directly passed to the `getAPRByTenor` function of the respective offer (`borrowOffer` or `loanOffer`). However, there is no validation to check if the provided tenor is zero. If the tenor is zero, the' getAPRByTenor' function may behave unexpectedly or produce errors.

## Proof of Concept
1. `getBorrowOfferAPR` and `getLoanOfferAPR` functions in [SizeView.sol#L140-L171](https://github.com/code-423n4/2024-06-size/blob/8850e25fb088898e9cf86f9be1c401ad155bea86/src/SizeView.sol#L140-L171)

2. `getAPRByTenor` function in [OfferLibrary.sol#L65-L81](https://github.com/code-423n4/2024-06-size/blob/8850e25fb088898e9cf86f9be1c401ad155bea86/src/libraries/OfferLibrary.sol#L65-L81)

3. `NULL_TENOR` error in [Errors.sol#L21](https://github.com/code-423n4/2024-06-size/blob/8850e25fb088898e9cf86f9be1c401ad155bea86/src/libraries/Errors.sol#L21)

   1. Suppose a user calls the `getBorrowOfferAPR` function with a `borrower` address and a `tenor` value of 0.

   2. The function retrieves the `borrowOffer` for the given borrower from `state.data.users[borrower].borrowOffer`.

   3. It checks if the `borrowOffer` is null using the `isNull()` function. If it is null, it reverts with the `Errors.NULL_OFFER()` error.

   4. However, there is no check for the tenor value being zero before calling `offer.getAPRByTenor()`.

   5. If the `tenor` is zero, it will be passed to the `getAPRByTenor` function in `OfferLibrary.sol`.

   6. Inside `getAPRByTenor`, the `tenor` value is used in calculations without any validation for zero.

   7. A zero tenor value may lead to unexpected behavior or errors depending on how the calculations are performed.

This is a test case that calls `getBorrowOfferAPR` or `getLoanOfferAPR` with a zero `tenor` value and observes the behavior. If the `getAPRByTenor` function is not designed to handle a zero `tenor`, it may revert or produce incorrect results.
```solidity
function testGetBorrowOfferAPRWithZeroTenor() public {
    // Assuming the borrower has a valid borrow offer
    address borrower = address(0x1);

    // Call getBorrowOfferAPR with a zero tenor
    vm.expectRevert(Errors.NULL_TENOR.selector);
    size.getBorrowOfferAPR(borrower, 0);
}
```
We expect the `getBorrowOfferAPR` function to revert with the `Errors.NULL_TENOR` error when called with a zero `tenor` value.

## Recommended Mitigation Steps
Add a check to ensure that the tenor is not zero before calling getAPRByTenor. If the tenor is zero, you can either revert with an appropriate error message or handle it according to your requirements.
```solidity
function getBorrowOfferAPR(address borrower, uint256 tenor) external view returns (uint256) {
    BorrowOffer memory offer = state.data.users[borrower].borrowOffer;
    if (offer.isNull()) {
        revert Errors.NULL_OFFER();
    }
    if (tenor == 0) {
        revert Errors.NULL_TENOR();
    }
    return offer.getAPRByTenor(
        VariablePoolBorrowRateParams({
            variablePoolBorrowRate: state.oracle.variablePoolBorrowRate,
            variablePoolBorrowRateUpdatedAt: state.oracle.variablePoolBorrowRateUpdatedAt,
            variablePoolBorrowRateStaleRateInterval: state.oracle.variablePoolBorrowRateStaleRateInterval
        }),
        tenor
    );
}

function getLoanOfferAPR(address lender, uint256 tenor) external view returns (uint256) {
    LoanOffer memory offer = state.data.users[lender].loanOffer;
    if (offer.isNull()) {
        revert Errors.NULL_OFFER();
    }
    if (tenor == 0) {
        revert Errors.NULL_TENOR();
    }
    return offer.getAPRByTenor(
        VariablePoolBorrowRateParams({
            variablePoolBorrowRate: state.oracle.variablePoolBorrowRate,
            variablePoolBorrowRateUpdatedAt: state.oracle.variablePoolBorrowRateUpdatedAt,
            variablePoolBorrowRateStaleRateInterval: state.oracle.variablePoolBorrowRateStaleRateInterval
        }),
        tenor
    );
}
```
By adding the `if (tenor == 0) { revert Errors.NULL_TENOR(); }` check, you ensure that the `tenor` is not zero before proceeding with the `getAPRByTenor` call.
