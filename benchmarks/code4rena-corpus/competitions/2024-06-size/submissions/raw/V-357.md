# Vulnerability details


## Impact
A sale involves the transfer/exchange of value between two different parties. In Size, credit is sold/bought/transferred. 
Validation for credit positions in [size.sellCreditMarket()](https://github.com/code-423n4/2024-06-size/blob/8850e25fb088898e9cf86f9be1c401ad155bea86/src/Size.sol#L189) is not sufficient enough as `creditPositions` which are marked not for sale can still be sold. The [validateSellCreditMarket()](https://github.com/code-423n4/2024-06-size/blob/8850e25fb088898e9cf86f9be1c401ad155bea86/src/libraries/actions/SellCreditMarket.sol#L51) function tries to validate the credit positions by calling [isCreditPositionTransferrable()](https://github.com/code-423n4/2024-06-size/blob/8850e25fb088898e9cf86f9be1c401ad155bea86/src/libraries/RiskLibrary.sol#L89) to check if the `creditPosition` to be sold is transferrable but `isCreditPositionTransferrable()` doesn't check if the creditPositon was marked for sale or not.

Credit Positions marked not for sale should not be transferrable and by extension sold as a sale involves a transfer from one party to the other.  

## Proof of Concept
- add test code below to `/test/local/actions/SellCreditMarket.t.sol`
- run test with `forge test --mt test_SellCreditMarket_sellCreditMarket_When_Credit_Marked_Not_For_Sale  -vv`

```solidity

        function test_SellCreditMarket_sellCreditMarket_When_Credit_Marked_Not_For_Sale()
        public
    {
        _setPrice(1e18);
        _updateConfig("swapFeeAPR", 0.01e18);

        _deposit(alice, weth, 200e18);
        _deposit(bob, usdc, 800000000000);
        _deposit(candy, usdc, 200e6);

        //alice indicates that she wants to sell credit
        _sellCreditLimit(alice, YieldCurveHelper.pointCurve(365 days, 0.2e18));

        //bob takes alice credit
        uint256 debtPositionId = _buyCreditMarket(
            bob,
            alice,
            100e6,
            365 days,
            true
        );
        uint256 creditPositionId = size.getCreditPositionIdsByDebtPositionId(
            debtPositionId
        )[0];

        //make credit position to not be for sale
        uint256[] memory creditPosArray = new uint256[](1);
        creditPosArray[0] = creditPositionId;
        //bob decides to not sell his credit so he puts it off sale via config
        _setUserConfiguration(bob, 0, false, false, creditPosArray);

        assertEq(size.getCreditPosition(creditPositionId).credit, 120e6);

        //candy puts an order to buy credit
        _buyCreditLimit(
            candy,
            block.timestamp + 365 days,
            YieldCurveHelper.pointCurve(365 days, 0.03e18)
        );

        Vars memory _before = _state();

        //bob credit can still be sold, so bob's credit goes. what position goes away? need to check that the id
        //credit has been sent to candy, also check the forSale value of the position with candy. 
        _deposit(bob, size.data().underlyingCollateralToken, 200e18);
        assertEq(size.getCreditPosition(creditPositionId).forSale, false); //creditPosition is not for sale. 
        _sellCreditMarket(bob, candy, creditPositionId, 120e6, 365 days, true);

        assertEq(size.getCreditPosition(creditPositionId).lender, candy); //so the credit position is not for bob anymore
        assertEq(size.getCreditPosition(creditPositionId).forSale, false); //so it is still false, meaning a position not forSale has been sucessfully sold/transferred to candy.  
        
    }
```

## Recommended Mitigation Steps
add extra check like below to logic of `isCreditPositionTransferrable()` or `validateSellCreditMarket()` that checks if a creditPosition is marked for sale or not. 


```solidity
if (creditPosition.forSale == false) {
      revert Errors.NOT_TRANSFERRABLE_NOT_FOR_SALE();
}
```
