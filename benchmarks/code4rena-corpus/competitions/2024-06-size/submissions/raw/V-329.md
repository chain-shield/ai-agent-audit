# Vulnerability details

## Impact
Protocol does not receive any swap fees from the borrower when liquidation with replacement is being done.

## Proof of Concept
The purpose of `liquidateWithReplacement` is to liquidate a debt position and replace the borrower with a new one. During this action, the new borrower receives the `borrowAToken` according to the borrow offer.

In the [`LiquidateWithReplacement::executeLiquidateWithReplacement`](https://github.com/code-423n4/2024-06-size/blob/main/src/libraries/actions/LiquidateWithReplacement.sol#L146) function the `issuanceValue` is calculated which is the exact amount of `borrowAToken` that is transferred to the new borrower. This value is calculated as follows:
```solidity
issuanceValue = Math.mulDivDown(debtPositionCopy.futureValue, PERCENT, PERCENT + ratePerTenor);
...
state.data.borrowAToken.transferFrom(address(this), params.borrower, issuanceValue);
```

However, according to the [Size documention](https://docs.size.credit/technical-docs/governance-variables-and-fees#governance-variables-work-in-progress):
```
swapFeeAPR is charged to the recipient of USDC on cash->credit and credit->cash swaps.
```

Inside the `LiquidateWithReplacement::executeLiquidateWithReplacement` function, swap fees are not subtracted from the `issuanceValue`. This means that the borrower does not pay any swap fees during the borrower replacement, which contradicts the documentation stating that the borrower should pay these fees when USDC is received.

## Tools Used
Manual Review

## Recommended Mitigation Steps
Add the following line that correctly removes the swap fees from the `issuanceValue` before transferring it to the new borrower. This will ensure that the protocol receives the correct amount of swap fees and that the borrower pays them as intended.
```diff
  issuanceValue = Math.mulDivDown(debtPositionCopy.futureValue, PERCENT, PERCENT + ratePerTenor);
+ issuanceValue = issuanceValue - state.getSwapFee(issuanceValue, tenor);
  liquidatorProfitBorrowToken = debtPositionCopy.futureValue - issuanceValue;
```
