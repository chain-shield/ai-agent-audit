# Vulnerability details

## Impact
Malicious users can grief liquidator by replacing `borrowOffer` to null by calling `sellCreditLimit` again.

## Proof of Concept
`liquidateWithReplacement` fails and is reverted if `borrowOffer` is null.

Malicious users can create real offer which is not null, and then front run by liquidator to replace borrowOffer to null by calling `sellCreditLimit`.

As we can see in above code, `borrowOffer` can be replaced to new Yield Curve.

In result, liquidator will try to match null offer with liquidated debt position, so transaction will be reverted.
