# Vulnerability details

## Impact
Broke core invariant due to unknown users could transfer tokens that only address(this) should can. This issue could lead to unexpected behaviour from the contract like DoS

## Proof of Concept
Unknown users can easily call `Size::multicall` with data for transfering untransferable tokens from one user to another. The tokens transferFrom's onlyOwner check passes because of the msg.sender becomes address(this) while delegateCalling from `Size::multicall`(because Size make call to itself) 

## Tools Used

## Recommended Mitigation Steps
Add `state.data.isMulticall == true` check in transferFrom functions
