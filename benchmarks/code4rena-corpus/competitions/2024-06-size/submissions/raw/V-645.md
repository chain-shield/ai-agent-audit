# Vulnerability details

### Vulnerability Report for Size Protocol: Incorrect Validation of BuyCreditMarket

#### Summary

The Size protocol has a potential vulnerability in the `validateBuyCreditMarket` function that allows borrowers to act as lenders in the same transaction. This creates a scenario where only the protocols benefits.

#### Vulnerability Description

The function `validateBuyCreditMarket` does not properly enforce the distinction between borrowers and lenders. This allows a borrower to simultaneously find themselves as a lender in the same transaction, leading to potential mismanagement.

#### Affected Code

The vulnerability is present in the following function:

```solidity

/// @param state The state
/// @param params The input parameters for buying credit as a market order
function validateBuyCreditMarket(State storage state, BuyCreditMarketParams calldata params) external view {
...
}
```

#### Impact

Allowing borrowers to act as lenders in the same transaction undermines the economic incentives designed to benefit distinct roles within the protocol. This could lead to destabilization of the protocol, and unfair advantages for certain users.

#### Recommended Mitigation

Implement a check to ensure that a borrower cannot act as their own lender within the same transaction:

#### Conclusion

This vulnerability report highlights a critical issue in the Size protocol's validation logic for market orders. By ensuring that borrowers and lenders are distinct entities in transactions, the protocol can maintain its intended economic incentives and overall stability.
