# Vulnerability details

## Impact
buy credit market and sell credit market will not work if market Rate multiplier is non-zero and variablePoolBorrowRateStaleRateInterval is set to zero . 

## Proof of Concept
```
 uint256 apr = borrowOffer.getAPRByTenor(
            VariablePoolBorrowRateParams({
                variablePoolBorrowRate: state.oracle.variablePoolBorrowRate,
                variablePoolBorrowRateUpdatedAt: state.oracle.variablePoolBorrowRateUpdatedAt,
                variablePoolBorrowRateStaleRateInterval: state.oracle.variablePoolBorrowRateStaleRateInterval
            }),
            tenor
        );
```
```
 uint256 ratePerTenor = state.data.users[borrower].borrowOffer.getAPRByTenor(
            VariablePoolBorrowRateParams({
                variablePoolBorrowRate: state.oracle.variablePoolBorrowRate,
                variablePoolBorrowRateUpdatedAt: state.oracle.variablePoolBorrowRateUpdatedAt,
                variablePoolBorrowRateStaleRateInterval: state.oracle.variablePoolBorrowRateStaleRateInterval
            }),
            tenor

```
getAPRByTenor and getAPRByTenor are widely used in buy credit market and sell credit market . Both of them are fetched from getAdjustedAPR .
```
 function getAdjustedAPR(int256 apr, uint256 marketRateMultiplier, VariablePoolBorrowRateParams memory params)
        internal
        view
        returns (uint256)
    {
        if (marketRateMultiplier == 0) {
            return SafeCast.toUint256(apr);
        } else if (
            params.variablePoolBorrowRateStaleRateInterval == 0
                || (
                    block.timestamp - params.variablePoolBorrowRateUpdatedAt
                        > params.variablePoolBorrowRateStaleRateInterval
                )
        ) {
            revert Errors.STALE_RATE(params.variablePoolBorrowRateUpdatedAt);
        } else {
            return SafeCast.toUint256(
                apr + SafeCast.toInt256(Math.mulDivDown(params.variablePoolBorrowRate, marketRateMultiplier, PERCENT))
            );
        }
    }
```
If market rate mulitiplier is non-zero , borrow rate interval has to be non-zero .

Protocol didn't validate variablePoolBorrowRateStaleRateInterval in the initializing [phase](https://github.com/code-423n4/2024-06-size/blob/8850e25fb088898e9cf86f9be1c401ad155bea86/src/libraries/actions/Initialize.sol#L132-L142) . 

When updating config , protocol assume like that 
```
  /// @dev Validation is done at execution
    ///      We purposefuly leave this function empty for documentation purposes
    function validateUpdateConfig(State storage, UpdateConfigParams calldata) external pure {
        // validation is done at execution
    }
```

But when execute the variablePoolBorrowRateStaleRateInterval , there 's no [validation](https://github.com/code-423n4/2024-06-size/blob/8850e25fb088898e9cf86f9be1c401ad155bea86/src/libraries/actions/UpdateConfig.sol#L137-L138)
```
else if (Strings.equal(params.key, "variablePoolBorrowRateStaleRateInterval")) {
            state.oracle.variablePoolBorrowRateStaleRateInterval = uint64(params.value);
        }
```
default value of variablePoolBorrowRateStaleRateInterval is zero and if protocol didn't set that value , there will be DOS for buy credit market and sell credit market with non-zero market rate multiplier.

1.protocol team forget to set value in the initializing phase .
2.buy credit market and sell credit market with zero market rate will be fine .
3.protocol assume everything is fine however when it comes to non-zero market rate buy credit market and sell credit market , there will be DOS
