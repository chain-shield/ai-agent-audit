# Vulnerability details

## Impact
`NonTransferrableScaledToken` (borrowAToken) is very important in the protocol.
But unscaling is not so correct, so overall behavior of protocol will not work properly.

## Proof of Concept
`borrowAToken` will be minted and burned based on difference in balance of `Size` protocol in `Aave Lending pool`.
Unscaled balance is calculated from this scaled balance.
Code comment states 
`The unscaled amount is the scaled amount divided by the current liquidity index`.

```solidity
/// @notice Unscales a scaled amount
    /// @param scaledAmount The scaled amount to unscale
    /// @return The unscaled amount
@>  /// @dev The unscaled amount is the scaled amount divided by the current liquidity index
    function _unscale(uint256 scaledAmount) internal view returns (uint256) {
@>      return Math.mulDivDown(scaledAmount, liquidityIndex(), WadRayMath.RAY);
    }


    /// @notice Returns the current liquidity index of the variable pool
    /// @return The current liquidity index of the variable pool
    function liquidityIndex() public view returns (uint256) {
        return variablePool.getReserveNormalizedIncome(address(underlyingToken));
    }

```
However, 'Unscaled Balance' does not match the code comment.
Unscaled Balance is the scaled amount multiplied by the liquidity index, as you can see in the calculation.
