# Vulnerability details

## Impact

Pausing liquidation functions can result in unliquidated bad debt.

## Proof of Concept

### Scenario:
1. A user deposits 1 WETH (assuming WETH is worth $3000).
2. The user then borrows 1900 USDC, resulting in a health factor of 1.57.
3. The protocol is paused by the pauser for some reason.
4. The value of WETH drops to $2000.
5. The user's health factor falls to 1.05, which is below the liquidation threshold of 1.30. However, since the protocol is paused, no one can liquidate the user's position.

## Tools Used

Manual Review

## Recommended Mitigation Steps

Ensure that liquidation functions remain operational even when the protocol is paused.
