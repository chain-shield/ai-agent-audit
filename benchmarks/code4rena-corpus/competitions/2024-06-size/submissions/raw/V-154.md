# Vulnerability details

The protocol is not implementing partial liquidations but it is implementing a mechanics that allow split a position, we can see this in the `compensate` function , this can be used to behave like a partial liquidation because the debt position can be split it.

The problem is that this function is up to the borrower so he decide if he does the split or not, so if a borrower is not splitting the debtPosition maybe because is not worth any more. The credit position stay there unable to get liquidate because the loan is so big.

## Impact
Inability to perform partial liquidations allows huge positions to does not get liquidate  which mean loses to the big liquidity providers.
