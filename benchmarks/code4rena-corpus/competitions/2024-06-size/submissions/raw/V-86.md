# Vulnerability details

## Impact
Storage of Size could be corrupted during an upgrade.

## Proof of Concept
In the `SizeStorage` contract, a single `State` storage struct holds all the data, composed of multiple nested structs. However, no gap storage is implemented between these nested structs. 

This design can result in significant issues when attempting to add new storage variables in the future, as new variables will override existing ones, leading to data corruption.

Appending new variables to the `State` struct is not a viable solution due to the complexity it introduces in managing and updating logic codes. This limitation highlights a significant design issue, as the inability to add new variables in nested structs impacts the protocol's upgradeability.

vscode

## Recommended Mitigation Steps
Add resvered storage gaps between each nested struct.
