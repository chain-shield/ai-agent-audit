# Vulnerability details

## Impact
Core function DoS

## Proof of Concept
1. When user execute `Size::sellCreditMarket` with params.exactAmountIn = false, it means that user wants to receive params.amount amount of `cash` for credit. 
2. Through the execution of `BuyCreditMarket::validateBuyCreditMarket` params.amount is validated as function reverts if `params.amount < state.riskConfig.minimumCreditBorrowAToken`, no matter params.exactAmountIn's value.

Finally from 1. and 2. we can assume that there is possible scenario where user can call `Size::sellCreditMarket` with `exactAmountIn = false` and `amount < minimumCreditBorrowAToken(while creditIn > minimumCreditBorrowAToken)`, then the function is going to revert no matter if actual creditIn is greather than `state.riskConfig.minimumCreditBorrowAToken`
