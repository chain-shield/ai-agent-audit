# Vulnerability details

## Bug Description 
![3307DF49-DF7E-4952-805E-7BFB9925CB9F_4_5005_c](https://github.com/adeolu98/audits-draft/assets/39372980/9de4f218-9258-486e-b15f-c9d1b3237739)

According to the aave docs, see [here](https://docs.aave.com/developers/core-contracts/pooladdressesprovider), the pool address should not be hardcoded, and instead the PoolAddressProvider contract should be queried EVERYTIME to provide the current pool address. This is because **if the pool contract is to be migrated to a new address**, it will break the Size protocol contract and force a redeploy/upgrade/change of implementation as the address is set once via `executeInitializeData()` as seen [here](https://github.com/code-423n4/2024-06-size/blob/8850e25fb088898e9cf86f9be1c401ad155bea86/src/libraries/actions/Initialize.sol#L237) and there is no way to change the set aave pool adddress in storage.

The PoolAddressProvider contract never changes and will always provide the latest pool address when queried.

in the `PoolAddressProvider`, there is a function that allows the AAVE admins to change the POOL address returned by [PoolAddressProvider.getPool()](https://github.com/aave/aave-v3-core/blob/6070e82d962d9b12835c88e68210d0e63f08d035/contracts/protocol/configuration/PoolAddressesProvider.sol#L75) at any time. see [here](https://github.com/aave/aave-v3-core/blob/6070e82d962d9b12835c88e68210d0e63f08d035/contracts/protocol/configuration/PoolAddressesProvider.sol#L57)

The current implementation in Size goes against the aave integration recommendations, as it is not fetched whenever needed but instead set once and can never be updated in the case of a change. 


# Impact
Aave pools not integrated correctly, aave pool address hardcoded which is against aave pool integration guidelines. Aave pool update to a different address will force redeploy/upgrade Size inplementation contract. 

## Tools used 
manual review 

## Recommended Mitigation
always get the pool address from the aave pool address provider contract before every call to the pool.
