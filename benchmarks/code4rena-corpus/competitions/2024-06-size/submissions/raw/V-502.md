# Vulnerability details

## Impact
```executeLiquidate()``` uses ```getDebtPositionAssignedCollateral(debtPosition)``` to get the assignedCollateral of a ```debtPosition``` from the borrower total collateral.

The issue with this is that the function get ```assignedCollateral``` based on the loan future value which includes loan interest, not taking note of the fact that borrower would have different loans from different lenders at different interest rate, so loans with lower interest rate will get lower shares of borrower collateral.

This could make liquidation of some loans unprofitable, leaving the lender to call ```selfLiquidate``` and protocol also loses liquidation fee.

## Proof of Concept
Consider Alice a borrower with two different debt positions.
First debt from Bob loan offer of $100 @50%/year, 
debtToken minted to Alice = 150(futureValue)

Second debt was from a loan offer Alice created with another account with APR of 300%/year(since there is no cap for APR except by ```SellCreditMarketParams.maxApr``` which will be set higher by Alice when selling credit)
debtToken minted to Alice = 400(for the same $100 loan and same duration)

Total collateral value = 1.3 * (150 + 400) =715 @ the time of borrow.

If collateral value crash to below 540(<100% debtPosition of Alice), both position becomes due for liquidation but won't be liquidated since it is not profitable.

For the first loan, assigned collateral = 150/550 * 540 = 147
While the assigned collateral for the decoy position = 400/550 * 540 = 392

Alice can then self liquidate the decoy credit position and get $392 worth of collateral while the credit owner of the first loan is left with no choice but to self liquidate(protocol loses what would have been liquidation fee)

Ideally, both positions should have equal amount of collateral assigned to them since the actual loaned amount is the same.
```solidity
    function getDebtPositionAssignedCollateral(State storage state, DebtPosition memory debtPosition)
        public
        view
        returns (uint256)
    {
        uint256 debt = state.data.debtToken.balanceOf(debtPosition.borrower);
        uint256 collateral = state.data.collateralToken.balanceOf(debtPosition.borrower);

        if (debt != 0) {
            return Math.mulDivDown(collateral, debtPosition.futureValue, debt);
        } else {
            return 0;
        }
    }
```
