# Vulnerability details

## Vulnerability details
Function `repay()` is used to repay debt:

    function repay(RepayParams calldata params) external payable override(ISize) whenNotPaused {
        state.validateRepay(params);
        state.executeRepay(params);
    }
Note that it have `whenNotPaused` modifier, which mean protocol is paused, user are not able to repay, which can lead to debt position is overdue after unpause, and lead to liquidated

## Impact
User's position can be liquidated due to overdue after pause

## Tools Used
Manual review.

## Recommended Mitigation Steps
Remove `whenNotPaused` modifier.
