# Vulnerability details

## Impact
If at some point the protocol needs to add some variables to `Size.sol`, it can't because of the absence of storage gap

## Proof of Concept
With the absence of storage gap, after the first upgrade that adds a new variable to `Size.sol`, the storage slots can get mixed up, which may DoS the whole new functionality that has been added via upgradability

## Tools Used
manual review
## Recommended Mitigation Steps
add storage gaps


## Assessed type

Upgradable
