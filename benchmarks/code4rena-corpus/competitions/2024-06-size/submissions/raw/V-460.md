# Vulnerability details

## Impact
An existing creditPosition can be bought by a user even though the remaining `tenor` of that creditPosition is greater than the `maxDueDate` mentioned by the user in their `LoanOffer`.

## Proof of Concept

When an existing creditPosition is getting transferred to a new lender, that creditPosition position is assigned without checking the `maxDueDate` of the `LoanOffer` the  new lender has mentioned.
