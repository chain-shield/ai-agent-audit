# Vulnerability details

## Impact
The executeUpdateConfig function in the protocol's configuration update logic contains an incorrect validation logic when updating the crLiquidation parameter. The current check ensures that the new crLiquidation value must be greater than or equal to the existing crLiquidation value, which is not the intended behavior. 
- According to the protocol's documentation, crLiquidation should always be less than crOpening to ensure proper risk management.
