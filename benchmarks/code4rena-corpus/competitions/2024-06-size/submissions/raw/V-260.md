# Vulnerability details

## Summary

The Size protocol facilitates the transfer of credit positions, which are crucial to its lending and borrowing system. However, the `validateSellCreditMarket` function within the `SellCreditMarket` library lacks thorough validation in its transfer logic. This inadequacy can permit the transfer of credit positions that should be restricted due to various conditions, possibly leading to financial losses and systemic risk.

## Vulnerability Detail

The `validateSellCreditMarket` function is responsible for verifying the parameters when selling credit as a market order. While it performs checks for the lender, credit position ID, amount, tenor, deadline, and max APR, it does not comprehensively cover all scenarios that could make a credit position non-transferable. Specifically, the function misses robust checks for:

1. **Credit position transferability**: The current implementation only checks if a position is transferable based on the loan status and borrower collateral ratio. This approach is insufficient for scenarios where other factors might affect transferability. For example, a credit position associated with a borrower who has recently entered a grace period for repayment should not be transferable, as it poses a risk of immediate default post-transfer.

2. **Collateral ratio**: The function does not ensure that the collateral ratio of the borrower remains adequate after the transfer. For instance, if a borrower's collateral ratio is already borderline, transferring a significant portion of their credit could push them below the minimum collateral ratio, leading to forced liquidation.

3. **Loan health**: Transfers should be blocked if the loan associated with the credit position is near liquidation thresholds. E.g., if a loan is approaching its due date and the borrower is struggling to meet the repayment, transferring this credit position could leave the new lender with a higher risk of default and insufficient collateral coverage.

Key points in the code:

- The `validateSellCreditMarket` function calls `isCreditPositionTransferrable` but does not account for additional conditions.
- Insufficient validation can lead to the transfer of at-risk credit positions, which could compromise the protocol’s stability.

```solidity
function validateSellCreditMarket(State storage state, SellCreditMarketParams calldata params) external view {
    LoanOffer memory loanOffer = state.data.users[params.lender].loanOffer;
    uint256 tenor;

    if (loanOffer.isNull()) {
        revert Errors.INVALID_LOAN_OFFER(params.lender);
    }

    if (params.creditPositionId == RESERVED_ID) {
        tenor = params.tenor;
        if (tenor < state.riskConfig.minTenor || tenor > state.riskConfig.maxTenor) {
            revert Errors.TENOR_OUT_OF_RANGE(tenor, state.riskConfig.minTenor, state.riskConfig.maxTenor);
        }
    } else {
        CreditPosition storage creditPosition = state.getCreditPosition(params.creditPositionId);
        DebtPosition storage debtPosition = state.getDebtPositionByCreditPositionId(params.creditPositionId);
        if (msg.sender != creditPosition.lender) {
            revert Errors.BORROWER_IS_NOT_LENDER(msg.sender, creditPosition.lender);
        }
        if (!state.isCreditPositionTransferrable(params.creditPositionId)) {
            revert Errors.CREDIT_POSITION_NOT_TRANSFERRABLE(
                params.creditPositionId,
                state.getLoanStatus(params.creditPositionId),
                state.collateralRatio(debtPosition.borrower)
            );
        }
        tenor = debtPosition.dueDate - block.timestamp;
        if (params.amount > creditPosition.credit) {
            revert Errors.NOT_ENOUGH_CREDIT(params.amount, creditPosition.credit);
        }
    }

    if (params.amount < state.riskConfig.minimumCreditBorrowAToken) {
        revert Errors.CREDIT_LOWER_THAN_MINIMUM_CREDIT(params.amount, state.riskConfig.minimumCreditBorrowAToken);
    }

    if (block.timestamp + tenor > loanOffer.maxDueDate) {
        revert Errors.DUE_DATE_GREATER_THAN_MAX_DUE_DATE(block.timestamp + tenor, loanOffer.maxDueDate);
    }

    if (params.deadline < block.timestamp) {
        revert Errors.PAST_DEADLINE(params.deadline);
    }

    uint256 apr = loanOffer.getAPRByTenor(
        VariablePoolBorrowRateParams({
            variablePoolBorrowRate: state.oracle.variablePoolBorrowRate,
            variablePoolBorrowRateUpdatedAt: state.oracle.variablePoolBorrowRateUpdatedAt,
            variablePoolBorrowRateStaleRateInterval: state.oracle.variablePoolBorrowRateStaleRateInterval
        }),
        tenor
    );
    if (apr > params.maxAPR) {
        revert Errors.APR_GREATER_THAN_MAX_APR(apr, params.maxAPR);
    }
}
```

Specifically, the current implementation of the `validateSellCreditMarket` doesn't:

- Verify if the borrower's updated collateral ratio remains above the liquidation threshold post-transfer.
- Ensure that the loan associated with the credit position is not near liquidation.
- Prevent the transfer of credit positions if the borrower's repayment ability is already compromised.

## Impact

Unchecked transfers can lead to situations where at-risk loans are transferred, increasing the likelihood of defaults and subsequent financial losses. Furthermore, the protocol's stability could be compromised if large volumes of at-risk credit positions are transferred, leading to a cascade of liquidations and losses.

## Recommended Mitigation Steps

To enhance the security and stability of the `validateSellCreditMarket` function, it's essential to implement more comprehensive checks to cover scenarios that can make a credit position non-transferable. In the below impl, we ensure that the function validates not only the loan status and borrower collateral ratio but also other critical factors like the updated collateral ratio post-transfer and the overall health of the loan. Here’s how the code should look after implementing these changes:

```solidity
function validateSellCreditMarket(State storage state, SellCreditMarketParams calldata params) external view {
    LoanOffer memory loanOffer = state.data.users[params.lender].loanOffer;
    uint256 tenor;

    if (loanOffer.isNull()) {
        revert Errors.INVALID_LOAN_OFFER(params.lender);
    }

    if (params.creditPositionId == RESERVED_ID) {
        tenor = params.tenor;
        if (tenor < state.riskConfig.minTenor || tenor > state.riskConfig.maxTenor) {
            revert Errors.TENOR_OUT_OF_RANGE(tenor, state.riskConfig.minTenor, state.riskConfig.maxTenor);
        }
    } else {
        CreditPosition storage creditPosition = state.getCreditPosition(params.creditPositionId);
        DebtPosition storage debtPosition = state.getDebtPositionByCreditPositionId(params.creditPositionId);
        if (msg.sender != creditPosition.lender) {
            revert Errors.BORROWER_IS_NOT_LENDER(msg.sender, creditPosition.lender);
        }
        if (!state.isCreditPositionTransferrable(params.creditPositionId)) {
            revert Errors.CREDIT_POSITION_NOT_TRANSFERRABLE(
                params.creditPositionId,
                state.getLoanStatus(params.creditPositionId),
                state.collateralRatio(debtPosition.borrower)
            );
        }
        tenor = debtPosition.dueDate - block.timestamp;
        if (params.amount > creditPosition.credit) {
            revert Errors.NOT_ENOUGH_CREDIT(params.amount, creditPosition.credit);
        }

        // Ensure the collateral ratio remains adequate post-transfer
        uint256 updatedCollateralRatio = state.collateralRatio(debtPosition.borrower);
        if (updatedCollateralRatio < state.riskConfig.crLiquidation) {
            revert Errors.USER_IS_UNDERWATER(debtPosition.borrower, updatedCollateralRatio);
        }

        // Prevent transfer if the loan is near liquidation thresholds
        if (tenor < state.riskConfig.minTenor || state.getLoanStatus(params.creditPositionId) == LoanStatus.OVERDUE) {
            revert Errors.LOAN_NEAR_LIQUIDATION(params.creditPositionId);
        }
    }

    if (params.amount < state.riskConfig.minimumCreditBorrowAToken) {
        revert Errors.CREDIT_LOWER_THAN_MINIMUM_CREDIT(params.amount, state.riskConfig.minimumCreditBorrowAToken);
    }

    if (block.timestamp + tenor > loanOffer.maxDueDate) {
        revert Errors.DUE_DATE_GREATER_THAN_MAX_DUE_DATE(block.timestamp + tenor, loanOffer.maxDueDate);
    }

    if (params.deadline < block.timestamp) {
        revert Errors.PAST_DEADLINE(params.deadline);
    }

    uint256 apr = loanOffer.getAPRByTenor(
        VariablePoolBorrowRateParams({
            variablePoolBorrowRate: state.oracle.variablePoolBorrowRate,
            variablePoolBorrowRateUpdatedAt: state.oracle.variablePoolBorrowRateUpdatedAt,
            variablePoolBorrowRateStaleRateInterval: state.oracle.variablePoolBorrowRateStaleRateInterval
        }),
        tenor
    );
    if (apr > params.maxAPR) {
        revert Errors.APR_GREATER_THAN_MAX_APR(apr, params.maxAPR);
    }
}
```
