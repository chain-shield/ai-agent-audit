# Vulnerability details

## Impact
The `getPrice` function in `PriceFeed` is using `Math.mulDivDown` which can lead to precision loss due to truncation and rounding down logic, especially when dealing with prices. Rounding errors in Solidity can significantly impact the accuracy of values, especially in financial applications where precision is paramount. When performing integer division in Solidity, the result may be truncated, leading to a loss in precision. This is because Solidity does not support floating-point arithmetic natively, and operations like division can result in fractional parts being discarded.
