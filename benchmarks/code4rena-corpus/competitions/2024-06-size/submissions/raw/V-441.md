# Vulnerability details

## Impact
The protocol allows lenders to exit their privileged loan positions in favor of another lender. This is a cool feature of the protocol that allows lenders to get paid early instead of waiting for loan maturity. The problem is that the protocol also requires the exiting lender to have a valid BorrowOffer. See src/libraries/actions/BuyCreditMarket.sol::Ln79-80

```solidity
borrower = creditPosition.lender;
            tenor = debtPosition.dueDate - block.timestamp; // positive since the credit position is transferrable, so the loan must be ACTIVE

```
and src/libraries/actions/BuyCreditMarket.sol::Ln86-87

```solidity
// validate borrower
if (borrowOffer.isNull()) {
   revert Errors.INVALID_BORROW_OFFER(borrower);
}
```
This is a huge downside to lenders since it means that **only** lenders who're willing to be borrowers can benefit from the provision.  
## Proof of Concept
Consider this scenario: 
1. Lender Alice has a loan with Bob.
2. James is interested in taking over Alice position and pay her immediately to exit her loan position.
3. James tries to make an offer but is unable.

This test shows that lenders without valid BorrowOffr positions cannot exit early:

```solidity
function test_BuyCreditMarket_needs_borrow_offer() public {
        _deposit(alice, usdc, 100e6);
        _deposit(candy, weth, 100e18);
        _deposit(james, usdc, 100e6);
        _sellCreditLimit(candy, 0.03e18, 10 days);
        uint256 debtPositionId = _buyCreditMarket(alice, candy, RESERVED_ID, 40e6, 10 days, false);

        uint256 deadline = block.timestamp;
        uint256 amount = 50e6;
        uint256 tenor = 10 days;
        bool exactAmountIn = false;

        vm.startPrank(james);

        uint256 creditPositionId = size.getCreditPositionIdsByDebtPositionId(debtPositionId)[0];
        vm.expectRevert(abi.encodeWithSelector(Errors.INVALID_BORROW_OFFER.selector, alice));
        size.buyCreditMarket(
            BuyCreditMarketParams({
                borrower: address(0),
                creditPositionId: creditPositionId,
                amount: 20e6,
                tenor: type(uint256).max,
                deadline: deadline,
                minAPR: 0,
                exactAmountIn: exactAmountIn
            })
        );
    }
    
```

## Recommended Mitigation Steps
Remove the restriction that lenders must have valid BorrowOffers in order to exit early
