# Vulnerability details

Borrower can take the accrued Interest from the AAVE pool which is deserved by the thelender.

## Impact
Detailed description of the impact of this finding.

## Proof of Concept

After the borrower amount is received via borrowATokens , a borrower  can withdraw USDC/underlyingBorrowToken from the AAVE POOL .

In the `withdrawUnderlyingTokenFromVariablePool()` we are withdrawing the USDC by calling `variablePool.withdraw(address(state.data.underlyingBorrowToken), amount, to)`

https://github.com/code-423n4/2024-06-size/blob/8850e25fb088898e9cf86f9be1c401ad155bea86/src/libraries/DepositTokenLibrary.sol#L74-L87
```solidity
    function withdrawUnderlyingTokenFromVariablePool(State storage state, address from, address to, uint256 amount)
        external
    {
        IAToken aToken =
            IAToken(state.data.variablePool.getReserveData(address(state.data.underlyingBorrowToken)).aTokenAddress);
        uint256 scaledBalanceBefore = aToken.scaledBalanceOf(address(this));

        // slither-disable-next-line unused-return
=>        state.data.variablePool.withdraw(address(state.data.underlyingBorrowToken), amount, to);

        uint256 scaledAmount = scaledBalanceBefore - aToken.scaledBalanceOf(address(this));

        state.data.borrowAToken.burnScaled(from, scaledAmount);
    }
```
From the AAVE docs , 
> "withdraw()
function withdraw(address asset, uint256 amount, address to)
Withdraws amount of the underlying asset, i.e. redeems the underlying token and burns the aTokens."



So the borrowers will receive the accrued interest also while withdrawing and they can use the accrued interest for paying the credit. 
At the same time accrued interest received by the depositors/lenders will be lesser than they deserve.
