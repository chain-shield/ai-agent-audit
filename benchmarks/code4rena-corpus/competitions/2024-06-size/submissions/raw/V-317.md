# Vulnerability details

## Impact
The function validateMinimumCollateralProfit can fail user expectations when users fail to provide sufficient input. This is because the function does not check that the liquidator has actually provided a value for params.minimumCollateralProfit, meaning that the default value of 0 is accepted.

```solidity
function validateMinimumCollateralProfit(
        State storage,
        LiquidateParams calldata params,
        uint256 liquidatorProfitCollateralToken
    ) external pure {
        if (liquidatorProfitCollateralToken < params.minimumCollateralProfit) {
            revert Errors.LIQUIDATE_PROFIT_BELOW_MINIMUM_COLLATERAL_PROFIT(
                liquidatorProfitCollateralToken, params.minimumCollateralProfit
            );
        }
    }
```
## Proof of Concept
Bob, wishing to liquidate Alice's illiquid position calls `size.liquidate` and specifies Alice's position. However, he does not provide a value for minimumCollateralProfit. While the transaction is in the mempool, the price of ETH in terms of USDC falls, making the call unprofitable. The transaction will still go through and Bob will endup  settling a loss-making position.

Consider this POC:
```solidity
function test_Liquidate_zero_min_profit() public {
        _setPrice(1e18);

        _deposit(alice, weth, 100e18);
        _deposit(alice, usdc, 100e6);
        _deposit(bob, weth, 100e18);
        _deposit(bob, usdc, 100e6);
        _deposit(liquidator, weth, 100e18);
        _deposit(liquidator, weth, 100e18);

        _buyCreditLimit(alice, block.timestamp + 365 days, YieldCurveHelper.pointCurve(365 days, 0.03e18));
        uint256 debtPositionId = _sellCreditMarket(bob, alice, RESERVED_ID, 15e6, 365 days, false);

        _setPrice(0.2e18);

        assertTrue(size.isDebtPositionLiquidatable(debtPositionId));
        assertEq(size.getLoanStatus(debtPositionId), LoanStatus.ACTIVE);

        vm.expectRevert();
        _liquidate(liquidator, debtPositionId);

        assertEq(size.getLoanStatus(debtPositionId), LoanStatus.ACTIVE);
    }
```

## Recommended Mitigation Steps
Add a check that user has provided a value for params.minimumCollateralProfit
```solidity
if (params.minimumCollateralProfit == 0) {
   revert Errors.ZERO_MIN_LIQUIDATION_PROFIT_VALUE(params.value);
}
