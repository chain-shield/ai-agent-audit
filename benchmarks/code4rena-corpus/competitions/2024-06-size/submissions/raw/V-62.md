# Vulnerability details

## Impact
`getDebtPositionAssignedCollateral` calculates the amount of collateral assigned to a specific `DebtPosition` based on the borrower's total debt and collateral. However, it does not consider the case where the borrower might have multiple `DebtPositions`. If a borrower has multiple `DebtPositions`, the function will assign the same collateral to each `DebtPosition` proportionally based on their `futureValue`. This means that the total assigned collateral across all `DebtPositions` of the borrower might exceed the borrower's actual collateral balance.

## Proof of Concept
The `getDebtPositionAssignedCollateral` calculates the assigned collateral for a specific `DebtPosition` based on the borrower's total debt and collateral.

```solidity

        public
        view

    {
        uint256 debt = state.data.debtToken.balanceOf(debtPosition.borrower);
        uint256 collateral = state.data.collateralToken.balanceOf(debtPosition.borrower);


        if (debt != 0) {
            return Math.mulDivDown(collateral, debtPosition.futureValue, debt);
        } else {
            return 0;
        }

```
However, suppose a borrower has multiple `DebtPositions`. In that case, the function assigns the same collateral to each `DebtPosition` proportionally based on their `futureValue`, potentially leading to the total assigned collateral exceeding the borrower's actual collateral balance.

Let's consider a scenario where a borrower has two `DebtPositions`
    - `DebtPosition` 1: `futureValue` = 1000
    - `DebtPosition` 2: `futureValue` = 2000
    - Borrower's total debt: 3000
    - Borrower's collateral balance: 1500

Using the current implementation of `getDebtPositionAssignedCollateral`, the assigned collateral for each `DebtPosition` would be
    - `DebtPosition` 1: `assignedCollateral` = 1500 * 1000 / 3000 = 500
    - `DebtPosition` 2: `assignedCollateral` = 1500 * 2000 / 3000 = 1000

The total assigned collateral across both `DebtPositions` would be 1500, which matches the borrower's actual collateral balance. However, this is incorrect because each `DebtPosition` is assigned collateral independently, leading to the total assigned collateral exceeding the borrower's actual collateral balance.

## Recommended Mitigation Steps
Consider the total `futureValue` of all `DebtPositions` of the borrower and calculate the assigned collateral proportionally based on that total `futureValue`.
```solidity
function getDebtPositionAssignedCollateral(State storage state, DebtPosition memory debtPosition)
    public
    view
    returns (uint256)
{
    uint256 totalDebt = state.data.debtToken.balanceOf(debtPosition.borrower);
    uint256 totalFutureValue = state.getTotalFutureValueForBorrower(debtPosition.borrower);
    uint256 collateral = state.data.collateralToken.balanceOf(debtPosition.borrower);

    if (totalFutureValue != 0) {
        return Math.mulDivDown(collateral, debtPosition.futureValue, totalFutureValue);
    } else {
        return 0;
    }
}
```
We first calculate the total `futureValue` of all `DebtPositions` for the borrower using a new function `getTotalFutureValueForBorrower`. Then, we calculate the assigned collateral based on the proportion of the specific `DebtPosition`'s futureValue to the total `futureValue`.

Or 

The proposed solution introduces a new function, `getTotalFutureValueForBorrower,` to calculate a borrower's total `futureValue` of all `DebtPositions`. The assigned collateral is then calculated based on the proportion of the specific `DebtPosition`'s `futureValue` to the total `futureValue`.
```solidity
function getTotalFutureValueForBorrower(State storage state, address borrower) internal view returns (uint256) {
    uint256 totalFutureValue = 0;
    for (uint256 i = DEBT_POSITION_ID_START; i < state.data.nextDebtPositionId; i++) {
        DebtPosition memory debtPosition = state.data.debtPositions[i];
        if (debtPosition.borrower == borrower) {
            totalFutureValue += debtPosition.futureValue;
        }
    }
    return totalFutureValue;
}
```
With this modification, the assigned collateral for each `DebtPosition` would be
    - `DebtPosition` 1: `assignedCollateral` = 1500 * 1000 / (1000 + 2000) = 500
    - `DebtPosition` 2: `assignedCollateral` = 1500 * 2000 / (1000 + 2000) = 1000

The total assigned collateral across both `DebtPositions` would be 1500, which matches the borrower's actual collateral balance.
