# Vulnerability details

## Impact
When closing a debtor position via liquidation, the protocol expects the liquidator to settle the full future amount of the loan. This expectation might render the protocol at risk of bad-debt when the position involved is a huge  amount where only a small number of whale accounts can close.  

## Proof of Concept
Consider this scenario: A corporation has taken a loan worth 10M USDC and the account is now underwater. The protocol now enters into a race to close the position ASAP to avoid bad-debts.Assume that only a small number of accounts is ready/willing to settle the position. This means that the position will remain unsettled until closed.

For simplicity, consider this POC where a liquidator without enough funds attempts to close a position:

```solidity
function test_Liquidate_low_balance() public {
        _setPrice(1e18);

        _deposit(alice, weth, 100e18);
        _deposit(alice, usdc, 100e6);
        _deposit(bob, weth, 100e18);
        _deposit(bob, usdc, 100e6);
        _deposit(liquidator, weth, 100e18);

        _buyCreditLimit(alice, block.timestamp + 365 days, YieldCurveHelper.pointCurve(365 days, 0.03e18));
        uint256 debtPositionId = _sellCreditMarket(bob, alice, RESERVED_ID, 15e6, 365 days, false);

        _setPrice(0.2e18);

        assertTrue(size.isDebtPositionLiquidatable(debtPositionId));
        assertEq(size.getLoanStatus(debtPositionId), LoanStatus.ACTIVE);

        vm.expectRevert();
        _liquidate(liquidator, debtPositionId);

        assertEq(size.getLoanStatus(debtPositionId), LoanStatus.ACTIVE);
    }
```
