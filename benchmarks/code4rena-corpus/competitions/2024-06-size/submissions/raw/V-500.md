# Vulnerability details


## Summary

When a borrower wants to `repay` their debt, the repay function expects full repayment. For partial repayment, the borrower can use the `compensate` function to split the debt. However, this feature is unavailable for debt positions with less than 1 hour remaining until the due date, which limits borrower options unnecessarily.

## Description

To split a debt, a borrower can call `size.compensate(...)` with a special `creditPositionToCompensateId` : `RESERVED_ID`. This triggers the following code in `validateCompensate`:

[https://github.com/code-423n4/2024-06-size/blob/8850e25fb088898e9cf86f9be1c401ad155bea86/src/libraries/actions/Compensate.sol#L56-L62](https://github.com/code-423n4/2024-06-size/blob/8850e25fb088898e9cf86f9be1c401ad155bea86/src/libraries/actions/Compensate.sol#L56-L62)

```sol
if (params.creditPositionToCompensateId == RESERVED_ID) {
            uint256 tenor = debtPositionToRepay.dueDate - block.timestamp;

            // validate tenor
            if (tenor < state.riskConfig.minTenor || tenor > state.riskConfig.maxTenor) {
                revert Errors.TENOR_OUT_OF_RANGE(tenor, state.riskConfig.minTenor, state.riskConfig.maxTenor);
            }
        }
```

This sets the tenor of the new split debt to the time remaining until the `dueDate` and checks if this tenor is greater than `state.riskConfig.minTenor`, which is set to `1 hour`. Consequently, borrowers with less than 1 hour until their due date cannot split their debt.

## Impact 

During periods of high blockchain activity, such as a bull run, the prices of USDC and WETH can fluctuate significantly, particularly WETH. Historical data shows:

    USDC max price: 1.0156 (+1.56%)
    USDC min price: 0.9912 (-0.88%)
    ETH max drawdown in 1 hour: -11.4% (05/05/2024: 19:00 UTC)

If a borrower wants to repay part of their debt to avoid liquidation during such fluctuations, they are unable to do so if the remaining time is less than 1 hour. This restriction serves no purpose and hinders borrowers from managing their debt effectively.

## Recommendation

Remove the tenor validation checks for splitting debt positions with less than 1 hour remaining. Debt positions with a tenor less than `state.riskConfig.maxTenor` should be able to split and partially repay their positions.

```diff
if (params.creditPositionToCompensateId == RESERVED_ID) {
        uint256 tenor = debtPositionToRepay.dueDate - block.timestamp;

-        // validate tenor
-        if (tenor < state.riskConfig.minTenor || tenor > state.riskConfig.maxTenor) {
-            revert Errors.TENOR_OUT_OF_RANGE(tenor, state.riskConfig.minTenor, state.riskConfig.maxTenor);
        }
    }
```
By making this adjustment, borrowers will be able to compensate and partially repay their debt even when there is less than 1 hour remaining until the due date.
