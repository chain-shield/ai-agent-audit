# Vulnerability details

## Impact
`depositUnderlyingBorrowTokenToVariablePool` function is responsible for depositing the underlying borrow token (e.g., USDC) into the Aave variable pool and minting the corresponding `borrowAToken` (e.g., aUSDC) to the specified `to` address.

However, bug in the function is that it directly mints the `borrowAToken` using the `scaledAmount` obtained from the Aave pool, without considering the exchange rate between the `underlyingBorrowToken` and the `borrowAToken`.

1. The function first transfers the `underlyingBorrowToken` from the `from` address to the contract: [DepositTokenLibrary.sol#L52](https://github.com/code-423n4/2024-06-size/blob/8850e25fb088898e9cf86f9be1c401ad155bea86/src/libraries/DepositTokenLibrary.sol#L52)
```solidity
state.data.underlyingBorrowToken.safeTransferFrom(from, address(this), amount);
```

2. It then retrieves the `aToken` address from the Aave variable pool: [DepositTokenLibrary.sol#L54-L55](https://github.com/code-423n4/2024-06-size/blob/8850e25fb088898e9cf86f9be1c401ad155bea86/src/libraries/DepositTokenLibrary.sol#L54-L55)
```solidity
IAToken aToken =
    IAToken(state.data.variablePool.getReserveData(address(state.data.underlyingBorrowToken)).aTokenAddress);
```

3. The function records the scaled balance of the contract before the deposit: [DepositTokenLibrary.sol#L80](https://github.com/code-423n4/2024-06-size/blob/8850e25fb088898e9cf86f9be1c401ad155bea86/src/libraries/DepositTokenLibrary.sol#L80)
```solidity
uint256 scaledBalanceBefore = aToken.scaledBalanceOf(address(this));
```

4. It approves the Aave variable pool to transfer the `underlyingBorrowToken` and supplies it to the pool: [DepositTokenLibrary.sol#L59-L60](https://github.com/code-423n4/2024-06-size/blob/8850e25fb088898e9cf86f9be1c401ad155bea86/src/libraries/DepositTokenLibrary.sol#L59-L60)
```solidity
state.data.underlyingBorrowToken.forceApprove(address(state.data.variablePool), amount);
state.data.variablePool.supply(address(state.data.underlyingBorrowToken), amount, address(this), 0);
```

5. The function calculates the `scaledAmount` by subtracting the previous scaled balance from the current scaled balance: [DepositTokenLibrary.sol#L62](https://github.com/code-423n4/2024-06-size/blob/8850e25fb088898e9cf86f9be1c401ad155bea86/src/libraries/DepositTokenLibrary.sol#L62)
```solidity
uint256 scaledAmount = aToken.scaledBalanceOf(address(this)) - scaledBalanceBefore; 
```

6. Finally, it mints the `borrowAToken` to the to address using the scaledAmount: [DepositTokenLibrary.sol#L64](https://github.com/code-423n4/2024-06-size/blob/8850e25fb088898e9cf86f9be1c401ad155bea86/src/libraries/DepositTokenLibrary.sol#L64)
```solidity
state.data.borrowAToken.mintScaled(to, scaledAmount);
```
The issue is in step 6, where the function directly mints the borrowAToken using the scaledAmount without considering the exchange rate.

## Proof of Concept
   * Assume the exchange rate between the `underlyingBorrowToken` and the `aToken` is 1:1.
   * If a user deposits 100 `underlyingBorrowToken`, the `scaledAmount` will be 100.
   * However, if the exchange rate between the `aToken` and the `borrowAToken` is 1:0.5 (meaning 1 `aToken` is worth 0.5 `borrowAToken`), the function will incorrectly mint 100 `borrowAToken` instead of 50 `borrowAToken`.

This leads to an incorrect minting of `borrowAToken`, inflating the supply and causing discrepancies in the system's accounting.

```solidity
// DepositTokenLibraryTest.sol

pragma solidity 0.8.23;

import "forge-std/Test.sol";
import "@src/libraries/DepositTokenLibrary.sol";
import "@src/SizeStorage.sol";
import "@aave/interfaces/IAToken.sol";
import "@openzeppelin/contracts/token/ERC20/IERC20.sol";

contract DepositTokenLibraryTest is Test {
    using DepositTokenLibrary for State;

    State state;
    address underlyingBorrowToken;
    address variablePool;
    address borrowAToken;

    function setUp() public {
        // Initialize the state and set up the necessary addresses and contracts
        state.data.underlyingBorrowToken = underlyingBorrowToken = address(new ERC20Mock("Mock USDC", "USDC", 18));
        state.data.variablePool = variablePool = address(new AaveVariablePoolMock());
        state.data.borrowAToken = borrowAToken = address(new ERC20Mock("Mock aUSDC", "aUSDC", 18));
    }

    function testDepositUnderlyingBorrowTokenToVariablePool() public {
        uint256 amount = 1000e18; // Deposit 1000 USDC

        // Mint underlying borrow tokens to the test contract
        ERC20Mock(underlyingBorrowToken).mint(address(this), amount);

        // Approve the DepositTokenLibrary to transfer the tokens
        ERC20Mock(underlyingBorrowToken).approve(address(this), amount);

        // Get the initial balances
        uint256 initialUnderlyingBalance = IERC20(underlyingBorrowToken).balanceOf(address(this));
        uint256 initialBorrowATokenBalance = IERC20(borrowAToken).balanceOf(address(this));

        // Perform the deposit
        state.depositUnderlyingBorrowTokenToVariablePool(address(this), address(this), amount);

        // Get the updated balances
        uint256 finalUnderlyingBalance = IERC20(underlyingBorrowToken).balanceOf(address(this));
        uint256 finalBorrowATokenBalance = IERC20(borrowAToken).balanceOf(address(this));

        // Check the balances
        assertEq(initialUnderlyingBalance - finalUnderlyingBalance, amount, "Underlying borrow token balance mismatch");
        assertEq(finalBorrowATokenBalance - initialBorrowATokenBalance, amount, "Borrow aToken balance mismatch");
    }
}

// Mock contracts for testing

contract ERC20Mock {
    // ERC20 mock implementation
    // ...
}

contract AaveVariablePoolMock {
    // Aave variable pool mock implementation
    // ...
}
```
due to the bug, this test will fail because the borrow `aToken` balance will not match the expected value. The function incorrectly mints the borrow `aToken using the `scaledAmount` without considering the exchange rate between the underlying borrow token and the borrow `aToken`.

## Recommended Mitigation Steps
The function should calculate the actual amount of `borrowAToken` to mint based on the `scaledAmount` and the current exchange rate between the `underlyingBorrowToken` and the `borrowAToken`.

```solidity
    // Calculate the actual amount of borrowAToken to mint based on the exchange rate
    uint256 borrowATokenAmount = scaledAmount * aToken.scaledTotalSupply() / aToken.totalSupply();

    state.data.borrowAToken.mint(to, borrowATokenAmount);
}
```
