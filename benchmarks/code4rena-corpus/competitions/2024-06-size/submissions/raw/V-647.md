# Vulnerability details

## Summary 
The `PriceFeed` contract is designed to provide the price of a base asset in terms of a quote asset using Chainlink price feeds. However, the current implementation does not account for the potential risk of oracle price manipulation where the price feed might return a minimum or maximum price during events like flash crashes or depegging events.
Chainlink aggregators have a built in circuit breaker if the price of an asset goes outside of a predetermined price band. The result is that if an asset experiences a huge drop in value (i.e. LUNA crash) the price of the oracle will continue to return the `minPrice` instead of the actual price of the asset. This would allow user to continue borrowing with the asset but at the wrong price.

## Impact
The wrong price may be returned in the event of a market crash. An adversary will then be able to borrow against the wrong price and incur bad debt to the protocol.

## Proof of Concept
The critical part of the contract that deals with fetching and processing price data is as follows:

```solidity
    function _getPrice(AggregatorV3Interface aggregator, uint256 stalePriceInterval) internal view returns (uint256) {
        // slither-disable-next-line unused-return
        (, int256 price,, uint256 updatedAt,) = aggregator.latestRoundData();

        if (price <= 0) revert Errors.INVALID_PRICE(address(aggregator), price);
        if (block.timestamp - updatedAt > stalePriceInterval) {
            revert Errors.STALE_PRICE(address(aggregator), updatedAt);
        }

        return SafeCast.toUint256(price);
    }

```
This function checks for invalid prices `(price <= 0)` and stale prices but does not validate the price against the `minAnswer` and `maxAnswer` bounds.

## Recommended Mitigation
```
function _getPrice(AggregatorV3Interface aggregator, uint256 stalePriceInterval) internal view returns (uint256) {
    (, int256 price,, uint256 updatedAt,) = aggregator.latestRoundData();
    if (price <= 0) revert Errors.INVALID_PRICE(address(aggregator), price);
    if (block.timestamp - updatedAt > stalePriceInterval) {
        revert Errors.STALE_PRICE(address(aggregator), updatedAt);
    }
    // Validate price against minAnswer and maxAnswer
    if (price < aggregator.minAnswer() || price > aggregator.maxAnswer()) {
        revert Errors.PRICE_OUT_OF_RANGE(address(aggregator), price);
    }
    return SafeCast.toUint256(price);
}
```
This modification adds a check to ensure that the price falls within the expected range, thus mitigating the risk of exploitation during extreme market conditions.
