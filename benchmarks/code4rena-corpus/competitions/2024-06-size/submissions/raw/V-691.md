# Vulnerability details

## Impact
Lenders can't liquidate their credit position even though loan is overdue.

## Proof of Concept
The condition if credit position is self liquidateable is as the following.
```solidity
function isCreditPositionSelfLiquidatable(State storage state, uint256 creditPositionId)
        public
        view
        returns (bool)
    {
        CreditPosition storage creditPosition = state.data.creditPositions[creditPositionId];
        DebtPosition storage debtPosition = state.data.debtPositions[creditPosition.debtPositionId];
        LoanStatus status = state.getLoanStatus(creditPositionId);
        // Only CreditPositions can be self liquidated
@>      return state.isCreditPositionId(creditPositionId)
            && (isUserUnderwater(state, debtPosition.borrower) && status != LoanStatus.REPAID); 
    }
```
However even though loan is over due, if borrower has enough collateral, then lender can't liquidate by self.


## Tools Used
Manual review

## Recommended Mitigation Steps
If the loan status is OVERDUE, it may be a good idea to allow self-liquidation. 
```solidity
function isCreditPositionSelfLiquidatable(State storage state, uint256 creditPositionId)
        public
        view
        returns (bool)
    {
        CreditPosition storage creditPosition = state.data.creditPositions[creditPositionId];
        DebtPosition storage debtPosition = state.data.debtPositions[creditPosition.debtPositionId];
        LoanStatus status = state.getLoanStatus(creditPositionId);
        // Only CreditPositions can be self liquidated
@>      return state.isCreditPositionId(creditPositionId)
            && (status == LoanStatus.OVERDUE || (isUserUnderwater(state, debtPosition.borrower) && status == LoanStatus.ACTIVE)); 
    }
```
