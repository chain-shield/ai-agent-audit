# Vulnerability details

summary

when the contract is paused users are unable to repay during the paused state
which can leave them vulnerable to liquidation if their collateral value falls below the required threshold. also when the contract is unpaused users are vulnerable to frontrunning where they can be exploited by malicious user


vulnerability details


After the contract was unpaused, User A attempted to repay. However, before their transaction could be processed, User B, who had been monitoring pending transactions, noticed User A's attempt. User B quickly submitted a transaction with a higher gas price to liquidate User A's account instead, resulting in User A being forcefully liquidated despite their intention to save themselves from getting liquidated


Impact

1): users can be frontrunned by malicious user after the contract is unpaused this can result in loss of their collateral

Tool used

Manual Review


recommendation

Implement a waiting period before executing liquidation transactions to allow users ample time to resolve collateral concerns
