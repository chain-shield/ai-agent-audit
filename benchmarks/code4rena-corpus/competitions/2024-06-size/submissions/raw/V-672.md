# Vulnerability details

## Impact
Size.sol is an upgradeable contract that inherits from SizeView.sol, which itself inherits from SizeStorage.sol. The issue is that SizeStorage does not include a storage gap which may be dangerous when upgrading the contract.

## Proof of Concept
When upgradable contracts inherit from other contracts it is important that there are storage gaps in case storage variables are added to inherited contracts. SizeStorage, used for the contract storage, does not include any storage gaps. This may be detrimental when updating the contract because upgrades may change the storage slots of all inherited contracts.

## Tools Used
Manual review

## Recommended Mitigation Steps
Add a storage gap to SizeStorage.sol.
