# Vulnerability details

## Impact
User can repay loans without actually having the amount

## Proof of Concept
In `repay` :
```solidity
    function repay(RepayParams calldata params) external payable override(ISize) whenNotPaused {
        state.validateRepay(params); //@audit checks if debt is repayed
        state.executeRepay(params); //@audit there is no check if you can actually execute it as you might not have the balance and it will still retur true
    }
```
here we first check if its debt is repayed and then we `executeRepay`:
```solidity
    function executeRepay(State storage state, RepayParams calldata params) external {
        DebtPosition storage debtPosition = state.getDebtPosition(params.debtPositionId);

        state.data.borrowAToken.transferFrom(msg.sender, address(this), debtPosition.futureValue);
        debtPosition.liquidityIndexAtRepayment = state.data.borrowAToken.liquidityIndex();
        state.repayDebt(params.debtPositionId, debtPosition.futureValue);

        emit Events.Repay(params.debtPositionId);
    }
}
```
The problem here is in `state.data.borrowAToken.transferFrom(msg.sender, address(this),` :

```solidity
    function transferFrom(address from, address to, uint256 value) public virtual override onlyOwner returns (bool) {
        uint256 scaledAmount = Math.mulDivDown(value, WadRayMath.RAY, liquidityIndex());

        _burn(from, scaledAmount);
        _mint(to, scaledAmount);

        emit TransferUnscaled(from, to, value);

        return true;
    }
```

There is no check if user actually has the amount to repay as it just `_burn` (set anount to 0) and then it mints them.
