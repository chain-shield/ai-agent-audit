# Vulnerability details

## Impact

This report is quite sensitive and i would like the reader to follow each step one after the other, based on the attack ideas provided by the protocol in their README on the Fee and Fragmentation fee implementation.

https://code4rena.com/audits/2024-06-size#top:~:text=Swap%20fee%3A%20During,credit%20fractionalization/split.

The current implementation of the `SellCreditMarket` in the protocol has errors related to the fragmentation fee mechanism, which affects the fee calculation differently for cash and credit transactions:

1. **Overcharging Borrowers**: In the `SellCreditMarket` implementation, lenders are charged more than they should be because the fee calculation was correctly implemented when using CREDITIN to getCASHOUT. This reduces the profitability of lenders and may deter participation in the market.

2. **Undercharging Borrowers**: Conversely, the `SellCreditMarket` implementation undercharges the fees when using cash when there is a fragmentation, leading to a loss in potential revenue for the protocol and creating an imbalance in the fee structure when using  CASHOUT to CREDITIN.

3. **Inconsistent Fee Structure**: The discrepancy between the CASH and CREDIT transactions creates an unfair fee landscape, which could lead to unintended arbitrage opportunities.

## Recommended Mitigation Steps

Apologise for the long report, I refactorised the two errors pointed out and the result gave a perfect fee mechanism. 
1. substitute the proper Formula for MaxCash Amount Out calculation

```solidity
 function getCashAmountOut(
        State storage state,
        uint256 creditAmountIn,
        uint256 maxCredit,
        uint256 ratePerTenor,
        uint256 tenor
    ) public  view returns (uint256 cashAmountOut, uint256 fees) {
         uint256 swapFeePercent = getSwapFeePercent(state, tenor);

        uint256 maxCashAmountOut = Math.mulDivDown(creditAmountIn, PERCENT - swapFeePercent, PERCENT + ratePerTenor);

        if (creditAmountIn == maxCredit) {
            fees = getSwapFee(state, maxCashAmountOut, tenor);

            if (fees > maxCashAmountOut) {
                revert Errors.NOT_ENOUGH_CASH(maxCashAmountOut, fees);
            }

            cashAmountOut = maxCashAmountOut;
            // - fees; no need to substract again the maxcashout removes swap fee directly
        } else if (creditAmountIn < maxCredit) {
            fees = getSwapFee(state, maxCashAmountOut, tenor) + state.feeConfig.fragmentationFee;

            if (fees > maxCashAmountOut) {
                revert Errors.NOT_ENOUGH_CASH(maxCashAmountOut, fees);
            }

            cashAmountOut = maxCashAmountOut - state.feeConfig.fragmentationFee;
             //- fees; no need to substract fee again the maxcashout removes swap fee directly
        } else {
            revert Errors.NOT_ENOUGH_CREDIT(creditAmountIn, maxCredit);
        }
    }
```

2. Use cashAmountOut + feeConfig.fragmentationFee in fee calculation and not just CashAmountout

```solidity
function getCreditAmountIn(
        State storage state,
        uint256 cashAmountOut,
        uint256 maxCashAmountOut,
        uint256 maxCredit,
        uint256 ratePerTenor,
        uint256 tenor
    ) public  view returns (uint256 creditAmountIn, uint256 fees) {
        uint256 swapFeePercent = getSwapFeePercent(state, tenor);

        uint256 maxCashAmountOutFragmentation = 0;

        if (maxCashAmountOut >= state.feeConfig.fragmentationFee;) {
            maxCashAmountOutFragmentation = maxCashAmountOut - state.feeConfig.fragmentationFee;;
        }

        if (cashAmountOut == maxCashAmountOut) {
            creditAmountIn = maxCredit;
            fees = Math.mulDivUp(cashAmountOut, swapFeePercent, PERCENT);
        } else if (cashAmountOut < maxCashAmountOutFragmentation) {
            creditAmountIn = Math.mulDivUp(
                cashAmountOut + state.feeConfig.fragmentationFee;, PERCENT + ratePerTenor, PERCENT - swapFeePercent
            );
            // creditAmountIn= creditAmountIn ;
            fees = Math.mulDivUp(cashAmountOut + state.feeConfig.fragmentationFee;, swapFeePercent, PERCENT) + state.feeConfig.fragmentationFee;;
        } else {
            revert Errors.NOT_ENOUGH_CASH(maxCashAmountOutFragmentation, cashAmountOut);
        }
    }
```
