# Vulnerability details

## Impact
The protocol specifies that users can use all credit positions, to compensate for their debt positions, but this is not the case with some credit positions, where the credit position to compensate is greater than the credit position with debt to repay, and the difference between them is less than 50 USDC(which is the minimum credit allowed),preventing the compensation process

## Proof of Concept
When a user wants to compensate they pass the credit position with debt and the position to compensate with,  

```solidity
 if (params.creditPositionToCompensateId == RESERVED_ID) {
            creditPositionToCompensate = state.createDebtAndCreditPositions({
                lender: msg.sender,
                borrower: msg.sender,
                futureValue: amountToCompensate,
                dueDate: debtPositionToRepay.dueDate
            });
        } else {
            creditPositionToCompensate = state.getCreditPosition(params.creditPositionToCompensateId);
            amountToCompensate = Math.min(amountToCompensate, creditPositionToCompensate.credit);
        }
```
Here we can see in this snippet that, the amountToCompensate is the min of amountToCompensate and the credit position credit.

and before this `amountToCompensate` is determined using the snippet below 

```solidity
  uint256 amountToCompensate = Math.min(params.amount, creditPositionWithDebtToRepay.credit);
```
This says you can only compensate fully or compensate a particular amount.
Which means that when you fully compensate a debt position the amountToCompensate will be the future value. 

```solidity
state.reduceDebtAndCredit(
            creditPositionWithDebtToRepay.debtPositionId, params.creditPositionWithDebtToRepayId, amountToCompensate
        );
```
Here during execute, it tries to reduceDebtAndCredit, inside reduceCredit, it validates minimum credit if it fails it reverts the whole operation as shown below 

```solidity
 function reduceCredit(State storage state, uint256 creditPositionId, uint256 amount) public {
        CreditPosition storage creditPosition = state.getCreditPosition(creditPositionId);
        creditPosition.credit -= amount;
        state.validateMinimumCredit(creditPosition.credit);

        emit Events.UpdateCreditPosition(
            creditPositionId, creditPosition.lender, creditPosition.credit, creditPosition.forSale
        );
    }
``` 

Illustrated Example
 
creditPositionToCompensate = 1500
creditPositionWithDebtToRepay = 1457
minimum credit amount = 50

creditPositionToCompensate - creditPositionWithDebtToRepay = 43

validateMinimumCredit(43) will fail the check

The impact is that compensate works, but under different circumstances it will always fail
