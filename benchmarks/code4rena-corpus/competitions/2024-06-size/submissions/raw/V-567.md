# Vulnerability details

## Impact
Protocol Fees will not be received

## Proof of Concept
when a position is filled via liquidateWithReplacement, the swap fees which are meant to be paid by a borrower when ever an order is filled is not paid, the only fees paid are liquidatorProfitBorrowToken which is spread gained by the protocol for making the call 
## Tools Used
manual analysis 

## Recommended Mitigation Steps
Amount transferred to borrower should account for swap fees and swap fees should be sent to appropriate recipient
