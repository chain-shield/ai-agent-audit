# Vulnerability details

## Impact
When `crOpening` is updated by calling `executeUpdateConfig()`, there is no check to make sure that `crOpening` is strictly greater than `crLiquidation`.
A configuration with `crLiquidation` set to 1.3e18 and `crOpening` set to (1.3e18 + 1 wei) is allowed, which is equivalent to `crOpening` being equal to `crLiquidation`.
If `crOpening` is slightly higher than `crLiquidation`, a borrower could become liquidable immediately after their sell limit order is matched by a lender who called the `BuyCreditMarket()` function - or after matching a buy credit limit by calling `sellCreditMarket()`

Additionally, a borrower could nearly put themselves in a liquidatable state by withdrawing a portion of their collateral or by selling credit, bringing them just to the `openingLimitBorrowCR` level. Their withdrawal/sellCredit will be successful after passing the following check in `validateUserIsNotBelowOpeningLimitBorrowCR()`:
```
if (collateralRatio(state, account) < openingLimitBorrowCR) {
            revert Errors.CR_BELOW_OPENING_LIMIT_BORROW_CR(
                account, collateralRatio(state, account), openingLimitBorrowCR
            );
        }
```

## Proof of Concept
Paste the following POC inside `SellCreditMarket.t.sol`
```
function test_SellCreditMarket_sellCreditMarket_user_almost_underwater() public {
        _setPrice(1e18);

        // crOpening is set to 1.3e18 + 1, almost equal to crLiquidation
        _updateConfig("crOpening", 1.3e18 + 1);

        // swapFeeAPR for the sake of simplicity is set to 0
        _updateConfig("swapFeeAPR", 0);

        _deposit(alice, usdc, 200e6);

        // Bob deposits the exact amount to be on the edge of being underwater when borrowing 100 USDC
        _deposit(bob, weth, 130e18 + 100);

        _buyCreditLimit(alice, block.timestamp + 12 days, YieldCurveHelper.pointCurve(12 days, 0));

        // Bob borrows 100 USDC
        uint256 debtPositionId = _sellCreditMarket(bob, alice, RESERVED_ID, 100e6, 12 days, false);

        // The price of ETH is slightly decreasing
        _setPrice(1e18 - 1);

        // Bob's position is liquidable
        assertTrue(size.isDebtPositionLiquidatable(debtPositionId));
    }
```

## Recommended Mitigation Steps
Ensure there is a gap between `crOpening` and `crLiquidation`. 
In the following example, `crOpening` must be greater than `crLiquidation` by more than 1%
```
if (r.crOpening <= (r.crLiquidation + 1e16)) {
           revert Errors.INVALID_LIQUIDATION_COLLATERAL_RATIO(r.crOpening, r.crLiquidation);
       }

```
