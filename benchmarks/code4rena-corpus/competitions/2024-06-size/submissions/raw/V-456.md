# Vulnerability details

## Impact

Significant impact on protocol generated revenue over time and breaks the FEES_01 invariant.

## Proof of Concept

As stated by the documentation [here](https://docs.size.credit/technical-docs/contracts/3.4-repayment)
![image](https://gist.github.com/assets/133224432/ab3b51ef-589a-4da9-a299-531c990ee35f)
and confirmed by protocol team , all credit splits as a result of compensation should incur the fragmentation fee. However from the implementation of `compensate::executeCompensate` we can see that credit fractionalization is only accounted for on `creditPositionToCompensate.credit`.
consider the following cases
![image](https://gist.github.com/assets/133224432/06ab80c5-a72a-4fd3-81e0-a8cc4d95d3ef)
Although 1,2,3 results in credit fractionalization the fragmentation fee is not collected on case 1 & 2.

//test/local/actions/Compensate.t.sol

 function test_compensate_compensate_fragmentation_fee() public {
        //Case 1.
        _deposit(alice, usdc, 100e6);
        _deposit(bob, weth, 150e18);

        _buyCreditLimit(alice, block.timestamp + 365 days, YieldCurveHelper.pointCurve(365 days, 1e18));
        uint256 debtPositionId1 = _sellCreditMarket(bob, alice, RESERVED_ID, 100e6, 365 days, true);
        uint256 creditPositionId1 = size.getCreditPositionIdsByDebtPositionId(debtPositionId1)[0];
        uint256 creditBeforeCompensate = size.getCreditPosition(creditPositionId1).credit;

        UserView memory bobBefore1 = size.getUserView(bob);
        _compensate(bob, creditPositionId1, RESERVED_ID, 50e6);
        UserView memory bobAfter1 = size.getUserView(bob);

        assertEq(bobAfter1.collateralTokenBalance, bobBefore1.collateralTokenBalance);//fee is not deducted from collateral balance
        assertEq(size.getCreditPosition(creditPositionId1).credit, creditBeforeCompensate - 50e6);

        //Case 2.
        //(Borrower: Bob, FutureValue: 100 USDC) (Lender: Alice, Credit: 100 USDC)
        _deposit(alice, usdc, 100e6);
        _deposit(bob, weth, 150e18);
        _buyCreditLimit(alice, block.timestamp + 365 days, YieldCurveHelper.pointCurve(365 days, 1e18));
        uint256 debtPositionWithDebtToRepayId = _sellCreditMarket(bob, alice, RESERVED_ID, 100e6, 365 days, true);
        uint256 creditPositionWithDebtToRepayId =
            size.getCreditPositionIdsByDebtPositionId(debtPositionWithDebtToRepayId)[0];

        //(Borrower: Candy, FutureValue: 50 USDC) (Lender: Bob, Credit: 50 USDC)
        _deposit(bob, usdc, 50e6);
        _deposit(candy, weth, 75e18);
        _buyCreditLimit(bob, block.timestamp + 365 days, YieldCurveHelper.pointCurve(365 days, 1e18));
        uint256 debtPositionToCompensateId = _sellCreditMarket(candy, bob, RESERVED_ID, 50e6, 365 days, true);
        uint256 creditPositionToCompensateId = size.getCreditPositionIdsByDebtPositionId(debtPositionToCompensateId)[0];

        uint256 creditBeforeCompensate2 = size.getCreditPosition(creditPositionWithDebtToRepayId).credit;
        UserView memory bobBefore2 = size.getUserView(bob);

        _compensate(bob, creditPositionWithDebtToRepayId, creditPositionToCompensateId);

        assertEq(size.getCreditPosition(creditPositionWithDebtToRepayId).credit, creditBeforeCompensate2 - 50e6);
        assertEq(bobBefore2.collateralTokenBalance, size.getUserView(bob).collateralTokenBalance);
    }
