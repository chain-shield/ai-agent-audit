# Vulnerability details

## Impact
`createDebtAndCreditPositions` mints debt tokens to the borrower without updating the borrower's total debt tracker. This can lead to inconsistencies in the borrower's total debt accounting.

## Proof of Concept
The `createDebtAndCreditPositions` function mints debt tokens to the borrower without updating the borrower's total debt tracker, which can lead to inconsistencies in accounting the borrower's total debt. [Link to the code](https://github.com/code-423n4/2024-06-size/blob/8850e25fb088898e9cf86f9be1c401ad155bea86/src/libraries/AccountingLibrary.sol#L53-L92)
```solidity
function createDebtAndCreditPositions(
    State storage state,
    address lender,
    address borrower,
    uint256 futureValue,
    uint256 dueDate
) external returns (CreditPosition memory creditPosition) {
    // ...

    state.data.debtToken.mint(borrower, futureValue);
}
```
* The missing update to the borrower's total debt tracker
    - In the `createDebtAndCreditPositions` function, the debt tokens are minted to the borrower using `state.data.debtToken.mint(borrower, futureValue)`, but there is no corresponding update to the borrower's total debt tracker (`state.data.totalDebtTracker[borrower]`).
    - Can be seen in the code where the update to the total debt tracker is missing.

* Consequences of the missing update
    - The system must update the borrower's total debt tracker to reflect the borrower's total debt accurately.
    - This could lead to issues in other system parts that rely on the total debt tracker, such as risk assessment or debt repayment calculations.
    - For example, if the total debt tracker is used to determine the borrower's creditworthiness or to calculate the total outstanding debt, the incorrect value could result in improper decision-making or financial discrepancies.

## Recommended Mitigation Steps
Update the borrower's total debt tracker after minting the debt tokens. By adding the line `state.data.totalDebtTracker[borrower] += futureValue;` after minting the debt tokens, the function ensures that the borrower's total debt tracker is updated correctly.
```solidity
function createDebtAndCreditPositions(
    State storage state,
    address lender,
    address borrower,
    uint256 futureValue,
    uint256 dueDate
) external returns (CreditPosition memory creditPosition) {
    // ... (existing code remains the same)

    state.data.debtToken.mint(borrower, futureValue);

    // Update the borrower's total debt tracker
    state.data.totalDebtTracker[borrower] += futureValue;
}
```
