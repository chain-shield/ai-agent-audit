# Vulnerability details

## Impact
When a borrower borrows with a market order using the sellCreditMarket function, a debt position is created for the borrower and a credit position is created for the lender.

```solidity
function createDebtAndCreditPositions(
        State storage state,
        address lender,
        address borrower,
        uint256 futureValue,
        uint256 dueDate
    ) external returns (CreditPosition memory creditPosition) {
        DebtPosition memory debtPosition =
            DebtPosition({borrower: borrower, futureValue: futureValue, dueDate: dueDate, liquidityIndexAtRepayment: 0});

        uint256 debtPositionId = state.data.nextDebtPositionId++;
        state.data.debtPositions[debtPositionId] = debtPosition;

        emit Events.CreateDebtPosition(debtPositionId, borrower, lender, futureValue, dueDate);

        creditPosition = CreditPosition({
            lender: lender,
            credit: debtPosition.futureValue,
            debtPositionId: debtPositionId,
            forSale: true
        }); 
```

And the credit position is created with the forSale being true. This may cause problems in some conditions. 


Users can be both lenders and borrowers simultaneously. However, a problem arises when a credit position is opened with "forSale" set to true. Anyone can purchase the lender's credit position, causing the lender to lose funds. When a credit position is bought, fees are taken from the borrower, who in this case is the original lender.

## Proof of Concept

BuyCreditMarket.t.sol

```solidity
function test_BuyCreditMarket_loseFunds() public {
        _setPrice(1e18);
        _updateConfig("borrowATokenCap", type(uint256).max);

        _deposit(alice, usdc, 1000e6);
        _deposit(bob, weth, 1600e18);
        _deposit(james, weth, 1600e18);
        _deposit(james, usdc, 1000e6);
        _deposit(candy, usdc, 1200e6);

        // Alice is both lender and borrower
        _buyCreditLimit(
            alice,
            block.timestamp + 365 days,
            YieldCurveHelper.pointCurve(365 days, 1e18)
        );

        _sellCreditLimit(alice, YieldCurveHelper.pointCurve(365 days, 1e18));

        Vars memory _before = _state();
        uint aliceBorrowTokenBalanceBefore = _before.alice.borrowATokenBalance;

        // Bob lends from Alice
        uint256 debtPositionId1 = _sellCreditMarket(
            bob,
            alice,
            100e6,
            365 days,
            false
        );
        uint256 creditPositionId1_1 = size.getCreditPositionIdsByDebtPositionId(
            debtPositionId1
        )[0];

        uint256 amountIn = 100e6;

        // After that James immidietly buys Alices credit position so Alice lose funds equal to fee amount
        _buyCreditMarket(james, creditPositionId1_1, amountIn, true);

        Vars memory _after = _state();
        uint256 aliceBorrowTokenBalanceAfter = _after.alice.borrowATokenBalance;

        assertLt(aliceBorrowTokenBalanceAfter, aliceBorrowTokenBalanceBefore);
    }
```

## Recommended Mitigation Steps
The forSale parameter should be set to false when creating a new credit position so that the lender does not face this issue and can decide whether to sell his position or not. Or, when someone buys a credit position, he should be the one who pays the fees.
