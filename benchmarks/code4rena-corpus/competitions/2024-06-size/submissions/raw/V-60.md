# Vulnerability details

## Impact
`getDebtPositionByCreditPositionId` retrieves the `CreditPosition` using the `getCreditPosition` function, which reverts if the `creditPositionId` is invalid. However, it then directly accesses the `debtPositionId` from the retrieved `CreditPosition` without checking if the `debtPositionId` is valid.

Suppose the `debtPositionId` stored in the `CreditPosition` is invalid or doesn't exist. In that case, the function will still attempt to retrieve the `DebtPosition` using `getDebtPosition`, which will revert due to an invalid `debtPositionId`.

To illustrate the concept in detail, let's consider an example scenario:

Suppose we have the following state:
   - `nextDebtPositionId` is 5
   - `nextCreditPositionId` is 10
   - `creditPositions[8]` exists and has a `debtPositionId` of 3
   - `debtPositions[3]` exists and is valid

When we call `getDebtPositionByCreditPositionId(state, 8)`, the function will:

   1. Retrieve `creditPosition` using `getCreditPosition(state, 8)`, which will return the `CreditPosition` at index 8.
   2. Access the `debtPositionId` from the retrieved `creditPosition`, which is 3.
   3. Directly call `getDebtPosition(state, 3)` to retrieve the corresponding `DebtPosition`.

Since `debtPositions[3]` exists and is valid, the function will return the correct `DebtPosition`.

However, let's consider another scenario
   - `nextDebtPositionId` is 5
   - `nextCreditPositionId` is 10
   - `creditPositions[8]` exists but has an invalid `debtPositionId` of 7
   - `debtPositions[7]` does not exist

When we call `getDebtPositionByCreditPositionId(state, 8)`, the function will

1. Retrieve `creditPosition` using `getCreditPosition(state, 8)`, which will return the `CreditPosition` at index 8.
2. Access the `debtPositionId` from the retrieved `creditPosition`, which is 7.
3. Directly call `getDebtPosition(state, 7)` to retrieve the corresponding `DebtPosition`.

Since `debtPositions[7]` does not exist, the `getDebtPosition` function will revert with an `INVALID_DEBT_POSITION_ID` error.

## Recommended Mitigation Steps
A check should be added to ensure that the `debtPositionId` retrieved from the `CreditPosition` is valid before calling `getDebtPosition`.
```solidity
function getDebtPositionByCreditPositionId(State storage state, uint256 creditPositionId)
    public
    view
    returns (DebtPosition storage)
{
    CreditPosition memory creditPosition = getCreditPosition(state, creditPositionId);
    if (isDebtPositionId(state, creditPosition.debtPositionId)) {
        return getDebtPosition(state, creditPosition.debtPositionId);
    } else {
        revert Errors.INVALID_DEBT_POSITION_ID(creditPosition.debtPositionId);
    }
}
```
