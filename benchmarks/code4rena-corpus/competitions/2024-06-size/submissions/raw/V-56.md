# Vulnerability details

## Impact
When creating a new credit position, the `createCreditPosition` function does not update the `creditPositionIdsByDebtPositionId` mapping. This mapping is used to keep track of all the credit positions associated with a specific debt position.

When a new credit position is created (in the `else` block), the function should add the new credit position ID to the `creditPositionIdsByDebtPositionId` mapping for the corresponding debt position ID.

## Proof of Concept
AccountingLibrary.sol: https://github.com/code-423n4/2024-06-size/blob/8850e25fb088898e9cf86f9be1c401ad155bea86/src/libraries/AccountingLibrary.sol#L103-L127
```solidity
    function createCreditPosition(State storage state, uint256 exitCreditPositionId, address lender, uint256 credit)
        external
    {
        CreditPosition storage exitCreditPosition = state.getCreditPosition(exitCreditPositionId);
        if (exitCreditPosition.credit == credit) {
            exitCreditPosition.lender = lender;


            emit Events.UpdateCreditPosition(
                exitCreditPositionId, lender, exitCreditPosition.credit, exitCreditPosition.forSale
            );
        } else {
            uint256 debtPositionId = exitCreditPosition.debtPositionId;


            reduceCredit(state, exitCreditPositionId, credit);


            CreditPosition memory creditPosition =
                CreditPosition({lender: lender, credit: credit, debtPositionId: debtPositionId, forSale: true});


            uint256 creditPositionId = state.data.nextCreditPositionId++;
            state.data.creditPositions[creditPositionId] = creditPosition;
            state.validateMinimumCreditOpening(creditPosition.credit);


            emit Events.CreateCreditPosition(creditPositionId, lender, debtPositionId, exitCreditPositionId, credit);
        }
    }
```

  1. Suppose there is a debt position with ID `1` and an associated credit position with ID `100`.
  2. The `createCreditPosition` function is called with `exitCreditPositionId = 100`, `lender = address(0x123)`, and `credit = 1000`.
  3. Since the `credit` amount differs from the existing credit position's credit, the function will enter the else block.
  4. It will reduce the credit of the existing credit position (ID `100`) by calling `reduceCredit`.
  5. Then, it will create a new credit position with ID 101 (assuming `nextCreditPositionId` is `101`).
  6. The new credit position will be added to the `creditPositions` mapping with the key `101`.
  7. However, without the fix, the `creditPositionIdsByDebtPositionId` mapping will not be updated to include the new credit position ID 101 for the debt position ID `1`.

As a result, when querying the credit positions for the debt position with ID `1`, only the credit position with ID `100` will be returned, even though there is a new credit position with ID 101 associated with it.

A test case that performs the above steps and then calls the `getCreditPositionIdsByDebtPositionId` function to retrieve the credit position IDs for the debt position ID 1. Without the fix, the returned array will only contain `[100]`, missing the newly created credit position ID `101`.
```solidity

    // Create a new credit position
    accountingLibrary.createCreditPosition(state, exitCreditPositionId, lender, credit);

    // Retrieve the credit position IDs for the debt position ID 1
    uint256[] memory creditPositionIds = state.getCreditPositionIdsByDebtPositionId(1);

    // Without the fix, the new credit position ID 101 will be missing
    assertEq(creditPositionIds.length, 1);
```

Without the fix, the `creditPositionIdsByDebtPositionId` mapping is not updated correctly, leading to inconsistencies in the credit position data.

## Recommended Mitigation Steps
By adding the line **`state.data.creditPositionIdsByDebtPositionId[debtPositionId].push(creditPositionId);`**, the function ensures that the new credit position ID is adequately associated with the corresponding debt position ID in the mapping.
```solidity
function createCreditPosition(State storage state, uint256 exitCreditPositionId, address lender, uint256 credit)
    external
{
    CreditPosition storage exitCreditPosition = state.getCreditPosition(exitCreditPositionId);
    if (exitCreditPosition.credit == credit) {
        exitCreditPosition.lender = lender;

        emit Events.UpdateCreditPosition(
            exitCreditPositionId, lender, exitCreditPosition.credit, exitCreditPosition.forSale
        );
    } else {
        uint256 debtPositionId = exitCreditPosition.debtPositionId;

        reduceCredit(state, exitCreditPositionId, credit);

        CreditPosition memory creditPosition =
            CreditPosition({lender: lender, credit: credit, debtPositionId: debtPositionId, forSale: true});

        uint256 creditPositionId = state.data.nextCreditPositionId++;
        state.data.creditPositions[creditPositionId] = creditPosition;
        state.validateMinimumCreditOpening(creditPosition.credit);

        // Add the new credit position ID to the creditPositionIdsByDebtPositionId mapping
++      state.data.creditPositionIdsByDebtPositionId[debtPositionId].push(creditPositionId);

        emit Events.CreateCreditPosition(creditPositionId, lender, debtPositionId, exitCreditPositionId, credit);
    }
}
```
