# Vulnerability details


## Summary

The `Compensate` event, emitted at the beginning of the `executeCompensate` function, might return an incorrect value.

```sol
function executeCompensate(State storage state, CompensateParams calldata params) external {
    emit Events.Compensate(
        params.creditPositionWithDebtToRepayId, params.creditPositionToCompensateId, params.amount
    );

    ...

    uint256 amountToCompensate = Math.min(params.amount, creditPositionWithDebtToRepay.credit);
}
```

```sol
event Compensate(
    uint256 indexed creditPositionWithDebtToRepayId, uint256 indexed creditPositionToCompensateId, uint256 amount
);
```

The event currently emits `params.amount` as `amount`, but the actual amount used for compensation is `amountToCompensate`, which is the lesser of `params.amount` and `creditPositionWithDebtToRepay.credit`.

## Proof of Concept (PoC)

Consider a user attempting to compensate with the maximum possible value by invoking the `executeCompensate` function with the following parameters:

```sol
CompensateParams compensateParams = CompensateParams({..., ..., amount: type(uint256).max});
```

In this scenario, the event will emit `amount` as `type(uint256).max`, whereas the actual compensation amount will be significantly lower.

Even when a user attempts to compensate with a legitimate value that exceeds `creditPositionWithDebtToRepay.credit`, the event will still provide misleading information.

## Impact

Events are crucial for monitoring blockchain actions. This discrepancy could mislead front-end applications and external technologies reliant on these events, resulting in user errors and potential operational issues.

## Recommendation

Emit the `Compensate` event at the end of the function, using `amountToCompensate` as the emitted amount:

```diff
 function executeCompensate(State storage state, CompensateParams calldata params) external {
-    emit Events.Compensate(
-        params.creditPositionWithDebtToRepayId, params.creditPositionToCompensateId, params.amount
-    );

    ...

    uint256 amountToCompensate = Math.min(params.amount, creditPositionWithDebtToRepay.credit);

    ...

+    emit Events.Compensate(
+        params.creditPositionWithDebtToRepayId, params.creditPositionToCompensateId, amountToCompensate
+    );
}
```

By making this adjustment, the emitted event will accurately reflect the actual amount compensated, ensuring reliable event data for monitoring and external integration purposes.
