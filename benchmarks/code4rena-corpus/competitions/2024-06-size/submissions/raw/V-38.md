# Vulnerability details

## Impact
The function [repay()](https://github.com/code-423n4/2024-06-size/blob/8850e25fb088898e9cf86f9be1c401ad155bea86/src/Size.sol#L198-L201) allow borrowers to pay back their borrowing positions. However, function `repay()` does not check the minimum leftover borrowing amount. A rogue borrower can partially pay back their position and leave a small borrowing amount in the position. One possible objective is to disincentivize a liquidator from liquidating their position.

Since the rogue borrower's position is too small for liquidators to gain liquidation profit compared to the liquidation cost (gas), the position will not be liquidated even if it is liquidatable. This eventually leaves bad debt to the protocol.

## Proof of Concept
As the `repay()` function docs state:
```solidity
///         Partial repayment are currently unsupported
```
But the `repay()` function does not check for the minimum leftover borrowing amount.
```solidity
 function repay(RepayParams calldata params) external payable override(ISize) whenNotPaused {
        state.validateRepay(params);
        state.executeRepay(params);
    }

```
Instead, it only validates if the loan is already repaid by calling the [validateRepay()](https://github.com/code-423n4/2024-06-size/blob/8850e25fb088898e9cf86f9be1c401ad155bea86/src/libraries/actions/Repay.sol#L33-L41) function. Hence, a borrower can partially pay back and leave any borrowing amount in their position at will. The `validateRepay()` function only checks if the loan is already repaid:
```solidity
  function validateRepay(State storage state, RepayParams calldata params) external view {
        // validate debtPositionId
        if (state.getLoanStatus(params.debtPositionId) == LoanStatus.REPAID) {
            revert Errors.LOAN_ALREADY_REPAID(params.debtPositionId);
        }

        // validate msg.sender
        // N/A
    }
```
There is `No minimum leftover borrowing amount check`.

## Recommended Mitigation Steps
Do not allow a borrower to pay back their position and leave in borrowing amount less than the proper minimum threshold.
