# Vulnerability details

## Impact
The [sellCreditMarket](https://github.com/code-423n4/2024-06-size/blob/8850e25fb088898e9cf86f9be1c401ad155bea86/src/Size.sol#L188C14-L188C30) function checks that the collateral ratio is above the opening rate, only when creating a new position. This means that a lender can sell very dangerous debt to other "passive" lenders that are offering to buy credit, event if the position is only 1 wei above the liquidation threshold. Enabling lenders to dump their soon to be liquidated position onto other traders (if they fear that the liquidation won't be exercised).

## Proof of Concept
When selling an existing credit position to another trader, the opening collateral ratio isn't check:
```
    function sellCreditMarket(SellCreditMarketParams memory params) external payable override(ISize) whenNotPaused {
        state.validateSellCreditMarket(params);
        uint256 amount = state.executeSellCreditMarket(params);
        if (params.creditPositionId == RESERVED_ID) {
            state.validateUserIsNotBelowOpeningLimitBorrowCR(msg.sender);
        }
        state.validateVariablePoolHasEnoughLiquidity(amount);
    }
```
This means that for as long as the position is active and 1 wei above liquidation, it can be sold:
```
    function isCreditPositionTransferrable(State storage state, uint256 creditPositionId)
        internal
        view
        returns (bool)
    {
        return state.getLoanStatus(creditPositionId) == LoanStatus.ACTIVE
            && !isUserUnderwater(state, state.getDebtPositionByCreditPositionId(creditPositionId).borrower);
    }
```

Since in the order book model the buyer of credit might be "passive", and will accept any order that fits their curve requirements, this can be used to dump very "dangerous" positions onto others, evading the risk of the liquidation not happening or being delayed, just by paying the swap fee price. While forcing the other trader to be exposed to such trouble.
