# Vulnerability details

## Impact
User loss of funds due to stuck amount

## Proof of Concept
Let's say user decides to deposit amount of 500 USDCs(borrowToken) to AAVE pool through Size, due to the AVVE's rayDiv formula for scale amount(Note that LiquidityIndex is 1,5e27), 333 will be recorded as scaleAmount in size
```solidity
uint256 amountScaled = amount.rayDiv(index);
```
```solidity
function rayDiv(uint256 a, uint256 b) internal pure returns (uint256 c) {
    // to avoid overflow, a <= (type(uint256).max - halfB) / RAY
    assembly {
      if or(iszero(b), iszero(iszero(gt(a, div(sub(not(0), div(b, 2)), RAY))))) {
        revert(0, 0)
      }

      c := div(add(mul(a, RAY), div(b, 2)), b)
    }
  }
```
