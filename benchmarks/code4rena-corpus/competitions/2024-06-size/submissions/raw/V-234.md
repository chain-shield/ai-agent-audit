# Vulnerability details

## Impact
The issue presents itself in a case where the price of an asset drops or rises drastically such that the oracle continues to wrongly use the min/max price(which is now lower that minPrice or higher than maxPrice). Instead of the actual price.




## Proof of Concept
Example, a token has price of $40. Its minimum price is $20 on chainlink. The actual price drops from $40 to $10. Because there is no check for this, the oracle continues to report $20 as the price.


## Tools Used
Manual Review 

## Recommended Mitigation Steps
A check can be used: 
`require(price >= minAnswer && price <= maxAnswer, "invalid price");`


## Assessed type

Oracle
