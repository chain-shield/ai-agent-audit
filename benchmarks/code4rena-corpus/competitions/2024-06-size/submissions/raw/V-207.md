# Vulnerability details

## Description
`withdrawUnderlyingTokenFromVariablePool` calculates the `scaledAmount` by subtracting the `scaledBalanceBefore` from the current `scaledBalanceOf(address(this))`. However, if the withdrawal from the Aave pool fails for any reason (e.g., insufficient liquidity, Aave pool being paused, etc.), the `scaledAmount` will still be calculated and the corresponding `burnScaled` operation will be performed on the `borrowAToken`.

This means that even if the withdrawal from Aave fails, the user's `borrowAToken` balance will still be burned, leading to a loss of funds for the user. The contract should ensure that the burnScaled operation is only performed if the withdrawal from Aave is successful.

## Impact
If the withdrawal from the Aave pool fails, the user's `borrowAToken` balance will still be burned, resulting in a loss of funds. [DepositTokenLibrary.sol#74-88](https://github.com/code-423n4/2024-06-size/blob/8850e25fb088898e9cf86f9be1c401ad155bea86/src/libraries/DepositTokenLibrary.sol#L74-L88)
```solidity
function withdrawUnderlyingTokenFromVariablePool(State storage state, address from, address to, uint256 amount)
    external
{
    IAToken aToken =
        IAToken(state.data.variablePool.getReserveData(address(state.data.underlyingBorrowToken)).aTokenAddress);

    uint256 scaledBalanceBefore = aToken.scaledBalanceOf(address(this));

    // slither-disable-next-line unused-return
    state.data.variablePool.withdraw(address(state.data.underlyingBorrowToken), amount, to);

    uint256 scaledAmount = scaledBalanceBefore - aToken.scaledBalanceOf(address(this));

    state.data.borrowAToken.burnScaled(from, scaledAmount);
}
```
The `withdraw` method of the Aave pool is called to withdraw the underlying borrow token. However, the return value of the `withdraw` function is not checked for success. Instead, the `scaledAmount` is calculated based on the difference between the `scaledBalanceBefore` and the current `scaledBalanceOf(address(this))`.

If the withdrawal from Aave fails, the `scaledAmount` will still be calculated, and the `burnScaled` operation will be performed on the user's `borrowAToken` balance. This means that even if the user doesn't receive the underlying tokens from Aave, their `borrowAToken` balance will be burned, effectively resulting in a loss of funds.

## Proof of Concept
Consider a scenario where a user attempts to withdraw 100 tokens from the Aave pool, but the withdrawal fails due to insufficient liquidity. In this case:

   1. The `scaledBalanceBefore` is recorded.
   2. The `withdraw` function is called, but it fails silently.
   3. The `scaledAmount` is calculated based on the difference between `scaledBalanceBefore` and the current `scaledBalanceOf(address(this))`, which will be 0 since the withdrawal failed.
   4. The user's `borrowAToken` balance is burned by the `scaledAmount`, even though they didn't receive the underlying tokens.
This scenario demonstrates how the user's funds can be lost if the withdrawal from Aave fails.

A test case that simulates a scenario where the withdrawal from the Aave pool fails.
```js
const { expect } = require("chai");
const { ethers } = require("hardhat");

describe("DepositTokenLibrary", function () {
  let size;
  let aavePool;
  let underlyingToken;
  let borrowAToken;
  let user;

  beforeEach(async function () {
    // Deploy the Size contract and initialize necessary variables
    const Size = await ethers.getContractFactory("Size");
    size = await Size.deploy();
    await size.deployed();

    // Deploy a mock Aave pool contract
    const AavePool = await ethers.getContractFactory("MockAavePool");
    aavePool = await AavePool.deploy();
    await aavePool.deployed();

    // Deploy a mock underlying token contract
    const UnderlyingToken = await ethers.getContractFactory("MockERC20");
    underlyingToken = await UnderlyingToken.deploy("Mock Token", "MTK");
    await underlyingToken.deployed();

    // Deploy a mock borrow aToken contract
    const BorrowAToken = await ethers.getContractFactory("MockBorrowAToken");
    borrowAToken = await BorrowAToken.deploy();
    await borrowAToken.deployed();

    // Set up the necessary state variables in the Size contract
    await size.setVariablePool(aavePool.address);
    await size.setUnderlyingBorrowToken(underlyingToken.address);
    await size.setBorrowAToken(borrowAToken.address);

    // Get the user account
    [user] = await ethers.getSigners();
  });

  it("should burn borrowAToken even if withdrawal from Aave fails", async function () {
    // Mint some underlying tokens to the user
    await underlyingToken.mint(user.address, ethers.utils.parseEther("100"));

    // User deposits underlying tokens to the Size contract
    await underlyingToken.connect(user).approve(size.address, ethers.utils.parseEther("100"));
    await size.connect(user).depositUnderlyingBorrowTokenToVariablePool(ethers.utils.parseEther("100"));

    // Check the user's initial borrowAToken balance
    const initialBorrowATokenBalance = await borrowAToken.balanceOf(user.address);

    // Set the mock Aave pool to always fail withdrawals
    await aavePool.setWithdrawalFailure(true);

    // User attempts to withdraw underlying tokens from the Size contract
    await expect(size.connect(user).withdrawUnderlyingTokenFromVariablePool(ethers.utils.parseEther("100")))
      .to.be.revertedWith("Withdrawal from Aave failed");

    // Check the user's borrowAToken balance after the failed withdrawal
    const finalBorrowATokenBalance = await borrowAToken.balanceOf(user.address);

    // The borrowAToken balance should remain unchanged
    expect(finalBorrowATokenBalance).to.equal(initialBorrowATokenBalance);
  });
});
```

## Recommended Mitigation Steps
Modify the code to handle the case when the withdrawal from Aave fails. One possible approach is to use a require statement to check the withdrawal's success and only proceed with the `burnScaled` operation if it is successful.
