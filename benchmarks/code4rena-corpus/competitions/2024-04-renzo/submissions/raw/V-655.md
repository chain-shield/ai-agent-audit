# Vulnerability details

## Impact
The WithdrawQueue.sol inherits the ``PausableUpgradeable`` from openzeppelin, and rightly implements the public functions, however it does not implement the actual modifiers. 
To pause either the ``withdraw()`` or ``claim()`` functions, the modifier ``whenNotPaused()`` needs to be implemented. However this was not done.

Therefore, by pausing the contract, nothing is actually done apart from a state variable change.
## Proof of Concept
The withdraw function:
```solidity
    /**
     * @notice  Creates a withdraw request for user
     * @param   _amount  amount of ezETH to withdraw
     * @param   _assetOut  output token to receive on claim
     */
    function withdraw(uint256 _amount, address _assetOut) external nonReentrant {
```
The claim function:

```solidity
    function claim(uint256 withdrawRequestIndex) external nonReentrant {
        // check if provided withdrawRequest Index is valid
        if (withdrawRequestIndex >= withdrawRequests[msg.sender].length)
            revert InvalidWithdrawIndex();
```

## Tools Used
Manual Review, Josephdara
## Recommended Mitigation Steps
Add the ``whenNotPaused()`` modifier to both the ``withdraw()`` and ``claim()`` functions to enable pausing functionality
