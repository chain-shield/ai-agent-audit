# Vulnerability details

token TVL limit is a safe mechanism in the protocol. It would limit the systemic risk a token could pose on the protocol. However, when the token TVL limit is checked, it does not include the token balance in withdraw queue.

```solidity
// Enforce individual token TVL limit if set, 0 means the check is not enabled
if (collateralTokenTvlLimits[_collateralToken] != 0) {
    // Track the current token's TVL
    uint256 currentTokenTVL = 0;

    // For each OD, add up the token TVLs
    uint256 odLength = operatorDelegatorTokenTVLs.length;
    for (uint256 i = 0; i < odLength; ) {
        currentTokenTVL += operatorDelegatorTokenTVLs[i][tokenIndex];
        unchecked {
            ++i;
        }
    }

    // Check if it is over the limit
    if (currentTokenTVL + collateralTokenValue > collateralTokenTvlLimits[_collateralToken])
        revert MaxTokenTVLReached();
}
```

It sums the operatorDelegatorTokenTVLs. But the protocol TVL includes the withdrawQueue balance.
```solidity
...
// record token value of withdraw queue
if (!withdrawQueueTokenBalanceRecorded) {
    totalWithdrawalQueueValue += renzoOracle.lookupTokenValue(
        collateralTokens[i],
        collateralTokens[j].balanceOf(withdrawQueue)
    );
}
...

// Add native ETH help in withdraw Queue and totalWithdrawalQueueValue to totalTVL
totalTVL += (address(withdrawQueue).balance + totalWithdrawalQueueValue);
```

The balance in withdrawQueue could be as high as `withdrawalBufferTarget + claimReserve`. `withdrawalBufferTarget` could be a high number to allow smooth withdrawals and it is always filled first before anything else is done in the protocol such as depositing into operatorDelegator.

## Impact
collateralTokenTvlLimits check is not adequate and it could put the protocol at risk.

## Proof of Concept
Assuming there's a token TVL limit of 100 and there are 90 in the protocol as follows
* 50 operator delegators
* 20 withdrawQueue.claimReserve
* 20 withdrawQueue.availableBalance

It should only accept 10 tokens but because of the invalid validation, it can accept 50 tokens and increase the token TVL to 140.

## Tools Used
Manual Review

## Recommended Mitigation Steps
Include the collateral token value in withdrawal queue when checking the token TVL limit.
