# Vulnerability details

## Impact

Users will not be able to use certain LSTs on L2, due to the strict check that requires that the returned scaled price must be greater than 1 ether. Minting xezETH will be almost impossible in xRenzoDeposit.sol.

## Proof of Concept

In RenzoOracleL2.sol the `getMintRate` is used to query chainlink prices from L2. The function introduces sanity checks to ensure that the returned scaled price is not less than 1 ether.

```solidity
    function getMintRate() public view returns (uint256, uint256) {
        (, int256 price, , uint256 timestamp, ) = oracle.latestRoundData();
        if (timestamp < block.timestamp - MAX_TIME_WINDOW) revert OraclePriceExpired();
        // scale the price to have 18 decimals
        uint256 _scaledPrice = (uint256(price)) * 10 ** (18 - oracle.decimals());
        if (_scaledPrice < 1 ether) revert InvalidOraclePrice();
        return (_scaledPrice, timestamp);
    }
```

This is an issue because, not all LSTs are pegged to ETH at a ratio greater than 1 ether. 

For reference, the protocol aims to deploy L2 contracts on Base, Arbitrum, Linea, BSC, Mode;

```solidity
    function getMintRate() public view returns (uint256, uint256) {
        // revert if PriceFeedNotAvailable
        if (receiver == address(0) && address(oracle) == address(0)) revert PriceFeedNotAvailable();
        if (address(oracle) != address(0)) {
            (uint256 oraclePrice, uint256 oracleTimestamp) = oracle.getMintRate(); //@note
            return
                oracleTimestamp > lastPriceTimestamp
                    ? (oraclePrice, oracleTimestamp)
                    : (lastPrice, lastPriceTimestamp);
        } else {
            return (lastPrice, lastPriceTimestamp);
        }
    }
```

The tight restriction set will cause that on most of the chains to be deployed on, the calls will always revert causing depositing tokens to mint xezETH to be virtually impossible.

Manual code review

## Recommended Mitigation Steps

Reduce the scaledPrice restriction to something lesser, maybe 0,95, taking into considerations the price deviations and offering protections in case of depegs.
