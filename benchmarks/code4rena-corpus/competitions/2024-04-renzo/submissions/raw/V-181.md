# Vulnerability details

## Impact
The `recoverERC20` provide the admin with the ability to withdraw user assets from the protocol contracts, effectively allowing them to perform a "rug pull" and drain user funds, leaving the protocol insolvent.

## Proof of Concept
An admin can call the `recoverERC20` and rugpull the project whenever they want.

## Tools Used
Manual Review

## Recommended Mitigation Steps
Allow access to only the relevant parts of protocol funds, e.g. by tracking fees internally. Forcing a timelock on the admin actions can be another mitigation.
