# Vulnerability details

## Description
The `getMintRate` function in the `xRenzoDeposit` contract retrieves the current price of `ezETH` from configured price feeds. However, there is a potential issue where the function may return stale or outdated price information if `oracleTimestamp` is less than or equal to `lastPriceTimestamp`. 

Stale price feeds could lead to inaccurate conversion rates, impacting users' ability to mint `xezETH` tokens at fair market value. 

## Impact
Stale prices may result in inaccurate conversion rates, leading to discrepancies between expected and actual token minting values for users. Outdated price feeds increase the risk of market manipulation, as attackers could exploit price discrepancies to their advantage. Persistent issues with stale prices could damage the platform's reputation, affecting its credibility and attractiveness to users and investors.

## Proof of Concept
See the following code:

```
function getMintRate() public view returns (uint256, uint256) {
        // revert if PriceFeedNotAvailable
        if (receiver == address(0) && address(oracle) == address(0)) revert PriceFeedNotAvailable();
        if (address(oracle) != address(0)) {
            (uint256 oraclePrice, uint256 oracleTimestamp) = oracle.getMintRate();
            return
                oracleTimestamp > lastPriceTimestamp
                    ? (oraclePrice, oracleTimestamp)
                    : (lastPrice, lastPriceTimestamp);
        } else {
            return (lastPrice, lastPriceTimestamp);
        }
    }
```

## Recommended Mitigation Steps
Check the timestamp of the price feed response to ensure it falls within an acceptable range of freshness. If the timestamp exceeds a predefined threshold, consider the price feed stale and take appropriate action.
