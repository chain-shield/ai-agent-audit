# Vulnerability details

## Impact
Using abi.encodePacked with more than one argument in hash hashing function cause hash collision

## Proof of Concept
Using abi.encodePacked doesn't pad items to 32 bytes

test the below code in chisel
```solidity
abi.encodePacked(0x123,0x456)
```
the answer is 0x123456

```solidity
abi.encode(0x123,0x456)
```

the answer is 0x0...1230...456
because it treat every argument as 32 byte

## Tools Used

Manual

## Recommended Mitigation Steps

Use abi.encode() instead which will pad items to 32 bytes
```solidity
ex: bytes32 _salt = keccak256(abi.encod(_name, _symbol, msg.sender));
```
