# Vulnerability details

## Impact
Use Deprecated function of strategy manager `queueWithdrawl()` and `completeQueuedWithdrawl()`

## Proof of Concept
Note that Eigenlayer has a to-be-deprecated strategy manager, which was likely deprecated due to the problematic functions queueWithdrawl() and completeQueuedWithdrawl() following the issue outlined here. These deprecated functions are called in OperatorDelegator contract.

https://github.com/code-423n4/2023-04-eigenlayer-findings/issues/132


## Tools Used

Manual Review

## Recommended Mitigation Steps

 Do not make use of the functions in the deprecated strategy manager contract.
