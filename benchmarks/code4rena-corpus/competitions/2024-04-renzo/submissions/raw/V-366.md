# Vulnerability details

The `sendPrice` & `xReceive` functions is used to send the price feed and take all collateral and deposit it into Renzo to the L1. Both functions however are  NOT protected by sending funds to wrong destination whitelisted chain.

## Impact
Funds will be lost when calling the function with unauthorized destination chain

## Tools Used
Manual Review
## Recommended Mitigation Steps
Include the following code and add the modifier into both vital functions:
```solidity
    /// @dev Modifier that checks if the chain with the given destinationChainSelector is allowlisted.
    /// @param _destinationChainSelector The selector of the destination chain.
    modifier onlyAllowlistedDestinationChain(uint64 _destinationChainSelector) {
        if (!allowlistedDestinationChains[_destinationChainSelector])
            revert DestinationChainNotAllowed(_destinationChainSelector);
        _;
    }
```
