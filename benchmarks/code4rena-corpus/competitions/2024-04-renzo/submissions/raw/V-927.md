# Vulnerability details

`Operator Delegator` contract exposes `getTokenBalanceFromStrategy(IERC20 token)` function for TVL calculations. This function uses `queuedShares` mapping to get the underlying token amount from the amount of shares + queued withdrawal shares however instead of indexing with the token's address, it uses its own address leading to wrong values.
## Impact
High - leads to wrong TVL calculation.

## Tools Used
Manual review
## Recommended Mitigation Steps
`queuedShares[address(this)] == 0` this should be `queuedShares[address(token)]` on line 329.
