# Vulnerability details

## Impact
Invalid signature can be passed without reverting.

## Proof of Concept
The stakeEthFromQueue function accepts a signature parameter as part of its input, but there is no validation performed on this parameter within the function or in the stakeEthInOperatorDelegator function called subsequently. 

The same issue is in the stakeEthFromQueueMulti function.

## Tools Used
Manual review

## Recommended Mitigation Steps
Validate signature input.



## Assessed type

Access Control
