# Vulnerability details

## Impact

The `mint` function in OptimismMintableXERC20.sol or in XERC20.sol has no form of access control which allows for unlimited token minting if the OptimismMintableXERC20.sol is set as a bridge.

## Proof of Concept

The `mint` function in OptimismMintableXERC20.sol inherits the implementation from XERC20.sol without adding any access control checks. This creates a vulnerability where any user can potentially mint tokens up to OptimismMintableXERC20.sol's minting limit.

OptimismMintableXERC20.sol holds the `mint` function, which lacks any form of access control and calling the function calls `XERC20.mint(_to, _amount)`. Anyone can simply call the function passing in a `_to` of their choice.

```solidity
    function mint(address _to, uint256 _amount) public override(XERC20, IOptimismMintableERC20) {
        XERC20.mint(_to, _amount);
    }
```

`XERC20.mint` calls the `_mintWithCaller` passing in `msg.sender` as the caller, which is OptimismMintableXERC20.sol.

```solidity
    function mint(address _user, uint256 _amount) public virtual {
        _mintWithCaller(msg.sender, _user, _amount);
    }
```
Seeing as to facilitate minting, OptimismMintableXERC20 might be [set](https://github.com/code-423n4/2024-04-renzo/blob/519e518f2d8dec9acf6482b84a181e403070d22d/contracts/Bridge/xERC20/contracts/XERC20.sol#L135) as a bridge giving it the ability to mint. The check for mint will go through and the internal `_mint` function will be called. Any user can potentially mint as much tokens as they're able to, potentially dossing the mint limts and devaluaing the XERC20 token.


```solidity
    function _mintWithCaller(address _caller, address _user, uint256 _amount) internal {
        // Do not allow 0 value mints
        if (_amount == 0) revert IXERC20_INVALID_0_VALUE();

        if (_caller != lockbox) {
            uint256 _currentLimit = mintingCurrentLimitOf(_caller);
            if (_currentLimit < _amount) revert IXERC20_NotHighEnoughLimits();
            _useMinterLimits(_caller, _amount);
        }
        _mint(_user, _amount);
    }
```
