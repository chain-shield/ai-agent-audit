# Vulnerability details

Chainlink CCIP to transfer tokens and arbitrary data between smart contracts on different blockchains

To construct a CCIP-compatible message the EVM2AnyMessage struct is used. The arguments of struct include an `extraArgs` that is hardcoded in the contract.

According to the [documentation](https://docs.chain.link/ccip/tutorials/programmable-token-transfers#transferring-tokens-and-data-and-pay-in-link), for production deployments, make sure that `extraArgs` is mutable. This allows you to build it offchain and pass it in a call to a function or store it in a variable that you can update on-demand. This makes `extraArgs` compatible with future CCIP upgrades.

## Impact
Hardcoded gas fee may be insufficient due to future CCIP upgrades, causing the contract to revert on gasLimits.

## Tools Used
Manual Review
## Recommended Mitigation Steps
Allow admin to set gas price via a mutator method.
