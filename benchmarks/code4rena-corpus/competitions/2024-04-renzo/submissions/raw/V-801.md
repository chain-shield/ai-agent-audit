# Vulnerability details

## Impact
The `lookupTokenValue` function divides the price by a hard-coded scale-factor of `10e18` instead of getting the actual scale factor through Chainlink's `pricefeed.decimals` function. 

If any token is introduced that deviates from this scaling factor, it will cause incorrect price look-ups.

Manual review.

## Recommended Mitigation Steps
Use the `pricefeed.decimals` function provided by Chainlink.
