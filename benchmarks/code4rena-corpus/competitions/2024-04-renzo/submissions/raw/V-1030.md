# Vulnerability details

## Impact
In the contract xRenzoDeposit.sol, the function _trade() and sweep() are using OpenZeppelin’s safeApprove() which has been documented as (1) Deprecated because of approve-like race condition and (2) To be used only for initial setting of allowance (current allowance == 0) or resetting to 0 because it reverts otherwise.



## Proof of Concept
https://github.com/code-423n4/2024-04-renzo/blob/main/contracts/Bridge/L2/xRenzoDeposit.sol#L369

```solidity
depositToken.safeApprove(address(connext), _amountIn);
```

```solidity
collateralToken.safeApprove(address(connext), balance);
```

## Recommended Mitigation Steps

> The safeIncreaseAllowance and safeDecreaseAllowance functions should be used instead.
Comment from the OZ library for this function:

“// safeApprove should only be called when setting an initial allowance, // or when resetting it to zero. To increase and decrease it, use // 'safeIncreaseAllowance' and ‘safeDecreaseAllowance'"
