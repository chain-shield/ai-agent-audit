# Vulnerability details

## Impact

The `initialize()` function in the `RestakeManager` contract is marked as public initializer, which allows any account to call this function before the intended deployer.

Manipulation of Role Assignments:

The attacker can set the `IRoleManager` contract address to one they control, effectively granting themselves the "restake manager admin" and "deposit/withdraw pauser" roles.
This would give the attacker the ability to call the following admin-only functions:

setPaused(bool _paused): The attacker can pause or unpause the deposit and withdrawal functionality, potentially freezing user funds.

addOperatorDelegator(IOperatorDelegator _newOperatorDelegator, uint256 _allocationBasisPoints): The attacker can add new operator delegators to the protocol and set their allocations, potentially diverting user funds.

removeOperatorDelegator(IOperatorDelegator _operatorDelegatorToRemove): The attacker can remove legitimate operator delegators, disrupting the protocol's functionality.

setOperatorDelegatorAllocation(IOperatorDelegator _operatorDelegator, uint256 _allocationBasisPoints): The attacker can adjust the allocation of operator delegators, potentially diverting user funds.

setMaxDepositTVL(uint256 _maxDepositTVL): The attacker can set the maximum deposit TVL, limiting user participation in the protocol, or increasing it to infinity.

addCollateralToken(IERC20 _newCollateralToken) and removeCollateralToken(IERC20 _collateralToken): The attacker can add or remove supported collateral tokens, disrupting the protocol's functionality.


Disruption of Protocol Functionality:

The attacker can set the `IEzEthToken`, `IRenzoOracle`, `IStrategyManager`, `IDelegationManager`, and `IDepositQueue` contract addresses to ones they control, effectively hijacking the protocol's core functionality.
This would allow the attacker to manipulate token minting and burning, pricing mechanisms, delegation management, and the deposit/withdrawal process, leading to significant financial losses for users.


Disabling Protocol Pausing:

The attacker can set the paused state to false, preventing the protocol from being paused in the future, even by legitimate admins.
This would make it more difficult to mitigate any issues or attacks on the protocol.


## Proof of Concept

The attacker observes the deployment of the RestakeManager contract and quickly calls the `initialize()` function before the intended deployer.

The attacker sets the `IRoleManager` contract address to one they control, effectively granting themselves the "restake manager admin" and "deposit/withdraw pauser" roles.

The attacker can now call the admin-only functions mentioned above to manipulate the protocol's state, add malicious operator delegators, adjust TVL limits, and disrupt the overall functionality of the `RestakeManager` contract.

Users attempting to interact with the protocol will be subject to the attacker's manipulations, potentially leading to the loss of their funds or disruption of their expected interactions.

## Tools Used
Manual Review

## Recommended Mitigation Steps
Use the factory pattern to allow only the factory to call the initializer or ensure it is not front-runnable by calling `initialize` directly in the deploy script.
