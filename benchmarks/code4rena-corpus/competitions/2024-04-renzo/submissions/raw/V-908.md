# Vulnerability details

## Impact
if protocol wants to pause the **withdraw** and **claim** and carry out upgrade, the pause can not be applied effectively.

Also, when updating some of critical parameters such as cool down time, the team could pause the withdraw and redeem and update the cool down. 

## Proof of Concept

The contract has the **__Pausable_init** in initializer. But the pause and un-pause is not used anywhere in the WithdrawQueue. contract. 

https://github.com/code-423n4/2024-04-renzo/blob/519e518f2d8dec9acf6482b84a181e403070d22d/contracts/Withdraw/WithdrawQueue.sol#L135-L150

```solidity
    /**
     * @notice  Pause the contract
     * @dev     Permissioned call (onlyWithdrawQueueAdmin)
     */
    function pause() external onlyWithdrawQueueAdmin {
        _pause();
    }

    /**
     * @notice  Unpause the contract
     * @dev     Permissioned call (onlyWithdrawQueueAdmin)
     */
    function unpause() external onlyWithdrawQueueAdmin {
        _unpause();
    }

```

The pause and unpause functions in the contract serve as mechanisms to control the contract's functionality during exceptional circumstances or when maintenance operations are required. Here's why they are included:

**Emergency Pausing:** The pause function allows an authorized admin to halt certain functionalities of the contract in case of emergencies or unexpected issues. For example, if a critical vulnerability is discovered, pausing the contract can prevent further interactions and potential exploitation until the issue is resolved.
**Maintenance:** These functions can also be used during maintenance activities such as upgrades or fixes. By pausing the contract, developers can ensure that no new actions can be performed while updates are being applied. Once maintenance is complete, the unpause function can be called to resume normal operations.

## Tools Used

Manual review, VS code.

## Recommended Mitigation Steps

if pause and unpause wanted to be used, we would suggest to apply it in the necessary functions such as withdraw or claim or in other places where the team wanted to do it.
