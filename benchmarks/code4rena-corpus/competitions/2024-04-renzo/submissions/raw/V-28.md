# Vulnerability details

All the upgradeable contracts of openzeppelin has a init(), which is supposed to be called in initialize() to set the initial value, but in `WithdrawQueue.sol`, `xRenzoDeposit.sol`, `xRenzoBridge.sol`, __ReentrancyGuard_init() is not called in `initialize()`

## Impact
As a result, it will not work as intended
