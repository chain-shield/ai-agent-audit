# Vulnerability details

## Impact

The pausing/unpausing mechanism within `WithdrawQueue` does nothing.

## Proof of Concept

`WithdrawQueue` has code that allows admins to pause/unpause certain functionalities within the contract:

```solidity
/**
* @notice  Pause the contract
* @dev     Permissioned call (onlyWithdrawQueueAdmin)
*/
function pause() external onlyWithdrawQueueAdmin {
  _pause();
}

/**
* @notice  Unpause the contract
* @dev     Permissioned call (onlyWithdrawQueueAdmin)
*/
function unpause() external onlyWithdrawQueueAdmin {
  _unpause();
}

```

The issue here is that none of the functions apply the `whenPaused` and `whenNotPaused` modifiers. As the code stands right now, the pausing/unpausing functionality does nothing.

## Tools Used

Manual Review

## Recommended Mitigation Steps

Apply the `whenPaused` and `whenNotPaused` modifiers to the function that you want to be available and not available when the protocol is paused. I assume only `WithdrawQueue::withdraw()` and `WithdrawQueue::claim()` will ever need to be paused.
