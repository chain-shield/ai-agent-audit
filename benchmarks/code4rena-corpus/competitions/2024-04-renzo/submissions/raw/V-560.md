# Vulnerability details

## Summary
Chainlink recommends that all Optimistic L2 oracles consult the Sequencer Uptime Feed to ensure that the sequencer is live before trusting the data returned by the oracle. This check is not implemented in `RenzoOracleL2` while fetching price

## Vulnerability Detail
The RenzoOracleL2 will be deployed on L2 chain like Base, Arbitrum etc. The `getMintRate` function doesn't check if L2 sequencer is down after receiving the price. This will result in using stale price to calculate the amount of xezETH minted for deposited tokens in xRenzoDeposit. 

## Impact
Protocol will allow users to continue to operate at the stale rates.
  
## Tools Used
Manual review

## Recommended Mitigation Steps
Follow chainlink's example https://docs.chain.link/data-feeds/l2-sequencer-feeds#example-code
