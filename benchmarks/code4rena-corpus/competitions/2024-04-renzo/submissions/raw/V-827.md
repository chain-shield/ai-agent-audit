# Vulnerability details

## Vulnerability Detail
Users on an L2 can interact with the renzo protocol by calling `xRenzoDeposit::depositETH()`

This will end up minting the user xezETH on the L2.

Then an admin will call `sweep()` to bridge the deposited funds to the L1, deposit in Renzo, and lock up the ezETH in the lockbox on L1.

The problem is that there is no way for the user on the L2 to redeem their xezETH for ETH or another LST.

## Impact
The user on the L2 will be stuck with xezETH and will not be able to redeem it for ETH or another LST.

Refer to Vulnerability Details

## Recommended Mitigation Steps
Implement a withdraw functionality for L2 users.
