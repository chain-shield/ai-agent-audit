# Vulnerability details

## Impact
In ```deposit()```, ```collateralTokenTvlLimits[_collateralToken]``` is checked, if it is not zero, it tries to enforce the tvl limit of the collateral token being used to deposit. 

Enforcement of the tvl limit is done by looping through all delegators and adding each delegator tvl of the collateral token, includes the current amount to be deposited and then checking against the max.
```solidity
// Enforce individual token TVL limit if set, 0 means the check is not enabled
        if (collateralTokenTvlLimits[_collateralToken] != 0) {
            // Track the current token's TVL
            uint256 currentTokenTVL = 0;

            // For each OD, add up the token TVLs
            uint256 odLength = operatorDelegatorTokenTVLs.length;
            for (uint256 i = 0; i < odLength; ) {
        @>     currentTokenTVL += operatorDelegatorTokenTVLs[i][tokenIndex]; //@audit-issue the value here is zero!
                unchecked {
                    ++i;
                }
            }

            // Check if it is over the limit
            if (currentTokenTVL + collateralTokenValue > collateralTokenTvlLimits[_collateralToken])
                revert MaxTokenTVLReached(); 
        }
```

The problem here is that ```calculateTVLS()``` returns zero for ```operatorDelegatorTokenTVLs[][]```, so even if there is a tvl limit for a token, it can be easily bypassed and exceeded.

## Proof of Concept
```operatorDelegatorTokenTVL[i]``` was updated to ```operatorValues``` immediately after ```operatorValues``` was initialized, so ```operatorDelegatorTokenTVL[i]``` will be set to all zero since ```operatorValues``` have not been updated yet.
```solidity
// Track the individual token TVLs for this OD - native ETH will be last item in the array
            uint256[] memory operatorValues = new uint256[](collateralTokens.length + 1); 
      @>    operatorDelegatorTokenTVLs[i] = operatorValues; //@audit-issue untimely update!
```

## Recommended Mitigation Steps
Update ```operatorDelegatorTokenTVL[I]``` after the last item on the list of ```operatorValues``` have been updated.
```solidity
   // Track the individual token TVLs for this OD - native ETH will be last item in the array
            uint256[] memory operatorValues = new uint256[](collateralTokens.length + 1);
         -- operatorDelegatorTokenTVLs[i] = operatorValues; //@audit-issue untimely update!
```
Update after eth value have been included
```solidity
 // Get the value of native ETH staked for the OD
            uint256 operatorEthBalance = operatorDelegators[i].getStakedETHBalance();

            // Save it to the array for the OD
            operatorValues[operatorValues.length - 1] = operatorEthBalance; 
      ++    operatorDelegatorTokenTVLs[i] = operatorValues; //@audit-ok now all indexes have been updated with value!
```
