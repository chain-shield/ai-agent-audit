# Vulnerability details

## Impact

`bridgeRouterFeeBps` cannot be updated when desired, unlike other hardcoded parameters.

## Proof of Concept
The `bridgeRouterFeeBps`, `sweepBatchSize` and `BridgeFeeShare` are declared upon xRenzoDeposit.sol initialization as 5 bps.
```solidity
    function initialize(
        uint256 _currentPrice,
        IERC20 _xezETH,
        IERC20 _depositToken,
        IERC20 _collateralToken,
        IConnext _connext,
        bytes32 _swapKey,
        address _receiver,
        uint32 _bridgeDestinationDomain,
        address _bridgeTargetAddress,
        IRenzoOracleL2 _oracle
    ) public initializer {
...
        // Connext router fee is 5 basis points
        bridgeRouterFeeBps = 5;
...
        // set bridge Fee Share 0.05% where 100 basis point = 1%
        bridgeFeeShare = 5;

        //set sweep batch size to 32 ETH
        sweepBatchSize = 32 ether;
    }
```

In the `_trade` function, a check is performed to see if the `bridgeRouterFeeBps` is greater than zero, indicating that it is desired that the value can be changed, to zero or potentially a different parameter. 

```solidity
    function _trade(uint256 _amountIn, uint256 _deadline) internal returns (uint256) {
...
        // Subtract the bridge router fee
        if (bridgeRouterFeeBps > 0) {
            uint256 fee = (amountNextWETH * bridgeRouterFeeBps) / 10_000;
            amountNextWETH -= fee;
        }

        return amountNextWETH;
    }
```

The same can be observed with the `bridgeFeeShare` and `sweepBatchSize` parameters which are both hardcoded upon initialization, and also feature update functions to change their values, but there's none for `bridgeRouterFeeBps`.

```solidity
    function updateBridgeFeeShare(uint256 _newShare) external onlyOwner {
        if (_newShare > 100) revert InvalidBridgeFeeShare(_newShare);
        emit BridgeFeeShareUpdated(bridgeFeeShare, _newShare);
        bridgeFeeShare = _newShare;
    }
```

```solidity
    function updateSweepBatchSize(uint256 _newBatchSize) external onlyOwner {
        if (_newBatchSize < 32 ether) revert InvalidSweepBatchSize(_newBatchSize);
        emit SweepBatchSizeUpdated(sweepBatchSize, _newBatchSize);
        sweepBatchSize = _newBatchSize;
    }
```

Manual code review
## Recommended Mitigation Steps
Introduce a `updatebridgeRouterFeeBps` function.
