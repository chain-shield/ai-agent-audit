# Vulnerability details

## Impact
The function calls in the `WithdrawQueue` contract cannot be paused, thus in case of sudden emergencies, pausing measures may not be taken.

## Proof of Concept
The `WithdrawQueue` contract inherits the `PausableUpgradeable` contract and implements the `pause` and `unpause` functions, allowing the `WithdrawQueueAdmin` role to modify the `_paused` variable.

[WithdrawQueue.sol#L11-L15](https://github.com/code-423n4/2024-04-renzo/blob/main/contracts/Withdraw/WithdrawQueue.sol#L11-L15)

```solidity
contract WithdrawQueue is
    Initializable,
    PausableUpgradeable,
    ReentrancyGuardUpgradeable,
    WithdrawQueueStorageV1
```

[WithdrawQueue.sol#L135-L149](https://github.com/code-423n4/2024-04-renzo/blob/main/contracts/Withdraw/WithdrawQueue.sol#L135-L149)

```solidity
    /**
     * @notice  Pause the contract
     * @dev     Permissioned call (onlyWithdrawQueueAdmin)
     */
    function pause() external onlyWithdrawQueueAdmin {
        _pause();
    }

    /**
     * @notice  Unpause the contract
     * @dev     Permissioned call (onlyWithdrawQueueAdmin)
     */
    function unpause() external onlyWithdrawQueueAdmin {
        _unpause();
    }
```

Since the `WithdrawQueue` contract inherits the `PausableUpgradeable` contract, it should, by design, have the ability to be paused.

`whenNotPaused` and `whenPaused` modifiers should be used to control whether functions can be called when the contract is paused.

[PausableUpgradeable.sol#L42-L64](https://github.com/OpenZeppelin/openzeppelin-contracts-upgradeable/blob/v4.9.3/contracts/security/PausableUpgradeable.sol#L42-L64)
```solidity
    /**
     * @dev Modifier to make a function callable only when the contract is not paused.
     *
     * Requirements:
     *
     * - The contract must not be paused.
     */
    modifier whenNotPaused() {
        _requireNotPaused();
        _;
    }

    /**
     * @dev Modifier to make a function callable only when the contract is paused.
     *
     * Requirements:
     *
     * - The contract must be paused.
     */
    modifier whenPaused() {
        _requirePaused();
        _;
    }
```

However, in the `WithdrawQueue` contract, none of the functions have a `whenNotPaused` or `whenPaused` modifier to control when they can be executed. This means that all functions can be called at any time, regardless of the paused state of the contract.


## Tools Used
Manual Analysis

## Recommended Mitigation Steps
Review all the functions in the `WithdrawQueue` contract and then:
1. Add the `whenNotPaused` modifier to the functions requiring pause functionality.
2. Add the `whenPaused` modifier to make a function callable only when the contract is paused.
