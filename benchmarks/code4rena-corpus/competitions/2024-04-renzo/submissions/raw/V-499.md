# Vulnerability details


## Impact
This incorrect token balance will affect the `calculateTVLs` calculation so that the TVLs will be incorrect.
All operations relying on calculateTVLs, such as deposits and withdrawals, will be based on faulty data.

## Proof of Concept

The `queuedShares` is updated in the `queueWithdrawals` and `completeQueuedWithdrawl` function.
https://github.com/code-423n4/2024-04-renzo/blob/main/contracts/Delegation/OperatorDelegator.sol#L231~L232
```solidity
    // track shares of tokens withdraw for TVL
    queuedShares[address(tokens[i])] += queuedWithdrawalParams[0].shares[i];
```
https://github.com/code-423n4/2024-04-renzo/blob/main/contracts/Delegation/OperatorDelegator.sol#L280~L281
```solidity
    // deduct queued shares for tracking TVL
    queuedShares[address(tokens[i])] -= withdrawal.shares[i];
```

```solidity
    function getTokenBalanceFromStrategy(IERC20 token) external view returns (uint256) {
        return
            queuedShares[address(this)] == 0 // @audit always true
                ? tokenStrategyMapping[token].userUnderlyingView(address(this))
                : tokenStrategyMapping[token].userUnderlyingView(address(this)) +
                    tokenStrategyMapping[token].sharesToUnderlyingView(
                        queuedShares[address(token)]
                    );
    }
```

## Recommended Mitigation Steps
It's recommended to use the `address(token)` instead of `address(this)`.

```solidity
    function getTokenBalanceFromStrategy(IERC20 token) external view returns (uint256) {
        return
+            queuedShares[address(token)] == 0
                ? tokenStrategyMapping[token].userUnderlyingView(address(this))
                : tokenStrategyMapping[token].userUnderlyingView(address(this)) +
                    tokenStrategyMapping[token].sharesToUnderlyingView(
                        queuedShares[address(token)]
                    );
    }
```
