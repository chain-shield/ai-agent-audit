# Vulnerability details

## Impact
All protocol ETH rewards go back to `depositQueue` to be restaked without paying back the gas costs to admin.

## Proof of Concept
The _refundGas() function aims to reimburse the admin for gas costs using protocol rewards. However, since the receive() function is not called by the admin in the protocol, tx.origin does not point to the admin. Consequently, when adminGasSpentInWei[tx.origin] > 0 evaluates to false, the admin does not receive a refund.

## Tools Used
Manual review.

## Recommended Mitigation Steps
Replace `adminGasSpentInWei[tx.origin]` with `adminGasSpentInWei[nativeEthRestakeAdmin]` where `nativeEthRestakeAdmin` is a state variable of address type assigned the correct value.
