# Vulnerability details

## Impact
There is miscalculation in the function [calculateTVLs](https://github.com/code-423n4/2024-04-renzo/blob/519e518f2d8dec9acf6482b84a181e403070d22d/contracts/RestakeManager.sol#L274), which will break critical functions such as deposit and withdraw in the codebase.

## Proof of Concept
calculateTVLs function in RestakeManager.sol is used many times throughout the codebase.The issue with the function is  the flag for withdrawal queue balance as given below:
```solidity
       bool withdrawQueueTokenBalanceRecorded = false;         
```
Initially it is set to false  outside of the foor loops. if we analyze the loops in the function 


That means no calculation of token value of withdraw queue will be made for others operator delegators in the array, which will result in incorrect value of operatorTVL and totalTVL.
