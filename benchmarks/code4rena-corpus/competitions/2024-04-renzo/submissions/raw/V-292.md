# Vulnerability details

## Impact
Collateral tokens' value might exceed the collateral's limit `collateralTokenTvlLimits`

## Proof of Concept
Contract might set each collateral token's maximum limit called `collateralTokenTvlLimits`. When user deposits this collateral token, function should make sure that tvl after deposit() is less than `collateralTokenTvlLimits`. TVL for one collateral token includes collateral deposited in operator delegators, new deposited collateral tokens and collateral tokens in withdrawqueue contract. In deposit()'s check, we miss withdraw queue contract's collateral tokens. 

```c

            // For each OD, add up the token TVLs
```
