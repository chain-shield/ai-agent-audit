# Vulnerability details

## Vulnerability Detail
A malicious ezEth holder can sandwich eigenlayer's updates to a validator's penalty or slashing event in order to avoid the loss. 

Validators can lose some or all of their deposit via penalties or slashing events

* In case of penalties Eigenlayer can be notified of the balance drop via the permissionless function `EigenPod::verifyBalanceUpdates()`.
* In case of slashing the validator is forced to exit and Eigenlayer can be notified via the permissionless function `EigenPod::verifyAndProcessWithdrawals()`

As soon as either `EigenPod::verifyBalanceUpdates()` or `EigenPod::verifyAndProcessWithdrawals()` is called, the total TVL of the protocol drops instantly. This is because both of the functions reduce the `podOwnerShares[podOwner]` which is used in the TVL calculations.

A malicious ezEth holder can take advantage (in a single tx) of this by the following steps:

1. Identify a slashing or penalty event taking place
3. Request a withdrawal via `WithdrawQueue::withdraw()` at an inflated stale TVL to redeem all their ezETH holdings to ETH 
4. Call the permissionless function `EigenPod::verifyBalanceUpdates()` or `EigenPod::verifyAndProcessWithdrawals()`, to instantly drop the TVL
5. Deposit the same amount of ETH back into the protocol, at the new reduced TVL, so they will be minted more ezETH than they initially redeemed. 


## Impact
The attacker has avoided the loss due to validator penalties/slashing which will be paid by all other ezETH holders

The sandwich attack will end up with the attacker extracting value from all other ezETH holders.

The attack vector also involves redeeming ETH at an inflated stale TVL. This breaks the following main invariant defined by the protocol:

>ezETH should be minted or redeemed based on current supply and TVL.

## Recommended Mitigation Steps
One solution would be for the Renzo protocol to monitor validator slashing/penalty events and call `EigenPod::verifyBalanceUpdates()` or `EigenPod::verifyAndProcessWithdrawals()` immediately to decrease the likelihood of the attack.
