# Vulnerability details


## Impact
The `calculateTVLs` function in the `RestakeManager` contract is malfunctioning due to an incorrect index being used for the collateralTokens array.

## Proof of Concept

https://github.com/code-423n4/2024-04-renzo/blob/main/contracts/RestakeManager.sol#L315~L321
```solidity
    // record token value of withdraw queue
    if (!withdrawQueueTokenBalanceRecorded) {
        totalWithdrawalQueueValue += renzoOracle.lookupTokenValue(
            collateralTokens[i], // @audit should be j?
            collateralTokens[j].balanceOf(withdrawQueue)
        );
    }
```

## Tools Used
Manual review

## Recommended Mitigation Steps
It's recommended to use the `j` instead of `i` to loop up token values.

```solidity
    // record token value of withdraw queue
    if (!withdrawQueueTokenBalanceRecorded) {
        totalWithdrawalQueueValue += renzoOracle.lookupTokenValue(
+            collateralTokens[j],
            collateralTokens[j].balanceOf(withdrawQueue)
        );
    }
```
