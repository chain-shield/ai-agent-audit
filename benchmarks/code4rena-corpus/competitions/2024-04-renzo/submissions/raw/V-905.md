# Vulnerability details


## Impact
The feeBasisPoints can be set to 100%(10000) [here](https://github.com/code-423n4/2024-04-renzo/blob/main/contracts/Deposits/DepositQueue.sol#L103).
In this case, the `feeAmount` is the same as balance in the `sweepERC20`, which means the amount can be `0` to invoke the `restakeManager.depositTokenRewardsFromProtocol`.
The `OperatorDelegator`'s `deposit` function does not allow the `0` token amount.
So if the `feeBasisPoints` is 100%, the `sweepERC20` will always reverts.

## Proof of Concept
https://github.com/code-423n4/2024-04-renzo/blob/main/contracts/Deposits/DepositQueue.sol#L254~L277
```solidity
    function sweepERC20(IERC20 token) external onlyERC20RewardsAdmin {
        uint256 balance = IERC20(token).balanceOf(address(this));
        if (balance > 0) {
            uint256 feeAmount = 0;

            // Sweep fees if configured
            if (feeAddress != address(0x0) && feeBasisPoints > 0) {
                feeAmount = (balance * feeBasisPoints) / 10000; // @audit feeBasisPoints can be 10000
                IERC20(token).safeTransfer(feeAddress, feeAmount);

                emit ProtocolFeesPaid(token, feeAmount, feeAddress);
            }

            // Approve and deposit the rewards
            token.approve(address(restakeManager), balance - feeAmount);
            restakeManager.depositTokenRewardsFromProtocol(token, balance - feeAmount); // @audit balance - feeAmount can be 0

            // Add to the total earned
            totalEarned[address(token)] = totalEarned[address(token)] + balance - feeAmount;

            // Emit the rewards event
            emit RewardsDeposited(IERC20(address(token)), balance - feeAmount);
        }
    }
```

    function deposit(
        IERC20 token,
        uint256 tokenAmount
    ) external nonReentrant onlyRestakeManager returns (uint256 shares) {
        if (address(tokenStrategyMapping[token]) == address(0x0) || tokenAmount == 0) // @audit reverts if tokenAmount == 0
            revert InvalidZeroInput();

        // Move the tokens into this contract
        token.safeTransferFrom(msg.sender, address(this), tokenAmount);

        return _deposit(token, tokenAmount);

## Recommended Mitigation Steps
It's recommended to add a check if balance != feeAmount before calling the `depositTokenRewardsFromProtocol`. Or consider changing the `feeBasisPoints` limitation.
