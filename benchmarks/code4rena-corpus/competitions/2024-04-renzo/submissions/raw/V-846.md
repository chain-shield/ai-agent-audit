# Vulnerability details

An indexing error exists within the `calculateTVLs()` function in `RestakeManager` contract, potentially leading to incorrect Total Value Locked (TVL) calculations for tokens held in the withdrawal queue.

## Impact
The use of an incorrect index may result in adding the wrong token value to the `totalWithdrawalQueueValue`, leading to an inaccurate representation of the protocol's TVL. This can affect decision-making processes within the protocol that rely on accurate TVL data.

## Proof of Concept
The issue is present in the following code block:

```solidity
    if (!withdrawQueueTokenBalanceRecorded) {
        totalWithdrawalQueueValue += renzoOracle.lookupTokenValue(
@-->        collateralTokens[i], // @audit Incorrect index used here
            collateralTokens[j].balanceOf(withdrawQueue)
        );
    }
```

The variable i is incorrectly used to reference a token in the `collateralTokens` array, where `j` should be used as it is the correct index for iterating over collateral tokens.

Manual Review

## Recommended Mitigation Steps
Correct the indexing within the conditional statement to use `j` instead of `i`:

```diff
    if (!withdrawQueueTokenBalanceRecorded) {
        totalWithdrawalQueueValue += renzoOracle.lookupTokenValue(
-           collateralTokens[i],
+           collateralTokens[j],
            collateralTokens[j].balanceOf(withdrawQueue)
        );
    }
```
