# Vulnerability details

## Impact
The withdrawal can be completed hence the token will be locked in `EigenLayer` until the strategy is not set again.

## Proof of Concept
The `OperatorDelegator` contract allow to set strategy for token that are being deposits in Eigen Layer. The Contract also allow to remove the strategy by setting it to `0x0`:
```solidity
/contracts/Delegation/OperatorDelegator.sol:105
105:     /// @dev Sets the strategy for a given token - setting strategy to 0x0 removes the ability to deposit and withdraw token
106:     function setTokenStrategy(
107:         IERC20 _token,
108:         IStrategy _strategy
109:     ) external nonReentrant onlyOperatorDelegatorAdmin {
110:         if (address(_token) == address(0x0)) revert InvalidZeroInput();
111: 
112:         tokenStrategyMapping[_token] = _strategy;
113:         emit TokenStrategyUpdated(_token, _strategy);
114:     }
```
To withdraw assets from Eigen layer the withdrawal most of the time takes 7 days. so first we need to request withdrawal and after 7 days we call the complete withdrawal transaction.
The concern function for this issue are `queueWithdrawals` or  `completeQueuedWithdrawal`. when `completeQueuedWithdrawal` this function get called it will withdraw the assets from Eigen Layer. deduct the fee from it and deposit the remaining amount in Eigen Layer again using strategy set for this token. The issue will arise if we remove the strategy for a given token.
As it can be arise in both function  but i will explain the `completeQueuedWithdrawal` function.

1. The strategy for token XYZ set to strategy ABC.
2. The user Deposits assets in Eigen layer using this strategy.
3. The users submit `queueWithdrawals` transaction .The eigenLayer will do these things mention [here](https://github.com/Layr-Labs/eigenlayer-contracts/blob/dev/docs/core/DelegationManager.md#queuewithdrawals) in docs.
4. During 7 days delay, The strategy got removed from Renzo and set to `0x0`.
5. After 7 days delay ,The user call `completeQueuedWithdrawal` Which after deduction the Fee amount and perform other required checks, then it check if the `balanceOfToken>0` then it tries to `_deposit` the remaining amount it will revert because the `_strategy` has removed for `token`.
