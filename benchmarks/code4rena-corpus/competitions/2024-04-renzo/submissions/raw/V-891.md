# Vulnerability details

## Impact
```solidity
    function _execute(address target, uint256 value, bytes calldata data) internal virtual {
        (bool success, ) = target.call{ value: value }(data);
        require(success, "TimelockController: underlying transaction reverted");
    }
```
[target.call{value: value}(data)](https://github.com/code-423n4/2024-04-renzo/blob/519e518f2d8dec9acf6482b84a181e403070d22d/contracts/TimelockController.sol#L369) line is sending value amount of Ether to the address specified by the target variable, which can be any address. This is considered a security risk because an attacker could potentially drain the contract's funds by calling this function repeatedly with different addresses. 

## Vulnerability Details
In the line [(bool success, ) = target.call{ value: value }(data);](https://github.com/code-423n4/2024-04-renzo/blob/519e518f2d8dec9acf6482b84a181e403070d22d/contracts/TimelockController.sol#L369). This line sends value amount of Ether to the address specified by target using the call function. _The call function is a low-level function that executes a call to a target address, and it does not include any security checks to prevent reentrancy attacks._

> The edge case that leads to the vulnerability is when the target address is a contract address that contains a fallback function (also known as a receive function). When the call function is used to send Ether to a contract address, the fallback function is executed. If the fallback function calls the [_execute](https://github.com/code-423n4/2024-04-renzo/blob/519e518f2d8dec9acf6482b84a181e403070d22d/contracts/TimelockController.sol#L368-L371) function again, it creates a recursive loop that can be exploited by an attacker to drain the contract's funds.

## Recommended Mitigation Steps
Use the transfer or send functions instead of call, as they include additional security checks to prevent reentrancy attacks.
```solidity
function _execute(address target, uint256 value, bytes calldata data) internal virtual {
    (bool success, ) = target.transfer(value);
    require(success, "TimelockController: underlying transaction reverted");
}
```
