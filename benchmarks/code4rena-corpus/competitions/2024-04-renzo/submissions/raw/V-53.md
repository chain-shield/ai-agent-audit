# Vulnerability details

User `deposits` collateral token into protocol and in return receives `ezETH`, which depends on the `depositedAmount`, `ezETH totalSupply` and `totalTVL`.
 Similarly, amount of token user will receive at withdraw also depends on `withdrawAmount`, `ezETH totalSupply` and `totalTVL`
```solidity
   uint256 ezETHToMint = renzoOracle.calculateMintAmount(
            totalTVL,
            collateralTokenValue,
            ezETH.totalSupply()
        );
```
```solidity
   uint256 amountToRedeem = renzoOracle.calculateRedeemAmount(
            _amount,
            ezETH.totalSupply(),
            totalTVL
        );
```

Rewards received by protocol is deposited back through `DepositQueue::receive()`, which increases the `totalTVL` of the protocol
```solidity
   receive() external payable nonReentrant {
        uint256 feeAmount = 0;
             //Code...
        // update remaining rewards
        uint256 remainingRewards = msg.value - feeAmount;
        // Check and fill ETH withdraw buffer if required
     @>   _checkAndFillETHWithdrawBuffer(remainingRewards);

           //Code...
    }
```
Now the problem is a malicious actor can frontrun `OperatorDelegator::withdrawNonBeaconChainETHBalanceWei()`(which is withdrawing rewards from EigenLayer, which will go to rewardHandler or depositQueue) to deposit collateral token into the protocol to mint `ezETH` and withdraw `just` after reward is deposited, `stealing` other users reward.


//How this works(very simple example)
1. Suppose initial totalTVL = ezETHTotalSupply = 8 ether(simple calculation)
1. Suppose protocol receives a reward of 4 ether and its going to be deposited back
2. malicious actor saw this and frontrun this to deposit asset amount worth 2 ezETH
3. after deposit, totalTVL = 10 ether, ezETHTotalSupply = 10 ether(assume 1:1 exchange rate)
4. reward of 4 ether is deposited back, which increases the totalTVL to 14 ether but ezETHTotalSupply is still 10 ether
5. malicious actor `immediately` withdraw his 2 ezETH
6. his redeemAmount = (totalTVL * withdrawAmount)/ ezEthTotalSupply ie 14*2/10 = 2.8 ether

This `extra` 0.8 ether was honest users `reward` who were deposited their collateral since `beginning` 

## Impact
Malicious actor will steal reward of honest users
