# Vulnerability details

## Title
`WithdrawQueue::withdraw` and `WithdrawQueue::claim` are missing `whenNotPaused` modifier which lets user call the functions even functionalities are paused. 

## Impact
The contract `WithdrawQueue` implements Openzeppelin's `PausableUpgradeable` functionalities to pause the functions of the contracts. 

https://github.com/code-423n4/2024-04-renzo/blob/1c7cc4e632564349b204b4b5e5f494c9b0bc631d/contracts/Withdraw/WithdrawQueue.sol#L139C1-L149C6

```solidity 
    function pause() external onlyWithdrawQueueAdmin {
        _pause();
    }

    /**
     * @notice  Unpause the contract
     * @dev     Permissioned call (onlyWithdrawQueueAdmin)
     */
    function unpause() external onlyWithdrawQueueAdmin {
        _unpause();
    }
```
But issue is that the modifier `whenNotPaused` is never used in the contract. The withdrawal and claim functionalities should be paused as the `onlyWithdrawQueueAdmin` paused these two important functions. If security vulnerable situation comes such as Oracle returning an manipulated price for a longer period then in `WithdrawQueque::withdraw`, `onlyWithdrawQueueAdmin` can pause the users from creating withdrawing request and claim requests even after cool down period is over for claim request.

## Recommended Mitigation Steps
We recommend to add the `whenNotPaused` modifier in both of these two functions.

```diff
-   function withdraw(uint256 _amount, address _assetOut) external nonReentrant {
+   function withdraw(uint256 _amount, address _assetOut) external nonReentrant whenNotPaused{
        ...
    }

-   function claim(uint256 withdrawRequestIndex) external nonReentrant {
+   function claim(uint256 withdrawRequestIndex) external nonReentrant whenNotPaused{
        ...
    }
```
