# Vulnerability details

## Impact
The `initialize()` function in the `OperatorDelegator` contract is marked as `external`, which allows any external account to call this function before the intended deployer.

An attacker can front-run the intended deployer and call the `initialize()` function first. This would allow the attacker to set the initial state of the `OperatorDelegator` contract to their advantage, including:

Manipulation of Role Assignments:

The attacker can set the IRoleManager contract address to one they control, effectively granting themselves the "operator delegator admin" role.
This would give the attacker the ability to call the following admin-only functions:

setTokenStrategy(IERC20 _token, IStrategy _strategy): The attacker can set the strategy for a given token, potentially directing user deposits to a malicious strategy.

setDelegateAddress(address _delegateAddress, ISignatureUtils.SignatureWithExpiry memory approverSignatureAndExpiry, bytes32 approverSalt): The attacker can set the delegate address for the OperatorDelegator, potentially redirecting user funds to an address they control.

setBaseGasAmountSpent(uint256 _baseGasAmountSpent): The attacker can adjust the base gas amount spent, potentially affecting the protocol's economics or gas efficiency.


Disruption of Protocol Functionality:

The attacker can set the `IStrategyManager`, `IRestakeManager`, `IDelegationManager`, and `IEigenPodManager` contract addresses to ones they control, effectively hijacking the protocol's delegation and staking mechanisms.
This would allow the attacker to manipulate the deposit, withdrawal, and staking processes, leading to significant financial losses for users.


Unauthorized EigenPod Deployment:

The attacker can potentially create a malicious `EigenPod` contract and set it as the `eigenPod` in the `OperatorDelegator`, allowing them to intercept and divert user funds.

## Proof of Concept
The attacker observes the deployment of the `OperatorDelegator` contract and quickly front-runs the `initialize()` function before the intended deployer.

The attacker sets the IRoleManager contract address to one they control, effectively granting themselves the "operator delegator admin" role.

The attacker can now call the admin-only functions mentioned above to manipulate the token strategies, delegate address, and base gas amount, effectively hijacking the core functionality of the `OperatorDelegator` contract.

Users attempting to interact with the protocol through the `OperatorDelegator` will be subject to the attacker's manipulations, potentially leading to the loss of their funds or disruption of their expected interactions.

## Tools Used
Manual Review

## Recommended Mitigation Steps
Use the factory pattern to allow only the factory to call the initializer or ensure it is not front-runnable by calling `initialize` directly in the deploy script.
