# Vulnerability details

## **Vulnerability Details:**

The **[queueWithdrawals](https://github.com/code-423n4/2024-04-renzo/blob/1c7cc4e632564349b204b4b5e5f494c9b0bc631d/contracts/Delegation/OperatorDelegator.sol#L193)** function in the **OperatorDelegator** contract allows the NativeEthRestakeAdmin to queue one or more withdrawals of shares across any strategy. After waiting for the maximum number of blocks, the **[completeQueuedWithdrawal](https://github.com/code-423n4/2024-04-renzo/blob/1c7cc4e632564349b204b4b5e5f494c9b0bc631d/contracts/Delegation/OperatorDelegator.sol#L265)** function can be called to complete the specified withdrawal.

The **completeQueuedWithdrawal** function completes the queued withdrawal from EigenLayer with **receiveAsToken** set to true, checks the withdraw buffer and fills it back up if it is below the buffer target, and redeposits the remaining tokens back to EigenLayer. The problem with this is that if the protocol needs to permanently exit a strategy, it is currently not possible as the function will redeposit any remaining tokens.

```solidity
    function completeQueuedWithdrawal(
        ...
    ) external nonReentrant onlyNativeEthRestakeAdmin {
        ...
        // complete the queued withdrawal from EigenLayer with receiveAsToken set to true
        delegationManager.completeQueuedWithdrawal(withdrawal, tokens, middlewareTimesIndex, true);
        IWithdrawQueue withdrawQueue = restakeManager.depositQueue().withdrawQueue();
        for (uint256 i; i < tokens.length;) {
            ...
            // check if token is not Native ETH
            if (address(tokens[i]) != IS_NATIVE) {
                ...
                // get balance of this contract
                uint256 balanceOfToken = tokens[i].balanceOf(address(this));
                if (bufferToFill > 0) {
                    ...
                    // fill Withdraw Buffer via depositQueue
                    restakeManager.depositQueue().fillERC20withdrawBuffer(address(tokens[i]), bufferToFill);
                }
                // Deposit remaining tokens back to eigenLayer
                if (balanceOfToken > 0) {
                    _deposit(tokens[i], balanceOfToken);
                }
            }
            unchecked {
                ++i;
            }
        }
        ...
    }
```

One solution could be to increase a token's withdraw buffer up to the point where it accounts for all withdrawn tokens; however, this would mean compromising the requirements of the withdraw buffer's functionality.

## **Impact:**

- Severity: Medium. The current implementation limits the protocol's ability to permanently exit a strategy.
- Likelihood: Medium. This issue will occur every time it is needed to permanently exit a strategy.

## **Tools Used:**

- Manual analysis

## **Recommendation:**

Consider implementing a mechanism that allows the protocol to permanently exit a strategy without redepositing remaining tokens. This could involve modifying the withdraw process or introducing a new function specifically for permanent strategy exits.
