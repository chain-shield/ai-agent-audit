# Vulnerability details

## Description
The `addOperatorDelegator` & `setOperatorDelegatorAllocation` functions in the `RestakeManager` contract has a potential vulnerability related to input validation of `_newOperatorDelegator` (addOperatorDelegator only)  & `_allocationBasisPoints` variables. 
## Impact
`addOperatorDelegator` is not checking `_newOperatorDelegator` for `0` address. If it restake manager mistakenly sends 0 address, it would automatically set it to that. Which can disrupt the whole functionality related to it.

Similarly it is also no validating `_allocationBasisPoints` for `0` value. The condition used is `if (_allocationBasisPoints > (100 * BASIS_POINTS))` but wht if  `_allocationBasisPoints == 0`? Which can be setting no allocation points resulting in unexpected functionality. 
## Proof of Concept
See the following code:
```
function addOperatorDelegator(
        IOperatorDelegator _newOperatorDelegator,
        uint256 _allocationBasisPoints
    ) external onlyRestakeManagerAdmin {
        // Ensure it is not already in the list
        uint256 odLength = operatorDelegators.length;
        for (uint256 i = 0; i < odLength; ) {
            if (address(operatorDelegators[i]) == address(_newOperatorDelegator))
                revert AlreadyAdded();
            unchecked {
                ++i;
            }
        }

        // Verify a valid allocation
        if (_allocationBasisPoints > (100 * BASIS_POINTS)) revert OverMaxBasisPoints();

        // Add it to the list
        operatorDelegators.push(_newOperatorDelegator);

        emit OperatorDelegatorAdded(_newOperatorDelegator);

        // Set the allocation
        operatorDelegatorAllocations[_newOperatorDelegator] = _allocationBasisPoints;

        emit OperatorDelegatorAllocationUpdated(_newOperatorDelegator, _allocationBasisPoints);
    }
```

## Recommended Mitigation Steps
Ensure that these variables in the `addOperatorDelegator` function are properly validated to prevent the addition of unauthorized operator delegators or incorrect allocation values.
