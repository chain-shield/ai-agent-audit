# Vulnerability details

## Impact
The `recoverNative` function in `xRenzoDeposit` provides admins with the ability to rugpull as much ETH as they want. If they decide to rug-pull, they can, leaving the protocol totally insolvent.

## Proof of Concept
An admin can call the `recoverNative` and rugpull the project whenever they want.

## Tools Used
Manual Review

## Recommended Mitigation Steps
Allow access to only the relevant parts of protocol funds, e.g. by tracking fees internally. Forcing a timelock on the admin actions can be another mitigation.
