# Vulnerability details

## Impact
An underflow occurs when a subtraction operation results in a negative value. In Solidity, unsigned integers wrap around when underflow occurs, leading to unexpected large positive values instead of throwing an error. In this case, if `_amount` is smaller than `bufferToFill`, `_amount -= bufferToFill` will result in `_amount` becoming a large positive value instead of reverting the transaction as might be expected.

## Proof of Concept
```solidity
if (bufferToFill > 0) {
            bufferToFill = (_amount <= bufferToFill) ? _amount : bufferToFill;
            // update amount to send to the operator Delegator
            _amount -= bufferToFill;

```
