# Vulnerability details

## Impact
Deposits might not be distributed precisely among operator delegators according to their allocation threshold, leading to imbalances or allocations that differ from expectations.

## Proof of Concept
The deposit allocation process is not precise. For instance, consider a scenario with three operator delegators (ODs):
- Total Value Locked (TVL) is 100.
- Allocation thresholds for OD1, OD2, and OD3 are 10%, 45%, and 45%, respectively.
- The TVL of operator delegators is 10, 45, and 45, respectively.

In this setup, the next deposit will be assigned to the first operator delegator because all delegators meet their allocation thresholds.
```solidity
    function chooseOperatorDelegatorForDeposit(
        uint256[] memory tvls,
        uint256 totalTVL
    ) public view returns (IOperatorDelegator) {
        // Ensure OperatorDelegator list is not empty
        if (operatorDelegators.length == 0) revert NotFound();

        // If there is only one operator delegator, return it
        if (operatorDelegators.length == 1) {
            return operatorDelegators[0];
        }

        // Otherwise, find the operator delegator with TVL below the threshold
        uint256 tvlLength = tvls.length;
        for (uint256 i = 0; i < tvlLength; ) {
            if (
                tvls[i] <
                (operatorDelegatorAllocations[operatorDelegators[i]] * totalTVL) /
                    BASIS_POINTS /
                    BASIS_POINTS
            ) {
                return operatorDelegators[i];
            }

            unchecked {
                ++i;
            }
        }

        // Default to the first operator delegator
        return operatorDelegators[0];
    }
```

If a large deposit is made (e.g., 900), it will be allocated entirely to the first operator delegator (OD1), increasing its TVL to 910. Now, despite OD1's allocation threshold being 10%, it holds 91% of the TVL, which significantly deviates from the expected allocation. Meanwhile, the other two ODs, which were expected to hold 90% of the TVL combined, now only hold 9%.

## Recommended Mitigation Steps
To address this, divide the deposit amount into smaller parts and allocate them to each operator delegator gradually to avoid imbalance situations. Alternatively, distribute deposits among operator delegators based on their allocation percentages. This ensures a fair distribution of deposits and prevents unexpected imbalances.
