# Vulnerability details

## Impact
The use of the `transfer()` function in the xRenzoDeposit contract could result in a Denial of Service (DoS) attack, causing the contract to fail when sending Ether to a contract with a fallback function that consumes more than 2300 gas.

## Proof of Concept

1. Deploy a contract with a fallback function that consumes more than 2300 gas.
2. Call the `recoverNative()` function in the xRenzoDeposit contract with the deployed contract's address as the `_to` parameter and any amount of Ether.
3. The `transfer()` function will fail, causing the `recoverNative()` function to revert.

## Tools Used

Solidity, Remix IDE

## Recommended Mitigation Steps
Replace the `transfer()` function with the `call.value().gas()()` function, which forwards all available gas and can invoke more complex functionality in the recipient contract. Additionally, check the return value of the `call` function to ensure that the transfer was successful.
