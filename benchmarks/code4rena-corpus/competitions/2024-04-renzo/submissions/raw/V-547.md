# Vulnerability details

## Impact
The `TimelockController` contract allows the zero address (`address(0)`) to be granted the `EXECUTOR_ROLE`. If this occurs, either intentionally or by mistake, any address can execute operations without explicitly having the `EXECUTOR_ROLE` assigned to them. This could lead to unauthorized execution of sensitive operations, potentially compromising the security of the contract and any dependent systems.

## Proof of Concept
The `onlyRoleOrOpenRole` modifier in the `TimelockController` contract allows execution if the caller has the specified role or if the zero address has been granted that role:

https://github.com/code-423n4/2024-04-renzo/blob/519e518f2d8dec9acf6482b84a181e403070d22d/contracts/TimelockController.sol#L127-L132
```solidity
modifier onlyRoleOrOpenRole(bytes32 role) {
    if (!hasRole(role, address(0))) {
        _checkRole(role, _msgSender());
    }
    _;
}
```

The constructor of the contract allows the possibility of assigning roles, including the `EXECUTOR_ROLE`, to the zero address:
https://github.com/code-423n4/2024-04-renzo/blob/519e518f2d8dec9acf6482b84a181e403070d22d/contracts/TimelockController.sol#L87-L119

```solidity
constructor(
    uint256 minDelay,
    address[] memory proposers,
    address[] memory executors,
    address admin
) {
    // ...

    // register executors
    for (uint256 i = 0; i < executors.length; ++i) {
        _setupRole(EXECUTOR_ROLE, executors[i]);
    }

    // ...
}
```

If the `executors` array passed to the constructor contains the zero address, it will be granted the `EXECUTOR_ROLE`. This allows anyone to execute operations without having the role explicitly assigned to them.

Exploit Scenario:
Alice creates a `TimelockController` contract, which is misconfigured using
one zero address. As a result, Eve is allowed to run proposals.

## Recommended Mitigation Steps:
Consider modifying the constructor to disallow assigning roles to the zero address:

```diff
constructor(
    uint256 minDelay,
    address[] memory proposers,
    address[] memory executors,
    address admin
) {
    // ...

    // register executors
    for (uint256 i = 0; i < executors.length; ++i) {
+        require(executors[i] != address(0), "TimelockController: cannot assign role to zero address");
        _setupRole(EXECUTOR_ROLE, executors[i]);
    }

    // ...
}
```
