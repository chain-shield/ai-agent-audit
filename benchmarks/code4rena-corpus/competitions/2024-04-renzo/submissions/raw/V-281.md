# Vulnerability details

## Impact

When the protocol receive rewards from the EigenLayer, those rewards for ex. native ETH is channelled to the DepositQueue contract through the rewardHandler, increasing the totalTVL currently hold by the protocol. Since ezETH supply is backed by the totalTVL, any ezETH token holder receive more value for their shares as the more value get added to the protocol. 

Before rewards get add to the totalTVL, an attacker could take advantage by frontrunning it with the deposit txn in RestakeManager(which mints ezETH token shares to the attacker) , and immediately backrunning it with `withdrawQueue::withdraw()` request.
