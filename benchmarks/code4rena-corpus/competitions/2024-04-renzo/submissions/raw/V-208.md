# Vulnerability details

## Impact

`RestakeManager::calculateTVLs()` is used for rate calculation throughout the protocol, incorrect tvls return by it could be disaster to the protocol. 

While calculating the value holded by WithdrawQueue through `lookupTokenValue()`, it uses index `i` instead of `j`, meaning it passes the same collateral address during the for-loop but differnt balance(which are correponding to other collateralTokens) to get the value. As a result, `totalWithdrawalQueueValue` recorded wrong token value from the withdrawQueue, which later added to `totalTVL`. 

## Proof of Concept
There are many instances. I'll cover one of them, which uses this `totalTVL` to calculate the mintRate for `xezETH` token on L2.  

BalancerRateProvide uses the current `totalTVL` to return the ezETH price in ETH via getRate(), 
https://github.com/code-423n4/2024-04-renzo/blob/519e518f2d8dec9acf6482b84a181e403070d22d/contracts/RateProvider/BalancerRateProvider.sol#L29-L41

this function is utilized by `xRenzoBridge::sendPrice()` to send the price as a exchangeRate to the `CCIPReceiver` contract on L2, 
https://github.com/code-423n4/2024-04-renzo/blob/519e518f2d8dec9acf6482b84a181e403070d22d/contracts/Bridge/L1/xRenzoBridge.sol#L215-L216

where the receiver contract, further calls `xRenzoDeposit.updatePrice(_price,)` to reflect the latest ezETH price from L1
https://github.com/code-423n4/2024-04-renzo/blob/519e518f2d8dec9acf6482b84a181e403070d22d/contracts/Bridge/L2/PriceFeed/CCIPReceiver.sol#L77

And finally, the `xRenzoDeposit::deposit()` utilized those received price to calculate the xezETH mintAmount. 
https://github.com/code-423n4/2024-04-renzo/blob/519e518f2d8dec9acf6482b84a181e403070d22d/contracts/Bridge/L2/xRenzoDeposit.sol#L245

## Recommended Mitigation Steps
Change collateralTokens[i] -> collateralTokens[j] [here](https://github.com/code-423n4/2024-04-renzo/blob/519e518f2d8dec9acf6482b84a181e403070d22d/contracts/RestakeManager.sol#L318),
```diff
        totalWithdrawalQueueValue += renzoOracle.lookupTokenValue(
-	    collateralTokens[i],
+           collateralTokens[j],
            collateralTokens[j].balanceOf(withdrawQueue)
        );
```
