# Vulnerability details

## Description
The parameters sent to the `initialize` function of `XERC20Factory`, `XERC20Lockbox`, `OptimismMintableXERC20` & `RestakeManager` contracts are not validated for anything.
## Impact
During deployment of these contracts, these params may be set with incorrect or invalid addresses for essential components such as role managers, tokens, or other contracts, leading to operational issues or incorrect behavior. 

Lets say if they are set to zero addresses. Main functionality of these contracts will just stop and protocol will face permanent DOS. As some of those params are for roles that have controlled access for handling all the critical actions in these contracts, which will result in NO Access to any of those actions. Also some of those params are not changeable, which means if they are set to invalid values then you are going to face issues for the rest of the time. 
## Proof of Concept
See the following code:

RestakeManager.sol
```
 function initialize(
        IRoleManager _roleManager,
        IEzEthToken _ezETH,
        IRenzoOracle _renzoOracle,
        IStrategyManager _strategyManager,
        IDelegationManager _delegationManager,
        IDepositQueue _depositQueue
    ) public initializer {
        __ReentrancyGuard_init();

        roleManager = _roleManager;
        ezETH = _ezETH;
        renzoOracle = _renzoOracle;
        strategyManager = _strategyManager;
        delegationManager = _delegationManager;
        depositQueue = _depositQueue;
        paused = false;
    }
```

XERC20Factory.sol
```
 function initialize(
        address _lockboxImplementation,
        address _xerc20Implementation
    ) public initializer {
        lockboxImplementation = _lockboxImplementation;
        xerc20Implementation = _xerc20Implementation;
    }
```

XERC20Lockbox.sol
```
 function initialize(address _xerc20, address _erc20, bool _isNative) public initializer {
        XERC20 = IXERC20(_xerc20);
        ERC20 = IERC20(_erc20);
        IS_NATIVE = _isNative;
    }
```

OptimismMintableXERC20.sol
```
 function initialize(
        string memory _name,
        string memory _symbol,
        address _factory,

    ) public initializer {
        __ERC165_init();
        __XERC20_init(_name, _symbol, _factory);
        l1Token = _l1Token;
```

## Recommended Mitigation Steps
Do proper validation of these parameters. Verify the format and validity of the addresses provided for essential components such as role managers, tokens, or other contracts, preventing misconfigurations or invalid configurations during initialization.
