# Vulnerability details

## Impact
`DepositQueue` will quickly run out of money due to lack of restriction on `tx.gasprice`. If the `tx.gasprice` has been high, this will quickly exhaust the ETH in the contract.


## Proof of Concept
`DepositQueue` will refund the ETH spent to `msg.sender`.

```solidity
    function _refundGas(uint256 initialGas) internal {
        uint256 gasUsed = (initialGas - gasleft()) * tx.gasprice;
        uint256 gasRefund = address(this).balance >= gasUsed ? gasUsed : address(this).balance;
        (bool success, ) = payable(msg.sender).call{ value: gasRefund }("");
        if (!success) revert TransferFailed();
        emit GasRefunded(msg.sender, gasRefund);
    }
```

The `gasUsed` is calculated using `tx.gasprice` without concerning if it is high or not. If the `tx.gasprice` has been high, this will quickly exhaust the ETH in the contract.

## Tools Used
Manual

## Recommended Mitigation Steps
It is recommended to set a upper limit for the gas to refund.
