# Vulnerability details

## Impact
This calculation error can lead to no operator delegators being selected under normal conditions because the calculated threshold is unrealistically low. This could disrupt the normal operation of depositing into the protocol.

The second issue is that the system will default to the first operator delegator for all deposits when all do not meet the threshold. This is unfair to the other delegators. This could lead to the first delegator receiving higher deposits when all other delegators do not meet the threshold.

This is a 2 in 1 issue caused by the double basis point division.

## Proof of Concept
    `function chooseOperatorDelegatorForDeposit(
        uint256[] memory tvls,
        uint256 totalTVL
    ) public view returns (IOperatorDelegator) {
        // Ensure OperatorDelegator list is not empty
        if (operatorDelegators.length == 0) revert NotFound();


        // If there is only one operator delegator, return it
        if (operatorDelegators.length == 1) {
            return operatorDelegators[0];
        }


        // Otherwise, find the operator delegator with TVL below the threshold
        uint256 tvlLength = tvls.length;
        for (uint256 i = 0; i < tvlLength; ) {
            if (
                tvls[i] <
                (operatorDelegatorAllocations[operatorDelegators[i]] * totalTVL) /
                    BASIS_POINTS /
                    BASIS_POINTS
            ) {
                return operatorDelegators[i];
            }


            unchecked {
                ++i;
            }
        }


        // Default to the first operator delegator
        return operatorDelegators[0];
    }`


Suppose:
BASIS_POINTS is 10,000
totalTVL is 1,000,000 units.
operatorDelegatorAllocations[operatorDelegators[i]] is 1,000 basis points (or 10%).
The expected calculation for a 10% allocation should be:

1,000 (basis points for 10%) * 1,000,000 (totalTVL) / 10,000 = 100,000

This result represents 10% of the `totalTVL`, which is the intended threshold.

However, with the double division:

1,000 * 1,000,000 / 10,000 / 10,000 = 10

## Recommended Mitigation Steps
`+` (operatorDelegatorAllocations[operatorDelegators[i]] totalTVL) / BASIS_POINTS
Make the allocation random and not just default to the first one in the operator delegator list to make it fair.
