# Vulnerability details

## Impact
Free gas refunds will be provided to the caller of the `stakeEthFromQueueMulti` function in the `DepositQueue` contract, if the function is called with zero value arrays for all the parameters, without performing any computation the refund gas will be added for the admin

## Proof of Concept
- When the `stakeEthFromQueueMulti` is called with zero value arrays for all parameters, as shown below 

```solidity
function stakeEthFromQueueMulti(
        IOperatorDelegator[] calldata operatorDelegators,
        bytes[] calldata pubkeys,
        bytes[] calldata signatures,
        bytes32[] calldata depositDataRoots
    ) external onlyNativeEthRestakeAdmin nonReentrant {
        uint256 gasBefore = gasleft();
        // Verify all arrays are the same length
        if (
            operatorDelegators.length != pubkeys.length ||
            operatorDelegators.length != signatures.length ||
            operatorDelegators.length != depositDataRoots.length
        ) revert MismatchedArrayLengths();

        // Iterate through the arrays and stake each one
        uint256 arrayLength = operatorDelegators.length;
        for (uint256 i = 0; i < arrayLength; ) {
            // Send the ETH and the params through to the restake manager
            restakeManager.stakeEthInOperatorDelegator{ value: 32 ether }(
                operatorDelegators[i],
                pubkeys[i],
                signatures[i],
                depositDataRoots[i]
            );

            emit ETHStakedFromQueue(
                operatorDelegators[i],
                pubkeys[i],
                32 ether,
                address(this).balance
            );

            unchecked {
                ++i;
            }
        }

        // Refund the gas to the Admin address if enough ETH available
        _refundGas(gasBefore);
    }
```

- when the function is called the if statement will pass, the loop will not execute, and then the _refundGas will execute and gas will actually be refunded to the caller without actually performing any computations

## Tools Used
Manual Review

## Recommended Mitigation Steps
Put an additional check to assert that if any of those parameters are zero and not only equal in length, the function should revert.
