# Vulnerability details

## Impact

getMintRate() will get temporarily DoSed when the ezETH price falls bellow 1 ether. Therefore, [xRenzoDeposit._deposit](https://github.com/code-423n4/2024-04-renzo/blob/main/contracts/Bridge/L2/xRenzoDeposit.sol#L245) will throw preventing users from deposioting into the contract.

The getMintRate() function faces a DoS situation when the price of ezETH drops below 1 ether. Consequently, the [xRenzoDeposit._deposit](https://github.com/code-423n4/2024-04-renzo/blob/main/contracts/Bridge/L2/xRenzoDeposit.sol#L245) function will throw an error, halting users from depositing into the contract.

## Proof of Concept

The getMintRate() function includes a check ensuring that the ezETH price remains equal to or above 1 ether:

```solidity
    function getMintRate() public view returns (uint256, uint256) {
        (, int256 price, , uint256 timestamp, ) = oracle.latestRoundData();
        if (timestamp < block.timestamp - MAX_TIME_WINDOW) revert OraclePriceExpired();
        // scale the price to have 18 decimals
        uint256 _scaledPrice = (uint256(price)) * 10 ** (18 - oracle.decimals());
        if (_scaledPrice < 1 ether) revert InvalidOraclePrice();
        return (_scaledPrice, timestamp);
    }
```

The concern here is that this check might disrupt the protocol if the ezETH price falls below 1 ether. Additionally, observation of the Renzo Restaked ETH [oracle](https://data.chain.link/feeds/ethereum/mainnet/ezeth-eth) reveals a price lower than 1 ether: 

- `answer 988816939838457900`

> Reference: https://etherscan.io/address/0x636A000262F6aA9e1F094ABF0aD8f645C44f641C#readContract

Consequently, deposits will face disruption during lunch time until the ezETH price rebounds to 1 ether.

## Recommended Mitigation Steps

Consider updating the getMintRate() function as follows:

```solidity
    function getMintRate() public view returns (uint256, uint256) {
        (, int256 price, , uint256 timestamp, ) = oracle.latestRoundData();
        if (timestamp < block.timestamp - MAX_TIME_WINDOW) revert OraclePriceExpired();
        if (price <= 0) revert();
        // scale the price to have 18 decimals
        uint256 _scaledPrice = (uint256(price)) * 10 ** (18 - oracle.decimals());
        return (_scaledPrice, timestamp);
    }
```
