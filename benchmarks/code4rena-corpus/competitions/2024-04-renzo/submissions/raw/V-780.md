# Vulnerability details

## Impact
when user call `withdrawTo` to send token to an address, and IS_NATIVE is set to true. 
the `_withdraw` function send NATIVE ether to `_to` address and revert if the code is not successful. 
but if the `_to` is a contract with no code. the call is always successful. whoever the user token will be burn and 
`withdrawTo` will not revert, and user will lost his token.
```solidity
function withdrawTo(address _to, uint256 _amount) external {
        _withdraw(_to, _amount);
    }
```
## Proof of Concept

```solidity
    function _withdraw(address _to, uint256 _amount) internal {
        emit Withdraw(_to, _amount);


        XERC20.burn(msg.sender, _amount);


        if (IS_NATIVE) {
            (bool _success, ) = payable(_to).call{ value: _amount }("");
            if (!_success) revert IXERC20Lockbox_WithdrawFailed();
        } else {
            ERC20.safeTransfer(_to, _amount);
        }
    }
```
