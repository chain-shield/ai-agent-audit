# Vulnerability details

## Impact

Deposits are vulnerable to inflation attacks, resulting in user losses.

## Proof of Concept

The formula for calculating the shares received by a user upon deposit is: `totalSupply(share) / (1 - (deltaAsset/(totalAsset+deltaAsset))) - totalSupply(share)`. 

However, in reality, this formula is equivalent to: `deltaAsset * SupplyShare / totalAsset`.

https://github.com/code-423n4/2024-04-renzo/blob/519e518f2d8dec9acf6482b84a181e403070d22d/contracts/Oracle/RenzoOracle.sol#L121-L149

Therefore, if a user donates to Withdraw, causing the totalAsset price to rise, this will result in the next user receiving significantly fewer shares than expected upon deposit, leading to losses.

Proof of Concept (PoC):

1. User B wants to deposit 100,000 tokens.
2. User A discovers B's transaction to deposit 100,000 tokens in the mempool and deposits 1 token first, obtaining 1 share.
3. User A then donates 49,999 tokens to the WithdrawQueue contract.
4. The share calculation for User B's deposit of 100,000 tokens is: 1 / (1 - (100,000 / (50,000 + 100,000))) - 1 => 2.999999 - 1 = 1.
5. User A withdraws 75,000 tokens.
