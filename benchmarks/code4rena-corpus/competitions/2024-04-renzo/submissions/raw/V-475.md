# Vulnerability details

## Impact

Stakers can avoid penalties, and other stakers have to bear the burden of the penalty.

## Proof of Concept

When depositing native token or LST to EigenLayer, the operators are subject to slashing conditions. When slashing happens, it will affect the total value of the collateral token in the operator delegator.

```
function calculateTVLs()

                // Get the value of this token

                uint256 operatorBalance = operatorDelegators[i].getTokenBalanceFromStrategy(
                    collateralTokens[j]
                );
```

This will affect the ezETH calculation conversion (a smaller TVL means lesser redeem amount).

```
        // Calculate amount to Redeem in ETH
        uint256 amountToRedeem = renzoOracle.calculateRedeemAmount(
            _amount,
            ezETH.totalSupply(),
            totalTVL
        );
```
```
 function calculateRedeemAmount(
        uint256 _ezETHBeingBurned,
        uint256 _existingEzETHSupply,
        uint256 _currentValueInProtocol
    ) external pure returns (uint256) {
        // This is just returning the percentage of TVL that matches the percentage of ezETH being burned
>        //@audit -> lower _currentValueInProtocol = lower redeemAmount
>        uint256 redeemAmount = (_currentValueInProtocol * _ezETHBeingBurned) / _existingEzETHSupply;

        // Sanity check
        if (redeemAmount == 0) revert InvalidTokenAmount();

        return redeemAmount;
    }
```

When users know that the validator is going to get slashed, they can frontrun the slashing event by withdrawing their ezETH. When `withdraw()` is called, a `withdrawRequest` will be created for the user.

```
 function withdraw(uint256 _amount, address _assetOut) external nonReentrant {
 // add withdraw request for msg.sender
        withdrawRequests[msg.sender].push(
            WithdrawRequest(
                _assetOut,
                withdrawRequestNonce,
                amountToRedeem,
                _amount,
                block.timestamp
            )
        );
```

After 7 days, the user can claim the same amount that is recorded in the `withdrawRequest` struct. 

```
 function claim(uint256 withdrawRequestIndex) external nonReentrant {
 // send selected redeem asset to user
        if (_withdrawRequest.collateralToken == IS_NATIVE) {
            payable(msg.sender).transfer(_withdrawRequest.amountToRedeem);
        } else {
            IERC20(_withdrawRequest.collateralToken).transfer(
                msg.sender,
                _withdrawRequest.amountToRedeem
            );
        }
        // emit the event
        emit WithdrawRequestClaimed(_withdrawRequest);
```

Other users that did not frontrun the slashing will have to bear the burden of the value of ezETH going down.

Recommend calculating the redeem amount again when claim is called using the same amount of ezETH deposited.
