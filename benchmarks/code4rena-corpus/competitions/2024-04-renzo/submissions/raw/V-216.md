# Vulnerability details

`xRenzoDeposit::_deposit` trade deposit tokens for nextWETH and mint xezETH. Within the function, bridge fee is calculated twice causing unfair fee charged.
```solidity
    function _deposit(
        uint256 _amountIn,
        uint256 _minOut,
        uint256 _deadline
    ) internal returns (uint256) {
        // calculate bridgeFee for deposit amount
        uint256 bridgeFee = getBridgeFeeShare(_amountIn);
        // subtract from _amountIn and add to bridgeFeeCollected
        _amountIn -= bridgeFee;
        bridgeFeeCollected += bridgeFee;

        // Trade deposit tokens for nextWETH
        uint256 amountOut = _trade(_amountIn, _deadline); //@audit-issue
        if (amountOut == 0) {
            revert InvalidZeroOutput();
        }
```
Within the `_deposit` function, `_trade` is utilized to deposit asset for nextWETH. The also deducts swapped assets with bridge fee, causing the user to pay the protocol bridge fee twice.
