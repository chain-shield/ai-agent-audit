# Vulnerability details

## Impact
The `OperatorDelegator` contract upgradeability is hindered due to the absence of the `Initializable` contract import. This prevents the proper use of the initializer function, which is essential for initializing upgradeable contracts. Without proper initialization, the contract may exhibit unexpected behavior during deployment or upgrade, potentially leading to security vulnerabilities and instability.

## Proof of Concept
Upgradeable contracts in Ethereum typically follow the pattern of separating the contract's state and logic into separate contracts. The logic contract is then made upgradeable by inheriting from the `Initializable` contract and using an initializer function to set initial state variables. However, in this case, the contract does not import the `Initializable` contract, which is crucial for initializing upgradeable contracts.

## Tools Used
Manual Review

## Recommended Mitigation Steps
Add the import statement for Initializable from OpenZeppelin to enable proper initialization of upgradeable contracts.

```javascript
import "@openzeppelin/contracts-upgradeable/proxy/utils/Initializable.sol";
```
