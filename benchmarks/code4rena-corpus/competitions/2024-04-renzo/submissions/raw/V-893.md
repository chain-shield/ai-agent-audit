# Vulnerability details

## Summary
If a strategy of a token is updated the previous balance in the strategy are not being considered for the TVL.

## Vulnerability detail
Strategy of a token can be updated using `setTokenStrategy` by `OperatorDelegatorAdmin`.

```
    function setTokenStrategy(
        IERC20 _token,
        IStrategy _strategy
    ) external nonReentrant onlyOperatorDelegatorAdmin {
        if (address(_token) == address(0x0)) revert InvalidZeroInput();

        tokenStrategyMapping[_token] = _strategy;
        emit TokenStrategyUpdated(_token, _strategy);
    }

```

If the strategy token is updated when there is token balance in the strategy, currently there is no mechanism to consider those balance in the TVL. This will result in less TVL value then intended. 

## Impact
Incorrect TVL calculation. Less value is accounted than actual value

## Tools Used
Manual review

## Recommended Mitigation Steps
Consider adding balance in previous strategy to TVL
