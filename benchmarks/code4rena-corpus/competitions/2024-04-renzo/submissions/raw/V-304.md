# Vulnerability details

## Description
 The sendPrice function takes two parameters: _destinationParam and _connextDestinationParam. These are arrays containing the details of the destination chains and the addresses of the corresponding receivers on those chains. The function does not validate the contents of these arrays before processing them, which means that any data passed into the function is used as-is.

## Impact
 If the arrays contain malformed or malicious data, this could result in failed transactions, incorrect exchange rates being sent, or exploitation of the contract's functionality. This could undermine the integrity of the price feed and potentially lead to financial losses or reputational damage.

## Proof of Concept

1 . Call sendPrice with a malformed entry in _destinationParam or _connextDestinationParam.
2 . Observe that the function processes the input without validation.
3 . Resulting behavior could be a failed transaction or incorrect data being sent to the receivers.



## Recommendation

 Implement thorough input validation for both _destinationParam and _connextDestinationParam arrays. Ensure that all fields within the structs are checked for correctness, such as valid addresses and sensible numerical values.
