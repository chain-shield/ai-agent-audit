# Vulnerability details

## Impact

`RestakeManager::calculateTVLs()` doesn't calculate the total value of the withdrawal queue correctly due to discrepancy when iterating over all of the collateral tokens.

## Proof of Concept

`RestakeManager::calculateTVLs()` uses the wrong token's price when calculating `totalWithdrawalQueueValue`.

Here's the piece we're interested in:

```solidity
  // Iterate through the tokens and get the value of each
  uint256 tokenLength = collateralTokens.length;
  for (uint256 j = 0; j < tokenLength; ) {
      // Get the value of this token

      uint256 operatorBalance = operatorDelegators[i].getTokenBalanceFromStrategy(
          collateralTokens[j]
      );

      // Set the value in the array for this OD
      operatorValues[j] = renzoOracle.lookupTokenValue(
          collateralTokens[j],
          operatorBalance
      );

      // Add it to the total TVL for this OD
      operatorTVL += operatorValues[j];

      // record token value of withdraw queue
      if (!withdrawQueueTokenBalanceRecorded) {
          totalWithdrawalQueueValue += renzoOracle.lookupTokenValue(
              collateralTokens[i],
              collateralTokens[j].balanceOf(withdrawQueue)
          );
      }

      unchecked {
          ++j;
      }
  }
```

The following code is wrong:

```solidity
// Set the value in the array for this OD
totalWithdrawalQueueValue += renzoOracle.lookupTokenValue(
    collateralTokens[i],
    collateralTokens[j].balanceOf(withdrawQueue)
);
```

It uses the balance of the currently iterated token with a different token due to the index used being wrong (`i` instead of `j`). This leads to the `totalWithdrawalQueueValue` being completely off when multiple collateral tokens are present. This then affects the accounting of all functions dependent on `RestakeManager::calculateTVLs()` within the protocol.

## Tools Used

Manual Review

## Recommended Mitigation Steps

Change the code to:

```solidity
totalWithdrawalQueueValue += renzoOracle.lookupTokenValue(
    collateralTokens[j],
    collateralTokens[j].balanceOf(withdrawQueue)
);
```
