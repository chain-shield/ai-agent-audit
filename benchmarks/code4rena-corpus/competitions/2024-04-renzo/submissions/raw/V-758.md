# Vulnerability details

## Impact
The `transfer()` function sends a fixed stipend of 2300 gas with Ether, so if the protocol interacts with a fallback function (`receive`) that requires more than 2300 gas, the transaction is reverted.

## Proof of Concept
The `WIthdrawQueue.sol#claim()` function uses the `transfer` function, not `call`, when transferring ETH.
```solidity
    function claim(uint256 withdrawRequestIndex) external nonReentrant {
        SNIP...

        // send selected redeem asset to user
        if (_withdrawRequest.collateralToken == IS_NATIVE) {
303:        payable(msg.sender).transfer(_withdrawRequest.amountToRedeem);
        } else {
            IERC20(_withdrawRequest.collateralToken).transfer(
                msg.sender,
                _withdrawRequest.amountToRedeem
            );
        }
        SNIP...
    }
```
Here, `msg.sender` can be a contract if the protocol is integrated with an external protocol.
That is, the `receive` function of the `msg.sender` contract is called.
At this time, if a transaction requiring more than 2300 gas is executed in the `receive` function, the transaction is reverted because the transfer function sends a fixed stipend of 2300 gas with the Ether.

## Tools Used
Manual Review
## Recommended Mitigation Steps
Use the `call` instead of the `transfer` in ETH transfer.
