# Vulnerability details

## Impact
The exchange rate from ezETH to collaterals is miscalculated.
This issue may cause many unexpected critical errors.

## Proof of Concept
`BalancerRateProvider.sol#getRate` function is the following.
```solidity
    function getRate() external view returns (uint256) {
        // Get the total TVL priced in ETH from restakeManager
31:     (, , uint256 totalTVL) = restakeManager.calculateTVLs();

        // Get the total supply of the ezETH token
        uint256 totalSupply = ezETHToken.totalSupply();

        // Sanity check
        if (totalSupply == 0 || totalTVL == 0) revert InvalidZeroInput();

        // Return the rate
40:     return (10 ** 18 * totalTVL) / totalSupply;
    }
```
In `L31`, the `totalTVL` is calculated by the following `RestakeManager.sol#calculateTVLs`.
```solidity
    function calculateTVLs() public view returns (uint256[][] memory, uint256[] memory, uint256) {
        uint256[][] memory operatorDelegatorTokenTVLs = new uint256[][](operatorDelegators.length);
        uint256[] memory operatorDelegatorTVLs = new uint256[](operatorDelegators.length);
        uint256 totalTVL = 0;

        // Iterate through the ODs
        uint256 odLength = operatorDelegators.length;

        // flag for withdrawal queue balance set
        bool withdrawQueueTokenBalanceRecorded = false;
        address withdrawQueue = address(depositQueue.withdrawQueue());

        // withdrawalQueue total value
        uint256 totalWithdrawalQueueValue = 0;

        for (uint256 i = 0; i < odLength; ) {
            // Track the TVL for this OD
            uint256 operatorTVL = 0;

            // Track the individual token TVLs for this OD - native ETH will be last item in the array
            uint256[] memory operatorValues = new uint256[](collateralTokens.length + 1);
            operatorDelegatorTokenTVLs[i] = operatorValues;

            // Iterate through the tokens and get the value of each
            uint256 tokenLength = collateralTokens.length;
            for (uint256 j = 0; j < tokenLength; ) {
                // Get the value of this token

                uint256 operatorBalance = operatorDelegators[i].getTokenBalanceFromStrategy(
                    collateralTokens[j]
                );

                // Set the value in the array for this OD
                operatorValues[j] = renzoOracle.lookupTokenValue(
                    collateralTokens[j],
                    operatorBalance
                );

                // Add it to the total TVL for this OD
                operatorTVL += operatorValues[j];

                // record token value of withdraw queue
                if (!withdrawQueueTokenBalanceRecorded) {
                    totalWithdrawalQueueValue += renzoOracle.lookupTokenValue(
                        collateralTokens[i],
                        collateralTokens[j].balanceOf(withdrawQueue)
                    );
                }

                unchecked {
                    ++j;
                }
            }

            // Get the value of native ETH staked for the OD
            uint256 operatorEthBalance = operatorDelegators[i].getStakedETHBalance();

            // Save it to the array for the OD
            operatorValues[operatorValues.length - 1] = operatorEthBalance;

            // Add it to the total TVL for this OD
            operatorTVL += operatorEthBalance;

            // Add it to the total TVL for the protocol
            totalTVL += operatorTVL;

            // Save the TVL for this OD
            operatorDelegatorTVLs[i] = operatorTVL;

            // Set withdrawQueueTokenBalanceRecorded flag to true
            withdrawQueueTokenBalanceRecorded = true;

            unchecked {
                ++i;
            }
        }

        // Get the value of native ETH held in the deposit queue and add it to the total TVL
        totalTVL += address(depositQueue).balance;

        // Add native ETH help in withdraw Queue and totalWithdrawalQueueValue to totalTVL
        totalTVL += (address(withdrawQueue).balance + totalWithdrawalQueueValue);

        return (operatorDelegatorTokenTVLs, operatorDelegatorTVLs, totalTVL);
    }
```
That is, the `totalTVL` is the total sum of values of ETH and other collaterals which is hold by `operatorDelegators`, `withdrawQueue` and `depositQueue`.
Now the exchange rate is equal to `ezETH.totalSupply() / totalTVL` in `L40`.

But `withdrawQueue` holds collaterals which are already requested to be withdrawal.
Since the amount of ezETH which is exchanged with them are already determined, they will not be exchanged by the above exchange rate.

Example:
1. Assume that `totalTVL = 10000` and `ezETH.totalSupply() = 10000`. Then, the exchange rate will be `10000 / 10000 = 1` in `L40`.
2. Now, assume that total value of collaterals which are already requested to be withdrawal in `withdrawQueue` is `5000` and `ezETH.balanceOf(withdrawQueue) = 4000` holds.
3. Therefore, since the total value of collaterals which can be exchanged with ezETH after now is `10000 - 5000 = 5000` and the corresponding amount of ezETH is `10000 - 4000 = 6000`, the exchange rate should be `6000 / 5000 = 1.2`.

The same problems also exist in the `RestakeManager.sol#deposit`, `RestakeManager.sol#depositETH` and `WithdrawQueue.sol#withdraw` functions.

## Recommended Mitigation Steps
Insert the following function into `WithdrawQueue.sol`.
```solidity
    function totalClaimReserveValues() public view returns (uint256) {
        uint256 totalValues = 0;
        address[] collateralTokens = restakeManager.collateralTokens();
        for (uint256 i = 0; i < collateralTokens.length; i++) {
            address collateralToken = collateralTokens[i];
            totalValues += renzoOracle.lookupTokenValue(collateralToken, claimReserve[collateralToken]);            
        }
        return totalValues;
    }
```
Modify the `BalancerRateProvider.sol#getRate` function as follows.
```solidity
    function getRate() external view returns (uint256) {
        // Get the total TVL priced in ETH from restakeManager
        (, , uint256 totalTVL) = restakeManager.calculateTVLs();

        // Get the total supply of the ezETH token
        uint256 totalSupply = ezETHToken.totalSupply();

        // Sanity check
        if (totalSupply == 0 || totalTVL == 0) revert InvalidZeroInput();

        // Return the rate
--      return (10 ** 18 * totalTVL) / totalSupply;
++      return (10 ** 18 * (totalTVL - withdrawQueue.totalClaimReserveValues())) / (totalSupply - ezETHToken.balanceOf(withdrawQueue));
    }
```
Modify the `RestakeManager.sol#deposit`, `RestakeManager.sol#depositETH` and `WithdrawQueue.sol#withdraw` functions also in the same way.
