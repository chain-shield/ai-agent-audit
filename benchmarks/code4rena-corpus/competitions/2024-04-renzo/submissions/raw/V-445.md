# Vulnerability details

## Impact
The oracle used to get a token value cannot be disabled, violating the expected behaviour outlined in the dev comments for the function.

## Vulnerability details

The `RenzoOracle` contract is used in the protocol to fetch token prices using Chainlink. The price feed for each token is configured through the `RenzoOracle::setOracleAddress()` function:

https://github.com/code-423n4/2024-04-renzo/blob/519e518f2d8dec9acf6482b84a181e403070d22d/contracts/Oracle/RenzoOracle.sol#L54-L66
```solidity
/// @dev Sets addresses for oracle lookup.  Permission gated to oracel admins only.
    /// Set to address 0x0 to disable lookups for the token.
    function setOracleAddress(
        IERC20 _token,
        AggregatorV3Interface _oracleAddress
    ) external nonReentrant onlyOracleAdmin {
        if (address(_token) == address(0x0)) revert InvalidZeroInput();

        // Verify that the pricing of the oracle is 18 decimals - pricing calculations will be off otherwise
        if (_oracleAddress.decimals() != 18)
            revert InvalidTokenDecimals(18, _oracleAddress.decimals());

        tokenOracleLookup[_token] = _oracleAddress;
        emit OracleAddressUpdated(_token, _oracleAddress);
    }

```

The dev comment above the function clearly and explicitly defines the following assumption:
> Set to address 0x0 to disable lookups for the token.

However the current logic in the function does not allow the oracle for a token to be disabled by setting its address to 0. The reason is the following check:

```solidity
if (_oracleAddress.decimals() != 18)
            revert InvalidTokenDecimals(18, _oracleAddress.decimals());
```

It is always executed, which means that if `_oracleAddress` argument is passed as `address(0)` in order to disable the lookup the decimal check will still be executed and since there is no contract at address 0 it will revert.

        IERC20 _token,
        AggregatorV3Interface _oracleAddress
    ) external nonReentrant onlyOracleAdmin {
        if (address(_token) == address(0x0)) revert InvalidZeroInput();
