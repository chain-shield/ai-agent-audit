# Vulnerability details

The ConnextReceiver is used as a receiver. The problem lies within not using OZ upgradable contracts, when the implementation do uses them. 
```solidity
contract ConnextReceiver is IXReceiver, Ownable, Pausable { //@audit not upgradeable
    /// @notice The address of connext Bridge
    address public connect; //@audit

    /// @notice The Address of xRenzoBridge contract on L1
    address public xRenzoBridgeL1;  //@audit
```
```solidity
contract xRenzoBridge is
    IXReceiver,
    Initializable,
    ReentrancyGuardUpgradeable,
    xRenzoBridgeStorageV1
{}
````
## Impact
There may be complications due to upgrade.

## Tools Used
Manual Review
## Recommended Mitigation Steps

Ensure that contract is upgradable
```diff
-- contract ConnextReceiver is IXReceiver, Ownable, Pausable 
++ contract ConnextReceiver is IXReceiver, OwnableUpgradable, PausableUpgradable 
```
