# Vulnerability details

## Summary
The `mint()` and `burn()` functions in the `XERC20` contract are designed to be called by `bridges` according to the function comments, which are external entities or contracts authorized to create or destroy tokens.
```solidity
     * @dev Can only be called by a bridge
```

However, the code does not include explicit checks to verify that the `msg.sender` is indeed a legitimate `bridge`.

## Proof of Concept
The `mint()` and `burn()` functions do not include explicit checks to ensure that `msg.sender` is an authorized `bridge`, potentially allowing any address to invoke these critical functions.

> [mint()](https://github.com/code-423n4/2024-04-renzo/blob/519e518f2d8dec9acf6482b84a181e403070d22d/contracts/Bridge/xERC20/contracts/XERC20.sol#L96-L98)
```solidity
    // @dev Can only be called by a bridge
     
    function mint(address _user, uint256 _amount) public virtual {
        _mintWithCaller(msg.sender, _user, _amount);
    }
```
> [burn()](https://github.com/code-423n4/2024-04-renzo/blob/519e518f2d8dec9acf6482b84a181e403070d22d/contracts/Bridge/xERC20/contracts/XERC20.sol#L107-L113)
```solidity
        
    // @dev Can only be called by a bridge
     
    function burn(address _user, uint256 _amount) public virtual {
        if (msg.sender != _user) {
            _spendAllowance(_user, msg.sender, _amount);
        }

        _burnWithCaller(msg.sender, _user, _amount);
    }
```

The `mint()` and `burn()` makes an internal call to `_mintWithCaller()` and `_burnWithCaller()` respectively. Within these internal functions, a check is made for the `msg.sender` / `_caller`.

> [_mintWithCaller()](https://github.com/code-423n4/2024-04-renzo/blob/519e518f2d8dec9acf6482b84a181e403070d22d/contracts/Bridge/xERC20/contracts/XERC20.sol#L348-L358)
```solidity
    function _mintWithCaller(address _caller, address _user, uint256 _amount) internal {
        // Do not allow 0 value mints
        if (_amount == 0) revert IXERC20_INVALID_0_VALUE();


        if (_caller != lockbox) {
            uint256 _currentLimit = mintingCurrentLimitOf(_caller);
            if (_currentLimit < _amount) revert IXERC20_NotHighEnoughLimits();
            _useMinterLimits(_caller, _amount);
        }
        _mint(_user, _amount);
    }
```
> [_burnWithCaller()](https://github.com/code-423n4/2024-04-renzo/blob/519e518f2d8dec9acf6482b84a181e403070d22d/contracts/Bridge/xERC20/contracts/XERC20.sol#L328-L338)
```solidity
    function _burnWithCaller(address _caller, address _user, uint256 _amount) internal {
        // Do not allow 0 value burns
        if (_amount == 0) revert IXERC20_INVALID_0_VALUE();


        if (_caller != lockbox) {
            uint256 _currentLimit = burningCurrentLimitOf(_caller);
            if (_currentLimit < _amount) revert IXERC20_NotHighEnoughLimits();
            _useBurnerLimits(_caller, _amount);
        }
        _burn(_user, _amount);
    }
```
As it can be seen, if the `_caller == lockbox`, the functions proceed to mint/burn tokens of the specified `amount`s in the `_mint()` and `_burn()` calls respectively.

## Impact
`Lockbox Exception`: 
The `lockbox` address is exempt from these checks and can mint or burn without limits.
Here the `lockbox` does the minting/burning without a check they are indeed a `bridge`.

## Tools Used
Manual Review

## Recommended Mitigation Steps
Implement an access control mechanism to restrict the `mint()` and `burn()` functions to authorized `bridges` only. Use modifiers or require statements to check against a list of approved bridges.

```solidity
// Modifier definition
modifier onlyAuthorizedBridge() {
    require(isBridge[msg.sender], "XERC20: unauthorized bridge");
    _;
}

// Updated mint function with access control
function mint(address _user, uint256 _amount) public onlyAuthorizedBridge {
    _mintWithCaller(msg.sender, _user, _amount);
}

// Updated burn function with access control
function burn(address _user, uint256 _amount) public onlyAuthorizedBridge {
    if (msg.sender != _user) {
        _spendAllowance(_user, msg.sender, _amount);
    }
    _burnWithCaller(msg.sender, _user, _amount);
}
```
