# Vulnerability details

As per the README.md, users receive ezETH minted in proportion to their contribution to the total TVL. When user call the `RestakeManager::deposit()`, it will deposit tokens as collateral.

`RenzoOracle::calculateMintAmount`function is used and calculates the minting amount based on the current protocol value, newly added value, and ezETH supply. This function is vital for minting proportional LRT ezETH corresponding to the contributed collateral token. However, the calculation does not accurately yield proportional LRT based on the collateral value.

For every LST or ETH deposited on Renzo, it mints an equivalent amount of ezETH.[official docs](https://docs.renzoprotocol.com/docs/renzo/how-do-lrts-work).
## Impact
User will not get fair value of proportional tokens minted per collateral token value.

## Proof of Concept
Practical usage of collateral token would be in 1e18. 
```solidity
// SPDX-License-Identifier: MIT
pragma solidity ^0.8.0;

 contract RenzoTest {
    uint constant SCALE_FACTOR = 10 ** 18;

    // Used for PoC
    function checkInflationCalculation() public pure returns(uint amount){
        uint a = 1e18 + 10e18;
        amount = 1e18 * 10e18 / a;
    }
        // Used for PoC
    function checkNewEzETHSupply() public pure returns(uint amount){
        uint a = 1e18 - 909090909090909090;
        amount = 1e18 * 1e18 / a;
    } 
    function calculateMintAmount(
        uint256 _currentValueInProtocol, // assuming someone deposited 1e18
        uint256 _newValueAdded, // 1
        uint256 _existingEzETHSupply //1e18 minted
    ) public pure returns (uint256) {
        // For first mint, just return the new value added.
        // Checking both current value and existing supply to guard against gaming the initial mint
        if (_currentValueInProtocol == 0 || _existingEzETHSupply == 0) {
            return _newValueAdded; // value is priced in base units, so divide by scale factor
        }

        // Calculate the percentage of value after the deposit
        // proven that can never be 0
        // 1e18 * 1e18 / (1e18 + 1e18)
        // 1e36 / 2e18
        // 5e17 or 0.5e18
        // Second Scenario
        // 1e18 * 10e18 / (1e18 + 10e18)
        // 909090909090909090
        uint256 inflationPercentaage = (SCALE_FACTOR * _newValueAdded) /
            (_currentValueInProtocol + _newValueAdded);

        // Calculate the new supply
        // 1e18 * 1e18 / (1e18 - 5e17)
        //  1e36 / 5e17
        // 2e18
        // Second Scenario
        // 1e18 * 1e18 / (1e18 - 909090909090909090)
        // 10999999999999999890
        uint256 newEzETHSupply = (_existingEzETHSupply * SCALE_FACTOR) /
            (SCALE_FACTOR - inflationPercentaage);

        // Subtract the old supply from the new supply to get the amount to mint
        // 2e18 - 1e18 = 1e18
        // Second Scenario
        // 10999999999999999890 - 10e18
        uint256 mintAmount = newEzETHSupply - _existingEzETHSupply;
  
        // Sanity check
        if (mintAmount == 0) revert();

        return mintAmount;
    }
    function attack() public pure returns(uint minted_amount){
        // @audit Collateral Token not proportional to mint value
        // minted_amount = calculateMintAmount(1e18,1e18,1e18); // 1000000000000000000
        // minted_amount = calculateMintAmount(10e18,1e18,10e18); // 999999999999999998
        // minted_amount = calculateMintAmount(10e18,10,10e18); // 9
        minted_amount = calculateMintAmount(1e18,10e18,1e18); //  9999999999999999890
    }
 }
```
