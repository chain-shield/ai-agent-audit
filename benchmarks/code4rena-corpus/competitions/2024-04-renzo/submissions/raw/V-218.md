# Vulnerability details

`xRenzoDeposit::_trade` is utilized to deposit asset for nextWETH. The function did not update the state variable for `bridgeFeeCollected`.
```solidity
    // Total bridge fee collected for current batch
    uint256 public bridgeFeeCollected;
```
```solidity
    function _trade(uint256 _amountIn, uint256 _deadline) internal returns (uint256) {
    -- SNIP --
        // Subtract the bridge router fee
        //@audit Not Updated
        if (bridgeRouterFeeBps > 0) {
            uint256 fee = (amountNextWETH * bridgeRouterFeeBps) / 10_000;
            amountNextWETH -= fee;
        }
```

## Impact
bridgeFeeCollected is not updated causing the protocol to lose funds.


## Tools Used
Manual Review
## Recommended Mitigation Steps
Include the bridgeFeeCollected in the state variable
```diff
    function _trade(uint256 _amountIn, uint256 _deadline) internal returns (uint256) {
    -- SNIP --
        // Subtract the bridge router fee
        //@audit Deduct again?

            amountNextWETH -= fee;
++          bridgeFeeCollected += fee;
        }
```
