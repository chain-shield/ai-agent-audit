# Vulnerability details

## Impact
The following `WithdrawQueue.pause` and `WithdrawQueue.unpause` functions are meant to pause and unpause functions of the `WithdrawQueue` contract. However, none of the `WithdrawQueue` contract's functions have the `whenNotPaused` modifier. As a result, calling these `WithdrawQueue.pause` and `WithdrawQueue.unpause` functions are not effective, and the `WithdrawQueue` contract's functions of interest that need to be paused during an emergency cannot be paused when needed.

    function unpause() external onlyWithdrawQueueAdmin {
        _unpause();

## Proof of Concept
The following steps can occur for the described scenario.
1. A very volatile market condition occurs that causes a bank run.
2. The `WithdrawQueueAdmin` wants to temporarily pause the `WithdrawQueue.withdraw` and `WithdrawQueue.claim` functions until the market becomes more stable.
3. The `WithdrawQueueAdmin` calls the `WithdrawQueue.pause` function.
4. However, because such `WithdrawQueue.pause` function call is not effective, the `WithdrawQueue.withdraw` and `WithdrawQueue.claim` functions cannot be paused.
5. The bank run continues that negatively affects the protocol.

## Tools Used
Manual Review

## Recommended Mitigation Steps
The `whenNotPaused` modifier can be added to the `WithdrawQueue` contract's functions of interest.
