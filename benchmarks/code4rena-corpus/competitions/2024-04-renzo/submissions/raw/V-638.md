# Vulnerability details

## Impact
There's no way to identify which is native token or not in the contract potentially leading to loss of funds

## Proof of Concept
The initialize function in the XERC20Lockbox contract takes three parameters: _xerc20 (the address of the XERC20 contract), _erc20 (the address of the ERC20 token), and _isNative (a boolean indicating whether the ERC20 token is the native gas token of the chain or not).

However, there is no explicit validation or check within the initialize function to ensure that the _erc20 address corresponds to the actual native token of the chain when _isNative is set to true. Similarly, there is no validation to ensure that the _erc20 address corresponds to a non-native ERC20 token when _isNative is set to false.
## Tools Used

## Recommended Mitigation Steps
Use a special value to represent the native token, and validating that the xerc20 address matches this value when _isNative is true.
