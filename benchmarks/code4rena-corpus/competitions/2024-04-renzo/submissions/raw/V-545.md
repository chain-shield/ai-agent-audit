# Vulnerability details

## Vulnerability details
The `RestakeManager.calculateTVLs` function contains a section that computes the Total Value Locked (TVL) for the Liquidity Stake Tokens (LSTs) in the `withdrawQueue`. This calculation is performed by iterating over the LSTs in the `withdrawQueue` and determining their values using `renzoOracle.lookupTokenValue`. 
```
                // record token value of withdraw queue
                if (!withdrawQueueTokenBalanceRecorded) {
                    totalWithdrawalQueueValue += renzoOracle.lookupTokenValue(
                        collateralTokens[i],
                        collateralTokens[j].balanceOf(withdrawQueue)
                    );
                }
```
However, there's an error in the token address indexing: the correct token address should be `collateralTokens[j]`, not `collateralTokens[i]`.

Since the `totalWithdrawalQueueValue` is designed to be calculated only once (as indicated by the `withdrawQueueTokenBalanceRecorded` boolean variable in a loop), the index `i` would be zero when computing the `totalWithdrawalQueueValue`. Consequently, the `RestakeManager.calculateTVLs` function uses the price of the first LST to calculate the value of all LSTs for the TVL in `withdrawQueue`. This leads to an inaccurate calculation of the Total TVL in the protocol.

## Impact
The TVL derived from `RestakeManager.calculateTVLs` is vital to the entire Renzo protocol because it sets the price of ezETH. However, due to the incorrect calculation, the TVL uses the price of the first LST to determine the value of all LSTs for the TVL in `withdrawQueue`. 

If the price of the first LST is below average, the calculated TVL will be lower than it should be. This will result in a lower ezETH price, allowing depositors to profit as the mint price of ezETH is lower than it should be. Conversely, if the price of the first LST is above average, the calculated TVL will be higher than it should be. This will lead to a higher ezETH redeem price, benefiting users who withdraw from the protocol.

## Recommended Mitigation Steps
Correct the index typo:
```diff
- collateralTokens[i]
+ collateralTokens[j]
```
