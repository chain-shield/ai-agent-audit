# Vulnerability details

## Impact

Admin is not able to withdraw fees from `xRenzoDeposit` deposits, losing these funds forever.

## Proof of Concept

`xRenzoDeposit::_recoverBridgeFee()` unwraps the native from a wrapper, such as `WETH9`. However, the blockchain may not have a wrapper, as suggested in the comment [above](https://github.com/code-423n4/2024-04-renzo/blob/main/contracts/Bridge/L2/xRenzoDeposit.sol#L161).
Thus, fees would be lost.

## Tools Used

Vscode

## Recommended Mitigation Steps

Create a separate fee withdrawal function that does not unwrap.
