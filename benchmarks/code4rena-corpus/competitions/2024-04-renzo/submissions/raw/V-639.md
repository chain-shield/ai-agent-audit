# Vulnerability details

## Impact
The withdrawal queue does not consider the token balance for each collateral token, leading to an underestimation of the total TVL (Total Value Locked) of the protocol.

## Proof of Concept
The method `RestakeManager.calculateTVLs()` computes the total TVL of the protocol. While a withdrawal queue exists for each collateral token, their values must be aggregated to obtain `totalWithdrawalQueueValue`. However, the flag is initially set to True for the first token and remains unchanged for subsequent tokens. Consequently, the withdrawal queue token balance for tokens other than the first one is not considered.

## Tools Used
Manual review.

## Recommended Mitigation Steps
The flag should be initialized within the initial for loop and positioned before the commencement of the subsequent nested for loop.
