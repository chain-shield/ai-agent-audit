# Vulnerability details


## Impact
The `WithdrawQueue` smart contract inherits from OpenZeppelin's `PausableUpgradeable` contract, but there's no function to use `whenNotPaused` modifier.
This means the `WithdrawQueue` contract is not pausable.
The admin can't pause the withdraw and claim functions.

## Proof of Concept
https://github.com/code-423n4/2024-04-renzo/blob/main/contracts/Withdraw/WithdrawQueue.sol#L206
```solidity
    function withdraw(uint256 _amount, address _assetOut) external nonReentrant { // @audit whenNotPaused?
        // check for 0 values
        if (_amount == 0 || _assetOut == address(0)) revert InvalidZeroInput();
```

## Tools Used
Manual review

## Recommended Mitigation Steps
To enable pausing `withdraw` and `claim` in emergency situations, it's recommended to incorporate the `whenNotPaused` modifier to both functions.
