# Vulnerability details

## Impact
The `DEPOSIT_WITHDRAW_PAUSER` role cannot pause/unpause withdraw.

## Proof of Concept
Code4Rena's Renzo ReadME mentions that the `DEPOSIT_WITHDRAW_PAUSER` role can pause/unpause depositi/withdrawal.

Code4Rena's Renzo ReadME:
>   DEPOSIT_WITHDRAW_PAUSER:	   allows the admin to pause/unpause deposits and withdraws

However, in `WithdrawQueue`, only the `WITHDRAW_QUEUE_ADMIN` role is allowed to pause/unpause withdraw.

```solidity
    function pause() external onlyWithdrawQueueAdmin {
        _pause();
    }
```

```solidity
    function unpause() external onlyWithdrawQueueAdmin {
        _unpause();
    }
```
Therefore, the `DEPOSIT_WITHDRAW_PAUSER` role cannot pause/unpause withdraw.

## Tools Used
Manual Review
## Recommended Mitigation Steps
Add the following modifier to `WithdrawQueue.sol#pause()` and `WithdrawQueue.sol#unpause()`.

```solidity
    modifier onlyWithdrawQueueAdminOrDepositWithdrawPauserAdmin() {
        if (!roleManager.isWithdrawQueueAdmin(msg.sender) && !roleManager.isDepositWithdrawPauser(msg.sender)) revert NotWithdrawQueueAdmin();
        _;
    }
```
