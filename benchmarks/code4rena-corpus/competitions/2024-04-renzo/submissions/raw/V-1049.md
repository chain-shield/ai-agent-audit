# Vulnerability details

The CCIPReceiver is meant to be an upgradeable contract. This is indicated by the use of OpenZeppelin's upgradeable contract patterns and tools such as Initializable, OwnableUpgradeable, and other upgradeable extensions in the related contract files. These components are essential for creating upgradeable smart contracts on the Ethereum network, allowing for the modification and upgrading of contract logic while preserving the contract's state and address.

As far as I know, I don't see any implementation of upgradeable in the contract, meaning if others are upgraded and it is not it will not work as intended or not support any interaction with an upgradeable contract.

## Tools Used
Manual review

## Recommended Mitigation Steps
Make the CCIP receiver and the context contract an upgradeable contract with others so it can work well.
