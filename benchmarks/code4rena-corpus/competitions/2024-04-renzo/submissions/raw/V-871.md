# Vulnerability details

In `RestakeManager`'s `CalculateTVLs` function, the TVLs for each operator delegator by individual token, total for each OD, and total for the protocol is calculated. In the second inner for loop, `CalculateTVLs` function also records withdraw queue's token values, however the indexing is wrong, instead of looking up each collateral token's value it always looks up the first token's value using every other token's balance of withdraw queue.
## Impact
High - leads to wrong TVL calculation.

## Tools Used
Manual review
## Recommended Mitigation Steps
Change `collateralTokens[i]` to `collateralTokens[j]` on line 318.
