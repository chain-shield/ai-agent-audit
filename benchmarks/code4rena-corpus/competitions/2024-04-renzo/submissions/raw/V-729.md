# Vulnerability details


## Impact
Aside from the ``whenNotPaused`` modifier not being implement, onE of the protocol rules from both the readme: https://github.com/code-423n4/2024-04-renzo/tree/main?tab=readme-ov-file#all-trusted-roles-in-the-protocol, and code comments: 
```solidity

    /// @dev Determines if the specified address has permission to pause deposits and withdraws
    /// @param potentialAddress Address to check
    function isDepositWithdrawPauser(address potentialAddress) external view returns (bool) {
        return hasRole(DEPOSIT_WITHDRAW_PAUSER, potentialAddress);
    }
```
They all state that the ``DEPOSIT_WITHDRAW_PAUSER`` can pause withdrawals, however that is never implemented. 
In the ``WithdrawQueue`` no provision is made for this role. and the withdrawals cannot be paused from the restakeManager
## Proof of Concept
In the ``WithdrawQueue``, we have only this provision:
```solidity
    /**
     * @notice  Pause the contract
     * @dev     Permissioned call (onlyWithdrawQueueAdmin)
     */
    function pause() external onlyWithdrawQueueAdmin {
        _pause();
    }

    /**
     * @notice  Unpause the contract
     * @dev     Permissioned call (onlyWithdrawQueueAdmin)
     */
    function unpause() external onlyWithdrawQueueAdmin {
        _unpause();
    }
```
