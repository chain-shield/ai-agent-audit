# Vulnerability details

## Impact
The `recoverNative` function in the `xRenzoDeposit` contract is responsible for sweeping accidental ETH value sent to the contract. However, there is a lack of validation for the `amount` and `_to` parameters.

As this function uses `transfer`, which can fail silently or doesn't verify the `amount` and `to` address before the transaction. Without proper validation of these parameters, `ETH` amount can be set to zero address which can be lost permanently. It's also possible that amount entered isn't available at that moment, it will also fail silently without reverting or anything. 

## Proof of Concept
See the following code:

```
/**
     * @notice  Sweeps accidental ETH value sent to the contract
     * @dev     Restricted to be called by the Owner only.
     * @param   _amount  amount of native asset
     * @param   _to  destination address
     */
    function recoverNative(uint256 _amount, address _to) external onlyOwner {
        payable(_to).transfer(_amount);
    }
```
