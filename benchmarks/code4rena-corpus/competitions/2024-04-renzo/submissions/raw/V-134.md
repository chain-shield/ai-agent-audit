# Vulnerability details

## Impact
The potential arithmetic issues in the `getStakedETHBalance` function could lead to incorrect calculation of the staked ETH balance. This could result in inaccurate reporting of the contract's staked ETH holdings, potentially leading to incorrect decision-making in the protocol or affecting the overall integrity of the system's financial calculations.


## Proof of Concept
The `getStakedETHBalance` function in the provided contract contains potential arithmetic issues due to unsafe casting from `int256` to `uint256`. This function calculates the staked ETH balance based on the value of `podOwnerShares`, which represents the staked shares of the contract in EigenPod. However, the calculation method is prone to two specific issues:

- Unsigned Integer Underflow: In the case where `podOwnerShares` is negative, the code attempts to subtract -`podOwnerShares` from `stakedButNotVerifiedEth`. However, if the absolute value of `-podOwnerShares` exceeds the value of `stakedButNotVerifiedEth`, an underflow will occur, leading to unexpected behavior or potential contract revert.
- Signed Integer Overflow: If `podOwnerShares` is very large (positive), and `stakedButNotVerifiedEth` is also large, the subsequent addition of `podOwnerShares` to the sum of `queuedShares[IS_NATIVE]` and `stakedButNotVerifiedEth` could result in a signed integer overflow. This overflow may cause the calculation to wrap around to a smaller value or produce incorrect results. 
```solidity
  /// @dev Gets the amount of ETH staked in the EigenLayer
    function getStakedETHBalance() external view returns (uint256) {
        // accounts for current podOwner shares + stakedButNotVerified ETH + queued withdraw shares
        int256 podOwnerShares = eigenPodManager.podOwnerShares(address(this)); // @audit-info unsafe casting from int256 to uint256
        return
            podOwnerShares < 0
                ? queuedShares[IS_NATIVE] + stakedButNotVerifiedEth - uint256(-podOwnerShares)
                : queuedShares[IS_NATIVE] + stakedButNotVerifiedEth + uint256(podOwnerShares);
    }
```
