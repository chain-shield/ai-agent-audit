# Vulnerability details

## Impact
Each OperatorDelegator contract contains token mapping to the appropriate single strategy. Using the operator's contract, you can also check the value of deposited funds, which is used, for example, to calculate the totalTVL of the system and the TVL of a single operator.

## Proof of Concept
The problem may occur after changing/modifying the strategy allowed by the operator's contract without checking whether funds are deposited in the strategy.

```solidity
//OperatorDelegator.sol

     function setTokenStrategy(
         IERC20 _token,
         IStrategy _strategy
     ) external nonReentrant onlyOperatorDelegatorAdmin {
         if (address(_token) == address(0x0)) revert InvalidZeroInput();

         tokenStrategyMapping[_token] = _strategy;
         emit TokenStrategyUpdated(_token, _strategy);
     }

```

After changing the strategy without migrating funds, the TVL will be incorrectly calculated, which will affect the price of the ezETH exchange, the minted number of which will be the same as before the strategy change.

Another, related problem will be removing an operator without checking whether the strategies associated with it have deposited funds.

```solidity
//RestakeManager.sol

     function removeOperatorDelegator(
         IOperatorDelegator _operatorDelegatorToRemove
     ) external onlyRestakeManagerAdmin {
         // Remove it from the list
         uint256 odLength = operatorDelegators.length;
         for (uint256 i = 0; i < odLength; ) {
             if (address(operatorDelegators[i]) == address(_operatorDelegatorToRemove)) {
                 // Clear the allocation
                 operatorDelegatorAllocations[_operatorDelegatorToRemove] = 0;
                 emit OperatorDelegatorAllocationUpdated(_operatorDelegatorToRemove, 0);

                 // Remove from list
                 operatorDelegators[i] = operatorDelegators[operatorDelegators.length - 1];
                 operatorDelegators.pop();
                 emit OperatorDelegatorRemoved(_operatorDelegatorToRemove);
                 return;
             }
             unchecked {
                 ++i;
             }
         }

         // If the item was not found, throw an error
         revertNotFound();
     }
```

## Tools Used

Manual review

## Recommended Mitigation Steps

Prevent the strategy from being deleted if it has deposited funds (similarly in the case of the operator).
This can be done by checking the balance of the strategy using the `getTokenBalanceFromStrategy()` function;
