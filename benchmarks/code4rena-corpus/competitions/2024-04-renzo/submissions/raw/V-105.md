# Vulnerability details



## Impact
If the `_minDelay` is set to a very high value, it could make the timelock unusable, as any new operation would require an extremely long delay before it can be executed. This could lead to a situation where the controlled contract becomes stuck and unable to perform important administrative actions, such as updating critical parameters or addresses.

## Proof of Concept
The `TimelockController` contract allows setting the `_minDelay` to an arbitrary `uint256` value without an upper limit in the constructor:

https://github.com/code-423n4/2024-04-renzo/blob/519e518f2d8dec9acf6482b84a181e403070d22d/contracts/TimelockController.sol#L87-L87

```solidity
constructor(
    uint256 minDelay,
    address[] memory proposers,
    address[] memory executors,
    address admin
) {
    // ...
    _minDelay = minDelay;
    emit MinDelayChange(0, minDelay);
}
```

Additionally, the `updateDelay` function allows the timelock itself to change the `_minDelay` value to any arbitrary `uint256` value without an upper limit:

https://github.com/code-423n4/2024-04-renzo/blob/519e518f2d8dec9acf6482b84a181e403070d22d/contracts/TimelockController.sol#L402-L406

```solidity
function updateDelay(uint256 newDelay) external virtual {
    require(msg.sender == address(this), "TimelockController: caller must be timelock");
    emit MinDelayChange(_minDelay, newDelay);
    _minDelay = newDelay;
}
```

If either the constructor or the `updateDelay` function is called with a very high `minDelay` value, it could potentially make the timelock unusable.

## Recommended Mitigation Steps:
Consider introducing an upper limit for the `_minDelay` value. This can be done by defining a constant `MAX_DELAY` and adding a check in both the constructor and the `updateDelay` function to ensure the `_minDelay` does not exceed this limit:

```solidity
uint256 private constant MAX_DELAY = 30 days; // Adjust the value as needed

constructor(
    uint256 minDelay,
    // ...
) {
    // ...
    require(minDelay <= MAX_DELAY, "TimelockController: minDelay exceeds maximum");
    _minDelay = minDelay;
    // ...
}

function updateDelay(uint256 newDelay) external virtual {
    // ...
    require(newDelay <= MAX_DELAY, "TimelockController: newDelay exceeds maximum");
    _minDelay = newDelay;
}
```
