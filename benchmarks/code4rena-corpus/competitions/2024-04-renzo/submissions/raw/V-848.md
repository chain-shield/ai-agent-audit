# Vulnerability details

## Description
`WithdrawQueue.claim` uses `transfer` to send ETH to the caller, which can fail if the caller is a smart contract which receive implementation consume more than 2300 gas. This would leave the ETH suck forever in the contract.

## Impact
Withdraw funds stuck for some smart contract.

## Recommended mitigation
Simply use call instead of transfer

```diff
if (_withdrawRequest.collateralToken == IS_NATIVE) {
-   payable(msg.sender).transfer(_withdrawRequest.amountToRedeem);
+   payable(msg.sender).call{value: _withdrawRequest.amountToRedeem}();
} else {
    //...
}
```
