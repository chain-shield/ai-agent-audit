# Vulnerability details

## Impact
The `xRenzoBridge::recoverNative` function performs a low-level call to transfer Ether to the specified recipient address. However, the return value of the low-level call is not checked or handled. If the call fails silently, the transaction will still be considered successful, leading to potential loss of funds.

If the low-level call in `recoverNative` fails (e.g., if the recipient address is invalid or the transfer fails for any reason), the bridge contract will not detect the failure. This can result in the bridge contract losing track of funds or assuming the transfer was successful when it actually failed. Funds sent to invalid or non-existent addresses may be permanently lost.


## Proof of Concept
Create a new test file in the test folder and add the following code:
```javascript
// SPDX-License-Identifier: MIT
pragma solidity 0.8.19;

import {Test} from "forge-std/Test.sol";
import "../contracts/Delegation/OperatorDelegator.sol";
import "../contracts/Bridge/L1/xRenzoBridge.sol";
import "../contracts/Bridge/xERC20/contracts/XERC20Lockbox.sol";

contract XRenzoBridgeTest is Test {
    xRenzoBridge public bridge;

    function setUp() public {
        bridge = new xRenzoBridge();
    }

    function testUnhandledReturnValueInRecoverNative() public {
        // Arrange
        address payable recipient = payable(address(0x1));
        uint256 amount = 1 ether;

        // Act
        (bool success,) = address(bridge).call{value: amount}(
            abi.encodeWithSignature("recoverNative(uint256,address)", amount, recipient)
        );

        // Assert
        assertFalse(success, "recoverNative should fail");
        assertEq(address(recipient).balance, 0, "Recipient balance should be zero");
    }
}
```
Run this test with `forge test --mt testUnhandledReturnValueInRecoverNative`

After running this test, you will see that it passes, demonstrating that the unhandled return value in `recoverNative` can lead to silent failures and potential fund loss.

## Recommended Mitigation Steps
Always check the return value of low-level calls and handle the failure cases appropriately. In the `xRenzoBridge::recoverNative` function, add a check for the success of the low-level call. If the call fails, revert the transaction or emit an event to indicate the failure. Consider implementing additional checks, such as validating the recipient address, to prevent transfers to invalid or non-existent addresses.
