# Vulnerability details

## Impact
In the `RestakeManager.sol#calcaulateTVLs()` function, `operatorDelegatorTVLs` returns an empty array.
Therefore, The token TVL limit can be easily bypassed in the `RestakeManager.sol#deposit()` function.

## Proof of Concept
In the `RestakeManager.sol#deposit()` function, if the individual token TVL limit is set, it checks whether the deposit amount does not exceed this limit.
