# Vulnerability details

## Impact
This discrepancy can lead to unintended behavior and security vulnerabilities in the contract. If the contract logic relies on the `fillEthWithdrawBuffer` function being accessible only to the `onlyRestakeManager` user, allowing access to the `onlyDepositQueue` could potentially introduce security risks or disrupt the intended flow of operations.

## Proof of Concept
The comment associated with the function states that the function is supposed to be a permissioned call restricted to only the RestakeManager contract (onlyRestakeManager), but the actual implementation restricts access to only the deposit queue (onlyDepositQueue).
```
     /**
     * @notice  fill Eth WithdrawBuffer from RestakeManager deposits
     * @dev     permissioned call (onlyRestakeManager)
     */
```
