# Vulnerability details

## Impact
To ensure reliable data in L2 environments like Arbitrum, Chainlink integrations must include checks for sequencer health. This prevents oracles from relying on potentially inaccurate information during sequencer downtime.
This will affect the depositing of tokens in `xRenzoDeposit` contract.

## Proof of Concept
https://github.com/code-423n4/2024-04-renzo/blob/main/contracts/Bridge/L2/Oracle/RenzoOracleL2.sol#L50~L57

    function getMintRate() public view returns (uint256, uint256) {
        (, int256 price, , uint256 timestamp, ) = oracle.latestRoundData(); //@audit missing sequencer checking
        if (timestamp < block.timestamp - MAX_TIME_WINDOW) revert OraclePriceExpired(); // @audit price > 0?
        // scale the price to have 18 decimals
        uint256 _scaledPrice = (uint256(price)) * 10 ** (18 - oracle.decimals());
        if (_scaledPrice < 1 ether) revert InvalidOraclePrice();
        return (_scaledPrice, timestamp);
    }
