# Vulnerability details

In RenzoOracleL2 contract's `getMintRate` function there is validation to ensure that ezETH price returned by the oracle is always greater than 1 ETH. But this is not always the case as price of ezETH can drop below 1 ETH when validators(ETH or AVS) of Renzo protocol experience slashes.



```solidity
    function getMintRate() public view returns (uint256, uint256) {
        (, int256 price, , uint256 timestamp, ) = oracle.latestRoundData();
        if (timestamp < block.timestamp - MAX_TIME_WINDOW) revert OraclePriceExpired();
        // scale the price to have 18 decimals
        uint256 _scaledPrice = (uint256(price)) * 10 ** (18 - oracle.decimals());
        // @audit ezETH price can be less than 1 ETH in case of slashes
        if (_scaledPrice < 1 ether) revert InvalidOraclePrice();
        return (_scaledPrice, timestamp);
    }
```

## Impact
Minting of ezETH will be halted in L2s when ezETH price drops below 1 ETH due to slashes
