# Vulnerability details

## Description
Operators are susceptible to [slashing and/or penalties](https://consensys.io/blog/understanding-slashing-in-ethereum-staking-its-importance-and-consequences) on an Execution Layer level.
EigenLayer has two functions that can be called by anyone to update the state whenever these two events happen:
- [verifyBalanceUpdates](https://github.com/Layr-Labs/eigenlayer-contracts/blob/dev/src/contracts/pods/EigenPod.sol#L188-L224)
- [verifyAndProcessWithdrawals](https://github.com/Layr-Labs/eigenlayer-contracts/blob/dev/src/contracts/pods/EigenPod.sol#L235-L280)

Both these functions leads to a change in [podOwnerShares](https://github.com/Layr-Labs/eigenlayer-contracts/blob/dev/src/contracts/pods/EigenPodManager.sol#L118), which in turn results in the `TVL` of Renzo changing because the variables `podOwnerShares` is used in here:

- [RestakeManager.sol#L329](https://github.com/code-423n4/2024-04-renzo/blob/1c7cc4e632564349b204b4b5e5f494c9b0bc631d/contracts/RestakeManager.sol#L329)
- [OperatorDelegator.sol#L338-L345](https://github.com/code-423n4/2024-04-renzo/blob/1c7cc4e632564349b204b4b5e5f494c9b0bc631d/contracts/Delegation/OperatorDelegator.sol#L338-L345)
```javascript
contract RestakeManager {
	uint256 operatorEthBalance = operatorDelegators[i].getStakedETHBalance();
}

contract OperatorDelegator{
	function getStakedETHBalance() external view returns (uint256) {
	        // accounts for current podOwner shares + stakedButNotVerified ETH + queued withdraw shares
	        int256 podOwnerShares = eigenPodManager.podOwnerShares(address(this));
	        return
	            podOwnerShares < 0
	                ? queuedShares[IS_NATIVE] + stakedButNotVerifiedEth - uint256(-podOwnerShares)
	                : queuedShares[IS_NATIVE] + stakedButNotVerifiedEth + uint256(podOwnerShares);
	    }
}
```
This means that a user can front-run any slashing/penalty and withdraw his full amount while the rest of the stakers get punished.
## Proof of Concept
- Alice has `1000 ezETH`.
- Alice monitors the mempool and sees that some of the validators that the operator uses is being slashed.
- Alice front-runs the `verifyBalanceUpdates()` call with a `withdraw()` call.
- Alice is now able to safely withdraw the full amount of `1000 ezETH`, before the `verifyBalanceUpdates()` function succeeds and results in a TVL drop.
