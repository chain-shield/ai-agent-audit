# Vulnerability details

## Impact
The return value of an external transfer call is not checked

## Proof of Concept
```
    IToken(olas).transfer(depositProcessor,transferAmount); 
```
```
    IToken(olas).transfer(depositProcessor,transferAmounts[i]);
```
```
    IToken(olas).transfer(timelock,refundAmount);
```
## Tools Used
slither v0.10.2

## Recommended Mitigation Steps
Use SafeERC20, or ensure that the transfer return value is checked.







## Assessed type

Token-Transfer
