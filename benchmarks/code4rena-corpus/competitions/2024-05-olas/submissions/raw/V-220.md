# Vulnerability details

## Impact
The DefaulTargetDispenser.sol in question includes a drain function designed to allow the contract owner to withdraw all Ether from the contract. However, there is no check within this function to determine whether the contract is in a paused state. This omission allows the drain function to be called even when the contract is paused, potentially leading to significant security and operational risks.

## Proof of Concept
```
function drain() external returns (uint256 amount) {
        // Reentrancy guard
        if (_locked > 1) {
            revert ReentrancyGuard();
        }
        _locked = 2;

        // Check for the owner address
        if (msg.sender != owner) {
            revert OwnerOnly(msg.sender, owner);
        }

        // Drain the slashed funds
        amount = address(this).balance;
        if (amount == 0) {
            revert ZeroValue();
        }

        // Send funds to the owner
        (bool success, ) = msg.sender.call{value: amount}("");
        if (!success) {
            revert TransferFailed(address(0), address(this), msg.sender, amount);
        }

        emit Drain(msg.sender, amount);

        _locked = 1;
    }
```
The drain function does not check whether the contract is paused (paused == 2) before allowing the owner to withdraw funds. This means that even when the contract is in a paused state, the function can be executed, potentially bypassing security measures intended to prevent contract interactions during critical periods.

In the event of a detected vulnerability or ongoing attack, the paused state is supposed to halt critical functions to prevent exploitation. The ability to call the drain function during this period allows the owner to withdraw all funds, potentially undermining the security response.

## Recommended Mitigation Steps
A paused state check should be incorporated into the drain function. This ensures that the function can only be executed when the contract is not paused.
```
function drain() external returns (uint256 amount) {
    // Reentrancy guard
    if (_locked > 1) {
        revert ReentrancyGuard();
    }
    _locked = 2;

    // Check for the owner address
    if (msg.sender != owner) {
        revert OwnerOnly(msg.sender, owner);
    }

    // Check if the contract is paused
    if (paused == 2) {
        revert ContractPaused();
    }

    // Drain the slashed funds
    amount = address(this).balance;
    if (amount == 0) {
        revert ZeroValue();
    }

    // Send funds to the owner
    (bool success, ) = msg.sender.call{value: amount}("");
    if (!success) {
        revert TransferFailed(address(0), address(this), msg.sender, amount);
    }

    emit Drain(msg.sender, amount);

    _locked = 1;
}
```
