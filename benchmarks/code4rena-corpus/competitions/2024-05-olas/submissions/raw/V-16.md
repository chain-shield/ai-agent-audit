# Vulnerability details

## Impact
The `createStakingInstance()` function creates a service staking contract instance using the `create2`, where the `salt` includes nonce and block.chainId?, but not `msg.sender`.

This is increase risk of reorgs attacks. Re-orgs can happen in all EVM chains and as confirmed the contracts will be deployed on most EVM compatible L2s including Arbitrum, etc.

Attacker is able to frontrun the service staking contract instance deployment

## Proof of Concept
```
bytes32 salt = keccak256(abi.encodePacked(block.chainid, localNonce));


assembly {
   instance := create2(
          0x0,
          add(0x20, deploymentData),
          mload(deploymentData),
          salt 
            )
        }
```
## Tools Used
Manual
## Recommended Mitigation Steps
Include in `salt` `msg.sender`
