# Vulnerability details

## Impact
Downcasting to uint96 can cause to lost staking incentive.

## Proof of Concept
the `incentives[8]` is downcasted to uint96 without any checks

```
 mapEpochStakingPoints[eCounter].stakingIncentive = uint96(incentives[8]);
```

## Tools Used
Manual
## Recommended Mitigation Steps
Enter a check that `incentives[8] < type(uint96).max`.
