# Vulnerability details

## Impact

Native tokens will be stuck in the contract.

## Proof of Concept

The DefaultTargetDispenserL2.sol contract has a special function to migrate the contract to another contract through the `migrate()` function.

```
    function migrate(address newL2TargetDispenser) external {
```

This function migrates all of the OLAS token in the contract to a `newL2TargetDispenser` contract.

```
   uint256 amount = IToken(olas).balanceOf(address(this));
        // Transfer amount to the new L2 target dispenser
        if (amount > 0) {
>           bool success = IToken(olas).transfer(newL2TargetDispenser, amount);
            if (!success) {
                revert TransferFailed(olas, address(this), newL2TargetDispenser, amount);
            }
        }
```

However, it does not migrate the native tokens in the contract.

In the contract, there's another function called `drain()`, which withdraws the native funds in the contract, which could be present due to cross-bridge leftovers and incorrectly sent funds.

```
 function drain() external returns (uint256 amount) {
        // Reentrancy guard
        if (_locked > 1) {
            revert ReentrancyGuard();
        }
        _locked = 2;

        // Check for the owner address
        if (msg.sender != owner) {
            revert OwnerOnly(msg.sender, owner);
        }

        // Drain the slashed funds
        amount = address(this).balance;
        if (amount == 0) {
            revert ZeroValue();
        }

        // Send funds to the owner
>       (bool success, ) = msg.sender.call{value: amount}("");
        if (!success) {
            revert TransferFailed(address(0), address(this), msg.sender, amount);
        }

        emit Drain(msg.sender, amount);

        _locked = 1;
    }
```
