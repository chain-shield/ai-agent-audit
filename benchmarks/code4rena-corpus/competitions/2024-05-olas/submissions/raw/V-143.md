# Vulnerability details

## Impact

In the current functionality, `StakingBase` contract is supposed to receive ERC-721 tokens and, because of this, implements `ERC721Receiver` but doesn't have interface for it making it impossible for users to know if the contract can accept safe transfers.

## Proof of Concept

According to the spec:

https://eips.ethereum.org/EIPS/eip-721
```
A wallet/broker/auction application MUST implement the wallet interface if it will accept safe transfers.
```

However, in the current implementation, there is no ERC-165 interface that's used for `ERC721TokenReceiver` making it not possible for the external parties to identify that the contract can accept safe transfers.

## Tools Used

Manual review.

## Recommended Mitigation Steps

Add support of `0x150b7a02` interface to the `supportsInterface()`.
