# Vulnerability details

_sendMessage function checks for the `maxSubmissionCostToken` and `maxSubmissionCostMessage` parameters to be non-zero before proceeding with the transfer. However, if these values are zero, the function will revert with a `ZeroValue` error.

This is because the `maxSubmissionCostToken` and `maxSubmissionCostMessage` parameters are used in the calculation of the total cost of the message transfer, which is then compared to the value of `msg.value`. If either of these values is zero, the function will revert with a `LowerThan` error if the total cost exceeds the value of `msg.value`.

However, if the `maxSubmissionCostToken` and `maxSubmissionCostMessage` parameters are both zero, the function will not proceed with the transfer and will instead revert with a `ZeroValue` error. This is because the calculation of the total cost will result in a value that is greater than or equal to the value of `msg.value`, which will cause the `LowerThan` error to be thrown.
