## Impact

Here’s how you can refactor these functions to include a maximum iteration count:
## Proof of Concept

Changes to _getSum Function
Added a Maximum Iteration Count:

Introduced the maxIterations variable set to MAX_NUM_WEEKS to limit the number of iterations in the loop.
Loop Condition Modified:

The loop now runs for a maximum of maxIterations times, ensuring it doesn't exceed a reasonable count.

function _getSum() internal returns (uint256) {
    uint256 t = timeSum;
    Point memory pt = pointsSum[t];
    for (uint256 i = 0; i < MAX_NUM_WEEKS; i++) {
        if (t > block.timestamp) {
            break;
        }
        t += WEEK;
        uint256 dBias = pt.slope * WEEK;
        if (pt.bias > dBias) {
            pt.bias -= dBias;
            uint256 dSlope = changesSum[t];
            pt.slope -= dSlope;
        } else {
            pt.bias = 0;
            pt.slope = 0;
        }

        pointsSum[t] = pt;
        if (t > block.timestamp) {
            timeSum = t;
        }
    }
    return pt.bias;
}
