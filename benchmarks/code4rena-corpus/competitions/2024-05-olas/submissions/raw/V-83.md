# Vulnerability details

## Impact

First service staker will get double the rewards if `totalRewards > lastAvailableRewards`.

## Proof of Concept

When calculating rewards, if the `totalRewards` is greater than the `lastAvailableRewards`, then the rewards per staker is recalculated to be proportionate to the percentage of `lastAvailableRewards / totalRewards`.

Afterwards, the code checks whether `lastAvailableRewards > updatedTotalRewards`, which can happen due to truncation. If so, the leftover amounts will be given to the first service staker.

```
 // Process the first service in the set
>               updatedReward = (eligibleServiceRewards[0] * lastAvailableRewards) / totalRewards;
                updatedTotalRewards += updatedReward;
                curServiceId = eligibleServiceIds[0];
                finalEligibleServiceIds[0] = eligibleServiceIds[0];
                // If the reward adjustment happened to have small leftovers, add it to the first service
                if (lastAvailableRewards > updatedTotalRewards) {
>                   updatedReward += lastAvailableRewards - updatedTotalRewards;
                }
                finalEligibleServiceRewards[0] = updatedReward;
                // Add reward to the overall service reward
>               mapServiceInfo[curServiceId].reward += updatedReward;
                // Set available rewards to zero
                lastAvailableRewards = 0;
```

The problem is the using the `+=` sign instead of the `=` sign when adding to `mapServiceInfo[curServiceId].reward`.

When the function runs, in Line 629, `mapServiceInfo[curServiceId].reward += updatedReward` is already called once.

```
                    mapServiceInfo[curServiceId].reward += updatedReward;
```

If the updatedReward is 5 tokens, the `mapServiceInfo[curServiceId].reward` will be 5 tokens.

Then, `updateReward` is singled out for the first service staker again, which is 5 tokens

```
updatedReward = (eligibleServiceRewards[0] * lastAvailableRewards) / totalRewards;
```

If there are any extra tokens leftover, `updatedReward` is incremented.

```
if (lastAvailableRewards > updatedTotalRewards) {
                    updatedReward += lastAvailableRewards - updatedTotalRewards;
                }
```

Then, `mapServiceInfo[curServiceId].reward += updatedReward;` is called again.

Now, `mapServiceInfo[curServiceId].reward` for the first staker is 10 tokens, instead of 5 + dust amounts. The first staker gets double award.

## Tools Used

Manual Review

## Recommended Mitigation Steps

Change the `+=` sign to a `=` sign.

```
        mapServiceInfo[curServiceId].reward += updatedReward;
```

should be:

```
        mapServiceInfo[curServiceId].reward = updatedReward;
```
