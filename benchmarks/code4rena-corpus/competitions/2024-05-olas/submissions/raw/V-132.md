# Vulnerability details

## Impact
GnosisTargetDispenserL2.receive() doesn't include the payable modifier. Hence the dispenser contract can't recieve DAI, which DAI is also an ethereum based stable coin. Hence the function reverts.

## Proof of Concept
A user Bob calls the     function _sendMessage() in the GnosisDepositProcessorL1.sol contract, sends a message along side DAI (an ethereum based stable coin), the     function receiveMessage(bytes memory data) external {} will revert  the call because it cannot recieve ether. Hence, the funds are stuck in the contract.

## Tools Used
Manual

## Recommended Mitigation Steps
If the execution gas fee should be
paid on the source chain, ensure that the connector contracts can accept ETH by adding the Payable modifer.
