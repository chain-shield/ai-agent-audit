# Vulnerability details

## Impact

Messages cannot be send on WormholeDepositProcessorL1.sol as it doesn't forward the needed native token to cover the cost of the `quoteEVMDeliveryPrice` when sending token with payload. This will cause the function to alsways fail.

## Proof of Concept

The `_sendMessage` function allows for sending token and or messages to L2. In WormholeDepositProcessorL1.sol, this is done by querying the `sendTokenWithPayloadToEvm` function in wormhole's TokenBase.sol. `_sendMessage` however doesn't however forward any native token to wormhole, hence there are no tokens available to cover the cost of sending.

```solidity
    function _sendMessage(
        address[] memory targets,
        uint256[] memory stakingIncentives,
        bytes memory bridgePayload,
        uint256 transferAmount
    ) internal override returns (uint256 sequence) {
        .....
        sequence = sendTokenWithPayloadToEvm(uint16(wormholeTargetChainId), l2TargetDispenser, data, 0,
            gasLimitMessage, olas, transferAmount, uint16(l2TargetChainId), refundAccount);
    }
```

When we look at `sendTokenWithPayloadToEvm` in wormhole, we find that the cost of sending is queried with `quoteEVMDeliveryPrice` function and is then expected to be forwarded to the relayer through the `sendVaasToEvm` function.

```solidity
    function sendTokenWithPayloadToEvm(
        uint16 targetChain,
        address targetAddress,
        bytes memory payload,
        uint256 receiverValue,
        uint256 gasLimit,
        address token,
        uint256 amount,
        uint16 refundChain,
        address refundAddress
    ) internal returns (uint64) {
        VaaKey[] memory vaaKeys = new VaaKey[](1);
        vaaKeys[0] = transferTokens(token, amount, targetChain, targetAddress);

        (uint256 cost, ) = wormholeRelayer.quoteEVMDeliveryPrice(
            targetChain,
            receiverValue,
            gasLimit
        );
        return
            wormholeRelayer.sendVaasToEvm{value: cost}(
                targetChain,
                targetAddress,
                payload,
                receiverValue,
                gasLimit,
                vaaKeys,
                refundChain,
                refundAddress
            );
    }
}
```

Due to native token not being sent when sending message, the `sendTokenWithPayloadToEvm` call will fail causing the `sendVaasToEvm` to fail an causing the entire function to revert as there's not enough tokens to cover the delivery cost.

Manual code review

## Recommended Mitigation Steps
Consider calculating the needed cost and forwarding the sent ETH to wormhole too.
```solidity
        sequence = sendTokenWithPayloadToEvm{value: cost}(uint16(wormholeTargetChainId), l2TargetDispenser, data, 0,
            gasLimitMessage, olas, transferAmount, uint16(l2TargetChainId), refundAccount);
```
