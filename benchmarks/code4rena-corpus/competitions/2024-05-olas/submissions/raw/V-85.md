# Vulnerability details

## Impact  
Several interfaces in `tokenomics/contracts/interfaces/` have not been implemented in any contract. Contracts in `Dispenser.sol`, `Tokenomics.sol` and a few other contracts out of scope import these interfaces and use the defined functions but the scope of those functions has not been defined anywhere and are thus, empty functions or simply dead code that is being used. Additionally, even if the functions have been implemented, the calls will not work as those interfaces have not been inherited by the contracts using them. This is a basic concept of Solidity and several other programming languages. One cannot use those interfaces if the contract isn't inheriting/extending them with the `is` keyword in Solidity.  
```javascript
import {IContract} from 'src/IContract.sol';

contract MyContract is IContract {
    ...
}
```

Such an error could lead to most of the code being useless as there are several functions in the contracts using those functions defined in the interfaces.

## Recommended Mitigation Steps  
Follow the below mentioned points in order - 
- Implement the functions in contracts.
- Inherit the interfaces properly. For example, IDonatorBlacklist's function scope has been defined in DonatorBlacklist.sol but it does not import and implement the interface, thus, it is essentially a separate, new function now. Also, if `Tokenomics` is importing IDonatorBlacklist, it needs to add the is keyword at contract definition. `contract Tokenomics is IDonatorBlacklist {...}`.
- Add comments, if possible to keep track of the implementation of the interfaces.
