# Vulnerability details

## Impact
The condition for checking the OLAS balance and the contract being unpaused: [@DefaultTargetDispenserL2.sol:188-202](https://github.com/code-423n4/2024-05-olas/blob/e2a8bc31d2769bfb578a06cc64919ad369a82c08/tokenomics/contracts/staking/DefaultTargetDispenserL2.sol#L189-L202)
```solidity
if (IToken(olas).balanceOf(address(this)) >= amount && localPaused == 1) {
    // Approve and transfer OLAS to the service staking target
    IToken(olas).approve(target, amount);
    IStaking(target).deposit(amount);

    emit StakingTargetDeposited(target, amount);
} else {
    // Hash of target + amount + batchNonce
    bytes32 queueHash = keccak256(abi.encode(target, amount, batchNonce));
    // Queue the hash for further redeem
    stakingQueueingNonces[queueHash] = true;

    emit StakingRequestQueued(queueHash, target, amount, batchNonce, localPaused);
}
```
The condition `localPaused == 1` suggests that the contract should only approve and transfer OLAS when the contract is paused. However, logically, it should be the opposite. The contract should only approve and transfer OLAS when it is not paused.

**`Impact on Staking Functionality:`** If the contract is not paused (`localPaused == 0`), but the condition is checking for `localPaused == 1`, the OLAS tokens will not be approved and transferred to the staking target. Instead, the staking request will be queued for further redemption. This means that even when the contract is in a valid state to perform staking, it will not do so, leading to incorrect functionality.

**`Impact on User Experience:`** Users interacting with the contract may expect their staking requests to be processed immediately when the contract is not paused. However, due to the incorrect condition, their requests will be queued instead, leading to confusion and a suboptimal user experience.

_The emit statements in the code provide further evidence of the inconsistency. When the condition is met (`localPaused == 1`), the `StakingTargetDeposited` event is emitted, indicating that the staking target has been deposited. However, when the condition is not met, the `StakingRequestQueued` event is emitted, along with the `localPaused` value._

## Proof of Concept
Unit test that covers the issue with the condition for checking the OLAS balance and the contract being unpaused in the `_processData`:
```solidity
pragma solidity ^0.8.0;

import "forge-std/Test.sol";
import "../contracts/staking/DefaultTargetDispenserL2.sol";
import "../contracts/mocks/MockToken.sol";
import "../contracts/mocks/MockStaking.sol";

contract DefaultTargetDispenserL2Test is Test {
    DefaultTargetDispenserL2 public dispenser;
    MockToken public olas;
    MockStaking public stakingTarget;

    function setUp() public {
        olas = new MockToken();
        stakingTarget = new MockStaking();
        dispenser = new DefaultTargetDispenserL2(address(olas), address(0));
    }

    function testProcessData_WhenPaused_ShouldQueueStakingRequest() public {
        // Arrange
        address[] memory targets = new address[](1);
        targets[0] = address(stakingTarget);
        uint256[] memory amounts = new uint256[](1);
        amounts[0] = 1000;
        bytes memory data = abi.encode(targets, amounts);

        // Pause the contract
        dispenser.pause();

        // Act
        dispenser._processData(data);

        // Assert
        bytes32 queueHash = keccak256(abi.encode(address(stakingTarget), 1000, 0));
        assertTrue(dispenser.stakingQueueingNonces(queueHash));
        assertEq(stakingTarget.depositedAmount(), 0);
    }

    function testProcessData_WhenNotPaused_ShouldTransferOLAS() public {
        // Arrange
        address[] memory targets = new address[](1);
        targets[0] = address(stakingTarget);
        uint256[] memory amounts = new uint256[](1);
        amounts[0] = 1000;
        bytes memory data = abi.encode(targets, amounts);

        // Mint OLAS tokens to the dispenser contract
        olas.mint(address(dispenser), 1000);

        // Act
        dispenser._processData(data);

        // Assert
        bytes32 queueHash = keccak256(abi.encode(address(stakingTarget), 1000, 0));
        assertFalse(dispenser.stakingQueueingNonces(queueHash));
        assertEq(stakingTarget.depositedAmount(), 1000);
    }
}
```
In this test, we create two test functions to cover the different scenarios.

1. **`testProcessData_WhenPaused_ShouldQueueStakingRequest`**

  - We create test data with a single staking target and an amount of 1000.
  - We pause the dispenser contract using the `pause()` function.
  - We call the `_processData` function with the test data.
  - We assert that the staking request is queued by checking the `stakingQueueingNonces` mapping.
  - We also assert that no OLAS tokens are transferred to the staking target by checking the `depositedAmount()` of the mock staking contract.

2. **`testProcessData_WhenNotPaused_ShouldTransferOLAS`**

  - We create test data with a single staking target and an amount of 1000.
  - We mint OLAS tokens to the dispenser contract to ensure it has sufficient balance.
  - We call the `_processData` function with the test data.
  - We assert that the staking request is not queued by checking the `stakingQueueingNonces` mapping.
  - We also assert that the OLAS tokens are transferred to the staking target by checking the `depositedAmount()` of the mock staking contract.

## Recommended Mitigation Steps
Change the condition to `localPaused == 0` or simply `!localPaused` to ensure that the contract only approves and transfers OLAS when it is not paused.
```solidity

    // Approve and transfer OLAS to the service staking target
    IToken(olas).approve(target, amount);

} else {
```
