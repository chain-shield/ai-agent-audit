# Vulnerability details

## Impact
In smart contracts, especially those handling significant assets or critical operations, a "paused" state is often used as a safeguard mechanism. The paused state can be activated during emergencies, such as detecting a vulnerability or undergoing maintenance. During this state, it is crucial that critical functions are restricted to prevent unauthorized or unintended actions.

## Proof of Concept
```
function changeOwner(address newOwner) external {
    // Check for the contract ownership
    if (msg.sender != owner) {
        revert OwnerOnly(msg.sender, owner);
    }

    // Check for the zero address
    if (newOwner == address(0)) {
        revert ZeroAddress();
    }

    owner = newOwner;
    emit OwnerUpdated(newOwner);
}
```
```
function pause() external {
    // Check for the contract ownership
    if (msg.sender != owner) {
        revert OwnerOnly(msg.sender, owner);
    }

    paused = 2;
    emit TargetDispenserPaused();
}
```
Based on the current implementation, the ```changeOwner``` function will operate regardless of the paused state of the contract. This means that the ownership can be changed even when the contract is paused, as there is no condition within changeOwner to check the [paused state](https://github.com/code-423n4/2024-05-olas/blob/3ce502ec8b475885b90668e617f3983cea3ae29f/tokenomics/contracts/staking/DefaultTargetDispenserL2.sol#L359).

Anything dealing with state variables update should be paused, however, the changeOwner wasn't therefore a new Owner can be set when DefaultTargetDispenser.sol is paused.

## Recommended Mitigation Steps
when setting owner in paused state it should revert, only when in unpaused state.
```
function changeOwner(address newOwner) external {
    // Check if the contract is paused
++    if (paused == 2) {
        revert ContractPaused();
    }

    // Check for the contract ownership
    if (msg.sender != owner) {
        revert OwnerOnly(msg.sender, owner);
    }

    // Check for the zero address
    if (newOwner == address(0)) {
        revert ZeroAddress();
    }

    owner = newOwner;
    emit OwnerUpdated(newOwner);
}
```
