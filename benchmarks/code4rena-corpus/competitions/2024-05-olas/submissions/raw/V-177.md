# Vulnerability details

## Impact
Incorrect inflation rate computation for OLAS token leads to minting imprecise amount of OLAS tokens each year.

As stated in the whitepaper, OLAS is an [inflationary token](https://olas.network/documents/whitepaper/Autonolas_Tokenomics_Core_Technical_Document.pdf), meaning its minting process is gradual rather than instantaneous (such as through token initialization) and the inflation is meant to be controlled.
> OLAS follows an inflationary model that accounts for the economic primitives enabled by this tokenomics, such as the bonding mechanism and specific OLAS top-ups, e.g. extra incentives that developers can eventually receive.
 
During the first 10 years, 47.35% of the total token supply (1 billion) is projected to be issued via bonding and component/agent top-ups. 

The technical aspects of the inflation rate calculations are described using the following parameters:

| |Parameter Name|Parameter Definition|Value in Whitepaper|
|-|:-|:-:|:-:|
| [P&#x2011;01] | First year inflation rate  | The percentage of the initial token supply that is minted during the year of the OLAS token launch | 0.6% |
| [P&#x2011;02] | Second year inflation rate | The percentage of the token supply that is minted during the second year | 7.2% |
| [P&#x2011;03] | Initial inflation rate     | The percentage of the token supply that is minted for the third year | 12.5% |
| [P&#x2011;04] | Dis-inflation rate         | The rate with which inflation is decreased every year in the range comprising year 3 to year 9 | 16% |
| [P&#x2011;05] | Long-term inflation rate   | Tokens minted in the long run | 2% |

Thus, we can infer that the inflation rates are variable and indeed obey this behavior:

<img src="https://github.com/MatinR1/MatinR1/blob/main/OLAS.PNG"  width="60%" height="60%">

The inflation rate for the OLAS token drastically increases during the initial three years, then stabilizes to a moderate pace for the subsequent six years. This pattern underscores the critical need for precise annual token minting. Any imprecision could break the invariant, leading to an uncontrollable inflation process. Therefore, maintaining accuracy in the token minting process each year is essential to ensure the system's stability.

The inflation rate calculations are implemented inside the `TokenomicsConstants` contract which is used in the `Tokenomics` contract:

```Solidity
    function getInflationForYear(uint256 numYears) public pure returns (uint256 inflationAmount) {
        // For the first 10 years the inflation caps are pre-defined as differences between next year cap and current year one
        if (numYears < 10) {
            // Initial OLAS allocation is 526_500_000_0e17
            uint88[10] memory inflationAmounts = [
                3_159_000e18,
                40_254_084e18,
                40_400_000e18,
                56_000_000e18,
                80_000_000e18,
                72_000_000e18,
                64_000_000e18,
                48_000_000e18,
                40_000_000e18,
                29_686_916e18
            ];
    ...
    }
```

Also, the inflation cap for a specific year is calculated via `getSupplyCapForYear()` which are derived from the inflation rate amounts.
To calculate the inflation amounts, supply caps, and inflation rates, the following relationships are used (with inflation rates presented in percentages):

$$ inflation \ rate = \frac{next \ year \ cap - current \ year \ cap}{current \ year \ cap} $$

$$ supply \ cap = (current \ year \ cap * (1 + \frac{inflation \ rate}{100})) $$

and:

$$ inflation \ Amount = next \ year \ cap - current \ year \ cap $$

Considering the inflation parameters presented in the table above, we calculate the mentioned parameters using the data provided in the smart contracts:
(Initial OLAS allocation is `526_500_000e18`)

$$  First \ year \ inflation \ rate = \frac{3159000 \times 10^{18}}{526500000 \times 10^{18}} = 0.6 \\%  $$
$$  First \ year \ supply \ cap = 3159000 \times 10^{18} + 526500000 \times 10^{18} = 529659000 \times 10^{18} $$
$$  Second \ year \ inflation \ rate = \frac{40254084 \times 10^{18}}{529659000 \times 10^{18}} = 7.6 \\%  $$
$$  Second \ year \ supply \ cap = 40254084 \times 10^{18} + 529659000 \times 10^{18} = 569913084 \times 10^{18} $$

Here, the Initial inflation rate is calculated according to this definition:
> [The percentage of the token supply that is minted for the third year](https://olas.network/documents/whitepaper/Autonolas_Tokenomics_Core_Technical_Document.pdf)

$$  Initial \ inflation \ rate = \frac{40400000 \times 10^{18}}{569913084 \times 10^{18}} = 7 \\%  $$
$$  Third \ year \ supply \ cap = 40400000 \times 10^{18} + 569913084 \times 10^{18} = 610313084 \times 10^{18} $$

Even if we calculate the Initial inflation rate based on the total tokens minted till the end of the third year, we will get:

$$  Initial \ inflation \ rate = \frac{(3159000 + 40254084 + 40400000) \times 10^{18}}{526500000 \times 10^{18}} = 15.9 \\%  $$

I keep this one as the initial inflation rate here.
Also for the fourth year, the inflation rate is calculated as 9.17%, which is equal to a 42% reduction compared to 15.9%.
