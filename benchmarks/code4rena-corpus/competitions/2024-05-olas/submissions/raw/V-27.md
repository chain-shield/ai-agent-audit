# Vulnerability details

## Impact
Looking at `accountOwnerIncentives` function, in the loop where the function checks the ownership of the components/agents: [@>accountOwnerIncentives#L1347-L1351](https://github.com/code-423n4/2024-05-olas/blob/e2a8bc31d2769bfb578a06cc64919ad369a82c08/tokenomics/contracts/Tokenomics.sol#L1347-L1351)
```solidity
// Check the component / agent Id ownership
address unitOwner = IToken(registries[unitTypes[i]]).ownerOf(unitIds[i]);
if (unitOwner != account) {
    revert OwnerOnly(unitOwner, account);
}
```
The problem is that if any of the provided `unitIds` does not belong to the `account`, the function will revert with the `OwnerOnly` error. However, before reverting, the function has already modified the state by clearing the rewards and top-ups for the previous `unitIds` that were processed in the loop. If an invalid `unitId` is provided later in the array, the function will revert, but the rewards and top-ups for the valid `unitIds` processed earlier will still be cleared, even though the function execution did not complete successfully.

If an invalid `unitId` is provided in the `unitIds` array, the function will revert due to the ownership check failure. However, before the revert occurs, the function has already modified the state by clearing the rewards and top-ups for the previous valid `unitIds` processed in the loop.
```solidity
for (uint256 i = 0; i < unitIds.length; ++i) {
    // ...

    // Check the component / agent Id ownership
    address unitOwner = IToken(registries[unitTypes[i]]).ownerOf(unitIds[i]);
    if (unitOwner != account) {
        revert OwnerOnly(unitOwner, account);
    }

    // ...

    // Accumulate total rewards and clear their balances
    reward += mapUnitIncentives[unitTypes[i]][unitIds[i]].reward;
    mapUnitIncentives[unitTypes[i]][unitIds[i]].reward = 0;
    // Accumulate total top-ups and clear their balances
    topUp += mapUnitIncentives[unitTypes[i]][unitIds[i]].topUp;
    mapUnitIncentives[unitTypes[i]][unitIds[i]].topUp = 0;
}
```
The ownership check is performed for each `unitId` in the loop. If the ownership check fails for any `unitId`, the function will revert with the `OwnerOnly` error. However, before the revert occurs, the function has already modified the state by clearing the rewards and top-ups for the previous valid `unitIds` processed in the loop.

An example scenario to illustrate the impact of this issue:

Suppose we have the following input:

   - `account`: `0x1234...`
   - `unitTypes`: `[0, 1, 0]`
   - `unitIds`: `[1, 2, 3]`

Let's assume that `unitId` 1 and 3 belong to `account`, but `unitId` 2 does not.

In this scenario, the function will start processing the `unitIds` array.

   1. For `unitId` 1, the ownership check passes, and the function clears the rewards and top-ups for `unitId` 1.
   2. For `unitId` 2, the ownership check fails because it does not belong to `account`. The function reverts with the `OwnerOnly` error.

At this point, even though the function has reverted and the execution did not complete successfully, the rewards and top-ups for `unitId` 1 have already been cleared. This means that the rightful owner of `unitId` 1 has lost their incentives, even though the function encountered an error later in the process.

## Recommended Mitigation Steps
Consider moving the ownership check before modifying the state (i.e., before clearing the rewards and top-ups). This way, if any of the `unitIds` fails the ownership check, the function will revert without modifying the state for the valid `unitIds`.
```solidity
for (uint256 i = 0; i < unitIds.length; ++i) {
    // ...

    // Check the component / agent Id ownership
    address unitOwner = IToken(registries[unitTypes[i]]).ownerOf(unitIds[i]);
    if (unitOwner != account) {
        revert OwnerOnly(unitOwner, account);
    }
}

for (uint256 i = 0; i < unitIds.length; ++i) {
    // ...

    // Accumulate total rewards and clear their balances
    reward += mapUnitIncentives[unitTypes[i]][unitIds[i]].reward;
    mapUnitIncentives[unitTypes[i]][unitIds[i]].reward = 0;
    // Accumulate total top-ups and clear their balances
    topUp += mapUnitIncentives[unitTypes[i]][unitIds[i]].topUp;
    mapUnitIncentives[unitTypes[i]][unitIds[i]].topUp = 0;
}
```
