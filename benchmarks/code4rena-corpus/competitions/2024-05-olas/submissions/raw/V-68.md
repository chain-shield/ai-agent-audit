# Vulnerability details

## Impact

Anybody can call `receiveWormholeMessages()` and input arbitrary data to mess up the accounting system.

For L1 -> L2, anyone can fabricate any amount of `targets` and `amounts` through the data parameter.
For L2 -> L1, anyone can set an arbitrary withheldSyncAmount. 

## Proof of Concept

When the destination contract receives the message from the source contract, the wormhole relayer will call `receiveWormholeMessages()` to finish the bridging transaction.

The problem is that anyone can call `receiveWormholeMessages()`, so the function must explicitly state that the msg.sender can only be the Wormhole Relayer.

In the WormholeDepositProcessorL1 contract and the WormholeTargetDispenserL2, receiveWormholeMessages() does not have any access control protection.

```
    //@audit -> no check for wormhole relayer as msg.sender
    function receiveWormholeMessages(
        bytes memory data,
        bytes[] memory,
        bytes32 sourceAddress,
        uint16 sourceChain,
        bytes32 deliveryHash
    ) external {
        // Check for the source chain Id
        if (sourceChain != wormholeTargetChainId) {
            revert WrongChainId(sourceChain, wormholeTargetChainId);
        }

        // Check the delivery hash uniqueness
        if (mapDeliveryHashes[deliveryHash]) {
            revert AlreadyDelivered(deliveryHash);
        }
        mapDeliveryHashes[deliveryHash] = true;

        // Get L2 target dispenser address
        address l2Dispenser = address(uint160(uint256(sourceAddress)));

        _receiveMessage(msg.sender, l2Dispenser, data);
    }
```

This issue is mentioned in the Wormhole documentation: https://docs.wormhole.com/wormhole/quick-start/tutorials/hello-wormhole/beyond-hello-wormhole#example-solution-for-problem-1

## Recommended Mitigation Steps

Add a check to make sure that the caller comes from the Wormhole Relayer.

In the HelloToken example, there is a `onlyWormholeRelayer` modifier set.

```
   function receivePayloadAndTokens(
        bytes memory payload,
        TokenReceived[] memory receivedTokens,
        bytes32, // sourceAddress
        uint16,
        bytes32 // deliveryHash
    ) internal override onlyWormholeRelayer {
        require(receivedTokens.length == 1, "Expected 1 token transfers");
```
