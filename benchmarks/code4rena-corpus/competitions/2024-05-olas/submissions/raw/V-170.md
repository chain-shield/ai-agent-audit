# Vulnerability details

## Impact
The StakingToken contract is upgradeable, but gaps slots are not defined. The storage might be corrupted during upgrades.

when dealing with upgradeable contracts using proxies, it's crucial to manage storage layout carefully. When upgrading a contract, the new implementation contract must align its storage layout with the original contract's layout to prevent storage conflicts and corruption. This is typically managed by introducing gap slots (unused variables) in the contract's storage structure.
