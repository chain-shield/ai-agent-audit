# Vulnerability details

# **Vulnerability Detail**

According to the devs, the staking token could be any whitelisted token, however when the staking contract is created, it goes through the verification, where there is a check that state that if token ≠ Olas Token → return false, which is incorrect since the staking token could be any token apart from olas 

# **Proof of Concept**
https://github.com/code-423n4/2024-05-olas/blob/3ce502ec8b475885b90668e617f3983cea3ae29f/registries/contracts/staking/StakingVerifier.sol#L210-L215

```solidity
if (success) {
            // The returned size must be 32 to fit one address
            if (returnData.length == 32) {
                address token = abi.decode(returnData, (address));
                if (token != olas) { //q: staking token allowed to be only olas?
                    return false;
                }
            } else {
                return false;
            }
        }
```

# **Impact**

The check always fail, not allowing to successfully create an staking contract.

# **Recommendation**

Ensure that token is equal to the stakingToken
