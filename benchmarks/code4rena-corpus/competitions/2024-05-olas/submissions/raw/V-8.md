# Vulnerability details

## Impact
A critical reentrancy vulnerability exists in the __mint__ and __burn__ functions of the OLA contract. This vulnerability allows an attacker to repeatedly mint or burn tokens within a single transaction, leading to inflation of the token supply or depletion of tokens from accounts without proper authorization.

## Vulnerability Description
The __mint__ function lacks protection against reentrancy attacks. An attacker can exploit this by deploying a malicious contract that re-enters the mint function before the initial transaction completes, allowing the attacker to mint an arbitrary number of tokens.

2.Deploy the Attack Contract

3.Execute the Attack

## Recommended Mitigation Steps
To mitigate this vulnerability, implement reentrancy guards in the mint and burn functions. Using OpenZeppelin’s __ReentrancyGuard__ is a common practice:
See this: https://gist.github.com/Hiiamgogo/c67b0906b19ffd2c97877335c2f761f6

By adding the __nonReentrant__ modifier, the contract ensures that no nested (reentrant) calls are made to the __mint__ and __burn__ functions, thereby preventing the described attack.
