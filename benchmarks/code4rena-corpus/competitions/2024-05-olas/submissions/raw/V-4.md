# Vulnerability details

## Impact
Detailed description of the impact of this finding.
This report outlines the security audit conducted on the deposit(uint256 amount) function of the StakingToken contract. The audit’s primary focus was the absence of modifiers to restrict access to the function, allowing it to be called by any address.

Audit Scope
Contract: StakingToken.sol
Function Under Review: deposit(uint256 amount)

## Recommended Mitigation Steps
Access Control: It is strongly recommended to implement access control modifiers to restrict the deposit function to authorised users only, such as onlyOwner or custom access checks.

Role-Based Permissions: Consider using a role-based access control (RBAC) system to manage different levels of access within the contract.

The absence of access control modifiers in the deposit function presents a critical security risk. It is imperative to address this issue to prevent unauthorised access and potential exploitation.
