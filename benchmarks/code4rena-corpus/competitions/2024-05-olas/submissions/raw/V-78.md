# Vulnerability details

## Impact

Stakers will be wrongly evicted due to error in code.

## Summary

`totalNumServices` is erroneously set to `evictServiceIds.length` instead of  `setServiceIds.length`, which affects the setServiceIds array and pops off the wrong inactive staker.

```
        // Get the total number of staked services
        // All the passed arrays have the length of the number of staked services
        uint256 totalNumServices = evictServiceIds.length;
```

## Proof of Concept

When checkpoint() is called to see how much rewards are distributed to each staker, the function calls calculateStakeRewards and records whether the staker is inactive through the `_checkRatioPass()` function.

```
 if (ratioPass) {
                    // Calculate the reward up until now and record its value for the corresponding service
                    eligibleServiceRewards[numServices] = rewardsPerSecond * ts;
                    totalRewards += eligibleServiceRewards[numServices];
                    eligibleServiceIds[numServices] = serviceIds[i];
                    ++numServices;
                } else {
                    serviceInactivity[i] = ts;
```

If the staker is inactive, the serviceInactivity[] array will be populated, and be returned.

Let's say out of 10 stakers in `setServiceIds`, 2 stakers are inactive for a while. These stakers, number 1 and 5, will be part of the `serviceInactivity` array.

In `checkpoint()`, all the `serviceIds` is looped again and if `serviceInactivity[i] > 0` and `serviceInactivity[i] > maxInactivityDuration` (stakers 1 and 5), then set the `evictServiceIds[i]` to the `curServiceId` and call `_evict()`.

```
 // Increase service inactivity if it is greater than zero
                if (serviceInactivity[i] > 0) {
                    // Get the overall continuous service inactivity
                    serviceInactivity[i] = mapServiceInfo[curServiceId].inactivity + serviceInactivity[i];
                    mapServiceInfo[curServiceId].inactivity = serviceInactivity[i];
                    // Check for the maximum allowed inactivity time
                    if (serviceInactivity[i] > maxInactivityDuration) {
                        // Evict a service if it has been inactive for more than a maximum allowed inactivity time
>                        evictServiceIds[i] = curServiceId;
                        // Increase number of evicted services
                        numServices++;
                    } else {
                        emit ServiceInactivityWarning(eCounter, curServiceId, serviceInactivity[i]);
                    }
                } else {
                    // Otherwise, set it back to zero
                    mapServiceInfo[curServiceId].inactivity = 0;
                }
 // Evict inactive services
>           if (numServices > 0) {
                _evict(evictServiceIds, serviceInactivity, numServices);
            }
```

The `_evict()` call passes in `evictServiceIds`, [staker1, staker5], `serviceInactivity`, [10 days, 10 days] and `numServices`, 2.

In evict, the totalNumService is set to evictServiceIds.length, which is 2. Then, when evicting services from the global set of staked services, `setServicesIds` is set to the `setServiceIds[totalNumService]` and popped, which is wrong.

```
 // Evict services from the global set of staked services
        for (uint256 i = numEvictServices; i > 0; --i) {
            // Decrease the number of services
            totalNumServices--;
            // Get the evicted service index
            uint256 idx = serviceIndexes[i - 1];
            // Assign last service Id to the index that points to the evicted service Id
>           setServiceIds[idx] = setServiceIds[totalNumServices];
            // Pop the last element
>           setServiceIds.pop();
        }
```

## Recommended Mitigation Steps

Set totalNumServices to `setServiceIds.length` instead.

```
        // Get the total number of staked services
        // All the passed arrays have the length of the number of staked services
-       uint256 totalNumServices = evictServiceIds.length;
+       uint256 totalNumServices = setServiceIds.length;
```
