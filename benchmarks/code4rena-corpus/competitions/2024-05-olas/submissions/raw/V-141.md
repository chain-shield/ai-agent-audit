# Vulnerability details

## Impact
User funds will be locked
## Proof of Concept
In StakingBase, when a user calls the stake function to stake, if the reward in the contract is insufficient (availableRewards == 0), the user's stake call will be rolled back. However, if the attacker loads 1 token or 1 wei into the contract in advance, the user's stake call will succeed, and the user will start staking but will hardly get any rewards and will not be able to exit (because availableRewards > 0).
## Tools Used
Manual Audit
## Recommended Mitigation Steps
Set the parameter MinStakingRewards
```solidity
+ uint256 public MinStakingRewards 


- if (availableRewards == 0) {
+ if (MinStakingRewards == 0) {
    revert NoRewardsAvailable();
  }
```
