# Vulnerability details

### Vulnerability Report: Incorrect Year Calculation in TokenomicsConstants.sol

#### Summary
The `TokenomicsConstants.sol` contract does not correctly account for leap years in its time calculations. This leads to potential inaccuracies in the calculation of supply caps and inflation amounts over time, which could have significant effects on tokenomics projections.

It affects 2024-05-olas/tokenomics/contracts
/Tokenomics.sol read further 

#### Vulnerability Details

**File**: [TokenomicsConstants.sol](https://github.com/code-423n4/2024-05-olas/blob/e2a8bc31d2769bfb578a06cc64919ad369a82c08/tokenomics/contracts/TokenomicsConstants.sol#L15)

**Lines of Code**:
- Definition of `ONE_YEAR`: 
  ```solidity
  uint256 public constant ONE_YEAR = 1 days * 365;
  ```
- Year calculation logic in `getSupplyCapForYear` and `getInflationForYear`:
  ```solidity
  uint256 numYears = (block.timestamp - timeLaunch) / ONE_YEAR;
  ```

**Issue**:
The constant `ONE_YEAR` is defined as `1 days * 365`, which does not account for leap years. Over long periods, this simplification results in incorrect year calculations, affecting the accuracy of supply cap and inflation amount calculations.

**Potential Impact**:
The inaccuracy grows over time, potentially causing the contract to miscalculate the number of years since launch, leading to incorrect supply cap and inflation values. This discrepancy could undermine the tokenomics model, affecting investor trust and the token's economic stability.

#### Steps to Reproduce
1. Deploy the contract and initialize `timeLaunch` with a timestamp.
2. Fast forward time to a point where leap years would cause a significant discrepancy.
3. Call `getSupplyCapForYear` and `getInflationForYear` to observe the incorrect values due to the leap year omission.

#### Suggested Fix
Implement a more accurate year calculation method that accounts for leap years. Here is an updated version of the contract:

### Vulnerability Report: Incorrect Year Calculation in Tokenomics.sol

### Suggested Fix

1. **Leap Year Calculation Functions**:

```solidity
function isLeapYear(uint256 year) internal pure returns (bool) {
    if (year % 4 != 0) {
        return false;
    } else if (year % 100 != 0) {
        return true;
    } else if (year % 400 != 0) {
        return false;
    } else {
        return true;
    }
}

function leapYearsBefore(uint256 year) internal pure returns (uint256) {
    year -= 1;
    return year / 4 - year / 100 + year / 400;
}

function secondsSinceEpoch(uint256 year, uint256 month, uint256 day) internal pure returns (uint256) {
    uint256 days = day - 1;

    // Days in the months before the current month
    if (month > 1) days += 31;
    if (month > 2) days += isLeapYear(year) ? 29 : 28;
    if (month > 3) days += 31;
    if (month > 4) days += 30;
    if (month > 5) days += 31;
    if (month > 6) days += 30;
    if (month > 7) days += 31;
    if (month > 8) days += 31;
    if (month > 9) days += 30;
    if (month > 10) days += 31;
    if (month > 11) days += 30;

    days += (year - 1970) * 365 + leapYearsBefore(year) - leapYearsBefore(1970);

    return days * 1 days;
}
```

2. **Calculating the number of years since the launch date**:

```solidity
function getNumYears(uint256 timeLaunch) internal view returns (uint256) {
    // Initial timestamp components
    (uint256 launchYear, uint256 launchMonth, uint256 launchDay) = timestampToDate(timeLaunch);
    // Current timestamp components
    (uint256 currentYear, uint256 currentMonth, uint256 currentDay) = timestampToDate(block.timestamp);

    uint256 numYears = currentYear - launchYear;
    
    // Check if the current date is before the launch date in the current year
    if (currentMonth < launchMonth || (currentMonth == launchMonth && currentDay < launchDay)) {
        numYears -= 1;
    }

    return numYears;
}

function timestampToDate(uint256 timestamp) internal pure returns (uint256 year, uint256 month, uint256 day) {
    uint256 z = timestamp / 86400 + 719468;
    uint256 era = (z >= 0 ? z : z - 146096) / 146097;
    uint256 doe = z - era * 146097;
    uint256 yoe = (doe - doe / 1460 + doe / 36524 - doe / 146096) / 365;
    uint256 y = yoe + era * 400;
    uint256 doy = doe - (365 * yoe + yoe / 4 - yoe / 100);
    uint256 mp = (5 * doy + 2) / 153;
    day = doy - (153 * mp + 2) / 5 + 1;
    month = mp < 10 ? mp + 3 : mp - 9;
    year = y + (month <= 2 ? 1 : 0);
}
```

    const currentYear = new Date().getFullYear();
