# Vulnerability details

## Root of the bug 

Is in the method used to calculate the ETH obtained from the swap. 
The calculation boughtETHAmount = address(this).balance - boughtETHAmount assumes that only the swap operation affects the contract balance, ignoring potential unrelated ETH transfers.
This is the vulnerable line 

```solidity
boughtETHAmount = address(this).balance - boughtETHAmount;

```


The bug is caused by the reliance on the contract's balance difference to determine the bought ETH amount, without isolating the balance changes specifically attributable to the swap operation.


## Impact

The incorrect ETH balance calculation in the _fillQuote function can lead to overestimation or underestimation of the ETH amount obtained from token swap And This impacts the accuracy of financial operations, rewards distribution

## Proof of Concept

I use this to show the bug 

```Python 
from sympy import symbols, Eq, solve

# Define symbolic variables
initial_balance, post_swap_balance, bought_eth_amount, unrelated_transfer, actual_bought_eth = symbols(
    'initial_balance post_swap_balance bought_eth_amount unrelated_transfer actual_bought_eth')

# Define the initial and post-swap balances including unrelated transfer
post_swap_balance_with_transfer = post_swap_balance + unrelated_transfer

# Model the balance calculation in the contract
bought_eth_calculation = post_swap_balance_with_transfer - initial_balance

# Define the equation based on the balance calculation
equation = Eq(bought_eth_amount, bought_eth_calculation)

# Solve for bought_eth_amount in terms of initial_balance, post_swap_balance, and unrelated_transfer
solution = solve(equation, bought_eth_amount)

# Expected bought ETH without unrelated transfers
expected_bought_eth = post_swap_balance - initial_balance

# Create a complex scenario
initial_balance_value = 10  # Initial ETH balance
post_swap_balance_value = 12  # Balance after swapping tokens to ETH
unrelated_transfer_value = 1  # Unrelated transfer during the swap

# Calculate bought_eth_amount based on the contract logic
calculated_bought_eth = solution[0].subs({
    initial_balance: initial_balance_value,
    post_swap_balance: post_swap_balance_value,
    unrelated_transfer: unrelated_transfer_value
})

# Check if the calculated bought ETH matches the expected bought ETH
is_bug_present = calculated_bought_eth != expected_bought_eth

# Print the results
print(f"Calculated bought ETH (with unrelated transfer): {calculated_bought_eth}")
print(f"Expected bought ETH (without unrelated transfer): {expected_bought_eth}")
print(f"Bug present: {is_bug_present}")
```

Calculated bought ETH (with unrelated transfer): 3
Expected bought ETH (without unrelated transfer): 2
