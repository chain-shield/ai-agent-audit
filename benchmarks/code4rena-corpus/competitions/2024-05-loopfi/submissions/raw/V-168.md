# Vulnerability details

## Impact
when lock ETH for an address in `lockFor` function a call to `_processLock` with `address _for` sent 

`balances[_receiver][ETH] += _amount;` update the `_receiver` for `_for`

whoever if the `_for` is a contract that doesn't accept ether , the ether will be locked .

## Proof of Concept
```solidity
function lockFor(address _token, uint256 _amount, address _for, bytes32 _referral) external {
        if (_token == ETH) {
            revert InvalidToken();
        }
        _processLock(_token, _amount, _for, _referral);
    }
```
