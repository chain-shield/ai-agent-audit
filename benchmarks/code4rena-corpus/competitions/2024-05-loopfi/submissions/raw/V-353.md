# Vulnerability details

## Impact
The convertAllETH function in the LoopFi Prelaunch Points Contract is critical for transitioning user stakes from locked ETH to lpETH. This function must be executed post-loop activation and within a specific timeframe to enable subsequent user actions, such as claims or staking in a vault. If this function is not called due to the centralized control of the contract owner or due to malicious intent by compromised owners, it results in significant negative consequences as users' ETH remains locked in the contract without being converted to lpETH, rendering these assets inert and unusable for the intended purpose of claiming or further staking. This directly impacts user liquidity and the utility of their investment.



## Proof of Concept
convertAllETH function has to be manually triggered by owner.

https://github.com/code-423n4/2024-05-loop/blob/main/src/PrelaunchPoints.sol#L315

```solidity
function convertAllETH() external onlyAuthorized onlyBeforeDate(startClaimDate) {
        if (block.timestamp - loopActivation <= TIMELOCK) {
            revert LoopNotActivated();
        }

        // deposits all the ETH to lpETH contract. Receives lpETH back
        uint256 totalBalance = address(this).balance;
        lpETH.deposit{value: totalBalance}(address(this));

        totalLpETH = lpETH.balanceOf(address(this));

        // Claims of lpETH can start immediately after conversion.
        startClaimDate = uint32(block.timestamp);

        emit Converted(totalBalance, totalLpETH);
    }
```

## Recommended Mitigation Steps

Enforce a smart contract mechanism that automatically triggers the convertAllETH function if not manually triggered by the owner within a specified timeframe after loop activation.
