# Vulnerability details

## Impact
When users try to withdraw ```WETH```, the withdraw function reverts. However, if users lock ```WETH```, the ```_processLock``` functionality makes a withdrawal from ```WETH```, increasing balances of ```ETH``` for users. 
Here's the problem: if a user locks ```WETH``` and ```_processLock``` makes a withdrawal from ```WETH```, it increases the balances of the user in ```ETH``` not ```WETH```. During the 7 days grace period, users who are no longer interested in locking up their ```WETH``` try to withdraw ```WETH```, but this will always revert because the user doesn't have any balance in ```WETH```.
