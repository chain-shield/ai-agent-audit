# Vulnerability details

## Impact
If the inputTokenAmount from the 0x API data consistently differs from the user-specified _amount, it could lead to a high rate of transaction failures due to the WrongDataAmount error being triggered.
The need for exact matches between user-specified amounts and API data can lead to inefficiencies.


## Proof of Concept
In the `PrelaunchPoints` smart contract, the `_validateData` function is used to validate swap data obtained from the 0x API during operations such as token claims. This function checks if the inputTokenAmount decoded from the _data matches the _amount specified by the user. However, due to the nature of the data returned by the 0x API, which aims to provide the best, gross, and guaranteed prices, there is no certainty that the inputTokenAmount will always match the _amount provided by the user.
```
if (inputTokenAmount != _amount) {
            revert WrongDataAmount(inputTokenAmount);
        }
```
due to the strict inequality the function may revert more frequently
