# Vulnerability details

```setOwner()``` function allows the current ```owner``` to transfer their ownership, which is required to call certain functions in the contract. The function does not prevent ownerhsip from being transferred to ```address(0)```, which would leave the contract without an owner irremediably, as ```address(0)``` is not able to execute functions.

Therefore, ownership will not be transferred any more and functions which require to be called by the owner will never work.
