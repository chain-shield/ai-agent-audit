# Vulnerability details

## Impact
The absence of a zero address check in the setOwner function when the owner calls it can result in a critical scenario where user funds may become permanently locked within the protocol.


## Proof of Concept
The absence of a zero address check in the setOwner function prevents anyone from calling the convertAllETH function. Consequently, users are unable to claim their ETH, leading to all their funds being trapped in the protocol indefinitely.

```
    /**
     * @notice Sets a new owner
     * @param _owner address of the new owner
     */
    function setOwner(address _owner) external onlyAuthorized {
        // @audit new owener can be zero address
        owner = _owner;

        emit OwnerUpdated(_owner);
    }

```
## Tools Used

## Recommended Mitigation Steps

```javascript
    error InvalidAddress();
    /**
     * @notice Sets a new owner
     * @param _owner address of the new owner
     */
    function setOwner(address _owner) external onlyAuthorized {
        if (_owner == address(0)) {
            revert InvalidAddress();
        }
        owner = _owner;

        emit OwnerUpdated(_owner);
    }
```
