**Attack scenario:**
1. The time for claims is now open, so users can start claiming lpETH with their locked ETH or other LRT tokens.
2. But then we will swap the locked LRT into lpETH with the 0x API.
3. And they can mention the `_percentage` parameter, which determines how much percent of amount to claim.
4. A user can call `claim` with `_percentage == 0`, and forge a calldata of swap that would pass all the checks, and swap can be performed.
5. Although the only thing that would stop is the zero allowance, if there are any previous swaps that were approved but the swap is silently reverted, So, the approved amounts can be looted.


## Tools Used
Manual review

## Recommended Mitigation Steps

Add a check that `_percentage > 0`
