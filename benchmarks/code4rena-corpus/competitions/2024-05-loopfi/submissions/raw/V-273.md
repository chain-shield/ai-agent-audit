# Vulnerability details

## Vulnerability details
``_claim `` function is intended to swap ETH/WETH/LRT Tokens to lpETH Token (1:1) .User can claim their Token after 7days or when ``convertAllEth`` function is called by the owner. 
```soldiity
   function convertAllETH() external onlyAuthorized onlyBeforeDate(startClaimDate) {
        if (block.timestamp - loopActivation <= TIMELOCK) {
            revert LoopNotActivated();
        }

        // deposits all the ETH to lpETH contract. Receives lpETH back
        uint256 totalBalance = address(this).balance;
        lpETH.deposit{value: totalBalance}(address(this));

        totalLpETH = lpETH.balanceOf(address(this));

        // Claims of lpETH can start immediately after conversion.
        startClaimDate = uint32(block.timestamp);

        emit Converted(totalBalance, totalLpETH);
    }
```
The root cause of the issue is that the totalLpETH is only updated when the convertAllETH function is called , which can only be called during block.timestamp < 7 days, so it becomes hardcoded .
Users can still deposit their tokens after  block.timestamp + 7  days using ``lockETH``.
