# Vulnerability details

## Description

Description:
The `_processLock()` function is responsible for processing token locks within the contract. It facilitates the transfer of tokens to the contract address while enforcing certain conditions, such as allowing locks only before a specified date. However, the function lacks consideration for transfer fees associated with ERC20 tokens. While it correctly processes Ether transfers, it fails to address the possibility of fee deductions for other ERC20 tokens ([Weird-ERC20](https://github.com/d-xo/weird-erc20?tab=readme-ov-file#fee-on-transfer)). Additionally, it does not validate whether the token implements a fee mechanism, potentially leading to inaccurate accounting.

## Impact
Failure to address transfer fees can lead to financial discrepancies and losses. Users may receive fewer tokens than expected due to fee deductions, causing inaccuracies in balance tracking and potential financial harm.
