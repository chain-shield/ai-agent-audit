# Vulnerability details

## Impact
In this protocol, the user can deposit the LRT token and eth. However, the owner can only rescue the erc20 token from protocol. There is no way to rescue the ETH from this protocol.
There should be one more function for the owner to rescue the ETH from the protocol

## Tools Used

Vscode

## Recommended Mitigation Steps

Add this function after `recoverERC20`

```javascript

    /**
     * @dev Allows the owner to recover other ETH mistakingly sent to this contract
     */
    function recoverETH(uint256 tokenAmount) external onlyAuthorized {
        (bool sent, ) = msg.sender.call{value: tokenAmount}("");

        if (!sent) {
            revert FailedToSendEther();
        }
        emit Recovered(ETH, tokenAmount);
    }
```
