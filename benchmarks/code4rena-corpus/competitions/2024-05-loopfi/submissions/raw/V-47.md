# Vulnerability details

## Impact
If the user transfers ETH to the contract directly, it will be locked forever.
I've already checked it in the source code, but even if it's owner, he can't recover it forever after startClaimDate by calling `convertAllEth`.

## Proof of Concept
There's no function for recovering the ETH balance.

## Tools Used
Manual review

## Recommended Mitigation Steps
1. It's recommended to create `recoverETH` function for it.
2. Another recommendation is that do not allow to receive ETH if it's not from WETH, exchangeProxy.
