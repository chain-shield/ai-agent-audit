# Vulnerability details

## Impact
Single-step ownership change for contracts is risky. 
The current ownership transfer process calls `setOwner()` to change the owner.
The `setOwner` function changes the owner's address without checking for a zero address. If it's not a valid account, the owner may accidentally transfer ownership to an uncontrolled account, breaking all functions that use the `onlyAuthorized()` modifier.

## Proof of Concept
If the owner's address is set to the wrong address, all functions that use the `onlyAuthorized()` modifier will break.
https://github.com/code-423n4/2024-05-loop/blob/main/src/PrelaunchPoints.sol#L336

## Tools Used
Manual review

## Recommended Mitigation Steps
Recommend implementing zero address check and two-step transfer ownership like `Ownable2Step`.
This ensures that the new account is valid and active.
