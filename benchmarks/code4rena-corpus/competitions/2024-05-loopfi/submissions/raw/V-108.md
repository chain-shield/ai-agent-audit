# Vulnerability details

## Impact
owner cannot set a token as disallowed

## Proof of Concept
based on implementation of [allowToken](https://github.com/code-423n4/2024-05-loop/blob/0dc8467ccff27230e7c0530b619524cc8401e22a/src/PrelaunchPoints.sol#L364) function, owner just can set a token as a allowed and it cannot disallow them and that cause if owner wrongly add a token to list it cannot remove that from list

## Tools Used
Manually

## Recommended Mitigation Steps
update allowToken function
```diff
-    function allowToken(address _token) external onlyAuthorized {
+    function allowToken(address _token,bool allowed) external onlyAuthorized {
        isTokenAllowed[_token] = allowed;
    }
```
