# Vulnerability details

## Impact
Single-step ownership transfer means that if a wrong address was passed when transferring ownership it can mean that ownership is lost forever. This can be detrimental in the context of this protocol, where if `setOwner` was called with a wrong `_owner` address, then the prelaunchPoints contract will be bricked, since it relies heavily on admin-only methods.

## Proof of Concept
Here is the `setOwner` function.

```solidity
    function setOwner(address _owner) external onlyAuthorized {
        owner = _owner;


        emit OwnerUpdated(_owner);
    }
```

## Tools Used
Manual Analysis with vs code

## Recommended Mitigation Steps
It is recommended to implement a two-step ownership transfer where the new owner  is set and
then the new owner has to claim that ownership to finalize the ownership transfer.
