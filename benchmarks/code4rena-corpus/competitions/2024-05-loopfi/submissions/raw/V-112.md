# Vulnerability details

## Impact
if prelaunchPoints contract has ETH balance for any reason every lender can cliam that because when every lender want to claim their lpETH [_claim function](https://github.com/code-423n4/2024-05-loop/blob/0dc8467ccff27230e7c0530b619524cc8401e22a/src/PrelaunchPoints.sol#L240) deposits all ETHs to lpETH contract and then send them to lender

## Proof of Concept
run this test with forge test --match-test test_custom -vvv --evm-version shanghai

## Recommended Mitigation Steps
Its better protocol has to get ETH balance before and after swap and deposit difference value between them to lpETH contract
```solidity
    function _claim(address _token, address _receiver, uint8 _percentage, Exchange ...
            uint pre = address(this).balance;
            _fillQuote(IERC20(_token), userClaim, _data);
            uint post = address(this).balance;


            // Convert swapped ETH to lpETH (1 to 1 conversion)
            claimedAmount = address(this).balance;
            lpETH.deposit{value: post - pre}(_receiver);
        }
        emit Claimed(msg.sender, _token, claimedAmount);
    }
```
