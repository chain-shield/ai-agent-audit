# Vulnerability details

## Impact

Failure to validate token approval in the `_processLock` function can result in unauthorized token transfers or failed transactions. When `msg.sender` locks tokens on behalf of another address `_for`, there should be an approval set by `_for` to authorize `msg.sender` to spend their tokens. Without proper validation, unauthorized transfers may occur, potentially leading to loss of funds or contract instability.

## Proof of Concept
The following line transfers tokens from msg.sender to the contract:

```javascript
IERC20(_token).safeTransferFrom(msg.sender, address(this), _amount);
```
However, if `msg.sender` is locking tokens on behalf of another address `(_for)`, there must be an approval to authorize `msg.sender` to spend their tokens before the `safeTransfer` is executed.

## Tools Used
Manual Review

## Recommended Mitigation Steps
 Ensure that the `_processLock` function validates token approval properly before transferring tokens. Check if the token holder `(_for)` has approved `msg.sender` to spend their tokens for the given amount.
 When checking token allowance, use `_for` as the spender address to ensure that the validation is performed correctly based on the actual token holder.
If `msg.sender` is locking tokens for another address `_for`, it should approve msg.sender to spend their tokens by calling the approve function on the ERC-20 token contract.

```javascript
function _processLock(address _token, uint256 _amount, address _receiver, bytes32 _referral)
    internal
    onlyBeforeDate(loopActivation)
{
    if (_amount == 0) {
        revert CannotLockZero();
    }

    if (_token == ETH) {
        totalSupply += _amount;
        balances[_receiver][ETH] += _amount;
    } else {
        if (!isTokenAllowed[_token]) {
            revert TokenNotAllowed();
        }

        // If msg.sender is not the same as _receiver, validate token allowance
        if (msg.sender != _receiver && IERC20(_token).approve(_receiver, msg.sender) < _amount) {
            revert InsufficientAllowance();
        }

        // Transfer tokens from _receiver to contract
        IERC20(_token).safeTransferFrom(_receiver, address(this), _amount);

        if (_token == address(WETH)) {
            WETH.withdraw(_amount);
            totalSupply += _amount;
            balances[_receiver][ETH] += _amount;
        } else {
            balances[_receiver][_token] += _amount;
        }
    }

    emit Locked(_receiver, _amount, _token, _referral);
}
```
