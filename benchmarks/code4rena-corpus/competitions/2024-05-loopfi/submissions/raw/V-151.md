# Vulnerability details

## Impact
When claiming ETH, the _percentage parameter has no effect.

## Proof of Concept
_percentage represents the percentage claim. When claiming tokens other than ETH, it will participate in the calculation normally. But when claiming ETH, it does not participate in the operation. This is a missing feature that does not meet user expectations.
