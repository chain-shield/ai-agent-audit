# Vulnerability details

## Impact
```emergencyMode``` inidcates that the system goes into an extraordinary state in which ```withdraw()``` function is callable with no time restrictions. It is pretty logical that a variable with such a name has great relevance, therefore all the users must be aware of the presence of this state at any time.

The contract makes use of events to inform about the changes that take place, but not for the value of ```emergencyMode```. An event must be included to tell when this function is used. It is advisable to prevent the function from being called several times with the same value, which would emit multiple events without really having the value changed.

## Tools Used

Manual review

## Recommended Mitigation Steps

Change the function and include an event which is emitted whenever the value of ```emergencyMode``` is changed.
