# Vulnerability details

## Impact
Use flash loans to manipulate totalSupply to significantly reduce the claimedAmount of other users.

Since the withdraw function will not reduce the total supply when withdrawing ERC20 tokens, but when locking ERC20 tokens (WETH), totalSupply will increase. Attackers can use this vulnerability to deposit and withdraw tokens, causing totalSupply to increase significantly. , and because in the _claim function, when other users use ETH to claim, ```claimedAmount = userStake.mulDiv(totalLpETH, totalSupply);```, this will cause other users' claimedAmount to be significantly reduced.

When the deployer calls the setLoopAddresses function, the attacker flash loans a large amount of WETH (100e18 WETH), then calls the lock function and withdraw function, and finally repays the flash loan. At this time, the totalSupply will increase significantly, and the attacker only needs to pay a low price gas fee can significantly reduce the claimedAmount of all users.

Since the current project has not been deployed yet, I am using the deployed pair contract for flash loans. The following code is the attacker’s contract.
