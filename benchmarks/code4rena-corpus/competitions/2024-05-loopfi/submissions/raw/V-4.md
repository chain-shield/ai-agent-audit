# Vulnerability details

## Impact
The LoopFi description mentions that conversion for LRTs happens on each claim using the 0x API, but the code provides only a general mechanism for claiming based on the token type, which may not be clear or specific enough to handle unique LRT logic or conversion rates.

To address the issue in the token conversion and claiming mechanism for LRTs (or any specific token requiring unique handling), we need to implement a more explicit and robust handling mechanism during the claim process, particularly when interacting with the 0x API. This is crucial to ensure that the contract correctly manages conversions with specific parameters or rates pertinent to LRTs.
