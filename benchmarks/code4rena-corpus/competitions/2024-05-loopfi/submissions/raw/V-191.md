# Vulnerability details


## Impact
The `_processLock` function has a critical bug related to handling WETH token transfers. If the token being transferred is WETH, the function attempts to withdraw the tokens before updating balances. This creates a vulnerability where another contract could exploit a race condition, leading to incorrect balance updates and potential token loss.

## Proof of Concept
Here's the vulnerable code snippet:

```solidity
function _processLock(address _token, uint256 _amount, address _receiver, bytes32 _referral)
    internal
    onlyBeforeDate(loopActivation)
{
    // Check if amount is zero
    if (_amount == 0) {
        revert CannotLockZero();
    }
    
    // Check if token is ETH
    if (_token == ETH) {
        // Update total supply and receiver's balance
        totalSupply = totalSupply + _amount;
        balances[_receiver][ETH] += _amount;
    } else {
        // Check if token is allowed
        if (!isTokenAllowed[_token]) {
            revert TokenNotAllowed();
        }
        
        // Transfer tokens from sender to this contract
        IERC20(_token).safeTransferFrom(msg.sender, address(this), _amount);

        // Vulnerable code when token is WETH
        if (_token == address(WETH)) {
            WETH.withdraw(_amount); // Potential vulnerability
            totalSupply = totalSupply + _amount;
            balances[_receiver][ETH] += _amount;
        } else {
            balances[_receiver][_token] += _amount;
        }
    }

    // Emit Locked event
    emit Locked(_receiver, _amount, _token, _referral);
}
```

## Recommended Mitigation Steps
1. **Reorder Operations:** Update balances before any external interactions like token withdrawals.
2. **Prevent Reentrancy:** Implement safeguards against reentrancy vulnerabilities to avoid race conditions.
3. **Upgrade Contracts:** Consider upgrading Solidity to the latest version for improved security features.
4. **Thorough Testing:** Conduct extensive testing, including stress tests, to identify and fix vulnerabilities.
