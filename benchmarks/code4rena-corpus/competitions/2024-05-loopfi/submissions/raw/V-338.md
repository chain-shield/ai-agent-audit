# Vulnerability details

**Description of the Issue:**
In the `convertAllETH()` function, the return value from the `lpETH.deposit{value: totalBalance}(address(this))` call is ignored. The contract assumes that after depositing all its ETH balance into the lpETH contract, it will receive a corresponding amount of lpETH tokens. This amount is then used to set the `totalLpETH` state variable, which is critical in calculating user claims.

The ILpETH `deposit` function is expected to return the number of lpETH tokens that represent the deposited ETH. If for any reason this function fails silently and returns 0 (for example, due to a bug in the lpETH contract implementation), or the transaction is reverted, the `totalLpETH` state variable would be incorrectly set to 0.

**Consequences:**
As a result of `totalLpETH` potentially being set to 0, users would not be able to claim their share of lpETH tokens:

- In `convertAllETH()`, the incorrect setting of `totalLpETH` would lead to a zero total pool of claimable lpETH tokens.
- In `_claim()`, the calculation for `claimedAmount = userStake.mulDiv(totalLpETH, totalSupply);` would always result in a zero claimable amount because of the zeroed `totalLpETH`.

This would effectively lock all users' funds within the contract, as `withdraw()` would also not function since `convertAllETH()` permanently transitions the contract state to the claimed phase, and withdraws are then only allowed before the loop activation or after the emergency mode is turned on.

**Emergency Mode Ineffectiveness:**
Even with the emergency mode turned on, users would not be able to reclaim their locked ETH because the recovery mechanism in `withdraw()` is only designed to handle the pre-conversion scenario, and there's no equivalent mechanism for users to recover lpETH after conversion.

**Recommendations:**
To mitigate this issue, the contract should check the return value of the `lpETH.deposit` call and proceed only if the number of lpETH tokens received matches the expectation:

```solidity
uint256 mintedLpETH = lpETH.deposit{value: totalBalance}(address(this));
require(mintedLpETH > 0, "Deposit to lpETH did not mint any tokens");
totalLpETH = mintedLpETH;
```
