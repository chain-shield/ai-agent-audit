# Vulnerability details

## Impact
The ownership change is single step and lacks zero address checks

which might lead to setting incorrect or unwanted address the ownership 

of critical aspects of the system which can only be modified by the owner.

Thus a 2 step procedure should be implemented for such actions where the existing 

owner has to confirm twice that they want to transfer the ownership

making this action less error prone .

## Proof of Concept (PoC)
The `setOwner` method changes ownership in one transaction 

with no zero address checks

```
   function setOwner(address _owner) external onlyAuthorized {
        owner = _owner;

        emit OwnerUpdated(_owner);
    }
```

This approach is prone to zero address ownership transfer or transferring 

ownership to an address which is incorrect or unwanted.

## Tools Used
Manual review
## Recommendation
Use Openzeppelin's 2 step ownership contracts or employ pendingAdmin and Actual admin paradigm .
