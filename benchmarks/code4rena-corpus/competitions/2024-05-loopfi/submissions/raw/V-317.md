# Vulnerability details

## Impact
Users may suffer loss of funds if wrapped LRT tokens are removed from the token whitelist.

## Proof of Concept
The `owner` can remove a specific token from the whitelist.
```solidity
    function allowToken(address _token) external onlyAuthorized {
        isTokenAllowed[_token] = true;
    }
```
The owner can recover other ERC20 accidentally transferred to this contract.
```solidity
    function recoverERC20(address tokenAddress, uint256 tokenAmount) external onlyAuthorized {
380:    if (tokenAddress == address(lpETH) || isTokenAllowed[tokenAddress]) {
            revert NotValidToken();
        }
383:    IERC20(tokenAddress).safeTransfer(owner, tokenAmount);

        emit Recovered(tokenAddress, tokenAmount);
    }
```
As you can see, #L380 checks whether the token is in the whitelist and recovers tokens that do not exist.
However, if tokens (i.e. weETH, ezETH) traded in the protocol are removed from the allow list, the locked user's assets may be leaked during recovery.
Therefore, the contract balance becomes less than `balances[msg.sender][_token]`.
`PrelaunchPoints.sol#withdraw()`:
```solidity
    SNIP...
284:    uint256 lockedAmount = balances[msg.sender][_token];
285:    balances[msg.sender][_token] = 0;
    SNIP...
302:    IERC20(_token).safeTransfer(msg.sender, lockedAmount);
```
As you can see, if the contract balance is less than `balances[msg.sender][_token]`, the transaction is reverted in #L302.
Therefore, the user will not be able to call `claim()` and `withdraw()`, and all assets will be locked.

## Tools Used
Manual Review
## Recommended Mitigation Steps
Track the locked balance according to individual tokens and add the following checks to the `recoverERC20()` function.

```solidity
+++ mapping(address => uint256) public tokenLocked;
    ... ... ...
    function recoverERC20(address tokenAddress, uint256 tokenAmount) external onlyAuthorized {
        if (tokenAddress == address(lpETH) || isTokenAllowed[tokenAddress]) {
            revert NotValidToken();
        }

+++     require(tokenLocked[tokenAddress] == 0, "The asset is locked in contract.");

        IERC20(tokenAddress).safeTransfer(owner, tokenAmount);

        emit Recovered(tokenAddress, tokenAmount);
    }
```
