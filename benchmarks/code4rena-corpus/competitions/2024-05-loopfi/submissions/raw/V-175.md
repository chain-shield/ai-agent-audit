# Vulnerability details

## Impact
The current implementation lacks support for allowing users to withdraw a percentage of ETH from their locked ETH, whereas such functionality exists for ERC20 tokens in the `_claim()` function. This limitation can lead to a discrepancy in user experience and functionality between ETH and ERC20 token withdrawals.

## Proof of Concept
To demonstrate the issue, attempt to withdraw a percentage of locked ETH using the `claim()` function. Notice that the function does not use a percentage value to withdraw rather it withdraws all ETH even though function accepts the percentage, unlike the _claim function for ERC20 tokens.

## Tools Used
Manual review

## Recommended Mitigation Steps
consider implementing a same logic for ETH as well which is similar to ERC20 in the contract that allows users to specify a percentage of locked ETH to withdraw.
