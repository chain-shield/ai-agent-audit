# Vulnerability details

## Impact

Users will have to wait ~1 block to withdraw their funds after loopActivation is set.

## Proof of Concept

- When Loop contracts are launched, the owner of the contract can call only once setLoopAddresses to set the lpETH contract as well as the staking vault for this token. This activation date is stored at loopActivation:

```solidity
    function setLoopAddresses(address _loopAddress, address _vaultAddress)
        external
        onlyAuthorized
        onlyBeforeDate(loopActivation)
    {
        lpETH = ILpETH(_loopAddress);
        lpETHVault = ILpETHVault(_vaultAddress);
        loopActivation = uint32(block.timestamp);

        emit LoopAddressesUpdated(_loopAddress, _vaultAddress);
    }
```

- One of the main invariants mentioned in the readme stipulate that:

> Withdrawals are only active on emergency mode or during 7 days after loopActivation is set.

- However, that can't be the case as the `setLoopAddresses()` current implementation will end up breaking the invariant becuase the function will throw and error ("CurrentlyNotPossible") when called just after loopActivation is set:

```solidity
            if (block.timestamp <= loopActivation) {
                revert CurrentlyNotPossible();
            }
```

#### Here is a coded PoC to demonstrate the issue:

```solidity
    function testWithdrawRevert() public {
        uint256 lockAmount = 1e18;
        lrt.approve(address(prelaunchPoints), lockAmount);
        prelaunchPoints.lock(address(lrt), lockAmount, referral);

        uint256 balanceBefore = lrt.balanceOf(address(this));

        prelaunchPoints.setLoopAddresses(address(lpETH), address(lpETHVault));

        vm.expectRevert(PrelaunchPoints.CurrentlyNotPossible.selector);
        prelaunchPoints.withdraw(address(lrt));
    }
```

- Incorporate the tests in [**`PrelaunchPointsTest`**]([link](https://github.com/code-423n4/2024-05-loop/blob/main/test/PrelaunchPoints.t.sol))
- Execute: **`forge test --mc PrelaunchPointsTest --mt testWithdrawRevert`**

## Tools Used

Manual review

## Recommended Mitigation Steps

Consider updating the check in the withdraw function as follows:

```solidity
            if (block.timestamp < loopActivation) {
                revert CurrentlyNotPossible();
            }
```
