# Vulnerability details

## Impact
The agreement allows withdrawal during the 7 days following loop activation without activating the emergency module. However, if the uniETH contract is in a paused state at that time, all transfers will be disabled, potentially causing users which lock uniETH to miss the withdrawal opportunity.

## Proof of Concept
uniETH overrides the _beforeTokenTransfer function to restrict transfers when the contract is paused.
[https://etherscan.io/token/0xF1376bceF0f78459C0Ed0ba5ddce976F1ddF51F4](https://etherscan.io/token/0xF1376bceF0f78459C0Ed0ba5ddce976F1ddF51F4)
```solidity
    function _beforeTokenTransfer(address from, address to, uint256 amount)
        internal
        whenNotPaused
        override(ERC20Upgradeable, ERC20SnapshotUpgradeable)
    {
        super._beforeTokenTransfer(from, to, amount);
    }
```
