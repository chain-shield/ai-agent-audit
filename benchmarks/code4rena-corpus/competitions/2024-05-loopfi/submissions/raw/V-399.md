# Vulnerability details

## Impact
- Malicious attacker would gain more 20% points by referring to themselves
- An attacker would refer to themselves while depositing to gain more 20%.
- According to docs "If a referral link is used to make deposits (e.g., ETH or LRT), the referral mechanism allows the referee to earn 20% of the points given to the depositor."
- So this is illegal for having extra 20%
