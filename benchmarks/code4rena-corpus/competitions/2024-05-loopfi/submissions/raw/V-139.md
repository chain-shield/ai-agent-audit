# Vulnerability details

## Impact

First claimer can get all `lpETH` tokens in the `PrelaunchPoints` contract

## Proof of Concept

Users can only claim `lpETH` when the owner has called the `convertAllETH()` function. `convertAllETH()` functions to convert all `ETH` balances in the `PrelaunchPoints` contract and get `lpETH` as much as `ETH` deposited into the `lpETH` contract and send `lpETH` back to the `PrelaunchPoints` contract.

An exploit that can occur is when the owner converts all `ETH` balances in the `PrelaunchPoints` contract, all `lpETH` balances are stored in the `PrelaunchPoints` contract. This allows the first claimer to claim with tokens other than `ETH` and get all the `lpETH` balance in the `PrelaunchPoints`contract.

### Exploit Scenario

1. Owner call `convertAllETH()` and set `startClaimDate.`In this way, users can claim `lpETH` tokens
2. Bob as the first claimer monitors transactions in the contract. When the owner has called the `convertAllETH()` function, Bob immediately calls the `claim()` function with a token other than `ETH`
3. The codebase for this function is as follows :

```solidity
        } else {
            uint256 userClaim = userStake * _percentage / 100;
            _validateData(_token, userClaim, _exchange, _data);
            balances[msg.sender][_token] = userStake - userClaim;

            // At this point there should not be any ETH in the contract
            // Swap token to ETH
            _fillQuote(IERC20(_token), userClaim, _data);

            // Convert swapped ETH to lpETH (1 to 1 conversion)
            claimedAmount = address(this).balance;
            lpETH.deposit{value: claimedAmount}(_receiver);
        }
        emit Claimed(msg.sender, _token, claimedAmount);
```

4. The problem lies in the code

```solidity
claimedAmount = address(this).balance;
```

5. When Bob directly calls the `claim()` function with tokens other than `ETH`, even with a very small number of tokens he gets all the `lpETH` in the `PrelaunchPoints` contract. This causes users after Bob to be unable to claim `lpETH` because liquidity is not available in the `PrelaunchPoints` contract.

## Tools Used

Manual review

## Recommended Mitigation Steps

Consider adding mapping for claimed amount to each user and make sure claimed amount = balance owned by the user
