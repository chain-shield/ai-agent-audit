# Vulnerability details

## Impact
Users will be unable to claim their vested lpETH until the year 2107 due to the `startClaimDate` being set to the maximum value of a uint32. This effectively locks users out of claiming their tokens for an unreachable time.

## Proof of Concept

Below you can see that in the constructor claim start date by epoch is hardcoded, year 2107

```startClaimDate = 4294967295; // Max uint32 ~ year 2107```


Below you can see the claim function has OnlyAfterDate modifier that passes startClaimDate, which corresponds to year 2107.
```
function claim(address _token, uint8 _percentage, Exchange _exchange, bytes calldata _data)
        external
        onlyAfterDate(startClaimDate)
    {
        _claim(_token, msg.sender, _percentage, _exchange, _data);
    }
```
