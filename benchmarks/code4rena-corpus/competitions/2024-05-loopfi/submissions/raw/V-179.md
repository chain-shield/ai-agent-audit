# Vulnerability details

## Impact
The contract currently lacks support for WETH (Wrapped Ether). Although users can lock WETH, the withdrawal function requires them to pass the token address as ETH. Since the contract does not differentiate between ETH and WETH, attempting to withdraw WETH by passing its token address will result in a revert error due to the zero balance. To address this issue, support for WETH should be implemented in the withdrawal function, allowing users to withdraw WETH tokens seamlessly.
