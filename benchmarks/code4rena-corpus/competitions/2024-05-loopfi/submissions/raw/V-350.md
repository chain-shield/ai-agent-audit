# Vulnerability details

#### Description:
The `setOwner` function in the PrelaunchPoints contract allows the current owner to transfer ownership of the contract to another address. However, the function does not contain a check to prevent the transfer of ownership to the zero address (0x0). Since the zero address is typically used to represent an 'empty' address in Ethereum, transferring ownership to it can lead to a situation where administrative functions are permanently locked, as no one can perform actions that are gated behind the `onlyAuthorized` modifier.

#### Recommendation:
To mitigate this risk, include a requirement that the new owner's address must be a valid, non-zero Ethereum address. This check will ensure that ownership can only be transferred to a potentially viable external account or smart contract. Implement this by adding a precondition check at the beginning of the function:

```solidity
function setOwner(address _owner) external onlyAuthorized {
    require(_owner != address(0), "New owner cannot be the zero address");
    owner = _owner;
    emit OwnerUpdated(_owner);
}
```
This simple precondition check ensures that the new owner address is not the zero address, helping to prevent an accidental or intentional transfer of ownership to an address from which the ownership cannot be recovered.
