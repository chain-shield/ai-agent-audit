# Vulnerability details

## Impact

As the description of Prelaunch Point contracts states:

> Once these addresses are set, all deposits are paused, and users have 7 days to withdraw their tokens in case they change their mind or detect a malicious contract being set.

Users can withdraw their deposited ERC20 tokens within 7 days if they find any malicious contract being set, but there are multiple pausable tokens this project is using, such as ezETH, rsETH, and uniETH.

These tokens are upgradable and owner-controlled contracts, so they can be paused anytime if any bugs or malicious activity is detected. If these tokens are paused within the allowed 7 days by the LoopFi protocol for withdrawal, then users cannot withdraw tokens and will be forced to convert them to lpETH, even when they wanted their tokens back within this 7-day limit.

## Recommended Mitigation Steps

Record these users' withdrawal attempts during the TIMELOCK period and allow them to withdraw their tokens once the tokens are unpaused.

```solidity
// * 1. create a state mapping for pausable tokens
mapping(address => bool) public isPausableToken;

// * 2. create a mapping to record users withdrawal attempts in the TIMELOCK period.
mapping(address => bool) public isWithdrawalAttemptedInTIMELOCK;

// * 3. pass an array of pausable tokens in the constructor.
constructor(address _exchangeProxy, address _wethAddress, address[] memory _allowedTokens, address[] memory _pausableTokens) {}

// * 4. set pausable tokens inside the constructor.

// Allow intital list of pausable tokens
length = _pausableTokens.length;

for (uint256 i = 0; i < length; ) {
    isPausableToken[_pausableTokens[i]] = true;
    unchecked {
        i++;
    }
}

// * 5. In the 'else' block of the withdraw function, check if the token is pausable. If it is pausable, then verify whether it is paused or not. If it is not paused, simply transfer the tokens. However, if it is paused, record the user's attempt to withdraw and allow them to withdraw later.

if (_token == ETH) {} else {
    if (isPausableToken[_token]) {
        if (IERC20(_token).pause()) {
            isWithdrawalAttemptedInTIMELOCK[msg.sender] = true;
        } else {
            IERC20(_token).safeTransfer(msg.sender, lockedAmount);
        }
    } else {
        IERC20(_token).safeTransfer(msg.sender, lockedAmount);
    } 
}

// * 6. create a second withdraw function which allow them to withdraw later.

function withdrawLater(address _token) external {
    if (
        isPausableToken[_token] &&
        isWithdrawalAttemptedInTIMELOCK[msg.sender]
    ) {
        uint256 lockedAmount = balances[msg.sender][_token];
        balances[msg.sender][_token] = 0;

        if (lockedAmount == 0) {
            revert CannotWithdrawZero();
        }

        IERC20(_token).safeTransfer(msg.sender, lockedAmount);
    } else {
        revert CannotWithdraw();
    }
}

// Note: Ensure that these users do not claim tokens at this time.
```
