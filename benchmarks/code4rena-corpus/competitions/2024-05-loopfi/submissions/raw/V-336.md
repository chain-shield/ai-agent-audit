# Vulnerability details

## Impact

When funds are mistakenly sent, funds are not fairly distributed between each accounts.

When funds are ETH, everything is shared between ETH depositors and not with LRT ones.

When LRT or WETH are mistakenly sent, nobody can recover based on the `recoverERC20` function (https://github.com/code-423n4/2024-05-loop/blob/40167e469edde09969643b6808c57e25d1b9c203/src/PrelaunchPoints.sol#L379). 

## Proof of Concept
First user deposit 1 ETH by calling `lock`.
Second user deposit 1 LRTX (suppose it worth 1 ETH) by calling `lock`.
An address mistakenly send 1 ETH to the contract.

As there is no recoverETH function, the funds stay on the contract. The owner call `setLoopAddress` and when possible `convertAllETH` effectively converting 2 ETH for  2 lpETH (based on this comment https://github.com/code-423n4/2024-05-loop/blob/40167e469edde09969643b6808c57e25d1b9c203/src/PrelaunchPoints.sol#L261). We have:
- totalSupply = 1
- totalLpETH = 2

When user 1 claim he will get 2 lpETH, while user 2 will get 1 lpETH (- swapfee +slippage).

This makes an unfair distribution between users

## Tools Used
Foundry

## Recommended Mitigation Steps
For ETH case: 
Consider adding a recoverETH function that should be called only before `convertAllETH` and the maximum amount recoverable should be capped by `address(this).balance - totalSupply`.

For WETH:
Change this line (https://github.com/code-423n4/2024-05-loop/blob/40167e469edde09969643b6808c57e25d1b9c203/src/PrelaunchPoints.sol#L380) for
```
if(tokenAddress!= WETH && (tokenAddress == address(lpETH) || isTokenAllowed[tokenAddress]))
``` 

For LRT:
Consider tracking the totalSupplyToken for each LRT and then remove the limitation (https://github.com/code-423n4/2024-05-loop/blob/40167e469edde09969643b6808c57e25d1b9c203/src/PrelaunchPoints.sol#L380) for
```
if(tokenAddress == address(lpETH))
``` 

And then cap the maximum recoverable by `LRT.balanceOf(address(this)) - totalSupplyToken`

After recovery, send the mistakenly sent funds as you would do for earned fess.
