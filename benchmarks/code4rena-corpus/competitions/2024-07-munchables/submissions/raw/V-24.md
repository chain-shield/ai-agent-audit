# Vulnerability details

## Description
`_farmPlots` is having a `wrong condition` regarding the `dirty detection mechanism` which will allow a player to `continue earning with an invalid plot` which seems to warrant `Medium` severity.


## Impact
Player can still earn while being on an invalid plot.

## PoC
Alice and Bob are the players. Alice is a landlord with 121 plots [0,120] as locked 1 ETH in LockManager.
1) Bob's stake NFT 1 on Alice's plotId 120. 
2) After a week, Alice unlock 0.01 ETH, reducing his number of plot to 120 [0,119], which should prevent Bob from earning point from now on, but it won't.
- 121 --> 120 plots. 
- [0,120] --> [0,119], so plotId 120 should become invalid (dirty == true)
3) Bob continue farming and earning points as usual, as his plot is not marked as dirty during farming.

By examining the condition, we can see that after the unlock, it will evaluate the following:
if (120 < 120) which will be false, so not marking the plot as dirty as it should.
