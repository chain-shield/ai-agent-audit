# Vulnerability details

# [H-1] `unstakeMunchable()` should not have notPaused modifier

## Impact
There is notPaused modifier used for the `unstakeMunchable()` function which defeats the purpose of pausing the contract. This will prevent the users from unstaking their munchables if there is an emergency situation

## Proof of Concept
The pausing functionality should be used if the contract gets exploited so the owners can pause it and prevent any further damage to the protocol. In such case the users should be able to unstake their tokens and not have their rewards stuck in the contract for indefinite time

## Tools Used
Manual review

## Recommended Mitigation Steps
Remove the `notPaused` from the `unstakeMunchable()` function
