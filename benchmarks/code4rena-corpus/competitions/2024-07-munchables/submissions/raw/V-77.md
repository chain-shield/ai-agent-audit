# Vulnerability details

## Impact
[_farmPlots](https://github.com/code-423n4/2024-07-munchables/blob/main/src/managers/LandManager.sol#L299) sets `lastPetMunchable` to `timestamp` (where that time is in the past), which will enable the landlord to [SnuggeryManager::pet](https://github.com/code-423n4/2024-07-munchables/blob/main/src/managers/SnuggeryManager.sol#L232-L233) multiple times in a row, gaming the petting reward system.

## Proof of Concept
Farming a `dirty` plot with [_farmPlots](https://github.com/code-423n4/2024-07-munchables/blob/main/src/managers/LandManager.sol#L299) will set the landlord's `lastPetMunchable` to his `plotMetadata[landlord].lastUpdated`, which can (and most likely will) be in the past:

```solidity
   if (_getNumPlots(landlord) < _toiler.plotId) {
      timestamp = plotMetadata[landlord].lastUpdated;
      toilerState[tokenId].dirty = true;
   }

   landlordMetadata.lastPetMunchable = uint32(timestamp);
```

This variable is used inside [SnuggeryManager::pet](https://github.com/code-423n4/2024-07-munchables/blob/main/src/managers/SnuggeryManager.sol#L232-L233) as a check to prevent users from petting a lot of NFTs in 1 TX. More specifically, it allows users to pet 1 NFT every 10 minutes.

```solidity
        if (_petterPlayer.lastPetMunchable + 10 minutes > block.timestamp) {
            revert PetTooSoonError();
        }
```

However thanks to [_farmPlot](https://github.com/code-423n4/2024-07-munchables/blob/main/src/managers/LandManager.sol#L299) a landlord can pet multiple times in a single block (even a single TX):

Set up at T1:
- Have a few different accounts that each have staked 1 NFT per plot.
- [unlock](https://github.com/code-423n4/2024-07-munchables/blob/main/src/managers/LockManager.sol#L407) all of his assets, setting `lastUpdated` to T1, and having 0 free plots.

Attack at T1+10:
1. pet an NFT at T1+10 min and earn a reward
2. Farm 1 dirty plot, from one of his accounts, setting his `lastPetMunchable` to T1
3. pet another NFT
4. Farm another, again setting `lastPetMunchable` to T1
5. pet another NFT
...

## Tools Used
Manual review

## Recommended Mitigation Steps
Set `landlordMetadata.lastPetMunchable` to `block.timestamp` instead of `timestamp`:
```diff
-   landlordMetadata.lastPetMunchable = uint32(timestamp);
+   landlordMetadata.lastPetMunchable = uint32(block.timestamp);
```
