# Vulnerability details

## Impact
`landlord` will receive rewards even if he unstake tokens from `lockManager` and `_getNumPlots()` returns `zero` of `totalPlotsAvail` for `landlord`

## Proof of Concept
The `stakeMunchable()` function allows users to stake their MunchNFT and occupy a landlord's plot if the landlord has sufficient staked funds in the `lockManager`. 

Stake flow:
1. The user wants to stake a munchNFT and occupy a plot of a landlord.
2. The stake function checks the amount of available plot IDs of the landlord.
3. Since the amount of available slots is zero-based in the stake function, used `>=`:
    - If the landlord has `1` available slot, e.g., `_getNumPlots(landlord)` returns `1`.
    - The available plot ID is `0`; otherwise, it will revert (`if (1 >= 1) revert PlotTooHighError();`).

```solidity
    function stakeMunchable(address landlord, uint256 tokenId, uint256 plotId) external override forceFarmPlots(msg.sender) notPaused {
        //...
        uint256 totalPlotsAvail = _getNumPlots(landlord);
        if (plotId >= totalPlotsAvail) revert PlotTooHighError();
        //..
    }
```
```solidity
    function _getNumPlots(address _account) internal view returns (uint256) {
        // Calculates the number of plots based on the locked weighted value divided by the price per plot
        return lockManager.getLockedWeightedValue(_account) / PRICE_PER_PLOT;
    }
```
We understand logic of reverting (zerobased plotId).

Users can have more than one MunchNFT and occupy more than one plot across different landlords.
We assume that the user has 10 MunchNFTs, with some of them already staked.
The functions `stakeMunchable()`, `unstakeMunchable()`, or `transferToUnoccupiedPlot()` has the `forceFarmPlots()` modifier.
When a user stakes another NFT, unstakes, or transfers an NFT to a different plot, the `forceFarmPlots()` modifier calls the internal `_farmPlots()` function.
This internal function is forced to calculate all rewards for landlords and mark them as `dirty` if a landlord unstakes money from the `lockManager` and should not generate any gain since they do not stake any money. (The `_getNumPlots` function is responsible for this calculation.)

Let's simulate an attack flow:
1. A landlord stakes money for one plot, e.g., `_getNumPlots(landlord)` returns `1`.
2. A user occupy `0` plotId.
3. The landlord unstakes all or part of the staked money, and `_getNumPlots(landlord)` returns `0`.
4. The user performs any action with any of his NFTs, and the `forceFarmPlots()` modifiers force the calculation of rewards for all landlords that the user occupies with their NFT.
5. In that list, we have a malicious landlord who has unstaked his money and now has `0` numPlots.
6. `_farmPlots()` should mark this plotId as dirty, and in every subsequent calculation, it should ignore this plot, and the landlords should not receive any gains.
7. However, the landlord will continue to receive rewards until the user unstakes the NFT from his plotId, even if he has had `0` numPlots for a long time.

An issue in this if condition
```solidity
    timestamp = block.timestamp;
    tokenId = staked[i];
    _toiler = toilerState[tokenId];
    if (_toiler.dirty) continue;
    landlord = _toiler.landlord;
@>  if (_getNumPlots(landlord) < _toiler.plotId) {
        timestamp = plotMetadata[landlord].lastUpdated;
        toilerState[tokenId].dirty = true;
    }
```

Since for a malicious landlord `_getNumPlots(landlord)` will return `0` and the user occupies his `0` PlotId, this if condition will never be true and the toiler won't be marked as `dirty`.
```solidity
uint256 landlordPlotsAvail = _getNumPlots(landlord);
// landlordPlotsAvail == 0
uint256 ocopyPlotId = _toiler.plotId;
// ocopyPlotId == 0 
if (landlordPlotsAvail < ocopyPlotId) {
    // 0 < 0 == false 
    // toiler won't be marked as dirty       
    toilerState[tokenId].dirty = true;
}
```

This is also true for any amount of the landlord's available plots; the last one will never be `dirty`.

## Recommended Mitigation Steps
Change from `<` to `<=` in `if` condition 
```solidity
    timestamp = block.timestamp;
    tokenId = staked[i];
    _toiler = toilerState[tokenId];
    if (_toiler.dirty) continue;
    landlord = _toiler.landlord;
-   if (_getNumPlots(landlord) < _toiler.plotId) {
+   if (_getNumPlots(landlord) <= _toiler.plotId) {
        timestamp = plotMetadata[landlord].lastUpdated;
        toilerState[tokenId].dirty = true;
    }
```
