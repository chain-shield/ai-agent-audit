# Vulnerability details

## Description
`transferToUnoccupiedPlot` is lacking updating `plotId field` during his operation which is unexpected and make this `transfer incomplete` which seems to warrant `Medium` severity.

This is a separate finding from my other (lacking dirty field) as it is a `different root cause`, `different impact` and `require a different fix`, so those two issues while being in the same code area should be treated distinctively.

## Impact
Stake accounting is bricked when a player is transfering plots, as the new plotId is not updated inside the toiler struct, which means from the staking accounting perspective, the player NFT is still staked against the previous plotId which bring multiple side effects, one being: 
- If transfering from a non-dirty plot (last landlord plotId --> first landlord plotId) and later on the Lanlord unlock funds and have his plots number reduced, the player will not be earning during farming, as while the plot count reduction should not affect the player, it will as the toiler still point to the previous plotId (the last one which is now gone instead of the first plotId), so it will be marked as dirty and stop earning.

## PoC
Alice and Bob are the players. Alice is a landlord with 121 plots [0,120] as locked 1 ETH in LockManager.
1) Bob's stake NFT 1 on Alice's plotId 120. 
2) Bob decides to `transferToUnoccupiedPlot` his NFT 1 to plotId 100, it will work fine, but the `toiler` will still point to 120 internally even if `plotOccupied` will be ok.
3) After a week, Alice unlock 0.1 ETH, reducing his number of plot to 112 [0,111].
4) Bob decides to farm but will have a odd surprise, as his NFT will be earning points only for on the `first attempt but not afterwards`, as it will be `marked as dirty`, since toiler still see 120 and not 100 as plotId.

## Recommended Mitigation Steps
Apply the following patch to resolve this issue.

```diff
    function transferToUnoccupiedPlot(
        uint256 tokenId,
        uint256 plotId
    ) external override forceFarmPlots(msg.sender) notPaused {
        (address mainAccount, ) = _getMainAccountRequireRegistered(msg.sender);
        ToilerState memory _toiler = toilerState[tokenId];
        uint256 oldPlotId = _toiler.plotId;
        uint256 totalPlotsAvail = _getNumPlots(_toiler.landlord);
        if (_toiler.landlord == address(0)) revert NotStakedError();
        if (munchableOwner[tokenId] != mainAccount) revert InvalidOwnerError();
        if (plotOccupied[_toiler.landlord][plotId].occupied)
            revert OccupiedPlotError(_toiler.landlord, plotId);
        if (plotId >= totalPlotsAvail) revert PlotTooHighError();

        toilerState[tokenId].latestTaxRate = plotMetadata[_toiler.landlord].currentTaxRate;
+	toilerState[tokenId].plotId = plotId;
        plotOccupied[_toiler.landlord][oldPlotId] = Plot({
            occupied: false,
            tokenId: 0
        });
        plotOccupied[_toiler.landlord][plotId] = Plot({
            occupied: true,
            tokenId: tokenId
        });

        emit FarmPlotLeave(_toiler.landlord, tokenId, oldPlotId);
        emit FarmPlotTaken(toilerState[tokenId], tokenId);
    }
```
