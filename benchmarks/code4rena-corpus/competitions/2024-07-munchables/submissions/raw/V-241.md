# Vulnerability details

## Impact
Whenever external calls are made (like transferring an `ERC721` token), there is a risk of unintended side effects. For example, in `stakeMunchable`:
```solidity
munchNFT.transferFrom(mainAccount, address(this), tokenId); 
```
If the `transferFrom` call triggers a fallback function or other code that could reenter this contract, there could be vulnerabilities.
