# Vulnerability details

## Impact
The 'unstakeMunchable' function is vulnerable to a reentrancy attack due to the external call to 'munchNFT.transferFrom'. 
An attacker could exploit this by using a malicious contract to re-enter the 'unstakeMunchable' function during the execution of 'munchNFT.transferFrom', potentially resulting in multiple unstakes or unintended state manipulation.

The 'munchNFT.transferFrom' function is an external call to another contract (munchNFT), which may contain its own logic and could call back into the 'unstakeMunchable' function or other functions within the same contract.

After the external call to 'munchNFT.transferFrom', the contract updates state variables such as `plotOccupied`, `toilerState`, `munchableOwner`, and calls `_removeTokenIdFromStakedList`. If a reentrancy attack occurs, these state variables may not be updated correctly, leading to inconsistent or exploitative states.

```solidity
    function ownerOf(uint256 tokenId) external view override returns (address) {
        return _owners[tokenId];

    function approve(address to, uint256 tokenId) external override {
        _operatorApprovals[msg.sender][to] = true;
    }

    function getApproved(uint256 tokenId) external view override returns (address) {
        return address(0);
    }

    function setApprovalForAll(address operator, bool approved) external override {
        _operatorApprovals[msg.sender][operator] = approved;

        return _operatorApprovals[owner][operator];
```

## Recommended Mitigation Steps
I have implemented OpenZeppelin's ReentrancyGuard and applied the nonReentrant modifier to the function. Additionally, I adhere to the checks-effects-interactions pattern to ensure state changes occur before any external calls.

```solidity
import "openzeppelin-contracts/security/ReentrancyGuard.sol";

contract LandManager is BaseBlastManagerUpgradeable, ILandManager, ReentrancyGuard {
    function unstakeMunchable(
        uint256 tokenId
    ) external override forceFarmPlots(msg.sender) notPaused nonReentrant {
        (address mainAccount, ) = _getMainAccountRequireRegistered(msg.sender);
        ToilerState memory _toiler = toilerState[tokenId];
        if (_toiler.landlord == address(0)) revert NotStakedError();
        if (munchableOwner[tokenId] != mainAccount) revert InvalidOwnerError();

        // Update state before external call
        plotOccupied[_toiler.landlord][_toiler.plotId] = Plot({
            occupied: false,
            tokenId: 0
        });
        toilerState[tokenId] = ToilerState({
            lastToilDate: 0,
            plotId: 0,
            landlord: address(0),
            latestTaxRate: 0,
            dirty: false
        });
        munchableOwner[tokenId] = address(0);
        _removeTokenIdFromStakedList(mainAccount, tokenId);

        // External call
        munchNFT.transferFrom(address(this), mainAccount, tokenId);
        emit FarmPlotLeave(_toiler.landlord, tokenId, _toiler.plotId);
    }

}
```
