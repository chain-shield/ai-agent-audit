# Vulnerability details

## Vulnerability details 
When _farmPlots() checks for dirty plotId, it compares landlord's number of plots to toiler.plotId.
```solidity
@> if (_getNumPlots(landlord) < _toiler.plotId) {
    timestamp = plotMetadata[landlord].lastUpdated;
    toilerState[tokenId].dirty = true;
}
```
Now the problem is, above check excludes `last` plotId which is `dirty` due to missing = sign along with <

//How this works
1. Suppose landlord has initially 4 plots ie [0, 1, 2, 3]
2. User staked for plotId = 3
3. Landlord withdraw his position, which decreased his number of plots to 3 ie [0, 1, 2]
4. Now, plotId = 3 is dirty but according to above check _getNumPlots(landlord) = 3 & plotId = 3, but 3 is not greater than 3 therefore plotId = 3 will not be marked as dirty

Note: All this happening due to missing = sign in if statement 


## Impact
Last plotId will not be marked as dirty
