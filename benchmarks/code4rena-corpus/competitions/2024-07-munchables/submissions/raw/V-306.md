# Vulnerability details

## Impact
Reentrancy attacks in the 'transferToUnoccupiedPlot' function due to the external call to 'munchNFT.transferFrom'.

An attacker could exploit this vulnerability by using a malicious contract to call back into the 'transferToUnoccupiedPlot' function during the execution of 'munchNFT.transferFrom'. This could result in multiple unauthorized transfers or unexpected state manipulations.

The 'munchNFT.transferFrom' function is an external call to another contract (munchNFT), which may have its own logic and could potentially call back into the 'transferToUnoccupiedPlot' function or other functions within the same contract.

Following the external call to 'munchNFT.transferFrom', the contract updates state variables such as 'plotOccupied' and 'toilerState'. If a reentrancy attack occurs, these state variables may not be updated correctly, leading to inconsistent or exploitable states.

## Recommended Mitigation Steps
I Implemented the 'ReentrancyGuard' from OpenZeppelin and applied the 'nonReentrant' modifier to the function. Additionally, I try to follow the checks-effects-interactions pattern, ensuring state changes are made before external calls.

```solidity
import "openzeppelin-contracts/security/ReentrancyGuard.sol";

contract LandManager is BaseBlastManagerUpgradeable, ILandManager, ReentrancyGuard {

    function transferToUnoccupiedPlot(
        uint256 tokenId,
        uint256 plotId
    ) external override forceFarmPlots(msg.sender) notPaused nonReentrant {
        (address mainAccount, ) = _getMainAccountRequireRegistered(msg.sender);
        ToilerState memory _toiler = toilerState[tokenId];
        uint256 oldPlotId = _toiler.plotId;
        uint256 totalPlotsAvail = _getNumPlots(_toiler.landlord);
        if (_toiler.landlord == address(0)) revert NotStakedError();
        if (munchableOwner[tokenId] != mainAccount) revert InvalidOwnerError();
        if (plotOccupied[_toiler.landlord][plotId].occupied)
            revert OccupiedPlotError(_toiler.landlord, plotId);
        if (plotId >= totalPlotsAvail) revert PlotTooHighError();

        // Update state before external call
        toilerState[tokenId].latestTaxRate = plotMetadata[_toiler.landlord]
            .currentTaxRate;
        plotOccupied[_toiler.landlord][oldPlotId] = Plot({
            occupied: false,
            tokenId: 0
        });
        plotOccupied[_toiler.landlord][plotId] = Plot({
            occupied: true,
            tokenId: tokenId
        });

        emit FarmPlotLeave(_toiler.landlord, tokenId, oldPlotId);
        emit FarmPlotTaken(toilerState[tokenId], tokenId);
    }

}
```
