# Vulnerability details

## Impact
Users can start staking their munchables even though the landlord has not specified the taxrates, This happens when the landlord has enough tokens locked and hence plots are allocated but has not updated the farm.

## Proof of Concept

In the `stakeMunchable()` , there are no checks done to ensure `plotMetadata[landlord].lastUpdated` not equal to `0` for the landlord specified by the user.

Allows user stake at 0 tax rate since landlord has only locked the tokens to get allocated plots but has not updated the `plotMetadata` with `DEFAULT_TAX`

https://github.com/code-423n4/2024-07-munchables/blob/94cf468aaabf526b7a8319f7eba34014ccebe7b9/src/managers/LandManager.sol#L131-L171

## Tools Used
Manual

## Recommended Mitigation Steps

Include  this check in `stakeMunchable()`
```solidity
if(plotMetadata[landlord].lastUpdated =0) revert;
```
