# Vulnerability details

## Impact
Malicious landlords can exploit renters by front-running a victim’s stake transaction, increasing the tax rate to the maximum just before the victim’s transaction is processed.

- Imagine a scenario where Bob is the landlord and Alice is the renter. Bob creates an opportunity by locking his tokens and setting an attractive minimum tax rate, which appears advantageous to Alice as she anticipates earning a significant amount of Schnibbles.

- However, when Alice sends a transaction to stake her NFT, Bob can observe this transaction and front-run it by sending a new transaction to increase the tax rate to the maximum. By setting a higher gas price than Alice, Bob ensures that his transaction gets processed first.

- Bob can then lower the tax rate again after Alice’s unstake transaction, allowing him to exploit other users with the same strategy.

- As a result, Alice, expecting to earn many Schnibbles, ends up earning far less than anticipated. This not only deceives Alice but also severely undermines the integrity of the protocol. Users are likely to feel tricked, leading to a significant loss of reputation and trust in the Munchables NFT platform.

- This exploit poses a critical threat to the fairness and reliability of the system, potentially driving users away and damaging the platform’s long-term viability. Immediate attention and resolution are required to safeguard the interests of all users and maintain trust in the platform.

      const [, { unfedSchnibbles: earnedSchnibblesOnFirstStake }] =
        await testContracts.accountManagerProxy.contract.read.getPlayer([alice]);

      // FrontRun Attack
      await testContracts.munchNFT.contract.write.approve(
        [testContracts.landManagerProxy.contract.address, 1n],
        { account: alice }
      );

      // malicious landlord updates tax rate to max before bob stakes it
      await testContracts.landManagerProxy.contract.write.updateTaxRate([maxTaxRate], {
        account: bob,
      });

      await testContracts.landManagerProxy.contract.write.stakeMunchable([alice, 1, 0], {
        account: alice,
      });

      await testContracts.landManagerProxy.contract.write.unstakeMunchable([1], {
        account: alice,
      });

      // malicious landlord lowers to min tax rate after unstake to make his plots attractive to new victims
      await testContracts.landManagerProxy.contract.write.updateTaxRate([minTaxRate], {
        account: bob,
      });

        await testContracts.accountManagerProxy.contract.read.getPlayer([alice]);

      const earnedSchnibblesOnSecondStake = totalEarnedSchnibbles - earnedSchnibblesOnFirstStake;
      console.log("earnedSchnibblesOnSecondStake", earnedSchnibblesOnSecondStake);

      assert(
        earnedSchnibblesOnSecondStake < earnedSchnibblesOnFirstStake,
        `Expected ${earnedSchnibblesOnSecondStake} to be less than ${earnedSchnibblesOnFirstStake}`
      );
    });

## Recommended Mitigation Steps

- Add a timelock to update the tax rate. 
- Make the updateTaxRate function internal and add the following functions and states to keep track of pending transactions.

```
// this can be any number
unit constant _lockTime = 100;

struct PendingTransaction {
        uint256 taxRate;
        uint256 unlockTime;
}

mapping(address => PendingTransaction) public pendingTransactions;

// this function creates a pending transaction to update the tax rate

    function createUpdateTaxRateTransaction(uint256 _taxRate) external {
        require(pendingTransactions[msg.sender].taxRate == 0, "Transaction already exists");
        pendingTransactions[msg.sender] = PendingTransaction({
            taxRate: _taxRate,
            unlockTime: block.timestamp + _lockTime
        });
    }

// landlords can execute this function to update their tax rate
    function executePendingTaxRateUpdateTransaction() external {
        PendingTransaction memory transaction = pendingTransactions[msg.sender];
        require(block.timestamp >= transaction.unlockTime, "Transaction is locked");

        uint256 newTaxRate = transaction.taxRate;
        transaction.taxRate = 0;

        updateTaxRate(newTaxRate);
    }

// make this function internal
   function updateTaxRate(uint256 newTaxRate) internal override notPaused {
        (address landlord, ) = _getMainAccountRequireRegistered(msg.sender);
        if (newTaxRate < MIN_TAX_RATE || newTaxRate > MAX_TAX_RATE)
            revert InvalidTaxRateError();
        if (plotMetadata[landlord].lastUpdated == 0)
            revert PlotMetadataNotUpdatedError();
        uint256 oldTaxRate = plotMetadata[landlord].currentTaxRate;
        plotMetadata[landlord].currentTaxRate = newTaxRate;
        emit TaxRateChanged(landlord, oldTaxRate, newTaxRate);
    }
```
