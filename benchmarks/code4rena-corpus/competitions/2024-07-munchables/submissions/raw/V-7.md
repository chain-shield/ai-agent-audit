# Vulnerability details

## Impact
If the landlord of the user ever withdraws enough funds to make the plot they are staking on invalid, transferring to another existing plot using `transferToUnoccupiedPlot` will not allow them to receive rewards.

## Proof of Concept

A plot becomes `dirty` when the landlord withdraws/unlocks funds and lowers the amount of plots they own making some of the plots currently being used invalid. The developers have decided to simply award the stakers and landlords once and set the plot as dirty by setting `toilerState[tokenId].dirty = true;`

When a user calls `transferToUnoccpiedPlot` the contract ensures that the new `plotId` is a valid one by checking `if (plotId >= totalPlotsAvail) revert PlotTooHighError();` but it never resets the `toilerState[tokenId].dirty` variable to signify the fact that the user is now staking on a valid plot. That means that when the user tries to farm the plot using `farmPlots` or through the modifier on all other functions `forceFarmPlots` the code will hit this check:
`if (_toiler.dirty) continue;` and skip over the plot and will not grand the user or the landlord any rewards.

## Recommended Mitigation Steps

```diff
    function transferToUnoccupiedPlot(
        uint256 tokenId,
        uint256 plotId
    ) external override forceFarmPlots(msg.sender) notPaused {
        (address mainAccount, ) = _getMainAccountRequireRegistered(msg.sender);
        ToilerState memory _toiler = toilerState[tokenId];
        uint256 oldPlotId = _toiler.plotId;
        uint256 totalPlotsAvail = _getNumPlots(_toiler.landlord);
        if (_toiler.landlord == address(0)) revert NotStakedError();
        if (munchableOwner[tokenId] != mainAccount) revert InvalidOwnerError();
        if (plotOccupied[_toiler.landlord][plotId].occupied)
            revert OccupiedPlotError(_toiler.landlord, plotId);
        if (plotId >= totalPlotsAvail) revert PlotTooHighError();

+       toilerState[tokenId].dirty = false;
        toilerState[tokenId].latestTaxRate = plotMetadata[_toiler.landlord]
            .currentTaxRate;
        plotOccupied[_toiler.landlord][oldPlotId] = Plot({
            occupied: false,
            tokenId: 0
        });
        plotOccupied[_toiler.landlord][plotId] = Plot({
            occupied: true,
            tokenId: tokenId
        });

        emit FarmPlotLeave(_toiler.landlord, tokenId, oldPlotId);
        emit FarmPlotTaken(toilerState[tokenId], tokenId);
    }
```
