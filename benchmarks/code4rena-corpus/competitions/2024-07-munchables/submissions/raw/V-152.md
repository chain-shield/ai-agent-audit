# Vulnerability details

Description: Functions like stakeMunchable and unstakeMunchable involve external calls before state changes, making them susceptible to reentrancy attacks.These functions can be targets for reentrancy attacks, as there are no reentrancy guards.

munchNFT.transferFrom(mainAccount, address(this), tokenId);
plotOccupied[landlord][plotId] = Plot({ occupied: true, tokenId: tokenId });


Impact
Reentrancy attacks can allow an attacker to re-enter a function and manipulate contract state in ways that can lead to loss of funds, inconsistent states, or other unexpected behaviors.

Recommendation
Add reentrancy guards to vulnerable functions. For example, use the ReentrancyGuard contract from OpenZeppelin.

import "openzeppelin-contracts/contracts/security/ReentrancyGuard.sol";

contract LandManager is BaseBlastManagerUpgradeable, ILandManager, ReentrancyGuard {
    // contract code...
}
