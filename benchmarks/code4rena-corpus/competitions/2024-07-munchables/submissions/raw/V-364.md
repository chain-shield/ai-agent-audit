# Vulnerability details

## Impact
The transferToUnoccupiedPlot function does not update toilerState[tokenId].dirty. As a result, a renter cannot collect schnibbles from a munchable flagged as dirty indefinitely, leading to a loss of game rewards and potential player dissatisfaction.

## Proof of Concept
Call the transferToUnoccupiedPlot function with a tokenId and a plotId.
Observe that toilerState[tokenId].dirty remains unchanged, despite the munchable being moved to a new plot.

    // @audit-issue toilerState.dirty is not updated in this function
    function transferToUnoccupiedPlot(
        uint256 tokenId,
        uint256 plotId
    ) external override forceFarmPlots(msg.sender) notPaused {
        (address mainAccount, ) = _getMainAccountRequireRegistered(msg.sender);
        ToilerState memory _toiler = toilerState[tokenId];
        uint256 oldPlotId = _toiler.plotId;
        uint256 totalPlotsAvail = _getNumPlots(_toiler.landlord);
        if (_toiler.landlord == address(0)) revert NotStakedError();
        if (munchableOwner[tokenId] != mainAccount) revert InvalidOwnerError();
        if (plotOccupied[_toiler.landlord][plotId].occupied)
            revert OccupiedPlotError(_toiler.landlord, plotId);
        if (plotId >= totalPlotsAvail) revert PlotTooHighError();
    
        toilerState[tokenId].latestTaxRate = plotMetadata[_toiler.landlord]
            .currentTaxRate;
        plotOccupied[_toiler.landlord][oldPlotId] = Plot({
            occupied: false,
            tokenId: 0
        });
        plotOccupied[_toiler.landlord][plotId] = Plot({
            occupied: true,
            tokenId: tokenId
        });

        emit FarmPlotLeave(_toiler.landlord, tokenId, oldPlotId);
        emit FarmPlotTaken(toilerState[tokenId], tokenId);
    }

## Tools Used
Manual code review

## Recommended Mitigation Steps
Update the toilerState[tokenId].dirty to false within the transferToUnoccupiedPlot function to allow renters to collect schnibbles.

    toilerState[tokenId].dirty = false;

Adding this line ensures the dirty flag is correctly updated, enabling schnibble collection after moving the munchable to a new plot.
