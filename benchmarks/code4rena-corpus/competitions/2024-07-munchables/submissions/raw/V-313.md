# Vulnerability details

## Impact
In _farmPlots() function, while checking for plots which are to be marked dirty, the check used is :
```Soldity
if (_getNumPlots(landlord) < _toiler.plotId){
    timestamp = plotMetadata[landlord].lastUpdated;
    toilerState[tokenId].dirty = true;
 }

```
https://github.com/code-423n4/2024-07-munchables/blob/94cf468aaabf526b7a8319f7eba34014ccebe7b9/src/managers/LandManager.sol#L258

But it should be :
```Soldity
if (_getNumPlots(landlord) <= _toiler.plotId){
    timestamp = plotMetadata[landlord].lastUpdated;
    toilerState[tokenId].dirty = true;
 }
```



## Proof of Concept

Consider landlord initially had 6 plots (0-5) , and the toiler was toiling on plot 5 initially. And then the number of plots of landlord decreases to 5 (0-4).
Now on this check for dirty plots , _getNumPlots(landlord) = 5 and toiler.plotId =5 also. But with the current implementation , it skips the check and wont mark the toilerState as dirty.
