# Vulnerability details

## Impact

The `transferToUnoccupiedPlot` function in the `LandManager.sol` contract is intended to move a Munchable NFT from its current plot to a new unoccupied plot. However, the function fails to update the `plotId` for the Munchable, resulting in an inconsistent state where the Munchable's recorded `plotId` does not match its actual plot location.

This can lead to several issues:

1. The `plotId` stored in the `toilerState` does not reflect the actual plot location, causing confusion and potential errors in subsequent operations.
2. Rewards and other operations dependent on the correct `plotId` will be calculated incorrectly.

## Proof of Concept

Current [`transferToUnoccupiedPlot`](https://github.com/code-423n4/2024-07-munchables/blob/main/src/managers/LandManager.sol#L199-L226) function (Simplified):

```solidity
solidityCopy code
function transferToUnoccupiedPlot(
    uint256 tokenId,
    uint256 plotId,
    address mainAccount,
    address landlord
) external override notPaused {
    ToilerState memory _toiler = toilerState[tokenId];
    uint256 oldPlotId = _toiler.plotId;

    if (_toiler.landlord == address(0)) revert NotStakedError();
    if (munchableOwner[tokenId] != mainAccount) revert InvalidOwnerError();
    if (plotOccupied[_toiler.landlord][plotId].occupied) revert OccupiedPlotError(_toiler.landlord, plotId);
    if (plotId >= _getNumPlots(landlord)) revert PlotTooHighError();

    // Transfer logic
    plotOccupied[_toiler.landlord][oldPlotId].occupied = false;
    plotOccupied[_toiler.landlord][plotId] = Plot(true, tokenId);

    emit PlotTransferred(_toiler.landlord, tokenId, oldPlotId, plotId);
}
```

In the current implementation, the `plotId` in the `toilerState` is not updated to reflect the new plot location. This results in an inconsistent state.

## Recommended Mitigation Steps

Update `plotId`: Ensure the `plotId` in the `toilerState` is updated to the new plot ID during the transfer.

Modified `transferToUnoccupiedPlot` Function:

```solidity
solidityCopy code
function transferToUnoccupiedPlot(
    uint256 tokenId,
    uint256 plotId,
    address mainAccount,
    address landlord
) external override notPaused {

    plotOccupied[_toiler.landlord][oldPlotId].occupied = false;

}
```
