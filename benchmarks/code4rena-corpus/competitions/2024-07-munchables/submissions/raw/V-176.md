# Vulnerability details

## Impact 
The `transferToUnoccupiedPlot` function fails to update `toilerState[tokenId].lastToilDate` when updating `toilerState[tokenId].latestTaxRate`. This oversight leads to inaccurate calculations of `schnibblesTotal` in the `_farmPlots` function, which subsequently results in incorrect values for `schnibblesLandlord`, `renterMetadata.unfedSchnibbles`, and `landlordMetadata.unfedSchnibbles`. Ultimately, this causes the `_farmPlots` function to malfunction.

## Proof of Concept

        plotOccupied[_toiler.landlord][plotId] = Plot({
            occupied: true,
            tokenId: tokenId
        });

        emit FarmPlotTaken(toilerState[tokenId], tokenId);
    }

## Recommended Mitigation Steps
It is recommended to update `toilerState[tokenId].lastToilDate` within the `transferToUnoccupiedPlot` function when updating `toilerState[tokenId].latestTaxRate`, as follows:
```solidity
+     toilerState[tokenId].lastToilDate = block.timestamp;
```
