# Vulnerability details

## Impact
The LandManager contract does not implement the IERC721Receiver interface. For an ERC721 token transfer to a contract to be successful, the receiving contract must implement the onERC721Received() function from the IERC721Receiver interface. Since the stakeMunchable() and unstakeMunchable() functions perform ERC721 transfers, the operations will always revert and thus, staking will never be possible.

## Proof of Concept
```contract LandManager is BaseBlastManagerUpgradeable, ILandManager {```
A contract that is ERC721 compatible will implement IERC721Receiver  which would look like this:
```contract LandManager is BaseBlastManagerUpgradeable, ILandManager, IERC721Receiver{```
