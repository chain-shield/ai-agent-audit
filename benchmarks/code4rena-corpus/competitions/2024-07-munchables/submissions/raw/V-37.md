# Vulnerability details

## Impact
While transferring Token to Unoccupied plot using the `transferToUnoccupiedPlot(...)` function, the logic is not properly update the new plot id in the Toiler state. This essentially breaks the logic check related to occupied plots vs unoccupied plots.

This will eventually lead to some plot to remain as occupied for the landlord while token was transferred to other plots.
 

## Proof of Concept
Lets say, for `tokenId` 15, the `plotId` assigned when staking was 1.
> toilerState.plotId = 1;
 plotOccupied[landlord][1] = {occupied, 15};

### First transfer:
At a later point, it was transferred to plotId 5.
> toilerState.plotId = 1; // due to bug, the plotId was not updated to 5
  plotOccupied[landlord][5] = {occupied, 15};

and 
> plotOccupied[landlord][1] = notoccupied, 0;  
  
### Second transfer:
At a later point, it was transferred to plotId 7.
> toilerState.plotId = 1; // due to bug, the plotId was not updated to 7
  plotOccupied[landlord][7] = {occupied, 15};

and
 
> plotOccupied[landlord][1] = notoccupied, 0; // incorrect plot is being marked as not occupied.

After executing these transfer for the landlord, plot number `5` and `7` are marked as occupied and will remain so. These plot cannot be reused by the landlord for other token ids.

Based on the total value of locked tokens, it is possible that some of the valid tokens are also marked dirty due to the plot number at which it was locked earlier. These tokens will remain locked for ever.

```solidity
   uint256 oldPlotId = _toiler.plotId;
   ...
 ==>if (plotOccupied[_toiler.landlord][plotId].occupied)
            revert OccupiedPlotError(_toiler.landlord, plotId);
    ...
 ==>   plotOccupied[_toiler.landlord][oldPlotId] = Plot({
            occupied: false,
            tokenId: 0
        });
```

Manual Review

## Recommended Mitigation Steps
Release the previous `plotId` during the transfer process. Update the `ToilerState` to reflect the `plotId` to which the `token-id` was transferred to.

```solidity
    toilerState[tokenId].plotId = plotId;
```
