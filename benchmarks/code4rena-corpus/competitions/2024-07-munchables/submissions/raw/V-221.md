# Vulnerability details

## Impact
User can stake to plotId = 0 when calling stakeMunchables() evading toiler.dirty in all cases making him accruing rewards uncoditionaly even if there are no available plots. 

## Proof of Concept
If we have Alice as staker:

1. Alice calls stakeMunchable(landlord = 1, tokenId = 1, plotId = 0);

```solidity
 function stakeMunchable(
        address landlord,
        uint256 tokenId,
        uint256 plotId
    ) external override forceFarmPlots(msg.sender) notPaused {
        -----------------------||----------------------------
        -----------------------||----------------------------
        -----------------------||----------------------------
        -----------------------||----------------------------
        uint256 totalPlotsAvail = _getNumPlots(landlord); 
        if (plotId >= totalPlotsAvail) revert PlotTooHighError(); //@audit plotId = 0 is valid value
    }
```

A stake like this breaks the game because in the code below Alice make sure she can farm even if there are no plots available making core game mechanic broken.

  ```solidity
  function _farmPlots(address _sender) internal {
        (address mainAccount, MunchablesCommonLib.Player memory renterMetadata) = _getMainAccountRequireRegistered(_sender);

        -----------------------||----------------------------
        -----------------------||----------------------------
        -----------------------||----------------------------
        -----------------------||----------------------------
        for (uint8 i = 0; i < staked.length; i++) {
            timestamp = block.timestamp;
            tokenId = staked[i];
            _toiler = toilerState[tokenId];
            if (_toiler.dirty) continue;
            landlord = _toiler.landlord;

            if (_getNumPlots(landlord) < _toiler.plotId) { //@audit we will never reach this logic making the toiler for the stake "forever clean"
                timestamp = plotMetadata[landlord].lastUpdated;
                toilerState[tokenId].dirty = true; 
            }
        }
  }
  ```

Likelihood = high 
Impact = high
Severity = high

## Tools Used
Manual review
## Recommended Mitigation Steps
Make the condition "if (plotId >= totalPlotsAvail)" to if "(plotId > totalPlotsAvail)", or check for plotId = 0 because 0 is not a valid value for plotId as it is colliding with totalPlotsAvail
