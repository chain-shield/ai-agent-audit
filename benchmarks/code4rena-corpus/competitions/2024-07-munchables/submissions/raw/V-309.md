# Vulnerability details

## Impact
The `initialize` function, protected by the `initializer` modifier, is designed to be called only once. However, if not properly secured, it could be invoked by unauthorized parties, potentially reconfiguring the contract with unauthorized settings.

## Recommended Mitigation Steps
To ensure that only authorized users, such as the contract owner, can invoke this function, please implement an access control modifier such as `onlyOwner`.
