# Vulnerability details

## Impact
Players and landlords with unclaimed rewards will receive a different amount based on the change.

## Proof of Concept
`BASE_SCHNIBBLE_RATE`, `REALM_BONUSES` and `RARITY_BONUSES` are all global parameters set by the config. However since they are not immutable it is presumed that if there is a need they can be changed to whatever the system sees fit.

```solidity
    uint256 BASE_SCHNIBBLE_RATE;
    uint256 PRICE_PER_PLOT;
    int16[] REALM_BONUSES;
    uint8[] RARITY_BONUSES;
```

However altering these variables will have an effect on all generated, but not yet claimed rewards. That is because [_farmPlots](https://github.com/code-423n4/2024-07-munchables/blob/main/src/managers/LandManager.sol#L270-L286) in a way generates reward time, which is multiplied by `BASE_SCHNIBBLE_RATE` to get the reward amount. Changing this value will have an effect, be it positive or negative, on all unclaimed rewards.

Same can be said for the rest of previously mentioned variables.

## Tools Used
Manual review

## Recommended Mitigation Steps
Take into account such behavior when changing these variables.
