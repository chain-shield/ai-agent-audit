# Vulnerability details

## Impact
Landlords may be prevented from petting when they should be allowed to if farming has recently occurred, since those are two different operations for generating Schnibbles.

In `LandManager.sol`, the `lastPetMunchable` is set:

```javascript
function _farmPlots(address _sender) internal {
    // ... previous code ...

    landlordMetadata.unfedSchnibbles += schnibblesLandlord;
    landlordMetadata.lastPetMunchable = uint32(timestamp); // Incorrect update during farming

    // ... rest of the function ...
}
```

In `SnuggeryManager.sol`, it would prevent the landlord from petting their Munchable, even though it hasn't been pet, it has only farmed the plot:

```javascript
function pet(address _pettedOwner, uint256 _tokenId) external notPaused {
    // ... previous code ...

    if (_petterPlayer.lastPetMunchable + 10 minutes > block.timestamp)
        revert PetTooSoonError();

    // ... rest of the function ...
}
```

## Tools Used

Manual code review

## Recommended Mitigation Steps

Rely on `lastToilDate` to track farming operations of a Munchable and remove the `lastPetMunchable` update for the landlord:

```diff
function _farmPlots(address _sender) internal {
    // ... previous code ...

    landlordMetadata.unfedSchnibbles += schnibblesLandlord;
-   landlordMetadata.lastPetMunchable = uint32(timestamp); // Incorrect update during farming

    // ... rest of the function ...
}
```
