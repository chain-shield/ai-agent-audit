# Vulnerability details

## Summary
Using ```transferFrom``` function when transferring NFTs does not verify that the receiver can handle receiving them properly.
In a time where more users depend on using smart contracts instead of EOAs this should be implemented properly.

## Impact
Smart contract accounts that not implement receiving NFTs (ERC721) can be stuck and lost.

## Tools Used
manual review

## Recommended Mitigation Steps
Replace line in question with:
```
munchNFT.safeTransferFrom(address(this), mainAccount, tokenId);
```
