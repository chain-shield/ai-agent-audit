# Vulnerability details

## Impact
The user can lock his NFT and be unable to unstake it causing him the loss of his NFT and also the loss of `schnibbles`.

## Proof of Concept
Imagine this scenario: 
1. Alice has staked ETH in the protocol , which means she has certain amount of plots, calculated by `_getNumPlots` function:
```
    function _getNumPlots(address _account) internal view returns (uint256) {
        return lockManager.getLockedWeightedValue(_account) / PRICE_PER_PLOT;
    }
```
2. Bob decides to stake his munchable NFT with the `stakeMunchable` function with landlord parameter `Alice` and plotId 0 or plotId 1, assuming Alice has enough staked to have plots.
3. Now Alice at no point in time updates her Plot metadata leaving the `lastUpdated` variable in the PlotMetadata to it's default value of 0.
4. Alice decides to unstake her tokens in the protocol, leaving her with close to 0 or funds under the `PRICE_PER_PLOT` variable , resulting in `_getNumPlots` function returning 0
5. Bob decides to unstake his munchable  NFT and `_farmPlots` function is called.
We get to this check that will be triggered because Alice has no staked funds and `_getNumPlots` returns 0:
```
            if (_getNumPlots(landlord) < _toiler.plotId) { //! What happens when a landlord removes his staked tokens?
                timestamp = plotMetadata[landlord].lastUpdated; //!lastUpdated can it be 0?
                toilerState[tokenId].dirty = true;
            }
```
`timestamp` is seto to  'lastUpdated' variable but remember this variable is 0 because Alice never updated her Plot metadata, look at point 3 above.
So timestamp being set to 0 we get to this calculation:
```
    schnibblesTotal = (timestamp - _toiler.lastToilDate) * BASE_SCHNIBBLE_RATE;
```
Where `timestamp - _toiler.lastToilDate` will be 0 - timestamp of NFT staking. 
This will return <0 and cause the function to revert.
6. Since the `_farmPlots` function reverts and it's called basically everywhere including in the `unstakeMunchable` and `transferToUnoccupiedPlot` this will leave the NFT stuck in the contract.

## Tools Used
Manual review
Integrate a check for the `lastUpdated` parameter for Plot metadata in the `_farmPlots` function.
