# Vulnerability details

## Impact
When renters farm the plots, the landlord's variable `lastPetMunchable` is updated to the current timestamp:

`LandManager::_farmPlots`
```javascript
landlordMetadata.lastPetMunchable = uint32(timestamp);
```

During the next ten minutes landlords will not be able to pet schnibbles:

`SnuggeryManager::pet`
```javascript
if (_petterPlayer.lastPetMunchable + 10 minutes > block.timestamp)
        revert PetTooSoonError();
```

If the landlord has locked a tiny amount it will not be problematic, however for those who own many plots it might become difficult to pet schnibbles to other munchables.

Since updating `lastPetMunchable` is not necessary when farming a plot, it is suggested to remove it as this might discourage some landlords from locking more tokens.
