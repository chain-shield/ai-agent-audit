# Vulnerability details

## Impact
The `_farmPlots` function contains an unbounded loop that iterates over all staked Munchables for a given user.If a user has a large number of staked Munchables, the function may exceed the block gas limit, causing the transaction to fail.Also an attacker could potentially stake a large number of Munchables to make the `_farmPlots` function unusable, effectively denying service to themselves and also potentially affecting other contract functionalities that rely on this function.




## Proof of Concept
Looking at the loop in the [`_farmPlots`](https://github.com/code-423n4/2024-07-munchables/blob/94cf468aaabf526b7a8319f7eba34014ccebe7b9/src/managers/LandManager.sol#L232-L310) function:

```solidity
for (uint8 i = 0; i < staked.length; i++) {
    // Loop body with multiple operations and state changes
}
```

This loop iterates over all staked Munchables, performing multiple operations for each, including external calls and state changes. The gas cost increases with the number of staked Munchables, potentially exceeding the block gas limit.
