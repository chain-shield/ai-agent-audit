# Vulnerability details

## Description
The current implementation of Schnibble calculation in the `_farmPlots` function is incorrect, leading to drastically reduced Schnibble generation and inverted bonus effects. This error significantly impacts the game's economy and core mechanics.

## Code snippet

```solidity
schnibblesTotal = uint256(
                (int256(schnibblesTotal) +
                    (int256(schnibblesTotal) * finalBonus)) / 100
            );
```

## Problem
The current calculation:
1. Incorrectly applies bonuses
2. Divides the result by 100, leading to a ~99% reduction in Schnibble output
3. Inverts the effect of bonuses, causing positive bonuses to decrease output and negative bonuses to increase it

## Impact
1. Severe deflation in the game economy: Players receive only about 1% of the intended Schnibbles
2. Stunted player progression due to drastically reduced rewards
3. Broken bonus system: Positive bonuses reduce output, negative bonuses increase it
4. Core gameplay mechanics are undermined, potentially leading to player frustration and churn

## Example Scenario
Initial Schnibble amount: 1000, Bonus: 10% (finalBonus = 10)

Current (incorrect) calculation:
(1000 + (1000 * 10)) / 100 = 11000 / 100 = 110

Correct calculation:
(1000 * (100 + 10)) / 100 = 110000 / 100 = 1100

Result: Players receive 110 Schnibbles instead of 1100, a 90% reduction

## Suggested Fix
Replace the current calculation with:
```solidity
schnibblesTotal = uint256((int256(schnibblesTotal) * (100 + finalBonus)) / 100);
```
