# Vulnerability details

The `_farmPlots` function is responsible for farming rewards for landlord and renter(mainAccount). However the positive rewards can only be generated even if the a player's(munchables) snuggery realm and the munchable's realm are same (i.e- I have a Munchable from the realm Verdentis. My snuggery is in Verdentis. That Munchable is going to get +10% chonk.). And if the a player's(munchables) snuggery realm and the munchable's realm are not same ,then negative rewards should be  generate.

But the problem is here that every time if the negative rewards are generating for the landlord and renter, we are measuring the `schnibblesTotal` as `uint256` and also it  wraps the negative rewards into the positive by `uint256`.  Which will always keep negative rewards as positive.

## Impact
All negative rewards will be converted into possible ,completely making landlord & mainAccount gaining rewards in a realm and snuggery realm mismatch state.

## Proof of Concept
Let's consider a scenario:

- Let's say a munchable `realm` = `Everfrost(0)` & landlord's `snuggeryRealm` = `Drench(1)`.
- Calculating `REALM_BONUSES` using `finalBonus` formula = `0 * 5 + 1` = `index(1)` = `-10 `.
- If the munchables rarity = Primordial/Common(0) = `index(0)`.
- Calculating `RARITY_BONUSES` using same `finalBonus` formula = `index(0)` = 0.
- Now the the `finalBonus` will be =  `-10`.
- Let's say `current timestamp` is 100 sec more than `lastToilDate`.
- The `schnibblesTotal` will be = `100 * 1e15` or `1e17`.
- Final `schnibblesTotal` will be = `((1e17) + (1e17 * -10))/100` = -`9000000000000000` = `-9e15`.
- But since the `schnibblesTotal` is uin256 and it also wraps value into `uint256` , it will be = `9e15`.

## Tools Used
Manual review.

## Recommended Mitigation Steps
Consider assigning these vars as int256 rather than uint256.

```diff
+       int256 schnibblesTotal;
+       int256 schnibblesLandlord;
        
+       schnibblesTotal = int256(
+                (int256(schnibblesTotal) +
+                    (int256(schnibblesTotal) * finalBonus)) / 100
+            );
```
