# Vulnerability details

**Impact**
Within the `LandManager` contract the "tennant" of a particular plot is responsible for claiming not only their own schnibbles rewards but also those of the "landlord". As shown here in `_farmPlots`:
```solidity
-->         schnibblesLandlord = (schnibblesTotal * _toiler.latestTaxRate) / 1e18;

            toilerState[tokenId].lastToilDate = timestamp;
            toilerState[tokenId].latestTaxRate = plotMetadata[_toiler.landlord].currentTaxRate;

            renterMetadata.unfedSchnibbles += (schnibblesTotal - schnibblesLandlord);

-->         landlordMetadata.unfedSchnibbles += schnibblesLandlord;
            landlordMetadata.lastPetMunchable = uint32(timestamp);
```
This means that if for whatever reason the tennant becomes inactive there is no way for the landlord to claim their part of the staking rewards themselves.

On top of this, there is also no way for the landlord to remove the inactive tennant from the plot to make space for a new tennant either. This means that the `plotId` in question is effectively dead. Therefore if the landlord wants to earn rewards from a new tennant they would have to lock additional tokens in the `LockManager` contract to have a greater number of plots within `LandManager`.

**Proof Of Concept**
Consider the following scenario:
1. Alice locks funds in `LockManager`
2. This amount of funds results `_getNumPlots` returning 1
3. A Bob stakes in Alice's plot, and to begin with plays normally, occasionally calling `farmPlots` adding schnibble rewards to both Alice and himself.
4. Bob stops interacting with the game entirely.
5. Alice now no longer is getting schnibble rewards, despite still having tokens locked in `LockManager`
6. On top of this a new active user cannot take over the "occupied" plot.

**Recommended Mitigation**
The scenario where an inactive user is effectively allowed to lock a landlord's plot permanently can be remedied in a number of ways:
1. Allow the landlord the ability to call `farmPlot` on any plot belonging to them.
2. Keep a `lastUpdated` variable for each tennant and if the tennant has been inactive for a some specified amount of time then give the landlord the right to evict them from the plot.
