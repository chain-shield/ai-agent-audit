# Vulnerability details

## Impact
unstakeMunchable function removes the old plot from the plotOccupied.

## Proof of Concept
1. User calls `stakeMunchable` function which creates a plot :
```
plotOccupied[landlord][plotId] = Plot({
            occupied: true,
            tokenId: tokenId
        });
```

2. User calls `transferToUnoccupiedPlot` which only updates the `latestTaxRate` of tghe toilerstate not the `plotId` results in not updating the new plot 

3. Upon Calling unstakeMunchable , it removes the old plot not new Plot
