# Vulnerability details

## Impact
when the function `transferToUnoccupiedPlot` is called, the current `plotOccupied` of the old `plotId` is moved to unoccupied while the  `plotOccupied` of the new `plotId` becomes occupied which makes sense however the attribute `plotId` of `toilerState` isn't updated and keeps pointing to the old `plotId`, this raises many issues as both `_farmPlots` and `unstakeMunchable` use `toilerState[tokenId].plotId`, the impact is the following:
- Incorrect reward calculations:  the '_farmPlots' function will use the wrong tax rate when calculating rewards, leading to unfair reward distributions.
- Issues with unstaking: Since the contract relies on toilerState for unstaking logic, this means users attempting to unstake their nfts might leave plots incorrectly marked as `occupied` since only the old plot will be updated to unoccupied which is already the case, people will be unable to stake to unoccupied plots and also people will be able to stake multiple nfts in the same plot.
## Proof of Concept

1. Initial State:

Alice is a landlord with plots 120 and 10.
Bob owns a Munchable (TokenID 1) staked on Alice's plot 120.
The tax rate for plot 120 is set to 10% (1e17).


2. Bob transfers his Munchable:

Bob calls transferToUnoccupiedPlot to move his Munchable from plot 120 to plot 10.
The plotOccupied mapping is updated correctly:

plotOccupied[alice][120] is set to unoccupied.
plotOccupied[alice][10] is set to occupied with TokenID 1.


However, toilerState[1].plotId may still be 120 (the old plot).


3. Alice updates tax rates:

Alice sets the tax rate for plot 120 (the old plot) to 1% (1e16).
Alice sets the tax rate for plot 10 (the new plot) to 50% (5e17).


4. Time passes, and rewards accumulate.
5. Bob farms his plots:

Bob calls farmPlots().
The _farmPlots function uses toilerState[1].plotId to determine which plot's tax rate to use.
If toilerState[1].plotId is still 120, it will use the 1% tax rate instead of the correct 50% tax rate.

6. Result:

Bob receives more rewards than he should because the farming calculation uses the lower tax rate from the old plot.
Alice receives less tax than she should from Bob's farming.
