# Vulnerability details

## Impact
The `updateTaxRate` function fails to update the `lastUpdated` timestamp when changing the tax rate. This oversight leads to inaccurate timestamp calculations in the `_farmPlots` function. Consequently, values such as `schnibblesTotal`, `schnibblesLandlord`, `renterMetadata.unfedSchnibbles`, `landlordMetadata.unfedSchnibbles`, `toilerState[tokenId].lastToilDate`, and `landlordMetadata.lastPetMunchable` are computed incorrectly.

## Proof of Concept
The `updateTaxRate` function does not update `lastUpdated` when changing the tax rate, as shown below:
[src/managers/LandManager.sol:updateTaxRate_L92-L101](https://github.com/code-423n4/2024-07-munchables/blob/94cf468aaabf526b7a8319f7eba34014ccebe7b9/src/managers/LandManager.sol#L92C1-L101C6)
```solidity
    function updateTaxRate(uint256 newTaxRate) external override notPaused {
        (address landlord, ) = _getMainAccountRequireRegistered(msg.sender);
        if (newTaxRate < MIN_TAX_RATE || newTaxRate > MAX_TAX_RATE)
            revert InvalidTaxRateError();
        if (plotMetadata[landlord].lastUpdated == 0)
            revert PlotMetadataNotUpdatedError();
        uint256 oldTaxRate = plotMetadata[landlord].currentTaxRate;
@audit=> plotMetadata[landlord].currentTaxRate = newTaxRate;
        emit TaxRateChanged(landlord, oldTaxRate, newTaxRate);
    }
```

Incorrect timestamp calculations are causing a cascade of errors in the system, affecting key variables like `schnibblesTotal`, `schnibblesLandlord`, and `unfedSchnibbles`. This ultimately hinders the `_farmPlots` function's proper operation.

Incorrect `timestamp` calculations directly affect the values of `toilerState[tokenId].lastToilDate`, `landlordMetadata.lastPetMunchable`, and `schnibblesTotal = (timestamp - _toiler.lastToilDate) * BASE_SCHNIBBLE_RATE`. These incorrect `schnibblesTotal` calculations further lead to inaccuracies in `schnibblesLandlord = (schnibblesTotal * _toiler.latestTaxRate) / 1e18`, `renterMetadata.unfedSchnibbles += (schnibblesTotal - schnibblesLandlord)`, and `landlordMetadata.unfedSchnibbles += schnibblesLandlord`. 
[src/managers/LandManager.sol:_farmPlots_L232-L310](https://github.com/code-423n4/2024-07-munchables/blob/94cf468aaabf526b7a8319f7eba34014ccebe7b9/src/managers/LandManager.sol#L232C1-L310C6)

## Recommended Mitigation Steps
It is recommended to update the `lastUpdated` timestamp within the `updateTaxRate` function when the tax rate is updated, as follows:
```solidity
+     plotMetadata[landlord].lastUpdated = block.timestamp;
```
