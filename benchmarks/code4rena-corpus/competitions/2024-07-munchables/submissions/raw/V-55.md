# Vulnerability details

## Impact
Landlords can receive more rewards from petting in an edge case.

## Proof of Concept

First Alice will lock some tokens and own 1 plot. Then Bob will stake his munchable on that plot. Then Alice can unlock some of her tokens making the plot she owned no longer valid. That would be at `block.timestamp = 5`. After some time at `block.timestamp = 11` Bob would call `SnuggeryManager::pet` and pet Alice's munchable and immediately after call `LandManager::farmPlots`. In the function call  the timestamp for the last time Alice's munchable was petted will be set to 5. That is because of the handling of the edge case:

`plotMetadata[landlord].lastUpdated` will have the value of the last time the landlord has called `LandManger::updatePlotMetadata` which in our case would be when Alice unlocked her tokens at `block.timestamp = 5`. So now while the current `block.timestamp = 11` the last registerd feeding of Alices munchable will be at `block.timestamp = 5` despite Bob petting it in the same transaction at `block.timestamp = 11` allowing someone else to instantly pet Alice's munchable earning them both more rewards than they were supposed to get.
