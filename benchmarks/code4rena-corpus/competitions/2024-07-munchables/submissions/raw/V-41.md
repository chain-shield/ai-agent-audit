# Vulnerability details

## Impact
Pausable unstake/withdraws can be dangerous as they restrict users in the case of an emergency, like a hack - when withdraws are most needed.

## Proof of Concept
[unstakeMunchable](https://github.com/code-423n4/2024-07-munchables/blob/main/src/managers/LandManager.sol#L175) is pausable:

```solidity
    function unstakeMunchable(uint256 tokenId) external override forceFarmPlots(msg.sender) notPaused {
```

However having pausability on critical user functions like unstake is dangerous as it can lead to pretty bad scenarios in the cases of a hack. Needing to unpause the whole system in order for users to withdraw will enable the hacker to exploit it even more.

## Tools Used
Manual review

## Recommended Mitigation Steps
Removed the `notPaused` modifier.

```diff
-    function unstakeMunchable(uint256 tokenId) external override forceFarmPlots(msg.sender) notPaused {
+    function unstakeMunchable(uint256 tokenId) external override forceFarmPlots(msg.sender) {
```

Another solution is to make 2 pause mods, normal - pausing everything but unstake, and emergency - pausing the whole system.
