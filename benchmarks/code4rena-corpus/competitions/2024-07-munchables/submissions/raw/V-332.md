# Vulnerability details

The [`LandManager._farmPlots()`](https://github.com/code-423n4/2024-07-munchables/blob/94cf468aaabf526b7a8319f7eba34014ccebe7b9/src/managers/LandManager.sol#L232-L310) function calculates the [`schnibblesTotal`](https://github.com/code-423n4/2024-07-munchables/blob/94cf468aaabf526b7a8319f7eba34014ccebe7b9/src/managers/LandManager.sol#L280-L289) amount, which is then split between the landlord and toiler.

The [`schnibblesTotal`](https://github.com/code-423n4/2024-07-munchables/blob/94cf468aaabf526b7a8319f7eba34014ccebe7b9/src/managers/LandManager.sol#L280-L289) rewarded is calculated from the time difference elapsed [`(timestamp - _toiler.lastToilDate)`](https://github.com/code-423n4/2024-07-munchables/blob/94cf468aaabf526b7a8319f7eba34014ccebe7b9/src/managers/LandManager.sol#L281), multiplied by the [`BASE_SCHNIBBLE_RATE`](https://github.com/code-423n4/2024-07-munchables/blob/94cf468aaabf526b7a8319f7eba34014ccebe7b9/src/managers/LandManager.sol#L282C17-L282C36). Afterward, the result is added to the final bonus, which is calculated from the [`rarity`](https://github.com/code-423n4/2024-07-munchables/blob/94cf468aaabf526b7a8319f7eba34014ccebe7b9/src/managers/LandManager.sol#L277-L279) and [`snuggeryRealm`](https://github.com/code-423n4/2024-07-munchables/blob/94cf468aaabf526b7a8319f7eba34014ccebe7b9/src/managers/LandManager.sol#L271-L276). The calculated `finalBonus` is a percentage value that should be applied to the `schniblesTotal`. However, the percentage is currently applied incorrectly.

The formula should be `schnibblesTotal = (schnibblesTotal + (schnibblesTotal * finalBonus) / 100)`

Currently, it is: `schnibblesTotal = (schnibblesTotal + (schnibblesTotal * finalBonus)) / 100`

## Impact

The `finalBonus` that should increase the `schnibblesTotal` actually decreases it, resulting in fewer schnibles being rewarded to the landlord and toilers.

## Proof of Concept

In the following contract, there are two functions: `wrong()`, which is the original implementation, and `right()`, which has the fixed formula.

You need to call both functions with the same parameters (e.g., `uint realm = 3`, `uint snuggeryRealm = 3`, `uint rarity = 5`) to see the difference.

```solidity
//SPDX-License-Identifier: MIT
pragma solidity ^0.8.0;

contract Test {
    int16[] public REALM_BONUSES = [
        int16(10), int16(-10), int16(-5), int16(0), int16(5),
        int16(-10), int16(10), int16(-5), int16(5), int16(0),
        int16(-5), int16(0), int16(10), int16(5), int16(-10),
        int16(0), int16(-5), int16(10), int16(10), int16(-10),
        int16(5), int16(10), int16(0), int16(-10), int16(10)
    ];
    int256[] public RARITY_BONUSES = [int256(0), int256(0), int256(10), int256(20), int256(30), int256(50)];

    function wrong(uint realm, uint snuggeryRealm, uint rarity) public view returns(uint withoutBonus, uint withBonus) {
        assert(realm > 0 && realm < 5);
        assert(snuggeryRealm > 0 && snuggeryRealm < 5);
        assert(rarity > 0 && rarity < 6);

        int finalBonus =
                int16(
                    REALM_BONUSES[
                        (uint256(realm) * 5) +
                            uint256(snuggeryRealm)
                    ]
                ) +
                int16(
                    int8(RARITY_BONUSES[uint256(rarity)])
                );
            uint schnibblesTotal =
                (3600) *
                1e15;
            withoutBonus = schnibblesTotal;

            schnibblesTotal = uint256(
                (int256(schnibblesTotal) +
                    (int256(schnibblesTotal) * finalBonus)) / 100
            );
            withBonus = schnibblesTotal;
    }

    function right(uint realm, uint snuggeryRealm, uint rarity) public view returns(uint withoutBonus, uint withBonus) {
        assert(realm > 0 && realm < 5);
        assert(snuggeryRealm > 0 && snuggeryRealm < 5);
        assert(rarity > 0 && rarity < 6);

        int finalBonus =
                int16(
                    REALM_BONUSES[
                        (uint256(realm) * 5) +
                            uint256(snuggeryRealm)
                    ]
                ) +
                int16(
                    int8(RARITY_BONUSES[uint256(rarity)])
                );
            uint schnibblesTotal =
                (3600) *
                1e15;
            withoutBonus = schnibblesTotal;

            schnibblesTotal = uint256(
                (int256(schnibblesTotal) +
                    (int256(schnibblesTotal) * finalBonus) / 100)
            );
            withBonus = schnibblesTotal;
    }
}
```

Result:

```jsx
wrong function:
withoutBonus 3600000000000000000
withBonus    2196000000000000000

right function:
withoutBonus 3600000000000000000
withBonus    5760000000000000000
```

You can see that in the incorrect function, the `withoutBonus` value is higher than the `withBonus` value.

## Recommended Mitigation Steps:

The proper calculation should be formatted as follows:

```diff
schnibblesTotal = uint256(
    (int256(schnibblesTotal) +
-       (int256(schnibblesTotal) * finalBonus)) / 100
+       (int256(schnibblesTotal) * finalBonus) / 100)
);
```
