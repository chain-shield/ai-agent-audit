# Vulnerability details

## Impact
The calculation of 'finalBonus' by summing values from the REALM_BONUSES and RARITY_BONUSES arrays risks an overflow if the total exceeds the int16 limit.

The operations in 'schibblesTotal', specifically the multiplication and addition, are susceptible to overflow, particularly when 'timestamp - _toiler.lastToilDate' is substantial.

Similarly, the 'schibblesLandlord' calculation is prone to overflow, especially if 'schnibblesTotal' is a large value.

The impact of overflow vulnerabilities in the 'farmPlots' function can lead to incorrect calculations and severe financial losses.

```solidity
function _farmPlots(address _sender) internal {
    (address mainAccount, MunchablesCommonLib.Player memory renterMetadata) = _getMainAccountRequireRegistered(_sender);

    uint256[] memory staked = munchablesStaked[mainAccount];
    MunchablesCommonLib.NFTImmutableAttributes memory immutableAttributes;
    ToilerState memory _toiler;
    uint256 timestamp;
    address landlord;
    uint256 tokenId;
    int256 finalBonus;
    uint256 schnibblesTotal;
    uint256 schnibblesLandlord;
    for (uint8 i = 0; i < staked.length; i++) {
        timestamp = block.timestamp;
        tokenId = staked[i];
        _toiler = toilerState[tokenId];
        if (_toiler.dirty) continue;
        landlord = _toiler.landlord;
        
        if (_getNumPlots(landlord) < _toiler.plotId) {
            timestamp = plotMetadata[landlord].lastUpdated;
            toilerState[tokenId].dirty = true;
        }
        (, MunchablesCommonLib.Player memory landlordMetadata) = _getMainAccountRequireRegistered(landlord);

        immutableAttributes = nftAttributesManager.getImmutableAttributes(tokenId);
        finalBonus = int16(
            REALM_BONUSES[
                (uint256(immutableAttributes.realm).mul(5)).add(uint256(landlordMetadata.snuggeryRealm))
            ]
        ) + int16(int8(RARITY_BONUSES[uint256(immutableAttributes.rarity)]));
        schnibblesTotal = (timestamp.sub(_toiler.lastToilDate)).mul(BASE_SCHNIBBLE_RATE);
        schnibblesTotal = uint256((int256(schnibblesTotal).add((int256(schnibblesTotal).mul(finalBonus))).div(100)));
        schnibblesLandlord = (schnibblesTotal.mul(_toiler.latestTaxRate)).div(1e18);

        toilerState[tokenId].lastToilDate = timestamp;
        toilerState[tokenId].latestTaxRate = plotMetadata[_toiler.landlord].currentTaxRate;

        renterMetadata.unfedSchnibbles = renterMetadata.unfedSchnibbles.add(schnibblesTotal.sub(schnibblesLandlord));
        landlordMetadata.unfedSchnibbles = landlordMetadata.unfedSchnibbles.add(schnibblesLandlord);
        landlordMetadata.lastPetMunchable = uint32(timestamp);
        accountManager.updatePlayer(landlord, landlordMetadata);
        emit FarmedSchnibbles(_toiler.landlord, tokenId, _toiler.plotId, schnibblesTotal.sub(schnibblesLandlord), schnibblesLandlord);
    }
    accountManager.updatePlayer(mainAccount, renterMetadata);
}
```

We ensure the 'finalBonus' calculation is securely handled using 'SafeMath' methods.

The 'schnibblesTotal' calculation is divided into multiple steps to guarantee safety at each stage.

Similarly, 'SafeMath' is employed in the 'schnibblesLandlord' calculation to prevent overflow
