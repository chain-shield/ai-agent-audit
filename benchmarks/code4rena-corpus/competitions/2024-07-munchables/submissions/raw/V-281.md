# Vulnerability details

## Impact
In the `LandManager.sol` contract, within the `_farmPlots` function, the expression `(uint256(immutableAttributes.realm) * 5) + uint256(landlordMetadata.snuggeryRealm)` is used as an index to access the `REALM_BONUSES` array. Similarly, `uint256(immutableAttributes.rarity)` is used as an index to access the `RARITY_BONUSES` array. However, there are no checks to ensure that these indices are within the bounds of the arrays.

## Proof of Concept
In the `LandManager.sol` contract, within the `_farmPlots` function, the following lines use indices to access array values without bounds checking:
- `(uint256(immutableAttributes.realm) * 5) + uint256(landlordMetadata.snuggeryRealm)` is used as an index for the `REALM_BONUSES` array.
- `uint256(immutableAttributes.rarity)` is used as an index for the `RARITY_BONUSES` array.

These indices could potentially exceed the array lengths, leading to out-of-bounds errors, but there are no checks in place to prevent this.

```solidity
+  uint256 realmBonusIndex = (uint256(immutableAttributes.realm) * 5) + uint256(landlordMetadata.snuggeryRealm);
+     require(realmBonusIndex < REALM_BONUSES.length, "Index out of bounds for REALM_BONUSES");
```
