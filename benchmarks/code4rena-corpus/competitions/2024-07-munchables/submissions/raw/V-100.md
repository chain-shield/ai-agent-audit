# Vulnerability details

## Impact
Users can stake more than 10 munchables.

## Proof of Concept

The `stakeMunchable()` function is intended to set a cap of 10 munchables per user:

```solidity
        if (munchablesStaked[mainAccount].length > 10)
            revert TooManyStakedMunchiesError();
```

- Each user should be able to stake up to 10 munchables. 
- However, the current implementation of the check is incorrect, allowing users to stake up to 11 munchables. 
- For example, if a user has already staked 10 munchables, the munchablesStaked array length will be 10. 
- When the user attempts to stake one more, the function will not revert because `10 > 10` is false, whereas it should revert when `10 >= 10`.

## Tools Used

Manual review

## Recommended Mitigation Steps

Update the check as follows:

```solidity
        if (munchablesStaked[mainAccount].length >= 10)
            revert TooManyStakedMunchiesError();
```
