# Vulnerability details

## Impact
Admins have the ability to blacklist accounts and tokens, which grants them significant control over the contract. This could lead to potential misuse or malicious actions, such as unjustly blacklisting users or manipulating token transfers.
```solidity
 function setTokenURI(
        uint256 _tokenId,
        string memory _tokenURI
    ) external onlyRole(Role.NFTOracle) {
        _setTokenURI(_tokenId, _tokenURI);
    }
```

## Proof of Concept
Suppose an admin, Charlie, wants to manipulate the market by blacklisting specific tokens to restrict their movement and control their supply.
```solidity
function blToken(uint256 _tokenId) external onlyAdmin {
    _blacklistToken[_tokenId] = true;
}
```
Potential Impact:
Charlie can artificially create scarcity for certain tokens, driving up their price and allowing him to profit by selling his own holdings at inflated prices.
Legitimate users holding the blacklisted tokens are unable to transfer or sell them, causing frustration and potential financial loss.
## Tools Used
Manual review
## Recommended Mitigation Steps
Implement a multisig wallet for admin actions to require multiple approvals.
Use timelocks for critical functions to provide a buffer period for community review.
Log all admin actions on-chain for public visibility.
Introduce community voting mechanisms for significant admin changes.
