# Vulnerability details

## Impact
If an NFT is transferred from a dirty plot to a non-dirty plot. Still can't get the Schnibbles I deserve. Users lose these Schnibbles.

## Proof of Concept
background:
1. The function of [`transferToUnoccupiedPlot` ](https://github.com/code-423n4/2024-07-munchables/blob/94cf468aaabf526b7a8319f7eba34014ccebe7b9/src/managers/LandManager.sol#L199)is to move an NFT from the previous plot to another plot. Also, if the NFT is dirty, it will not be reset.
2. In the `_farmPlots` function, [whether a piece of land is dirty is determined based on the landlord's pledge. If it is dirty, Schnibbles will not be updated after this time](https://github.com/code- 423n4/2024-07-munchables/blob/94cf468aaabf526b7a8319f7eba34014ccebe7b9/src/managers/LandManager.sol#L258-L261).

Therefore, if an NFT is moved from a dirty plot to a non-dirty plot, it will not receive the rewards it deserves.
```solidity
    function transferToUnoccupiedPlot(
        uint256 tokenId,
        uint256 plotId
    ) external override forceFarmPlots(msg.sender) notPaused {
        (address mainAccount, ) = _getMainAccountRequireRegistered(msg.sender);
        ToilerState memory _toiler = toilerState[tokenId];
        uint256 oldPlotId = _toiler.plotId;
        uint256 totalPlotsAvail = _getNumPlots(_toiler.landlord);
        if (_toiler.landlord == address(0)) revert NotStakedError();
        if (munchableOwner[tokenId] != mainAccount) revert InvalidOwnerError();
        if (plotOccupied[_toiler.landlord][plotId].occupied)
            revert OccupiedPlotError(_toiler.landlord, plotId);
        if (plotId >= totalPlotsAvail) revert PlotTooHighError();

        toilerState[tokenId].latestTaxRate = plotMetadata[_toiler.landlord]
            .currentTaxRate;
        plotOccupied[_toiler.landlord][oldPlotId] = Plot({
            occupied: false,
            tokenId: 0
        });
        plotOccupied[_toiler.landlord][plotId] = Plot({
            occupied: true,
            tokenId: tokenId
        });
```
