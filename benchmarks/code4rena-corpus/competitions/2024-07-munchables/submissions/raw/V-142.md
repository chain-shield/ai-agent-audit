# Vulnerability details

## Impact
This comparison `(_getNumPlots(landlord) < _toiler.plotId)` is wrong, and it should be `(_getNumPlots(landlord) <= _toiler.plotId)`. The direct impact is that, one extra plot which should've been inactive at the moment and it should enter the code block of the `IF`, but the wrong comparison makes it be treated as an active plot and NOT entering the `IF`'s code block. 

Therefore, some important states of the game are messed up as the following:
1. These state updates are missed for the associated `landlord` and `tokenId`
```
    timestamp = plotMetadata[landlord].lastUpdated;
    toilerState[tokenId].dirty = true;
```

2. The `schnibblesTotal` calculation will be wrong for this token, not only for the current farming round, but also for all future rounds. Because it should've been marked as `true` for `dirty`, but it didn't.

In a nutshell, the design of the game is broken by the code, and the scale of the impact is large. Both the parties of `renters` and `landlords` are impacted on their yield calculation. Therefore, this bug is a `High` severity issue to the game.

## Proof of Concept
Firstly, there are other 2 places of code where it is using the correct logic. They are [Line#145-146](https://github.com/code-423n4/2024-07-munchables/blob/94cf468aaabf526b7a8319f7eba34014ccebe7b9/src/managers/LandManager.sol#L145-L146) and [Line#211](https://github.com/code-423n4/2024-07-munchables/blob/94cf468aaabf526b7a8319f7eba34014ccebe7b9/src/managers/LandManager.sol#L211). It's obvious that the Line#258 which this finding is point at, is wrong.

Secondly, step by step why it is wrong:
1. Assume the `_getNumPlots(landlord)` returns a number, for example, `4`
2. Then, the `_toiler.plotId` of `[0,1,2,3]` shall be treated as good plots. This is OK. But, starting with `plotId` of `4`, the plots should be treated as bad/inactive plots.
3. However, the code is doing it starting with `plotId` of `5`. The `4` got away with it, because when `_getNumPlots(landlord) == _toiler.plotId == 4`, it doesn't enter the `IF`'s code block.

Manual review.

## Recommended Mitigation Steps
Change that piece of code to `if (_getNumPlots(landlord) <= _toiler.plotId)`.
