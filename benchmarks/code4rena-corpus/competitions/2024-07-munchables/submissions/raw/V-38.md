# Vulnerability details

## Impact
`schnibblesTotal` will be significantly lowered, reducing rewards for users.

## Proof of Concept
The current math used for farming schnibbles (inside [_farmPlots](https://github.com/code-423n4/2024-07-munchables/blob/main/src/managers/LandManager.sol#L283-L286))  has a `finalBonus` that will be applied to `schnibblesTotal`, however the calculation incorrectly encloses the total amount before the division:

$$
\frac{schnibblesTotal + schnibblesTotal \cdot finalBonus}{100}
$$

Where the real bonus calculation should be:

$$
schnibblesTotal + \left( \frac{schnibblesTotal \cdot finalBonus}{100} \right)
$$


This in tern will transform the bonus calculation into a penalty one. Bellow is the [code snippet](https://github.com/code-423n4/2024-07-munchables/blob/main/src/managers/LandManager.sol#L283-L286) where that takes place.

```solidity
// (schnibblesTotal + schnibblesTotal * finalBonus) / 100 
schnibblesTotal = uint256((int256(schnibblesTotal) + (int256(schnibblesTotal) * finalBonus)) / 100);
```

## Tools Used
Manual review

## Recommended Mitigation Steps
Change the formula:

```diff
    // (schnibblesTotal + schnibblesTotal * finalBonus) / 100 
-   schnibblesTotal = uint256((int256(schnibblesTotal) + (int256(schnibblesTotal) * finalBonus)) / 100);

    // schnibblesTotal + (schnibblesTotal * finalBonus / 100)
+   schnibblesTotal = uint256(int256(schnibblesTotal) + (int256(schnibblesTotal) * finalBonus / 100));
```
