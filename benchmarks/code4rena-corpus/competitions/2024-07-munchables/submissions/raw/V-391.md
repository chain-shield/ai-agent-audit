# Vulnerability details

## Impact
Unoccupied plots will wrongfully be set as occupied preventing users from staking their munchables on unoccupied plots and preventing them form transferring their munchables to unoccupied plots through `stakeMunchable(...)` and `transferToUnoccupiedPlot(...)` respectively.

## Proof of Concept
toilerState[tokenId].plotId will always be the initial plotId even after calling `transferToUnoccupiedPlot(...)`. The `oldPlotId` value will be wrong (outdated) when calling `transferToUnoccupiedPlot(...)` for the second time with the same `tokenId`.
#### Imagine this scenario for `transferToUnoccupiedPlot(...)`:
- toilerState[tokenId].plotId = 1
- Innocent user calls `transferToUnoccupiedPlot(1, 2)` =>
toilerState[tokenId].plotId = 1
oldPlotId = 1
plotOccupied[_toiler.landlord][2].occupied = true
plotOccupied[_toiler.landlord][1].occupied = false
- Innocent user calls `transferToUnoccupiedPlot(1, 3)` => 
toilerState[tokenId].plotId = 1
oldPlotId = 1
plotOccupied[_toiler.landlord][1].occupied = false
plotOccupied[_toiler.landlord][2].occupied = true
plotOccupied[_toiler.landlord][3].occupied = true
=> plotOccupied[_toiler.landlord][2].occupied will always be true now even though it is unoccupied, it will not be possible to transfer munchables to this plot even though it's unoccupied
#### Imagine this scenario for `stakeMunchable(...)`:
- toilerState[tokenId].plotId = 1
- Innocent user calls `transferToUnoccupiedPlot(1, 2)` =>
toilerState[tokenId].plotId = 1
oldPlotId = 1
plotOccupied[_toiler.landlord][2].occupied = true
plotOccupied[_toiler.landlord][1].occupied = false
- Innocent user calls `transferToUnoccupiedPlot(1, 3)` => 
toilerState[tokenId].plotId = 1
oldPlotId = 1
plotOccupied[_toiler.landlord][1].occupied = false
plotOccupied[_toiler.landlord][2].occupied = true
plotOccupied[_toiler.landlord][3].occupied = true
- Innocent user calls `stakeMunchable(addr, 1, 2)` and reverts since `plotOccupied[_toiler.landlord][2].occupied = true` but it should be `plotOccupied[_toiler.landlord][2].occupied = false` and the user should be able to stake.

## Recommended Mitigation Steps
```diff
 function transferToUnoccupiedPlot(
        uint256 tokenId,
        uint256 plotId
    ) external override forceFarmPlots(msg.sender) notPaused {
        (address mainAccount, ) = _getMainAccountRequireRegistered(msg.sender);
        ToilerState memory _toiler = toilerState[tokenId];
        uint256 oldPlotId = _toiler.plotId;
        uint256 totalPlotsAvail = _getNumPlots(_toiler.landlord);
        if (_toiler.landlord == address(0)) revert NotStakedError();
        if (munchableOwner[tokenId] != mainAccount) revert InvalidOwnerError();
        if (plotOccupied[_toiler.landlord][plotId].occupied)
            revert OccupiedPlotError(_toiler.landlord, plotId);
        if (plotId >= totalPlotsAvail) revert PlotTooHighError();
+       toilerState[tokenId].plotId = plotId;
        toilerState[tokenId].latestTaxRate = plotMetadata[_toiler.landlord]
            .currentTaxRate;
        plotOccupied[_toiler.landlord][oldPlotId] = Plot({
            occupied: false,
            tokenId: 0
        });
        plotOccupied[_toiler.landlord][plotId] = Plot({
            occupied: true,
            tokenId: tokenId
        });

        emit FarmPlotLeave(_toiler.landlord, tokenId, oldPlotId);
        emit FarmPlotTaken(toilerState[tokenId], tokenId);
    }
```
