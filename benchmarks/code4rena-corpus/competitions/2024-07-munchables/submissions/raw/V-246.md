# Vulnerability details

## Impact
In the ``stakeMunchable()`` function, 
```solidity
    function stakeMunchable(address landlord, uint256 tokenId, uint256 plotId)
        external
        override
        forceFarmPlots(msg.sender)
        notPaused
    {
        (address mainAccount,) = _getMainAccountRequireRegistered(msg.sender);
        if (landlord == mainAccount) revert CantStakeToSelfError();
        if (plotOccupied[landlord][plotId].occupied) {
            revert OccupiedPlotError(landlord, plotId);
        }
        if (munchablesStaked[mainAccount].length > 10) {
            revert TooManyStakedMunchiesError();
        }

--SNIP--

        munchablesStaked[mainAccount].push(tokenId);

--SNIP--
```
We have the following check:
```solidity
        if (munchablesStaked[mainAccount].length > 10) {
            revert TooManyStakedMunchiesError();
        }
```

This check clearly defines an invariant i.e max number of munchables staked should be 10.

But this check has a major flaw. It should be ``>=`` instead of ``>`` as this check is performed before pushing munchables in the ``munchablesStaked`` mapping. Thus, an extra munchable can be pushed into an array which breaks the invariant.


## Proof of Concept
```solidity
--SNIP--
        if (munchablesStaked[mainAccount].length > 10) {
            revert TooManyStakedMunchiesError();
        }

--SNIP--

        munchablesStaked[mainAccount].push(tokenId);

--SNIP--
```

Lets suppose, ``munchablesStaked[mainAccount].length == 10``.
We have:
```
        if (munchablesStaked[mainAccount].length > 10) {
            revert TooManyStakedMunchiesError();
        }
```
as ``10 !> 10``, this will not revert and this will execute:
```
        munchablesStaked[mainAccount].push(tokenId);
```
Which leads to pushing of 11 munchables and that shouldn't be the case. It breaks the invariant.

Manual Analysis

## Recommended Mitigation Steps
Modify ``>`` with ``>=`` in the length check:
```solidity
stakeMunchable():

        if (munchablesStaked[mainAccount].length >= 10) {
            revert TooManyStakedMunchiesError();
        }
```
