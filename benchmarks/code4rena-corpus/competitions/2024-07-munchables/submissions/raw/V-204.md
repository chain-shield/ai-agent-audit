# Vulnerability details

## Description

Each landlord has a number of plots where users can stake their munchable tokens to earn schnibbles. The amount of plots each landlord has depends on their `getLockedWeightedValue()` from the `LockManager` contract. If a landlord wants to earn schnibbles from the `LandManager`, they need to lock some tokens inside the `LockManager` contract. However, there's a way to bypass this and continue earning schnibbles even without any plots.

Suppose a landlord has 3 plotsm and a renter stakes their munchable token to `plotId = 0`.

![discord chat](https://i.imgur.com/889iwC6.png)
[(Which is a valid value according to sponsor)](https://discord.com/channels/810916927919620096/1264356051415732224/1265676664663310489)

If the landlord later unlocks all their tokens from the `LockManager` contract, causing `getLockedWeightedValue()` to return 0, the landlord now has 0 plots. The renter's token should go dirty, which is intended behavior. However, in the `_farmPlots()` function, `_getNumPlots(landlord)` is compared with `_toiler.plotId` using `<` operator instead of `<=`.

```solidity
  ❌@>     if (_getNumPlots(landlord) < _toiler.plotId) {
                timestamp = plotMetadata[landlord].lastUpdated;
                toilerState[tokenId].dirty = true;
            }
```

https://github.com/code-423n4/2024-07-munchables/blob/94cf468aaabf526b7a8319f7eba34014ccebe7b9/src/managers/LandManager.sol#L258-L260

Even if `_getNumPlots(landlord)` is 0, `_toiler.plotId[0]` will never become dirty, allowing the renter and the landlord to continue earning schnibbles for this token.

In all other places where `_getNumPlots(landlord) < _toiler.plotId` is chicked, the `<=` operator is used, which is the correct approach.

```solidity
        uint256 totalPlotsAvail = _getNumPlots(landlord);
 ❌@>   if (plotId >= totalPlotsAvail) revert PlotTooHighError();
```

https://github.com/code-423n4/2024-07-munchables/blob/94cf468aaabf526b7a8319f7eba34014ccebe7b9/src/managers/LandManager.sol#L145-L146

## Impact

A landlord will continue to earn schnibbles even after unlocking all of their tokens from the `LockManager` and having 0 plots, which isn't intended behavior.

## Recommended Mitigation Steps

Modify `_farmPlots()` as follows:

```diff
-            if (_getNumPlots(landlord) < _toiler.plotId) {
+            if (_getNumPlots(landlord) <= _toiler.plotId) {
```
