# Vulnerability details

The condition for a `plotId` to be valid is inconsistent across the codebase. 
```solidity
// In `stakeMunchable#146` and `transferToUnoccupiedPlot#211`, plotId < _getNumPlots(landlord) is considered valid
if (plotId >= totalPlotsAvail) revert PlotTooHighError();
```

```solidity258
// In `_farmPlots#258`, plotId <= _getNumPlots(landlord) is considered non-dirty (valid)
if (_getNumPlots(landlord) < _toiler.plotId) {
```

Judging by the use case, the implementation in `_farmPlots` is the wrong one.

## Impact
Implementation in `_farmPlots` accepts the value of `_getNumPlots(landlord)` as valid plot id, which results in each landlord effectively having one free plot. This extra plot can be used in the following case:
1. The user is staked on the highest `plotId` available for a particular landlord.
2. The locked value of the landlord decreases, resulting in decrease of one plot (the `plotId` that user is staked on) as per #146 and #258. 

Due to wrong check in `_farmPlots`, the plot is not declared dirty and the landlord and staker, both can still earn schnibbles from that plot. Using this, a landlord can earn from one plot even after he has unlocked all his tokens.

## Proof of Concept
```solidity
function test_PlotValidityIssue() external {
    // Landlord having 2 plots (i.e. plot indices 0 and 1 are valid)
    lockManager.mockPlayerWeightedValue(LANDLORD, PRICE_PER_PLOT * 2);
    vm.assertEq(landManager.getNumPlots(LANDLORD), 2);

    // Staker stakes on plot id 1
    vm.prank(STAKER);
    landManager.stakeMunchable(LANDLORD, 0, 1);

    // Landlord's locked amount decreases in value such that landlord now has only 1 plot (i.e. only plot index 0 is valid)
    lockManager.mockPlayerWeightedValue(LANDLORD, PRICE_PER_PLOT*2 - 1);
    vm.assertEq(landManager.getNumPlots(LANDLORD), 1);
    
    vm.prank(STAKER);
    landManager.farmPlots();

    // Toiler on plot 1 should have been marked dirty, but it isn't
    vm.assertEq(landManager.getToilerState(0).plotId, 1);
    vm.assertEq(landManager.getToilerState(0).dirty, false);
}
```
