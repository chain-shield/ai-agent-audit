# Vulnerability details

## Impact

Due to an incorrect calculation of total Schnibbles in farming plots, both toilers and landlords will harvest significantly fewer Schnibbles than anticipated. This discrepancy may adversely impact the growth of Munchables and the overall game strategy.

## Proof of Concept

In the `_farmPlots()` function, `schnibblesTotal` is calculated as follows:

```solidity
    function _farmPlots(address _sender) internal {
        ... ...
        for (uint8 i = 0; i < staked.length; i++) {
            ... ...
            schnibblesTotal =
                (timestamp - _toiler.lastToilDate) *
                BASE_SCHNIBBLE_RATE;
            schnibblesTotal = uint256(
                (int256(schnibblesTotal) +
                    (int256(schnibblesTotal) * finalBonus)) / 100 
            );
            ... ...
        }
        ... ...
    }
```

If we rewrite the above statement as formula:
$$
\text{schnibblesTotal} = \frac{(\text{schnibblesTotal} + \text{schnibblesTotal} \times \text{finalBonus})}{100}
$$

If we assume that `finalBonus` is 10%, `schnibblesTotal` is reduced to only 11% of its value. Therefore, the tailor and his landlord will receive much less Schnibbles.

I am sure the intended formula of the above statement is like the below:

$$
\text{schnibblesTotal} = \text{schnibblesTotal} + \frac{\text{schnibblesTotal} \times \text{finalBonus}}{100}
$$

## Recommended Mitigation Steps

I would suggest changing the issued statement as follow:

```solidity
    function _farmPlots(address _sender) internal {
        ... ...
        for (uint8 i = 0; i < staked.length; i++) {
            ... ...
-           schnibblesTotal = uint256(
-               (int256(schnibblesTotal) +
-                   (int256(schnibblesTotal) * finalBonus)) / 100 
-           );

+           schnibblesTotal = uint256(
+               int256(schnibblesTotal) +
+                   (int256(schnibblesTotal) * finalBonus) / 100 
+           );
            ... ...
        }
        ... ...
    }
```
