# Vulnerability details

## Impact

The lastPetMunchable state being updated every time the farm function is called violates the intended game design. This affects the operation of the original pet function, increase or decrease the landlord's chances of being actively pet munchable and get reward.

## Proof of Concept

Within the `_farmPlots` function, [`lastPetMunchable` is updated erroneously](https://github.com/code-423n4/2024-07-munchables/blob/main/src/managers/LandManager.sol#L299):

```solidity
            landlordMetadata.lastPetMunchable = uint32(timestamp);
```

This attribute（`lastPetMunchable`） has nothing to do with the farm function.

The pet function has a frequency limit within a certain period of time, [the code snippet](https://github.com/code-423n4/2024-07-munchables/blob/main/src/managers/SnuggeryManager.sol#L232-L233):

```solidity
        if (_petterPlayer.lastPetMunchable + 10 minutes > block.timestamp)
            revert PetTooSoonError();
```

This will affect landlords' access to use the pet function and their chances of earning rewards may be increase or decrease.

Manual
