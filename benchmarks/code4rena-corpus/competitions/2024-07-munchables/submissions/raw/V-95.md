# Vulnerability details

## Impact
The discovered issue lies within the `unstakeMunchable` function in the smart contract. Specifically, the function `_removeTokenIdFromStakedList` can be manipulated by an attacker to cause a Denial of Service `(DoS)` attack. If an attacker is able to manipulate the `munchablesStaked` array for a particular account such that it becomes empty, this will cause the function to revert, preventing legitimate users from unstaking their tokens.
