# Vulnerability details

## Impact
The LandManager contract retains approval to transfer NFTs even after they have been unstaked. This persistent approval presents several risks:

1. Unexpected Control: Users may assume that unstaking an NFT removes all permissions, but the LandManager can still transfer their NFT.
2. Increased Attack Surface: If the LandManager contract is compromised in the future, it could affect NFTs that users believe are fully under their control.
3. Reduced NFT Liquidity: Potential buyers on secondary markets may be hesitant to purchase NFTs with existing approvals, potentially impacting the asset's value.
4. User Trust: This behavior contradicts user expectations, potentially eroding trust in the platform.

While users can manually revoke approvals, this requires extra steps and knowledge that many users may not have, making it a suboptimal solution from a user experience perspective.

## Proof of Concept
The issue occurs in the `unstakeMunchable` function of the LandManager contract:


```solidity
function unstakeMunchable(uint256 tokenId) external override forceFarmPlots(msg.sender) notPaused {
    // ... existing code ...
    munchNFT.transferFrom(address(this), mainAccount, tokenId);
    // Approval is not revoked here
    emit FarmPlotLeave(_toiler.landlord, tokenId, _toiler.plotId);
}
```

To demonstrate:

1. User stakes their NFT, approving the LandManager.
2. User unstakes their NFT using `unstakeMunchable`.
3. The NFT is returned to the user, but the LandManager's approval remains.
4. The LandManager can still transfer the NFT without further approval.

## Recommended Mitigation Steps
Add an approval revocation step in the `unstakeMunchable` function:

```solidity
function unstakeMunchable(uint256 tokenId) external override forceFarmPlots(msg.sender) notPaused {
    // ... existing code ...
    munchNFT.transferFrom(address(this), mainAccount, tokenId);
    munchNFT.approve(address(0), tokenId);  // Revoke approval
    emit FarmPlotLeave(_toiler.landlord, tokenId, _toiler.plotId);
}
```

This ensures that the LandManager's approval is removed when the NFT is unstaked, aligning with user expectations and reducing potential security risks.
