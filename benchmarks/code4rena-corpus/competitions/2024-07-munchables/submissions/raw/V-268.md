# Vulnerability details

## Impact
If no. of plots are less than plotId then plot is marked as dirty, but the problem is it doesn't check for all plotId ie it miss the last plotId.
```solidity
if (_getNumPlots(landlord) < _toiler.plotId) {
                timestamp = plotMetadata[landlord].lastUpdated;
                toilerState[tokenId].dirty = true;
            }

```
Let landlord has 3 plots[0,1,2] and user staked for 2 plotId, but landlord reduced his position and as result he has only 2 plots[0,1] then 2 should be marked as dirty but will not because 2(no. of plots) is not less than 2(dirty plotId)
