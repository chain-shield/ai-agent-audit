# Vulnerability details

## Impact
ERC721 transfer doesn't return Boolean https://eips.ethereum.org/EIPS/eip-721 if the return value will not be checked. unstakeMunchable() & stakeMunchable() will update the state even on failers.

## Proof of Concept
The stakeMunchable and unstakeMunchable functions perform actions involving the transfer of ERC721 tokens. According to the ERC721 standard, the transferFrom function does not return a boolean value. If the transfer fails, the function will revert, but if the failure is not properly handled, the state may be updated incorrectly.

## Tools Used
manual review

## Recommended Mitigation Steps

Utilize the safeTransferFrom function instead of transferFrom to ensure the transfer is completed successfully and handle any potential failure gracefully.
