# Vulnerability details

## Overview
The addition of ```finalBonus``` in LOC-285 in the ```_farmPlots(address _sender)``` function is wrong.

## Proof of Concept
The ```_farmPlots(address _sender)``` function has the following calculation:

https://github.com/code-423n4/2024-07-munchables/blob/main/src/managers/LandManager.sol#L285

```solidity
            schnibblesTotal =
                (timestamp - _toiler.lastToilDate) *
                BASE_SCHNIBBLE_RATE;
            schnibblesTotal = uint256(
                (int256(schnibblesTotal) +
                    (int256(schnibblesTotal) * finalBonus)) / 100
            );
```

However, if we unfold the above equation, we find:

```
schnibblesTotal = (timestamp - _toiler.lastToilDate) * BASE_SCHNIBBLE_RATE;

schnibblesTotal = uint256[{int256(schnibblesTotal) + (int256(schnibblesTotal) * finalBonus)} / 100];
```

This is wrong. The purpose of the ```finalBonus``` is to increase (or decrease) the ```schnibblesTotal``` based on if it is +ve or -ve. This should be done as:

```
schnibblesTotal = uint256[{int256(schnibblesTotal) + ((int256(schnibblesTotal) * finalBonus) / 100)}];
```

For example, with:

```
schnibblesTotal = 30 * 24 * 3600 * 0.001; (basically, 30 days (in sec) multiplied with BSR)
finalBonus = 10;
```

By the present calculation:

```
schnibblesTotal would be 285;
```

By the correct calculation:

```
schnibblesTotal would be 2851;
```

Hence, by the present calculation, stakers and landlords would lose a lot of harvest schnibbles rewards.

## Severity
Impact: The stakers and landlords lose reward value due to a wrong calculation. So, the impact is High.

Likelihood: This would happen every time a user would farm their plot. So, the likelihood is High.

Therefore, the severity is High.

## Recommended Mitigation Steps
Change the calculation as follows:

```diff
            schnibblesTotal =
                (timestamp - _toiler.lastToilDate) *
                BASE_SCHNIBBLE_RATE;
-           schnibblesTotal = uint256(
-               (int256(schnibblesTotal) +
-                   (int256(schnibblesTotal) * finalBonus)) / 100
-           );
+          schnibblesTotal = uint256(
+              (int256(schnibblesTotal) +
+                  ((int256(schnibblesTotal) * finalBonus) / 100))
+          );

```
