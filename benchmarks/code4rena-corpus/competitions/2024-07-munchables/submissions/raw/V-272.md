# Vulnerability details

## Description

RARITY_BONUSES is defined as uint8[] as follows:

```solidity
uint8[] RARITY_BONUSES;
```
uint8 has 8 bits and it handle at most 2^8 - 1. uint8 to int8 conversion is unsafe due to missing bit. int8 store sign bit and it can handle at most 2^7 - 1.
So, basicly every value between 128 to 255 will be panicked. Also, after this conversion it directly convert int8 to int16 which isn't necessary. Directly converting uint8 to int16 is a safe operation.

## Impact
Functionality problem
Can't set higher value than 127 to RARITY_BONUSES if it's setted by storage players who have massive rarity bonus can't farm the plots.

## Proof of Concept
In order to illustrate this behaviour, following function can be runned to see the result:

```solidity
function test_UnsafeCasting() public {
  uint8 a = 128;
  int8 b = int8(a);
}
```

## Tools Used
Manual Review
## Recommended Mitigation Steps
Removing int8() casting will solve the problem
