# Vulnerability details

## Description
`transferToUnoccupiedPlot` is lacking updating `dirty field` during his operation which will prevent the player from earning during farming as even if the plot transfered to exist, the farming logic will believe such plot is gone (as dirty still set to true), which seems to warrant `Medium` severity.

## Impact
Player is not earning from farming as it should when transfering from a dirty plot, as the new plot is still being considered `dirty`, so [ignored](https://github.com/code-423n4/2024-07-munchables/blob/main/src/managers/LandManager.sol#L251) in the farming calculation.

## PoC
Alice and Bob are the players. Alice is a landlord with 121 plots [0,120] as locked 1 ETH in LockManager.
1) Bob's stake NFT 1 on Alice's plotId 120. 
2) After a week, Alice unlock 0.1 ETH, reducing his number of plot to 112 [0,111].
3) Bob note that he is not earning any rewards anymore for his NFT, so he decides to `transferToUnoccupiedPlot` his NFT 1 to plotId 100, which works fine (and call `forceFarmPlots` which will mark plotId 120 dirty if not yet done).
4) Unfortunatelly, Bob will not be earning point during farming afterwards either, as the transfer didn't overwrite the `dirty` field, so the farming accounting will still think the plot is invalid.

## Recommended Mitigation Steps
Apply the following patch to resolve this issue.

```diff
    function transferToUnoccupiedPlot(
        uint256 tokenId,
        uint256 plotId
    ) external override forceFarmPlots(msg.sender) notPaused {
        (address mainAccount, ) = _getMainAccountRequireRegistered(msg.sender);
        ToilerState memory _toiler = toilerState[tokenId];
        uint256 oldPlotId = _toiler.plotId;
        uint256 totalPlotsAvail = _getNumPlots(_toiler.landlord);
        if (_toiler.landlord == address(0)) revert NotStakedError();
        if (munchableOwner[tokenId] != mainAccount) revert InvalidOwnerError();
        if (plotOccupied[_toiler.landlord][plotId].occupied)
            revert OccupiedPlotError(_toiler.landlord, plotId);
        if (plotId >= totalPlotsAvail) revert PlotTooHighError();

        toilerState[tokenId].latestTaxRate = plotMetadata[_toiler.landlord].currentTaxRate;
+	toilerState[tokenId].dirty = false;
        plotOccupied[_toiler.landlord][oldPlotId] = Plot({
            occupied: false,
            tokenId: 0
        });
        plotOccupied[_toiler.landlord][plotId] = Plot({
            occupied: true,
            tokenId: tokenId
        });

        emit FarmPlotLeave(_toiler.landlord, tokenId, oldPlotId);
        emit FarmPlotTaken(toilerState[tokenId], tokenId);
    }
```
