# Vulnerability details

## Impact
Landlords can loose out on rewards because users have staked their tokens before the landlord has called `triggerPlotMetadata` to initialize their plot.

## Proof of Concept
There are no checks inside `stakeMunchable` to verify weather the plot the user wants to occupy has `currentTaxRate` set meaning that any user that calls `stakeMunchable` before that has happened will not pay the fee and the landlord will not receive any rewards.

## Tools Used

Manual review

## Recommended Mitigation Steps

Check `plotMetadata[landlord].lastUpdated != 0`
