# Vulnerability details

## Impact
Upon each toiling operation (staking, unstaking, or transferring a token to another plot), the [_farmPlots](https://github.com/code-423n4/2024-07-munchables/blob/94cf468aaabf526b7a8319f7eba34014ccebe7b9/src/managers/LandManager.sol#L232-L310) function is called by the `forceFarmPlots` modifier to farm schnibbles rewards for the caller. The issue is that this modifier is applied when transferring a token to a new valid plot, which it should not be, **because the transfer should only occur if the current plot ID a munchable is on becomes invalid**; Therefore, schnibbles rewards for the period between the last update and the transfer moment should be disregarded and new farming should begin, as confirmed by the sponsor:
> the intended behavior is that if you transfer plots, it disregards the time between your last updated and when you transfer and begins farming normally after that
```solidity
function transferToUnoccupiedPlot( uint256 tokenId,uint256 plotId) external override 
    forceFarmPlots(msg.sender) // @audit Should not be called
    notPaused 
{ // ... }
```

Another related issue is that after the transfer, the function does not update the `toilerState.lastToilDate` state:
```solidity
function transferToUnoccupiedPlot(uint256 tokenId, uint256 plotId ) external override forceFarmPlots(msg.sender) notPaused {
    
    // ...

    toilerState[tokenId].latestTaxRate = plotMetadata[_toiler.landlord] .currentTaxRate;

    // @audit `toilerState[tokenId].lastToilDate` not updated!

    plotOccupied[_toiler.landlord][oldPlotId] = Plot({
        occupied: false,
        tokenId: 0
    });
    plotOccupied[_toiler.landlord][plotId] = Plot({
        occupied: true,
        tokenId: tokenId
    });

    emit FarmPlotLeave(_toiler.landlord, tokenId, oldPlotId);
    emit FarmPlotTaken(toilerState[tokenId], tokenId);
}
```

## Recommended Mitigation Steps
Consider removing the `forceFarmPlots(msg.sender)` modifier from the `transferToUnoccupiedPlot` function, and updating the `lastToilDate` for the toiler state. Below is a suggestion for an updated version of `transferToUnoccupiedPlot`:
```diff
function transferToUnoccupiedPlot( uint256 tokenId,uint256 plotId) external override 
-    forceFarmPlots(msg.sender) 
    notPaused 
{ 
    
// ...

    toilerState[tokenId].latestTaxRate = plotMetadata[_toiler.landlord] .currentTaxRate;
+    toilerState[tokenId].lastToilDate = block.timestamp;

    plotOccupied[_toiler.landlord][oldPlotId] = Plot({
        occupied: false,
        tokenId: 0
    });
    plotOccupied[_toiler.landlord][plotId] = Plot({
        occupied: true,
        tokenId: tokenId
    });

    emit FarmPlotLeave(_toiler.landlord, tokenId, oldPlotId);
    emit FarmPlotTaken(toilerState[tokenId], tokenId);
}
```
