# Vulnerability details

## Impact
Based on the docs users can have 6 or more Munchables in the Snuggery (if the buy more slots). The rest of them live in the Stables. There is no limit how many Munchables user can have in their Stables. Based on conversation with sponsor users are only showed to stake Munchables not in the Snuggery.

## Proof of Concept
The issue lies in this check in [stakeMunchable](https://github.com/code-423n4/2024-07-munchables/blob/94cf468aaabf526b7a8319f7eba34014ccebe7b9/src/managers/LandManager.sol#L140):

```js
        if (munchablesStaked[mainAccount].length > 10)
            revert TooManyStakedMunchiesError();
```
It will revert if user have more than 10 Munchables that it is already staking. If he wants to stake more which is possible since users can have more than 10 munchables and decide they want to stake them it will revert.

## Issue
Some users would not be able to stake Munchables.


## Tools Used
Manual Review.

## Recommended Mitigation Steps
Remove that check.
