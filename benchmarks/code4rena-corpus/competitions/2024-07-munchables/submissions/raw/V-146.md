# Vulnerability details

## Impact
Calculating `schnibblesTotal` using this formula `uint256((int256(schnibblesTotal) + (int256(schnibblesTotal) * finalBonus)) / 100)` can make the `schnibblesTotal` value to the maximum of uint256 because of the typecast.
It will revert on this line:
https://github.com/code-423n4/2024-07-munchables/blob/94cf468aaabf526b7a8319f7eba34014ccebe7b9/src/managers/LandManager.sol#L287
This is pretty much unwanted situation.

## Proof of Concept
Let me provide some context of the `REALM_BONUSES` and `RARITY_BONUSES`:
```js
export const REALM_BONUSES = [
  10, -10, -5, 0, 5, -10, 10, -5, 5, 0, -5, 0, 10, 5, -10, 0, -5, 10, 10, -10, 5, 10, 0, -10, 10,
];

export const RARITY_BONUSES = [0, 0, 10, 20, 30, 50];
```
If for example the realm of the NFT in `immutableAttributes.realm` is `Everfrost` which is at index 0 in the enum and the `landlordMetadata.snuggeryRealm` is `Drench` which is at index 1 in the enum and the `immutableAttributes.rarity` is `Primordial` which is at index 0 in the enum then the `finalBonus` will be `-10`.
This is just one of the ways that this can happen.
If the `finalBonus` is a negative value, then when we typecast from int256 to uint256 after the math inside the brackets, then we will get max value of uint256.

```js
int256 finalBonus = -10;
uint256 BASE_SCHNIBBLE_RATE = 1e15;
uint256 currentStamp = 1722112024; // today
uint256 lastStamp = 1722002024; // yesterday
uint256 schnibblesTotal = (currentStamp - lastStamp) * BASE_SCHNIBBLE_RATE;

schnibblesTotal = uint256((int256(schnibblesTotal) + (int256(schnibblesTotal) * finalBonus)) / 100);

```

## Recommended Mitigation Steps
You can make a separate variable for the math inside the brackets.
Then we check if that variable is negative value, so we can typecast correctly.
```diff
- schnibblesTotal = uint256((int256(schnibblesTotal) + (int256(schnibblesTotal) * finalBonus)) / 100);

+ int256 schnibblesMath = (int256(schnibblesTotal) + (int256(schnibblesTotal) * finalBonus)) / 100;
+ schnibblesTotal = schnibblesMath >= 0 ? uint256(schnibblesMath) : uint256(-schnibblesMath);
```
