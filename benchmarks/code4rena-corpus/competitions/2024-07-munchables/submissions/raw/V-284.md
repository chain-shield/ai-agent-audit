# Vulnerability details

## Impact
User earns less schnibbles due to incorrect calculation of bonus percentage

## Proof of Concept
In the farmPlots function, the users total schnibbles is calculated by getting the schnibbles earned over time then adding a 'finalbonus' percentage to it.
```
schnibblesTotal = uint256(
               (int256(schnibblesTotal1) +
                    (int256(schnibblesTotal1) * finalBonus)) / 100
            );

```
The final bonus is meant to be a percentage of the earned schnibbles but its calculation is executed incorrectly.
```
//bonus is calculated as:
((int256(schnibblesTotal1) +(int256(schnibblesTotal1) * finalBonus)) / 100

//rather than
(int256(schnibblesTotal1) +(int256(schnibblesTotal1) * finalBonus) / 100)
```

This results in a significantly lower amount of schnibbles earned.
## Tools Used
Manual Review

## Recommended Mitigation Steps
Reimplement the calculation in farm plot by calculating the schnibblesTotal as: 
```
schnibblesTotal = uint256(
               (int256(schnibblesTotal1) +
                    (int256(schnibblesTotal1) * finalBonus) / 100 ) 
            );
```
