# Vulnerability details

## Impact
Landlords are not able to fully utilize the `SnuggeryManager::pet` functionality and will not be able to receive rewards if others want to pet their munchables.

## Proof of Concept

The `SnuggeryManager::pet` functionality has a time lock of 5 minutes for the person whose munchable is being petted:

```solidity
if (pettedAttributes.lastPettedTime + 5 minutes > block.timestamp)
            revert PettedTooSoonError();
```

Because of that a malicious user can keep calling `LandManager::farmPlots` while having staked a munchable at another user's plot and continuously update the `lastPetMunchable` variable every 5 minutes or by simply frontrunning every attempt of other users to pet the landlords munchable. That is caused by the fact that `lastPetMunchable` is set to `block.timestamp`

Both the user and the landlord will receive proper rewards from the `farmPlots` function meaning that the incentive of the attack would be the difference between the rewards the landlord receives from the `pet` function and the gas fee on `farmPlots` which is currently favoring the attacker meaning that the attack makes the landlord loose more than the attacker looses.

## Recommended Mitigation Steps

Either set a timeout on `farmPlots` or do not update `lastPetMunchable` in `farmPltos`.
