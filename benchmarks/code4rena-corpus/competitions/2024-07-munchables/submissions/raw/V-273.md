# Vulnerability details

## Impact
For calculating schnibblesLandlord, schnibblesTotal is used which is already multiplied & divided above. Solidity rounds down the result of an integer division,  so its recommended to multiply before dividing.
```solidity
 schnibblesTotal =
                (timestamp - _toiler.lastToilDate) *
                BASE_SCHNIBBLE_RATE;
            schnibblesTotal = uint256(
                (int256(schnibblesTotal) +
                    (int256(schnibblesTotal) * finalBonus)) / 100
            );
            schnibblesLandlord =
                (schnibblesTotal * _toiler.latestTaxRate) /
                1e18;
```
