# Vulnerability details

## Impact
Landlord can loose on potential profits and get incentivized to participate.

## Proof of Concept
Imagine this scenario.
1. Bob stakes some collateral and get's a number of plots based on the amount in USD of his collateral calculated in `_getNumPlots`.

2. Alice decides to stake her munchables in Bob's plot.

3. Let's say Bob has 5 plots and Alice stakes in all of Bob's plots.
Toiler state gets updated:
```
....
        toilerState[tokenId] = ToilerState({
            lastToilDate: block.timestamp,
            plotId: plotId,
            landlord: landlord,
            latestTaxRate: plotMetadata[landlord].currentTaxRate, //! what happens if I increase taxRate suddenly?
            dirty: false
        });
....
```
So the `latestTaxRate` is the `currentTaxRate` which can be the default value if Bob never used the `updateTaxRate` function to update the tax rate.

4. Bob decides to update his tax rate so that he can get better return of investment. Calls the `updateTaxRate` and makes his tax rate bigger/close to max.
Now the plots are still occupied with Alice's munchables, but the `_farmPlots` function uses the old `_toiler.latestTaxRate` to calculate `schnibblesLandlord` and AFTER that updates `toilerState[tokenId].latestTaxRate`:
```
...
            schnibblesTotal = (timestamp - _toiler.lastToilDate) * BASE_SCHNIBBLE_RATE;
            schnibblesTotal = uint256((int256(schnibblesTotal) + (int256(schnibblesTotal) * finalBonus)) / 100);
            schnibblesLandlord = (schnibblesTotal * _toiler.latestTaxRate) / 1e18;

            toilerState[tokenId].lastToilDate = timestamp;
            toilerState[tokenId].latestTaxRate = plotMetadata[_toiler.landlord].currentTaxRate;
...
```
This means that if the staker (Alice) never usntakes or moves her munchables to another plot the `_farmPlots` function will not trigger and update the new tax rate that Bob set. Meaning Bob cannot impose his new tax rate willingly.

5. Even if Bob unstakes his collateral and stake it again, he still won't be able to impose his new tax rate.

## Tools Used
Manual review
## Recommended Mitigation Steps
Update in tax rate `updateTaxRate` should properly implement change in `latestTaxRate` of `toilerState`.
