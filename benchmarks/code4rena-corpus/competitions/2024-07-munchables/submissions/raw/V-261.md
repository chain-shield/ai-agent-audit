# Vulnerability details



## Summary
The _farmPlots() function permanently skips processing of Munchables on "dirty" plots, leading to a permanent loss of rewards for affected assets.

## Vulnerability Details
In the _farmPlots() function:

```solidity
if (_toiler.dirty) continue;
```

Once a plot is marked as "dirty", the function skips it in all future farming operations without updating its state or allowing for recovery.

## Impact
- Severity: Critical
- Munchables on "dirty" plots permanently stop generating rewards.
- Users could suffer significant economic losses if their valuable Munchables become stuck in this state.
- This could lead to frustration and loss of trust in the game mechanics, potentially driving users away.

## Tools Used
- Manual code review


## Recommendations
1. Implement a recovery mechanism for "dirty" plots:
   ```solidity
   if (_toiler.dirty) {
       if (canReassignPlot(_toiler)) {
           reassignPlot(_toiler);
       } else {
           // Implement fallback reward calculation or alert user
       }
   }
   ```
2. Create a function allowing users to manually "rescue" Munchables from dirty plots.
