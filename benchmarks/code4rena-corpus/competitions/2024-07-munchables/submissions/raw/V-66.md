# Vulnerability details

## Impact
The total stake amount could unintentionally exceed the stake cap.

## Proof of Concept

Users can stake one more token even after they have staked 10 NFTs:
```solidity
131:     function stakeMunchable(
...
140:         if (munchablesStaked[mainAccount].length > 10) // <=
141:             revert TooManyStakedMunchiesError();
```

The `stakeMunchable()` function has an intended maximum cap of 10 NFTs per user. However, the current implementation doesnot properly enforce this cap. The check at line 140 in the function verifies if the number of already staked NFTs exceeds 10 but does not account for the NFT being staked in the current transaction.

## Tools Used
manual

## Recommended Mitigation Steps

```diff
-        if (munchablesStaked[mainAccount].length > 10)
+        if (munchablesStaked[mainAccount].length >= 10)
             revert TooManyStakedMunchiesError();
```
