# Vulnerability details

## Impact
1. Inconsistent State:
The toilerState mapping will have an outdated plotId, 
leading to incorrect tracking of the staked NFT's location.

2. Reward Calculation Errors:
Functions that rely on the plotId in toilerState for calculating rewards 
or other plot-specific logic will produce incorrect results.

For example, 
the following line inside the `_farmPlots` function 
reads the wrong plotId
```
if (_getNumPlots(landlord) < _toiler.plotId) 
```

3. Data Integrity Issues:
The contract's overall data integrity is compromised, 
which might cause unexpected behaviors in other functions or integrations.
 

## Proof of Concept

The `transferToUnoccupiedPlot` function in the `LandManager` contract allows users 
to transfer a staked munchable NFT from one plot to another unoccupied plot. 

However, the current implementation does not update the plotId 
in the `toilerState` mapping.

Example Scenario


1. Initial State: The NFT with tokenId 1234 is staked in plotId 1.


```
toilerState[1234] = ToilerState({
    lastToilDate: 1627593600,  // Timestamp
    plotId: 1,                 // Initially staked in plotId 1
    landlord: 0x123...,        // Address of the landlord
    latestTaxRate: 500,        // Example tax rate
    dirty: false               // Dirty flag
});
```
2. Function Call: We transfer the NFT to a new plotId 2.
Call the transferToUnoccupiedPlot function
```
landManager.transferToUnoccupiedPlot(1234, 2);
```

3. Incorrect Behavior: The plotId in the toilerState mapping remains 1 
											 instead of being updated to 2.
```
toilerState[1234] = ToilerState({
    lastToilDate: 1825564624,  // new timestamp
    plotId: 1,                 // Incorrectly remains 1 instead of 2
    landlord: 0x123...,        // Address of the landlord remains the same
    latestTaxRate: 600,        // Latest tax rate 
    dirty: false               // Dirty flag remains false
});
```

## Recommended Mitigation Steps
```
// Update the plotId in the toilerState mapping
 toilerState[tokenId].plotId = plotId;

```
