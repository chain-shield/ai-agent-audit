# Vulnerability details

## Impact
When user lock funds and became landlord his address with according plot metadata is stored in this mapping `plotMetadata`.

```js
    // landlord to plot metadata
    mapping(address => PlotMetadata) plotMetadata;
```
When updating in [updatePlotMetadata](https://github.com/code-423n4/2024-07-munchables/blame/94cf468aaabf526b7a8319f7eba34014ccebe7b9/src/managers/LandManager.sol#L116) if it is not updated before it will update(create) with current `block.timestamp` and `DEFAULT_TAX_RATE` if it was it will just update `lastUpdated` with current `block.timestamp` as we can see here:
```js
        if (plotMetadata[landlord].lastUpdated == 0) {
            plotMetadata[landlord] = PlotMetadata({
                lastUpdated: block.timestamp,
                currentTaxRate: DEFAULT_TAX_RATE
            });
        } else {
            plotMetadata[landlord].lastUpdated = block.timestamp;
        }
```

The issue is there is no check if user still have funds locked in order to be able to own plots as this is mandatory to be a landlord.
## Proof of Concept
Bob lock his funds and wants to become a landlord so the `updatePlotMetadata` is called with his address and his address get stored in `plotMetadata` mapping.
Bob after locking period take out his funds but his address and plot metadata associated with his address still remains in `plotMetadata` mapping.
Bob now can update even thou he don't have any funds locked.

## Recommended Mitigation Steps
Check if user have locked funds everytime it updates plot's metadata:

```difference
   function updatePlotMetadata(
        address landlord
    ) external override onlyConfiguredContract(StorageKey.AccountManager) {
+        uint256 totalAvail = _getNumPlots(landlord);
+        if (totalAvail >= 1) {
        if (plotMetadata[landlord].lastUpdated == 0) {
            plotMetadata[landlord] = PlotMetadata({
                lastUpdated: block.timestamp,
                currentTaxRate: DEFAULT_TAX_RATE
            });
        } else {
            plotMetadata[landlord].lastUpdated = block.timestamp;
        }
+        } revert NotEnoughtLockedFundsError();

        emit UpdatePlotsMeta(landlord);
    }
```
