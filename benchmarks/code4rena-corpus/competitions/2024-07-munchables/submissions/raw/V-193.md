# Vulnerability details

### Impact
A reentrancy vulnerability in the `LandManager.sol` contract allows an attacker to re-enter the contract during a state update, potentially leading to state inconsistencies and fund loss.

### Proof of Concept
1. External call:
   - [LandManager.sol#L300](https://github.com/code-423n4/2024-07-munchables/blob/main/src/managers/LandManager.sol#L300)
2. State update after external call:
   - [LandManager.sol#L260](https://github.com/code-423n4/2024-07-munchables/blob/main/src/managers/LandManager.sol#L260)

### Tools Used
- Slither for static analysis
- Forge for fuzz testing

### Recommended Mitigation Steps
1. Use reentrancy guards (e.g., OpenZeppelin’s `ReentrancyGuard`).
2. Ensure state changes occur before external calls.
