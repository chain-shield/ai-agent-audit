# Vulnerability details

## Impact
Newly Updated Dirty Toiler is Still Farmed instead of Exempted, thereby giving undue privilege and bonus to a dirty toiler

The code above shows how farm is plotted in the LandManager contract, as pointed out in the first pointer when toiler is dirty the loop simply continues without further implementation or calculation of schnibbles bonus for Munchables, the problem is that when a toiler is just newly updated to be dirty apart from the necessary timestamp update other implementation should not proceed for that toiler just like a previously dirty toiler instead the code should correctly proceed to the next iteration without further implementation
