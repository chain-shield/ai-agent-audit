# Vulnerability details

## Impact
The current implementation of the schnibbles calculation in the farming mechanism mistakenly reduces the `schnibblesTotal` by a factor of 100. This results in  only 1% of the intended `unfedSchnibbles`. This significantly impact the game model of the protocol which can cause a loss of user/protocol funds.

## Proof of Concept
The issue is located in the `_farmPlots` function:

```js
schnibblesTotal = uint256(
    (int256(schnibblesTotal) +
        (int256(schnibblesTotal) * finalBonus)) / 100
);
```

This implementation is equivalent to x * (1 + P) / 100, where x is schnibblesTotal and P is finalBonus.
For example, if schnibblesTotal is 1000 and finalBonus is 10:

Intended result: 1000 * (1 + 10/100) = 1100
Actual result: (1000 + 1000 * 10) / 100 = 110

Suposing that `TaxRate` is equal to 1e17, this shows that `unfedSchnibbles` would be around 99 instead of 990 which is a big difference.

## Tools Used

Manual review

## Recommended Mitigation Steps

Modify the calculation to correctly apply the percentage bonus:

```js
schnibblesTotal = uint256(
    int256(schnibblesTotal) * (100 + finalBonus) / 100
);
```
