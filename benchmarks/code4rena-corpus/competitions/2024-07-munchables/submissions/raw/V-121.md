# Vulnerability details

## Impact
Users have the ability to transfer their staked tokens to other unoccupied plots. This function can be used when the plotId is outside the maximum number of plots for the landlord. However, the problem is that it does not update some essential states for the transfer to be fully completed. The `dirty` state is not updated, so even if you move your token to a normal plotId within the landlord's available range of plots, you will lose your potential next rewards because your token would be tagged as "dirty" and you won't be able to change it. Additionally, the `toilerState` does not update the `plotId` after transferring the token, making it confusing for the user to know on which plot their token is located.
