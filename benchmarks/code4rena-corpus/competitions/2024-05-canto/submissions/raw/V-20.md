# Vulnerability details

The current implementation of the RegisterLegacyAminoCodec function in Govshuttle is incorrect:


```go
func (AppModuleBasic) RegisterCodec(cdc *codec.LegacyAmino) {
	types.RegisterCodec(cdc)
}

func (AppModuleBasic) RegisterLegacyAminoCodec(cdc *codec.LegacyAmino) {
	types.RegisterCodec(cdc)
}
```


When calling AppModuleBasic -> RegisterLegacyAminoCodec -> types.RegisterCodec(cdc), it is evident that the function within Govshuttle contains no executable code.

https://github.com/code-423n4/2024-05-canto/blob/d1d51b2293d4689f467b8b1c82bba84f8f7ea008/canto-main/x/govshuttle/types/codec.go#L39-L42

```go
func RegisterCodec(cdc *codec.LegacyAmino) {
	// this line is used by starport scaffolding # 2
}

```

This oversight means that the cdc.RegisterConcrete calls performed by other modules are not executed for messages sent to the Govshuttle module. Consequently, these types will not be properly decoded when signed with the LegacyAmino codec.

## Impact
Messages to the Govshuttle module will fail when signed with the legacy Amino method

## Proof of Concept

Send message signed with the Legacy Amino method to the GovShuttle module

## Tools Used
Code review

## Recommended Mitigation Steps


```diff
func (AppModuleBasic) RegisterLegacyAminoCodec(cdc *codec.LegacyAmino) {
+    cdc.RegisterConcrete(..)
}
```
