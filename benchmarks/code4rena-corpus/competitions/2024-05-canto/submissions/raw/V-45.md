# Vulnerability details

## Impact
Users can make profit by using convertCoins with tokenPairs of widely variant values

## Proof of Concept
When converting coins on cosmos SDK, IBC packets allows to convert a coin on one chain for equivalent value of another coin on another chain.
However the convertCoin interface in Canto does not take into consideration the difference in value between different tokens. And the same amount of 1 token which is sent from user is the same amount of the 2nd transferred.

Even among stable coins, it is possible for price deviations to occur. In this case, if the price of a token pair defiates by even a small percentage, then a user can use convertCoins to directly acquire the 2nd token, in which the user profits on the price difference between both tokens
