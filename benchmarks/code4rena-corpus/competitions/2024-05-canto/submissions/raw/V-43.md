# Vulnerability details

## Impact
When converting coins/erc20 tokens the erc20 module doesn't take into account the difference between precision of ERC20 tokens and native cosmos ones which might result in loss or gain of funds for users.

## Recommended Mitigation Steps
Since it's possible to have different token precision for erc20 and cosmos coins it should be take into the account when doing token conversions. Use `GetDenomMetaData` and `QueryERC20` functions to get decimals.
