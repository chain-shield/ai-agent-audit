# Vulnerability details

## Impact
The RegisterGRPCGatewayRoutes method does not implement any rate limiting or throttling mechanism for the gRPC Gateway routes, which can make the application vulnerable to Denial of Service (DoS) attacks.

Without rate limiting, an attacker can overwhelm the server with a high volume of requests, leading to resource exhaustion and service unavailability.


## Proof of Concept
Send a large number of gRPC requests to the server and observe the potential for resource exhaustion.


## Tools Used
Manual review

## Recommended Mitigation Steps
Implement rate limiting for gRPC Gateway routes to prevent DoS attacks.

```diff
func (AppModuleBasic) RegisterGRPCGatewayRoutes(clientCtx client.Context, mux *runtime.ServeMux) {
+	limiter := tollbooth.NewLimiter(1, &limiter.ExpirableOptions{DefaultExpirationTTL: time.Minute})
+	mux.Handle("POST", "/my-endpoint", tollbooth.LimitFuncHandler(limiter, MyEndpointHandler))
}
```
