# Vulnerability details

## Impact
The GetSender function does not include a mechanism to ensure that transactions are unique and have not been previously used. This oversight allows for replay attacks, where an attacker can resubmit the same transaction multiple times. As a result, unauthorized transactions could be executed repeatedly, leading to potential financial losses or other unauthorized actions.

## Proof of Concept
The GetSender function retrieves the sender's address from a transaction's signature. However, it does not verify if the transaction has been used before. Without nonce checking, the same transaction can be executed multiple times, as illustrated below.

1- An attacker submits a valid transaction.
2- The transaction is processed, and the sender's address is retrieved using the GetSender function.
3- The attacker resubmits the same transaction.
4- Without nonce checking, the transaction is processed again, causing the same action to be executed multiple times.

Example Scenario
Alice sends 1 ETH to Bob.
The transaction is processed, and Bob receives 1 ETH.
An attacker intercepts and resubmits the same transaction.
Bob receives another 1 ETH, leading to unauthorized duplication of funds.

Manual Testing

## Recommended Mitigation Steps
1- Implement Nonce Checking: Ensure that each transaction includes a nonce that is checked against the sender's account to prevent replay attacks.
2- Store Processed Transactions: Maintain a record of processed transactions to prevent them from being reused.

##Add nonce validation in the GetSender function:

func (msg *MsgEthereumTx) GetSender(chainID *big.Int) (common.Address, error) {
    signer := ethtypes.LatestSignerForChainID(chainID)
    from, err := signer.Sender(msg.AsTransaction())
    if err != nil {
        return common.Address{}, err
    }

    // Check if the nonce has been used before
    if hasNonceBeenUsed(from, msg.Nonce) {
        return common.Address{}, fmt.Errorf("nonce has already been used")
    }

    msg.From = from.Hex()
    return from, nil
}

##Implement the hasNonceBeenUsed function to check the nonce against a stored list of used nonces:

func hasNonceBeenUsed(address common.Address, nonce uint64) bool {
    // Example implementation using a map
    usedNonces := map[common.Address]map[uint64]bool{
        address: {
            nonce: true,
        },
    }

    if used, ok := usedNonces[address][nonce]; ok && used {
        return true
    }
    return false
}
