# Vulnerability details

## Impact
The SetPort function commits the address of the current govShuttle map contract to the state without validating the input address. This can lead to issues if an invalid or malicious address is set.

An invalid or malicious address could disrupt the functionality of the govShuttle module, potentially leading to loss of funds or denial of service.

## Proof of Concept
Set an invalid address:
```go
keeper.SetPort(ctx, common.Address{}) // Setting an empty address

```

## Tools Used
Manual review

## Recommended Mitigation Steps
Add validation to check if the address is valid before setting it in the state.

```diff
func (k Keeper) SetPort(ctx sdk.Context, portAddr common.Address) error {
+	if portAddr == (common.Address{}) {
+		return fmt.Errorf("invalid address")
+	}
	store := runtime.KVStoreAdapter(k.storeService.OpenKVStore(ctx))
	prefixStore := prefix.NewStore(store, types.PortKey)
	prefixStore.Set(types.PortKey, portAddr.Bytes())
+	return nil
}
```
