# Vulnerability details

## Impact
ConvertERC20 allows specifying any sender when converting an erc20 to a cosmos token which allows an attacker to drain all erc20 tokens.

## Summary 
When converting erc20 to a cosmos coin sender's tokens are burned (transferred to the module in case of native). Since any sender can be specified this allows an attacker to drain all evm balances.

## Recommended Mitigation Steps
Require sender's signature or have some other method to bind receiver to the sender.
