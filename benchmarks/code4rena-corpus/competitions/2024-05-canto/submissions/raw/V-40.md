# Vulnerability details

## Impact
The InitGenesis method initializes the module's state without performing any access control checks. This can potentially allow unauthorized actors to initialize or manipulate the module's state.

Unauthorized initialization or modification of the module's state could lead to security breaches, manipulation of data, and loss of funds.


## Proof of Concept
Attempt to initialize the module with unauthorized access, leading to potential state manipulation.


## Tools Used

Manual review

## Recommended Mitigation Steps
Implement access control checks within the InitGenesis method to ensure only authorized entities can initialize the module's state.
