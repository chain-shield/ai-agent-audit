# Vulnerability details

## Impact
Sender account is not checked against blacklist making it possible for malicious users to convert tokens back and forth between cosmos and and erc20.

## Summary
ERC20 module checks whether a token receiver is in the block list using `MintingEnabled` function.
https://github.com/code-423n4/2024-05-canto/blob/main/canto-main/x/erc20/keeper/msg_server.go#L53
https://github.com/code-423n4/2024-05-canto/blob/main/canto-main/x/erc20/keeper/msg_server.go#L112
However it doesn't do that for senders making it possible for malicious users to transact.
