# Vulnerability details



There is a front-running vulnerability in the swap function. The swap function is not checking the minimum amount out in the swap. It means an attacker could potential use this gap to front run the swap function and consequently, steal funds.

## Recommended Mitigation Steps
 
To mitigate this vulnerability the contract should have a minimum output amount parameter that ensures the user receives at least a certain number of tokens, even if the price moves. If the conditions do not meet the expected output, the transaction should revert:
