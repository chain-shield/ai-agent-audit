# Vulnerability details

## Proof of Concept
Potential Integer Overflow/Underflow Risks: The add_delta function attempts to manage overflow and underflow conditions using Rust's overflowing_add and overflowing_sub methods. However, it only checks if the result of these operations causes an overflow or underflow. Given that the checks are not exhaustive for all input combinations, this can still lead to unexpected behaviors.

Proof of Concept: If a very large positive number and a negative number are added together in certain configurations, the result could still lead to undefined behavior due to the way Rust handles integer wrapping
For example:
let result = add_delta(u128::MAX, -1);
Here, u128::MAX + (-1) does not cause a traditional overflow but the function could return a wrong result since overflowing_add would just wrap around.

Impact: Potential Loss: Can lead to incorrect liquidity calculations, which may result in financial losses or unexpected behavior in smart contracts.
## Recommended Mitigation Steps
1. Implement explicit checks before performing operations, such as validating ranges of inputs.
2. Consider using the checked_* methods instead of overflowing_* methods, which return None on overflow instead of wrapping.
