# Vulnerability details

## Finding description and impact

Write a detailed description of the root cause and impact(s) of this finding. 

Unlike the function named _get_amount_0_delta. 
The _get_amount_1_delta function is missing a zero check.
The zero check is missing for the parameter named sqrt_ratio_a_x_96.
This zero check should happen before the muliplication/division/rounding.
The result is an unstable function that reverts without an informal error message when zero is passed for the first parameter in the function.
