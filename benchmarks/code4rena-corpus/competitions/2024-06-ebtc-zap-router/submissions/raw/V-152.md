# Vulnerability details

## Impact
If other parties can deposit large amounts of stETH to the contract between the balance checks, it can affect the calculation of _stETHDiff, making it inaccurate for determining the amount of stETH involved in the closeCdp operation.
This logic is worked same as _adjustCdpWithPermit() function.


## Tools Used
Manual Review

## Recommended Mitigation Steps
Using Reentrancy Guard and Pausing Deposits
First, Add Reentrancy Guard: Ensure the operation is atomic.
Second, Pause Deposits Temporarily: Prevent deposits during the operation.
```
bool private depositsPaused;
modifier whenDepositsNotPaused() {
    require(!depositsPaused, "Deposits are paused");
    _;
}

function openCdp(...) external whenDepositsNotPaused returns ...
...


function _closeCdpWithPermit(...) internal {
    ...

    depositsPaused = true;

    uint256 _zapStEthBalanceBefore = stEth.balanceOf(address(this));
    borrowerOperations.closeCdp(_cdpId);
    uint256 _zapStEthBalanceAfter = stEth.balanceOf(address(this));
    uint256 _stETHDiff = _zapStEthBalanceAfter - _zapStEthBalanceBefore;

    depositsPaused = false;

    ...
}
```
