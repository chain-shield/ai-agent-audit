# Vulnerability details

## Issue

In the LeverageMacroBase contract, the _doSwap function uses a low-level call but doesn't check the success boolean.

While there is a require statement checking the success boolean, it doesn't check the return data. This could lead to a situation where the call is considered successful, but the actual swap operation failed.
Risk: Failed swaps might not be detected, leading to incorrect state changes and potential loss of funds.

       //...

        require(success, "Call has failed");
        //...
     }


## Recommended Mitigation Steps

Check both the success boolean and the return data. Consider using a more robust error handling mechanism for external calls.
