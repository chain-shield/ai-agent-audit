# Vulnerability details

## Impact
Incorrect fee assessment can result in users being charged fees even when their debt does not increase. This can lead to financial losses for users and damage the trust and reputation of the platform

## Proof of Concept
https://github.com/code-423n4/2024-06-badger/blob/9173558ee1ac8a78a7ae0a39b97b50ff0dd9e0f8/ebtc-protocol/packages/contracts/contracts/LeverageMacroBase.sol#L548-L560

The above function calls borrowerOperations.adjustCdpWithColl without checking if _isDebtIncrease is true before assessing the fee.

## Tools Used
Manual Code Review

## Recommended Mitigation Steps
Modify the _adjustCdpCallback function to include a check ensuring that fees are only assessed when the debt increases.
Add a require statement to enforce this condition.

 // Ensure that the fee is assessed only when debt increases
    require(flData._isDebtIncrease, "Fee can only be assessed when debt increases");
