# Vulnerability details

When opening a Collateralized Debt Position (CDP) with permit, the borrower assignment is inconsistent. The borrower should always be set to the signer of the transaction, especially when third-party integrations are involved. However, in the current implementation, the borrower is hardcoded to `msg.sender`, which can cause misalignment if a permit is used.

## Impact
The borrower is not correctly assigned restricting the actual borrower access to the CDP.

## Proof of Concept
Consider a scenario where a user uses a third-party service to open a CDP. The service signs the permit on behalf of the user. With the current implementation, the borrower is set to the third-party service (`msg.sender`) rather than the actual user. This misalignment can lead to the wrong borrower being assigned, causing potential security and functional issues.

A third party (InstaDapp) wants to open a CDP using a permit signed by another user (BOB). According to the current logic:

1. InstaDapp submits the transaction with Bob's permit.
2. The protocol records InstaDapp as the borrower instead of Bob.
3. If Bob intended to manage the CDP, he no longer has the correct authority or access, as InstaDapp is recorded as the borrower.

## Recommended Mitigation Steps

Modify the `_openCdp` function to correctly assign the borrower to the signer of the permit if a permit is used, and to `msg.sender` if called directly.

```solidity
function _openCdp(
    uint256 _debt,
    bytes32 _upperHint,
    bytes32 _lowerHint,
    uint256 _stEthLoanAmount,
    uint256 _stEthMarginAmount,
    uint256 _stEthDepositAmount,
    bytes calldata _positionManagerPermit,
    TradeData calldata _tradeData
) internal nonReentrant returns (bytes32 cdpId) {
    
    _requireZeroOrMinAdjustment(_debt);
    _requireAtLeastMinNetStEthBalance(_stEthDepositAmount - LIQUIDATOR_REWARD);

    address borrower = msg.sender;

    if (_positionManagerPermit.length > 0) {
        PositionManagerPermit memory approval = abi.decode(_positionManagerPermit, (PositionManagerPermit));
        _permitPositionManagerApproval(borrowerOperations, approval);
        borrower = _getPermitSigner(_positionManagerPermit);
    }

    // pre-compute cdpId for post checks
    cdpId = sortedCdps.toCdpId(borrower, block.number, sortedCdps.nextCdpNonce());

    OpenCdpForOperation memory cdp;

    cdp.eBTCToMint = _debt;
    cdp._upperHint = _upperHint;
    cdp._lowerHint = _lowerHint;
    cdp.stETHToDeposit = _stEthDepositAmount;
    cdp.borrower = borrower;

    _openCdpOperation({
        _cdpId: cdpId,
        _cdp: cdp,
        _flAmount: _stEthLoanAmount,
        _tradeData: _tradeData
    });

    if (_positionManagerPermit.length > 0) {
        borrowerOperations.renouncePositionManagerApproval(borrower);
    }
}
```


If there's no permit the borrower is set to `msg.sender` if there's a permit it's set to the permit signer.
