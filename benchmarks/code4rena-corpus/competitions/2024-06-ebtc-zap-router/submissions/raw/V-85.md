# Vulnerability details

## Impact
Detailed description of the impact of this finding.

The use of block.number as a proxy for time can lead to unpredictable and insecure behaviour in smart contracts. Block numbers and timestamps are not precise and can be manipulated to some extent by miners. This makes them unsuitable for time-sensitive operations. Instead, using a reliable oracle to fetch time values ensures greater accuracy and security.

## Recommended Mitigation Steps
To mitigate this issue, we will use a mock oracle to provide reliable time values. The following changes show how to replace block.number with an oracle-based approach.
***Code before mitigation:***
```sol
expectedCdpId = sortedCdps.toCdpId(
    address(this),
    block.number,
    sortedCdps.nextCdpNonce()
);
```
***Code after mitigation:***
First, we introduce a mock oracle contract to fetch the current block timestamp:
```sol
interface ITimeOracle {
    function getCurrentTimestamp() external view returns (uint256);
}

contract TimeOracle is ITimeOracle {
    function getCurrentTimestamp() external view override returns (uint256) {
        return block.timestamp;
    }
}
```
Then, we modify the LeverageMacroBase.sol contract to use this oracle:
```sol
contract LeverageMacroBase {
    ITimeOracle public timeOracle;

    constructor(address _timeOracle) {
        timeOracle = ITimeOracle(_timeOracle);
    }

    function doOperation(
        FlashLoanType flType,
        uint256 borrowAmount,
        LeverageMacroOperation calldata operation,
        PostOperationCheck postCheckType,
        PostCheckParams calldata checkParams
    ) external virtual {
        _assertOwner();

        // Figure out the expected CDP ID using sortedCdps.toCdpId
        bytes32 expectedCdpId;
        uint256 currentTime = timeOracle.getCurrentTimestamp();
        if (
            operation.operationType == OperationType.OpenCdpOperation &&
            postCheckType != PostOperationCheck.none
        ) {
            expectedCdpId = sortedCdps.toCdpId(
                address(this),
                currentTime,
                sortedCdps.nextCdpNonce()
            );
        } else if (
            operation.operationType == OperationType.OpenCdpForOperation &&
            postCheckType != PostOperationCheck.none
        ) {
            OpenCdpForOperation memory flData = abi.decode(
                operation.OperationData,
                (OpenCdpForOperation)
            );
            // This is used to support permitPositionManagerApproval
            expectedCdpId = sortedCdps.toCdpId(
                flData.borrower,
                currentTime,
                sortedCdps.nextCdpNonce()
            );
        }

        _doOperation(flType, borrowAmount, operation, postCheckType, checkParams, expectedCdpId);
    }
}
```
With this mitigation, the contract now relies on the oracle for time values, reducing the risk of manipulation and ensuring more precise and secure time-dependent operations.
