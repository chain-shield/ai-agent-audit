# Vulnerability details

## Impact
The `call`/`delegatecall` function returns a boolean value indicating whether the call was successful. However, it is important to note that this return value is not being checked in the current implementation.

As a result, there is a possibility that the call wasn't successful, while the transaction continues without reverting.

## Recommended Mitigation Steps
To ensure the robustness and security of your smart contract, it's essential to check the return value of low-level `call()` and `delegatecall()` functions. These functions return a boolean value indicating the success of the call, and it's crucial to validate this return value to handle potential failures gracefully. By checking the return value, you can implement appropriate error handling and take necessary actions in case the call is not successful, preventing unexpected behavior or vulnerabilities in your contract.
