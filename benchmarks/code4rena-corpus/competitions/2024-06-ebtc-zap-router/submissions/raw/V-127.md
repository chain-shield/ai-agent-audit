# Vulnerability details

## Impact

The `_closeCdpOperation` function is intended to close CDP (Collateralized Debt Position) positions. However, it does not correctly handle the close operation within the `_handleOperation` function.

## Proof of Concept

The `_closeCdpOperation` function calls `_doOperation`, which should in turn call `_handleOperation` with `OperationType.CloseCdpOperation` to manage the closing operation. Without this handling, the `_closeCdpCallback(operation.OperationData)` is never invoked, meaning the close operation is never truly executed.

## Tools Used

Manual Review

## Recommended Mitigation Steps

Replace the `FlashLoanType` from `eBTC` to `noFlashloan` in the `_doOperation` call.

```diff
        _doOperation(
-           FlashLoanType.eBTC,
+           FlashLoanType.noFlashloan,
            _debt,
            op,
            PostOperationCheck.isClosed,
            _getPostCheckParams(_cdpId, 0, 0, ICdpManagerData.Status.closedByOwner, 0),
            bytes32(0)
        );
```
