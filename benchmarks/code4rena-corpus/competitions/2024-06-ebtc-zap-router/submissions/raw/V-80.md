# Vulnerability details

## Impact
Detailed description of the impact of this finding.

Contracts often need access to time values to perform certain types of functionality. Values such as block.timestamp, and block.number can give you a sense of the current time or a time delta, however, they are not safe to use for most purposes.

In the case of block.timestamp, developers often attempt to use it to trigger time-dependent events. As Ethereum is decentralized, nodes can synchronize time only to some degree. Moreover, malicious miners can alter the timestamp of their blocks, especially if they can gain advantages by doing so. However, miners can't set a timestamp smaller than the previous one (otherwise the block will be rejected), nor can they set the timestamp too far ahead in the future. Taking all of the above into consideration, developers can't rely on the preciseness of the provided timestamp.

As for block.number, considering the block time on Ethereum is generally about 14 seconds, it's possible to predict the time delta between blocks. However, block times are not constant and are subject to change for a variety of reasons, e.g. fork reorganisations and the difficulty bomb. Due to variable block times, block.number should also not be relied on for precise calculations of time.

Using block values (e.g., block.timestamp and block.number) as proxies for time in smart contracts can lead to inaccurate time calculations. Miners can manipulate block timestamps within certain bounds, and the variability in block times means that relying on block.number for precise time calculations is unreliable. This can cause unintended behavior in time-sensitive operations and potentially lead to security vulnerabilities or logical errors in the smart contract.

## Recommended Mitigation Steps

Replace the use of block.number with a reliable time source. One solution is to use an oracle to provide accurate time information. For this example, we will use a mock oracle to demonstrate the mitigation.

Code After Mitigation:
```sol
// Interface for time oracle
interface ITimeOracle {
    function getCurrentTime() external view returns (uint256);
}

// Implementation in the contract
contract EbtcLeverageZapRouter {
    ITimeOracle public timeOracle;

    constructor(address _timeOracle) {
        timeOracle = ITimeOracle(_timeOracle);
    }

    function _openCdp(
        uint256 _debt,
        bytes32 _upperHint,
        bytes32 _lowerHint,
        uint256 _stEthLoanAmount,
        uint256 _stEthMarginAmount,
        uint256 _stEthDepositAmount,
        bytes calldata _positionManagerPermit,
        TradeData calldata _tradeData
    ) internal nonReentrant returns (bytes32 cdpId) {
        _requireZeroOrMinAdjustment(_debt);
        _requireAtLeastMinNetStEthBalance(_stEthDepositAmount - LIQUIDATOR_REWARD);

        if (_positionManagerPermit.length > 0) {
            PositionManagerPermit memory approval = abi.decode(_positionManagerPermit, (PositionManagerPermit));
            _permitPositionManagerApproval(borrowerOperations, approval);
        }

        // Use oracle time instead of block.number
        uint256 currentTime = timeOracle.getCurrentTime();
        cdpId = sortedCdps.toCdpId(msg.sender, currentTime, sortedCdps.nextCdpNonce());

        OpenCdpForOperation memory cdp;
        cdp.eBTCToMint = _debt;
        cdp._upperHint = _upperHint;
        cdp._lowerHint = _lowerHint;
        cdp.stETHToDeposit = _stEthDepositAmount;
        cdp.borrower = msg.sender;

        _openCdpOperation({
            _cdpId: cdpId,
            _cdp: cdp,
            _flAmount: _stEthLoanAmount,
            _tradeData: _tradeData
        });

        if (_positionManagerPermit.length > 0) {
            borrowerOperations.renouncePositionManagerApproval(msg.sender);
        }
    }
}
```
The mitigation involves replacing the unreliable block.number with a time value obtained from a trusted oracle, ensuring more precise and secure time-dependent operations. This approach reduces the risk of manipulation and variability associated with block-based time calculations.
