# Vulnerability details

## Impact
Detailed description of the impact of this finding.

Incorrect debt and collateral adjustments can destabilise the CDP, leading to potential financial loss or liquidation.

## Proof of Concept
Provide direct links to all referenced code in GitHub. Add screenshots, logs, or any other relevant proof that illustrates the concept.

The _adjustCdpOperation function does not validate the ```_cdp``` and ```debt``` input parameters, potentially leading to incorrect adjustments of debt and collateral. Malicious inputs can cause the contract to perform unintended operations.

***Code before mitigation***
```sol
function _adjustCdpOperation(
    bytes32 _cdpId,
    FlashLoanType _flType,
    uint256 _flAmount,
    AdjustCdpOperation memory _cdp,
    uint256 debt,
    uint256 coll,
    TradeData calldata _tradeData
) internal {
    uint256 newDebt = _cdp._isDebtIncrease ? debt + _cdp._EBTCChange : debt - _cdp._EBTCChange;
    uint256 newColl = _cdp._stEthBalanceIncrease > 0 ? 
        coll + stEth.getSharesByPooledEth(_cdp._stEthBalanceIncrease) : 
        coll - stEth.getSharesByPooledEth(_cdp._stEthBalanceDecrease);

    _doOperation(
        _flType,
        _flAmount,
        _getAdjustCdpParams(_cdp, _tradeData),
        PostOperationCheck.cdpStats,
        _getPostCheckParams(
            _cdpId, 
            newDebt, 
            newColl, 
            ICdpManagerData.Status.active,
            _tradeData.collValidationBufferBPS
        ),
        _cdpId
    );

    _sweepEbtc();
}
```

## Tools Used
Manual review.
## Recommended Mitigation Steps
Add input validation to ensure ```_cdp``` and ```debt``` parameters are within expected ranges.

***Code after mitigation***
```sol
function _adjustCdpOperation(
    bytes32 _cdpId,
    FlashLoanType _flType,
    uint256 _flAmount,
    AdjustCdpOperation memory _cdp,
    uint256 debt,
    uint256 coll,
    TradeData calldata _tradeData
) internal {
    require(_cdp._EBTCChange > 0, "EBTCChange must be positive");
    require(_cdp._stEthBalanceIncrease >= 0 && _cdp._stEthBalanceDecrease >= 0, "Invalid stETH balance change");

    uint256 newDebt = _cdp._isDebtIncrease ? debt + _cdp._EBTCChange : debt - _cdp._EBTCChange;
    uint256 newColl = _cdp._stEthBalanceIncrease > 0 ? 
        coll + stEth.getSharesByPooledEth(_cdp._stEthBalanceIncrease) : 
        coll - stEth.getSharesByPooledEth(_cdp._stEthBalanceDecrease);

    _doOperation(
        _flType,
        _flAmount,
        _getAdjustCdpParams(_cdp, _tradeData),
        PostOperationCheck.cdpStats,
        _getPostCheckParams(
            _cdpId, 
            newDebt, 
            newColl, 
            ICdpManagerData.Status.active,
            _tradeData.collValidationBufferBPS
        ),
        _cdpId
    );

    _sweepEbtc();
}
```
