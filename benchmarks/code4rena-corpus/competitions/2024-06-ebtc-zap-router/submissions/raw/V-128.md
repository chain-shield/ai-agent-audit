# Vulnerability details

## Impact
This will cause the router to become unusable.

## Proof of Concept
There are no funds in the router, and [the protocol only transfers stEthMarginBalance to the router](https://github.com/code-423n4/2024-06-badger/blob/9173558ee1ac8a78a7ae0a39b97b50ff0dd9e0f8/ebtc-zap-router/src/EbtcLeverageZapRouter.sol#L397-L399), but does not transfer stEthBalanceChange to the router. But in the end, [BorrowerOperations needs to transfer stEthMarginBalance+stEthBalanceChange from the router to the activepool](https://github.com/code-423n4/2024-06-badger/blob/9173558ee1ac8a78a7ae0a39b97b50ff0dd9e0f8/ebtc-protocol/packages/contracts/contracts/BorrowerOperations.sol#L7788)(In the case of isStEthMarginIncrease==isStEthBalanceIncrease==true.). It will fail due to the lack of tokens in the router.
```soldity
        uint256 marginIncrease = _params.isStEthBalanceIncrease ? _params.stEthBalanceChange : 0;
        if (_params.isStEthMarginIncrease && _params.stEthMarginBalance > 0) {
            marginIncrease += _params.stEthMarginBalance;
        }
```

## Recommended Mitigation Steps
