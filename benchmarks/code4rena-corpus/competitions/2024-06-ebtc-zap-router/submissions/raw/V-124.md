# Vulnerability details

## Impact
Users can re-enter Router through DEX to reduce the fee of flash loan from BorrowerOperations.

## Proof of Concept
Under normal business, if the user adjusts the CDP through the Router, [he or she needs to perform flash loan through borrowerOperations/activePool](https://github.com/code-423n4/2024-06-badger/blob/9173558ee1ac8a78a7ae0a39b97b50ff0dd9e0f8/ebtc-zap-router/src/EbtcLeverageZapRouter.sol#L436-L438). The more CDPs you want to change, the more tokens you need to borrow. [The greater the number of flash loans, the more fees there will be](https://github.com/code-423n4/2024-06-badger/blob/9173558ee1ac8a78a7ae0a39b97b50ff0dd9e0f8/ebtc-protocol/packages/contracts/contracts/BorrowerOperations.sol#L1128-L1133).
```solidity
        _adjustCdpOperation({
            _cdpId: _cdpId,
            _flType: _params.isDebtIncrease ? FlashLoanType.stETH : FlashLoanType.eBTC,
```

However, users can make the fee smaller by reentry. Users can borrow smaller flash loans and adjust the CDP again through reentry. In this way, you only need one flash loan and can perform multiple operations.

Specifically, the steps are as follows (the following operations are completed in one transaction):
1. The user first performs the normal adjustCdp operation to lend amountX eBTC.
2. When the [_doSwap function is executed, DEX will be called](https://github.com/code-423n4/2024-06-badger/blob/9173558ee1ac8a78a7ae0a39b97b50ff0dd9e0f8/ebtc-protocol/packages/contracts/contracts/LeverageMacroBase.sol#L464-L470). According to the documentation, this is 0x or 1inch.
3. Taking 1inch as an example, since [calldataForSwap](https://github.com/code-423n4/2024-06-badger/blob/9173558ee1ac8a78a7ae0a39b97b50ff0dd9e0f8/ebtc-protocol/packages/contracts/contracts/LeverageMacroBase.sol#L469C13-L469C37) is defined by the user, [swap](https://www.codeslaw.app/contracts/ethereum/0x1111111254eeb25477b68fb85ed929f73a960582?file=AggregationRouterV5.sol&start=973) can be called here, and then the user's own contract is called through [the call function in swap](https://www.codeslaw.app/contracts/ethereum/0x1111111254eeb25477b68fb85ed929f73a960582?file=AggregationRouterV5.sol&start=1046).
4. After the user calls any dex in his contract to exchange eBTC for stETH, he can then call the router again to lend out amountX of eBTC.
5. In this way, users can perform multiple operations with one flash loan, saving the fees of flash loans.
```solidity
    function _doSwap(SwapOperation memory swapData) internal {

        _ensureNotSystem(swapData.addressForSwap);

        IERC20(swapData.tokenForSwap).safeApprove(
            swapData.addressForApprove,
            swapData.exactApproveAmount
        );

        (bool success, ) = excessivelySafeCall(
            swapData.addressForSwap,
            gasleft(),
            0,
            0,
            swapData.calldataForSwap
        );
        require(success, "Call has failed");
```

Users can also use Uni's flash loan function to re-enter when calling a pool such as Uni. The fee is only the swap fee and there is no flash loan fee.
## Tools Used
Manual

## Recommended Mitigation Steps
Add a re-enter lock to the router.
