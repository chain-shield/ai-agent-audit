# Vulnerability details


The `adjustCdpWithEth` function in `EbtcLeverageZapRouter` allows users to send Ether along with their transactions. However, if certain conditions are not met within the function, the transaction does not handle the sent Ether appropriately, potentially resulting in the loss of funds.

## Impact
If a user sends Ether with their transaction but the conditions related to `_params.isStEthMarginIncrease` and `_params.stEthMarginBalance` are not satisfied, the function does not revert or return the Ether. This can lead to a scenario where the Ether is locked in the contract, effectively causing a loss of funds for the user.

## Proof of Concept
Consider the following code snippet from the `adjustCdpWithEth` function:

```solidity
uint256 _zapStEthBalanceBefore = stEth.balanceOf(address(this));
if (_params.isStEthMarginIncrease && _params.stEthMarginBalance > 0) {
    _params.stEthMarginBalance = _convertRawEthToStETH(_params.stEthMarginBalance);
}
```

In this function, if `msg.value` is not zero and the condition `_params.isStEthMarginIncrease && _params.stEthMarginBalance > 0` evaluates to false, the sent Ether is not reverted or returned to the user.


## Recommendation
To prevent users from losing their Ether, the function should include a mechanism to revert the transaction if Ether is sent and the necessary conditions are not satisfied. This can be achieved by adding a conditional check that reverts the transaction when `msg.value` is not zero and the conditions are not met.

### Implementation
Update the `adjustCdpWithEth` function to include a revert statement:

```solidity
function adjustCdpWithEth(...) public payable {
    uint256 _zapStEthBalanceBefore = stEth.balanceOf(address(this));
    if (_params.isStEthMarginIncrease && _params.stEthMarginBalance > 0) {
        _params.stEthMarginBalance = _convertRawEthToStETH(_params.stEthMarginBalance);
    }

    // Check if Ether is sent but conditions are not met, and revert the transaction
    if (msg.value != 0 && !(_params.isStEthMarginIncrease && _params.stEthMarginBalance > 0)) {
        revert("Conditions not met for Ether deposit");
    }

    // Rest of the function logic...
}
```

This update ensures that if the user sends Ether and the conditions are not met, the transaction is reverted, preventing the loss of funds.
