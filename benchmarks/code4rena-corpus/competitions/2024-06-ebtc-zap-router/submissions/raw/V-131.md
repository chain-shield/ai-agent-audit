# Vulnerability details

## Description
The protocol relies on low level `call()` to deposit native eth into lido and get stEth in return, the problem however arises from the fact that `call()` wouldn't revert if lido reverts and the contract doesn't handle the returned value (`success`). this will cause the _deposit() variable to equal 0, and the contract deposited eth being locked there with no way to get them back, causing a critical lock of funds (also knowing that the codeonly has sweep ebtc and sweep stEth functions and no sweep native Eth). This is the function that handels depositing user funds into Lido, 
As we can see .call() is used, and the return value of the low level call is not handeld
https://github.com/code-423n4/2024-06-badger/blob/9173558ee1ac8a78a7ae0a39b97b50ff0dd9e0f8/ebtc-zap-router/src/ZapRouterBase.sol#L34-L41
```solidity
    function _depositRawEthIntoLido(uint256 _initialETH) internal returns (uint256) {
        // check before-after balances for 1-wei corner case
        uint256 _balBefore = stEth.balanceOf(address(this));
        // TODO call submit() with a referral?
        payable(address(stEth)).call{value: _initialETH}("");
        uint256 _deposit = stEth.balanceOf(address(this)) - _balBefore;
        return _deposit;
    }
```

As we can see there are 2 conditions in which the transaction will revert (other than 0 amt transfer):
- Lido paused (`require(!stakeLimitData.isStakingPaused(), "STAKING_PAUSED");`)
- msg.value is more than staking limit (`require(!stakeLimitData.isStakingPaused(), "STAKING_PAUSED");)

**If either of those conditions are met, the user deposited eth in the ebtcRouter or leverage router could be locked, with no way to get them**
## Recomendation
To mitigate this issue, we recommend to either use a high level call (submit()) or to handle the low level call returns

```diff
    function _depositRawEthIntoLido(uint256 _initialETH) internal returns (uint256) {
        // check before-after balances for 1-wei corner case
        uint256 _balBefore = stEth.balanceOf(address(this));
        // TODO call submit() with a referral?
-        payable(address(stEth)).call{value: _initialETH}("");
+        (bool success,  )payable(address(stEth)).call{value: _initialETH}("");
+        require(success,"Deposit in Lido failed");
        uint256 _deposit = stEth.balanceOf(address(this)) - _balBefore;
        return _deposit;
    }
```
