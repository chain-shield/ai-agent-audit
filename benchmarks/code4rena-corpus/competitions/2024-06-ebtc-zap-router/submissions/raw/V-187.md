# Vulnerability details

## Vulnerability Details
Lido's Staked Ether (stETH) is a liquid staking derivative that represents staked ETH in the Ethereum beacon chain. As a rebasing token, stETH balances automatically adjust to reflect accrued staking rewards. These rebases occur at regular intervals, typically daily, affecting all stETH holders simultaneously.

For DeFi protocols interacting with stETH, accurate tracking of user deposits is crucial but challenging. The token's rebasing nature means that balance changes can occur not only from transfers but also from passive reward accrual. This dual source of balance fluctuation introduces complexities in deposit accounting, potentially leading to discrepancies between actual and recorded deposit amounts.

## Issue
The `_transferInitialStETHFromCaller` function in the ZapRouterBase contract contains a vulnerability that may result in overstating user deposits if a rebase occurs during the function's execution:

https://github.com/code-423n4/2024-06-badger/blob/main/ebtc-zap-router/src/ZapRouterBase.sol#L107

```solidity
function _transferInitialStETHFromCaller(uint256 _initialStETH) internal returns (uint256) {
    uint256 _balBefore = stEth.balanceOf(address(this));
    stEth.transferFrom(msg.sender, address(this), _initialStETH);
    uint256 _deposit = stEth.balanceOf(address(this)) - _balBefore;
    return _deposit;
}
```

The problem stems from:

1. The use of before-and-after balance checks to determine the deposit amount.
2. Lack of differentiation between balance increases from transfers and those from rebases.
3. Absence of validation that the balance increase matches the expected transfer amount.

## Impact
- Deposit amounts may be recorded higher than the actual user contribution
- Distortion of user position sizes and collateralization ratios
- Potential for strategic exploitation by timing deposits with rebase events
- Overall impairment of the protocol's accounting accuracy and fairness

## Mitigation
Implement a strict equality check between the expected and actual transfer amounts
