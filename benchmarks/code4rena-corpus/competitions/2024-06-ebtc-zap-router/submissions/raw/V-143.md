# Vulnerability details

## Summary

Incorrect math in `_convertWrappedEthToStETH` function, can break the functionality of protocol.

## Vulnerability Details

The function `_convertWrappedEthToStETH` is converting `wEth` to `StEth` 

This function involves use or `Eth` , `wEth` and `StEth` 
Let us consider at this stage we have 10ETH, 10stETH, 10WETH in the contract and `_initialWETH=5`
And with these valued we try to simulate the function we get, the following
```solidity
_wETHBalBefore=10WEth//gets the current balance of weth in contract
transfer(5WETH)//transfers wEth from msg.sender to this contract
//current balance = 10+5 WEth 
_wETHReiceived=15-10=5 WEth//gets the total wEth recieved i.e `_initialWETH`

_rawETHBalBefore=10 ETH//gets balance of raw Eth in contract
withdraw(5 WEth)//withdraws wEth received i.e. 5 
//current balance = 15-5=10 wEth 
_rawETHConverted=10-10=0//gets amount of raw eth converted
_depositRawEthIntoLido(0)//deposits raw eth to Lido
``` 
In line 
```solidity
uint256 _rawETHConverted = address(this).balance - _rawETHBalBefore;
```
`address(this).balance` -> balance of raw eth in contract which would stay same as the previous line i.e 
```solidity
        IWrappedETH(address(wrappedEth)).withdraw(_wETHReiceived);
```
withdraws wEth not Eth, so balance of wEth in contract changes 
Hence, `_rawETHConverted` is `0` as `address(this).balance` and `_rawETHBalBefore` is same

So `_depositRawEthIntoLido(0)` will deposit zero value. 

## Impact

Impact is high as, functionality of `_convertWrappedEthToStETH` is broken due to which `_depositRawEthIntoLido` deposits `0` value. Everytime the function is called, conversion of wEth to StEth doesn't happen. All other functions using `_convertWrappedEthToStETH` will also give wrong results and it can potentially break the functionality of protocol.

## Proof of concept

```solidity 
    function _convertWrappedEthToStETH(uint256 _initialWETH) internal returns (uint256) {
        uint256 _wETHBalBefore = wrappedEth.balanceOf(address(this));
        wrappedEth.transferFrom(msg.sender, address(this), _initialWETH); 
        uint256 _wETHReiceived = wrappedEth.balanceOf(address(this)) - _wETHBalBefore;

        uint256 _rawETHBalBefore = address(this).balance;
        IWrappedETH(address(wrappedEth)).withdraw(_wETHReiceived);//<@
        uint256 _rawETHConverted = address(this).balance - _rawETHBalBefore;//<@
        return _depositRawEthIntoLido(_rawETHConverted); 
    }
   ```
