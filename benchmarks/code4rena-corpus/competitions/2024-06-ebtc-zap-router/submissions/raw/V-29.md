# Vulnerability details

## Impact
The `_doSwapChecks` function currently lacks a check for the zero address, which can lead to interactions with an invalid ERC20 token address. This could cause unexpected failures or potential security vulnerabilities. Additionally, the function could benefit from emitting events to improve traceability and debugging.

## Proof of Concept
Missing Zero Address Check:
```
require(
    IERC20(swapChecks[i].tokenToCheck).balanceOf(address(this)) >
        swapChecks[i].expectedMinOut,
    "LeverageMacroReference: swap check failure!"
);
```
Event Emission:
```
emit SwapCheckPassed(tokenToCheck, expectedMinOut);
```

## Tools Used
Manual code review

## Recommended Mitigation Steps
- Add zero address check
- Emit events for successfull checks
```
function _doSwapChecks(SwapCheck[] memory swapChecks) internal {
    uint256 length = swapChecks.length;
    unchecked {
        for (uint256 i; i < length; ++i) {
            address tokenToCheck = swapChecks[i].tokenToCheck;
            uint256 expectedMinOut = swapChecks[i].expectedMinOut;

            require(
                tokenToCheck != address(0),
                "LeverageMacroReference: invalid token address!"
            );

            require(
                IERC20(tokenToCheck).balanceOf(address(this)) > expectedMinOut,
                "LeverageMacroReference: swap check failure!"
            );

            emit SwapCheckPassed(tokenToCheck, expectedMinOut);
        }
    }
}

event SwapCheckPassed(address indexed tokenToCheck, uint256 expectedMinOut);
```
