# Vulnerability details

## Impact
`IERC3156FlashLender` interface's `flashLoan` function returns the sucessful state result.
Without checking for success, there is no way to track whether the function actually succeeded or failed, and a malicious user could claim that the loan by `flashLoan()` was never received.
Also, if it fails, `borrowAmount` token may be left, but there is no way to determine which user the request came from.
