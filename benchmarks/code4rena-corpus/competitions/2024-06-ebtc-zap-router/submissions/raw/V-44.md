# Vulnerability details

## Impact

The `LeverageZapRouterBase` contract currently does not provide the owner with the ability to modify the `zapFeeBPS` and `zapFeeReceiver` parameters. This inflexibility poses a significant risk to the contract's usability and adaptability. If there is a need to update these parameters in response to changing market conditions or organizational changes, the contract will become inoperative, leading to potential financial and operational issues.

## Proof of Concept

In `LeverageZapRouterBase` contract there are no mechanisms for the owner to update the `zapFeeBPS` and `zapFeeReceiver`. This lack of functionality means that the contract cannot adapt to necessary changes, which is a critical flaw in its design.

Scenario Demonstration:
1. Fee Structure Necessity: Suppose the current `zapFeeBPS` is set to 200 basis points. If the market conditions change and a lower fee is required to stay competitive, the contract owner has no means to update this fee, leading to a potential decline in usage.
2. Fee Receiver Update: If the `zapFeeReceiver` address, initially set to `0x123...abc`, becomes compromised or the organization decides to change the recipient address to `0x456...def`, the contract lacks the functionality to make this update. This scenario can result in continued fee distribution to an outdated or compromised address.

## Recommended Mitigation Steps

To resolve this critical issue, it is recommended to implement the following functions to provide the owner with the necessary control over these parameters. These functions should be restricted to the contract owner to ensure security:

Proposed Solutions:
1. Function to Update Zap Fee Basis Points:
```solidity
// Function to update the zap fee basis points
function setZapFeeBPS(uint256 newZapFeeBPS) external onlyOwner {
    zapFeeBPS = newZapFeeBPS;
}
```

2. Function to Update Zap Fee Receiver:
```solidity
// Function to update the zap fee receiver address
function setZapFeeReceiver(address newZapFeeReceiver) external onlyOwner {
    require(newZapFeeReceiver != address(0), "Invalid address");
    zapFeeReceiver = newZapFeeReceiver;
}
```
