# Vulnerability details

## Vulnerability Detail
If permit was previously set to Persistent, opening/adjusting/closing another position could override it to None.

Calling `renouncePositionManagerApproval` after every openCDP/adjustCDP/closeCDP operation in EbtcLeverageZapRouter
```solidity
   if (_positionManagerPermit.length > 0) {
@>    borrowerOperations.renouncePositionManagerApproval(msg.sender);
   }
```
Sets PositionManagerApproval to None, no matter if previously it was set to OneTime or Persistent.

This is the implementation from BorrowersOperations contract:
```solidity
    function renouncePositionManagerApproval(address _borrower) external override {
@>      _setPositionManagerApproval(_borrower, msg.sender, PositionManagerApproval.None);
    }
```

We can see that in BorrowersOperations, in `_requireBorrowerOrPositionManagerAndUpdateManagerApproval` which is called for all of the 3 operations, this is avoided by setting it to None, only if it was previously set to OneTime.
```solidity
@>      if (_approval == PositionManagerApproval.OneTime) {
            _setPositionManagerApproval(_borrower, msg.sender, PositionManagerApproval.None);
        }
```        
## Impact
Someone using operation can override Persistent state. As it is "Persistent" it should be overridden only by calling _setPositionManagerApproval in BorrowersOperations, so we should also validate that we are overriding only OneTime Approvals as we do in `_requireBorrowerOrPositionManagerAndUpdateManagerApproval`

## Proof of Concept
Add this test to `LeverageZaps.t.sol` and run it with `forge test --match-test test_PersistentPermitApprovalIsOverriden`

```solidity
    function test_PersistentPermitApprovalIsOverriden() public {
        seedActivePool();

        // Open Leveraged CDP position
        _before();
        (address user, bytes32 cdpId) = createLeveragedPosition(MarginType.stETH);
        _after();

        (uint256 debt, uint256 collShares) = cdpManager.getSyncedDebtAndCollShares(cdpId);
        uint256 stEthAmount = collateral.getPooledEthByShares(collShares);
        IEbtcLeverageZapRouter.TradeData memory tradeData =
            _getExactOutCollateralToDebtTradeData(debt, stEthAmount * COLLATERAL_BUFFER / SLIPPAGE_PRECISION);

        // Set Approval to Persistent
        vm.prank(user);
        borrowerOperations.setPositionManagerApproval(
            address(leverageZapRouter), IPositionManagers.PositionManagerApproval.Persistent
        );

        // Adjust with permit. This will revoke the Persistent approval
        IEbtcZapRouter.PositionManagerPermit memory pmPermit = createPermit(user);
        uint256 debtChange = 2e18;
        uint256 marginIncrease = 0.5e18;
        uint256 collValue = _debtToCollateral(debtChange) * COLLATERAL_BUFFER / 10000;
        uint256 flAmount = _debtToCollateral(debtChange);

        vm.prank(user);
        leverageZapRouter.adjustCdp(
            cdpId,
            _getAdjustCdpParams(flAmount, int256(debtChange), int256(collValue), int256(marginIncrease), false),
            abi.encode(pmPermit),
            _getExactInDebtToCollateralTradeData(debtChange)
        );

        // @audit-issue Any operation, in this case closeCDP without permit, should revert
        vm.prank(user);
        vm.expectRevert(
            "BorrowerOperations: Only borrower account or approved position manager can OpenCdp on borrower's behalf"
        );
        leverageZapRouter.closeCdp(cdpId, "", tradeData);
    }
```

## Recommended Mitigation Steps
In every operation (i.e. openCDP, adjustCDP, closeCDP ) change the check:
```diff
-        if (_positionManagerPermit.length > 0) {
+       PositionManagerApproval approval = borrowerOperations.getPositionManagerApproval(msg.sender, address(this);
+       if (_positionManagerPermit.length > 0 && approval != PositionManagerApproval.Persistent) {
            borrowerOperations.renouncePositionManagerApproval(msg.sender);
        }
```
