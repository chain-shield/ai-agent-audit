# Vulnerability details

## Impact
The reentrancy vulnerability in smart contracts occurs when an external call to another contract is made before the state of the contract making the call is updated. This can allow the called contract to make recursive calls back to the original contract, potentially repeating certain actions multiple times before the initial function is completed, leading to unintended behavior or draining of funds.

File is: ZapRouterBase.sol
