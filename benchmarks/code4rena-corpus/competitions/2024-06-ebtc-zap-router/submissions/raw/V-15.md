# Vulnerability details

## Impact
Detailed description of the impact of this finding.

The function called ```_convertWrappedEthToStETH``` does not validate the parameter called _initialWETH. This can lead to zero values being entered or overly large values being passed through the function.

There is also a typo in the variable named ```_wETHReiceived```, which should be named ```_wETHReceived```.
