# Vulnerability details

[sweepToCaller()](https://github.com/code-423n4/2024-06-badger/blob/9173558ee1ac8a78a7ae0a39b97b50ff0dd9e0f8/ebtc-protocol/packages/contracts/contracts/LeverageMacroBase.sol#L247-L263) function designed to transfer all eBTC and collateral tokens to the caller after operations. However, due to potential rounding errors/dust amounts, small quantities of tokens may remain in the contract. This violates the stated _invariant that the ZapRouter contract should not hold any tokens after each operation_, aside from rounding.

The `sweepToCaller()` function uses `balanceOf()` and `sharesOf()` to determine the amounts to transfer:
```solidity
function sweepToCaller() public { 
    _assertOwner(); 
    
    uint256 ebtcBal = ebtcToken.balanceOf(address(this)); 
    uint256 collateralBal = stETH.sharesOf(address(this));

    if (ebtcBal > 0) {
        ebtcToken.transfer(msg.sender, ebtcBal);
    }
    
    if (collateralBal > 0) {
        stETH.transferShares(msg.sender, collateralBal);
    }
```
While this approach attempts to transfer all tokens, it doesn't account for potential dust amounts that could accumulate over time due to rounding errors in various operations.

## Impact
The contract may retain small amounts of tokens, contradicting the expectation that it should hold no tokens after operations.

Over time, these small amounts could accumulate to significant values, especially if the contract is used frequently.

The presence of residual tokens may lead to unexpected behavior in other parts of the system that assume the contract is empty after operations.

## Proof of Concept
1. User performs an operation that leaves 1 wei of eBTC in the contract due to rounding.
2. `sweepToCaller()` is called, but 1 wei remains as it's below the dust threshold for transfers.
3. This process repeats multiple times, gradually accumulating small amounts of tokens.
4. Eventually, a significant amount of tokens are trapped in the contract, violating the no-token-retention invariant.

## Recommended Mitigation Steps
Implement a dust threshold and accumulate small amounts for the owner:
```solidity
uint256 constant DUST_THRESHOLD = 1000; // Example value, adjust as needed mapping(address => uint256) public accumulatedDust;

function sweepToCaller() public { 
    _assertOwner(); 
    
    uint256 ebtcBal = ebtcToken.balanceOf(address(this)); 
    uint256 collateralBal = stETH.sharesOf(address(this));

    if (ebtcBal > 0) {
        if (ebtcBal < DUST_THRESHOLD) {
            accumulatedDust[address(ebtcToken)] += ebtcBal;
        } else {
            ebtcToken.transfer(msg.sender, ebtcBal);
        }
    }
    
    if (collateralBal > 0) {
        if (collateralBal < DUST_THRESHOLD) {
            accumulatedDust[address(stETH)] += collateralBal;
        } else {
            stETH.transferShares(msg.sender, collateralBal);
        }
    }
    

    function sweepAccumulatedDust(address token) public { 
        _assertOwner(); 
        
        uint256 amount = accumulatedDust[token]; 
        require(amount > 0, "No dust to sweep"); 
        accumulatedDust[token] = 0; IERC20(token).transfer(msg.sender, amount); 
    }
```

**_Alternatively_** 

Modify the `sweepToCaller` function to ensure all tokens are swept, considering even minimal residual balances
```solidity
function sweepToCaller() public {
    _assertOwner();
    uint256 ebtcBal = ebtcToken.balanceOf(address(this));
    uint256 collateralBal = stETH.sharesOf(address(this));

    if (ebtcBal > 0) {
        ebtcToken.transfer(msg.sender, ebtcBal);
    }
    if (collateralBal > 0) {
        stETH.transferShares(msg.sender, collateralBal);
    }

    // Check for any residual balances and attempt another sweep if necessary
    uint256 residualEbtcBal = ebtcToken.balanceOf(address(this));
    uint256 residualCollateralBal = stETH.sharesOf(address(this));

    if (residualEbtcBal > 0 || residualCollateralBal > 0) {
        if (residualEbtcBal > 0) {
            ebtcToken.transfer(msg.sender, residualEbtcBal);
        }
        if (residualCollateralBal > 0) {
            stETH.transferShares(msg.sender, residualCollateralBal);
        }
    }
}
```
