# Vulnerability details

## Impact
Considering that the scale of funds in this protocol is increasing, the referral reward is also a considerable amount. Since the referral account is not properly set, Lido’s referral rewards will be lost.
## Proof of Concept

When users need to obtain eBTC within this protocol, they need to use stETH as collateral. A significant portion of this process may involve transferring ETH or WETH to the protocol, then staking it with Lido via the _depositRawEthIntoLido function to retrieve stETH. The ETH staking with Lido can be done either through the submit() function or by directly transferring ETH via a call. However, by using the submit() function and entering a referral address parameter, that address can earn referral rewards from Lido. The _depositRawEthIntoLido function does not do this, resulting in a loss of rewards.
