# Vulnerability details

## Proof of Concept
The code uses an explicit casting to uint128 when adding to state.protocolFee. This can cause truncation if delta is greater than 2^128 - 1.

## Recommended Mitigation Steps
Use SafeCast to convert delta to uint128 before adding :

`state.protocolFee += SafeCast.toUint128(delta);`
