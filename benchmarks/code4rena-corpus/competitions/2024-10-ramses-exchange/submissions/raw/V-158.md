# Vulnerability details

## Proof of Concept
Immutable Variables Exposure: The contract uses immutable variables for critical addresses. If any of these addresses are set incorrectly in the constructor, they cannot be changed later.
Example:
If the nfpManager is set incorrectly:
constructor(address _nfpManager, ...) {
    nfpManager = _nfpManager; // If incorrect, cannot be changed later
}

Impact: This can lead to situations where the factory cannot operate correctly due to invalid contract addresses, resulting in locked funds or an inability to deploy gauges.

## Recommended Mitigation Steps
1. Introduce validation during the constructor execution to ensure all addresses are correct.
2. Consider mechanisms for updating addresses if necessary (though this contradicts the immutable purpose).
