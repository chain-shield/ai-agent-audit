# Vulnerability details

## Proof of Concept
According to the [Docs](https://github.com/code-423n4/2024-10-ramses-exchange/blob/4a40eba36bc47eba8179d4f6203a4b84561a4415/contracts/CL/core/libraries/PoolStorage.sol#L16), the token protocol fee is a percentage of the fee calculated, thus:
```solidity
/// @dev the current protocol fee as a percentage of the swap fee taken on withdrawal
/// @dev represented as an integer denominator (1/x)%
    uint8 feeProtocol;
``` 
The key word here is **percentage**. For instance, when calculating the token protocol fee during a [swap](https://github.com/code-423n4/2024-10-ramses-exchange/blob/4a40eba36bc47eba8179d4f6203a4b84561a4415/contracts/CL/core/RamsesV3Pool.sol#L539-L546), the calculation used is:
```solidity
/// @dev if the protocol fee is on, calculate how much is owed, decrement feeAmount, and increment protocolFee
            if (cache.feeProtocol > 0) {
                unchecked {
                    uint256 delta = (step.feeAmount * cache.feeProtocol) / 100;
                    step.feeAmount -= delta;
                    state.protocolFee += uint128(delta);
                }
            }
```
This mechanism is not used when [loan flashing](https://github.com/code-423n4/2024-10-ramses-exchange/blob/4a40eba36bc47eba8179d4f6203a4b84561a4415/contracts/CL/core/RamsesV3Pool.sol#L711-L721): 
```solidity
uint8 feeProtocol = $.slot0.feeProtocol;
            if (paid0 > 0) {
                uint256 pFees0 = feeProtocol == 0 ? 0 : paid0 / feeProtocol;
                if (uint128(pFees0) > 0) $.protocolFees.token0 += uint128(pFees0);
                $.feeGrowthGlobal0X128 += FullMath.mulDiv(paid0 - pFees0, FixedPoint128.Q128, _liquidity);
            }
            if (paid1 > 0) {
                uint256 pFees1 = feeProtocol == 0 ? 0 : paid1 / feeProtocol;
                if (uint128(pFees1) > 0) $.protocolFees.token1 += uint128(pFees1);
                $.feeGrowthGlobal1X128 += FullMath.mulDiv(paid1 - pFees1, FixedPoint128.Q128, _liquidity);
            }

```
Here, the feeProtocol is used as a denominator instead of a percentage. This POC shows that when an amount of 20002n of Token A is loaned, the fee is 10:

```solidity


                it("increases the fee growth by the expected amount", async () => {
                    await flash(20002n, 4004n, other.address);

                    const fees = await pool.fee();
                    (fees/1000000)/6;
                    const [token0ProtocolFees, token1ProtocolFees] =
                        await pool.protocolFees();
                    expect(token0ProtocolFees).to.eq(10);
                    expect(token1ProtocolFees).to.eq(2);
                    console.log(token0ProtocolFees);
                    console.log(token1ProtocolFees);

                    expect(await pool.feeGrowthGlobal0X128()).to.eq(
                        (6n * 2n ** 128n) / expandTo18Decimals(2n),
                    );
                    expect(await pool.feeGrowthGlobal1X128()).to.eq(
                        (11n * 2n ** 128n) / expandTo18Decimals(2n),
                    );
                });

```
When the code is changed as per the recomendation in this report and the same amount is loaned, the fee is 3:

```solidity


                it("correct token feeprotocol", async () => {
                    await flash(20002n, 4004n, other.address);

                    const [token0ProtocolFees, token1ProtocolFees] =
                        await pool.protocolFees();
                    expect(token0ProtocolFees).to.eq(3);

                });
```

Impact- wrong calculation method results in excessive charging of fee.
## Recommended Mitigation Steps
Use the formulae dictated by the Docs and as used during a swap. Change [Ln 713](https://github.com/code-423n4/2024-10-ramses-exchange/blob/4a40eba36bc47eba8179d4f6203a4b84561a4415/contracts/CL/core/RamsesV3Pool.sol#713) to:
```diff
-   uint256 pFees0 = feeProtocol == 0 ? 0 : paid0 / feeProtocol;
+   uint256 pFees0 = feeProtocol == 0 ? 0 : (paid0 * feeProtocol)/100;
```
Also change [Ln 718](https://github.com/code-423n4/2024-10-ramses-exchange/blob/4a40eba36bc47eba8179d4f6203a4b84561a4415/contracts/CL/core/RamsesV3Pool.sol#L718):
```diff
-  uint256 pFees1 = feeProtocol == 0 ? 0 : paid1 / feeProtocol;
+  uint256 pFees1 = feeProtocol == 0 ? 0 : (paid1 * feeProtocol) / 100;
```
