# Vulnerability details

## Proof of Concept
The two getPeriodReward() uses different way of calcuating positionHash, so one of them must be wrong.

First one: 

```javascript
       bytes32 _positionHash = positionHash(
            owner,
            index,
            tickLower,
            tickUpper
        );

```


Second one: 

```javascript
bytes32 _positionHash = positionHash(
            address(_nfpManager),
            tokenId,
            tickLower,
            tickUpper
        );
```


This is a serious problem, since that means it will not correctly retrieve the rewards. So  I mark this as a HIGH.
