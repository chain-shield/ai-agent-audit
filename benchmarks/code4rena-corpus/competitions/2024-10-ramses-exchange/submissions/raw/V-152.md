# Vulnerability details

## Proof of Concept
Immutable Parameters Structure Risks: The Parameters struct in createPool is populated and then deleted, making it susceptible to exploitation if execution is halted after population but before deletion. A paused state would expose parameters to unintended access or manipulation.

Impact: If an attacker gains access to Parameters during a paused state, they could potentially redirect the deployment address or inject unintended values, resulting in potential financial loss.

## Recommended Mitigation Steps
Initialize Parameters only when needed and avoid leaving temporary states open for extended periods. Alternatively, use a local variable instead of a contract-level struct to eliminate the need for deletion.
example:
// Refactor by using local variables:
function createPool(...) external returns (address pool) {
    address token0 = ...;
    ...
}
