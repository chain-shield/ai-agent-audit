# Vulnerability details

•	Proof of Concept:
An attacker could call setPoolFeeProtocolBatch with mismatched array lengths.
For instance, they could provide 3 pool addresses in pools but only 2 fee protocols in _feeProtocols.
This would cause the loop to attempt to access an element outside the bounds of the _feeProtocols array, leading to a revert or potentially unexpected behavior.

Recommended Mitigation: Add a check at the beginning of the function to ensure both arrays have the same length:
Solidity
require(pools.length == _feeProtocols.length, "Array lengths must match"); 
Use code with caution.
