# Vulnerability details

the [`createPool`](https://github.com/code-423n4/2024-10-ramses-exchange/blob/4a40eba36bc47eba8179d4f6203a4b84561a4415/contracts/CL/core/RamsesV3Factory.sol#L70-L103) function swaps the `tokenA` and `tokenB`, it does not swap the input price. If the user has fed the price as `tokenA/tokenB`, then the pool can be intialized with the incorrect price due to the function sorting the tokens based on their address.

## Impact
The issue will not cause any damage:
- As long as the deployers are aware of this, they can always input the tokens in the correct order.
- Even if the pool is created, the first swap can fix the price with a dust amount of `mint`, and `swap`

However, if it is unnoticed, and big amounts get invested into the protocol, then they will be swapping on the incorrect price. e.g. instead of ETH trading with 2600 USD, 2600 ETH will trade with 1 USD! Which can create big arbitrage opportunities.

```solidity
// SPDX-License-Identifier: UNLICENSED
pragma solidity ^0.8.13;

import {Test, console} from "forge-std/Test.sol";

import "../RamsesV3Pool.sol";
import "../RamsesV3Factory.sol";
import "../RamsesV3PoolDeployer.sol";

import "../libraries/PoolStorage.sol";

import { IERC20 } from "../lib/openzeppelin-contracts/contracts/token/ERC20/IERC20.sol";

// This is a fork test, running against real tokens
// Run with forge test -vvvv --rpc-url https://eth-mainnet.g.alchemy.com/v2/ALCHEMY_TOKEN --fork-block-number BLOCK_NUMBER --via-ir
contract RamsesTest is Test {

    uint256 INITIAL_FUND = 1e20;

    // System Actors
    AccessManager accessManager = new AccessManager();

    // Factory Contracts
    RamsesV3Factory factory = new RamsesV3Factory(address(accessManager));
    RamsesV3PoolDeployer deployer = new RamsesV3PoolDeployer(address(factory));

    RamsesV3Pool pool;

    IERC20 USDC = IERC20(0xA0b86991c6218b36c1d19D4a2e9Eb0cE3606eB48); // token 0
    IERC20 WETH = IERC20(0xC02aaA39b223FE8D0A0e5C4F27eAD9083C756Cc2); // token 1

    function setUp() public {
        factory.initialize(address(deployer));

        pool = RamsesV3Pool(factory.createPool(address(WETH), address(USDC), 10, (uint160(1e6) << 96)/50)); //SQRT of 1 WETH somewhat equals 2500 USD
    }

    function testThis() public {
        (uint160 price,,,,,,) = pool.slot0();
        console.log(pool.token0()); // Tokens' places are swapped
        console.log(pool.token1());
        console.log(price);
    }
}
```
