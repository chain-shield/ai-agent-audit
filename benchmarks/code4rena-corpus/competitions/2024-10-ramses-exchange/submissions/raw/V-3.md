# Vulnerability details

## Proof of Concept
In Rameses V3 Pool, we will initialize the oracle when we initialize the pool. 
The problem is that we initialize oracle with time =0, this will cause the Observation[0] is initialized with time = 0. This is incorrect. We should initialize this timestamp to block.timestamp.

Ramses provide Oracle, other web3 system will integrate with Ramses's Oracle. They will want to calculate the price via Ramses oracle. If `Observation[0]`'s timestamp is 0, third party web3 system tries to get price via oracle and the `tickCumulative` may be incorrect. This may cause the third party web3 system trigger wrong actions, for example, liquidating users' position which should not be liquidated.
