# Vulnerability details


## Proof of Concept
**DESCRIPTION:**
In the RamsesV3Factory.sol contract, there is an attempt to import `AccessManaged` from `OpenZeppelin`a module that does `not exist` in the OpenZeppelin library. OpenZeppelin provides commonly used access control contracts like `Ownable` and `AccessControl`, but there is no contract called AccessManaged in any version of OpenZeppelin

**IMPACT**:
Security Breach: Malicious actors could compromise the security of the entire protocol by taking advantage of unrestricted access, leading to loss of funds or contract integrity.

## Recommended Mitigation Steps
- Remove the non-existent AccessManaged import from OpenZeppelin.
