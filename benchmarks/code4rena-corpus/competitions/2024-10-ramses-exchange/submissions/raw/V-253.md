# Vulnerability details

1. Function transform
Code Analysis
In the function transform, the line uint32 delta = blockTimestamp - last.blockTimestamp; performs a subtraction inside an unchecked block. Here, underflow could occur if blockTimestamp is less than last.blockTimestamp, resulting in delta wrapping around to a high value, potentially causing unintended behavior downstream.

Vulnerability Level
Severity: Medium
Impact: If underflow occurs, it could lead to a miscalculation of tickCumulative and secondsPerLiquidityCumulativeX128, propagating incorrect values throughout the contract and potentially affecting any logic that relies on accurate cumulative values.

Suggested Mitigation
To mitigate this, add an explicit check outside the unchecked block:

require(blockTimestamp >= last.blockTimestamp, "Block timestamp underflow");

This prevents underflow by ensuring blockTimestamp is never less than last.blockTimestamp, thus maintaining accurate calculations and ensuring cumulative values reflect intended results.
