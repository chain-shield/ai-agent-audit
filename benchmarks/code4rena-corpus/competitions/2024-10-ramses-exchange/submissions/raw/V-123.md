# Vulnerability details

## Summary

**Context:**
When fees are collected from users on swap() and flash() function calls, the protocol charges `feeProtocol`. This `feeProtocol` percentage is sent to the FeeCollector while the remaining is kept for the LPs to claim ([reference](https://discord.com/channels/810916927919620096/1290740440873697320/1293674297616896093)). When pools do not have a specific feeProtocol value, they use the default `feeProtocol` value (currently 80) from the factory.

**Issue:**
The issue is that the swap() and flash() function calls retrieve the `feeProtocol` value from slot0(). This means that if the `feeProtocol` value is updated using the [setFeeProtocol()](https://github.com/code-423n4/2024-10-ramses-exchange/blob/4a40eba36bc47eba8179d4f6203a4b84561a4415/contracts/CL/core/RamsesV3Factory.sol#L119) function, the existing pools continue using the outdated value from slot0(). 

**Impact:**
Due to this, during flash() and swap() calls, the fees would be split incorrectly between the LPs and the FeeCollector, with either the LPs or FeeCollector receiving more or less than intended.

This is also an invariant suggested by the sponsor in the [README](https://github.com/code-423n4/2024-10-ramses-exchange?tab=readme-ov-file#attack-ideas-where-to-focus-for-bugs) - `reward accounting being accurate and not substantially inflated or deflated from reality are crucial`. Since this issue of incorrect fee splits alongside the invariant violation affects all pools relying on the default `feeProtocol` value provided by the protocol, the issue is being submitted as Medium-severity. 

## Proof of Concept

1. Let's assume there is a RamsesV3 pool that uses the default `feeProtocol` value of 80.

```solidity
        /// @dev the initial feeSplit of what is sent to the FeeCollector to be distributed to voters and the treasury
        /// @dev 80% to FeeCollector
        feeProtocol = 80;
```

2. The owner of the factory contract (which is assumed to be a multisig and decentralized governance model over time [as per the README](https://github.com/code-423n4/2024-10-ramses-exchange#all-trusted-roles-in-the-protocol)) decides to update the `feeProtocol` value to 50 using function setFeeProtocol().

```solidity
    /// @inheritdoc IRamsesV3Factory
    function setFeeProtocol(uint8 _feeProtocol) external override restricted {
        require(_feeProtocol <= 100, FTL());
        uint8 feeProtocolOld = feeProtocol;
        feeProtocol = _feeProtocol;
        emit SetFeeProtocol(feeProtocolOld, _feeProtocol);
    }
```

3. Now let's say a swap() or flash() call occurs on the pool. Even though the `feeProtocol` value was updated to 50, the FeeCollector is still allocated 80% of the fee amount (0.8x) and the LPs the remaining 20% (0.2x). This means the LPs receive 30% lesser than intended and the FeeCollector 30% more than intended. This occurs since the swap() and flash() function both retrieve the outdated value of `feeProtocol` from slot0() instead of calling the poolFeeProtocol() function on the factory. 

```solidity
// swap() function
472:    feeprotocol: slot0Start.feeProtocol,

... ...

// flash() function
711:    uint8 feeProtocol = $.slot0.feeProtocol;
```

## Recommended Mitigation Steps
In both the instances below, check if `feeProtocol` is 0 (i.e. the pool was only initialised to rewards LPs). If true, continue the call. If false, retrieve the `feeProtocol` value from [poolFeeProtocol()](https://github.com/code-423n4/2024-10-ramses-exchange/blob/4a40eba36bc47eba8179d4f6203a4b84561a4415/contracts/CL/core/RamsesV3Factory.sol#L164) function present in the factory contract to retrieve the updated default `feeProtocol` value.
```solidity
// swap() function
472:    feeprotocol: slot0Start.feeProtocol,

... ...

// flash() function
711:    uint8 feeProtocol = $.slot0.feeProtocol;
```

Here's a sample fix:
```solidity
// swap() function
        
        uint256 feeProtocol = slot0Start.feeProtocol;
        if (slot0Start.feeProtocol != 0) {
           feeProtocol = factory.poolFeeProtocol();
        }

472:    feeprotocol: feeProtocol,

... ...

// flash() function

711:    uint256 feeProtocol;
        if ($.slot0.feeProtocol != 0) {
           feeProtocol = factory.poolFeeProtocol();
        }
```
