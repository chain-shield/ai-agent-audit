# Vulnerability details

## Proof of Concept
In RamsesV3Pool, we support flashloan feature via function flash(). The contract will charge a part of flashloan fee. And these flashloan fee will be splitted two part. One part belongs to the protocol and the other part belongs to the LP holders.

The problem is that we make the wrong calculation when we distribute the flashloan fees. The variable `$.slot0.feeProtocol`'s meaning is different with Uniswap V3 pool. 
In Rameses, the `feeProtocol` means that the fee's percentage which the protocol will charge. For example: `feeProtocol = 50`, it means that the protocol will take one half of the whole fees.
The fee's split calculation in flash() is as below `uint256 pFees0 = feeProtocol == 0 ? 0 : paid0 / feeProtocol;`. This is incorrect. If the `feeProtocol` is 50, the protocol can only get 1/50 of the fees.
