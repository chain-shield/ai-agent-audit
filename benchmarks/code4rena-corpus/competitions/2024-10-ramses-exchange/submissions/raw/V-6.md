# Vulnerability details

The `RamsesV3Pool.sol` contract utilizes the `Position` library defined in `Position.sol`. Within the `Position` library, there is a function named `_updatePosition` that is causing a _"Stack too deep" compilation error._

The error occurs specifically on line 329 of Position.sol, which is part of the `_updatePosition` function. The line of code causing the error is: [Position.sol#L329](https://github.com/code-423n4/2024-10-ramses-exchange/blob/236e9e9e0cf452828ab82620b6c36c1e6c7bb441/contracts/CL/core/libraries/Position.sol#L329)
```solidity
$.slot0.observationCardinality
```
The _"Stack too deep"_ error happens when the number of local variables and function parameters in a function exceeds the maximum stack depth limit of the Ethereum Virtual Machine (EVM). _In this case, the `_updatePosition` function have a large number of local variables and complex expressions, leading to the stack overflow._

**Here's what causes it**
Is the excessive number of local variables and complex expressions within the `_updatePosition` function. When the function is called, it pushes a large number of elements onto the stack, exceeding the maximum stack depth limit of the EVM.

The EVM has a limited stack size, typically allowing a maximum of 1024 elements to be pushed onto the stack. When a function tries to push more elements than the limit, it results in a stack overflow, causing the "Stack too deep" error.

**Here's how likely it is to happen**
Is deterministic and will occur every time the `RamsesV3Pool` contract is compiled using the Solidity compiler version 0.8.26 or higher. As long as the `_updatePosition` function remains unchanged with its current complexity, the error will persist.

## Impact
The "Stack too deep" error prevents the successful compilation of the RamsesV3Pool.sol contract. As a result, the contract cannot be deployed or used in its current state. This issue affects the functionality of the Ramses V3 pool system and needs to be addressed to ensure the proper operation of the system.
