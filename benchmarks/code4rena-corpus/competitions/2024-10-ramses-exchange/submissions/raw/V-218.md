# Vulnerability details

The `refundETH()` function is  to be called by anyone who has interacted with the  contract and may have leftover ETH.  

## Proof of Concept
When  Eth is sent to the contract any one  can call the function to refund Eth . 
``` 
function refundETH() external payable override {
// if contract balance > 0         
if (address(this).balance > 0) TransferHelper.safeTransferETH(msg.sender, address(this).balance);
    } 
```

When called , it transfers every balance of Eth in the contract to the caller  `msg.sender`

An attacker can  deploy a contract to call the function since its an external contract and there is no access control  whenever the contract has received fund. 

## Recommended Mitigation Steps
Ensure that excess eth can only be refunded  by the sender
