# Vulnerability details

## Proof of Concept
When deleting a struct in Solidity, it will not delete the mapping within it. The delete keyword in Solidity sets every field in the struct to its default value.

However, for mappings, the delete keyword has no effect. This is because mappings are implemented as hash tables and the Ethereum Virtual Machine does not keep track of which keys have been used in the mapping. As a result, it doesn't know how to "reset" a mapping. Therefore, when you delete a struct, the mapping within it will still retain its old data.

This can lead to potential security issues. For example, let’s say you have a struct that contains sensitive data within a mapping. If you delete the struct assuming that all data within it will be erased, the data in the mapping will still persist, potentially leading to unintended access or misuse.

In The storage struct below, there is a mapping for ticks mapped to a tick.

```
 struct PoolState {
        ...
  ==>   mapping(int24 => TickInfo) _ticks;
        ...
    }
```
The TickInfo struct is as below, which has its own mapping separated into periods

```
  struct TickInfo {
    ...
    mapping(uint256 => uint256) periodSecondsPerLiquidityOutsideX128;
}
```

The clear function in the `Tick` library deletes the period under the tick and then deletes the tick from the ticks map per the below code snippet.

```
    function clear(mapping(int24 => TickInfo) storage self, int24 tick, uint256 period) internal {
        delete self[tick].periodSecondsPerLiquidityOutsideX128[period];
        delete self[tick];
    }
```
But, if there were multiple periods inserted into the TickInfo for a given tick, then all those periods will not be cleared from the storage and hence they will remain accessible. 

Any reference to such periods will return stale data.

## Recommended Mitigation Steps
If tick should have only one period, then remove mapping and store it in a variable. If there are multiple periods for a tick, then the `clear` function implementation is buggy since it does not clear all the periods for the tick being deleted.
