# Vulnerability details

``` 
   function initialize(address _ramsesV3PoolDeployer) external restricted {
@>      require(ramsesV3PoolDeployer == address(0));
        ramsesV3PoolDeployer = _ramsesV3PoolDeployer;

## Description:
The `initialize` function lacks proper validation for the `ramsesV3PoolDeployer` argument, allowing it to be called multiple times. This absence of a one-time initialization check means that the `deployer` address can be reset or overwritten, creating an opening for a malicious actor. An attacker could exploit this by calling the function repeatedly with a different address, effectively hijacking control over pool deployment.

## Impact:
This vulnerability can allow an attacker to deploy unauthorized and potentially malicious pools. Such a breach compromises the overall security and integrity of the system, leading to severe consequences such as the creation of pools with malicious intent, which can affect users and the system as a whole.

## Proof of Concept:
If an attacker manages to repeatedly call the `initialize` function with a different `ramsesV3PoolDeployer` address, they can continuously overwrite the `deployer` and take control of the pool deployment process, enabling them to create pools without authorization.

```solidity
//POC Example
function initialize(address newDeployer) external {
    require(ramsesV3PoolDeployer == address(0), "Deployer already set");
    ramsesV3PoolDeployer = newDeployer;
}
// No mechanism here prevents repeated calls and resetting of the deployer
```

## Tools Used:
Manual review

## Recommended Mitigation:
Implement an explicit validation check to ensure that the initialize function can only be called once. This can be done by introducing a `bool` flag that is set to true once the `deployer` is initialized, ensuring subsequent calls are blocked.

``solidity
bool isInitialized = false;

function initialize(address newDeployer) external {
    require(!isInitialized, "Already initialized");
    require(ramsesV3PoolDeployer == address(0), "Deployer already set");
    ramsesV3PoolDeployer = newDeployer;
    isInitialized = true;
}
```
