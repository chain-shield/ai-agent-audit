# Vulnerability details

## Proof of Concept
**DESCRIPTION:**
Description:
In the `Oracle.sol` contract, When the oracle is first written to, especially if called immediately after its `initialization`, it may try to read data from an uninitialized observation array. This can occur because the implementation assumes that the `last observation` is valid without performing an explicit check on the initialization state of the oracle. If the oracle's state is not properly set up before the first write operation, it can lead to unintended consequences, such as reading default or garbage values, thereby compromising the reliability of the data it provides.
**IMPACT:**
Incorrect Data Reading: If the oracle attempts to read from an uninitialized observation array, it may produce invalid or erroneous results, leading to unreliable oracle outputs.

## Recommended Mitigation Steps
- To prevent the read of uninitialized data, implement a check to ensure that the observation array is initialized before any read or write operations are performed
```javascript 
 require(isInitialized(), "Oracle is not initialized");
```
