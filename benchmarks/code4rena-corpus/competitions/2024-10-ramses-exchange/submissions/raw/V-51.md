# Vulnerability details

Anyone can invoke the `mint( )` function to add  LP position  within their desired range. The function depends on _modifyPosition( )   to calculate  `amount0Int`  and `amount1Int` to be transferred to the pool. However, it depends on `slot0` price, which can be manipulated, potentially leading to the LP position being out of the current range and resulting in a loss of yield.

## Proof of Concept
Before  `IUniswapV3MintCallback(msg.sender).uniswapV3MintCallback()` is called  in the mint function,  minter positions are updated and modified through the function `_modifyPosition( )`
Note that  `index`,  `tickLower` and  `tickUpper` are user supplied values  as shown below :

## Impact
Attackers can manipulate the `slot0` price data points to cause loss of yield for the protocol.

## Recommended Mitigation Steps
It’s recommend to use TWAP price instead of slot0 price to get the current price.
