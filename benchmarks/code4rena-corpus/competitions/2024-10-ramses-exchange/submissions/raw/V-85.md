# Vulnerability details

## Proof of Concept
The gauge/FeeCollector.sol contract can be compiled in versions above 0.8.13, but the use of customError in the require function is only allowed in the 0.8.26 (Pipeline IR) and 0.8.27 (Pipeline Legacy) compilers.

So using customError in require() will have no effect, even if the contract is compiled in any version below 0.8.26.

This would allow the onlyTreasury modifier to have no effect. Thus causing an Access Control vulnerability.

modifier onlyTreasury() {
        require(msg.sender == treasury, Unauthorized());
        _;
    }


## Recommended Mitigation Steps
Consider changing the build version of the contract.
