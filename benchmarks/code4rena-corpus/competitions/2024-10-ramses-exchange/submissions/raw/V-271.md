# Vulnerability details

## Proof of Concept
The code attempts to handle the case where a tick is crossed for the first time in a new period (periodSecondsPerLiquidityOutsideBeforeX128 == 0). In this scenario, it should calculate periodSecondsPerLiquidityOutsideX128 based on the seconds per liquidity accumulated since the beginning of the period. However, the current implementation incorrectly uses the endSecondsPerLiquidityPeriodX128 from the previous period, leading to an inaccurate value.

## Impact:

Inaccurate Fee Distribution: The periodSecondsPerLiquidityOutsideX128 value is likely used to calculate fees for liquidity providers. An inaccurate value will lead to incorrect fee distributions, potentially shortchanging some users while overpaying others.

## Recommended Mitigation Steps
The solution is to calculate periodSecondsPerLiquidityOutsideX128 based on the seconds per liquidity accumulated since the start of the current period. Here's the corrected code:
```
if (tick <= periodStartTick && periodSecondsPerLiquidityOutsideBeforeX128 == 0) {
    // Calculate seconds elapsed in the current period
    uint32 secondsElapsed = time - (period * 1 weeks);

    periodSecondsPerLiquidityOutsideX128 =
        secondsPerLiquidityCumulativeX128 -
        endSecondsPerLiquidityPeriodX128 -
        ((uint160(secondsElapsed) << 128) / ($.liquidity > 0 ? $.liquidity : 1)); // Subtract seconds elapsed in the current period
}
```
1. Calculate Elapsed Time: We calculate secondsElapsed by subtracting the start time of the current period (period * 1 weeks) from the current block timestamp (time).

2. Adjust for Elapsed Time: We subtract the seconds per liquidity accumulated during the elapsed time (secondsElapsed) from the difference between secondsPerLiquidityCumulativeX128 (cumulative value up to the current block) and endSecondsPerLiquidityPeriodX128 (cumulative value up to the end of the previous period). This adjustment ensures that periodSecondsPerLiquidityOutsideX128 accurately reflects the seconds per liquidity accumulated only within the current period.
