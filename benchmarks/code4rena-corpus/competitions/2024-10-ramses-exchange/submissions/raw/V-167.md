# Vulnerability details

## Proof of Concept
Insufficient Access Controls: Functions in GaugeV3.sol like notifyRewardAmount and addRewards allow reward notifications or additions without comprehensive access control. This can enable unauthorized users to adjust rewards or manipulate contract states if they have partial permissions.

Affected Functions:
notifyRewardAmount
addRewards
 (PoC):If an attacker gains control of an account with partial permissions (e.g., voter), they could add arbitrary rewards to the contract:
// Malicious call to add unauthorized rewards
GaugeV3 gauge = GaugeV3(contractAddress);
gauge.addRewards(address(maliciousRewardToken));
This allows unauthorized tokens to be added as rewards, which could harm the reward distribution system.
## Recommended Mitigation Steps
1. Implement role-based access control using OpenZeppelin’s AccessControl or Ownable to restrict functions like notifyRewardAmount and addRewards to specific, trusted accounts.
2. Restrict the addRewards function to ensure only vetted tokens can be added as rewards.
