# Vulnerability details

## Proof of Concept

Currently the function `initializeSecondsStart()` initializes `secondsPerLiquidityPeriodStartX128` for a period:

https://github.com/code-423n4/2024-10-ramses-exchange/blob/main/contracts/CL/core/libraries/Position.sol#L447-449
```
   position
            .periodRewardInfo[secondsInRangeParams.period]
            .secondsPerLiquidityPeriodStartX128 = secondsPerLiquidityPeriodIntX128;
```

The problem is that this function is only called when minting a position meaning it will be initialized only for the first period:

https://github.com/code-423n4/2024-10-ramses-exchange/blob/main/contracts/CL/core/libraries/Position.sol#L387-399
```
 if (!position.periodRewardInfo[period].initialized || position.liquidity == 0) {
            initializeSecondsStart(
                position,
                PositionPeriodSecondsInRangeParams({
                    period: period,
                    owner: params.owner,
                    index: params.index,
                    tickLower: params.tickLower,
                    tickUpper: params.tickUpper,
                    _blockTimestamp: params._blockTimestamp
                }),
                secondsPerLiquidityPeriodX128
            );

```

As you can see here, the check makes sure if the reward info for a period is not initialized and then calls `initializeSecondsStart()`. Therefore, it creates a situation where start seconds are only initialized for the first period meaning they will always be 0 when used in other functions making `secondsPerLiquidityInsideX128` being incorrectly calculated:

https://github.com/code-423n4/2024-10-ramses-exchange/blob/main/contracts/CL/core/libraries/Position.sol#L253-257
```
        secondsPerLiquidityInsideX128 = uint160(
            int160(secondsPerLiquidityInsideX128) - secondsPerLiquidityPeriodStartX128
        );

        RewardInfo storage rewardInfo = $.positions[_positionHash].periodRewardInfo[params.period];

```

## Recommended Mitigation Steps

Call `initializeSecondsStart()` for every period after the first one (when the period changes).
