# Vulnerability details

## Proof of Concept
Approval Reuse Vulnerability: collectProtocolFees() approves tokens for transfer without first setting previous approvals to zero. This oversight could be exploited if feeDist address changes to a malicious contract.
this can be seen here in the function: 
token0.approve(address(feeDist), amount0); // Unchecked re-approval
feeDist.notifyRewardAmount(address(token0), amount0);

Impact: An attacker could use the approved tokens for unauthorized withdrawals, leading to financial loss for the protocol.
## Recommended Mitigation Steps
Reset the allowance to zero before setting it to a new value to prevent unexpected re-approval issues:
token0.approve(address(feeDist), 0);
token0.approve(address(feeDist), amount0);
