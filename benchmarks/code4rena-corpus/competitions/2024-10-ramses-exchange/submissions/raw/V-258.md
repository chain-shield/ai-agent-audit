# Vulnerability details

## Proof of Concept
**DESCRIPTION:**
In the `RamsesV3Pools.sol contract`, the `increaseObservationCardinalityNext` function allows users to increase the `observationCardinalityNext` value. However, there is no explicit `upper limit` imposed on how large this value can be set. Without such a restriction, users could set extremely `high values`for observationCardinalityNext, potentially causing the contract to run out of gas during storage operations, particularly when expanding the size of the observation array.

**IMPACT:**
This can lead to `gas exhaustion` during function execution, making the contract impractical to use or causing denial-of-service (DoS) vulnerabilities. Additionally, extreme values could significantly increase gas costs for normal users interacting with the contract, negatively impacting usability.

## Recommended Mitigation Steps
- Define a reasonable upper bound for observationCardinalityNext to prevent extreme values from being set.
