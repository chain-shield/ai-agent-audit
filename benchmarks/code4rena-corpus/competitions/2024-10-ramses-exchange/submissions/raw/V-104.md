# Vulnerability details

## Proof of Concept
Reason for Race Condition risk is due to the fact that the `initialize()` lack access control

Observing the code using the link below
https://github.com/code-423n4/2024-10-ramses-exchange/blob/236e9e9e0cf452828ab82620b6c36c1e6c7bb441/contracts/CL/gauge/FeeCollector.sol#L30-L41
It can be seen that anyone can call the `initialize()` because there is no access control restricting it
Even though, the `initialize()` function uses the initializer modifier, this modifier only allows that this function can be called only once but does not restrict who can call it first.

Non-upgradeable Contract:

Since this is a non-upgradeable contract as specified in the ReadMe, using initialize() without proper access control can pose serious security risk. The purpose of `initialize()` is generally to set up the contract’s initial state after deployment, but without proper access control anyone can race to do this.

Race Condition:

If a malicious actor notices the contract has been deployed but not yet initialized, they could call `initialize()` before the rightful deployer. In doing so, they could set themselves as the treasury or assign other critical roles like the voter.
Once the `initialize()` function has been called, no one else (including the legitimate deployer) would be able to call it again, locking the contract in an initialized state with potentially malicious or incorrect parameters.

Impact of the Race Condition:
Hijacking the Protocol: The protocol can be hijacked if a malicious actor manages to call initialize() before the intended deployer, they can gain control of critical contract parameters like the treasury and voter addresses. This could allow them to redirect funds, manipulate voting systems, or otherwise control the contract in unintended ways.

Loss of Ownership: The legitimate deployer will lose control over the protocol, as important roles could be assigned to unauthorized addresses.



## Recommended Mitigation Steps
Use Constructor for non-upgradeable contract, if the `initialize()`function must be used then implement access control
