# Vulnerability details

## Proof of Concept
When initializing the `FeeCollector` contract with the `initialize` function, no input validation was done to check the value of certain important addresses such as `treasury`. If this variable is set to `address(0)`, all funds sent to it will be lost and can never be recovered:
```solidity
    function initialize(
        address _treasury,
        address _voter
    ) external initializer {
        // @audit lack of input validation
        treasury = _treasury;
        voter = IVoter(_voter);
    }
```

## Impact
Risk of loss of funds when `treasury=address(0)`.

## Recommended Mitigation Steps
```diff
    function initialize(
        address _treasury,
        address _voter
    ) external initializer {
+       require(_treasury != address(0), "Invalid treasury address");
        treasury = _treasury;
        voter = IVoter(_voter);
    }
```
