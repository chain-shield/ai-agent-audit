# Vulnerability details

## Proof of Concept
In the notifyRewardAmount() function, the ERC20 transferFrom function is used without checking whether it returns true or false. Some non-standard ERC20 tokens do not revert on failure and instead return false, which can lead to missed reward transfers.

```
IERC20(token).safeTransferFrom(msg.sender, address(this), amount);

```
If the token does not successfully transfer, it will not revert, and the contract could incorrectly assume the rewards were transferred.

## Recommended Mitigation Steps

To mitigate this issue, add a check to ensure that the transfer succeeded by verifying the return value of the safeTransferFrom() call. This can be done as follows:

```
bool success = IERC20(token).safeTransferFrom(msg.sender, address(this), amount);
require(success, "Transfer failed");

```
