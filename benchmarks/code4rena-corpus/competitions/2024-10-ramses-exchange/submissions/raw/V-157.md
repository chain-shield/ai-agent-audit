# Vulnerability details

## Proof of Concept
Access Control Vulnerability: The createGauge function has a simple access control mechanism that only allows the voter address to create new gauges. If this address is compromised or incorrectly assigned, anyone can deploy gauges without authorization.
Example:
If the voter address were compromised, an attacker could execute:
clGaugeFactory.createGauge(attackerPoolAddress);
This would create a malicious gauge at attackerPoolAddress.

Impact: An attacker could create arbitrary gauges, potentially siphoning off funds, manipulating liquidity incentives, or even deploying malicious contracts that mimic legitimate gauges, causing financial loss to users and damaging the protocol's integrity.

## Recommended Mitigation Steps
Implement a more robust access control mechanism, such as:

1. Multi-signature wallets for critical functions.
2. Role-based access control to delegate specific permissions to trusted addresses
