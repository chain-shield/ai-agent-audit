# Vulnerability details

## Proof of Concept
Insufficient Input Validation: The tokenURI function uses external contract data without performing comprehensive checks on input values. For instance, it assumes the tokenId is valid without verifying that it exists in the positionManager.

Impact: An invalid tokenId could result in unexpected behavior or revert transactions, leading to denial of service.

Proof of Concept:
function tokenURI(INonfungiblePositionManager positionManager, uint256 tokenId) external view override returns (string memory) {
    // No check if tokenId is valid
    (address token0, address token1) = positionManager.positions(tokenId);
    // If tokenId does not exist, this could lead to unexpected results.
}

Here’s an example of code that demonstrates the Insufficient Input Validation vulnerability:
// SPDX-License-Identifier: MIT
pragma solidity ^0.8.20;

contract SimpleAuction {
    address public highestBidder;
    uint256 public highestBid;
    mapping(address => uint256) public bids;

    // Start an auction with a minimum bid
    function bid() external payable {
        // Insufficient input validation for bid amount
        require(msg.value > highestBid, "Bid must be higher than current highest bid");
        
        // Refund the previous highest bidder
        if (highestBidder != address(0)) {
            payable(highestBidder).transfer(highestBid);
        }

        highestBidder = msg.sender;
        highestBid = msg.value;
        bids[msg.sender] += msg.value;
    }

    // Function to withdraw bids
    function withdraw() external {
        uint256 amount = bids[msg.sender];
        require(amount > 0, "No bids to withdraw");
        
        // Insufficient input validation here
        bids[msg.sender] = 0;
        payable(msg.sender).transfer(amount);
    }
}
An attacker could call the bid function with invalid values or exploit the withdraw function to drain funds without proper checks.

## Recommended Mitigation Steps
1. Add checks to verify the existence of the tokenId.
2. Handle potential errors gracefully.
