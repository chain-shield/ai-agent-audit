# Vulnerability details

## Sommary
The logic explained in the v3 documentation is not the same as that implemented in the `FeeCollector`contract.

## Proof of Concept
In fact, as mentioned in the documentation : `Ramses V3 (the codebase for this competition) refines our existing contracts from our V2 deployment, removing proxies`. Ramses V3 no longer includes the proxy because the removal of upgreadability is part of the migration from `V2` to `V3`. However, the `FeeCollector` contract has been implemented to be an upgreadable contract because it uses the `initialize` function and inherits from the OZ proxy library which is part of the upgreadable process. It also calls the `_disableInitializers` function in its constructor, which is one of the main functions required to robustly implement the upgreable functionality:
```solidity
    contract FeeCollector is Initializable, IFeeCollector {
        
        /// ... The other code

        constructor() {
            // @audit use of upgradable tools in non upgradable contract
@>          _disableInitializers();
        }

        // @audit use of upgradable tools in non upgradable contract
        /// @dev initializes the contract
@>      function initialize(
            address _treasury,
            address _voter
        ) external initializer {
            treasury = _treasury;
            voter = IVoter(_voter);
        }

        /// ... The other code

    }
```

## Impact
Unnecessary Complexity: Upgradable tools like `Initializable` and the `initializer` modifier are specifically designed for upgradable contracts using proxy patterns. In a non-upgradable contract, using these tools adds complexity that isn't required, as constructors can handle initialization directly. 
This increases the risk of mistakes during contract deployment, such as forgetting to call the `initialize` function, which can leave the contract in an uninitialized state and potentially vulnerable.

## Recommended Mitigation Steps
Use only `constuctor` to initialise all variables in the contract.

```diff
    contract FeeCollector is Initializable, IFeeCollector {
        
        /// ... The other code

        constructor(
+           address _treasury,
+           address _voter
        ) {
-           _disableInitializers();
+           treasury = _treasury;
+           voter = IVoter(_voter);
        }


-       function initialize(
-           address _treasury,
-           address _voter
-       ) external initializer {
-           treasury = _treasury;
-           voter = IVoter(_voter);
-       }

        /// ... The other code

    }
```
