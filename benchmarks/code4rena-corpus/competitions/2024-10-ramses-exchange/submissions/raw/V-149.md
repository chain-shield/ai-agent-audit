# Vulnerability details

## Proof of Concept
Uninitialized Values in Protocol Settings: In setPoolFeeProtocol and setPoolFeeProtocolBatch, if _feeProtocol is set to 0, the function defaults to using the feeProtocol value, which can lead to unintended fee settings if feeProtocol is altered unexpectedly.

Impact: If the feeProtocol value changes without initializing each pool specifically, fees may inadvertently default to an unintended global setting. This could lead to loss of revenue, unbalanced fees, and reduced trust among liquidity providers.

## Recommended Mitigation Steps
Add explicit initialization for each pool and avoid using a global default. If 0 is provided, require explicit confirmation.
example:
// Example check:
require(_feeProtocol > 0, "Fee protocol cannot be zero");
