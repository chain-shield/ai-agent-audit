# Vulnerability details

## Proof of Concept
By passing 0 as the time parameter when initializing the Oracle contract the first observation will be created with a timestamp of 0 which will lead to wrong fee calculations in all of the methods in which it is used.

## Recommended Mitigation Steps
Use the method _blockTimestamp() instead of passing 0:
```
- (uint16 cardinality, uint16 cardinalityNext) = Oracle.initialize($.observations, 0);
+ (uint16 cardinality, uint16 cardinalityNext) = Oracle.initialize($.observations, _blockTimestamp());
```
