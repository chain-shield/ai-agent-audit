# Vulnerability details

## Description:
The RamsesV3 contract suite demonstrates inconsistent use of basis points (BPS) when calculating and setting percentages across different functions. There are at least three different standards observed:

-10,000 BPS = 100% (standard convention where 1 BPS = 0.01%)
-100 BPS = 100% (interpreted as a percentage directly out of 100)
-1,000,000 BPS = 100% (implying 1 BPS = 0.0001%)
This lack of uniformity can lead to serious miscalculations in fee adjustments, especially in functions that handle sensitive financial operations. For instance:

-In `setTreasuryFees`, BASIS is defined as 10,000, making 100% equal to 10,000 BPS.
-In `setFeeProtocol`, the maximum `_feeProtocol` is 100, suggesting that the percentage is calculated out of 100.
-In `enableTickSpacing`, `initialFee` is capped at 1,000,000, representing 1000%, which deviates from the other standards.
## Impact
The inconsistent usage of BPS standards across contracts and functions can result in miscalculations when configuring or interacting with fees, potentially allowing incorrect fee setups. This may lead to unintended treasury drain, incorrect fee distributions, or excessive values, particularly in user-settable parameters where input values are unchecked or ambiguous. Misinterpreting fee values could expose the contract to financial risks, especially if the difference in BPS ranges goes unnoticed by developers, operators, or external integrators.
## Proof of Concept
Example 1 (10,000 BPS standard):
```
function setTreasuryFees(uint256 _treasuryFees) external override onlyTreasury {
    require(_treasuryFees <= BASIS, FTL());  // BASIS defined as 10,000 BPS
    treasuryFees = _treasuryFees;
    emit TreasuryFeesChanged(treasuryFees, _treasuryFees);
}
```
Example 2 (100 BPS standard):
```
function setFeeProtocol(uint8 _feeProtocol) external override restricted {
    require(_feeProtocol <= 100, FTL());  // Assumes 100% = 100
    feeProtocol = _feeProtocol;
    emit SetFeeProtocol(feeProtocolOld, _feeProtocol);
}
```
Example 3 (1,000,000 BPS standard):
```
function enableTickSpacing(int24 tickSpacing, uint24 initialFee) external override restricted {
    require(initialFee < 1_000_000, FTL());  // Assumes 100% = 1,000,000
    tickSpacingInitialFee[tickSpacing] = initialFee;
    emit TickSpacingEnabled(tickSpacing, initialFee);
}
```
## Recommended Mitigation Steps
- Standardize BPS Across Contracts: Establish a single basis point standard (e.g., 10,000 BPS for 100%) across all contracts and document this standard clearly.
