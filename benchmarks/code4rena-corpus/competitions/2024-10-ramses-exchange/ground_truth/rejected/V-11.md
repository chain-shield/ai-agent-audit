## Brief Summary

The `cachePeriodEarned` function checks if the period data has been written to storage using the `periodAmountsWritten` mapping. If it hasn't been written and `caching` is `false`, it calculates the amount but doesn't store it. This leads to inconsistencies between cached and actual earned rewards.
