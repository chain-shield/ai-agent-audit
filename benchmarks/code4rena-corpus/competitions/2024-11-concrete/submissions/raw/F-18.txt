S-174
`ConcreteMultiStrategyVault::pullFundsFromSingleStrategy` doesn't check for 0 strategy balance, forcing `changeAllocations` to revert sometimes
0xAlix2
82
Sufficient
383d ago
Finding description and impact

Funds are deposited into multiple strategies according to certain allocations set by the admin. The admin has a way to redistribute these funds into the strategies according to new allocations, this could be done using changeAllocations, while passing redistribute as true. However, pullFundsFromSingleStrategy doesn't check if the vault has some funds in the strategy before withdrawing from it, https://github.com/code-423n4/2024-11-concrete/blob/main/src/vault/ConcreteMultiStrategyVault.sol#L930C14-L938. Redeemding/withdrawing 0 shares/assets will revert, https://github.com/code-423n4/2024-11-concrete/blob/main/src/strategies/StrategyBase.sol#L163.

This is okay for now as all strategies should have funds after the first deposit, however, this poses a DOS issue when the admin wants to add a new strategy. The following are the steps taken by the admin to add a new strategy:

addStrategy is called while passing the new index, replace as false, and 0 allocations for that new strategy. Because passing >0 allocation would revert https://github.com/code-423n4/2024-11-concrete/blob/main/src/libraries/MultiStrategyVaultHelper.sol#L242-L244.
When the new strategy is added with 0 allocations, changeAllocations is called with redistribute set as true, so the funds are redistributed to all the strategies, including the new one.

However, step 2 above will revert, as it'll try to pull funds from the new strategy (pullFundsFromStrategies will be called to pull from all strategies), which initially has no funds deposited in it.

Recommended mitigation steps

ConcreteMultiStrategyVault::pullFundsFromSingleStrategy:

function pullFundsFromSingleStrategy(uint256 index_) public onlyOwner {
    IStrategy strategy = strategies[index_].strategy;
+   if (strategy.balanceOf(address(this)) == 0) return;
    // slither-disable-next-line unused-return
    if (strategy.getAvailableAssetsForWithdrawal() != strategy.totalAssets()) {
        strategy.withdraw(strategy.getAvailableAssetsForWithdrawal(), address(this), address(this));
        return;
    }
    strategy.redeem(strategy.balanceOf(address(this)), address(this), address(this));
}
