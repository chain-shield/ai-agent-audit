Wrong calculation of protocol fees in `ConcreteMultiStrategyVault::takeFees`
0xAlix2
82
Sufficient
383d ago
Finding description and impact

In ConcreteMultiStrategyVault, the "default" 4626 shares/assets conversion is manipulated to block inflation attacks:

function _convertToShares(uint256 assets, Math.Rounding rounding) internal view override returns (uint256 shares) {
    shares = assets.mulDiv(totalSupply() + 10 ** decimalOffset, totalAssets() + 1, rounding);
}

function _convertToAssets(uint256 shares, Math.Rounding rounding) internal view virtual override returns (uint256) {
    return shares.mulDiv(totalAssets() + 1, totalSupply() + 10 ** decimalOffset, rounding);
}

These functions convert users' balances/shares, whenever they deposit, mint, redeem, or withdraw.
On the other hand, the protocol uses the takeFees modifier to mint some percent of the profit to the fee recipient, https://github.com/code-423n4/2024-11-concrete/blob/main/src/vault/ConcreteMultiStrategyVault.sol#L104-L120:

modifier takeFees() {
    uint256 totalFee = accruedProtocolFee() + accruedPerformanceFee();
    uint256 shareValue = convertToAssets(1e18);
    uint256 _totalAssets = totalAssets();

    if (shareValue > highWaterMark) highWaterMark = shareValue;

    if (totalFee > 0 && _totalAssets > 0) {
        uint256 supply = totalSupply();
        uint256 feeInShare = supply == 0
            ? totalFee
@>          : totalFee.mulDiv(supply, _totalAssets - totalFee, Math.Rounding.Floor);
        _mint(feeRecipient, feeInShare);
    }
    feesUpdatedAt = block.timestamp;
    _;
}

As shown, it converts the fees in assets to shares without the usage of convertToShares, and the issue here is that it is using the default 4626 conversion, which is different from the conversions done for other users.

This results in unfair and wrong calculation of minted shares to the fee recipient.

Proof of Concept

Add the following test in test/ConcreteMultiStrategyVault.t.sol:

function test_wrongFeesCalculation() public {
    uint256 amount = 100e18;

    asset.mint(jimmy, amount);

    vm.startPrank(jimmy);
    asset.approve(address(vault), type(uint256).max);
    vault.deposit(amount, jimmy);
    vm.stopPrank();

    asset.mint(address(vault), amount);

    uint256 expectedFees = vault.accruedProtocolFee() +
        vault.accruedPerformanceFee();
    uint256 expectedFeesInShares = expectedFees.mulDiv(
        vault.totalSupply() + 10 ** vault.decimalOffset(),
        vault.totalAssets() - expectedFees + 1,
        Math.Rounding.Floor
    );

    vault.takePortfolioAndProtocolFees();

    assertNotEq(vault.balanceOf(feeRecipient), expectedFeesInShares);
}
Recommended mitigation steps
modifier takeFees() {
    uint256 totalFee = accruedProtocolFee() + accruedPerformanceFee();
    uint256 shareValue = convertToAssets(1e18);
    uint256 _totalAssets = totalAssets();

    if (shareValue > highWaterMark) highWaterMark = shareValue;

    if (totalFee > 0 && _totalAssets > 0) {
        uint256 supply = totalSupply();
        uint256 feeInShare = supply == 0
            ? totalFee
-           : totalFee.mulDiv(supply, _totalAssets - totalFee, Math.Rounding.Floor);
+           : totalFee.mulDiv(supply + 10 ** decimalOffset, _totalAssets - totalFee + 1, Math.Rounding.Floor);

    }

    _;
}
