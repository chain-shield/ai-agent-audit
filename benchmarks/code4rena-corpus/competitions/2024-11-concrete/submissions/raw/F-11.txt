S-1343
`previewMint()` returns a wrong value
samuraii77
63
Sufficient
383d ago
Finding description and impact

previewMint() returns a wrong value due to not considering the sender might be a fee recipient

Proof of Concept

This is what previewDeposit returns:

    function previewDeposit(uint256 assets_) public view override returns (uint256) {
        uint256 netAssets = assets_ -
            (
                msg.sender != feeRecipient
                    ? assets_.mulDiv(uint256(fees.depositFee), MAX_BASIS_POINTS, Math.Rounding.Floor)
                    : 0
            );
        return _convertToShares(netAssets, Math.Rounding.Floor);
    }

As seen, we consider the msg.sender and return the according value as fee recipients are not charged a fee. If we take a look at previewMint(), we will see that this is not the case there:

    function previewMint(uint256 shares_) public view override returns (uint256) {
        uint256 grossShares = shares_.mulDiv(MAX_BASIS_POINTS, MAX_BASIS_POINTS - fees.depositFee, Math.Rounding.Floor);
        return _convertToAssets(grossShares, Math.Rounding.Floor);
    }

This results in a wrong return value of previewMint().

Recommended mitigation steps

Consider the msg.sender the way you do in previewDeposit(). Alternatively, change previewDeposit() to always account for a fee regardless of the msg.sender as usually such preview functions are not supposed to account for the sender.
