S-156
`setVaultByTokenLimit` and `setTotalVaultsAllowed` will not be usable
0xrex
69
Sufficient
383d ago
Finding description and impact

Functions setVaultByTokenLimit and setTotalVaultsAllowed of the deployment manager contract won't work since the VaultManager owns the contract and there is no function exposed in the vault manager contract to invoke both functions. Thus, setting the total vaults allowed as well as the token limit for each vault will not be possible.

Proof of Concept

The vault manager contract exposes a lot of functions to manage protocol states such as deployNewVault for example which calls deployNewVault of the deployment manager contract:

function deployNewVault(
        ...
    ) external onlyRole(VAULT_MANAGER_ROLE) returns (address newVaultAddress) {
 @>       newVaultAddress = deploymentManager.deployNewVault(id_, data_);
...     
    }

The deployNewVault function of the deployment manager is gated by the onlyOwner modifier which suggests the vault manager would be the owner of the deployment manager

@>   function deployNewVault(bytes32 id_, bytes calldata data_) external onlyOwner returns (address newVaultAddress) {
        ...
    }

However, in the case of setting the vaults by token limits and total vaults allowed, there is no function in the vault manager contract to invoke these in the deployment manager.

Recommended mitigation steps

Expose functions in the vault manager to be able to call the setVaultByTokenLimit and setTotalVaultsAllowed functions.
