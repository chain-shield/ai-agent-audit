S-1034
`ConcreteMultiStrategyVault.mint()` can fail due to rounding up the strategy deposit amount
berndartmueller
00
Sufficient
383d ago
Finding description and impact

ConcreteMultiStrategyVault.mint() immediately allocates the deposited assets into its strategies, based on the strategy allocation percentages.

321: strategies[i].strategy.deposit(
322:     assets.mulDiv(strategies[i].allocation.amount, MAX_BASIS_POINTS, Math.Rounding.Ceil),
323:     address(this)
324: );

However, contrary to deposit() (see line 259), the amount to deposit into the strategy is rounded up (Math.Rounding.Ceil). This can lead to a situation where the user's deposited amount (assets) is less than the total amount of funds allocated to the strategies, causing the strategies[i].strategy.deposit() call to fail when attempting to transfer the assets due to insufficient funds and thus preventing the user from depositing into the ConcreteMultiStrategyVault vault.

Proof of Concept

The following PoC demonstrates how a user can fail to deposit a specific amount of funds into the ConcreteMultiStrategyVault vault due to rounding up the strategy deposit amount.

Copy the following test case to test/ConcreteMultiStrategyVault.t.sol#L387 and run via

forge test -vvvv --match-test "test_mintFailsRoundingUp" --match-path ./test/ConcreteMultiStrategyVault.t.sol
error ERC20InsufficientBalance(address sender, uint256 balance, uint256 needed);

function test_mintFailsRoundingUp() public {
    (ConcreteMultiStrategyVault newVault, ) = _createNewVault(false, false, false);

    // Change allocations so that all funds are distributed to strategies
    Allocation[] memory allocations = new Allocation[](3);
    allocations[0] = Allocation({index: 0, amount: 2500});
    allocations[1] = Allocation({index: 0, amount: 2500});
    allocations[2] = Allocation({index: 0, amount: 5000});
    vm.prank(admin);
    newVault.changeAllocations(allocations, false);

    uint256 amount_ = 1e18 + 1; // amount that causes rounding up
    uint256 jimmyShareAmount = amount_;
    asset.mint(jimmy, jimmyShareAmount);

    vm.prank(jimmy);
    asset.approve(address(newVault), jimmyShareAmount);

    vm.prank(jimmy);

    vm.expectRevert(abi.encodeWithSelector(ERC20InsufficientBalance.selector, 0xD6BbDE9174b1CdAa358d2Cf4D57D1a9F7178FBfF, 499999999, 500000001));
    uint256 jimmyAssetAmount = newVault.mint(jimmyShareAmount, jimmy);
}
Recommended mitigation steps

Similar to the deposit() function, consider rounding down the amount to deposit into the strategy in ConcreteMultiStrategyVault.mint() to prevent the user from failing to deposit due to insufficient funds.
