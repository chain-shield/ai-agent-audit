S-935
VaultManager doesn't implement function to call `harvestRewards` on ConcreteMultiStrategyVault
nnez
87
Sufficient
383d ago
Impact

Once a vault is deployed, it will be impossible to call harvestRewards on ConcreteMultiStrategyVault.

Description

VaultManager is designated to be a owner of deployed ConcreteMultiStrategyVault as we can see from some of functions within VaultManager contract.

See: https://github.com/code-423n4/2024-11-concrete/blob/main/src/managers/VaultManager.sol

// File: 2024-11-concrete/src/managers/VaultManager.sol
    function toggleIdleVault(address vault_) external onlyRole(VAULT_MANAGER_ROLE) {
        IConcreteMultiStrategyVault(vault_).toggleVaultIdle();
    }
    // ...
    function removeStrategy(address vault_, uint256 index_) external onlyRole(VAULT_MANAGER_ROLE) {
        IConcreteMultiStrategyVault(vault_).removeStrategy(index_);
    }
    // ...
    function batchClaimWithdrawal(address vault_, uint256 maxRequests) external onlyRole(VAULT_MANAGER_ROLE) {
        IConcreteMultiStrategyVault(vault_).batchClaimWithdrawal(maxRequests);
    }
    // ...

All of these functions call into restricted-to-owner methods on ConcreteMultiStrategyVault contract.
See: toggleVaultIdle, removeStrategy, batchClaimWithdrawal

However, VaultManager contract overlooks one critical function for vault's operation, which is harvestRewards function.

harvestRewards is also a restricted-to-owner method and has to be invoked from time to time in order to distribute rewards to vault depositors.
See: https://github.com/code-423n4/2024-11-concrete/blob/main/src/vault/ConcreteMultiStrategyVault.sol#L989-L1025

Therefore, once a vault is deployed and its owner set as VaultManager, it will be impossible to call harvestRewards on ConcreteMultiStrategyVault.

Note that this is unrecoverable because VaultManager cannot transfer its ownerhship of the vault to another address as it also lacks this function.

Proof-of-Concept

One can verify the issue by searching for harvestRewards within VaultManager contract and find out that there is none.

Recommended Mitigations

Add a function into call harvestRewards on the vault.

    function removeStrategy(bytes memory encodedData) external onlyRole(VAULT_MANAGER_ROLE) {
        IConcreteMultiStrategyVault(vault_).harvestRewards(encodedData);
    }
