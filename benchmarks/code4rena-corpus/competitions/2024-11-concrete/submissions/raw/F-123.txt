S-1193
Dust Shares Check Bypass Through Mint Function
a2security
00
Sufficient
383d ago
Finding Description and Impact

The vault implements a dust shares check in the deposit function to prevent users from minting very small amounts of shares (less than 1e8). However, this check can be bypassed by using the mint function directly, which lacks the same validation. This allows users to mint any amount of shares, even as small as 1 share.

The impact is:

Users can bypass the intended minimum shares requirement
accounting precision issues with extremely small share amounts
Inconsistency between deposit and mint functions behavior
Proof of Concept

The deposit function properly implements the dust check:

function _deposit(uint256 assets_, address receiver_) private returns (uint256 shares) {
    // Calculate the net shares to mint for the deposited
    shares = _convertToShares(assets_, Math.Rounding.Floor) - feeShares;
    if (shares <= DUST) revert ZeroAmount();
    ...
}

However, the mint function lacks this check, allowing users to mint dust amounts:

function mint(uint256 shares_, address receiver_) public override returns (uint256) {
    if (shares_ > maxMint(receiver_)) revert MaxError();
    uint256 assets = previewMint(shares_);
    _deposit(assets, receiver_);
    return assets;
}

Here's a POC demonstrating the issue:

    function reInitVaultWithUsdc() public returns (ConcreteMultiStrategyVault, MockERC20) {

    function test_mintDust() public {
        //1. create new vault with only performance fees
        (ConcreteMultiStrategyVault v, MockERC20 asset) = reInitVaultWithUsdc();

        uint128 amount = 1000000e18;

        asset.mint(hazel, 1000000e18);
        vm.startPrank(hazel);
        asset.approve(address(v), type(uint256).max);
        // hazel deposit 10 tokens , and get 10e9 shares
        v.mint(1, hazel);
        assertEq(v.balanceOf(hazel), 1);

Recommended Mitigation Steps

Add the dust check to the mint function:

function mint(uint256 shares_, address receiver_) public override returns (uint256) {
    if (shares_ > maxMint(receiver_)) revert MaxError();
    if (shares_ <= DUST) revert ZeroAmount();  // Add dust check
