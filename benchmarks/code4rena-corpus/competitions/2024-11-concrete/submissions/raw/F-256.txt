S-1469
No zero check on prices from the Berachain Oracle
waydou
75
Sufficient
383d ago
Finding description and impact

The _convertFromTokenToStable function retrieves a price from an oracle via _getPriceFromOracle. However, it does not check if the returned price is zero. since we devide by the price in

stableAmount_.mulDiv(10 ** tokenDecimals, 10 ** CONCRETE_USD_DECIMALS, Math.Rounding.Floor).mulDiv(
                10 ** quoteDecimals,
                price,
                Math.Rounding.Floor
            )

the whole function will revert. Another issue is that the code assumes that berachain oracle works perfectly. If an asset experiences a huge drop in value (i.e. LUNA crash) the price of the oracle will continue to return the minPrice instead of the actual price of the asset. This would allow user to continue borrowing with the asset but at the wrong price. This is exactly what happened to Venus on BSC when LUNA imploded. However, the protocol misses to implement such a check.
