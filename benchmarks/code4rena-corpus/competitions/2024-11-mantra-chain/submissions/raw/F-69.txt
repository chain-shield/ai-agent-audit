S-172
Fee market's `GasPrices` query returns inflated gas price for default fee coin
berndartmueller
00
Sufficient
383d ago
Finding description and impact

ExtraDenoms() returns all coin denoms that have a multiplier configured, i.e., all allowed fee coins.

It is used as part of skip-mev's feemarket GetMinGasPrices() in line 117 to query the minimum gas prices for all allowed fee coins. Note that the default fee coin is supposed to be separate from the extra denoms, as it is already added to minGasPrices:

114: minGasPrice := sdk.NewDecCoinFromDec(params.FeeDenom, baseGasPrice)
115: minGasPrices := sdk.NewDecCoins(minGasPrice)
116:
117: extraDenoms, err := k.resolver.ExtraDenoms(ctx)
118: // [...]

Subsequently, the extra denoms are retrieved and the base gas fee converted for each of them before adding them to minGasPrices:

122: for _, denom := range extraDenoms {
123: 	gasPrice, err := k.ResolveToDenom(ctx, minGasPrice, denom)
124: 	if err != nil {
125: 		k.Logger(ctx).Info(
126: 			"failed to convert gas price",
127: 			"min gas price", minGasPrice,
128: 			"denom", denom,
129: 		)
130: 		continue
131: 	}
132: 	minGasPrices = minGasPrices.Add(gasPrice)
133: }

Assuming that the base fee denom (i.e., uom) is also added to the multipliers, as otherwise, this would completely prevent using a non-default fee coin (outlined in another submission, "Base fee coin likely has no multiplier configured, preventing using other allowed fee coins for gas payments or, if it has a multiplier, it leads to inflated priority fees"), ExtraDenoms() will also include the base fee denom.

Consequently, the base fee for the default denom will be doubled as it is converted and repeatedly added to minGasPrices within the for loop.

As a result, the gas prices query will return an inflated gas price for the default fee coin (uom), which might lead to off-chain tools and wallets using incorrect/inflated fees.

Proof of Concept

x/xfeemarket/keeper/resolver.go::ExtraDenoms()

25: func (k Keeper) ExtraDenoms(ctx sdk.Context) ([]string, error) {
26: 	iter, err := k.DenomMultipliers.Iterate(ctx, nil)
27: 	if err != nil {
28: 		return nil, err
29: 	}

31: 	extraDenoms, err := iter.Keys()
32: 	if err != nil {
33: 		return nil, err
34: 	}
35: 	return extraDenoms, nil
36: }
Recommended mitigation steps

Consider filtering out the default fee coin from ExtraDenoms() to prevent the base fee denom from being included in the extra denoms the query returns. This will ensure that the base fee is not inflated when querying the minimum gas prices for all allowed fee coins.
