# Vulnerability details

## Proof of Concept
The selfdestruct function allows an account to be flagged for deletion, but there is no validation to ensure the action is authorized or warranted. This could lead to unauthorized accounts being marked for destruction.

```

func selfdestruct(self: model.Account*) -> model.Account* {
    return new model.Account(
        ...
        selfdestruct=1,  // Account marked for destruction without additional checks
        ...
    );
}
```

Impact: Unauthorized account deletion, leading to loss of contract state or denial of service.

PoC
```
def test_selfdestruct_exploit():
    account = create_account()  # Simulate account creation
    malicious_call(account.selfdestruct())  # Simulate malicious selfdestruct
    assert account.selfdestruct == 1  # Account is improperly marked for destruction
```



## Recommended Mitigation Steps
 Add access control checks to ensure only authorized entities can trigger selfdestruct.
