# Vulnerability details

## Proof of Concept
The transfer_ownership function allows transferring ownership to any address, including the zero address (0x0). This could result in the contract being permanently locked, with no way to recover ownership.
```
@external
func transfer_ownership{syscall_ptr: felt*, pedersen_ptr: HashBuiltin*, range_check_ptr}(
    new_owner: felt
) {
    Ownable.transfer_ownership(new_owner);
    return ();
}
```

An attacker or even the legitimate owner could accidentally transfer ownership to 0x0, causing a permanent loss of control over the contract:

```
transfer_ownership(0);
```
Permanent loss of control over contract upgrades, pausing, or other administrative functions, effectively making the contract unmanageable.


## Recommended Mitigation Steps

Add validation to prevent setting the owner to a zero address:

```
@external
func transfer_ownership{syscall_ptr: felt*, pedersen_ptr: HashBuiltin*, range_check_ptr}(
    new_owner: felt
) {
    assert new_owner != 0; // Prevent zero address takeover
    Ownable.transfer_ownership(new_owner);
    return ();
}
```
