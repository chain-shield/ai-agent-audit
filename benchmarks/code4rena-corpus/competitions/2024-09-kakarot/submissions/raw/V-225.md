# Vulnerability details

## Description
The calculate_gas_extend_memory function computes the `current_memory_length` with the following calculation: https://github.com/kkrt-labs/kakarot/blob/7411a5520e8a00be6f5243a50c160e66ad285563/src/kakarot/gas.cairo#L87
However the correct calculation should be: `let current_memory_length = (words_len * 32) * is_memory_length_not_zero;`
This can lead to computing the length incorrectly and incorrectly undercharging for gas during memory expansion

## Recommended Mitigation Steps
Calculate the memory length without subtracting 1 from the words_len
