# Vulnerability details

## Proof of Concept

Take a look at the `SystemOperations::exec_create`:

```cairo
52:         let opcode_number = [evm.message.bytecode + evm.program_counter];
53:         let is_create2 = is_not_zero(opcode_number - 0xf0);
54:         let popped_len = 3 + is_create2;
55:         let (popped) = Stack.pop_n(3 + is_create2);
56
57:         let value = popped;
58:         let offset = popped[1];
59:         let size = popped[2];
```

The problem is in the calculation of `popped_len` and the following `Stack.pop_n` call. The function assumes that:

-- For CREATE (opcode 0xf0), 3 stack elements are popped.
-- For CREATE2 (opcode 0xf5), 4 stack elements are popped.

Albeit, this assumption is incorrect. It should actually be:

-- For CREATE (opcode 0xf0), 3 stack elements are popped.
-- For CREATE2 (opcode 0xf5), 4 stack elements are popped, but the `salt` is at the top of the stack, so it should be popped first.


Because the function doesn't account for this difference in stack layout between `CREATE` and `CREATE2`, incorrect values would be assigned to the wrong variables. The salt value would be incorrectly assigned to the `value` variable, while the actual value would be assigned to the `offset` variable. This could result in deploying contracts with incorrect initial balances and  incorrect initialization code.

## Recommended Mitigation Steps

Consider modifying the `exec_create` function to handle CREATE and CREATE2 operations separately:

```diff
 let opcode_number = [evm.message.bytecode + evm.program_counter];
 let is_create2 = is_not_zero(opcode_number - 0xf0);
-let popped_len = 3 + is_create2;
-let (popped) = Stack.pop_n(3 + is_create2);
-
-let value = popped;
-let offset = popped[1];
-let size = popped[2];
+if (is_create2 != FALSE) {
+    let (popped) = Stack.pop_n(4);
+    let salt = popped[0];
+    let value = popped[1];
+    let offset = popped[2];
+    let size = popped[3];
+} else {
+    let (popped) = Stack.pop_n(3);
+    let value = popped[0];
+    let offset = popped[1];
+    let size = popped[2];
+}
```
