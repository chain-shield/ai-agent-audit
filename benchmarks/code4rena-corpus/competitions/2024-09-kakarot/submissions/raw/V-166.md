# Vulnerability details

## Proof of Concept
The write_storage function modifies the contract’s storage but lacks reentrancy protection. This could allow attackers to recursively invoke this function within the same transaction, leading to unintended state manipulation.

```
func write_storage{pedersen_ptr: HashBuiltin*, range_check_ptr}(
    self: model.Account*, key: Uint256*, value: Uint256*
) -> model.Account* {
    alloc_locals;
    local storage: DictAccess* = self.storage;
    let (storage_addr) = Internals._storage_addr(key);
    dict_write{dict_ptr=storage}(key=storage_addr, new_value=cast(value, felt));
    ...
}
```

Without reentrancy protection, attackers could call the write_storage function repeatedly within the same transaction, modifying the storage in unpredictable ways. This could lead to loss of funds, state corruption, and denial of service.

PoC:
An attacker invokes the write_storage function and sets up a callback to call the function again before the state is fully updated.
This recursive invocation can lead to overwriting values or bypassing checks that rely on state updates.

```
def test_reentrancy_write_storage():
    account = create_account()
    attacker = deploy_reentrancy_attack_contract(account)
    # Attacker invokes reentrant call
    attacker.perform_reentrancy_attack()  
    
    # Check that storage has not been corrupted
    assert account.storage == expected_storage
```
An attacker triggers the write_storage function and, within the same transaction, calls back into the function recursively. This could modify the storage in ways that bypass critical checks (e.g., balance updates) and allow unauthorized access or modifications.

## Recommended Mitigation Steps
Add reentrancy protection using a mutex-like flag (nonReentrant). This ensures the function can’t be called recursively within the same transaction.
```
func write_storage{pedersen_ptr: HashBuiltin*, range_check_ptr}(
    self: model.Account*, key: Uint256*, value: Uint256*
) -> model.Account* {
    require(nonReentrant, "Reentrancy not allowed");
    nonReentrant = TRUE;
    ...
    nonReentrant = FALSE;
}
```
