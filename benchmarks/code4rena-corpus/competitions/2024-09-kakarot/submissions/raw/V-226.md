# Vulnerability details

## Description
Due to the following use of `is_le_felt`:https://github.com/kkrt-labs/kakarot/blob/7411a5520e8a00be6f5243a50c160e66ad285563/src/kakarot/gas.cairo#L88 which returns true in the equality case, extra gas can be charged even if there is no memory expansion, especially combined with the previous issue that calculates the memory length incorrectly. 

## Recommended Mitigation Steps
Ensure that the memory expansion function returns 0 if `current_memory_length` is equal to `max_offset` like how geth does here: https://github.com/ethereum/go-ethereum/blob/65e5ca7d8126f7a8c708f8affb64f16c22cc63c0/core/vm/gas_table.go#L45-L55
