# Vulnerability details

## Proof of Concept
Division by Zero: The function assumes that div is non-zero, but does not explicitly check for this. Division by zero would cause an error. This is a critical security issue, as division by zero can cause contract failure or unexpected behavior in dependent functions.

Impact: This could result in a runtime failure or revert the transaction, leading to potential denial-of-service scenarios. 
## Recommended Mitigation Steps
Add a check for div at the beginning of the function
assert div != 0, "Division by zero is not allowed."
