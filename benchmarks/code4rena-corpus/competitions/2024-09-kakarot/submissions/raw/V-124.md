# Vulnerability details

https://github.com/kkrt-labs/kakarot/blob/7411a5520e8a00be6f5243a50c160e66ad285563/src/kakarot/accounts/account_contract.cairo#L96
https://github.com/kkrt-labs/kakarot/blob/7411a5520e8a00be6f5243a50c160e66ad285563/src/kakarot/eth_rpc.cairo#L239
In `kakarot`, transactions are sent through the `eth_send_raw_unsigned_tx` function called by `execute_from_outside`.
When `eth_send_raw_unsigned_tx` is called from `execute_from_outside`, the `caller address` is retrieved, but it is not the `user address`, it is the `Account Contract address`.

## Proof of Concept
https://github.com/kkrt-labs/kakarot/blob/7411a5520e8a00be6f5243a50c160e66ad285563/src/kakarot/accounts/library.cairo#L217

```
    let (return_data_len, return_data, success, gas_used) = IKakarot.eth_send_raw_unsigned_tx(
        contract_address=kakarot_address, tx_data_len=tx_data_len, tx_data=tx_data
    );
```

The `execute_from_outside` function calls the `eth_send_raw_unsigned_tx` function via the `IKakarot.eth_send_raw_unsigned_tx` interface.

https://github.com/kkrt-labs/kakarot/blob/7411a5520e8a00be6f5243a50c160e66ad285563/src/kakarot/eth_rpc.cairo#L257

```
let (caller_address) = get_caller_address();

// Validate nonce
let (account_nonce) = IAccount.get_nonce(contract_address=caller_address);
with_attr error_message("Invalid nonce") {
    assert tx.signer_nonce = account_nonce;
}
```
In the `eth_send_raw_unsigned_tx` function, the `caller_address` is retrieved using the `get_caller_address` function, but this `caller_address` always returns the `Account Contract address`.

This is because `eth_send_raw_unsigned_tx` is actually called within the `Account Contract`, so the return value of `get_caller_address` is always the `Account Contract address`.

## Recommended Mitigation Steps
Add a `sender address` parameter to the `eth_send_raw_unsigned_tx` function.
Additionally, since the `eth_send_raw_unsigned_tx` function in the `kakarot contract` is decorated with `@external`, add a routine to check if the `sender address` and `tx.origin` are the same.
