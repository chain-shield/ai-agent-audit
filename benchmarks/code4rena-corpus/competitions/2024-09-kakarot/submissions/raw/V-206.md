# Vulnerability details

## Proof of Concept
Explanation:
The staticcallCairo functions rely on staticcall to execute read-only functions on the external Cairo contract. However, there are no fallback mechanisms or checks for scenarios where the target contract might not implement the specified function (e.g., if functionSelector or functionName are invalid).
Impact:
Moderate Impact: This could cause the transaction to fail unexpectedly without clear error handling. In the case of a critical function or a read operation to retrieve data for other contracts, this could cause disruptions.

## Recommended Mitigation Steps
Implement error handling for cases where staticcall fails, providing a clear error message or fallback behavior.

Example of error handling for staticcall:
(bool success, bytes memory result) = CAIRO_PRECOMPILE_ADDRESS.staticcall(callData);
if (!success) {
    revert("CairoLib: staticcall failed");
}
