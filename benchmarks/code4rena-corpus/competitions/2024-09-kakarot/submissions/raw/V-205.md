# Vulnerability details

## Proof of Concept
Explanation:
delegatecallCairo uses delegatecall, which is a powerful but dangerous Solidity function. It allows the callee contract to run in the context of the calling contract, potentially modifying its state variables.
If the target contract (callee) is malicious or buggy, it can corrupt the storage layout of the calling contract.

Impact:
High Impact: Misuse of delegatecall can lead to complete loss of control over the calling contract's state, leading to significant financial and functional damage. Historically, many hacks (e.g., Parity Wallet Bug) have involved delegatecall vulnerabilities.

## Recommended Mitigation Steps
Ensure only trusted contracts are used with delegatecall.

Example: Add whitelisting or restrict usage
require(whitelistedContracts[contractAddress], "Unauthorized contract");
