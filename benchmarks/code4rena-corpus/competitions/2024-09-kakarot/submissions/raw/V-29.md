Severity: Medium
Type: EVM Equivalence Issue
Function: add_transfer

The add_transfer function ignores transfers where the sender and recipient are the same, returning success without updating balances or recording the transfer. In the EVM, self-transfers are processed normally and can affect the account’s balance and emit events. Ignoring self-transfers deviates from EVM behaviour and may lead to inconsistencies. Inconsistent contract logic between Kakarot and EVM. 

*Vulnerable Code - Lines 369-371*
A contract that expects a self-transfer to update balances or emit an event will not function as intended because the transfer is ignored.
```Cairo
let sender = recipient;
        if (transfer.sender.evm == transfer.recipient.evm) {
            return 1;
        }
```
## Recommended Mitigation Steps
Remove the check that ignores self-transfers, allowing them to be processed like any other transfer.

