# Vulnerability details

## Proof of Concept
When processing transactions, the program assumes that items_len will only be 6 or 9, but does not validate against other possible values. Undefined behavior may result if the incoming data does not conform to the expected format.
If items_len is not equal to 6 or 9, subsequent array access out of bounds or logic errors may occur. For example, if items_len is 7, the line assert items[6].is_list = FALSE; will access an element that is out of the array range, which may cause an exception or data corruption.

```cairo
// Pre eip-155 txs have 6 fields, post eip-155 txs have 9 fields
if (items_len == 6) {
    tempvar is_some = 0;
    tempvar chain_id = 0;
} else {
    assert items_len = 9;
    ...
}
```
