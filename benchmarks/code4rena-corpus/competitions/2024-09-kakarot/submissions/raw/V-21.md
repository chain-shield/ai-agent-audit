Type: Missing Range Checks
Location: Multiple functions (init, set_code, & set_nonce)

Several functions accept input parameters that are not validated for expected ranges. For instance, code_len in the set_code function and nonce in the set_nonce function can be zero or excessively large due to the nature of felt in Cairo. This lack of validation can lead to unintended behaviour, such as memory allocation errors or logic flaws. Unvalidated input parameters can cause the contract to behave unpredictably, potentially leading to crashes, incorrect state updates, or security vulnerabilities that attackers could exploit.
