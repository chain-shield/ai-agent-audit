# Vulnerability details


## Proof of Concept

Protocol includes [multiple precompile implementations](https://github.com/kkrt-labs/kakarot-ssj/tree/d4a7873d6f071813165ca7c7adb2f029287d14ca/crates/evm/src/precompiles):

- [ECADD](https://github.com/kkrt-labs/kakarot-ssj/blob/d4a7873d6f071813165ca7c7adb2f029287d14ca/crates/evm/src/precompiles/ec_operations/ec_add.cairo)
- [ECMUL](https://github.com/kkrt-labs/kakarot-ssj/blob/d4a7873d6f071813165ca7c7adb2f029287d14ca/crates/evm/src/precompiles/ec_operations/ec_mul.cairo)
- [SHA256](https://github.com/kkrt-labs/kakarot-ssj/blob/d4a7873d6f071813165ca7c7adb2f029287d14ca/crates/evm/src/precompiles/sha256.cairo)
- [ECRECOVER](https://github.com/kkrt-labs/kakarot-ssj/blob/d4a7873d6f071813165ca7c7adb2f029287d14ca/crates/evm/src/precompiles/ec_recover.cairo)

Going to the in-scope implementation of [cairo1_helpers.cairo](https://github.com/kkrt-labs/kakarot-ssj/blob/d4a7873d6f071813165ca7c7adb2f029287d14ca/crates/contracts/src/cairo1_helpers.cairo) we see how the call to a precompile is being forwarded.

Now to pass a call to the precompile and execute we need to call https://github.com/kkrt-labs/kakarot-ssj/blob/d4a7873d6f071813165ca7c7adb2f029287d14ca/crates/contracts/src/cairo1_helpers.cairo#L131-L149:

```cairo
        fn exec_precompile(
            self: @TContractState, address: felt252, data: Span<u8>
        ) -> (bool, u64, Span<u8>) {
            let result = match address {
                0 => Result::Err(EVMError::NotImplemented),
                1 => Result::Err(EVMError::NotImplemented),//@audit
                2 => Sha256::exec(data),
                3 | 4 => Result::Err(EVMError::NotImplemented),
                5 => Result::Err(EVMError::NotImplemented),
                6 => EcAdd::exec(data),
                7 => EcMul::exec(data),
                _ => Result::Err(EVMError::NotImplemented),
            };
            match result {
                Result::Ok((gas, output)) => (true, gas, output),
                Result::Err(_) => (false, 0, [].span())
            }
        }
```

## Impact

Some precompiles can't be accessed, in this case ecrecover, which bricks any needed signature logic in the protocol.
