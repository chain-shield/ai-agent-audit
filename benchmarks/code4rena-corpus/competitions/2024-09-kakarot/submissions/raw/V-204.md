# Vulnerability details

## Proof of Concept
Explanation: There is no validation for the contractAddress, functionSelector, and data parameters passed to the callCairo, delegatecallCairo, and staticcallCairo functions. Malformed or unintended input could lead to unexpected behavior or malicious contract interactions.
Impact:
Moderate to High Impact: Calling an incorrect or malicious contract could lead to unwanted state changes or security vulnerabilities, depending on the external contract's nature.

## Recommended Mitigation Steps
Add input validation, like checking whether contractAddress is a valid contract and functionSelector corresponds to a real function.

example validation check:
require(isContract(contractAddress), "Invalid contract address");

function isContract(address _addr) internal view returns (bool) {
    uint256 size;
    assembly { size := extcodesize(_addr) }
    return size > 0;
}
