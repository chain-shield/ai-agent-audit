Severity: Medium
Type: Underflow
Location: Internals._cache_storage_keys, Line 674

The recursive function _cache_storage_keys performs a subtraction operation storage_keys_len - 2 without ensuring that storage_keys_len is greater than zero. If storage_keys_len is 1, subtracting two will underflow in the field of finite size used by Cairo, resulting in a large unintended positive number due to wrapping. An attacker could exploit this underflow by providing an input where storage_keys_len is Lt zero, causing the contract to enter an infinite recursive loop and potentially leading to a denial-of-service (DoS) attack.

*Proof of Concept (PoC)*
```Cairo
/// Set storage_keys_len = 1;
Internals._cache_storage_keys(self.address.evm, storage_keys_len - 2, storage_keys);
```
This causes an underflow that sets the value to the maximum value for uint256.
