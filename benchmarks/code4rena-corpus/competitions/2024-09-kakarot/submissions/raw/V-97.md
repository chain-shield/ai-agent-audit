# Vulnerability details

## Impact
the gas fee is not calculated, it may cause a Dos attack.

## Proof of Concept
EnvironmentalInformation.exec_balance calculates gas when obtaining account information:

```rust
    func exec_balance{
        syscall_ptr: felt*,
        pedersen_ptr: HashBuiltin*,
        range_check_ptr,
        bitwise_ptr: BitwiseBuiltin*,
        stack: model.Stack*,
        memory: model.Memory*,
        state: model.State*,
    }(evm: model.EVM*) -> model.EVM* {
        alloc_locals;

        let (address_uint256) = Stack.pop();
        let evm_address = uint256_to_uint160([address_uint256]);

        // Gas
        // Calling `get_account` subsequently will make the account warm for the next interaction
        let is_warm = State.is_account_warm(evm_address);
        tempvar gas = is_warm * Gas.WARM_ACCESS + (1 - is_warm) * Gas.COLD_ACCOUNT_ACCESS;
        let evm = EVM.charge_gas(evm, gas);
        if (evm.reverted != FALSE) {
            return evm;
        }

        let account = State.get_account(evm_address);
        Stack.push(account.balance);

        return evm;
    }
```

Because `get_account` needs to fetch data from storage.

But the problem is that the `selfbalance` command also needs to obtain account information, but does not calculate gas:

```rust
    func selfbalance{
        syscall_ptr: felt*,
        pedersen_ptr: HashBuiltin*,
        range_check_ptr,
        stack: model.Stack*,
        state: model.State*,
    }(evm: model.EVM*) {
        //@audit No calculated gas
        let account = State.get_account(evm.message.address.evm);
        Stack.push(account.balance);
        return ();
    }
```

In addition, the same problem exists with `BlockInformation.blockhash` and other calls to `get_account`.
