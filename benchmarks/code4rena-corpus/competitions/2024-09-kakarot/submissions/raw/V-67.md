### Impact
The sendMessageToL1 function in the L2KakarotMessaging contract lacks proper access control. 
Allowing any external account to invoke it and send arbitrary messages from L2 to L1. 
This can lead to unauthorized actions on the L1 contract.

### Vulnerable Code
```Solidity
// https://github.com/kkrt-labs/kakarot/blob/7411a5520e8a00be6f5243a50c160e66ad285563/solidity_contracts/src/L1L2Messaging/L2KakarotMessaging.sol#L9-L13

    /// @param data The data to send to the contract on L1.
    function sendMessageToL1(address to, bytes calldata data) external {
        bytes memory payload = abi.encode(to, msg.sender, data);
        CairoLib.sendMessageToL1(payload);
    }
```

## Recommended Mitigation Steps
Implement access control on the sendMessageToL1 function to restrict its usage to authorized accounts only. 
This can be achieved by introducing a modifier that checks if msg.sender is authorized.
```Solidity
import "@openzeppelin/contracts/access/Ownable.sol";

contract L2KakarotMessaging is Ownable {
    mapping(address => bool) public authorizedSenders;

    modifier onlyAuthorized() {
        require(authorizedSenders[msg.sender], "Not authorized");
        _;
    }

    /// @notice Adds an authorized sender.
    function authorizeSender(address sender) external onlyOwner {
        authorizedSenders[sender] = true;
    }

    /// @notice Sends a message to a contract on L1.
    function sendMessageToL1(address to, bytes calldata data) external onlyAuthorized {
        bytes memory payload = abi.encode(to, msg.sender, data);
        CairoLib.sendMessageToL1(payload);
    }
}
```
