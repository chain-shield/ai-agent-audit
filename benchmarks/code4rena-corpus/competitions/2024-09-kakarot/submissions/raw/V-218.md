# Vulnerability details

## Title
The function `ICairo1Helpers::library_call_keccak()` is not implemented.

## Links to affected code
https://github.com/kkrt-labs/kakarot/blob/b8f5f2a20bd733cc8885c010291885e1df7dc50e/cairo_zero/kakarot/interfaces/interfaces.cairo

https://github.com/kkrt-labs/kakarot/blob/b8f5f2a20bd733cc8885c010291885e1df7dc50e/cairo_zero/kakarot/instructions/system_operations.cairo#L1067
## Impact 
The function `ICairo1Helpers::library_call_keccak()` is meant (we assume) to be called to compute a keccak hash from the interface `Karakot::ICairo1Helpers` but the implementation is missing in the `Karakot::ICairo1Helpers` program which will be problematic for the functions calling the `ICairo1Helpers::library_call_keccak()` such as `get_create2_address()` and `get_create_address` in the CreateHelper.
