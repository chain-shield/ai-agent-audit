# Vulnerability details

## Proof of Concept

The code to handle token transfer is:

```solidity
    /// A `Result` indicating success or an `EVMError` if the transfer fails.
    #[inline(always)]
    fn add_transfer(ref self: State, transfer: Transfer) -> Result<(), EVMError> {
        if (transfer.amount == 0 || transfer.sender.evm == transfer.recipient.evm) {
            return Result::Ok(());
        }
        let mut sender = self.get_account(transfer.sender.evm);
        let mut recipient = self.get_account(transfer.recipient.evm);

        let (new_sender_balance, underflow) = sender.balance().overflowing_sub(transfer.amount);
        ensure(!underflow, EVMError::InsufficientBalance)?;

        let (new_recipient_balance, overflow) = recipient.balance.overflowing_add(transfer.amount);
        ensure(!overflow, EVMError::NumericOperations(BALANCE_OVERFLOW))?;

        sender.set_balance(new_sender_balance);
        recipient.set_balance(new_recipient_balance); // @audit add callback?

        self.set_account(sender);
        self.set_account(recipient);

        self.transfers.append(transfer);
        Result::Ok(())
    }
```

the comments and implementations says: A `Result` indicating success or an `EVMError` if the transfer fails.

But in some code, the return value for transfer is not sufficiently handled, result in slient transfer failure.

### Slient failure of the coinbase address payment

In the end of transaction, the sender needs to [pay for fee](https://github.com/kkrt-labs/kakarot/blob/7411a5520e8a00be6f5243a50c160e66ad285563/src/kakarot/interpreter.cairo#L1032) and the coinbase address is the recipient.

```solidity
        // So as to not burn the base_fee_per gas, we send it to the coinbase.
        let actual_fee = total_gas_used * env.gas_price;
        let (fee_high, fee_low) = split_felt(actual_fee);
        let actual_fee_u256 = Uint256(low=fee_low, high=fee_high);
        let transfer = model.Transfer(sender.address, coinbase.address, actual_fee_u256);

        with state {
            State.add_transfer(transfer);
            State.finalize();
        }
```

With unhandled add_transfer return, even when the sender address has insufficient balance and transaction should revert, the transfer sliently fails and the coinbase payment is bypassed.

This allow users to evade coinbase payment.

## Recommended Mitigation Steps

Always Handle the return value of add_transfer
