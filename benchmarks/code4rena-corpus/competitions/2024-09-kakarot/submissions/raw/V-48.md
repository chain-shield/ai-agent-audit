# Vulnerability details

The deploy function allows accounts to be deployed using any provided evm_address without checking if the caller is authorized. This lack of access control could allow unauthorized users to deploy malicious accounts, which could lead to severe security vulnerabilities depending on the contract's use case (e.g., fraud, unauthorized access to sensitive features).

Exploitation Example:
An attacker could call the deploy function to create a malicious account or impersonate another user’s account. The attacker could exploit this to deploy multiple unauthorized accounts and disrupt the intended behavior of the contract.

Mitigation:
Add access control mechanisms such as role-based access control (RBAC) or validate whether the deploying entity is authorized to create the account.
