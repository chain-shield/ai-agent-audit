# Vulnerability details

## Description
If a contract create tx from the root context reverts due to an out of balance check, geth will not update the nonce: https://github.com/ethereum/go-ethereum/blob/65e5ca7d8126f7a8c708f8affb64f16c22cc63c0/core/vm/evm.go#L442-L449
However kakarot will incorrectly increment the nonce by 1: https://github.com/kkrt-labs/kakarot/blob/7411a5520e8a00be6f5243a50c160e66ad285563/src/kakarot/interpreter.cairo#L1024
This breaks EVM conformance. 

## Recommended Mitigation Steps
Ensure that if the nonce overflows or if the value being transferred is more than allowed that the caller's nonce is not incremented.
