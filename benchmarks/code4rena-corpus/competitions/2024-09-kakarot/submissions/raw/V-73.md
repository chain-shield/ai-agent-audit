# Vulnerability details

## Impact

Initialization of a `L1KakarotMessaging.sol` can accept an invalid input (invalid starknet address for `kakarot`) that cannot be recovered post deployment of the `L1KakarotMessaging` contract. When this happens, this causes `L1KakarotMessaging` contract instance to point to invalid starknet addresses (immutably), and therefore make the instance of the contract unusable.

## Proof of Concept
The `constructor` logic of the `L1KakarotMessaging.sol`[1] does not validate whether the `_kakarotAddress` (of type `uint256`) is a valid starknet address. 

```
// L1KakarotMessaging.sol

contract L1KakarotMessaging {

// ...

uint256 public immutable kakarotAddress;

// ...

constructor(address starknetMessaging_, uint256 kakarotAddress_) {
    starknetMessaging = IStarknetMessaging(starknetMessaging_);
    kakarotAddress = kakarotAddress_; // This input is not validated!
}

// ...

}
```

This is important as in other parts of the code this is ensured with a simple check, such as in the `_transferFrom(...)` function call in the `DualVmToken.sol` code:

```
// DualVmToken.sol

if (from >= STARKNET_FIELD_PRIME || to >= STARKNET_FIELD_PRIME) {
    revert InvalidStarknetAddress();
}
```

For example, in this case in `DualVmToken.sol`, this ensures that the `from` and `to` addresses are valid starknet addresses.

The impact of this, is that a bad constructor input to the `kakarotAddress` will be immutably (and therefore permanently) set on the smart contract, where the only resolution would be to re-deploy with correct parameters.

## Recommended Mitigation Steps

To avoid this, a similar approach can be taken as seen in the `DualVmToken.sol` solidity contract, where the `STARKNET_FIELD_PRIME` is declared as a constant, and used to validate any `uint256` inputs that are intended to be parsed as starknet addresses.

For example, the `L1KakarotMessaging.sol` contract/constructor should be updated like so:

```
// L1KakarotMessaging.sol

contract L1KakarotMessaging {

// ...

uint256 public constant STARKNET_FIELD_PRIME = 2 ** 251 + 17 * 2 ** 192 + 1;
uint256 public immutable kakarotAddress;

error InvalidStarknetAddress();

// ...

constructor(address starknetMessaging_, uint256 kakarotAddress_) {
    if (kakarotAddress_ >= STARKNET_FIELD_PRIME) {
        revert InvalidStarknetAddress();
    }
    starknetMessaging = IStarknetMessaging(starknetMessaging_);
    kakarotAddress = kakarotAddress_; // Address here is now validated!
}

// ...

}
```

NOTE: This could additionally be enforced at stages leading up to the deployment of such a contract (e.g. caller input validation beforehand), however for certainty (and such a minimal one time gas cost), this means this issue can no longer happen.
