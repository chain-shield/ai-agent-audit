Issue: Stack size exceeds EVM maximum stack size
Severity: Medium
Type: EVM Equivalence Issue
Location: push: Lines 36-44

The EVM enforces a maximum stack size of 1024 items. The Stack implementation does not enforce this limit, allowing more than 1024 items to be pushed. This discrepancy can lead to issues when interfacing with systems expecting EVM-compliant behaviour. Applications relying on EVM stack limits will malfunction. Excessive stack growth will consume resources.

*POC*
```Cairo
let stack = Stack.init();
for i in range(0, 1025):
    let item = Uint256(i, 0);
    stack.push(&item);  // No check, allows more than 1024 items
```
## Recommended Mitigation Steps
Enforce EVM stack size limit in push.
```Cairo
func push{stack: model.Stack*}(element: Uint256*) {
    if (stack.size >= 1024) {
        assert 0 = 1;  // Stack overflow
    }
    // Rest of the function...
}
```
