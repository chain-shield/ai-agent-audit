# Vulnerability details

## Proof of Concept

In the `cairo_precompile` function, When an account needs to be deployed, the function deploys it but fails to initialize the `caller_starknet_address` variable properly. This could lead to using an uninitialized or incorrect address in subsequent operations which could cause issuess.

Take a look at this part of the code: https://github.com/kkrt-labs/kakarot/blob/7411a5520e8a00be6f5243a50c160e66ad285563/src/kakarot/precompiles/kakarot_precompiles.cairo#L85-L98

```cairo
if (is_not_deployed != FALSE) {
    // Deploy account -
    // order of returned values in memory matches the explicit ones in the other branch
    Starknet.deploy(caller_address);
} else {
    tempvar syscall_ptr = syscall_ptr;
    tempvar pedersen_ptr = pedersen_ptr;
    tempvar range_check_ptr = range_check_ptr;
    tempvar caller_starknet_address = caller_starknet_address;
}
let syscall_ptr = cast([ap - 4], felt*);
let pedersen_ptr = cast([ap - 3], HashBuiltin*);
let range_check_ptr = [ap - 2];
let caller_starknet_address = [ap - 1];
```

The issue is that when `is_not_deployed != FALSE` (i.e., the account needs to be deployed), the `Starknet.deploy(caller_address)` function is called. But after this deployment, the code doesn't update or set the `caller_starknet_address` variable.

In the `else` branch (when the account is already deployed), the `caller_starknet_address` is properly set as a `tempvar`. But in the `if` branch, this doesn't happen.

As a result, when the code reaches the line `let caller_starknet_address = [ap - 1];`, it's using a value from the stack that wasn't properly set in the case of a newly deployed account.

This could lead to using an incorrect or uninitialized `caller_starknet_address` in the subsequent `IAccount.execute_starknet_call()` function call.

## Impact
The `caller_starknet_address` is used in the `IAccount.execute_starknet_call()` function call:

```cairo
let (retdata_len, retdata, success) = IAccount.execute_starknet_call(
    caller_starknet_address, to_starknet_address, starknet_selector, data_len, data
);
```

If `caller_starknet_address` is uninitialized or incorrect, this call could fail or, worse, execute with the wrong caller address, potentially leading to unauthorized actions or other security issues.

## Recommended Mitigation Steps

Consider properly initializiing `caller_starknet_address` after deploying the account. 
```diff
 if (is_not_deployed != FALSE) {
     // Deploy account -
     // order of returned values in memory matches the explicit ones in the other branch
     Starknet.deploy(caller_address);
+    let caller_starknet_address = Account.get_registered_starknet_address(caller_address);
+    tempvar syscall_ptr = syscall_ptr;
+    tempvar pedersen_ptr = pedersen_ptr;
+    tempvar range_check_ptr = range_check_ptr;
+    tempvar caller_starknet_address = caller_starknet_address;
 } else {
     tempvar syscall_ptr = syscall_ptr;
     tempvar pedersen_ptr = pedersen_ptr;

 }
```
