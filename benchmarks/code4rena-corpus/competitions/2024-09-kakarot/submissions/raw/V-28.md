Severity: Medium
Type: Under-Constrained Computation / Missing Input Validation
Location: peek: Lines 102-112 & swap_i: Lines 118-133

Functions accepting indices do not validate that these indices are within the valid range. Without proper checks, negative or excessively large indices can cause out-of-bounds access, leading to unexpected behaviour or security vulnerabilities. Out-of-bounds memory access can lead to information leakage or corruption. The program will crash or behave unpredictably.

## Recommended Mitigation Steps

```Cairo
func swap_i{stack: model.Stack*}(i: felt) {

        assert 0 = 1;  // Invalid index

    // Rest of the function...
}
```
