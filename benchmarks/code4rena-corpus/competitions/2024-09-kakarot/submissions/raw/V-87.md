# Vulnerability details

## Proof of Concept

In the current implementation of `interpreter.cairo`, the function `exec_opcode()` is used to execute the program by executing every opcode and charging the gas for it. The problem is that if such execution faced out of gas error when charging the gas, it does not stop with an exceptional halt and continues to execute the program:

```
// Update static gas
        let evm = EVM.charge_gas(evm, opcode.gas);
        if (evm.reverted != FALSE) {
            return evm;
        }
```

Here the function charges the static gas for a given opcode and then returns an evm. However, `charge_gas()` function may result in an out-of-gas error:

https://github.com/kkrt-labs/kakarot/blob/7411a5520e8a00be6f5243a50c160e66ad285563/src/kakarot/evm.cairo#L206-218
```
 not_enough_gas:
        let range_check_ptr = [ap - 1];
        let (revert_reason_len, revert_reason) = Errors.outOfGas(self.gas_left, amount);
        return new model.EVM(
            message=self.message,
            return_data_len=revert_reason_len,
            return_data=revert_reason,
            program_counter=self.program_counter,
            stopped=TRUE,
            gas_left=0,
            gas_refund=self.gas_refund,
            reverted=Errors.EXCEPTIONAL_HALT,
        );

```

But in the `exec_opcode()` to handle this exception, the execution just continues which is not expected even if there are no more gas left. The function only checks whether `evm.reverted != FALSE` and then returns new EVM model instead of stopping it before.

If EVM is not stopped (the current execution context), the execution just continues:

```
  if (evm.stopped == FALSE) {
            let evm = exec_opcode(evm);
            return run(evm);
        }
```

Otherwise, EVM will be finalized (not done in the current functionality due to the incorrect handling of the out-of-gas scenario):

https://github.com/kkrt-labs/kakarot/blob/7411a5520e8a00be6f5243a50c160e66ad285563/src/kakarot/interpreter.cairo#L755-760
```
Memory.finalize();
        Stack.finalize();
        State.finalize();
        with evm {
            EVM.finalize();
        }
```

## Recommended Mitigation Steps


Handle an exception the same way as it's done with stack overflow/underflow errors:

https://github.com/kkrt-labs/kakarot/blob/7411a5520e8a00be6f5243a50c160e66ad285563/src/kakarot/interpreter.cairo#L164-168
```
   if (stack_overflow != 0) {
            let (revert_reason_len, revert_reason) = Errors.stackOverflow();
            let evm = EVM.stop(evm, revert_reason_len, revert_reason, Errors.EXCEPTIONAL_HALT);
            return evm;
        }

```

So we have to use `stop()` to stop the current execution context with an exceptional halt reason and the revert reason that's returned from the `charge_gas()` function.
