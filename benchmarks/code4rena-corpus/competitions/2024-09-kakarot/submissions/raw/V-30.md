Severity: Medium
Type: Missing Range Checks / Memory Safety
Functions: add_event & add_transfer

The functions add_event and add_transfer increment state.events_len and state.transfers_len without ensuring they stay within the bounds of the allocated arrays. This can lead to out-of-bounds memory writes, resulting in memory corruption or unexpected behaviour. 

*Impact*
-Memory corruption leading to undefined behaviour.
-Potential security vulnerabilities due to corrupted memory.

*Vulnerable Code - Lines 345 & 398*
```Cairo
// In add_event
assert state.events[state.events_len] = event;

// In add_transfer
assert state.transfers[state.transfers_len] = transfer;
```

*POC*
An attacker could cause state.events_len or state.transfers_len to exceed the allocated array size by repeatedly calling these functions, leading to memory corruption.

## Recommended Mitigation Steps
Implement checks to ensure that state.events_len and state.transfers_len do not exceed the allocated sizes of the arrays.
```Cairo
// Add bounds check
if (state.events_len >= MAX_EVENTS_LEN) {
    // Handle error
    return ();
}

// Similarly for transfers_len
```
