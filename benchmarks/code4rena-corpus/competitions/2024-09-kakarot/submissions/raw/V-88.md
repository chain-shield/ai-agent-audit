# Vulnerability details

## Impact

When the user's balance is low, it can avoid paying the gas fee.

## Proof of Concept

The `Interpreter.execute` function determines the return value of `add_transfer` when handling `msg.value`:

```rust
    func execute{
        syscall_ptr: felt*,

    }
        ......
        with state {
        ......

@>      let success = State.add_transfer(transfer);
        }
        ......
        if (success == 0) {
            let (revert_reason_len, revert_reason) = Errors.balanceError();
            tempvar evm = EVM.stop(evm, revert_reason_len, revert_reason, Errors.EXCEPTIONAL_HALT);
```

However, the return value of `add_transfer` was not judged when the `gas fee` was processed:

```rust
        // So as to not burn the base_fee_per gas, we send it to the coinbase.
        let actual_fee = total_gas_used * env.gas_price;
        let (fee_high, fee_low) = split_felt(actual_fee);
        let actual_fee_u256 = Uint256(low=fee_low, high=fee_high);
        let transfer = model.Transfer(sender.address, coinbase.address, actual_fee_u256);

        with state {
@>              State.add_transfer(transfer);
                State.finalize();
        }
```

If the `add_transfer` function fails to execute, such as the account balance is insufficient,`add_transfer` will return 0, and no transfer operation will be performed.

```rust
   func add_transfer{
```

Therefore, when the account balance is insufficient, the user can not pay any gas.
