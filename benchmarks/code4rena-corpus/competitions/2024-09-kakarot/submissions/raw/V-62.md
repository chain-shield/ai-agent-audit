# Vulnerability details

## Impact
Using delegatecall to an untrusted address (starknetToken) allows an attacker to execute arbitrary code within the context of the DualVmToken contract. This can lead to the following.
- Unauthorized modification of the contract’s storage.
- Theft of tokens or Ether stored in the contract.
- Execution of malicious code affecting contract behavior.

The DualVmToken contract’s _approve function uses delegatecall to invoke the approve function on the starknetToken contract.
```Solidity
    function _approve(uint256 spender, uint256 amount) private {
        if (spender >= STARKNET_FIELD_PRIME) {
            revert InvalidStarknetAddress();
        }
        // Split amount in [low, high]
        uint128 amountLow = uint128(amount);
        uint128 amountHigh = uint128(amount >> 128);
        uint256[] memory approveCallData = new uint256[](3);
        approveCallData[0] = spender;
        approveCallData[1] = uint256(amountLow);
        approveCallData[2] = uint256(amountHigh);


        starknetToken.delegatecallCairo("approve", approveCallData);
    }
```
Since starknetToken is set during construction and can be any address, an attacker can deploy a malicious contract and set it as the starknetToken. When delegatecall is used, the malicious contract’s code is executed in the context of DualVmToken, allowing the attacker to manipulate its state.

2. Run forge test -vvvv --match-contract DualVmTokenTest.
3. See the successful results.

		uint256 spender = uint256(0xbEEF); 
		uint256 amount = uint256(1e4);

		vm.stopPrank();
	}

}

## Recommended Mitigation Steps
Replace delegatecall with a regular call to prevent execution in the context of DualVmToken:
```Solidity
function _approve(uint256 spender, uint256 amount) private {
    if (spender >= STARKNET_FIELD_PRIME) {
        revert InvalidStarknetAddress();
    }
    // Split amount in [low, high]
    uint128 amountLow = uint128(amount);
    uint128 amountHigh = uint128(amount >> 128);
    uint256;
    approveCallData[0] = spender;
    approveCallData[1] = uint256(amountLow);
    approveCallData[2] = uint256(amountHigh);

    // Use call instead of delegatecall
    starknetToken.callCairo("approve", approveCallData);
}
```
The use of delegatecall to an untrusted contract in DualVmToken poses a significant security risk. By modifying the call to use call and ensuring that starknetToken is a trusted contract, this vulnerability can be mitigated.
