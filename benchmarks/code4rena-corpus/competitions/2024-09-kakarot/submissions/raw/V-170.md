# Vulnerability details

## Proof of Concept
The fetch_or_create function allows for the creation of new accounts without any constraints on how many accounts can be created in a short period of time or how frequently the function can be invoked. This makes the system vulnerable to Denial of Service (DoS) attacks where an attacker can overwhelm the system with account creation requests, leading to resource exhaustion.

```
func fetch_or_create{syscall_ptr: felt*, pedersen_ptr: HashBuiltin*, range_check_ptr}(
    evm_address: felt
) -> model.Account* {
    // Code that creates accounts without any resource constraints
}
```
Attackers can flood the system with account creation requests, consuming significant resources such as storage, computational power, and memory, eventually causing the system to slow down or crash.



## Recommended Mitigation Steps
Implement rate-limiting or resource allocation constraints to prevent excessive or repeated account creation in a short period of time. Introducing a time-based or resource-based limit will help mitigate the risk of DoS attacks.

Time Constraint: Add a cooldown period for account creation from the same address or IP.
Resource Limitation: Limit the total number of accounts that can be created within a specific timeframe or introduce gas costs proportional to resource usage.

```
// Example: Rate-limiting logic (pseudo-code)
let (last_created_time) = get_last_creation_time(evm_address);
let (current_time) = get_current_time();
if (current_time - last_created_time < CREATION_COOLDOWN_PERIOD) {
    // Reject the request or return an error
    return ERR_TOO_SOON;
}
// Proceed with account creation if time constraint passes
```
