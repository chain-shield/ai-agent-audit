# Vulnerability details

## Proof of Concept

push_uint128 does not check that element argument(which is of felt type) is less than 2^128.
It then assigns this value as the "low" part of Uint256:

```
    func push_uint128{stack: model.Stack*}(element: felt) {
        tempvar item = new Uint256(element, 0);
        push(item);
        return ();
    }
```

This Uint256 value is then: written to the stack dict as part of the push operation:

```
    func push{stack: model.Stack*}(element: Uint256*) {
        let dict_ptr = stack.dict_ptr;
        with dict_ptr {
            dict_write(stack.size, cast(element, felt));
        }

        tempvar stack = new model.Stack(stack.dict_ptr_start, dict_ptr, stack.size + 1);
        return ();
    }
```

Since there were no validation checks, reading this value from the stack dict would return a much greater value than the felt valiue that was actually stored

Functions that call push_uint128 such as exec_calldatasize :

```
    func exec_calldatasize{
        ...
    }(evm: model.EVM*) -> model.EVM* {
        Stack.push_uint128(evm.message.calldata_len);
        return evm;
    }
```

(paydata_len is signed with tthe user's tx)
