## [M1] Potential Overflow in Multiplication of tx.gas_limit and tx.max_fee_per_gas

Severity: Medium
Issue Type: Arithmetic Overflow / Underflow

Impact: An overflow in the calculation of max_gas_fee can lead to incorrect computation of transaction costs, allowing transactions to proceed without sufficient funds or gas checks. This can cause denial of service or unintended behavior in the contract execution.

Location: eth_send_raw_unsigned_tx function, during the computation of max_gas_fee.

```Cairo

```
Description:

In the eth_send_raw_unsigned_tx function, max_gas_fee is calculated by multiplying tx.gas_limit and tx.max_fee_per_gas. Both of these variables are of type felt, which can hold values up to {2 ^ 251 - 1}. Multiplying two such large numbers can result in a value up to {2 ^ 501}, exceeding the capacity of a single felt. Since max_gas_fee is stored in a felt, this overflow causes an incorrect value, leading to improper transaction cost calculations and potential security vulnerabilities.

Proof of Concept:

An attacker can craft a transaction with large tx.gas_limit and tx.max_fee_per_gas values to cause an overflow:

```Cairo
// Example values that cause overflow
let tx.gas_limit = 2**126; // Large gas limit
let tx.max_fee_per_gas = 2**126; // Large max fee per gas

// This multiplication overflows the felt size
let max_gas_fee = tx.gas_limit * tx.max_fee_per_gas;

// The overflowed value leads to incorrect fee calculations
let (max_fee_high, max_fee_low) = split_felt(max_gas_fee);
```
## Recommended Mitigation Steps
Add range checks on tx.gas_limit and tx.max_fee_per_gas to ensure their product does not exceed 2^{256} - 1:
```Cairo
// Define maximum values to prevent overflow
const MAX_GAS_LIMIT = 2**128 - 1;
const MAX_MAX_FEE_PER_GAS = 2**128 - 1;

// Add range checks before multiplication
with_attr error_message("tx.gas_limit too large") {
    assert_le(tx.gas_limit, MAX_GAS_LIMIT);
}
with_attr error_message("tx.max_fee_per_gas too large") {
    assert_le(tx.max_fee_per_gas, MAX_MAX_FEE_PER_GAS);
}

// Proceed with multiplication knowing it won't overflow 256 bits
let (max_gas_fee_high, max_gas_fee_low, carry) = uint256_mul(tx.gas_limit, tx.max_fee_per_gas);
assert carry = 0; // Ensure no overflow beyond 256 bits
```
Alternatively, implement multi-felt arithmetic for multiplication and subsequent calculations to handle values larger than a single felt.
