# Vulnerability details

The function name _transfer_eth is misleading, suggesting that it transfers Ether (ETH) instead of ERC20 tokens.

And If this function is intended to transfer ETH, then using the IERC20.transferFrom method is incorrect. ETH transfers should be done through native Cairo or StarkNet-specific mechanisms for sending ETH (e.g., via system calls or contract logic for ETH). This function suggests confusion between ETH and ERC20 logic.

Impact:

Confusion: The misleading name could lead to confusion for developers or users, potentially resulting in incorrect usage or unintended consequences.
Misuse: If developers mistakenly believe the function transfers ETH, they might use it in contexts where it's not applicable, leading to errors or vulnerabilities.
Security Risks: In some cases, incorrect usage of functions could inadvertently expose the contract to security risks, such as unauthorized transfers or loss of funds.
Mitigation:

Rename the Function: Change the function name to _transfer_erc20 or a similar name that accurately reflects its purpose. This will improve clarity and reduce the risk of confusion.
