# Vulnerability details

## Proof of Concept

There are currently 2 functions inside of the `state.cairo` that interact with transient storage:

https://github.com/kkrt-labs/kakarot/blob/7411a5520e8a00be6f5243a50c160e66ad285563/src/kakarot/state.cairo#L314-326
```
// @notice Reads the transient storage of an account at the given key.
    // @param evm_address The EVM address of the account to read.
    // @param key The key of the storage slot to read.
    // @return The value of the storage slot.
    func read_transient_storage{
        syscall_ptr: felt*, pedersen_ptr: HashBuiltin*, range_check_ptr, state: model.State*
    }(evm_address: felt, key: Uint256*) -> Uint256* {
        alloc_locals;
        let account = get_account(evm_address);
        let (account, value) = Account.read_transient_storage(account, key);
        update_account(account);
        return value;
    }


```

https://github.com/kkrt-labs/kakarot/blob/7411a5520e8a00be6f5243a50c160e66ad285563/src/kakarot/state.cairo#L300-312
```
  // @notice Update a storage key with the given value
    // @param evm_address The evm address of the account to write storage to.
    // @param key The pointer to the Uint256 storage key
    // @param value The pointer to the Uint256 value
    func write_storage{
        syscall_ptr: felt*, pedersen_ptr: HashBuiltin*, range_check_ptr, state: model.State*
    }(evm_address: felt, key: Uint256*, value: Uint256*) {
        alloc_locals;
        let account = get_account(evm_address);
        let account = Account.write_storage(account, key, value);
        update_account(account);
        return ();
    }
```

https://github.com/kkrt-labs/kakarot/blob/7411a5520e8a00be6f5243a50c160e66ad285563/src/kakarot/interpreter.cairo#L170-174
```
 // Update static gas
        let evm = EVM.charge_gas(evm, opcode.gas);

```


## Recommended Mitigation Steps

Introduce TLOAD / TSTORE opcodes gas costs to supporting reading from and writing to the transient 
storage:

https://soliditylang.org/blog/2024/01/26/transient-storage/
```
Consequently, transient storage is as cheap as warm storage access, with TSTORE and TLOAD priced at 100 gas.
```
