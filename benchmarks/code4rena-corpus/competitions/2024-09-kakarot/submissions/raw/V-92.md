# Vulnerability details

## Proof of Concept

Currently the intrinsic gas inside of Karakot VM is calculated the following way:

https://github.com/kkrt-labs/kakarot/blob/7411a5520e8a00be6f5243a50c160e66ad285563/src/kakarot/interpreter.cairo#L922
```
let intrinsic_gas = intrinsic_gas + access_list_cost;
```

The formula is used according to the EIP-1559 specification:

https://github.com/ethereum/EIPs/blob/master/EIPS/eip-1559.md
```
21000 + 16 * non-zero calldata bytes + 4 * zero calldata bytes + 1900 * access list storage key count + 2400 * access list address count
```

Everything is done correctly except for the way access list cost is calculated:

https://github.com/kkrt-labs/kakarot/blob/7411a5520e8a00be6f5243a50c160e66ad285563/src/kakarot/interpreter.cairo#L919
```
   let access_list_cost = State.cache_access_list(access_list_len, access_list);
```

https://github.com/kkrt-labs/kakarot/blob/7411a5520e8a00be6f5243a50c160e66ad285563/src/kakarot/state.cairo#L528-531
```
       tempvar item_len = 2 + storage_keys_len * Uint256.SIZE;

        let cum_gas_cost = _cache_access_list(access_list_len - item_len, access_list + item_len);
        return cum_gas_cost + Gas.TX_ACCESS_LIST_ADDRESS_COST + storage_keys_len *
            Gas.TX_ACCESS_LIST_STORAGE_KEY_COST;
```


As you can see here, we add `storage_keys_len * Gas.TX_ACCESS_LIST_STORAGE_KEY_COST` to the `cum_gas_cost + Gas.TX_ACCESS_LIST_ADDRESS_COST` but according to the spec it's done like this:


```
1900 * access list storage key count + 2400 * access list address count
```

This will lead to incorrect calculations being made when dealing with transactions containing access list.

## Recommended Mitigation Steps

Modify the formula for intrinsic gas calculation for it to be compatible with EIP-1559.
