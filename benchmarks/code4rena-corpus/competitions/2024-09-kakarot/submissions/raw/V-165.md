# Vulnerability details

## Proof of Concept
The set_balance function allows direct manipulation of an account’s balance without implementing any access control. This could be exploited by a malicious contract or external party to alter account balances arbitrarily.

```
func set_balance(self: model.Account*, balance: Uint256*) -> model.Account* {
    return new model.Account(
        ...
        balance=balance,
    );
}
```

Impact: Attackers could manipulate account balances, leading to unauthorized fund transfers or theft. Since balance is a critical value in any financial contract, its alteration can result in serious financial loss.

PoC:

```
def test_unauthorized_balance_change():
    account = create_account()
    malicious_entity = get_malicious_actor()
    # Malicious actor calls set_balance
    malicious_entity.set_balance(account, Uint256(new_balance))
    assert account.balance == original_balance  # Should not allow unauthorized modification
```


## Recommended Mitigation Steps
Implement strict access control checks using either a role-based mechanism (only allowing certain roles to modify balances) or ensure that this function is only callable by trusted contracts or administrators.
