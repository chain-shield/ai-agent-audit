## [M] Missing Range Checks on tx_data_len Relative to packed_tx_data_len

	•	Severity: Medium
	•	Issue Type: Missing range checks
	•	Location: Lines 96-149

## Impact: 
An attacker can cause the contract to read memory out of bounds or cause denial of service by providing a large tx_data_len.	
```Cairo
let tx_data_len = [packed_tx_data];
assert [range_check_ptr] = tx_data_len;
let range_check_ptr = range_check_ptr + 1;

let (tx_data) = Helpers.load_packed_bytes(
    packed_tx_data_len - 1, packed_tx_data + 1, tx_data_len
);
```

## Description: 
The tx_data_len is read from [packed_tx_data] without ensuring that it is less than or equal to packed_tx_data_len - 1. This could cause Helpers.load_packed_bytes to read beyond the end of the provided data, potentially leading to undefined behavior or security vulnerabilities.

## Proof of Concept (PoC):
An attacker can set tx_data_len to a value larger than packed_tx_data_len - 1, causing the function to read out-of-bounds memory during Helpers.load_packed_bytes execution.

## Recommended Mitigation Steps
Add a check to ensure that tx_data_len does not exceed packed_tx_data_len - 1.
```Cairo
with_attr error_message("Execute from outside: tx_data_len exceeds packed_tx_data_len") {
    assert_le(tx_data_len, packed_tx_data_len - 1);
}
```
