# Vulnerability details

## Impact

`required_validators` is set to 0, which completely bypasses the validator multi-signature mechanism

SettlementSignatureVerifier contract. In the `set_required_validators_num` method, `required_validators` can be set to any value by an account with the `MANAGER_ROLE` role. If `required_validators` is set to 0, then during the signature verification process, the `verifyECDSA` function will return `true` as soon as any valid signature is recovered, without requiring any other valid validator signatures. This will completely bypass the multi-signature mechanism of the validator, leading to a serious security vulnerability.

## Recommended Mitigation Steps

**Minimum validator limit**: When deploying a contract, ensure that there are always at least 2 validators in the system to prevent malicious or accidental setting of `required_validators` to 0.
