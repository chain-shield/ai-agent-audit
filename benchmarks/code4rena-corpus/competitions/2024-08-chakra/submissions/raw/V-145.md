# Vulnerability details

The mint_to and burn_from functions in the ckr_btc.cairo contract do not emit events after their operations, which reduces transparency and makes it difficult to track these critical actions on-chain.
While the contract emits events for manager and operator actions, it doesn't emit events for mint and burn operations.

Impact:

Lack of event emissions complicates off-chain monitoring, auditing, and tracking, increasing the likelihood of undetected malicious activities.
Exploitation Example:

Tokens are minted or burned without any on-chain record (aside from state changes), making it difficult to trace these actions.
Suggested Mitigation:

Emit events for all critical actions to ensure transparency and traceability.

EXAMPLES:

func mint_to(to: felt, amount: felt) -> felt {
    balance[to] += amount
    total_supply += amount
    emit Mint(to, amount)
    return 0
}

func burn_from(from: felt, amount: felt) -> felt {
    balance[from] -= amount
    total_supply -= amount
    emit Burn(from, amount)
    return 0
}
