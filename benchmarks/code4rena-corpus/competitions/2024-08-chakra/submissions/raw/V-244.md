# Vulnerability details

## Impact
Unauthorized Caller would Send Cross Chain Messages due to absence of msg.sender validation as against Protocol expectation
## Proof of Concept

The code above shows how send_cross_chain_msg is implemented in the ChakraSettlement contract, it can be noted from the pointer in the code above that "from_address" is suppose to be the msg.sender caller of this function however the Protocol failed to validate this before proceeding with the code implementation, only from_handler was assigned the value of msg.sender, the implication of this is that anybody can send cross chain message for another address even though they are not authorized to which can be taken advantage of to manipulate the contract functionality for an innocent user.
