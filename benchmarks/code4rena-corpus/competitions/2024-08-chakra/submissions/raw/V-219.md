# Vulnerability details

## Impact
When we try to update required_validators via settlement, the update does not work.

## Proof of Concept
In settlement, we have several functions to update key parameters of the verifier contract, `add_validator`, `remove_validator`, `set_required_validators_num`.
The problem is that we should trigger verifier's related function to take effect.
In set_required_validators_num(), we only update the variable `required_validators` in settlement, the `required_validators` in `SettlementSignatureVerifier` does not take effect.
When we try to verify signatures, verifier contract will verify signatures based on the variable `required_validators` in SettlementSignatureVerifier.

```javascript
BaseSettlement>>
    function set_required_validators_num(
        uint256 _required_validators
    ) external onlyRole(MANAGER_ROLE) {
        uint256 old = required_validators;
        required_validators = _required_validators;
        emit RequiredValidatorsChanged(msg.sender, old, required_validators);
    }
```
```javascript
SettlementSignatureVerifier>>
    function set_required_validators_num(
        uint256 _required_validators
    ) external virtual onlyRole(MANAGER_ROLE) {
        uint256 old = required_validators;
        required_validators = _required_validators;
        emit RequiredValidatorsChanged(msg.sender, old, required_validators);
    }

```
## Tools Used
Manual

## Recommended Mitigation Steps
When we update `set_required_validators_num` in settlement, we should trigger SettlementSignatureVerifier::set_required_validators_num() to take effect.
