# Vulnerability details

## Impact
THe users that have locked funds in the protocol by initiating transactions, cannot get the funds back in case the transaction verification fails




## Description
Users initiate cross-chain transactions by calling `cross_chain_erc20_settlement()` and locking `amount` of tokens. After that off-chain validators confirm, sign the data and [call `receive_cross_chain_callback()` to execute it](https://github.com/code-423n4/2024-08-chakra/blob/main/solidity/handler/contracts/ChakraSettlementHandler.sol#L365). 

Problem is that if the transaction is marked FAILED for some reason there is no way for the funds to be withdrawn leaving them stuck in the contract.

## Tools Used
Manual review

## Recommended Mitigation Steps
Add an additional step in the flow (a new function) so that the owner of locked funds can withdraw them if their submitted cross-chain transaction was FAILED and was not relayed.
