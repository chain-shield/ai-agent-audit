# Vulnerability details

## Impact

In the current implementation of `ChakraSettlementHandler`, the function `cross_chain_erc20_settlement()` serves as an entry point for users to send cross-chain transactions. The problem is that, when creating `CreatedCrossChainTx` for a txId and saving it in `create_cross_chain_txs`, the protocol makes a mistake by storing `address(this)` as `from_token` parameter when in reality it's an address of the `from_handler`

## Proof of Concept

Take a look at the current functionality of `cross_chain_erc20_settlement()`:

https://github.com/code-423n4/2024-08-chakra/blob/main/solidity/handler/contracts/ChakraSettlementHandler.sol#L268#L154-164
```
 create_cross_txs[txid] = CreatedCrossChainTx(
                txid,
                chain,
                to_chain,
                msg.sender,
                to,
                address(this),
                to_token,
                amount,
                CrossChainTxStatus.Pending
            );

```

The struct has `address(this)` parameter on the place where `token` of the handler contract should be:

https://github.com/code-423n4/2024-08-chakra/blob/main/solidity/handler/contracts/BaseSettlementHandler.sol#L59
```
  struct CreatedCrossChainTx {
        uint256 txid;
        string from_chain;
        string to_chain;
        address from;
        uint256 to;
        address from_token;
        uint256 to_token;
        uint256 amount;
        CrossChainTxStatus status;
    }

```

This would result in storing an incorrect information about cross-chain tx and violation of the spec. Moreover, it might potentially affect offchain services as the same mistake is repeated when emitting an event:

https://github.com/code-423n4/2024-08-chakra/blob/main/solidity/handler/contracts/ChakraSettlementHandler.sol#L268#L212-222
```
  emit CrossChainLocked(
            txid,
            msg.sender,
            to,
            chain,
            to_chain,
            address(this),
            to_token,
            amount,
            mode
        );
```


## Tools Used

Manual review.

## Recommended Mitigation Steps

Change `address(this)` parameter on `token` that corresponds to the token of the settlement handler contract.
