# Vulnerability details


## Summary
The `ChakraSettlementHandler` contract implements multiple settlement modes in the `receive_cross_chain_msg` function, but only handles the `MintBurn` mode in the callback function. This inconsistency can lead to incomplete or incorrect processing of cross-chain transactions for modes other than `MintBurn`.

## Description

In the `ChakraSettlementHandler.sol` contract, we observe the following:

The `receive_cross_chain_msg` function `(lines 300-355)` implements four settlement modes:

- MintBurn
- LockUnlock
- LockMint
- BurnUnlock

Each mode has a specific implementation for handling incoming cross-chain messages.

However, the callback function `(lines 384-386)` only implements the `MintBurn` mode:

```solidity
if (mode == SettlementMode.MintBurn) {
    _erc20_burn(address(this), create_cross_txs[txid].amount);
}
```

This discrepancy means that while the contract can receive and process messages for all four modes, it can only complete the transaction cycle (including callback) for the `MintBurn` modeo only.


## Impact

The inconsistent handling of settlement modes between the `receive_cross_chain_msg` and callback functions can lead to several issues:

1. Incomplete Transactions: Cross-chain transactions using `LockUnlock`, `LockMint`, or `BurnUnlock` modes may not complete properly, as the callback function doesn't handle these modes.

2. Stuck Funds: In modes like `LockUnlock` or `BurnUnlock`, funds might remain locked or unprocessed due to the lack of proper callback handling.

3. Inconsistent State: The contract's state may become inconsistent across different chains if the callback doesn't properly finalize transactions for all modes.

4. Limited Functionality: The contract's advertised multi-mode functionality is effectively limited to only the `MintBurn` mode in practice.


## Recommendation

To address this issue and ensure consistent handling of all settlement modes, consider adding implementation for the other modes also.

Expand the callback function to handle all implemented modes:

```solidity
if (mode == SettlementMode.MintBurn) {
    _erc20_burn(address(this), create_cross_txs[txid].amount);
} else if (mode == SettlementMode.LockUnlock) {
    // Implement LockUnlock callback logic
} else if (mode == SettlementMode.LockMint) {
    // Implement LockMint callback logic
} else if (mode == SettlementMode.BurnUnlock) {
    // Implement BurnUnlock callback logic
}
```
