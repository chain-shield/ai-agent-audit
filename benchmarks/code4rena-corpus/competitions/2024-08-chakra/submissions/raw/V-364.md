# Vulnerability details

## Impact
The actual amount minted will be much smaller than intended.

## Proof of Concept
The mint_to function performs a balance check using the equation new_balance == old_balance + amount:

```
    fn mint_to(ref self: ContractState, to: ContractAddress, amount: u256) -> bool {
            let caller = get_caller_address();
            assert(self.chakra_operators.read(caller) == 1, Errors::NOT_OPERATOR);
            let old_balance = self.erc20.balance_of(to);
            self.erc20.mint(to, amount);
            let new_balance = self.erc20.balance_of(to);
            return new_balance == old_balance + amount;
        }
```

An overflow could occur if old_balance + amount exceeds the maximum value that can be stored in a u256 (2^256 - 1).

Assume the current balance of an address is close to the maximum u256 value.
Calling mint_to function with an amount that, when added to the current balance, would exceed 2^256 - 1 and cause an overflow.
