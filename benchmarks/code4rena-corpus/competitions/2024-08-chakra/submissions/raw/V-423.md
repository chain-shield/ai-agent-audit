# Vulnerability details

## Impact
An attacker can replay signatures to receive cross chain message and settlement.

## Proof of Concept
`SettlementSignatureVerifier.sol#verifyECDSA()` function is as follows.
```solidity
    function verifyECDSA(
        bytes32 msgHash,
        bytes calldata signatures
    ) internal view returns (bool) {
        require(
            signatures.length % 65 == 0,
            "Signature length must be a multiple of 65"
        );

        uint256 len = signatures.length;
        uint256 m = 0;
        for (uint256 i = 0; i < len; i += 65) {
            bytes memory sig = signatures[i:i + 65];
            if (
                validators[msgHash.recover(sig)] && ++m >= required_validators
            ) {
                return true;
            }
        }

        return false;
    }
```
As we can see above, there is no check for duplication of validators of signatures.   
So an attacker can replay signatures.

            "Signature length must be a multiple of 65"

            bytes memory sig = signatures[i:i + 65];

+           require(!flag[t]);
+           flag[t] = true;
