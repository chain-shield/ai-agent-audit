# Vulnerability details

Note: In this submission, the vulnerability is referred to the solidity codebase, but this can apply also for the Cairo codebase.

## Vulnerability details 
In `'ChakraSettlement:send_cross_chain_msg'` there is not access control, and this can lead to DoS attack by malicious users that could call repeatedly this function in order to create a `'CrossChainMsg'` event that will be constantly supervised by validators. 

This is amplified by the fact that the gas value to use in order to call `'ChakraSettlement:send_cross_chain_msg'` is pretty low.

## Impact
A DoS attack can influence the activity of the validators, that may not process the  legit transactions in certain moments, leaving them in a pending status very long. 

## Proof of Concept
Here there is a test (done in Foundry) when a malicious users calls `'ChakraSettlement:send_cross_chain_msg'` multiples times (1000 times).  
```solidity 
function test_sendCrossChainTx_Directly_ManyTimes() public {
vm.selectFork(arbFork);
address marco = address(123); 
vm.startPrank(marco); 
for(uint256 i = 0; i < 1000; i++){
chakraSettlementArb.send_cross_chain_msg("Ethereum", marco, uint160(address(chakraSettlementHandlerEth)), PayloadType.ERC20, "");
}
}
```

## Tools Used
Manual review, Foundry

## Recommended Mitigation Steps
Since `'ChakraSettlement:send_cross_chain_msg'` is supposed to be called only by the handler contract, implement an access control that requires that the sender is a valid handler contract. 

Consider adding this modifier in `'ChakraSettlement'`: 
```solidity
modifier IsValidHandler(address handler) {
require(isValidHandler[handler] == true, "Not a valid handler"); 
_;
}
```

And then implement this modifier in `'ChakraSettlement:send_cross_chain_msg'`: 

```solidity
function send_cross_chain_msg(
        string memory to_chain,
        address from_address,
        uint256 to_handler,
        PayloadType payload_type,
        bytes calldata payload
    ) external IsValidHandler(msg.sender){
        nonce_manager[from_address] += 1; 

        address from_handler = msg.sender;

        uint256 txid = uint256(
            keccak256(
                abi.encodePacked(
                    contract_chain_name, // from chain
                    to_chain,
                    from_address, // msg.sender address
                    from_handler, // settlement handler address
                    to_handler,
                    nonce_manager[from_address]
                )
            )
        );

        create_cross_txs[txid] = CreatedCrossChainTx(
            txid,
            contract_chain_name,
            to_chain,
            from_address,
            from_handler,
            to_handler,
            payload,
            CrossChainMsgStatus.Pending
        );

        emit CrossChainMsg(
            txid,
            from_address,
            contract_chain_name,
            to_chain,
            from_handler,
            to_handler,
            payload_type,
            payload
        );
    }
```
