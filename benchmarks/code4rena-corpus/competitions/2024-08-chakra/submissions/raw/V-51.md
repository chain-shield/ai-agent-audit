# Vulnerability details

## Summary
The `to_chain` is used to generate the unique  `txid` while sending the cross chain msg but there is no check whether string has value or not. Which leads to txid number will unintended.


## Impact
The `txid` number which will be un-intended than the expected.

## Proof of Concept
Please check for `@audit check here` comment in the below POC.

## Recommended Mitigation Steps
Implement the check whether the `to_chain` string is zero value or not to avoid unintended `txid` number in `send_cross_chain_msg()` function.
