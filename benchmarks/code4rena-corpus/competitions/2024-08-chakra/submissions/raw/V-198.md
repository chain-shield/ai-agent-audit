# Vulnerability details

## Impact
`ChakraSettlement` contract is based on the UUPS pattern, where initialize function is called through the proxy contract by the owner of the proxy contract. However, the `initialize` function is a public function and can be called by anyone. So `initialize` function can be called by anyone before the owner of the proxy contract calls it. This can lead to unexpected behavior in the contract.

## Tools Used
Manual Review

## Recommended Mitigation Steps
To fix this, OpenZeppelin provides the function `_disableInitializers()` that must be executed in the constructor of the implementation contract. Refer to [Rareskills Blog on UUPS (ERC-1822)](https://www.rareskills.io/post/uups-proxy#:~:text=The%20contract%20that%20implements%20the,with%20the%20ERC%2D1967%20standard.) for better understanding and `selfdestruct` attack.

Similar behavior is also observed in `SettlementSignatureVerifier`
