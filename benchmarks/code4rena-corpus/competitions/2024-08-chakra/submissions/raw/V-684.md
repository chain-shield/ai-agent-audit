# Vulnerability details

### Summary
A vulnerability exists in the cross-chain transaction system where validators are responsible for paying gas fees on behalf of users. This "no-gas fees execution" model can be exploited by users, resulting in a financial burden on validators. The vulnerability stems from the fact that users can generate an excessive number of transactions, particularly between chains like BSC and Ethereum, without incurring any direct costs themselves.

### Vulnerability Details
- **No-gas fees execution model**: Users are not required to pay for the gas fees in cross-chain transactions.
- **Validator responsibility**: Validators are tasked with covering the gas fees for transactions initiated by users.
- **Abuse scenario**: A user could exploit this by initiating numerous transactions, effectively offloading the gas cost burden onto validators. This creates a potential attack vector where users could spam transactions, especially between chains that have varying gas costs (e.g., BSC to Ethereum).

### Impact
The financial loss for validators could be significant, as they are responsible for covering gas fees without any cost to the user. This may result in:
- **Loss of funds for validators**: Validators could lose substantial amounts of money due to gas costs.
- **System instability**: If validators face excessive financial pressure, they may leave the network, causing disruptions to the cross-chain transaction service.
- **Increased transaction delays**: Overburdened validators may lead to slower transaction processing times.

### Tools Used
Manual Review

### Recommendations
- **Rate limiting**: Implement a rate limit on the number of cross-chain transactions a single user can initiate within a given time frame to prevent spamming.
- **Deposit or fee model**: Introduce a user deposit or a fee system where users pay a portion of the gas fees or provide collateral, which can be refunded or partially used for gas costs.
- **Validator reimbursement**: Create a system to reimburse validators for gas fees from a shared pool funded by transaction fees or network incentives.
