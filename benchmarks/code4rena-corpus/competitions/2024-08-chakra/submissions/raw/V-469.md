# Vulnerability details

## Impact
Function `settlement.receive_cross_chain_msg` is used to retrive token on starknet chain, because the function lacks of checking if a cross messages has already been executed, a malicious user can keep calling the function with the same parateters to steal tokens

## Proof of Concept
Unlike function `ChakraSettlement.receive_cross_chain_msg`, which checks if the cross-chain-message-id's status is `CrossChainMsgStatus.Unknow` in [ChakraSettlement.sol#L199-L203](https://github.com/code-423n4/2024-08-chakra/blob/d0d45ae1d26ca1b87034e67180fac07ce9642fd9/solidity/settlement/contracts/ChakraSettlement.sol#L199-L203).

The cairo version function `settlement.receive_cross_chain_msg` doesn't have such check, and the function doesn't check if a cross-chain-message has been executed.

Because lacking of such checks, the malicious user can steal token by keeping calling `settlement.receive_cross_chain_msg` with a same set of valid parameters.
