# Vulnerability details

### Summary
The `cross_chain_erc20_settlement` function is responsible for initiating cross-chain ERC20 token transfers. It interacts directly with user tokens without explicit authorization for each transaction.

The function uses `_erc20_lock` or `_erc20_burn` to handle tokens, which in turn call `_safe_transfer_from` or directly burn tokens. However, there's no check to ensure that the contract has sufficient allowance from the user for each specific transaction.

    } else if (mode == SettlementMode.LockMint) {
        _erc20_lock(msg.sender, address(this), amount);
    } else if (mode == SettlementMode.BurnUnlock) {
        _erc20_burn(msg.sender, amount);

}

### Impact
1. Unauthorized token spending: If a user has previously approved a large amount of tokens to the contract, anyone could initiate transfers up to that amount without the user's explicit consent for each transaction.
2. Potential for front-running attacks: Malicious actors could monitor pending transactions and front-run them with unauthorized transfers.

### Scenario
1. Alice approves 1000 tokens to the contract, intending to make several small transfers over time.
2. Alice initiates a transfer of 100 tokens.
3. Bob sees Alice's pending transaction and quickly submits a transaction to transfer 900 of Alice's tokens to himself on another chain.
4. Both transactions could potentially succeed, with Alice losing more tokens than intended.

### Fix
Implement a per-transaction approval system:

1. Require users to sign messages approving each specific cross-chain transfer.
2. Verify the signature in the `cross_chain_erc20_settlement` function before proceeding with the transfer.


```solidity
function cross_chain_erc20_settlement(
    string memory to_chain,
    uint256 to_handler,
    uint256 to_token,
    uint256 to,
    uint256 amount,
    uint256 deadline,
    uint8 v,
    bytes32 r,
    bytes32 s
) external {
    require(block.timestamp <= deadline, "Transaction expired");
    
    bytes32 messageHash = keccak256(abi.encodePacked(
        address(this),
        to_chain,
        to_handler,
        to_token,
        to,
        amount,
        deadline
    ));
    bytes32 ethSignedMessageHash = keccak256(abi.encodePacked("\x19Ethereum Signed Message:\n32", messageHash));
    address signer = ecrecover(ethSignedMessageHash, v, r, s);
    
    require(signer == msg.sender, "Invalid signature");
    
    // Proceed with the original function logic
    // ...
}
```
