# Vulnerability details

## Impact
The state of transactions are updated with the wrong token address this can lead to unexpected error and a possible loss of funds.

I am reporting this as a High severity because the Chakra Validators are heavily dependent on event emitted from the contracts.

## Proof of Concept
`ChakraSettlementHandler::cross_chain_erc20_settlement(...)` is called to initiate a cross chain ERC20 settlement. When this happens, `create_cross_txs[txid]` is updated for the created `txid` with details of the transaction including the token of the source chain where the transaction is created.

However, instead of using token of the source chain, the `ChakraSettlementHandler` address is wrongly used as the address of the token as shown below. Also, the event emitted is used by the chakra validators offchain and this error is contained in this event
