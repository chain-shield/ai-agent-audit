# Vulnerability details

## Impact
The missing validation of the `to_chain` and `to_handler` during cross-chain ERC20 settlement results in eventual transaction failures and also goes against the protocol requirement that these values must be valid for each other.

## Proof of Concept
In the `cross_chain_erc20_settlement()` function, the `chain` and `handler` are not validated

The function [`is_valid_handler()`](https://github.com/code-423n4/2024-08-chakra/blob/abef77d95866f2fec93270491fc5abc9ab14f86d/solidity/handler/contracts/ChakraSettlementHandler.sol#L41-L46) checks if a `handler` is valid for a given `chain`:
```solidity
    function is_valid_handler(
        string memory chain_name,
        uint256 handler
    ) public view returns (bool) {
        return handler_whitelist[chain_name][handler];
    }
```
The same goes for [`is_valid_handler()`](https://github.com/code-423n4/2024-08-chakra/blob/abef77d95866f2fec93270491fc5abc9ab14f86d/cairo/handler/src/handler_erc20.cairo#L234-L236) which is used in [`handle_erc20::cross_chain_erc20_settlement()`](https://github.com/code-423n4/2024-08-chakra/blob/abef77d95866f2fec93270491fc5abc9ab14f86d/cairo/handler/src/handler_erc20.cairo#L168) to validate the  `to_chain` and  `to_handler` provided during initialization of cross-chain ERC20 settlement
```solidity
    assert(self.support_handler.read((to_chain, to_handler)), 'not support handler');
```

However, in [`ChakraSettlementHandler::cross_chain_erc20_settlement()`](https://github.com/code-423n4/2024-08-chakra/blob/abef77d95866f2fec93270491fc5abc9ab14f86d/solidity/handler/contracts/ChakraSettlementHandler.sol#L111), this check is not performed:
The function just uses the `to_chain` and  `to_handler` provided as they are without performing any validations.

As such, an invalid `to_handler` for the given `to_chain` may be used which may result in failed transactions.

## Tools Used
Manual Review

## Recommended Mitigation Steps
Validate the `to_chain` and `to_handler` in the `ChakraSettlementHandler::cross_chain_erc20_settlement()`:
```diff
        require(to_handler != 0, "Invalid to handler address");
        require(to_token != 0, "Invalid to token address");
+       require(is_valid_handler(to_chain, to_handler), "Invalid handler");
```
