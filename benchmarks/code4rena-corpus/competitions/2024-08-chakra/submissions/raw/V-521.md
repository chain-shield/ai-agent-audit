# Vulnerability details

## Impact

Function is incorrectly written, users will not be able to burn their tokens.

## Proof of Concept

The burn function in ChakraToken is written as such:

```
    function burn(uint256 value) external onlyRole(OPERATOR_ROLE) {
        _burn(_msgSender(), value);
    }
```

It calls the `_burn()` function with `_msgSender()` as the caller. As such, the `onlyRole(OPERATOR_ROLE)` is not needed here, otherwise only the OPERATOR_ROLE can burn their own tokens.

Typically, if an ERC20 contract implements a burn function, it will be public and only allow the `msgSender()` to burn his own tokens.

## Tools Used

Manual Review

## Recommended Mitigation Steps

Remove the `onlyRole` modifier.

```
    function burn(uint256 value) external {
        _burn(_msgSender(), value);
    }
```
