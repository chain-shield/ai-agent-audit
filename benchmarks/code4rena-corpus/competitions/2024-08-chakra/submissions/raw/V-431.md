# Vulnerability details

## Impact

The current functionality of the `handler_erc20` does not set status MINTED for the Mint / Burn mode not handling the callback properly. This can lead to a violation of the spec and potential misbehavior as the information is monitored by the off-chain services.

## Proof of Concept

Take a look at how `CrossChainTxStatus` is set at the moment for the Mint / Burn mode:

https://github.com/code-423n4/2024-08-chakra/blob/main/cairo/handler/src/handler_erc20.cairo#L161
```
   tx_status: CrossChainTxStatus::SETTLED
```

However, according to the spec, status MINTED should be assigned:


https://github.com/code-423n4/2024-08-chakra/blob/main/cairo/handler/src/constant.cairo#L35-41
```
pub mod CrossChainTxStatus{
    pub const UNKNOW: u8 = 0;
    pub const PENDING: u8 = 1;
    pub const MINTED: u8 = 2;
    pub const SETTLED: u8 = 3;
    pub const FAILED: u8 = 4;
}
```

## Tools Used

Manual review.

## Recommended Mitigation Steps

Assign status MINTED if the transaction was for Mint / Burn mode.
