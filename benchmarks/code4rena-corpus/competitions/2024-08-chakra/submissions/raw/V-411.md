# Vulnerability details

## Impact
Cairo implementation of Erc20 Handler (`handler_erc20.cairo`) is missing a validation for cross-chain settlement parameters and thus breaks the following invariant: 

"Cross-chain ERC20 settlements can only be initiated with a valid amount (greater than 0), a valid recipient address, a valid handler address, and a valid token address."

None of the parameters are validated at all (it is checked if the handler address is whitelisted) and therefore it is possible to create and trigger multiple transactions where the `amount=0` thus causing a network congestion and possibly DoS the protocol. 

## Tools Used
Manual review, VS Code

## Recommended Mitigation Steps
Add validation for all parameters: 

`assert(amount > 0, 'Invalid amount')`
`assert(to_handler != 0, 'Invalid to_handler')`
`assert(to_token != 0, 'Invalid to_token')`
`assert(to != 0, 'Invalid to address')`
