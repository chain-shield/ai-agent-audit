# Vulnerability details

## Impact
Function ChakraSettlementHandler.cross_chain_erc20_settlement() - Initiates a cross-chain ERC20 settlement. However, an error occurred when mode == SettlementMode.MintBurn.

## Proof of Concept
The ChakraSettlementHandler.cross_chain_erc20_settlement() function states:
https://github.com/code-423n4/2024-08-chakra/blob/main/solidity/handler/contracts/ChakraSettlementHandler.sol#L124
if (mode == SettlementMode.MintBurn) {
_erc20_lock(msg.sender, address(this), amount);
}
However, in MintBurn mode, _erc20_mint must be executed.
This will result in incorrect cross-chain service interaction.

## Tools Used
Manual review

## Recommended Mitigation Steps
Replace with _erc20_mint function.
