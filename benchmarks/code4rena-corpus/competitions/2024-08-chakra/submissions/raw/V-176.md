# Vulnerability details

## Impact
- Incorrect slice length 
The slice may contain too many or too few elements.

- Potential out-of-bounds access
If begin + end exceeds the source array's length, it may cause runtime errors or undefined behavior.

- Unexpected results
Users of this function will likely get slices that don't match their intentions.

## Proof of Concept
The u128_array_slice function in the codebase contains a critical bug in its length calculation. The function is designed to create a slice of a u128 array, but it incorrectly calculates the length of the slice.

```
fn u128_array_slice(src: @Array<u128>, mut begin: usize, end: usize) -> Array<u128> {
    let mut slice = ArrayTrait::new();
    let len = begin + end;
    loop {
        if begin >= len {
            break ();
        }
        if begin >= src.len() {
            break ();
        }

        slice.append(*src[begin]);
        begin += 1;
    };
    slice
}
```

## Recommended Mitigation Steps
The function should be revised to clearly define the meaning of the end parameter. Two possible corrections are:

If end should represent the number of elements:

```
let len = begin + end;
if len > src.len() {
    len = src.len();
}
```


If end should represent the end index:
```
let len = end;
if len > src.len() {
    len = src.len();
}
```
