# Vulnerability details

## Impact

The settlement handler contract lacks a refund mechanism for users whose cross-chain transactions have failed. When a cross-chain transaction encounters an unexpected error and the status is marked as `Failed`, users are unable to withdraw their locked tokens, leading to loss of funds.

## Proof of Concept

If an error occurs during the cross-chain settlement process, for example, the handler of target chain does not have sufficient tokens to be unlocked, the `create_cross_txs[txid].status` is [set to `Failed`](https://github.com/code-423n4/2024-08-chakra/blob/abef77d95866f2fec93270491fc5abc9ab14f86d/solidity/handler/contracts/ChakraSettlementHandler.sol#L391-L393).

However, the settlement handler does not provide a way for users to retrieve their tokens once a transaction is marked as `Failed`.

## Tools Used
vscode

## Recommended Mitigation Steps

Implement a refund function within the settlement handler contract that allows users to withdraw their locked tokens if their cross-chain transaction is marked as `Failed`.
