# Vulnerability details

## Impact
The lack of access control on the `send_cross_chain_msg()` function allows unauthorized users to emit cross-chain events without locking or burning tokens, leading to malicious actors unlock tokens for free on the target chain.

## Proof of Concept

According to the contract's design, this function should only be called by the `ChakraSettlementHandler`, which manages the necessary token lock and burn operations before any cross-chain message is sent.

However, the current implementation of `send_cross_chain_msg()` does not enforce any access control.

## Recommended Mitigation Steps

Ensure the `send_cross_chain_msg()` function can be called by the `ChakraSettlementHandler` only.
