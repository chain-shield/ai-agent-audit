# Vulnerability details

## Impact
According to the description of Chakra operation, two pairs of contracts are used for cross-chain interaction: Chakra Settlement Contract and SettlementHandlerContract.

The ChakraSettlement.receive_cross_chain_msg() function checks the condition:

https://github.com/code-423n4/2024-08-chakra/blob/main/solidity/settlement/contracts/ChakraSettlement.sol#L199-L202
require(
receive_cross_txs[txid].status == CrossChainMsgStatus.Unknow,
"Invalid transaction status"
);

Cross-chain messages will not be executed.

## Proof of Concept
The ChakraSettlement.receive_cross_chain_msg() function will fail because the transaction txid is not known on another chain in the Chakra Settlement Contract and SettlementHandlerContract. It is not possible to verify that this transaction has the Unknow status. Chakra will not work in cross-chain communication.

This may also lead to transactions being executed multiple times.

## Tools Used
Manual review

## Recommended Mitigation Steps
Add a shared storage for Chakra contracts where created transactions will be received.
