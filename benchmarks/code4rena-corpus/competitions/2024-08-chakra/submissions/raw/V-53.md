# Vulnerability details

## Impact:
Gas Limit Exceeded in _Settlement_init Function:
The function _Settlement_init includes a loop that iterates through the _managers array to assign roles. If the array is too large, this operation could exceed the gas limit, resulting in a failed transaction.
Affected Code:
for (uint256 i = 0; i < _managers.length; i++) {
    _grantRole(MANAGER_ROLE, _managers[i]);
}
link to code:https://github.com/code-423n4/2024-08-chakra/blob/main/solidity/settlement/contracts/BaseSettlement.sol#L66-L68

External Call Vulnerabilities in add_validator and remove_validator Functions:
Both functions make external calls to the signature_verifier contract. If this contract is compromised or behaves unexpectedly, it could lead to a denial of service.
Affected Code:
signature_verifier.add_validator(validator);
link to code:https://github.com/code-423n4/2024-08-chakra/blob/main/solidity/settlement/contracts/BaseSettlement.sol#L89
signature_verifier.remove_validator(validator);
link to code:https://github.com/code-423n4/2024-08-chakra/blob/main/solidity/settlement/contracts/BaseSettlement.sol#L106

Potential Overhead in set_required_validators_num Function:
Changing the number of required validators may cause performance issues if it leads to excessive gas consumption or impacts contract operations.
Affected Code:

## Recommended Mitigation Steps
Limit Array Size:
Mitigation: Implement restrictions to limit the size of arrays like `_managers` to avoid excessive gas consumption. For example, set a maximum number of managers that can be added.
// Adding a constant for the maximum number of managers
uint256 public constant MAX_MANAGERS = 100;

function _Settlement_init(address[] memory _managers) internal {
    require(_managers.length <= MAX_MANAGERS, "Too many managers");
    for (uint256 i = 0; i < _managers.length; i++) {
        _grantRole(MANAGER_ROLE, _managers[i]);
    }
}

Optimize External Calls:
Mitigation: Ensure that external contracts like `signature_verifier` are secure and reliable. Implement checks to handle failures from external calls gracefully.

Monitor Gas Consumption:
Mitigation: Regularly review and optimize gas consumption for critical functions. Use gas-efficient algorithms and avoid operations that could lead to high gas costs.
// Optimizing gas usage for critical functions
function set_required_validators_num(uint256 _required_validators) external {
    require(_required_validators > 0, "Invalid number of validators");
    require(_required_validators <= MAX_VALIDATORS, "Exceeds max validators");
    uint256 old = required_validators;
    required_validators = _required_validators;
    emit RequiredValidatorsUpdated(old, _required_validators);
}

event RequiredValidatorsUpdated(uint256 oldValue, uint256 newValue);

Batch Operations:
Mitigation: Break down tasks into smaller, manageable chunks to avoid exceeding gas limits. For instance, consider batching operations or processing them in multiple transactions.
