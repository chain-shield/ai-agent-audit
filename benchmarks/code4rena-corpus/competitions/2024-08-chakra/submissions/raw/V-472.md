# Vulnerability details

## Impact
This breaks core protocol functionality and invariant.

## Proof of Concept
The `utils::u64_array_slice` function is used to create array slice containing elements from a `begin` index to (but not including) an `end` index. 

However, due a missing check in the loop, the slice can contain elements even beyond the end index. This is because the loop does not break when `begin` is greater than or equal to `end`

```rust
File: utils.cairo
444: fn u64_array_slice(src: @Array<u64>, mut begin: usize, end: usize) -> Array<u64> {
445:     let mut slice = ArrayTrait::new();
446:     let len = begin + end;
447:     loop {
448:         if begin >= len {
449:             break ();
450:         }
451:         if begin >= src.len() {
452:             break ();
453:         }
454: 
455:         slice.append(*src[begin]);
456:         begin += 1;
457:     };
458:     slice 
459: }

```

The problem is that the function can return a sliced array that contains elements beyond and including the `end` index thus breaking the intended functionality.

**SCENARIO**
- Consider and array with `src` = 8 elements
- `begin` = 2 and `end` = 4
- `len = begin + end` = 6
- the `slice` is suppose to contain only elements at index 2 and 3 , but the loop iterates 5 times and add 5 elements from index 2 to 6.
- the function returns 5 elements instead of 2
