# Vulnerability details

## Impact
The txid is intended to be unique and deterministic, allowing the system to track and verify cross-chain transactions securely. However, an issue arises when the to_handler is invalid or incorrectly specified.

Using an invalid to_handler will result in transactions being routed to non-existent or incorrect destinations. If to_handler is set to a zero address (address(0)), any cross-chain transaction relayed to this handler could be lost, leading to a loss of assets or the failure of the cross-chain operation.
