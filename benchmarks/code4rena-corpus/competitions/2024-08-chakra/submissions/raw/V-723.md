# Vulnerability details

## Impact
The `cross_chain_erc20_settlement` function lacks proper access controls. This vulnerability allows any external actor to initiate cross-chain settlements, potentially leading to unauthorized token transfers, manipulation of cross-chain state, and financial losses.

## Proof of Concept
In the Solidity implementation:

```solidity
function cross_chain_erc20_settlement(
    string memory to_chain,
    uint256 to_handler,
    uint256 to_token,
    uint256 to,
    uint256 amount
) external {     // No access control checks
    // ...
}
```

## Tools Used
Manual code review

## Recommended Mitigation Steps
Modify the function to include an access control check:

   For Solidity:
   ```solidity
   function cross_chain_erc20_settlement(
       string memory to_chain,
       uint256 to_handler,
       uint256 to_token,
       uint256 to,
       uint256 amount
   ) external onlyRole(OPERATOR_ROLE) {
       // ...
   }
   ```
