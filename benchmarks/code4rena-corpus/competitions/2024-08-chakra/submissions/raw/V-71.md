# Vulnerability details

## Impact

`TokenRoles` contract is the contract that helps to add / remove operators. However, the initialization function can be called by anybody and anybody can change the owner of the contract.

## Proof of Concept

Current functionality of the initialization:

https://github.com/code-423n4/2024-08-chakra/blob/main/solidity/handler/contracts/TokenRoles.sol#L19-23
```
    function __TokenRoles_init(address _owner, address _operator) public {
        __Ownable_init(_owner);
        _grantRole(DEFAULT_ADMIN_ROLE, _owner);
        _grantRole(OPERATOR_ROLE, _operator);
    }
```

As you can see, the function has `public` visibility meaning anybody can call the function and initialize it by, for example, front-running the owner. 

## Tools Used

Manual review.

## Recommended Mitigation Steps

The owner of the contract should be set in the constructor and only he can call the initialization functionality.


## Assessed type

Access Control
