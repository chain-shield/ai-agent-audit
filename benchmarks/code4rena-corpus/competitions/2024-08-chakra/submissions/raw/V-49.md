# Vulnerability details

## Impact
Detailed description of the impact of this finding.
there is no check of the balance of _to, the function does not check or update any user balances. If users are interacting with this function after transferring all their tokens out (through another mechanism), they could potentially transfer tokens they shouldn't be able to access.

 function _safe_transfer_from(
        address from,
        address to,
        uint256 amount
    ) internal {
        require(
            IERC20(token).balanceOf(from) >= amount,
            "Insufficient balance"
        );

        // transfer tokens
        IERC20(token).transferFrom(from, to, amount);
    }

    function _safe_transfer(address to, uint256 amount) internal {
        require(
            IERC20(token).balanceOf(address(this)) >= amount,
            "Insufficient balance"
        );

        // transfer tokens
        IERC20(token).transfer(to, amount);
    }
