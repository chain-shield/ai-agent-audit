# Vulnerability details

## Impact
Users are minted more tokens when the ChakraToken custom decimals are lesser on the destination chain.

## Proof of Concept

We know ChakraToken supports custom decimals. 
```solidity
contract ChakraToken is ERC20Upgradeable, TokenRoles, IERC20Mint, IERC20Burn {
    // Custom decimals for the token
    uint8 set_decimals; 
```

When a cross_chain_erc20_settlement() call occurs, it encodes the source amount. But when the msg is received on destination, it does not round down the amount to correct decimalas
