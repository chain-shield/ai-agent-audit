# Vulnerability details

## Impact
The contract uses abi.decode with uint256 for decoding addresses (from, to, from_token, to_token). However, Ethereum addresses are 20 bytes (160 bits) long, not 32 bytes. Using uint256 will result in incorrect decoding of addresses, leading to potential security vulnerabilities such as incorrectly decoded addresses, which could result in token transfers being sent to wrong or invalid addresses.

## Proof of Concept
The deocde_transfer() function decodes addresses as uint256, but addresses are only 20 bytes long (160 bits). For example, if the address is supposed to be 0xec5e27beCbf4731Cd18B33AB95Dcd3cF0e63B2e6, this function will misinterpret the payload and return an incorrect address, leading to tokens being transferred to the wrong address.

## Tools Used
Manual

## Recommended Mitigation Steps
Use address type (20 bytes) for addresses instead of uint256 (32 bytes) in both the encode_transfer() and deocde_transfer() functions.

```
function deocde_transfer(
    bytes calldata _payload
) external pure returns (ERC20TransferPayload memory transferPayload) {
    transferPayload.method_id = ERC20Method(uint8(_payload[0]));
    transferPayload.from = abi.decode(_payload[1:21], (address)); // Address is 20 bytes
    transferPayload.to = abi.decode(_payload[21:41], (address));  // Address is 20 bytes
    transferPayload.from_token = abi.decode(_payload[41:61], (address));  // Address is 20 bytes
    transferPayload.to_token = abi.decode(_payload[61:81], (address));    // Address is 20 bytes
    transferPayload.amount = abi.decode(_payload[81:113], (uint256));
}
```
```
function encode_transfer(
    ERC20TransferPayload memory _payload
) external pure returns (bytes memory encodedPaylaod) {
    encodedPaylaod = abi.encodePacked(
        _payload.method_id,
        address(_payload.from),    // Encode as 20-byte address
        address(_payload.to),      // Encode as 20-byte address
        address(_payload.from_token),  // Encode as 20-byte address
        address(_payload.to_token),    // Encode as 20-byte address
        _payload.amount
    );
}
```
