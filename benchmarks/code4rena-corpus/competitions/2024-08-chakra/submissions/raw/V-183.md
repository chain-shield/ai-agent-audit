# Vulnerability details

## Impact

The function `receive_cross_chain_callback` lacks comprehensive error handling for the `mode` and `status` parameters. This deficiency can lead to incorrect behavior or silent failures when encountering unexpected or invalid values.

**Summarry:**

1. **Error Handling for `mode`:**
    - **Issue:** The function performs operations based on the `mode` parameter (e.g., burning tokens). However, there is no explicit validation to ensure that `mode` is one of the expected values (e.g., `SettlementMode.MintBurn`). If an invalid `mode` is provided, the function may proceed without proper error handling, leading to incorrect or unintended operations.
    - **Improvement Needed:** Implement validation to check if `mode` is valid before performing operations. Emit an event and revert the transaction if an invalid `mode` is encountered.
2. **Error Handling for `status`:**
    - **Issue:** The function handles only two statuses: `CrossChainMsgStatus.Success` and `CrossChainMsgStatus.Failed`. If the `status` parameter contains an unexpected or unsupported value, the function does not explicitly handle it, which could result in unnoticed issues or incorrect behavior.
    - **Improvement Needed:** Add handling for unexpected `status` values. Emit an event and revert the transaction if an invalid `status` is encountered.

## Proof of Concept

ChakraSettlementHandler.sol#L383-L388
```
  function receive_cross_chain_callback(
      ...
    ) external onlySettlement returns (bool) {
        //  from_handler need in whitelist
        if (is_valid_handler(from_chain, from_handler) == false) {
            return false;
        }

        require(
            create_cross_txs[txid].status == CrossChainTxStatus.Pending,
            "invalid CrossChainTxStatus"
        );

        if (status == CrossChainMsgStatus.Success) {
            if (mode == SettlementMode.MintBurn) { 
                _erc20_burn(address(this), create_cross_txs[txid].amount);
            }
            //@audit need emit event for tokens burned
            create_cross_txs[txid].status = CrossChainTxStatus.Settled;
        }

        if (status == CrossChainMsgStatus.Failed) {
            create_cross_txs[txid].status = CrossChainTxStatus.Failed;
        }

        return true;
    }
```

* Adds a fallback for unexpected status values.
