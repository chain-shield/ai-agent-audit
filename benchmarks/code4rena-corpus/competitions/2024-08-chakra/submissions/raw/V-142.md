# Vulnerability details

## Impact
If the `mode` of the settlement handler is not set correctly during the deployment of `ChakraSettlementHandler`, users can exploit the `cross_chain_erc20_settlement()` function to send cross-chain messages without locking or burning any tokens.

## Proof of Concept

The `cross_chain_erc20_settlement()` function does not revert if the `mode` is is invalid:

```solidity

127:         } else if (mode == SettlementMode.LockMint) {
128:             _erc20_lock(msg.sender, address(this), amount);
129:         } else if (mode == SettlementMode.BurnUnlock) {

```

This flaw allows users to call the `cross_chain_erc20_settlement()` function and send cross-chain messages without locking or burning any tokens, receving tokens on the target chain for free.
