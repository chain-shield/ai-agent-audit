# Vulnerability details

## Impact
In the `receive_cross_chain_callback` function of handler contract, the cross_chain_msg_status/CrossChainMsgStatus can be successful or failed. The users should lock or burn their tokens before cross-chain. If the cross_chain_msg_status/CrossChainMsgStatus is failed, there is no return of locked users' tokens and the tokens will be stuck in the handler contract. The users lost tokens with failed cross chain message.

From above code, if cross_chain_msg_status/CrossChainMsgStatus is failed, only the status of cross chain message is changed. There are no other changes.
