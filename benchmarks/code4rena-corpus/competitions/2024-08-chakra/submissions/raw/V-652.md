# Vulnerability details

## Impact
Invalid addresses with bytes length/size less than 20 will bypass all validation checks

## Proof of Concept
Ethereum valid addresses should not be less than 20 bytes of length that makes them invalid as cited [ An Ethereum address is a 42-character hexadecimal address derived from the last 20 bytes of the public key](https://info.etherscan.com/what-is-an-ethereum-address/) and [here](https://ethereum.org/en/developers/docs/accounts/)

but we can see that in out checks below;
```solidity
function to_bytes(
        bytes32 _addressBytes32,
        uint256 _size
    ) internal pure returns (bytes memory result) {
        //@audit
        if (_size == 0 || _size > 32) revert AddressCast_InvalidSizeForAddress();

```
as we can see in this casting function, the check above will only revert if the length or size of bytes is 0 or greater than 32 this means any address of size less than 20 bytes will pass the check
