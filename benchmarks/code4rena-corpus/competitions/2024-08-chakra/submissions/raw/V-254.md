# Vulnerability details

## Impact
The constants in the file used for bit manipulation (MASK_8, TWO_POW_8, etc.) can potentially cause overflows or incorrect handling of large numbers. When used improperly, these constants might result in unexpected values in cryptographic operations or arithmetic manipulations. If such issues occur in a cross-chain context or while calculating balances, it could lead to major inconsistencies, security exploits, or financial losses in the system.

## Proof of Concept
const MASK_8: u256 = 0xFF;
const TWO_POW_8: u256 = 0x100;
const TWO_POW_16: u256 = 0x10000;
const TWO_POW_24: u256 = 0x1000000;

In the above code, if these constants are applied to large data or used in calculations without sufficient range checking, they may produce incorrect results. For example, an attacker might craft input values that exploit the overflow behavior during bitwise operations.

Example: Masking large values incorrectly could potentially manipulate balances or token transfer amounts during bitwise encoding of transaction data.

1. Validate all input values before applying bitmask operations, ensuring they are within a safe range.
2. Use safe arithmetic methods or wrap operations in overflow checks.
3. Implement test cases for both normal and extreme values to ensure there are no overflows.
