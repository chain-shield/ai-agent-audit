# Vulnerability details


##  Description  +  Impact

``  TokenRoles :: __TokenRoles_init() `` is a `` public `` function without any authorization meaning that any address can execute it setting the `` owner  `` & `` operator `` of the `` ChakraToken `` contract that inherits `` TokenRoles ``

`` __TokenRoles_init() `` function has to be used as an `` internal `` function with ``onlyInitializing `` modifier because it is executed from `` initialize() `` 


This exact issue is seen in more instances like  `` BaseSettlementHandler :: _Settlement_handler_init() `` 



##  PoC


This issue is very simple to understand so a coded PoC will not make a difference. After the deployer executes `` ChakraToken :: initialize() `` that will execute ``  TokenRoles :: __TokenRoles_init() `` , any address can execute the function again with arbitrary values that will compromise the contract
