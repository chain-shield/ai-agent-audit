# Vulnerability details

## Impact
The `receive_cross_chain_callback` function in the `ChakraSettlementHandler` contract only handles the `MintBurn` settlement mode, leaving other modes such as `LockUnlock`, `LockMint`, and `BurnUnlock` unimplemented. This incomplete implementation results in incorrect cross-chain transaction behavior for any mode other than `MintBurn`. Specifically, cross-chain settlements using other modes may not properly complete, leading to issues like locked tokens, mismatched balances, and loss of funds.
When handling cross-chain transactions, each settlement mode should have distinct actions corresponding to its design. If these actions are not handled correctly, the system may leave tokens in an inconsistent state, resulting in economic imbalances and operational issues in cross-chain transfers.

## Proof of Concept
The [`receive_cross_chain_callback`](https://github.com/code-423n4/2024-08-chakra/blob/d0d45ae1d26ca1b87034e67180fac07ce9642fd9/solidity/handler/contracts/ChakraSettlementHandler.sol#L365-L396) function only includes logic for burning tokens only in `MintBurn` mode:
```solidity
    function receive_cross_chain_callback(
        uint256 txid,
        string memory from_chain,
        uint256 from_handler,
        CrossChainMsgStatus status,
        uint8 /* sign_type */, // validators signature type /  multisig or bls sr25519
        bytes calldata /* signatures */
    ) external onlySettlement returns (bool) {
        //  from_handler need in whitelist
        if (is_valid_handler(from_chain, from_handler) == false) {
            return false;
        }


        require(
            create_cross_txs[txid].status == CrossChainTxStatus.Pending,
            "invalid CrossChainTxStatus"
        );


        if (status == CrossChainMsgStatus.Success) {
            if (mode == SettlementMode.MintBurn) {
                _erc20_burn(address(this), create_cross_txs[txid].amount);
            }


            create_cross_txs[txid].status = CrossChainTxStatus.Settled;
        }


        if (status == CrossChainMsgStatus.Failed) {
            create_cross_txs[txid].status = CrossChainTxStatus.Failed;
        }


        return true;
    }
```
For other modes, such as `LockUnlock`, `LockMint`, and `BurnUnlock`, there is no specific handling or state update logic which could lead to incomplete transaction processing if additional actions are needed.

## Recommended Mitigation Steps
Extend the `receive_cross_chain_callback` function to handle all supported settlement modes (`LockUnlock`, `LockMint`, and `BurnUnlock`) to ensure that tokens are properly managed across chains.

```diff
        uint256 txid,
        string memory from_chain,
        uint256 from_handler,
        CrossChainMsgStatus status,
        uint8 /* sign_type */, // validators signature type /  multisig or bls sr25519
        bytes calldata /* signatures */
    ) external onlySettlement returns (bool) {
        //  from_handler need in whitelist
        if (is_valid_handler(from_chain, from_handler) == false) {
            return false;
        }


        require(
            create_cross_txs[txid].status == CrossChainTxStatus.Pending,
            "invalid CrossChainTxStatus"
        );


        if (status == CrossChainMsgStatus.Success) {
            if (mode == SettlementMode.MintBurn) {
                _erc20_burn(address(this), create_cross_txs[txid].amount);
            }
+           if (mode == SettlementMode.LockUnlock) {
+               _erc20_unlock(address(this), create_cross_txs[txid].amount);  // Unlock tokens on success
+           }
+           else if (mode == SettlementMode.LockMint) {
+               _erc20_mint(address(this), create_cross_txs[txid].amount);  // Mint tokens
+           } 
+           else if (mode == SettlementMode.BurnUnlock) {
+               _erc20_unlock(address(this), create_cross_txs[txid].amount);  // Unlock tokens after burn
+           }



            create_cross_txs[txid].status = CrossChainTxStatus.Settled;
        }


        if (status == CrossChainMsgStatus.Failed) {
            create_cross_txs[txid].status = CrossChainTxStatus.Failed;
        }


        return true;
    }
```
