# Vulnerability details

## Impact
Array slicing is done wrongly causing unintended values to end up in sliced array or possible out of bounds error.

## Proof of Concept
The u128_array_slice and u64_array_slice functions are intended to return a slice (sub-array) of an input array src of u128 and u64 elements, starting from a specified begin index and ending at a specified end index. However, the current implementation wrongly calculates where the slicing is meant to end leading to a wrong slicing of the array. 

```
let len = begin + end;
```
The len variable above used to determine the number of iterations of elements to be slices is calculated by adding the specified begin and end inputs. Which shouldnt be so, as in standard array slicing, the end represents the index at which the slicing stops. Therefore adding it to the begin index and using the sum as the point to stop the slicing will cause it return fewer or more elements than intended, or even fail to slice the array correctly due to an out of bounds error.

## Tools Used
Manual Review

## Recommended Mitigation Steps
Calculate the len as follows:
```
if end > src.len() {
    let len = src.len();
}else {
    let len = end;
}
```
