# Vulnerability details

## Impact
This vulnerability allows a malicious validator to break through the multi-signature verification logic by reusing the same signature into `bytes memory signatures`. Since the contract does not check whether the same validator's signature is used multiple times, the attacker can reuse the same valid signature multiple times, thereby accumulating the number of verification passes (`m`) until the required_validators condition is met.
This signature replay attack will undermine the multi-signature security mechanism of the contract, allowing malicious users to bypass the correct verification logic and perform unauthorized operations, affecting the security of funds and the integrity of the contract.

### Attack process:
- The attacker only needs to have a valid signature, even if it only meets the signature requirements of one verifier, and they can repeatedly concatenate the same signature into bytes memory signatures.
- Since there is no check for repeated signatures, ++m will be incremented every time the same signature is used repeatedly.
- When the value of `m` accumulates to required_validators , the transaction will be incorrectly considered validated.


**code[For example]:**
```solidity
    // Suppose we have a signatures variable that contains multiple identical signatures
    bytes memory signatures = abi.encodePacked(signature1, signature1, signature1); // Using the same signature three times
```

## Recommended Mitigation Steps

To prevent signature replay attacks, it is recommended to add a signature uniqueness check to the contract and ensure that each signature is used only once.

The following measures can be taken:
Track whether each validator's signature has been used through mapping or other data structures to ensure that each signature can only be counted into `m` once.

**Code[For example]:**
```solidity
mapping(address => bool) usedSignatures;

address signer = msgHash.recover(sig);
require(!usedSignatures[signer], "Signature already used");
usedSignatures[signer] = true;
```
