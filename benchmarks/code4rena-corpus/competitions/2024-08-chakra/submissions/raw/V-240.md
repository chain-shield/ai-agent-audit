# Vulnerability details

## Impact
Lack of checking the status of tx_status in received_tx mapping leads that `receive_cross_chain_msg` on Starknet can be called many times with one valid input. The tokens can be minted and unlocked without any restrictions.

## Proof of Concept
https://github.com/code-423n4/2024-08-chakra/blob/d0d45ae1d26ca1b87034e67180fac07ce9642fd9/cairo/handler/src/settlement.cairo#L325-L383
https://github.com/code-423n4/2024-08-chakra/blob/d0d45ae1d26ca1b87034e67180fac07ce9642fd9/cairo/handler/src/handler_erc20.cairo#L108-L136
From above code, if `receive_cross_chain_msg` is called successfully once, anyone can use same input to call `receive_cross_chain_msg` many times.

settlement.cairo::receive_cross_chain_msg
```diff
            assert(to_chain == self.chain_name.read(), 'error to_chain');
```
