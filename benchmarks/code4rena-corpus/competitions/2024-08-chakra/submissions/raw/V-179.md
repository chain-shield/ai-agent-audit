# Vulnerability details

## Impact
If end is meant to be the number of elements to include (rather than an end index), the slice may contain more elements than intended.

## Proof of Concept
The u128_array_slice function contains an inefficiency in its main loop. 

```
fn u128_array_slice(src: @Array<u128>, mut begin: usize, end: usize) -> Array<u128> {
    let mut slice = ArrayTrait::new();
    let len = begin + end;
    loop {
        if begin >= len {
            break ();
        }
        if begin >= src.len() {
            break ();
        }

        slice.append(*src[begin]);
        begin += 1;
    };
    slice
}
```

The loop continues until begin reaches len (which is calculated as begin + end) or exceeds src.len(), adding more elements to the slice than necessary.

## Tools Used
Manual review

## Recommended Mitigation Steps
Modify the loop to break as soon as the desired number of elements has been appended.
