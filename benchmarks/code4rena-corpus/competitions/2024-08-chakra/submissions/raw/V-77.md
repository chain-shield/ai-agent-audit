# Vulnerability details

The ChakraSettlement contract relies on external calls to the receive_cross_chain_msg and receive_cross_chain_callback functions of external handlers. These calls are not validated or checked for potential malicious behavior.
Impact
Unchecked external calls can lead to various security vulnerabilities, including:

Malicious code execution: If the external handler contains malicious code, it can be executed when the contract calls it, potentially leading to unauthorized actions, data theft, or contract manipulation.
To mitigate the risks associated with unchecked external calls, the following measures can be implemented:

Validate external handler addresses: Before calling an external handler, verify its address against a known whitelist or trusted registry. This helps prevent calls to malicious or unknown contracts.

Mitigation Examples for Unchecked External Calls in ChakraSettlement
1. Whitelist Validation:

Create a whitelist: Maintain a list of trusted external handler addresses.
Validate before calling: Before calling an external handler, check if its address is included in the whitelist.
Update whitelist regularly: Ensure the whitelist is regularly updated to include new trusted handlers and remove compromised addresses.
