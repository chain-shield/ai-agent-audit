# Vulnerability details

### M-01 Lack of Minimum Validator Requirement in `set_required_validators_num` Function

### Description:
The `set_required_validators_num` function allows a user with the `MANAGER_ROLE` to update the number of required validators for the contract. However, there is no minimum constraint enforced on the `_required_validators` value, which means it could be set to zero. Setting the number of required validators to zero can severely compromise the security of the contract, as it would effectively disable the validation mechanism, allowing any action to be considered valid without requiring any validators.

### Part of Code:
```solidity
function set_required_validators_num(
    uint256 _required_validators
) external onlyRole(MANAGER_ROLE) {
    uint256 old = required_validators;
    required_validators = _required_validators;
    emit RequiredValidatorsChanged(msg.sender, old, required_validators);
}
```
https://github.com/code-423n4/2024-08-chakra/blob/main/solidity/settlement/contracts/BaseSettlement.sol#L121

### Recommendation:
Implement a `require` statement to enforce a minimum number of validators that cannot be set to zero. This ensures the security of the contract by maintaining the integrity of the validation process.

Example update:
```solidity
function set_required_validators_num(
    uint256 _required_validators
) external onlyRole(MANAGER_ROLE) {
    require(_required_validators > 0, "Validators number cannot be zero");

    uint256 old = required_validators;
    required_validators = _required_validators;
    emit RequiredValidatorsChanged(msg.sender, old, required_validators);
}
```
