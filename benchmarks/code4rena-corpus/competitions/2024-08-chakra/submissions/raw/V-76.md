# Vulnerability details

## Impact
Please note the issue exist on both solidity and cairo code, therefore the have the same fix.
When processing a crossChain transaction and callback inside [ChakraSettlement.sol](https://github.com/code-423n4/2024-08-chakra/blob/main/solidity/settlement/contracts/ChakraSettlement.sol) there is signature verification to ensure only validators signed the message and the minimum validator signature threshold is met.
```solidity
 require(
                signature_verifier.verify(message_hash, signatures, sign_type),
                "Invalid signature"
            );
``` 

The verify signature checks that the signature type is 0 and process to call the verifyECDSA() function.

```solidity
function verify(
        bytes32 msgHash,
        bytes calldata signatures,
        uint8 sign_type
    ) external view returns (bool) {
        if (sign_type == 0) {
            return verifyECDSA(msgHash, signatures);
        } else {
            return false;
        }
    }
```

However in verifyECDSA() function there is no check to ensure a single validator did not sign multiple times to pass the threshold.
```solidity
function verifyECDSA(
        bytes32 msgHash,
        bytes calldata signatures
    ) internal view returns (bool) {
        require(
            signatures.length % 65 == 0,
            "Signature length must be a multiple of 65"
        );

        uint256 len = signatures.length;
        uint256 m = 0;
        for (uint256 i = 0; i < len; i += 65) {
            bytes memory sig = signatures[i:i + 65];
            if (
                validators[msgHash.recover(sig)] && ++m >= required_validators // àaudit here
            ) {
                return true; 
            }
        }

        return false;
    }
```

Therefore validators that goes rogue can sign multiple times to bypass the validators number threshold.

## Proof of Concept
The issue with the current implementation is that it does not ensure that each valid signature comes from a distinct validator. In scenarios where validators are not unique, a single validator could potentially sign multiple times, allowing them to meet or exceed the required_validators threshold by themselves.

Consider the following scenario:

Suppose:

- There are 4 signatures.
- Only the second and fourth signatures are valid ( for the sake of this example).
- However, both valid signatures come from the same validator.
In this case, even though there are two valid signatures, they come from a single validator, not two distinct validators. The function will still return true if required_validators is 2, which is incorrect because the requirement of distinct validators is not met.

## Recommended Mitigation Steps
To address this issue, you need to track which validators have already been counted, ensuring that each validator is only counted once. Here’s how you can modify the function to include this check in solidity:

1. Add a Set to Track Unique Validators:

- Use a mapping or set to keep track of validators that have already been counted.

2. Modify the Loop to Check for Unique Validators:

- Check whether the validator has already been counted before incrementing the counter.

Here is the updated code:
```diff
function verifyECDSA(
    bytes32 msgHash,
    bytes calldata signatures
) internal view returns (bool) {
    require(
        signatures.length % 65 == 0,
        "Signature length must be a multiple of 65"
    );

    uint256 len = signatures.length;
    uint256 m = 0;
    + mapping(address => bool) memory countedValidators;  // Mapping to track counted validators

    for (uint256 i = 0; i < len; i += 65) {
        bytes memory sig = signatures[i:i + 65];
        + address recovered = msgHash.recover(sig);
        
        // Check if the recovered address is a validator and if it hasn't been counted yet
        + if (validators[recovered] && !countedValidators[recovered]) {
            + countedValidators[recovered] = true;  // Mark this validator as counted
            ++m;  // Increment the count of distinct validators
            + if (m >= required_validators) {
                return true;
            }
        }
    }

    return false;
}
```
