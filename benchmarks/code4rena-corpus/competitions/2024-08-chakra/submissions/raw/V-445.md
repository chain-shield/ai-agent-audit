# Vulnerability details

## Impact
The current implementation of the cross-chain settlement system lacks any mechanism to handle failed transactions and recover tokens on either the source and destination chains. This can lead to permanent loss of user funds and create inconsistencies between chains.

This issue is also present in cairo code.

## Proof of Concept
1. Source Chain (Token Locking/Burning):
In the cross_chain_erc20_settlement function, tokens are locked or burned immediately:
```solidity
if (mode == SettlementMode.MintBurn) {
    _erc20_lock(msg.sender, address(this), amount);
} else if (mode == SettlementMode.LockUnlock) {
    _erc20_lock(msg.sender, address(this), amount);
} else if (mode == SettlementMode.LockMint) {
    _erc20_lock(msg.sender, address(this), amount);
} else if (mode == SettlementMode.BurnUnlock) {
    _erc20_burn(msg.sender, amount);
}
```
However, there's no mechanism to reverse this action if the cross-chain settlement fails.

2. Destination Chain (Token Minting/Unlocking):
In the receive_cross_chain_msg function, tokens are minted or unlocked based on the settlement mode:
```solidity
if (mode == SettlementMode.MintBurn) {
    _erc20_mint(AddressCast.to_address(transfer_payload.to), transfer_payload.amount);
} else if (mode == SettlementMode.LockUnlock) {
    _erc20_unlock(AddressCast.to_address(transfer_payload.to), transfer_payload.amount);
}
// ... similar for other modes
```
If this operation fails e.g. due to liquidity being not available, there's no mechanism to allow any recovery.

3. Failure Handling:
In the receive_cross_chain_callback function, failed transactions are only marked as failed without any recovery action:
```solidity
if (status == CrossChainMsgStatus.Failed) {
    create_cross_txs[txid].status = CrossChainTxStatus.Failed;
}
```
There's no code to initiate a refund or recovery process.

Manual Review

## Recommended Mitigation Steps
Implement an appropriate recovery mechanism e.g. an escrow mechanism on the source chain which allows user claims on failed cross-chain settlementss.
