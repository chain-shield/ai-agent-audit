# Vulnerability details

## Impact
The current implementation lacks a mechanism to refund unused gas for cross-chain transactions. When gas payment for cross-chain operations is implemented in the future, users may consistently overpay without the ability to reclaim excess funds. This could lead to financial losses for users and potentially discourage use of the cross-chain functionality.

## Proof of Concept
The existing contract architecture does not include any provisions for tracking, calculating, or refunding unused gas in cross-chain transactions. This absence is notable in key functions like `cross_chain_erc20_settlement` in ChakraSettlementHandler and `receive_cross_chain_msg` in ChakraSettlement.

## Tools Used
Manual review

## Recommended Mitigation Steps
1. Design a gas estimation system for cross-chain transactions.
3. Create a refund mechanism to return unused gas to users, in the callback methods.
4. Modify relevant functions (e.g., `receive_cross_chain_callback`) to incorporate gas usage data.

Implementing these changes will prepare the protocol for future updates involving cross-chain gas payments, ensuring fair and efficient gas usage for users.
