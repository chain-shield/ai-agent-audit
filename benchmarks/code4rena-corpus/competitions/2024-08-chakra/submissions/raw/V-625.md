# Vulnerability details


## Issue Description
The methods `receive_cross_chain_msg` from both `settlement.cairo` and `handler_erc20` miss to check whether `cross_chain_msg_id` has been already handled or not.
Moreover, anyone can call the public external method `receive_cross_chain_msg` from `settlement.cairo`, which calls the one from `handler_erc20.cairo`.
Any valid transaction sent to the settlement can be intercepted and replayed by anyone, resulting in unauthorized minting or loss of tokens.

## Impact
Unauthorized and unlimited minting or burning of tokens due to transaction replay.
