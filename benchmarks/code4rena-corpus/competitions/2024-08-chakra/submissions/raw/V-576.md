# Vulnerability details

## Summary
In ChakraSettlementHandler.sol  the function cross_chain_erc20_settlement()  is not checking whether the to_chain the user wants to send will be supported to bridge the tokens or not. If he sends any wrong to_chain parameter then the funds will not be bridged to the destination chain and the funds will get stuck in the handler contracts itself, as validator is not sure about to which chain to bridge the funds to.

## Impact
Due to passing of the incorrect to_chain parameter users funds will not be bridged to the destination chain and the user funds will get stuck in the handler correct. due to this users will loose his funds.

## Tools Used
Manual Inspection

## Recommended Mitigation Steps
To fix this issue, we have to check whether the `to_chain` the user given to the function is a valid destination chain or not.

```solidity
mapping(string chain => bool) isToChainSupported;

function cross_chain_erc20_settlement(
        string memory to_chain,
        uint256 to_handler,
        uint256 to_token,
        uint256 to,
        uint256 amount
    ) external {
+	require(isToChainSupported[to_chain], "Chain is not supported to send tokens");
	.....
}
```
