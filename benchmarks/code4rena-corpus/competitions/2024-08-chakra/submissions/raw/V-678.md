# Vulnerability details

## Impact

If the Message fails at destination chain, the tokens remain locked in the contract at source and are never returned to the user. This results in a permanent loss of user funds, with no way to recover or transfer them out of the protocol, leading to significant financial loss for users.

## Proof of Concept

The issue arises in the following scenario:

1. A message fails to execute on the destination chain, triggering the `receive_cross_chain_callback` function on the source chain (step 6, as documented [here](https://s3labs.notion.site/Contract-Design-Document-f4aa296f71fb40b1818c0890c40be55c)) with status: `CrossChainMsgStatus.Failed`.

2. In the `receive_cross_chain_callback` function, the following validation occurs first:

```solidity

    if (is_valid_handler(from_chain, from_handler) == false) {
        return false;
    }

```

3. Next, the transaction status is verified to ensure it is `CrossChainTxStatus.Pending`, preventing redundant callbacks for the same transaction.

4. Depending on the status returned by the settlement, the code updates the transaction status:
    * If the status is Success, the transaction status is updated to Settled, and the tokens are either burned on the source chain in case of `MintBurn` mode:


```solidity

    if (status == CrossChainMsgStatus.Success) {
```

5. **Issue**: If the status is Failed, the transaction status is simply updated to Failed without any mechanism to return the tokens to the user:

```solidity

    // @audit-info If Failed, Tokens are not returned to User
    if (status == CrossChainMsgStatus.Failed) {
        create_cross_txs[txid].status = CrossChainTxStatus.Failed;
    }

```

6. This results in the locked tokens never being returned to the user, effectively freezing the funds in the protocol. Additionally, there is no function available to rescue or unlock the tokens.

In the case of `BurnUnlock` mode, the tokens are burned on the source chain but are not redeemable on either source chain or destination chain due to the failure, leading to permanent loss.
