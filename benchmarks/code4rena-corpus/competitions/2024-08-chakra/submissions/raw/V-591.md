# Vulnerability details

## Abstract

The ECDSA signature verification function in the SettlementSignatureVerifier contract is vulnerable to signature reuse attacks. The current implementation does not check for duplicate signatures, allowing a single valid signature to be counted multiple times towards the required threshold.

## Impact
This vulnerability could severely undermine the contract's multi-signature security model. An attacker could replicate a single valid signature to meet the required threshold, effectively bypassing the intended consensus mechanism.

## Recommended Mitigation Steps

Implement a mechanism to track and enforce unique signers.

- Use a mapping or array to store addresses of signers who have already contributed a valid signature.
- Before counting a signature as valid, check if the signer's address has already been recorded.
