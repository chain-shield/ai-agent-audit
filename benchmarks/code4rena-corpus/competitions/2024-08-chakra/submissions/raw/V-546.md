# Vulnerability details

**Summary:**

The `SettlementSignatureVerifier` smart contract has a critical issue in the `set_required_validators_num` function. This function allows the number of required validators to be set arbitrarily without checking if the new value exceeds the total number of validators. This can result in the `required_validators` being set to a number greater than the actual count of validators, leading to potential system inoperability and vulnerability to exploitation.

---

**Vulnerability Detail:**

- **Function Affected:** `set_required_validators_num(uint256 _required_validators)`
- **Issue:** The function does not validate that the new value for `required_validators` is less than or equal to the current number of validators (`validator_count`). As a result, `required_validators` can be set to a value greater than the number of validators available.
- **Code Snippet:**
  ```solidity
  function set_required_validators_num(
      uint256 _required_validators
  ) external virtual onlyRole(MANAGER_ROLE) {
      uint256 old = required_validators;
      required_validators = _required_validators;
      emit RequiredValidatorsChanged(msg.sender, old, required_validators);
  }
  ```

---

**Impact:**

- **System Inoperability:** If `required_validators` is set to a number higher than `validator_count`, no operation or transaction can meet this threshold, making it impossible for the contract to function as intended.
- **Transaction Blocking:** Transactions or decisions that require validator signatures will never succeed if the number of required validators exceeds the number of available validators.
- **Potential Exploitation:** Malicious actors could exploit this bug to set an unattainable number of required validators, effectively blocking certain contract functions or halting the system.

---

**Recommendations:**

1. **Add Validation Check:**
   Implement a validation check in the `set_required_validators_num` function to ensure that the new value for `required_validators` does not exceed the current number of validators. Modify the function as follows:
   ```solidity
   function set_required_validators_num(
       uint256 _required_validators
   ) external virtual onlyRole(MANAGER_ROLE) {
       require(_required_validators <= validator_count, "Required validators cannot exceed total validators");
       uint256 old = required_validators;
       required_validators = _required_validators;
       emit RequiredValidatorsChanged(msg.sender, old, required_validators);
   }
   ```

By addressing this bug, you will prevent potential operational issues and ensure the reliability and security of the smart contract.
