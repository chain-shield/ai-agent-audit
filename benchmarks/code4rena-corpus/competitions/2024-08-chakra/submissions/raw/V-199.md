# Vulnerability details

## Impact
The `SettlementSignatureVerifier` contract utilizes the UUPS (Universal Upgradeable Proxy Standard) upgrade pattern. In this design, the `initialize` function is essential for setting up the contract's initial state. However, the current implementation exposes the `initialize` function as a public method, making it vulnerable to being called by any external actor. If the `initialize` function is invoked by someone other than the owner of the proxy contract before the intended setup, it could lead to a situation where the contract’s state is initialized incorrectly.

## Tools Used
Manual Review

## Recommended Mitigation Steps
OpenZeppelin provides the function `_disableInitializers()` that must be executed in the constructor of the implementation contract. Refer to [Rareskills Blog on UUPS (ERC-1822)](https://www.rareskills.io/post/uups-proxy#:~:text=The%20contract%20that%20implements%20the,with%20the%20ERC%2D1967%20standard.) for better understanding.
