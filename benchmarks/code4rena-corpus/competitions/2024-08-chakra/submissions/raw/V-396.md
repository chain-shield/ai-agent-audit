# Vulnerability details


## Impact
The function `settlement/contracts/SettlementSignatureVerifier::verifyECDSA` is used to validate input signatures for the `ChakraSettlement::receive_cross_chain_callback` function. However, neither this function nor the `SettlementSignatureVerifier::verify` function checks for duplicate signatures. This oversight allows a single validator to submit their signature `required_validators` times, effectively bypassing the `required_validators` check, potentially resulting in the burning of tokens locked in the contract.

Additionally, while the `verifyECDSA` method is present in `handler/contracts/SettlementSignatureVerifier::verifyECDSA`, it is not currently used in any handler contracts. Therefore, current handler contracts are not vulnerable. However, if this library is used in future developments, the vulnerability will be present.

```javascript
    function verify(
        bytes32 msgHash,
        bytes calldata signatures,
        uint8 sign_type
    ) external view returns (bool) {
        if (sign_type == 0) {
            return verifyECDSA(msgHash, signatures);
        } else {
            return false;
        }
    }

    function verifyECDSA(                
        bytes32 msgHash,
        bytes calldata signatures
    ) internal view returns (bool) {
        require(
            signatures.length % 65 == 0,
            "Signature length must be a multiple of 65"
        );

        uint256 len = signatures.length;
        uint256 m = 0;
        for (uint256 i = 0; i < len; i += 65) {
            bytes memory sig = signatures[i:i + 65];
            if (
                validators[msgHash.recover(sig)] && ++m >= required_validators
            ) {
                return true;
            }
        }

        return false;
    }
```

As demonstrated by the code, there is no check for duplicate signatures. Thus, a single signature can be repeated `required_validators` times and provided as the input parameter for signatures.

## Recommended Mitigation Steps

Add validation to detect duplicate signatures:

```diff
SettlementSignatureVerifier::verifyECDSA

    uint256 len = signatures.length;
+   for (uint256 i = 0; i < len - 1; i += 65) {
+       for (uint j = i + 1; j < len; j += 65){
```
