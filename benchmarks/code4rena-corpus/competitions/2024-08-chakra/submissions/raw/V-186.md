# Vulnerability details

While the function updates the internal state of the contract,the function receive_cross_chain_callback in handler_erc20.cairo contract doesn't emit any events to notify external observers (like applications or other contracts) about the successful settlement.

 Events are critical for providing transparency and traceability of contract interactions, especially when state-changing operations affect cross-chain transactions and token balances.

IMPACTS:
Potential for Malicious Activities to Go Undetected:
   - In the absence of emitted events, an attacker could exploit vulnerabilities or manipulate state variables without being detected. This could be used to obscure malicious activities such as token theft, cross-chain transaction manipulation, or settlement tampering, as there would be no recorded event logs to analyze.

The attacker could manipulate cross-chain settlement data without triggering any event logs, making it hard to detect the attack until it's too late.
By modifying state variables such as cross-chain transaction statuses, the attacker could cause discrepancies between the actual state of the contract and what off-chain systems believe to be true.




MITIGATIONS:

emit events for significant state changes, especially when interacting with external entities like other chains. Here's what you could add:


// ... existing code in receive_cross_chain_callback function ...

  }
);

return true;
