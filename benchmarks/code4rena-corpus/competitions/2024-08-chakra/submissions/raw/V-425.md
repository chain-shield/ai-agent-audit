# Vulnerability details

## Impact
SettlementSignatureVerifier contract there is as storage variable `required_validators` which dictates how many validators have to signed a message for it to be valid and processed. This can be easily bypassed by re-using one valid signature over and over.

Please note: One validator has to be malicious

The protocol can be drained of all funds by calling `ChakraSettlement::receive_cross_chain_msg` with crafted data by the validator.

## Proof of Concept
The entry-point to the verification process is [here](https://github.com/code-423n4/2024-08-chakra/blob/d0d45ae1d26ca1b87034e67180fac07ce9642fd9/solidity/settlement/contracts/SettlementSignatureVerifier.sol#L174). Then it makes an internal call to this [function](https://github.com/code-423n4/2024-08-chakra/blob/d0d45ae1d26ca1b87034e67180fac07ce9642fd9/solidity/settlement/contracts/SettlementSignatureVerifier.sol#L193) which validates the signature and checks the mapping `mapping(address => bool) public validators;` to see if the validator is approved. The problem is the function never checks if the signature has already been used. Therefore, you can re-use the same signatures until the `required_validators` check has been satisfied.

     * @return A boolean indicating if the signature is verified

    function verifyECDSA(bytes32 msgHash, bytes calldata signatures) internal view returns (bool) {
        require(signatures.length % 65 == 0, "Signature length must be a multiple of 65");

        uint256 len = signatures.length;
        uint256 m = 0;
        for (uint256 i = 0; i < len; i += 65) {
            bytes memory sig = signatures[i:i + 65];

                return true;
            }

        return false;

## Recommended Mitigation Steps
Create a storage mapping to record if a signature has been used and replace the old `SettlementSignatureVerifier::verifyECDSA` with the following function.
```solidity
   //New Storage Mapping
    mapping(bytes32 => mapping(address => bool)) hasValidatorsigned;
    //---------------------------------

    function verifyECDSA_V2(bytes32 msgHash, bytes calldata signatures) internal returns (bool) {
        require(signatures.length % 65 == 0, "Signature length must be a multiple of 65");

        uint256 len = signatures.length;
        uint256 m = 0;

        for (uint256 i = 0; i < len; i += 65) {
            bytes memory sig = signatures[i:i + 65];
            address recoveredAddress = msgHash.recover(sig);
            if (validators[recoveredAddress]) {
                if (!hasValidatorsigned[msgHash][recoveredAddress]) {
                    hasValidatorsigned[msgHash][recoveredAddress] = true;
                    ++m;
                }
            }
        }

        if (m >= required_validators) {
            return true;
        } else {
            return false;
        }
    }
```
