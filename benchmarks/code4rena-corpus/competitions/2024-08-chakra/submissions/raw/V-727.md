# Vulnerability details

## Impact
The parameters `payload_type` and `payload` are not included in the txid hash compute, allowing the `payload` / `payload_type` to be tampered with for a given txid. 

## Proof of Concept

From https://github.com/code-423n4/2024-08-chakra/blob/d0d45ae1d26ca1b87034e67180fac07ce9642fd9/solidity/settlement/contracts/ChakraSettlement.sol#L122-L133

```solidity
        uint256 txid = uint256(
            keccak256(
                abi.encodePacked(
                    contract_chain_name, // from chain
                    to_chain,
                    from_address, // msg.sender address
                    from_handler, // settlement handler address
                    to_handler,
                    nonce_manager[from_address]
                )
            )
        );
```

## Recommended Mitigation Steps
Add payload_type and payload to txid hash computation.

```solidity
        uint256 txid = uint256(
            keccak256(
                abi.encodePacked(
                    contract_chain_name, // from chain
                    to_chain,
                    from_address, // msg.sender address
                    from_handler, // settlement handler address
                    to_handler,
                    nonce_manager[from_address],
                    payload_type,
                    payload
                )
            )
        );
```
