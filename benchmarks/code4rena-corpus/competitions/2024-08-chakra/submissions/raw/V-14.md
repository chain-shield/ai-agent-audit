# Vulnerability details

## Impact
The inputs provided to emit the `CrossChainHandleResult` event are incorrect, leading to inconsistencies in the cross-chain communication process.

## Proof of Concept
When a cross-chain message is received, the `receive_cross_chain_msg()` function processes the message and emits the `CrossChainHandleResult` event. This event is essential for the Chakra Network, as it triggers the `receive_cross_chain_callback()` function on the source chain.

Deposit event and call flow: https://s3labs.notion.site/image/https%3A%2F%2Fprod-files-secure.s3.us-west-2.amazonaws.com%2Fff27c54f-ad06-4fb3-8619-a46841a5c94b%2F2423b1ff-51f6-40dc-a8a3-6c363f28752a%2FUntitled.png?table=block&id=3becbfeb-9ae3-4bae-ace3-2d6dbe1ab083&spaceId=ff27c54f-ad06-4fb3-8619-a46841a5c94b&width=2000&userId=&cache=v2

However, the inputs used to emit the `CrossChainHandleResult` event are incorrectly assigned:
-   `contract_chain_name` should be replaced with `from_chain`.
-   `from_chain` should be replaced with `contract_chain_name`.
-   `address(to_handler)` should be replaced with `from_handler`.
-   `from_handler` should be replaced with `to_handler`.
