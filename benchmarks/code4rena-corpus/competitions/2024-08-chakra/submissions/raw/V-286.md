# Vulnerability details

The transferFrom() function returns a boolean value indicating success. This parameter needs to be checked to see if the transfer has been successful.

## Impact
A new cross chain tx is created and processed in a normal way even though ChakraSettlementHandler contract did not receive tokens from user.

## Tools Used

Manual analysis

## Recommended Mitigation Steps

Consider using OpenZeppelin’s safeTransfer/safeTransferFrom or require() consistently.
