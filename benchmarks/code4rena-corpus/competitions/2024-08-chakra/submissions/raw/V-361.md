# Vulnerability details

### Description:

1. **Lack of Access Restriction:**
The function `__TokenRoles_init` is marked as `public`, allowing any user to call this function. There is no check (e.g., `onlyOwner` or `initializer` modifier) to restrict access to this initialization process.
2. **Potential Impact:**
    - An attacker could call this function to assign themselves or another malicious address as the `DEFAULT_ADMIN_ROLE` or `OPERATOR_ROLE`, thereby gaining complete control over the contract.
    - The unauthorized user would have the ability to manage other roles, withdraw funds, modify state variables, and perform sensitive operations.
    - If this function can be called multiple times, it could also lead to privilege escalation or role hijacking, depending on the contract's role management.

Vulnerable Code: TokenRoles.sol#L19

```
function __TokenRoles_init(address _owner, address _operator) public {
    __Ownable_init(_owner);
    _grantRole(DEFAULT_ADMIN_ROLE, _owner);
    _grantRole(OPERATOR_ROLE, _operator);
}

```



### Proof of Concept:

1. Deploy the contract without any initialization check.
2. Call the `__TokenRoles_init` function as an arbitrary user:
    
    ```solidity
    __TokenRoles_init(attackerAddress, attackerAddress);
    
    ```
    
3. The attacker now has the `DEFAULT_ADMIN_ROLE` and `OPERATOR_ROLE`.

### Recommended Fix:

1. **Restrict Access:**
Add a modifier like `initializer` or `onlyOwner` to ensure that only the contract owner or an authorized entity can call this function:
    
    ```solidity
    function __TokenRoles_init(address _owner, address _operator) public onlyOwner {
        __Ownable_init(_owner);
        _grantRole(DEFAULT_ADMIN_ROLE, _owner);
        _grantRole(OPERATOR_ROLE, _operator);
    }
    
    ```
    
    Alternatively, use the `initializer` modifier from OpenZeppelin’s `Initializable` contract to prevent re-initialization:
    
    ```solidity
    function __TokenRoles_init(address _owner, address _operator) public initializer {
        __Ownable_init(_owner);
        _grantRole(DEFAULT_ADMIN_ROLE, _owner);
        _grantRole(OPERATOR_ROLE, _operator);
    }
    
    ```
