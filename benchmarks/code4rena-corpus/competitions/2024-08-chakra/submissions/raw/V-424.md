# Vulnerability details

## Impact
An attacker can make `Handler` to receive wrong transaction or to DOS for receiving transaction.


## Proof of Concept
`ChakraSettlementHandler.sol#cross_chain_erc20_settlement()` function which is called for settlement is as follows.

As we can see above, nonce for `msg.sender` is increased on L135 and `txid` is calculated with this nonce.   
On L203, it calls `ChakraSettlement.sol#send_cross_chain_msg()` function.

As we can see above, `send_cross_chain_msg()` function can be called by any user.   
Usually, `txid` on L122 is same as `txid` calculated `ChakraSettlementHandler.sol#L139`.   
But an attacker can increase `ChakraSettlement#nonce_manager[from_address]`.   
Then, if a user which addres is same as `from_address` creates settlement, `txid` in `ChakraSettlementHandler` becomes different from `txid` from `ChakraSettlement`.   

And user calls `ChakraSettlement.sol#receive_cross_chain_callback()` to run `settlement`.

As we can see on L313, `txid` is in ChakraSettlement.   
Then, this `txid` is used to call `ChakraSettlementHandler.sol#receive_cross_chain_callback()` on L318.   
```solidity

        require(

        if (status == CrossChainMsgStatus.Success) {
```

But this `txid` is different on `ChakraSettlementHandler`.   
So on L379, `create_cross_txs[txid]` is not intended `tx`.
So this call may dos or receives wrong transaction of `Handle`.

## Recommended Mitigation Steps
Mitigation steps is as follows.
1. `BaseSettlement.sol#nonce_manager` mapping has to be modified as follows.
```solidity
    
    // Mapping for nonce manager and validators
-   mapping(address => uint256) public nonce_manager;
+   mapping(address => mapping(address => uint256)) public nonce_manager;

```
2. `ChakraSettlement.sol#send_cross_chain_msg()` function has to be modified as follows.
```solidity
    function send_cross_chain_msg(
        string memory to_chain,
        address from_address,
        uint256 to_handler,
        PayloadType payload_type,
        bytes calldata payload
    ) external {
-       nonce_manager[from_address] += 1;

        address from_handler = msg.sender;

                    to_handler,

+                   nonce_manager[from_handler][from_address]
```
