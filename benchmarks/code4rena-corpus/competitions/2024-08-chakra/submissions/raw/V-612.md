# Vulnerability details

## Summary
This bug pertains to the absence of the `__AccessControl_init` in the `BaseSettlement::_Settlement_init` and `BaseSettlementHandler::_Settlement_handler_init` Function, which inherits from `AccessControlUpgradeable`. The lack of this initialization function can impact the proper functioning of access control roles within the contract, particularly affecting the `_grantRole` function. Without the initialization step, there is a risk of unauthorized access or incorrect role assignments, potentially compromising the security and integrity of the contract's access control mechanisms.

## Vulnerability Details
The `BaseSettlement` contract inherits from `AccessControlUpgradeable` but lacks the `  __AccessControl_init()` function, which is essential for initializing access control roles.
```javascript
abstract contract BaseSettlement is
    OwnableUpgradeable,
    UUPSUpgradeable,
    AccessControlUpgradeable
{
```

```javascript
 function _Settlement_init(
        string memory _chain_name,
        uint256 _chain_id,
        address _owner,
        address[] memory _managers,
        uint256 _required_validators,
        address _signature_verifier
    ) public {
        __Ownable_init(_owner);
->        // @audit   __AccessControl_init() is missing here in both handler and settlement 
        __UUPSUpgradeable_init();
        _grantRole(DEFAULT_ADMIN_ROLE, _owner);

        for (uint256 i = 0; i < _managers.length; i++) {
            _grantRole(MANAGER_ROLE, _managers[i]);
        }

        chain_id = _chain_id;
        contract_chain_name = _chain_name;
        required_validators = _required_validators;
        signature_verifier = ISettlementSignatureVerifier(_signature_verifier);
    }
```

## Impact
Without proper initialization of access control roles, the `_grantRole` function may not work as intended, potentially leading to unauthorized access or role assignment issues.

## Tools Used
Manual Review

## Recommendations
To address this bug:
1. Implement the `  __AccessControl_init()` function in the `BaseSettlement::_Settlement_init` and `BaseSettlementHandler::_Settlement_handler_init` contract to properly initialize access control roles.

2. Ensure that access control roles are correctly set up before using functions like `_grantRole` to maintain secure access control within the contract.
