# Vulnerability details

## Vulnerability detail
The `verifyECDSA` function in the `SettlementSignatureVerifier` contract allows multiple signatures from a single validator to be counted towards the required threshold for signature verification. This vulnerability undermines the intended multi-signature security model by potentially allowing a small number of validators (or even a single validator) to meet the required threshold by submitting multiple signatures.

## Impact
This vulnerability has a high severity impact because:

- It compromises the core security mechanism of the contract, which is designed to require approval from multiple distinct validators.
- It allows for potential centralization of power, where a single validator could have disproportionate influence over the verification process.
- It may lead to unauthorized approvals of settlements or other critical operations that rely on this signature verification.

## Proof of Concept
```
function verifyECDSA(
    bytes32 msgHash,
    bytes calldata signatures
) internal view returns (bool) {
    require(
        signatures.length % 65 == 0,
        "Signature length must be a multiple of 65"
    );

    uint256 len = signatures.length;
    uint256 m = 0;
    for (uint256 i = 0; i < len; i += 65) {
        bytes memory sig = signatures[i:i + 65];
        if (
            validators[msgHash.recover(sig)] && ++m >= required_validators
        ) {
            return true;
        }
    }

    return false;
}
```
To exploit this:

- A malicious validator could create multiple valid signatures for the same message.
- They would submit these signatures in the `signatures` parameter.
- Each of their signatures would increment the `m` counter.
- If they provide enough signatures to reach `required_validators`, the function returns true, even though only one validator participated.

## Recommended Mitigation Steps
To mitigate this vulnerability, modify the `verifyECDSA` function to ensure each validator is only counted once:
```
function verifyECDSA(
    bytes32 msgHash,
    bytes calldata signatures
) internal view returns (bool) {
    require(
        signatures.length % 65 == 0,
        "Signature length must be a multiple of 65"
    );

    uint256 len = signatures.length;
    uint256 validSignatures = 0;
    mapping(address => bool) memory usedValidators;

    for (uint256 i = 0; i < len; i += 65) {
        bytes memory sig = signatures[i:i + 65];
        address signer = msgHash.recover(sig);
        if (validators[signer] && !usedValidators[signer]) {
            usedValidators[signer] = true;
            validSignatures++;
            if (validSignatures >= required_validators) {
                return true;
            }
        }
    }

    return false;
}
```
