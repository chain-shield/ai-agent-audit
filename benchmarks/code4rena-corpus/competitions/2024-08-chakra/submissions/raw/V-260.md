# Vulnerability details

Function `receive_cross_chain_callback` in handler_erc20.cairo does not check the status of cross chain message coming from destination chain. 
Specifically, users can call `cross_chain_erc20_settlement` in the handler_erc20.cairo which calls `send_cross_chain_msg` in settlement.cairo, then a CrossChainMsg event is emitted. Then, validators call `receive_cross_chain_msg` in ChakraSettlement.sol which verifies message signature and calls `receive_cross_chain_msg` in ChakraSettlementHandler.sol. Then, the result of handler function will be checked in order to set CrossChainMsgStatus, and if the transaction was not handled correctly it will be set to CrossChainMsgStatus.Failed:

```
        bool result = ISettlementHandler(to_handler).receive_cross_chain_msg( 
            txid,
            from_chain,
            from_address,
            from_handler,
            payload_type,
            payload,
            sign_type,
            signatures
        );

        CrossChainMsgStatus status = CrossChainMsgStatus.Failed;
        if (result == true) {
            status = CrossChainMsgStatus.Success;
            receive_cross_txs[txid].status = CrossChainMsgStatus.Success;
        } else {
            receive_cross_txs[txid].status = CrossChainMsgStatus.Failed;
        }
``` 

Then there will be another CrossChainHandleResult event that will be monitored by validators, that will call `receive_cross_chain_callback` in settlement.cairo.
Function `receive_cross_chain_callback` will call `receive_cross_chain_callback` in handler_erc20.cairo. Now, before performing burning tokens and changing `create_cross_txs[txid].status` to CrossChainTxStatus.Settled, it is needed to check the status of the message coming from ChakraSettlement.sol as it is done in the `receive_cross_chain_callback` function in ChakraSettlementHandler.sol:
```
        if (status == CrossChainMsgStatus.Success) { 
            if (mode == SettlementMode.MintBurn) { 
                _erc20_burn(address(this), create_cross_txs[txid].amount); 
            }
            create_cross_txs[txid].status = CrossChainTxStatus.Settled;
        }
        if (status == CrossChainMsgStatus.Failed) {
            create_cross_txs[txid].status = CrossChainTxStatus.Failed;
        }
```
However, function `receive_cross_chain_callback` in handler_erc20.cairo lacks that check and burns the tokens and set tx_status to CrossChainTxStatus::SETTLED in any case. Indeed, tx_status is not set correctly if the status of cross chain message coming from destination chain is FAILED, and it always will be set to CrossChainTxStatus::SETTLED:
```
            let erc20 = IERC20MintDispatcher{contract_address: self.token_address.read()};
            if self.mode.read() == SettlementMode::MintBurn{
                erc20.burn_from(get_contract_address(), self.created_tx.read(cross_chain_msg_id).amount);
            }
            let created_tx = self.created_tx.read(cross_chain_msg_id);
            self.created_tx.write(cross_chain_msg_id, CreatedCrossChainTx{
                tx_id: created_tx.tx_id,
                from_chain: created_tx.from_chain,
                to_chain: created_tx.to_chain,
                from:created_tx.from,
                to:created_tx.to,
                from_token: created_tx.from_token,
                to_token: created_tx.to_token,
                amount: created_tx.amount,
                tx_status: CrossChainTxStatus::SETTLED
            });
```

## Recommended Mitigation Steps
Adding following checks to `receive_cross_chain_callback` in handler_erc20.cairo can fix the issue:
```
        if cross_chain_msg_status == CrossChainMsgStatus::SUCCESS {                
            let erc20 = IERC20MintDispatcher{contract_address: self.token_address.read()};
            if self.mode.read() == SettlementMode::MintBurn{
                erc20.burn_from(get_contract_address(), self.created_tx.read(cross_chain_msg_id).amount); 
            }
        
            let created_tx = self.created_tx.read(cross_chain_msg_id);
            self.created_tx.write(cross_chain_msg_id, CreatedCrossChainTx{
                tx_id: created_tx.tx_id,
                from_chain: created_tx.from_chain,
                to_chain: created_tx.to_chain,
                from:created_tx.from,
                to:created_tx.to,
                from_token: created_tx.from_token,
                to_token: created_tx.to_token,
                amount: created_tx.amount,
                tx_status: CrossChainTxStatus::SETTLED
            });
        }
        if cross_chain_msg_status == CrossChainMsgStatus::FAILED {    
            let created_tx = self.created_tx.read(cross_chain_msg_id);
            self.created_tx.write(cross_chain_msg_id, CreatedCrossChainTx{
                tx_id: created_tx.tx_id,
                from_chain: created_tx.from_chain,
                to_chain: created_tx.to_chain,
                from:created_tx.from,
                to:created_tx.to,
                from_token: created_tx.from_token,
                to_token: created_tx.to_token,
                amount: created_tx.amount,
                tx_status: CrossChainTxStatus::FAILED
            });
        } 
```
