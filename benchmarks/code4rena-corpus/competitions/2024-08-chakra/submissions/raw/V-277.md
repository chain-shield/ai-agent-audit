# Vulnerability details

## Impact
The current implementation of the add_validator, remove_validator, and set_required_validators_num functions introduces a risk that could compromise the integrity of the validator-based message verification system. Specifically, if validators are removed and the number of remaining validators falls below the required_validators threshold, it becomes impossible to meet the requirement for validating messages.  currently the manager can do the following 

```javascript
 function add_validator(address validator) external onlyRole(MANAGER_ROLE) {
        require(validators[validator] == false, "Validator already exists");
        validators[validator] = true;
        validator_count += 1;
        emit ValidatorAdded(msg.sender, validator);
    }

    function remove_validator(
        address validator
    ) external onlyRole(MANAGER_ROLE) {
        require(validators[validator] == true, "Validator does not exists");
        validators[validator] = false;
        validator_count -= 1;
        emit ValidatorRemoved(msg.sender, validator);
    }

    function set_required_validators_num(
        uint256 _required_validators
    ) external virtual onlyRole(MANAGER_ROLE) {
        uint256 old = required_validators;
        required_validators = _required_validators;
        emit RequiredValidatorsChanged(msg.sender, old, required_validators);
    }

```

Failure to validate messages if the number of validators is below the required threshold, causing potential disruptions in transaction processing.

## Proof of Concept
Consider the following sequence of operations:

Set Initial Threshold:

Assume required_validators is initially set to 5.
The system currently has 7 validators.
Remove Validators:

An administrator removes 3 validators, reducing the total count to 4.
The remaining number of validators (4) is now below the required_validators threshold (5).
Impact:

With only 4 validators, the system cannot meet the threshold of 5 required validators for validation.
Attempts to verify signatures or process messages will fail due to insufficient validators.

## Recommended Mitigation Steps

Modify the `remove_validator` function to include a check that prevents the removal of validators if it would drop the number of validators below the required threshold.

```javascript
function remove_validator(
    address validator
) external onlyRole(MANAGER_ROLE) {
    require(validators[validator] == true, "Validator does not exist");
    require(validator_count > required_validators, "Cannot remove validator; below required threshold");
    validators[validator] = false;
    validator_count -= 1;
    emit ValidatorRemoved(msg.sender, validator);
}

```

Update the set_required_validators_num function to validate that the new threshold does not exceed the current number of validators.

```javascript
function set_required_validators_num(
    uint256 _required_validators
) external onlyRole(MANAGER_ROLE) {
    require(_required_validators <= validator_count, "Required validators exceed current count");
    uint256 old = required_validators;
    required_validators = _required_validators;
    emit RequiredValidatorsChanged(msg.sender, old, required_validators);
}

```
