# Vulnerability details

## Impact

Slicing includes the last index.

## Proof of Concept

```
fn u128_array_slice(src: @Array<u128>, mut begin: usize, end: usize) -> Array<u128> {
    let mut slice = ArrayTrait::new();
    let len = begin + end;
    loop {
        if begin >= len {
            break ();
        }
        if begin >= src.len() {
            break ();
        }

        slice.append(*src[begin]);
        begin += 1;
    };
    slice
}
```

When u128_array_slice is called with Arr:[10,20,30,40,50] , begin with 1 and end with 3, it should return [20,30] but instead it returns [20,30,40]

## Tools Used

Manual Review

## Recommended Mitigation Steps

Ensure that the slice does not include the last index
