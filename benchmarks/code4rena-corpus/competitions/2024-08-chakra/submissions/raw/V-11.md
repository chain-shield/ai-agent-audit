# Vulnerability details

## Summary
The TokenRoles contract, which is designed to be upgradeable, is missing the required upgrade authorization method, allowing unauthorized upgrades.

## Vulnerability Detail
The contract inherits from UUPSUpgradeable but lacks the _authorizeUpgrade function:

```
contract TokenRoles is UUPSUpgradeable {
    // Missing _authorizeUpgrade function
}
```
## Impact
If a critical bug is discovered within the TokenRoles contract after deployment that causes a loss of assets, the contract cannot be upgraded to fix the bugs. All assets or functionalities controlled by this contract will be at risk.
