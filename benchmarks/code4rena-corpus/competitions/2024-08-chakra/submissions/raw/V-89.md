# Vulnerability details

## Summary
The Chakra Network's smart contracts lack a robust mechanism for handling failed cross-chain messages. There is no implemented functionality for users to retry failed transactions or recover locked/burned tokens in case of cross-chain message failures. This oversight could lead to permanent loss of user funds in certain scenarios.

## Vulnerability Details
The current implementation in `ChakraSettlementHandler.sol` and related contracts does not provide:

A way for users to retry failed cross-chain transactions.
A mechanism to recover locked or burned tokens if a cross-chain message fails.


The `receive_cross_chain_callback` function can mark a transaction as failed, but there's no further action taken:

```solidity
...
if (status == CrossChainMsgStatus.Failed) {
    create_cross_txs[txid].status = CrossChainTxStatus.Failed;
}
...
```
Lack of failed msgs handling is the main issue here, which can be main reason for loss of funds permanently.
## Impact
The lack of failure handling mechanisms could lead to:

- Permanent loss of user funds if cross-chain messages fail and tokens remain locked or burned.
- Poor user experience due to inability to retry failed transactions.
Increased support burden as users with failed transactions have no self-service recovery options.
- Potential accumulation of locked funds in the contract, leading to inefficient use of capital.

## Recommended Mitigation Steps
Here are few recommendations  to fix the issue -
1. Implement a retry mechanism for failed transactions:

```solidity
function retryCrossChainTransaction(uint256 txid) external {
    require(create_cross_txs[txid].status == CrossChainTxStatus.Failed, "Transaction not failed");
    require(create_cross_txs[txid].from_address == msg.sender, "Not the transaction initiator");
    
    // Reset status and reinitiate the cross-chain message
    create_cross_txs[txid].status = CrossChainTxStatus.Pending;
    // Logic to resend the cross-chain message
}
```

2. Add a token recovery function for failed transactions:

```solidity
function recoverFailedTransaction(uint256 txid) external {
    require(create_cross_txs[txid].status == CrossChainTxStatus.Failed, "Transaction not failed");
    require(create_cross_txs[txid].from_address == msg.sender, "Not the transaction initiator");
    
    uint256 amount = create_cross_txs[txid].amount;
    if (mode == SettlementMode.LockUnlock || mode == SettlementMode.LockMint) {
        _erc20_unlock(msg.sender, amount);
    } else if (mode == SettlementMode.MintBurn) {
        _erc20_mint(msg.sender, amount);
    }
    
    create_cross_txs[txid].status = CrossChainTxStatus.Recovered;
    emit TransactionRecovered(txid, msg.sender, amount);
}
```
