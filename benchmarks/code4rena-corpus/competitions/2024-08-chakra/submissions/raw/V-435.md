# Vulnerability details

## Impact
The `BaseSettlementHandler` contract inherits from `AccessControlUpgradeable` but does not call the `grantRole` function during initialization. As a result, no roles are initially granted to any account. This can lead to issues with access control, particularly if the contract relies on specific role permissions for critical functions (e.g., managing settlements across chains or handling token transfers). Without properly assigned roles, privileged functions could either be left unprotected or accessible only to the default admin (or even inaccessible), leading to potential misuse or inability to execute important transactions.

## Proof of Concept
The `_Settlement_handler_init` function in `BaseSettlementHandler` does not include any role assignments:
```solidity
  function _Settlement_handler_init(
        address _owner,
        SettlementMode _mode,
        address _token,
        address _verifier,
        string memory _chain,
        address _settlement
    ) public {
        __Ownable_init(_owner);
        __UUPSUpgradeable_init();
        settlement = ISettlement(_settlement);
        verifier = ISettlementSignatureVerifier(_verifier);
        mode = _mode;
        token = _token;
        chain = _chain;
   }
```
It initializes other contracts and parameters but does not invoke `grantRole` to assign any roles. The issue can be mitigated by adding role assignments, such as the `DEFAULT_ADMIN_ROLE`, to the contract owner during initialization.

If role assignments are omitted, it may introduce security risks or operational failure, especially in a multi-chain settlement environment like `ChakraSettlementHandler`, which depends on correct role management for access control across different chains.

## Recommended Mitigation Steps
Add role management in the `_Settlement_handler_init` function in `BaseSettlementHandler`. For example, grant the DEFAULT_ADMIN_ROLE to the owner:
```diff
  function _Settlement_handler_init(
        address _owner,
        SettlementMode _mode,
        address _token,
        address _verifier,
        string memory _chain,
        address _settlement
    ) public {
        __Ownable_init(_owner);
        __UUPSUpgradeable_init();
        settlement = ISettlement(_settlement);
        verifier = ISettlementSignatureVerifier(_verifier);
        mode = _mode;
        token = _token;
        chain = _chain;
+       _grantRole(DEFAULT_ADMIN_ROLE, _owner);
   }
```
