# Vulnerability details

## Summary
Chakra is using OZ contracts version `v0.14.0` which has a known issue in `_transfer_ownership` which is fixed in `v0.16.0`

## Impact
This vulnerability can lead to unauthorized ownership transfer, contrary to the original owner's intention of leaving the contract without an owner. It introduces a security risk where an unintended party (pending owner) can gain control of the contract after the original owner has renounced ownership.

This could also be used by a malicious owner to simulate leaving a contract without an owner, to later regain ownership by previously having proposed himself as a pending owner.


## Proof of Concept
It's a very recent issue for which I got a bounty reward from OZ, and it is fixed in version v0.16.0, however Chakra is using `v0.14.0` version so this issue is still present https://github.com/OpenZeppelin/cairo-contracts/security/advisories/GHSA-w2px-25pm-2cf9

## Recommended Mitigation Steps
Either upgrade the version to latest one where the issue is fixed, or overwrite the `_transfer_ownership` function and reset pending owner via `self.Ownable_pending_owner.write(Zero::zero());`
