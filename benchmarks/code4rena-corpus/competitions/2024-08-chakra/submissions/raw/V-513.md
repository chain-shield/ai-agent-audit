# Vulnerability details

## Impact
Token decimals is stored on mutable variable which could be modified later since it is an upgradable contract. Changing the number of decimals could cause issues in external applications or token holders who assume a fixed number of decimals.

`uint8 set_decimals;`

## Proof of Concept

Deploy V1:Deploy ChakraTokenV1 with 18 decimals

Upgrade to V2: Deploy ChakraTokenV2 with 6 decimals

Mint and Test: Mint tokens to the owner and see the balance affected because of decimal changes


## Tools Used
Manual

## Recommended Mitigation Steps
Set set_decimals as immutable variable
`uint8 private _decimals;`




## Assessed type

Decimal
