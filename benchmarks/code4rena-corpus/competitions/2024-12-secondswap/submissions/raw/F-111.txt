S-362
Receiver can be same as sender when spot purchasing a Listing
AshishLach
00
Sufficient
383d ago
Finding description and impact

When placing listings using spotPurchase() function, protocol doesn't check whether receiver is not the same as the sender

Need to keep this require statement in spotPurchase() function

require(msg.sender != listing.seller, " seller cant be same as receiver")


Write a detailed description of the root cause and impact(s) of this finding.

While no major attack path was identified, this could potentially enable attacks based on learnings from previous protocols. Therefore, it is advisable to keep this check in place

        await Marketplace.token.write.transfer([s2admin.account.address, parseEther("1000000")]);
