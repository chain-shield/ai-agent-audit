Inability to Sell Remaining Tokens Due to Base Amount Check
macart224
00
Sufficient
383d ago
Finding description and impact

The current implementation of the baseAmount calculation in the listVesting function can lead to a situation where a user is unable to sell their last portion of a listing when the listing type is set to partial. Specifically, if the remaining amount of tokens is too small, it may not satisfy the condition baseAmount > 0, causing the transaction to always revert. This can prevent buyers from purchasing the remaining tokens.

The relevant code snippet is as follows:

uint256 baseAmount = (_amount * discountedPrice) / 
    uint256(
        10 **
            (
                IERC20Extended(
                    address(
                        IVestingManager(IMarketplaceSetting(marketplaceSetting).vestingManager())
                            .getVestingTokenAddress(listing.vestingPlan)
                    )
                ).decimals()
            )
    ); 
require(baseAmount > 0, "SS_Marketplace: Amount too little");

If the baseAmount calculation results in a value of zero due to rounding or insufficient token quantity, the require statement will trigger, preventing the sale of the remaining tokens. This can lead to a poor user experience and potential financial loss for users who wish to liquidate their holdings.

Recommended mitigation steps

To mitigate this issue, consider implementing the following changes:

Review the logic for partial listings: Ensure that the logic for handling partial listings is robust enough to allow for small remaining amounts to be sold, possibly by adjusting the conditions under which a sale can occur.
