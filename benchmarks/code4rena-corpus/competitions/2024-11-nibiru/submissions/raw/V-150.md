# Vulnerability details

## Issue Description: 

The function does not verify if fees is non-zero. A zero fee could bypass deductions.

## Proof-of-Concept:

    k.DeductTxCostsFromUserBalance(ctx, sdk.Coins{}, sender)

## Impact: 

This could allow transactions to proceed without proper fee deductions, leading to economic inconsistencies.

## Risk: 

High

## Mitigation: 

Add a check to ensure fees is greater than zero.


    if fees.IsZero() {
      return errors.Wrap(errortypes.ErrInvalidRequest, "fees must be greater than zero")
    }
