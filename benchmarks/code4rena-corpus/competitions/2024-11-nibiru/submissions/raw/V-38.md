# Vulnerability details

## Finding description and impact

The EthAccount function in Keeper lacks proper validation for the input Ethereum address. When an invalid address is provided, the function attempts to process it and returns an unclear error message

- 1.Usability issue: Users receive unclear or vague error messages when providing invalid addresses
- 2.Potential security issue: Misinterpreted errors might lead to unintended behavior in downstream systems
