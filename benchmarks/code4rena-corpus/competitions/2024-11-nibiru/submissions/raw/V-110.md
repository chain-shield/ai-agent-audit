# Vulnerability details

## Issue Description:

In the Run function, gas consumption is calculated locally using the startResult.CacheCtx.GasMeter().GasConsumed(). However, this does not directly ensure synchronization with the EVM gas mechanism, leading to potential gas miscalculations. This can result in undercharging or overcharging users.

## Proof-of-Concept Code:

wasm.go#L79

    contract.UseGas(startResult.CacheCtx.GasMeter().GasConsumed())

## Impact:

May lead to Denial of Service (DoS) if gas is underestimated.
Economic discrepancies in gas costs between EVM and Wasm.

## Mitigation Code:

Update the gas accounting to explicitly ensure it aligns with the EVM gas accounting:

    evmGasUsed := ctx.GasMeter().GasConsumed() * GasAdjustmentFactor
    if evmGasUsed > contract.Gas {
       return nil, vm.ErrOutOfGas
    }
    contract.UseGas(evmGasUsed)
