# Vulnerability details

## Issue Description: 

The function does not account for potential errors in ConsumeGas, which may leave the gas meter in an inconsistent state.

## Proof-of-Concept:

    k.ResetGasMeterAndConsumeGas(ctx, gasUsed)
    // Error during ConsumeGas leaves an inconsistent gas meter state.


## Impact: 

This can result in overcharging or undercharging gas fees.

## Risk:

High

## Mitigation: 

Implement error handling or rollback for gas meter operations.

    initialGas := ctx.GasMeter().GasConsumed()
    defer func() {
    if r := recover(); r != nil {
        ctx.GasMeter().RefundGas(ctx.GasMeter().GasConsumed()-initialGas, "rollback gas count")
    }
    }()
    ctx.GasMeter().ConsumeGas(gasUsed, "apply evm transaction")
