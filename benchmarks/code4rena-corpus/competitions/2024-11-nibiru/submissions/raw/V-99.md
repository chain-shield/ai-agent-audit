# Vulnerability details

## Issue Description: 

The method directly processes hash without ensuring that it is valid or follows the expected format.


## Proof-of-Concept: 

Passing an invalid hash (e.g., malformed or empty) can cause unexpected errors downstream, such as null dereferencing or backend crashes.

    hash := common.HexToHash("invalid_hash")
    tx, err := api.GetTransactionByHash(hash)
    if err != nil {
     fmt.Println("Error:", err)
    }

## Impact: Medium.

This can lead to application crashes or potential Denial-of-Service (DoS) if exploited repeatedly.


## Mitigation: 

Validate the hash format before processing

    if !common.IsHexAddress(hash.Hex()) {
     return nil, errors.New("invalid transaction hash")
    }
