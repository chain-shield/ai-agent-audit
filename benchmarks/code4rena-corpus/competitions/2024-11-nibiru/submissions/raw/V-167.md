# Vulnerability details


## Proof of Concept

Nibiru's EVM implementation lacks any support for transient storage as defined in [EIP-1153](https://eips.ethereum.org/EIPS/eip-1153).

To explain this, lets take the go-ethereum implementation as an example, which includes transient storage tracking in their Journal through `transientStorageChange`, but this functionality and other places that support `TSTORE/`TLOAD` is completely absent in Nibiru's codebase.

Using code snippets, see the Go-Ethereum Implementation https://github.com/ethereum/go-ethereum/blob/23800122b37695be50565f8221858a16ce1763db/core/state/journal.go#L283-L287:

```go

type transientStorageChange struct {
    account       common.Address
    key, prevalue common.Hash
}

func (ch transientStorageChange) revert(s *StateDB) {
    s.setTransientState(ch.account, ch.key, ch.prevalue)
}


```

Nibiru lacks this implementation entirely however, see [./x/evm/statedb/journal.go](https://github.com/code-423n4/2024-11-nibiru/blob/8ed91a036f664b421182e183f19f6cef1a4e28ea/x/evm/statedb/journal.go)

Note that the TSTORE/TLOAD opcodes are used most popularly for reentrancy guards, flash accounting, and slippage protection in some cases, which would then mean that this isn't implementable in Nibiru.

## Impact

Smart contracts relying on transient storage will fail, i.e DApps designed with transient storage optimizations won't work (incompatibility with Ethereum mainnet behavior).

Which also showcases how the first window for attack ideas requested by Nibiru for the audit is not followed:

## Attack ideas (where to focus for bugs)

Considering users that expect the same implementation of `tstore` even in Nibiru would not get this as they are used to it on Chains like Mainnet/Arbitrum.

### Recommended Mitigation

1. Implement transient storage support:

```go
type transientStorageChange struct {
    account  common.Address
    key      common.Hash
    prevalue common.Hash
}

func (ch transientStorageChange) Revert(s *StateDB) {
    s.setTransientState(ch.account, ch.key, ch.prevalue)
}
```

2. Add necessary StateDB methods:

```go
func (s *StateDB) SetTransientState(addr common.Address, key, value common.Hash)
func (s *StateDB) GetTransientState(addr common.Address, key common.Hash) common.Hash
```
