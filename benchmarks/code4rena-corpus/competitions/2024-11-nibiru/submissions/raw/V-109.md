# Vulnerability details

## Description: 

The instantiate method doesn't enforce strict access control, allowing any caller to instantiate contracts.

## Proof of Concept:

    txMsg, err := p.parseArgsWasmInstantiate(args, callerBech32.String())

There is no validation to restrict unauthorized users.

## Impact:

Malicious actors could deploy unverified contracts, leading to trust issues.

## Risk: 

High

## Mitigation Code:

Implement role-based access checks:

    if !isAuthorizedCaller(callerBech32) {
     return nil, fmt.Errorf("caller %s is not authorized to instantiate contracts", callerBech32)
    }
