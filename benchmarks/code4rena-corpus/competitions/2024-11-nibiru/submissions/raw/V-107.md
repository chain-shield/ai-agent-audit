# Vulnerability details

## Issue Description:

In SendRawTransaction, raw transaction bytes are decoded without additional validation.

## Proof of Concept:

call_tx.go#L30

    if err := tx.UnmarshalBinary(data); err != nil {
    b.logger.Error("transaction decoding failed", "error", err.Error())
     return common.Hash{}, err
    }

If malformed or malicious data is submitted, it could crash the system or lead to unexpected behavior.

## Impact:

Denial of service through malformed payloads.

## Risk:

High

## Mitigation: 

Add input validation to ensure data integrity before decoding

    if len(data) == 0 || len(data) > maxTransactionSize {
     return common.Hash{}, errors.New("invalid transaction size")
    }
