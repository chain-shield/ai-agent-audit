# Vulnerability details

## Issue Description: 

The SafeInsert function directly inserts the token without checking if a token with the same ID already exists in the state. This could overwrite existing tokens without notice.

## Proof of Concept Code:

    err := fun.SafeInsert(ctx, erc20, "testDenom", true)
    if err == nil {
    fmt.Println("First insertion successful")
    }
    err = fun.SafeInsert(ctx, erc20, "newDenom", true)
    if err == nil {
    fmt.Println("Overwrote existing token")
    }


## Impact: 

Overwriting tokens may cause data loss and inconsistencies, especially if the same erc20 address maps to multiple bankDenom values.

## Risk: 

Medium - While recoverable, this could lead to business logic errors or unintended overwrites.

## Mitigation Code:

    existingToken := fun.Get(ctx, funtoken.ID())
    if existingToken != nil {
    return fmt.Errorf("token with ID %s already exists", funtoken.ID())
    }

Add this check before calling Insert.
