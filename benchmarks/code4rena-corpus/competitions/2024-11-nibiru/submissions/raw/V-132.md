# Vulnerability details

## Issue Description: 

Functions AddBalance and SubBalance directly modify balances without validating that the operations do not result in overflow/underflow.

- In the AddBalance and SubBalance methods, there is no explicit check for overflow or underflow when performing arithmetic operations on the account balance.

- Although Go supports arbitrary-precision integers with *big.Int, overflow or underflow could occur with operations involving external inputs (such as user-provided amounts).

AddBalance:
    
    s.SetBalance(new(big.Int).Add(s.Balance(), amount))

SubBalance:
    
    s.SetBalance(new(big.Int).Sub(s.Balance(), amount))

Even though *big.Int handles large values, operations that might result in invalid values (such as subtracting a larger amount than the balance) should be handled carefully to avoid unexpected behavior or errors during contract execution.

## Proof of Concept #1:

    func (s *stateObject) AddBalance(amount *big.Int) {
    // Potential overflow if amount > maxInt
    s.SetBalance(new(big.Int).Add(s.Balance(), amount))
    }

## Proof of Concept #2:

    // A negative balance scenario (SubBalance example):

## Impact:

Exploiting this vulnerability could allow attackers to create invalid states by either inflating or depleting balances beyond acceptable limits.

- Risk of unexpected behaviors such as negative balances when performing transfers or state changes. This can lead to unintended results like contract malfunctions or security loopholes.

- Contract logic breakage when a user attempts to subtract more funds than are available, causing inconsistency in contract state.


## Risk:
High

## Mitigation

- Use the big.Int methods that handle overflow or underflow checks. For instance, use new(big.Int).Add(x, y).Mod() or check if the result is negative before committing state changes.

- Ensure that any balance modification includes a check for logical consistency (e.g., not allowing balance subtraction if the resulting balance is negative).

Mitigation Code:

    func (s *stateObject) AddBalance(amount *big.Int) {
    if amount.Sign() == 0 {
        return
    }
    newBalance := new(big.Int).Add(s.Balance(), amount)
    if newBalance.Sign() < 0 {
        panic("Balance overflow")
    }
    s.SetBalance(newBalance)
    }
