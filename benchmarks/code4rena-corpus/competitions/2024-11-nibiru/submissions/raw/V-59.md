# Vulnerability details

## Description 
The `sendToBank` function in `funtoken.go` assumes that the Transfer method of an ERC20 token will return a non-nil MsgEthereumTxResponse. However, tokens like USDT (and potentially other non-standard ERC20 implementations) do not return a response in the standard format or omit it entirely. This discrepancy can cause runtime errors, such as nil pointer dereference, or lead to incomplete transaction handling for these tokens.
## Impact
Transaction Failures: Calls to sendToBank involving non-standard tokens like USDT fail due to the missing response.


## Recommended mitigation steps
Add checks to identify tokens with non-standard behavior (e.g., USDT) and adapt the handling logic accordingly.
