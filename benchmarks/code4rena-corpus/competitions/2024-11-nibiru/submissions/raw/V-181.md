# Vulnerability details

## Issue Description: 

The txData.GetGas() method is used directly to determine gas limits without robust validation to ensure it aligns with the block gas limit.


## Proof of Concept

    if gasWanted > blockGasLimit {
    // Validation exists here, but the prior use of gasWanted can be exploited.
    }

An attacker can craft transactions with inflated gas limits, potentially exploiting this check.

## Impact: 

Can lead to denial of service (DoS) by exceeding gas thresholds or resource exhaustion.

## Risk: 

High

## Mitigation:

    if txData.GetGas() > anteDec.maxGasWanted || txData.GetGas() > blockGasLimit {
      return ctx, errors.Wrapf(sdkerrors.ErrOutOfGas, "gas limit exceeds allowed thresholds")
    }
