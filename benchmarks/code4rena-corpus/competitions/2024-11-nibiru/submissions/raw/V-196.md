# Vulnerability details

## Issue Description:


The RPCFilterCap function lacks mechanisms to enforce or validate the filter cap dynamically, which might lead to resource exhaustion.

## Proof of Concept (PoC):

    func (b *Backend) RPCFilterCap() int32 {
     return b.cfg.JSONRPC.FilterCap // Returns a static value
    }

## Impact:

Resource exhaustion from excessive filter creation.

## Risk Level:

High

## Mitigation:

Implement runtime validation for FilterCap:

    func (b *Backend) RPCFilterCap() int32 {
    filterCap := b.cfg.JSONRPC.FilterCap
    if filterCap <= 0 || filterCap > MaxAllowedFilters {
        return DefaultFilterCap // Use a safe fallback
    }
    return filterCap
    }
