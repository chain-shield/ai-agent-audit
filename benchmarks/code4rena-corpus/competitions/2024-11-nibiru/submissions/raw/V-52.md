# Vulnerability details

In the Code query implementation, the GetCode function is used to retrieve smart contract bytecode:

https://github.com/code-423n4/2024-11-nibiru/blob/main/x/evm/keeper/grpc_query.go#L211

```go
func (k Keeper) Code(
    goCtx context.Context, req *evm.QueryCodeRequest,
) (*evm.QueryCodeResponse, error) {
    if err := req.Validate(); err != nil {
        return nil, err
    }

    ctx := sdk.UnwrapSDKContext(goCtx)

    address := gethcommon.HexToAddress(req.Address)
    acct := k.GetAccountWithoutBalance(ctx, address)

    var code []byte
    if acct != nil && acct.IsContract() {
        code = k.GetCode(ctx, gethcommon.BytesToHash(acct.CodeHash))
    }

    return &evm.QueryCodeResponse{
        Code: code,
    }, nil
}
```

The GetCode function, however, uses panic to handle errors instead of returning an error to the caller:

https://github.com/code-423n4/2024-11-nibiru/blob/main/x/evm/keeper/statedb.go#L42

```go
// GetCode: Loads smart contract bytecode.
// Implements the `statedb.Keeper` interface.
func (k *Keeper) GetCode(ctx sdk.Context, codeHash gethcommon.Hash) []byte {
    codeBz, err := k.EvmState.ContractBytecode.Get(ctx, codeHash.Bytes())
    if err != nil {
        panic(err) // TODO: We don't like to panic.
    }
    return codeBz
}
```

---

### Impact

The impact is relatively low but significant enough to warrant attention. The use of panic may cause the service to terminate unexpectedly, leading to interruptions and a poor user experience.

---

### Suggested Fix

Replace the panic call with proper error handling to return the error to the caller, allowing it to be handled gracefully:

```go
func (k *Keeper) GetCode(ctx sdk.Context, codeHash gethcommon.Hash) ([]byte, error) {
    codeBz, err := k.EvmState.ContractBytecode.Get(ctx, codeHash.Bytes())
    if err != nil {
        return nil, err
    }
    return codeBz, nil
}
```

Update the calling code to handle the error appropriately:

```go
if acct != nil && acct.IsContract() {
    var err error
    code, err = k.GetCode(ctx, gethcommon.BytesToHash(acct.CodeHash))
    if err != nil {
        return nil, err
    }
}
```

This ensures the service remains stable and avoids unexpected interruptions.
