# Vulnerability details

## Issue Description:

Several functions, such as retrieveEVMTxFeesFromBlock and AllTxLogsFromEvents, use unchecked type assertions that may cause runtime panics.

## Proof-of-Concept Code:

utils.go#L133

    gasLimitUint64, ok := (*ethBlock)["gasLimit"].(hexutil.Uint64)
    if !ok {
     return fmt.Errorf("invalid gas limit type: %T", (*ethBlock)["gasLimit"])
    }


## Impact:

- Runtime panics due to invalid type assertions.

- Inconsistent behavior and potential Denial-of-Service (DoS) vectors.

## Risk:

High

## Mitigation:

Replace unchecked type assertions with safe conversions and handle errors gracefully.

    gasLimitUint64, err := parseHexutilUint64((*ethBlock)["gasLimit"])
    if err != nil {
     return fmt.Errorf("invalid gas limit type: %v", err)
    }

Add a utility function:

    func parseHexutilUint64(value interface{}) (hexutil.Uint64, error) {
    if v, ok := value.(hexutil.Uint64); ok {
        return v, nil
    }
     return 0, fmt.Errorf("expected hexutil.Uint64, got %T", value)
    }
