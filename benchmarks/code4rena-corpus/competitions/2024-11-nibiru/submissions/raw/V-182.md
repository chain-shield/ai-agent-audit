# Vulnerability details

## Issue Description: 

The eth.NewInfiniteGasMeterWithLimit(gasWanted) is used, which potentially allows infinite gas consumption during the ReCheckTx phase.

## Proof of Concept

    newCtx := ctx.WithGasMeter(eth.NewInfiniteGasMeterWithLimit(gasWanted))

Gas abuse can occur during state transition, especially when gasWanted is incorrectly calculated.

## Impact:

Potential overconsumption of network resources.

## Risk: 

Medium

## Mitigation

    if gasWanted == 0 || gasWanted > anteDec.maxGasWanted {
     return ctx, errors.Wrapf(sdkerrors.ErrOutOfGas, "invalid gas wanted value")
    }
    newCtx := ctx.WithGasMeter(sdk.NewGasMeter(gasWanted))
