# Vulnerability details

The SetParams function is a setter function used to update module parameters. It stores the received params into the module's state. Before storing, the function checks if the CreateFuntokenFee is negative, and if so, it returns an error. However, it fails to check if CreateFuntokenFee is zero.

https://github.com/code-423n4/2024-11-nibiru/blob/main/x/evm/keeper/evm_state.go#L121

```go
// SetParams: Setter for the module parameters.
func (k Keeper) SetParams(ctx sdk.Context, params evm.Params) (err error) {
	if params.CreateFuntokenFee.IsNegative() {
		return fmt.Errorf("createFuntokenFee cannot be negative: %s", params.CreateFuntokenFee)
	}

	k.EvmState.ModuleParams.Set(ctx, params)
	return
}
```

### Impact

- **Zero CreateFuntokenFee**: Setting CreateFuntokenFee to zero could allow the creation of smart contracts without any fees. This can lead to system abuse, especially when a large number of users or malicious actors create tokens without cost, consuming significant resources and potentially causing system overload.
- **Lack of Incentive**: Without a sufficient fee, smart contract creation may lack proper incentives to prevent abuse. Attackers could create large numbers of meaningless tokens or contracts with zero fees, wasting network resources and potentially triggering Denial of Service attacks on the system.

### Suggested Fix

A check for zero CreateFuntokenFee should be added to prevent the creation of contracts without fees:

```go
// SetParams: Setter for the module parameters.
func (k Keeper) SetParams(ctx sdk.Context, params evm.Params) (err error) {
    // Check if CreateFuntokenFee is negative
    if params.CreateFuntokenFee.IsNegative() {
        return fmt.Errorf("createFuntokenFee cannot be negative: %s", params.CreateFuntokenFee)
    }

    // Check if CreateFuntokenFee is zero
    if params.CreateFuntokenFee.IsZero() {
        return fmt.Errorf("createFuntokenFee cannot be zero: %s", params.CreateFuntokenFee)
    }

    // Save the parameters
    k.EvmState.ModuleParams.Set(ctx, params)
    return
}
```
