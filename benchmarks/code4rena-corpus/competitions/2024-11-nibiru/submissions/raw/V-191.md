# Vulnerability details

## Issue Description:

The Contains function does not validate the idx before accessing al.slots[idx]. If idx is out of bounds due to an invalid state, it will panic.

## Proof of Concept (PoC):

    al := newAccessList()
    addr := common.HexToAddress("0x456")
    _, _ = al.Contains(addr, common.HexToHash("0x789")) // Causes index out of bounds panic


## Impact:

A panic could halt execution unexpectedly, causing disruptions in smart contract processing.

## Risk: 

Medium

Although this requires an invalid state, improper initialization or corrupted state can trigger it.

## Mitigation: 

Add a boundary check:

    if idx < 0 || idx >= len(al.slots) {
    return true, false
    }
