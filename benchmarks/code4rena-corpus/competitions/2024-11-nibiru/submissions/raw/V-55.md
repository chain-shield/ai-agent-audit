# Vulnerability details

## Finding description and impact

This is a issue in the Nibiru EVM RPC implementation where the `StateOverride` parameter in the `eth_call` method is completely ignored. This parameter is critical for simulating smart contract calls with modified state conditions.

The current implementation:
```go
func (e *EthAPI) Call(args evm.JsonTxArgs,
    blockNrOrHash rpc.BlockNumberOrHash,
    _ *rpc.StateOverride, // Silently ignored
) (hexutil.Bytes, error) {
    // ... executes call without applying state overrides
    return (hexutil.Bytes)(data.Ret), nil
}
```

This creates several critical issues:

1. **Silent Failure**: The code accepts state overrides but silently ignores them, providing no indication that the simulation is running against unmodified state.

2. **Incorrect Simulation Results**: Applications that rely on state overrides for testing or simulation will receive incorrect results without any error indication.

3. **Breaking Standard Ethereum Tooling**: As highlighted in audit guidelines, this breaks expected behavior of standard tooling like Web3 libraries (ethers.js, web3.js)

## Proof of Concept

Any `call` invocation with state overrides will be incorrect:

For example: using ethers.js to simulate a contract call with modified balance:
```javascript
const result = await provider.call({
    to: contractAddress,
    data: encodedData
}, {
    blockTag: "latest",
    stateOverride: {
        [accountAddress]: {
            balance: ethers.utils.parseEther("100")
        }
    }
});
// Result will be based on actual balance, not 100 ETH
```

## Recommended mitigation steps


Choose ONE of these approaches to fix the silent failure:

Option 1: Full Implementation of StateOverrides

OR

Option 2: Explicit Non-Support of StateOverrides

```go
func (e *EthAPI) Call(
    args evm.JsonTxArgs,
    blockNrOrHash rpc.BlockNumberOrHash,
    stateOverride *rpc.StateOverride,
) (hexutil.Bytes, error) {
    if stateOverride != nil {
        return nil, &rpc.JSONError{
            Code:    -32000,
            Message: "StateOverride parameter is not supported on Nibiru network",
            Data:    "Use standard eth_call without state overrides",
        }
    }
    
    blockNum, err := e.backend.BlockNumberFromTendermint(blockNrOrHash)
    if err != nil {
        return nil, err
    }
    
    return e.backend.DoCall(args, blockNum)
}
```
