# Vulnerability details

## Issue Description: 

The deployERC20ForBankCoin function creates a deterministic address using the nonce of the EVM_MODULE_ADDRESS. If the nonce reaches its limit, the contract creation will fail.

## Proof-of-Concept (PoC) Code

    for i := 0; i < maxNonce; i++ {
    _, err := k.deployERC20ForBankCoin(ctx, validMetadata)
    if err != nil {
        fmt.Println("Deployment failed:", err)
    }
    }


## Impact: 
Failure to deploy new ERC20 contracts once the nonce is exhausted.

## Risk Level: 

High.

## Mitigation:

Check and handle nonce exhaustion explicitly

    if nonce := k.GetAccNonce(ctx, evm.EVM_MODULE_ADDRESS); nonce >= maxNonce {
    return gethcommon.Address{}, fmt.Errorf("nonce exhausted for EVM_MODULE_ADDRESS")
    }
