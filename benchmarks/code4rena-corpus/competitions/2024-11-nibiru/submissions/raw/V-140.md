# Vulnerability details

## Issue Description

Balance conversion from string in GetBalance and GetProof lacks proper validation and error handling.

## Proof of Concept


    balance, ok := sdkmath.NewIntFromString(res.BalanceWei)
    if !ok {
     return nil, errors.New("invalid balance")
    }


## Impact

Malformed balance strings can crash the node or cause undefined behavior.

## Risk

High

## Mitigation

Add logging and validation:

    balance, ok := sdkmath.NewIntFromString(res.BalanceWei)
    if !ok || balance.IsNegative() {
     b.logger.Error("Invalid balance format", "balance", res.BalanceWei)
     return nil, errors.New("invalid or negative balance")
    }
