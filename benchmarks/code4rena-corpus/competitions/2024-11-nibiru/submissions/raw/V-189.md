# Vulnerability details

## Issue Description: 

The TxIndex and LogIndex are retrieved using uint conversion, which may result in undefined behavior if the source value exceeds the bounds of unit.

## Proof-of-Concept Code


    k.EvmState.BlockTxIndex.Set(ctx, math.MaxUint64+1) // Exceeds uint limit
    txConfig := k.TxConfig(ctx, txHash)
    fmt.Println(txConfig.TxIndex) // Unexpected results

## Impact: 

Integer overflow could lead to incorrect configuration or crashing nodes.

## Risk: 

Medium

## Mitigation Code:

    func (k *Keeper) TxConfig(ctx sdk.Context, txHash common.Hash) statedb.TxConfig {
    txIndex := k.EvmState.BlockTxIndex.GetOr(ctx, 0)
    logIndex := k.EvmState.BlockLogSize.GetOr(ctx, 0)

    // Ensure values do not exceed uint limits.
    if txIndex < 0 || logIndex < 0 {
        panic("Index cannot be negative")
    }

    return statedb.TxConfig{
        BlockHash: common.BytesToHash(ctx.HeaderHash()),
        TxHash:    txHash,
        TxIndex:   uint(txIndex),
        LogIndex:  uint(logIndex),
    }
    }
