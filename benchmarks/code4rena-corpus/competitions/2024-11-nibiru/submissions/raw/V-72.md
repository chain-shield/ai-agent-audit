# Vulnerability details

## Issue Description:

In the GetCode function, if an error occurs while fetching the bytecode, the function uses panic(err). This can lead to a complete halt of the system if an unexpected error occurs.

## Proof of Concept:

    codeBz, err := k.EvmState.ContractBytecode.Get(ctx, codeHash.Bytes())
    if err != nil {
    panic(err) // TODO: We don't like to panic.
    }


## Impact:

A single unexpected failure in this function could crash the node or application, leading to denial of service (DoS).
A panic could halt the execution of the chain node, resulting in downtime.

## Risk Level:

High

- Chains need to remain resilient against such events.

- A failure in loading bytecode can crash the system, affecting the availability and reliability of the 
  network.

## Mitigation:

Replace the panic with proper error handling to ensure the application continues running:

    if err != nil {
    return nil, sdkerrors.Wrapf(evm.ErrBytecodeRetrieval, "failed to get code for hash: %s", 
    codeHash.Hex())
    }
