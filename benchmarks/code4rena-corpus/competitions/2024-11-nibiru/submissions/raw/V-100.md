# Vulnerability details

## Issue Description: 

The res.MsgIndex field is cast to an integer without verifying bounds or type.


## Proof-of-Concept: 

If res.MsgIndex is set to a very large value or has invalid data (possibly due to external manipulation), this can cause integer overflow or undefined behavior.

    index := int(res.MsgIndex) // unsafe conversion


## Impact: High

May cause incorrect indexing of logs or runtime panics.


## Mitigation: 

Validate res.MsgIndex to ensure it fits within the integer range:

    if res.MsgIndex > math.MaxInt32 {
     return nil, errors.New("index out of bounds")
    }
    index := int(res.MsgIndex)
