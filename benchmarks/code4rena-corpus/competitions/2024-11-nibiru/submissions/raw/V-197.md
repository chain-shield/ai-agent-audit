# Vulnerability details

## Issue Description: 

The SafeInsert method does not validate if the provided erc20 address is non-zero. An invalid or zero Ethereum address could lead to storage of invalid tokens and potential disruptions during retrieval.

## Proof of Concept Code:

    err := fun.SafeInsert(ctx, gethcommon.Address{}, "testDenom", true)
    if err == nil {
    fmt.Println("Inserted invalid token")
    }

## Impact: 

Storing tokens with invalid erc20 addresses could lead to inconsistencies and failures when attempting to retrieve or interact with these tokens.

## Risk: 

High - This could result in corrupted token data and make retrieval impossible.

## Mitigation Code:

    if erc20 == (gethcommon.Address{}) {
    return fmt.Errorf("invalid ERC20 address: zero address is not allowed")
    }

Add this validation at the beginning of the SafeInsert function.
