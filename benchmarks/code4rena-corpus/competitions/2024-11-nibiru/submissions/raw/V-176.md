# Vulnerability details

## Issue Description: 

The MintCoins, BurnCoins, and SendCoins functions assume that balances are non-negative. There are no checks to prevent negative balances due to logic errors.

## Proof-of-Concept:

    if err := bk.BaseKeeper.BurnCoins(ctx, moduleName, coins); err != nil {
	return err
    }
    // No check for resulting negative balance


## Impact:

- Negative balances can lead to state inconsistencies.

- Could be exploited to create invalid state transitions.

## Risk Level: 

Critical

## Mitigation: 

Add validation to ensure that resulting balances are non-negative.

    if err := bk.BaseKeeper.BurnCoins(ctx, moduleName, coins); err != nil {
	return err
    }
    newBalance := bk.GetBalance(ctx, acc, evm.EVMBankDenom).Amount.BigInt()
    if newBalance.Sign() < 0 {
	panic("Negative balance detected")
    }
