# Vulnerability details

## Issue Description

The contract checks whether baseFeeWeiPerGas is nil, but the subsequent call to msgEthTx.EffectiveGasCapWei(baseFeeWeiPerGas) does not handle the scenario where it is nil. This creates the potential for a runtime panic.

## Proof of Concept
 
    baseFeeWeiPerGas := evm.NativeToWei(ctd.EVMKeeper.BaseFeeMicronibiPerGas(ctx))

    // If baseFeeWeiPerGas is nil, the following line will cause a runtime panic
    if msgEthTx.EffectiveGasCapWei(baseFeeWeiPerGas).Cmp(baseFeeWeiPerGas) < 0 {
    ...
    }


## Impact

High: This could cause a denial of service (DoS) by panicking the system when processing specific transactions.

## Risk Level

High

## Mitigation

Add a return statement immediately after detecting that baseFeeWeiPerGas is nil to ensure no further operations are performed.

## Mitigation Code

    if baseFeeWeiPerGas == nil {
    return ctx, errors.Wrap(
        evm.ErrInvalidBaseFee,
        "base fee is nil for this block.",
    )
    }
