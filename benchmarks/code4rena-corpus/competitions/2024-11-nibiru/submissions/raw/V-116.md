# Vulnerability details

## Issue Description:

The code uses txIndex to iterate through the sorter array, but there is no check to ensure that txIndex does not exceed the length of the array.

## Proof of Concept Code:

    for sumGasUsed < thresholdGasUsed && txIndex < ethTxCount-1 {
    txIndex++
    sumGasUsed += sorter[txIndex].gasUsed
    }


## Impact:

- Index Out of Range: If the array sorter is empty or if txIndex exceeds ethTxCount-1, the code will 
  panic due to an "index out of range" error.

## Risk:

High - This can cause the service to crash, making it unreliable.

## Mitigation Code:

Ensure txIndex does not exceed the length of the array:

    for sumGasUsed < thresholdGasUsed && txIndex < ethTxCount {
    txIndex++
    sumGasUsed += sorter[txIndex].gasUsed
    }
