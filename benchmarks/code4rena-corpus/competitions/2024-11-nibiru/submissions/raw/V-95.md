# Vulnerability details

## Issue Description:

HandleOutOfGasPanic is used to recover from panics. However, recovery without full state inspection may leave partial changes in place.

The HandleOutOfGasPanic function is used in the Run method to gracefully recover from gas-related panics. However, the implementation appears to lack sufficient checks to ensure that it only catches and handles panics related to "out of gas" conditions. This could inadvertently catch other types of panics, masking critical bugs and leading to inconsistent behavior or silent failures.

## Proof-of-Concept 

Consider the following snippet from the Run method:

    // Gracefully handles "out of gas"
    defer HandleOutOfGasPanic(&err)()


If a non-gas-related panic occurs, such as a nil pointer dereference or an unexpected type assertion failure, it will also be caught by HandleOutOfGasPanic. This can result in misleading error reporting or improper handling of critical issues.

For example:

    // Simulating a type assertion failure
    var x interface{} = "string"
    _ = x.(int) // This will panic

This panic would also be caught by HandleOutOfGasPanic, which could lead to misdiagnosing the issue as an out-of-gas error.


## Impact

Severity: High

Improper handling of panics can result in undefined behavior, making debugging and resolution of actual issues significantly harder.

This issue is likely to occur if there are unexpected panics during execution, especially in a dynamic environment like the Ethereum Virtual Machine (EVM).


## Risk:

Critical bugs may be hidden, and incorrect assumptions about the state of execution can lead to vulnerabilities or failures.


## Mitigation

Enhance Panic Recovery: Modify the HandleOutOfGasPanic function to differentiate between out-of-gas panics and other types of panics.

Add Specific Panic Handling:

- Use the recover function to check the type or message of the panic.

- Only handle known out-of-gas errors, re-throwing other panics for debugging.

#### Mitigation #1:

Replace the HandleOutOfGasPanic function with the following enhanced implementation:

    func HandleOutOfGasPanic(err *error) {
     if r := recover(); r != nil {
        if errMsg, ok := r.(string); ok && strings.Contains(errMsg, "out of gas") {
            *err = fmt.Errorf("execution terminated due to out of gas: %v", r)
        } else {
            panic(r) // Re-throw the panic if it's not an out-of-gas error
        }
     }
    }
