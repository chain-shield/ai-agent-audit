# Vulnerability details

## Issue:

Potential Memory Exhaustion in Gas Estimation 

## Proof of Concept:

The EstimateGas method processes arbitrarily large transaction inputs:

    bz, err := json.Marshal(&args)

Large inputs could overwhelm system memory, leading to crashes.

## Impact

- May allow DoS attacks via large transaction inputs.
- Affects service availability.

## Risk

High – Memory exhaustion vulnerabilities are a common vector for attacks.

## Mitigation

Enforce size limits on transaction data:

    const MaxTxSize = 1_000_000 // 1 MB
    if len(bz) > MaxTxSize {
     return 0, fmt.Errorf("transaction data exceeds maximum allowed size of %d bytes", MaxTxSize)
    }
