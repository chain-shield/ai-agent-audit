# Vulnerability details

## Finding description and impact
When a new FunToken is to be created for an existing ERC20 token, it's first checked if there's an existing FunToken mapping for the provided ERC20 address:

```go
func (k *Keeper) createFunTokenFromERC20(
	ctx sdk.Context, erc20 gethcommon.Address,
) (funtoken *evm.FunToken, err error) {
	// 1 | ERC20 already registered with FunToken?
	if funtokens := k.FunTokens.Collect(ctx, k.FunTokens.Indexes.ERC20Addr.ExactMatch(ctx, erc20)); len(funtokens) > 0 {
		return funtoken, fmt.Errorf("funtoken mapping already created for ERC20 \"%s\"", erc20)
	}

        // ...
```

If there isn't one, the code proceeds to query the ERC20 token contract on the EVM for its name, symbol and decimals and generates a metadata struct for the to-be-created bank coin. After that the bank coin's metadata is saved against the provided ERC20 address which is used as a store key as is.

```go
        // ...
  
	return funtoken, k.FunTokens.SafeInsert(
		ctx, erc20, bankDenom, false,
	)
}
```

The little detail here is that `erc20` can be the valid address of a single ERC20 token for which a FunToken mapping does not exist yet in the application in quite a few cases:
- `0x000AAA111BBB...`
- `0x000aaa111bbb...`
- `0x000aAa111bbb...`
- `0x000Aaa111bbb...`
and so on, rotating which letters we capitalize... Quite a few combinations possible for a 20 byte address.

Which breaks the 5th main invariant listed in the contest readme.
> **Main invariants**
> 5. Similar to (3), any ERC20 on Nibiru can be used to create a <u>canonical</u> bank coin representation. The owner of the ERC20 is unbounded, while only the EVM Module account can mint the bank coin representation produced.
## Proof of Concept
1. Deploy a single ERC20 token on Nibiru's EVM.
2. Take the address it was deployed at and call `CreateFunToken()` with it as many variations of the hex representation as possible.
3. Now we have >1 FunToken mapping for a single ERC20 token contract.
## Recommended mitigation steps
When checking if a FunToken exists for the provided `erc20` address, lowercase it and then use it for checking of FunToken existence or using it as a key in the store.
