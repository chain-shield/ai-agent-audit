# Vulnerability details

## Issue Description:

The Revert function depends on a snapshot index without validating its range.

## Proof-of-Concept Code:

    func (j *journal) Revert(statedb *StateDB, snapshot int) {
    for i := len(j.entries) - 1; i >= snapshot; i-- {
        j.entries[i].Revert(statedb)
    }
    j.entries = j.entries[:snapshot]
    }


If snapshot is out of bounds (e.g., greater than len(j.entries)), this will lead to a runtime panic.


## Impact:

Improper handling can lead to crashes or undefined behavior during state rollbacks.

## Risk:

High — as state rollback is critical to blockchain execution integrity.

## Mitigation Code:

    func (j *journal) Revert(statedb *StateDB, snapshot int) {
    if snapshot < 0 || snapshot > len(j.entries) {
        return // Ignore invalid snapshot requests
    }
    for i := len(j.entries) - 1; i >= snapshot; i-- {
        j.entries[i].Revert(statedb)
    }
    j.entries = j.entries[:snapshot]
    }
