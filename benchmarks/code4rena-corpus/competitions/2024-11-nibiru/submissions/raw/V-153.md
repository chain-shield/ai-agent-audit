# Vulnerability details

## Issue Description:

The PendingTransactions method assumes TxDecoder is always non-nil, leading to a potential panic if it's not initialized.

## Proof-of-Concept:

    tx, err := b.clientCtx.TxConfig.TxDecoder()(txBz)


If TxDecoder is nil, this line will panic.

## Impact: 

High. Critical functionality relies on TxDecoder.

## Risk: 

High. Can crash the application during runtime.

## Mitigation Code:


    func (b *Backend) PendingTransactions() ([]*sdk.Tx, error) {
    mc, ok := b.clientCtx.Client.(tmrpcclient.MempoolClient)
    if !ok {
        return nil, errors.New("invalid rpc client")
    }

    if b.clientCtx.TxConfig.TxDecoder() == nil {
        return nil, errors.New("TxDecoder is not initialized")
    }

    res, err := mc.UnconfirmedTxs(b.ctx, nil)
    if err != nil {
        return nil, err
    }

    result := make([]*sdk.Tx, 0, len(res.Txs))
    for _, txBz := range res.Txs {
        tx, err := b.clientCtx.TxConfig.TxDecoder()(txBz)
        if err != nil {
            return nil, err
        }
        result = append(result, &tx)
    }

    return result, nil
    }
