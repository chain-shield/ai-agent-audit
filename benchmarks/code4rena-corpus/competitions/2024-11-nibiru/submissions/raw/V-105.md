# Vulnerability details

## Issue:

Failure to Validate Gas Cap Configuration

#### #1. Undefined or Improper Gas Cap:

The RPCGasCap() function is used to determine the gas cap but does not validate whether the returned value is:

 - Set to a reasonable default.
 
 - Within a permissible range.

#### #2. Implications:

If RPCGasCap() is not configured or is improperly set, it may:
 
 - Permit transactions with excessive gas, consuming node resources unnecessarily.

 - Reject legitimate transactions with insufficient gas, leading to operational disruptions.

#### #3. Context of Misconfiguration:

 - Node operators might misconfigure the gas cap in environments with shared infrastructure, causing 
   cascading effects on dependent services.

## Proof of Concept:

Gas cap enforcement is implied in the EstimateGas method but is not validated for correctness:

call_tx.go#L236

    GasCap: b.RPCGasCap(),


If b.RPCGasCap() is misconfigured or too high, malicious actors could overload the network.

## Impact

Potential for DoS attacks on the RPC endpoint.

May lead to block production delays.

#1. Resource Overutilization:

- Unbounded gas caps can allow malicious transactions to exhaust node resources.

#2. Transaction Failures:

- Excessively restrictive gas caps can prevent valid transactions, hindering user operations and
 contract execution.

#3. Reputation Risk:

 - Misconfigured gas cap policies might lead to user frustration and loss of trust in the network.

## Risk

High – Misconfigured gas limits are a common vulnerability.


## Mitigation

#1. Enforce reasonable upper bounds on the gas cap:

    const MaxGasCap = 30_000_000 // Example cap    
    if gasCap := b.RPCGasCap(); gasCap > MaxGasCap {
     return 0, fmt.Errorf("gas cap %d exceeds maximum allowed %d", gasCap, MaxGasCap)
    }

#2. Validate Gas Cap Value

Add validation to ensure the gas cap is always within a safe and reasonable range:

    func (b *Backend) RPCGasCap() uint64 {
    gasCap := b.config.GasCap // Assume this retrieves the configured gas cap
    if gasCap < 21000 || gasCap > 30_000_000 { // Enforce reasonable bounds
        panic("Invalid gas cap configuration: must be between 21,000 and 30,000,000")
    }
    return gasCap
    }
 
#3. Fallback to Default

If the gas cap is not explicitly set, fallback to a default:

    func (b *Backend) RPCGasCap() uint64 {
    if b.config.GasCap == 0 {
        return 15_000_000 // Default gas cap for safety
    }
    return b.config.GasCap
    }

#4. Log Misconfigurations

Log warnings for suspicious gas cap values to assist node operators:

    if gasCap < 21000 || gasCap > 30_000_000 {
      b.logger.Warn("Gas cap value is outside recommended bounds", "gasCap", gasCap)
    }
