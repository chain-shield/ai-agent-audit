# Vulnerability details

## Issue Description: 

The GasToRefund function assumes refundQuotient is always non-zero. A zero value will cause a division by zero error, leading to a runtime panic.

## Proof-of-Concept Code:

    GasToRefund(availableRefund: 1000, gasConsumed: 5000, refundQuotient: 0)

## Impact: 

This issue could cause the application to crash if the refundQuotient value is accidentally set to zero, disrupting the state machine.

## Risk:

High

## Mitigation: 

Add a check to ensure refundQuotient is greater than zero.


    func GasToRefund(availableRefund, gasConsumed, refundQuotient uint64) uint64 {
    if refundQuotient == 0 {
        return 0 // Or handle it gracefully
    }
    refund := gasConsumed / refundQuotient
    if refund > availableRefund {
        return availableRefund
    }
    return refund
    }
