# Vulnerability details

## Issue Description:

Addresses passed in execute, executeMulti, instantiate, and query are not validated to ensure they are correctly formatted Bech32 addresses.

## Proof-of-Concept Code:

    wasmContract, err := sdk.AccAddressFromBech32(m.ContractAddr)

Impact:

- Invalid addresses can bypass execution checks.

- May lead to funds being sent to unintended or inaccessible addresses.


## Mitigation Code:

Add strict validation for Bech32 format and ensure the checksum is verified:

    func validateBech32Addr(addr string) error {
    _, err := sdk.AccAddressFromBech32(addr)
    if err != nil {
        return fmt.Errorf("invalid Bech32 address: %s", addr)
    }
     return nil
    }

Invoke this validation before using any address in Wasm execution.
