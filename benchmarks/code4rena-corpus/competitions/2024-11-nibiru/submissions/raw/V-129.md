# Vulnerability details

## Issue Description:

Functions like s.getStateObject() assume the existence of valid state without error handling. This assumption may fail under edge cases.

## Prrof of Concept:

    func (ch balanceChange) Revert(s *StateDB) {
     s.getStateObject(*ch.account).setBalance(ch.prevWei) // No error check
    }


## Impact:

May lead to inconsistent states if getStateObject returns nil.

## Risk:

High — as it affects the correctness of state modifications.

## Mitigation Code:

    func (ch balanceChange) Revert(s *StateDB) {
    obj := s.getStateObject(*ch.account)
    if obj == nil {
        return // Handle gracefully
    }
    obj.setBalance(ch.prevWei)
    }
