# Vulnerability details

## Issue Description

In requiredGas, the isMutation map is accessed without checking for the presence of the method. While tests may ensure valid methods, introducing new methods without updating isMutation can lead to panics.

## Proof-of-Concept

    method := &gethabi.Method{Name: "nonExistentMethod"}
    gas := requiredGas(someInput, abi)
    // Panic: KeyError in isMutation map lookup.


## Impact

- Contracts could break if unexpected methods are introduced.

- Potential for deployment downtime or unintended halts.

## Risk

Medium – A well-maintained codebase reduces the risk, but unhandled edge cases can still cause issues.

## Mitigation Code

Introduce default handling:
    
    isMutable, ok := isMutation[PrecompileMethod(method.Name)]
    if !ok {
    return defaultGas // Assign a fallback gas cost
    }
    if isMutable {
    costPerByte, costFlat = gasCfg.WriteCostPerByte, gasCfg.WriteCostFlat
    } else {
    costPerByte, costFlat = gasCfg.ReadCostPerByte, gasCfg.ReadCostFlat
    }
