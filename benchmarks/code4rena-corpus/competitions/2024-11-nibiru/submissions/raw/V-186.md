# Vulnerability details

## Issue Description: 

Gas is consumed unconditionally in some scenarios, such as when EVM execution fails due to an error other than ErrOutOfGas. This could lead to over-consumption of gas.

## Proof of Concept:

    evmResp.VmError = "arbitrary_vm_error"
    if evmResp.Failed() {
    k.ResetGasMeterAndConsumeGas(ctx, evmResp.GasUsed)
    }

## Impact:

- Unnecessary depletion of gas for transactions that fail due to logical errors or external constraints.

- Potential Denial of Service (DoS) if this behavior is exploited.

## Risk Level: 

High

## Mitigation Code: 

Consume gas only when ErrOutOfGas is identified explicitly.

    if strings.Contains(evmResp.VmError, vm.ErrOutOfGas.Error()) {
    k.ResetGasMeterAndConsumeGas(ctx, evmResp.GasUsed)
    } else {
    err = fmt.Errorf("transaction failed with VM error: %s", evmResp.VmError)
    return
    }
