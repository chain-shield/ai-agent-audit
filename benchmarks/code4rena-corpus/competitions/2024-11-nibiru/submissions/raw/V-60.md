# Vulnerability details

## description 
The `sendToBank` function in `funtoken.go` (lines 147–152) does not implement slippage protection, exposing users to potential financial losses during volatile market conditions. Without slippage checks, users might inadvertently send tokens but receive an unexpectedly smaller value in return due to rapid price fluctuations or discrepancies in the token value calculation.
This is especially concerning when transferring volatile assets or during periods of high network congestion.
## impact
Financial Loss: Users may receive fewer tokens than expected when transferring due to value misalignment during execution.

## Recommended mitigation steps
Add slippage parameters to the function arguments, allowing users to specify the maximum acceptable slippage. Validate this during execution.
