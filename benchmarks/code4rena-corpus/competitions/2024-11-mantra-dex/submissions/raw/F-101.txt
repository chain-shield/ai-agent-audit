Pending ownership transfer not canceled when the current owner renounces ownership.
thisvishalsingh
07
Sufficient
383d ago
Finding description and impact
File: fee_collector.rs
Function: execute (for renounce_ownership in UpdateOwnership)
Root Issue: The renounce of ownership action does not invalidate the pending ownership transfer, leaving it active despite the current owner renouncing ownership.

The contract does not check for or cancel pending transfers during renouncement.

ExecuteMsg::UpdateOwnership(action) => {
    // @audit RenounceOwnership would be implemented as part of this action
}

Impact: While this violates logical expectations (a pending transfer being valid after the owner renounces ownership), could cause functional inconsistencies and unexpected contract behavior.

Recommended mitigation steps

Cancel pending ownership transfers when renouncing ownership.
