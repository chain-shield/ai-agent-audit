# Vulnerability details

## Issue:
Critical functions like addVault() and removeVault() in the IVaultRegistry contract are missing access control. This allows any external user to add or remove vaults, which could lead to unauthorized vault manipulation.

## Proof of Concept:

function addVault(ICDPVault vault) external {
    // No access control
}

function removeVault(ICDPVault vault) external {
    // No access control
}

## Mitigation:
Implement RBAC using OpenZeppelin’s AccessControl to ensure only authorized roles (e.g., ADMIN_ROLE) can add or remove vaults.
