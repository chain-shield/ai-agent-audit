# Vulnerability details

## Impact
The [_moveFunds](https://github.com/code-423n4/2024-10-loopfi/blob/d219f0132005b00a68f505edc22b34f9a8b49766/src/Treasury.sol#L68C5-L73C6) function can be called by any internal function within the contract or derived contracts, which allows unauthorized users to transfer funds from the contract to any specified treasury address. This could lead to significant financial losses, as attackers can exploit this vulnerability to siphon off funds.

Here is a comment from the dev
```solidity
/// @dev This function is only callable by the funds administrator
```
But the access control is missing in this critical function.
This vulnerability directly impacts the financial security of the contract, potentially allowing attackers to transfer funds without authorization.

## Proof of Concept
https://github.com/code-423n4/2024-10-loopfi/blob/d219f0132005b00a68f505edc22b34f9a8b49766/src/Treasury.sol#L68C5-L73C6

1. Attacker Deploys Malicious Contract: The attacker deploys a malicious contract that inherits from VulnerableContract or interacts with it through a public function:

```solidity
contract MaliciousContract {
    VulnerableContract public vulnerable;

    constructor(address _vulnerableAddress) {
        vulnerable = VulnerableContract(_vulnerableAddress);
    }

    function exploitMoveFunds(address treasury, IERC20 token) public {
        // This function indirectly triggers _moveFunds
        vulnerable._moveFunds(treasury, token);
    }
}
```

2. Calling the Exploit Function: The attacker calls the exploitMoveFunds function from their MaliciousContract, passing in their own address as the treasury:

```solidity
attackerContract.exploitMoveFunds(attackerAddress, token);
```
3. Executing the Exploit: When the exploitMoveFunds function is called, it can execute _moveFunds without any access control checks, leading to:

The balance of tokens in the VulnerableContract being sent to the attacker's address.

## Recommended Mitigation Steps
Implement the "onlyRole(FUNDS_ADMINISTRATOR_ROLE)" modifier.

```solidity
function _moveFunds(address treasury, IERC20 token) onlyRole(FUNDS_ADMINISTRATOR_ROLE) internal {
```
