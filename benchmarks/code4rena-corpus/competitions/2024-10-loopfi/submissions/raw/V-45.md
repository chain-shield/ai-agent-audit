# Vulnerability details

```solidity
function _moveFunds(address treasury, IERC20 token) internal {
    uint256 amount = token.balanceOf(address(this));
    if (amount > 0) {
        SafeERC20.safeTransfer(token, treasury, amount);
    }
}
```
## Description:
The `_moveFunds` function transfers `ERC20` tokens directly using `SafeERC20.safeTransfer`. However, this method does not handle the approval step required for ERC20 transfers that operate under an allowance model. Although safeTransfer itself is safe, it assumes that the contract already has sufficient approval to transfer tokens. If the approval step is missed elsewhere, this transfer could fail.
###### Note: This is an internal function but called in above external functions.

## impact:
The function could fail if the contract does not have approval to transfer tokens on behalf of the treasury, leading to incomplete or failed fund transfers.

## Proof Of Concept:
If an `ERC20` token requires the treasury to approve a specific token amount, but no such approval exists, calling `moveFunds` will fail silently or revert, leaving the funds in the contract.

## Tool used:
Manual Review.

## Recommended mitigation:
Ensure that the contract has approval from the token contract to transfer the desired amount of tokens before attempting the `safeTransfer`. Alternatively, include an approval check as part of the `_moveFunds` function to verify and handle allowances.
