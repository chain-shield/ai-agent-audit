# Vulnerability details

## Issue
The function accesses elements from primarySwapPath without checking its length:

token = primarySwapPath[0];
token = primarySwapPath[primarySwapPath.length - 1];
If the primarySwapPath array is empty, this will cause a transaction revert due to an out-of-bounds array access.

## Mitigation
Add array length checks to ensure that primarySwapPath has at least one element before accessing it:

require(primarySwapPath.length > 0, "Invalid swap path");
