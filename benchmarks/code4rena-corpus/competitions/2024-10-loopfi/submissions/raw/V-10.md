# Vulnerability details

## Proof of Concept

Overview :

* Within the `_doTransferOutRewards` function of the `RewardManager` contract, there is a critical line of code that is commented out, which prevents the proper transfer of accrued rewards to users. This oversight poses significant risks to user funds and undermines the contract's intended functionality. Below, we analyze the implications of this issue and recommend necessary actions for remediation.

Issue Description :

Commented-Out Code

The following line of code, responsible for transferring rewards to users, is currently commented out:
```
// _transferOut(tokens[i], receiver, rewardAmounts[i]);
```

Impacts :

* Reward Non-Distribution:

Issue: Since the reward transfer logic is commented out, users may never receive their accrued rewards. This directly affects user trust and satisfaction, as the contract fails to deliver the expected functionality.
Example: A user who has accrued rewards over time will see their rewards calculated correctly in the contract state but will not receive any tokens when attempting to withdraw, leading to frustration and potential loss of user engagement.

* Contract Functionality:

Issue: The failure to implement the reward transfer logic undermines the purpose of the `RewardManager` contract. The contract is designed to manage and distribute rewards; without the transfer mechanism, it does not fulfill its core function.
Example: Users may question the integrity of the contract if they are unable to withdraw rewards, leading to negative sentiment in the community and reduced adoption.

* Potential for Exploitation:

Issue: Malicious actors may take advantage of the omitted logic to exploit the contract. If users cannot receive rewards, they may attempt to interact with the contract in unintended ways, which could expose other vulnerabilities.
Example: Users could flood the contract with calls in an attempt to trigger the reward distribution, leading to high gas fees and network congestion.

## Recommended Mitigation Steps

* Recommendation: The commented-out line must be implemented properly to ensure that rewards are transferred to users.
