# Vulnerability details

## Description:
The `setParameter` function allows setting various vault parameters like `debtFloor`, `liquidationRatio`, and `reward-related` addresses. While there is an access control check `onlyRole(VAULT_CONFIG_ROLE)`, if roles are assigned incorrectly, an unauthorized account might gain control over sensitive vault operations.

## Impact:
An attacker or unauthorized user could modify critical vault parameters, leading to potential financial loss, increased liquidation risk, or reward distribution manipulation.

## Proof of Concept:
If an account is mistakenly granted the `VAULT_CONFIG_ROLE` it can call `setParameter` to reduce the `debtFloor`, enabling unsafe debt positions or adjusting `liquidationRatio`, increasing liquidation risks.

## Tool used:
Manual review

## Recommended mitigation:
Implement strict role management and validation for role assignments.
Add events for role changes.
