# Vulnerability details

## Impact

The current smart contract `ILOPool` inherits ERC-721 token functionality but does not follow specification correctly which creates a deviation and therefore possible incompatibility.

## Proof of Concept

According to the ERC-721 docs:

https://eips.ethereum.org/EIPS/eip-721
```
Every ERC-721 compliant contract must implement the ERC721 and ERC165 interfaces
```

The word MUST means it's not an option and all the contracts inheriting ERC-721 must implement this functionality to be ERC-721 compliant.

## Tools Used

Manual review.

## Recommended Mitigation Steps

Implement ERC-165 interface.
