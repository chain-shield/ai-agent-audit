# Vulnerability details

## Impact
The contest [README](https://code4rena.com/audits/2024-06-vultisig#top:~:text=ERC20%20token%20behaviors%20in%20scope) mentions that pausable tokens are in-scope.

Some tokens are pausable by admins, which won't allow any transfers.

Before the project is officially launched, investors can transfer `RAISE_TOKEN` to the `ILOPool`. When the project is launched, the `RAISE_TOKEN` is sent to the actual `Uniswap V3 pool` in return to mint liquidity for the position.

If the token is paused prior to `launch time`, the tokens will be locked in the `ILOPool` contract.

## Proof of Concept
Users can invest into projects by calling `ILOPool::buy()`

[ILOPool.sol#L173](https://github.com/code-423n4/2024-06-vultisig/blob/main/src/ILOPool.sol#L173)
```javascript
TransferHelper.safeTransferFrom(RAISE_TOKEN, msg.sender, address(this), raiseAmount);
```

This transfers `RAISE_TOKEN` from the sender into the `ILOPool`.

When the project is launched, these tokens are sent to the `Uniswap V3 pool` to mint liquidity for the position.

[ILOPool.sol#L284-L303](https://github.com/code-423n4/2024-06-vultisig/blob/main/src/ILOPool.sol#L284-L303)
```javascript
    // calculate sale amount of tokens needed for launching pool
    if (token0Addr == RAISE_TOKEN) {
        amount0 = totalRaised;
        amount0Min = totalRaised;
        (amount1, liquidity) = _saleAmountNeeded(totalRaised);
    } else {
        (amount0, liquidity) = _saleAmountNeeded(totalRaised);
        amount1 = totalRaised;
        amount1Min = totalRaised;
    }

    // actually deploy liquidity to uniswap pool
    (amount0, amount1) = addLiquidity(AddLiquidityParams({
        pool: IUniswapV3Pool(uniV3PoolAddress),
        liquidity: liquidity,
        amount0Desired: amount0,
        amount1Desired: amount1,
        amount0Min: amount0Min,
        amount1Min: amount1Min
    }));
```

If the token is paused before `launch time`, this will lock the funds in the contract indefinitely, and DoS project launches.
