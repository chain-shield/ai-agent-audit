# Vulnerability details

## Impact
The `checkWhitelist` method is meant to ensure that only whitelisted users can receive tokens, however, this was poorly implemented, making it possible for unwhitlisted users to be able to receive tokens.

## Proof of Concept
The below test will pass if put in the hardhat unit test even though the user's address isn't whitelisted. Which is a weird behavior since it is expected to fail

```javascript
it("Should pass checkWhitelist when not whitelisted", async function () {
      const { whitelist, pool, otherAccount, mockContract } = await loadFixture(
        deployWhitelistFixture
      );
      await whitelist.setVultisig(mockContract);
      await whitelist.setLocked(false);
      await whitelist.setAllowedWhitelistIndex(1);
      expect(await whitelist.whitelistIndex(otherAccount)).to.equal(0);
      // This should fail if otherAccount isn't whitlisted but it doesn't in this case
      whitelist.connect(mockContract).checkWhitelist(pool, otherAccount, 0);
 });
```

## Recommended Mitigation Steps
Include a check `_whitelistIndex[to] == 0 ` in the function's conditional to validate if the user's address has been whitelisted or not. Revert if not.

```javascript
function checkWhitelist(address from, address to, uint256 amount) external onlyVultisig {
        if (from == _pool && to != owner()) {
            // We only add limitations for buy actions via uniswap v3 pool
            // Still need to ignore WL check if it's owner related actions
            if (_locked) {
                revert Locked();
            }

            if (_isBlacklisted[to]) {
                revert Blacklisted();
            }

-           if (_allowedWhitelistIndex == 0 || _whitelistIndex[to] > _allowedWhitelistIndex)
+           if (_allowedWhitelistIndex == 0 || _whitelistIndex[to] == 0 || _whitelistIndex[to] > _allowedWhitelistIndex)
            {
                revert NotWhitelisted();
            }

            // // Calculate rough ETH amount for VULT amount
            uint256 estimatedETHAmount = IOracle(_oracle).peek(amount);
            if (_contributed[to] + estimatedETHAmount > _maxAddressCap) {
                revert MaxAddressCapOverflow();
            }

            _contributed[to] += estimatedETHAmount;
        }
    }
```
