# Vulnerability details

## Impact

The impact of allowing blacklisted addresses to be whitelisted is that it defeats the purpose of the blacklist. If an address is blacklisted, it is likely because it has been identified as malicious or otherwise undesirable. Allowing the owner to whitelist such addresses could enable those bad actors to regain access and potentially exploit the contract’s features. 

## Proof of Concept
1.) The receive function prevents blacklisted addresses from self-whitelisting:
```js

receive() external payable {
    if (_isSelfWhitelistDisabled) {
        revert SelfWhitelistDisabled();
    }
    if (_isBlacklisted[_msgSender()]) {
        revert Blacklisted();
    }
    _addWhitelistedAddress(_msgSender());
    payable(_msgSender()).transfer(msg.value);
}

```

2. The `addWhitelistedAddress` function that calls `_addWhitelistedAddress` function does not check if the address is blacklisted:

```js

function addWhitelistedAddress(address whitelisted) external onlyOwner {
    _addWhitelistedAddress(whitelisted);
}

 function _addWhitelistedAddress(address whitelisted) private {
        if (_whitelistIndex[whitelisted] == 0) {
            _whitelistIndex[whitelisted] = ++_whitelistCount;
        }
    }
}
```



### POC 
```solidity
// SPDX-License-Identifier: MIT
pragma solidity ^0.8.24;

import "forge-std/Test.sol";
import "../src/Whitelist.sol";

contract WhitelistTest is Test {
    Whitelist whitelist;
    address owner = address(0x1);
    address blacklistedAddress = address(0x2);

    function setUp() public {
        vm.startPrank(owner);
        whitelist = new Whitelist();
        whitelist.setBlacklisted(blacklistedAddress, true);
        vm.stopPrank();
    }

    function testBlacklistedAddressCanSelfWhitelist() public {
        // Ensure the address is blacklisted
        assertTrue(whitelist.isBlacklisted(blacklistedAddress));

        // Owner whitelists the blacklisted address
        vm.startPrank(owner);
        whitelist.addWhitelistedAddress(blacklistedAddress);
        vm.stopPrank();

        // Check if the blacklisted address is now whitelisted
        assertTrue(whitelist.whitelistIndex(blacklistedAddress) > 0);
    }
}
```

## Recommended Mitigation Steps
To mitigate this issue, the `_addWhitelistedAddress` function should be modified to include a check for blacklisted addresses. The function should revert if an attempt is made to whitelist a blacklisted address.



```js
 function _addWhitelistedAddress(address whitelisted) private {
 if (_isBlacklisted[whitelisted]) {
        revert Blacklisted();
    }
        if (_whitelistIndex[whitelisted] == 0) {
            _whitelistIndex[whitelisted] = ++_whitelistCount;
        }
    }
}

```
