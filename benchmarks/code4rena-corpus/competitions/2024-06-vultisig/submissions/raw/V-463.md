# Vulnerability details

## Impact
`ILOPool::claim` does not require any native tokens to be sent to the contract. Any `ETH` sent during this call will be forever stuck in the contract.

```
    function claim(uint256 tokenId)
        external
@>      payable
        override
        isAuthorizedForToken(tokenId)
        returns (uint256 amount0, uint256 amount1)
    {
```

## Tools Used
Manual Review

## Recommended Mitigation Steps
Make the function non-payable
