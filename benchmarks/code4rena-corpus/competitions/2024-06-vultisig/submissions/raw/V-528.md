# Vulnerability details

## Impact
Even after being Whitelisted user cannot receive the vult token.

## Proof of Concept
As per the VultisigWhitelisted contract to transfer Vult token to any address it first checks that the address is Whitelisted. Before any vult token transfer `_beforeTokenTransfer` is called to check that address is Whitelisted or not.
The `Whitelist::checkWhitelist()` checks that Whitelist address index should not be more than _allowedWhitelistIndex.

```solidity
function checkWhitelist(address from, address to, uint256 amount) external onlyVultisig {
        if (from == _pool && to != owner()) {
          ...
            // @audit-info the `to` address index should not be greater than _allowedWhitelistIndex
            if (_allowedWhitelistIndex == 0 || _whitelistIndex[to] > _allowedWhitelistIndex) {
                revert NotWhitelisted();
            }

            // // Calculate rough ETH amount for VULT amount
            uint256 estimatedETHAmount = IOracle(_oracle).peek(amount);
            if (_contributed[to] + estimatedETHAmount > _maxAddressCap) {
                revert MaxAddressCapOverflow();
            }

            _contributed[to] += estimatedETHAmount;
        }
    }
```

Because it can be set more than the _allowedWhitelistIndex in the `Whitelist::_addWhitelistedAddress()`. 

```solidity
 function _addWhitelistedAddress(address whitelisted) private {
        if (_whitelistIndex[whitelisted] == 0) {
            // @audit the user index can bypassed the _allowedWhitelistIndex, if the whiteListCount is greater than _allowedWhitelistIndex
            _whitelistIndex[whitelisted] = ++_whitelistCount; // e set the user index to the most recent one count
        }
    }
```
So this user even after whitelisted would not be able to receive the vult token.

## Recommended Mitigation Steps
Consider adding a check in the `Whitelist::_addWhitelistedAddress()`
```solidity
function _addWhitelistedAddress(address whitelisted) private {
        if (_whitelistIndex[whitelisted] == 0) { // e if not already whitelist (meaning 0 index) 
            // @audit-info make sure have a check whiteListCount <= allowedWhitelistIndex
            _whitelistIndex[whitelisted] = ++_whitelistCount; // e set the user index to the most recent one count
            require(whiteListCount <= _allowedWhitelistIndex, "Invalid Index");
        }
    }
```
