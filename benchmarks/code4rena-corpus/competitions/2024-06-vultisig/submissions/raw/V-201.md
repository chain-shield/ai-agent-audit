# Vulnerability details

## Impact

When transferring ETH, use call() instead of transfer().

The transfer() function only allows the recipient to use 2300 gas. If the recipient uses more than that, the transfer will fail. In the future gas costs might change increasing the likelihood of that happening.

Keep in mind that call() introduces the risk of reentrancy. But, as long as the router follows the checks effects interactions pattern it should be fine.

## Tools Used
Manual

## Recommended Mitigation Steps

Replace transfer() calls with call(). Keep in mind to check whether the call was successful by validating the return value:

```javascript
(bool success, ) = _msgSender().call{value: amount}("");
require(success, "Transfer failed.")

```
