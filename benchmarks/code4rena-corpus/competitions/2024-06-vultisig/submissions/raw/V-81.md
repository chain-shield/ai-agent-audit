# Vulnerability details

## Impact
The `whenNotInitialized()` modifier is there to prevent the `ILOPool.sol` to get initialized again, essentially act as a constructor, and it does that  by cheking `initialized != true`
```java 
modifier whenNotInitialized() {
        require(!_initialized,"The contract is already Initialized");
        _;
        _initialized = true;
    }
```
 But since we are calling `_disableInitialize()` in he constructor
```java 
function _disableInitialize() internal {
        _initialized = true;
    }
``` 
`_initialized` will already be true , so we will not be able to call `initialize()`
