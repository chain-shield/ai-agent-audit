# Vulnerability details

## Impact

In `UniswapV3Oracle` the variable `PERIOD` is set as a constant variable. It defines the time window for calculating the Time-Weighted Average Price (TWAP). The inability to change this variable after deployment poses a risk. The `PERIOD` variable should be changeable to allow the owner to update it based on market conditions and manipulation.

## Proof of Concept

The `PERIOD` variable is set to `30 minutes`:
```javascript
  uint32 public constant PERIOD = 30 minutes;
```
This variable is very important and crucial because it sets how often price updates occur. Frequent updates yield more accurate prices but are vulnerable to flash loan manipulation. Longer periods offer protection against such attacks but reduce accuracy. In a black swan event, slower updates increase risk due to delayed price adjustments. 
Therefore, the owner should have the ability to change it depending on market conditions.

## Recommended Mitigation Steps

The `PERIOD` variable shouldn’t be constant. Also, add a `setPeriod` function that set a value to the `PERIOD` variable and can be called only by the contract owner (use `onlyOwner` modifier).  You can also define the `minPeriod` variable that can be set to `30 minutes`.

```diff
+ function setPeriod(uint32 newPeriod) external onlyOwner {
+    require(newPeriod > minPeriod,"NewPeriod is not correct”);
+    PERIOD = newPeriod;
+ }
```
