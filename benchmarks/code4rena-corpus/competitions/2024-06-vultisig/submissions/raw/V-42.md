# Vulnerability details

## Impact
The null index in the array `Whitelist::_whitelistIndex` is kept for users that have not yet been added to the whitelist. When a user acquires tokens from the Uniswap pool, the function `Whitelist::checkwhitelsit` is called by the hook `_beforeTokenTransfer` and it checks whether the user is eligible to buy the tokens or not. However, this function is missing the check for the null index and therefore allows not whilisted users to claim tokens, breaking the core functionality.
