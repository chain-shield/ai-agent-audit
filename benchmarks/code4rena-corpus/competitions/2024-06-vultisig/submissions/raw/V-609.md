# Vulnerability details

## Impact
[launch() function#L190](https://github.com/code-423n4/2024-06-vultisig/blob/cb72b1e9053c02a58d874ff376359a83dc3f0742/src/ILOManager.sol#L190)
```solidity
require(_cachedProject[uniV3PoolAddress].initialPoolPriceX96 == sqrtPriceX96, "UV3P");
```
This line compares the `initialPoolPriceX96` value stored in the `_cachedProject` mapping for the given `uniV3PoolAddress` with the pool's current `sqrtPriceX96`. If the values are not equal, the function will throw an error with the message "UV3P."

## Proof of Concept
The comparison is based on the `sqrtPriceX96` value at the time the project was launched. However, market fluctuations can change the `sqrtPriceX96` value over time. If the current `sqrtPriceX96` value differs from the value stored in `_cachedProject`, it may indicate a discrepancy between the project's launch price and the current market price.

## Tools Used
Manual Review
## Recommended Mitigation Steps
If the market price has significantly changed since the project was launched, consider updating the `initialPoolPriceX96` value to reflect the current market price.
