# Vulnerability details

## Impact

ILOPool.Launch() could fail unreasonably due to rounding error and slippage check.

## Proof of Concept

When launching, all RAISE_TOKENs stored in the ILOPool are deposited into the uniswap pool. So, `amountMin` for slippage check is set as `totalRaised` and the minted `liquidity` is precalculated in L288.

https://github.com/code-423n4/2024-06-vultisig/blob/main/src/ILOPool.sol#L269-L335
```solidity
    function launch() external override OnlyManager() {
            [...]    
            // calculate sale amount of tokens needed for launching pool
            if (token0Addr == RAISE_TOKEN) {
                amount0 = totalRaised;
287:            amount0Min = totalRaised;
288:            (amount1, liquidity) = _saleAmountNeeded(totalRaised);
            } else {
                (amount0, liquidity) = _saleAmountNeeded(totalRaised);
                amount1 = totalRaised;
                amount1Min = totalRaised;
            }
            [...]
    }
```

However, the actual amount of RAISE_TOKEN for minting `liquidity` could be smaller than `totalRaised` due to rounding error. 
As a result, the launch() function will be reverted, because it cannot pass the slippage check in L56 of the following code. 

https://github.com/code-423n4/2024-06-vultisig/blob/main/src/base/LiquidityManagement.sol#L41-L57
```solidity
    function addLiquidity(AddLiquidityParams memory params)
        internal
        returns (
            uint256 amount0,
            uint256 amount1
        )
    {
        (amount0, amount1) = params.pool.mint(
            address(this),
            TICK_LOWER,
            TICK_UPPER,
            params.liquidity,
            ""
        );

56:     require(amount0 >= params.amount0Min && amount1 >= params.amount1Min, 'Price slippage check');
    }
```

A simulation shows that the likelihood of reversal is very high when the price of SALE_TOKEN is smaller than 1.

## Recommended Mitigation Steps

I recommend tht `amountMin` for slippage check should be adjusted.

```diff
    function launch() external override OnlyManager() {
                [...]
            // calculate sale amount of tokens needed for launching pool
            if (token0Addr == RAISE_TOKEN) {
                amount0 = totalRaised;
-               amount0Min = totalRaised;
+               amount0Min = totalRaised - DUST;
                (amount1, liquidity) = _saleAmountNeeded(totalRaised);
            } else {
                (amount0, liquidity) = _saleAmountNeeded(totalRaised);
                amount1 = totalRaised;
-               amount1Min = totalRaised;
+               amount1Min = totalRaised - DUST;
            }
                [...]
    }
```
