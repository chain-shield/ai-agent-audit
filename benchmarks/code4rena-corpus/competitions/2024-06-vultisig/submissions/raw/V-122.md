# Vulnerability details

## Impact

`Whitelist.sol` file has a function `checkWhitelist()` to check whether the `to` address is whitelisted or not. It is not correctly checking for whitelist address. When the `_whitelistIndex[to]` is equal to zero which is default value it still passes this `checkWhitelist()` check This flaw can result in unauthorized users bypassing the whitelist restrictions. But it should revert in this case. Confirmed by the sponsors.
