# Vulnerability details

## Impact
For the initial launch of VULT, this protocol would only allow buyers, who are not blacklisted, to obtain the VULT tokens according to https://github.com/code-423n4/2024-06-vultisig?tab=readme-ov-file#main-invariants. However, a non-blacklisted user can buy VULT tokens from the VULT/ETH Uniswap V3 pool and then transfer these bought VULT tokens to a blacklisted actor who is suspicious. This breaks the invariant that VULT tokens should not be given to blacklisted actor during the initial launch of VULT.

https://github.com/code-423n4/2024-06-vultisig/blob/58ebda57ccf6a74bdef2b88eb18a62ec4ad46112/hardhat-vultisig/contracts/extensions/VultisigWhitelisted.sol#L28-L33
```solidity
    function _beforeTokenTransfer(address from, address to, uint256 amount) internal override {
        if (_whitelistContract != address(0)) {
            IWhitelist(_whitelistContract).checkWhitelist(from, to, amount);
        }
        super._beforeTokenTransfer(from, to, amount);
    }
```

https://github.com/code-423n4/2024-06-vultisig/blob/58ebda57ccf6a74bdef2b88eb18a62ec4ad46112/hardhat-vultisig/contracts/Whitelist.sol#L204-L228
```solidity
    function checkWhitelist(address from, address to, uint256 amount) external onlyVultisig {
        if (from == _pool && to != owner()) {
            // We only add limitations for buy actions via uniswap v3 pool
            // Still need to ignore WL check if it's owner related actions
            if (_locked) {
                revert Locked();
            }

            if (_isBlacklisted[to]) {
                revert Blacklisted();
            }

            if (_allowedWhitelistIndex == 0 || _whitelistIndex[to] > _allowedWhitelistIndex) {
                revert NotWhitelisted();
            }

            // // Calculate rough ETH amount for VULT amount
            uint256 estimatedETHAmount = IOracle(_oracle).peek(amount);
            if (_contributed[to] + estimatedETHAmount > _maxAddressCap) {
                revert MaxAddressCapOverflow();
            }

            _contributed[to] += estimatedETHAmount;
        }
    }
```

## Proof of Concept
The following steps can occur for the described scenario.
1. Alice is not blacklisted and Bob is blacklisted during the initial launch of VULT.
2. Alice buys VULT tokens that are worth 3 ETH from the VULT/ETH Uniswap V3 pool.
3. Alice transfers these bought VULT tokens to Bob.
4. Although Bob is blacklisted, he is still able to obtain VULT tokens during the initial launch of VULT.

## Recommended Mitigation Steps
In addition to its current code, the `checkWhitelist` function can be updated to also revert if `from == _pool && to != owner()` is false and `to` is blacklisted.
