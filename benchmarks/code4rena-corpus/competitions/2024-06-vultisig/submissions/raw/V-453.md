# Vulnerability details

## Impact
An attacker can prevent a project admin to initialize his project for already existing UniV3Pool by manipulating the price of the pool.

## Proof of Concept
The `initProject` method caches the project in the `_cachedProject` mapping and deploys a UniV3 pool if necessary. This is handled by the `_initUniV3PoolIfNecessary` function

https://github.com/code-423n4/2024-06-vultisig/blob/main/src/ILOManager.sol#L119

```solidity
function _initUniV3PoolIfNecessary(PoolAddress.PoolKey memory poolKey, uint160 sqrtPriceX96) internal returns (address pool) {
        pool = IUniswapV3Factory(UNIV3_FACTORY).getPool(poolKey.token0, poolKey.token1, poolKey.fee);
        if (pool == address(0)) {
            pool = IUniswapV3Factory(UNIV3_FACTORY).createPool(poolKey.token0, poolKey.token1, poolKey.fee);
            IUniswapV3Pool(pool).initialize(sqrtPriceX96);
        } else {
            (uint160 sqrtPriceX96Existing, , , , , , ) = IUniswapV3Pool(pool).slot0(); //@audit attacker can DOS this by manipulating the price
            if (sqrtPriceX96Existing == 0) {
                IUniswapV3Pool(pool).initialize(sqrtPriceX96);
            } else {
                require(sqrtPriceX96Existing == sqrtPriceX96, "UV3P"); //since slot0 is the most recent datapoint, this makes sure
                //the pool has just been initialized @audit what if the price is a bit different from the initial price this will revert
            }
        }
```

The function handles the case where a project is initiated for an already existing UniV3 pool and requires that the initial price should be = to the current price of the pool, witch is fetched from `slot0`. `slot0` is the most recent data point (price) for the pool and can be manipulated by a malicious user with a flash loan. In this situation a flash loan might not be needed even just a slightly larger trade so the price can be minimally affected but still make the `require(sqrtPriceX96Existing == sqrtPriceX96, "UV3P");` statement fail.

## Tools Used
Manual Review

## Recommended Mitigation Steps
For the case of initiating a project with an already deployed UniV3 pool, fetch the price via the pool's TWAP and compare that price with the initial price in the require statement at the end of _initUniV3PoolIfNecessary.
