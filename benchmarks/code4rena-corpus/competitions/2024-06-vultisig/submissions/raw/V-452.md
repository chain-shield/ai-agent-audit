# Vulnerability details

## Impact
The `Whitelist` contract has the "self whitelist" functionality with which a user can whitelist themselves by contributing no more than 3 ETH to the contract. If the self whitelisting feature is allowed the code uses `transfer` instead of low level call to get the `msg.value` from the user. The build in `transfer` method forwards only 2300 gas to the recipient and this can cause issues when the recipient is a contract.

## Recommended Mitigation Steps
Use call instead of transfer and attach a `nonReentrant` modifier to the receive method.
