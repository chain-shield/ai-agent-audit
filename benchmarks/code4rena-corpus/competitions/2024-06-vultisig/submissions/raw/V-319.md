# Vulnerability details



## Impact

The current implementation of the fee calculation for user positions does not update the `feeGrowthInside` values when a new position is minted or when additional tokens are added to an existing position. This leads to inaccurate fee calculations, allowing users to collect more fees than they are entitled to. This discrepancy arises because the `feeGrowthInside` values remain at zero or do not reflect the current fee growth, resulting in overpayment of fees when users claim their tokens.

The critical impact of this issue includes:
- Users receiving more fees than they should, leading to potential losses for the protocol.
- Misalignment with the documented behavior, which states that `feeGrowthInside` should reflect the fee growth as of the last action on the individual position.

## Recommended Mitigation Steps

To address this issue and ensure accurate fee calculations:

1. **Update `feeGrowthInside` Values on Minting**:
   - Ensure that `feeGrowthInside0LastX128` and `feeGrowthInside1LastX128` are updated to the current fee growth values when a new position is minted.

 ```solidity
   function buy(uint256 raiseAmount, address recipient)
        external override 
        returns (
            uint256 tokenId,
            uint128 liquidityDelta
        )
    {
        ...
        // Update fee growth to the current value
(, uint256 feeGrowthInside0LastX128, uint256 feeGrowthInside1LastX128, , ) = pool.positions(positionKey);
        position.feeGrowthInside0LastX128 = pool.feeGrowthGlobal0X128();
        position.feeGrowthInside1LastX128 = pool.feeGrowthGlobal1X128();
    }
 ```

2. **Accurate Fee Calculation on Position Update**:
   - When adding to an existing position, calculate and store the fees based on the current `feeGrowthInside` values before updating the position. Include these variables to track the fees  position.fees0 and position.fees1.

 ```solidity

    function _updatePosition(...) internal {
        ...
        // Calculate existing fees
(, uint256 feeGrowthInside0LastX128, uint256 feeGrowthInside1LastX128, , ) = pool.positions(positionKey);
        uint256 existingFees0 = FullMath.mulDiv(
                                    feeGrowthInside0LastX128 - position.feeGrowthInside0LastX128,
                                    positionLiquidity,
                                    FixedPoint128.Q128
                                );
        uint256 existingFees1 = FullMath.mulDiv(
                                    feeGrowthInside1LastX128 - position.feeGrowthInside1LastX128,
                                    positionLiquidity,
                                    FixedPoint128.Q128
                                );
        // Update fee growth to the current value
        position.feeGrowthInside0LastX128 = pool.feeGrowthGlobal0X128();
        position.feeGrowthInside1LastX128 = pool.feeGrowthGlobal1X128();
        
        // Update stored fees
        position.fees0 += existingFees0;
        position.fees1 += existingFees1;
    }

```
