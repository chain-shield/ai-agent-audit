# Vulnerability details

## Impact
The use of `slot0` to retrieve `sqrtPriceX96` in `src/ILOManager::launch` function can lead to price manipulation. A malicious actor could manipulate the Uniswap V3 pool's price just before calling the `launch` function, thereby meeting the requirement for `sqrtPriceX96`. This could result in launching the project at an incorrect price.

## Proof of Concept
In the `launch` function, the current price is fetched using `slot0`:
```
function launch(address uniV3PoolAddress) external override {
    require(block.timestamp > _cachedProject[uniV3PoolAddress].launchTime, "LT");
@>    (uint160 sqrtPriceX96, , , , , , ) = IUniswapV3Pool(uniV3PoolAddress).slot0();
@>    require(_cachedProject[uniV3PoolAddress].initialPoolPriceX96 == sqrtPriceX96, "UV3P");
    address[] memory initializedPools = _initializedILOPools[uniV3PoolAddress];
    require(initializedPools.length > 0, "NP");
    for (uint256 i = 0; i < initializedPools.length; i++) {
        IILOPool(initializedPools[i]).launch();
    }
    emit ProjectLaunch(uniV3PoolAddress);
}
```
A malicious actor can manipulate the price by executing large trades just before calling the `launch` function, making the `sqrtPriceX96` match the required initial pool price, thereby triggering the launch under manipulated conditions.

Manual review

## Recommended Mitigation Steps
Use the `TWAP` function to get the value of `sqrtPriceX96`.
