# Vulnerability details

## Vulnerability Details
`checkWhitelist()` logic is incorrect.

```
            if (_allowedWhitelistIndex == 0 || _whitelistIndex[to] > _allowedWhitelistIndex) {
                revert NotWhitelisted();
            }
```
[Link](https://github.com/code-423n4/2024-06-vultisig/blob/main/hardhat-vultisig/contracts/Whitelist.sol#L216)

This function should also check that `_whitelistIndex[to]` was previously set, i.e. not zero.

## Impact
Any address not on the whitelist will pass the whitelist check as long as `_allowedWhitelistIndex` is more than 0. This violates a main invariant of `Whitelist.sol`.

## Proof of Concept
The following test should pass, but fails.
```
import { loadFixture } from "@nomicfoundation/hardhat-toolbox/network-helpers";
import { expect } from "chai";
import { ethers } from "hardhat";

describe("Whitelist", function () {
  async function deployWhitelistFixture() {
    const [owner, otherAccount, batchedAccount, mockContract, pool] = await ethers.getSigners();

    const Whitelist = await ethers.getContractFactory("Whitelist");
    const whitelist = await Whitelist.deploy();
    await whitelist.setPool(pool);

    const MockOracleSuccess = await ethers.getContractFactory("MockOracleSuccess");
    const MockOracleFail = await ethers.getContractFactory("MockOracleFail");

    const mockOracleSuccess = await MockOracleSuccess.deploy();
    const mockOracleFail = await MockOracleFail.deploy();

    return {
      whitelist,
      mockOracleSuccess,
      mockOracleFail,
      owner,
      otherAccount,
      batchedAccount,
      mockContract,
      pool,
    };
  }

  describe("WhitelistPoC", function () {
    it("Should revert when whitelist index is non-zero, but account is not on the whitelist", async function () {
      const { whitelist, pool, otherAccount, mockContract } = await loadFixture(deployWhitelistFixture);

      await whitelist.setVultisig(mockContract);
      await whitelist.setLocked(false);

      // Enable whitelist.
      await whitelist.setAllowedWhitelistIndex(1);

      // otherAccount is not on the whitelist.
      await expect(whitelist.connect(mockContract).checkWhitelist(pool, otherAccount, 0)).to.be.revertedWithCustomError(
        whitelist,
        "NotWhitelisted",
      );
    });
  });
});
```


## Recommended Mitigation Steps

The check in `checkWhitelist()` should instead be the following:
```
            if (_whitelistIndex[to] == 0 || _whitelistIndex[to] > _allowedWhitelistIndex) {
                revert NotWhitelisted();
            }
```
