# Vulnerability details

## Impact
When `checkWhitelist()` is not called, the `_locked` state check is bypassed. Therefore tokens can be transferred even when the contract `owner` intends to prevent all transfers, potentially leading to unauthorized transfers.

## Proof of Concept
The `_locked` state is designed to temporarily halt token transfers. If `_locked` is `true`, the contract reverts any transfer attempts that are subject to this lock. During whitelist period, this is [checked](https://github.com/code-423n4/2024-06-vultisig/blob/cb72b1e9053c02a58d874ff376359a83dc3f0742/hardhat-vultisig/contracts/Whitelist.sol#L208-L210):
```solidity
if (_locked) {
    revert Locked();
}
```
However, if the `whitelist period` ends and `_whitelistContract` is set to `address(0)`, the [`checkWhitelist()` function will not be called](https://github.com/code-423n4/2024-06-vultisig/blob/cb72b1e9053c02a58d874ff376359a83dc3f0742/hardhat-vultisig/contracts/extensions/VultisigWhitelisted.sol#L26-L33).
```solidity
function _beforeTokenTransfer(address from, address to, uint256 amount) internal override {
        if (_whitelistContract != address(0)) {
            IWhitelist(_whitelistContract).checkWhitelist(from, to, amount);
        }
>>      // @ausit-issue Lock check is skipped here
        super._beforeTokenTransfer(from, to, amount);
    }
```

#### Issue: 
---> Transfers will proceed even if the contract is in a `locked` state, which is meant to halt transfers 

## Tools Used
Manual Review

## Recommended Mitigation Steps
1. Separate Lock Check in `_beforeTokenTransfer()`
Add a direct check for the `_locked` state within the `_beforeTokenTransfer()` function itself.

```diff
function _beforeTokenTransfer(address from, address to, uint256 amount) internal override {
+   // @audit Ensure the contract is not in a locked state
+   if (_locked) {
+       revert Locked();
+   }

    // Check whitelist if applicable
    if (_whitelistContract != address(0)) {
        IWhitelist(_whitelistContract).checkWhitelist(from, to, amount);
    }

    super._beforeTokenTransfer(from, to, amount);
}
```
