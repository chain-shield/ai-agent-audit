# Vulnerability details

## Impact
Funds may be lost

## Proof of Concept
In the PeripheryPayments contract, require(msg.sender == WETH9, 'Not WETH9') is used to prevent donations, but attackers can use the selfdestruct method to transfer money to the contract. Therefore, attackers can use the selfdestruct method to transfer money to the contract, causing the contract to enter the logic of (token == WETH9 && address(this).balance >= value) when calling the pay function (this logic should not be entered), which may cause damage to the contract assets.

## Tools Used
Manual Audit

## Recommended Mitigation Steps
The first variable EthBalance is used to record the assets in the contract.
```solidity
+ uint256 public EthBalance;

    receive() external payable {
-       require(msg.sender == WETH9, 'Not WETH9');
+       EthBalance += msg.sender; 
    }

    function pay(
        address token,
        address payer,
        address recipient,
        uint256 value
    ) internal {
-       if (token == WETH9 && address(this).balance >= value) {
+       if (token == WETH9 && EthBalance >= value) {
            // pay with WETH9
            IWETH9(WETH9).deposit{value: value}(); // wrap only what is needed to pay
            IWETH9(WETH9).transfer(recipient, value);
        } else if (payer == address(this)) {
            // pay with tokens already in the contract (for the exact input multihop case)
            TransferHelper.safeTransfer(token, recipient, value);
        } else {
            // pull payment
            TransferHelper.safeTransferFrom(token, payer, recipient, value);
        }
    }
    }
```
