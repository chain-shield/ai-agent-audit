# Vulnerability details

## Impact
Launch will fail, causing the contract DOSed.

## Proof of Concept
In the function `launch`, leftover sale token will be transfered back to project admin. However, if the admin is blacklisted from the token, it will be reverted. Finally, the `launch` will never succeed, which DOSes the contract.

## Tools Used
VScode

## Recommended Mitigation Steps
Transfer the token to the vault and record the amount, instead of transfer the token to the admin instantly.
