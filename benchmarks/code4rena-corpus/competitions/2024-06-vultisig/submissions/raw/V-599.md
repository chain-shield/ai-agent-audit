# Vulnerability details

## Impact
```solidity
    function _initUniV3PoolIfNecessary(PoolAddress.PoolKey memory poolKey, uint160 sqrtPriceX96) internal returns (address pool) {
        pool = IUniswapV3Factory(UNIV3_FACTORY).getPool(poolKey.token0, poolKey.token1, poolKey.fee);
        if (pool == address(0)) {
            pool = IUniswapV3Factory(UNIV3_FACTORY).createPool(poolKey.token0, poolKey.token1, poolKey.fee);
            IUniswapV3Pool(pool).initialize(sqrtPriceX96);
        } else {
            (uint160 sqrtPriceX96Existing, , , , , , ) = IUniswapV3Pool(pool).slot0();
            if (sqrtPriceX96Existing == 0) {
                IUniswapV3Pool(pool).initialize(sqrtPriceX96);
            } else {
                require(sqrtPriceX96Existing == sqrtPriceX96, "UV3P");
            }
        }
```
[ILOManager.sol#109-L120](https://github.com/code-423n4/2024-06-vultisig/blob/cb72b1e9053c02a58d874ff376359a83dc3f0742/src/ILOManager.sol#L109-L121)
 1. The function first checks if the pool already exists by calling `IUniswapV3Factory(UNIV3_FACTORY).getPool(...)1`.
 2. If the pool doesn't exist, it creates a new pool using `IUniswapV3Factory(UNIV3_FACTORY).createPool(...)` and initializes it with the  provided `sqrtPriceX96`.
 3. However, if the pool already exists, it retrieves the existing `sqrtPriceX96` value from the pool using `IUniswapV3Pool(pool).slot0()`.
 4. If the existing `sqrtPriceX96` is zero, it initializes the pool with the provided `sqrtPriceX96`.
 5. If the existing `sqrtPriceX96` is non-zero, it compares it with the provided `sqrtPriceX96` and reverts if they don't match.

The bug lies in step 4. If the pool already exists but has a zero `sqrtPriceX96` value, it means that it has already been initialized before. Initializing it again with a different `sqrtPriceX96` value could lead to unexpected behavior or break the pool's functionality.

## Recommended Mitigation Steps
Instead of initializing the pool again, the function should either: **a)** Revert if the existing `sqrtPriceX96` is zero, indicating that the pool has already been initialized, or **b)** Skip the initialization step altogether if the pool already exists, regardless of the existing `sqrtPriceX96` value.
