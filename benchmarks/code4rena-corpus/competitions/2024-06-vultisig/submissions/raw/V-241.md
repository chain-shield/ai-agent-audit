# Vulnerability details

## Impact
Blacklisting can be bypassed easily.

When an address is blacklisted, it can be transferred to any non-blacklisted recipient address and then transferred to blacklisted address.

## Proof of Concept
`Whitelist.checkWhitelist()` does not allow any transfer from pool address to blacklisted address, but non-pool address to blacklisted address.

https://github.com/code-423n4/2024-06-vultisig/blob/main/hardhat-vultisig/contracts/Whitelist.sol#L204-L214
```
    function checkWhitelist(address from, address to, uint256 amount) external onlyVultisig {
        if (from == _pool && to != owner()) {
            // We only add limitations for buy actions via uniswap v3 pool
            // Still need to ignore WL check if it's owner related actions
            if (_locked) {
                revert Locked();
            }

            if (_isBlacklisted[to]) {
                revert Blacklisted();
            }

```
