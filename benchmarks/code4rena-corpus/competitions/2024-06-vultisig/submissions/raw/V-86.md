# Vulnerability details


## Summary:

The `ProjectAdmin` role holds critical privileges for specific projects within the protocol. The `ILOManager::transferAdminProject` function permits the current project admin to transfer ownership and all associated critical privileges to another address in a single step. 

Relevant Code: 
[ILOManager.sol::transferAdminProject](https://github.com/code-423n4/2024-06-vultisig/blob/cb72b1e9053c02a58d874ff376359a83dc3f0742/src/ILOManager.sol#L169)
```solidity
    function transferAdminProject(address admin, address uniV3Pool) external override onlyProjectAdmin(uniV3Pool) {
        Project storage _project = _cachedProject[uniV3Pool];
        _project.admin = admin;
        emit ProjectAdminChanged(uniV3Pool, msg.sender, admin);
    }
```

[ILOManager.sol::claimRefund()](https://github.com/code-423n4/2024-06-vultisig/blob/cb72b1e9053c02a58d874ff376359a83dc3f0742/src/ILOManager.sol#L201)
```solidity
    function claimRefund(address uniV3PoolAddress)
        external
        override
        onlyProjectAdmin(uniV3PoolAddress)
        returns (uint256 totalRefundAmount)
    {
        require(_cachedProject[uniV3PoolAddress].refundDeadline < block.timestamp, "RFT");
        address[] memory initializedPools = _initializedILOPools[uniV3PoolAddress];
        for (uint256 i = 0; i < initializedPools.length; i++) {
            totalRefundAmount +=
                IILOPool(initializedPools[i]).claimProjectRefund(_cachedProject[uniV3PoolAddress].admin);
        }
    }
```

## Impact
Critical `ProjectAdmin` priviliges could be transferred to an incorrect address e.g. if:

- mistakenly inputs an incorrect address when calling `ILOManager::transferAdminProject`.
- the protocol becomes the victim of a Clipboard Replacement Attack

With the ownership privilages transferred to an incorrect account, the ability to perform sensitive actions like `claiming refunds`.

## Recommended Mitigation Steps

To address the identified security risk, the implementation can be modified to require a two-step process for transferring admin privileges. This approach ensures that the new admin must explicitly accept the role before the transfer is finalized, providing an additional layer of security.


Interface Changes:
[IILOManager.sol](https://github.com/code-423n4/2024-06-vultisig/blob/main/src/interfaces/IILOManager.sol)
```diff solidity

-   function transferAdminProject(address admin, address uniV3Pool) external;
+   function proposeNewAdminProject(address _newAdmin, address uniV3Pool) external;

}
```
