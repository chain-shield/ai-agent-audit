# Vulnerability details

## Impact
The `_allowedWhitelistIndex` variable defines the maximum index allowed for whitelisted addresses within the contract.

```javascript
/// @notice Max index allowed
    uint256 private _allowedWhitelistIndex;
```

 Without validating this variable when adding new whitelisted addresses, several potential issues arise:

Exceeding Allowed Limits: Addresses could be added with indices that exceed `_allowedWhitelistIndex`, potentially granting unintended privileges or bypassing intended restrictions.
Contract Misconfiguration: Failure to check `_allowedWhitelistIndex` undermines the contract's intended access control mechanisms, leading to inconsistencies in whitelist management.

## Proof of Concept
Adding Addresses Without Validation:

Assume `_allowedWhitelistIndex` is set to a value restricting indices.

```javascript
/// @notice Setter for allowed whitelist index
    /// @param newIndex New index for allowed whitelist
    function setAllowedWhitelistIndex(uint256 newIndex) external onlyOwner {
        _allowedWhitelistIndex = newIndex;
    }
```

Attempt to add a new whitelisted address with an index higher than `_allowedWhitelistIndex`.
The function responsible for adding whitelisted addresses does not check `_allowedWhitelistIndex`, allowing the address to be added regardless of the allowed range.
Impact of Unchecked `_allowedWhitelistIndex`:

Addresses added without `_allowedWhitelistIndex` validation can potentially perform actions or access resources that should be restricted based on their whitelist index.
This oversight can lead to unauthorized operations or unintended access within the contract, compromising security and violating access control policies.

## Recommended Mitigation Steps
To mitigate the risk associated with the lack of validation against `_allowedWhitelistIndex` when adding whitelisted addresses, implement the following measures:

Validate `_allowedWhitelistIndex`: Ensure that before adding any address to the whitelist, the index is checked against `_allowedWhitelistIndex`.

```javascript
function addWhitelistedAddress(address whitelisted, uint256 index) external onlyOwner {
    require(index < _allowedWhitelistIndex, "Index exceeds allowed whitelist index");
    _addWhitelistedAddress(whitelisted, index);
}
```
