# Vulnerability details

## Impact
These two functions set fee's that are taken globally across all project pool's. Without any type of upper number limit, `onlyOwner` could set these to 100% by accident.
The effect of having 100% fee's would be detrimental to user's since all their money in that transaction would be taken.

## Proof of Concept
Add the following test in `ILOManager.t.sol`
```
    function testMaxFees() public {
        vm.startPrank(MANAGER_OWNER);
        iloManager.setPerformanceFee(10000);
        assert(iloManager.PERFORMANCE_FEE() == 10000);
        iloManager.setPlatformFee(10000);
        assert(iloManager.PLATFORM_FEE() == 10000);
        vm.stopPrank();
    }
```

## Tools Used
Foundry

## Recommended Mitigation Steps
Consider adding a require statement with a max percentage that you would like it to not surpass.
```diff
    function setPlatformFee(uint16 _platformFee) external onlyOwner() {
+       require(_platformFee <= 2500, "Too high of fee")    
        PLATFORM_FEE = _platformFee;
    }

    function setPerformanceFee(uint16 _performanceFee) external onlyOwner() {
+       require(_perfomanceFee <= 2500, "Too high of fee")    
        PERFORMANCE_FEE = _performanceFee;
    }
```
