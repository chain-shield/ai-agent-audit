# Vulnerability details


## Impact

The vulnerability identified in the `ILOPool.sol` contract lies in its initialization logic. The constructor uses the `_disableInitialize` modifier, which sets the `_initialized` variable to `true`. Consequently, the `initialize` function, which is crucial for setting up the contract's state variables, includes a `whenNotInitialized` modifier that checks if `_initialized` is `false`. Since `_initialized` is already set to `true` upon deployment, any attempt to call `initialize` will always revert, rendering the contract non-functional. This prevents the proper setup of essential state variables, causing the contract to fail in its intended operations.

## Proof of Concept

1. **Vulnerable Code Location:**

   - Constructor using `_disableInitialize`:
     ```solidity
     constructor() ERC721('', '') {
         _disableInitialize();
     }
     ```
   - `_disableInitialize` function:
     ```solidity
     function _disableInitialize() internal {
         _initialized = true;
     }
     ```
   - `initialize` function with `whenNotInitialized` modifier:

     ```solidity
     modifier whenNotInitialized() {
         require(!_initialized);
         _;
         _initialized = true;
     }

     function initialize(InitPoolParams calldata params) external override whenNotInitialized()
     ```

2. **Exploit Steps:**

   - **Step 1:** Deploy the `ILOPool.sol` contract.
   - **Step 2:** Attempt to call the `initialize` function with the required parameters.
   - **Result:** The transaction reverts due to the `whenNotInitialized` modifier, which fails the `require(!_initialized)` check since `_initialized` is already `true`.

3. **Proof:**
   - **GitHub Reference:**
     - [Constructor Code](https://github.com/code-423n4/2024-06-vultisig/blob/main/src/ILOPool.sol#L49-L51)

## Recommended Mitigation Steps

1. **Remove `_disableInitialize` from the Constructor:**
   ```solidity
   constructor() ERC721('', '') {
       // _disableInitialize();
   }
   ```
2. **Explicitly Set `_initialized` in the `initialize` Function:**

   ```solidity
   modifier whenNotInitialized() {
       require(!_initialized);
       _;
       // _initialized = true; // Remove this line from the modifier
   }

   function initialize(InitPoolParams calldata params) external override whenNotInitialized() {
       // Initialization code here
       _initialized = true; // Set _initialized here instead
   }
   ```

By making these changes, the contract can be properly initialized after deployment, ensuring that all necessary state variables are set correctly and the contract operates as intended.
