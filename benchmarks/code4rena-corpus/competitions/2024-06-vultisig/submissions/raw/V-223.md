# Vulnerability details

## Impact
In `VultiSig::approveAndCall` function once the amount for the spender is approved the logic calls `IApproveAndCallReceiver::receiveApproval`, however there isn't a check that will confirm that the received approval has arrived successfully. 

Instead the function `VultiSig::approveAndCall` returns `true` as default value which appears as successfully executed contract transaction. However, if the `transferFrom` inside the `IApproveAndCallReceiver::receiveApproval` fails then the approval amount would be transferred unsuccessfully which contradicts completely to what the `VultiSig::approveAndCall` logic is supposed to do.

## Proof of Concept
1. Send funds to `Whitelist` contract
2. If the `payable(_msgSender()).transfer(msg.value);` fails then the funds get locked
   
## Tools Used
Solidity, Foundry

## Recommended Mitigation Steps

`IApproveAndCallReceiver::receiveApproval` must contain:

```solidity
-        IERC20(token).transferFrom(from, address(this), amount);
+        bool success = IERC20(token).transferFrom(from, address(this), amount);
+        require(success, "Error has occurred while transferring funds");
```

Thus, if there is an error it will bubble up and the logic in `VultiSig::approveAndCall` will not appear as if everything went smoothly.

Another option is to change the logic in such a way that the `receiveApproval` returns bool depending on whether the transfer when through.

```solidity

    function approveAndCall(address spender, uint256 amount, bytes calldata extraData) external returns (bool) {
        // Approve the spender to spend the tokens
        _approve(msg.sender, spender, amount);

        // Call the receiveApproval function on the spender contract
+       bool success = IApproveAndCallReceiver(spender).receiveApproval(msg.sender, amount,address(this),extraData);
-       IApproveAndCallReceiver(spender).receiveApproval(msg.sender, amount,address(this),extraData);

        // audit-high - no check whether the receiveApproval is completed

+       return success;
-       return true;
    }

```
