# Vulnerability details

## Impact
The function `_initUniV3PoolIfNecessary` is vulnerable to slippage issues that can result in a DOS. This vulnerability arises from strict checks against a price that may not always reflect current market conditions.

## Proof of Concept
The vulnerability stems from the assumption that the price when initializing or interacting with the pool should always match an expected value. For an already created pool with ongoing trades, price is constantly moving.

```js
    function _initUniV3PoolIfNecessary(PoolAddress.PoolKey memory poolKey, uint160 sqrtPriceX96) internal returns (address pool) {
...
            if (sqrtPriceX96Existing == 0) {
                IUniswapV3Pool(pool).initialize(sqrtPriceX96);
            } else {
                require(sqrtPriceX96Existing == sqrtPriceX96, "UV3P");
            }
        }
```

The project can never be initiated for ongoing pools. 

## Tools Used

Manual review

## Recommended Mitigation Steps

Modify the function to handle price discrepancies more flexibly by allowing a small range of deviation.
