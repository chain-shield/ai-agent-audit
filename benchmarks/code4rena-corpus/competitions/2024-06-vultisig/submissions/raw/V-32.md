# Vulnerability details


## Summary:
In the `UniswapV3Oracle` contract located at `hardhat-vultisig\contracts\oracles\uniswap\UniswapV3Oracle.sol`, there is a discrepancy between the code and the comment in the `peek` function. The comment suggests dividing by `1e18`, but the actual code divides by `1e20`. This leads to an incorrect calculation of the TWAP price for VULT/ETH, affecting the final output value significantly.

## Vulnerability Details:
The `peek` function is intended to return the TWAP (Time-Weighted Average Price) for 1 VULT for the last 30 minutes, applying a 5% slippage. The division factor used in the calculation should be `1e18` as per the comment, but the code currently uses `1e20`. This results in a substantial error in the final price calculation.

Relevant code snippet:
```solidity
return (quotedWETHAmount * baseAmount * 95) / 1e20; // 100 / 1e18
```

## Impact
The incorrect division factor leads to a hundredfold reduction in the calculated TWAP price for VULT/ETH. This can cause significant financial discrepancies and incorrect price reporting, potentially leading to substantial losses for users relying on the accurate price calculation for their transactions.

Based on the vulnerability classifications:
- **Impact**: Medium - A small amount of funds can be lost or ancillary functionality of the protocol is affected. The user or protocol may experience reduced or delayed receipt of intended funds.
- **Likelihood**: Medium - An attack vector that is only possible in uncommon cases or requires a large amount of capital to exercise relative to the amount gained or the disruption to the protocol.

Therefore, the severity of this issue is assessed as **Medium**.

## Proof of Concept
Consider the following values:
- `quotedWETHAmount = 1e18`
- `baseAmount = 1e18`

With the current code:
\[ \text{result} = \frac{1e18 \times 1e18 \times 0.95}{1e20} = 9.5 \times 10^{15} \]

With the corrected division factor (`1e18`):
\[ \text{result} = \frac{1e18 \times 1e18 \times 0.95}{1e18} = 9.5 \times 10^{17} \]

The difference is substantial and indicates a hundredfold reduction due to the incorrect division factor.
