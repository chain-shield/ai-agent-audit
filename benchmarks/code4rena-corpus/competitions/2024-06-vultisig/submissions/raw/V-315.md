# Vulnerability details

## Impact
IILOPool can never be initialized.

## Proof of Concept
The constructor in the ILOPool.sol disables initializing and sets `_initialized = true`, which is required to be `false` in `whenNotInitialized()`.
```Solidity
constructor() ERC721('', '') {
        _disableInitialize();
    }
```
```Solidity
abstract contract Initializable {
    bool private _initialized;
    function _disableInitialize() internal {
        _initialized = true;
    }
    modifier whenNotInitialized() {
        require(!_initialized);
        _;
        _initialized = true;
    }
    modifier afterInitialize() {
        require(_initialized);
        _;
    }
}
```
Meaning that when a project admin decides to initialize their ILOPool by using the `initILOPool` function in ILOManager.sol, they won't be able to. That is because of the modifier of the initialize function `whenNotInitialized()` in ILOPool.sol.
