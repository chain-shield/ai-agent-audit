# Vulnerability details

## Impact
The `_maxAddressCap` determines the Maximum ETH amount to contribute. When `_whitelistContract` is set to `address(0)`, the condition `if (_whitelistContract != address(0))` evaluates to `false`. As a result, the `checkWhitelist()` function is not called, and the `_maxAddressCap` check is bypassed.

Without the cap, a single address could contribute a disproportionate `amount` of tokens.

## Proof of Concept
The [_beforeTokenTransfer()](https://github.com/code-423n4/2024-06-vultisig/blob/cb72b1e9053c02a58d874ff376359a83dc3f0742/hardhat-vultisig/contracts/extensions/VultisigWhitelisted.sol#L28-L33) function is responsible for calling the [checkWhitelist()](https://github.com/code-423n4/2024-06-vultisig/blob/cb72b1e9053c02a58d874ff376359a83dc3f0742/hardhat-vultisig/contracts/Whitelist.sol#L204-L228) function if the `_whitelistContract` is set.
```solidity
function _beforeTokenTransfer(address from, address to, uint256 amount) internal override {
    if (_whitelistContract != address(0)) {
>>      IWhitelist(_whitelistContract).checkWhitelist(from, to, amount);
    }
    super._beforeTokenTransfer(from, to, amount);
}
```
During `whitelist period`,  the [following code](https://github.com/code-423n4/2024-06-vultisig/blob/cb72b1e9053c02a58d874ff376359a83dc3f0742/hardhat-vultisig/contracts/Whitelist.sol#L220-L226) is not executed:
```solidity
uint256 estimatedETHAmount = IOracle(_oracle).peek(amount); //! May revert on overflow (reported)
if (_contributed[to] + estimatedETHAmount > _maxAddressCap) {
    revert MaxAddressCapOverflow();
}
_contributed[to] += estimatedETHAmount;
```
This ensures that the maximum address cap check is bypassed.

However, when `whitelist period` is over, this check is bypassed.

## Recommended Mitigation Steps
1. Independent Cap Check in `_beforeTokenTransfer()`:
```diff
function _beforeTokenTransfer(address from, address to, uint256 amount) internal override {
   
    // Check whitelist if applicable
    if (_whitelistContract != address(0)) {
        IWhitelist(_whitelistContract).checkWhitelist(from, to, amount);
    }

+   // Independent maximum address cap check
+   uint256 estimatedETHAmount = IOracle(_oracle).peek(amount);
+   if (_contributed[to] + estimatedETHAmount > _maxAddressCap) {
+       revert MaxAddressCapOverflow();
+   }
+   _contributed[to] += estimatedETHAmount;

    super._beforeTokenTransfer(from, to, amount);
}
```
