# Vulnerability details

## Impact
Using `slot0` to fetch `sqrtPriceX96` in the `ILOManager` contract can be manipulated, leading to incorrect pricing calculations. While launching any project using the `function launch()` it uses the `sqrtPriceX96` which is fetched using `IUniswapV3Pool(uniV3PoolAddress).slot0()` which is the most recent data point and can be easily manipulated via MEV bots and FlashLoans with sandwich attacks.<br />
While `ILOPool` contract depends on the `ILOManager` contract for the exact pricing which can also lead to an issue.<br />
As `TickMath` Library contract also uses `sqrtPriceX96` to compute values based on it which can also be changed and it will lead to the wrong calculation of the `tick`.


## Proof of Concept
As you can see here in the `ILOManager.sol` in function`launch()`:-
```
function launch(address uniV3PoolAddress) external override {
        require(block.timestamp > _cachedProject[uniV3PoolAddress].launchTime, "LT");
        (uint160 sqrtPriceX96, , , , , , ) = IUniswapV3Pool(uniV3PoolAddress).slot0();
        require(_cachedProject[uniV3PoolAddress].initialPoolPriceX96 == sqrtPriceX96, "UV3P");
        address[] memory initializedPools = _initializedILOPools[uniV3PoolAddress];
        // Pool should exist then only we can launch right
        require(initializedPools.length > 0, "NP");
        for (uint256 i = 0; i < initializedPools.length; i++) {
            IILOPool(initializedPools[i]).launch();
        }

        emit ProjectLaunch(uniV3PoolAddress);
    }
```
These function is used to launch new project which uses `sqrtPriceX96` pulled from `IUniswapV3Pool(uniV3PoolAddress).slot0()`. <br/>
An attacker manipulates the Uniswap V3 pool price right before the `launch()`function is called. This can lead to erroneous pricing for the new token project, which can have serious financial repercussions for the ILO participants.
```
#### Example
- The attacker identifies a pool with low liquidity and performs trades to manipulate the price.
- By the time the launch() function is called, the price fetched from slot0 is manipulated.
- The ILOManager.sol calls the launch() function.
- The launch() function uses IUniswapV3Pool(pool).slot0() to fetch the current sqrtPriceX96.
```
- The manipulated price affects all subsequent calculations involving `sqrtPriceX96`.
- This can lead to incorrect token pricing, causing substantial financial loss for participants.
- This is especially critical if the manipulated price is used to set initial offering parameters, distribute tokens, or determine liquidity ratios.
