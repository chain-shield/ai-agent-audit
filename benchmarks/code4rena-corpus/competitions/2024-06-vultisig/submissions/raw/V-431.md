# Vulnerability details

## Impact
Ineffective `transferOwnership` call

## Proof of Concept
Constructor logic is not executed in upgradeable contracts.
```
    constructor () {
        transferOwnership(tx.origin);
    }
```
instead it executes initialize,
as a result owner will not be transferred.

## Tools Used
Manual review
## Recommended Mitigation Steps
Move `constructor` logic to `initialize`.
And if `constructor` logic is redundant or not effective, it should be removed. 


## Assessed type

Upgradable
