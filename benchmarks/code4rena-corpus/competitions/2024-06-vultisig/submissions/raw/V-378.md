# Vulnerability details

## Vulnerability details

In `buy` function there is a restriction that single user can not buy more than `maxCapPerUser`.

```javascript
require(
    raiseAmount <= saleInfo.maxCapPerUser - _position.raiseAmount,
    "UC"
);
```

However this require statement can be easily bypassed by transfering current NFT to other address controlled by a user. Then he can buy tokens (will also receive new NFT) and will bypass this check. After purchase he can transfer back his first NFT. User can do it as many times as he wishes using only 2 of his addresses.

```javascript
    if (balanceOf(recipient) == 0) {
            _mint(recipient, (tokenId = _nextId++));
            _positionVests[tokenId].schedule = _vestingConfigs[0].schedule;
        } else {
            tokenId = tokenOfOwnerByIndex(recipient, 0);
        }

        Position storage _position = _positions[tokenId];
        require(raiseAmount <= saleInfo.maxCapPerUser - _position.raiseAmount, "UC");
        _position.raiseAmount += raiseAmount;
```

## Impact

Protocol requirements can be bypassed by NFT transfer.

## Recommended Mitigation Steps

Make NFT non transferable for sale time. It will prevent users from transfering NFT to other addresses and buying more tokens bypassing max user cap check.
