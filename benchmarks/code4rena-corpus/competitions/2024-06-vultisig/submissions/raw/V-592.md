# Vulnerability details

## Impact
The use of `abi.encodePacked` in the `src/ILOManager::initILOPool` function can lead to hash collisions, which may allow a malicious actor to create different inputs that produce the same hash. This could potentially result in the creation of duplicate ILO pools or other unintended behaviors, compromising the integrity of the system.

In the `initILOPool` function, the salt for the deterministic clone is generated using `abi.encodePacked`:

The use of `abi.encodePacked` to generate the salt can result in hash collisions, as different inputs can produce the same hash, potentially leading to unintended behavior.
