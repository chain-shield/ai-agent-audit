# Vulnerability details

## Impact
Salt used for creating clone of pool can be frontrun as all the required information required for frontrunning is present on chain like chainid/length of pool/pool address
```solidity
            // this salt make sure that pool address can not be represented in any other chains
        --->    bytes32 salt = keccak256(abi.encodePacked(
                ChainId.get(),
                params.uniV3Pool,
                _initializedILOPools[params.uniV3Pool].length
            ));
            iloPoolAddress = Clones.cloneDeterministic(ILO_POOL_IMPLEMENTATION, salt);
```
This will make the honest transaction to revert
