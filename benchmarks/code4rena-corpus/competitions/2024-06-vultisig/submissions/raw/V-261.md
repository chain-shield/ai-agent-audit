# Vulnerability details

## Impact
Users will suffer losses due to slippage.

## Detail
In the function `buy`, user can transfer fund into contract and obtain some liquidity. However, there is no slippage check for `liquidityDelta`, causing user may receive less liquidity than expected.

## Tools Used
VScode

## Recommended Mitigation Steps
Add a minLiquidity parameter to the function `buy`.
