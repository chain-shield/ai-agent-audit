# Vulnerability details

## Impact

When the project is launched via `ILOManager.launch()`; the price of the project's uniswapV3 pool is fetched via `IUniswapV3Pool(uniV3PoolAddress).slot0()` and this value is compared with the cashed `initialPoolPriceX96` that was saved when the project was initialized (via `ILOManager.initProject()`):

```js
    function launch(address uniV3PoolAddress) external override {
        require(block.timestamp > _cachedProject[uniV3PoolAddress].launchTime, "LT");
        (uint160 sqrtPriceX96, , , , , , ) = IUniswapV3Pool(uniV3PoolAddress).slot0();
        require(_cachedProject[uniV3PoolAddress].initialPoolPriceX96 == sqrtPriceX96, "UV3P");
        // the rest of the function...
    }
```

but `IUniswapV3Pool(uniV3PoolAddress).slot0()` is succeptable to manipulation via flashloans, so any malicious actor can manipulate the pool price to break the `_cachedProject[uniV3PoolAddress].initialPoolPriceX96 == sqrtPriceX96` check, thus preventing project launch.
