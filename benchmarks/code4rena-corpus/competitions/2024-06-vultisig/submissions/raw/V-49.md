# Vulnerability details

## Impact
If ILO_POOL_IMPLEMENTATION is address(0), it will cause an issue because the cloning process needs a valid implementation address to create a functional proxy. Cloning with a zero address would result in a proxy that delegates calls to the zero address, which is not a valid contract and will cause any function call to revert. Since ILO_POOL_IMPLEMENTATION  is set up in initialize() function and initILOPool() does not use afterInitialize() modifier the scenario may occur. 

## Proof of Concept
```code
function initILOPool(InitPoolParams calldata params) external override onlyProjectAdmin(params.uniV3Pool) returns (address iloPoolAddress) {
```
Does not use afterInitialize() modifier, ILO_POOL_IMPLEMENTATION does not have initial value.
```code
 address public override ILO_POOL_IMPLEMENTATION;
```

## Tools Used
Manual review

## Recommended Mitigation Steps
Add modifier afterInitialize() to initILOPool ()
