# Vulnerability details

## Impact
Any non-whitelisted user can bypass the validation of the `checkWhitelist()` function. This results, an attacker can easily contribute `estimatedETHAmount` to the `VultiSig` protocol without being in whitelist. 

## Proof of Concept
The vulnerability is in the `checkWhitelist()` of `Whitelist` contract which is called by the `_beforeTokenTransfer()` hook of the VultiSig. 
https://github.com/code-423n4/2024-06-vultisig/blob/cb72b1e9053c02a58d874ff376359a83dc3f0742/hardhat-vultisig/contracts/Whitelist.sol#L216 

```solidity
if (_allowedWhitelistIndex == 0 || _whitelistIndex[to] > _allowedWhitelistIndex) {
   revert NotWhitelisted();
}
```

Attack explained, 
Let's say, two accounts were whitelisted `otherAccount` and `batchedAccount` by owner respectively. i.e, `whitelistCount` = 2. Let's say owner only allowing first account in the whitelist. i.e, `allowedWhitelistIndex` = 1.

1. If `checkWhitelist()` function is called with `to` address as `otherAccount` the call be succeeded as `otherAccount` is in the whitelist and within the `allowedWhitelistIndex`.

2. When `checkWhitelist()` function is called with `to` address as `batchedAccount`  call will be reverted with `NotWhitelisted()` error. Because this account is not within the `allowedWhitelistIndex`.

```solidity
// false || true => true => revert()
if (1 == 0 || 2 > 1) { 
   revert NotWhitelisted();
}
```

3. If the `checkWhitelist()` function is called with `to` address as `attackerAccount` this still passes the check. Because there is no check that `_whitelistIndex[to] != 0`. In the mapping of the `_whitelistIndex` all the uninitialised address keys will get zero index as value.Since the `attackerAccount` is not whitelisted `_whitelistIndex[to]=_whitelistIndex[attackerAccount] = 0`. The `checkWhitelist()` function does the following check in this case, 

```solidity
// false || false => false => whitelist check bypassed
if (1 == 0 || 0 > 2){
}
```

In this way any user who is not whitelisted can be easily perform the whitelisted actions.

## POC
Add this test case to the `hardhat-vultisig/test/unit/Whitelist.ts` to run with `npx hardhat test`

```javascript 
// @audit : POC
  describe.only("Checkwhitelist Bypass", function () {

    it("Not whitelisted account passing checkWhitelist check", async function () {
      const { whitelist, pool, otherAccount, batchedAccount, mockContract, mockOracleSuccess, attackerAccount} = await loadFixture(deployWhitelistFixture);
      await whitelist.setVultisig(mockContract);
      await whitelist.setLocked(false);
      await whitelist.setOracle(mockOracleSuccess);

      await whitelist.addWhitelistedAddress(otherAccount);
      await whitelist.addWhitelistedAddress(batchedAccount);
      await whitelist.setAllowedWhitelistIndex(1);
      expect(await whitelist.whitelistCount()).to.eq(2);
      expect(await whitelist.allowedWhitelistIndex()).to.eq(1); 

      // @notice: Checking with whitelisted address : [otherAccount]
      expect(await whitelist.whitelistIndex(otherAccount)).to.eq(1);
      await whitelist.connect(mockContract).checkWhitelist(pool, otherAccount, 0);
      expect(await whitelist.contributed(otherAccount)).to.eq(ethers.parseEther("1.5"));

      // @notice: Checking with whitelisted address but not in allowedWhitelistIndex : [batchedAccount]
      expect(await whitelist.whitelistIndex(batchedAccount)).to.eq(2);
      await expect(
        whitelist.connect(mockContract).checkWhitelist(pool, batchedAccount, 0),
      ).to.be.revertedWithCustomError(whitelist, "NotWhitelisted");

      // @notice: Checking with non-whitelisted address : [attackerAccount]
      expect(await whitelist.whitelistIndex(attackerAccount)).to.eq(0);
      await whitelist.connect(mockContract).checkWhitelist(pool, attackerAccount, 0);
      expect(await whitelist.contributed(attackerAccount)).to.eq(ethers.parseEther("1.5"));

    });
  });
```

## Recommended Mitigation Steps

To mitigate this, perform additional check that reverts when `_whitelistIndex[to] == 0`.


```diff
-    if (_allowedWhitelistIndex == 0 || _whitelistIndex[to] > _allowedWhitelistIndex){
+    if (_allowedWhitelistIndex == 0 || _whitelistIndex[to] > _allowedWhitelistIndex || _whitelistIndex[to] == 0){
   revert NotWhitelisted();
}
```
