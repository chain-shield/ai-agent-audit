# Vulnerability details

## Impact
Whitelisted users can buy more $VULT tokens although they already own over the max address cap. 

## Proof of Concept
Whitelist contract validate the max address cap for every whitelisted user as follows.
```solidity
File: Whitelist.sol
    function checkWhitelist(address from, address to, uint256 amount) external onlyVultisig {
        if (from == _pool && to != owner()) {
            // We only add limitations for buy actions via uniswap v3 pool
            // Still need to ignore WL check if it's owner related actions
            if (_locked) {
                revert Locked();
            }

            if (_isBlacklisted[to]) {
                revert Blacklisted();
            }

            // @audit-issue use `_whitelistIndex[to]` instead of `_allowedWhitelistIndex` since `_whitelistIndex[to] == 0` for not whitelisted `to`
            if (_allowedWhitelistIndex == 0 || _whitelistIndex[to] > _allowedWhitelistIndex) {
                revert NotWhitelisted();
            }

            // // Calculate rough ETH amount for VULT amount
222:        uint256 estimatedETHAmount = IOracle(_oracle).peek(amount);
223:        if (_contributed[to] + estimatedETHAmount > _maxAddressCap) {
                revert MaxAddressCapOverflow();
            }

227:        _contributed[to] += estimatedETHAmount;
        }
    }
```
As shown above, `_contributed[to]` is the sum of `estimatedETHAmount` and it is the estimated eth amount of `amount` $VULT tokens.
However the price of `$VULT` is not fixed and it may be increased during 24 hours whitelist launch period.
So the total estimated eth amount of whitelisted users can be over the max address cap along time passed.

Scenario:
1. Suppose that At the start of whitelist launch period, the price of $VULT is 0.0001 ETH and a whitelisted user buys 20000 $VULT and thus `_contributed[user]` are `2 ether`.
2. After 12 hours passed, the price of $VULT is increased to 0.0002 ETH, so the price of the users total $VULT tokens are increased to 4 ETH.
3. However the user can buy 5000 $VULT more which is equal 1 ETH and the price of the users total $VULT tokens become 5 ETH.
