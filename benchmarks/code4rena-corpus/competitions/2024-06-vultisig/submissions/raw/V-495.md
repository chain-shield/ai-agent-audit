# Vulnerability details

## Impact
The function `multicall()` in contract `multicall.sol` may fail due to unbounded loop over data.length.
The `data` is an dynamic array of types bytes. since the function multicall is public it can be called by anyone if a malicious user provides this data with a length very huge then iterating over its length in loop can cause dos due to exceed of gas limit. 

## Proof of Concept
the multicall function below is vulnerable to dos
```javascript
   function multicall(bytes[] calldata data) public payable override returns (bytes[] memory results) {
        //reorg attacks,,dos unbounded for loop.//@audit
        results = new bytes[](data.length);
        for (uint256 i = 0; i < data.length; i++) {
            (bool success, bytes memory result) = address(this).delegatecall(data[i]);

            if (!success) {
                // Next 5 lines from https://ethereum.stackexchange.com/a/83577
                if (result.length < 68) revert();
                assembly {
                    result := add(result, 0x04)
                }
                revert(abi.decode(result, (string)));
            }

            results[i] = result;
        }
    }
```
