# Vulnerability details

## Impact

Users can exploit periods of high volatility to increase their contributions in `Whitelist`. A sudden price drop can be used to buy at a low cost, and when the Uniswap TWAP oracle is used, it would return a value higher than the market price, recording higher contribution values for users.

## Proof of Concept

```
            uint256 estimatedETHAmount = IOracle(_oracle).peek(amount);
            if (_contributed[to] + estimatedETHAmount > _maxAddressCap) {
                revert MaxAddressCapOverflow();
            }

            _contributed[to] += estimatedETHAmount;
```

In this code snippet, we can see the issue (assuming the peek function returns correct values, otherwise it will be addressed in another finding).

## Tools Used

Manual

## Recommended Mitigation Steps

The Uniswap TWAP is vulnerable during periods of high volatility. Possible solutions include using Chainlink or reverting the calls during those periods.
