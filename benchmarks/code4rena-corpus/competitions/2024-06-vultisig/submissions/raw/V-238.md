# Vulnerability details

## Impact
Any address can bypass whitelist check.

## Proof of Concept
`Whitelist.checkWhitelist()` does not check if `to` is added to whitelist.

https://github.com/code-423n4/2024-06-vultisig/blob/main/hardhat-vultisig/contracts/Whitelist.sol#L216-L219

```
      if (_allowedWhitelistIndex == 0 || _whitelistIndex[to] > _allowedWhitelistIndex) {
             revert NotWhitelisted();
       }
```

## Tools Used
Manual Review

## Recommended Mitigation Steps
`Whitelist.checkWhitelist()` should check if `to` is in whitelist.

https://github.com/code-423n4/2024-06-vultisig/blob/main/hardhat-vultisig/contracts/Whitelist.sol#L216-L219
```
-       if (_allowedWhitelistIndex == 0 || _whitelistIndex[to] > _allowedWhitelistIndex) {
+       if (_allowedWhitelistIndex == 0 || _whitelistIndex[to] == 0 || _whitelistIndex[to] > _allowedWhitelistIndex) {
                revert NotWhitelisted();
       }

```
