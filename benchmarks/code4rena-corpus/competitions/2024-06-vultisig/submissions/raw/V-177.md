# Vulnerability details

## Impact
In the current implementation of the upgradable contract, There are no storage gaps for contract upgradability

## Proof of Concept
Upgradable contracts typically store state variables in storage slots to maintain data across contract upgrades. Without a gap between these variables, a new version of the contract might inadvertently overwrite existing data, leading to:

Data Corruption: Overwriting existing storage variables during contract upgrades can result in the loss or corruption of critical data, affecting the contract's functionality and potentially causing financial loss to users.

## Tools Used
Manual Review

## Recommended Mitigation Steps
 Explicitly add gaps between state variables to safeguard against accidental overwriting during contract upgrades.
