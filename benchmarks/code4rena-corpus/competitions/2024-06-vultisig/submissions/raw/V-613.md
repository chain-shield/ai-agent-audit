# Vulnerability details

## Impact

- `ILOManager` enables a project admin to initialize multiple ILOPools for the same project
- The project with its pools can be initialized by anyone as long as the launch time is passed by invoking `ILOManager.launch()`:

```js
function launch(address uniV3PoolAddress) external override {
        require(block.timestamp > _cachedProject[uniV3PoolAddress].launchTime, "LT");
        //...
        for (uint256 i = 0; i < initializedPools.length; i++) {
            IILOPool(initializedPools[i]).launch();
        }
        //...
    }
```

- As can be seen; the pools are launched in a loop where it will first check the following before launching it:

```js
   function launch() external override OnlyManager() {
        require(!_launchSucceeded, "PL");
        // when refund triggered, we can not launch pool anymore
        require(!_refundTriggered, "IRF");
        // make sure that soft cap requirement match
        require(totalRaised >= saleInfo.softCap, "SC");

        //the rest of the function...
   }
```

so if a pool has already been launched (impossible scenario as it can't be re-launched again) or if the `_refundTriggered` is set to `true` or if the `totalRaised` is less than the soft cap; the pool will not be launched rendering freezing the project launch permanently.

This could happen in the following cases:

- If any of the investors called `ILOPool.claimRefund()` before pool launch and during the refund window; the `_refundTriggered` variable will be set to `true`, and this is done via `refundable` modifier, and this could be exploited by any malicious investor to hinder projects launch by buying and claiming refund before launch:

```js
    modifier refundable() {
        if (!_refundTriggered) {
            // if ilo pool is lauch sucessfully, we can not refund anymore
            require(!_launchSucceeded, "PL");
            IILOManager.Project memory _project = IILOManager(MANAGER).project(
                _cachedUniV3PoolAddress
            );
            require(block.timestamp >= _project.refundDeadline, "RFT");

            _refundTriggered = true;
        }
        _;
    }
```

- If the purchase window of any of the project pools is closed while `totalRaised` is still below the `saleInfo.softCap`:

```js
   function buy(
        uint256 raiseAmount,
        address recipient
    ) external override returns (uint256 tokenId, uint128 liquidityDelta) {

        require(_isWhitelisted(recipient), "UA");
        require(
            block.timestamp > saleInfo.start && block.timestamp < saleInfo.end,
            "ST"
        );

        // the rest of the function...
    }
```

## Tools Used

Manual Review.

## Recommended Mitigation Steps

Launch the project ILOPools in a try-catch block, so if any of the ILOPools can't be launched then its investors (shares buyers) can claim their refund without affecting the launch of the whole project.
