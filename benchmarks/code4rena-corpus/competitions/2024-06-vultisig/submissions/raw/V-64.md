# Vulnerability details

```_isBlacklisted``` is used to block suspected addresses from buying VULT tokens during the whitelisted period. According to the readme, this is done to remove any suspicious addresses that the admin might detect. But the protection is ineffective when self-whitelisting is enabled because such a malicious actor can have many addresses with which they can whitelist themselves repeatedly, and interact with the pool to buy VULT tokens.  

Also, when admin calls ```setBlacklisted()``` to blacklist an address, the malicious actor can simply front-run the admin's call to utilize their whole ```maxAddressCap``` and get the VULT tokens transferred to themselves, before the setBlacklisted call actually gets executed. In such a situation, there will be no effect of the blacklist as these token holders can easily use/transfer their VULT tokens after the whitelist period has ended, so they do not lose anything.


## Impact
Suspicious actors will be able to acquire hoard of VULT tokens and there is no effective way to stop them, and the blacklisting protection against this is ineffective. These actors can freely transfer these VULT tokens after the whitelist period has ended.

## Proof of Concept
The hook used to check whitelist logic is only called if the whitelist period is still running (ie. whitelist contract address has not been set to zero) :

``` 
function _beforeTokenTransfer(address from, address to, uint256 amount) internal override {
        if (_whitelistContract != address(0)) {
            IWhitelist(_whitelistContract).checkWhitelist(from, to, amount);
        }
        super._beforeTokenTransfer(from, to, amount);
    }
```
so even blacklisted actors can access the tokens they acquire maliciously.

## Tools Used
Manual review

## Recommended Mitigation Steps
Remove the self-whitelisting functionality and only allow the admin to add whitelisted addresses. Another solution can be to blacklist an address forever such that the tokens remain locked with them forever and any transfers revert, this way after getting blacklisted they will lose out on the VULT tokens as well as the ETH used to buy them.
