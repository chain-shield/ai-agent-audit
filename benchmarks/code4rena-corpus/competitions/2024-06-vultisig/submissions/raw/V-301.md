# Vulnerability details

During `claimRefund` any user position gets deleted , and the `RAISE_TOKEN` is transferred back to that user .

Tokens like USDC can be paused, this means that during the pause state refund cannot occur, because the transfer will be blocked.

## Impact
Refund cannot occur in pause state.

## Recommended Mitigation Steps
The `claimRefund` function should implement a check to verify whether the `tokenOwner` address is blacklisted before attempting the safeTransfer.
