# Vulnerability details

## Impact
The schedules can be overlapped.

## Proof of Concept
In the function `_validateVestSchedule`, there is a check for the `schedule[i].start` which must be greater or equal than the `lastEnd`. However, the `schedule[i].end` is not checked with `schedule[i].start`, which means it can be smaller than `schedule[i].start`. Therefore, the schedules can be overlapped, even that schedules can start before launchTime, which violates the contract.

## Tools Used
VScode

## Recommended Mitigation Steps
```solidity
+++    require(schedule[i].end > schedule[i].start, "VT");
```
