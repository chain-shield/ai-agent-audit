# Vulnerability details

## Impact
Non-whitelisted address can buy liquidity and can claim VULT tokens which was meant for only whitelisted addresses.

## Proof of Concept
Github:- https://github.com/code-423n4/2024-06-vultisig/blob/cb72b1e9053c02a58d874ff376359a83dc3f0742/hardhat-vultisig/contracts/Whitelist.sol#L204

In `Whitelist.sol::checkWhitelist` function we are not checking the value of the `_whitelistIndex` mapping of the address, means if a address is not whitelisted it will return 0, and the whitelisted index starts with index 1, but we are not checking if the _whitelistIndex is greater then 0 or not. 

```javascript
function checkWhitelist(address from, address to, uint256 amount) external onlyVultisig {
        if (from == _pool && to != owner()) {
            // We only add limitations for buy actions via uniswap v3 pool
            // Still need to ignore WL check if it's owner related actions
            if (_locked) {
                revert Locked();
            }
            if (_isBlacklisted[to]) {
                revert Blacklisted();
            }
            if (_allowedWhitelistIndex == 0 || _whitelistIndex[to] > _allowedWhitelistIndex) {
                revert NotWhitelisted();
            }
            // // Calculate rough ETH amount for VULT amount
            uint256 estimatedETHAmount = IOracle(_oracle).peek(amount);
            if (_contributed[to] + estimatedETHAmount > _maxAddressCap) {
                revert MaxAddressCapOverflow();
            }
            _contributed[to] += estimatedETHAmount;
        }
    }

```

Manual Review

## Recommended Mitigation Steps
Add a if condition inside the `Whitelist.sol::checkWhitelist` function to check the value of `_whitelistIndex[to]` and if it's equal to 0 then revert.
```diff
            if (_isBlacklisted[to]) {
                revert Blacklisted();
            }

+           if(_whitelistIndex[to] == 0){
+               revert NotWhitelisted();
+           }

            if (_allowedWhitelistIndex == 0 || _whitelistIndex[to] > _allowedWhitelistIndex) {
                revert NotWhitelisted();
            }
```
