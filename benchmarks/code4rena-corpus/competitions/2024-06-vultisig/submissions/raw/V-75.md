# Vulnerability details

## Impact
The `claimProjectRefund` function uses the `OnlyManager` modifier instead of the `onlyProjectAdmin` modifier. According to the documentation, only the project admin should be able to initialize the ILO pool for the project and claim project refunds.

The current implementation violates the specified access control requirements by allowing the manager, instead of the project admin, to claim project refunds. This can lead to unauthorized access and potential misuse of the funds intended to be controlled by the project admin.

## Recommended Mitigation Steps

Replace the `OnlyManager` modifier with the `onlyProjectAdmin` modifier in the `claimProjectRefund` function to ensure that only the project admin can call this function.

```solidity
function claimProjectRefund(address projectAdmin) external override refundable() onlyProjectAdmin returns (uint256 refundAmount) {
    return _refundProject(projectAdmin);
}
```
