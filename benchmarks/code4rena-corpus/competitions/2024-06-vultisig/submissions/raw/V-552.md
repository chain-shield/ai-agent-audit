# Vulnerability details

## Impact
The Whitelist.sol contract has a `receive() payable` function which allows users to whitelist themselves by sending ETH to the contract. Although this is desired according to the documentation, but users can take advantage of this to whitelist a number of addresses by sending native ETH to this contract, just after deployment. 

## Proof of Concept
1. Vultisig deloys the Whitelist contract.
2. Alice looks at the transaction in the mempool, and runs its script to call Whitelist contract without any calldata, from 1000 different addresses.
3. Now Alice has 1000 addresses which are whitelisted.

## Tools Used
Manual Review
## Recommended Mitigation Steps
Set the `_isSelfWhitelistDisabled` to `false` in constructor
