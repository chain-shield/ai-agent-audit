# Vulnerability details

## Impact
When `_isSelfWhitelistDisabled` is false and users can send eth to the contract to obtain a whitelist, they can simply send 1 wei on many accounts filling up all the slots. This leaves the owner with either having to increase `_allowedWhitelistIndex` value allowing all those accounts to still be whitelisted or spending a lot of your own eth calling `setBlacklisted` on each account individually.

## Proof of Concept
You will need to implement this test contract made in foundry and run this PoC -
```
    function test_GriefWhitelistEntry() public {

        }
        console.log(whitelist._whitelistCount());
```
