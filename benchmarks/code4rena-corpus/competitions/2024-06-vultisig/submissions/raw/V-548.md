# Vulnerability details

## Vulnerability Details

In the `ILOManager.sol:initILOPool` function there are no checks to ensure that the 
Project have not been launched before adding a new pool to the pool array, So pools can be added even after the project is launched.

The `ILOManager.sol:launch` function loops through the `initializedPools` array and launches each pool individually.

The problem is that the `IILOPool(initializedPools[i]).launch();` function reverts if the pool has already been launched. So the pools added after launch cannot be launched.

```solidity
    function launch(address uniV3PoolAddress) external override {
        ...
        for (uint256 i = 0; i < initializedPools.length; i++) {
@->         IILOPool(initializedPools[i]).launch();
        }

        emit ProjectLaunch(uniV3PoolAddress);
    }

```



## Impact

The pool cannot be launched, and funds are lost.
