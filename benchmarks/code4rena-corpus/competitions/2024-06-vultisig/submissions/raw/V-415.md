# Vulnerability details

## Impact

There is no protection within `ILOManager.initialize`, allowing attackers to monitor the deployment and initialize the contract with contaminated variables, rendering the contract useless.

## Proof of Concept

```
function initialize(
    address initialOwner,
    address _feeTaker,
    address iloPoolImplementation,
    address uniV3Factory,
    address weth9,
    uint16 platformFee,
    uint16 performanceFee
) external override whenNotInitialized() {
    PLATFORM_FEE = platformFee;
    PERFORMANCE_FEE = performanceFee;
    FEE_TAKER = _feeTaker;
    transferOwnership(initialOwner);
    UNIV3_FACTORY = uniV3Factory;
    ILO_POOL_IMPLEMENTATION = iloPoolImplementation;
    WETH9 = weth9;
}
```
