# Vulnerability details


## Impact
There are many cases where the `ILOPool` launch functions can revert, such as when the `refundTriggered` is true or the `totalRaise` is less than the softCap.
If one of the `ILOPool` launch fails, the project launch will revert as well even if the other `ILOPools` are successful.

## Proof of Concept
Project admin can create several ILOPools by using [initILOPool](https://github.com/code-423n4/2024-06-vultisig/blob/main/src/ILOManager.sol#L72).
- If one of the `ILOPool` does not meet the `softCap`, the launch function will revert in the `ILOPool` contract. [launch](https://github.com/code-423n4/2024-06-vultisig/blob/main/src/ILOPool.sol#L274)
- After the `refundDeadline` passes, the investor can call the `claimRefund` function in the `ILOPool` contract. [claimRefund](https://github.com/code-423n4/2024-06-vultisig/blob/main/src/ILOPool.sol#L350)
If the `refundTriggered` or the `totalRaise` is less than the `softCap`, the launch function will revert in the `ILOPool` contract. [launch](https://github.com/code-423n4/2024-06-vultisig/blob/main/src/ILOPool.sol#L272-L274)

If one of the `ILOPool` launch functions fails, it will lead to reverts on the `ILOManager` launch function.
```solidity
    function launch(address uniV3PoolAddress) external override {
        require(block.timestamp > _cachedProject[uniV3PoolAddress].launchTime, "LT");
        (uint160 sqrtPriceX96, , , , , , ) = IUniswapV3Pool(uniV3PoolAddress).slot0();
        require(_cachedProject[uniV3PoolAddress].initialPoolPriceX96 == sqrtPriceX96, "UV3P");
        address[] memory initializedPools = _initializedILOPools[uniV3PoolAddress];
        require(initializedPools.length > 0, "NP");
        for (uint256 i = 0; i < initializedPools.length; i++) {
            IILOPool(initializedPools[i]).launch(); // @audit revert if one of the ILOPool launch functions fails
        }
        emit ProjectLaunch(uniV3PoolAddress);
    }
```
The worst-case scenario is that the launch function in the `ILOManager` contract will revert always if one of the `ILOPool` launch functions fails.


## Tools Used
Manual review

## Recommended Mitigation Steps
To enhance the functionality, it is recommended to make changes to the launch function in the `ILOPool` contract so that it returns a status code instead of triggering a revert.
And, the launch function in the `ILOManager` contract should only proceed if at least one of the `ILOPool` launch functions is successful.
