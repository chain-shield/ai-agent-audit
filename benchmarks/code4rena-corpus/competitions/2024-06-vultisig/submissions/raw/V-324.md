# Vulnerability details

## Impact
Any transfer by an approved EOA for `VULT` token will be denied

## Vulnerability Details
The [approveAndCall()](https://github.com/code-423n4/2024-06-vultisig/blob/cb72b1e9053c02a58d874ff376359a83dc3f0742/hardhat-vultisig/contracts/Vultisig.sol#L16-L24) function in the Vultisig contract allows a user to approve a `spender` and then call the `receiveApproval()` function on the `spender` contract.
```solidity
    function approveAndCall(address spender, uint256 amount, bytes calldata extraData) external returns (bool) {
        // Approve the spender to spend the tokens
        _approve(msg.sender, spender, amount);

        // Call the receiveApproval function on the spender contract
        IApproveAndCallReceiver(spender).receiveApproval(msg.sender, amount, address(this), extraData);

        return true; // @audit-issue Always returns true
    }
```
However, if `spender` is an `EOA`, the call to `receiveApproval()` fails silently, leading to a false sense of success as the function is set to always return `true`. As such, approval appears successful, but the `spender` cannot actually spend the tokens.

The `spender` might attempt to transfer these tokens using `transferFrom()/safeTransferFrom()`, but it will fail due to the approval `amount` being set to `0`.

## Tools Used
Manual Review

## Recommended mitigation steps
Use a boolean `success` to check the return value of `receiveApproval()`. Ensure the function reverts if `receiveApproval()` returns `false`.
```diff
    function approveAndCall(address spender, uint256 amount, bytes calldata extraData) external returns (bool) {
        // Approve the spender to spend the tokens
        _approve(msg.sender, spender, amount);

        // Call the receiveApproval function on the spender contract
-       IApproveAndCallReceiver(spender).receiveApproval(msg.sender, amount, address(this), extraData);
+       bool success = IApproveAndCallReceiver(spender).receiveApproval(msg.sender, amount, address(this), extraData);
+       require(success, "Approval Failed");
    }
```
