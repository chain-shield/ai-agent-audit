# Vulnerability details

## Impact
VULT token is designed for whitelist presale only. But this validation could allow EVERYONE not in the blacklist can buy the token in presale stage.

## Proof of Concept
```
it("Shoud not pass this", async function () {
      const { whitelist, pool, otherAccount, batchedAccount, mockContract, randomAccount, mockOracleSuccess } = await loadFixture(deployWhitelistFixture);

      await whitelist.setVultisig(mockContract);
      await whitelist.setLocked(false);

      // Whitelist 2 accounts and only allow first one
      await whitelist.addBatchWhitelist([otherAccount, batchedAccount]);
      await whitelist.setAllowedWhitelistIndex(1);
      await whitelist.setOracle(mockOracleSuccess);
      expect(await whitelist.oracle()).to.eq(mockOracleSuccess);

      // mallicious account pass the check
      await expect(
        whitelist.connect(mockContract).checkWhitelist(pool, randomAccount, 0),
      ).to.be.revertedWithCustomError(whitelist, "NotWhitelisted");
    });
```
