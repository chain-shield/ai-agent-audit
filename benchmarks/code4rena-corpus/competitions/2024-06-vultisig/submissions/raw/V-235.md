# Vulnerability details

## Impact
DoS revert while launching ILOPools.

## Proof of Concept
There's strict equality check between initial spot price and current spot price in `ILOManager.launch()`.

Attacker can frontrun swap tx to manipulate spot price and subsequent launch tx to be reverted.

https://github.com/code-423n4/2024-06-vultisig/blob/main/src/ILOManager.sol#L187-L198

Strict 
```
    function launch(address uniV3PoolAddress) external override {
...
        (uint160 sqrtPriceX96, , , , , , ) = IUniswapV3Pool(uniV3PoolAddress).slot0();
        require(_cachedProject[uniV3PoolAddress].initialPoolPriceX96 == sqrtPriceX96, "UV3P"); // @audit - launch can be DoSed by frontrunning swap
...
        }

        emit ProjectLaunch(uniV3PoolAddress);
    }
```

## Tools Used
Manual Review

## Recommended Mitigation Steps
1) It can be mitigated by hiding tx with Flashbot RPC.

2) Strict equality can be changed to greater or equality check with minimum spot price.
