# Vulnerability details

## Impact
https://github.com/code-423n4/2024-06-vultisig?tab=readme-ov-file#main-invariants states that `iloPool can only launch from manager. only project admin can launch project(aka launch all ilo pool)`. However, the `ILOManager.launch` function allows anyone to call it, which breaks the invariant that only project admin should be allowed to launch project and all of its ilo pools.

## Proof of Concept
Because the following `ILOManager.launch` function does not call the `ILOManager.onlyProjectAdmin` modifier and the `ILOPool.OnlyManager` modifier called by the `ILOPool.launch` function only ensures that the caller of the `ILOPool.launch` function is the `ILOManager` contract, the `ILOManager.launch` function is callable by anyone. This breaks the invariant that only project admin should be allowed to launch project and all of its ilo pools.
