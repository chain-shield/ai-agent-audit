# Vulnerability details

## Impact

In `ILOManager` smart contract, when the project is about to be launched with all the pools, we use `slot0` to get the value of `sqrtPrice` which can lead to price manipulations as the `slot0` param represents the current price.

## Proof of Concept

In the `ILOManager` smart contract, `launch()` has the following functionality to get the price:

https://github.com/code-423n4/2024-06-vultisig/blob/main/src/ILOManager.sol#L189
```
(uint160 sqrtPriceX96, , , , , , ) = IUniswapV3Pool(uniV3PoolAddress).slot0();
```

So when the project is launched, we use the current price instead of using the time weighted price which can lead to different flash loan manipulations by performing large value swaps.

## Tools Used

Manual review.

## Recommended Mitigation Steps

Consider relying on time weighted price to avoid flash loan manipulations.
