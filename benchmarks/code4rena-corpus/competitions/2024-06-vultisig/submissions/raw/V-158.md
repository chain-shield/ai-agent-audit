# Vulnerability details

## Impact
The contract has not checked that the unlocked end must be greater than start. Therefore, using vest.end - vest.start may cause overflow. This will result in the user unlocking less liquidity.

## Proof of Concept
When [calculating the liquidity unlocked](https://github.com/code-423n4/2024-06-vultisig/blob/cb72b1e9053c02a58d874ff376359a83dc3f0742/src/ILOPool.sol#L400-L427) for users, vest.end - vest.start will be used. 
```solidity
                liquidityUnlocked += uint128(FullMath.mulDiv(
                    vest.shares * totalLiquidity, 
                    block.timestamp - vest.start, 
                    (vest.end - vest.start) * BPS
                ));
```
However, for the [check of vest](https://github.com/code-423n4/2024-06-vultisig/blob/cb72b1e9053c02a58d874ff376359a83dc3f0742/src/base/ILOVest.sol#L43-L44), it is only verified in _validateVestSchedule that the start of the next vest is greater than the end of the previous vest. However, there is no requirement for one start in vest must be smaller than end. So it is possible that vest.end is smaller than vest.start.
```solidity
        for (uint256 i = 0; i < scheduleLength; i++) {
            // vesting schedule must not overlap
            require(schedule[i].start >= lastEnd, "VT");
            lastEnd = schedule[i].end;
            // we need to subtract fist in order to avoid int overflow
            require(BPS - totalShares >= schedule[i].shares, "VS");
            totalShares += schedule[i].shares;
        }
```

This will cause the denominator to be abnormally large when calculating the amount of liquidity unlocked by users, so users have no new unlocked funds during this cycle.

## Recommended Mitigation Steps
```diff
        for (uint256 i = 0; i < scheduleLength; i++) {
            // vesting schedule must not overlap
            require(schedule[i].start >= lastEnd, "VT");
+           require(schedule[i].start < schedule[i].end, "VT");
            lastEnd = schedule[i].end;
            // we need to subtract fist in order to avoid int overflow
            require(BPS - totalShares >= schedule[i].shares, "VS");
            totalShares += schedule[i].shares;
        }
```
