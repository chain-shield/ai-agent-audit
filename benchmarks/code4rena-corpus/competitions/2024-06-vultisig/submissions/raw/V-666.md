# Vulnerability details

## Impact
The ```initialize``` function can be called by any address, allowing arbitrary users to initialize a contract with any parameters.

## Proof of Concept
```solidity 

function initialize(InitPoolParams calldata params) external override whenNotInitialized() {
        _nextId = 1;
        // initialize imutable state
        MANAGER = msg.sender;
        IILOManager.Project memory _project = IILOManager(MANAGER).project(params.uniV3Pool);
         ...
```
https://github.com/code-423n4/2024-06-vultisig/blob/main/src/ILOPool.sol#L61

The attacker can watch when the contract is deployed. 

When the contract owner calls the ```initialize``` function, the attacker can see his transaction on the blockchain, then also call ```initialize```, e.g., to pay more gas.

## Tools Used

Manual

## Recommended Mitigation Steps

Limit access to the initialization function to only authorized addresses, such as an administrator or contract manager.
