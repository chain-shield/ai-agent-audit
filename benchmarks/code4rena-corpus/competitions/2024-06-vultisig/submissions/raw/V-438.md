# Vulnerability details

## Impact

Unallowed users can receive Vultisig tokens. This could make the launching process not to work well, because vultisig token holders can change the exchange rates of the uniswap v3 pools which have vultisig tokens.

## Proof of Concept

L216 checks if `to` is allowed to receive vultisig tokens. However, it only works well when `_whitelistIndex[to] > 0`.
So, users with `_whitelistIndex` as `0` can pass this check.

https://github.com/code-423n4/2024-06-vultisig/blob/main/hardhat-vultisig/contracts/Whitelist.sol#L204-L228
