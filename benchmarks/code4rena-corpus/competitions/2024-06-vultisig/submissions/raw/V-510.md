# Vulnerability details

## Impact
Uniswap math libraries rely on wrapping behavior for conducting arithmetic operations. Solidity
version 0.8.0 introduced checked arithmetic by default where operations that cause an overflow would revert.
Since the code was adapted from Uniswap these arithmetic operations should be wrapped in an unchecked block.
As the present spdx version of fullMath.sol and tickmath.sol is [>=0.4.0](https://github.com/code-423n4/2024-06-vultisig/blob/cb72b1e9053c02a58d874ff376359a83dc3f0742/hardhat-vultisig/contracts/oracles/uniswap/uniswapv0.8/FullMath.sol#L2)&[>=0.5.0](https://github.com/code-423n4/2024-06-vultisig/blob/cb72b1e9053c02a58d874ff376359a83dc3f0742/hardhat-vultisig/contracts/oracles/uniswap/uniswapv0.8/TickMath.sol#L2C17-L2C24)
due to this any call that leads to overflow, underflow will be reverted.
This happens because from solidity version 0.8.0 checked is by default as mentioned in their [docs](https://docs.soliditylang.org/en/latest/control-structures.html#checked-or-unchecked-arithmetic)
>As impacts would be too many I am here talking about one of them.

**Impact:**
Due to [_saleAmountNeeded](https://github.com/code-423n4/2024-06-vultisig/blob/cb72b1e9053c02a58d874ff376359a83dc3f0742/src/ILOPool.sol#L382) using getLiquidityForAmount1, getLiquidityForAmount0, etc which uses FullMath.sol for calculations, sale token amount needed for the raise Amount will be far off what actually it should be.
## Proof of Concept
The Uniswap protocol has a reference implementation for these changes in a branch named [0.8.](https://github.com/Uniswap/v3-core/tree/0.8)
Here are correct version of [TickMath.sol](https://github.com/Uniswap/v3-core/blob/0.8/contracts/libraries/TickMath.sol) and [FullMath.sol](https://github.com/Uniswap/v3-core/blob/0.8/contracts/libraries/FullMath.sol)
This was also reported by [Pashov](https://solodit.xyz/issues/m-01-tickmath-and-fullmath-libraries-are-missing-unchecked-pashov-none-tapiocadao-markdown),[spearbit](https://solodit.xyz/issues/use-unchecked-intickmathsol-andfullmathsol-spearbit-overlay-pdf)
