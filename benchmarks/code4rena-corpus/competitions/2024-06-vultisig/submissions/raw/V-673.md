# Vulnerability details

### **Relevant Context**
When pools are being created, the project sets a defined initial trading price of assets using the `uint160 initialPoolPriceX96`. Also, theres is a check in the `launch` function which ensures the current `sqrtPriceX96` is the same as the `initialPoolPriceX96` that was set upon the project deployment

```solidity
     function launch(address uniV3PoolAddress) external override {
        require(block.timestamp > _cachedProject[uniV3PoolAddress].launchTime, "LT");
        (uint160 sqrtPriceX96, , , , , , ) = IUniswapV3Pool(uniV3PoolAddress).slot0();
        require(_cachedProject[uniV3PoolAddress].initialPoolPriceX96 == sqrtPriceX96, "UV3P");  //❌ @audit
        address[] memory initializedPools = _initializedILOPools[uniV3PoolAddress];
        require(initializedPools.length > 0, "NP");
        for (uint256 i = 0; i < initializedPools.length; i++) {
            IILOPool(initializedPools[i]).launch();
        }

        emit ProjectLaunch(uniV3PoolAddress);
    }
```

`launch` is function used to launch a project after initialization and pool deployment.
It is the core function of the business logic as the whole idea behind the ILO is being able to launch a project.

However, this critical invariant can be DOS'ed by malicious attacker/users which could be as a result of griefing since there is no economic benefit attached to the exploit.

Attacker can decide to frontrun a newly deployed pool by adding liquidity to the pool in an un proportional manner in order to increase the `sqrtPriceX96` current value which breaks the check as shown in the code above. Thereby making it impossible for projects to launch their projects.

Example; if the current price is 1eth == 2000 vaultsig, but the attacker adds 1eth and 3000 vaultsig, the price will adjust to reflect the new ratio of token in the pool, thereby making it impossible to launch the project


### Impact Summary
This is a high impact as it breaks a core/critical invariant of the whole business logic

Remove the check or revamp the logic entirely.
