# Vulnerability details

## Impact
The function `initialize()` in `ILOPool.sol` may fail due to unbounded loop over ` params.vestingConfigs.length`.
In ILOPool contract, the `initialize()` function might not be available to be called if there are a lot of vestingConfigs in VestingConfig[] array of ILOPool.
`VestingConfig[]` is an dynamic array of indefinite length which can grow into a huge length and iterating over its length can cause dos due to exceed gas limit.


## Proof of Concept
```javascript
  for (uint256 index = 0; index < params.vestingConfigs.length; index++) {
            _vestingConfigs.push(params.vestingConfigs[index]);
        }
```

## Tools Used
Manual review

## Recommended Mitigation Steps
Declare the array `VestingConfig[]` of fixed length and then iterate in for loop


## Assessed type

DoS
