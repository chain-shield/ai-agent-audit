# Vulnerability details

## Impact
To init a project, the adminstrator of the project should call the [initProject](https://github.com/code-423n4/2024-06-vultisig/blob/0957ff9e50441cd6de6b4f6e28c7ea93f5cffa85/src/ILOManager.sol#L57-L65) function. It creates a `saleToken/raiseToken` pool on Uniswap V3 and initialize the price. However, Interacting with Uniswap V3 directly, anybody can create a `saleToken/raiseToken` pool and initialize a price. As a result, the project can't be initialized due to this vulnerability.

## Proof of Concept
To init a project, the adminstrator of the project calls the [initProject](https://github.com/code-423n4/2024-06-vultisig/blob/0957ff9e50441cd6de6b4f6e28c7ea93f5cffa85/src/ILOManager.sol#L57-L65) function.
This function first calculates poolKey from `saleToken`, `raiseToken`, `fee` and inits an Uniswap V3 pool if necessary at L61.

In the [_initUniV3PoolIfNecessary](https://github.com/code-423n4/2024-06-vultisig/blob/0957ff9e50441cd6de6b4f6e28c7ea93f5cffa85/src/ILOManager.sol#L109-L122) function, if the pool exists in Uniswap V3, it checks if `sqrtPriceX96Existing` is equal to `sqrtPriceX96` at L119.
```solidity

             if (pool == address(0)) {
                 pool = IUniswapV3Factory(UNIV3_FACTORY).createPool(poolKey.token0, poolKey.token1, poolKey.fee);
                 IUniswapV3Pool(pool).initialize(sqrtPriceX96);
             } else {
                 (uint160 sqrtPriceX96Existing, , , , , , ) = IUniswapV3Pool(pool).slot0();
                 if (sqrtPriceX96Existing == 0) {
                     IUniswapV3Pool(pool).initialize(sqrtPriceX96);
                 } else {
119                  require(sqrtPriceX96Existing == sqrtPriceX96, "UV3P");
                 }
             }
         }
```
However, interacting with Uniswap V3 directly, anybody can create a `saleToken/raiseToken` pool and initialize the price as any value he wants. So an attacker can do it before the administrator calls the [initProject](https://github.com/code-423n4/2024-06-vultisig/blob/0957ff9e50441cd6de6b4f6e28c7ea93f5cffa85/src/ILOManager.sol#L57-L65) function, call to this function reverts.

## Tools Used
Manual Review

## Recommended Mitigation Steps
When `saleToken` token contract is deployed, the adminstrator of the project must create `saleToken/raiseToken` pool on Uniswap V3 and initialize it with intended price.
