# Vulnerability details

## Impact
 Without the ability to remove addresses from the whitelist, once an address is whitelisted, it remains whitelisted permanently. This limitation can pose significant issues if there is a need to revoke access due to malicious activities

## Proof of Concept
No function exists to remove an address from the whitelist.

## Tools Used
Hardhat
