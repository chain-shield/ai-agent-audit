# Vulnerability details

## Impact
__maxCapPerUser__ should check the total raiseAmount of the ILO positions owned by a user, or a user can buy many ILO positions with the total raiseAmount higher than __maxCapPerUser__.

## Proof of Concept
[__maxCapPerUser__](https://github.com/code-423n4/2024-06-vultisig/blob/cb72b1e9053c02a58d874ff376359a83dc3f0742/src/interfaces/IILOSale.sol#L9) is used in ILOPool contract to limit the max raiseAmount a single user can buy.
```
    function buy(uint256 raiseAmount, address recipient)
        external override 
        returns (
            uint256 tokenId,
            uint128 liquidityDelta
        )
    {
        ...

        // if investor already have a position, just increase raise amount and liquidity
        // otherwise, mint new nft for investor and assign vesting schedules
        if (balanceOf(recipient) == 0) {
@>          _mint(recipient, (tokenId = _nextId++));
            _positionVests[tokenId].schedule = _vestingConfigs[0].schedule;
        } else {
@>          tokenId = tokenOfOwnerByIndex(recipient, 0);
        }


        Position storage _position = _positions[tokenId];
@>      require(raiseAmount <= saleInfo.maxCapPerUser - _position.raiseAmount, "UC");

        ...
    }
```
Protocol compares __maxCapPerUser__ to the raiseAmount of the first position the user owned, to check if __maxCapPerUser__ is exceeded. 
The problem is that the position token can be transferred and a user can own multiple positions, results in  the total raiseAmount of the positions owned by a user is larger than __maxCapPerUser__.

## Tools Used
Manual Review

## Recommended Mitigation Steps
Should check if the total raiseAmount of the ILO positions owned by a user larger than __maxCapPerUser__.
```diff
    function buy(uint256 raiseAmount, address recipient)
        external override 
        returns (
            uint256 tokenId,
            uint128 liquidityDelta
        )
    {
        ...

        // if investor already have a position, just increase raise amount and liquidity
        // otherwise, mint new nft for investor and assign vesting schedules
+       uint256 totalRaiseAmount;

            _positionVests[tokenId].schedule = _vestingConfigs[0].schedule;

+           for (uint i; i < balanceOf(recipient); ++i) {
+               uint256 _tokenId = tokenOfOwnerByIndex(recipient, i);
+               totalRaiseAmount += _positions[_tokenId].raiseAmount;
+           }
        }

        Position storage _position = _positions[tokenId];
-       require(raiseAmount <= saleInfo.maxCapPerUser - _position.raiseAmount, "UC");
+       require(raiseAmount <= saleInfo.maxCapPerUser - totalRaiseAmount, "UC");

        ...
    }
```

Add the same check when transfer the position tokens.
