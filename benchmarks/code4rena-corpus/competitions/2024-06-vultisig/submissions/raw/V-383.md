# Vulnerability details

The contract currently lacks a validation check to ensure that `schedule[0].start` is less than `schedule[0].end` within the `_validateVestSchedule` method. This missing validation can lead to significant issues, such as users being able to withdraw liquidity at the beginning of the vesting period for the first schedule.

## Impact

Failure to validate that the start time is before the end time in the first vesting schedule can lead to the following issues:

1. **Immediate Liquidity Withdrawal:** Users might be able to withdraw liquidity immediately at the beginning of the vesting period, which could undermine the vesting process.
2. **Contract Logic Flaws:** Incorrect scheduling can result in logical inconsistencies within the contract, affecting its overall functionality and trustworthiness.
3. **User Exploits:** Potential exploits where users might benefit from faulty scheduling, leading to unfair distribution of shares.

## Recommended Mitigation Steps

To prevent these issues, the following steps should be taken:

**Add Validation for Schedule Times:** Update `_validateVestSchedule` to include a check ensuring that `schedule[0].start` is less than `schedule[0].end`.

```diff

function _validateVestSchedule(
        uint64 launchTime,
        LinearVest[] memory schedule
    ) internal pure {
        require(schedule[0].start >= launchTime, "VT");
        uint16 BPS = 10000;
        uint16 totalShares;
        uint64 lastEnd;
        uint256 scheduleLength = schedule.length;
+       require(scheduleLength > 0 && schedule[0].start < schedule[0].end);
        for (uint256 i = 0; i < scheduleLength; i++) {
            // vesting schedule must not overlap
            require(schedule[i].start >= lastEnd, "VT");
            lastEnd = schedule[i].end;
            // we need to subtract fist in order to avoid int overflow
            require(BPS - totalShares >= schedule[i].shares, "VS");
            totalShares += schedule[i].shares;
        }
        // total shares should be exactly equal BPS
        require(totalShares == BPS, "VS");
    }
```
