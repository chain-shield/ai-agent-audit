# Vulnerability details

## Impact
Vultisig token transfers can be Dossed, preventing users from receiving them.

## Proof of Concept
Look at the checkWhitelist function:

```solidity
    function checkWhitelist(address from, address to, uint256 amount) external onlyVultisig {
        if (from == _pool && to != owner()) {
            // We only add limitations for buy actions via uniswap v3 pool
            // Still need to ignore WL check if it's owner related actions
            if (_locked) {
                revert Locked();
            }

            if (_isBlacklisted[to]) {
                revert Blacklisted();
            }

            if (_allowedWhitelistIndex == 0 || _whitelistIndex[to] > _allowedWhitelistIndex) {
                revert NotWhitelisted();
            }

            // // Calculate rough ETH amount for VULT amount
            uint256 estimatedETHAmount = IOracle(_oracle).peek(amount);
            if (_contributed[to] + estimatedETHAmount > _maxAddressCap) {
                revert MaxAddressCapOverflow();
            }

            _contributed[to] += estimatedETHAmount;
        }
    }
```

Take a look at this section:

```solidity
            uint256 estimatedETHAmount = IOracle(_oracle).peek(amount);
            if (_contributed[to] + estimatedETHAmount > _maxAddressCap) {
                revert MaxAddressCapOverflow();
            }
```

The function will revert if `_contributed[to] + estimatedETHAmount > _maxAddressCap`:

An attacker can leverage this. They can manipulate the `estimatedETHAmount` value that comes from the `peek` function. An attacker could donate a large amount of raise tokens (WETH) into the pool, hence inflating the sale token (VULT) price.

Hence, the value returned by the `peek` function would be high as the price of the VULT token in terms of WETH would be high. Hence, the above condition will revert.

Note that this attack would be easy to pull off right after the launch, as the TWAP price can be more easily manipulated. Once the attack is done, then every subsequent VULT token transfer will fail.
