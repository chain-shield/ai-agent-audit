# Vulnerability details

## Impact

The issue comes from the fact that an address added to the blacklist 
is not removed from the `_whitelistIndex` mapping.

Similarly an address that is added to whitelist is not set to false 
in the `_isBlacklisted` mapping.

This creates inconsistencies and 
potentially allow blacklisted addresses to circumvent restrictions 
intended to be imposed on them, and may prevent whitelisted addresses from 
accessing their designated features.
