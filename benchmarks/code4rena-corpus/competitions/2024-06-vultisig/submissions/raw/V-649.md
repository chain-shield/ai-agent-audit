# Vulnerability details

## Vulnerability Detail

The `initILOPool` function doesn't check if the `param.start` and `param.end` are in the future, or if they have sufficient windows between them, this can lead to a project that cannot be launched if one of the pools have a sales period in the past.  

## Impact

Such a pool will make the project doom to fail from the start

## Proof of Concept

1. Alice Creates a project.
2. She Creates 1 pool with a valid sales period.
3. After the sales period she accidentally created a pool but with a sales end in the past.
4. Because of this invalid pool, the project cannot be launched.

Add the following test suite to the test folder and run

