# Vulnerability details

## Impact
The current implementation lacks a check for blacklisted addresses `(_isBlacklisted)` before adding them to the whitelist. This oversight can lead to several potential issues:

Blacklisted addresses could potentially circumvent their restrictions by being added to the whitelist, compromising the intended security measures.
Failure to check the blacklist undermines the contract's access control mechanisms, leading to inconsistent management of address permissions.
Unauthorized actions or access could occur if blacklisted addresses are inadvertently added to the whitelist without proper validation.

## Proof of Concept
```javascript
  function addWhitelistedAddress(address whitelisted) external onlyOwner {
        _addWhitelistedAddress(whitelisted);
    }
```

## Tools Used
Manual Review

## Recommended Mitigation Steps
Before adding any address to the whitelist, verify that the address is not blacklisted using _isBlacklisted.

```javascript
function addWhitelistedAddress(address whitelisted) external onlyOwner {
    require(!_isBlacklisted[whitelisted], "Address is blacklisted");
    _addWhitelistedAddress(whitelisted);
}
```
