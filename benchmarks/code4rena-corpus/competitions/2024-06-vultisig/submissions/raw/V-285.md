# Vulnerability details

## Impact
An unbounded loop in `ILOManager.sol::launch` and `ILOManager.sol::claimRefund` can make the function unexecutable and the user token can get locked in the contract.

## Proof of Concept
Github:- https://github.com/code-423n4/2024-06-vultisig/blob/cb72b1e9053c02a58d874ff376359a83dc3f0742/src/ILOManager.sol#L192
https://github.com/code-423n4/2024-06-vultisig/blob/cb72b1e9053c02a58d874ff376359a83dc3f0742/src/ILOManager.sol#L204
These loops uses `initializedPools.length` which is unbounded and after a certain values it won't be executable because of the block gas limit.
## Tools Used
Manual Review

## Recommended Mitigation Steps
Use bounded loops, where the function takes 2 inputs from the caller, startIndex and endIndex.
