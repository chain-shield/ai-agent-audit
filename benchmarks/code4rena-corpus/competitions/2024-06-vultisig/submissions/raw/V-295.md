# Vulnerability details

The `LiquidityAmounts` library implements the liquidity amount functions for computing liquidity amounts from token amounts and prices. However , it does not implements the `getLiquidityForAmounts` and `getAmountsForLiquidity` functions.

## Impact
The protocol could require these functions. 

## Proof of Concept
The both functions are implemented in new updated uniswapV3's `liquidityAmounts` library.
You can check the official code of uniswapV3 here - [getLiquidityForAmounts](https://github.com/Uniswap/v3-periphery/blob/main/contracts/libraries/LiquidityAmounts.sol#L56) , [getAmountsForLiquidity](https://github.com/Uniswap/v3-periphery/blob/main/contracts/libraries/LiquidityAmounts.sol#L120)

## Tools Used
Manual reveiw.
## Recommended Mitigation Steps
Consider implementing both function in the `LiquidityAmounts.sol` library.


## Assessed type

Uniswap
