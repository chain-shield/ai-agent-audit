# Vulnerability details

## Impact

The current whitelisting system is ineffective because whitelisted users can approve or send NFTs to non-whitelisted addresses, allowing those addresses to interact with the protocol. This undermines the purpose of having a whitelist.

## Proof of Concept

Regardless of the whitelist, any user can interact with the protocol if a whitelisted user approves or sends an NFT to them. This bypasses the whitelist restrictions.

## Tools Used

Manual Review

## Recommended Mitigation Steps

Implement checks in every function to enforce user access limitations based on the whitelist.
