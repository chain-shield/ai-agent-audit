# Vulnerability details

## Impact
Anyone calling the claim function can send value to it. This is not recorded, and it cannot be redeemed from the contract. Locking native currency forever.

## Proof of Concept

The [claim](https://github.com/code-423n4/2024-06-vultisig/blob/main/src/ILOPool.sol#L184-L189) function is used to claim for rewards and is called by investors with the specified tokenID.

This function can receive native currency, but it doesn't specifies how to handle it and doesn't record if the user deposited or not. Any funds sent this way will get stuck in the contract forever, since there are no functions to redeem it.

```
    function claim(uint256 tokenId)
        external
        payable
        override
        isAuthorizedForToken(tokenId)
        returns (uint256 amount0, uint256 amount1)
    {
       ...
    }
```

## Tools Used

Manual review

## Recommended Mitigation Steps

Remove the payable modifier or add a require statement specifying that 0 msg.value must be sent.
