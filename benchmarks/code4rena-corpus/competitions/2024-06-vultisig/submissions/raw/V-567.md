# Vulnerability details

## Impact
[ILOManager#Launch()](https://github.com/code-423n4/2024-06-vultisig/blob/cb72b1e9053c02a58d874ff376359a83dc3f0742/src/ILOManager.sol#L189) uses the `IUniswapV3Pool(uniV3PoolAddress).slot0()` to determine the number of tokens it has in it's position.  However, the sqrtPriceX96 is pulled from `IUniswapV3Pool(uniV3PoolAddress).slot0(), which is the most recent data point and can be manipulated easily via MEV bots and Flashloans with sandwich attacks

**Impacts:**
-  Project might get launched at the wrong price
- [_initUniV3PoolIfNecessary](https://github.com/code-423n4/2024-06-vultisig/blob/cb72b1e9053c02a58d874ff376359a83dc3f0742/src/ILOManager.sol#L109) will give the wrong pricing due to which [initProject](https://github.com/code-423n4/2024-06-vultisig/blob/cb72b1e9053c02a58d874ff376359a83dc3f0742/src/ILOManager.sol#L57) will initialize the project with the wrong details.

 function launch(address uniV3PoolAddress) external override {
        require(block.timestamp > _cachedProject[uniV3PoolAddress].launchTime, "LT");
        (uint160 sqrtPriceX96, , , , , , ) = IUniswapV3Pool(uniV3PoolAddress).slot0();
        require(_cachedProject[uniV3PoolAddress].initialPoolPriceX96 == sqrtPriceX96, "UV3P");
        address[] memory initializedPools = _initializedILOPools[uniV3PoolAddress];
        require(initializedPools.length > 0, "NP");
        for (uint256 i = 0; i < initializedPools.length; i++) {
            IILOPool(initializedPools[i]).launch();
        }

        emit ProjectLaunch(uniV3PoolAddress);
    }
