# Vulnerability details

## Impact
The usage of `_safeMint` guarantees that the receiver `to` address is either a smart contract that implements `IERC721Receiver.onERC721Received` or an EOA, when using `_mint` and the receiver is a smart contract that does not support the `ERC721` the NFT will be locked and cannot be retrieved, and may cause financial loss to the user, which will not be able to use many of the functions in the protocol.

## Tools Used
Manual Review

## Recommended Mitigation Steps
According to OpenZeppelin, the usage of `_mint` is discouraged,use `_safeMint` whenever possible, and ensure that the code handles reentrancy properly.
