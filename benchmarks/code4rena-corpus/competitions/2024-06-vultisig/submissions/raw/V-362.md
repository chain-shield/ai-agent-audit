# Vulnerability details

## Impact
The lack of a minimum `raiseAmount` check in the `buy()` function can lead to spam and unauthorized NFT minting for any `recipient`.

## Vulnerability Details
The [buy()](https://github.com/code-423n4/2024-06-vultisig/blob/cb72b1e9053c02a58d874ff376359a83dc3f0742/src/ILOPool.sol#L143-L145) function in the `ILOPool` contract allows users to mint an NFT by depositing a `raiseAmount`. However, there is no check to ensure that the `raiseAmount` is significant. A malicious actor could exploit this by depositing a minuscule `raiseAmount` to mint an NFT to any `recipient` who doesn't already have a position. 
```solidity
        // otherwise, mint new nft for investor and assign vesting schedules
        if (balanceOf(recipient) == 0) {
            _mint(recipient, (tokenId = _nextId++));
            _positionVests[tokenId].schedule = _vestingConfigs[0].schedule;
        }
```
If the `recipient` does not already have a position, a new NFT is minted for them.

The function only ensures that the amount of liquidity (`liquidityDelta`) associated with the `raiseAmount` must be greater than `zero`.
```solidity
        // get amount of liquidity associated with raise amount
        if (RAISE_TOKEN == _cachedPoolKey.token0) {
            liquidityDelta = LiquidityAmounts.getLiquidityForAmount0(SQRT_RATIO_X96, SQRT_RATIO_UPPER_X96, raiseAmount);
        } else {
            liquidityDelta = LiquidityAmounts.getLiquidityForAmount1(SQRT_RATIO_LOWER_X96, SQRT_RATIO_X96, raiseAmount);
        }

        require(liquidityDelta > 0, "ZA"); // @audit The only condition required interms of raiseAmount deposited
```
This means that even a minuscule `raiseAmount` can be used to mint an NFT, potentially leading to spam or unauthorized NFT minting.

## Tools Used
Manual Review

## Recommended mitigation steps
Introduce a minimum `raiseAmount` to ensure that only significant contributions can mint an NFT and keep off spam and unauthorized NFT minting by malicious actors.
```diff
+   uint256 public constant MIN_RAISE_AMOUNT = 1 ether; // Example minimum amount

    function buy(uint256 raiseAmount, address recipient)
        external override 
        returns (
        uint256 tokenId,
        uint128 liquidityDelta
        )
    {
        //...
+       require(raiseAmount >= MIN_RAISE_AMOUNT, "Deposit amount too low");
        //...
    }
```
