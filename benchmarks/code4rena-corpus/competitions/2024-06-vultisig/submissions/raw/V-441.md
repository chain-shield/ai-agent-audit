# Vulnerability details

## Impact

The `initILOPool` function adds a new pool to the `_initializedILOPools` array, this array is unbounded and can grow to any length causing DOS to function looping through it. 

```solidity 
    function initILOPool(InitPoolParams calldata params) external override onlyProjectAdmin(params.uniV3Pool) returns (address iloPoolAddress) {
        ...
        _initializedILOPools[params.uniV3Pool].push(iloPoolAddress);
    }
```

The `launch` and `claimRefund` functions will experience denial of service if the array grows too large.

## Proof of Concept

The gas cost for launching 100 pools will be less than the cost for launching a 1000 pools

## Tools Used

Manual Analysis

## Recommended Mitigation Steps

Add a maximum length for the `_initializedILOPools` array, it should not grow above that length
