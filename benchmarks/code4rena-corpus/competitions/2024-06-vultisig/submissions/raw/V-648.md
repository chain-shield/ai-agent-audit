# Vulnerability details

## Impact
`initILOPool` function in the [ILOPool](https://github.com/code-423n4/2024-06-vultisig/blob/main/src/ILOPool.sol) contract should check if the initialPoolPrice is in range of the lower and upper tick provided. 

But we look closely, it only checks if the `lower < upper` & `lower < initial`.

Thus there can be scenario where `lower < upper < initial` will hold true
