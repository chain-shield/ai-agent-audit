# Vulnerability details

## Impact
In the `checkWhitelist`, The peek function of the IOracle interface is called with the amount parameter, representing the number of tokens being transferred. However, the peek function is likely expecting the token amount to be in the token's smallest unit (e.g., wei for VULT tokens).
```solidity
uint256 estimatedETHAmount = IOracle(_oracle).peek(amount);
```
If the amount parameter passed to peek is not in the correct unit, it could lead to incorrect calculations and unexpected behavior when estimating the ETH amount.

## Recommended Mitigation Steps
Ensure that the `amount` parameter is properly scaled to the token's smallest unit before passing it to the `peek` function by multiplying `amount` by the token's decimals factor. For example, if the VULT token has 18 decimals, it must multiply `amount` by 10^18 before calling peek.
```solidity
uint256 estimatedETHAmount = IOracle(_oracle).peek(amount * 10**18);
```
