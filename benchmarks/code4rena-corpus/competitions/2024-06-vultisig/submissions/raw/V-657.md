# Vulnerability details

## Impact
excessive length for `_vestingConfigs.length` and `projectConfig.schedule.length` might make the whole project unlaunchable.

## Proof of Concept
there is a length of `_vestingConfigs` and `projectConfig.schedule` that might cause the `launch` function to revert due to lack of gas but will not cause `initialize`, `_validateSharesAndVests` and `_validateVestSchedule` to revert. This length would be one where the gas consumed by state updates, external calls, and multiple loops in the launch function exceeds the block gas limit, while the checks in _validateSharesAndVests and _validateVestSchedule remain within the limit.
This will make the project unlaunchable, and any call to the function will revert.

## Tools Used
Foundry
Manual Review

## Recommended Mitigation Steps
To avoid this issue, it is essential to ensure that `_vestingConfigs` and `projectConfig.schedule` are kept within a manageable length
