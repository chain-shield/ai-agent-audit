# Vulnerability details

## Impact

The `launch` function in `ILOManager` can be permanently DoSed.

## Proof of Concept

The `ILOManager` currently allows:

* Projects to initialize by calling `initProject`.

* Project Admins to create multiple `ILOPool` instances for a project.

* Once the `launchtime` has passed and the soft cap is reached on all the `ILOPool` instances, anyone can call the `launch` function to launch all the `ILOPool` instances together.

```solidity

    function launch(address uniV3PoolAddress) external override {
        require(block.timestamp > _cachedProject[uniV3PoolAddress].launchTime, "LT");
        (uint160 sqrtPriceX96, , , , , , ) = IUniswapV3Pool(uniV3PoolAddress).slot0();
        require(_cachedProject[uniV3PoolAddress].initialPoolPriceX96 == sqrtPriceX96, "UV3P");
        address[] memory initializedPools = _initializedILOPools[uniV3PoolAddress];
        require(initializedPools.length > 0, "NP");
        for (uint256 i = 0; i < initializedPools.length; i++) {
@->         IILOPool(initializedPools[i]).launch();
        }

        emit ProjectLaunch(uniV3PoolAddress);
    }

```

Issue with this function:

* The `launch` function iterates over the unbounded `initializedPools` array, launching every pool in a single transaction. This can lead to a high gas cost and potential transaction failure if too many `ILOPool` instances are created & it crosses block gas limit.

#### Test to Understand Gas Cost

We can analyze the gas cost of each `launch` by wrapping the `launch` call in the `_launch` function in `ILOPool.t.sol` with following lines:

```diff

+       uint initialGas = gasleft();
+       vm.prank(address(iloManager));
        IILOPool(iloPool).launch();
+       uint gasUsed = initialGas - gasleft();
+       console2.log("Gas Used = ", gasUsed);

```

Now run the `testRefundAfterLaunch` test:

```powershell

    forge test --match-test testRefundAfterLaunch -vvv

```

**Result:**

**Analysis:**

The gas used for a single `launch` is approximately `1.14M gas`.

* On Ethereum (block gas limit = 30M), a project with around 26 `ILOPools` will be DoSed from launch.

* On Avalanche C-Chain (block gas limit = 15M), a project with around 13 `ILOPools` will be DoSed from launch.

This means if a project creates too many `ILOPools`, the launch function will fail due to exceeding the block gas limit, leading to a permanent DoS.
