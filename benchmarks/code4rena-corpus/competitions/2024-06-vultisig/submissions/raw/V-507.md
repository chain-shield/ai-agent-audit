# Vulnerability details

**Description:- In `Whitelist.sol` contract the variable** `_allowedWhitelistIndex` tell us how much address can be whitelist and store in `mapping(address => uint256) private _whitelistIndex;` mapping and the `_whitelistCount` variable is show how much address is whitelisted until. since the `_allowedWhitelistIndex` is set in `setAllowedWhitelistIndex` through owner. when the owner call the `addWhitelistedAddress` and pass the address to set as whitelist address. and call the `addBatchWhitelist` and pass list of address to set as whitelist address. both function doesn't check that the amount of whitelist address which is hold by `_whitelistCount` doesn't exceed from the max amount of allowed address `_allowedWhitelistIndex`. this lack of checking will lead to add more than address (1k whitelisted slots) as whitelist address.

```solidity
function addWhitelistedAddress(address whitelisted) external onlyOwner {
        // @audit check that address should not be zero.
        _addWhitelistedAddress(whitelisted);
    }
    /// @notice Add batch whitelists
    /// @param whitelisted Array of addresses to be added
    function addBatchWhitelist(address[] calldata whitelisted) external onlyOwner {
        for (uint i = 0; i < whitelisted.length; i++) {
            _addWhitelistedAddress(whitelisted[i]);
        }
    }
    /// @notice Internal function used for whitelisting. Only increase whitelist count if address is not whitelisted before
    /// @param whitelisted Address to be added
    function _addWhitelistedAddress(address whitelisted) private {
        if (_whitelistIndex[whitelisted] == 0) {
            _whitelistIndex[whitelisted] = ++_whitelistCount;
        }
    }
```

**Mitigation Steps:- Check the `_whitelistCount` with `_allowedWhitelistIndex` to prevent from adding address to whitelist addresses mapping more than the `_allowedWhitelistIndex` amount. add the check block in** `addWhitelistedAddress` and `addBatchWhitelist` functions.

```solidity
**if(_whitelistCount > _allowedWhitelistIndex){**

**revert("Enough Addresses are Whitelisted!");**

**}**
```
