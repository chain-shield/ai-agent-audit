# Vulnerability details

## Impact
Anyone (attacker or not) can stop the launch of the ILOPool if they trade on the Uniswap pool and change its price. If it is different from the ILOManager contract stored price for that pool, the launch function will always revert.

## Proof of Concept

If a project has already circulating supply on its token, anyone can add liquidity and trade on newly created pools. This will change the uniswapv3 pool state (the [price of the token](https://github.com/code-423n4/2024-06-vultisig/blob/main/src/ILOManager.sol#L189)) and avoid the launch of the ILOPool.

```solidity
    function launch(address uniV3PoolAddress) external override {
        require(block.timestamp > _cachedProject[uniV3PoolAddress].launchTime, "LT");
        (uint160 sqrtPriceX96, , , , , , ) = IUniswapV3Pool(uniV3PoolAddress).slot0();
        // HERE WILL ALWAYS REVERT IF THE POOL IS ALREADY BEING USED
        require(_cachedProject[uniV3PoolAddress].initialPoolPriceX96 == sqrtPriceX96, "UV3P");
        address[] memory initializedPools = _initializedILOPools[uniV3PoolAddress];
        require(initializedPools.length > 0, "NP");
        for (uint256 i = 0; i < initializedPools.length; i++) {
            IILOPool(initializedPools[i]).launch();
        }

        emit ProjectLaunch(uniV3PoolAddress);
    }
```

Example:

- project has an already circulating supply of its token and want to create another ILOPool with an existing or new uniswap pool.

- [code](https://github.com/code-423n4/2024-06-vultisig/blob/main/src/ILOManager.sol#L57): owner of project initializes uniswap pool ([if applicable](https://github.com/code-423n4/2024-06-vultisig/blob/main/src/ILOManager.sol#L61)) and project. ILOManager records uniswap [initial price](https://github.com/code-423n4/2024-06-vultisig/blob/main/src/ILOManager.sol#L142).

- [code](https://github.com/code-423n4/2024-06-vultisig/blob/main/src/ILOManager.sol#L72): owner initializes the ILOPool.

- [code](https://github.com/Uniswap/v3-core/blob/main/contracts/UniswapV3Pool.sol#L57-L58): Anyone makes any trade on the Uniswap pool, thus changing its price

- [code](https://github.com/code-423n4/2024-06-vultisig/blob/main/src/ILOManager.sol#L187): If price differs from ILOPool stored price on launch it will always [revert](https://github.com/code-423n4/2024-06-vultisig/blob/main/src/ILOManager.sol#L189-L190).

- Attacker can keep trading before the launch to avoid the uniswap pool price to match.

## Tools Used
Manual review

## Recommended Mitigation Steps

The launch should not depend or revert if the initial pool price is different. At least it should only revert if it's out of range, and range should be changeable by the admin of the project.
