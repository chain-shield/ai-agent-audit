# Vulnerability details

## Impact

All the pools cannot be launched because of one pool.

## Proof of Concept

When a protocol creates a project, he can create many pools for the project through `ILOManager.initILOPool()`. One reason for creating many pools for the ILO is to have different tick sizes or different hard/soft cap and start/end parameters.

The cloned pool address will be saved in the `_initializedILOPools` mapping.

```
        IILOPool.InitPoolParams memory initParams = IILOPool.InitPoolParams({
            uniV3Pool: params.uniV3Pool,
            tickLower: params.tickLower,
            tickUpper: params.tickUpper,
            sqrtRatioLowerX96: sqrtRatioLowerX96,
            sqrtRatioUpperX96: sqrtRatioUpperX96,
            hardCap: params.hardCap,
            softCap: params.softCap,
            maxCapPerUser: params.maxCapPerUser,
            start: params.start,
            end: params.end,
            vestingConfigs: params.vestingConfigs
        });
        IILOPool(iloPoolAddress).initialize(initParams);
>       _initializedILOPools[params.uniV3Pool].push(iloPoolAddress);
```

When it is time for the protocol to launch the pools, the admin will call `launch()`, and the function loops through all the pools that was created and attempt to launch the pool.

```
        for (uint256 i = 0; i < initializedPools.length; i++) {
>           IILOPool(initializedPools[i]).launch();
        }
```

In ILOPool, if there is a refund in one of the pool, the pool will not be able to launch. Since there is a loop, if one pool fails to launch, all the pool will fail to launch.

```
    function launch() external override OnlyManager() {
        require(!_launchSucceeded, "PL");
        // when refund triggered, we can not launch pool anymore
        require(!_refundTriggered, "IRF");
        // make sure that soft cap requirement match
        require(totalRaised >= saleInfo.softCap, "SC");
```

There are also other reasons for the failure to launch, such as the `totalRaised` being lesser than the `saleInfo.softCap`.

## Tools Used

Manual Review

## Recommended Mitigation Steps

Have a try/catch block when creating pools so that those pools which are ready for launch will be launched, and those pools which are not ready to launch will be able to get refunds.
