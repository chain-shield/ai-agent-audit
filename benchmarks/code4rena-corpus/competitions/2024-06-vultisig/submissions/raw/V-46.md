# Vulnerability details

## Impact
The provided documentation states the following:

```
There could be some suspicious actors so owner can add those addresses to the blacklist. In this case, the total whitelisted addresses will be whitelistCount - blacklistedCount. So owner can increase allowedWhitelistedIndex by blacklistedCount to make sure that always 1k whitelisted slots are secured.
```
However, this is prone to error since no count of blacklisted addresses is being used and no events are emitted. 

## Proof of Concept
Add this to the "Checkwhitelist" describe in Whitelist.ts:

```javascript
    it("Does not allow new whitelisted address when current whitelisted user is blacklisted", async function () {
      const { whitelist, mockOracleSuccess, pool, otherAccount, batchedAccount, mockContract } =
        await loadFixture(deployWhitelistFixture);
      await whitelist.setVultisig(mockContract);
      await whitelist.setLocked(false);
      await whitelist.setOracle(mockOracleSuccess);

      await whitelist.addBatchWhitelist([otherAccount, batchedAccount]);
      await whitelist.setAllowedWhitelistIndex(1);
      await whitelist.setBlacklisted(otherAccount, true);
      await expect(whitelist.connect(mockContract).checkWhitelist(pool, batchedAccount, 0)).to.be.revertedWithCustomError(
        whitelist,
        "NotWhitelisted",
      );
    });
```

## Recommended Mitigation Steps
Include the maximum total whitelisted addresses increase in the function `Whitelist::setBlacklisted`. If a user is already on the whitelist and is blacklisted, then the maximum amount should be extended in 1. If a user who was blacklisted is whitelisted again, the amount should be reduced in 1. Otherwise just set the flag to true or false:

```javascript
    function setBlacklisted(address blacklisted, bool flag) external onlyOwner {
        if (flag && _whitelistIndex[blacklisted] != 0) {
            _allowedWhitelistIndex++;
        } else if (
            _isBlacklisted[blacklisted] &&
            !flag &&
            _whitelistIndex[blacklisted] != 0
        ) {
            _allowedWhitelistIndex--;
        }
        _isBlacklisted[blacklisted] = flag; 
    }
```
