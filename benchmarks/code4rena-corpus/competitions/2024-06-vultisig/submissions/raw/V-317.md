# Vulnerability details

## Impact
In ChainId.sol the `get()` function should not be pure.

## Proof of Concept
The `pure` keyword shouldn't be there, since the function needs to interact with the blockchain to retrieve the `chainId`.
```Solidity
function get() internal pure returns (uint256 chainId) {
        assembly {
            chainId := chainid()
        }
    }
```

## Tools Used
Manual review
## Recommended Mitigation Steps
Consider removing the pure keyword from the function.
