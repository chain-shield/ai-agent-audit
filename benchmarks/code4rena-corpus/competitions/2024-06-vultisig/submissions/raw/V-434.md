# Vulnerability details

## Impact
The function `initProject` can be called by anyone. If the function is called once, it can't be called again with the same parameters(`saleToken`, `raiseToken`, `fee`). A malicious attacker can frontrun the call to this function and the contract `ILOManager` should be deployed again due to this vulnerability.

## Proof of Concept

The [initProject](https://github.com/code-423n4/2024-06-vultisig/blob/0957ff9e50441cd6de6b4f6e28c7ea93f5cffa85/src/ILOManager.sol#L57-L65) function is an external function and anybody can call this function.
This function first calculates `poolKey` and caches the project at L63.
```solidity
    function initProject(InitProjectParams calldata params) external override afterInitialize() returns(address uniV3PoolAddress) {
        uint64 refundDeadline = params.launchTime + DEFAULT_DEADLINE_OFFSET;

        uniV3PoolAddress = _initUniV3PoolIfNecessary(poolKey, params.initialPoolPriceX96);
        
63      _cacheProject(uniV3PoolAddress, params.saleToken, params.raiseToken, params.fee, params.initialPoolPriceX96, params.launchTime, refundDeadline);
        emit ProjectCreated(uniV3PoolAddress, _cachedProject[uniV3PoolAddress]);
    }
```
In the [_cacheProject](https://github.com/code-423n4/2024-06-vultisig/blob/0957ff9e50441cd6de6b4f6e28c7ea93f5cffa85/src/ILOManager.sol#L124-L147) function, it checks if `_project.uniV3PoolAddress` is `address(0)` or not at L134. If it is not `address(0)`, it reverts.
