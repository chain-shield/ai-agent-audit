# Vulnerability details

## Impact
Vultisig token has a whitelist functionality that applies a rule where a receiver should only be able to receive a pre-determined maximum amount of the token from the uniswap pool. However, the ILOPool contract is also a receiver of the uniswap pool and thus, the claim function will become DoSed once this limit is reached.

The checkWhitelist function will enforce the _maxAddressCap if the sender is the set uniswapV3 pool. This is done on every transfer done using the Vultisig token.

https://github.com/code-423n4/2024-06-vultisig/blob/main/hardhat-vultisig/contracts/Whitelist.sol#L204
```js
    function checkWhitelist(address from, address to, uint256 amount) external onlyVultisig {
        if (from == _pool && to != owner()) {
            // We only add limitations for buy actions via uniswap v3 pool
            // Still need to ignore WL check if it's owner related actions
            if (_locked) {
                revert Locked();
            }

            if (_isBlacklisted[to]) {
                revert Blacklisted();
            }

            if (_allowedWhitelistIndex == 0 || _whitelistIndex[to] > _allowedWhitelistIndex) {
                revert NotWhitelisted();
            }

            // // Calculate rough ETH amount for VULT amount
            uint256 estimatedETHAmount = IOracle(_oracle).peek(amount);
            if (_contributed[to] + estimatedETHAmount > _maxAddressCap) {
                revert MaxAddressCapOverflow();
            }

            _contributed[to] += estimatedETHAmount;
        }
    }
```

However, after token launch naturally some of the initial investors will want to claim their tokens. They will do this via the claim() function.

That function will burn the liquidity they wish to claim and then collect it via the collect function of uniV3.

https://github.com/code-423n4/2024-06-vultisig/blob/main/src/ILOPool.sol#L242
```js
    (uint128 amountCollected0, uint128 amountCollected1) = pool.collect(
        address(this),
        TICK_LOWER,
        TICK_UPPER,
        type(uint128).max,
        type(uint128).max
    );
```

The [collect function](https://github.com/Uniswap/v3-core/blob/main/contracts/UniswapV3Pool.sol#L490C1-L513C6) will trigger a transfer of tokens from the uniV3Pool to the ILOPool contract.

As such, the whitelist functionality will enforce the _maxAddressCap, and when any user reaches that cap his/her transction will revert and they will not be able to claim their funds.
