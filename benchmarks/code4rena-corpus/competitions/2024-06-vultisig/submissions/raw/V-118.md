# Vulnerability details

## Impact
Pool can never be launched and the tokens being raised can be locked until the pool receives enough tokens to launch or `refundDeadline` is met for the users to refund their tokens

## Proof of Concept

In the `ILOPool` in `launch()` the pool assumes it will have tokens as seen below

```solidity
            // actually deploy liquidity to uniswap pool
            (amount0, amount1) = addLiquidity(AddLiquidityParams({
                pool: IUniswapV3Pool(uniV3PoolAddress),
                liquidity: liquidity,
                amount0Desired: amount0,
                amount1Desired: amount1,
                amount0Min: amount0Min,
                amount1Min: amount1Min
            }));
```

However when deploying a pool from the `ILOManager` we never force the deployer to transfer tokens to the given pool.

## Tools Used

Manual Review

## Recommended Mitigation Steps

I recommend transferring the token being sold at the deployment of `ILOPool` this allows for the least amount of manual error possible and assures the user that the token is in the pool and ready to be sold.

```solidity
        {
            require(_project.uniV3PoolAddress != address(0), "NI");
            // validate time for sale start and end compared to launch time
            require(params.start < params.end && params.end < _project.launchTime, "PT");
            // this salt make sure that pool address can not be represented in any other chains
            bytes32 salt = keccak256(abi.encodePacked(
                ChainId.get(),
                params.uniV3Pool,
                _initializedILOPools[params.uniV3Pool].length
            ));
            iloPoolAddress = Clones.cloneDeterministic(ILO_POOL_IMPLEMENTATION, salt);
            TransferHelper.safeTransferFrom(_project.saleToken, msg.sender, iloPoolAddress, amountToBeSold); // Add this line to ensure pool has funds
            emit ILOPoolCreated(_project.uniV3PoolAddress, iloPoolAddress, _initializedILOPools[params.uniV3Pool].length);
        }
```
