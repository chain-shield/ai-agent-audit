# Vulnerability details

## Impact
There is no check which stops an user from buying liquidity after pool launch. Token send by user will be locked forever because user can't recover using claimRefund() because transaction will be reverted due to pool launch 
```solidity
  modifier refundable() {
        if (!_refundTriggered) {
            // if ilo pool is lauch sucessfully, we can not refund anymore
         --->   require(!_launchSucceeded, "PL");
            IILOManager.Project memory _project = IILOManager(MANAGER).project(_cachedUniV3PoolAddress);
            require(block.timestamp >= _project.refundDeadline, "RFT");

            _refundTriggered = true;
        }
        _;
    }
```
