# Vulnerability details

## Impact
Attacker can front-run `initProject()` by creating a Uniswap pool and `initialize()` a different `sqrtPriceX96` to cause launch to fail.

## Proof of Concept
The `initProject()` function initializes a project by setting up a Uniswap V3 pool using specified `saleToken`, `raiseToken`, and `fee` parameters. These tokens are essential for establishing a trading pair on the Uniswap pool. Notably, the `saleToken` is assumed to be non-publicly traded at the time of initialization. The function then utilizes `_initUniV3PoolIfNecessary()` to determine if the pool already exists. If not, it deploys a new Uniswap pool instance and initializes it with the desired initial price using `sqrtPriceX96`.

```solidity
    function _initUniV3PoolIfNecessary(PoolAddress.PoolKey memory poolKey, uint160 sqrtPriceX96) internal returns (address pool) {
        pool = IUniswapV3Factory(UNIV3_FACTORY).getPool(poolKey.token0, poolKey.token1, poolKey.fee);
        if (pool == address(0)) {
          ->pool = IUniswapV3Factory(UNIV3_FACTORY).createPool(poolKey.token0, poolKey.token1, poolKey.fee);
          ->IUniswapV3Pool(pool).initialize(sqrtPriceX96);
        } else {
            (uint160 sqrtPriceX96Existing, , , , , , ) = IUniswapV3Pool(pool).slot0();
            if (sqrtPriceX96Existing == 0) {
                IUniswapV3Pool(pool).initialize(sqrtPriceX96);
            } else {
                require(sqrtPriceX96Existing == sqrtPriceX96, "UV3P");
            }
        }
    }
```
It's important to note that anyone can `IUniswapV3Factory.createPool()` and `IUniswapV3Pool.initialize()`.

Attacker can take advantage of by front-running `initProject()` with the specific `saleToken`, `raiseToken` and `fee` tier. And they can immediately `initialize()` its initial price to be significantly different than project's intention. This will  likely cause project launch to fail, as all calculation rely on `SQRT_RATIO_X96`.

Consider following scenario:
`raiseToken` has fixed amount of total supply 100,000,000 1e18.
By `initialize()` `saleToken:raiseToken = 1e29:1`, there will never be enough `raiseToken` to successfully launch.
