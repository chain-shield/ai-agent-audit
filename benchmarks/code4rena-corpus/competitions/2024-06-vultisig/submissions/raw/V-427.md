# Vulnerability details

## Impact
Upgradeable contracts cannot use `ownable` instead they use `OwnableUpgradeable` 

## Proof of Concept
`contract ILOManager is IILOManager, Ownable, Initializable`

we can see that the contract is inheriting or using Openzeppelin's `Ownable` contract for access control but it is strongly recommended by openzeppelin to use `OwnableUpgradeable` for upgradeable contracts for maximum effectiveness.

## Tools Used
manual review
## Recommended Mitigation Steps
use `OwnerUpgradeable` instead

Upgradable
