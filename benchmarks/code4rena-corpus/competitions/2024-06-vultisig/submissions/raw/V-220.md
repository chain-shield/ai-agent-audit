# Vulnerability details

## Impact
High, unchecked transfer, funds might not move as intended

(src/base/PeripheryPayments.sol#21-38) In the `PeripheryPayments::pay` [Line:30] there is an unchecked transfer and its return value is ignored.

## Proof of Concept
To reproduce:
1. Deploy contracts
2. Call `PeripheryPayments::pay` from one of contracts which inherits `PeripheryPayments`, make sure that the token is `WETH9` and the balance of the contract is greater than the requested pay amount (address(this).balance >= value). Of course, the chance for the transfer to fail is low.

## Tools Used
Solidity

## Recommended Mitigation Steps
In the `PeripheryPayments::pay` make the following changes:

```solidity
-    IWETH9(WETH9).transfer(recipient, value);
+    bool success = IWETH9(WETH9).transfer(recipient, value);
+    require(success, "Error has occurred while transferring funds");
```
