# Vulnerability details

## Proof of Concept


Currently the `executeRecovery()` function is used so that the users would be able to finalize their recovery process. The problem is that the function uses `execTransactionFromModule()` with `DelegateCall` operation being set:

https://github.com/code-423n4/2024-10-kleidi/blob/main/src/RecoverySpell.sol#L306-314
```
   require(
            safe.execTransactionFromModule(
                MULTICALL3,
                0,
                abi.encodeWithSelector(IMulticall3.aggregate3.selector, calls3),
                Enum.Operation.DelegateCall
            ),
            "RecoverySpell: Recovery failed"
        );

```

However, in the `Guard` module, only `Call` operation is currently allowed:

https://github.com/code-423n4/2024-10-kleidi/blob/main/src/Guard.sol#L65-68
```
  require(
            operationType == Enum.Operation.Call,
            "Guard: delegate call disallowed"
        );


```

This will result in a transaction being blocked by the `Guard` module.

## Recommended Mitigation Steps

Change the functionality so that it does not use `DelegateCall`.
