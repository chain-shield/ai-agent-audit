# Vulnerability details

## Summary
The `executeWhitelisted()` and `executeWhitelistedBatch()` functions do not validate the `msg.value` to ensure that the `ether` sent with the call is the `ether` the caller intends to use. Because the contract can hold `ether` from other users (via the `receive()` function), a  caller could execute these functions without providing any ether of their own. 

This would allow them to consume ether already held in the contract from previous users.

**The Contract Holds Ether**:
The [`receive()`](https://github.com/code-423n4/2024-10-kleidi/blob/ab89bcb443249e1524496b694ddb19e298dca799/src/Timelock.sol#L1339-L1343) function allows the contract to receive and hold `ether` from any external source, including previous users or other contracts.
```solidity
    /// @dev Timelock can receive/hold ETH, emit an event when this happens for
    /// offchain tracking
    receive() external payable {
        emit NativeTokensReceived(msg.sender, msg.value);
    }
```
**No Validation of Ether Origin**:
These functions allow the caller to provide an arbitrary value (in the `value` parameter) to be sent to the `target` address, but they do not check if the caller has actually provided the required ether via `msg.value`. 
If the caller does not send enough `ether` with the transaction, the contract can still attempt to execute the transaction, drawing from `ether` already held in the contract from previous deposits via the `receive()` function.

## Recommended Mitigation Steps
Before executing any call, the contract should ensure that the caller has provided the correct amount of ether via `msg.value`. 
For `execute()`:
```diff
    // Ensure that msg.value matches the value being transferred
+   require(msg.value == value, "Insufficient msg.value");

    _execute(target, value, payload);
```

For `executeBatch()`:
```diff
    // Ensure that msg.value matches the total value being transferred
+   require(msg.value == totalValue, "Insufficient msg.value");

    for (uint256 i = 0; i < targets.length; i++) {
        bytes calldata payload = payloads[i];

        _execute(targets[i], values[i], payload);
        emit CallExecuted(id, i, targets[i], values[i], payload);
    }
```
