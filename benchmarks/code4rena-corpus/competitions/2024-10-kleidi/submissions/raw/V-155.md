# Vulnerability details


## Description

The `InstanceDeployer::createSystemInstance()` function does not enforce the user to set at least one `recoverySpell` as module of safe, during deployment. This means that, if the safe owners lose their private keys shortly after deployment, they will not have any recovery mechanism to use it, in order to recover the safe. Consequently, they would be forced to deploy a new safe and timelock, incurring additional gas fees, and they may even lose funds locked in the timelock contract if they have sent any.

## Impact

if the safe owners lose their private keys, they will lose access to their safe and will be unable to interact with timelock. This could result in the loss of funds stored in the timelock and additional costs to deploy new contracts. for this reason, `InstanceDeployer` should enforce the user to set atleast single Recovery Method for it's safe, in this case, is called `RecoverySpell`.

## Proof Of Concept

before the for loop where we set each recoverySpell address as safe module on [#L274-L291](https://github.com/solidity-labs-io/kleidi/blob/0d72b6cb5725c1380212dc76257da96fcfacf22f/src/InstanceDeployer.sol#L274-L291), we dont enforce the user to atleast set single Recovery Method for it's safe, meaning if the owners of safe lost their keys, they will have no way to recover it:

```javascript
    function createSystemInstance(NewInstance memory instance)
        external
        returns (SystemInstance memory walletInstance)
    {
            // ignore all codes before the for loop 


            // NOTE: Require Statement should exist here to ensure atleast single recovery method is
            //       set for safe, to make sure they have backup plan, if owners lost keys after deployment

            for (uint256 i = 0; i < instance.recoverySpells.length; i++) {
                calls3[index++].callData = abi.encodeWithSelector(
                    ModuleManager.enableModule.selector,
                    instance.recoverySpells[i]
                );
            }

            // ignore rest of the code
    }
```

## Recommended Mitigation

Add a check to ensure that at least one `recoverySpell` is provided inside `InstanceDeployer::createSystemInstance()` function:

```diff
    function createSystemInstance(NewInstance memory instance)
        external
        returns (SystemInstance memory walletInstance)
    {

        // ignore codes before the line below


+           require(instance.recoverySpells.length > 0, "InstanceDeployer: At least one recovery spell is required");
            for (uint256 i = 0; i < instance.recoverySpells.length; i++) {
                calls3[index++].callData = abi.encodeWithSelector(
                    ModuleManager.enableModule.selector,
                    instance.recoverySpells[i]
                );
            }
        }


        // ignore rest of the code
    }

```
