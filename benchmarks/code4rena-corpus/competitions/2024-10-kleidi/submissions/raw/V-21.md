# Vulnerability details

## Proof of Concept
A vulnerability exists in the `RecoverySpellFactory` contract where the `recoveryThreshold` parameter is not adequately checked to ensure it is greater than zero. This omission could allow the `recoveryThreshold` to be set to 0, meaning that the recovery process could be executed without requiring any owner signatures, leading to unauthorized control of the `Safe` contract.

The `RecoverySpellFactory` contract deploys instances of `RecoverySpell` contracts. These recovery spells can be used to recover ownership of a `Safe` contract, provided that a sufficient number of signatures are obtained. The number of signatures required for recovery is controlled by the `recoveryThreshold` parameter. However, the contract currently lacks a check to ensure that `recoveryThreshold` is greater than 0.

The missing check allows for a scenario where `recoveryThreshold` is set to 0, meaning that no signatures are required for recovery. In such a case, anyone could potentially trigger the recovery process without requiring the consent of any owners, leading to unauthorized control over the `Safe` contract.

The vulnerability lies in the `_paramChecks` function in the `RecoverySpellFactory` contract, where the validation for `recoveryThreshold` does not ensure that it is greater than zero.
https://github.com/code-423n4/2024-10-kleidi/blob/ab89bcb443249e1524496b694ddb19e298dca799/src/RecoverySpellFactory.sol#L118-L138
```solidity
function _paramChecks(
    address[] memory owners,
    uint256 threshold,
    uint256 recoveryThreshold,
    uint256 delay
) private pure {
    require(
        threshold <= owners.length,
        "RecoverySpell: Threshold must be lte number of owners"
    );
    require(
        recoveryThreshold <= owners.length,
        "RecoverySpell: Recovery threshold must be lte number of owners"
    );
    // MISSING CHECK: recoveryThreshold > 0
    require(threshold != 0, "RecoverySpell: Threshold must be gt 0");
    require(delay <= 365 days, "RecoverySpell: Delay must be lte a year");
    for (uint256 i = 0; i < owners.length; i++) {
        require(owners[i] != address(0), "RecoverySpell: Owner cannot be 0");
    }
}
```

The absence of a boundary check on `recoveryThreshold` allows it to be set to 0, which means the recovery process can be executed without any signatures. This could lead to unauthorized and malicious recoveries of `Safe` contracts, potentially leading to asset theft or control over sensitive contracts.

## Recommended Mitigation Steps
To prevent this vulnerability, a boundary check should be added in the `_paramChecks` function to ensure that the `recoveryThreshold` is greater than zero:
```solidity
require(recoveryThreshold > 0, "RecoverySpell: Recovery threshold must be gt 0");
```
