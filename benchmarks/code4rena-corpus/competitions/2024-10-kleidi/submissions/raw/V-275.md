# Vulnerability details

## Proof of Concept
On `Timelock.sol` `revokeHotSigner` function should only be called by the timelock or the safe.
I indicated the point.
[On this line on source code, github](https://github.com/code-423n4/2024-10-kleidi/blob/main/src/Timelock.sol#L800)

```solidity

    /// @notice function to revoke the hot signer role from an address
👉 /// can only be called by the timelock or the safe
    /// @param deprecatedHotSigner the address of the hot signer to revoke
    function revokeHotSigner(address deprecatedHotSigner) external onlySafe {
        _revokeRole(HOT_SIGNER_ROLE, deprecatedHotSigner);
    }

```

But it can only be called by `the safe`, because of the `onlySafe` modifier. 

Calling it with `the timelock` in `testRevokeHotSignerFailsNotSafe` function will fail.

if we call it with `the timelock` it will fail like this test.

```diff
     function testRevokeHotSignerFailsNotSafe() public {
+        vm.prank(address(timelock));
         vm.expectRevert("Timelock: caller is not the safe");
         timelock.revokeHotSigner(address(this));
     }
```

## Recommended Mitigation Steps
To make sure that it can only be called by the timelock or the safe follow those steps.

* create a modifier on the `Timelock.sol`, so that it can be called by the safe or the timelock.

```solidity
    modifier onlyTimelockOrSafe() {
        require(
            msg.sender == safe || msg.sender == address(this),
            "Timelock: caller is not the timelock or the safe"
        );
        _;
    }
```

* add the modifier to the `Timelock.sol`'s `revokeHotSigner` function and make it `public`.

```diff
    /// @notice function to revoke the hot signer role from an address
    /// can only be called by the timelock or the safe
    /// @param deprecatedHotSigner the address of the hot signer to revoke
-   function revokeHotSigner(address deprecatedHotSigner) external onlySafe {
+   function revokeHotSigner(address deprecatedHotSigner) public onlyTimelockOrSafe {
        _revokeRole(HOT_SIGNER_ROLE, deprecatedHotSigner);
    }
```

* add the following test function on `Timelock.t.sol` after `testRevokeHotSignerSafeSucceeds` function.

```solidity
    function testRevokeHotSignerTimeLockSucceeds() public {
        vm.prank(address(timelock));
        timelock.revokeHotSigner(HOT_SIGNER_ONE);

        vm.prank(address(timelock));
        timelock.revokeHotSigner(HOT_SIGNER_TWO);

        vm.prank(address(timelock));
        timelock.revokeHotSigner(HOT_SIGNER_THREE);

        assertFalse(
            timelock.hasRole(timelock.HOT_SIGNER_ROLE(), HOT_SIGNER_ONE),
            "Hot signer one should have role revoked"
        );
        assertFalse(
            timelock.hasRole(timelock.HOT_SIGNER_ROLE(), HOT_SIGNER_TWO),
            "Hot signer two should have role revoked"
        );
        assertFalse(
            timelock.hasRole(timelock.HOT_SIGNER_ROLE(), HOT_SIGNER_THREE),
            "Hot signer three should have role revoked"
        );
    }
```

* also do not foget to update the `testRevokeHotSignerFailsNotSafe` function.
