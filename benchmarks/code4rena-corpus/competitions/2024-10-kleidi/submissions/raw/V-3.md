# Vulnerability details

## Vulnerability Details

The `_updatePauseDuration` function updates the pause duration without verifying if the contract is in a paused state. While the function is meant to be called when the contract is unpaused, it lacks explicit enforcement of this condition. This omission could lead to unintended behavior, such as resetting the `pauseStartTime` while the contract is paused, effectively unpausing it unintentionally.

## Impact
The contract can be unintentionally unpaused if `_updatePauseDuration` is called while the contract is paused, allowing bypass of the enforced pause period.

## Proof of Concept

1. Assume the contract is paused, with a valid `pauseStartTime` and `pauseDuration`.
2. If this function is called while the contract is paused, the following behavior occurs:
   - The `pauseStartTime` is reset to 0.
   - The contract becomes unpaused unexpectedly.

## Recommended Mitigation Steps

Enforce a check to ensure that `_updatePauseDuration` is only called when the contract is unpaused. This can be achieved by using the `whenNotPaused` modifier or adding an explicit validation check.

**Fix using `whenNotPaused` modifier:**

```solidity
                                                                     
function _updatePauseDuration(uint128 newPauseDuration) internal whenNotPaused {
    require(
        newPauseDuration >= MIN_PAUSE_DURATION
            && newPauseDuration <= MAX_PAUSE_DURATION,
        "ConfigurablePause: pause duration out of bounds"
    );

    uint256 oldPauseDuration = pauseDuration;
    pauseDuration = newPauseDuration;

    emit PauseDurationUpdated(oldPauseDuration, pauseDuration);
}
```

**Fix with explicit pause check:**

```solidity
function _updatePauseDuration(uint128 newPauseDuration) internal {
(+) require(!paused(), "ConfigurablePause: contract is paused");
    require(
        newPauseDuration >= MIN_PAUSE_DURATION
            && newPauseDuration <= MAX_PAUSE_DURATION,
        "ConfigurablePause: pause duration out of bounds"
    );

    uint256 oldPauseDuration = pauseDuration;
    pauseDuration = newPauseDuration;

    emit PauseDurationUpdated(oldPauseDuration, pauseDuration);
}
```
