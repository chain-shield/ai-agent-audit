# Vulnerability details

## Description

The `createRecoverySpell` function in the `RecoverySpellFactory` contract aims to create new `RecoverySpell` contracts with a set of owners, a safe address, and other parameters. It includes a check to prevent duplicate owners in the `owners` array. However, this check has a flaw.

The duplicate owner check uses an assembly block with transient storage to mark encountered owners. While this approach works in most cases, it fails when the `owners` array contains the address of the `RecoverySpellFactory` contract itself. This is because the transient storage slot used for marking owners is also used by the factory contract's own code, leading to an incorrect duplicate detection.

## Vulnerable Code Snippet

```solidity
assembly ("memory-safe") {
    found := tload(owner)
    if eq(found, 0) { tstore(owner, 1) }
}
```

## Impact

This bug allows the creation of a `RecoverySpell` contract with duplicate owners if one of the owners is the `RecoverySpellFactory` contract itself. This can lead to unexpected behavior and potential security vulnerabilities, as the duplicate owner might have more influence in the recovery process than intended.

## Scenario

1. An attacker calls `createRecoverySpell` with an `owners` array that includes the address of the `RecoverySpellFactory` contract multiple times.
2. The duplicate owner check fails to detect the duplicates due to the transient storage collision.
3. A `RecoverySpell` contract is created with duplicate owners, granting the attacker more control over the recovery process.

## Fix

To fix this issue, the duplicate owner check should use a different mechanism that doesn't rely on transient storage that can be influenced by the input data. One option is to use a mapping in memory to track encountered owners:

```solidity
mapping(address => bool) seen;
for (uint256 i = 0; i < owners.length; i++) {
    require(!seen[owners[i]], "RecoverySpell: Duplicate owner");
    seen[owners[i]] = true;
}
```

## Test

```solidity
// SPDX-License-Identifier: MIT
pragma solidity 0.8.25;

import {Test} from "forge-std/Test.sol";
import {RecoverySpellFactory} from "../src/RecoverySpellFactory.sol";
import {RecoverySpell} from "../src/RecoverySpell.sol";

contract RecoverySpellFactoryTest is Test {
    RecoverySpellFactory factory;
    address mockSafe;
    
    function setUp() public {
        factory = new RecoverySpellFactory();
        mockSafe = makeAddr("safe");
        // Deploy mock safe with some code
        vm.asm("PUSH1 0x01 PUSH1 0x00 MSTORE");
        bytes memory code = vm.getCode("TestContract");
        vm.etch(mockSafe, code);
    }

    function testCollisionWithFactoryAddress() public {
        // Create owners array with factory address
        address[] memory owners = new address[](3);
        owners[0] = makeAddr("owner1");
        owners[1] = address(factory);  // Factory address
        owners[2] = address(factory);  // Duplicate factory address

        // This should revert but might not due to transient storage collision
        vm.expectRevert("RecoverySpell: Duplicate owner");
        factory.createRecoverySpell(
            bytes32(uint256(1)),
            owners,
            mockSafe,
            2,  // threshold
            1,  // recoveryThreshold
            1 days  // delay
        );
    }

    function testCollisionWithContractInteraction() public {
        // Create a contract that uses transient storage
        TransientStorageUser tUser = new TransientStorageUser();
        
        address[] memory owners = new address[](2);
        owners[0] = address(tUser);
        owners[1] = address(tUser);  // Duplicate address

        vm.expectRevert("RecoverySpell: Duplicate owner");
        factory.createRecoverySpell(
            bytes32(uint256(1)),
            owners,
            mockSafe,
            1,
            1,
            0
        );
    }
}

// Contract that uses transient storage
contract TransientStorageUser {
    constructor() {
        assembly {
            tstore(address(), 0)  // Use own address as transient storage key
        }
    }
}
```
