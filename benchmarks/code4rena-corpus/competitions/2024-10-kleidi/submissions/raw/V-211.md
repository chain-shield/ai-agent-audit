# Vulnerability details

## Proof of Concept
The [`grantRole`](https://github.com/code-423n4/2024-10-kleidi/blob/ab89bcb443249e1524496b694ddb19e298dca799/src/Timelock.sol#L759-L769) and [`revokeRole`](https://github.com/code-423n4/2024-10-kleidi/blob/ab89bcb443249e1524496b694ddb19e298dca799/src/Timelock.sol#L771-L782) functions in the Timelock contract are intended to use the OpenZeppelin AccessControl's built-in role-based access control. However, the current implementations do not correctly implement this:

```solidity
    function grantRole(bytes32 role, address account)
        public
        override(AccessControl, IAccessControl)
    {
        require(role != DEFAULT_ADMIN_ROLE, "Timelock: cannot grant admin role");
        super.grantRole(role, account);
    }
```

```solidity
    function grantRole(bytes32 role, address account)
        public
        override(AccessControl, IAccessControl)
    {
        require(role != DEFAULT_ADMIN_ROLE, "Timelock: cannot grant admin role");
        super.grantRole(role, account);
    }
```
These functions are missing the `onlyRole(getRoleAdmin(role))` modifier, which is crucial for enforcing that only accounts with the admin role for a given role can grant or revoke that role.
The current implementation allows any account to call these functions (subject only to the `DEFAULT_ADMIN_ROLE` check), which could lead to unauthorized role assignments or revocations.

## Recommended Mitigation Steps
To address this issue, add the `onlyRole(getRoleAdmin(role))` modifier to both functions:
```diff
    function grantRole(bytes32 role, address account)
        public
        override(AccessControl, IAccessControl)
+       onlyRole(getRoleAdmin(role))
        
    {
        require(role != DEFAULT_ADMIN_ROLE, "Timelock: cannot grant admin role");
        super.grantRole(role, account);
    }
```
```diff
    function grantRole(bytes32 role, address account)
        public
        override(AccessControl, IAccessControl)
+       onlyRole(getRoleAdmin(role))
    {
        require(role != DEFAULT_ADMIN_ROLE, "Timelock: cannot grant admin role");
        super.grantRole(role, account);
    }
```
