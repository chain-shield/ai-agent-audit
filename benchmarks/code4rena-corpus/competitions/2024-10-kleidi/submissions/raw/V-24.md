# Vulnerability details

## Impact
The time-lock contract is missing the onlySafe modifier on the execute function. So, a malicious caller can call the Timelock.execute() function which is payable.

### Vulnerable Code
```Solidity
// https://github.com/code-423n4/2024-10-kleidi/blob/ab89bcb443249e1524496b694ddb19e298dca799/src/Timelock.sol#L589-L609

    function execute(
        address target,
        uint256 value,
        bytes calldata payload,
        bytes32 salt
    ) external payable whenNotPaused {
        bytes32 id = hashOperation(target, value, payload, salt);


        /// first reentrancy check, impossible to reenter and execute the same
        /// proposal twice
        require(_liveProposals.remove(id), "Timelock: proposal does not exist");
        require(isOperationReady(id), "Timelock: operation is not ready");


        _execute(target, value, payload);
        emit CallExecuted(id, 0, target, value, payload);


        /// second reentrancy check, second check that operation is ready,
        /// operation will be not ready if already executed as timestamp will
        /// be set to 1
        _afterCall(id);
    }
```

## Recommended Mitigation Steps
Add the onlySafe modifier to the execute function.
```Solidity
    function execute(
        address target,
        uint256 value,
        bytes calldata payload,
        bytes32 salt
    ) external payable whenNotPaused onlySafe {
```
