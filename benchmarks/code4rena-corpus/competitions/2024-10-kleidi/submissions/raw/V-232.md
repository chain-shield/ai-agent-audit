# Vulnerability details

## Proof of Concept
In InstanceDeployer.createSystemInstance(), the external call to SafeProxyFactory.createProxyWithNonce() is made before emitting the SafeCreationFailed() event in case of failure. This allows a reentrancy attack to manipulate the logic, leading to incorrect failure reporting.

### Impact
A reentrancy attack could result in inconsistent or incorrect event reporting, leaving failed system instance creations undetected or incorrectly reported, which can affect system auditability and integrity.

### Code Snippet

'''solidity

safeProxy = SafeProxyFactory(safeProxyFactory).createProxyWithNonce(...);
if (failure) {
    emit SafeCreationFailed(...); // Event emitted after external call
}
'''

## Recommended Mitigation Steps
Emit failure-related events before making external calls or use a reentrancy guard to ensure no manipulation can occur between the call and the event emission.



## Assessed type

Reentrancy
