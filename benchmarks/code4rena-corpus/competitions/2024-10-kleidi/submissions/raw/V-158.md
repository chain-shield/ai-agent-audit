# Vulnerability details

## Proof of Concept
The [`getSlicedBytesHash`](https://github.com/code-423n4/2024-10-kleidi/blob/ab89bcb443249e1524496b694ddb19e298dca799/src/BytesHelper.sol#L61-L67) function currently does not perform a check to ensure that the `start` index is less than the `end` index when slicing a byte array. This omission can lead to unexpected behavior, including the return of invalid byte slice if `start` is greater than or equal to `end`.
```solidity
    function getSlicedBytesHash(
        bytes memory toSlice,
        uint256 start,
        uint256 end
    ) public pure returns (bytes32) { 
        return keccak256(sliceBytes(toSlice, start, end));
    }
```

The function does not include a check to ensure that `startIndex < endIndex`.

## Recommended Mitigation Steps
To ensure proper functioning, a validation should be added in the `getSlicedBytesHash` function to check that the `start` index is strictly less than the `end` index, preventing invalid slices from being processed.
