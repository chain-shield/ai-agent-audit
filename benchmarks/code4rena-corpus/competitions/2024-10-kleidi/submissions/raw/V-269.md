# Vulnerability details

## Summary
in `AddressCalculation.sol`, `.code.length` is used to check that the recovery spell address,safe and timelock instance have no bytecode, to prevent deploying to an address that already has a contract.
however there are instances where there may be a contract at the said address. 
OpenZeppelin gives some insight to this

https://docs.openzeppelin.com/contracts/2.x/api/utils
https://github.com/OpenZeppelin/openzeppelin-contracts/blob/a5445b0afb8b350417b6e6ab3160554967bc151f/contracts/utils/Address.sol#L13C6-L39

## possible implications
1. Contracts in Construction 
as noted in the OpenZeppelin will return 0 on `address.code.length` for contracts that are currently being constructed.A malicious actor contract can watch the mempool during when the original contract transaction is being deployed and plan the process of deployment of his malicious contract such that `address.code.length` will return 0.
 
2. i.An attacker can also deploy a contract to the deterministic address, 
ii.then call selfdestruct to remove its bytecode from an address of which  `address.code.length=0` will pass 
 iii. they would then deploy their malicious contract.

3. Short Address Attack: an attacker can a transaction with a shortened address (less than 20 bytes), and solidity pads it. `calculateAddress` does not validate that addresses are exactly 20 bytes long, an attacker could send a transaction that manipulates which address is being referenced, potentially leading to unintended interactions.
Example: An attacker could send a transaction with a 19-byte address, which gets padded and interpreted as a valid 20-byte address, leading to unexpected behavior in `calculateAddress`.

## possible mitigations
-consider deployment in a private mempool
 -use bytes20 data type for addresses in function parameters to enforce strict fixed-length checks to mitigate short address attacks
 -check that address is not only empty but also has not been used for any critical operations (e.g being registered in a mapping of known addresses).
