# Vulnerability details

_addCalldataCheck function get called for adding a calldata check, the issue lies in the if statement under _addCalldataCheck , which is only check if length is 1.
```
 if (listLength == 1) {
            require(
                calldataChecks[0].startIndex != calldataChecks[0].endIndex,
                "CalldataList: Cannot add check with wildcard"
            );
```

the above check might get easily bypassed unwillingly and of no use, when the _calldataList.length is greater than 1, which makes the check for calldataChecks at 0 index for start and end Index completely skip that could make the operation under _addCalldataCheck to occur when start and end Index are same for calldataChecks.

The issue is likely to occur because their could be more than 1 Indexes that are already get registered and making it more open to completely skip this check.

Recommendation:
---   if (listLength == 1) {
            require(
                calldataChecks[0].startIndex != calldataChecks[0].endIndex,
                "CalldataList: Cannot add check with wildcard"
            );
+++    if (listLength >= 1) {
            require(
                calldataChecks[0].startIndex != calldataChecks[0].endIndex,
                "CalldataList: Cannot add check with wildcard"
            );
```
