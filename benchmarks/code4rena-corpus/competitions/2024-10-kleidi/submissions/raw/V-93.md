# Vulnerability details

## Proof of Concept
`isOperationExpired` function does not properly check if an operation exists in the `_liveProposals` set before determining if it has expired. As a result, operations that have been removed from `_liveProposals` (e.g., due to execution or cancellation) but still have a non-zero timestamp can be incorrectly identified as expired and cleaned up before their intended expiration time.

The root cause is the `isOperationExpired` function. It only checks if the timestamp is non-zero and not equal to one, but it doesn't verify if the operation exists in the `_liveProposals` set. This incomplete check allows for a scenario where an operation can be considered expired even if it's not in the live proposals set.

In the `cleanup` function, we rely solely on the `isOperationExpired` check to determine if an operation can be cleaned up. However, this check is insufficient because it doesn't account for the operation's actual presence in the `_liveProposals` set.

function isOperationExpired(bytes32 id) public view returns (bool) {
    uint256 timestamp = timestamps[id];

    require(timestamp != 0, "Timelock: operation non-existent");
    require(timestamp != 1, "Timelock: operation already executed");

    return block.timestamp >= timestamp + expirationPeriod; // <@Audit: Incorrect expiration check
}

function cleanup(bytes32 id) external whenNotPaused {
    require(isOperationExpired(id), "Timelock: operation not expired"); // <@Audit: Relies on faulty isOperationExpired

    emit Cleanup(id);
}

## Recommended Mitigation Steps
The `isOperationExpired` function to properly check if an operation exists in the `_liveProposals` set
```diff
function isOperationExpired(bytes32 id) public view returns (bool) {
    uint256 timestamp = timestamps[id];

-   require(timestamp != 0, "Timelock: operation non-existent");
-   require(timestamp != 1, "Timelock: operation already executed");

+   if (timestamp == 0 || timestamp == 1 || !_liveProposals.contains(id)) {
+       return false;
+   }

    return block.timestamp >= timestamp + expirationPeriod;
}
```
Update the `cleanup` function to double-check if the operation exists in `_liveProposals`
```diff
function cleanup(bytes32 id) external whenNotPaused {
    require(isOperationExpired(id), "Timelock: operation not expired");
+   require(_liveProposals.contains(id), "Timelock: operation not in live proposals");
    assert(_liveProposals.remove(id));

    emit Cleanup(id);
}
```
