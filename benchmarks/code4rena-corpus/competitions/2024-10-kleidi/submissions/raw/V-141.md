|[M-01] | Avoid using 'abi.encodepacked()' with Dynamic Types | 2 |



Details 
|[M-01] | Avoid using 'abi.encodepacked' with Dynamic Types; The function `calculateCreate2Address` in the 'Create2Helper.sol' uses 'abi.encodepacked' with dynamic type when passing the results to a function, Using abi.encodePacked() with more than one dynamic type  like bytes can result in hash collisions when not critically validated, This is because the length of these dynamic types can vary, and not validating the length, can result in different inputs producing the same byte array and, consequently, the same hash. This can lead to address collisions and other unexpected behavior.

Impact: 
Risk of Collision, Variable Gas consumption.

Tool Used: Manual Review

Recommendation: if need be to encode multiple dynamic types in a hash function, use 'abi.encode()' instead. Also the use of unique identifiers in the encoded data can reduce the likelihood of collisions.
