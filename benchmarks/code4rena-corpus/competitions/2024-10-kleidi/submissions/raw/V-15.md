# Vulnerability details

## Proof of Concept

The expiration time is calculated using variable parameter of expiration period as follows:

```solidity
    function isOperationExpired(bytes32 id) public view returns (bool) {
        /// if operation is done, save an extra SLOAD
        uint256 timestamp = timestamps[id];

        /// if timestamp is 0, the operation is not scheduled, revert
        require(timestamp != 0, "Timelock: operation non-existent");
        require(timestamp != 1, "Timelock: operation already executed");

        return block.timestamp >= timestamp + expirationPeriod;
    }
```

This expiration period is updatable parameter and it can make any expired execution request ready for execution later. 

```solidity
    function updateExpirationPeriod(uint256 newPeriod) external onlyTimelock {
        require(newPeriod >= MIN_DELAY, "Timelock: delay out of bounds");

        emit ExpirationPeriodChange(expirationPeriod, newPeriod);
        expirationPeriod = newPeriod;
    }
```

## Impact

It can cause unexpected execution behaviours because of timing issues. There are many timing operations in the contract. 

### Possible Scenario

Delay of execution: 7 days
Expiration period: 3 days

Let say we have some scheduled operations which are expired 4 days before. User can ignore those operations because they're expired and can't be executed anyway and user didn't clean them from live proposals. 

Cold signers schedule an update on expiration period from 3 days to 14 days. After 7 days, the expiration period can upgradable to 14 days. Now, our previous scheduled executions are 11 days ago. 

In conclusion, these expired scheduled operations can be executed right now due to variable expiration period.

These operations can be safe on day X but it doesn't mean it's still safe after 11 days. These operations can be executed immediately after updating the expiration period by anyone. 

## Recommended Mitigation Steps

Calculate the expiration timestamp while scheduling it and check this timestamp in `isOperationExpired()` function.
