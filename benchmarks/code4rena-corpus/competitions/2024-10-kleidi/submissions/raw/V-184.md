# Vulnerability details

## Proof of Concept
https://github.com/code-423n4/2024-10-kleidi/blob/main/src/TimelockFactory.sol#L37-L55
```solidity
    function createTimelock(address safe, DeploymentParams memory params)
        external
        returns (address timelock)
    {
        timelock = address(
            new Timelock{
                salt: keccak256(abi.encodePacked(params.salt, msg.sender))
            }(
                safe,
                params.minDelay,
                params.expirationPeriod,
                params.pauser,
                params.pauseDuration,
                params.hotSigners
            )
        );

        emit TimelockCreated(timelock, block.timestamp, msg.sender);
    }
```
According to the project's documentation requirements, this contract will be deployed on different chains (including l2). When deploying a contract with create2, the address is predictable because it is generated based on specific inputs (sender_address, salt, bytecode). If you use the same salt and the same bytecode on different chains, and the deployer's address (msg.sender) is also the same, the same contract address will be generated on different chains, which will cause problems when crossing chains. If the same contract address is generated on chain A and chain B, but the deployed contract logic or functions are different, it may cause incorrect interactions and even affect the function of the contract.

## Recommended Mitigation Steps
1. Introduce chainId: Use assembly code to get the chainId of the current chain.
2. Update the calculation method of salt: Based on the existing params.salt, chainId and msg.sender are included in the hash calculation.
```solidity
function createTimelock(address safe, DeploymentParams memory params)
    external
    returns (address timelock)
{
    uint256 chainId;
    assembly {
        chainId := chainid()
    }

    bytes32 computedSalt = keccak256(abi.encodePacked(params.salt, chainId, msg.sender));

    timelock = address(
        new Timelock{salt: computedSalt}(
            safe,
            params.minDelay,
            params.expirationPeriod,
            params.pauser,
            params.pauseDuration,
            params.hotSigners
        )
    );

    emit TimelockCreated(timelock, block.timestamp, msg.sender);
}
```
