# Vulnerability details

## Proof of Concept
The function [`_grantGuardian`](https://github.com/code-423n4/2024-10-kleidi/blob/ab89bcb443249e1524496b694ddb19e298dca799/src/ConfigurablePause.sol#L134-L139) allows the assignment of a new `pauseGuardian`. However, this function does not restrict access to the contract owner, which poses a significant security risk. Without an `onlyOwner` modifier, any entity that has access to the function (whether inadvertently or maliciously) could assign themselves or another arbitrary address as the `pauseGuardian`.

Here’s the current implementation of `_grantGuardian`
```solidity
    function _grantGuardian(address newPauseGuardian) internal { 
        address previousPauseGuardian = pauseGuardian;
        pauseGuardian = newPauseGuardian;

        emit PauseGuardianUpdated(previousPauseGuardian, newPauseGuardian);
    }
```
In the current implementation, there are no checks to ensure that only the contract owner can call this function, meaning that it could potentially be executed by any authorized account with internal access. This could lead to scenarios where a malicious actor assigns themselves as the `pauseGuardian` and abuses the pause functionality, affecting the stability and functionality of the contract.

Scenario:
An attacker who manages to gain internal access to the contract could call `_grantGuardian` without any ownership restriction.
The attacker assigns themselves as the `pauseGuardian`.
The attacker now has the ability to pause the contract at will by calling the `pause()` function, potentially causing disruption to contract operations.
This action could be particularly damaging in systems reliant on continuous contract functionality, such as DeFi protocols or time-sensitive applications.

## Recommended Mitigation Steps
To mitigate this risk, restrict access to the `_grantGuardian` function to only the contract owner by adding an `onlyOwner` modifier. This will ensure that only the owner of the contract can assign or update the `pauseGuardian`, maintaining control over the key functionality of the contract.

```diff
+   function _grantGuardian(address newPauseGuardian) internal onlyOwner  { 
        address previousPauseGuardian = pauseGuardian;
        pauseGuardian = newPauseGuardian;

        emit PauseGuardianUpdated(previousPauseGuardian, newPauseGuardian);
    }
```
