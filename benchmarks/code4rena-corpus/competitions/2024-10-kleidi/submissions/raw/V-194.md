# Vulnerability details

## Proof of Concept
The sliceBytes function does not enforce a maximum length on the input byte string, which may lead to potential denial-of-service (DoS) vulnerabilities. An attacker could supply an excessively large byte array, causing high gas consumption and possibly resulting in transaction failures. Implementing a maximum length restriction for the toSlice parameter is necessary to mitigate this risk and enhance the function’s security.
https://github.com/code-423n4/2024-10-kleidi/blob/main/src/BytesHelper.sol#L35-L58
```solidity
    function sliceBytes(bytes memory toSlice, uint256 start, uint256 end)
        public
        pure
        returns (bytes memory)
    {
        require(
            start < toSlice.length,
            "Start index is greater than the length of the byte string"
        );
        require(
            end <= toSlice.length,
            "End index is greater than the length of the byte string"
        );
        require(start < end, "Start index not less than end index");

        uint256 length = end - start;
        bytes memory sliced = new bytes(length);

        for (uint256 i = 0; i < length; i++) {
            sliced[i] = toSlice[i + start];
        }

        return sliced;
    }
```
Any type that satisfies bytes memory toSlice can call the sliceBytes function, but there is no limit on the length of toSlice in the sliceBytes function, which will lead to excessive gas consumption. Since BytesHelper is a library contract, it means that it will be widely used by any user, which is a dangerous problem.

## Recommended Mitigation Steps
You can add a length restriction to toSlice in the sliceBytes function, such as setting a maximum length. Here is a simple implementation example:
```solidity
function sliceBytes(bytes memory toSlice, uint256 start, uint256 end)
    public
    pure
    returns (bytes memory)
{
    uint256 maxLength = (Set a maximum value); 

    require(toSlice.length <= maxLength, "Byte string exceeds maximum length");
    require(start < toSlice.length, "Start index is greater than the length of the byte string");
    require(end <= toSlice.length, "End index is greater than the length of the byte string");
    require(start < end, "Start index not less than end index");

    uint256 length = end - start;
    bytes memory sliced = new bytes(length);

    for (uint256 i = 0; i < length; i++) {
        sliced[i] = toSlice[i + start];
    }

    return sliced;
}
```
