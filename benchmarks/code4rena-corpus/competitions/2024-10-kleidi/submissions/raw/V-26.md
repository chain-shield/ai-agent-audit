# Vulnerability details

## Proof of Concept
The [`cleanup()`](https://github.com/code-423n4/2024-10-kleidi/blob/ab89bcb443249e1524496b694ddb19e298dca799/src/Timelock.sol#L671-L677) function is designed to remove expired timelock operations by asserting that the proposal is removed from the `_liveProposals` set. However, it fails to properly clear all state associated with the operation, specifically the entry in the `timestamps` mapping.
```solidity
    function cleanup(bytes32 id) external whenNotPaused {
        require(isOperationExpired(id), "Timelock: operation not expired");
        assert(_liveProposals.remove(id));   // Only removes from _liveProposals
        emit Cleanup(id);
    }
```
In contrast, the [`cancel()`](https://github.com/code-423n4/2024-10-kleidi/blob/ab89bcb443249e1524496b694ddb19e298dca799/src/Timelock.sol#L659-L663) and [`pause()`](https://github.com/code-423n4/2024-10-kleidi/blob/ab89bcb443249e1524496b694ddb19e298dca799/src/Timelock.sol#L695-L696) functions ensure both the `_liveProposals` and timestamps mappings are properly cleared:
```solidity
    function cancel(bytes32 id) external onlySafe whenNotPaused {
        require(isOperation(id) && _liveProposals.remove(id), "Timelock: operation does not exist");
        delete timestamps[id];   // Clears the timestamp mapping
        emit Cancelled(id);
    }

    function pause() public override {
        super.pause();
        bytes32[] memory proposals = _liveProposals.values();
        for (uint256 i = 0; i < proposals.length; i++) {
            bytes32 id = proposals[i];
            delete timestamps[id];   // Clears the timestamp mapping
            assert(_liveProposals.remove(id));
            emit Cancelled(id);
        }
    }
```
## Impact
Residual State in timestamps Mapping:
- After a timelock operation is cleaned up, its associated entry in `timestamps` is not removed. 

## Recommended Mitigation Steps
To fully clean up expired operations, the `cleanup()` function should also delete the corresponding entry in the timestamps mapping
```diff
    function cleanup(bytes32 id) external whenNotPaused {
        require(isOperationExpired(id), "Timelock: operation not expired");
        
        // Remove the operation from _liveProposals and clear its timestamp
        assert(_liveProposals.remove(id));
+       delete timestamps[id];   // Clears the associated timestamp
        
        emit Cleanup(id);
    }
```
