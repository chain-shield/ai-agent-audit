# Vulnerability details

## Proof of Concept
In [`_addCalldataCheck()`](https://github.com/code-423n4/2024-10-kleidi/blob/ab89bcb443249e1524496b694ddb19e298dca799/src/Timelock.sol#L1069-L1078), a wildcard check is allowed under specific conditions:

`startIndex == endIndex == 4`: 
- This indicates a wildcard, which only checks the function `selector` and ignores calldata arguments.
No other checks exist for the given `contractAddress` and `selector`:
```solidity
    if (startIndex == endIndex) {
        require(startIndex == 4, "CalldataList: End index equals start index only when 4");
        require(listLength == 0, "CalldataList: Add wildcard only if no existing check");
        require(data.length == 0, "CalldataList: Data must be empty");
    }
```
 This allows for the function signature to be checked without imposing specific constraints on calldata beyond the first `4 bytes`.

**Issue in checkCalldata()**:
When validating calldata in [`checkCalldata()`](https://github.com/code-423n4/2024-10-kleidi/blob/ab89bcb443249e1524496b694ddb19e298dca799/src/Timelock.sol#L491-L493), if a `wildcard` is encountered (`startIndex == endIndex`), the function `returns` immediately, skipping further checks:

This  `return`   statement causes the function to exit without checking the rest of the `calldataChecks`, leading to potential validation bypass.

## Impact
If a `wildcard` check exists, subsequent `calldata` checks (which validate function arguments) are skipped. 
Since a `wildcard` is always the first element added (*if added*), when `checkCalldata()` encounters it, the function immediately `returns`. This guarantees that any subsequent calldata checks are skipped, meaning no further validation occurs. 

---> This allows invalid calldatas that would otherwise fail validation to pass.

## Recommended Mitigation Steps
Modify the logic in `checkCalldata()` to skip the `wildcard` without returning early, allowing subsequent checks to proceed:
```diff
    if (calldataCheck.startIndex == calldataCheck.endIndex) {
-       return;
+       continue;  // Skip this check, but validate the remaining checks
    }
```
