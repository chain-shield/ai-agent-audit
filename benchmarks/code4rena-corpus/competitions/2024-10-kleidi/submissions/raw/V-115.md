# Vulnerability details

## Proof of Concept
The executeWhitelisted function allows hot signers to execute pre-approved transactions. However, the validation mechanism in the checkCalldata function might be insufficient, which allows potentially dangerous transactions to pass. If not properly configured, malicious calldata could bypass the checks and perform unintended actions like transferring funds or altering contract states.

```

function executeWhitelisted(
    address target,
    uint256 value,
    bytes calldata payload
) external payable onlyRole(HOT_SIGNER_ROLE) whenNotPaused {
    /// first ensure calldata to target is whitelisted,
    /// and that parameters are not malicious
    checkCalldata(target, payload); 
    _execute(target, value, payload);

    emit CallExecuted(bytes32(0), 0, target, value, payload);
}
```

PoC demonstrates how a compromised hot signer can craft a malicious payload that could pass through the validation mechanism and execute unintended operations.


```
pragma solidity 0.8.25;

import "./Timelock.sol";

contract MaliciousWhitelistedPayload {
    Timelock timelock;

    constructor(address _timelock) {
        timelock = Timelock(_timelock);
    }

    function executeMaliciousPayload(
        address target,
        uint256 value,
        bytes calldata maliciousPayload
    ) external {
        timelock.executeWhitelisted(target, value, maliciousPayload);
    }
}
```

Steps to Exploit:
The attacker compromises a hot signer and uses this compromised account to execute executeWhitelisted.
The attacker crafts a malicious payload to transfer funds or modify the state of the contract.
The payload passes the checkCalldata function due to insufficient validation.


Funds Theft: The attacker can transfer funds from the contract to their own wallet by crafting a malicious transaction.
Contract State Manipulation: Depending on the scope of whitelisted functions, the attacker may alter the contract’s behavior.


## Recommended Mitigation Steps

Stronger Input Validation: Ensure that checkCalldata validates not just the format but also the semantics of the transaction to ensure no malicious intent.
Access Control Improvements: Consider requiring additional multi-signature approval for sensitive transactions involving large amounts of value.
