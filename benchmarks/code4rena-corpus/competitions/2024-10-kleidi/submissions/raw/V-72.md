# Vulnerability details

## Proof of Concept

The InstanceDeployer.sol contract does not perform adequate validation on recovery spells added as modules to the Safe. Since recovery spells are critical for restoring access to the Safe, a malicious recovery spell could introduce backdoors, allowing unauthorized access or modifying other sensitive parameters.

```

for (uint256 i = 0; i < instance.recoverySpells.length; i++) {
    calls3[index++].callData = abi.encodeWithSelector(
        ModuleManager.enableModule.selector,
        instance.recoverySpells[i]
    );
}
```

An attacker could deploy a malicious recovery spell and include it as a module through the createSystemInstance function. Since there is no validation, the malicious recovery spell could introduce a backdoor, allowing the attacker to:

Add themselves as an owner.
Modify the threshold or other critical settings of the Safe.
Hijack control of the Safe.


Backdoors: A malicious recovery spell can enable unauthorized access or backdoor mechanisms that can be triggered later.
Loss of Funds or Control: If an attacker takes control of the Safe through a malicious recovery spell, they can steal funds or prevent legitimate owners from recovering access to their Safe.



## Recommended Mitigation Steps


Add Validation for Recovery Spells:
Implement validation logic to ensure that only trusted recovery spells are added to the Safe. This could involve using a whitelist of known, secure recovery spell contracts.
```


mapping(address => bool) public trustedRecoverySpells;

function isTrustedRecoverySpell(address spell) public view returns (bool) {
    return trustedRecoverySpells[spell];
}

for (uint256 i = 0; i < instance.recoverySpells.length; i++) {
    require(isTrustedRecoverySpell(instance.recoverySpells[i]), "Untrusted recovery spell");
    calls3[index++].callData = abi.encodeWithSelector(
        ModuleManager.enableModule.selector,
        instance.recoverySpells[i]
    );
}
```

Whitelist and Audit Recovery Spells:
Only allow recovery spells that have been audited and reviewed for security vulnerabilities to be included as modules.
