# Vulnerability details


## Proof of Concept

The `paused()` function in the `ConfigurablePause` could lead to incorrect pause state determination. This can cause the contract to report as paused even when it should be in an unpaused state.

Take a look at this part of the fn: https://github.com/code-423n4/2024-10-kleidi/blob/ab89bcb443249e1524496b694ddb19e298dca799/src/ConfigurablePause.sol#L69-L71

```solidity
function paused() public view returns (bool) {
    return block.timestamp <= pauseStartTime + pauseDuration;
}
```


The issuee here is that this function doesn't correctly handle the case when the contract is not paused (i.e., when `pauseStartTime` is 0). 

1. When the contract is not paused, `pauseStartTime` is set to 0.
2. In this case, the function will return `true` (meaning paused) if `block.timestamp <= pauseDuration`.
3. This means that immediately after deployment or after the pause period ends, the contract will incorrectly report as paused for a duration equal to `pauseDuration`.

This contradicts the intended behavior [described in the natspec](https://github.com/code-423n4/2024-10-kleidi/blob/ab89bcb443249e1524496b694ddb19e298dca799/src/ConfigurablePause.sol#L5-L8):

```solidity
/// @notice possible states for this contract to be in:
///     1. paused, pauseStartTime != 0, guardian == address(0)
///     2. unpaused, pauseStartTime == 0, guardian != address(0)
///     3. unpaused, pauseStartTime <= block.timestamp - pauseDuration, guardian == address(0)
```

Impact:
1. Immediately after deployment, the contract will incorrectly report as paused for a duration equal to `pauseDuration`.
2. After a pause period ends, the contract will continue to report as paused for an additional `pauseDuration` period.
3. This can lead to unintended blocking of contract functionality that relies on the `whenNotPaused` modifier accross the protocol.

## Recommended Mitigation Steps

Consider modifying the `paused()` function to explicitly check if `pauseStartTime` is non-zero before comparing timestamps:

```diff
function paused() public view returns (bool) {
-   return block.timestamp <= pauseStartTime + pauseDuration;
+   return pauseStartTime != 0 && block.timestamp <= pauseStartTime + pauseDuration;
}
```
