# Vulnerability details

## Proof of Concept
The current onlyTimelock modifier requires that msg.sender must be the address of the contract itself (ie msg.sender == address(this)). This means that only the contract itself can call functions with the onlyTimelock modifier, and no external account or contract (including the timelock contract) can call these functions.
https://github.com/code-423n4/2024-10-kleidi/blob/main/src/Timelock.sol#L344-L349
```solidity
    modifier onlyTimelock() {
        require(
            msg.sender == address(this), "Timelock: caller is not the timelock"
        );
        _;
    }
```
In the Timelock contract, the logic of onlyTimelock is to ensure that the caller is the current contract address (this), which will lead to a problem. It doesn’t matter in testing because the caller can be specified with a cheat code, but it is impossible in actual deployment because there is no guarantee that the caller.

```solidity
    /// @notice update the expiration period for timelocked actions
    /// @param newPeriod the new expiration period
    function updateExpirationPeriod(uint256 newPeriod) external onlyTimelock {
        require(newPeriod >= MIN_DELAY, "Timelock: delay out of bounds");

        emit ExpirationPeriodChange(expirationPeriod, newPeriod);
        expirationPeriod = newPeriod;
    }
```
```solidity
    function testUpdateExpirationPeriodSucceedsAsTimelock() public {
        uint256 minDelay = MIN_DELAY;

        vm.prank(address(timelock));
        timelock.updateExpirationPeriod(minDelay);

        assertEq(
            minDelay,
            timelock.expirationPeriod(),
            "expirationPeriod should be updated"
        );
    }
```
For example, in this function, the permission control is onlyTimelock. Because the restriction is msg.sender == address(this), no address can call this function, including the administrator. It can only be simulated through testing, but cannot be deployed in the actual main network.The same applies to other functions.
## Recommended Mitigation Steps
Do not use msg.sender == address(this) permission control, but select a specific address, which can be an administrator or a contract.
