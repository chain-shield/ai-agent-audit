# Vulnerability details


Kledi wallet users can define a recovery spell, which when executed, replaces the owners of the safe with a list of other owners. The code calls `safe.getOwners()` to get all current owners, and then iterates over them and removes them. As such, in the case a safe has many current owners, the iteration step may revert due to the block's gas limit.

```sol
/// remove all existing owners except the last one
for (uint256 i = 0; i < existingOwnersLength - 1; i++) {
    calls3[index++].callData = abi.encodeWithSelector(
        OwnerManager.removeOwner.selector,
        SENTINEL,
        existingOwners[i],
        1
    );
}
```

## Proof of Concept
```sol
// RecoverySpell.t.sol
// forge test --match-test testTooManyOwners -vvv --gas-limit 30000000
function testTooManyOwners() public {
    vm.pauseGasMetering();

    for (uint256 i = 1; i < 4000; i++) {
        recoveryOwners.push(vm.addr(i));
    }

    safe.setOwners(recoveryOwners);

    vm.resumeGasMetering();

    testRecoverySucceeds(); // revert - gas: 36_248_949
}
```
## Recommended Mitigation Steps
Execution of recovery can be 2/more steps process, eg by allowing the caller to provide a chunked list of owners.
