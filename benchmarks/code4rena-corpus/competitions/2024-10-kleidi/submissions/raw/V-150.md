# Vulnerability details

## Proof of Concept
According to [EIP712 Standard](https://eips.ethereum.org/EIPS/eip-712#definition-of-typed-structured-data-%F0%9D%95%8A):

> The dynamic values `bytes` and `string` are encoded as a `keccak256` hash of their contents.

However, hashing in [`hashOperation`](https://github.com/code-423n4/2024-10-kleidi/blob/ab89bcb443249e1524496b694ddb19e298dca799/src/Timelock.sol#L429-L436) and [`hashOperationBatch`](https://github.com/code-423n4/2024-10-kleidi/blob/ab89bcb443249e1524496b694ddb19e298dca799/src/Timelock.sol#L443-L450)  is done as follows
```solidity
    function hashOperation(
        address target,
        uint256 value,
        bytes calldata data,
        bytes32 salt
    ) public pure returns (bytes32) {
        return keccak256(abi.encode(target, value, data, salt));
    }
```

```solidity
   function hashOperationBatch(
        address[] calldata targets,
        uint256[] calldata values,
        bytes[] calldata payloads,
        bytes32 salt
    ) public pure returns (bytes32) {
        return keccak256(abi.encode(targets, values, payloads, salt));
    }
```
As seen, in both `hashOperation` and `hashOperationBatch`, `data` and   `payloads` are `dynamic` values. However, the hashing (`slot`) encodes these values directly and not the `keccak256` hash of their contents as required by the standard.

Non-compliance with `EIP712` can cause problems with integrators and potentially lead to denial of service.

## Recommended Mitigation Steps
Correct this as follows:
```diff
    function hashOperation(
        address target,
        uint256 value,
        bytes calldata data,
        bytes32 salt
    ) public pure returns (bytes32) {
-       return keccak256(abi.encode(target, value, data, salt));
+       return keccak256(abi.encode(target, value, keccak256(data), salt));
    }
```

```diff
   function hashOperationBatch(
        address[] calldata targets,
        uint256[] calldata values,
        bytes[] calldata payloads,
        bytes32 salt
    ) public pure returns (bytes32) {
_       return keccak256(abi.encode(targets, values, payloads, salt));
+       return keccak256(abi.encode(targets, values, keccak256(payloads), salt));
    }
```
