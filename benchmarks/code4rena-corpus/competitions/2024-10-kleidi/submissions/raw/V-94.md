# Vulnerability details

## Proof of Concept
https://github.com/code-423n4/2024-10-kleidi/blob/main/src/Timelock.sol#L378-L387
```sol
    /// @notice supports 1155 and 721 receiver
    /// also supports ERC165 interface id
    function supportsInterface(bytes4 interfaceId)
        public
        view
        override(IERC165, AccessControlEnumerable)
        returns (bool)
    {
        return interfaceId == type(IERC1155Receiver).interfaceId
            || interfaceId == type(IERC721Receiver).interfaceId
            || super.supportsInterface(interfaceId);
    }
```
The contract supports ERC1155 and ERC721 interfaces, but we found that the supportsInterface function did not return true for ERC1155 and ERC721 interfaces when called, which means that ERC1155 and ERC721 interfaces are not supported.
In addition to supporting 1155 and 721 receivers, their own interfaces must also be supported.
