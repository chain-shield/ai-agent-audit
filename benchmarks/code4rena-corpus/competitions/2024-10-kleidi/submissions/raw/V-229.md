# Vulnerability details

## Proof of Concept

This vulnerability arises from a combination of reentrancy issues in InstanceDeployer.createSystemInstance() and RecoverySpell.executeRecovery(), alongside ignored return values in AccessControlEnumerable._grantRole() and _revokeRole(). Together, these flaws enable an attacker to use reentrancy to repeatedly bypass role checks and alter access control state, granting or maintaining unauthorized privileges. The lack of return value checks allows roles to persist despite intended removals, giving an attacker prolonged and unrestricted access to privileged functions.

### Impact
An attacker could exploit this vulnerability to establish and maintain unauthorized roles, granting themselves high-level privileges. This could lead to unrestricted access to critical functions, including unauthorized system instance creation and recovery disruptions, resulting in significant compromise of the contract’s security and integrity.

### Scenario

'''solidity

// Reentrant attack with createSystemInstance or executeRecovery
safeProxy = SafeProxyFactory(safeProxyFactory).createProxyWithNonce(...);
walletInstance.timelock = Timelock(...);
// Reentrant access to _grantRole and _revokeRole
for (uint256 i = 0; i < reentrantCalls; i++) {
    _grantRole(adminRole, attacker); // Return value ignored, attacker gains admin role
    _revokeRole(adminRole, legitimateUser); // Return value ignored, legitimate user loses admin role
}
emit SystemInstanceCreated(...); // Event emitted after reentrancy
'''

## Recommended Mitigation Steps

Reentrancy Protection: Apply nonReentrant modifiers to createSystemInstance(), executeRecovery(), _grantRole(), and _revokeRole() to prevent repeated calls in the same transaction.

Return Value Checks: Enforce return value checks on add() and remove() operations in access control functions, reverting if the role change fails.

Real-Time Monitoring: Implement safeguards to validate event logs for high-privilege actions, ensuring unauthorized changes are detected and handled immediately.
