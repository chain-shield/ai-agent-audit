# Vulnerability details

## Proof of Concept
The createSystemInstance() function in InstanceDeployer makes external calls to untrusted contracts, such as SafeProxyFactory.createProxyWithNonce() and Timelock.createTimelock(), before emitting the event SystemInstanceCreated(). This introduces a reentrancy risk where state changes may occur before the event emission, potentially leading to an inconsistent contract state.

### Impact
An attacker could exploit this reentrancy vulnerability to manipulate contract behavior, allowing for unauthorized system instance creation or state inconsistencies. This could result in incorrect event emissions or malicious state changes.

### Code Snippet

'''solidity

safeProxy = SafeProxyFactory(safeProxyFactory).createProxyWithNonce(...); 
walletInstance.timelock = Timelock(...);
emit SystemInstanceCreated(...); // Event emitted after external calls
'''

## Recommended Mitigation Steps
Move event emissions before making external calls, or apply a reentrancy guard (nonReentrant) to prevent state changes from occurring before event emissions.
