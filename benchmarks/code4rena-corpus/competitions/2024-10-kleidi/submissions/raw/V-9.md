# Vulnerability details

## Summary
The `revokeHotSigner()` function  is intended to be callable by both the `safe` and the `timelock` contracts, allowing them to `revoke` a hot signer's role. However, due to a restrictive modifier (`onlySafe`), only the `safe` can invoke this function, while attempts by the `timelock` will fail. 

This misconfiguration prevents the `timelock` from executing its intended role, which could lead to governance or administrative delays or failures in the revocation of signers.

## Proof of Concept
The [`revokeHotSigner()`](https://github.com/code-423n4/2024-10-kleidi/blob/ab89bcb443249e1524496b694ddb19e298dca799/src/Timelock.sol#L800-L804) function is protected by the [`onlySafe`](https://github.com/code-423n4/2024-10-kleidi/blob/ab89bcb443249e1524496b694ddb19e298dca799/src/Timelock.sol#L338-L341) modifier, which enforces that only the safe contract can call this function.
```solidity
    /// can only be called by the timelock or the safe
    function revokeHotSigner(address deprecatedHotSigner) external onlySafe { 
        _revokeRole(HOT_SIGNER_ROLE, deprecatedHotSigner);
    }

    modifier onlySafe() {
        require(msg.sender == safe, "Timelock: caller is not the safe");
        _;
    }
```
The function's comment states it can be called by either the `safe` or the `timelock`, but the current implementation contradicts that by excluding the [`timelock`](https://github.com/code-423n4/2024-10-kleidi/blob/ab89bcb443249e1524496b694ddb19e298dca799/src/Timelock.sol#L344-L349) from accessing the function
```solidity
    modifier onlyTimelock() {
        require(
            msg.sender == address(this), "Timelock: caller is not the timelock"
        );
        _;
    }
```
This results in incorrect access control since the `timelock` is unable to call `revokeHotSigner()`, despite the intention for it to be allowed.

## Recommended Mitigation Steps
To ensure both the `safe` and the `timelock` can execute the `revokeHotSigner()` function, the access control logic should be updated to allow either contract to invoke it.
```diff
    /// can only be called by the timelock or the safe
-   function revokeHotSigner(address deprecatedHotSigner) external onlySafe { 
+   function revokeHotSigner(address deprecatedHotSigner) external { 
+       require(
+           msg.sender == safe || msg.sender == address(this),
+           "Caller is not authorized"
+       );
        _revokeRole(HOT_SIGNER_ROLE, deprecatedHotSigner);
    }
```
