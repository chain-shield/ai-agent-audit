# Vulnerability details

## Description

The `calculateAddress` function is a critical component used to predict RecoverySpell contract addresses before deployment. This function is often called on-chain as part of larger transactions or integration flows.

The current implementation uses a nested loop for duplicate checking:

```solidity
// Current inefficient implementation - O(n²) complexity
for (uint256 i = 0; i < owners.length; i++) {
    for (uint256 j = i + 1; j < owners.length; j++) {
        require(
            owners[i] != owners[j], 
            "RecoverySpell: Duplicate owner"
        );
    }
}
```

Gas consumption grows quadratically with the number of owners:
- 5 owners: ~1,500 gas
- 10 owners: ~6,000 gas
- 50 owners: ~150,000 gas
- 100 owners: ~600,000 gas

## Impact

1. Gas Inefficiency:
   - Excessive gas consumption for larger owner sets
   - Higher transaction costs for users
   - Potential for transaction failures due to block gas limits

2. Integration Risks:
   - Smart contracts integrating with RecoverySpellFactory might fail when handling larger owner sets
   - Multi-operation transactions could hit gas limits
   - Potential DOS vector for systems requiring address calculation

## Fix

1. Implement an optimized memory-based sorting approach for duplicate detection:

```solidity
function calculateAddress(
    bytes32 salt,
    address[] memory owners,
    address safe,
    uint256 threshold,
    uint256 recoveryThreshold,
    uint256 delay
) external view returns (address predictedAddress) {
    _paramChecks(owners, threshold, recoveryThreshold, delay);
    _checkDuplicateOwnersOptimized(owners);
    
    predictedAddress = calculateCreate2Address(
        address(this),
        type(RecoverySpell).creationCode,
        abi.encode(owners, safe, threshold, recoveryThreshold, delay),
        salt
    );
}

function _checkDuplicateOwnersOptimized(
    address[] memory owners
) internal pure {
    // Early return for small arrays
    if (owners.length <= 1) return;
    
    // Create a memory copy for sorting
    address[] memory sortedOwners = new address[](owners.length);
    for (uint256 i = 0; i < owners.length; i++) {
        sortedOwners[i] = owners[i];
    }
    
    // Sort owners (using insertion sort for memory efficiency)
    for (uint256 i = 1; i < sortedOwners.length; i++) {
        address key = sortedOwners[i];
        int256 j = int256(i) - 1;
        
        while (j >= 0 && uint160(sortedOwners[uint256(j)]) > uint160(key)) {
            sortedOwners[uint256(j + 1)] = sortedOwners[uint256(j)];
            j--;
        }
        sortedOwners[uint256(j + 1)] = key;
    }
    
    // Check adjacent elements for duplicates - O(n)
    for (uint256 i = 1; i < sortedOwners.length; i++) {
        require(
            sortedOwners[i] != sortedOwners[i - 1],
            "RecoverySpell: Duplicate owner"
        );
    }
}
```
