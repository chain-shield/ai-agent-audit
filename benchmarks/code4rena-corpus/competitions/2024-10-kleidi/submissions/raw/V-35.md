# Vulnerability details

## Proof of Concept
The `executeRecovery()` function lacks an assertion to verify that the number of function calls populated in the `calls3` array matches the expected length. This omission can lead to logical errors if the population of `calls3` is incomplete or inconsistent.

[`createSystemInstance()`](https://github.com/code-423n4/2024-10-kleidi/blob/ab89bcb443249e1524496b694ddb19e298dca799/src/InstanceDeployer.sol#L330-L333) includes a validation check to ensure the integrity of the array size after populating it, which is an essential safeguard.
```solidity
    /// ensure that the number of calls is equal to the index
    /// this is a safety check and should never be false
    assert(calls3.length == index);
```
This assertion ensures that the number of function calls in the `calls3` array matches the number of calls actually added. This check prevents silent failures by confirming that all necessary actions are accounted for before executing the calls.

However, in the [`executeRecovery()`](https://github.com/code-423n4/2024-10-kleidi/blob/ab89bcb443249e1524496b694ddb19e298dca799/src/RecoverySpell.sol#L251-L289) function, the omission of the assertion assert(calls3.length == index); means there is no verification that all expected function calls were added to the calls3 array.
```solidity
    IMulticall3.Call3[] memory calls3 =
        new IMulticall3.Call3[](owners.length + existingOwnersLength + 1);

    // ... populating calls3 array ...

    // Missing validation check
    // assert(calls3.length == index);
```
This oversight can lead to incomplete execution of critical operations.

## Impact
- Without validating that `calls3` is fully populated, the function may execute fewer calls than intended. This could prevent crucial updates or changes from being applied, potentially leaving the system in an incorrect or insecure state.
- Errors resulting from this oversight may go unnoticed during execution, leading to silent failures where the recovery process does not complete as expected.

## Recommended Mitigation Steps
Include an assertion at the end of the calls population logic to ensure that calls3.length matches `index`:
```diff
    IMulticall3.Call3[] memory calls3 =
        new IMulticall3.Call3[](owners.length + existingOwnersLength + 1);

    // ... populating calls3 array ...

    // Add validation check
+   assert(calls3.length == index);
```
