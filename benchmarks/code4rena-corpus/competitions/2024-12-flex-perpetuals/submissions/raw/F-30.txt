Vulnerability Details

IntentHandler.sol has no checks validating that market is active.

Impact

Delisted Market transactions can still be executed by the IntentHandler.sol contract

Proof of concept

The delistMarket() function was added in the ConfigStorage.sol contract and was not there in the HMX contracts, therefore no checks were done in any of the functions to verify that the market tied to a specific market index is still active and not delisted. The Flex protocol team failed to consider this and add subsequent checks to functions that require markets to be active. Due to this error, delisted market transactions can still be executed by the IntentHandler.sol contract.

Here is the delisted market code in the ConfigStorage.sol contract:
'''solidity

function delistMarket(uint256 _marketIndex) external onlyOwner {
    emit LogDelistMarket(_marketIndex);
    delete marketConfigs[_marketIndex].active;
}


'''
In the IntentHandler.sol contract here is how the execute function begins:
'''solidity

function execute(ExecuteIntentInputs memory inputs) external onlyIntentExecutors {
if (inputs.accountAndSubAccountIds.length != inputs.cmds.length) revert IntentHandler_BadLength();

    ExecuteIntentVars memory _localVars;
    ExecuteTradeOrderVars memory _vars;

    // Update price to Pyth
    pyth.updatePriceFeeds(inputs.priceData, inputs.publishTimeData, inputs.minPublishTime, inputs.encodedVaas);

    _localVars.cmdsLength = inputs.accountAndSubAccountIds.length;
    _localVars.tpTokens = configStorage.getHlpTokens();

    for (uint256 _i; _i < _localVars.cmdsLength; ) {
        _localVars.mainAccount = address(uint160(inputs.accountAndSubAccountIds[_i].decodeUint(0, 160)));
        _localVars.subAccountId = uint8(inputs.accountAndSubAccountIds[_i].decodeUint(160, 8));
        _localVars.cmd = Command(inputs.cmds[_i].decodeUint(0, 3));

        if (_localVars.cmd == Command.ExecuteTradeOrder) {
            _vars.order.marketIndex = inputs.cmds[_i].decodeUint(3, 8);


'''
As can be seen, there is no verification that the market index connected to the order is delisted. Therefore any delisted market transactions can still can still be executed.

Tools Used

Manual review

Mitigation

Add checks to relevant functions to ensure market is not delisted.
