S-206
FeeQuoter will never receive price update from key stone oracle via onReport hook.
ladboy233
37
Sufficient
383d ago
Description

FeeQuoter should receive price update from key stone oracle.

contract FeeQuoter is AuthorizedCallers, IFeeQuoter, ITypeAndVersion, IReceiver, KeystoneFeedsPermissionHandler {

The fee quote is in charge of computing message fee and process message to set fee related field.

The price updated is done via the onReport hook.

However, the fee quoter contract does not implement IReceover.support interface,

then the feeQuoter will never receive the on report price update.

Because when the key stone oracle push price update to the fee quoter, the first thing the code check is if the fee quoter contract implement the receiver interface,

if not, the message is not delivered.

  // This call can consume up to 90k gas.
    if (!ERC165Checker.supportsInterface(receiver, type(IReceiver).interfaceId)) {
      s_transmissions[transmissionId].invalidReceiver = true;
      return false;
    }

    bool success;
    bytes memory payload = abi.encodeCall(IReceiver.onReport, (metadata, validatedReport));

    uint256 remainingGas = gasleft() - INTERNAL_GAS_REQUIREMENTS_AFTER_REPORT;
    assembly {
      // call and return whether we succeeded. ignore return data
      // call(gas,addr,value,argsOffset,argsLength,retOffset,retLength)
      success := call(remainingGas, receiver, 0, add(payload, 0x20), mload(payload), 0x0, 0x0)
    }

note the check:

!ERC165Checker.supportsInterface(receiver, type(IReceiver).interfaceId)

because the receiver, which is the fee quoter contract does not implement type(IReceiver).interfaceId, the message is not delivered.

the impact is that the token price data cannot be updated on time and the user may either over-pay the cross-chain fee, or under-pay the cross-chain fee consistently.

the under-pay case is more concerning.

Recommendation

implement type(IReceiver).interfaceId in the fee quoter contract.

   function supportsInterface(bytes4 interfaceId) external pure override returns (bool) {
        return interfaceId == _INTERFACE_ID_IReceiver || interfaceId == _INTERFACE_ID_ERC165;
    }
