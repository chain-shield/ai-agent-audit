# Vulnerability details

## Impact
The WETH contract deployed on blast is not a standard weth99 contract and it doesn’t have the following check on transferFrom:
```
if (src != msg.sender && allowance[src][msg.sender] != uint(-1))
{ require(allowance[src][msg.sender] >= wad);
  allowance[src][msg.sender]-=wad;
}
```
It will always revert on Blast because it will check for the allowance, but works fine on mainnet, so a developer might assume the same behavior on Blast and the protocol could run into DOS



## Proof of Concept
If the token will be WETH

```            
    token.transferFrom(_tokenOwner, 
     address(this), _quantity);
```
