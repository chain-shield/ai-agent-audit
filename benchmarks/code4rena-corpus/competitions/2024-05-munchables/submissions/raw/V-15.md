# Vulnerability details

## Impact
lockOnBehalf() is locking the tokens of the caller and not for on Behalf address.
The lockOnBehalf should operated on the tokens owned by the On Behalf address if the current user(msg.sender) has the necessary approval to spend on behalf.

But, look at the implementation logic, the tokens being spent are of the msg.sender, the caller of the function which is incorrect.

## Proof of Concept
Refer to the below function that accepts _onBehalfOf as the target address for which the caller is locking the tokens, only if the current user(msg.sender) has the necessary entitlements.

```
function lockOnBehalf(
        address _tokenContract,
        uint256 _quantity,
        address _onBehalfOf
)
```

Note how lockRecipient is updated if the onBehalfOf is non zero address.
To the lock function, the tokenOwner passed is msg.sender.

So, the allowance being checked against is that of the msg.sender on whom the
current contract's allowance is checked. That means the current contract is spending the tokens of the msg.sender and not the onBehalf address.

```
   uint256 allowance = token.allowance(_tokenOwner, address(this));
   if (allowance < _quantity) revert InsufficientAllowanceError();
```

Subsequently, 

The tokens are being transferred from msg.sender to this contract and not from onBehalf address which is incorrect.

```
 if (_tokenContract != address(0)) {
            IERC20 token = IERC20(_tokenContract);
            token.transferFrom(_tokenOwner, address(this), _quantity);
        }
```

## Recommended Mitigation Steps
The approval for spending the tokens should be from onbehalf first for the current user, msg.sender. if the msg.sender has the entitlements, then tokens should be transfer from onBehalf account to the current contract if the necessary approvals exist.

```
- uint256 allowance = token.allowance(_tokenOwner, address(this));
+ uint256 allowance = token.allowance(_lockRecipient, address(this));
```

and like wise for transfer of tokens, it should be as below.

```
 if (_tokenContract != address(0)) {
            IERC20 token = IERC20(_tokenContract);
      -       token.transferFrom(_tokenOwner, address(this), _quantity);
      +       token.transferFrom(_lockRecipient, address(this), _quantity);   
        }
```
