# Vulnerability details

## Impact
Using call instead of transfer is better and less error-prone as there is gas limit of 2300 with transfer and no-check for success.

## Recommended Mitigation Steps

Use the below code [here](https://github.com/code-423n4/2024-05-munchables/blob/main/src/managers/LockManager.sol#L420) 

```solidity

(bool success, ) = payable(msg.sender).call{value: _quantity}(""); 
require(success, "Failed to send Ether");

```
