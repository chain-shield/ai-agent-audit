# Vulnerability details

## Impact
When a user unlock() his tokens, only `lockedToken.quantity` is reduced leading to `reuse` of remainder when user lock his tokens next time
```solidity
 function unlock(
        address _tokenContract,
        uint256 _quantity
    ) external notPaused nonReentrant {
       ///
       lockedToken.quantity -= _quantity;

        ///
       
    }
```
From _lock()
```solidity
       // add remainder from any previous lock
        uint256 quantity = _quantity + lockedToken.remainder;
```
