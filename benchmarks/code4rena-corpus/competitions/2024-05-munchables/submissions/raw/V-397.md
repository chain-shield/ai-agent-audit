# Vulnerability details

## Impact
The current implementation of [_setLockDuration](https://github.com/code-423n4/2024-05-munchables/blob/57dff486c3cd905f21b330c2157fe23da2a4807d/src/managers/LockManager.sol#L245) function only implements one check i.e of [MaxLockDuration](https://github.com/code-423n4/2024-05-munchables/blob/57dff486c3cd905f21b330c2157fe23da2a4807d/src/managers/LockManager.sol#L246).
Due to the absence of `minLockDuration` check, users could potentially make locks that have a very small duration, making the contract prone to DOS and gas griefing types of attacks.

## Proof of Concept
- A user locked for 31 days.
- Just when his lock duration was about to end(30 sec prior) he introduces another lock but this time of 1 min, hence bypassing the [_lock](https://github.com/code-423n4/2024-05-munchables/blob/57dff486c3cd905f21b330c2157fe23da2a4807d/src/managers/LockManager.sol#L357) check of `minLockDuration`.

function setLockDuration(uint256 _duration) external notPaused {
        if (_duration > configStorage.getUint(StorageKey.MaxLockDuration))
            revert MaximumLockDurationError();
+       if (_duration < lockdrop.minLockDuration)
            revert LockDurationTooShortError(); //Make sure to write this error in ILockManager.sol
        playerSettings[msg.sender].lockDuration = uint32(_duration);
        // update any existing lock
        uint256 configuredTokensLength = configuredTokenContracts.length;
        for (uint256 i; i < configuredTokensLength; i++) {
            address tokenContract = configuredTokenContracts[i];
            if (lockedTokens[msg.sender][tokenContract].quantity > 0) {
                // check they are not setting lock time before current unlocktime
                if (
                    uint32(block.timestamp) + uint32(_duration) <
                    lockedTokens[msg.sender][tokenContract].unlockTime
                ) {
                    revert LockDurationReducedError();
                }

                uint32 lastLockTime = lockedTokens[msg.sender][tokenContract].lastLockTime;
                lockedTokens[msg.sender][tokenContract].unlockTime = lastLockTime + uint32(_duration);
            }
        }

        emit LockDuration(msg.sender, _duration);
    }
