# Vulnerability details

## Impact
Users are allowed to create a lock that has no funds inside it. Because of that they are allowed to reach the 30+ day period when they get increased rewards from the harvest.

## Proof of Concept
There are no checks weather the amount to be locked is 0 which allows for the creation of an empty lock. While the user will not receive any rewards while the lock is empty, they can make a increase the lock amount and start earning increased rewards while having locked 0 funds beforehand. For example, one of the bonuses is only available after 30 days of lock time have passed.

https://github.com/code-423n4/2024-05-munchables/blob/57dff486c3cd905f21b330c2157fe23da2a4807d/src/managers/BonusManager.sol#L150-L159

That means the users are essentially able to increase their rewards while having an empty lock.

## Tools Used
Manual review

## Recommended Mitigation Steps
Check that the amount locked is > 0 or create a minimum lock amount
