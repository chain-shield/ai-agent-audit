# Vulnerability details

## Impact & details
_configureLockDrop() function allows _minLockDuration to be more than the StorageKey.MaxLockDuration.
This will result in the lock() function always reverting with InvalidLockDurationError, because of this check:

   if (_lockDuration < lockdrop.minLockDuration || _lockDuration > uint32(configStorage.getUint(StorageKey.MaxLockDuration))) revert InvalidLockDurationError();

## Recommendation
Add check in _configureLockDrop to make sure _minLockDuration is bigger than configStorage.getUint(StorageKey.MaxLockDuration);
