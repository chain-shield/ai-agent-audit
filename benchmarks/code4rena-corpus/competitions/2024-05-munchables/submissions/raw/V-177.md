# Vulnerability details

## Impact

According to provided documentation, protocol does not implement any trusted role, which implicitly implies, that every role within the protocol should be treated as a non-trusted:

[File: README.md](https://github.com/code-423n4/2024-05-munchables/blob/main/README.md#all-trusted-roles-in-the-protocol)
```
All trusted roles in the protocol

N/A
```

A non-trusted `onlyAdmin` role can call `configureToken()` multiple of times - adding many tokens to `configuredTokenContracts` array.

Protocol implements a loop on `configuredTokenContracts` array in many places. When `configuredTokenContracts` array is too big, protocol will revert with out of gas error - thus noone will be able to use properly use the smart contract.
