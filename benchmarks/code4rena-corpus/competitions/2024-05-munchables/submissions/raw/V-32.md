# Vulnerability details

## Impact
Detailed description of the impact of this finding.
### Location:
`LockManager.proposeUSDPrice(uint256, address[])` (src/managers/LockManager.sol#142-174) deletes `ILockManager.USDUpdateProposal` (src/interfaces/ILockManager.sol#60-69), which contains a mapping:
- `delete usdUpdateProposal` (src/managers/LockManager.sol#161)

### Description:
Deleting a structure that contains a mapping does not delete the mapping itself, as per the [Solidity documentation](https://solidity.readthedocs.io/en/latest/types.html##delete). The residual data may pose a security risk and potentially compromise the contract.
## Proof of Concept
Provide direct links to all referenced code in GitHub. Add screenshots, logs, or any other relevant proof that illustrates the concept.

**Incorrect:**
```sol
delete usdUpdateProposal;
```

**Correct:**
```sol
delete usdUpdateProposal[i];
```

## Tools Used
Slither.
## Recommended Mitigation Steps
To ensure optimal security and functionality, delete individual elements rather than the entire array.

So, instead ```delete usdUpdateProposal;``` you would instead write ```delete usdUpdateProposal[i];``` and loop through each value in the array.
