# Vulnerability details

## Issue
In the 423 Line, the `transfer` function is used to send tokens to `msg.sender` without checking the return value. This can lead to potential vulnerabilities if the transfer fails for any reason, such as insufficient balance or contract reverts.

## Impact
If the `transfer` function fails, the tokens will not be sent to the intended recipient (msg.sender). This could result in loss of funds or unexpected behavior in the contract.

Manual Audit

## Recommended Mitigation Steps
To mitigate this vulnerability, it's recommended to check the return value of the `transfer` function to ensure that the token transfer was successful. One common approach is to use the `SafeERC20` library, which provides safe implementations of ERC20 functions, including `transfer`.

Here's how you can modify the code using `SafeERC20`:

```
SafeERC20.safeTransfer(IERC20(token), msg.sender, _quantity);
```
