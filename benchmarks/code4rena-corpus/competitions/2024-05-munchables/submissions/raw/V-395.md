# Vulnerability details

The `_executeUSDPriceUpdate()` function can be used to update the any tokenContract's usd price. However, a meicious user can front-run the usd price update transaction. This enables a well-known attack vector, in which the melicious user can `lock` their tokens before that usdPrice updates. This allow him to potentially increases his `_lockedWeightedValue`.

The user's `lockedWeightedValue` is determined as follows:
```javascript
 function getLockedWeightedValue(
        address _player
    ) external view returns (uint256 _lockedWeightedValue) {
        uint256 lockedWeighted = 0;
        uint256 configuredTokensLength = configuredTokenContracts.length;
        for (uint256 i; i < configuredTokensLength; i++) {
            if (
                lockedTokens[_player][configuredTokenContracts[i]].quantity >
                0 &&
                configuredTokens[configuredTokenContracts[i]].active
            ) {                 
                uint256 deltaDecimal = 10 **
                    (18 -
                        configuredTokens[configuredTokenContracts[i]].decimals);

@>                lockedWeighted +=
                    (deltaDecimal *
                        lockedTokens[_player][configuredTokenContracts[i]]
                            .quantity *
@>                       configuredTokens[configuredTokenContracts[i]]
                            .usdPrice) /
                    1e18;
            }
        }

        _lockedWeightedValue = lockedWeighted;
    }
```
User `_lockedWeightedValue` can be decreased when the token contract's `usdPrice` is increases. Consider when the usdPrice updates , the usdPrice value set higher than current value, assume currently is 0. But an melicious user tracks that transaction on mempool and lock his tokens before usdPrice updates. Now it is potentially allowing him to increase his tokens locked weight.

## Impact
A melicious user can front-run the `_executeUSDPrice` transaction . And able to `lock` his tokens at previous `usdPrice` . Which means potentially increasing his `_lockedWeightedValue`.
