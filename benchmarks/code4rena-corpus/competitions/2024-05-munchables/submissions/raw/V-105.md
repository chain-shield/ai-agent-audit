ensures that the lock duration for any single lock operation is within the minimum and maximum bounds, it does not prevent the cumulative lock duration from exceeding the maximum limit when multiple locks are performed consecutively.

## Impact
The current lock mechanism allows the lock duration to extend beyond the maximum allowed period (90 days) if a user repeatedly locks additional tokens before the previous lock expires. This circumvents the intended limit on the maximum lock duration and enables users to unfairly receive bonus rewards for extended periods.

## Proof of Concept
The `_lock` function resets the `lastLockTime` and recalculates the `unlockTime` each time tokens are locked:
https://github.com/code-423n4/2024-05-munchables/blob/57dff486c3cd905f21b330c2157fe23da2a4807d/src/managers/LockManager.sol#L381-L384
```solidity
lockedToken.lastLockTime = uint32(block.timestamp);
lockedToken.unlockTime = uint32(block.timestamp) + uint32(_lockDuration);
```
By resetting `lastLockTime` to the current block timestamp and setting `unlockTime` to the current timestamp plus the lock duration, the effective lock period can be extended indefinitely with repeated locks. This allows users to circumvent the intended maximum lock duration.

Initial Lock:User locks tokens for 70 days.
Subsequent Lock:On the 69th day, the user locks more tokens.
Result: Unlock time is recalculated to the current time + 70 days, effectively resulting in a lock period of 139 days from the initial lock.

The total effective lock period now exceeds the maximum intended duration of 90 days.

## Recommended Mitigation Steps
To ensure the lock duration never exceeds the maximum allowed duration, we should modify the logic to respect the maximum lock duration limit by checking the total cumulative lock duration.

```solidity
uint32 maxLockDuration = uint32(configStorage.getUint(StorageKey.MaxLockDuration));
uint32 newUnlockTime = uint32(block.timestamp) + uint32(_lockDuration);

if (newUnlockTime > lockedToken.lastLockTime + maxLockDuration) {
    revert MaximumLockDurationExceededError();
}

lockedToken.unlockTime = newUnlockTime;
```
