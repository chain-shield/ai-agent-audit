# Vulnerability details

The `configureToken` function only allows for the addition and configuration of tokens but does not provide a mechanism to deactivate or remove tokens. This poses a significant risk, as there is no way to respond to a token becoming malicious or otherwise problematic.

The `ConfiguredToken` struct is defined as follows:
```solidity
struct ConfiguredToken {
    uint256 usdPrice;
    uint256 nftCost;
    uint8 decimals;
    bool active;
}
```

The `configureToken` function sets the configuration for tokens but lacks functionality to deactivate or remove tokens:
https://github.com/code-423n4/2024-05-munchables/blob/57dff486c3cd905f21b330c2157fe23da2a4807d/src/managers/LockManager.sol#L115-L127
```solidity
function configureToken(
    address _tokenContract,
    ConfiguredToken memory _tokenData
) external onlyAdmin {
    if (_tokenData.nftCost == 0) revert NFTCostInvalidError();
    if (configuredTokens[_tokenContract].nftCost == 0) {
        // new token
        configuredTokenContracts.push(_tokenContract);
    }
    configuredTokens[_tokenContract] = _tokenData;

    emit TokenConfigured(_tokenContract, _tokenData);
}
```
This function only configures tokens and adds new tokens to `configuredTokenContracts` but does not address the scenario where a token needs to be deactivated or removed.

## Impact
The inability to deactivate or remove tokens can result in the following issues:

1. **Exposure to Malicious Tokens:** If a token becomes malicious, the contract cannot prevent users from interacting with it, leading to potential financial losses and security risks.
2. **Operational Inflexibility:** The contract lacks flexibility to respond to changes in token status, making it harder to manage the token ecosystem effectively.

## Proof of Concept
Consider the following scenario:
1. A token that was previously configured and added to the contract becomes malicious.
2. The admin has no way to deactivate or remove this token, leaving users exposed to potential risks.

## Recommended Mitigation Steps
Implement a function to deactivate tokens, setting their `active` status to `false`.

   ```solidity
   function deactivateToken(address _tokenContract) external onlyAdmin {
       configuredTokens[_tokenContract].active = false;
       emit TokenDeactivated(_tokenContract);
   }
   ```
