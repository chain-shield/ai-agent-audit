# Vulnerability details

## Impact
Tokens with non-standard decimals could lead to incorrect adjustments, resulting in inaccurate USD value calculations.

## Proof of Concept
The `getLockedWeightedValue()` function calculates the USD value of locked tokens for a player. It assumes tokens have a maximum of 18 decimals and uses this assumption to adjust token quantities.
 
However, readme suggests that ERC20 token behaviours with low decimals(<6) & high decimals(>18) are in scope:
>Low decimals ( < 6)	  Yes
 High decimals ( > 18)	  Yes

Therefore, if a token has more than 18 decimals or fewer than 6 decimals, the ` getLockedWeightedValue()` function may produce incorrect results.

The calculation produces a zero value for any token with more than 18 decimals, severely underestimating the locked value.
```js
    function getLockedWeightedValue(
        address _player
    ) external view returns (uint256 _lockedWeightedValue) {
        uint256 lockedWeighted = 0;
        uint256 configuredTokensLength = configuredTokenContracts.length;
        for (uint256 i; i < configuredTokensLength; i++) {
            if (
                lockedTokens[_player][configuredTokenContracts[i]].quantity >
                0 &&
                configuredTokens[configuredTokenContracts[i]].active
            ) {
                // We are assuming all tokens have a maximum of 18 decimals and that USD Price is denoted in 1e18
                uint256 deltaDecimal = 10 **
                    (18 -
                        configuredTokens[configuredTokenContracts[i]].decimals);
                lockedWeighted +=
                    (deltaDecimal *
                        lockedTokens[_player][configuredTokenContracts[i]]
                            .quantity *
                        configuredTokens[configuredTokenContracts[i]]
                            .usdPrice) /
                    1e18;
            }
        }


        _lockedWeightedValue = lockedWeighted;
    }
```
_Simple Example: >18 Decimals_
Quantity: 1,000 tokens
Decimals: 20
USD Price: $1 (1e18)
```js
uint256 deltaDecimal = 10 ** (18 - 20); // Results in 10 ** -2 which is incorrect
lockedWeighted += (deltaDecimal * 1000 * 1e18) / 1e18; // This results in incorrect value
```
_Simple Example: <6 Decimals_
Quantity: 1,000 tokens
Decimals: 4
USD Price: $1 (1e18)
```js
uint256 deltaDecimal = 10 ** (18 - 4); // Results in 10 ** 14
```
```js
lockedWeighted += (1e14 * 1000 * 1e18) / 1e18; // lockedWeighted += 1e14 * 1000
```
This results in:
```js
lockedWeighted += 1e17; // A very large value
```
The calculation produces an excessively large value, potentially causing incorrect weighted value representation.
