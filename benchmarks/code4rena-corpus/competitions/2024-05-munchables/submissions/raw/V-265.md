# Vulnerability details

## Impact
Users may end up paying for NFTs without receiving them if they attempt to lock tokens outside the lockdrop duration. This leads to a direct loss of funds for the users.
In the ``_lock`` function, there is a condition that checks if the current time is within the lockdrop period. If this condition fails, the user will still be charged the token amount without receiving the corresponding Munchables NFTs, leading to a potential loss of funds.

## Proof of Concept
1) The user calls the ``lock`` or ``lockOnBehalf`` function during a time period outside the lockdrop duration.
2) The condition 
```if (lockdrop.start <= uint32(block.timestamp) && lockdrop.end >= uint32(block.timestamp))```
fails, and the code block for calculating and revealing NFTs is skipped.
3) The function proceeds to transfer the tokens from the user without providing the Munchables NFTs.
4) The user loses funds without receiving the expected NFTs.

## Tools Used
manual review

## Recommended Mitigation Steps
To mitigate this vulnerability, add a revert statement to ensure that the transaction fails if the lockdrop conditions are not met. This way, users will not be charged without receiving the corresponding NFTs.
Like so:
```
        if (
            lockdrop.start <= uint32(block.timestamp) &&
            lockdrop.end >= uint32(block.timestamp)
        ) {
            if (
                _lockDuration < lockdrop.minLockDuration ||
                _lockDuration >
                uint32(configStorage.getUint(StorageKey.MaxLockDuration))
            ) revert InvalidLockDurationError();
            if (msg.sender != address(migrationManager)) {
                // calculate number of nfts
                remainder = quantity % configuredToken.nftCost; // (10 + 3) % 2 = 1
                numberNFTs = (quantity - remainder) / configuredToken.nftCost; // 13-1/2

                if (numberNFTs > type(uint16).max) revert TooManyNFTsError();

                // Tell nftOverlord that the player has new unopened Munchables
                nftOverlord.addReveal(_lockRecipient, uint16(numberNFTs));
            }
        }else revert InvalidPeriod();   <=== @audit
```
