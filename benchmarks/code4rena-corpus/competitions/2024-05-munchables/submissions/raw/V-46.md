# Vulnerability details

## Users can set lock period below `minLockDuration`

In the function `LockManager.setLockDuration`, users can set a lock period lower than 'minLockDuration'. That can also influence the amount of `Schnibbles` the users will harvest, thus influencing faster growth of the `munchable` NFT, with potential to economic impact, in case the user sells it.

## Proof of Concept
It is missing a check if the `_duration` is not lower than the `minLockDuration`

[LockManager.sol#L249](https://github.com/code-423n4/2024-05-munchables/blob/57dff486c3cd905f21b330c2157fe23da2a4807d/src/managers/LockManager.sol#L249)
