# Vulnerability details

## Impact
Yield for `USDB` and `WETH` tokens are lost

## Proof of Concept
The protocol mentioned in the contest README that [Balance changes outside transfers](https://code4rena.com/audits/2024-05-munchables#top:~:text=ERC20%20token%20behaviors%20in%20scope) are in-scope.

The protocol will be deployed on `Blast Mainnet`, where `USDB` and `WETH` automatically accrue yield. 

There is no function that can retrieve the accrued yield from these tokens, and since users who lock tokens will only be able to unlock the same amount of tokens they originally locked, the yield accrued will be lost.

## Tools Used
Manual review.

## Recommended Mitigation Steps
Implement a function to retrieve the yield generated from these tokens
