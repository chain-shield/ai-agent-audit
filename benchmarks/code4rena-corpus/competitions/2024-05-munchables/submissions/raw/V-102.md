# Vulnerability details

The `configureToken` function in the contract lacks adequate validation for the `nftCost` parameter. While the function does check if `nftCost` is zero and reverts with an error, it does not ensure that `nftCost` is set to a reasonable value . This can lead to issues where the token unusable.

The `ConfiguredToken` struct is defined as follows:
```solidity
struct ConfiguredToken {
    uint256 usdPrice;
    uint256 nftCost;
    uint8 decimals;
    bool active;
}
```

The `configureToken` function sets the configuration for tokens:
https://github.com/code-423n4/2024-05-munchables/blob/57dff486c3cd905f21b330c2157fe23da2a4807d/src/managers/LockManager.sol#L115-L127
```solidity
function configureToken(
    address _tokenContract,
    ConfiguredToken memory _tokenData
) external onlyAdmin {
    if (_tokenData.nftCost == 0) revert NFTCostInvalidError();
    if (configuredTokens[_tokenContract].nftCost == 0) {
        // new token
        configuredTokenContracts.push(_tokenContract);
    }
    configuredTokens[_tokenContract] = _tokenData;

    emit TokenConfigured(_tokenContract, _tokenData);
}
```

## Impact
The lack of validation for `nftCost` can result in setting an extremely high `nftCost` could render the token unusable or inaccessible to users, as they would be unable to afford the cost.


## Proof of Concept

Extremely High `nftCost` can be set 
   ```solidity
   ConfiguredToken memory tokenData = ConfiguredToken({
       usdPrice: 100,
       nftCost: 2**256 - 1,  // Max value for uint256
       decimals: 18,
       active: true
   });
   configureToken(tokenAddress, tokenData);
   ```
   This would make the token essentially unusable due to the high cost.


## Tools Used
Manual Code Review

## Recommended Mitigation Steps
Add validation to ensure `nftCost` is within a reasonable range
```solidity
function configureToken(
    address _tokenContract,
    ConfiguredToken memory _tokenData
) external onlyAdmin {
    if ( _tokenData.nftCost > MAX_NFT_COST) revert NFTCostInvalidError();
    if (configuredTokens[_tokenContract].nftCost == 0) {
        // new token
        configuredTokenContracts.push(_tokenContract);
    }
    configuredTokens[_tokenContract] = _tokenData;

    emit TokenConfigured(_tokenContract, _tokenData);
}
```
