# Vulnerability details

## Impact
`remainder` is set to 0 if a lockdrop event is not running at the time a user locks their tokens. This means that their `remainder` will be 0 in upcoming lockdrop events.

## Proof of Concept
In `LockManager.sol:379`, the `remainder` is overwritten when locking tokens outside of a lockdrop event:

```solidity
lockedToken.remainder = remainder; 
lockedToken.quantity += _quantity;
lockedToken.lastLockTime = uint32(block.timestamp);
lockedToken.unlockTime = uint32(block.timestamp) + uint32(_lockDuration);
```

If a user locks tokens during a lockdrop event and receives a remainder, and then locks more tokens outside of a lockdrop event, their remainder will be set to 0. This means that if they lock tokens a third time during another lockdrop event, their previous remainder will be ignored.

```solidity
// Complete setup in https://gist.github.com/Tychaios/74bc20a13771ed6eca97a710b5e4bcfb
function testUserCanLoseRemainder() external {
        address bob = vm.addr(0x2);
        fundEther(bob, 1000 ether);

        vm.startPrank(bob);
        lockManager.lock{value: 1 ether}(address(0x0), 1 ether);

        ILockManager.LockedTokenWithMetadata[] memory lockedInfo = lockManager.getLocked(bob);
        uint256 remainderAfterFirstLock = lockedInfo[0].lockedToken.remainder;
        assertGt(remainderAfterFirstLock, 0);

        // Move time to past the lockdrop
        vm.warp(block.timestamp + 22 days);
        lockManager.lock{value: 1 ether}(address(0x0), 1 ether); // Lock more tokens outside the lockdrop
        vm.stopPrank();

        // A new lockdrop is coming!
        ILockManager.Lockdrop memory newLockDrop = ILockManager.Lockdrop({
            start: uint32(block.timestamp),
            end: uint32(block.timestamp + 10 days),
            minLockDuration: uint32(10 days)
        });
        lockManager.configureLockdrop(newLockDrop);

        // Bob locks some more tokens hoping that the remainder of his first lock will get him some more NFTs
        vm.prank(bob);
        lockManager.lock{value: 1 ether}(address(0x0), 1 ether);
        assertGt(lockManager.getLocked(bob)[0].lockedToken.remainder, remainderAfterFirstLock);
    }
```

## Recommended Mitigation Steps
If locking tokens outside of a lockdrop event, preserve the existing `remainder` value.
