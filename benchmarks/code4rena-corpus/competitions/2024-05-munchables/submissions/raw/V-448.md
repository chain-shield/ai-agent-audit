# Vulnerability details

## Impact
If a user locks a token but has already locked this token, these previous tokens will have the new unlockTime.

## Proof of Concept
https://github.com/code-423n4/2024-05-munchables/blob/main/src/managers/LockManager.sol#L382-L384

## Recommended Mitigation Steps
You may need to store different unlockTime each time a user locks his tokens.
