# Vulnerability details

**Description:** 
The LockManager contract uses the transferFrom method to transfer ERC20 tokens from a token owner to the contract. This method directly calls the transferFrom function of the ERC20 token, which can lead to issues if the token does not fully comply with the ERC20 standard or has custom logic that requires more gas than is typically provided by default.

**Impact:** 
Can result in failed token transfers if the token contract does not strictly adhere to the ERC20 standard.

**Proof of Concept:**

```javascript
if (_tokenContract != address(0)) {
    IERC20 token = IERC20(_tokenContract);
@>  token.transferFrom(_tokenOwner, address(this), _quantity); // Direct transferFrom call
}


```

**Recommended Mitigation:** 
To ensure safe and reliable token transfers, use OpenZeppelin’s safeTransferFrom method, which handles potential issues and reverts gracefully in case of errors.
