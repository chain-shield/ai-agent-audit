# Vulnerability details

## Impact
As there is no functionality to handel ETH yeild, so all ETH yeild will be lost

## Proof of Concept
`BaseBlastManager.sol` is a abstract contract, and it is inherited by `LockManager.sol` which is in `Scope`. So technically all functionality of `BaseBlastManager` falls under `LockManager.sol`

And taking this into consideration i'm submiting this Bug Report.

We know that `User not only lock WETH & USDB but also ETH`

## Recommended Mitigation Steps
As like other 2 (`WETH` & `USDB`) there should `IBlast(0x43...02).configureClaimableYield()` present to handel `ETH` yeild & a `claimYield` function for ETH

[Refer this example](https://docs.blast.io/building/guides/eth-yield#claimable-yield) present in official docs of BLAST
