# Vulnerability details

## Impact
calling the _lock function with invalid _tokenContract(some erc20 contract but not in configration list) outside lockdrop time, the function will store invalid lockedtoken, call the forceHarvest function and update player's duration.

## Recommended Mitigation Steps
adding check code for _tokenContract.

ConfiguredToken storage configuredToken = configuredTokens[
            _tokenContract
        ];
if (_tokenContract.nftCost == 0) revert InvaliTokenContract;
