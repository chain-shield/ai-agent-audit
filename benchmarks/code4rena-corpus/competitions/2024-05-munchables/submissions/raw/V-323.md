# Vulnerability details

## Impact

if one proposal need to be passed, he need more approves compared to disapproves.

## Proof of Concept
 
 If one user create a proposal, he can approve the  proposal again, because he is the proposer.
 The issue is , if he create a proposal, which surely means that he agree with proposal.   But  he don't have rights to approve. 
 The default value of  `APPROVE_THRESHOLD` and  `DISAPPROVE_THRESHOLD`  are both 3, proposer nums is 5.
 So if we  try to make approval  proposal pass, we need 1 proposer and 3 other users to approve, 
 the participation rate is  4/5 = 80%.
 If we try to make disapproval proposal pass, we need 3 proposers. 
the participation rate is  3/5 = 60%.
 
 The partication rate is different, the disapproval proposal is easier to pass.
