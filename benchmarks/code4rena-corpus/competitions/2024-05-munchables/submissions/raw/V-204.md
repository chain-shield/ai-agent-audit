# Vulnerability details

## Impact
User can deposit tokens on behalf of other user using lockOnBehalf() function. Now when a user deposits, it sets unlockTime which is checked while unlocking tokens
```solidity
lockedToken.unlockTime =
            uint32(block.timestamp) +
            uint32(_lockDuration);
```
Any bad user can frontrun the unlock() of honest user by depositing 1 wei on his behalf, which will increase his unlockTime, successfully causing DOS
