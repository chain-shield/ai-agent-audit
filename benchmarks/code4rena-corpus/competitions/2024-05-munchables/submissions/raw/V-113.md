# Vulnerability details

## Impact
Zero yield will be earned on ETH causing 4% yield loss.

 
- No yield will be earned if the external call made to the `configureClaimableYield()` fails because the boolean `success` return value is not checked.

## Proof of Concept

In the `__BaseBlastManager_reconfigure()` function, an external call is made to Blast's `configureClaimableYield()` function in order to configure yield earning on  ETH because the default DO NOT earn yield.

As we can see in the above the external call `blastAddress.call(...)` was made without checking if the returned `success` boolean is false and revert.

If the external `blastAddress.call(...)` call to `configureClaimableYield()` fails for any reason, one of which may be invalid blast addresss among other, the transaction execution will be successful. This will make the project assume they are earning 4% yield on ETH while they are not.
