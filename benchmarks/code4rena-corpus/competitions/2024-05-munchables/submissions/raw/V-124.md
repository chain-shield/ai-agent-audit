# Vulnerability details

## Impact

When a user locks tokens, they have to wait for a certain period before they can unlock them. However, if they lock more tokens during this period, they will not be able to unlock the initially locked tokens after the first unlock time has passed, because the new lock will set a new unlock time for the token contract.

## Proof of Concept

## Tools Used

Manual review

## Recommended Mitigation Steps

You can create a struct where you can save the unlock time for the different qunatities that are locked
