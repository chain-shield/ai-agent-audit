# Vulnerability details

## Impact
Detailed description of the impact of this finding.
### Issue: Incomplete Deletion of Mapping in USD Price Update Function

**Location:**
- `LockManager._execUSDPriceUpdate()` (src/managers/LockManager.sol: lines 506-527)

**Details:**
- The function deletes `ILockManager.USDUpdateProposal` (src/interfaces/ILockManager.sol: lines 60-69), which includes a mapping.
- Specifically, the line `delete usdUpdateProposal` (src/managers/LockManager.sol: line 525) is intended to remove the proposal.

**Problem:**
- Deleting a structure that contains a mapping does not remove the mapping itself, as per [Solidity Documentation](http://solidity.readthedocs.io/en/develop/types.html#delete).
- Residual data in the mapping may pose a security risk and could potentially be exploited to compromise the contract.

**Recommendation:**
- Implement explicit deletion of all elements within the mapping before deleting the structure to ensure complete removal and mitigate any security risks.

So, instead ```delete usdUpdateProposal;``` you would instead write ```delete usdUpdateProposal[i];``` and loop through each value in the array.
