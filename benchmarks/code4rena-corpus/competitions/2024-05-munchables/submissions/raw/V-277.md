# Vulnerability details

## Impact
The current implementation of ``getLockedWeightedValue`` function does not accurately calculate the weighted average of the locked tokens' values. Instead, it sums up the weighted values of each token and returns the total. This discrepancy can lead to incorrect reporting of the player's total locked value, potentially causing issues in downstream processes that rely on this calculation.

### Potential impact:
- Financial Misreporting: Users may see incorrect valuations of their locked assets, which can lead to financial misreporting.
- Incorrect Reward Distribution: Any rewards or incentives based on the locked asset value might be distributed incorrectly.

## Proof of Concept
1) Scenario Setup:
- Token A: 100 units, priced at $2 each.
- Token B: 200 units, priced at $5 each.
2) Expected Calculation:
- Correct Weighted Value: $ ((100*2)+(200*5)) / (100+200) = (200+1000) / 300 = 1200 / 300 = 4 $
3) Actual Calculation by Original Function:
- The function simply adds the weighted values without averaging: $ 200(100*2)+1000(200*5)=1200 $

## Recommended Mitigation Steps
```
function getLockedWeightedValue(
    address _player
) external view returns (uint256 _lockedWeightedValue) {
    uint256 lockedWeighted = 0;
    uint256 totalQuantity = 0;
    uint256 configuredTokensLength = configuredTokenContracts.length;
    
    for (uint256 i; i < configuredTokensLength; i++) {
        if (
            lockedTokens[_player][configuredTokenContracts[i]].quantity > 0 &&
            configuredTokens[configuredTokenContracts[i]].active
        ) {
            uint256 deltaDecimal = 10 ** 
                (18 - configuredTokens[configuredTokenContracts[i]].decimals);
            
            uint256 quantity = lockedTokens[_player][configuredTokenContracts[i]].quantity;
            uint256 weightedValue = 
                (deltaDecimal * quantity * configuredTokens[configuredTokenContracts[i]].usdPrice) / 1e18;

            totalQuantity += quantity;
            lockedWeighted += weightedValue;
        }
    }
    
    if (totalQuantity == 0) {
        _lockedWeightedValue = 0;
    } else {
        _lockedWeightedValue = lockedWeighted / totalQuantity;
    }
}
```
