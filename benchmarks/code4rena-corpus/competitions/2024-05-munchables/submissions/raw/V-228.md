# Vulnerability details

## Impact
msg.value can be less than quantity, or be 0, or allowance less than quantity

## Proof of Concept
The _lock function checks the msg.value only when _tokenContract is the zero address. However, it does not check if the msg.value is less than quantity or zero when _tokenContract is a valid token contract addres.

`if (_tokenContract == address(0)) {
    if (msg.value != _quantity) revert ETHValueIncorrectError();
} else {
    if (msg.value != 0) revert InvalidMessageValueError();
    // ...
}`

## Tools Used
Manual review

## Recommended Mitigation Steps
Also check mdh.value against quantity and zero, includig allowance not less than quantity when _tokenCotract is not address(0).
