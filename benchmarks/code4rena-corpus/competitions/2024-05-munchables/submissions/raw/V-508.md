# Vulnerability details

## Impact
Users unlock time is increased by another user causing them to be unable to unlock their tokens on schedule.

## Proof of Concept
In the lock function a user can lock specific for a specific period of time and unlock/withdraw the tokens when the unlock time is reached.

https://github.com/code-423n4/2024-05-munchables/blob/57dff486c3cd905f21b330c2157fe23da2a4807d/src/managers/LockManager.sol#L382C9-L384C35

```
lockedToken.unlockTime =
            uint32(block.timestamp) +
            uint32(_lockDuration);
```

The code works as intended but the issue arises in the lockOnBehalf function where another user can lock tokens on behalf of another user. 

https://github.com/code-423n4/2024-05-munchables/blob/57dff486c3cd905f21b330c2157fe23da2a4807d/src/managers/LockManager.sol#L275

```
function lockOnBehalf(
        address _tokenContract,
        uint256 _quantity,
        address _onBehalfOf
    )
```

Using this function a malicious user can decides to lock negligible amounts tokens on behalf of another user, this would then increase the user's unlock time by the set ```playerSettings[_lockRecipient].lockDuration``` or by ```lockdrop.minLockDuration``` by this block of code:

```
        // users token configurations being fetched from storage
        LockedToken storage lockedToken = lockedTokens[_lockRecipient][
            _tokenContract
        ];
        
        ...
        
        
        uint32 _lockDuration = playerSettings[_lockRecipient].lockDuration;

        if (_lockDuration == 0) {
            _lockDuration = lockdrop.minLockDuration;
        }
        
        ...
        
        // lockOnBehalf called by another user increasing a user's intended 
        // unlock time for the same token
        lockedToken.unlockTime =
            uint32(block.timestamp) +
            uint32(_lockDuration); 
```

This could lead to almost double wait time for a user which can be classified as DOS

## Tools Used
Manual Review

## Recommended Mitigation Steps
Consider increasing unlockedTime only if msg.sender == _lockReceipient or separate the unlocking of user staked tokens and tokens locked on behalf of.
