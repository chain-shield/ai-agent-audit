# Vulnerability details

## Vulnerability Detail
disapproveUSDPrice() function has no check if the disapprover is the proposer, as proposal is created by the proposer, he automatically votes for approval, allowing him to vote for disapproval also can compromise the voting results, because he votes for both.

## Impact
Not correctly handling the Voting for the proposed usd price can lead to incorrect data being calculated in the getLockedWeightedValue() function which will not work properly due to over/under pricing of the USD value.

## Tools Used
Manual Review

## Recommendation
Add check in disapproveUSDPrice(), to make sure that the proposer is not disapproving the proposal.

    if (usdUpdateProposal.proposer == msg.sender) {
    revert ProposerCannotDissapproveError();
    }
