# Vulnerability details

## Impact

In getLockedWeightedValue() we are calculating the USD value of all tokens locked by a player, weighted by their yield. if we have locked a token with 6 decimals we will get more locked weighted value because we will have much more delta decimals than a token with 18 decimals. The more locked weighted we have value the more daily schnibbles we get 

## Proof of Concept

Example with 6-Decimal Token (USDC)
Decimals: 6
Price: $1
Quantity: 10,000

Example with 18-Decimal Token (ETH)
Decimals: 18
Price: $2,000
Quantity: 5

Let's calculate the lockedWeighted value for both scenarios.

6-Decimal Token (USDC)
Calculate deltaDecimal:

uint256 deltaDecimal = 10 ** (18 - 6); // 10^12 = 1,000,000,000,000

Values:
deltaDecimal: 1,000,000,000,000
quantity: 10,000
usdPrice: 1

Calculating lockedWeighted:
lockedWeighted += (1,000,000,000,000 * 10,000 * 1) / 1e18;

Performing the Calculation:

Multiplication:
1𝑒12×1𝑒4×1=1𝑒16

Division by 1e18:
1𝑒16/1𝑒18=0.01

So, the lockedWeighted value for the 6-decimal token (USDC) is 0.01.

18-Decimal Token (ETH)
Calculate `deltaDecimal:

uint256 deltaDecimal = 10 ** (18 - 18); // 10^0 = 1

Values:
deltaDecimal: 1
quantity: 5
usdPrice: 2,000

Calculating `lockedWeighted:
lockedWeighted += (1 * 5 * 2,000) / 1e18;
Performing the Calculation:

Multiplication:
1×5×2,000=10,000

Division by 1e18:
10,000/1e18=0.00000000001

So, the lockedWeighted value for the 18-decimal token (ETH) is 0.00000000001.

Summary
6-decimal token (USDC): lockedWeighted value is 0.01.
18-decimal token (ETH): lockedWeighted value is 0.00000000001.

In this scenario, even though both tokens have the same total value (price * quantity = $10,000), the lockedWeighted value is significantly higher for the 6-decimal token due to the impact of deltaDecimal. This example highlights how the decimal scaling affects the lockedWeighted calculation, making tokens with fewer decimals contribute more significantly.
