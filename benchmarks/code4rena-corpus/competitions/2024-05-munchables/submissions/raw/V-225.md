# Vulnerability details

**Description:** 
The contract uses payable.transfer() to send Ether, which has a hard gas limit of 2300 gas. This can cause the transaction to fail if the recipient's fallback or receive function requires more than 2300 gas, or if there is a change in gas costs in the Ethereum network.

**Impact:** 
If the recipient has a complex fallback or receive function that requires more than 2300 gas than tx can revert.

**Proof of Concept:**
The vulnerability is present in the unlock function:
```javascript
if (_tokenContract == address(0)) {
    payable(msg.sender).transfer(_quantity);
} else {
    IERC20 token = IERC20(_tokenContract);
    token.transfer(msg.sender, _quantity);
}

```
In this code, payable(msg.sender).transfer(_quantity); uses the transfer method, which is limited to 2300 gas for the recipient.

**Recommended Mitigation:** 
Use .call with proper error handling to send Ether, which provides more flexibility by forwarding all remaining gas and allowing manual gas limit specification:
