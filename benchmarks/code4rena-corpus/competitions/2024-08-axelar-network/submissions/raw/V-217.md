# Vulnerability details

## Vulnerability Details
The `_validateSignatures` function in the BaseWeightedMultisig contract is responsible for validating signatures against a set of weighted signers. It's a critical security component ensuring that only authorized signers can approve actions.

The function has a vulnerability that allows an attacker to bypass the signature validation by reordering and duplicating valid signatures.

The current implementation accumulates weights and checks against the threshold without ensuring uniqueness of signers. This allows an attacker to:
1. Reorder signatures of valid signers
2. Duplicate signatures of high-weight signers
3. Potentially meet the threshold without having the required diverse set of signers

## Impact
An attacker could potentially approve unauthorized actions by manipulating the signature order and duplicating high-weight signer signatures, bypassing the intended security model of the multisig system.

## Scenario
Assume a multisig setup with three signers:
- Signer A: weight 3
- Signer B: weight 2
- Signer C: weight 1
Threshold: 5

An attacker with only Signer A's signature could create a valid proof by duplicating A's signature: [SignatureA, SignatureA]. This would pass the current validation, despite not meeting the intended security requirement of having at least two distinct signers.

## Fix
Implement a mechanism to ensure each signer is only counted once:

```solidity
function _validateSignatures(
    bytes32 messageHash,
    WeightedSigners calldata weightedSigners,
    bytes[] calldata signatures
) internal pure {
    WeightedSigner[] calldata signers = weightedSigners.signers;
    uint256 signersLength = signers.length;
    uint256 signaturesLength = signatures.length;
    uint256 totalWeight;
    bool[] memory usedSigners = new bool[](signersLength);

    if (signaturesLength == 0) revert LowSignaturesWeight();

    for (uint256 i; i < signaturesLength; ++i) {
        address recoveredSigner = ECDSA.recover(messageHash, signatures[i]);

        uint256 signerIndex;
        for (; signerIndex < signersLength; ++signerIndex) {
            if (recoveredSigner == signers[signerIndex].signer) break;
        }

        if (signerIndex == signersLength) revert MalformedSignatures();
        if (usedSigners[signerIndex]) revert DuplicateSignature();

        usedSigners[signerIndex] = true;
        totalWeight += signers[signerIndex].weight;

        if (totalWeight >= weightedSigners.threshold) {
            if (i + 1 == signaturesLength) return;
            revert RedundantSignaturesProvided(i + 1, signaturesLength);
        }
    }

    revert LowSignaturesWeight();
}
```
