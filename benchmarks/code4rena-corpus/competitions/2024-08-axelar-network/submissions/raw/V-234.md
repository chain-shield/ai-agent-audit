# Vulnerability details

## Impact
According to comments in [InterchainTokenFactory.sol#L165](https://github.com/code-423n4/2024-08-axelar-network/blob/4572617124bed39add9025317d2c326acfef29f1/interchain-token-service/contracts/InterchainTokenFactory.sol#L165), `originalChainName means The name of the chain where the token originally exists`
However, `originalChainName` can only be set to **the only value** as `keccak256(bytes(originalChainName)) == InterchainTokenService.chainNameHash`, which means it can only be set to one value.

## Proof of Concept
While calling [InterchainTokenFactory.deployRemoteInterchainToken](https://github.com/code-423n4/2024-08-axelar-network/blob/4572617124bed39add9025317d2c326acfef29f1/interchain-token-service/contracts/InterchainTokenFactory.sol#L172-L210), in [InterchainTokenFactory.sol#L192-L200](https://github.com/code-423n4/2024-08-axelar-network/blob/4572617124bed39add9025317d2c326acfef29f1/interchain-token-service/contracts/InterchainTokenFactory.sol#L192-L200), the function calculates [tokenId](https://github.com/code-423n4/2024-08-axelar-network/blob/4572617124bed39add9025317d2c326acfef29f1/interchain-token-service/contracts/InterchainTokenFactory.sol#L192-L194), and then get local `IInterchainToken token` based on `tokenId` in [InterchainTokenFactory.sol#L196](https://github.com/code-423n4/2024-08-axelar-network/blob/4572617124bed39add9025317d2c326acfef29f1/interchain-token-service/contracts/InterchainTokenFactory.sol#L196), and then query token metadata in [InterchainTokenFactory.sol#L198-L200](https://github.com/code-423n4/2024-08-axelar-network/blob/4572617124bed39add9025317d2c326acfef29f1/interchain-token-service/contracts/InterchainTokenFactory.sol#L198-L200).

In order to make sure [InterchainTokenFactory.sol#L198-L200](https://github.com/code-423n4/2024-08-axelar-network/blob/4572617124bed39add9025317d2c326acfef29f1/interchain-token-service/contracts/InterchainTokenFactory.sol#L198-L200) won't revert, it means `IInterchainToken token` must be deployed in the local chain

And based on how [tokenId](https://github.com/code-423n4/2024-08-axelar-network/blob/4572617124bed39add9025317d2c326acfef29f1/interchain-token-service/contracts/InterchainTokenFactory.sol#L192-L194) is calculated, it means that `IInterchainToken token` has to be deployed by [InterchainTokenFactory.deployInterchainToken](https://github.com/code-423n4/2024-08-axelar-network/blob/4572617124bed39add9025317d2c326acfef29f1/interchain-token-service/contracts/InterchainTokenFactory.sol#L127-L161).
And in `InterchainTokenFactory.deployInterchainToken`, the `chainNameHash` is constant value set in [InterchainTokenFactory.sol#L42](https://github.com/code-423n4/2024-08-axelar-network/blob/4572617124bed39add9025317d2c326acfef29f1/interchain-token-service/contracts/InterchainTokenFactory.sol#L42)

So to sum up, in `InterchainTokenFactory.deployRemoteInterchainToken`, the function use locally deployed `IInterchainToken` to fetch metadata(name/symbol/decimals), and because when deploy `IInterchainToken` token, `chainNameHash` uses constant value, so `originalChainName` in `InterchainTokenFactory.deployRemoteInterchainToken` can only be set to `chainNameHash`, otherwise, the function will revert in [InterchainTokenFactory.sol#L198](https://github.com/code-423n4/2024-08-axelar-network/blob/4572617124bed39add9025317d2c326acfef29f1/interchain-token-service/contracts/InterchainTokenFactory.sol#L198)
