Lack of Balance Check in interchainTransfer Function within InterchainTokenStandard contract

The interchainTransfer function lacks a balance check to ensure that the msg.sender has a sufficient balance to transfer the specified amount of tokens. 

This omission can lead to situations where the contract attempts to initiate a transfer that the sender cannot cover, potentially resulting in failed transactions and a poor user experience.

The code snippet below illustrates the problematic section in the interchainTransfer function:
```sol
    function interchainTransfer(
        string calldata destinationChain,
        bytes calldata recipient,
        uint256 amount,
        bytes calldata metadata
    ) external payable {
        address sender = msg.sender;


        _beforeInterchainTransfer(msg.sender, destinationChain, recipient, amount, metadata);


        ITransmitInterchainToken(interchainTokenService()).transmitInterchainTransfer{ value: msg.value }(
            interchainTokenId(),
            sender,
            destinationChain,
            recipient,
            amount,
            metadata
        );
    }
```

In this function, there is no check to verify whether msg.sender possesses a balance at least equal to amount. 

Without this check, the function might proceed with attempting to transfer tokens that the sender does not have, leading to unintended errors or failed transactions.

## Recommended Mitigation Steps

To address this issue, implement a balance check before proceeding with the transfer. 

This ensures that the sender has enough tokens to fulfill the transfer request. 

Below is a coded example of how to integrate this balance check:
```sol
function interchainTransfer(
    string calldata destinationChain,
    bytes calldata recipient,
    uint256 amount,
    bytes calldata metadata
) external payable {
    address sender = msg.sender;

    // Check if sender has sufficient balance
    require(balanceOf(sender) >= amount, "Insufficient balance for transfer");

    _beforeInterchainTransfer(sender, destinationChain, recipient, amount, metadata);

    ITransmitInterchainToken(interchainTokenService()).transmitInterchainTransfer{ value: msg.value }(
        interchainTokenId(),
        sender,
        destinationChain,
        recipient,
        amount,
        metadata
    );
}
```
