# Vulnerability details

## Impact
Detailed description of the impact of this finding.

InterchainTokenService contract Missing override Specifier for Overriding Functions and State Variables.

Solidity Language Inconsistency / Compilation Error

This issue prevents the contract from being compiled successfully, which could halt the deployment or upgrade process. Without proper compilation, the contract cannot be deployed, which means the intended functionalities will not be available on the blockchain.

The Solidity compiler encountered multiple fatal errors due to missing override specifiers on functions and state variables that override those from inherited contracts or interfaces. In Solidity, when a function or state variable is overridden, the override keyword must be explicitly used to ensure that the developer is aware of and intends to override the inherited definition.
