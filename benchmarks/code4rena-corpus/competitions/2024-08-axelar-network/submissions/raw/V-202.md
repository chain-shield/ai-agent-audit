# Vulnerability details

The ITS Hub `UpdateTrustedAddress` message has the `Elevated` permission. This permission is defined in the `axelar-wasm-std::permission_control` module and means that the message can only be executed by admin or governance roles. The setters for these roles are also implemented in the same file.

It is important to note that this admin and the admin specified during contract deployment are different entities and are stored differently.

When the ITS Hub is [initiated](https://github.com/code-423n4/2024-08-axelar-network/blob/main/axelar-amplifier/interchain-token-service/src/contract.rs#L53-L82), these roles are not set, and there are no interfaces to set or change them.

### Impact
Once the contract has been initialized, the list of trusted addresses cannot be changed.

### Tools Used
Manual review

### Recommended Mitigation Steps
Add `admin` and/or `governance` to the `InstantiateMsg` and set them in contract instantiation.
