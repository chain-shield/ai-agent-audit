# Vulnerability details

## Impact
Detailed description of the impact of this finding.

The absence of the override specifier in the function implementation causes a compilation error, preventing the contract from being deployed or tested. This issue halts the deployment process and may introduce bugs or misunderstandings during future contract maintenance if not properly addressed.

In Solidity, when a function in a contract overrides a function from a parent contract or an interface, the override keyword is required. This specifier informs the compiler that the function is intentionally overriding a base function. Without the override specifier, the Solidity compiler generates an error, as it cannot confirm that the function is correctly overriding the intended function.

The specific error reported by the Solidity compiler is:
```log
[ERROR]: Solc experienced a fatal error.

TypeError: Overriding function is missing "override" specifier.

    |
249 |     function messageHashToSign(bytes32 signersHash, bytes32 dataHash) public view returns (bytes32) {
    |     ^ (Relevant source part starts here and spans across multiple lines).
Note: Overridden function is here:
  --> /2024-08-axelar-network/axelar-gmp-sdk-solidity/contracts/interfaces/IBaseWeightedMultisig.sol:61:5:
   |
61 |     function messageHashToSign(bytes32 signersHash, bytes32 dataHash) external view returns (bytes32);
   |     ^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^
```

This error arises because the messageHashToSign function in the BaseWeightedMultisig contract is meant to override a function defined in the IBaseWeightedMultisig interface. The missing override specifier prevents the compiler from correctly linking the two functions, leading to a fatal compilation error.

## Recommended Mitigation Steps

To resolve this issue, add the override keyword to the function declaration in the BaseWeightedMultisig contract. This explicitly tells the compiler that the function is intended to override a parent or interface function, thereby resolving the compilation error.

The function should be updated as follows:
```sol
// In BaseWeightedMultisig.sol

function messageHashToSign(bytes32 signersHash, bytes32 dataHash) public view override returns (bytes32) {
    return keccak256(bytes.concat('\x19Ethereum Signed Message:\n96', domainSeparator, signersHash, dataHash));
}
```

By including the override specifier, the Solidity compiler will correctly recognise the function as an override, allowing the contract to compile and function as intended.
