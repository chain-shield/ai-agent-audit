# Vulnerability details

## Impact
`AxelarAmplifierGateway` and all other contracts containing the `signers` array are vulnerable to high gas expenses and potential DoS attacks.

## Proof of Concept
In `AxelarAmplifierGateway.js` set `numSigners` to be equal to 800 and then change the `before` function. Run `REPORT_GAS=true npm run test` and see how much gas is consumed now and after the change of code for the `AxelarAmplifierGatewayProxy`.

describe function:
```javascript
describe('AxelarAmplifierGateway', () => {
    const numSigners = 800;
    const threshold = 500;
    const chainName = 'chain';
    const router = 'router';
    const domainSeparator = keccak256(toUtf8Bytes(chainName + router + 'axelar-1'));
    const minimumRotationDelay = 0;
    const previousSignersRetention = 800;
    ...
}
```

before function:
```javascript
before(async () => {
        const wallets = await ethers.getSigners();
        owner = wallets[0];
        operator = wallets[1];
        user = wallets[2];

        const additionalSigners = [];

        for (let i = 0; i < 800; i++) {
            let w = ethers.Wallet.createRandom();
            w = w.connect(ethers.provider);
            additionalSigners.push(w);
        }

        console.log('additional length: ', additionalSigners.length);

        signers = sortBy(
            Array.from({ length: numSigners }, (_, i) => additionalSigners[i]),
            (wallet) => wallet.address.toLowerCase(),
        );

        weightedSigners = {
            signers: signers.map((wallet) => ({ signer: wallet.address, weight: 1 })),
            threshold,
            nonce: id('0'),
        };

        gatewayFactory = await ethers.getContractFactory('AxelarAmplifierGateway', owner);
        gatewayProxyFactory = await ethers.getContractFactory('AxelarAmplifierGatewayProxy', owner);
    });
```
