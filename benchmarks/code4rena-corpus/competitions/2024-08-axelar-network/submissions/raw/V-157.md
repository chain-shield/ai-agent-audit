# Vulnerability details

## Impact
When an interchain token is deployed via [InterchainTokenFactory::deployRemoteInterchainToken](https://github.com/code-423n4/2024-08-axelar-network/blob/main/interchain-token-service/contracts/InterchainTokenFactory.sol#L172-L207), the source chain token is verified to exist, and token information is retrieved from the local chain token. Additionally, the minter is checked to ensure it matches the source chain minter. However, when an interchain token is deployed via [InterchainTokenService::deployInterchainToken](https://github.com/code-423n4/2024-08-axelar-network/blob/main/interchain-token-service/contracts/InterchainTokenService.sol#L327-L349), these checks are not performed.

## Proof of Concept
First from [InterchainTokenFactory::deployRemoteInterchainToken](https://github.com/code-423n4/2024-08-axelar-network/blob/main/interchain-token-service/contracts/InterchainTokenFactory.sol#L172-L207) we can see the following code:

if (minter != address(0)) {

source chain token is verified to exist and minter is checked.

From [InterchainTokenService::deployInterchainToken](https://github.com/code-423n4/2024-08-axelar-network/blob/main/interchain-token-service/contracts/InterchainTokenService.sol#L327-L349) we can see: minter, decimals is not checked ,even if source chain token is exist is not checked.
```solidity
  function deployInterchainToken(
      bytes32 salt,
      string calldata destinationChain,
      string memory name,
      string memory symbol,
      uint8 decimals,
      bytes memory minter,
      uint256 gasValue
  ) external payable whenNotPaused returns (bytes32 tokenId) {
      address deployer = msg.sender;

      if (deployer == interchainTokenFactory) deployer = TOKEN_FACTORY_DEPLOYER;

      tokenId = interchainTokenId(deployer, salt);

      if (bytes(destinationChain).length == 0) {
          address tokenAddress = _deployInterchainToken(tokenId, minter, name, symbol, decimals);

          _deployTokenManager(tokenId, TokenManagerType.NATIVE_INTERCHAIN_TOKEN, abi.encode(minter, tokenAddress));
      } else {
          _deployRemoteInterchainToken(tokenId, name, symbol, decimals, minter, destinationChain, gasValue);//@audit not checked.
      }
  }
```
