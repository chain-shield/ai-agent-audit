# Vulnerability details


## Impact

The `acceptMintership` function in the `Minter` contract lacks any access control, which allows any external account to call this function and potentially become the new minter. This issue contrasts with other functions in the contract that use the `onlyRole` modifier to ensure only authorized users can execute them. The absence of such a restriction in the `acceptMintership` function poses a significant risk, as it allows unauthorized users to take control of the contract's minting privileges.



## Proof of Concept

The `acceptMintership` function is implemented as follows:

```solidity
function acceptMintership(address fromMinter) external {
    _acceptRole(fromMinter, msg.sender, uint8(Roles.MINTER));
}
```

This function does not have any access control modifiers like `onlyRole`, meaning any external account can call it. This oversight allows anyone to accept the mintership, effectively granting themselves minting rights.

In contrast, other functions in the contract, such as `transferMintership` and `proposeMintership`, include the `onlyRole(uint8(Roles.MINTER))` modifier to restrict access only to the current minter:

```solidity
function transferMintership(address minter_) external onlyRole(uint8(Roles.MINTER)) {
    _transferRole(msg.sender, minter_, uint8(Roles.MINTER));
}
```

```solidity
function proposeMintership(address minter_) external onlyRole(uint8(Roles.MINTER)) {
    _proposeRole(msg.sender, minter_, uint8(Roles.MINTER));
}
```

The inconsistency in access control between these functions allows anyone to call `acceptMintership` and take over the minter role, bypassing the intended security mechanisms.

## Recommended Mitigation Steps

To mitigate this issue, the `acceptMintership` function should be updated to include the `onlyRole(uint8(Roles.MINTER))` modifier or a similar access control mechanism. This change would ensure that only the intended recipient of the minter role can call this function, preserving the integrity of the contract's role management.

```solidity
function acceptMintership(address fromMinter) external onlyRole(uint8(Roles.MINTER)) {
    _acceptRole(fromMinter, msg.sender, uint8(Roles.MINTER));
}
```
