# Vulnerability details

## Impact
Function TokenHandler.transferTokenFrom() - This function transfers token from and to a specified address.:
https://github.com/code-423n4/2024-08-axelar-network/blob/main/interchain-token-service/contracts/TokenHandler.sol#L135-L156

## Proof of Concept
Anyone can call the TokenHandler.transferTokenFrom() function with any address from value. Thus, an attacker can steal tokens from the address.

## Tools Used
Manual review

## Recommended Mitigation Steps
Add to the function either in from = msg.sender or allow it to be called by specific addresses

Token-Transfer
