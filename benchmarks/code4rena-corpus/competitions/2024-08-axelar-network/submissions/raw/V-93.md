# Vulnerability details

## Impact
The InterchainTokenFactory.sol and InterchainTokenService.sol contracts use the onlyOwner modifier:
https://github.com/code-423n4/2024-08-axelar-network/blob/main/interchain-token-service/contracts/InterchainTokenFactory.sol#L301
https://github.com/code-423n4/2024-08-axelar-network/blob/main/interchain-token-service/contracts/InterchainTokenService.sol#L5 78
https://github.com/code-423n4/2024-08-axelar-network/blob/main/interchain-token-service/contracts/InterchainTokenService.sol#L586
https://github.com/code-423n4/2024-08-axelar-network/blob/main/interchain-token-service/contracts/InterchainTokenService.sol#L594
This modifier allows you to check that the function can only be called by the specified owner in the contract.

## Proof of Concept
However, the InterchainTokenFactory.sol and InterchainTokenService.sol contracts do not specify the owner parameter. Functions with the onlyOwner modifier cannot be called by anyone.

## Tools Used
Manual review

## Recommended Mitigation Steps
Add setting the owner parameter to the InterchainTokenFactory.sol and InterchainTokenService.sol contracts
