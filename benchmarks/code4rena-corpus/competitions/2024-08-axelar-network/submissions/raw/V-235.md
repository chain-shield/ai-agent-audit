# Vulnerability details

## Impact
Rebasing tokens are tokens that have each holder's balanceof() increase/decrease over time. If the balance of rebase token is increased, the incremental amount of token will be stuck in the contract, and if the balance is decreased, the last user might can't get his token back.
## Proof of Concept
As [TokenHandler.giveToken](https://github.com/code-423n4/2024-08-axelar-network/blob/4572617124bed39add9025317d2c326acfef29f1/interchain-token-service/contracts/TokenHandler.sol#L45-L79) shows, the function use `amount` directly without future calculation.
