# Vulnerability details

### Impact

`isCommandExecuted` in Gateway only checks if a message is non existent, as a result, attempting to express execute an approved message will be impossible.

### Proof of Concept

Looking at the `expressExecute`, it attempts to check if the command is executed in the gateway.

```solidity
    function expressExecute(
        bytes32 commandId,
        string calldata sourceChain,
        string calldata sourceAddress,
        bytes calldata payload
    ) public payable whenNotPaused {
        uint256 messageType = abi.decode(payload, (uint256));
        if (messageType != MESSAGE_TYPE_INTERCHAIN_TRANSFER) {
            revert InvalidExpressMessageType(messageType);
        }

        if (gateway.isCommandExecuted(commandId)) revert AlreadyExecuted();
//...
    }
```

In the BaseAmplifierGateway, the `isCommandExecuted` function is set like this.

```solidity
    function isCommandExecuted(bytes32 commandId) public view override returns (bool) {
        return _baseAmplifierGatewayStorage().messages[commandId] != MESSAGE_NONEXISTENT;
    }
```

As can be seen, a message can be of three types, non existent, approved and executed. So when the command is to be express executed, the check to see if the command is already executed, will always revert for approved messages, even if they had not been executed. This is because the `isCommandExecuted` returns true if message is not non-existent, rather than returning true if the message has been executed. As a result, approved messages cannot be express executed.


`expressExecute` is also called in `expressExecuteWithToken` and such, the function also experiences the same issue.
```solidity
    function expressExecuteWithToken(
        bytes32 commandId,
        string calldata sourceChain,
        string calldata sourceAddress,
        bytes calldata payload,
        string calldata tokenSymbol,
        uint256 amount
    ) external payable {
        _checkPayloadAgainstGatewayData(payload, tokenSymbol, amount);
        // It should be ok to ignore the symbol and amount since this info exists on the payload.
        expressExecute(commandId, sourceChain, sourceAddress, payload);
    }
```

### Tools Used
Manual code review

### Recommended Mitigation Steps

Recommend fixing the check.
```diff
    function isCommandExecuted(bytes32 commandId) public view override returns (bool) {
-        return _baseAmplifierGatewayStorage().messages[commandId] != MESSAGE_NONEXISTENT;
+        return _baseAmplifierGatewayStorage().messages[commandId] == MESSAGE_EXECUTED;
    }
```
