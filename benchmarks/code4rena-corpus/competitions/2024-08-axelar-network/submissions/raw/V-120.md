# Vulnerability details

## Impact
Detailed description of the impact of this finding.

***Prerequisites:
Update all contracts from pragma version ^0.8.0 to ^0.8.4.
This will enable the contracts to compile successfully following the override keyword being added to functions in all contracts that inherit the same functions from their respective interfaces or parents.***

InterchainTokenExpressExecutable contract is Missing override Specifier in Overriding Functions.

Issue Type: Solidity Error / Incorrect Inheritance
Status: Unresolved

The contract InterchainTokenExpressExecutable attempts to override functions defined in its parent interface IInterchainTokenExpressExecutable and InterchainTokenExecutable, respectively. However, the overriding functions are missing the override specifier. This leads to a compilation error, preventing the contract from being deployed or used correctly.

Specifically, the errors are raised for the following functions:

1. expressExecuteWithInterchainToken: 
Overriding function is missing the override specifier when overriding the same function in IInterchainTokenExpressExecutable.

2. executeWithInterchainToken: 
Overriding function is missing the override specifier when overriding the same function in IInterchainTokenExecutable.

## Recommended Mitigation Steps

To resolve this issue, the override keyword must be added to the function definitions that are overriding functions in the parent contracts or interfaces.
```sol
abstract contract InterchainTokenExecutable is IInterchainTokenExecutable {
...
    function executeWithInterchainToken(
        bytes32 commandId,
        string calldata sourceChain,
        bytes calldata sourceAddress,
        bytes calldata data,
        bytes32 tokenId,
        address token,
        uint256 amount
    ) external virtual onlyService override returns (bytes32) {
}

abstract contract InterchainTokenExpressExecutable is IInterchainTokenExpressExecutable, InterchainTokenExecutable {
...
    function expressExecuteWithInterchainToken(
        bytes32 commandId,
        string calldata sourceChain,
        bytes calldata sourceAddress,
        bytes calldata data,
        bytes32 tokenId,
        address token,
        uint256 amount
    ) external virtual onlyService override returns (bytes32) {
}

}
```

The mitigation is straightforward and involves adding the override specifier to the appropriate functions. This should be addressed promptly to ensure the contract functions as intended.
