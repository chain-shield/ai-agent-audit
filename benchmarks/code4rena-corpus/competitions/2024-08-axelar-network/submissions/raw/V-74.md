# Vulnerability details

## Impact

Anyone can call UpdatedTrustedAddress to update the trusted address.

## Proof of Concept

The two functions of ITS in contract.rs is either `ExecuteMsg::Execute` or `ExecuteMsg::UpdatedTrustedAddress`

In the execute function, there is an access control check, `let msg = msg.ensure_permissions(deps.storage, &info.sender, match_gateway)?;`, which checks that the call must come from the gateway.

```
pub fn execute(
    deps: DepsMut,
    _: Env,
    info: MessageInfo,
    msg: ExecuteMsg,
) -> Result<Response, axelar_wasm_std::error::ContractError> {
>   let msg = msg.ensure_permissions(deps.storage, &info.sender, match_gateway)?;

    match msg {
>       ExecuteMsg::Execute {
            cc_id,
            source_address,
            payload,
        } => execute::execute_message(deps, cc_id, source_address, payload),
>       ExecuteMsg::UpdateTrustedAddress { chain, address } => {
            execute::update_trusted_address(deps, chain, address)
        }
    }?
    .then(Ok)
}

```

The `update_trusted_address` function doesn't have any access control checks.

```
pub fn update_trusted_address(
    deps: DepsMut,
    chain: ChainName,
    address: Address,
) -> Result<Response, Error> {
    save_trusted_address(deps.storage, &chain, &address)
        .change_context(Error::InvalidStoreAccess)?;

    Ok(
        Response::new()
            .add_event(ItsContractEvent::TrustedAddressUpdated { chain, address }.into()),
    )
}
```

A user can call the `ExecuteMsg::UpdateTrustedAddress` through the gateway to change the state of the trusted address and since the function only checks that the gateway is the caller, the function can be executed.

## Recommended Mitigation Steps

Let the deployer of the contract.rs contract be the access control instead of the gateway when calling `ExecuteMsg::UpdateTrustedAddress`.

Save the owner in the Config when instantiating the contract and check if the caller is the info.owner. Something like:

```
#[cw_serde]
pub struct Config {
    pub chain_name: ChainNameRaw,
    pub gateway: Addr,
+   pub owner: Addr,
}
```

Instantiate:

```
  state::save_config(
        deps.storage,
        &Config {
            chain_name: msg.chain_name,
            gateway,
>           owner: deps.api.addr_validate(&msg.owner)?,
        },
    )?;
```

```
pub fn update_trusted_address(
    deps: DepsMut,
```
