# Vulnerability details

## Description
The deployTokenManager function at the InterchainTokenService contract only stops callers from deploying NATIVE_INTERCHAIN_TOKEN token managers:
```solidity
if (tokenManagerType == TokenManagerType.NATIVE_INTERCHAIN_TOKEN) revert CannotDeploy(tokenManagerType);
```

If a user deploys a gateway token manager, the `_checkPayloadAgainstGatewayData` function will always revert as the gateway tokens deployed by users in a permissionless fashion do not necessarily have a stored symbol at the gateway:
```solidity
function _checkPayloadAgainstGatewayData(bytes memory payload, string calldata tokenSymbol, uint256 amount) internal view {
        ...
        if (validTokenAddress(tokenId) != gateway.tokenAddresses(tokenSymbol) || amount != amountInPayload)
            revert InvalidGatewayTokenTransfer(tokenId, payload, tokenSymbol, amount);
    }
```
Since the gateway is protocol-controlled, stored symbols is not likely to be an offering for retail users. 

The `_checkPayloadAgainstGatewayData` function is executed in both the contractCallWithTokenValue and expressExecuteWithToken functions - that are crucial for the usage of a gateway token.  Since both coordinate the flow of cross-chain token messaging, the gateway token managers deployed by users do not deliver its core functionality.

## Impact
Gateway tokens deployed by users are unusable. 
Users may deploy gateway token managers at the original chain believing its supposed to work properly, but it doesn't.
## Tools Used
Manual review
## Recommended Mitigation Steps
Make sure to disallow users from deploying gateway token managers at the deployTokenManager function. 
The registerGatewayToken function at the factory contract already helps in solving the issue  as it only allows the contract owner to call deployTokenManager for a gateway token manager.
The next step in ensuring gateway token managers cannot be deployed by other users is ensuring only deployTokenManager calls made by the factory contract can deploy token managers of the gateway type:
```solidity
function deployTokenManager(
        bytes32 salt,
        string calldata destinationChain,
        TokenManagerType tokenManagerType,
        bytes calldata params,
        uint256 gasValue
    ) external payable whenNotPaused returns (bytes32 tokenId) {
    ...
	if (msg.sender != interchainTokenFactory){
		if (tokenManagerType == TokenManagerType.GATEWAY) revert CannotDeploy(tokenManagerType);
	}
```
