# Vulnerability details

## Description
The approveService function in the TokenManager contract attempts to read the token address by invoking the ``tokenAddress()``` function. However, the design assumes that the tokenAddress() will be correctly retrieved from the TokenManagerProxy's storage through delegate calls. 

The `approveService` function in the TokenManager contract includes a call to this.tokenAddress(), expecting to retrieve the correct token address. The contract assumes this function interacts seamlessly with the proxy's storage and logic. However, if the TokenManagerProxy contract does not define or properly delegate the `tokenAddress()` function, this call will fail.

In a standard proxy pattern, the proxy delegates function calls to the implementation contract, maintaining a separate storage context. If `tokenAddress()` is not appropriately handled in the proxy (either through a missing function or improper storage setup), the function call within approveService will revert, causing the transaction to fail. This results in the inability to correctly approve the service, which may lead to contract malfunction or halt critical operations.

## Proof of Concept
[ITokenManagerProxy](https://github.com/code-423n4/2024-08-axelar-network/blob/main/interchain-token-service/contracts/interfaces/ITokenManagerProxy.sol#L30) 
```
/**
     * @notice A function to renew approval to the service if we need to.
     */
    function approveService() external onlyService {
        /**
         * @dev Some tokens may not obey the infinite approval.
         * Even so, it is unexpected to run out of allowance in practice.
         * If needed, we can upgrade to allow replenishing the allowance in the future.
         */
        IERC20(this.tokenAddress()).safeCall(abi.encodeWithSelector(IERC20.approve.selector, interchainTokenService, UINT256_MAX));
    }
```
This function above in the `TokenManager` contract makes a call to `TokenManagerProxy` to get the tokenAddress stored in [tokenAddress()](https://github.com/code-423n4/2024-08-axelar-network/blob/4572617124bed39add9025317d2c326acfef29f1/interchain-token-service/contracts/interfaces/ITokenManagerProxy.sol#L30)function:
```
**
     * @notice Returns token address that this token manager manages.
     * @return address The token address.
     */
    function tokenAddress() external view returns (address);
```
However the function which was called to get the tokenAddress never stored anything or let me say didn't implement the function logic in the `TokenManagerProxy` contract. When the `TokenManagerProxy` gets this call from the `TokenManager`, the Proxy contract delegates a back to the implementation contract (TokenManager) as an empty stored slot. 

See the following functions which stores value to slot in the [Proxy contract](https://github.com/code-423n4/2024-08-axelar-network/blob/main/interchain-token-service/contracts/proxies/TokenManagerProxy.sol):
```

    /**
     * @notice Returns implementation type and token address.
     * @return implementationType_ The implementation type.
     * @return tokenAddress_ The token address.
     */
    function getImplementationTypeAndTokenAddress() external view returns (uint256 implementationType_, address tokenAddress_) {
        implementationType_ = implementationType;
        tokenAddress_ = tokenAddress;
    }

    /**
     * @notice Returns the address of the current implementation.
     * @return implementation_ The address of the current implementation.
     */
    function implementation() public view override(BaseProxy, IProxy) returns (address implementation_) {
        implementation_ = _tokenManagerImplementation(interchainTokenService, implementationType);
    }

    /**
     * @notice Returns the implementation address from the interchain token service for the provided type.
     * @param interchainTokenService_ The address of the interchain token service.
     * @param implementationType_ The token manager type.
     * @return implementation_ The address of the implementation.
     */
    function _tokenManagerImplementation(
        address interchainTokenService_,
        uint256 implementationType_
    ) internal view returns (address implementation_) {
        implementation_ = ITokenManagerImplementation(interchainTokenService_).tokenManagerImplementation(implementationType_);
    }
```

## Recommendation
Update the `TokenManagerProxy` contract to ensure that the tokenAddress() function is properly defined and its storage is correctly managed. 
```
    function tokenAddress() external view returns (address) {
    tokenAddress_ = tokenAddress;
}
