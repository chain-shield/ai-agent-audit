# Vulnerability details

## Description
The `TokenManagerProxy` contract, designed to delegate calls to the `TokenManager` implementation contract, includes a setup function intended for one-time initialization during the proxy's construction. However, due to the absence of a robust mechanism to prevent multiple invocations, this function can potentially be called more than once.
 
The TokenManagerProxy employs a proxy pattern to delegate execution to the TokenManager implementation contract. During the proxy's construction, the setup function within the implementation is called via delegatecall to initialize critical contract parameters, including operator roles and flow limiter settings. The setup function is explicitly marked with an `onlyProxy` modifier, ensuring that only the proxy can invoke this function. Despite this restriction, the design lacks a mechanism to enforce single-time invocation, which presents a significant vulnerability.

## Proof of Concept
***Upon deployment, `TokenManagerProxy` calls the setup function in the implementation contract using delegatecall. This function sets up the operator roles and other essential configurations.
The setup function is meant to be executed only once, safeguarding the initialization integrity of the contract.***
```solidity

    /**
     * @notice Constructs the TokenManagerProxy contract.
     * @param interchainTokenService_ The address of the interchain token service.
     * @param implementationType_ The token manager type.
     * @param tokenId The identifier for the token.
     * @param params The initialization parameters for the token manager contract.
     */
    constructor(address interchainTokenService_, uint256 implementationType_, bytes32 tokenId, bytes memory params) {
        if (interchainTokenService_ == address(0)) revert ZeroAddress();

        interchainTokenService = interchainTokenService_;
        implementationType = implementationType_;
        interchainTokenId = tokenId;

        address implementation_ = _tokenManagerImplementation(interchainTokenService_, implementationType_);
        if (implementation_ == address(0)) revert InvalidImplementation();

        (bool success, ) = implementation_.delegatecall(abi.encodeWithSelector(IProxy.setup.selector, params));  <---------
        if (!success) revert SetupFailed();

        tokenAddress = IBaseTokenManager(implementation_).getTokenAddressFromParams(params);
    }
```
***The current implementation does not utilize a state flag (e.g., initialized) to prevent multiple calls to the setup function.
Without this safeguard, if the proxy or any external actor manages to trigger setup again, the contract's state could be reset or reconfigured, leading to catastrophic failures in contract operations.***
```solidity
function setup(bytes calldata params_) external override(Implementation, IImplementation) onlyProxy {
        bytes memory operatorBytes = abi.decode(params_, (bytes));

        address operator = address(0);

        if (operatorBytes.length != 0) {
            operator = operatorBytes.toAddress();
        }

        // If an operator is not provided, set `address(0)` as the operator.
        // This allows anyone to easily check if a custom operator was set on the token manager.
        _addAccountRoles(operator, (1 << uint8(Roles.FLOW_LIMITER)) | (1 << uint8(Roles.OPERATOR)));
        // Add operator and flow limiter role to the service. The operator can remove the flow limiter role if they so chose and the service has no way to use the operator role for now.
        _addAccountRoles(interchainTokenService, (1 << uint8(Roles.FLOW_LIMITER)) | (1 << uint8(Roles.OPERATOR)));
    }
```

## Impact
Reinitializing the contract can disrupt the established configuration, resulting in operational anomalies.

## Tools Used
Manual Review

## Recommended Mitigation Steps
Introduce a boolean flag (e.g., initialized) in the proxy's storage, set to true upon the first successful execution of setup. Any subsequent calls should check this flag and revert if already set.
```solidity
bool private initialized;

function setup(bytes calldata params_) external override onlyProxy {
    require(!initialized, "Contract already initialized");
    initialized = true;
    // Proceed with setup logic
}
```
