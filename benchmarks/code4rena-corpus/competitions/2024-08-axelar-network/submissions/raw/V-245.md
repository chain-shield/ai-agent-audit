# Vulnerability details

## Impact
The ``InterchainTokenFactory`` contract lacks event emissions for critical operations such as token deployment and registration.  Off-chain systems and users might not easily track when new tokens are deployed or registered, limiting the contract's observability.
## Proof of Concept
The following key functions in the ``InterchainTokenFactory`` contract perform critical operations without emitting any events:

## Recommended Mitigation Steps
Ensure that all relevant information is included in the events to facilitate comprehensive off-chain tracking.
```solidity
event InterchainTokenDeployed(bytes32 indexed tokenId, address indexed deployer, string name, string symbol, uint8 decimals, uint256 initialSupply, address minter);
event RemoteInterchainTokenDeployed(bytes32 indexed tokenId, string originalChainName, address indexed deployer, address minter, string destinationChain);
event CanonicalInterchainTokenRegistered(bytes32 indexed tokenId, address indexed tokenAddress);
event GatewayTokenRegistered(bytes32 indexed tokenId, bytes32 tokenIdentifier, string symbol);
```
