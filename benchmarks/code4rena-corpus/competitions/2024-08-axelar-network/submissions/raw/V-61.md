# Vulnerability details

## Description
The Axelarnet Gateway contract is initliazed by calling `instantiate()`:
```rust
#[cfg_attr(not(feature = "library"), entry_point)]
pub fn instantiate(
    deps: DepsMut,
    _env: Env,
    _info: MessageInfo,
    msg: InstantiateMsg,
) -> Result<Response, axelar_wasm_std::error::ContractError> {
    cw2::set_contract_version(deps.storage, CONTRACT_NAME, CONTRACT_VERSION)?;

    let router = deps
        .api
        .addr_validate(&msg.router_address)
        .change_context(Error::InvalidAddress(msg.router_address.clone()))?;

    let config = Config {
        chain_name: msg.chain_name,
        router,
    };

    state::save_config(deps.storage, &config).change_context(Error::InvalidStoreAccess)?;

    Ok(Response::new())
}
```

If we take a look at the [Cosmwasm docs](https://docs.cosmwasm.com/docs/smart-contracts/migration), we can find the following:
```md
CosmWasm made contract migration a first-class experience. 
When instantiating a contract, there is an optional admin field that you can set. 
If it is left empty, the contract is immutable. 
If it is set (to an external account or governance contract), that account can trigger a migration. 
The admin can also change admin or even make the contract fully immutable after some time. 
However, when we wish to migrate from contract A to contract B, contract B needs to be aware somehow of how the state was encoded.
```

In the `instantiate()` function shown above, there is no `admin` field set. This means that this contract is immutable and contrary to the intention of the Sponsor, `migrate()` will not be callable:
```rust
#[cfg_attr(not(feature = "library"), entry_point)]
pub fn migrate(
    deps: DepsMut,
    _env: Env,
    _msg: Empty,
) -> Result<Response, axelar_wasm_std::error::ContractError> {
    cw2::set_contract_version(deps.storage, CONTRACT_NAME, CONTRACT_VERSION)?;

    Ok(Response::default())
}
```

This results in a non-upgradeable contract, even though it should be upgradeable, breaking one of the invariants set in the `README.md`.
