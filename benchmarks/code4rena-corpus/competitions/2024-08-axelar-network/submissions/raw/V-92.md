# Vulnerability details

## Impact
TokenHandler.giveToken() function - this function gives a token to a specified address from the token manager. An attacker can affect the operation of the contract by calling the giveToken() function with its own parameters:
https://github.com/code-423n4/2024-08-axelar-network/blob/main/interchain-token-service/contracts/TokenHandler.sol#L45-L79

## Proof of Concept
The giveToken() function has an external data type and does not check the address of the caller for permission. Thus, this function can be called by anyone with their own parameters.

## Tools Used
Manual review

## Recommended Mitigation Steps
Add a check to the TokenHandler.giveToken() function that only the InterchainTokenService.sol contract can call it.
