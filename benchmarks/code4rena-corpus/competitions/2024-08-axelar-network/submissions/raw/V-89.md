# Vulnerability details

## Impact
The Axelar description states: "ERC20 used by the protocol: Any (all possible ERC20s)". The InterchainTokenFactory.sol and TokenHandler.sol contracts use the symbol parameter reading via the symbol() command. The symbol parameter is of type string:

https://github.com/code-423n4/2024-08-axelar-network/blob/main/interchain-token-service/contracts/InterchainTokenFactory.sol#L199
https://github.com/code-423n4/2024-08-axelar-network/blob/main/interchain-token-service/contracts/InterchainTokenFactory.sol #L290
https://github.com/code-423n4/2024-08-axelar-network/blob/main/interchain-token-service/contracts/InterchainTokenFactory.sol#L317
https://github.com/code-423n4/2024-08-axelar-network/blob/main/interchain-token-service/contracts/TokenHandler.sol#L113

However, not all tokens are of type metadata string.
