# Vulnerability details

## Impact
Detailed description of the impact of this finding.

Lack of Zero Address Check in transferOperatorship Function in the AxelarAmplifierGateway contract

The transferOperatorship function allows the current operator or owner to transfer the operator role to a new address. 

However, the transferOperatorship function does not verify if the newOperator is not a zero address (address(0)). 

Assigning the zero address to the operator role can result in the loss of control over the operator-specific functions, potentially leading to governance issues or other critical operational failures.

## Proof of Concept
Provide direct links to all referenced code in GitHub. Add screenshots, logs, or any other relevant proof that illustrates the concept.

Potential loss of contract control due to setting an essential role to a zero address.

Vulnerable Code:
```sol
    function transferOperatorship(address newOperator) external onlyOperatorOrOwner {
        _transferOperatorship(newOperator);
    }
```

Here’s a simplified scenario demonstrating the issue:

1. The current operator calls transferOperatorship with the zero address by mistake or maliciously:
```sol
contract.transferOperatorship(address(0));
```

2. The _transferOperatorship function sets the operator to address(0).

3. Any subsequent actions requiring the operator’s authority would become unexecutable, as address(0) cannot perform transactions or execute functions.

## Recommended Mitigation Steps

To prevent this vulnerability, a check should be added in the transferOperatorship function to ensure that the newOperator is not zero addresses. 

Here is the proposed mitigation code:
```sol
function transferOperatorship(address newOperator) external onlyOperatorOrOwner {
          require(newOperator != address(0), “Zero address not allowed”);
        _transferOperatorship(newOperator);
    }
```

This mitigation ensures that the operator role cannot be inadvertently set to an invalid address, thereby preserving the control and integrity of the contract’s governance functions.
