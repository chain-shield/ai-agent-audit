# Vulnerability details

`deployInterchainToken()` deploys a new interchain token with specified parameters.
When there is a `initialSupply` value specified, tokens should be minted to the specified `minter` address as specified in the Natspec.

"*@dev Creates a new token and optionally mints an initial amount to a specified minter.*"

However the tokens are minted to the `sender` (msg.sender) instead of the `minter`.

## Proof of Concept
As can be seen on Line 151, the address is set to the address of msg.sender aka `sender`.
```solidity
File: InterchainTokenFactory.sol

127:   function   deployInterchainToken(
          ...
135:      address sender = msg.sender;
          ...
151:      token.mint(sender, initialSupply);  // @note - minted to sender
```
## Impact
Tokens minted to the wrong address.

## Tools Used
Manual Review

## Recommended Mitigation Steps
Also add a check here to ensure that the tokens are not minted to address(0).
```solidity
File: InterchainTokenFactory.sol

- 151:      token.mint(sender, initialSupply);

            if (minter != address(0) {
+ 151:         token.mint(minter, initialSupply);
            }
```
