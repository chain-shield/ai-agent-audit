# Vulnerability details

## Description
In case a user wants to transfer native tokens across chains, the expressExecute function at the InterchainTokenService contract is payable and attempts to call TokenHandler's transferTokenFrom function. 
The logic, however, has some oversights:
The first one is the msg.value of the payable call. If a user wants to send some native tokens at the express execution, there should be sanity checks ensuring the payload-encoded amount corresponds to the msg.value. This doesn't happen at the `expressExecute` or at the `_expressExecute` implementations.

The second oversight is at the delegate call to  TokenHandler's transferTokenFrom function:
the `_expressExecute` function decodes the amount but never checks if the tokenId's corresponding token address is zero and doesn't check if the amount is equal to the msg.value:
```solidity
function _expressExecute(bytes32 commandId, string calldata sourceChain, bytes calldata payload) internal {
        (, bytes32 tokenId, bytes memory sourceAddress, bytes memory destinationAddressBytes, uint256 amount, bytes memory data) = abi
            .decode(payload, (uint256, bytes32, bytes, bytes, uint256, bytes));
       ...
            (bool success, bytes memory returnData) = tokenHandler.delegatecall(
                abi.encodeWithSelector(ITokenHandler.transferTokenFrom.selector, tokenId, msg.sender, destinationAddress, amount)
            );
    ...
}
```
## Impact
Malicious users may attempt to do native transfers with amounts set on the payload without sending any msg.value in order to spend the available InterchainTokenService native funds.
Legitimate users that want to help the protocol work by doing express executions may set amounts lower than the msg.value and not receive any sort of refund.

## Tools Used
Manual review
## Recommended Mitigation Steps
Make sure the amount variable decoded at the payload is sanity checked in case the tokenId's corresponding token address is zero.
Make sure not to allow users to send a msg.value different than this amount.
