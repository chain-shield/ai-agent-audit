***ERC20Permit contract has Block Timestamp Manipulation Risk.***

Mythril Log:

Issue Type: Time Manipulation

The permit function of the ERC20Permit contract utilizes block.timestamp to determine if the deadline for the permit has expired. The specific code segment is:
```sol
if (block.timestamp > deadline) revert PermitExpired();
```

This code introduces a potential security risk because the block.timestamp is a variable that can be manipulated within a certain range by a malicious miner. Miners can choose a timestamp that slightly deviates (typically within a 15-second window) from the actual current time, potentially allowing them to exploit the timing of transactions.

For example, a miner could delay the inclusion of a transaction until the block.timestamp is just before or after the deadline, depending on whether the miner benefits from the permit being valid or invalid at that time.

Exploitability: 
Miners with the ability to manipulate block.timestamp could execute or prevent the execution of permit based on the expiration logic.

Loss of Trust: 
Users relying on strict timing mechanisms for permits may lose trust in the system if they suspect that miners can affect the outcome of permit validity.

Mitigation Complexity: 
Preventing such issues requires careful consideration of alternative mechanisms to replace or supplement the block.timestamp check.

## Proof of Concept

A miner might exploit the following transaction sequence to influence the outcome of a permit:

1. A user submits a transaction with a deadline close to the current time.
2. The miner delays including the transaction in a block until the deadline passes or is about to pass, depending on their preference.
3. The miner manipulates block.timestamp to just fall within or outside the deadline, influencing whether the permit function reverts.

## Recommended Mitigation Steps

To mitigate the risk associated with block.timestamp manipulation, you can introduce an external time oracle that provides a more reliable current time. Below is an example of how you might integrate a time oracle into the ERC20Permit contract’s permit function.

Step 1: Define the Time Oracle Interface

You need to define an interface for the time oracle, which will return the current time. This oracle should be trusted and ideally decentralised.
```sol
interface ITimeOracle {
    function getCurrentTime() external view returns (uint256);
}
```

Step 2: Integrate the Time Oracle into the ERC20Permit Contract

You then modify the ERC20Permit contract to use the time from the oracle instead of block.timestamp.
```sol
// SPDX-License-Identifier: MIT
pragma solidity ^0.8.4;

import { IERC20 } from '../../../axelar-gmp-sdk-solidity/contracts/interfaces/IERC20.sol';
import { IERC20Permit } from '../../../axelar-cgp-solidity/contracts/interfaces/IERC20Permit.sol';
import { ERC20 } from './ERC20.sol';
import { ITimeOracle } from './ITimeOracle.sol';  // Import the Time Oracle interface

/**
 * @title ERC20Permit Contract with Time Oracle
 * @dev Extension of ERC20 to include permit functionality (EIP-2612) with a Time Oracle for improved security.
 * Allows for approval of ERC20 tokens by signature rather than transaction.
 */
contract ERC20PermitWithOracle is IERC20, IERC20Permit, ERC20 {
    error PermitExpired();
    error InvalidS();
    error InvalidV();
    error InvalidSignature();

    ITimeOracle public timeOracle;  // Oracle contract for getting the current time

    constructor(address _timeOracle) {
        timeOracle = ITimeOracle(_timeOracle);
    }

    /**
     * @dev Represents hash of the EIP-712 Domain Separator.
     */
    bytes32 public nameHash;

    string private constant EIP191_PREFIX_FOR_EIP712_STRUCTURED_DATA = '\x19\x01';

    // keccak256('EIP712Domain(string name,string version,uint256 chainId,address verifyingContract)')
    bytes32 private constant DOMAIN_TYPE_SIGNATURE_HASH = bytes32(0x8b73c3c69bb8fe3d512ecc4cf759cc79239f7b179b0ffacaa9a75d522b39400f);

    // keccak256('Permit(address owner,address spender,uint256 value,uint256 nonce,uint256 deadline)')
    bytes32 private constant PERMIT_SIGNATURE_HASH = bytes32(0x6e71edae12b1b97f4d1f60370fef10105fa2faae0126114a169c64845d6126c9);

    /**
     * @dev Mapping of nonces for each address.
     */
    mapping(address => uint256) public override nonces;

    /**
     * @notice Internal function to set the token name hash
     * @param name The token name
     */
    function _setNameHash(string memory name) internal {
        nameHash = keccak256(bytes(name));
    }

    /**
     * @notice Calculates the domain separator.
     * @dev This is not cached because chainid can change on chain forks.
     */
    // solhint-disable func-name-mixedcase
    // slither-disable-next-line naming-convention
    function DOMAIN_SEPARATOR() public view override returns (bytes32) {
        return keccak256(abi.encode(DOMAIN_TYPE_SIGNATURE_HASH, nameHash, keccak256(bytes('1')), block.chainid, address(this)));
    }

    // solhint-enable func-name-mixedcase

    /**
     * @notice Permit the designated spender to spend the holder's tokens
     * @dev The permit function is used to allow a holder to designate a spender
     * to spend tokens on their behalf via a signed message.
     * @param issuer The address of the token holder
     * @param spender The address of the designated spender
     * @param value The number of tokens to be spent
     * @param deadline The time at which the permission to spend expires
     * @param v The recovery id of the signature
     * @param r Half of the ECDSA signature pair
     * @param s Half of the ECDSA signature pair
     */
    function permit(
        address issuer,
        address spender,
        uint256 value,
        uint256 deadline,
        uint8 v,
        bytes32 r,
        bytes32 s
    ) external override {
        uint256 currentTime = timeOracle.getCurrentTime(); // Get current time from the oracle

        if (currentTime > deadline) revert PermitExpired();

        if (uint256(s) > 0x7FFFFFFFFFFFFFFFFFFFFFFFFFFFFFFF5D576E7357A4501DDFE92F46681B20A0) revert InvalidS();

        if (v != 27 && v != 28) revert InvalidV();

        bytes32 digest = keccak256(
            abi.encodePacked(
                EIP191_PREFIX_FOR_EIP712_STRUCTURED_DATA,
                DOMAIN_SEPARATOR(),
                keccak256(abi.encode(PERMIT_SIGNATURE_HASH, issuer, spender, value, nonces[issuer]++, deadline))
            )
        );

        address recoveredAddress = ecrecover(digest, v, r, s);

        if (recoveredAddress != issuer) revert InvalidSignature();

        _approve(issuer, spender, value);
    }
}
```

1. Time Oracle Integration: 
The contract now accepts the address of a TimeOracle contract through the constructor. This oracle is used to retrieve the current time.

2. Time Check: 
The block.timestamp check is replaced by currentTime, which is fetched from the TimeOracle.

3. Security Enhancement: 
By using a trusted oracle for time, the contract is protected against miner manipulation of block.timestamp, making the permit function more secure.
