# Vulnerability details

## Impact
In `InterchainTokenFactory::deployInterchainToken` if minter is not address(0), he is set as a flow limiter for consistency with the remote token manager. In `InterchainTokenFactory::deployRemoteInterchainToken` there is a if clause on L203 to set the minter if he is not address(0), but doesn't do anything if it is zero in both functions. As the minter is the address to distribute the token on the destination chain this can cause mishandlng of tokens and thus loss of funds.

## Tools Used
Manual review

## Recommended Mitigation Steps
Add a require or if statement for minter and revert if it equals address(0)
