# Vulnerability details

## Impact
Detailed description of the impact of this finding.

Functions that override those declared in an interface or a base contract must include the override specifier. Failing to do so leads to compilation errors, preventing the contract from being successfully deployed or used. This error hinders the contract’s functionality and may disrupt the contract upgrade process, resulting in potential downtime or inability to upgrade the system.

In the provided Solidity contract code, several functions are missing the override specifier, which is mandatory when a function is overriding a function in a parent contract or interface. The lack of the override keyword causes a TypeError during compilation, which results in a fatal error. This issue occurs across multiple contracts as highlighted by the error messages.
