# Vulnerability details

## Impact
Detailed description of the impact of this finding.

Compilation error in the AxelarAmplifierGateway contract due to Incompatible Solidity Version Specified in Pragma.

The AxelarAmplifierGateway contract is specified to use Solidity version 0.8.0 in its pragma directive:
```sol
pragma solidity ^0.8.0;
```

However, the compiler encountered a fatal error due to issues in this Solidity version. 

Specifically, the compiler version 0.8.0 has known issues that could lead to parser errors or other unexpected behaviours, which are resolved in later versions of Solidity, starting from 0.8.4.

Customer Impact:
This issue prevents the contract from being compiled successfully, which blocks the deployment and use of the contract. 

As a result, all functionalities provided by the contract, such as message approvals, signer rotations, and operator management, become inaccessible. 

This will significantly delay project milestones and hinder customers’ ability to utilise the platform for their cross-chain operations.

Company Impact:
The company may experience delays in product release schedules, potentially leading to financial setbacks and reputation damage. 

Customers may lose trust in the company’s ability to deliver reliable solutions if fundamental issues like this are not resolved promptly.

## Recommended Mitigation Steps

These issues stem from using an outdated and buggy version of the Solidity compiler.

To resolve this issue, the Solidity pragma version should be updated to at least 0.8.4, which includes important bug fixes and stability improvements. 

The updated pragma directive should be:
```sol
pragma solidity ^0.8.4;
```

This change ensures that the contract will be compiled using a more stable version of the Solidity compiler, which avoids the known issues present in version 0.8.0.
