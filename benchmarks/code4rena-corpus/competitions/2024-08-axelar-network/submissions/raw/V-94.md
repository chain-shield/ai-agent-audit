# Vulnerability details

## Impact
Detailed description of the impact of this finding.

The absence of the override specifier in an overriding function can lead to compilation failures, which prevent the contract from being deployed or executed on the blockchain. This can cause significant delays in the deployment process and potentially lead to unexpected behaviour if the function is not correctly recognised as an override by the Solidity compiler.

The contract attempts to override a function defined in an interface, but it fails to include the required override keyword. Solidity requires explicit use of the override specifier to indicate that a function is intended to override a function from a parent contract or interface. The lack of this specifier results in a compilation error.

## Proof of Concept
Provide direct links to all referenced code in GitHub. Add screenshots, logs, or any other relevant proof that illustrates the concept.

This error arises because the signerHashByEpoch function in the BaseWeightedMultisig contract is intended to override a function defined in the IBaseWeightedMultisig interface. Without the override specifier, the compiler cannot verify that this function correctly overrides the one declared in the interface.

Here is the code that causes the issue:
```sol
// In BaseWeightedMultisig.sol

function signerHashByEpoch(uint256 signerEpoch) external view returns (bytes32) {
    return _baseWeightedMultisigStorage().signerHashByEpoch[signerEpoch];
}
```

This function is supposed to override the following interface function:
```sol
// In IBaseWeightedMultisig.sol

function signerHashByEpoch(uint256 signerEpoch) external view returns (bytes32);
```

The missing override keyword leads to a compilation error, preventing the contract from being compiled and deployed.

## Recommended Mitigation Steps

To resolve this issue, the override keyword must be added to the function declaration in the BaseWeightedMultisig contract. This explicitly informs the compiler that the function is intended to override a parent or interface function, thereby resolving the compilation error.

Update the function in the BaseWeightedMultisig contract as follows:
```sol
// In BaseWeightedMultisig.sol

function signerHashByEpoch(uint256 signerEpoch) external view override returns (bytes32) {
    return _baseWeightedMultisigStorage().signerHashByEpoch[signerEpoch];
}
```

By including the override specifier, the Solidity compiler will correctly recognise the function as an override, allowing the contract to compile successfully and behave as expected.
