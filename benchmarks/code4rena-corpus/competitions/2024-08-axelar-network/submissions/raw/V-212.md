# Vulnerability details

The `deployInterchainToken()` deploys a new interchain token with specified parameters. The `minter` parameter can also be `address(0)` as stated in the natspec.

"*If `address(0)` was provided, add it as a minter to allow anyone to easily check that no custom minter was set.*"

However if the minter is set to `address(0)` then no one will be able to call the `mint` & `burn` functions. The only thing one can do with the deployed token contract is to simply read the values using the `interchainTokenService()` and `interchainTokenId()`.

## Proof of Concept
If there is an `initialSupply` set & the `minter` is set to `address(0)`, then after minting the token, the `MINTER` role is transferred from the InterchainTokenFactory to `address(0)`.
 
```solidity
File: InterchainTokenFactory.sol

    function deployInterchainToken(
        ...
        bytes memory minterBytes = new bytes(0);

        if (initialSupply > 0) {
            minterBytes = address(this).toBytes();
        } else if (minter != address(0)) {
            minterBytes = minter.toBytes();
        }

        tokenId = _deployInterchainToken(salt, '', name, symbol, decimals, minterBytes, 0);

        if (initialSupply > 0) {
            IInterchainToken token = IInterchainToken(interchainTokenService.interchainTokenAddress(tokenId));
            ITokenManager tokenManager = ITokenManager(interchainTokenService.tokenManagerAddress(tokenId));

            token.mint(sender, initialSupply);

            token.transferMintership(minter);    // @note - setting to address(0)
            ...
        }
    }
```

Once the `MINTER` role is transferred, the `mint` & `burn` functions are useless because they will revert for any caller calling these functions because of the `onlyRole(uint8(Roles.MINTER))` check.

```solidity
File: InterchainToken.sol

   function mint(address account, uint256 amount) external onlyRole(uint8(Roles.MINTER)) {       // @note - will revert
        _mint(account, amount);
    }

    function burn(address account, uint256 amount) external onlyRole(uint8(Roles.MINTER)) {       // @note - will revert
        _burn(account, amount);
    }
```
Thus `onlyRole()` will revert leading to a DoS.
```solidity
File: RolesBase.sol

    modifier onlyRole(uint8 role) {
        if (!_hasRole(_getRoles(msg.sender), role)) revert MissingRole(msg.sender, role);

        _;
    }
```
