# Vulnerability details


## Impact
The `update_token_balance` function in the `interState.rs` contract of the `interchain-token-service` package does not update the `token_balance` with `TokenBalance::Tracked(balance)`, which prevents the token balance from being saved in storage. Functions that call this method, such as `apply_balance_tracking` in the `execute.rs` contract, will also fail to properly update the token balance and then impact the functionalities of the `execute_message` function in the `execute.rs` contract and the the `execute` function in the `contract.rs` contract.

## Proof of Concept
In the `interchain-token-service` package, the `State.rs` contract's `update_token_balance` function is responsible for updating the token balance of `token_id` on the `chain` in storage, increasing or decreasing the balance by `amount` based on the `is_deposit` flag. However, this function fails to update `token_balance` with the new `balance`, resulting in the updated balance not being saved in storage.
