# Vulnerability details


### Impact

DOS to an entry point to the ITS Hub, considering the attempt reverts when querying a test code in live production.

Now would be key to note that this report only focuses on _querying_ the trusted addresses, however this same bug case is applicable to all other functions under the first test scope that's been implemented in across the ITS, as they all would revert and are being used in core areas across scope raising the impact/severity of the finding.

Below are search commands to pinpoint areas where these functionalities are implemented across scope:

- https://github.com/search?q=repo%3Acode-423n4%2F2024-08-axelar-network+start_token_balance+language%3ARust&type=code
- https://github.com/search?q=repo%3Acode-423n4%2F2024-08-axelar-network+update_token_balance+language%3ARust&type=code
- https://github.com/search?q=repo%3Acode-423n4%2F2024-08-axelar-network+may_load_token_balance+language%3ARust&type=code

Evidently these three are heavily used in [execute.rs](https://github.com/code-423n4/2024-08-axelar-network/blob/4572617124bed39add9025317d2c326acfef29f1/axelar-amplifier/interchain-token-service/src/contract/execute.rs#L428) with the first even causing a revert during [deployments of new interchain tokens](https://github.com/code-423n4/2024-08-axelar-network/blob/4572617124bed39add9025317d2c326acfef29f1/axelar-amplifier/interchain-token-service/src/contract/execute.rs#L135).

### Proof of Concept

Take a look at https://github.com/code-423n4/2024-08-axelar-network/blob/69c4f2c3fcefb1b8eb2129af9c3685a44ae5b6fe/axelar-amplifier/interchain-token-service/src/contract/query.rs#L12-L17

```rust
pub fn all_trusted_addresses(deps: Deps) -> Result<Binary, state::Error> {
    let addresses = state::load_all_trusted_addresses(deps.storage)?
        .into_iter()
        .collect();
    to_json_binary(&AllTrustedAddressesResponse { addresses }).map_err(state::Error::from)
}
```

This function is used to query the trusted addresses in the ITS, it's been externally called via https://github.com/code-423n4/2024-08-axelar-network/blob/69c4f2c3fcefb1b8eb2129af9c3685a44ae5b6fe/axelar-amplifier/interchain-token-service/src/contract.rs#L112-L124

```rust
#[cfg_attr(not(feature = "library"), entry_point)]
pub fn query(
    deps: Deps,
    _: Env,
    msg: QueryMsg,
) -> Result<Binary, axelar_wasm_std::error::ContractError> {
    match msg {
        QueryMsg::TrustedAddress { chain } => query::trusted_address(deps, chain)?,
        QueryMsg::AllTrustedAddresses {} => query::all_trusted_addresses(deps)?,
        QueryMsg::TokenBalance { chain, token_id } => query::token_balance(deps, chain, token_id)?,
    }
    .then(Ok)
}
```

Issue however is that in the [ITS `state.rs`](https://github.com/code-423n4/2024-08-axelar-network/blob/69c4f2c3fcefb1b8eb2129af9c3685a44ae5b6fe/axelar-amplifier/interchain-token-service/src/state.rs#L121) file, the `load_all_trusted_addresses()` is only accessed in a testing environment, due to being under `#[cfg(test)]`, see https://github.com/code-423n4/2024-08-axelar-network/blob/69c4f2c3fcefb1b8eb2129af9c3685a44ae5b6fe/axelar-amplifier/interchain-token-service/src/state.rs#L121-L138

```rust
#[cfg(test)]
// ..snip

pub(crate) fn load_all_trusted_addresses(
    storage: &dyn Storage,
) -> Result<Vec<(ChainName, Address)>, Error> {
    TRUSTED_ITS_ADDRESSES
        .range(storage, None, None, cosmwasm_std::Order::Ascending)
        .collect::<Result<Vec<_>, _>>()
        .map_err(Error::from)
}

```

From the official rust docs: https://doc.rust-lang.org/book/ch11-03-test-organization.html#the-tests-module-and-cfgtest, we can see how it's been specified that we are to use `#[cfg(test)]` when we don't want the code to be part of the compiled results

### Coded POC

The test [here](https://github.com/code-423n4/2024-08-axelar-network/blob/69c4f2c3fcefb1b8eb2129af9c3685a44ae5b6fe/axelar-amplifier/interchain-token-service/src/contract/query.rs#L60-L80) proves the bug case, considering we only attempt to access `state::load_all_trusted_addresses(deps.storage)` in test mode where it gets compiled.

```rust
    #[test]
    fn query_all_trusted_addresses() {
        let mut deps = mock_dependencies();

        let chain1: ChainName = "chain1".parse().unwrap();
        let address1: Address = "address1".parse().unwrap();
        let chain2: ChainName = "chain2".parse().unwrap();
        let address2: Address = "address2".parse().unwrap();

        // Save trusted addresses
        save_trusted_address(deps.as_mut().storage, &chain1, &address1).unwrap();
        save_trusted_address(deps.as_mut().storage, &chain2, &address2).unwrap();

        // Query all trusted addresses
        let bin = all_trusted_addresses(deps.as_ref()).unwrap();
        let res: AllTrustedAddressesResponse = from_json(bin).unwrap();
        assert_eq!(res.addresses.len(), 2);
        assert_eq!(res.addresses.get(&chain1), Some(&address1));
        assert_eq!(res.addresses.get(&chain2), Some(&address2));
    }

```

### Recommended Mitigation Steps

There is already two instances of `#[cfg(test)]` due to a mistake in the code, remove the first one.
