# Vulnerability details

## Impact
Detailed description of the impact of this finding.

The Solidity contract TokenManager was found to have several instances where overriding functions are missing the override specifier. This issue prevents the contract from compiling, resulting in a “Solc experienced fatal error” message. Adding the override specifier to each function resolves the issue, allowing the contract to compile successfully.

The absence of the override specifier on functions that are intended to override functions from parent contracts/interfaces can lead to compiler errors, rendering the contract non-deployable. This prevents the contract from being used in a live environment, effectively halting development or deployment until the issue is resolved.
