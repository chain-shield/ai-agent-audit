# Vulnerability details

## Vulnerability Details
The `BaseWeightedMultisig` contract implements a weighted multisig system where signers can be rotated. The `_rotateSigners` function is responsible for updating the signer set.

It allows for rotating to a repeat signer set and updating its epoch to the latest. This can potentially be exploited to manipulate the signer set history.

## Code Snippet
```solidity
function _rotateSigners(WeightedSigners memory newSigners, bool enforceRotationDelay) internal {
        BaseWeightedMultisigStorage storage slot = _baseWeightedMultisigStorage();

        _validateSigners(newSigners);

        _updateRotationTimestamp(enforceRotationDelay);

        bytes memory newSignersData = abi.encode(newSigners);
        bytes32 newSignersHash = keccak256(newSignersData);

        // assign the next epoch to the new signers
        uint256 newEpoch = slot.epoch + 1;
        slot.epoch = newEpoch;
        slot.signerHashByEpoch[newEpoch] = newSignersHash;

        // signers must be distinct, since nonce should guarantee uniqueness even if signers are repeated
        if (slot.epochBySignerHash[newSignersHash] != 0) revert DuplicateSigners(newSignersHash);

        slot.epochBySignerHash[newSignersHash] = newEpoch;

        emit SignersRotated(newEpoch, newSignersHash, newSignersData);
    }
}
```

## Scenario
1. The contract starts with Signer Set A at epoch 1.
2. It's rotated to Signer Set B at epoch 2.
3. An attacker calls a function that uses `_rotateSigners` to rotate back to Signer Set A.
4. Now Signer Set A is associated with the latest epoch, potentially invalidating signatures from epoch 2.


## Impact
An attacker could potentially exploit this to:
1. Reuse old signer sets, potentially bypassing intended security measures.
2. Manipulate the contract's understanding of which signer set is most recent.
3. Potentially interfere with the `previousSignersRetention` mechanism, affecting signature validation.


## Fix
Implement a check to prevent rotation to a previously used signer set. Add a new mapping to track used signer sets:

```solidity
mapping(bytes32 => bool) public usedSignerSets;

function _rotateSigners(WeightedSigners memory newSigners, bool enforceRotationDelay) internal {
    // ... (earlier part of the function)

    bytes32 newSignersHash = keccak256(newSignersData);

    // Check if this signer set has been used before
    require(!usedSignerSets[newSignersHash], "Signer set already used");

    // ... (rest of the existing function)

    // Mark this signer set as used
    usedSignerSets[newSignersHash] = true;
}
```
