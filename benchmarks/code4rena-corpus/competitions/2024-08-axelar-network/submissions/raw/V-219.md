The TokenHandler contract contract contains a logic to give an ERC-20 approval to the Axelar gateway.
  function _approveGateway(address tokenAddress, uint256 amount) internal {
        uint256 allowance = IERC20(tokenAddress).allowance(address(this), gateway);
        if (allowance == 0) {
            IERC20(tokenAddress).safeCall(abi.encodeWithSelector(IERC20.approve.selector, gateway, amount));
        }

The logic is called through a delegatecall so that the approval is given from 
InterchainTokenservice.



            (success, returnData) = tokenHandler.delegatecall(
            abi.encodeWithSelector(ITokenHandler.postTokenManagerDeploy.selector, tokenManagerType, tokenManager_)
        );

The approval call may be executed in multiple transactions when deploying multiple gateway token mangers for the same tokens .However some ERC-20 tokens may require setting the allowance to zero before setting a  newallowance .This is the case for USDT.
