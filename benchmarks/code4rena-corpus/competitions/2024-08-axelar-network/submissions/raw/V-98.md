# Vulnerability details

## Impact
As anyone can call the `validateProof` and `approveMessages` functions, a malicious user can see the proof provided the first time these functions are called with a valid data hash and then call them multiple times causing a DoS attack as both of these functions are very gas expensive. 

## Proof of Concept
 
 Place the following code in `AxelarAmplifierGateway.js` test file for the `validateProof` and similar test in the comment for `approveMessages`. These tests can show how much time it will cost to execute them multiple times. 

```javascript
it('validateProof can be called multiple times', async () => {
            const messageId = '1';
            const payload = defaultAbiCoder.encode(['address'], [owner.address]);
            const payloadHash = keccak256(payload);
            const sourceChain = 'Source';
            const sourceAddress = 'address0x123';

            const messages = [
                {
                    sourceChain,
                    messageId,
                    sourceAddress,
                    contractAddress: owner.address,
                    payloadHash,
                },
            ];

            const proof = await getProof(APPROVE_MESSAGES, messages, weightedSigners, signers.slice(0, threshold));

            for(let i=0;i<10000;i++) {
                // await gateway.approveMessages(messages, proof);
                // or
                // await gateway.validateProof(keccak256(getApproveMessageData(messages)), proof);
                await expect(gateway.approveMessages(messages, proof)).to.not.be.reverted;
            }
        });
```


## Tools Used
Manual review.

## Recommended Mitigation Steps
1. Add a onlyRole modifier
2. Check if the provided hash has been already approved/validated by the current signers


## Assessed type

DoS
