# Vulnerability details

## Impact
Detailed description of the impact of this finding.

The creation of a new escrow contract in createEscrow() might fail if there are unforeseen conditions (e.g., out-of-gas error or invalid initialization parameters). This could cause a denial of service (DoS), preventing legitimate users from creating escrows.

## Recommended Mitigation Steps
Add checks to ensure valid inputs (e.g., non-zero addresses) before attempting to create an escrow contract. Also, handle failed creation attempts gracefully to prevent DoS.
```sol
function createEscrow(
    address borrower,
    address account,
    address asset
) public override returns (address escrowContract) {
    require(account != address(0), "Invalid account address");
    require(borrower != address(0), "Invalid borrower address");

    escrowContract = getEscrowAddress(borrower, account, asset);

    if (escrowContract.code.length == 0) {
        tmpEscrowParams = TmpEscrowParams(borrower, account, asset);
        new WildcatSanctionsEscrow{salt: _deriveSalt(borrower, account, asset)}();
        sanctionOverrides[borrower][escrowContract] = true;
        _resetTmpEscrowParams();
    }
}
```
