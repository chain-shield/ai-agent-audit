# Vulnerability details

## Overview
The [grantRoles](https://github.com/code-423n4/2024-08-wildcat/blob/fe746cc0fbedc4447a981a50e6ba4c95f98b9fe1/src/access/AccessControlHooks.sol#L393-L402) function in the provided smart contract code is vulnerable to a Denial of Service (DoS) attack due to excessive gas consumption when processing a large number of accounts.

## Description
If an attacker sends a large array of accounts, in the [grantRoles](https://github.com/code-423n4/2024-08-wildcat/blob/fe746cc0fbedc4447a981a50e6ba4c95f98b9fe1/src/access/AccessControlHooks.sol#L393-L402) function, the gas cost for processing this function can become excessively high. This can lead to the transaction failing due to exceeding the gas limit, effectively causing a DoS attack where valid transactions cannot be processed.

## Impact
- **Transaction Failure:** If the gas required to process the function exceeds the block gas limit, the transaction will fail, preventing the intended withdrawals.
- **Service Disruption:** An attacker could exploit this to disrupt normal operations, causing inconvenience or financial loss.

## Recommended Mitigation Steps
