# Vulnerability details

## Impact
The functions defined in `src/IHooksFactory.sol` interface were not implemented in the implementing contract(`HooksFactory.sol`).
The `addAllowedSenderOnChain` function in the `ISphereXEngine.sol` also lacks implementation in the `SphereXConfig.sol` The code will have compilation issues because of unimplemented functions.

## Recommended Mitigation Steps

All functions to be overridden from the `IHooksFactory` interface contract within the `HooksFactory` contract should be modified with the `override` modifier. Also the `addAllpwedSenderOnChain` function in the `ISphereXEngine.sol` interface in `src/spherex` directory should be implemented and overridden within the `SphereXConfig.sol` contract using the `override` modifier.
