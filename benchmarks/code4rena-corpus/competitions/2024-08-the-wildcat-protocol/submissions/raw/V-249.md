# Vulnerability details

##Impact
https://github.com/code-423n4/2024-08-wildcat/blob/fe746cc0fbedc4447a981a50e6ba4c95f98b9fe1/src/WildcatArchController.sol#L157
```
  function registerBorrower(address borrower) external onlyOwner {
    if (!_borrowers.add(borrower)) {
      revert BorrowerAlreadyExists();
    }
    emit BorrowerAdded(borrower);
  }
```
The registerBorrower function, because it lacks a limit on the number of borrowers that can be added, when called in a loop for a large number of borrowers, can consume a significant amount of gas, potentially exceeding the block gas limit. This can lead to DoS attacks and MemoryOOG.

```
function test_registerBorrower_DOS() external {
    // Record the initial amount of gas available
    uint256 initialGas = gasleft();
    uint256 gasUsed;
    uint256 totalGasUsed = 0;
    uint256 borrowerCount = 0;
    
    // Pre-create 1000 unique addresses
    address[] memory borrowers = new address[](1000);

    // Populate the array with unique addresses
    for (uint256 i = 0; i < 1000; i++) {
        borrowers[i] = address(uint160(i + 1)); // Create unique address
    }

    // Register each borrower and calculate the gas used for each operation
    for (uint256 i = 0; i < 1000; i++) {
        // Record the amount of gas before registering the borrower
        uint256 gasBeforeRegister = gasleft();
        
        // Register the borrower
        archController.registerBorrower(borrowers[i]);
        
        // Calculate the gas used for this operation
        gasUsed = gasBeforeRegister - gasleft();
        totalGasUsed += gasUsed;
        borrowerCount++;
    }

    // Log the final count of borrowers registered and the total gas used
    console.log("Final borrower count: %s, Total gas used: %s", borrowerCount, totalGasUsed);
}
```


## Recommended Mitigation Steps
1.Set a Limit on Borrowers: Introduce a maximum limit on the number of borrowers that can be added.
2.Check for Limit Before Adding: Ensure that the number of borrowers does not exceed the limit before adding a new borrower.
