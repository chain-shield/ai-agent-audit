# Vulnerability details

## Impact
If BlackList assest list become very long then Function getBlacklistedAssets() will always revert due to insufficient gas.

## Proof of Concept
1. In WildcatArchController.sol getBlacklistedAssets calls _assetBLacklist.values.
``` 
function getBlacklistedAssets() external view returns (address[] memory) {
    return _assetBlacklist.values();   
  }
```
2. Values function will revert if BlackListAssets value if the set grows to a point where copying to memory consumes too much gas to fit in a block.
```
 function values(AddressSet storage set) internal view returns (address[] memory) {
        bytes32[] memory store = _values(set._inner);
        address[] memory result;

        /// @solidity memory-safe-assembly
        assembly {
            result := store
        }

        return result;
    }
```

Manual review.

## Recommended Mitigation Steps
Implementing check if there is insufficient gas due to large BlacklistAsset list.
