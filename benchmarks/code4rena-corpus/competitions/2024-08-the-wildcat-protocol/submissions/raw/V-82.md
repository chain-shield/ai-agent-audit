# Vulnerability details

## Impact
Detailed description of the impact of this finding.

The createEscrow() function may be vulnerable to denial of service (DoS) due to the block gas limit. If a borrower attempts to create too many escrow contracts within a single transaction or block, the gas required for deploying the contracts could exceed the block gas limit, resulting in failed transactions. This can prevent legitimate users from deploying necessary escrow contracts.

## Recommended Mitigation Steps
Implement batching of escrow creation to ensure that gas limits are respected. You could limit the number of escrows created in a single transaction or break down escrow creation into multiple transactions over time.
```sol
function createBatchEscrow(
    address borrower,
    address[] memory accounts,
    address asset
) public override {
    require(accounts.length <= 10, "Batch limit exceeded");

    for (uint i = 0; i < accounts.length; i++) {
        _createSingleEscrow(borrower, accounts[i], asset);
    }
}

function _createSingleEscrow(
    address borrower,
    address account,
    address asset
) internal {
    address escrowContract = getEscrowAddress(borrower, account, asset);

    if (escrowContract.code.length == 0) {
        tmpEscrowParams = TmpEscrowParams(borrower, account, asset);
        new WildcatSanctionsEscrow{salt: _deriveSalt(borrower, account, asset)}();
        sanctionOverrides[borrower][escrowContract] = true;
        _resetTmpEscrowParams();
    }
}
```
