# Vulnerability details

## Summary
The use of block.timestamp in FixedTermLoanHooks.sol could lead to manipulation risks, as miners can adjust the timestamp slightly.

## Vulnerability Details
In the following code, block.timestamp is used to check if a withdrawal is allowed:

if (market.fixedTermEndTime > block.timestamp) {
    revert WithdrawBeforeTermEnd();
}
Miners can slightly manipulate block.timestamp, which could potentially allow early or delayed withdrawals.

## Impact
This could lead to incorrect or unintended behavior, such as withdrawals occurring before the fixed term ends due to miner manipulation of the block time.

## Proof of Concept
The use of block.timestamp without additional verification leaves room for minor manipulations. A miner could adjust the block time slightly to cause early withdrawals.

## Tools Used
Manual code review.

## Recommended Mitigation Steps
Consider using a trusted time oracle, such as Chainlink, to ensure a more accurate and tamper-resistant time check. Alternatively, a small buffer can be added, but this should be done carefully to avoid affecting the business logic.
