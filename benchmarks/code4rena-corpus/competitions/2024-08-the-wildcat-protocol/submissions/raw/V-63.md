# Vulnerability details

## Impact
Detailed description of the impact of this finding.

 A malicious user could deliberately pass a very large array of addresses (and corresponding timestamps) to force the function to consume more gas than the block limit allows, resulting in failed transactions. This would prevent the contract from functioning properly for legitimate users.
