# Vulnerability details

## Summary
The repay function in WildcatMarket.sol does not perform a balance or ownership check before allowing users to make repayments. This could lead to unauthorized or excessive repayments.
## Vulnerability Details
In the following code, the repay function transfers funds from the caller without checking if the caller is the borrower or has an outstanding debt:
function repay(uint256 amount) external nonReentrant sphereXGuardExternal {
    if (amount == 0) revert_NullRepayAmount();

    asset.safeTransferFrom(msg.sender, address(this), amount);
    emit_DebtRepaid(msg.sender, amount);

    MarketState memory state = _getUpdatedState();
    if (state.isClosed) revert_RepayToClosedMarket();

    // Execute repay hook if enabled
    hooks.onRepay(amount, state, _runtimeConstant(0x24));

    _writeState(state);
}
There is no check for whether the caller is the borrower or if the amount being repaid exceeds the outstanding debt.
## Impact
This could result in unauthorized repayments from users who are not borrowers or excessive repayments that exceed the amount owed, leading to financial inconsistencies in the system.
## Proof of Concept
Any user can call the repay function and transfer funds to the contract without validation, potentially repaying amounts for which they are not liable.
## Tools Used
Manual code review.
## Recommended Mitigation Steps
1.	Implement a check to ensure the caller is the borrower or an authorized account.
2.	Add a balance check to ensure the repayment amount does not exceed the outstanding debt.
