# Vulnerability details

## Impact
 This will revert unexpectedly and user wont be able to withdraw funds. It also dont allow other queue address to withdraw funds wheather pool 
 has enough to fulfill there withdrawal request

## Proof of Concept
Below function will revert the under or overflow error if there is less required amount to fulfill the request.
