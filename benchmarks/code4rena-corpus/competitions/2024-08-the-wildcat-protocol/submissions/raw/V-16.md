# Vulnerability details

## Impact
 mcopy and mstore instructions are low level instructions used to store data in memeory and copy data between memory locations respectively. They require a cancun compatible EVM due to optimization and features only available in the cancun EVM upgrade. Any other solc version will cause deployment issues, compilation issues and contract-EVM compatibilty issues.

## Recommended Mitigation Steps
 Although the cancun-compatible EVM require a solidity version of >=0.8.21, the `0.8.25 version` as specified in the foundry.toml file of this codebase, is not yet released, therefore not recognised by the solidity compiler.Most of the libraries in the `src/libraries` directory, and `src/types/TransientBytesArray.sol` specify invalid solidity versions. You should consider Changing the solidity versions of the contracts to a version of say 0.8.24 (`pragma solidity ^0.8.24`) and specify the following in the foundry.toml file

```
[profile.lib]
solc_version = '0.8.24'
evm_version = 'cancun'
```
