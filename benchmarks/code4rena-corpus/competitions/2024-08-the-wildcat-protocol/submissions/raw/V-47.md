# Vulnerability details

## Impact
The contract allows the owner to remove controllers and markets without any checks on their current status or ongoing operations. This can lead to severe disruptions in the contract's functionality and potentially result in loss of funds or stuck assets.

## Proof of Concept
Lets take a look at both the [`removeController`](https://github.com/code-423n4/2024-08-wildcat/blob/fe746cc0fbedc4447a981a50e6ba4c95f98b9fe1/src/WildcatArchController.sol#L304-L309) and [`removeMarket`](https://github.com/code-423n4/2024-08-wildcat/blob/fe746cc0fbedc4447a981a50e6ba4c95f98b9fe1/src/WildcatArchController.sol#L355-L360) functions:

```solidity
function removeController(address controller) external onlyOwner {
    controllers[controller] = false;
    emit ControllerRemoved(controller);
}

function removeMarket(address market) external onlyOwner {
    markets[market] = false;
    emit MarketRemoved(market);
}
```

These functions allow the owner to remove a controller or market without any checks, simply by setting their status to `false` in the respective mappings.

## Tools Used
Manual review

## Recommended Mitigation Steps
Implement checks and ensure that the controller or market is not currently involved in any active operations before removing it. Also. you can add events to notify users of pending removals.

```solidity
function markMarketForRemoval(address market) external onlyOwner {
    require(markets[market], "Market does not exist");
    require(!marketRemovalPending[market], "Market already marked for removal");
    marketRemovalPending[market] = true;
    marketRemovalTime[market] = block.timestamp + REMOVAL_DELAY;
    emit MarketMarkedForRemoval(market, marketRemovalTime[market]);
}

function finalizeMarketRemoval(address market) external onlyOwner {
    require(marketRemovalPending[market], "Market not marked for removal");
    require(block.timestamp >= marketRemovalTime[market], "Removal delay not passed");
    require(getOpenPositionsCount(market) == 0, "Market has open positions");
    
    markets[market] = false;
    marketRemovalPending[market] = false;
    emit MarketRemoved(market);
}
```
