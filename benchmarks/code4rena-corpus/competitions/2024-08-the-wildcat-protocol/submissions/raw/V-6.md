# Vulnerability details

## Impact
Reentrancy Attack: If the external contract called is malicious or compromised, it could reenter the current contract and execute unintended logic, leading to potential loss or manipulation of state.

## Proof of Concept
The impacted code sections directly in the repository: https://github.com/code-423n4/2024-08-wildcat/blob/main/src/HooksFactory.sol#L75-L77

## Tools Used
Manual review

## Recommended Mitigation Steps
-Apply the `nonReentrant` modifier to all functions that perform critical external calls.
-Ensure that external calls are made after all state changes within the function.

Revised Code Example:

function registerWithArchController() external override nonReentrant {
    IWildcatArchController(_archController).registerController(address(this));
}
