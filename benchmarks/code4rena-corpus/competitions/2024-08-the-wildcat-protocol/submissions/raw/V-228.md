# Vulnerability details

### Impact

AccessControlHooks and FixedTermLoanHooks addresses are automatically encoded as address(0) and the address is not set when market is deployed after. As a result, deploying market will always revert with the hook not found error. 

### Proof of Concept

In the constructor of AccessControlHooks.sol and FixedTermLoanHooks.sol, we can see that the configuration of the hooks encodes the hookAddress as address(0).

```solidity
    HooksConfig optionalFlags = encodeHooksConfig({
      hooksAddress: address(0),
      useOnDeposit: true,
```

And as such, it is expected that before deploying the markets, the deployed hook instance address be retrieved and be set as the hook address before market depoyment. This implementation step is what is followed in the `deployMarketAndHooks` functions.

```solidity
    HooksTemplate memory templateDetails = _templateDetails[hooksTemplate];
    if (!templateDetails.exists) {
      revert HooksTemplateNotFound();
    }
    hooksInstance = _deployHooksInstance(hooksTemplate, hooksTemplateArgs);
    parameters.hooks = parameters.hooks.setHooksAddress(hooksInstance);
```

However, if the two step method of first deploying hooks, and then deploying market is attempted, this will not work as the hookInstance address is not set as the hook address, therefore will still be address(0) as initially encoded. So when the `deployMarket` function attempts to get the hooksInstance address, address(0) is returned, causing the hooksTemplate to also be 0, and the deployment to revert with the `HooksInstanceNotFound()` error.

```solidity
    address hooksInstance = parameters.hooks.hooksAddress();
    address hooksTemplate = getHooksTemplateForInstance[hooksInstance];
    if (hooksTemplate == address(0)) {
      revert HooksInstanceNotFound();
    }
```

### Tools Used
 Manual code review
 
### Recommended Mitigation Steps

Recommend querying the returned address from the `deployHooksInstance` function and setting it as hook address in the hooks before deploying market.
