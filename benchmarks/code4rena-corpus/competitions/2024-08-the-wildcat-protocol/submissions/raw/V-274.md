# Vulnerability details

## Proof of Concept

The ReentrancyGuard contract provided uses a nonReentrant modifier to prevent reentrancy attacks by setting a guard before function execution and clearing it afterward. However, this implementation has a significant limitation: it blocks not only external reentrant calls but also legitimate internal calls between functions protected by the same nonReentrant modifier.

When a nonReentrant function calls another nonReentrant function internally, the reentrancy guard detects the guard as already set and reverts the transaction. This behavior hinders modular contract design and can lead to potential vulnerabilities if not addressed properly.

contract ReentrancyGuard {
    uint256 private constant _NOT_ENTERED = 0;
    uint256 private constant _ENTERED = 1;
    uint256 private _status;

    modifier nonReentrant() {
        require(_status != _ENTERED, "NoReentrantCalls");
        _status = _ENTERED;
        _;
        _status = _NOT_ENTERED;
    }
}

contract test is ReentrancyGuard {
    function functionA() external nonReentrant {
        // Some logic
        functionB();
    }

    function functionB() internal nonReentrant {
        // Some logic
    }
}
1) functionA is an external function protected by the nonReentrant modifier.
2) functionB is an internal function also protected by the nonReentrant modifier.
3) When functionA calls functionB, the nonReentrant modifier on functionB checks the reentrancy guard.
4) Since _status is already set to _ENTERED by functionA, the check in functionB fails, and the transaction reverts with the error "NoReentrantCalls".

##Impact 

- Developers cannot have protected functions call other protected functions internally without causing a revert.

- Developers may end up duplicating code to avoid internal calls, leading to less maintainable and more error-prone contracts.

## Recommended Mitigation Steps

Maybe implement a counter-based reentrancy guard that allows internal calls between protected functions by tracking the depth of function calls : 
    modifier nonReentrant() {
        _guardCounter += 1;
        uint256 localCounter = _guardCounter;
        _;
        require(localCounter == _guardCounter, "NoReentrantCalls");
    }

Or, apply the nonReentrant modifier only to external functions, and ensure internal functions cannot be accessed externally :)
