# Vulnerability details

## Where is bug
Between `WildcatMarketController` and `WildcatArchController`. In the `registerMarket` function of `WildcatArchController` and the `deployMarket` function of `WildcatMarketController`.

In `WildcatArchController.sol`:
```solidity
function registerMarket(address market) external {
  if (!_controllers.contains(msg.sender)) revert NotController();
  if (!_markets.add(market)) revert MarketAlreadyExists();
  emit MarketAdded(msg.sender, market);
}
```

In `WildcatMarketController.sol`:
```solidity
function deployMarket(
  address asset,
  string memory namePrefix,
  string memory symbolPrefix,
  uint256 maxTotalSupply,
  uint16 annualInterestBips,
  uint16 delinquencyFeeBips,
  uint32 withdrawalBatchDuration,
  uint16 reserveRatioBips,
  uint32 delinquencyGracePeriod
) external virtual returns (address market) {
  if (!WildcatArchController(archController).isRegisteredBorrower(msg.sender)) {
    revert NotRegisteredBorrower();
  }
  // market deployment code
  WildcatArchController(archController).registerMarket(market);
}
```

## Impact
Bug allows a controller to register markets for borrowers who are no longer approved in the system. While there is access control preventing non-borrowers from directly deploying markets, the missed check in `registerMarket` means that a controller associated with a removed borrower can continue to register markets. Opening a vector to unauthorized market creation.

## Recommended Mitigation Steps
Change `registerMarket` in `WildcatArchController` to include a check that verifies the borrower associated with the market is still registered:

```solidity
function registerMarket(address market) external {
    if (!_controllers.contains(msg.sender)) revert NotController();
    if (!_markets.add(market)) revert MarketAlreadyExists();
    
    // New check: Verify that the borrower associated with this market is still registered
    address borrower = IWildcatMarketController(msg.sender).borrower();
    if (!isRegisteredBorrower(borrower)) revert BorrowerNotRegistered();

    emit MarketAdded(msg.sender, market);
}
```
