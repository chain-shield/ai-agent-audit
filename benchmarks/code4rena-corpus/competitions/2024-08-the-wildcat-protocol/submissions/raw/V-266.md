# Vulnerability details

## Proof of Concept
The HooksFactory contract uses the create opcode for deploying new hooks instances. However, the test results show that after a simulated block reorganization, the contract address remains the same and the original contract still exists. This indicates a critical vulnerability in handling state persistence and  deployment during blockchain reorganizations.

https://github.com/code-423n4/2024-08-wildcat/blob/fe746cc0fbedc4447a981a50e6ba4c95f98b9fe1/src/HooksFactory.sol#L319
`hooksInstance := create(0, initCodePointer, initCodeSizeWithArgs)`

Add function `test_deployHooksInstance_BlockReorg` in HooksFactory.t.sol
and run with `forge test --mt test_deployHooksInstance_BlockReorg -vvvvv`
```
function test_deployHooksInstance_BlockReorg() external {
    // Initial setup
    archController.registerBorrower(address(this));
    hooksFactory.addHooksTemplate(
        hooksTemplate,
        'name',
        address(0),
        address(0),
        0,
        0
    );

    // Create a snapshot
    uint256 snapshot = vm.snapshot();

    // Deploy initial hooks instance
    bytes memory constructorArgs = 'initial deployment';
    address initialHooks = hooksFactory.deployHooksInstance(hooksTemplate, constructorArgs);

    // Verify initial deployment
    MockHooks initialHooksInstance = MockHooks(initialHooks);
    assertEq(initialHooksInstance.deployer(), address(this));
    assertEq(initialHooksInstance.constructorArgsHash(), keccak256(constructorArgs));

    // Simulate block reorganization
    vm.revertTo(snapshot);
    
    // Redeploy hooks instance
    address reorgHooks = hooksFactory.deployHooksInstance(hooksTemplate, constructorArgs);

    // Verify deployment after reorganization
    MockHooks reorgHooksInstance = MockHooks(reorgHooks);
    assertEq(reorgHooksInstance.deployer(), address(this));
    assertEq(reorgHooksInstance.constructorArgsHash(), keccak256(constructorArgs));

    // Check if the original contract address and the address after reorganization are the same
    assertEq(initialHooks, reorgHooks, "Hooks addresses should be the same after reorg");

    // Verify original contract exists
    uint256 initialCodeSize;
    assembly {
        initialCodeSize := extcodesize(initialHooks)
    }
    assertGt(initialCodeSize, 0);

    // Verify new contract exists
    uint256 reorgCodeSize;
    assembly {
        reorgCodeSize := extcodesize(reorgHooks)
    }
    assertGt(reorgCodeSize, 0);
}
```
