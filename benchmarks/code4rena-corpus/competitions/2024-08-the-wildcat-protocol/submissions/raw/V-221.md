# Vulnerability details

## Proof of Concept
In WildcatSanctionsEscrow.sol, the releaseEscrow function allows sanctioned accounts to release their escrowed assets. If a market employs withdrawal restrictions (e.g., to prevent withdrawals before a certain date), the sanctioned account handling in this function can lead to unexpected behavior. Specifically, the attempt to force a lender into a withdrawal treats these withdrawals as any other, allowing sanctioned accounts to bypass restrictions. This leads to unwanted interest payments to a sanctioned entity's escrow address, where the funds will remain locked until withdrawal restrictions are lifted.

```
function releaseEscrow() public override {
   if (!canReleaseEscrow()) revert CanNotReleaseEscrow();
   
   uint256 amount = balance();
   address _account = account;
   address _asset = asset;
   
   asset.safeTransfer(_account, amount);
   emit EscrowReleased(_account, _asset, amount);
}
```
Sanctioned accounts can receive interest payments via the escrow address.
Markets with withdrawal restrictions can inadvertently enable sanctioned accounts to benefit from interest accrual.

## Recommended Mitigation Steps
Introduce Sanction Checks: Implement checks to prevent releasing escrow if the market employs withdrawal restrictions.
Reconsider Interest Payments: Evaluate the escrow handling mechanism to avoid sanctioned accounts benefiting from interest accrual.
