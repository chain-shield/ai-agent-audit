# Vulnerability details

## Impact
Detailed description of the impact of this finding.

The contract uses block.timestamp for calculating expiry times, which can be slightly manipulated by miners. Although this practice is common, it introduces the potential for small-scale time manipulation, which could lead to undesired behavior in the system. For instance, miners could delay or accelerate actions based on the expiry mechanism, potentially creating situations where actions are executed too early or too late, depending on the expiry-based logic.

## Proof of Concept
Provide direct links to all referenced code in GitHub. Add screenshots, logs, or any other relevant proof that illustrates the concept.

The MarketConstraintHooks contract uses block.timestamp to calculate the expiry of temporary reserve ratios in several places, including the following snippet:
```sol
uint32 expiry = uint32(block.timestamp + 2 weeks);
```

While block.timestamp is widely used as a proxy for time, it is not an entirely accurate source because miners can manipulate it within a range of approximately 15 seconds. This is especially risky in systems where accurate timekeeping is critical.

Affected Function: onSetAnnualInterestAndReserveRatioBips
The timestamp is used here to set an expiry window for temporary reserve ratios:
```sol
uint32 expiry = uint32(block.timestamp + 2 weeks);
```
This makes it possible for a miner to influence the timing of when temporary reserve ratios expire, allowing them to gain a slight advantage by manipulating block timestamps.

## Recommended Mitigation Steps
To mitigate the risk of timestamp manipulation, we recommend using an external, trusted oracle, such as Chainlink’s time oracle, to fetch a more accurate and tamper-resistant current time.

Here is an example of how you could integrate the Chainlink time oracle to replace block.timestamp:

	1.	Add the Chainlink Time Oracle:
```sol
// SPDX-License-Identifier: MIT
pragma solidity ^0.8.20;

interface IChainlinkOracle {
    function getCurrentTime() external view returns (uint256);
}
```
	2.	Update the Contract:

Replace the usage of block.timestamp with the Chainlink time oracle:
```sol
// SPDX-License-Identifier: MIT
pragma solidity ^0.8.20;

import "./IChainlinkOracle.sol";

abstract contract MarketConstraintHooks {
    IChainlinkOracle public chainlinkOracle;

    constructor(address _chainlinkOracle) {
        chainlinkOracle = IChainlinkOracle(_chainlinkOracle);
    }

    function onSetAnnualInterestAndReserveRatioBips(
        uint16 annualInterestBips,
        uint16 reserveRatioBips,
        MarketState calldata intermediateState,
        bytes calldata extraData
    ) public virtual returns (uint16 newAnnualInterestBips, uint16 newReserveRatioBips) {
        uint32 currentTime = uint32(chainlinkOracle.getCurrentTime());
        uint32 expiry = currentTime + 2 weeks;

        // Rest of the function logic...

        return (newAnnualInterestBips, newReserveRatioBips);
    }
}
```
