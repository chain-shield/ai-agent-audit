# Vulnerability details

This report is inspired by this [valid code4rena report](https://github.com/code-423n4/2021-10-mochi-findings/issues/155).
## Impact
The functions  `createWithStoredInitCode()` relies on  `CREATE2` opcode to deploy new contracts . The function does not revert properly if there is a failed contract deployment or revert from the create2 opcode as it does not properly check the returned address for bytecode. The create2 opcode returns the expected address which will never be the zero address .
