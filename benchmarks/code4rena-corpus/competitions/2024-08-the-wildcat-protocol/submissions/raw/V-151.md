# Vulnerability details

## Proof of Concept
WildcatMarketWithdrawals.executeWithdrawal() and WildcatMarketWithdrawals.executeWithdrawals() functions - Execute a pending withdrawal request for a batch that has expired. When calling these functions, if the account is _isSanctioned, funds may be lost due to the lack of escrow != address(0) check.

1. The user calls the WildcatMarketWithdrawals.executeWithdrawal() or WildcatMarketWithdrawals.executeWithdrawals() function.
2. In these functions, the _executeWithdrawal() function is called.
3. If the account is _isSanctioned the escrow address is calculated:
https://github.com/code-423n4/2024-08-wildcat/blob/main/src/market/WildcatMarketWithdrawals.sol#L264-L265
address escrow = _createEscrowForUnderlyingAsset(accountAddress);
4. However, if the calculation results in address escrow == 0, the funds will be sent to address 0.

## Recommended Mitigation Steps
Add check address escrow != 0
