# Vulnerability details

## Summary

In `WildcatMarket.sol`, `repay` function does not include a check to prevent the user from paying more than their outstanding debt. The repay function allows the user to deposit the specified amount, but it does not check whether this amount exceeds the user's current debt. If the user pays more than their debt, an overpayment occurs.

```solidity
/**
   * @dev Transfers funds from the caller to the market.
   *
   *      Any payments made through this function are considered
   *      repayments from the borrower. Do *not* use this function
   *      if you are a lender or an unrelated third party.
   *
   *      Reverts if the market is closed or `amount` is 0.
   */
  function repay(uint256 amount) external nonReentrant sphereXGuardExternal {
    if (amount == 0) revert_NullRepayAmount();

    asset.safeTransferFrom(msg.sender, address(this), amount);
    emit_DebtRepaid(msg.sender, amount);

    MarketState memory state = _getUpdatedState();
    if (state.isClosed) revert_RepayToClosedMarket();

    // Execute repay hook if enabled
    hooks.onRepay(amount, state, _runtimeConstant(0x24));

    _writeState(state);
  }
```

When a user overpays their debt, the excess amount is essentially spent unnecessarily. This can lead to a financial loss for the user, especially when large payments are involved.

The excess payment can disrupt the liquidity accounts and the debt-credit balance within the system. For example, if a user overpays even after the system considers their debt cleared, these assets may not appear in the debt repayment accounts, resulting in excess liquidity being held in the system. Additionally, depending on how the protocol handles the overpayment, it could create imbalances in the assets available for withdrawal by other users.


## Proof of Concept

```solidity
function test_repay_ExcessPayment() external {
    // Let's initiate a borrow transaction for Alice

    asset.mint(address(this), 1e18); // 1 token is minted (0.5 overpayment)
    
    asset.approve(address(market), 1e18); // Allow overpayment

    // Perform the overpayment
    vm.expectEmit(address(market));
    emit DebtRepaid(address(this), 1e18);
    market.repay(1e18); // Pays more than the debt (0.5 debt, paying 1)

    
}

```



## Recommended Mitigation Steps


Control to Prevent Overpayment: A check can be added to the `repay` function to prevent the user from paying more than their debt. For example:

```diff
function repay(uint256 amount) external nonReentrant sphereXGuardExternal {
    if (amount == 0) revert_NullRepayAmount();

    MarketState memory state = _getUpdatedState();
    uint256 outstandingDebt = state.totalDebts().satSub(totalAssets());

+    if (amount > outstandingDebt) {
+        revert_RepayAmountExceedsOutstandingDebt();
+    }

    asset.safeTransferFrom(msg.sender, address(this), amount);
    emit_DebtRepaid(msg.sender, amount);

    if (state.isClosed) revert_RepayToClosedMarket();

    hooks.onRepay(amount, state, _runtimeConstant(0x24));

    _writeState(state);
}

```
