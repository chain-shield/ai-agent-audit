# Vulnerability details

## Impact
Detailed description of the impact of this finding.

The pushProtocolFeeBipsUpdates function has the potential to run into block gas limits when looping through a large number of markets. This can result in a denial of service (DoS) when trying to update protocol fees across all markets associated with a hooks template.

If the number of markets exceeds the block gas limit, the pushProtocolFeeBipsUpdates function will fail, preventing protocol fee updates from being propagated across all markets. This could result in outdated or incorrect fee structures for many markets.

Vulnerable code
```sol
  function pushProtocolFeeBipsUpdates(
    address hooksTemplate,
    uint marketStartIndex,
    uint marketEndIndex
  ) public override nonReentrant {
    HooksTemplate memory details = _templateDetails[hooksTemplate];
    if (!details.exists) revert HooksTemplateNotFound();


    address[] storage markets = _marketsByHooksTemplate[hooksTemplate];
    marketEndIndex = MathUtils.min(marketEndIndex, markets.length);
    uint256 count = marketEndIndex - marketStartIndex;
    uint256 setProtocolFeeBipsCalldataPointer;
    uint16 protocolFeeBips = details.protocolFeeBips;
    assembly {
      // Write the calldata for `market.setProtocolFeeBips(protocolFeeBips)`
      // this will be reused for every market
      setProtocolFeeBipsCalldataPointer := mload(0x40)
      mstore(0x40, add(setProtocolFeeBipsCalldataPointer, 0x40))
      // Write selector for `setProtocolFeeBips(uint16)`
      mstore(setProtocolFeeBipsCalldataPointer, 0xae6ea191)
      mstore(add(setProtocolFeeBipsCalldataPointer, 0x20), protocolFeeBips)
      // Add 28 bytes to get the exact pointer to the first byte of the selector
      setProtocolFeeBipsCalldataPointer := add(setProtocolFeeBipsCalldataPointer, 0x1c)
    }
    for (uint256 i = 0; i < count; i++) {
      address market = markets[marketStartIndex + i];
      assembly {
        if iszero(call(gas(), market, 0, setProtocolFeeBipsCalldataPointer, 0x24, 0, 0)) {
          // Equivalent to `revert SetProtocolFeeBipsFailed()`
          mstore(0, 0x4484a4a9)
          revert(0x1c, 0x04)
        }
      }
    }
  }
```

## Recommended Mitigation Steps

Use a batching approach to process updates across markets in smaller chunks. This prevents hitting the block gas limit by breaking the process into multiple transactions.

```sol
function pushProtocolFeeBipsUpdates(
    address hooksTemplate,
    uint startIndex,
    uint endIndex,
    uint16 protocolFeeBips
) public nonReentrant {
    HooksTemplate memory details = _templateDetails[hooksTemplate];
    require(details.exists, "HooksTemplateNotFound");

    address[] storage markets = _marketsByHooksTemplate[hooksTemplate];
    uint256 maxEndIndex = MathUtils.min(endIndex, markets.length);
    for (uint256 i = startIndex; i < maxEndIndex; i++) {
        markets[i].setProtocolFeeBips(protocolFeeBips);
    }
}
```
The updated function allows for breaking the update process into chunks, which can be called over multiple transactions.
