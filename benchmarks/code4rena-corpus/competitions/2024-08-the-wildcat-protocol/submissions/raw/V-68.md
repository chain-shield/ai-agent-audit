# Vulnerability details

## Overview
The function [executeWithdrawals](https://github.com/code-423n4/2024-08-wildcat/blob/fe746cc0fbedc4447a981a50e6ba4c95f98b9fe1/src/market/WildcatMarketWithdrawals.sol#L212-L229) in the provided smart contract allows for the execution of multiple withdrawal operations in a single transaction. The function accepts two arrays: `accountAddresses` and `expiries`, and performs withdrawals based on these inputs. However, the function does not currently limit the size of these arrays, which could lead to high gas consumption and potential Denial of Service (DoS) vulnerabilities.

## Description
If an attacker sends a large array, in the [executeWithdrawals](https://github.com/code-423n4/2024-08-wildcat/blob/fe746cc0fbedc4447a981a50e6ba4c95f98b9fe1/src/market/WildcatMarketWithdrawals.sol#L212-L229) function, the gas cost for processing this function can become excessively high. This can lead to the transaction failing due to exceeding the gas limit, effectively causing a DoS attack where valid transactions cannot be processed.

## Impact
- **Transaction Failure:** If the gas required to process the function exceeds the block gas limit, the transaction will fail, preventing the intended withdrawals.
- **Service Disruption:** An attacker could exploit this to disrupt normal operations, causing inconvenience or financial loss.
