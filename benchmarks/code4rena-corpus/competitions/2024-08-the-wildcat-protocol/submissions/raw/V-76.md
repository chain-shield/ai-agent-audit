# Vulnerability details

## Impact
Detailed description of the impact of this finding.

Issue type: Insufficient Gas Griefing.

The pushProtocolFeeBipsUpdates function performs external calls to multiple markets, which could potentially fail if not enough gas is provided to those calls, causing the entire function to revert.

If one of the markets does not receive enough gas to complete the update, the entire pushProtocolFeeBipsUpdates function will fail, causing a denial of service for the entire fee update process.

## Recommended Mitigation Steps
Instead of directly failing on every external call, use a try/catch mechanism or check the success of each call without reverting the entire transaction. Log failed calls, allowing for individual failures without impacting the entire batch.
```sol
function pushProtocolFeeBipsUpdates(
    address hooksTemplate,
    uint startIndex,
    uint endIndex,
    uint16 protocolFeeBips
) public nonReentrant {
    HooksTemplate memory details = _templateDetails[hooksTemplate];
    require(details.exists, "HooksTemplateNotFound");

    address[] storage markets = _marketsByHooksTemplate[hooksTemplate];
    uint256 maxEndIndex = MathUtils.min(endIndex, markets.length);
    for (uint256 i = startIndex; i < maxEndIndex; i++) {
        try markets[i].setProtocolFeeBips(protocolFeeBips) {
            // Success, do nothing
        } catch {
            emit MarketUpdateFailed(markets[i]);
        }
    }
}
```
This mitigation ensures that if a market update fails, it won’t impact the rest of the updates. A failure can be logged for future investigation or retrying.
