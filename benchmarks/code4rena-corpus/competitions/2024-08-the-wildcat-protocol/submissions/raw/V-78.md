# Vulnerability details

## Impact
Detailed description of the impact of this finding.

The WildcatArchController contract includes two key functions, _updateSphereXEngineOnRegisteredContractsInSet and updateSphereXEngineOnRegisteredContracts, which involve looping through arrays of contract addresses (e.g., controller factories, controllers, and markets) and making external calls to each address. These external calls use all the available gas without setting a gas limit, making the contract vulnerable to Insufficient Gas Griefing attacks. Specifically, if a malicious contract consumes an excessive amount of gas, it could cause the entire transaction to fail, leading to a Denial of Service (DoS) attack.

In this scenario, _callWith uses the gas() function to pass all available gas when interacting with external contracts, potentially allowing third-party contracts to consume all gas and disrupt contract operations.

Functions Affected:

	•	_updateSphereXEngineOnRegisteredContractsInSet
	•	updateSphereXEngineOnRegisteredContracts

An attacker could deploy a malicious contract that consumes excessive gas when called by _callWith. This would result in transaction failure, causing legitimate operations such as updating the SphereX engine on registered contracts to be blocked. This could lead to a Denial of Service (DoS) by preventing legitimate users from updating controller factories, controllers, or markets.

## Recommended Mitigation Steps
To mitigate the risk of Insufficient Gas Griefing, we can modify the _callWith function to enforce a fixed gas limit when making external calls. By doing this, we can ensure that external contracts are only provided with a limited amount of gas, preventing them from consuming all the available gas and causing transaction failure.

The gas limit should be set high enough to allow legitimate external contracts to execute their operations while still preventing malicious contracts from consuming excessive gas.
```sol
// Solidity coded mitigation
function _callWith(address target, bytes memory data) internal {
    uint256 gasLimit = 100_000; // Set an appropriate gas limit here
    
    assembly {
        if iszero(call(gasLimit, target, 0, add(data, 0x20), mload(data), 0, 0)) {
            returndatacopy(0, 0, returndatasize())
            revert(0, returndatasize())
        }
    }
}
```

function _updateSphereXEngineOnRegisteredContractsInSet(
    EnumerableSet.AddressSet storage set,
    address engineAddress,
    address[] memory contracts,
    bytes memory changeSphereXEngineCalldata,
    bytes memory addAllowedSenderOnChainCalldata,
    bytes4 notInSetErrorSelectorBytes
) internal {
    uint256 gasLimit = 100_000; // Added gas limit for protection

    for (uint256 i = 0; i < contracts.length; i++) {
        address account = contracts[i];
        if (!set.contains(account)) {
            uint32 notInSetErrorSelector = uint32(notInSetErrorSelectorBytes);
            assembly {
                mstore(0, notInSetErrorSelector)
                revert(0x1c, 0x04)
            }
        }

        // Apply gas limit on external calls
        _callWith(account, changeSphereXEngineCalldata);

        if (engineAddress != address(0)) {
            assembly {
                mstore(add(addAllowedSenderOnChainCalldata, 0x24), account)

            _callWith(engineAddress, addAllowedSenderOnChainCalldata);
            emit_NewAllowedSenderOnchain(account);
        }
    }
}
