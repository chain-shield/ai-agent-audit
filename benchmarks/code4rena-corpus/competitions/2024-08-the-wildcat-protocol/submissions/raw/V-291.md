# Vulnerability details

## Summary

The Wildcat protocol allows borrowers to create lending markets for their assets. When a market is created, the borrower defines several parameters, including the reserve ratio. The reserve ratio determines the percentage of the market's assets that must be kept in the market as collateral. A higher reserve ratio means the borrower is required to maintain a larger collateralization ratio.

The setAnnualInterestAndReserveRatioBips function in WildcatMarket does not prevent the borrower from setting the reserveRatioBips to 100% after market creation. This allows the borrower to block further deposits and then withdraw all available assets, effectively stealing funds from the lenders.

## Details

The setAnnualInterestAndReserveRatioBips function in WildcatMarket allows the borrower to update the annualInterestBips and reserveRatioBips of the market after creation.

The function only checks if the new reserveRatioBips is higher than the initial value set at market creation and if there are enough reserves to support the new ratio. It does not prevent the borrower from setting the ratio to the maximum value (10000, representing 100%).

If the borrower sets the reserveRatioBips to 100%, the maximumDeposit function will always return 0, as 100% of the assets will be considered required reserves. This prevents any further deposits into the market.

The borrower can then call the borrow function to withdraw all assets that are not required for covering withdrawals. As the reserveRatioBips is now 100%, all deposited assets are considered free to withdraw, allowing the borrower to drain the market.

## Impact

This vulnerability allows a malicious borrower to steal all assets deposited by lenders in a market by manipulating the reserveRatioBips.

## Scenario

- A borrower creates a market with a reasonable initial reserveRatioBips, attracting lenders to deposit assets.
- After a significant amount of assets are deposited, the borrower calls setAnnualInterestAndReserveRatioBips, setting the reserveRatioBips to 100%.
- The borrower then calls borrow to withdraw all available assets from the market.
- Lenders are unable to deposit more assets due to the 100% reserve ratio and cannot withdraw their existing funds as the borrower has drained the market.

## Fix

Modify the setAnnualInterestAndReserveRatioBips function to include a check that prevents the borrower from setting the reserveRatioBips to 100%. This could be achieved by adding a condition that ensures the new reserveRatioBips is strictly less than 10000.

```solidity
// WildcatMarket.sol

function setAnnualInterestAndReserveRatioBips(
    uint16 _annualInterestBips,
    uint16 _reserveRatioBips
) external nonReentrant sphereXGuardExternal {

        revert_ReserveRatioMustBeBelow100Percent();
    }

    // Existing code...
}
```
