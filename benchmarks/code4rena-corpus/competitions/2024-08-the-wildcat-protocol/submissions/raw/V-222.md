# Vulnerability details

## Proof of Concept
The borrower has the ability to close the market, which stops interest accrual and prevents the penalty of delinquency fees. This is due to the fact that when the market is closed, the timeDelinquent timer is set to zero, removing the accumulation of delinquency fees. This mechanism can be exploited by a borrower to avoid penalty fees intentionally.

```
function closeMarket() external onlyBorrower nonReentrant sphereXGuardExternal {
   MarketState memory state = _getUpdatedState();
   if (state.isClosed) revert_MarketAlreadyClosed();
   ...
   state.timeDelinquent = 0; // Avoids further delinquency fees
}
```
Borrowers can avoid delinquency fees by closing the market while it's in penalized delinquency. This manipulation allows the borrower to evade penalties designed to protect lenders.

## Recommended Mitigation Steps
Introduce Grace Period: Implement a grace period that prevents the immediate closure of the market if it has recently become delinquent.
Accrue Pending Fees: Accrue and apply delinquency fees before allowing market closure to prevent fee avoidance.

function closeMarket() external onlyBorrower nonReentrant sphereXGuardExternal {
    MarketState memory state = _getUpdatedState();
    if (state.isClosed) revert_MarketAlreadyClosed();

    // Check if the market is delinquent and enforce grace period
    if (state.isDelinquent) {
        require(
            block.timestamp >= delinquencyStartTime + gracePeriod,
            "Grace period not elapsed, market closure not allowed"
        );

        // Accrue pending delinquency fees before closure
        uint256 pendingFees = calculatePendingDelinquencyFees(state);
        state.accruedProtocolFees += uint128(pendingFees);
    }

    // Set state to closed
    state.isClosed = true;
    state.timeDelinquent = 0; // Reset delinquency timer
    _writeState(state);
    
    emit MarketClosed(block.timestamp);
}

function calculatePendingDelinquencyFees(MarketState memory state) internal view returns (uint256) {
    // Calculate pending delinquency fees based on timeDelinquent and fee rate
    uint256 timeElapsed = block.timestamp - delinquencyStartTime;
    uint256 feeRate = state.protocolFeeBips; // Use the protocol fee rate or define a specific delinquency fee rate
    uint256 pendingFees = timeElapsed * feeRate; // Simplified calculation, adjust based on the specific fee structure
    return pendingFees;
}
