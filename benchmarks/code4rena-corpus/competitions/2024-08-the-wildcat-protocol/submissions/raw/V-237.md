Description

The LibStoredInitCode library allows deploying initialization (init) code for smart contracts without enforcing size restrictions on the provided init code. This omission poses a risk where deploying excessively large init code can consume a significant amount of gas, potentially causing transactions to fail due to exceeding the block gas limit. Such failures can disrupt the intended functionality of contracts relying on this library, leading to denial of service scenarios.

Impact

Denial of Service (DoS): 
Malicious or accidental deployment of extremely large init code can exhaust gas resources, causing the deployInitCode function to fail. This failure can prevent legitimate contract deployments, disrupting services that depend on the library.

Operational Disruption: 
Contracts utilizing this library may become inoperable if essential deployment functions consistently fail due to gas exhaustion, affecting the reliability and availability of the overall system.

        // Generate an excessively large init code (e.g., 10 million bytes)
        uint256 size = 10_000_000;
        bytes memory largeInitCode = new bytes(size);
        for (uint256 i = 0; i < size; i++) {
            largeInitCode[i] = bytes1(uint8(i % 256));
        }

        // Expect the deployment to revert due to gas exhaustion
        vm.expectRevert(LibStoredInitCode.InitCodeDeploymentFailed.selector);
        LibStoredInitCode.deployInitCode(largeInitCode);
    }
}

## Recommended Mitigation Steps
To prevent the risk of deploying excessively large init codes, it is advisable to implement size restrictions within the deployInitCode function. Enforcing a maximum allowed size ensures that deployments remain within manageable gas consumption limits, mitigating potential DoS attacks.
```sol
// SPDX-License-Identifier: Apache-2.0
pragma solidity >=0.8.24;

library LibStoredInitCode {
    error InitCodeDeploymentFailed();
    error DeploymentFailed();
    error InitCodeTooLarge(uint256 size, uint256 maxSize);

    uint256 internal constant MAX_INIT_CODE_SIZE = 24576; // Example limit (24 KB)

    function deployInitCode(bytes memory data) internal returns (address initCodeStorage) {
        if (data.length > MAX_INIT_CODE_SIZE) {
            revert InitCodeTooLarge(data.length, MAX_INIT_CODE_SIZE);
        }

        assembly {
            let size := mload(data)
            let createSize := add(size, 0x0b)
            // Prefix Code
            //
            // Has trailing STOP instruction so the deployed data
            // can not be executed as a smart contract.
            //
            // Instruction                | Stack
            // ----------------------------------------------------
            // PUSH2 size                 | size                  |
            // PUSH0                      | 0, size               |
            // DUP2                       | size, 0, size         |
            // PUSH1 10 (offset to STOP)  | 10, size, 0, size     |
            // PUSH0                      | 0, 10, size, 0, size  |
            // CODECOPY                   | 0, size               |
            // RETURN                     |                       |
            // STOP                       |                       |
            // ----------------------------------------------------

            // Shift (size + 1) to position it in front of the PUSH2 instruction.
            // Reuse `data.length` memory for the create prefix to avoid
            // unnecessary memory allocation.
            mstore(data, or(shl(64, add(size, 1)), 0x6100005f81600a5f39f300))
            // Deploy the code storage
            initCodeStorage := create(0, add(data, 21), createSize)
            // if (initCodeStorage == address(0)) revert InitCodeDeploymentFailed();
            if iszero(initCodeStorage) {
                mstore(0, 0x11c8c3c0)
                revert(0x1c, 0x04)
            }
            // Restore `data.length`
            mstore(data, size)
        }
    }

    // ... rest of the library code ...
}
```
Size Check Implementation:
Introduced a new constant MAX_INIT_CODE_SIZE set to an example limit of 24 KB (24,576 bytes). This value can be adjusted based on specific requirements.
Added a condition to check if the provided init code exceeds MAX_INIT_CODE_SIZE. If it does, the function reverts with a new error InitCodeTooLarge, providing details about the attempted size and the maximum allowed size.

Error Definition:
Defined a new error InitCodeTooLarge(uint256 size, uint256 maxSize) to provide clear feedback when the size limit is breached.

Integration into Deployment Function:
Placed the size check at the beginning of the deployInitCode function to prevent unnecessary gas consumption when the size limit is violated.
