# Vulnerability details

## Proof of Concept
```
 function _loopTryGetCredential(
    LenderStatus memory status,
    address accountAddress,
    uint256 pullProviderIndexToSkip
  ) internal view returns (bool foundCredential) {
    uint256 providerCount = _pullProviders.length;
    for (uint256 i = 0; i < providerCount; i++) {
      if (i == pullProviderIndexToSkip) continue;
      RoleProvider provider = _pullProviders[i];
      if (_tryGetCredential(status, provider, accountAddress)) return (true);
    }
    // No explicit return statement 
  }
```
The looping function _loopTryGetCredential implicitly returns false if no valid credentials are found.
This lack of explicitness can make it difficult to read, maintain, and understand the flow of the function.


## Recommended Mitigation Steps
Make the return behavior explicit to improve code clarity and maintainability.
Add an explicit return value outside the loop to return false if no valid credential has been found.
```
for (uint256 i = 0; i < providerCount; i++) {  
    if (i == pullProviderIndexToSkip) continue;  
    if (_tryGetCredential(status, provider, accountAddress)) return true;  
}  
return false; // Explicit return statement
```
