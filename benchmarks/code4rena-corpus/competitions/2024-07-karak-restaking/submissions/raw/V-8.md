# Vulnerability details

## Impact
`maxRedeem(address)` checks the maximum amount of shares that a specific account can redeem. 

```solidity
/// @dev Returns the maximum amount of Vault shares that can be redeemed
    /// from the `owner`'s balance in the Vault, via a redeem call.
    ///
    /// - MUST return a limited value if `owner` is subject to some withdrawal limit or timelock.
    /// - MUST return `balanceOf(owner)` otherwise.
    /// - MUST NOT revert.
    function maxRedeem(address owner) public view virtual returns (uint256 maxShares) {
        maxShares = balanceOf(owner);
    }
```

However, using `address(this)` will return the maximum redeemable shares for the contract itself, not the user who is attempting to redeem. Thus, users might attempt to redeem more shares than they are entitled to or users who try to redeem shares based on their actual entitlement may face unnecessary rejections.
