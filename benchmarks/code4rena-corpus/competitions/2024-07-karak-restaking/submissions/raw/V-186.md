# Vulnerability details

## Impact
More assets will be deducted than transferred.

## Proof of Concept

But there is a problem as we can analyse from the function above that is the assets are being subtracted from `self.nodeOwnerToWithdrawAmount[startedWithdrawal.nodeOwner]` before the check `startedWithdrawal.assets > withdrawableAssets` in a case the check is true the value of assets changes to withdrawableAssets which makes the previous `nodeOwnerToWithdrawAmount` out of sync.
