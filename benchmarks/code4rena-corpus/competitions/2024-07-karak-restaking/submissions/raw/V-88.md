# Vulnerability details

## Impact
According to the [doc](https://docs.karak.network/protocol/v2/native-restaking) of the project and the developer, user can restake their ETH on the `NativeNode` contract.However, the contract it self won't be able to accept any native token such as ETH because it doesn't have a fallback or receive function, so any attempt trying to send ETH to `NativeNode` will always fail.

## Proof of Concept
Add the following POC to `test/nativeRestaking/nativeNode.t.sol`
```solidity
function test_sendETHtoNode() public {
        address node = nativeVault.createNode();
        (bool success, ) = payable(node).call{value:10 ether}("");
        if (!success){
            console2.log("Failed to send any eth");
        }
    }
```

## Recommended Mitigation Steps

Add
```solidity
    fallback() external payable {}
    receive() external payable {} 
```
