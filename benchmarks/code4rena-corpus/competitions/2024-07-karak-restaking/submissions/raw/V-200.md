# Vulnerability details

## Impact
whenever there is a failed deployment, it does not revert from the create2 opcode as it does not properly check the returned address for bytecode

## Proof of Concept
in [`CoreLib.cloneVault()`](https://github.com/code-423n4/2024-07-karak/blob/f5e52fdcb4c20c4318d532a9f08f7876e9afb321/src/entities/CoreLib.sol#L149) the function makes a call like `LibClone.deployDeterministicERC1967BeaconProxy(address(this), salt)` which returns the deterministic address for the vault.

 however before this call is done executing there a few things that can go wrong i.e;
if you look in the `LibClone.deployDeterministicERC1967BeaconProxy` you'll see it calls an internal function `deployDeterministicERC1967BeaconProxy` with 3 parameters.
```solidity
    function deployDeterministicERC1967BeaconProxy(uint256 value, address beacon, bytes32 salt)
        internal
        returns (address instance)
    {
        /// @solidity memory-safe-assembly
        assembly {
            let m := mload(0x40) // Cache the free memory pointer.
            mstore(0x60, 0xb3582b35133d50545afa5036515af43d6000803e604d573d6000fd5b3d6000f3)
            mstore(0x40, 0x1b60e01b36527fa3f0ad74e5423aebfd80d3ef4346578335a9a72aeaee59ff6c)
            mstore(0x20, 0x60195155f3363d3d373d3d363d602036600436635c60da)
            mstore(0x09, or(shl(160, 0x60523d8160223d3973), shr(96, shl(96, beacon))))
            instance := create2(value, 0x0c, 0x74, salt)
@-->            if iszero(instance) {
                mstore(0x00, 0x30116425) // `DeploymentFailed()`.
                revert(0x1c, 0x04)
            }
            mstore(0x40, m) // Restore the free memory pointer.
            mstore(0x60, 0) // Restore the zero slot.
        }
    }
```
in that function we can see that after the create2 function execution the next line checks whether the value returned to `instance` is an address(0). 

However that is not a thorough check because whenever there is a failed deployment, it does not revert from the create2 opcode as it does not properly check the returned address for bytecode meaning the return value can be of a valid address but of `codesize = 0`, which is also invalid but our checks will not catch it

## Recommended Mitigation Steps
it is recommended to update iszero(result) to iszero(extcodesize(result)) or check size of code.
