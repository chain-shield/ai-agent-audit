# Vulnerability details

## Impact
As no Ethers can be sent to the `NativeNode` contract, the `withdraw` function does not work.

## Proof of Concept
In the `withdraw` function, we see that it uses OZ's address library to send Ethers to withdrawers. However, as the function sends out Ether, but the contract itself, and its inherited contracts do not contain a payable or receive function, there is no Ether to be withdrawn from.

## Tools Used
Manual review

## Recommended Mitigation Steps
Add a receive function for `NativeNode` contract.
