# Vulnerability details

## Impact

The current functionality in `Core` requires setting max slashable percentage from DSS to be considered registered. However, the DSS might want to set slashable percentage as 0% and do not slash any operators for anything. The problem is that in the current version of the code there is no any flag that indicates that DSS does not slash anything from the operators if it wants to which goes in deviation from the spec.

## Proof of Concept

Take a look at this comment:

https://github.com/code-423n4/2024-07-karak/blob/main/src/Core.sol#L258-261
```
/// @notice Allows the caller to register as a DSS and set the max slashable percentage
    /// @dev If you want to have 0% slashing, set `maxSlashablePercentageWad` to `1` since 0 is used as a default flag for not set
    /// If a operator is set, it will have a non-zero slashable percentage. Hence we can just check for that to see if a DSS is registered
```

Moreover, in the code review performed by the sponsors the same thing was said - that is DSS might want to not slash its operators and it has to specify 1 as `maxSlashablePercentageWad`. However, it's not the case, as when slashing event occurs, 1 in `maxSlashablePercentageWad` is treated exactly like 1%:


https://github.com/code-423n4/2024-07-karak/blob/main/src/entities/SlasherLib.sol#L85-90
```
  for (uint256 i = 0; i < slashingMetadata.vaults.length; ++i) {
            earmarkedStakes[i] = Math.mulDiv(
                slashingMetadata.slashPercentagesWad[i],
                IKarakBaseVault(slashingMetadata.vaults[i]).totalAssets(),
                Constants.MAX_SLASHING_PERCENT_WAD
            );
```

As you can see, the formula just multiplies slash percentage on total assets and divides by max slashing percentage. When validating slashing percentages, there is no any flag for 0% as well:

https://github.com/code-423n4/2024-07-karak/blob/main/src/entities/SlasherLib.sol#L54-55
```
 if (slashingRequest.slashPercentagesWad[i] == 0) revert ZeroSlashPercentageWad();
            if (slashingRequest.slashPercentagesWad[i] > maxSlashPercentageWad) revert MaxSlashPercentageWadBreached();

```

These are the only checks that are performed.

## Tools Used

Manual review.

## Recommended Mitigation Steps

Set some additional flag for 0% slashing.
