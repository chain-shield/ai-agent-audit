# Vulnerability details

## Impact
Anybody can stake their funds to a vault including DSS accounts, however this conflict of interest provides a unique opportunity for DSS to extract maximum value from vaults they run and game the system for more profit by unstaking all their just tokens before they slash. This may not be detected early but will hurt protocol reputation in the long term. while this cannot be completely mitigated as DSS can register through other accounts, it may lead to periodic bank-run type withdrawals from vaults if stakers discover that a staked DSS is has suddenly initiated a withdrawl.

## Proof of Concept
    ```function deposit(uint256 assets, address to)
        public
        override(ERC4626, IVault)
        whenFunctionNotPaused(Constants.PAUSE_VAULT_DEPOSIT)
        nonReentrant
        returns (uint256 shares)
    {
        if (assets == 0) revert ZeroAmount();
        return super.deposit(assets, to);
    }```
Deposits have no check to ensure that DSS account does not directly participate in the staking process.
