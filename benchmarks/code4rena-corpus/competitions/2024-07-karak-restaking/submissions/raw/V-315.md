# Vulnerability details

## Impact
Several functions in the codebase call `HookLib.callHookIfInterfaceImplemented` without checking its return value. This can lead to scenarios where hooks fail to execute properly, but the system continues to operate as if they did. Specifically, the function `registerOperatorToDSS` is the only one where `ignoreFailure: false` is set, indicating that the return value must be checked to ensure the hook was executed successfully.

Not checking the return value in these cases can result in the registration or execution of operators and processes that do not meet necessary interface requirements, potentially causing failures or incorrect behavior in subsequent operations. 

## Proof of Concept

    function callHookIfInterfaceImplemented(
        IERC165 dss,
        bytes memory data,
        bytes4 interfaceId,
        bool ignoreFailure,
        uint32 hookCallGasLimit,
        uint32 supportsInterfaceGasLimit,
        uint32 hookGasBuffer

        if (gasleft() < (supportsInterfaceGasLimit * 64 / 63 + hookGasBuffer)) {
            revert NotEnoughGas();

            abi.encodeWithSelector(IERC165.supportsInterface.selector, interfaceId),
            supportsInterfaceGasLimit

            // Either call failed or interface isn't implemented
