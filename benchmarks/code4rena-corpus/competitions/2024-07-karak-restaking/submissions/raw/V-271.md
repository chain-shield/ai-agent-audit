# Vulnerability details

## Impact
The `handleSlashing` function in the contract is designed to burn ERC20 tokens by transferring them to the zero address. While this approach is intended to remove the tokens from circulation, it may encounter issues with certain ERC20 token implementations that do not allow transfers to the zero address. This can cause the function to revert and break the protocol's functionality when handling specific tokens.

Functionality Breakage: The handleSlashing function will fail for tokens that do not allow transfers to the zero address, such as XRP, Wrapped TON Coin, SHIB-INU, NEAR, UNI, and Bitfinex LEO Token.

Protocol Incompatibility: This incompatibility limits the range of tokens the protocol can handle, contradicting the claim that all ERC20 tokens are supported.
