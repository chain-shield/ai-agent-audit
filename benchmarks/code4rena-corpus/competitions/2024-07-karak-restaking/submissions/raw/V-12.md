# Vulnerability details

## Summary

0xaliyah
arabgodx

1. Owner can change the standard vault implementation without any time-lock, affecting all vaults using the default implementation.

## Vulnerability Detail

1. `changeStandardImplementation` method allowed the owner to change the standard vault implementation and could result in all vaults switching to the potentially faulty or malicious implementation

2. `changeImplementationForVault` allowed the owner to change the implementation for a specific vault, and potentially switching it to the unverified implementation

3. `pauseVault` or `unpauseVault` without any emit

4. owner can allowlist some arbitrary vault implementations at `allowlistVaultImpl`, allowed potentially unverified or malicious implementations inside of the list

## Impact

1. High impact and medium likeliness owasp
