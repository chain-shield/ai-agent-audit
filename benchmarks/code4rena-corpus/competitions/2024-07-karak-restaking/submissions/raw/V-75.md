# Vulnerability details

The veto committee can cancel slashing requests at any time, even beyond the designated veto window. This bypasses the intended security mechanism that limits the time during which the veto committee can intervene to cancel slashing requests.

Specifically, while the system checks for a minimum slashing delay before finalizing a slashing request, it does not enforce any time constraints on the veto committee’s ability to cancel slashing requests.


In `finalizeSlashing` it indicates there's a window for veto to cancel the slashing request, However this is not enforced on the ` cancelSlashing` function.
https://github.com/code-423n4/2024-07-karak/blob/main/src%2Fentities%2FSlasherLib.sol#L126-L131ie
```solidity
function finalizeSlashing(CoreLib.Storage storage self, QueuedSlashing memory queuedSlashing) external {
        bytes32 slashRoot = calculateRoot(queuedSlashing);
        if (!self.slashingRequests[slashRoot]) revert InvalidSlashingParams();
        if (queuedSlashing.timestamp + Constants.SLASHING_VETO_WINDOW > block.timestamp) {
            revert MinSlashingDelayNotPassed();

}
```

## Impact
This undermines the security mechanisms designed to ensure that slashing requests are processed within a predictable and secure timeframe.
Also a malicious or compromised veto committee could exploit this to indefinitely protect certain participants from being slashed , undermining the deterrent effect of the slashing mechanism.

## Proof of Concept

1. A slashing request is made and queued.
2. The veto committee cancels the slashing request even after the `SLASHING_VETO_WINDOW` has passed.
3. This demonstrates that the time constraint is not enforced, allowing slashing requests to be canceled indefinitely.

## Recommended Mitigation Steps

Add a time constraint check in the `cancelSlashing` function to ensure that the veto committee can only cancel slashing requests within the designated veto window. 

```solidity
function cancelSlashing(CoreLib.Storage storage self, QueuedSlashing memory queuedSlashing) external {
        bytes32 slashRoot = calculateRoot(queuedSlashing);
        if (!self.slashingRequests[slashRoot]) revert InvalidSlashingParams();
        if (queuedSlashing.timestamp + Constants.SLASHING_VETO_WINDOW <= block.timestamp) {
            revert VetoWindowPassed();
        }
        delete self.slashingRequests[slashRoot];
```
