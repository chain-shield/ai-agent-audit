# Vulnerability details

## Impact
The `if (totalAssetsToSlash > self.totalAssets)` check can empty asset pool if wrong amount is entered even by accident.

In `slashAssets` function of `NativeVault` contract, the check performed - 
```solidity
        if (totalAssetsToSlash > self.totalAssets) {
            totalAssetsToSlash = self.totalAssets;
        }
```
So, if the owner mistakenly inputs wrong value of `totalAssetsToSlash` greater than `self.totalAssets` then as per the next line - 
```solidity
self.totalAssets -= totalAssetsToSlash;
```
`self.totalAssets ` =0, as `self.totalAssets=self.totalAssets- totalAssetsToSlash` and `totalAssetsToSlash` = `self.totalAssets`
