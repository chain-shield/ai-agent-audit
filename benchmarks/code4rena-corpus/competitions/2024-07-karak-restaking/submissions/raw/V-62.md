# Vulnerability details

## Impact
- Security Risk
- Incorrect Initialization
- Operational Failures

## Proof of Concept
The *'initialize'* function does not validate the *'_depositToken'* address properly. It uses *'_tryGetAssetDecimals(address(_depositToken))'* without ensuring *'_depositToken'* is a valid ERC20 token
Code snippet L62-L71:
```
        (bool decimalsSuccess, uint8 result) = _tryGetAssetDecimals(address(_depositToken));
        VaultLib.Config storage config = _config();

        config.asset = _depositToken;
        config.name = _name;
        config.symbol = _symbol;
        config.decimals = decimalsSuccess ? result : _DEFAULT_UNDERLYING_DECIMALS;
        config.operator = _operator;
        config.extraData = _extraData;
    }
```
If *'_depositToken'* is not a valid ERC20 token, *'_tryGetAssetDecimals'* might fail silently, leading to incorrect configuration.

## Tools Used
Manual review

## Recommended Mitigation Steps
Add a check to ensure *'_depositToken'* is a valid ERC20 token before proceeding with initialization.
```
function initialize(
    address _owner,
    address _operator,
    address _depositToken,
    string memory _name,
    string memory _symbol,
    bytes memory _extraData
) external initializer {
    require(_owner != address(0), "Owner address cannot be zero");
    require(_operator != address(0), "Operator address cannot be zero");
    require(_depositToken != address(0), "Deposit token address cannot be zero");

    _initializeOwner(_owner);
    __Pauser_init();

    // Check if _depositToken is a valid ERC20 token
    require(IERC20(_depositToken).totalSupply() > 0, "Invalid ERC20 token");

    (bool decimalsSuccess, uint8 result) = _tryGetAssetDecimals(address(_depositToken));
    VaultLib.Config storage config = _config();

    config.asset = _depositToken;
    config.name = _name;
    config.symbol = _symbol;
    config.decimals = decimalsSuccess ? result : _DEFAULT_UNDERLYING_DECIMALS;
    config.operator = _operator;
    config.extraData = _extraData;
}
```
Explanation:
- Zero Address Checks: Added *'require'* statements to ensure *'_owner'*, *'_operator'*, and *'_depositToken'* are not zero addresses.
- ERC20 Validation: Added a check using *'IERC20(_depositToken).totalSupply()'* to ensure *'_depositToken'* is a valid ERC20 token.
