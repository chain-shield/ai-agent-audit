## Proof of Concept
As you can see in the code snippet above, the reason 2000 gas is left is for the next act.
```solidity

            revert BeaconTimestampIsCurrent();

        if (
            beaconStateRootProof.timestamp < node.lastSnapshotTimestamp

        uint256 totalRestakedWei;
-->     BeaconProofs.validateBeaconStateRootProof(

        for (uint256 i = 0; i < validatorFieldsProofs.length; i++) {
            totalRestakedWei += self.validateWithdrawalCredentials(
                nodeOwner,
```

However, `_increaseBalance()` is called after `validateBeaconStateRootProof()`.
In `_increaseBalance()`, `_mint()` is called.
But `_mint()` requires more than 2000 gas, so the gas calculation is wrong.
