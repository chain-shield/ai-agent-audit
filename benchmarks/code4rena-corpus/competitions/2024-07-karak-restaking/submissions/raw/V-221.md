# Vulnerability details

The pausing mechanism utilizes a 256-bit bitmap to control the paused and unpaused states of various functions. The constants define indexes for specific functions, starting from 0. The admin can unpause functions by passing a bitmap where the bit at the corresponding index is set to 0.

However, there is a critical flaw:

When the admin wants to unpause specific functions like `PAUSE_VAULT_DEPOSIT`, `PAUSE_CORE_REGISTER_OPERATOR`, `PAUSE_NODE_WITHDRAW`, and `PAUSE_NATIVEVAULT_SLASHER`, they pass a bitmap with bits set to 0 at the corresponding indexes.
If the admin passes 0 to unpause specific functions, it unintentionally unpauses all functions because 0 in the bitmap signifies unpausing all functions.
```solidity
    /// @notice Lets the owner or manager of the NativeVault pause NativeNode functions
    /// @param map: 256 bitmap for paused and unpaused functions, 0 to unpause all functions    //@audit cant unpause 0 map
    function pauseNode(INativeNode node, uint256 map) external onlyRolesOrOwner(Constants.MANAGER_ROLE) {
        node.pause(map);
    }
```

## Impact

This flaw could lead to unintended unpausing of all functions, potentially allowing unauthorized actions and security breaches. This makes the protocol vulnerable to various attacks, as critical functions may become active without proper control.

## Tools Used

Manual review.

## Recommended Mitigation Steps

Modify the function indexes to start from 1 instead of 0. This prevents the bitmap value of 0 from unpausing all functions inadvertently.
