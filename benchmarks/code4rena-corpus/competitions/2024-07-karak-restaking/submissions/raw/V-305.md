# Vulnerability details

## Impact

Caller can register DSS through the registerDss() function, however DSS is checked with the isContract modifier. The isContract function that uses EXTCODESIZE was discovered to be bypassable. The function will return false if it is invoked from a contract’s constructor, because the contract has not been deployed yet.

## Proof of Concept
The function in CommonUtils.sol

```solidity
function isSmartContract(address addr) external view returns (bool) { //@audit - isSmartContract check not viable
        uint256 size;
        assembly {
            size := extcodesize(addr)
        }
        return size > 0;
    }
```

Where it is called:

```solidity
function registerDSS(uint256 maxSlashablePercentageWad) external {
        IDSS dss = IDSS(msg.sender);
        if (!address(dss).isSmartContract()) revert NotSmartContract();
        _self().setDSSMaxSlashablePercentageWad(dss, maxSlashablePercentageWad);
        emit DSSRegistered(msg.sender, maxSlashablePercentageWad);
    }
```

This check can be prone to reverting and DOSing the registerDss() function for the DSS if it initiated this logic in its constructor. The probability is very low but the impact is high.
