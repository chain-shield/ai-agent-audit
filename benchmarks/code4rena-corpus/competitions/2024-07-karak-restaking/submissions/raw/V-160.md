# Vulnerability details

## Impact
Due to lack of slippage protection user may cost more deposit token than preview amount or than user expected.

## Proof of Concept
For ERC4626 protocol user can preview the cost of assets before mint shares.
```solidity
function previewMint(uint256 shares) public view virtual returns (uint256 assets) {
    if (!_useVirtualShares()) {
        uint256 supply = totalSupply();
        return supply == 0
            ? _initialConvertToAssets(shares)
            : FixedPointMathLib.fullMulDivUp(shares, totalAssets(), supply);
    }
    uint256 o = _decimalsOffset();
    if (o == 0) {
        return FixedPointMathLib.fullMulDivUp(shares, totalAssets() + 1, _inc(totalSupply()));
    }
    return FixedPointMathLib.fullMulDivUp(shares, totalAssets() + 1, totalSupply() + 10 ** o);
}
```
However the actually cost may changed due to scenario like `DSS` reward vault.
Assuming the following scenario
- 1. alice invoke previewMint to check the cost
- 2. dss send reward token to vault
- 3. alice invoke mint
