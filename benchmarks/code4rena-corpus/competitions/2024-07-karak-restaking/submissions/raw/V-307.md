# Vulnerability details

## Summary

In HookLib.sol callHookIfInterfaceImplemented does wrong initial gas checks.  
The point of a gas checks is to avoid silent fails in calls, as well as finish code-execution early and not waste resources.

## Vulnerability Details
For callHookIfInterfaceImplemented we pass 3 values for gas limits. ( I will take an example values from the DeployCoreLocal.sol )

 HOOK_CALL_GAS_LIMIT = 500_000;
 HOOK_GAS_BUFFER = 40_000;
 SUPPORTS_INTERFACE_GAS_LIMIT = 20_000;
  
As seen, the HOOK_CALL_GAS_LIMIT has the highest limit, as its expected that the hook itself would consume the most gas. 
However, if the remaining gas is above SUPPORTS_INTERFACE_GAS_LIMIT + HOOK_GAS_BUFFER, but bellow HOOK_CALL_GAS_LIMIT the first gas check would pass and we will execute the call for the supportsInterface check.

```solidity
  function callHookIfInterfaceImplemented(
        IERC165 dss,
        bytes memory data,
        bytes4 interfaceId,
        bool ignoreFailure,
        uint32 hookCallGasLimit,
        uint32 supportsInterfaceGasLimit,
        uint32 hookGasBuffer
    ) internal returns (bool) {
 @>>    if (gasleft() < (supportsInterfaceGasLimit * 64 / 63 + hookGasBuffer)) {
            revert NotEnoughGas();
        }

        (bool success, bytes32 result) = performLowLevelCallAndLimitReturnData(
            address(dss),
            abi.encodeWithSelector(IERC165.supportsInterface.selector, interfaceId),
            supportsInterfaceGasLimit
        );

        if (!success || result == bytes32(0)) {
            // Either call failed or interface isn't implemented
            emit InterfaceNotSupported();
            return false;
        }
        return callHook(address(dss), data, ignoreFailure, hookCallGasLimit, hookGasBuffer);
    }
```
And we will continue execution till the next gas check, even though we wouldn't have enough in the first place, to finish the call. As if we are SUPPORTS_INTERFACE_GAS_LIMIT + HOOK_GAS_BUFFER, but bellow HOOK_CALL_GAS_LIMIT 
the second gas check in callHook() will **ALWAYS** fail.

```solidity
        address target,

 @>>    if (gasleft() < (hookCallGasLimit * 64 / 63 + hookGasBuffer)) revert NotEnoughGas();

        return success;
    }
```
