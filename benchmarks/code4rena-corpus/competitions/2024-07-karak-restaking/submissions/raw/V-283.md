# Vulnerability details

## Impact
The deposit function in the Vault contract calls the `deposit` function of the ERC4626 contract, which transfers assets from the Vault contract. This process assumes that the Vault contract already holds the assets intended for deposit, which creates a vulnerability. A malicious user can observe the legitimate user's transaction in the mempool(transferring asset to vault contract) and execute a transaction just after the legitimate user’s transaction which transferred asset in vault and executing attacker/miner transaction before user calls `deposit`, causing the legitimate user to lose funds and revert. The issue arises because both the transfer and deposit operations cannot be done atomically by an externally owned account (EOA).
results in Loss of Funds: Legitimate users can lose their assets if their deposit transactions are front-run and manipulated by malicious users.

## Proof of Concept
https://github.com/code-423n4/2024-07-karak/blob/f5e52fdcb4c20c4318d532a9f08f7876e9afb321/src/Vault.sol#L78

Step 1: Legitimate User’s Actions:
User A prepares a transaction to transfer 100 tokens to the Vault contract.
User A prepares a transaction to call the deposit function with 100 tokens.

Step 2: Malicious User’s Actions:
User B monitors the mempool and identifies User A’s pending transfer and deposit transactions.
User B quickly prepares a transaction to call the deposit function with 100 tokens with high gas fee, front-running User A's deposit transaction.

Step 3: Attack Execution:
User B’s transaction is executed first, transferring shares from the Vault contract to User B.
User A's deposit transaction is executed, but the shares have already been minted to User B.

## Tools Used
Manual review

## Recommended Mitigation Steps
To prevent this issue, implement a solution that ensures atomic transfer and deposit operations.

Modify the deposit function to handle the asset transfer internally, ensuring that the assets are transferred from the user's address directly to the vault during the deposit call.
