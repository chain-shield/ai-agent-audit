# Vulnerability details

## Impact
When a User tries to withdraw assets from a Native Vault he may lose assets if the `withdrawableAssets` are less than the assets the user is attempting to withdraw. 

## Proof of Concept
When a User tries to withdraw ETH from a Native Node in the Native Vault, he should first start a withdrawal request by calling the `startWithdrawal` function in the Native Vault, then after the `MIN_WITHDRAWAL_DELAY` has passed, He can call the `finishWithdrawal` to finish the withdrawal and get the ETH from the Node.

When the user calls the `finishWithdrawal` he can lose assets because this function will first:
1. Subtract the amount the user asked to withdraw from the `nodeOwnerToWithdrawAmount` mapping that saves the pending to withdraw amounts for the user.
2. Then, it will return from the `withdrawableWei` function call, the minimum value between the assets balance of the owner and the `withdrawableCreditedNodeETH`.
3. If the amount of assets the user tries to withdraw is greater than the amount returned by the `withdrawableWei` function, it'll update the assets to withdraw with this `withdrawableAssets` amount, but the original assets amount has been already subtracted from the `nodeOwnerToWithdrawAmount` mapping causing a loss to the user.
4. Then, it will update the balances of the `totalAssets` and the user `totalRestakedETH` in the function `_decreaseBalance`.
5. later, it will withdraw from the node. the ETH and send to the user the `withdrawableAssets` amount updated in step 3.
6. Finally, this amount is subtracted from the `withdrawableCreditedNodeETH`.

```solidity
function finishWithdrawal(bytes32 withdrawalKey) external nonReentrant
   whenFunctionNotPaused(Constants.PAUSE_NATIVEVAULT_FINISH_WITHDRAWAL)
{
  //...
// 1.-
  self.nodeOwnerToWithdrawAmount[startedWithdrawal.nodeOwner] -= startedWithdrawal.assets;
// 2.-
  uint256 withdrawableAssets = withdrawableWei(startedWithdrawal.nodeOwner);
// 3.-
  if (startedWithdrawal.assets > withdrawableAssets) {
      startedWithdrawal.assets = withdrawableAssets;
   }
// 4.-
   _decreaseBalance(startedWithdrawal.nodeOwner, startedWithdrawal.assets);
// 5.-
    INativeNode(node.nodeAddress).withdraw(startedWithdrawal.to, startedWithdrawal.assets);
 // 6.-
    node.withdrawableCreditedNodeETH -= startedWithdrawal.assets;
}
```
