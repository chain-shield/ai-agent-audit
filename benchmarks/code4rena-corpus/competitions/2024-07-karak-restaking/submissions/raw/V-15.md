# Vulnerability details

##summary 

there is no check for 0 address at `handleSlashing` function .
If the token being slashed has a specific mechanism that requires transfer to a particular address or if transferring to the zero address causes issues in the token's logic, this can be problematic. It is advisable to check whether transferring to the zero address is appropriate for all tokens.

## Impact
If the token contract does not handle transfers to the zero address properly, this could result in a permanent loss of tokens.

## Recommended Mitigation Steps

add checks for 0 address : 
```require(amount == 0) revert ZeroAmount();```
