# Vulnerability details

## Impact
The `validateSnapshotProofs` function is used to validate balance proofs for all active validators associated with a specific node owner. However, the function does not check if the `lastSnapshotTimestamp` is still active, meaning it does not validate whether the snapshot has expired before validating new proofs. 

## Proof of Concept
`validateSnapshotProofs` function in the NativeVaultLib.NativeNode contract.
The function should check if the lastSnapshotTimestamp is still active and ensure the snapshot has not expired before proceeding with validation.

The function does not check if the lastSnapshotTimestamp is still active, potentially validating proofs against an expired snapshot.

[The function validates balance proofs against a snapshot that has expired](https://github.com/code-423n4/2024-07-karak/blob/f5e52fdcb4c20c4318d532a9f08f7876e9afb321/src/NativeVault.sol#L139C1-L140C75).

However, it does not check if the snapshot has expired based on the `lastSnapshotTimestamp`. This omission can allow validators to submit proofs against an outdated snapshot, causing several issues as described above.

```
 function validateSnapshotProofs(
        address nodeOwner,
        BeaconProofs.BalanceProof[] calldata balanceProofs,
        BeaconProofs.BalanceContainer calldata balanceContainer
    )
        external
        nonReentrant
        nodeExists(nodeOwner)
        whenFunctionNotPaused(Constants.PAUSE_NATIVEVAULT_VALIDATE_SNAPSHOT)
    {
        NativeVaultLib.Storage storage self = _state();
        NativeVaultLib.NativeNode storage node = self.ownerToNode[nodeOwner];
        NativeVaultLib.Snapshot memory snapshot = node.currentSnapshot;

        if (node.currentSnapshotTimestamp == 0) revert NoActiveSnapshot();

        BeaconProofs.validateBalanceContainer(snapshot.parentBeaconBlockRoot, balanceContainer);

        for (uint256 i = 0; i < balanceProofs.length; i++) {
            NativeVaultLib.ValidatorDetails memory validatorDetails =
                node.validatorPubkeyHashToDetails[balanceProofs[i].pubkeyHash];

            if (validatorDetails.status != NativeVaultLib.ValidatorStatus.ACTIVE) revert InactiveValidator();
            if (validatorDetails.lastBalanceUpdateTimestamp >= node.currentSnapshotTimestamp) {
                revert ValidatorAlreadyProved();
            }

            int256 balanceDeltaWei = self.validateSnapshotProof(
                nodeOwner, validatorDetails, balanceContainer.containerRoot, balanceProofs[i]
            );

            snapshot.remainingProofs--;
            snapshot.balanceDeltaWei += balanceDeltaWei;
        }

        _updateSnapshot(node, snapshot, nodeOwner);
    }
```

When a snapshot expires, it means that the data it contains no longer accurately reflects the current state of the node's balance and validator statuses. This can occur for several reasons, such as changes in validator balances due to earnings or penalties, or due to validators being added or removed from the node.
Expired snapshots contain outdated balance information and Validators' balances and statuses are inaccurately recorded.

>My scenerio
- A snapshot is created for the validators associated with nodeOwner on January 1st, 2024.
- The `currentSnapshotTimestamp` is set to the timestamp of January 1st, 2024.
- The lastSnapshotTimestamp is also updated to January 1st, 2024.
- The snapshot contains balance proofs and state data of validators as of January 1st, 2024.
- No new snapshots are created or validated for the next 30 days.
- The `currentSnapshotTimestamp` remains as January 1st, 2024.
- The `lastSnapshotTimestamp` also remains unchanged. // Default or 0
On January 31st, 2024, the snapshot has technically expired as it has not been updated within the SNAPSHOT_EXPIRY_PERIOD (assume 30 days for this scenario
>Attack:
On February 1st, 2024, a malicious validator submits balance proofs to the `validateSnapshotProofs` function.
- The malicious validator's balance proofs are based on the outdated snapshot from January 1st, 2024.
-The `validateSnapshotProofs` function does not check if the snapshot has expired.
- The function proceeds with validating the proofs against the stale snapshot data from January 1st, 2024.
- The proofs are validated successfully because they match the outdated state of the system.
- The function updates the snapshot data with the validated proofs, modifying `snapshot.remainingProofs` and `snapshot.balanceDeltaWei`.
- These updates are based on the outdated validator balances from January 1st, 2024.

## Recommended Mitigation Steps
```function validateSnapshotProofs(
    address nodeOwner,
    BeaconProofs.BalanceProof[] calldata balanceProofs,
    BeaconProofs.BalanceContainer calldata balanceContainer
)
    external
    nonReentrant
    nodeExists(nodeOwner)
    whenFunctionNotPaused(Constants.PAUSE_NATIVEVAULT_VALIDATE_SNAPSHOT)
{
    NativeVaultLib.Storage storage self = _state();
    NativeVaultLib.NativeNode storage node = self.ownerToNode[nodeOwner];
    NativeVaultLib.Snapshot storage snapshot = node.currentSnapshot;

    if (node.currentSnapshotTimestamp == 0) revert NoActiveSnapshot();
    
    // Check if the snapshot has expired
    if (block.timestamp > node.lastSnapshotTimestamp + Constants.SNAPSHOT_EXPIRY_PERIOD) {
        revert SnapshotExpired(); <<<-----------
    }

    BeaconProofs.validateBalanceContainer(snapshot.parentBeaconBlockRoot, balanceContainer);

    for (uint256 i = 0; i < balanceProofs.length; i++) {
        NativeVaultLib.ValidatorDetails storage validatorDetails =
            node.validatorPubkeyHashToDetails[balanceProofs[i].pubkeyHash];

        if (validatorDetails.status != NativeVaultLib.ValidatorStatus.ACTIVE) revert InactiveValidator();
        if (validatorDetails.lastBalanceUpdateTimestamp >= node.currentSnapshotTimestamp) {
            revert ValidatorAlreadyProved();
        }

        int256 balanceDeltaWei = self.validateSnapshotProof(
            nodeOwner, validatorDetails, balanceContainer.containerRoot, balanceProofs[i]
        );

        snapshot.remainingProofs--;
        snapshot.balanceDeltaWei += balanceDeltaWei;
    }

    _updateSnapshot(node, snapshot, nodeOwner);
}
```
Also, when starting a snapshot update the lastTimestamp so that when validating outdated snapshot cannot be used.
