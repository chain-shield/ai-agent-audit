# Vulnerability details

## Impact

In the `Vault` contract, while the `deposit` function has a slippage-protection version:

```
function deposit(uint256 assets, address to)
function deposit(uint256 assets, address to, uint256 minSharesOut)
```

The `mint()` function lacks a slippage-protection version.

As a result, users cannot specify the maximum amount of assets they want to transfer during a `mint()` call. This lack of slippage control could cause users to pay more assets than intended. For example, if a reward is sent to the vault before a `mint()` call, more assets would need to be transferred from the user.

## Tools Used

Manual Review

## Recommended Mitigation Steps

Similar to the `deposit()` function, add a slippage-protection version of the `mint()` function that allows users to specify the `maxAssetsIn`.
