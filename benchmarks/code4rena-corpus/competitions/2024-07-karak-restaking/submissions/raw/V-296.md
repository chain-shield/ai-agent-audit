# Vulnerability details

## Impact

`Core::finalizeUpdateVaultStakeInDSS()` can be called by anyone to finalize an update. It calls `validateAndUpdateVaultStakeInDSS()` to execute the state updates and in that function a callback is made to the DSS. In that callback we use low-level call to call the `finishUpdateStakeHook(address operator)` function, but instead of passing the operator the protocol passes `msg.sender` which can be anyone.

```solidity
    function validateAndUpdateVaultStakeInDSS(CoreLib.Storage storage self, QueuedStakeUpdate memory queuedStakeUpdate)
        external
    {
        ...
        HookLib.callHookIfInterfaceImplemented({
            dss: dss,
@->         data: abi.encodeWithSelector(dss.finishUpdateStakeHook.selector, msg.sender),
            interfaceId: dss.finishUpdateStakeHook.selector,
            ignoreFailure: true,
            hookCallGasLimit: self.hookCallGasLimit,
            supportsInterfaceGasLimit: self.supportsInterfaceGasLimit,
            hookGasBuffer: self.hookGasBuffer
        });
    }
```

The DSS will most likely take this argument and assume it is the operator which is not correct.

Manual Review

## Recommended Mitigation Steps

Change `msg.sender` to the operator of the vault.

```diff
    function validateAndUpdateVaultStakeInDSS(CoreLib.Storage storage self, QueuedStakeUpdate memory queuedStakeUpdate)
        external
    {
        ...
        HookLib.callHookIfInterfaceImplemented({
            dss: dss,
-           data: abi.encodeWithSelector(dss.finishUpdateStakeHook.selector, msg.sender)
+           data: abi.encodeWithSelector(dss.finishUpdateStakeHook.selector, queuedStakeUpdate.operator),
            interfaceId: dss.finishUpdateStakeHook.selector,
            ignoreFailure: true,
            hookCallGasLimit: self.hookCallGasLimit,
            supportsInterfaceGasLimit: self.supportsInterfaceGasLimit,
            hookGasBuffer: self.hookGasBuffer
        });
    }
```
