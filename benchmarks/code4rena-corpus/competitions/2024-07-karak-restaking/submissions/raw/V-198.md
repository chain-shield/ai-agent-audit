# Vulnerability details


## Description:  
The Karak protocol allows the DSS to punish misbehaving operators by slashing their stakes. This slashing event is initiated by the DSS through the `requestSlashing(...)` function and is subject to a two-day review period by the slashing committee. After this period, anyone can call `finalizeSlashing(...)` to actually slash the operator's stake. If the committee disapproves of the slashing event, it can be canceled by calling `cancelSlashing(...)`.

However, there is no specific timeframe within which the VETO_COMMITTEE_ROLE must act to cancel the slashing event. This lack of defined timeframes could allow the VETO_COMMITTEE_ROLE to front-run legitimate calls to `finalizeSlashing(...)` by canceling the slashing event at any point, even after the review period has ended. As a result, legitimate `finalizeSlashing(...)` transactions might fail, undermining the integrity of the slashing process and potentially leading to status ambiguity in the system

        depositToken.approve(address(vault), amount);
        uint256 expectedShares = vault.convertToShares(amount);
        shares = vault.deposit(amount, address(this), expectedShares);
    }

    function mintAndDepositBy(uint256 amount, address by) public returns (uint256 shares) {
        vm.startPrank(by);
        depositToken.mint(by, amount);
        depositToken.approve(address(vault), amount);
        uint256 expectedShares = vault.convertToShares(amount);
        shares = vault.deposit(amount, by, expectedShares);
        vm.stopPrank();
    }

    function setupDDs() public {
        stake_vaults_to_dss();
        vault = Vault(address(vaults[0]));
        vm.prank(operator);
        core.registerOperatorToDSS(dss2, "");
    }

    function setupSlash() public returns (uint96[] memory slashPercentagesWad) {
        uint96 slashPercentageWad = uint96(core.getDssMaxSlashablePercentageWad(dss));

        slashPercentagesWad = new uint96[](vaults.length);
        slashPercentagesWad[0] = slashPercentageWad;
        // Generate nonequal percentages
        uint96 slashPercentageWad1 =
            (slashPercentageWad + uint96(10 * Constants.ONE_WAD)) % uint96(core.getDssMaxSlashablePercentageWad(dss));
        // Make sure zero is not passed
        slashPercentageWad1 = slashPercentageWad1 == 0 ? slashPercentageWad1 : uint96(Constants.ONE_WAD);
        slashPercentagesWad[1] = slashPercentageWad1;
    }

    function test_cancel_ligitmaete_transaction() public {
        setupDDs();
        uint96[] memory slashPercentagesWad = setupSlash();
        vm.startPrank(address(dss));
        address[] memory operatorVaults = core.fetchVaultsStakedInDSS(operator, dss);

        SlasherLib.SlashRequest memory slashingReq = SlasherLib.SlashRequest({
            operator: operator,
            slashPercentagesWad: slashPercentagesWad,
            vaults: operatorVaults
        });
        // after 2 days , got slashed
        SlasherLib.QueuedSlashing memory queuedSlashing = core.requestSlashing(slashingReq);
vm.stopPrank();
        uint256[] memory postSlashedAssets = new uint256[](operatorVaults.length);
        for (uint256 i = 0; i < operatorVaults.length; i++) {
            postSlashedAssets[i] = compute_post_slashed_assets_in_vault(operatorVaults[i], slashPercentagesWad[i]);
        }

        // Although the time to cancel the slashing has passed, the veto decides to cancel the slashing
        vm.warp(block.timestamp + Constants.SLASHING_VETO_WINDOW + 2 hours);
        vm.prank(vetoCommittee);
        core.cancelSlashing(queuedSlashing);
        // legitimate transaction is reverted and transaction cost is lost
        vm.expectRevert();
        core.finalizeSlashing(queuedSlashing);
    }
}

### Updated Recommendation:
To mitigate this issue, it is recommended to enforce a defined timeframe within which the VETO_COMMITTEE_ROLE must exercise its authority to cancel the slashing event.
