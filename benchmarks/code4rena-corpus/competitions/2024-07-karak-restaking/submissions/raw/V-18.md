# Vulnerability details

## Impact

The transaction may revert when trying to call a DSS hook while it should not.

## Proof of Concept

The function `HookLib::callHook()` and `HookLib::callHookIfInterfaceImplemented()` start by making sure the `gasleft()` is enough to execute the corresponding hook on a DSS by following the 63/64 rule.

This rule stipulates an external call forwards 63/64 of the gas left and keeps 1/64 of the gas left to proceed the last part of the transaction once the external call succeeded.

In the mentioned functions, in case the gas that will be forwarded is not enough, the transaction reverts early.

Here is how `callHook()` estimates the gas the hook costs.

```solidity
if (gasleft() < (hookCallGasLimit * 64 / 63 + hookGasBuffer)) revert NotEnoughGas();
```

This formula does not calculate the gas accurately.

The calculation returns a value greater than it should meaning the transactions will most likely revert while they should not.

## Tools Used

Manual review

## Recommended Mitigation Steps

Reverse the `63` and `64` values in the corresponding formulas

*callHook()*

```diff
- if (gasleft() < (hookCallGasLimit * 64 / 63 + hookGasBuffer)) revert NotEnoughGas();
+ if (gasleft() < (hookCallGasLimit * 63 / 64 + hookGasBuffer)) revert NotEnoughGas();
```

*callHookIfInterfaceImplemented()*

```diff
- if (gasleft() < (supportsInterfaceGasLimit * 64 / 63 + hookGasBuffer)) {
-     revert NotEnoughGas();
- }

+ if (gasleft() < (supportsInterfaceGasLimit * 63 / 64 + hookGasBuffer)) {
+     revert NotEnoughGas();
+ }
```
