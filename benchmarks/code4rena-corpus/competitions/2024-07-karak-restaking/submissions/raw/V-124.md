# Vulnerability details

## Impact
If the contract owner needs to pause a function or all functions due to an attack, the Core::pause function will not be able to pause the function(s).

## Proof of Concept
In the Karak repo, under the test folder, create a new file including this contract:

## Recommended Mitigation Steps

We can include to the Core contract, a library constants including a bit position for each function, a modifier: 
    /// @notice Modifier to check if the function is not paused
    /// @param functionBit: The bit position of the function to check
    modifier coreNotPaused(uint256 functionBit) {
        require(!pause(functionBit), "Core function is paused");
        _;
    }

Add this modifier to each function of the Core contract:
/// @notice Allows the manager to allowlist assets that then vaults can be created for with the asset as the underlying token.
    /// @dev If an asset that is already allowlisted is passed, it will be set to allowlisted again.
    /// @param assets: The list of assets to allowlist
    function allowlistAssets(address[] memory assets, address[] memory slashingHandlers)
        external
        onlyRolesOrOwner(Constants.MANAGER_ROLE)
        coreNotPaused(Constants.PAUSE_ALLOWLIST_ASSETS)
    {
        _self().allowlistAssets(assets, slashingHandlers);
        emit AllowlistedAssets(assets);
    }
