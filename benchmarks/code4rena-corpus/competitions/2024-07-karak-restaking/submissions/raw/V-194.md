# Vulnerability details

## Impact
The Core.sol contract provides the ability for a user with the MANAGER_ROLE or owner role to pause the contract:
https://github.com/code-423n4/2024-07-karak/blob/main/src/Core.sol#L72-L80.

The Core.registerOperatorToDSS() function has a whenFunctionNotPaused modifier. When the contract is paused, the user cannot call the Core.registerOperatorToDSS() function.
https://github.com/code-423n4/2024-07-karak/blob/main/src/Core.sol#L97-L107

## Proof of Concept
However, the Core.registerOperatorToDSS() function calls the Operator.registerOperatorToDSS() function:
https://github.com/code-423n4/2024-07-karak/blob/main/src/Core.sol#L105

The Operator.registerOperatorToDSS() function is of type external and does not have the whenFunctionNotPaused modifier checks. An attacker can call the Operator.registerOperatorToDSS() function directly at a time when Core.registerOperatorToDSS() is not called due to a pause.

This may lead to a deterioration in the security of the contract.

## Tools Used
Manual review

## Recommended Mitigation Steps
Add a check to the Operator.registerOperatorToDSS() function that only the Core.sol contract can call it.
