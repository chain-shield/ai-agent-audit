# Vulnerability details

## Impact

The current implementation, contains a critical bug that renders the slashing functionality ineffective. The bug arises from the intended design to send slashed tokens to the zero address. However, the ERC20 standard, as implemented, reverts any transaction involving the zero address as either the sender or the receiver. This behavior makes it impossible to complete the slashing operation.

```
    function _transfer(address from, address to, uint256 value) internal {
        if (from == address(0)) {
            revert ERC20InvalidSender(address(0));
        }
        if (to == address(0)) {
            revert ERC20InvalidReceiver(address(0));
        }
        _update(from, to, value);
    }
```
