# Vulnerability details

In Vault.sol two of the functions are startRedeem() and finishRedeem(). Both functions are using convertToAssets() with parameter. This function is inherited from solmate. It is clear that convertToAssets() uses totalSupply. When totalSupply is used since it is very easy to manipulate there is a possibility for users of the protocol to lose funds. 

## Impact
Users may receive a worse price than expected for their shares when convertToAssets() is used. There's no protection at all for minimum return amount potentially leading to loss of user funds.

## Recommended Mitigation Steps
Allow a user to specify a minOutAmount and make a check in startRedeem() and finishRedeem() in order to minimize the possibility of losing funds.
