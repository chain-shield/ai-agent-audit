# Vulnerability details

## Impact
The `merkleizeSha256` function in the contract incorrectly computes the Merkle root of a tree when the number of levels is a power of two. The function overwrites intermediate results in the same array during the hasging process, leading to incorrect Merkle root compulation. This flaw can cause validation errors, leading to potential security risks and incorrect functioning of any system relying on this Merkle tree implementation.

## Proof of Concept
The original function uses a single array (`layer`) to store intermediate nodes, and it overwrites this during the computation. This results in incorrect hashes as the nodes are altered before they are fully processed.
```
function merkleizeSha256(bytes32[] memory leaves) internal pure returns (bytes32) {
    uint256 numNodesInLayer = leaves.length / 2;
    bytes32[] memory layer = new bytes32[](numNodesInLayer);
    for (uint256 i = 0; i < numNodesInLayer; i++) {
        layer[i] = sha256(abi.encodePacked(leaves[2 * i], leaves[2 * i + 1]));
    }
    numNodesInLayer /= 2;
    while (numNodesInLayer != 0) {
        for (uint256 i = 0; i < numNodesInLayer; i++) {
            layer[i] = sha256(abi.encodePacked(layer[2 * i], layer[2 * i + 1]));
        }
        numNodesInLayer /= 2;
    }
    return layer[0];
}
```

## Recommended Mitigation Steps

1. **Use Separate Arrays**: Modify the function to use separate arrays for each layer to avoid overwriting intermidiate nodes.
2. **Add Validations**: Ensure the input leaves array is not empty and handle the best case where `leaves.length == 1`.

## Corrected Code
```
function merkleizeSha256(bytes32[] memory leaves) internal pure returns (bytes32) {
    require(leaves.length > 0, "Leaves array is empty");

    if (leaves.length == 1) {
        return leaves[0];
    }

    bytes32[] memory currentLayer = leaves;

    while (currentLayer.length > 1) {
        uint256 numNodesInLayer = currentLayer.length / 2;
        bytes32[] memory nextLayer = new bytes32[](numNodesInLayer);
        
        for (uint256 i = 0; i < numNodesInLayer; i++) {
            nextLayer[i] = sha256(abi.encodePacked(currentLayer[2 * i], currentLayer[2 * i + 1]));
        }

        currentLayer = nextLayer;
    }

    return currentLayer[0];
}
```
