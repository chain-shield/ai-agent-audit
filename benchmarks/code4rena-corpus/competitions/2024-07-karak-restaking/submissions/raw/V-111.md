# Vulnerability details

## Impact
If address(0) is passed the function will not revert as it was intended to do because of a mistake in the check.

## Proof of Concept
Currently this is how we check if the code should revert or not:
```diff
if (!(implementation == address(0) || isVaultImplAllowlisted(self, implementation))) {
            revert VaultImplNotAllowlisted();
}
```
 however if address(0) is passed this check will fail to revert, because the current logic will look like this: !(true || false) which evaluates to !true and results to false, so we will not enter the if body.

## Tools Used
Manual Review

## Recommended Mitigation Steps
Consider changing the following:
```diff
-   if (!(implementation == address(0) || isVaultImplAllowlisted(self, implementation))) {
+   if (implementation == address(0) || !isVaultImplAllowlisted(self, implementation)) {
            revert VaultImplNotAllowlisted();
}
```
