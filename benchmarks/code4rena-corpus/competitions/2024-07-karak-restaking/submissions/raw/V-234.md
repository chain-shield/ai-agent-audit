# Vulnerability details

## Impact

The `_startSnapshot` method in the NativeVault contract is an internal function called by the `startSnapshot` and `validateExpiredSnapshot` methods. The `validateExpiredSnapshot` method does not verify the caller, so any user can call the `_startSnapshot` method to process the slashed ETH and transfer it to the slashing storage. This may lead to unauthorized operations and fund transfers. The `validateExpiredSnapshot` method does not restrict the caller, allowing anyone to call and pass in `nodeOwner`. This means that a malicious user can call the `_startSnapshot` method by passing in the address of another node owner. This may pose the following risks:

- `_transferToSlashStore` **Method**: Process the slashed ETH and transfer it to the slashing storage. Malicious users may take advantage of this and force trigger `nodeOwner` to perform a slashing operation, transfer ETH to the slashing storage, and cause fund losses.
- `_updateBalance` **Method**: Update the balance of the node owner. A malicious user could cause the node owner's balance to be constantly updated by calling the `_startSnapshot` method frequently, resulting in unnecessary consumption of computational resources and potential fund inconsistency.

## Proof of Concept

https://github.com/code-423n4/2024-07-karak/blob/main/src/NativeVault.sol#L210

In this code, the `validateExpiredSnapshot` function does not restrict the caller, allowing anyone to call it and subsequently call the `_startSnapshot` method, resulting in a potential unauthorized transfer of funds.

```solidity
function validateExpiredSnapshot(address nodeOwner)
    external
    nonReentrant
    nodeExists(nodeOwner)
    whenFunctionNotPaused(Constants.PAUSE_NATIVEVAULT_VALIDATE_EXPIRED_SNAPSHOT)
{
    NativeVaultLib.NativeNode storage node = _state().ownerToNode[nodeOwner];
    // Only check if the last snapshot has expired or not
    if (node.lastSnapshotTimestamp + Constants.SNAPSHOT_EXPIRY > block.timestamp) {
        revert SnapshotNotExpired();
    }

    _startSnapshot(node, false, nodeOwner);
}
```
