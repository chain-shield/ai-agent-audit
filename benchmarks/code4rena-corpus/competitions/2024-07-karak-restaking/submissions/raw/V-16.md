# Vulnerability details

## Impact
The off-by-one error in the `sort` function of the `CommonUtils` library impacts the correctness of the `hasDuplicates` function. If the sorting is incorrect, it may result in false positives or false negatives during duplicate detection. This could affect protocol operations that rely on ensuring unique addresses, such as participant lists, whitelists, or blacklists. Incorrect duplicate detection might either reject valid addresses or allow duplicate entries, leading to potential issues in protocol functionality and availability.

## Proof of Concept
Let's consider an array of addresses [3, 1, 2, 4] and the pivot set to the last element 4.

**Original Recursive Calls**
1. Initial Call: `sort(arr, 0, 3)`
 * The array is `[3, 1, 2, 4]`
 * Partitioning starts with `left = 0` and `right = 3`.
 * After partitioning around `pivot = 4` (index `3`), the array becomes `[3, 1, 2, 4]` with `lastUnsortedInd = 3`.

2. First Recursive Call: `sort(arr, 0, 2)`
 * The left partition `[3, 1, 2]` is sorted correctly.
 * `lastUnsortedInd = 2` after partioning.
3. Second Recursive Call: `sort(arr, 3, 3)`
 * This call incorrectly includes the pivot element again (`4`), resulting in no change to the array, maintaining `[3, 1, 2, 4]`.

**Corrected Recursive Calls**
1. Initial Call: `sort(arr, 0, 3)`
 * The array is `[3, 1, 2, 4]`
 * Partitioning starts with `left = 0` and `right = 3`.
 * After partitioning around `pivot = 4` (index `3`), the array becomes `[3, 1, 2, 4]` with `lastUnsortedInd = 3`.

2. First Recursive Call: `sort(arr, 0, 2)`
 * The left partition `[3, 1, 2]` is sorted correctly.
 * `lastUnsortedInd = 2` after partioning.
3. Second Recursive Call: `sort(arr, 4, 3)`
 * This call correctly starts after the pivot element (`4`), sorting the right partition `[4]`.

### Comparison
* Original Code: The second recursive call includes the pivot element again (4), resulting in no sorting of the right partition and potentially incorrect behavior.

* Corrected Code: Adjusting the second recursive call to sort(arr, lastUnsortedInd + 1, right) ensures that the right partition starts after the pivot element (4), correctly sorting the array.

## Recommended Mitigation Steps
```diff
function sort(address[] memory arr, uint256 left, uint256 right) private pure {
    if (left >= right) return;
    uint256 lastUnsortedInd = left;
    uint256 pivot = right;
    for (uint256 i = left; i < right; i++) {
        if (uint160(arr[i]) <= uint160(arr[pivot])) {
            if (i != lastUnsortedInd) swap(arr, i, lastUnsortedInd);
            lastUnsortedInd++;
        }
    }
    swap(arr, pivot, lastUnsortedInd);
    if (lastUnsortedInd > left) {
        sort(arr, left, lastUnsortedInd - 1);
    }

-   sort(arr, lastUnsortedInd, right);
+   sort(arr, lastUnsortedInd + 1, right);
}
```
