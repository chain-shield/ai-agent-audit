# Vulnerability details

## Impact
The `Core` contract inherits from `Pauser` for its pausable functionalities. It is reasonable to assume that all DSS and operator-facing functions are intended to be pausable. However, unlike other such functions, `registerDSS()` is not modified by `whenFunctionNotPaused()` and is not pausable.

The impact of this issue is that if critical vulnerabilities are later found in the `registerDSS()` function, the manager may not be able to pause it in a timely manner.

## Tools Used
Manual Review

## Recommended Mitigation Steps
Define a pausing index in the `Constants.sol`:
```solidity
uint8 internal constant PAUSE_CORE_REGISTER_DSS = 10;
```

Then add the `whenFunctionNotPaused` modifier to the `registerDSS()` function:
```diff
function registerDSS(uint256 maxSlashablePercentageWad) external
+ whenFunctionNotPaused(Constants.PAUSE_CORE_REGISTER_DSS)
{
```
