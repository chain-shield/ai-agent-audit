# Vulnerability details

## Impact
The `registerDSS` function currently uses `dss` which is casting msg.sender to IDSS interface to check if the caller is a smart contract by inspecting the bytecode size. This method fails if the function is called from within a constructor because the bytecode hasn't been deployed yet. To mitigate this issue, the function should accept an address parameter and perform the check on this address.
