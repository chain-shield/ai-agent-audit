# Vulnerability details

## Impact
Compromised and Susceptible vault implementation vaults cannot be blacklisted, since there is no way to remove any compromised/susceptible from the `allowlistedVaultImpl`.
So when allowing custom ERC4626 vault implementation there should be a way to blocklist any compromised vault implementation.

## Proof of Concept
Common Pitfalls: https://www.zellic.io/blog/exploring-erc-4626/#potential-security-pitfalls-under-erc-4626
https://medium.com/coinmonks/security-considerations-in-eip-4626-by-fairyproof-38ec078b4565


## Tools Used
Manual Review

## Recommended Mitigation Steps
Add a function to remove any compromised implementation, or add a blacklist and validate implementation while returning the implementation.
