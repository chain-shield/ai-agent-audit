# Vulnerability details

## Impact
In the given smart contract, there is a function allowlistAssets that takes two lists as parameters:

- `assets`: A list of asset addresses to be allowlisted.

- `slashingHandlers`: A list of slashing handlers related to those assets.

The issue arises when the lengths of these two lists do not match. In such a case, some assets may not have corresponding slashing handlers, which can lead to issues in slashing operations later on.

## Proof of Concept
```javascript
const { expect } = require("chai");
const { ethers } = require("hardhat");

describe("Core Contract", function () {
    let Core;
    let core;

    beforeEach(async function () {
        Core = await ethers.getContractFactory("Core");
        core = await Core.deploy();
        await core.deployed();
    });

    it("Should fail when lengths of assets and slashingHandlers do not match", async function () {
        const assets = [ethers.constants.AddressZero];
        const slashingHandlers = [];
        
        await expect(core.allowlistAssets(assets, slashingHandlers))
            .to.not.be.reverted; // No check is performed in this version

        await expect(core.allowlistAssetsWithCheck(assets, slashingHandlers))
            .to.be.revertedWith("Assets and slashingHandlers length mismatch");
    });

    it("Should succeed when lengths of assets and slashingHandlers match", async function () {
        const assets = [ethers.constants.AddressZero];
        const slashingHandlers = [ethers.constants.AddressZero];
        
        await expect(core.allowlistAssetsWithCheck(assets, slashingHandlers))
            .to.not.be.reverted;
    });
});

## Recommended Mitigation Steps

To address this issue, it is essential to add a check to ensure that the lengths of the two lists match before proceeding with the allowlisting process. Here is an improved version of the function

```solidity

function allowlistAssets(address[] memory assets, address[] memory slashingHandlers)
    external
    onlyRolesOrOwner(Constants.MANAGER_ROLE)
{
    require(assets.length == slashingHandlers.length, "Assets and slashingHandlers length mismatch");
    _self().allowlistAssets(assets, slashingHandlers);
    emit AllowlistedAssets(assets);
}

```
