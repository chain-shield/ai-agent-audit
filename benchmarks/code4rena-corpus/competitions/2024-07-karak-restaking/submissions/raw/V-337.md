# Vulnerability details

## Intro

The current implementation of the Vault contract, which inherits from ERC4626, is vulnerable to first depositor inflation attack. This could allow the initial depositor to manipulate the share price, potentially leading to significant losses for subsequent depositors.

## Vulnerability Details

The vulnerability arises from the share price calculation mechanism and the ability of the first depositor to manipulate the initial share price. The attack vector works as follows: First, the attacker deposits a minimal amount (as little as 1 wei) of the asset, receiving 1 share in return. Then, they transfer a large amount of assets directly to the vault contract. This causes the vault's total assets to increase significantly, while the total shares remain at 1. As a result, subsequent depositors receive fewer shares per asset than they should, effectively losing value to the attacker.

The deposit function only checks for non-zero deposits but doesn't enforce a minimum deposit amount. It uses the standard ERC4626 share calculation and doesn't protect against direct asset transfers to the contract. 

The current implementation inherits directly from ERC4626 without additional protections:

https://github.com/code-423n4/2024-07-karak/blob/main/src/Vault.sol#L94

```solidity
function deposit(uint256 assets, address to)
    public
    override(ERC4626, IVault)
    whenFunctionNotPaused(Constants.PAUSE_VAULT_DEPOSIT)
    nonReentrant
    returns (uint256 shares)
{
    if (assets == 0) revert ZeroAmount();
    return super.deposit(assets, to);
}
```



## Impact

- Financial loss for subsequent depositors


## Recommended Mitigations

### Minimum Deposit Amount

Implement a minimum deposit amount to prevent tiny initial deposits:

```solidity
function deposit(uint256 assets, address to) public override returns (uint256) {
    require(assets >= MINIMUM_DEPOSIT, "Deposit too small");
    // ... rest of the function
}
```

### Initial Share Minting

Mint an initial amount of shares to the zero address during contract initialization:

```solidity
constructor() {
    _mint(address(0), INITIAL_SHARES);
}
```

### Custom Share Price Calculation

Implement a custom share price calculation that's more resistant to manipulation:

```solidity
function convertToShares(uint256 assets) public view override returns (uint256) {
    uint256 supply = totalSupply();
    return supply == 0 ? assets : assets.mulDivDown(supply, totalAssets());
}
```

### Virtual Offset

Add a virtual offset to the asset and share totals:

```solidity
uint256 constant VIRTUAL_OFFSET = 1e6;

function totalAssets() public view override returns (uint256) {
    return super.totalAssets() + VIRTUAL_OFFSET;
}

function totalSupply() public view override returns (uint256) {
    return super.totalSupply() + VIRTUAL_OFFSET;
}
```
