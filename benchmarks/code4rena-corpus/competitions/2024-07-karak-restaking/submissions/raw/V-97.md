# Vulnerability details

The `registerOperatorToDSS()` does not correctly handle this [edge case], leading to unexpected behavior during operator registration. When an operator attempts to register with a DSS that they are already registered with. The current implementation does not check for this scenario, potentially allowing multiple registrations of the same operator to the same DSS.

The `Core` contract manages the registration of operators to various DSS instances. The `registerOperatorToDSS()` function ([lines 97-107](https://github.com/code-423n4/2024-07-karak/blob/f5e52fdcb4c20c4318d532a9f08f7876e9afb321/src/Core.sol#L97-L107)) is designed to allow operators to register with a DSS, enabling them to allocate assets delegated by stakers, the current implementation fails to properly handle all scenarios, potentially leading to inconsistent state or unintended behavior.

## Impact

The incorrect handling of edge cases in the `registerOperatorToDSS()` function could lead to:

1. Operators being unable to register with certain DSS instances when they should be allowed to.
2. Inconsistent state between the Core contract and the DSS regarding operator registration.
3. Potential loss of functionality for affected operators, as they may be unable to allocate assets or participate in the protocol as intended.

These issues could undermine the reliability and functionality of the operator registration process, potentially affecting the overall stability and trustworthiness of the protocol.

## Proof of Concept

The function should include a check to prevent an operator from registering with a DSS they are already registered with, ensuring the integrity of the registration process.

1. An operator attempts to register with a DSS using `registerOperatorToDSS()`.
2. The function checks if the DSS is registered using `self.isDSSRegistered(dss)`.
3. Due to the edge case not being properly handled, the function fails to register the operator or registers them incorrectly.
4. The operator is now in an inconsistent state, unable to properly interact with the DSS or allocate assets.

function registerOperatorToDSS(IDSS dss, bytes memory registrationHookData)
    external
    whenFunctionNotPaused(Constants.PAUSE_CORE_REGISTER_TO_DSS)
    nonReentrant
{
    address operator = msg.sender;
    CoreLib.Storage storage self = _self();
    if (!self.isDSSRegistered(dss)) revert DSSNotRegistered();
    
    // Add additional checks here

    // Proceed with registration
    self.registerOperatorToDSS(dss, operator, registrationHookData);
    emit RegisteredOperatorToDSS(operator, address(dss));
}
