# Vulnerability details

## Impact
The gas calculation in the `callHookIfInterfaceImplemented` and `callHook` functions from the hooklib can cause the functions that call them to revert due to a bad gas calculation.

## Proof of Concept
The `callHookIfInterfaceImplemented` and `callHook` functions are used to call a hook from a DSS when an operator wants to register, unregister or update a vault staked in a DSS with the functions: `registerOperatorToDSS, unregisterOperatorFromDSS, requestUpdateVaultStakeInDSS, validateAndUpdateVaultStakeInDSS`, also the slasher lib use these function for the slashing mechanism `requestSlashing, finalizeSlashing, cancelSlashing`.

when these functions are called they first calculate the gas needed to make the external `call` using these formulas: 

```solidity
function callHookIfInterfaceImplemented(//...) internal returns (bool) {
     if (gasleft() < (supportsInterfaceGasLimit * 64 / 63 + hookGasBuffer)) {
         revert NotEnoughGas();
     }
//...
}

function callHook(//...) internal returns (bool){
    if (gasleft() < (hookCallGasLimit * 64 / 63 + hookGasBuffer)) revert NotEnoughGas();
//...
}
```
but these formulas fail to apply the 63/64 rule correctly, which results in the calculation of a different amount of gas required (less gass) to pass the gas check allowing some calls to pass these checks and trying to execute the calls to the DSS hooks, this can cause a DOS for OOG errors in the slashing, register/unregister and stake/unstake mechanisms.

The current formula calculates the gas needed to execute the external calls using the 63/64 accounting only for the `supportsInterfaceGasLimit` in the `callHookIfInterfaceImplemented` function.
```solidity
if (gasleft() < (supportsInterfaceGasLimit * 64 / 63 + hookGasBuffer)) {
    revert NotEnoughGas();
}
```
and for the `hookCallGasLimit`in the `callHook` function.
```solidity
if (gasleft() < (hookCallGasLimit * 64 / 63 + hookGasBuffer)) revert NotEnoughGas();
```
 but the calculation should be applied for the full gas sent to the function to correctly validate the gasLeft to this point is enough to complete the external calls and the function.

first, we sum up the gas variables and then apply the 63/64 rule, something like
```solidity
if (gasleft() < (hookCallGasLimit + hookGasBuffer) * 64 / 63) revert NotEnoughGas();
```

comparing the 2 different calculations in the `callHookIfInterfaceImplemented` function we can see a difference that will allow some calls to pass and can cause a DOS for OOG in the function.

```solidity
// Current calculation in the contract results in a gas calculation of 60,317
uint256 gasCalculate = (supportsInterfaceGasLimit * 64 / 63 + hookGasBuffer);

//This Formulate results in a gas calculation of 60,952
uint256 gasCalculate2 = (supportsInterfaceGasLimit + hookGasBuffer) * 64 / 63;
```
