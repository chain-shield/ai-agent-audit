# Vulnerability details

## Impact
1. Insufficient Address Validation

The withdraw function in the SlashStore contract does not validate that the to address is not a zero address. This oversight allows an attacker or an unintended caller to withdraw funds to the zero address, where they become irretrievably lost.

2. Insufficient Balance Validation

While the contract does check that the contract has sufficient balance to cover the requested withdrawal amount, it's crucial to ensure this validation is consistently enforced. The absence of address validation represents a more significant concern.

The bug has a severe impact because it can lead to the loss of Ether. Funds sent to the zero address cannot be recovered, posing a significant risk to the contract’s users.

###  Hardhat Test Script (test/SlashStoreTest.js)

```
const { expect } = require("chai");
const { ethers } = require("hardhat");

describe("SlashStore Contract", function () {
    let SlashStore;
    let slashStore;
    let owner;
    let recipient;
    let zeroAddress;
    let initialBalance = ethers.utils.parseEther("1");
    let withdrawAmount = ethers.utils.parseEther("0.5");
    let excessiveAmount = ethers.utils.parseEther("2");

    beforeEach(async function () {
        // Get the ContractFactory and Signers
        SlashStore = await ethers.getContractFactory("SlashStore");
        [owner, recipient] = await ethers.getSigners();
        zeroAddress = ethers.constants.AddressZero;

        // Deploy the contract
        slashStore = await SlashStore.deploy();
        await slashStore.deployed();

        // Initialize the contract
        await slashStore.initialize(owner.address);

        // Fund the contract
        await owner.sendTransaction({
            to: slashStore.address,
            value: initialBalance
        });
    });

    it("should allow owner to withdraw funds successfully", async function () {
        const initialRecipientBalance = await ethers.provider.getBalance(recipient.address);

        // Withdraw funds
        await expect(() => slashStore.connect(owner).withdraw(recipient.address, withdrawAmount)).to.changeEtherBalances(
            [slashStore, recipient],
            [-withdrawAmount, withdrawAmount]
        );

        // Check balances
        const contractBalance = await ethers.provider.getBalance(slashStore.address);
        expect(contractBalance).to.equal(initialBalance.sub(withdrawAmount));

        const recipientBalance = await ethers.provider.getBalance(recipient.address);
        expect(recipientBalance).to.be.closeTo(initialRecipientBalance.add(withdrawAmount), ethers.utils.parseUnits("0.01", "ether"));
    });

    it("should revert if withdrawing to the zero address", async function () {
        await expect(slashStore.connect(owner).withdraw(zeroAddress, withdrawAmount))
            .to.be.revertedWith("Cannot withdraw to the zero address");
    });

    it("should revert if withdrawing more than the contract balance", async function () {
        await expect(slashStore.connect(owner).withdraw(recipient.address, excessiveAmount))
            .to.be.revertedWith("Insufficient balance");
    });

    it("should revert if non-owner tries to withdraw", async function () {
        const [_, nonOwner] = await ethers.getSigners();
        await expect(slashStore.connect(nonOwner).withdraw(recipient.address, withdrawAmount))
            .to.be.revertedWith("Ownable: caller is not the owner");
    });

    it("should handle withdrawal of zero amount", async function () {
        // Withdraw zero amount
        await expect(() => slashStore.connect(owner).withdraw(recipient.address, 0)).to.not.changeEtherBalance(recipient, 0);

        // Check that contract balance remains unchanged
        const contractBalance = await ethers.provider.getBalance(slashStore.address);
        expect(contractBalance).to.equal(initialBalance);

        // Check that recipient balance remains unchanged
        const recipientBalance = await ethers.provider.getBalance(recipient.address);
        expect(recipientBalance).to.be.closeTo(initialRecipientBalance, ethers.utils.parseUnits("0.01", "ether"));
    });
});

```

Tests:
- should allow owner to withdraw funds successfully: Verifies successful withdrawals and correct balance updates.
- should revert if withdrawing to the zero address: Tests that withdrawing to the zero address reverts.
- should revert if withdrawing more than the contract balance: Tests that attempting to withdraw more than the available balance reverts.
- should revert if non-owner tries to withdraw: Ensures only the owner can withdraw funds.
- should handle withdrawal of zero amount: Verifies that withdrawing zero amount does not affect balances.

## Recommended Mitigation Steps
```
function withdraw(address to, uint256 weiAmount) external nonReentrant onlyOwner {
    require(to != address(0), "Invalid address");
    require(address(this).balance >= weiAmount, "Insufficient balance");

    Address.sendValue(payable(to), weiAmount);
    emit NodeETHWithdrawn(address(this), to, weiAmount);
}
```
