# Vulnerability details

## Impact
Erroneous admin actions can cost a DSS functionality (and then all the Core functionality). Because updateGasValues in Corelib doesnot check gas limits we can set them to zero or very low.
```sol
    function updateGasValues(
        Storage storage self,
        uint32 _hookCallGasLimit,
        uint32 _supportsInterfaceGasLimit,
        uint32 _hookGasBuffer
    ) internal {
        self.hookCallGasLimit = _hookCallGasLimit;
        self.hookGasBuffer = _hookGasBuffer;
        self.supportsInterfaceGasLimit = _supportsInterfaceGasLimit;
    }
```

## Proof of Concept
1) admin sets hookCallGasLimit=0 and hookGasBuffer=0
2) callHook in HookLibrary always fails because check become `gasleft() < 0`
```sol
    function callHook(
        address target,
        bytes memory data,
        bool ignoreFailure,
        uint32 hookCallGasLimit,
        uint32 hookGasBuffer
    ) internal returns (bool) {
        if (gasleft() < (hookCallGasLimit * 64 / 63 + hookGasBuffer)) revert NotEnoughGas();

        (bool success, bytes32 returnData) = performLowLevelCallAndLimitReturnData(target, data, hookCallGasLimit);

        if (!ignoreFailure && !success) revert DSSHookCallReverted(returnData);

        if (success) emit HookCallSucceeded(returnData);
        else emit HookCallFailed(returnData);
        return success;
    }
```

## Recommended Mitigation Steps
```sol
    function setGasValues(uint32 _hookCallGasLimit, uint32 _hookGasBuffer, uint32 _supportsInterfaceGasLimit)
        external
        onlyRolesOrOwner(Constants.MANAGER_ROLE)
    {
         if (_hookCallGasLimit > 0 && _supportsInterfaceGasLimit > 0 && _hookGasBuffer > 0) { // or you can add another checks
            _self().updateGasValues(_hookCallGasLimit, _supportsInterfaceGasLimit, _hookGasBuffer);
        }
    }
```
