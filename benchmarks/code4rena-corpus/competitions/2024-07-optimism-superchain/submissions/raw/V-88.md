# Vulnerability details

### Vulnerabilities in the Contract

### **Blockhash Function Limitation**
**Issue:**
The `blockhash` function only provides access to block hashes of the most recent 256 blocks.

**Impact:**
If the dispute game creation relies on a block hash older than 256 blocks, the `blockhash` function will return zero, leading to potential failures or incorrect initializations.

**Solution:**
Add a check to ensure that the parent block hash is not zero.

```solidity
bytes32 parentHash = blockhash(block.number - 1);
require(parentHash != bytes32(0), "Blockhash unavailable");
