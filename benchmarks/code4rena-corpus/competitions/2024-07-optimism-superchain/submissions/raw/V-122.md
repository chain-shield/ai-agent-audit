# Vulnerability details

## Vulnerability detail
The vulnerability in the `findLatestGames` function stems from an incorrect loop condition that prevents the function from iterating over the intended range of indices in the `_disputeGameList`. Specifically, the loop is designed to search backward from the index `_start` down to 0, but the condition `i >= 0 && i <= _start` ensures that the loop either does not execute at all (if `_start` is not 0) or executes just once (if `_start` is 0)

The loop condition consists of two parts combined with a logical AND operator (`&&`):

- `i >= 0`: This condition checks if the current index `i` is greater than or equal to 0. Since `i` is initialized to `_start`, and `_start` is presumably a positive integer (or at least not negative), this condition will always be true.

- `i <= _start`: This condition checks if `i` is less than or equal to `_start`. Given that `i` is initialized to `_start`, this condition will also always be true.

Issue: For the loop to execute even a single iteration, both conditions must be true simultaneously. However, this is impossible because `i` cannot be both greater than or equal to 0 and less than or equal to `_start` at the same time. The only scenario where both conditions could theoretically be true is if `_start` is exactly 0, but this would mean the loop has no iterations to begin with
## Impact
The function fails to search through the entire range of games from `_start` to 0, potentially missing relevant games that match the specified criteria. This could lead to incomplete or inaccurate search results

## Proof of Concept
The issue is evident in the loop below
```solidity
        for (uint256 i = _start; i >= 0 && i <= _start;) {
    ...
}
```

## Recommended Mitigation Steps
- Modify the loop condition to ensure it iterates over the intended range of indices. The corrected condition should be `i >= _start && i < 0`, allowing the loop to execute for each index from `_start` down to 0.
```
for (uint256 i = _start; i >= 0; i--) {
    ...
}
```
