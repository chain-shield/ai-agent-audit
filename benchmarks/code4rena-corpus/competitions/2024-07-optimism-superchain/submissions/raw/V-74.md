# Vulnerability details

## Summary
If a game is created with big MAX_GAME_DEPTH and attacker keep attacking, it would cost too much for a honest player to win the game.

## Vulnerability Detail
For a honest party to win a game, player should keep attacking malicious players when they make a claim. If the MAX_GAME_DEPTH is too big, player should put lots of bonds to get to the final step. 

## Tools Used
Manual Review

## Recommended Mitigation Steps
Change the way to calculate bonds.
