# Vulnerability details

## Summary
Attack and Defense for a claim both use the same clock. Attacker can take advantage of this to reverse chess clock.

## Impact
Malicious attacker can gain more time while shorten the others', make the game resolved incorrectly.

## Vulnerability Detail
1. Here's the chain of attack: `0(root claimer) <- 1(attacker) <- 2(root claimer) <- 3(attacker) <- 4(root claimer)`,
2. When the time to challenge 2 is about to end, honest player Bob come to support root by creating a defense 5 to 2.
3. Attacker then attack Bob's defense 5, thus reverse the chess clock.

## Tools Used
Manual Review

## Recommended Mitigation Steps
Change the way to calculate nextDuration when the move is a defense.
