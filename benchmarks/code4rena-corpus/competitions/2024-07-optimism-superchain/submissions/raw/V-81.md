# Vulnerability details

### Vulnerabilities in the Contract

**Unchecked External Calls**:
    - The contract makes external calls without proper validation of their results. For instance, `WETH.deposit{ value: msg.value }()` and `oracle.loadLocalData()`.
    - **Mitigation**: Check the success of these external calls using proper error handling mechanisms.

### Suggested Improvements

**External Call Validation**:
    ```
    function initialize() public payable virtual nonReentrant {
        // ... existing code ...

        // Deposit the bond.
        (bool success,) = address(WETH).call{ value: msg.value }(abi.encodeWithSignature("deposit()"));
        require(success, "WETH deposit failed");

        // Set the game's starting timestamp
        createdAt = Timestamp.wrap(uint64(block.timestamp));
    }
    ```
