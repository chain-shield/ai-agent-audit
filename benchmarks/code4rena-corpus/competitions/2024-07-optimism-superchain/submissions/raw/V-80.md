# Vulnerability details

### Vulnerabilities in the Contract

**Reentrancy Attack in `initialize` Function**:
    - The `initialize` function calls `WETH.deposit{ value: msg.value }()`, which transfers Ether. If the `WETH` contract has a callback mechanism, this could lead to a reentrancy attack.
 **Reentrancy Attack in `resolve` Function**:
    - The `resolve` function calls `ANCHOR_STATE_REGISTRY.tryUpdateAnchorState()` without proper validation. If this external call can execute arbitrary code, it could lead to a reentrancy attack.
    - **Mitigation**: Implement a reentrancy guard using the `nonReentrant` modifier from OpenZeppelin's `ReentrancyGuard`.
