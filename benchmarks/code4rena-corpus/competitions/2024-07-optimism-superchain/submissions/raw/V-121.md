# Vulnerability details

## Vulnerability detail
The `setCountered` function in the `CannonTypes.sol` does not correctly clear the relevant bits before setting the countered flag. 
The other setter functions (`setTimestamp`, `setPartOffset`, etc.) follow a consistent pattern of first clearing the target bits and then setting the new value. This pattern ensures that the new value is correctly applied without residual bits from previous values. The `setCountered` function should follow the same pattern to maintain consistency and correctness.

It also employs a mask designed for a 64-bit segment instead of targeting the intended single bit.
The operation attempts to extract the entire 64-bit segment, instead of isolating the 255th bit, which is intended to represent the boolean `countered` flag.
This method does not correctly isolate the 255th bit, leading to potential misinterpretation of the `countered state`.
## Impact
The `countered` flag may not reflect the intended boolean value, causing logical errors in the application’s functionality. For instance, if the flag is set to `true` when it should be `false`, or vice versa, this could disrupt the expected behavior of critical functions.

function setCountered(LPPMetaData _self, bool _countered) internal pure returns (LPPMetaData self_) {
    assembly {
        self_ := or(_countered, and(_self, not(U64_MASK)))
    }
}
```
Issues:
- Lack of Clearing: The function does not clear the bit before setting it, leading to potential residual values.
- Incorrect Masking: The function uses `U64_MASK` (0xFFFFFFFFFFFFFFFF), which targets the lower 64 bits instead of the intended single bit.

## Recommended Mitigation Steps
- Ensure the bit is correctly cleared before setting the new value
- Use a single bit to represent the boolean value
```
function setCountered(LPPMetaData _self, bool _countered) internal pure returns (LPPMetaData self_) {
    assembly {
        // Create a mask to clear the 255th bit
        let mask := shl(255, 1)
        // Clear the 255th bit and then set it based on _countered
        self_ := or(shl(255, _countered), and(_self, not(mask)))
    }
}
