# Vulnerability details

### Vulnerabilities in the Contract

**Direct Access to State Variables**:
    - Direct access to state variables like `claimData`, `subgames`, and `resolutionCheckpoints` can lead to inconsistencies if not managed properly.
    - **Mitigation**: Use private variables with getter functions to control access and ensure data integrity.

### Suggested Improvements

**Private State Variables with Getters**:
```solidity
    // Make state variables private
    ClaimData[] private _claimData;
    mapping(uint256 => uint256[]) private _subgames;
    mapping(uint256 => ResolutionCheckpoint) private _resolutionCheckpoints;

    // Add getter functions
    function getClaimData(uint256 index) public view returns (ClaimData memory) {
        return _claimData[index];
    }

    function getSubgames(uint256 index) public view returns (uint256[] memory) {
        return _subgames[index];
    }

    function getResolutionCheckpoints(uint256 index) public view returns (ResolutionCheckpoint memory) {
        return _resolutionCheckpoints[index];
    }
