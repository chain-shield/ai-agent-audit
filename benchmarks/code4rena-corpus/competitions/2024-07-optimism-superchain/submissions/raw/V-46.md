# Vulnerability details

## Impact
anyone can call `load**` functions and modify the data, the fucntion `readPreimage` may get wrong data.

## Proof of Concept
take function `loadLocalData`  for example:  

this function is external but don't have access control, and when modify key value, don't check key value exist or not.
