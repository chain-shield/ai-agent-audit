# Security Policy

## Supported Releases

The project is currently in GitHub beta. Security fixes are applied on a best-effort basis to the latest default branch.

## Reporting A Vulnerability

Please do not open a public GitHub issue for a suspected security vulnerability in this repository.

Instead, send a private report to the maintainers with:

- A clear description of the issue
- Reproduction steps or a proof of concept
- Impact and affected components
- Any suggested remediation if you have one

If you already have a secure maintainer contact channel, use that. If not, open a minimal GitHub issue asking for a private contact route without disclosing details.

## Disclosure Guidance

- Give maintainers reasonable time to investigate and fix the issue before public disclosure.
- Avoid publishing exploit details for unpatched vulnerabilities.
